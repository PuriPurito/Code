## Особенности физической структуры данных для различных типов СУБД

**1\. XML**

Хранение объектов - каждый объект в своем XML файле в папке wt\_data\\objects в папке сервера

Хранение каталогов - Бинарные индексные файлы в папке wt\_data\\catalogs в папке сервера

**2\. MS SQL\\Oracle\\PostgreSQL**

Хранение объектов - запись в таблице с именем типа объекта. Данные в поле data (типа XML). Идентификатор в поле ID

Также существует дополнительная таблица (spxml\_objects) с атрибутами ID (объекта), Form (тип объекта), FormURL (URL объекта), created, modified, is\_deleted

Хранение каталогов - таблица (имя типа объекта + s)

**3\. Microsoft Azure**

Хранение объектов - запись в таблице Azure Table Storage. Данные в поле data (типа XML). Идентификатор в поле ID

Cуществует таблица в SQL (spxml\_objects) с атрибутами ID (объекта), Form (тип объекта), FormURL (URL объекта), created, modified, is\_deleted

Хранение каталогов - таблица в SQL (имя типа объекта + s)
