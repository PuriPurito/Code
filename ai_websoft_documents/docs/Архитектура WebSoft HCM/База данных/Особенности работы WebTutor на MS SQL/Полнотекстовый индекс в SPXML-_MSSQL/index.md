## Полнотекстовый индекс в SPXML->MSSQL

Мост SPXML->SQL максимально использует возможности MS SQL 2005/2008/2012, полнотекстовый поиск - не исключение, поэтому для каждой базы WebTutor создается полнотекстовый индекс с каталогом по-умолчанию , который имеет наименование базы данных при ее создании.  
В ранних версиях моста для таблиц WebTutor определялось автоматическое обновление индекса при изменении таблицы, также как и при использовании внутренней базы, но это явно создавало большую нагрузку на сервер , поэтому начиная с версии 1.2.2.1 всем таблицам указано ручное обновление индекса. Да , теперь, это требует от администратора SQL вручную настроить агента (SQL Job), в котором будет указано выполнение процедуры обновления и его частота. Рассмотрим как это сделать:  
  
Откройте базу SQL Server Management Studio и раскойте Storage\\Full Text Catalogs , там, скорее всего, будет единственный каталог с таким же наименованием как и база (как на рис. внизу).  
  
  
  
Здесь мы удостоверились, что нам известно наименование каталога , оно нам понадобится для создания агента.  
Переходим в раздел SQL Server Agent (он должен быть установлен и работать как сервис) -> правой кнопкой мыши указываем "New Job" и заполняем поля , примерно как указано на рис. (вместо Owner "sa" желательно указывать пользователя базы данных).  
  
Пример:  
Name: WT\_TEST173\_FT\_UPDATE  
Owner: sa  
Category: Full-Text  
Description: WT\_TEST173 Fulltext Incremental Update  
  
  
  
  
  
Переходим в раздел "Steps" и указываем соотв. действия:  
  
Пример:  
Step Name: Update FT Index  
Type: T-SQL  
Database: wt\_test173 (здесь указываете свою базу данных)  
Command: exec **sp\_fulltext\_catalog** @ftcat='wt\_test173',@action= 'start\_incremental' (в переменной @ftcat указываете наименование каталога, обычно совпадает с наименованием базы данных)  
  
  
**Внимание!**  
  
В системе используется "Incremental Timestamp-Based Population" , от процедуры **sp\_fulltext\_catalog** при настройке агента по полнотекствому индексу можно отказаться.  
  
В разделе "Steps" в поле command вместо exec sp\_fulltext\_catalog @ftcat='wt\_test173',@action= 'start\_incremental' вставить код данного скрипта
