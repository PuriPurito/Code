## Особенности работы WebTutor на MS SQL

Данные внутри базы MS SQL 2005/2008/2012 хранятся в отдельных таблицах документов, каждая таблица характеризует тип документа, в поле типа xml содержится сам документ, схема описания xsd описывается в соответствии с описанием типа документа (xmd), каталоги также хранятся в отдельных таблицах и содержат поля, указанные в описаниях соответствующих каталогов
