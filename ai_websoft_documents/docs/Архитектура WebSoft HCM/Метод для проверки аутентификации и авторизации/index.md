## Метод для проверки аутентификации и авторизации

**Проверка аутентификации и авторизации**

**Аутентификация** — это процесс проверки подлинности пользователя, чтобы убедиться, что он является тем, за кого себя выдает. Для аутентификации пользователи могут вводить логин и пароль, биометрические данные или другие методы идентификации.

**Авторизация** — это процесс проверки прав доступа пользователя к определенным ресурсам или функциям. Он проводится после успешной аутентификации.

Начиная с релиза 2023.2 может быть использован следующий метод для проверки аутентификации и авторизации в приложении, плеере и т.д.:

1) Запустите файл index.html приложения (плеера, виртуального класса и т.д.)

2) Выполните запрос к API для того, чтобы узнать, авторизован и аутентифицирован ли пользователь.

3) Если пользователь не авторизован и не аутентифицирован, откройте _iframe_ со страницей входа.

Адрес ссылки на страницу можно узнать в разделе **Сайты – Сайт по умолчанию** программы **Администратор**:

Элемент _iframe_ можно растянуть на весь экран или добавить во всплывающее диалоговое окно.

4) После срабатывания события onload элемента iframe должен быть запущен обработчик приложения:

window.addEventListener(  
        'message',  
        (e) => {  
          if (e.data === 'on-signed-in') {  
            // Пользователь зашел, делаем повторную инициализацию в приложении  
          }  
        },  
        false  
      )

5) После входа в iframe запускается через postMessage событие user\_init.html, уведомляющее о завершении аутентификации.

Администратор системы или приложения может получить сообщение с информацией о том, что что пользователь зашел в систему.

6) После этого диалоговое окно iframe в приложении может быть удалено и страница может быть повторно инициализирована.

Авторизация пользователя завершена.
