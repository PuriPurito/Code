## Правила удаления объектов

Удалить объект (электронную карточку) можно разными способами:

*   администратором через интерфейсную команду меню **Удалить запись** в списке объектов;
*   администратором через интерфейсную команду меню **Удалить документ** в открытой экранной форме объекта;
*   программистом через программный код с выполнением метода DeleteDoc.

При удалении объектов в интерфейсе системы они (объекты) помещаются в корзину и становятся недоступны пользователю. Их можно восстановить или удалить окончательно в разделе **Системное администрирование** → **Корзина**.

При удалении объекта программным кодом поведение системы зависит от второго параметра метода DeleteDoc: _false_ помещает объект в корзину, _true_ – безвозвратно удаляет его из системы.

Для объектов, содержащих связанные большие бинарные данные, например, для ресурсов базы, есть особенности процесса хранения объектов и их удаления.

Такие объекты хранятся в системе в двух сущностях: собственно XML объекта – в одной таблице СУБД и бинарные данные (файл) – в виде блоба в другой таблице (или файла в файловой системе).

Особенность удаления таких объектов состоит в том, что при удалении в корзину файл/блоб в системе физические никуда не перемещается, а остается на своем месте.

При удалении пользователем из интерфейса объекта из корзины файл/блоб физически удаляется с сервера, освобождая место. Но при удалении программым кодом, используя метод DeleteDoc( url, true ), файл/блоб физически не удалется с сервера и остается там, «отвязанный» от всех связей с объектом.

Поэтому корректно невозвратное удаление объекта с бинарными данными (типа ресурсов базы) из системы (минуя корзину) программным кодом производится с помощью команды:

_ms\_tools.delete\_resource ( oResourceParam, true )_, где oResourceParam – ID удаляемого ресурса.
