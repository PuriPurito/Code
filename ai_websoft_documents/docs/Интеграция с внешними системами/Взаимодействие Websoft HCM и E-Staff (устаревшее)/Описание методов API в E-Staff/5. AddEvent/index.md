## 5. AddEvent

Метод добавляет/обновляет событие. Если в параметрах указан опциональный идентификатор (_opt\_eid_) события, то ищется и обновляется это событие или создается новое. Если идентификаторы не заданы, создается новое событие.

**Входные параметры:**

**Параметр**

**Тип**

**Описание**

**Обязат.**

event

Структура для указания события

Да

Параметры структуры _event_:

**Параметр**

**Тип**

**Описание**

**Обязат.**

id

integer

Идентификатор события

Да

eid

string

Внешний идентификатор события. Задается здесь или в поле opt\_eid. Если задан здесь, то отсутствие в системе события с таким идентификатором приведет к ошибке. Используется для обновления существующих событий

Нет

opt\_eid

string

Идентификатор события. Если задан здесь, то при отсутствии в системе события с таким идентификатором будет создано новое событие

Нет

date

date

Дата события

Да

candidate\_id

integer

Да

candidate\_eid

string

Внешний идентификатор кандидата

Да

vacancy\_skip

bool

Вакансия может быть пропущена.  
Значение по умолчанию - _false_.

Нет

integer

string

Внешний идентификатор вакансии

Признак каландарного события

Да

participants

Структура для описания участников события

Нет

string

Комментарий

Да

web\_url

string

participant\_web\_url

string

Ссылка на портал для участника

Да
