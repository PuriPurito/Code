## 4. AddDivision

Метод добавляет или обновляет подразделение. Если в параметрах указан один из идентификаторов подразделения, то ищется и обновляется это подразделение. Если идентификаторы не заданы, создается новое подразделение.  
  
Метод позволяет создать/обновить массив сотрудников, описанных аналогично методу AddPerson.

**Входные параметры:**

**Параметр**

**Тип**

**Описание**

**Обязат.**

Структура для описания подразделения

Да

options

Структура для задания параметров процесса

Нет

embedded

Структура для задания массива сотрудников

Нет
