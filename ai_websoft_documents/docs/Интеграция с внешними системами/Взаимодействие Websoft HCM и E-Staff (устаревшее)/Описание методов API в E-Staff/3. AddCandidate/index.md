## 3. AddCandidate

Метод добавляет/обновляет кандидата. Если в параметрах указан один из идентификаторов кандидата, то ищется и обновляется этот кандидат или создается новый. Если идентификаторы не заданы, создается новый кандидат.

**Входные параметры:**

**Параметр**

**Тип**

**Описание**

**Обязат.**

candidate

Структура для указания кандидата

Да

Параметры структуры _candidate_:

**Параметр**

**Тип**

**Описание**

**Обязат.**

api\_type\_replacement

integer

Тип замещения полей  
(значение по умолчанию - 0):

*   0 – замена только заполненных полей из источника, отсутствующие поля источника пропускаются (в документе E-Staff значения не меняются при этом), пустые поля источника очищаются в документе E-Staff (например, _<profession\_id></profession\_id>_ удалит все значения массива профессий);
*   1 – замена только полей, которые еще не имеют значений в документе E-Staff,
*   2 – замена всех полей из источника с очисткой в документе E-Staff всех полей, значения которых не заданы в источнике.

Нет

opt\_code

string

Код кандидата. Используется для поиска существующего кандидата по коду. Если документ с таким кодом не найден, то будет создан новый кандидат

Да

opt\_eid

string

Внешний идентификатор кандидата. Используется для поиска существующего кандидата по inet\_uid. Если документ с таким кодом не найден, то будет создан новый кандидат

Да

html\_resume

string

Резюме в формате HTML

Да

vacancy\_id

integer

Идентификатор вакансии

Да

vacancy\_eid

string

Внешний идентификатор вакансии

Да

vacancy\_code

string

Код вакансии

Да
