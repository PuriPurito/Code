## 9. GetDocFields

Метод возвращает запрошенный набор полей документа. На вход в параметр request подается тип документа и один из следующих идентификаторов: _ID, eid_ или _code_. Также задается набор полей, которые необходимо вернуть из документа. Метод позволяет получать вложенные поля относительно текущего документа. Например, если в документе есть поле _user\_id_, указывающее на каталог _user_, то можно получить код связанного сотрудника.
