## Описание объекта api_estaff.xml

## **Местоположение файла**  
Файл _api\_estaff.xml_ размещен в папке _source_ программы **Websoft HCM**.  
 

## **Инициализация объекта и вызов методов**  
Особенности инициализации объекта и вызова его методов указаны в разделе **"Описание методов API в E-Staff"**.  
 

## **Доступные методы**  
На стороне **E-Staff** реализован модуль. Доступные для вызова методы определены в файлах api.xml и api.js, которые размещены в папке module\_wtapi, скопированной из дистрибутива **Websoft HCM** (см. раздел "**Настройка системы E-Staff**").

### **TestAccess**  
Тестовый метод для проверки доступа к E-Staff. Выводит в лог E-Staff сообщения о вызове метода, проверяет наличие доступа в параметрах и возвращает переданное на вход сообщение.

### **AddAttachment**  
Метода добавляет приложение _binary_ в заданный документ.

### **AddCandidate**  
Метод добавляет/обновляет кандидата. Указание вакансии, на которую претендует кандидат, опционально.

### **AddDivision**  
Метод добавляет/обновляет подразделение. Если в параметрах указан один из идентификаторов подразделения, то ищется и обновляется это подразделение. Если идентификаторы не заданы, создается новое подразделение.  
Метод позволяет создать/обновить массив сотрудников, описанных аналогично методу _AddPerson_.

### **AddEvent**  
Метод добавляет/обновляет событие. При создании нового события передача вакансии и кандидата обязательны.

### **AddPerson**  
Метод добавляет/обновляет сотрудника. Если в параметрах указан один из идентификаторов сотрудника, то ищется и обновляется этот сотрудник. Если идентификаторы не заданы, создается новый сотрудник.

### **AddVacancy**  
Метод добавляет вакансию. Список параметров определен в файле _api.xml_. Возвращает ID созданной вакансии.

### **GetAttachments**  
Метод возвращает массив прикрепленных к объекту приложений.

### **GetDocFields**  
Метод возвращает запрошенный набор полей документа. На вход в параметр request подается тип документа и один из следующих идентификаторов: _ID, eid_ или _code_. Также задается набор полей, которые необходимо вернуть из документа. Метод позволяет получать вложенные поля относительно текущего документа. Например, если в документе есть поле _user\_id_, указывающее на каталог _user_, то можно получить код связанного сотрудника: _user\_id.ForeignElem.person\_id.ForeignElem.code_.  
Если при вычислении значения поля произошла ошибка, будет возвращено значение без тега _<value/>_, а в логе E-Staff будет выведена ошибка.

### **GetXQuery**  
Метод возвращает запрошенный набор полей из запроса xquery. На вход в параметр request подается запрос. Также задается набор полей, которые необходимо вернуть из каталога (параметр _value_) или документа (параметра _doc\_value_). Метод позволяет получать вложенные поля относительно текущего элемента каталога или документа.
