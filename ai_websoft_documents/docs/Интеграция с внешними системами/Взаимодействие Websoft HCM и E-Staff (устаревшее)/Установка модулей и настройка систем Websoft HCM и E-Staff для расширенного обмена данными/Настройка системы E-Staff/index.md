## Настройка системы E-Staff

## **Установка модуля**

1.  Для установки модуля перепишите директорию _module\_wtapi_ из дистрибутива (расположение _..\\WebSoftServer\\wtv\\estaff\\module\_wtapi\\_) в директорию, в которую установлен сервер **E-Staff**.
2.  В файле _xHttp.ini_ подключите добавленный модуль. Для этого добавьте строку:  
    **USE-MODULE: module\_wtapi**  
    Примечание: Поскольку файл _xHttp.ini_ заменяется при установке/обновлении, то лучше использовать отдельный файл  _xHttp1.ini_ в корне сервера, который не меняется при обновлении, и в нем уже указать подключаемые модули.
3.  Перезапустите сервер **E-Staff**.

## **Настройка доступа к модулю**

Модуль позволяет ограничить по IP-адресу, логину и названию метода обращения к своему интерфейсу. По умолчанию открыты для доступа все возможности модуля для любых обращений. Если есть необходимость ограничить возможности обращений к системе **E-Staff** выполните нижеприведенные настройки.

В приложении **E-Staff Рекрутер** откройте меню **Сервис -> Администрирование**:

Откройте в разделе **Администрирование -> Общие настройки** пункт **Настройки API**:

В открывшемся окне укажите при обращении с каких IP-адресов каким пользователям E-Staff какие методы допускается выполнять.  
Списки логинов и методов разделяются точкой с запятой. Символ «звездочка» снимает ограничение в поле, в котором она указана.

Список методов:

1.  **TestAccess** – тестовый метод для проверки доступа,
2.  **AddAttachment** – добавить приложение в документ,
3.  **AddCandidate** – добавить/изменить кандидата,
4.  **AddDivision** – добавить/изменить подразделение,
5.  **AddEvent** – добавить/изменить событие,
6.  **AddPerson** – добавить/изменить сотрудника,
7.  **AddVacancy** – добавить/изменить вакансию,
8.  **GetAttachments** – получить список приложений,
9.  **GetDocFields** – получить поля документа,
10.  **GetXQuery** – получить поля запроса XQuery.

Доступ к методам для изменения объектов ограничивается настройкой «**Доступ только на просмотр**» уровня доступа сотрудника.
