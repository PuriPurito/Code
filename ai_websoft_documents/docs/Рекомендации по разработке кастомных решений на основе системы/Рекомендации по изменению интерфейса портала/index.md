## Рекомендации по изменению интерфейса портала

Изменение интерфейса портала рекомендуется производить с использованием **редактора интерфейсов (конструктора страниц)**.

При создании пользовательского интерфейса портала необходимо обратить внимание на следующие основные положения:

•             Если требования заказчика могут быть реализованы с помощью конструктора страниц, то используем его (в том числе могут быть использованы коллекции, удаленные действия и показатели).

•             Для тех страниц, которые не могут быть реализованы с помощью редактора используем любой из допустимых фреймворков (JQuery, Vue), но в процессе реализации программно-аппаратной части сервиса (бэкенда) обращаемся к коллекциям, удаленным действиям и показателям (отдельная инструкция будет опубликована позднее).
