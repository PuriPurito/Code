## Правила формирования объектов с программным кодом и имен файлов

Объекты, входящие в состав приложения, отображаются на карточке приложения (в разделе **Дизайнер – Приложения** – \[Код\_приложения\]) на вкладке **Объекты.**

•             Любой объект, связанный с выполнением программного кода, содержит только ссылку на исполняемый файл из библиотеки приложения (и ничего больше – ни переменных, ни вложенного программного кода).  
•             В названии файлов рекомендуется указывать код объекта, к которому файл относится, с добавлением соответствующего расширения.  
•             Файлы, относящиеся к приложению, рекомендуется размещать в директории приложения – _\[WebSoftServer\]/applications/\[код\_приложения\]_.  
•             Рекомендуемые допустимые расширения файлов, имеющих отношение к приложению: xml, xaml, html, bs, css (другие расширения нежелательны, чтобы не возникали проблемы с пересылкой вложений по почте).  
•             Все коды и названия файлов должны писаться строчными (маленькими) буквами, чтобы не было проблем имплементации на Linux-версиях (поскольку Linux регистрозависим).  
 

В состав объектов приложения рекомендуется включать:

•             иконку приложения (ресурс базы);  
•             все программные объекты, связанные с приложением (шаблоны, элементы шаблонов, агенты, выборки, удаленные действия, карточки библиотек и т.д.);  
•             дополнительные ресурсы (если они есть). Если в программном коде объектов (например, шаблонов портала) используются дополнительные ресурсы (_js, css_), то их рекомендуется помещать в директорию приложения; для них создаются шаблоны, и они включаются в состав объектов приложения, а ссылка на них оформляется в виде _custom\_web\_template.html?custom\_web\_template\_id= ._  
•             аналогично, если в составе приложения имеются графические элементы, то они размещаются в ресурсах базы, добавляются в состав объектов приложения, а ссылка на них имеет вид _download\_file.html ._
