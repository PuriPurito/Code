## Рекомендации по изменению бизнес-логики сервера

Изменение бизнес-логики сервера рекомендуется производить с помощью создания **пользовательских библиотек**.

При создании пользовательской библиотеки необходимо обратить внимание на следующие основные положения:

•             Основные функции бизнес-логики хранятся в одной или нескольких библиотеках, созданных разработчиком.

•             Выборки данных для портальных интерфейсов реализуются в виде коллекций, использующих функции из библиотек.

•             Серверные операции реализуются в виде удаленных действий (независимо от того, имеется ли у них пользовательский интерфейс (UI) для задания параметров операции). Удаленные действия обращаются к функциям из библиотек.

•             Данные для информеров/виджетов реализуются в виде показателей, использующих функции из библиотек.

•             Код внутри объектов должен быть минимизирован (он может использоваться только там, где нельзя без этого обойтись).
