## Общая архитектура кастомизации

Пользовательское автоматизированное решение обычно состоит из следующих компонентов:

•             Интерфейс настроек и администрирования (формируется с помощью пользовательских приложений).

•             Бизнес-логика сервера (формируется с помощью пользовательских библиотек).

•             Интерфейс портала (формируется с помощью редактора интерфейсов (конструктора страниц)).
