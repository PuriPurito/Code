## API

Функционал предназначен для обеспечения возможности взаимодействия с объектами WebTutor и выполнения различных операций путем выполнения команд из внешней системы. 

Варианты использования:  
\- интеграция со внешними системами (учет кадров, аналитика, учет финансов, корпоративный портал, система электронного документооборота и т.п.)  
\- использование WebTutor как бэк-енд систему, с реализацией пользовательского интерфейса на внешнем (по отношению к WT) портале

Существует два варианта реализации API:  
\- версия 1 реализует обработку запросов по стандарту SOAP в формате XML (поддерживается, начиная с версии WebTutor 2.7)  
\- версия 3 реализует обработку запросов по стандарту OPEN API в формате JSON (поддерживается, начиная с версии WebTutor за 2 квартал 2019 г. (2019.2.3))
