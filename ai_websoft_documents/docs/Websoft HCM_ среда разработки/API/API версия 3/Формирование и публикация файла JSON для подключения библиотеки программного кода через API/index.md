## Формирование и публикация файла JSON для подключения библиотеки программного кода через API

Для корректного подключения (публикации) стандартной библиотеки программного кода через API (данная функциональность добавлена в релизе 2021.2)необходимо сформировать файл описания в формате JSON.

Данный файл формируется автоматически из соответствующих файлов JS библиотек программного кода. Генерация файлов JSON производится на основании JsDoc-вставок перед функциями в JS -файлах библиотек.

Для генерации необходимо выполнить следующие действия:

\- скачать фреймворк **Node.js** (например, отсюда: https://nodejs.org/en/download/) и установить его на локальный компьютер

\- запустить консоль **Node.js** и выполнить следующую команду установки расширения JsDoc:

`npm install -g jsdoc`

\- для публикации функций библиотеки программного кода выполните команду:

`jsdoc -X “c:\folder\file.js” > “c:\folder\file.json”`

где:

_c:\\folder\\file.js_ – путь к файлу библиотеки (здесь необходимо указать реальный путь к файлу библиотеки),

_c:\\folder\\file.json_ – путь к файлу JSON описания, который будет получен (здесь необходимо указать реальный путь к файлу JSON описания).

Начиная с релиза 2023.2 в JsDoc-описаниях используется импортирование описаний стандартных типов данных, вынесенных в отдельный файл.

К сожалению, стандартная библиотека JsDoc не поддерживает такой импорт. если вы получаете ошибку при генерации JSON, надо сделать следующее:

а) Установить компонент jsdoc-to-markdown 

npm install --save-dev jsdoc-to-markdown

б) Установить компонент jsdoc-tsimport-plugin

npm install --save-dev jsdoc-tsimport-plugin

Устанавливать оба компонента следует из директории текущего пользователя (%USERPROFILE%)

в) Подключить компонент, **создав** в любом месте (например c:\\temp) и отредактировав файл конфигурации приложения jsdoc2md - **conf.json**  
(адрес в разделе plugins - место размещения tsimport, обычно в директории текущего пользователя, т.е. надо заменить Websoft в строке на свое имя пользователя)

{  
    "tags": {  
        "allowUnknownTags": true  
    },  
    "source": {  
        "includePattern": ".+\\\\.js(doc|x)?$",  
        "excludePattern": "(^|\\\\/|\\\\\\\\)\_"  
    },  
    "plugins": \[  
        "C:\\\\Users\\\\Websoft\\\\node\_modules\\\\jsdoc-tsimport-plugin\\\\index.js"  
    \],  
    "templates": {  
        "cleverLinks": false,  
        "monospaceLinks": false,  
        "default": {  
            "outputSourceFiles": true  
        }  
    }  
} `\`

 г) запустить генерацию описания можно в командной строке (адрес файла запуска, адрес файла конфигурации, исходного js и выходного json надо поменять на свои).

C:\\Users\\Websoft\\node\_modules\\.bin\\jsdoc2md -c c:\\temp\\conf.json --jsdoc --json c:\\temp\\course\_library.js > c:\\temp\\course\_library.json

Можно также создать командный файл с таким содержимым:

%USERPROFILE%\\node\_modules\\.bin\\jsdoc2md -c c:\\temp\\conf.json --jsdoc --json %1 > %~n1.json

Также необходимо сформировать соответствующие настройки в профиле безопасности.
