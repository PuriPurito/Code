## Варианты использования API

## Low-Level (низкоуровневый вариант использования)

На данном уровне предоставляется возможность работать непосредственно с объектами системы WebTutor. В зависимости от настроек возможно предоставить права на чтение списка объектов системы, создание, удаление, модификацию объекта.

Список доступных объектов и вариантов действий над ним настраивается индивидуально для каждого пользователя API/внешнего приложения/системы.

Доступ (создание/чтение/изменение/удаление/список) может быть предоставлен к любым существующим в системе объектам. Дополнительного программирования не требуется.

## High-Level (высокоуровневый вариант использования)

На данном уровне представляется возможность выполнять конкретные функции/операции, и только их. Для реализации данного функционала, помимо настроек доступа, функция должна быть описана и запрограммирована в системе.

В данном варианте разделение доступа заключается в определении списка доступных функций для пользователя. 

В высокоуровневом варианте использования, начиная с релиза 2021.2, появилась возможность публикации **функций, входящих в состав стандартных коробочных библиотек** (разрешается их использование и предоставляется описание параметров). Для этого разработаны специальные настройки в профиле безопасности.  
Кроме того, необходимо подготовить файл JSON описания публикуемых функций.
