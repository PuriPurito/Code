## Получение описания (definition) и проверка функций

По адресу /oapi?app-id=<Идентфикатор приложения>, либо по адресу /oapi с переданным кодом клиента в заголовке x-app-id, можно получить описание возможных объектов, функций и параметров их вызова. Описание формируется в формате JSON и соответствует спецификации стандарта OpenAPI 3.0.

<Идентфикатор приложения> (x-app-id) можно найти в карточке внешнего приложения API (подробнее об этом см. статью "Принципы организации доступа".

Также в системе предусмотрен инструмент визуализации, размещенный по адресу /scripts/openapi/spec/index.html?remote\_app\_id= , где в параметре remote\_app\_id необходимо указать ID карточки приложения, зарегистрированного в системе (внимание, не APP-ID из поля карточки, а именно ID самого объекта WebTutor).

ID карточки приложения (ID объекта **Внешнее приложение API**) можно определить стандартным способом, который описывается в статье "Как определить идентификационный номер (ID) объекта".
