## API версия 3

API версии 3 платформы WebTutor соответствует спецификации OpenAPI версии 3.0  
Подробнее -  https://github.com/OAI/OpenAPI-Specification

\- доступный формат данных – application/json  
\- доступные методы – GET, POST, PATCH, DELETE  
\- доступные варианты авторизации – анонимный доступ, Basic

Имеются два варианта использования **API версии 3** - низкоуровненый и высокоуровневый.
