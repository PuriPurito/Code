## Вызов методов API

Получив описание списка методов и параметров API мы получаем правила для вызова функции.   
В целом, вызов функции или метода работы с объектом осуществляется одним из перечисленных ниже вариантов

## Для методов объекта

/oapi/имя\_объекта/идентификатор\_объекта

Тип вызываемого метода определяется HTTP-методом отправки запроса. Так, в примере, приведенном ранее:

\- вызов метода GET на адрес /oapi/collaborator даст нам список объектов системы

\- вызов метода POST на адрес /oapi/collaborator – создаст новый объект

\- вызов метода GET на адрес /oapi/collaborator/123456789988999 – вернет объект JSON, содержащий информацию о полях объекта сотрудника с ID=123456789988999

\- вызов метода PATCH на адрес /oapi/collaborator/123456789988999 – изменит объект с ID=123456789988999

\- вызов метода DELETE на адрес /oapi/collaborator/123456789988999 – удалит объект с ID=123456789988999
