## Типовое использование API

В системе реализовано несколько способов взаимодействия через API, включая низкоуровневый, в рамках которого осуществляется прямое управление объектами системы. Однако типовым вариантом является использование готовых, существующих функций, которые при необходимости могут дополняться собственными. Данный способ существенно сокращает время разработки интеграции, а также гарантирует применение во всей системе единой логики.

Все функции системы собраны в библиотеки программного кода, каждая из которых используется для реализации конкретного бизнес-процесса или направления автоматизации. Например, «Библиотека оценки MBO», «Библиотека дистанционного обучения» и пр. В документации описаны все библиотеки и содержащиеся в них функции (см. здесь). И любые из них могут использоваться через API.

Если существующих функций недостаточно, то можно создать собственную библиотеку программного кода, наполнить ее необходимыми методами и открыть к ней доступ наряду со стандартными.  
 

### **Настройка использования API в режиме «Клиент-сервер»**

API может работать в режиме прямого доступа с «фронта». Это позволяет обращаться к функциям, например, из собственного приложения, написанного на vue. В этом случае авторизация осуществляется по данным пользователя, который работает с этим приложением.

Для настройки доступа к функциям нужных библиотек в этом режиме выполните следующие действия:

1.  В интерфейсе администратора откройте раздел **API** → **Профили безопасности** блока **Безопасность**.
2.  Откройте профиль с названием «Базовые API».
3.  С помощью кнопки **Добавить строку** сформируйте список необходимых библиотек, которые будут доступны через API.
4.  В поле **Фильтр** для каждой библиотеки введите через точку запятой названия функций, которые будут доступны через API или «\*», если нужно, чтобы были доступны все функции библиотеки.

Функции библиотек кешируются для достижения необходимого быстродействия, поэтому после добавления новой библиотеки потребуется перезагрузка сервера. Этих действий достаточно для открытия доступа.  
 

### **Настройка использования API в режиме «Сервер-сервер»**

Данный режим используется, если необходимо настроить взаимодействие со внешней системой, и функции API будут вызываться внешним серверным приложением.

Для настройки доступа к функциям нужных библиотек в этом режиме выполните следующие действия:

1.  Выберите библиотеки, которые должны быть доступны через API, следующим образом:
    1.  В интерфейсе администратора откройте раздел **API** → **Профили безопасности** блока **Безопасность** и нажмите кнопку **Новая запись**.
    2.  Введите любой код и название.
    3.  В поле **Источник** выберите значение _Библиотека функций_.
    4.  С помощью кнопки **Добавить строку** сформируйте список необходимых библиотек, которые будут доступны через API.
    5.  В поле **Фильтр** для каждой библиотеки введите через точку запятой названия функций, которые будут доступны через API или «\*», если нужно, чтобы были доступны все функции библиотеки.
2.  Настройте удостоверение безопасности следующим образом:
    1.  В интерфейсе администратора откройте раздел **API** → **Удостоверение** блока **Безопасность** и нажмите на кнопку **Новая запись**.
    2.  Введите любой код и название.
    3.  В поле **Тип** выберите способ авторизации – _Анонимный_ или _Basic_. В первом случае авторизация будет осуществляться просто по идентификатору (ключу), который передается внешним приложением в заголовке (см. ниже). Во втором случае необходимо указать логин и пароль, которые будут требоваться дополнительно к идентификатору.
    4.  В поле **Профиль безопасности** укажите созданный на предыдущем этапе профиль.
3.  Настройте внешнее приложение следующим образом:
    1.  В интерфейсе администратора откройте раздел **API** → **Внешние приложения API** блока **Безопасность** и нажмите кнопку **Новая запись**.
    2.  В поле **APP ID** пропишите строку с произвольным идентификатором. Этот идентификатор внешнее приложение должно присылать в поле «x-app-id» заголовка запроса.
    3.  В поле **Удостоверение** выберите созданное на предыдущем этапе удостоверение.

Функции библиотек кешируются для достижения необходимого быстродействия, поэтому после добавления новой библиотеки потребуется перезагрузка сервера. После выполнения этих действий можно из внешнего серверного приложения использовать через API указанные функции.
