## Обращение к выборке из JavaScript

Получить результат выборки можно с помощью AJAX-запроса (POST) на адрес:

_/pp/Ext5/extjs\_json\_collection\_data.html_

### Входные параметры

*   `collection_code` \- _string_ \- код выборки. Проверяется первым, если существует, то будет использована перавя найденная выборка с таким кодом, `collection_id` будет проигнорирован.
*   `collection_id` \- _string|integer_ \- ID выборки. Будет использован, если `collection_code` отсутствует или по коду ничего не найдено.
*   `limit` \- _integer_ \- размер страницы. Опционально. Если отсутствует, выдача будет полной
*   `start` \- _integer_ \- номер начальной записи страницы. Если отсутствует, выдача будет полной
*   `parameters` \- _string_ \- Строковой массив параметров WVAR коллекции, в виде пар `name=value`, раделитель пар - точка с запятой. Эти переменные будут переданы в код выборки как WVAR
*   `user_id` \- _string|integer_ - если присутствует, будет передан в выборку в качестве WVAR _curUserID_
*   `sort` \- _string_ \- Stringified JSON-массив. Состоит из одного объекта, т.е. `[ { property: "some_property", direction: "ascending|descending" } ]`. 

### Формат результата

Возвращает JSON-объект, содержащий поля 

*   `success` - _bool_ \- true если нет ошибки
*   `messageText` - _string_ \- текст ошибки
*   `results` \- _array_ - массив результатов в той форме, в которой его выдает выборка
*   `columns` \- _array_ \- если коллекция возвращает массив columns - в той форме, в которой его выдает выборка
*   `total` \- _integer_ \- всего записей - в той форме, в которой его выдает выборка
*   `sorters` \- _array_ \- массив объектов вида  `{ property: "some_property", direction: "ascending|descending" }`, по которым в реальности происходила сортировка 

Пример ответа с ошибкой:

`{"success":false,"messageText":"Data source '' not found", "results":[]}`
