## Входные параметры выборки

В нормальной ситуации, если ничего не сломалось, в код выборки передаются глобальные объекты _curUser_, _curObject_ (если существуют и доступны) и объект _Request_. Если выборка использует внешние библиотеки – передать нужные объекты и переменные туда является задачей автора.

Дополнительные параметры определяются как **WVARS** в карточке выборки и доступны в коде как локальные переменные. Доступные для использования в редакторе типы переменных

*   _string_ \- строка, будет показана как input типа text
*   _text_ \- многострочный текст, textarea
*   _integer_ \- целое число, spinner с шагом 1
*   _real_ \- число, spinner с шагом 0.1 и возможностью свободного ввода
*   bool - true|false, checkbox или flipbox
*   _select_ \- выпадающее меню
*   _date_ \- дата, datepicker
*   _foreign\_elem_ \- выбор элемента из базы данных

Для подстановок на стороне сервера (на основе _curUser, curObject, curContext, curDoc, curEnv_), для подстановок на стороне браузера (на основе _ITEM, LOCAL, FIELD_) можно использовать только поля типа _string_. Это означает, что, если вы, например, хотите передать в выборку значение поля `my_field` на странице с типом данных _foreign\_elem_ (т.е. содержащее _id_ элемента), для этого придется задать переменную типа _string_, чтобы автор мог вставить туда подстановку `{{FIELD.my_field}}`. Удобным вариантом может быть дублирование входной переменной – для простого указания объекта базы можно задать переменную типа _Ссылка на объект базы_, и следом определить ее дублера типа _string_, которое, если не пусто, будет обладать приоритетом. Таким образом можно будет обеспечить удобный выбор объекта базы в простом случае и обеспечить приоритет для значений с подстановкой

Описывая переменную, не забудьте добавить описание - это описание будет показано в редакторе как названия поля. Можно также добавить опциональное значение по умолчанию.

Заметьте, что описание состоит из двух частей, разделенных двойным дефисом: первая часть будет показана как название поля (и ее лучше делать максимально короткой), а вторая - как всплывающая подсказка при наведении мыши на поле (может быть более развернутым).
