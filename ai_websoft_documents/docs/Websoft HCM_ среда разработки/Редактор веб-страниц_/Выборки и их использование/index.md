## Выборки и их использование

Для заполнения страниц содержимым из базы данных виджеты используют Выборки (коллекции). 

Используется два типа заполнения (и их комбинации) - прямая привязка полей элементов выборки к полям элементов виджета и текстовые подстановки в поля элементов виджета на основе ITEM. На картинке ниже показан пример комбинации прямой привязки полей и текстовой подстановки для формирования URL.
