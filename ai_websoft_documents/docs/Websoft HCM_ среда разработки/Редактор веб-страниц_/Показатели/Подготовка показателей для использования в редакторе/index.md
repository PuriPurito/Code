## Подготовка показателей для использования в редакторе

Код, вычисляющий собственно значения показателей, в этой статье не обсуждается, предполагается, что он уже создан.

Для того, чтобы показатель можно было использовать в редакторе, нужно в карточке показателя установить следующие параметры в карточке показателя:

1\. На вкладке _Общие сведения_ установить ссылку на файл с кодом и установить чекбокс **Вычисление контекста**

2\. На вкладке _Способ представления_ выбрать **Способ отображения -** тип скалярной величины или объект:

Замечание: для boolean значений обычно используется числовое представление 0|1, поскольку это упрощает использование показателей в условиях

3\. Опционально. Если показатель имеет явную связь с каким-то типом объекта - можно добавить этот тип объекта на вкладке _Общие сведения_ \- это позволит показать показатель в списке возможных подстановок на странице, также связанной с этим типом объекта, и упростит жизнь автору. В противном случае автору придется вписать название показателя в подстановке самому. Например, на картинке ниже показатель привязан к типу объекта Wiki-статья.
