## Правила показа, скрытия и обновления виджетов

Для каждого виджета доступны 4 правила:

**ИСКЛЮЧИТЬ**  -  Полностью исключить виджет со страницы. Исполняется **на сервере**, соответственно, для условий можно использовать только существующие на сервере объекты: _curUser, curObject, curContext, curDoc, curEnv_. 

**ПОКАЗАТЬ/СПРЯТАТЬ** \- показать или скрыть виджет. Виджет при этом не исключается из страницы, только скрывается. Исполняется в браузере. Для условий можно использовать серверные объекты и локальные переменные.

**ПЕРЕЗАГРУЗИТЬ** - перезагрузить виджет. Для условий можно применить подписку на изменение ID текущего объекта или изменение локальной переменной на определенное значение.
