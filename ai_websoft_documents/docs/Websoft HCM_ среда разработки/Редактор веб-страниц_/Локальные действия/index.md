## Локальные действия

Локальные действия  - действия, исполняемые на стороне браузера.

### Заменить текущий объект

Применимо для виджетов, заполняемых выборкой из базы данных.

Для каждой страницы существует значение идентификатора текущего объекта, которое используется в каждом вызове от страницы к серверу - обновления виджета или удаленного действия. Если в контексте страницы существует curObject, то сразу после загрузки страницы это значение равно curObjectId. Данное действие заменяет идентификатор текущего объекта на идентификатор объекта из текущего элемента виджета, на котором было вызвано действие. 

Обычно используется в связке с правилом **Перезагрузить**, которое задается для виджета, который нужно обновить при изменении идентификатора в заданном объекте (т.е. это по сути подписка на обновление идетификатора текущего объекта, вызванное локальным действием указанного виджета). Например, на картинке ниже виджет Рейтинг будет перезагружен, если виджет Простой список изменить ID объекта локальным действием - таким образом будет показан рейтинг для элемента списка, на который нажали.

### Изменить локальную переменную

Действие похоже на Заменить текущий объект, с той разницей, что идетификатор выбранного элемента будет записан не во внутреннее значение ID текущего объекта, а в указанную локальную переменную или поле ввода.

### Вызов функции-обработчика

Вызов кастомной функции-обработчика, которую можно определить в настройках страницы или в любом другом подгружаемом файле. В поле указывается только название функции.

В качестве единственного параметра в которую будет передан JSON-объект выбранного элемента. 

`function fnRefreshList(oItem)   {   ...   }`
