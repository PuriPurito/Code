## Входные параметры удаленного действия.

Входные параметры действия определяются как переменные **WVARS**. Доступные для использования в редакторе типы переменных

*   _string_ \- строка, будет показана как input типа text
*   _text_ \- многострочный текст, textarea
*   _integer_ \- целое число, spinner с шагом 1
*   _real_ \- число, spinner с шагом 0.1 и возможностью свободного ввода
*   bool - true|false, checkbox или flipbox
*   _select_ \- выпадающее меню
*   _date_ \- дата, datepicker
*   _foreign\_elem_ \- выбор элемента из базы данных (единственный и множественный выбор). Для поля типа foreign\_elem с множественным выбором переменная будет доступна в действии как простой массив идентификаторов выбранных элементов.

Описывая параметр, не забудьте добавить описание - это описание будет показано в редакторе как названия поля. Можно также добавить опциональное значение по умолчанию.

Заметьте, что описание состоит из двух частей, разделенных двойным дефисом: первая часть будет показана как название поля (и ее лучше делать максимально короткой), а вторая - как всплывающая подсказка при наведении мыши на поле (может быть более развернутым).

Для действий, выполняемых в приложении администратора, устанавливаются некоторые зарезервированные поля (контекст выполнения действия):  
\- SELECTED\_OBJECT\_IDS - идентификаторы объектов (через точку с запятой), выделенных в представлении  
\- OBJECT\_ID - идентификатор текущего объекта, карточка которого сейчас открыта или на котором сейчас расположен указатель мыши  
\- sAPPLICATION - код текущего приложения  
\- ELEMENT\_IDS - идентификаторы записей элементов массива внутри объекта (для действий, выполняемых внутри карточки, например список преподавателей)
