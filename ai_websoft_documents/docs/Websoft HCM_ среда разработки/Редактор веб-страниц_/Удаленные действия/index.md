## Удаленные действия

**Удаленные действия** (remote\_actions) - код, который вызывается из браузера запросом на сервер, исполняется на сервере и возвращает команды для исполнения на стороне страницы.

Вызов удаленного действия осуществляется по нажатию мыши из виджета, в котором в качестве типа отклика выбран тип **Удаленное действие.**

Для того, чтобы удаленное действие могло взаимодействовать со страницей, действие должно соответствовать следующим требованиям:

1.  Входные переменные действия должны быть описаны через WVARS в документе действия.
2.  Структура кода действия должна содержать проверку базовых команд.
3.  Возвращаемый код должен содержать JSON-объект в определенном формате с командами для веб-страницы

Опционально действие может быть привязано к Типу объектов, являющимися основными для этого действия - для удобства работы с ними в редакторе. Например, если действие относится к подаче заявки на учебную программу, то логично привязать его к типу объекта Учебная программа. В этом случае при редактировании страниц, привязанных к тому же каталогу, это действие будет доступно через меню быстрого выбора, а не через общий диалог выбора.
