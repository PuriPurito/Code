## Создание локальных переменных общего назначения

В отличие от локальных переменных типа `FIELD`, переменные общего назначения должны быть определены автором страницы заранее. Для этого откроем диалог **Настройки страницы** и в поле **Переменные runtime (LOCAL)** опеделим JSON-массив с описанием нужных переменных. Например:

`[       {"id":"has_smth","type":"bool","value":false},       {"id":"my_age","type":"integer","value":116},       {"id":"firstname","type":"string","value":"Василий"},       {"id":"middlename","type":"string","value":"Алибабаевич"}   ]`

Переменные, определенные таким образом, будут немедленно доступны для текстовых подстановок, например, `{{LOCAL.firstname}}` - в текстах страницы и параметрах выборок и удаленных действий, а также в правилах показа и скрытия. При показе страницы эти подстановки будут автоматически заменены на текущие значения переменных.

Набор типов переменных ограничен следующим списком:

*   bool
*   string
*   integer
*   real

ВАЖНО! Названия переменных должны подчиняться правилам именования переменных JavaScript - только латинские символы, цифры и подчерк (underscore). Название не должно начнаться с цифры и не должно содержать пробелов.
