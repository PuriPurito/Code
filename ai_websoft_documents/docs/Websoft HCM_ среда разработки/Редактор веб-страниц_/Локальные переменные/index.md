## Локальные переменные

Локальные переменные существуют только при просмотре страницы в браузере, серверу они недоступны. Однако их значения могут быть переданы в параметры удаленных действий и выборок сервера при обновлении отдельных виджетов страницы.

Поддерживаются два типа локальных переменных:

1.  Переменные общего назначения - `LOCAL`. Задаются автором страницы в диалоге **Настройки страницы**.
2.  Переменные, привязанные к полям ввода - `FIELD`. Создаются автоматически для каждого виджета типа **Поле ввода**.

За исключением указанной разницы в создании и привязке, локальные переменные обоих типов обладают похожими характеристиками и используются одинаково.

Локальные переменные **реактивны**, т.е. программное изменение значения переменной немедленно изменяет значение всех подстановок на ее базе (и значение поля если это переменная типа FIELD) и наоборот - изменение значения поля в реальном времени вызывает изменение значения связанной переменной и всех подстановок на ее базе.
