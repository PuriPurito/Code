## Работа с локальными переменными в JavaScript

Функционал для разработчиков

Переменные общего назначения хранятся в глобальном объекте WTLP.oLocal, обращение возможно как в dot notation, так и с селекторам свойства объекта:

WTLP.oLocal.my\_var = "my\_value";  
WTLP.oLocal\["my\_var"\] = "my\_value";

Переменные полей ввода хранятся в глобальном объекте WTLP.oFlds, обращение возможно как в dot notation, так и с селекторам свойства объекта:

WTLP.oFlds.my\_fld = "my\_value";  
WTLP.oFlds\["my\_fld"\] = "my\_value";

Дополнительно для переменных поля ввода доступен указатель на объект виджета Поле ввода, содержащий это поле:

WTLP.oFlds.oWidgetRefs\["my\_fld"\]  

Зарезервированные названия в объектах `WTLP.oLocal` и `WTLP.oFlds`:  **`oValueStorage, oWidgetRefs`** - не следует использовать такие названия для локальных переменных и имен полей.
