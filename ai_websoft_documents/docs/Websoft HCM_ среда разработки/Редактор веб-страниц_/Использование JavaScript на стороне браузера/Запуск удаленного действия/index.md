## Запуск удаленного действия

Удаленное действие может быть вызвано из кастоной функции следующим образом:

`WTLP.Click(   {       oElem: WTLP.oElems["...widget hex id..."],       sHexOWTId: WTLP.oElems["...widget hex id..."].sId,       sAction: "remote",       sRAId: "...remote action hex id...",       oItem: oItem,       bCollectFlds: true   });`

`oElem` - опциональный, объект виджета, в котором использовано удаленное действие

`sHexOWTId` - обязательный, hex ID виджета, в котором использовано удаленное действие, может быть пустым, но не может отсутствовать. Если такой виджет существует, то из него будут взяты значения параметров действия. Если нет - действие будет вызвано без параметров WVARS.

`sAction` - всегда "remote" для данного типа вызова

`sRAId` - hex ID вызываемого действия

`oItem` - опциональный JSON-объект элемента выборки

`bCollectFlds` - опциональный ключ, если true - в действие будут переданы все текущие значения полей воода на странице как массив form\_fields (см. Удаленные действия)
