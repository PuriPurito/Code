## Обновление виджета

Для безусловного обновления виджета в кастомной функции используется вызов метода _Request_ объекта _WTWebMode_. 

Перед вызовом, если необходимо, следует установить все локальные переменные, если они используются в параметрах обновляемого виджета. Сам вызов выглядит так:

`WTLP.oModes[ WTLP.sCurrentWebModeId ].Request({ sType: "link", sId: "0x5FCE31974E3D2EFE", sObjectId: oItem.id });`

здесь 

`sType` - всегда "link", нужен для совместимости

`sId` \- hex ID виджета, который нужно обновить

`sObjectId` \- опциональный идентификатор объекта, который будет передан при обновлении как текущий (при этом, в отличие от локального действия **Заменить текущий объект**, он будет использован единожды и НЕ заменит общий ID текущего объекта страницы)
