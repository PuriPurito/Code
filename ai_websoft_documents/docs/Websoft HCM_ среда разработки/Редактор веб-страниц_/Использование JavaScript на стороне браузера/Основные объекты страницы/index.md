## Основные объекты страницы

Основной объект, который содержит все базовые методы имеет фиксированное название `WTLP` и всегда доступен на странице, с важной оговоркой - если существует webmode (тип страницы, который при создании страницы в редакторе всегда существует, но при сборке вне редактора может отсутствовать). 

Некоторые свойства этого объекта, которые могут быть полезны в кастомных функциях:

`string WTLP.sCurrentWebModeId   // id текущего типа страницы (webmode), существует всегда   string WTLP.sDocId  // id текущего документа или пустая строка   string WTLP.sObjectId   // id текуущего объекта или пустая строка   string WTLP.sLang   //  двухбуквенный код текущего языка, по умолчанию "ru"   string WTLP.sFallbackLang  // двухбуквенный "аварийный" код языка, по умолчанию "ru"`

В этом объекте хранятся также объекты с локальными переменными и полями `WTLP.oLocal` и `WTLP.oFlds` (см. раздел Локальные переменные).

`object WTLP.oModes` 

Содержит указатели на объекты типа WTWebMode, создаваемые для типа страницы. В текущем варианте такой объект всегда один и к нему всегда можно обратиться:

`WTLP.oModes[WTLP.sCurrentWebModeId]`

`object WTLP.oElems` 

Содержит указатели на объекты виджетов данной страницы. К объекту виджета можно обратиться по его id (в hex-формате), например:

`WTLP.oElems["0x5FCE31974E3D2EFE"]`
