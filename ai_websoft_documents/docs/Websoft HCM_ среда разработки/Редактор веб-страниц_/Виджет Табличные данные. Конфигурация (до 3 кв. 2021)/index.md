## Виджет Табличные данные. Конфигурация (до 3 кв. 2021)

Виджет **Табличные данные** имеет поле _Конфигурация_, которое позволяет кастомизировать показ колонок таблицы. Если в этом поле содержится валидный JSON-массив состав и способ показа колонок таблицы будет взят из этого массива с приоритетом. Пример:

`[   {"name":"img_url","view":"image","width":"8em","css":"wt-lp-wgrid-img-size-4"},   {"name":"course_name","view":"link","link":"course_url","target":"_self"},   {"name":"course_author","view":"link","link":"/_wt/{{ITEM.author_id}}","target":"_blank"},   {"name":"fullname","width":"100%"}   ]`

### Возможные параметры элементов массива

`name` - _string_ \- имя поля, обязательное  
`view` - _string_ \- представление данных, возможные значения - _image_ (значения будут интерпретированы как URL картинки, при клике на картинку откроется ее увеличенный вариант) или _link_ \- значения будут обернуты в ссылку, построенную по значениям параметров `link` и `target`  
`width` \- _integer|real|string_ - ширина колонки, числовые значения в пикселах, строковые могут быть в % и em|rem  
`align` - _string - left|center|right_ - выравнивание в колонке  
`visible` \- _bool_ - позволяет исключить показ колонки  
`css` \- _string_ - дополнительный класс для ячеек колонки, содержащих данные  
`headercss` \- _string_ \- дополнительный класс для ячейки заголовка колонки  
`filtercss` \- _string_ \- дополнительный класс для ячейки с фильтром этой колонки  
`filtering` - _bool_ \- позволяет исключить фильтры для колонки  
`sorting` \- _bool_ \- позволяет исключить сортировку для колонки  
`link` - _string_ \- (только если `view=link`) строка с возможными подстановками на основе ITEM, если в строке **НЕ будет найден** признак подстановки {{...}}, то строка воспринимается, как имя поля, из которого будет взята ссылка  
`target` - _string_ \- (только если `view=link`) открытие ссылки в другом окне. Значение по умолчанию _\_self_. Если нужно открыть в новом окне - _\_blank_.

Для показа картинок (view=image) в общие стили редактора добавлено 5 стандартных размеров, определяемых классами через параметр css: `wt-lp-wgrid-img-size-1, wt-lp-wgrid-img-size-2, wt-lp-wgrid-img-size-3,wt-lp-wgrid-img-size-4,wt-lp-wgrid-img-size-5.` По умолчанию картинка имеет размер 2 (3.2em).
