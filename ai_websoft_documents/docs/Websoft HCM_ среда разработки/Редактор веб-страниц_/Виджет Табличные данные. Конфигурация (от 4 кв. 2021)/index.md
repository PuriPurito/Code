## Виджет Табличные данные. Конфигурация (от 4 кв. 2021)

Виджет **Табличные данные** имеет поле _Конфигурация_, которое позволяет кастомизировать показ колонок таблицы. Если в этом поле содержится валидный JSON-массив состав и способ показа колонок таблицы будет взят из этого массива с приоритетом. При отсутствии конфигурации виджет покажет весь набор полей, приходящих из выборки с форматированием ячеек по типу данных. 

Начиная с 4 квартала 2021 года изменен код, формирующий таблицы, благодаря чему возможности конфигурации значительно расширились. Параметры, использовавшиеся в предыдущем варианте, максимально сохранены. 

Важное замечание: поведение параметра _width_ изменилось. Значение 100% теперь интерпретируется как 100% от ВСЕЙ ширины контейнера таблицы, а не от остатка ширины.

Пример:

`[   {"name":"img_url","view":"image","width":"8%","css":"wt-lp-wgrid-img-size-4"},   {"name":"course_name","view":"link","link":"course_url","target":"_self"},   {"name":"course_author","view":"link","link":"/_wt/{{ITEM.author_id}}","target":"_blank"},   {"name":"fullname","width":"50%"}   ]`

Возможные **параметры элементов массива** (синим обозначены общие параметры с предыдущей версией, черным - новые, серым - неподдерживаемые старые)

`name` | `field`  - _string_ \- имя поля, обязательное  
`view`  - _string_ \- представление данных, возможные значения и связанные параметры см. список ниже  
`width` \- _integer|real|string_ - ширина колонки, числовые значения в пикселах, строковые могут быть только в %   
`minWidth`  \- _integer|real|string_ - минимальная ширина колонки - только в пикселах  
`maxWidth`  \- _integer|real|string_ - максимальная ширина колонки - только в пикселах  
`align``|hozAlign` \- _string - left|center|right_ - выравнивание в колонке  
`valign|vertAlign` \- _string - top|middle|bottom_ - вертикальное выравнивание в колонке  
`header_align|headerHozAlign` \- _string - left|center|right_ - выравнивание в заголовке колонки  
`visible` \- _bool_ - позволяет исключить показ колонки  
`css``|cssClass`  \- _string_ - дополнительный класс для ячеек колонки, содержащих данные  
`headercss`  \- _string_ \- дополнительный класс для ячейки заголовка колонки - более не поддерживается  
`filtercss` \- _string_ \- дополнительный класс для ячейки с фильтром этой колонки - более не поддерживается  
`filtering``|headerFilter`  - _bool_ \- позволяет исключить встроенные фильтры для колонки для режима обработки данных в браузере (общее разрешение - в параметрах виджета)  
`sorting``|headerSort`  \- _bool_ \- позволяет исключить сортировку для колонки (общее разрешение - в параметрах виджета)

### Представления данных в колонке

По умолчанию данные показываются в соответствии с типом, возвращаемым в описании поля выборки. Стандартные представления по типам данных, если конфигурация не используется или используется, но параметр _view_ не определен:

*   `string` \- данные типа _string_ и все прочие, для которых нет представления по умолчанию представляются как строка
*   `text` \- представление многострочный текст
*   `date` \- представление _date_, зависит от параметров виджета, определяющих показ даты ISO8601
*   `integer, real` \- представление типа _number_
*   `bool` \- представление типа _tickCross_ (галка - true, крестик - false)

### Возможные значения view и связанные параметры

### _**image**_

Применимо только для полей с типом данных _string_. Содержимое ячейки трактуется как url картинки. Картинка будет показана как квадрат с заполнением картинкой с полным заполнением с возможным обрезанием, при клике на картинку она откроется для просмотра. Дополнительные параметры:

*   `size` \- _number|string -_ из набора 1|2|3|4|5 - опционально - стандартный размер. В общие стили редактора добавлено 5 стандартных размеров, определяемых классами через параметр css:  `wt-lp-wgrid-img-size-1, wt-lp-wgrid-img-size-2, wt-lp-wgrid-img-size-3,wt-lp-wgrid-img-size-4,wt-lp-wgrid-img-size-5.`  По умолчанию картинка имеет размер 2 (3.2em).
*   `imgWidth` \- _number|string_ - опционально - ширина картинки. Числовое значение трактуется как пиксели, строковое подставляется as is.
*   `imgHeight` \- _number|string_ - опционально - высота картинки. Числовое значение трактуется как пиксели, строковое подставляется as is.  

### _**link**_

Применимо только для полей с типом данных _string_. Содержимое ячейки заменяется ссылкой, которая может быть сформирована по-разному. По умолчанию в качестве URL и текста ссылки будет использовано содержимое ячейки, это поведение можно изменить параметрами.

*   `target` \- _string_ \- опционально - тип открытия ссылки. Значение по умолчанию _\_self_. Если нужно открыть в новом окне - _\_blank_. По умолчанию используется значение этого параметра из виджета.
*   `download` - _bool_ \- опционально - если true, то браузер будет пытаться загрузить файл по ссылке, а не показать в браузере
*   `link|url_from`  - _string_ \- опционально - строка ссылки. Строка с возможными подстановками на основе ITEM, если в строке **НЕ будет найден** признак подстановки {{...}}, то строка воспринимается, как имя поля выборки, из которого будет взята ссылка.
*   `label_from` \- _string_ \- опционально - строка текста ссылки (в этом случае содержимое ячейки считается ссылкой, а текст ячейки будет заменен). Строка с возможными подстановками на основе ITEM, если в строке **НЕ будет найден** признак подстановки {{...}}, то строка воспринимается, как имя поля выборки, из которого будет взята текст ссылки. Этот способ формирования ссылки обладает меньшим приоритетом, чем с помощью предыдущего параметра, при одновременном наличии `link|url_from` он будет проигнорирован.
*   `label` \- _string_ \- опционально - текст ссылки - текстовая константа. Этот параметр обладает приоритетом, если он есть - текст безусловно будет заменен на его содержимое

### _html_

Содержимое ячейки будет вставлено как HTML, без маскирования тэгов. 

ОСТОРОЖНО! Вставка HTML без маскирования - потенциальная уязвимость. Используйте только если уверены в безопасности возвращаемых выборкой данных.

### _money_

Применимо только для полей с типом данных _integer|real_. Содержимое ячейки будет приведено к денежному формату. По умолчанию используется формат с округлением до двух десятичных знаков для _real_ и символом рубля после числа.

*   `symbol` \- _string_ \- строка валюты. По умолчанию ₽.
*   `symbolAfter` \- _bool_ \- по умолчанию _true_, значение _false_ перенесет символ валюты перед числом.

### _star_

Применимо только для полей с типом данных _integer|real._ Содержимое ячейки будет показано как рейтинг из звездочек. Ожидается значение, соответствующее числу звездочек (_real_ будет округлено).

*   `maxStars` \- _integer_ \- число звездочек в рейтинге. По умолчанию 5.

### _traffic_

Применимо только для полей с типом данных _integer|real_. Содержимое ячейки будет показано как светофорный кружок определяемого по значению цвета. Минимальным значением всегда считается  0, максимальное значение по умолчанию - 100. По умолчанию в массиве цветов используется три цвета - красный, желтый, зеленый, деление в равных долях по числу цветов в массиве цветов. 

*   `maxValue` \- _integer|real_ - максимальное значение
*   `colorArray` \- _array_ \- переопределит массив цветов. Формат - массив строковых значений, например _\["#c00", "#fc0", "#060"\]_

### _progress_

Применимо только для полей с типом данных _integer|real_. Содержимое ячейки будет показано как прогресс-индикатор. Минимальным значением всегда считается  0, максимальное значение по умолчанию - 100. По умолчанию в массиве цветов используется три цвета - красный, желтый, зеленый, деление в равных долях по числу цветов в массиве цветов. 

*   `maxValue` \- _integer|real_ - максимальное значение
*   `colorArray` \- _array_ \- переопределит массив цветов. Формат - массив строковых значений, например _\["#c00", "#fc0", "#060"\]_
*   `legend` \- _bool_ \- опционально. Если _false_ \- показ значения будет скрыт.
*   `legendAlign` \- _string_ \- _left|center|right_ \- Позиция значения, по умолчанию _center_.

### _color_

Применимо для данных типа _string_. Содержимое ячейки считается цветом и будет использовано для окраски ячейки. 

### _lookup_

Применимо для данных типа _string_. Содержимое ячейки будет подменено строкой из определенного в параметре объекта, ключом для выбора будет значение. Если подмена не найдена, значение покажется as is.

*   `list` \- _object_ \- со структурой _key:value_. Например: _{ "n": "Не начат", "i": "В процессе", "c": "Завершен", "p": "Пройден успешно", "f": "Провален", "u": "Неизвестно" }_

### _sparkline_

Применимо для данных типа _string_. Содержимое ячейки будет подменено инлайн-графиком разных типов. Поскольку это представление крайне трудно формализуемо в рамках виджета (каждый тип графика ожидает своего набора данных и параметров представления), то для этого представления ожидается единственный параметр, объединяющий всю конфигурацию:

*   `formatterParams` \- _object_ \- полный объект конфигурации, составляемый по документации плагина Sparkline ( https://omnipotent.net/jquery.sparkline/ ) и плагина Tabulator ( http://tabulator.info/docs/5.0/ )

### _items\_array_

Применимо для данных типа _string_. В данных для этой ячейки ожидается stringified array определенного вида. На основе данных этого массива в ячейке будет представлен список наборов значений в конфигурируемом виде. Пример нужных данных:  
  
`{       "items":       [           {               "id": 1105387902724063500,               "img_url": "/person_icon.html?id=1105387902724063510&type=100x100",               "name": "Анисимов Геннадий Федорович",               "link_url": "/_wt/1105387902724063510",               "position": "Директор учебного центра",               "subdivision": "Учебный центр"           }       ],       "total": 1,       "items_left": 0,       "cell_display": "pn"   }`

В ячейке будет показан список объектов массива items в виде, определяемом параметром _cell\_display_ (возможные значения _pn|p|n_ - комбинации _photo_ и _name_, коллекция должна просто оттранслировать его из параметров коллекции). Для показа будут использованы только картинка и/или название (имя).

Если _link\_url_ будет не пустым, то имя или картинка станут ссылкой.

Прочие поля будут показаны в тултипе при наведении на элемент (сейчас это фиксированные поля _position_, _subdivision_).

Если в параметрах коллекции определен вывод ограниченного числа элементов (через параметр коллекции) и общее число элементов больше этого ограничения, то поле _items\_left_ коллекция должна вернуть их оставшееся число, чтобы в конце списка появился текст "+N"
