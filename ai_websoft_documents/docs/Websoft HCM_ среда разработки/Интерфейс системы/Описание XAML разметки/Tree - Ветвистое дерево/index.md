## Tree - Ветвистое дерево

Элемент разметки  
Название:    Tree  
Краткое описание:    Ветвистое дерево  
Тип:    Пользовательский элемент  
Содержимое:      
Подробное описание:      
Деревовидная структура, на ветки которой можно нажать. Данные получает из подгрузки удаленных выборокLite Тестирование  
Примеры использования:    

<Tree Source="TreeGrow" DataID="id" DataParent="parent\_object\_id" DataTitle="name" DataFatherhood="hasChildren"/>

выборка "TreeGrow":

Параметры:

**Атрибут**

**Тип**

**Описание**

Name

string

Идентификатор. Опционален

Source

string

Код документа выборки в WT. Если написать просто код выборки, то она будет напрямую запрошена с сервера. Если написать код выборки в фигурных скобках {}, то выборка будет проводиться через объект Collection (который в этом случае должен существовать). Это нужно, если требуется на каждый запрос к выборке передать еще какие-то данные, которые в этом самом объекте Collection и описываются.

DataTitle

string

Поле из результатов выборки, из которого брать название элемента дерева

DataParent

string

Поле из результатов выборки, из которого определять ID родительского элемента

DataID

string

Поле из результатов выборки, в котором находится уникальный ID элемента

DataFatherhood

string

Поле из результатов выборки, в котором указано - есть ли у него дочерние элементы или нет (для асинхронного дерева)

DataIcon

string

Поле из результатов выборки, в котором находится путь до значка-изображения элемента

DataExpanded

string

Поле из результатов выборки, в котором указано, раскрыта ветка или нет

Class

string

Имя класса из таблицы стилей если нужно

Hidden

bool

Скрыт элемент или показан. По умолчанию показан.

Preservable

bool

Сохранять состояние дерева после обновления страницы. По умолчанию false

Width

integer

Ширина. В пикселях.

Height

integer

Фиксированная высота таблицы. Опционально

Tooltip

bool

Дублирование названия во всплывающей подсказке

DataSelected

string

Поле из результатов выборки, в котором указано, выбран ли элемент. В выборке должен быть только один такой элемент, если их больше - будет взят последний. Без указания данного параметра явно, выбора не происходит.

Multiline

bool

Располагать заголовки с переносом строк

События:

**Событие**

**Описание**

Click

Выполнение действия при нажатии на ветку.
NB: в фигурных скобках можно использовать поля из выборки. Например {id}
