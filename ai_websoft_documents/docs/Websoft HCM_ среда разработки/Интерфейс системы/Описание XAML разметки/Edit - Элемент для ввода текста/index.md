## Edit - Элемент для ввода текста

Элемент разметки  
Название:    Edit  
Краткое описание:    Элемент для ввода текста  
Тип:    Пользовательский элемент  
Содержимое:    Изначально загруженный текст  
Подробное описание:      

Сюда вводят текст пользователи  
Примеры использования:      
<Edit Name="Edit1">Какое-то значение</Edit>

Параметры:

**Атрибут**

**Тип**

**Описание**

Enabled

bool

Активно ли поле ввода

Name

string

Идентификатор

Width

integer

Ширина. В пикселях.

Class

string

Имя класса из таблицы стилей если нужно

Hidden

bool

Скрыто ли поле визуально, \[true,false\]

Type

string

Тип вводимого текста \[text, password\].

MaxLength

integer

Максимально допустимое количество символов \[0 - выкл\]

Editable

bool

Можно ли пользователю редактировать поле \[true,false\]

EmptyText

string

Приглашающий текст при пустом значении \[""\]

События:

**Событие**

**Описание**

KeyPress

Выполнение действий при нажатии на определенные клавиши. Действий может быть несколько и они разграничиваются следующим синтаксисом:
#\[!\]\[S\]<код клавиши>:<действия>
или
#\[!\]\[S\]<код клавиши от>-<код клавиши до>:<действия>

! - прерывать событие по умолчанию (в данном случае добавление этого символа в строку ввода) \[необязательно\]
S - нажат shift или нет \[необязательно\]
код клавиши - код клавиши (ваш КО)

Можно указать один код или диапазон от и до.

Таких наборов может быть несколько.
Если данная комбинация нажатых клавиш совпадает с несколькими наборами, выполнятся все по очереди.


В действие также передается параметр key, к которому также можно обратиться.


Все возможные примеры в одной строке:

<Edit Name="E1" KeyPress="#S81:ALERT=Shift+Q нажат, код клавиши {key};#48-57:ALERT=Нажата какая-то цифра;#13:ALERT=Enter нажат, перезагружаюсь;REFRESH;#!122:ALERT=Я не дам тебе набрать 'z'">value1</Edit>


Разрешено вводить только цифры:

<Edit Name="Age" KeyPress="#!1-47:STOP;#!58-10000:STOP;#!S1-10000:STOP" Width="50"></Edit>
