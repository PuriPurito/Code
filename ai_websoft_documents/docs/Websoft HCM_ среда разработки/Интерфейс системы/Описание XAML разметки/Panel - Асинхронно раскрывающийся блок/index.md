## Panel - Асинхронно раскрывающийся блок

Элемент разметки  
Название:    Panel  
Краткое описание:    Асинхронно раскрывающийся блок  
Тип:    Контейнер  
Содержимое:    Другие компоненты (если не указан параметр Source, иначе объекты Param)  
Подробное описание:      
Раскрывающийся блок c заголовком, содержащий другие элементы  
Примеры использования:    

<Panel Title="expand me" Source="xaml\_my\_tests"/>

Параметры:

**Атрибут**

**Тип**

**Описание**

Width

integer

Ширина. В пикселях.

Source

string

Код документа XAML в базе WT. Опционально. XAML будет добавлен в тело панели при развертывании последней, если она свернута, при показе, если она спрятана, ну или сразу, если сразу. Важно! Подгруженное содержимое существует в области видимости родительской формы, как будто существовало сразу вместе с родителем, а не подгружалось асинхронно.

Class

string

Стиль панели

Title

string

Заголовок

Hidden

bool

Скрыт элемент или показан. По умолчанию показан.

Expanded

bool

Развёрнута или свёрнута панель \[true\]

ShowHeader

bool

Показывать ли заголовки столбцов. \[true\]

Adapt

bool

Автоматически отключает возможность схлопывания панели при режиме плеера "mobile"
