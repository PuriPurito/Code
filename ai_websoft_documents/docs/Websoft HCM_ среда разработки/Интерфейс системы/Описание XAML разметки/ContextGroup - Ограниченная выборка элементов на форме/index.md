## ContextGroup - Ограниченная выборка элементов на форме

Элемент разметки  
Название:    ContextGroup  
Краткое описание:    Ограниченная выборка элементов на форме  
Тип:    Управляющий элемент  
Содержимое:      
Подробное описание:      
По умолчанию в объект CONTEXT (см. XAMLLite Тестирование, ParamLite Тестирование) попадают все элементы формы. С помощью ContextGroup можно ограничивать набор элементов, передаваемых в CONTEXT (см. вызов действийLite Тестирование)  
Примеры использования:    

<ContextGroup Name\="GridUndEdit" Items\="Grid1,Edit2"/>

Параметры:

**Атрибут**

**Тип**

**Описание**

Name

string

Идентификатор группы

Items

string

Перечисленные через запятую (,) идентификаторы элементов формы, которые относятся к этой выборке
