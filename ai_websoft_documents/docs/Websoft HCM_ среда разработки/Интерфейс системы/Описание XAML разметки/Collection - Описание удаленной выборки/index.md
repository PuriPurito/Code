## Collection - Описание удаленной выборки

Элемент разметки  
Название:    Collection  
Краткое описание:    Описание удаленной выборки  
Тип:    Управляющий элемент  
Содержимое:    Объекты или объект  
Подробное описание:      
Описание удаленной выборки. Это запись говорит плееру, что в WT есть такая выборка и все параметры в этой выборке.   
Может находиться в любом месте формы, но рекомендуем описывать выборку в самом начале элемента SPXMLScreen. Так правильно, особенно если использовать статические данные.

Вообще элементы типа таблицLite Тестирование и деревьевLite Тестирование, требующие выборок, могут напрямую вызывать данные из выборки (если в источнике элемента мы пишем ID удаленной выборки без фигурных скобок {}). Это описание нужно, чтобы передать дополнительные параметры и данные в код выборки, вот и всё (см. описание Source у таблицLite Тестирование и растенийLite Тестирование)

Чтобы задать статические данные без обращения к удаленным выборкам, следует описать тег DataLite Тестирование  
Если указан и источник, и статические данные, у последних больший приоритет и из источника данные браться не будут.  
Примеры использования:    

  
**<!-- Для таблицы -->**

<Collection Name\="GetGridData" Source\="WTGridData">  
<Param Name\="sTargetName" Value\="{Edit1}"/>  
<Param Name\="iTargetRank" Value\="10"/>  
<Data\>  
<Row\>  
<Cell Id\="link" Value\="websoft.ru"/>  
<Cell Id\="datefield" Value\="01.01.2000"/>  
</Row\>  
<Row\>  
<Cell Id\="link" Value\="datex.ru"/>  
<Cell Id\="datefield" Value\="02.02.2010"/>  
</Row\>  
</Data\>  
</Collection\>

**<!-- Для дерева-->**

**<Collection Name\="StillTree">  
<Data\>  
<Row\>  
<Cell Id\="id" Value\="branch01"/>  
<Cell Id\="name" Value\="Branch"/>  
<Cell Id\="hasChildren" Value\="true"/>  
</Row\>  
<Row\>  
<Cell Id\="id" Value\="leaf01"/>  
<Cell Id\="name" Value\="Leaf"/>  
<Cell Id\="parent\_id" Value\="branch01"/>  
<Cell Id\="hasChildren" Value\="false"/>  
</Row\>  
</Data\>  
</Collection\>**

**Атрибут**

**Тип**

**Описание**

Name

string

Идентификатор для вызова из элемента. В общем просто ID выборки, по которой обращается компонент

Source

string

Код выборки в базе WT. Если не указан, будет взято значение из Name. Может быть затежен {}
