## Написание удаленного действия

Элемент разметки  
Название:    Написание удаленного действия  
Краткое описание:    WT Remote actions  
Тип:    Справка  
Содержимое:      
Подробное описание:      
Удаленные действия принимают параметры, которые описаны в блоке ActionLite Тестирование - ParamLite Тестирование, если конечно не были вызваны напрямую.  
Рекомендуем перечислять их на форме со значениями по умолчанию. 

В коде эти переменные-параметры можно использовать в таком же виде: var\_str, var\_int и т.п.

Одна хитрость: в переменные плеер всегда передает curUserID. Она может и не объявлена явно, но она есть.  
Также есть переменная PAGEURL, в которой можно считать URL из браузера  
В результате обязаны быть заполненными следующие переменные:

ERROR - 1 или 0. В принципе система сама поставит 1 в конце или 0, если программер этого не сделал.

MESSAGE - сообщение для юзера от программера. В итоге окажется в свойстве messageText у объекта RESULT

RESULT - объект, который можно начинить любыми плоскими свойствами, для дальнейшего использования результатов (например в результирующих событиях ActionLite Тестирование)
