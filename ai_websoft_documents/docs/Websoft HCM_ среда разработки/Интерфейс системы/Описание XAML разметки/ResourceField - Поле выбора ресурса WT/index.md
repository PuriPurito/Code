## ResourceField - Поле выбора ресурса WT

Элемент разметки  
Название:    ResourceField  
Краткое описание:    поле выбора ресурса WT  
Тип:    Пользовательский элемент  
Содержимое:    Название ресурса, который уже выбран (начальное значение)  
Подробное описание:      
Этот компонент выбирает ресурс (resource) из базы WT.  
Примеры использования:    

<ResourceField Name="FileField01" Width="200" Source="MyFileList"/>

Параметры:

**Атрибут**

**Тип**

**Описание**

Name

string

Идентификатор поля. В Context при передаче данных будет передано ID ресурса через "\[Name\]" и название ресурса через "\[Name\]Title", если не указан атрибут TitleName. Если поле Name не указано, то оно будет случайной

Width

integer

Ширина, в пикселях

Source

string

Код документа выборки в WT. Если написать просто код выборки, то она будет напрямую запрошена с сервера. Если написать код выборки в фигурных скобках {}, то выборка будет проводиться через объект Collection (который в этом случае должен существовать). Это нужно, если требуется на каждый запрос к выборке передать еще какие-то данные, которые в этом самом объекте Collection и описываются. Выборка должна возвращать массив элементов, среди полей которых обязательно должны быть поле "id" - WT ID ресурса, и "name" - название ресурса или файла

TitleName

string

Хранилище названия файла/ресурса. В CONTEXT будет передано через это поле, но если не указано, то будет передано через "\[Name\]Title".

CanCreate

bool

Отображать в странице диалога создание нового ресурса. По умолчанию true

CanSelect

bool

Отображать в странице диалога выбор ресурса. По умолчанию true

CurrentValue

string

WT ID ресурса, который уже выбран (начальное значение). Название самого файла нужно писать в содержимое
