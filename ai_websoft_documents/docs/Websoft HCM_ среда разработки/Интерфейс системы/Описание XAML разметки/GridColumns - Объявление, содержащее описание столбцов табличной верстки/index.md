## GridColumns - Объявление, содержащее описание столбцов табличной верстки

Элемент разметки  
Название:    GridColumns  
Краткое описание:    Объявление, содержащее описание столбцов табличной верстки  
Тип:    Управляющий элемент  
Содержимое:    Описание столбца GridColumn  
Подробное описание:      
Столбец таблицы компоновки. Содержит описание столбцов GridColumnLite Тестирование  
Примеры использования:      
<Grid Width="500">  
<GridColumns>  
<GridColumn Width="200"/>  
<GridColumn Width="300"/>  
</GridColumns>  
<GridRow>  
<Label>TopLeft</Label>  
<Label>TopRight</Label>  
</GridRow>  
<GridRow>  
<Label>BottomLeft</Label>  
<Label>BottomRight</Label>  
</GridRow>  
</Grid>
