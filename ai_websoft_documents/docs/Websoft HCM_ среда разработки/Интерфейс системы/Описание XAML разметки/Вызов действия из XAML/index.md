## Вызов действия из XAML

В разнообразных компонентах, имеющих события (Button, Link, CheckBox и т.д.) на каждое событие можно вызвать какое-то действие.

Действий можно производить несколько друг за другом, через точку с запятой (;)

Есть действия останавливающие (после них другие действия выполняться не будут), я их буду помечать символом (**X**)

Действия бывают удаленные и стандартные.

**ВЫЗОВ УДАЛЕННОГО ДЕЙСТВИЯ**

\* действия, помеченные **X**, прекращают обработку дальнейшей цепочки команд.

\- **ACTION** - **X + сбрасывается CONTEXT** - выполнить удаленное действие. Сначала будет поиск такого действия среди действий Action. Если не найдено, будет попытка вызвать действие с таким кодом в WT. (_ACTION=MyFirstAction_)

**ОБНОВЛЕНИЯ И ПЕРЕХОДЫ**

\- **OPENURL** - **X** - перейти по заданному URL (_OPENURL=https://www.smeshariki.ru_)

\- **OPENWINDOW** - **X** - открыть по URL в новом окне. Первый параметр URL.

Дополнительные опциональные параметры:

    **Width** \- ширина окна,

    **Height** \- высота,

    **Scroll** - есть ли полосы прокрутки (см. пример)

    **Resizable** - есть ли полосы прокрутки (см. пример)

    **CloseAction** - выполнение удаленного действия Action после закрытия окна.

\- **REFRESH** - **X** - перезагрузить XAML и отрисовать заново. Без параметров. В XAML отправляется CONTEXT.

**ДИАЛОГОВЫЕ ОКНА**

\- **OPENDIALOG** - **X** - отрыть диалоговое окно. Первый параметр - идентификатор описания диалога Dialog _(OPENDIALOG=my\_dialog)_

\- **CLOSEDIALOG** - **X** _-_ закрыть диалоговое окно. Закрывает текущее окно, если оно диалог. Выполняет действие **Close** диалога если есть.

\- **CANCELDIALOG** - **X** _-_ закрыть диалоговое окно. Закрывает текущее окно, если оно диалог. Игнорирует действие **Close** диалога если есть.

**СООБЩЕНИЯ**

\- **CONFIRM** - **X** **если выбран отказ**  - спросить подтверждение _(CONFIRM=Ты уверен?)_

\- **ALERT** - вывести сообщение _(ALERT=Сейчас что-то произойдет)_

**ОТОБРАЖЕНИЕ ЭЛЕМЕНТОВ**

\- **SHOW** - покзать скрытый элемент _(SHOW=Grid1,Panel1)_

\- **HIDE** - скрыть элемент _(HIDE=Grid1,Panel1)_

\- **TOGGLE** - HIDE/SHOW попеременно _(TOGGLE=Grid1,Panel1)_

поддерживается элементами _StackPanel, DataGrid, Grid, Tree, TabControl, Calendar, Panel, TileView,_ графики

\- **EXPAND** - развернуть элемент _(EXPAND=Panel1)_

\- **COLLAPSE** - свернуть элемент _(COLLAPSE=Panel1,Panel2)_

поддерживается элементами _Panel, Calendar_

\- **PRESS** - нажать первую возможную кнопку с соответствующей ToggleGroup _(PRESS=ButtonsPack) или нажать на определенную \[начиная с 0\] (PRESS=ButtonsPack,2)_

\- **RELEASE** - отжать все кнопки с соответствующей ToggleGroup _(RELEASE=ButtonsPack) или отжать определенную \[начиная с 0\] (_RELEASE=_ButtonsPack,2)_

\- **ENABLE** \- сделать доступной группу кнопок с соответствующей ControlGroup (_ENABLE=ButtonsGroup1_)  
\- **DISABLE** \- сделать недоступной группу кнопок с соответствующей ControlGroup (_DISABLE=ButtonsGroup1_)

поддерживается элементами _Button_

**УПРАВЛЕНИЕ ДАННЫМИ**

\- **UPDATE** - обновить данные элементов, ID которых перечислены (поддерживаются DataGrid,Tree, Calendar, Panel \[если есть источник\],TileView, графики **\***Chart)_(UPDATE=Grid1,Tree1)_

\- **SET** - установить значение элементу. Первый параметр - идентификатор элемента, второй - значение _(SET=Edit1,Hello!!!;SET=Edit1,{Edit2})_

Менять также можно значения параметров в метаданных, типа Dialog, Collection и Action

Для этого используются суффиксы-пути.

например если у действия _Action1_ есть параметр _param1_:

_(SET=Action1/param1,100500)_

Суффиксы-селекторы не используются!

\- **DELETE** - удаляет значение из элемента. У чекбоксов снимает выделение. У DataGrid удаляет выделенные строки. _(DELETE=Grid1,Edit1;DELETE=Grid1:\*)_

Поддерживаемые суффиксы: селекторы _**\***_ и **^**

\- **CONTEXT** - переопределение текущего контекста, отправляемого на сервер. Первы параметр - идентификатор контекстной группы либо нет параметров. По умолчанию на сервер отправляются все данные формы (например с действиями **REFRESH**, **OPEN** и т.д.). Если на форме определены контекстные группы ContextGroup, текущий контекст можно ограничить этой группой. Если указать значение _NULL_, в контекст ничего не будет передано. Внимание: после выполнения всей цепочки действий контекст вернется к значению по умолчанию: все элементы формы. Также если не указать идентификатор группы или указать пустой, контекст вернется к значению по умолчанию: все элементы формы _(CONTEXT=ContextGroup1;CONTEXT=NULL;CONTEXT=;CONTEXT)_

**ДРУГОЕ**

\- **STOP** - **X** - прекратить цепочку действий

Для значений этих действий после знака равно можно исползовать значения полей или выборок (для DataGrid, Dialog и т.п.), записав их ID в фигурные скобки **{}** (см. пример)

_<Button Click="ACTION=MyAction" Width="100">_Нажми меня_</Button>_

<Edit Name="Edit1" Width="500">Напиши здесь что искать...</Edit>

_<Button Click="OPENWINDOW=http://www.google.com/search?q={Edit1},Width=800,Height=500,Scroll=0">_Погугли_</Button_\>
