## OrgChart - Орг чарт

Элемент разметки  
Название:    OrgChart  
Краткое описание:    Орг чарт  
Тип:    Пользовательский элемент  
Содержимое:    Может содержать элементы OrgChartButton  
Подробное описание:      
 

Рисует красивую иерархическую диаграмку с возможностью выбора нескольких узлов.  
Может содержать кнопки OrgChartButtonDocument Link Icon  
Примеры использования:      
<Collection Name="OrgChartCollection" Source="org\_chart\_collection"/>

<OrgChart Name="OneHellOfAChart" Width="100%" Height="600" Source="{OrgChartCollection}" Selectable="1">  
<OrgChartButton Click="OPENURL=view\_doc.html?mode=collaborator&doc\_id=<%=curDocID%>&object\_id={person\_id}" Image="/pics/person.gif">Open collaborator</OrgChartButton>  
</OrgChart>

  
Параметры:

**Атрибут**

**Тип**

**Описание**

Name

string

Идентификатор

Width

integer

Ширина. В пикселях.

Height

integer

Высота. В пикселях.

Source

string

 

Код документа выборки в WT. Если написать просто код выборки, то она будет напрямую запрошена с сервера. Если написать код выборки в фигурных скобках {}, то выборка будет проводиться через объект Collection (который в этом случае должен существовать). Это нужно, если требуется на каждый запрос к выборке передать еще какие-то данные, которые в этом самом объекте Collection и описываются.

Selectable

bool

Возможность выбирать узлы. Выбранные значения будут отдаваться при обращении к орг-чарту в виде массива объектов (как у DataGrid и прочих). Возможны использования селекторов

Orientation

string

Направление построения оргчарта: top (по умолчанию) - сверху вниз left - слева направо

Alignment

string

Выравнивание оргчарта. center (по умолчанию) - по центру Если Orientation=top left - по левому краю right - по правому краю Если Orientation=left top - по верхней границе bottom - по нижней границе

NodeMode

string

Если элементов слишком много, удаленные от корня могут отображаться как: dot (по умолчанию) - точки normal - по нормальному полностью

DataID

string

Поле элемента из результатов выборки, в котором находится уникальный идентификатор элемента \[id\]

DataParent

string

Поле элемента из результатов выборки, в котором находится идентификатор родителя элемента \[parent\]

DataSister

string

Поле элемента из результатов выборки, в котором находится булевое значение, показывающее что элемент является равнозначным родителю, а не подчиненным \[sister\]

DataTitle

string

Поле элемента из результатов выборки, в котором находится заголовок элемента \[title\]

DataText

string

Поле элемента из результатов выборки, в котором находится HTML-содержимое элемента \[text\]

DataColor

string

Поле из результатов выборки, в котором записан цвет заголовка в HEX вида #RRGGBB \[color\]

DataImage

string

Поле элемента из результатов выборки, в котором находится URL до картинки/аватарки элемента \[image\]

События:

**Событие**

**Описание**

NodeClick

k

Выполнение действия при нажатии на ноду.
NB: в фигурных скобках можно использовать поля из выборки. Например {id}
