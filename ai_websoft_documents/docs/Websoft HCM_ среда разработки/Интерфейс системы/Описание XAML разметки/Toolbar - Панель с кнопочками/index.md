## Toolbar - Панель с кнопочками

Элемент разметки  
Название:    Toolbar  
Краткое описание:    Панель с кнопочками  
Тип:    Пользовательский элемент  
Содержимое:    Кнопки  
Подробное описание:      
Панель управления чем-то.   
Содержать может:  
\- кнопкиLite Тестирование  
\- расхлопывающиеся спискиLite Тестирование

  
Если не содержит ни одного элемента, то самопроизвольно исчезает.  
Примеры использования:    

  
<Toolbar>  
<Button Click="OPENWINDOW=http://ya.ru" Icon="/pics/img.png">Open URL</Button>  
</Toolbar>

Параметры:

**Атрибут**

**Тип**

**Описание**

Width

integer

Ширина. В пикселях или процентах

Class

string

Имя класса из таблицы стилей если нужно
