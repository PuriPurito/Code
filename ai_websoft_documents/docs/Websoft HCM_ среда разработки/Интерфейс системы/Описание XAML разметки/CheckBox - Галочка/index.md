## CheckBox - Галочка

Название:    CheckBox  
Краткое описание:    Галочка  
Тип:    Пользовательский элемент  
Содержимое:    Текст около элемента

  
Примеры использования:    

<CheckBox Name\="checkbox1">Выбери меня</CheckBox\>

Параметры:

**Атрибут**

**Тип**

**Описание**

Name

string

Идентификатор

Enabled

bool

Активен ли элемент

Value

string

Значение, которое будет возвращено при выборе чекбокса. По умолчанию 1

Checked

bool

Элемент отмечен или нет

Class

string

Имя класса из таблицы стилей если нужно

События:

**Событие**

**Описание**

Change

Выполнение действия при переключении значения.

Check

Выполнение действия при установке отметки

Uncheck

Выполнение действия при снятии отметки
