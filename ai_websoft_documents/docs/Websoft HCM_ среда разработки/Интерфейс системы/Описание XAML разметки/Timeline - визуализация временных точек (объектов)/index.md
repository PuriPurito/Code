## Timeline - визуализация временных точек (объектов)

Элемент разметки  
Название:    Timeline  
Краткое описание:    Визуализация временных точек (объектов)  
Тип:    Пользовательский элемент  
Содержимое:  

Элемент отрисовывает временные линии для каждого ключевого объекта (линии) с временными точками, в соответствии с параметрами самого XAML элемента и данными, полученными из коллекции. 

Примеры использования:

<Timeline Name\="timelineForCollab" Height\="500" Width="1100" FontColor\="#000000" BgColor\="#ffffff" FntSzNameScale\="13" Source\="{collection\_timeline}"/>

Параметры для вызова удаленной выборки (uni\_collection\_timeline)

<Collection Name\="collection\_timeline" Source\="uni\_collection\_timeline">

            <Param Name\="dStartPeriod" Value\="<%=sPeriodStart%>"/>

            <Param Name\="dEndPeriod" Value\="<%=sPeriodEnd%>"/>

            <Param Name\="sDateType" Value\="<%=iSelectDateType%>"/>

            <Param Name\="sPersonIds" Value\="<%=sChoiceCollIds%>"/>

</Collection\>

Коллекция для XAML элемента Timeline представляет собой массив ключевых объектов.

Каждый ключевой объект - это набор данных, с указанными датами, по которым условная единица данных будет позиционироваться на линии времени.

Ключевым объектом может быть:

\- набор данных по сотруднику. Например, он может включать информацию по всем законченным курсам, тестам, пройденным мероприятиям, опросам и т.п. сотрудника.

\- набор данных по объекту WT из списка объектов (законченный курс/тест, результат мероприятия, результаты опросов и т.п.). Например, он может включать информацию по всем связанным с ним сотрудникам (участник мероприятия, сотрудник из карточки завершенного курса/теста и т.п.)

Формат ключевого объекта oKey:

oKey = {

    “icon”: “url img”                                                                 // ссылка на картинку, которой будет обозначена линия

    “name”: “имя объекта”,                                                   // название объекта (курс, тест, мероприятия, фио сотрудника…)

    “color”: “цвет линии”,                                                      // цвет линии соответствующего ключевого объекта

    “desc”: “<div class=’dlg-container’ >…</div>”,               // html структура для всплывающего окна с описанием объекта

    “aPoints”: \[ point1, point2, point3 … \]                             // массив единиц данных (точек), связанных с объектом

}

Формат объекта (точки) oPoint массива единиц данных:

oPoint = {

    “date”: “2019-12-01”,                                                      // формат строго: yyyy-mm-dd

    “id”: “57695353237565”,                                                // id объекта в wt

    “name”: “имя объекта”,                                                 // название объекта, например, наименование законченного курса/теста, пройденного мероприятия и т.п.

    “desc”: “<div class=’dlg-container’ >…</div>”,              // html структура для всплывающего окна с описанием объекта

    “icon”: “url img”                                                              // ссылка на картинку, которой будет обозначена точка. Если не передана, будет подставлена картинка для соответствующей линии

}

Сформированный набор данных, состоящий из ключевых объектов, собирается в результирующий массив RESULT, возвращаемый XAML элементу timeline.

Параметры:

Атрибуты

Тип

Описание

Name

string

Идентификатор XAML элемента

Height

integer

Высота XAML элемента. Задается в px. Переданное значение приводится к целому числу, если это возможно. В противном случае используется значение по умолчанию, равное 750px. Содержимое элемента автоматически позиционируется и подстраивается под высоту контейнера, если не заданы параметры: HeightTimeLine, HeightObjectScale.

Width

integer

Ширина XAML элемента. Задается в px. Переданное значение приводится к целому числу, если это возможно. В противном случае используется значение по умолчанию, равное 1200px.

Source

string

Код документа выборки в WT. Если написать просто код выборки, то она будет напрямую запрошена с сервера. Если написать код выборки в фигурных скобках {}, то выборка будет проводиться через объект Collection (который в этом случае должен существовать). Это нужно, если требуется на каждый запрос к выборке передать еще какие-то данные, которые в этом самом объекте Collection и описываются.

Hidden

bool

Скрыт элемент или показан. По умолчанию показан. (либо явно задается true, false, либо 1, 0). Значение обязательно оборачивается в кавычки.

DistanceScroll

integer

Расстояние шага прокрутки стрелками. Если не задано, считается как половина ширины контейнера.

SpeedScroll

integer

Длительность анимации прокрутки стрелками (в ms). Переданное значение приводится к целому числу, если это возможно. В противном случае используется значение по умолчанию, равное 300 ms.

HeightTimeLine

integer

Длина линии, соединяющей иконку временной точки с соответствующей линией времени. Задается в px. Переданное значение приводится к целому числу, если это возможно. В противном случае используется значение по умолчанию, равное 50px.

HeightObjectScale

integer

Высота линии времени. Задается в px. Переданное значение приводится к целому числу, если это возможно. В противном случае используется значение по умолчанию, равное 50px.

WidthLinePoint

integer

Длина отрезка минимальнй единицы (шага) шкалы времени. Задается в px. Переданное значение приводится к целому числу, если это возможно. В противном случае используется значение по умолчанию, равное 30. Предусмотрено ограничение размера ширины шага, если он больше HeightTimeLine. Также задает максимальную ширину/высоту иконки временной точки. Это исключает их наложение друг на друга, когда они расположены рядом.

WthHthImgLinkPoint

integer

Ширина/высота img (link-point). Задается в px. Переданное значение приводится к целому числу, если это возможно. В противном случае используется значение по умолчанию, равное WidthLinePoint.

WidthDlg

integer

Ширина диалогового окна с описанием. Задается в px. По умолчанию auto.

HeightDlg

integer

Высота диалогового окна с описанием. Задается в px. По умолчанию auto.

FntSzNameScale

integer

Размер шрифта названий временных линий. Задается в px. Переданное значение приводится к целому числу, если это возможно. В противном случае используется значение по умолчанию, равное 16px. Предусмотрено ограничение, если размер шрифта максимально допустимого (высота шкалы \* коэффицент) равен максимально допустимому.

ShowMarkPoint

bool

Показать точки на временной линии.По умолчанию false.

ScrollWheel

bool

Вкл/Откл прокрутку колесом мыши.По умолчанию true.

ScrollArrows

bool

Вкл/Откл прокрутку стрелками. По умолчанию true.

FontColor

string

Основной цвет текста. По умолчанию черный (#000000).

BgColor

string

Цвет фона. По умолчанию белый (#ffffff).

ColorTitle

string

Цвет уголка плашки со списком объектов (курсов, тестов, мероприятий и т.п.) соответствующей временной точки.
