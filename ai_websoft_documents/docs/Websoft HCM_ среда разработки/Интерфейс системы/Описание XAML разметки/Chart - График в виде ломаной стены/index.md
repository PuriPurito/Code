## Chart - График в виде ломаной стены

Элемент разметки  
Название:    Chart  
Краткое описание:    График в виде ломаной стены  
Тип:    Пользовательский элемент  
Содержимое:    

Рисует суперуниверсальный график.

Внимание! Параметры каждой диаграммы описываются с помощью массива COLUMNS в удаленной выборкеLite

Примеры использования:    

<Chart Name\="MyChart" Width\="100%" Height\="400" DataChartID\="caption" DataCategory\="x" 

DataValue\="y"Source\="ChartData"/>

Данные из удаленной выборкиLite Тестирование ChartData:  
RESULT = (\[  
{"caption": "Диаграмма Джо", "x": "сегодня", "y": 60},  
{"caption": "Диаграмма Джо", "x": "завтра", "y": 65},  
{"caption": "Диаграмма Джо", "x": "через неделю", "y": 80},  
{"caption": "Диаграмма Джо", "x": "после выборов", "y": 40},

{"caption": "Диаграмма Джэйн", "x": "сегодня", "y": 30},  
{"caption": "Диаграмма Джэйн", "x": "завтра", "y": 95},  
{"caption": "Диаграмма Джэйн", "x": "через неделю", "y": 20},  
{"caption": "Диаграмма Джэйн", "x": "после выборов", "y": 10}  
\]);

COLUMNS = (\[  
{"id": "Диаграмма Джо", "type":"area"},  
{"id": "Диаграмма Джэйн", "type":"line"}  
\]);

Параметры:

**Атрибут**

**Тип**

**Описание**

Name

string

Идентификатор

Width

integer

Ширина. В пикселях

Height

integer

Высота. В пикселях

Source

string

Код документа выборки в WT. Если написать просто код выборки, то она будет напрямую запрошена с сервера. Если написать код выборки в фигурных скобках {}, то выборка будет проводиться через объект Collection (который в этом случае должен существовать). Это нужно, если требуется на каждый запрос к выборке передать еще какие-то данные, которые в этом самом объекте Collection и описываются.

DataChartID

string

Поле элемента из результатов выборки, в котором находится уникальное название графика. Данные будут сгруппированы в один график по нему. \[chart\]

DataCategory

string

Поле элемента из результатов выборки, в котором указана категория (значение по оси X). \[category\]

DataValue

string

Поле элемента из результатов выборки, в котором указаны значения (значение по оси Y). \[value\]

DataColor

string

Поле элемента из результатов выборки, в котором указан цвет значения (важно для пирогов и бубликов) \[color\]

ShowLabels

bool

Показывать значения на графике \[false\]

Scrollable

bool

У графика появляется скролл и ширина расчитывается по размеру данных. Работает только если Width указан в пикселях.

StackSeries

bool

Графики стеком \[false\]

View3D

bool

Изометрический режим \[false\]

Invert

bool

Поменять оси местами \[false\]

Legend

string

Показывать легенду в одной из сторон света Принимаемые значения: \[n, nw, w, sw, s, se, e, ne\]. При любом другом значении не показывается вообще (по умолчанию не показывается)

Options

string

Служебные настройки, применимые только к своей версии плеера XAML. Имеют формат <параметр1>:<значение1>,<параметр2>:<значение2>,.....,<параметрN>:<значениеN> Пример: Options="fontSize:20,gridColor:'red'" ExtJS Player 5: - fontSize \[integer\]: размер шрифта для подписей \[14\] - gridColor: \[string\] - HTML цвет сетки \[gray\] - padding \[int\]: отступ в пикселях от края границы \[10\]

События:

**Событие**

**Описание**

Click

Выполнение действия при нажатии на точку/дольку значения.
в фигурных скобках можно использовать поля из результатов выборки, например {caption}
