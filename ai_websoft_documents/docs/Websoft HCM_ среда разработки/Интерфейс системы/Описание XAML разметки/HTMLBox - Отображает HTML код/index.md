## HTMLBox - Отображает HTML код

Элемент разметки  
Название:    HTMLBox  
Краткое описание:    Отображает HTML код  
Тип:    Пользовательский элемент  
Содержимое:    HTML в CData секции  
Подробное описание:      
Show details for HTMLBoxHTMLBox

Если нужно отобразить какой-то HTML кусок, HTMLBox должен тебе помочь.  
Примеры использования:      
<HTMLBox>  
<!\[CDATA\[  
<b>TEXT TEST!!!</b>  
\]\]>  
</HTMLBox> 

Параметры:

**Атрибут**

**Тип**

**Описание**

Width

integer

Ширина. В пикселях.

Height

integer

Высота. В пикселях.

Class

string

Имя класса из таблицы стилей если нужно

Name

string

Идентификатор. По нему группируются элементы.

Dynamic

bool

Считывать динамические данные из содержимого (скрипты, стили). Крайне нежелательно! \[false\]
