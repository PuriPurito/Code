## MindMap - Рисует ментальную карту [ExtJS Player]

Элемент разметки  
Название:    MindMap  
Краткое описание:    Рисует карту ума \[ExtJS Player\]  
Тип:    Пользовательский элемент  
Содержимое:      
Подробное описание:      
 

  
Рисует диаграмму, по сути ничем не отличающуюся от орг-чарта.

Примеры использования:    

<Collection Name="MMCollection" Source="mind\_map">  
</Collection>

<MindMap Name="PlanOfMind" Width="100%" Height="500" Source="{MMCollection}" ShowToolbar="1" Click="OPENWINDOW={url}"/>

Параметры:

**Атрибут**

**Тип**

**Описание**

Name

string

Уникальный идентификатор элемента

Width

integer

Ширина. В пикселях.

Height

integer

Высота. В пикселях.

ShowToolbar

bool

Показывать ли панель с управляющими кнопками. По умолчанию false

Source

string

Код документа выборки в WT. Если написать просто код выборки, то она будет напрямую запрошена с сервера. Если написать код выборки в фигурных скобках {}, то выборка будет проводиться через объект Collection (который в этом случае должен существовать). Это нужно, если требуется на каждый запрос к выборке передать еще какие-то данные, которые в этом самом объекте Collection и описываются.

DataID

string

Поле элемента из результатов выборки, в котором находится уникальный идентификатор элемента \[id\]

DataParent

string

Поле элемента из результатов выборки, в котором находится идентификатор родителя элемента \[parent\]

DataTitle

string

Поле элемента из результатов выборки, в котором находится заголовок элемента \[title\]

DataTurnround

string

Поле элемента из результатов выборки, в котором содержится флаг смены направления \[turnround\]

DataColor

string

Поле из результатов выборки, в котором записан цвет фона в HEX вида #RRGGBB \[color\]

DataText

string

Поле элемента из результатов выборки, в котором находится текст содержимого \[text\]

DataClickable

string

Поле элемента из результатов выборки, в котором показано, если ли у элемента событие Click \[clickable\]

DataExpanded

string

Поле элемента из результатов выборки, в котором показано, раскрыт элемент изначально или нет \[expanded\].

События:

**Событие**

**Описание**

Click

Действие на нажатие на черную скрепку элемента \[если у него выставлено clickable\]
