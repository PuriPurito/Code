## Button - Кнопка

Элемент разметки  
Название:    Button  
Краткое описание:    Кнопка  
Тип:    Пользовательский элемент  
Содержимое:    Заголовок кнопки и/или меню

Подробное описание:    

Кнопка на которую надо нажимать. В качестве действия передается набор действий, стандартных или нет.

Может содержать контекстное меню MenuDocument Link Icon, если это не нажимательно-отжимательная кнопка, и на ней не висит событие Click  
Примеры использования:    

<Button Click\="ACTION=MyAction" Width\="100">Нажми меня</Button\>  
<Button Click\="OPENWINDOW=http://www.google.com/search?q={Edit1}">Сходи погугли</Button\>  
  
  
<Button Click\="ALERT=Браза!" Toggle\="1" ToggleGroup\="!Twinz" Pressed\="1">Брат</Button\>  
<Button Click\="ALERT=Систа!" Toggle\="1" ToggleGroup\="!Twinz">Сестра</Button\>  
  
<Button Click\="ALERT=Ты нажал меня!" Release\="ALERT=Ты ОТЖАЛ меня!!!" Toggle\="1">Мрачный тип</Button\>

Параметры:

**Атрибут**

**Тип**

**Описание**

Width

integer

Ширина. В пикселях.

Enabled

bool

Активна ли кнопка

Class

string

Имя класса из таблицы стилей если нужно

Icon

string

Если ДА, то кнопка нажимательно-отжимательная

ToggleGroup

string

Если указана группа, то все кнопки в этой группе будут переключаться как селекторы. Работает только при включенном Toggle. Если название группы начинается с восклицательного знака (!), можно отжимать все кнопки

Pressed

bool

Если ДА, то кнопка изначально нажата. Работает только при включенном Toggle

Name

string

Идентификатор. Только для технических целей.

ControlGroup

string

Название группы для дальнейших действий над кнопками в этой группе

События:

**Событие**

**Описание**

Click

Действие на нажатие кнопки. 

Release

Действие на отжатие кнопки. Работает только если кнопка сама по себе нажимается/отжимается, т.е. Toggle включен, но ToggleGroup не указана (см. пример)
