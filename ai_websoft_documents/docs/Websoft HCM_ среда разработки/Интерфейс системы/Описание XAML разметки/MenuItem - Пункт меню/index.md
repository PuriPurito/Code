## MenuItem - Пункт меню

Элемент разметки  
Название:    MenuItem  
Краткое описание:    Пункт меню  
Тип:    Пользовательский элемент  
Содержимое:      
Подробное описание:      
Описание элемента контекстного меню MenuLite Тестирование  
Примеры использования:    

<Edit Name="Edit1" Width="500">  
<Menu>  
<MenuItem Title="Очистить" Click="DELETE=Edit1"/>  
</Menu>  
</Edit>

Параметры:

**Атрибут**

**Тип**

**Описание**

Title

string

Заголовок. Если равен "-", то станет сепаратором.

События:

**Событие**

**Описание**

Click

Действие на вызов данного пункта меню. 
N.B. при вызове контекстного меню в DataGrid в окружение также передаются данные из текущей строки таблицы
