## FlowChart - Графическое представление какой-нибудь иерархии или процесса [ExtJS Player]

Элемент разметки  
Название:    FlowChart  
Краткое описание:    Графическое представление какой-нибудь иерархии или процесса \[ExtJS Player\]  
Тип:    Пользовательский элемент  
Содержимое:      
Подробное описание:    

  
Рисует квадратики соединенные стрелочками, в соответствии с иерархией.  
Примеры использования:    

<FlowChart Name="Graph1" Width="900" Height="400" DataID="id" DataTitle="name" DataParent="parent\_object\_id" Source="FlowGrow"/>

Код удалённой выборкиLite Тестирование FlowGrow:  
RESULT = new Array();  
RESULT\[ArrayCount(RESULT)\] = ({"id":"1", "name": "L 1"});  
RESULT\[ArrayCount(RESULT)\] = ({"id":"11", "name": "L 1.1", "parent\_object\_id": "1"});  
RESULT\[ArrayCount(RESULT)\] = ({"id":"111", "name": "L 1.1.1", "parent\_object\_id": "11"});  
RESULT\[ArrayCount(RESULT)\] = ({"id":"112", "name": "L 1.1.2", "parent\_object\_id": "11"});

Параметры:

**Атрибут**

**Тип**

**Описание**

Width

integer

Ширина. В пикселях

Height

integer

Высота. В пикселях.

Source

string

Код документа выборки в WT. Если написать просто код выборки, то она будет напрямую запрошена с сервера. Если написать код выборки в фигурных скобках {}, то выборка будет проводиться через объект Collection (который в этом случае должен существовать). Это нужно, если требуется на каждый запрос к выборке передать еще какие-то данные, которые в этом самом объекте Collection и описываются.

DataID

string

Поле элемента из результатов выборки, в котором находится уникальный ID элемента \[id\]

DataTitle

string

Поле элемента из результатов выборки, из которого брать название элемента дерева \[title\]

DataParent

string

Поле элемента из результатов выборки, из которого определять ID родительского элемента \[parent\]

DataIcon

string

Поле элемента из результатов выборки, из которого можно заполучить URL картинки. Опционально. \[icon\]

Name

string

Идентификатор

События:

**Событие**

**Описание**

Click

Выполнение действия при нажатии на ветку.
NB: в фигурных скобках можно использовать поля \[id,parent,title\], см. удаленные выборки в графах. Например {id}
