## EditBox - Элемент для ввода многострочного текста

Элемент разметки  
Название:    EditBox  
Краткое описание:    Элемент для ввода многострочного текста  
Тип:    Пользовательский элемент  
Содержимое:    Изначально загруженный текст  
Подробное описание:      

Элемент для ввода многострочного текста  
Примеры использования:      
<EditBox Name="Edit1">  
Какой-то стишок  
Внутри моего поля.  
Хайку похоже...  
</EditBox>

Параметры:

**Атрибут**

**Тип**

**Описание**

Name

string

Идентификатор

Enabled

bool

Активно ли поле ввода

Width

int

Ширина. В пикселях.

Height

int

Высота. В пикселях.

Class

string

Имя класса из таблицы стилей если нужно

MaxLength

integer

Максимально допустимое количество символов \[0 - выкл\]
