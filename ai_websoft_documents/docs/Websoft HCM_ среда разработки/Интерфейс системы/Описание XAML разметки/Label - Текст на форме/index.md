## Label - Текст на форме

Элемент разметки  
Название:    Label  
Краткое описание:    Текст на форме  
Тип:    Пользовательский элемент  
Содержимое:    Собственно текст  
Подробное описание:      
Show details for LabelLabel

Просто текст на форме  
Примеры использования:  

   
<Label>Заголовок</Label>

Параметры:

**Атрибут**

**Тип**

**Описание**

Width

integer

Ширина. В пикселях.

Class

string

Имя класса из таблицы стилей если нужно

Align

string

\[left,center,right\] - выравнивание текста.

NoWrap

bool

Не переносить текст, всё в одну строку(false) \[ExtJS Player 5\]: совместно с параметром Width при превышении ширины обрежет текст троеточием

Adapt

bool

Автоматически отключает параметр NoWrap при режиме плеера "mobile"
