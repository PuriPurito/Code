## RichEdit - Расширенный текстовый редактор

Элемент разметки  
Название:    RichEdit  
Краткое описание:    Расширенный текстовый редактор (Редактор "богатого текста")  
Тип:    Пользовательский элемент  
Содержимое:    Исходный текст  
Подробное описание:    

Компонент для редактирования rich-text.

NB:  
В реализации ExtJS используется TinyMCE. Весь текст сохраняется в HTML  
В реализации ExtJS 5 используется встроенный редактор либо CKEditor (с 2019-го CKEditor выставлен по умолчанию).  
Примеры использования:    

<RichEdit Name="Rich1" Width="100%" Height="500">  
<!\[CDATA\[<%=CONTEXT.GetOptProperty("Rich1","<b>DEFAULT TEXT</b>")%>\]\]>  
</RichEdit>

Параметры:

**Атрибут**

**Тип**

**Описание**

Name

string

Идентификатор

Width

integer

Ширина. В пикселях.

Height

integer

Высота. В пикселях.

AllowLinks

bool

включить поддержку ссылок

LinkToWTObject

string

вставить ссылку на объект Webtutor (работает только при включенном параметре AllowLinks). В качестве параметра передается название каталога, либо название каталога и условие xquery, разделенные вертикальной чертой. Пример: resource|$elem/type = 'img' and ($elem/person\_id=null() or $elem/person\_id=##curUserID##) Условие xquery может быть с закодированными спец-символами
