## ComboBox - Раскрывающийся список

Элемент разметки  
Название:    ComboBox  
Краткое описание:    Раскрывающийся список  
Тип:    Пользовательский элемент  
Содержимое:    Содержит элементы ComboBoxItem, являющиеся пунктами списка  
Подробное описание:      
Show details for Раскрывающийся список  
Примеры использования: 

<ComboBox Name\="MyCombo1">  
  <ComboBoxItem Value\="0">Zero</ComboBoxItem\>  
  <ComboBoxItem Value\="1">Uno</ComboBoxItem\>  
  <ComboBoxItem Value\="2">Due</ComboBoxItem\>  
</ComboBox\>

Параметры:

**Атрибут**

**Тип**

**Описание**

Name

string

Идентификатор

Width

int

Ширина. В пикселях.

Enabled

bool

SelectedItem

bool

События:

**Событие**

**Описание**

Change

Выполнение действия при переключении. Если у элемента ComboBoxItem стоит своё событие Change, то текущее действие будет проигнорировано и выполнится действие Change у выбранного элемента.
