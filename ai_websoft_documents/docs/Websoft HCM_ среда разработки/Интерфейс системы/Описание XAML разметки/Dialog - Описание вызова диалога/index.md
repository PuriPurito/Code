## Dialog - Описание вызова диалога

Элемент разметки  
Название:    Dialog  
Краткое описание:    Описание вызова диалога  
Тип:    Управляющий элемент  
Содержимое:    Объекты 

Подробное описание:    

Описывает вызываемый диалог и все его параметры, также события на закрытие. Содержит параметры ParamLite Тестирование для передачи данных в XAML диалога в переменную PARAMETERSLite Тестирование

Примеры использования:      
<Dialog Name="my\_dialog" Source="-xaml-dialog" Title="Диаложек" Close="ALERT={EditX}!">  
<Param Name="BodyTitle" Value="Добро пожаловать в диалог!"/>  
</Dialog>

<Button Click="OPENDIALOG=my\_dialog">Открыть диалог</Button>

**Атрибут**

**Тип**

**Описание**

Width

integer

Ширина окна, в пикселях. По умолчанию 80%

Height

integer

Высота окна, в пикселях. По умолчанию 50%

Title

string

Заголовок окна

Source

string

Код документа XAML в базе WT, по которому будет нарисован диалог. Может быть затежен {}

Name

string

Идентификатор диалога

ShowHeader

bool

Показывать ли заголовки столбцов. \[true\]

MinHeight

integer

Минимальная высота диалога

События:

**Событие**

**Описание**

Close

Выполнение действия при закрытии диалога. В области видимости видны элементы из контекста диалога, но выполняется всё в родительском окружении.
