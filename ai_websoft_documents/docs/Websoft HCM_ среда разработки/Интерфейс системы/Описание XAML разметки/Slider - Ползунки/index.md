## Slider - Ползунки

Элемент разметки  
Название:    Slider  
Краткое описание:    Ползунки  
Тип:    Пользовательский элемент  
Содержимое:      
Подробное описание:    

Только для версии проигрывателя \[ExtJS Player 5\]

Ползунок для указание значения или диапазона

  
Примеры использования:    

<Slider Name="MySlider" Ranged="true" Width="200" Min="0" Max="100" Value="20,50"/>

Параметры:

**Атрибут**

**Тип**

**Описание**

Name

string

Идентификатор

Width

integer

Ширина. В пикселях.

Class

string

Имя класса из таблицы стилей если нужно

Hidden

bool

Скрыто ли поле визуально, \[true,false\]

Value

string

Значение. Если Ranged=true, то два числа через запятую, в противном случае одно число

Min

integer

Минимальное значение ползунка \[0\]

Max

string

Максимальное значение \[0\]

Ranged

bool

Если true, можно выбрать диапазон значений, в противном случае одно значение \[false\]

События:

**Событие**

**Описание**

Change

Выполнение действия при изменении значения.
