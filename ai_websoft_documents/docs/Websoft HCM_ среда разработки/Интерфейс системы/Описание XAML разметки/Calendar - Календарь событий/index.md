## Calendar - Календарь событий

Элемент разметки  
Название:    Calendar  
Краткое описание:    Календарь событий  
Тип:    Пользовательский элемент  
Содержимое:      
Подробное описание:      
Show details for CalendarCalendar

Календарь событий. Использует в качестве данных подгрузку из удаленных выборокLite Тестирование

Особенности:   
Если в полученном событии нет даты начала, оно выкидывается; нет даты завершения - она приравнивается к дате начала.  
События с одинаковыми именами и разными датами рисуются независимо. В категоризованном виде они группируются в одной строке.  
Если два события вообще идентичны и по названиям, и по времени - он будут всё-равно считаться двумя независимыми событиями.

Примеры использования:    

<Calendar Width\="800" Height\="500" Source\="CalendarData" Name\="Calendar1" Hidden\="0" 

Modes\="Day,Week"DayClick\="ALERT=Day view!" MonthClick\="ALERT=Month view!" SelectedView\="Week"/>

  
Пример CollectionLite Тестирование "CalendarData" с названиями полей по умолчанию:  
RESULT = (\[  
{"title": "Период один", "start": "15.06.2011", "end": "23.06.2011"},  
{"title": "Период два", "start": "19.06.2011", "end": "20.06.2011"},  
{"title": "Период три", "start": "30/05/2011", "end": "02/06/2011", "format": "d/m/Y"}  
\]);

Параметры:

**Атрибут**

**Тип**

**Описание**

Width

integer

Ширина. В пикселях.

Source

string

Код документа выборки в WT. Если написать просто код выборки, то она будет напрямую запрошена с сервера. Если написать код выборки в фигурных скобках {}, то выборка будет проводиться через объект Collection (который в этом случае должен существовать). Это нужно, если требуется на каждый запрос к выборке передать еще какие-то данные, которые в этом самом объекте Collection и описываются. В выборку всегда отдаются три параметра: start (начало выбранного периода), end (соответственно конец) и viewmode - выбранный режим (из Modes)

DataTitle

string

Поле из результатов выборки, из которого брать название события. \[title\]

DataStart

string

Дата начала периода. \[start\]

DataEnd

string

Дата конца периода. \[end\]

DataFormat

string

Формат расшифровки даты начала и даты завершения. \[format\]. По умолчанию d.m.Y

DataColor

string

Цвет (#RRGGBB). \[color\]

DataCategory

string

Категория (для категоризованного вида) \[category\]

DataDesc

string

Комментарий

Modes

string

Список доступных режимов через запятую (,). По умолчанию открыты все. \[day, week, month, monthcategory,category\]

SelectedView

string

Выбранный по умолчанию режим. \[day, week, month, monthcategory,category\]

Hidden

bool

Скрыт элемент или показан. По умолчанию показан.

CategoryTitle

string

Заголовок столбца с категориями (для mode=category)

EventTitle

string

Заголовок столбца с названиями (для mode=category)

AutoReload

bool

Перезапрашивать данные из выборки после каждого действия с параметрами (влево/вправо, смена даты, смена представления и т.д.) \[false\]

CategoryWidth

integer

Ширина колонок с категориями (для mode=category)\[150\]

RepeatHeader

integer

Повторение заголовка в категоризованном виде, по умолчанию 0 (не повторять)

Name

string

Идентификатор

DataClass

string

Поле из результатов выборки, из которого брать CSS-класс. \[class\]

События:

**Событие**

**Описание**

DayClick

Выполнение действия при выборе отображения "День".

WeekClick

Выполнение действия при выборе отображения "Неделя".

MonthClick

Выполнение действия при выборе отображения "Месяц".

MonthCategoryClick

Выполнение действия при выборе отображения "Месяц по категориям".

EventClick

Выполнение действия при нажатии на событие. В фигурных скобках можно использовать поля из результатов выборки, например {name}

CategoryClick

Выполнение действия при выборе отображения "Категория".
