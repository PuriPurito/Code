## Param - Параметр вызываемого удаленного действия Action

Элемент разметки  
Название:    Param  
Краткое описание:    Параметр вызываемого удаленного действия Action  
Тип:    Управляющий элемент  
Содержимое:      
Подробное описание:      
Параметр вызываемого удаленного действия, выборки или шаблона. Может содержаться внутри объектов ActionLite Тестирование, CollectionLite Тестирование, PanelLite Тестирование с источником, TileViewDocument Link Icon, DialogLite Тестирование и т.д.  
Примеры использования:    

<Action Name="CrashKillNDestroy" Action="CrashKillNDestroy">  
  <Param Name="sTargetName" Value="{Edit1}"/>  
  <Param Name="oWholeFormData" Value="{CONTEXT}"/>  
  <Param Name="iTargetRank" Value="10"/>  
</Action>

Параметры:

**Атрибут**

**Тип**

**Описание**

Name

string

Имя переменной-параметра. Должно совпадать с именем переменной у удаленного действия в базе WT

Value

string

Значение параметра. Если указано в фигурных скобках {}, значение будет взято из элемента, чей идентификатор указан внутри фигурных скобок. Также зарезервированным словом является {CONTEXT}, которое передаёт в параметр все данные из формы (см. пример)
