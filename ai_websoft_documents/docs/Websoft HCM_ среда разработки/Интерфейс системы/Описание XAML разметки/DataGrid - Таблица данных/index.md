## DataGrid - Таблица данных

Элемент разметки  
Название:    DataGrid  
Краткое описание:    Таблица данных  
Тип:    Пользовательский элемент  
Содержимое:    Описание столбцов таблицы DataGridColumn  
Подробное описание:      

Таблица данных. Использует в качестве данных подгрузку из удаленных выборокLite Тестирование  
Содержит описание столбцов таблицы DataGridColumnLite Тестирование  
Примеры использования:    

Пример 1.

<DataGrid Name\="Grid1" Title\="My first grid" Source\="SelectMe" Height\="200" PageSize\="5">  
  <DataGridColumn Title\="ID" Value\="id" Width\="200" Type\="Label" Hidden\="true"/>  
  <DataGridColumn Title\="Название" Value\="name" Width\="50%" Type\="string" 

  ColorSource\="#FF0000"/>  
  <DataGridColumn Title\="Дата создания" Value\="modification\_date" Width\="100" Type\="date" 

Editable\="1"/>  
</DataGrid\>

Выборка SelectMe:

Пример 2.

  
<Collection Name\=**"StaticOne"**\>  
<Data>  
<Row>  
<Cell Id=**"val"** Value=**"Websoft rulez"**/>  
<Cell Id=**"linkfield"** Value=**"websoft.ru"**/>  
<Cell Id=**"datefield"** Value=**"01.01.2000"**/>  
</Row>  
<Row>  
<Cell Id=**"val"** Value=**"Datex decides"**/>  
<Cell Id=**"linkfield"** Value=**"datex.ru"**/>  
<Cell Id=**"datefield"** Value=**"02.02.2010"**/>  
</Row>  
</Data>  
</Collection>  
<DataGrid Name=**"Grid2Static"** Title=**"My rigid grid"** Source=**"{StaticOne}"** Height=**"200"** ShowHeader=**"true"**Selection=**"single"**\>  
<DataGridColumn Title=**"Link"** Value=**"linkfield"** Width=**"100%"** Type=**"string"**/>  
<DataGridColumn Title=**"Дата какая-то"** Value=**"datefield"** Width=**"100"** Type=**"date"** Editable=**"1"**/>  
</DataGrid>  
  
 

Параметры:

**Атрибут**

**Тип**

**Описание**

Name

string

Идентификатор

Title

string

Заголовок таблицы. Опционально.

Source

string

Код документа выборки в WT. Если написать просто код выборки, то она

будет напрямую запрошена с сервера. Если написать код выборки в фигурных

скобках {}, то выборка будет проводиться через объект Collection (который

в этом случае должен существовать). Это нужно, если требуется на каждый

запрос к выборке передать еще какие-то данные, которые в этом самом

объекте Collection и описываются.

Height

integer

Фиксированная высота таблицы. Опционально

PageSize

integer

Размер страницы. Если используется постраничное отображение.

Игнорируется при статичных выборках.

Selection

string

Опционально: способ выбора строк в таблице single - выбирается одна

строка multiple - выбираются несколько строк. none (по умолчанию) - строки

не выбираются. В случае отправки данных, если строки не выбираются,

то отправляются все строки текущей страницы таблицы. Если выбираются -

отправляются только выбранные.

Categorized

string

Если не пустой, включает категоризацию. Содержит пару полей: \[идентификатор\]:

\[идентификатор родителя\]. Разделены двоеточием. Пример:

Categorized="id:parent\_object\_id" Если вначале указать восклицательный знак(!),

то это будет сообщением компоненту, что данные отсортированы верно

(родитель и после него дети: "родитель1,дитё11,дитё12,...,дитё1K,родитель2,дитё21,дитё22,...,дитё2L,

родительN,дитёN1,дитёN2,...,дитёNM") и сортировать на клиенте данные не нужно Пример: Categorized="!id:parent\_object\_id"

ShowHeader

bool

Показывать ли заголовки столбцов. По умолчанию true

Class

string

Имя класса из таблицы стилей если нужно

Width

integer

Ширина. В пикселях.

Hidden

bool

Скрыт элемент или показан. По умолчанию показан.

X-Lite

bool

Включает/выключает облегчённую версию таблицы (какая таблица используется по умолчанию указывается в настройках плеера)

Expanded

bool

Для категоризованных таблиц. По умолчанию раскрывать все категории или схлопывать. По умолчанию false

AutoSelect

string

В панели пейджинга (пока) появляется кнопка "Выделить всё". Есть три режима: all - выделить всё parents - в категоризованных таблицах выбрать все категории children - в категоризованных таблицах выбрать всех детей под всеми категориями

MaxHeight

integer

Максимальная высота таблицы в пикселях (null)

События:

**Событие**

**Описание**

EmptyAction

Выполнение действия при отсутствии данных. Срабатывает только на удаленных выборках после каждой загрузки если было возвращено 0 записей.
