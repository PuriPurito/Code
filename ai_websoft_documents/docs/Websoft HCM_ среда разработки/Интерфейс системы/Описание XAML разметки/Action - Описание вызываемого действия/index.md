## Action - Описание вызываемого действия

Элемент разметки

Название:    **Action**  
Краткое описание:    **Описание вызываемого действия**  
Тип:    Управляющий элемент  
Содержимое:    Объекты

**Подробное описание:**      
Описание удаленного действия. Это действие говорит плееру, что в WT есть такое действие и все параметры в этом действии.   
Может находиться в любом месте формы, но рекомендуем описывать действия в самом начале элемента SPXMLScreen. 

Если указаны дальнейшие действия на события Success/Failure, то там будут видны свойства из объекта RESULT (см. пример)  
Если в коде действия ошибка, Success/Failure вызваны не будут вообще.  
Примеры использования:    

<Action Name\="CrashKillNDestroy" Source\="CrashKillNDestroy" Success\="ALERT={messageText};SET=Edit1,data"Success\="ALERT=Bore level exceeded: {boreLevel}">  
  <Param Name\="sTargetName" Value\="{Edit1}"/>  
  <Param Name\="iTargetRank" Value\="10"/>  
  <Param Name\="sContext" Value\="{CONTEXT}"/>  
</Action\>

  
Параметры:    

**Атрибут**

**Тип**

**Описание**

Name

string

Идентификатор для вызова из действий элемента. В общем просто ID действия.

Source

string

Код действия в базе WT. Если не указан, или указано значение NULL, то никакого обращения в WT и выполнения действия не будет. Однако если указано событие Initialize, оно будет выполнено. Может быть затежен {}

Delay

integer

Задержка перед запуском действия, в миллисекундах. \[0\]

События:

**Событие**

 

**Описание**

Success

Выполнение действия при успешном завершении операции (ERROR = 0)

Failure

Выполнение действия при ошибке выполнения (ERROR > 0)

Initialize

Выполнение действия до отправки основного запроса по Source.
