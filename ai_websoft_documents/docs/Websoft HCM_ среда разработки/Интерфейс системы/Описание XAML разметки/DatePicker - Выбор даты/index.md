## DatePicker - Выбор даты

Элемент разметки  
Название:    DatePicker  
Краткое описание:    Выбор даты  
Тип:    Пользовательский элемент  
Содержимое:    Значение по умолчанию

Подробное описание: 

Примеры использования:      
<DatePicker Name="MyDate1">01.01.2030</DatePicker>

**Атрибут**

**Тип**

**Описание**

Name

string

Идентификатор

Width

integer

Ширина. В пикселях.

Enabled

bool

Активен ли элемент

Class

string

Имя класса из таблицы стилей если нужно

Format

string

Формат расшифровки даты начала и даты завершения. По умолчанию d.m.Y

Fat

bool

Вместо поля с датой отображать календарь целиком. \[false\]
