## Link - Гиперссылка

Элемент разметки  
Название:    Link  
Краткое описание:    Гиперссылка  
Тип:    Пользовательский элемент  
Содержимое:    Текст гиперссылки  
Подробное описание:      
Show details for LinkLink

Обычная гиперссылка. Функционально ничем не отличается от кнопки ButtonLite.

  
Примеры использования:    

<Link HRef="http://ya.ru">Yandex</Link>

<Link Click="OPENWINDOW=http://ya.ru,500,300">Yandex</Link>

Параметры:

**Атрибут**

**Тип**

**Описание**

Width

integer

Ширина. В пикселях.

Class

string

Имя класса из таблицы стилей если нужно

NoWrap

bool

Не переносить текст, всё в одну строку(false)

Adapt

bool

Автоматически отключает параметр NoWrap при режиме плеера "mobile

HRef

string

Адрес ссылки. Будет проигнорирована при указанном событии Click

События:

**Событие**

**Описание**

Click

Выполнение действия при переключении значения.
