## HTMLTip - Всплывающая подсказка

Элемент разметки  
Название:    HTMLTip  
Краткое описание:    Всплывающая подсказка  
Тип:    Пользовательский элемент  
Содержимое:      
Подробное описание:      
Всплывающая подсказка, содержащая текст в формате HTML. Помещается в тело простых элементов.

Элементы, поддерживающие подсказку: LabelLite Тестирование, EditLite Тестирование, DatePickerLite Тестирование, CheckBoxLite Тестирование, LinkLite Тестирование, ButtonLite Тестирование, RadioButtonLite Тестирование, ComboBoxLite Тестирование, ImageLite Тестирование, EditBoxLite Тестирование  
Примеры использования:    

  
<Edit Name="EditX">  
Следуй за белым кроликом  
<HTMLTip>  
<!\[CDATA\[  
<b>Здесь люди пишут всякое</b>  
<br/>  
<img src="pics/collaborator.png"/>  
\]\]>  
</HTMLTip>  
</Edit>

Параметры:

**Атрибут**

**Тип**

**Описание**

Class

string

Имя класса из таблицы стилей если нужно

ShowDelay

integer

Задержка показа подсказки при наведении на элемент, в миллисекундах. \[500\]
