## RadioButton - Селектор

Элемент разметки  
Название:    RadioButton  
Краткое описание:    Селектор  
Тип:    Пользовательский элемент  
Содержимое:    Заголовок радиобаттона (т.е. текст рядом)  
Подробное описание:      
Радио баттон  
Примеры использования:      
<RadioButton Name="selector1" Value="0">Zero</RadioButton>  
<RadioButton Name="selector1" Value="1">Un</RadioButton>

Параметры:

**Атрибут**

**Тип**

**Описание**

Name

string

Идентификатор. По нему группируются элементы.

Value

string

Значение селектора

Class

string

Имя класса из таблицы стилей если нужно

Checked

bool

Выбран элемент или нет

События:

**Событие**

**Описание**

Change

Выполнение действия при переключении значения.
