## Написание XAML

Элемент разметки  
Название:    Написание XAML  
Краткое описание:    WT XAML для самых маленьких  
Тип:    Справка  
Содержимое:      
Подробное описание:      
Как пользоваться настраиваемыми шаблонами в WT думаю описывать не надо.

В этих самых шаблонах одна особенность: выставить тип "XAML" и вперед.  
Код может использовать Boris ASP вставки, но на выходе должен получиться чистый XAML с верхним элементом SPXMLScreenLite Тестирование

В коде всегда видны кое-какие глобальные переменные, которые можно попользовать:  
PARAMETERS - объект со свойствами-параметрами. Всё что было передано в качестве параметров будет именно там (например при открытии диалога).  
CONTEXT - объект, содержащий содержимое... Да. Содержащий содержимое элементов формы. с портала, если передали конечно. Иначе просто голый объект. Другими словами это что-то вроде POST-данных с XAML формы.  
ISDIALOG - признак того, что XAML открывается как модальное окно \[true,false\].

PLAYER\_ID - идентификатор текущего проигрывателя.  
PAGEURL - адресная строка браузера.

TopElem, он же Ps - открытый документ, если вдруг кто удосужился передать параметр SPXMLID c ID документа. Иначе просто пустой документ <dummy/>, см. сюдаLite Тестирование

Заглавным элементом результирующего XAML должен (ДОЛЖЕН!) быть элемент SPXMLScreenLite Тестирование. Всё что в него не попало, то, как говорится, пропало.  
Далее внутри уже все остальные элементики.

Для вставки другого XAML шаблона внутри существующего используется функция: tools\_web.place\_xaml(XAML\_CODE), где XAML\_CODE - код шаблона в базе WT:  
<Panel>  
<%=tools\_web.place\_xaml("xaml\_my\_courses")%>  
</Panel>

SPXMLScreenLite Тестирование вставленного шаблона будет равносилен StackPanelLite Тестирование
