## StackPanel - Контейнер

Элемент разметки  
Название:    StackPanel  
Краткое описание:    Контейнер  
Тип:    Контейнер  
Содержимое:      
Подробное описание:      
Контейнер.

NB: Горизонтальная ориентация будет стараться ужать содержимое до минимальной ширины. Если у дочернего элемента ширина не указана/указана в процентах, контейнер сожмет её максимально узко  
Примеры использования:      
<StackPanel>  
...  
</StackPanel>

  
Параметры:

**Атрибут**

**Тип**

**Описание**

Width

integer

Ширина, в пикселях

Height

integer

Высота, в пикселях

Orientation

string

Располагать элементы вертикально, горизонтально или горизонтально с переносом. Принимаемые значения: \[Horizontal,Vertical, Wrap\]

Class

string

Имя класса из таблицы стилей если нужно

Align

string

Выравнивание дочерних элементов \[left,center,right\]

Hidden

bool

Скрыт элемент или показан. По умолчанию показан.

Name

string

Идентификатор

UsePadding

bool

Использовать отступ. По умолчанию true

Adapt

bool

Автоматически переключает параметр Orientation в значение "Vertical" при режиме плеера "mobile"
