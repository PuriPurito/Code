## SPXMLScreen - Корневой элемент формы

Элемент разметки  
Название:    SPXMLScreen  
Краткое описание:    Корневой элемент формы  
Тип:    Контейнер  
Содержимое:    Содержит в себе ВСЁ!  
Подробное описание:      
Корневой элемент формы, является начальным контейнером. Без него никуда!

NB: если объявлен внутри другого SPXMLScreen'а, то превращается в StackPanelLite Тестирование с параметрами по умолчанию равными своим наследуемыми параметрами (те что ниже). Т.е. выставить SPXMLScreen параметр Orientation от StackPanel не выйдет.

Примеры использования:      
<SPXMLScreen Title="<%=Ps.name%>" Width="500">  
...  
</SPXMLScreen>

Параметры:

**Атрибут**

**Тип**

**Описание**

Width

int

Ширина формы. Значение задается в пикселях

Height

int

Высота формы. Значение задается в пикселях

Name

string

Идентификатор

Class

string

Имя класса из таблицы стилей если нужно

Параметры:

**Событие**

**Описание**

Ready

Выполнение действия после завершения загрузки всего содержимого
