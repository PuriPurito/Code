## Работа с программным кодом на языке C# в редакторе Websoft OmniCode for HCM (с 2023.2)

Редактор Websoft OmniCode for HCM позволяет создавать на языке C# различные типы объектов, например, выборки, агенты сервера, удаленные действия и т.д. Помимо редактирования и выполнения программного кода в редакторе можно проводить его отладку. Отладка кода C# – это процесс добавления точек останова и анализа выполнения кода в конкретные моменты времени.

При работе с программным кодом на языке C# доступны функциональности:

*   подключение зависимостей;
*   объявление пространства имен:
    *   для агентов – Agents;
    *   для выборок – Collections;
    *   для удалённых действий – RemoteActions;
    *   для показателей – Statistics;
*   объявление основного класса:
    *   для агентов – ServerAgent;
    *   для выборок – RemoteCollection;
    *   для удалённых действий – RemoteAction;
    *   для показателей – StatisticRec;
*   написание метода, вызываемого при запуске агента.

В программный код объекта на языке C# должен быть вставлен метод **Run**, указывающий на точку входа проекта, которая характеризует выполняемый объект. При необходимости точку входа можно изменить, объявив над нужным методом атрибут **EntryPoint**. Точка входа определяется следующим образом:

`[EntryPoint("Название_пространства_имен_(namespace).Название_класса.Run")]`

`[EntryPoint("Agents.ServerAgent.Run")]` (для агентов)  
`[EntryPoint("Collections.RemoteCollection.Run")]` (для выборок)  
`[EntryPoint("RemoteActions.RemoteAction.Run")]` (для удаленных действий)  
`[EntryPoint("Statistics.StatisticRec.Run")]` (для показателей)

При необходимости из объекта C# может быть создан объект JavaScript (JsObject) с помощью команды:

`var collObject = datexGlobal.CreateJsObject(false);`
