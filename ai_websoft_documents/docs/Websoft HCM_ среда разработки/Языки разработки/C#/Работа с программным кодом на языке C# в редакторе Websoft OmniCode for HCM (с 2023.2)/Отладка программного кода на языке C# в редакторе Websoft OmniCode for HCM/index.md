## Отладка программного кода на языке C# в редакторе Websoft OmniCode for HCM

Для отладки кода на языке C# необходимо произвести все настройки в соответствии с инструкцией по установке редактора Websoft OmniCode for HCM.

Рассмотрим отладку программного кода на примере выборки **my\_test\_collection**, которую мы создали в предыдущей статье. Представленная выборка возвращает id, ФИО и e-mail каждого сотрудника. Для отладки кода выборки выполним действия:

1.  В разделе **WEBSOFT HCM LINK SERVERS** откроем файл программного кода **my\_test\_collection.cs**, отладку которого нужно выполнить.
2.  В контекстном меню вкладки файла **my\_test\_collection.cs** выберем **AddTo C# DevKit Solution**. В результате появится возможность полноценной отладки проекта.
    
3.  В области редактирования кода станут доступны действия:
    
    •
    
    появится дополнительная информация о классах, методах и т.д., в которые можно «проваливаться» с помощью зажатой клавиши **Ctrl**:
    
    •
    
    появится технология автодополнения Microsoft IntelliSense, которая дописывает название функции при вводе начальных букв:
    
4.  Для компиляции кода в контекстном меню вкладки файла **my\_test\_collection.cs** выберем **Показать в панели проводника** (**Reveal in Explorer View** в английской версии), после чего выбранный файл появится в разделе **ОБОЗРЕВАТЕЛЬ РЕШЕНИЙ** (**SOLUTION EXPLORER** в английской версии) вкладки **ПРОВОДНИК** (**EXPLORER** в английской версии).
    
5.  В контекстном меню папки **my\_test\_collection** выберем **Собрать** (**Build** в английской версии). После чего в терминале VS Code появится информация о сборке.
    
6.  Откроем файл **launch.json**, в котором содержится две конфигурации:
    
    •
    
    A – запуск локального сервера **xhttp\_64.exe** и соединение с ним;
    
    •
    
    B – соединение с существующим локальным сервером, который работает в текущий момент.
    
7.  Настроим среду отладки. Для этого создадим переменную среды **WebTutorServerDir**, в которой будет указан путь к локальному серверу **xhttp\_64.exe** (если она не была создана на этапе установки редактора Websoft OmniCode for HCM).
8.  Во вкладке **ЗАПУСК И ОТЛАДКА** (**RUN AND DEBUG** в английской версии) в раскрывающемся списке выберем _XHTTP Attach_.
    
9.  Перейдем в файл **my\_test\_collection.cs** и нажмем **F5**, после чего произойдет соединение с сервером.
10.  Поставим точку останова в области редактирования кода в строке 16 слева от нумерации и запустим выполнение кода (**Alt+F5**). После запуска мы попадем в точку останова, а в разделе **ПЕРЕМЕННЫЕ** (**VARIABLES** в английской версии) отобразятся значения переменных, параметров, объектов и т.д. в текущий момент.
     
11.  В разделе **КОНТРОЛЬНОЕ ЗНАЧЕНИЕ** (**WATCH** в английской версии) можно добавить любой параметр (например, «xqi») и посмотреть его значение в текущий момент отладки.
     
12.  В разделе **ТОЧКИ ОСТАНОВА** (**BREAKPOINTS** в английской версии) перечислены все точки останова отладочного файла.
     
13.  В процессе отладки можно вносить изменения в программный код файла. После выполнения синхронизации эти изменения передаются на авторизованный сервер.
