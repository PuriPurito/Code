## Примеры работы с программным кодом на языке C# в редакторе Websoft OmniCode for HCM

Рассмотрим два примера создания объектов в редакторе Websoft OmniCode for HCM на языке C#: простого агента сервера и выборки. Запустим выполнение программного кода объекта и посмотрим результаты в консоли **HCM CONSOLE**.

Аналогичные примеры, написанные на языке Server-Side Java Script, приведены здесь.

## Создание и запуск агента сервера

Создадим простейший агент, который будет здороваться с миром и выводить на экран текущую дату и время. Для этого в редакторе Websoft OmniCode for HCM на языке C# выполним действия:

1.  В разделе **WEBSOFT HCM LINK SERVERS** наведем курсор на папку **Agents** и нажмем появившуюся кнопку **Create** ().
2.  Во всплывающем окне «Create entry» введем название агента, например, «my\_test\_agent», и нажмем клавишу **Enter**.
    
3.  Выберем язык программирования C# (cv).
    
4.  В окне «Create entry» подтвердим название соответствующего файла программного кода и путь к нему.
    
5.  После создания агента сервера в папке **Agents** появится папка **my\_test\_agent** с автоматически созданными файлами. В области редактирования кода откроется файл программного кода **my\_test\_agent.cs**, где можно вносить изменения.
    
    Обратите внимание, в редактор Websoft OmniCode for HCM по умолчанию встроены шаблоны программного кода создаваемых объектов в соответствии с типом объекта и языком программирования. В данном случае, шаблон соответствует простейшему агенту сервера, написанному на языке C#.
    
6.  Сохраним файл (**Ctrl+S**), после чего произойдет синхронизация с сервером, так как включена автоматическая синхронизация с помощью кнопки **Enable Auto Sync** ().
7.  Внесем изменения в блок **try** и снова сохраним файл (**Ctrl+S**).
8.  Запустим выполнение программного кода с помощью кнопки **Run** () или сочетания клавиш **Alt+F5**.
9.  Результат компиляции и выполнения кода отобразится в консоли **HCM CONSOLE**.
    

## Создание и запуск выборки

Создадим выборку, которая будет возвращать id, ФИО и e-mail каждого сотрудника. Для этого в редакторе Websoft OmniCode for HCM на языке C# выполним действия:

1.  В разделе **WEBSOFT HCM LINK SERVERS** наведем курсор на папку **RemoteCollections** и нажмем появившуюся кнопку **Create** ().
2.  Во всплывающем окне «Create entry» введем название выборки, например, «my\_test\_collection», и нажмем клавишу **Enter**.
3.  Выберем язык программирования C# (cv).
4.  В окне «Create entry» подтвердим название соответствующего файла программного кода и путь к нему.
5.  После создания выборки в папке **RemoteCollections** появится папка **my\_test\_collection** с автоматически созданными файлами. В области редактирования кода откроется файл программного кода **my\_test\_collection.cs**, где можно вносить изменения.
    
    Обратите внимание, в программном коде выборки используется шаблон, написанный на языке C#.
    
6.  Сохраним файл (**Ctrl+S**), после чего произойдет синхронизация с сервером, так как включена автоматическая синхронизация с помощью кнопки **Enable Auto Sync** ().
7.  Внесем изменения в блок **try** и снова сохраним файл (**Ctrl+S**).
8.  Запустим выполнение программного кода с помощью кнопки **Run** () или сочетания клавиш **Alt+F5**.
    
9.  Результат компиляции и выполнения кода отобразится в консоли **HCM CONSOLE**.
