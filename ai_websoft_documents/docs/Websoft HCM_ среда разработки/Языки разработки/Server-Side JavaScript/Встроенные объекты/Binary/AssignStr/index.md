## AssignStr

Метод объекта Binary.  
Копирует в текущий бинарный объект данные из заданной строки. Данные, хранившиеся в текущем бинарном объекте, удаляются без предупреждения.

_Синтаксис:_  
      **Binary.AssignStr (<str>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Строка, которую следует скопировать в текущий бинарный объект.

_Возвращаемое значение:_  
      Копируются данные из заданной строки. Возвращаемое значение отсутствует.

_Пример:_  
      `_bBinary = new Binary ();         bBinary.AssignStr ( 'abc' ); // копирует строковые данные в бинарный объект         bBinary.AssignStr ( 'abc' ); // еще раз копирует строковые данные в бинарный объект         iSize = bBinary.Size; // определение размера бинарного объекта в байтах         alert (iSize); // возвращает размер бинарного объекта в байтах, равный 3_`
