## AssignBinary

Метод объекта Binary.  
Копирует данные из бинарного объекта, указанного в качестве аргумента, в текущий бинарный объект. Данные, хранившиеся в текущем бинарном объекте, удаляются без предупреждения.

_Синтаксис:_  
      **Binary.AssignBinary (<obj>)**

_Аргументы:_  
      _<obj> (обязательный)_  
      Тип: **Бинарный объект**. Объект, данные из которого следует скопировать в текущий бинарный объект.

_Возвращаемое значение:_  
      Копируются данные из бинарного объекта. Возвращаемое значение отсутствует.

_Пример:_  
      `_bBinary = new Binary ();         bBinary.AppendStr ( 'abc' ); // сформирован бинарный объект bBinary размером 3 байта         bBinary1 = new Binary ();         bBinary1.AssignBinary ( bBinary ); // копирует данные из бинарного объекта bBinary в текущий бинарный объект bBinary1         bBinary1.AssignBinary ( bBinary ); // еще раз копирует данные из бинарного объекта bBinary в текущий бинарный объект bBinary1         iSize = bBinary1.Size; // определение размера бинарного объекта bBinary1 в байтах         alert (iSize); // возвращает размер бинарного объекта bBinary1 в байтах, равный 3_`
