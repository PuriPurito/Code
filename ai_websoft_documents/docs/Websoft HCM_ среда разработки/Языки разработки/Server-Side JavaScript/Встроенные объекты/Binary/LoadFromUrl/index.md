## LoadFromUrl

Метод объекта Binary.  
Загружает в текущий бинарный объект данные из файла с указанным url.  
Если данный файл отсутствует в файловой системе, выводится сообщение об ошибке «Файл не найден» с прерыванием выполняемого кода.

_Синтаксис:_  
      **Binary.LoadFromUrl (<url>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Url файла, из которого загружаются данные.

_Возвращаемое значение:_  
      Загружаются данные из файла. Возвращаемое значение отсутствует.

_Пример:_  
      `_bBinary = new Binary ();         bBinary.LoadFromUrl ( 'file:///D:/WebTutor/wtl.xfp' ); // загружает содержимое файла в бинарный объект (указанный файл должен существовать в файловой системе)         iSize = bBinary.Size; // определение размера бинарного объекта в байтах         alert (iSize); // возвращает размер бинарного объекта в байтах_`
