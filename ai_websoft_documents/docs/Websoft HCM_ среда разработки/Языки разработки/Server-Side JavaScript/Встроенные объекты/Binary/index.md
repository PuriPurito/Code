## Binary

Предназначен для работы с бинарными данными, в том числе с бинарными данными большого размера.  
Объект активно использовался в прошлом, когда строки не могли содержать в себе бинарные данные, либо для особых случаев (например, для многократной записи информации в большую строку маленькими фрагментами (это необходимо, например, при генерации HTML-файлов большого размера)). Поскольку добавление к строке большого количества маленьких фрагментов в цикле существенно медленнее, чем запись данных в **объект Binary**, то для подобных случаев использовался именно **объект Binary**, который потом преобразовывался в строку. 

            _Атрибут объекта:_  
      Size  
      WriteStream  
  
            _Метод объекта:_  
      AppendBinary  
      AppendStr  
      AssignBinary  
      AssignStr  
      GetStr  
      LoadFromUrl  
      PrepareWriteSpace  
      PutToUrl
