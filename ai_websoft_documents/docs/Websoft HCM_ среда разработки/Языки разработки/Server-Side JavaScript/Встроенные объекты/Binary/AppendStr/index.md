## AppendStr

Метод объекта Binary.  
Добавляет в текущий бинарный объект данные из заданной строки.

_Синтаксис:_  
      **Binary.AppendStr (<str>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Строка, которую следует добавить в текущий бинарный объект.

_Возвращаемое значение:_  
      Добавляются данные из заданной строки. Возвращаемое значение отсутствует.

_Пример:_  
      `_bBinary = new Binary ();         bBinary.AppendStr ( 'abc' ); // добавление строковых данных в бинарный объект         iSize = bBinary.Size; // определение размера бинарного объекта в байтах         alert (iSize); // возвращает размер бинарного объекта в байтах, равный 3_`
