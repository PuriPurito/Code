## AppendBinary

Метод объекта Binary.  
Добавляет данные из бинарного объекта, указанного в качестве аргумента, в текущий бинарный объект.

_Синтаксис:_  
      **Binary.AppendBinary (<obj>)**

_Аргументы:_  
      _<obj> (обязательный)_  
      Тип: **Бинарный объект**. Объект, данные из которого следует добавить в текущий бинарный объект.

_Возвращаемое значение:_  
      Добавляются данные из бинарного объекта. Возвращаемое значение отсутствует.

_Пример:_  
      `_bBinary = new Binary ();         bBinary.AppendStr ( 'abc' ); // сформирован бинарный объект bBinary размером 3 байта         bBinary1 = new Binary ();         bBinary1.AppendBinary ( bBinary ); // добавляет содержимое бинарного объекта bBinary в текущий бинарный объект bBinary1         bBinary1.AppendBinary ( bBinary ); // еще раз добавляет содержимое бинарного объекта bBinary в текущий бинарный объект bBinary1         iSize = bBinary1.Size; // определение размера бинарного объекта bBinary1 в байтах         alert (iSize); // возвращает размер бинарного объекта bBinary1 в байтах, равный 6_`
