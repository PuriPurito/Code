## PutToUrl

Метод объекта Binary.  
Сохраняет данные из текущего бинарного объекта в файл с заданным url.  
Если указанный файл уже существует в файловой системе, производится перезапись файла без вывода предупреждения.

_Синтаксис:_  
      **Binary.PutToUrl (<url>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Url файла, в который сохраняются данные.

_Возвращаемое значение:_  
      Данные сохраняются в файл. Возвращаемое значение отсутствует.

_Пример:_  
      `_bBinary = new Binary ();         bBinary.LoadFromUrl ( 'file:///D:/WebTutor/wtl.xfp' ); // загружает содержимое файла в бинарный объект (указанный файл должен существовать в файловой системе)         iSize = bBinary.Size; // определение размера бинарного объекта в байтах         alert (iSize); // возвращает размер бинарного объекта в байтах         bBinary.PutToUrl ( 'file:///D:/WebTutor/wtl1.xfp' ); // сохраняет данные из бинарного объекта в указанный файл_`
