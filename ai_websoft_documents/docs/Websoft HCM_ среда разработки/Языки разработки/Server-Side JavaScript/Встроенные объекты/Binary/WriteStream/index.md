## WriteStream

Атрибут объекта Binary.  
Поток, в который можно писать данные любыми функциями, которые работают с потоками. Данные из указанного потока попадают в объект. В настоящее время этот метод является устаревшим, так как для работы с потоками был создан специальный объект _WriteBuffStream_.

_Синтаксис:_  
      **Binary.WriteStream**

_Возвращаемое значение:_  
      Тип: **Объект Stream**. Строковое выражение пути к директории (папке) для хранения данных пользователя.

_Пример:_  
      `_bBinary = new Binary ();         doc.SaveToStream ( bBinary.WriteStream );_`
