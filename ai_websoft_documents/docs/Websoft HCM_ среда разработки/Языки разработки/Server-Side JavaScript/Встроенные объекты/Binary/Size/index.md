## Size

Атрибут объекта Binary.  
Размер содержимого бинарного объекта в байтах.

_Синтаксис:_  
      **Binary.Size**

_Возвращаемое значение:_  
      Тип: **Целое число**. Размер содержимого бинарного объекта в байтах.

_Пример:_  
      `_bBinary = new Binary ();         bBinary.AppendStr ( 'abc' ); // добавление строковых данных в бинарный объект         iSize = bBinary.Size; // определение размера бинарного объекта в байтах         alert (iSize); // возвращает размер бинарного объекта в байтах, равный 3_`
