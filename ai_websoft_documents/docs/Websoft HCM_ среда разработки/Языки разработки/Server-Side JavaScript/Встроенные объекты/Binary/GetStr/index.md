## GetStr

Метод объекта Binary.  
Преобразует данные из бинарного объекта в формат строки, содержащей массив байтов.

_Синтаксис:_  
      **Binary.GetStr ()**

_Аргументы:_  
      Метод вызывается без аргументов.

_Возвращаемое значение:_  
      Тип: **Строка**. Строковое выражение данных из бинарного объекта.

_Пример:_  
      `_bBinary = new Binary ();         bBinary.AppendStr ( 'abc' ); // добавление строковых данных в бинарный объект         sData = bBinary.GetStr(); // преобразует бинарные данные в формат строки         alert (sData); // возвращает бинарные данные в виде строки_`
