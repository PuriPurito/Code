## PrepareWriteSpace

Метод объекта Binary.  
Сообщает текущему потоковому объекту предполагаемый размер фрагмента данных, который будет в него впоследствии записан.  
Данный метод позволяет оптимизировать скорость записи в поток за счет предварительного резервирования памяти.  
В частности, этот метод рекомендуется использовать в случае записи данных небольшими фрагментами в объект WriteBuffStream.

_Синтаксис:_  
      **Binary.PrepareWriteSpace (<size>)**

_Аргументы:_  
      _<size> (обязательный)_  
      Тип: **Целое число**. Предполагаемый размер фрагмента данных в байтах для записи в потоковый объект.

_Возвращаемое значение:_  
      Указывается размер фрагмента данных. Возвращаемое значение отсутствует.

_Пример:_  
      `_bBinary.PrepareWriteSpace( 1 * 1024 );         bBinary.PrepareWriteSpace ( StrLen ( sHtmlParam ) );_`
