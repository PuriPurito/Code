## HttpResponse

**Объект HttpResponse** - это объект Http-ответа, который возвращает функция HttpRequest. Основной атрибут этого объекта - Body, все остальные атрибуты объекта **HttpResponse** используются в редких случаях.

_Синтаксис:_  
      **HttpResponse**

            _Атрибут объекта:_  
      BinaryBody  
      Body  
      ContentType  
      Header  
      RespCode  
      Url  
  
            _Метод объекта:_  
      SaveToFile
