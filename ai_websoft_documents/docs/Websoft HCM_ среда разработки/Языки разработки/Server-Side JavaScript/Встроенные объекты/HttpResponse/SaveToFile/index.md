## SaveToFile

Метод объекта HttpResponse.  
Сохраняет результат Http-запроса напрямую в файл, помогает экономить оперативную память.

_Синтаксис:_  
      **HttpResponse.SaveToFile (<url>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Url файла, в который сохраняется результат Http-запроса.

_Возвращаемое значение:_  
      Производит сохранение результата Http-запроса в файл. Возвращаемое значение отсутствует.

_Пример:_  
      `_resp = HttpRequest ( 'http://reg.datex-soft.com/' ); // получение объекта HttpResponse         resp.SaveToFile ( 'file:///D:/WebTutor/file1.txt' ); // сохранение результата Http-запроса в файл (в файловой системе должна существовать папка D:\\WebTutor)_`
