## RespCode

Атрибут объекта HttpResponse.  
Код ошибки, возвращаемый Http-запросом. Если Http-запрос выполняется без ошибки, возвращается _код 200_. Если произошла ошибка, то соответствующий код ошибки будет сохранен в этом атрибуте.  
Если произошла ошибка, сопровождающаяся исключением, код ошибки не возвращается. В этом случае имеет смысл использовать **атрибут RespCode**, если функция HttpRequest задана с параметром _Ignore-Error_.

_Синтаксис:_  
      **HttpResponse.RespCode**

_Возвращаемое значение:_  
      Тип: **Целое число**. Код ошибки, возвращаемый Http-запросом.

_Пример:_  
      `_resp = HttpRequest ( 'http://reg.datex-soft.com/' ); // получение объекта HttpResponse         alert (resp.RespCode); // возвращает код Http-ответа (или код ошибки)_`
