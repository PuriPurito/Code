## BinaryBody

Атрибут объекта HttpResponse.  
Тело Http-ответа, возвращаемое в виде объекта типа Binary, содержащего бинарные данные. Редко используется с тех пор, когда строковый формат стал поддерживать бинарные данные.

_Синтаксис:_  
      **HttpResponse.BinaryBody**

_Возвращаемое значение:_  
      Тип: **Объект Binary**. Тело Http-ответа, содержащее бинарные данные.

_Пример:_  
      `_resp = HttpRequest ( 'http://reg.datex-soft.com/' ); // получение объекта HttpResponse         bObj = resp.BinaryBody; // получение объекта Binary из HttpResponse         sData = bObj.GetStr(); // преобразование бинарных данных в формат строки         alert (sData); // возвращает тело Http-ответа, преобразованное из объекта Binary в формат строки_`
