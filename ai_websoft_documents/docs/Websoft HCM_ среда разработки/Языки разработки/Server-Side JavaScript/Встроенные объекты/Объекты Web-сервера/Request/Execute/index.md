## Execute

Метод объекта Request.  
Выполняет код указанного фрагмента Web-страницы с записью результата в текущий HTTP-ответ. Метод используется для включений фрагментов, общих для различных видов страниц.

_Синтаксис:_  
      **Request.Execute (<path>\[, <allowSubCancel>\])**

_Аргументы:_  
      _<path> (обязательный)_  
      Тип: **Строка**. Путь к исполняемому фрагменту. Если указан относительный путь (что, как правило, и делается), путь считается относительно родительской директории по отношению к текущей странице.  
      _<allowSubCancel> (необязательный)_  
      Тип: **Булево**. Параметр, характеризующий разрешение завершения выполнения кода. Если значение аргумента равно _true_, то в случае, если код фрагмента завершается исключением типа Cancel, метод все равно завершается успешно. Значение по умолчанию равно _false_. Аргумент используется для удобства завершения фрагментов кода при использовании функции Cancel, поскольку использовать оператор return непосредственно в коде фрагмента страницы невозможно.

_Возвращаемое значение:_  
      Выполняет код фрагмента Web-страницы и записывает результат в текущий HTTP-ответ. Возвращаемое значение отсутствует.

_Пример:_  
      `_<% Request.Execute ( "/social/const_soc.html" ); %>_`
