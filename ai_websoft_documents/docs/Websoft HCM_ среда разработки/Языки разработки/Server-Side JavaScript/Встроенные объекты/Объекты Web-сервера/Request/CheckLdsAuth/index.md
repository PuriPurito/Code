## CheckLdsAuth

Метод объекта Request.  
Вызывает проверку авторизации запроса по стандартному методу авторизации для рабочего места (через вызов OnCheckAuth).

_Синтаксис:_  
      **Request.CheckLdsAuth ()**

_Аргументы:_  
      Метод вызывается без аргументов.

_Возвращаемое значение:_  
      Производит проверку авторизации запроса. Возвращаемое значение отсутствует.

_Пример:_  
      `_<% Request.CheckLdsAuth(); %>_`
