## PermanentRedirect

Метод объекта Request.  
Вызывает отправку статуса HTTP _301 "Object Moved" ("Постоянное перенаправление")_ и производит перенаправление HTTP-запроса.  
Если заголовок уже был отправлен, метод возвращает ошибку.

_Синтаксис:_  
      **Request.PermanentRedirect (<redirectUrl>)**

_Аргументы:_  
      _<redirectUrl> (обязательный)_  
      Тип: **Строка**. Url, на который производится перенаправление.

_Возвращаемое значение:_  
      Производится отправка статуса HTTP _301_ и выполняется перенаправление. Возвращаемое значение отсутствует.

_Пример:_  
      `_<% Request.PermanentRedirect ( urlRedir ); %>_`
