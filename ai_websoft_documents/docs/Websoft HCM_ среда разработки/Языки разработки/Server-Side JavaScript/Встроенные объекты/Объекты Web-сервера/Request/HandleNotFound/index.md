## HandleNotFound

Метод объекта Request.  
Вызывает отправку статуса HTTP _404 "Not found" ("Объект не найден")_.  
Если заголовок уже был отправлен, метод возвращает ошибку.

_Синтаксис:_  
      **Request.HandleNotFound ()**

_Аргументы:_  
      Метод вызывается без аргументов.

_Возвращаемое значение:_  
      Производится отправка статуса HTTP _404_. Возвращаемое значение отсутствует.

_Пример:_  
      `_<% Request.HandleNotFound (); %>_`
