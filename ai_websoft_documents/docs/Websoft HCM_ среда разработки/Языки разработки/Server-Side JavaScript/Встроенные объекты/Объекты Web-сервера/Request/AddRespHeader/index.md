## AddRespHeader

Метод объекта Request.  
Добавляет или изменяет поле заголовка HTTP-ответа.  
Если заголовок уже был отправлен, метод возвращает ошибку.

_Синтаксис:_  
      **Request.AddRespHeader (<fieldName>, <fieldValue>\[, <replaceExisting>\])**

_Аргументы:_  
      _<fieldName> (обязательный)_  
      Тип: **Строка**. Имя поля.  
      _<fieldValue> (обязательный)_  
      Тип: **Строка**. Значение поля.  
      _<replaceExisting> (необязательный)_  
      Тип: **Булево**. Параметр замены существующего поля с именем , если оно существует. Значение параметра по умолчанию равно _true_.

_Возвращаемое значение:_  
      Добавляет или изменяет поле заголовка HTTP-ответа. Возвращаемое значение отсутствует.

_Пример:_  
      `_<% Request.AddRespHeader( 'X-Auth-Message', 'Превышено количество попыток ввода пароля.' ); %>_`
