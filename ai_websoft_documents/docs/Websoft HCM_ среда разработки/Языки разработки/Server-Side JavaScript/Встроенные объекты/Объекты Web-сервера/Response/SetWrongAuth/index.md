## SetWrongAuth

Метод объекта Response.  
Используется для проверки авторизации внутри Web-страницы. Вызывает отправку статуса _HTTP 401 "Authorization required"_. Более старый эквивалент метода SetWrongAuth объекта Request.  
Код Web-страницы обычно вызывает данный метод, если Request.AuthLogin возвращает пустую строку, либо указаны неверные авторизационные данные.  
Если заголовок уже был отправлен, метод возвращает ошибку.

_Синтаксис:_  
      **Response.SetWrongAuth (\[<options>\])**

_Аргументы:_  
      _<options> (необязательный)_  
      Тип: **Строка**. Перечень опций вида _'name1=value1;name2=value2;...'_.  
      _Допустимые значения:_  
      **basic=1, ntlm=1** - разрешенные виды авторизации.

_Возвращаемое значение:_  
      Производит проверку авторизации. Возвращаемое значение отсутствует.

_Пример:_  
      `_<% Response.SetWrongAuth( 'basic=0;ntlm=1;' ); %>         <% Response.SetWrongAuth(); %>_`
