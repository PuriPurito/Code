## Response

Объект **Response** доступен на сервере xHttp.exe при вызове кода веб-страницы. Обозначает ответ сервера на соответствующий HTTP-запрос к странице.  
Обычно данные объекты используются в html-файлах.  
В современных приложениях объект **Response** использовать не рекомендуется, поскольку он доступен только в ASP-коде страницы, но не доступен, например, в коде OnWebRequest. Вместо этого, рекомендуется использовать аналогичные методы объекта Request, которые позже были разработаны на основе объекта **Response**.

_Принципиальная структура идентификаторов HTTP-запросов:_

Подробнее см. стандарт RFC 3986.

            _Атрибут объекта:_  
      ContentType  
      OrigRequest  
      Stream  
      WriteMode  
  
            _Метод объекта:_  
      AddHeader  
      CheckModified  
      HandleStaticFile  
      Redirect  
      SetRespStatus  
      SetWrongAuth  
      Write  
      WriteBinary
