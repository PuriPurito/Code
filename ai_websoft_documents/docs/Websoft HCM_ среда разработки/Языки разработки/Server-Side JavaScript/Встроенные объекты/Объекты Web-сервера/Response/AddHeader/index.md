## AddHeader

Метод объекта Response.  
Добавляет или заменяет поле заголовка HTTP-ответа. Более старый эквивалент метода AddRespHeader объекта Request.  
Если заголовок уже был отправлен, метод возвращает ошибку.

_Синтаксис:_  
      **Response.AddHeader (<fieldName>, <fieldValue>\[, <replaceExisting>\])**

_Аргументы:_  
      _<fieldName> (обязательный)_  
      Тип: **Строка**. Имя поля.  
      _<fieldValue> (обязательный)_  
      Тип: **Строка**. Значение поля.  
      _<replaceExisting> (необязательный)_  
      Тип: **Булево**. Параметр замены существующего значения поля (_true_ – заменить значение существующего поля с таким же именем, если такое поле имеется, _false_ – не заменять). По умолчанию равен _true_.

_Возвращаемое значение:_  
      Добавляет или заменяет поле заголовка HTTP-ответа. Возвращаемое значение отсутствует.

_Пример:_  
      `_<% Response.AddHeader( "Content-Type", "application/vnd.ms-excel"); %>         <% Response.AddHeader( "Access-Control-Allow-Origin", "*"); %>_`
