## Catalog

Обозначает каталог в базе данных. Обычно доступен как глобальная переменная с именем каталога. Пример каталогов в E-Staff: candidates, vacancies, events.  
Может быть использован в качестве абстрактного массива (как правило для небольших каталогов):

for ( eventType in event\_types )  
{  
  
}
