## AskFileOpen

Метод объекта. Вызывает меню (диалоговое окно) открытия файла. Возвращает url выбранного (открытого) файла.

_Синтаксис:_  
      **Screen.AskFileOpen(<s1>, <sFile\_mask> )**

_Аргументы:_  
      **<s1>** — любое строковое выражение (можно использовать пустую строку), для веб-админки  данный аргумент игнорируется (строка).  
     **<sFile\_mask>** — маска описания (расширение) файла для поиска (строка). Данный аргумент может иметь следующий формат: "<комментарий>\\t<маска\_расширения\_файла>" (например, для поиска файла с расширением XLS можно использовать выражение "Excel\\t\*.xls"). Вместо "\\t" можно использовать выражение "&#09;". Допустимо выбирать несколько масок файлов для поиска (например: "Files&#09;\*.xls&#09;\*.xml"). В случае задания маски файла "\*.\*" или отсутствия маски ("") в диалоговом окне производится поиск по всем файлам.  
  
_Результат:_  
**Строка.** Url файла, выбранного в диалоговом окне.

  
Примерs:

sUrl = Screen.AskFileOpen( "", "\*.\*" ); // выбор любого файла  
sExcelFile = Screen.AskFileOpen("", "Excel\\t\*.xls" ); // выбор файла с расширением XLS  
sFileUrl1 = Screen.AskFileOpen(''", "Files&#09;\*.xls&#09;\*.xml" ); // выбор файлов XLS и XML  
sFileUrl2 = Screen.AskFileOpen( "", "" ); // выбор любого файла
