## MsgBox

Метод **MsgBox** выдает стандартный диалог Windows с сообщением на текущем экране.  
Действует при выполнении программного кода на клиенте (а не на сервере).

_Синтаксис:_  
      **Screen.MsgBox( <txt1\_info>, <txt2\_head>, <type>\[, <titles>\]);**

_Аргументы:_  
     _<txt1\_info> (обязательный)_  
     Тип: **Строка**. Текст сообщения. Для переноса текста на следующую строку используется комбинация символов '\\n'.  
     _<txt2\_head> (обязательный)_  
     Тип: **Строка**. Текст заголовка.  
      _<type> (обязательный)_  
     Тип: **Строка**. Тип диалогового окна (например, 'info', 'question').   
     _<titles> (необязательный)_  
     Тип: **Строка**. Наименования кнопок диалогового окна, перечисленные через запятую. В частности, для окна типа 'info' указывать данный аргумент не нужно.

_Возвращаемое значение:_  
      Тип: **Булево** или др. Вывод диалогового окна на экран. Результат выполнения функции.

_Пример:_  
`_// Тип диалогового окна 'question'_`  
`_Scr1 = Screen.MsgBox( 'Сообщение 1', 'Заголовок окна', 'question', 'yes,no' );_`  
_alert (Scr1); // выдает true или false_  
`_      // Тип диалогового окна 'info'   Scr2 = Screen.MsgBox( 'Сообщение 2', 'Заголовок окна', 'info' );   alert (Scr2); // выдает undefined   _`
