## ModalDlg

Метод ModalDlg выдает модальное окно диалога с сообщением на текущем экране.  
Действует при выполнении программного кода на клиенте (а не на сервере).

_Синтаксис:_  
      **Screen.ModalDlg( <docDlg> );**

_Аргументы:_  
     _<docDlg> (обязательный)_  
     Тип: **Объект**. Данные для вызова модального окна  
     Основные параметры объекта:  
          _<title> (необязательный)_  
          Тип: **Строка**. Текст заголовка. Если данный параметр задан пустой строкой, то будет отображен заголовок по умолчанию: **"Редактирование записи"**  
           _<message> (обязательный)_  
          Тип: **Строка**. Текст окна. Для переноса текста на следующую строку используется комбинация символов '\\n'.  
          _<height> (необязательный)_  
          Тип: **Целое число**. Высота окна.  
          _<width> (необязательный)_  
          Тип: **Целое число**. Ширина окна.

Примечание - Если высота и ширина окна не заданы, то по умолчанию размеры окна будут соответствовать размерам открытого ранее аналогичного окна. Размеры окна можно изменять с помощью мыши. 

_Возвращаемое значение:_  
      Выходные данные отсутствуют.

_Пример:_  
`_var docDlg = OpenDoc( 'x-local://wtv/wtv_dlg_edit_list_item.xml' ); // формирование данных для вызова модального окна                                   docDlg.TopElem.title = 'Проверка исходных данных';                                   docDlg.TopElem.message = 'Исходные данные';                                   docDlg.TopElem.height = 50;                                   docDlg.TopElem.width = 20;   Screen.ModalDlg( docDlg ); // вызов модального окна   // выполнение дальнейших действий при нажатии на кнопку "Применить"_`  
`_alert ("Агент продолжает работу");   _`
