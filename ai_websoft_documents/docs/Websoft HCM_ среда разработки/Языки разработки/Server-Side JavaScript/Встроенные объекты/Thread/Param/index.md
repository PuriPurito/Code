## Param

Атрибут объекта. Объект типа Object, используемый для хранения произвольных параметров. Обычно параметры устанавливаются перед запуском потока, после чего код, выполняемый в потоке, использует их.  
Параметр не является thread-safe, поэтому код, запускающий поток, не должен обращаться к ним после запуска потока.
