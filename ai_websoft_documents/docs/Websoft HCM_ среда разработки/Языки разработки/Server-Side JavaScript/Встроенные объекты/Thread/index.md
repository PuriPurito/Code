## Thread

Объект, обозначающий отдельный запускаемый поток (thread).

Пример:

thread = new Thread;  
thread.EvalCodeUrl( 'base1\_agents.js', 'Main()' );

На сегодняшний день создание потока через объект Thread не рекомендуется, поскольку существует более удобный способ запyска потока через метод EvalThread() объекта XmlDoc, предлагающий концепцию класса, содержажего атрибуты и методы.
