## ErrorDesc

Атрибут объекта **MethodRunner**.  
Возвращает строку с описанием ошибки, которую вернул метод в случае ошибочного завершения.  
Если метод завершил работу успешно, возвращается пустая строка.

_Синтаксис:_  
      **MethodRunner.ErrorDesc**

_Возвращаемое значение:_  
      Тип: **Строка**. Строковое выражение с описанием ошибки при ошибочном завершении метода.

_Пример:_  
      `_if (Ps.runner.ErrorDesc == "") // если возвращается пустая строка               alert ("Метод завершил работу успешно");_`
