## SetArguments

Метод объекта **MethodRunner**.  
Передача значений аргументов, необходимых для запуска функции (метода), описанной в объекте **MethodRunner**. Набор указанных аргументов должен соответствовать перечню параметров, заданных в описании функции.

_Синтаксис:_  
      **MethodRunner.SetArguments(<args>)**

_Аргументы:_  
      _<args> (обязательный)_  
      Тип: **Строка**. Набор аргументов, необходимых для запуска функции (метода).

_Возвращаемое значение:_  
      Выполняется передача значений аргументов, необходимых для запуска функции (метода). Возвращаемое значение отсутствует.

_Пример 1:_  
      `_runner.SetArguments ( message );         runner.SetArguments ( message, options );         runner.SetArguments ( message, options.GetOptProperty( 'GateID' ) );         methRunner.SetArguments (XAML_TEMPLATE_ID, sParameters + sLocalParameters);         methRunner.SetArguments (XAML_TEMPLATE_ID, "PAGEURL="+UrlEncode(Request.Url) + "&sysparam=" + (NO_CACHE ? "nocache" : ""));_`
