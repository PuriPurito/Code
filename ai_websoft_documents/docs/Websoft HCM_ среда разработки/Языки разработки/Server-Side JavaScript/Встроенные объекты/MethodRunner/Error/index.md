## Error

Атрибут объекта **MethodRunner**.  
Возвращает объект типа Error, содержащий ошибку, которую вернул метод в случае ошибочного завершения.  
Если метод завершил работу успешно, возвращается undefined.

_Синтаксис:_  
      **MethodRunner.Error**

_Возвращаемое значение:_  
      Тип: **Объект Error**. Объект, содержащий информацию об ошибке при ошибочном завершении метода.

_Пример 1:_  
      `_if ( runner.Error != undefined )         {               if ( is_dlg )               {                     Screen.RunCommand( 'Ok' );               }               else               {                     if ( ! IsCancelError( runner.Error ) )                           Screen.ShowErrorMsg( runner.Error );                     Screen.Close();               }               return;         }_`
