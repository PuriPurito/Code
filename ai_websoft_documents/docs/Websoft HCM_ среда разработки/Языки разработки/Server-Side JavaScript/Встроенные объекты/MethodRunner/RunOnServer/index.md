## RunOnServer

Атрибут объекта **MethodRunner**.  
Флаг, обозначающий, что, будучи вызванном внутри клиентского приложения, метод будет запущен на сервере приложения с передачей параметров и возвращаемого результата через специальный протокол. При вызове метода на сервере атрибут игнорируется.  
Значение по умолчанию определяется атрибутом RUN-ON-SERVER описания метода.  
Экспериментальный атрибут.

_Синтаксис:_  
      **MethodRunner.RunOnServer**

_Возвращаемое значение:_  
      Тип: **Булево**. Значение _true_ показывает, что метод, запущенный внутри клиентского приложения, будет запущен на сервере.

_Пример:_  
      `_runner = new MethodRunner( lib_agent, 'kick_agent' );         runner.SetArguments ( RValue( agentID ) );         runner.RunOnServer = !agent.run_on_client;         runner.Run();_`
