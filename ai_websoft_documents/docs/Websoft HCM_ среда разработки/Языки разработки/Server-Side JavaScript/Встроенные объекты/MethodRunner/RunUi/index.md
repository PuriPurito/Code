## RunUi

Атрибут объекта **MethodRunner**.  
Флаг, обозначающий, что при запуске метода будет отображаться окно с пользовательским интерфейсом, показывающее статус выполнения метода (как правило включающий прогресс-индикатор). Сам метод при этом будет выполняться в отдельном потоке, тогда как окно будет отображаться в основном потоке.  
При выполнении метода на сервере атрибут игнорируется.  
Значение по умолчанию определяется атрибутом RUN-UI описания метода.

_Синтаксис:_  
      **MethodRunner.RunUi**

_Возвращаемое значение:_  
      Тип: **Булево**. Значение _true_ показывает, что при запуске метода будет отображаться окно с пользовательским интерфейсом.

_Пример:_  
      `_var baseRunner;         baseRunner = this.GetBaseRunner();         if ( baseRunner != undefined && baseRunner.RunUi )               this.RunUi = false;_`
