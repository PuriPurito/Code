## SetDefaultEnvObject

Метод объекта **MethodRunner**.  
Установка значений переменных окружения, необходимых для запуска функции (метода), описанной в объекте **MethodRunner**.

_Синтаксис:_  
      **MethodRunner.SetDefaultEnvObject(<JSObj>)**

_Аргументы:_  
      _<JSObj> (обязательный)_  
      Тип: **Объект JavaScript**. Набор значений переменных окружения.

_Возвращаемое значение:_  
      Производит установку значений переменных окружения, необходимых для запуска функции (метода). Возвращаемое значение отсутствует.

_Пример:_  
      `_methRunner.SetDefaultEnvObject ( ({ "Request": Request, "CurMethodResult": ({}) } ) );         // В данном случае аргументом метода является объект JavaScript со свойствами Request и CurMethodResult._`
