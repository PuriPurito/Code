## ShowCompletionMessage

Атрибут объекта **MethodRunner**.  
Флаг, обозначающий, что, если вызов метода происходить в клиентском приложении и у метода включен атрибут RUN-UI, то по завершении выполнения метода откроется окно, показывающее результат выполнения. Окно будет содержать сообщение об успешно завершении метода, или текст ошибки, а также статистические данные, если метод поддерживает статистику выполнения.  
При запуске метода на сервере атрибут игнорируется.  
Значение по умолчанию определяется атрибутом SHOW-COMPLETION-MESSAGE описания метода.

_Синтаксис:_  
      **MethodRunner.ShowCompletionMessage**

_Возвращаемое значение:_  
      Тип: **Булево**. Значение _true_ показывает, что по завершении выполнения метода откроется окно, показывающее результат выполнения.

_Пример:_  
      `_var baseRunner;         baseRunner = this.GetBaseRunner();         if ( baseRunner != undefined && baseRunner.ShowCompletionMessage )               this.ShowCompletionMessage = false;_`
