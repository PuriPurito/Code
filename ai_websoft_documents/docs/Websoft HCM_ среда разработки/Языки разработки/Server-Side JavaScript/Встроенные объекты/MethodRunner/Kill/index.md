## Kill

Метод объекта **MethodRunner**.  
Прекращение исполнения функции (метода), описанной в объекте **MethodRunner**.

_Синтаксис:_  
      **MethodRunner.Kill()**

_Аргументы:_  
      Функция вызывается без аргументов.

_Возвращаемое значение:_  
      Прекращает исполнение функции (метода). Возвращаемое значение отсутствует.

_Пример:_  
      `_if ( Ps.runner.IsRunning ) // если метод еще выполняется               Ps.runner.Kill(); // прекратить выполнение метода_`
