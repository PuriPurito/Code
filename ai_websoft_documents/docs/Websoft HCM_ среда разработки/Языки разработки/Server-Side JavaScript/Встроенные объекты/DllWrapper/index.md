## DllWrapper

Объект **DllWrapper** предназначен для вызова функций, описанных во внешних библиотеках (DLL).  
Функции должны удовлетворять требованиям, аналогичным требованиям для импорта внешних библиотек в _Visual Basic_.  
Для вызова функции из определенной библиотеки необходимо создать экземпляр объекта **DllWrapper**, что вызовет загрузку библиотеки. После этого необходимо один раз зарегистрировать каждую функцию, которую планируется вызывать, используя метод RegisterProc.  
После этого функции библиотеки можно будет вызывать как методы объекта **DllWrapper**.

      RegisterProc

_Синтаксис:_  
      **DllWrapper (<libPath>\[, <options>\])**

_Конструктор **DllWrapper** имеет следующий аргументы:_  
      _<libPath> (обязательный)_  
      Тип: **Строка**. Строковое выражение имени или пути к файлу библиотеки.  
      _<options> (необязательный)_  
      Тип: **Строка**. Строковое выражение опций вызова. Доступна опция 'use-alt-search-path' - искать в списке стандартных путей (опция LOAD\_WITH\_ALTERED\_SEARCH\_PATH в Windows).

_Возвращаемое значение:_  
      Тип: **Объект DllWrapper**. Создает экземпляр объекта для вызова загрузки библиотеки DLL.

_Пример:_  
      `_lib = new DllWrapper ( 'User32.dll' ); // создание объекта lib (объект типа DllWrapper) для работы с библиотекой User32.dll         lib.RegisterProc ( 'MessageBoxA', 'integer', 'integer', 'string', 'string', 'integer' ); // регистрация функции MessageBoxA библиотеки User32.dll         retVal = lib.MessageBoxA ( 0, 'Text', 'Title', 0 ); // функция MessageBoxA библиотеки User32.dll вызывается как метод объекта lib (объект типа DllWrapper)_`
