## RegisterProc

Метод объекта DllWrapper.  
Регистрирует функцию из DLL для последующего использования.  
Метод проверяет наличие заданной функции внутри DLL и сохраняет описание параметров для формирования корректного вызова в дальнейшем.  
Метод имеет два статических аргумента, плюс по одному аргументу на каждый описываемый аргумент функции. Функция может иметь не более 9 аргументов.

Внимание! Неправильное описание параметров или способов вызова может вызвать падение приложения. В качестве атрибутов _<option>, <options>, <argOptions>_ могут выступать только скалярные величины (не объекты).

_Синтаксис:_  
      **DllWrapper.RegisterProc (<libPath> , <option>\[, <options1>\[; <argOptions1>\]\], \[, <options2>\[; <argOptions2>\]\], ...)**

_Аргументы:_  
      _<funcName> (обязательный)_  
      Тип: **Строка**. Строковое выражение имени функции.  
      _<option> (обязательный)_  
      Тип: **Строка**. Строковое выражение типа функции.  
      _<options1>, <options2>, ... (необязательный)_  
      Тип: **Строка**. Строковое выражение типов параметров функции. Доступны опции _'string', 'integer'_ и _'cdecl'_ (тип вызова). По умолчанию функция имеет тип вызова _'pascal'_ и не возвращает значения.  
      _<argOptions1>, <argOptions2>, ... (необязательный)_  
      Тип: **Строка**. Строковое выражение опций дополнительных аргументов. Доступна опция _'out'_ (возвращаемый параметр).

_Возвращаемое значение:_  
      Производит регистрацию функции из DLL. Возвращаемое значение отсутствует.

_Пример:_  
      `_lib = new DllWrapper ( 'User32.dll' ); // создание объекта lib (объект типа DllWrapper) для работы с библиотекой User32.dll         lib.RegisterProc ( 'MessageBoxA', 'integer', 'integer', 'string', 'string', 'integer' ); // регистрация функции MessageBoxA библиотеки User32.dll         lib.RegisterProc ( 'GetWindowTextA', 'integer', 'integer', 'string;out', 'integer;out' ); // регистрация функции GetWindowTextA библиотеки User32.dll      Рассмотрим подробнее порядок указания аргументов, необходимых при регистрации функции MessageBoxA (вторая строка в примере): первый аргумент - название регистрируемой функции, второй аргумент - тип результата выполнения регистрируемой функции, третий аргумент - тип аргумента hWnd регистрируемой функции, четверный аргумент - тип аргумента lpText, пятый аргумент - тип аргумента lpCaption, шестой аргумент - тип аргумента uType._`
