## DeleteByValue

Метод объекта XmlMultiElem.   
Удаляет соответствующий множественный элемент с заданным значением. Если таких элементов несколько, удаляет первый. В случае отсутствия таких элементов возвращает ошибку.

Аргументы:  
     val   - значение элемента

Результат:  
нет

Пример:  
  
candidate.profession\_id.DeleteByValue( 2054 );
