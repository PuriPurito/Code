## ByValueExists

Метод объекта XmlMultiElem. XmlMultiElem.ByValueExists()  
Проверяет, существует ли соответствующий множественный элемент с заданным значением.

Синтаксис  
ByValueExists( value )

Аргументы  
value - заданное значение

Пример:  
  
if ( candidate.profession\_id.ByValueExists( 2054 ) )  
{  
}
