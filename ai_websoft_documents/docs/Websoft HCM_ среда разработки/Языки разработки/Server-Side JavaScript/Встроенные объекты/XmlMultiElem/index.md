## XmlMultiElem

XmlMultiElem - это виртуальный объект, множественный элемент, объявленный с атрибутом MILTIPLE (MILTIPLE="1")  (например, создаваемый при вызове параметров profession\_id или role\_id).

Объект XmlMultiElem является массивом, который возвращает список всех элементов c указанным именем, являющихся дочерними элементами своего родителя.

  
С более подробной информацией можно ознакомиться на странице http://docs.datex.ru/article.htm?id=5607317807203771902
