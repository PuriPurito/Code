## XQueryLiteral

Атрибут объекта XmlMultiElem.   
Возвращает константу на языке XQuery в виде последовательности из значений соответствующих множественных элементов.

Результат:  
     String

Пример:  
  
candidate.profession\_id.XQueryLiteral // может вернуть идентификаторы профессий в скобках '(7136288496998367416, 7136288496998367413, 7136288496998367419)'
