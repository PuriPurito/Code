## BindToDb

Преобразует документ (как правило, вновь созданный) в объектный с присвоением нового id (и соответственно url). 

 При создании нового документа нужно связать его с базой данных (если документ не связан с базой данных, то выводится сообщение об ошибке **«Empty document url»**) .

_Синтаксис:_  
      **BindToDb (\[<arg1>\])**

_Аргументы:_  
     _<arg1> (необязательный)_  
      Тип: **Строка**. Имя базы данных. Для текущей базы данных может использоваться имя **DefaultDb**.

_Возвращаемое значение:_  
      Производит преобразование документа. Возвращаемое значение отсутствует.

_Пример:_

      doc.BindToDb();  
      requestDoc.BindToDb( DefaultDb );
