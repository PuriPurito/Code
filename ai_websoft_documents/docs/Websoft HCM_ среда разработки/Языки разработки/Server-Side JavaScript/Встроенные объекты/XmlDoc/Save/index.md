## Save

Сохраняет документ.  
Если аргумент не указан, то сохраняет документ под существующим url.  
Если аргумент указан, устанавливает url документа и сохраняет его.

_Синтаксис:_  
      **Save (\[<docUrl>\])**

_Аргументы:_  
     _<docUrl> (необязательный)_  
      Тип: **Строка**. Url, под которым должен быть сохранен документ. 

_Возвращаемое значение:_  
      Производит сохранение документа. Возвращаемое значение отсутствует.

_Пример:_

`_// Пусть в системе имеются один или несколько материалов библиотеки   arr_cat_elem = XQuery("for $elem in library_materials return $elem") ; // отбор всех материалов библиотеки   alert ( 'Количество материалов библиотеки в системе: ' + ArrayCount (arr_cat_elem));_`

`_for (cat_elem in arr_cat_elem) // перебор всех материалов библиотеки (агент может выполняться долго)   {         cat_elem_id = cat_elem.id;          doc = OpenDoc(UrlFromDocID(cat_elem_id)); // открытие документа (материала библиотеки) по ID         if ( doc.TopElem.use_old_format == true ) {               doc.TopElem.use_old_format = false; // изменение свойства документа use_old_format (преобразование формата в HTML)               **doc.Save();** // сохранение измененного документа в базу         }   }_`
