## XmlDoc

Объект **XmlDoc** является объектом документа.

Для преобразования документа используется встроенная функция **TopElem**. 

После изменения документа необходимо сохранить его в базе с помощью функции **Save**.

  
С более полным составом функций данного объекта можно ознакомиться на странице http://docs.datex.ru/article.htm?id=5620203358492510980
