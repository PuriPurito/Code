## TopElem

Возвращает корневой элемент в  документе. Также к можно обратиться к корневому элементу, используя его имя, но TopElem - более универсальный способ.   
Данный атрибут документа _XmlDoc_ используется, в частности, для обращения к свойствам объекта, найденного из каталога (каталожной записи), а также для изменения свойств документа. 

Результат:  
Объект XmlElem

Пример 1:  
     // Пусть в системе имеется сотрудник Васильева Людмила Петровна  
     // Находим программно сотрудника Васильеву Л.П. с помощью функции tools.get\_doc\_by\_key  
     oCollab = tools.get\_doc\_by\_key ( 'collaborator', 'fullname', 'Васильева Людмила Петровна' );  
     alert ( 'Найден сотрудник ' + oCollab.TopElem.fullname + ' с идентификационным номером ' + oCollab.DocID ); // на экран выводится информация об отобранном сотруднике

Пример 2 (изменение свойства документа _use\_old\_format_, отсутствующего в каталожной записи):

// Пусть в системе имеются один или несколько материалов библиотеки  
arr\_cat\_elem = XQuery("for $elem in library\_materials return $elem") ; // отбор всех материалов библиотеки  
alert ( 'Количество материалов библиотеки в системе: ' + ArrayCount (arr\_cat\_elem));

for (cat\_elem in arr\_cat\_elem) // перебор всех материалов библиотеки (агент может выполняться долго)  
{  
      cat\_elem\_id = cat\_elem.id;   
      doc = OpenDoc(UrlFromDocID(cat\_elem\_id)); // открытие документа (материала библиотеки) по ID  
      if ( doc.TopElem.use\_old\_format == true ) {  
            doc.TopElem.use\_old\_format = false; // изменение свойства документа use\_old\_format (преобразование формата в HTML)  
            doc.Save(); // сохранение документа в базу  
      }  
}
