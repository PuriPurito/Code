## FindExtDataElemByFieldID

Находит в документе элемент внешнего хранения с заданным внешним ID. Если элемент не найден, возвращается undefined.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Аргумент:_  
**extID** – внешний ID элемента (Integer)

_Результат:_  
Объект XmlElem
