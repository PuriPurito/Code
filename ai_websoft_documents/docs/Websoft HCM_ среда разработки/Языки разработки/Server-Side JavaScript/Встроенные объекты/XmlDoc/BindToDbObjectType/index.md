## BindToDbObjectType

Преобразует документ (как правило, вновь созданный) в объектный с присвоением нового id (и соответственно url).

_Синтаксис:_  
      **BindToDbObjectType (<dbName>, <objectType>)**

_Аргументы:_  
     _<dbName> (обязательный)_  
      Тип: **Строка**. Имя базы данных.   
     _<objectType> (обязательный)_  
      Тип: **Строка**. Тип объекта. 

_Возвращаемое значение:_  
      Производит преобразование документа. Возвращаемое значение отсутствует.
