## SaveToLds

Экспериментальный метод.

Сохраняет документ принудительно на сервере приложений. Используется для синхронизации, когда, например, документ открывается или создается локально, а сохраняется на сервере.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.
