## number

Атрибут объекта **Error**.  
Возвращает числовой код ошибки.

_Синтаксис:_  
      **Error.number**

_Возвращаемое значение:_  
      Тип: **Целое число**. Числовой код ошибки.

_Пример:_  
      `_try {               A = 1/0; // смоделирована ошибка: Деление на ноль         }         catch (error) {               alert (error); // возвращает все содержание объекта - полный текст сообщения об ошибке (например, "Zero divide (x-local://wtv/wtv_server_agent.xmd, line 293)")               alert (error.number); // возвращает код ошибки (например, 1008)               alert (error.message); // возвращает пользовательское сообщение (например, "Zero divide")               alert (error.description); // возвращает пользовательское сообщение (например, "Zero divide")         }_`
