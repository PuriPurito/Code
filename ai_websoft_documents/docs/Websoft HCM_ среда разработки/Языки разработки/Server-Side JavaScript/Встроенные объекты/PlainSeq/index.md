## PlainSeq

Псевдо-массив заданной длины N, содержащий последовательность целых чисел от 0 до N-1 (например, нулевой элемент псевдо-массива будет иметь значение 0, первый - 1, второй - 2 и т.д.). При этом массив не содержит реальных данных и практически не занимает памяти.  
Данный объект используется в редких случаях для упрощения написания кода. Например, в качестве счетчика цикла при построении экранных форм.

_Синтаксис:_  
      **PlainSeq (<num>)**

_Аргументы:_  
      _<num> (обязательный)_  
      Тип: **Целое число**. Длина псевдо-массива (N).

_Возвращаемое значение:_  
      Тип: **Массив**. Формирует псевдо-массив длины N со значениями элементов массива от 0 до N-1.

_Пример:_  
      `_<LOOP EXPR="PlainSeq ( 7 )" VAR="_weekDayIndex">               <COL WIDTH="4zr"/>         </LOOP>_`
