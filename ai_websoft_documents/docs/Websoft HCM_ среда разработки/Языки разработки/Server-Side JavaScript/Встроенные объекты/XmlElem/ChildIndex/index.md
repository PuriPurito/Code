## ChildIndex

Атрибут. Возвращает индекс текущего элемента внутри родительского элемента, начиная с "0". Если родительского элемента нет - возвращается ошибка.

Данный атрибут удобно использовать, например, для работы с модулями, входящими в состав многомодульных курсов.

_Синтаксис:_  
      **ChildIndex**

_Аргументы:_  
      Атрибут вызывается без аргументов

_Возвращаемое значение:_  
      Тип: **Целое число**. Индекс текущего элемента внутри родительского элемента.

_Примеры:_  
  
_\_res.parts = ArraySelect( teCourse.parts, "This.ChildIndex==0 || This.ChildIndex==2" );_

  
teDoc = doc.TopElem; // корневой элемент  
aParts = teDoc.parts;  
// aParts - массив модулей курса

for ( part in aParts ) // вывод на экран индексов модулей  
{  
      alert ( part.ChildIndex );  
}
