## OptChildAttrValue

Метод находит (среди дочерних элементов текущего элемента) элемент, имеющий атрибут с заданным именем, и возвращает значение другого заданного атрибута у найденного элемент. Если такого элемент или такого атрибута нет, возвращается пустая строка.

Редко используемый метод.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Аргументы:_  
attrName – имя атрибута, по значению которого ищется дочерний элемент (String).  
attrValue – значение атрибута, по значению которого ищется дочерний элемент (String).  
attrValue2 – требумое значение атрибута найденного дочернего элемента (String).

_Результат:_  
String
