## DeleteChildren

Удаляет все дочерние элементы, удовлетворяющие заданому условию.

Аргументы  
qualExpr   - строка, содержащая выражение (условие), вычисляемое относительно каждого значения элемента (String). Необязательный аргумент. Если выражение не указано, удаляются все дочерние элементы.

Результат  
Отсутствует

Пример:

docLearningTaskResult.TopElem.files.DeleteChildren( "This.is\_expert == true" );
