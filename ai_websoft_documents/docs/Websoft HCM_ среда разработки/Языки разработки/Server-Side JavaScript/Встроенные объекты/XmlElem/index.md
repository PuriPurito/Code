## XmlElem

Объект **XmlElem** соответствует определенном узлу (элементу) в открытом XML-документе. Элемент **XmlElem** имеет значение и набор дочерних элементов.

Любой элемент обладает свойствами массива, то есть можно получить список дочерних элементов, используя стандарнтые методы работы с массивами, в том числе прямое индексирование ( _elem\[i\]_ ).

Также к любому дочернему элементу можно обратиться как к атрибуту объекта, например _elem.xxx_.

Элемент может быть привязан к форме или формироваться динамически (без связи с формой).

С информацией об объекте **XmlElem** можно подробнее ознакомиться на странице http://docs.datex.ru/article.htm?id=5607317807203771901
