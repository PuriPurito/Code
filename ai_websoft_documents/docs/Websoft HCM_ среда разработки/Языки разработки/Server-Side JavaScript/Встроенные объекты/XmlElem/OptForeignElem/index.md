## OptForeignElem

Атрибут. Возвращает соответствующий элемент целевого массива (описанного в атрибуте FOREIGN-ARRAY) или связанного каталога.  
В отличие от атрибута **ForeignElem**, если результат не найден - возвращает значение _undefined_.  
См. также **ForeignElem**.

Необходимо обратить внимание на то, что указанный атрибут возвращает не документ, а каталожную запись. Если необходимо работать именно с документом, то его нужно открывать отдельно.

_Синтаксис:_  
      **OptForeignElem**

_Аргументы:_  
      Атрибут вызывается без аргументов

_Возвращаемое значение:_  
      Тип: О**бъект**. Элемент целевого массива или связанного каталога.

_Пример 1:_

`_// Пусть в системе имеется сотрудник Васильева Людмила Петровна, работающая в организации «Programming Development». Выведем на экран ФИО сотрудника, название и код организации (код организации может быть взят только из связанного каталога_ org (Организация)_)_`

`_// Находим программно сотрудника Васильеву Л.П. с помощью функции_ _tools.get_doc_by_key_   _oCollab = tools.get_doc_by_key ( 'collaborator', 'fullname', 'Васильева Людмила Петровна' );   alert ( 'Найден сотрудник ' + oCollab.TopElem.fullname + ' с идентификационным номером ' + oCollab.DocID ); // на экран выводится информация об отобранном сотруднике   alert ( 'Сотрудник работает в организации ' + oCollab.TopElem.org_name ); // на экран выводится название организации, в которой работает сотрудник (название организации может быть взято из карточки сотрудника)   alert ( 'Код организации ' + oCollab.TopElem.org_id.OptForeignElem.code ); // производится переход к записи в связанном каталоге **Организации**, откуда считывается код организации (используется функция **OptForeignElem**)_`

_Пример 2:_

`_arrElems=XQuery('for $elem in learnings return $elem'); // отбор по каталогу **Законченные электронные курсы**   for (fldElem in arrElems)   {               fldCourse=fldElem.course_id.OptForeignElem // обращение к элементу связанного каталога **Курсы**                if (fldCourse!=undefined) // проверка на наличие указанного элемента в связанном каталоге **Курсы**                {                          alert('course name='+fldCourse.name)               }   }_`
