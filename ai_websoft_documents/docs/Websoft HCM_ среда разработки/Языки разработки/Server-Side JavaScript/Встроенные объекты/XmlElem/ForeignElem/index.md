## ForeignElem

Атрибут. Возвращает соответствующий сопряженный элемент целевого массива (описанного в атрибуте FOREIGN-ARRAY) или связанного каталога. Если элемент не найден - возвращает исключение.  
См. также **OptForeignElem** и описание функции **ForeignElem**  языка XQuery.

Необходимо обратить внимание на то, что указанный атрибут возвращает не документ, а каталожную запись. Если необходимо работать именно с документом, то его нужно открывать отдельно.

_Синтаксис:_  
      **ForeignElem**

_Аргументы:_  
      Атрибут вызывается без аргументов

_Возвращаемое значение:_  
      Тип: О**бъект**. Элемент целевого массива или связанного каталога.

_Пример 1:_

`_// Пусть в системе имеется сотрудник Анисимов Геннадий Федорович, работающая в некоторой организации. Выведем на экран ФИО сотрудника, название и код организации (код организации может быть взят только из связанного каталога org (Организация))_`

`_// Находим программно сотрудника Анисимова Г.Ф. с помощью функции tools.get_doc_by_key   oCollab = tools.get_doc_by_key ( 'collaborator', 'fullname', 'Анисимов Геннадий Федорович' );   alert ( 'Найден сотрудник ' + oCollab.TopElem.fullname + ' с идентификационным номером ' + oCollab.DocID ); // на экран выводится информация об отобранном сотруднике   alert ( 'Сотрудник работает в организации ' + oCollab.TopElem.org_name ); // на экран выводится название организации, в которой работает сотрудник (название организации может быть взято из карточки сотрудника)   alert ( 'Код организации ' + oCollab.TopElem.org_id.ForeignElem.code ); // производится переход к записи в связанном каталоге Организации, откуда считывается код организации (используется функция ForeignElem)_`
