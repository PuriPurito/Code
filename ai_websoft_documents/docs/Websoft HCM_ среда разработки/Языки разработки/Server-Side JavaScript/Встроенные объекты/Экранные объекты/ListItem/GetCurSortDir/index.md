## GetCurSortDir

Метод объекта ListItem.  
Возвращает информацию о направлении сортировки.

_Синтаксис:_  
      **ListItem.GetCurSortDir ()**

_Аргументы:_  
Метод вызывается без аргументов.

_Возвращаемое значение:_  
      Тип: **Строка**. Строковое выражение условного обозначения направления сортировки.  
      _Допустимые значения:_  
      **'+'**    – сортировка по возрастанию;  
      **'-'**     – сортировка по убыванию.

_Пример:_  
      `_if ( List.GetCurSortColumnIndex() < ColumnMaxNum )         {               _array = ArraySort ( _array, ColumnName, List.GetCurSortDir() );         }_`
