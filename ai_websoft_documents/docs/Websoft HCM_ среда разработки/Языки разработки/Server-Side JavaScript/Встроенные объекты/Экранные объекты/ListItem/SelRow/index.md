## SelRow

Атрибут объекта ListItem.  
Возвращает первую выделенную строку (элемент ROW, который представляют из себя объект типа ScreenItem).

_Синтаксис:_  
      **ListItem.SelRow**

_Возвращаемое значение:_  
      Тип: **Объект ScreenItem**. Первая выделенная строка в списке.

_Пример:_  
      `_curElem = List.SelRow.Env.ListElem;_`
