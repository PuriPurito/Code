## CurSortColumn

Атрибут объекта ListItem.  
Возвращает столбец (объект типа ScreenItem), по которому производится сортировка.

_Синтаксис:_  
      **ListItem.CurSortColumn**

_Возвращаемое значение:_  
      Тип: **Объект ScreenItem**. Столбец, по которому производится сортировка.

_Пример:_  
      `_oCol_ScreenItem = List.CurSortColumn;         sEnv = List.CurSortColumn.Env;_`
