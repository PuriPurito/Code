## HasSingleSel

Атрибут объекта ListItem.  
Возвращает _true_, если в списке выделен только один элемент. В противном случае атрибут возвращает _false_.

_Синтаксис:_  
      **ListItem.HasSingleSel**

_Возвращаемое значение:_  
      Тип: **Булево**. Возвращает значение, показывающее, выделен ли в списке только один элемент (_true_ – выделен только один элемент, _false_ – в списке выделено более одного элемента или ни один элемент не выделен).

_Пример:_  
      `_bList_SingleSelect = List.HasSingleSel;         bGrid_SingleSelect = Grid.HasSingleSel;_`
