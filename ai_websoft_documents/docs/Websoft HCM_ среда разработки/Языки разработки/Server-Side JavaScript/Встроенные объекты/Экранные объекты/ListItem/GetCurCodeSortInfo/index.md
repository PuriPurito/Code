## GetCurCodeSortInfo

Метод объекта ListItem.  
Возвращает параметры сортировки - строку с наименованием ключа (поля) и условным обозначением направлением сортировки для текущего экранного объекта. Содержимое этой строки можно вставить в код для выполнения (например, для сортировки массива с помощью функции ArraySort и функции выполнения кода eval).  
Данный метод целесообразно применять для сортировки массива внутри объекта.

_Синтаксис:_  
      **ListItem.GetCurCodeSortInfo ()**

_Аргументы:_  
      Метод вызывается без аргументов.

_Возвращаемое значение:_  
      Тип: **Строка**. Строковое выражение параметров сортировки для последующего формирования и выполнения кода.  
      _Примеры отображения параметров сортировки:_  
      **'name, +'**   – сортировка производится по ключу (полю) name по возрастанию;  
      **'date, -'**   – сортировка производится по ключу (полю) date по убыванию.

_Пример:_  
      `_sortInfo = list.GetCurCodeSortInfo();         eval ( "ArraySort ("vArray, " + list.GetCurCodeSortInfo() + ")" ); // выполняется код, определяющий сортировку массива vArray с ключом и направлением сортировки, заданными значением атрибута list.GetCurCodeSortInfo()_`
