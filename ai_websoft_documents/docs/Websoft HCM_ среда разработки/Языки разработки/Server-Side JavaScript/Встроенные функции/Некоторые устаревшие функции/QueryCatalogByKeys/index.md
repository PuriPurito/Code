## QueryCatalogByKeys

Устаревшая функция, используемая во времена, когда запросы **XQuery** по множественным ключевым значения выполнялись неэффективно. Запрос на получение массива записей.  
В настоящий момент конструкция вида

QueryCatalogByKeys( 'persons', 'id', \[12359841651, 8498132581, 68496313181\] );

автоматически преобразуется в

XQuery( 'for $elem in persons where MatchSome( $elem/id, (12359841651, 8498132581, 68496313181) ) return $elem' ); 

_Синтаксис:_  
      **QueryCatalogByKeys( <catalogName>, <keyName>, <keyValues>)**

_Аргументы:_  
      _<catalogName> (обязательный)_  
      Тип: **Строка**. Название каталога .  
      _<keyName> (обязательный)_  
      Тип: **Строка**. Название поля, по которому строится запрос.  
      _<keyValues> (обязательный)_  
      Тип: **Массив**. Массив значений.

_Возвращаемое значение:_  
      Тип: **Массив**. Получение массива записей.

_Пример:_  
      `_curPersonsArray = QueryCatalogByKeys( 'collaborators', 'id', arrID );_`
