## ExportElemsToStr

Загружает массив XML-элементов в строку. Используется для передачи параметров в плагины и другие внешние процедуры.  
Смотри также функцию LoadElemsFromStr.

_Синтаксис:_  
      **ExportElemsToStr (<objArray>)**

_Аргументы:_  
      _<objArray> (обязательный)_  
      Тип: **Массив**. Массив XML-элементов.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая объекты в XML-формате. Результат действия функции.

_Пример 1 (формирование массива из одного объекта, включающего в себя пары "параметр-значение"):_  
      `_str = '<sample><id>123</id><name>TEST</name></sample>';         entriesArray = LoadElemsFromStr (str); // массив entriesArray состоит из одного элемента (объекта), включающего в себя пары "параметр-значение"         for(e in entriesArray) // в цикле выполняется одна итерация и производится перебор одного элемента массива         {               alert(e.id); // выводится значение параметра id для перебираемого элемента массива               alert(e.name); // выводится значение параметра name для перебираемого элемента массива         }                 str1 = ExportElemsToStr(entriesArray); // возвращает строку, содержащую отформатированные данные массива XML-элементов         alert(str1);_`

_Пример 2 (формирование массива из двух объектов, включающих в себя пары "параметр-значение"):_  
      `_str = '<sample1><id>1</id><name>TEST 1</name></sample1> <sample2><id>2</id><name>TEST 2</name></sample2>';         entriesArray = LoadElemsFromStr (str); // массив entriesArray состоит из двух элементов (объектов), включающих в себя пары "параметр-значение"         for(e in entriesArray) // в цикле выполняются две итерации и производится перебор двух элементов массива         {               alert(e.id); // выводится значение параметра id для перебираемого элемента массива               alert(e.name); // выводится значение параметра name для перебираемого элемента массива         }                 str1 = ExportElemsToStr(entriesArray); // возвращает строку, содержащую отформатированные данные массива XML-элементов         alert(str1);_`
