## GetForeignElem

Находит целевой элемент массива по значению первичного ключа (для стандартных каталогов первичным ключом по умолчанию является id объекта).  
Если соответствующий элемент не найден, функция выдает ошибку.  
Смотри также функцию GetOptForeignElem.  
Примечание - Действие функции несколько отличается от функции ArrayOptFindByKey за счет поддержки рекурсивных массивов XML-элементов.

_Синтаксис:_  
      **GetForeignElem (<objArray>, <keyVal>)**

_Аргументы:_  
      _<objArray> (обязательный)_  
      Тип: **Массив**. Массив объектов.  
      _<keyVal> (обязательный)_  
      Тип: **Строка, Число, Булево** и т.д. Значение ключевого элемента.

_Возвращаемое значение:_  
      Тип: **Объект** (как правило, **объект XmlElem**). Ссылка на найденный объект. Результат действия функции.

_Пример:_  
      `_obj1 = GetForeignElem ( collaborators, 6148914691236517121 );         // 6148914691236517121 - реальный id объекта (сотрудника) (здесь нужно будет вставить id своего тестового сотрудника)         // Если в системе такого id объекта (сотрудника) не существует, функция возвращает ошибку с прерыванием выполняемого кода         // О том, как определить id объекта - см._ _здесь__.         alert (obj1.fullname); // выдает полное имя найденного сотрудника_`

_Другие примеры:_  
      `_event_type1 = GetForeignElem ( event_types, 'interview' );         action = GetForeignElem( object_actions, actionID );_`
