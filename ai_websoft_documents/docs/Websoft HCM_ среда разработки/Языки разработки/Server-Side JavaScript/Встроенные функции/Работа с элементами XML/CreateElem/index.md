## CreateElem

Создает XML-элемент, заданный по фрагменту формы (см. **пример и прилагаемый файл**). Созданный элемент не имеет родительского элемента.  
Функция используется для управления сложными структурами в оперативной памяти компьютера (как альтернатива JavaScript Object), а также для формирования XML для внешнего использования.

_Синтаксис:_  
      **CreateElem (<formUrl>, <elemPath>)**

_Аргументы:_  
      _<formUrl> (обязательный)_  
      Тип: **Строка**. Url xmd-файла, в котором находится форма.  
      _<elemPath> (обязательный)_  
      Тип: **Строка**. Путь к фрагменту формы.

_Возвращаемое значение:_  
      Тип: **Объект XmlElem**. Ссылка на созданный объект XmlElem. Результат действия функции.

_Пример:_  
      `_// Перед запуском данного кода выполните следующие действия:         // 1. Архивный файл, необходимый для запуска кода, можно скачать на вкладке «Файлы». На данной странице Вики-статьи перейдите на вкладку "Файлы" и скачайте размещенный там файл.         // 2. Разархивируйте файл и разместите его содержимое в папку d:\WebTutor\ на вашем компьютере.         // 3. Скопируйте приведенный ниже пример в программный агент и запустите указанный агент, нажав на кнопку "Выполнить агент на стороне клиента".         // Таким образом, должна быть предварительно создана папка \WebTutorAdmin\Dir1\ и в ней размещен файл формы wtv_user.xmd (см. **Рис.1**), фрагмент которой представляет собой описание элемента <user>...</user>         userElem = CreateElem ( 'x-local://Dir1/wtv_user.xmd', 'user' ); // элемент создается на основании фрагмента <user> из файла формы wtv_user.xmd         for ( _elem in userElem ) // вывод на экран наименований и значений свойств элемента <user>         {               alert (_elem.Name + ' = ' + _elem.Value); // см. **Рис.2**         }         // создание элемента с одним свойством         userLoginElem = CreateElem ( 'x-local://Dir1/wtv_user.xmd', 'user.login' ); // создается элемент с именем userLoginElem и одним текстовым свойством login на основании фрагмента <user><login>...</login></user> из файла формы wtv_user.xmd         alert (userLoginElem.Name + ' = ' + userLoginElem.Value); // См. **Рис.3**_`  
  
**Рис.1. Содержимое файла формы wtv\_user.xmd**  
  
  
**Рис.2. Вывод на экран первого свойства (class) элемента <user> из файла формы wtv\_user.xmd**   
  
  
**Рис.3. Вывод на экран созданнного элемента <userLoginElem> со свойством login и пустым значением этого свойства**  

_Другие примеры:_  
      `_destPerson = CreateElem ( '//base2/base2_person.xmd', 'person' );_`
