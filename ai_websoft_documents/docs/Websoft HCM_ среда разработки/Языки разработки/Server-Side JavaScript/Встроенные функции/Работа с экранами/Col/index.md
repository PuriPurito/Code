## Col

Абстрактная переменная, характеризующая отдельную колонку внутри элементов TABLE, LIST, GRID.  
Объект типа COL является элементом набора колонок COLUMNS.

_Синтаксис:_  
      **col.\[...\]**

_Пример:_  
`_col = columns.AddChild ( 'COL' );   col.name = 'value';   col.AddAttr ( 'WIDTH', '100%' );_`
