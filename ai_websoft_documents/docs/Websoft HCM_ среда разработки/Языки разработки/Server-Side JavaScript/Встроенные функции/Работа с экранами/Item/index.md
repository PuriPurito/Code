## Item

Абстрактная переменная типа Объект ScreenItem, которая, будучи вызвана из кода какого-либо элемента экрана, возвращает сам этот элемент.  
Редко используемая абстрактная переменная.

_Синтаксис:_  
      **Item.\[...\]**

_Пример:_  
`_column = Item.columns[columnIndex];   Item.Parent.SetSourceValue( newWidth );_`
