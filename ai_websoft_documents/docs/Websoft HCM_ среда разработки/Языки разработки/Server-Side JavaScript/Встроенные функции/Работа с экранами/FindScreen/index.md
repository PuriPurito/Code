## FindScreen

Ищет экран с заданным именем среди всех открытых экранов.

_Синтаксис:_  
      **FindScreen (<screenName>)**

_Аргументы:_  
      _<screenName> (обязательный)_  
      Тип: **Строка**. Имя экрана.

_Возвращаемое значение:_  
      Тип: **Объект Экран (Screen)**. Ссылка на найденный экран. Результат действия функции.

_Пример:_  
      `_screen = FindScreen( 'FrameStats' );         // ищет экран с именем 'FrameStats'_`
