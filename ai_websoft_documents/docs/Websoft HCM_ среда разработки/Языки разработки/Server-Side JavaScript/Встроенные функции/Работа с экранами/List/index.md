## List

Абстрактная переменная типа Объект ScreenItem, характеризует элемент типа LIST, который отображает статическую таблицу. Элемент типа LIST состоит из строк (ROW или, что тоже самое, LIST-ROW). Внутри каждой строки могут содержаться колонки (COL), внутри которых, в свою очередь - другие элементы экрана, например LABEL, EDIT и т.п.  
Переменная видна в коде в любом месте внутри LIST. Может быть вызвана из любого элемента, находящегося внутри LIST. Как правило, вызывается из меню, выпадающего при нажатии правой кнопки мыши.

_Синтаксис:_  
      **List.\[...\]**

_Пример:_  
`_curElem = List.SelRow.Env.ListElem;_`
