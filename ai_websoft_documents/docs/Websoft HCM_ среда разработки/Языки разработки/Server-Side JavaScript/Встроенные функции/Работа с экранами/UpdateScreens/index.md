## UpdateScreens

Вызывает обновление экрана с заданными параметрами. Данную функцию можно безопасно вызывать из различных потоков.

_Синтаксис:_  
      **UpdateScreens (<maskScreen>, <maskForm>)**

_Аргументы:_  
      _<maskScreen> (обязательный)_  
      Тип: **Строка**. Маска выбора имени экрана.  
      _<maskForm> (обязательный)_  
      Тип: **Строка**. Маска выбора имени экранной формы.

_Возвращаемое значение:_  
      Обновляет указанные экраны. Возвращаемое значение отсутствует.

_Пример:_  
      `_UpdateScreens( '*', '*' ); //обновление всех экранов.         UpdateScreens( '*', '*view*' ); //обновление всех экранов, наименование файла экранной формы которых содержит 'view'._`
