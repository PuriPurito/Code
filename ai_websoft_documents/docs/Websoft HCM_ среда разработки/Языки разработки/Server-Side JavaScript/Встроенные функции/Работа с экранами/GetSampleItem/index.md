## GetSampleItem

Функция используется для работы со сложными составными элементами, описанными в виде шаблона с установленным флагом SAMPLE (_SAMPLE ="1"_), таких как, например, object\_setector, voc\_elem\_selector, date\_selector.  
Возвращает элемент из любого места кода внутри экземпляра внешнего (составного) элемента.  
Флаг SAMPLE показывает, что данный элемент формы не используется при построении элемента экрана. Такой элемент может использоваться только как шаблон для другого элемента через конструкции ITEM и INHERIT.

_Синтаксис:_  
      **GetSampleItem ()**

_Аргументы:_  
      _Функция вызывается без аргументов._

__Возвращаемое значение:__  
      _Тип: **Объект**. Функция возвращает объект из любого места кода внутри экземпляра этого объекта. Результат действия функции._

__Пример:__  
      _`__base_selector = GetSampleItem();         // возвращает ссылку на элемент-контейнер типа Selector из кода этого элемента                 if ( GetSampleItem().IsPassive )               GetSampleItem().FindSubItemByType( 'LABEL' ).UpdateText();_`_
