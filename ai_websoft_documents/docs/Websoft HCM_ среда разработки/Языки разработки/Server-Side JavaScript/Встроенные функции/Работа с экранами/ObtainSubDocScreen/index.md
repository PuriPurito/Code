## ObtainSubDocScreen

Если есть какой-либо большой глобальный документ (как правило - это общие настройки или персональные настройки), и требуется, чтобы он редактировался не в одном большом окне, а в нескольких маленьких разделах, то открывается большой документ, но в окне показывается его фрагмент.  
См. также CreateSubDocScreen.

_Синтаксис:_  
      **ObtainSubDocScreen (<docElem>, <xmsUrl>)**

_Аргументы:_  
      _<docElem> (обязательный)_  
      Тип: **Раздел документа (объект XmlElem)**.  
      _<xmsUrl> (обязательный)_  
      Тип: **Строка**. url экранной формы, при помощи которой документ будет открыт.

_Возвращаемое значение:_  
      Тип: **Объект Экран (Screen)**. Ссылка на экран, демонстрирующий фрагмент документа. Результат действия функции.

_Пример:_  
      `_ObtainSubDocScreen ( global_settings.web, '//base1/base1_global_settings_web.xms' );         // открывает раздел документа global_settings.web с помощью экранной формы '//base1/base1_global_settings_web.xms'_`
