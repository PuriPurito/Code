## Grid

Абстрактная переменная типа Объект ScreenItem, характеризует элемент типа GRID, который отображает динамическую таблицу (например, таблицу типа Excel). Элемент типа GRID содержит описание группы колонок (COLUMNS), каждая из которых внутри содержит набор элементов COL, содержащих атрибут WIDTH, и рядов ROW.  
Таблица может содержать внутри себя несколько описаний групп колонок. При этом каждое последующее описание будет отменять действие предыдущего на последующие строки таблицы.  
Переменная видна в коде в любом месте внутри GRID. Может быть вызвана из любого элемента, находящегося внутри GRID. Как правило, она вызывается из меню, выпадающего при нажатии правой кнопки мыши.

_Синтаксис:_  
      **Grid.\[...\]**

_Пример:_  
      `_curItem = Grid.SelRow.Env._level;_`
