## OpenInnerPage

Используется для добавления новых элементов списка в комбинированных формах \*.xms.  
Редко используемая функция.

_Синтаксис:_  
      **OpenInnerPage (<addElem>)**

_Аргументы:_  
      _<addElem> (обязательный)_  
      Тип: **Объект XmlElem**. Ссылка на добавляемый элемент.

_Возвращаемое значение:_  
      Добавляет новые элементы списка в комбинированных формах \*.xmc. Возвращаемое значение отсутствует.

_Пример:_  
      `_OpenInnerPage ( userElem );_`
