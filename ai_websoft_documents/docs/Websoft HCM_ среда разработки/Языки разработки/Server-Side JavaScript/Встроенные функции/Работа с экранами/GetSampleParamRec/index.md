## GetSampleParamRec

Возвращает параметр (код) для элементов, описанных в виде шаблона с установленным флагом SAMPLE.  
Флаг SAMPLE показывает, что данный элемент формы не используется при построении элемента экрана. Такой элемент может использоваться только как шаблон для другого элемента через конструкции ITEM и INHERIT.  
Если значение аргумента у элемента не задано, возвращает _undefined_.  
Если значение результирующего параметра (кода) не является пустым строковым выражением, то может быть использована функция EvalSampleParamRec с тем же аргументом.

_Синтаксис:_  
      **GetSampleParamRec (<paramName>)**

_Аргументы:_  
      _<paramName> (обязательный)_  
      Тип: **Строка**. Строковое выражение, содержащее наименование параметра.  
Пример значения параметра _<paramName>_:  
_'afterSelectAction'_

_Возвращаемое значение:_  
      Тип: **Строка**. Код элементов, описанных в виде шаблона. Результат действия функции.

_Пример:_  
      `_code = GetSampleParamRec ( 'afterSelectAction' );         if ( code != '' )               EvalSampleParamRec ( 'afterSelectAction' );_`
