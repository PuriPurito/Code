## FindScreenByDocUrl

Ищет экран с заданным url документа. Если экран не найден, возвращает исключение (ошибку с прерыванием выполняемого кода).  
См. также FindOptScreenByDocUrl и ObtainDocScreen.

_Синтаксис:_  
      **FindScreenByDocUrl (<docUrl>)**

_Аргументы:_  
      _<docUrl> (обязательный)_  
      Тип: **Строка**. Url документа.

_Возвращаемое значение:_  
      Тип: **Объект Экран (Screen)**. Ссылка на найденный экран. Результат действия функции.

_Пример:_  
      `_screen = FindScreenByDocUrl ( docUrl );         // ищет экран с заданным url_`
