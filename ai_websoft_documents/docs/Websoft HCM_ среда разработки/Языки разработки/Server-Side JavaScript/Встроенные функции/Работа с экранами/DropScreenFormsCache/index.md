## DropScreenFormsCache

Удаляет данные из кэша. Используется, когда программа самостоятельно модифицирует некоторые формы, и, чтобы обновления вступили в силу, необходимо удалить данные из кэша.  
Редко используемая функция.

_Синтаксис:_  
      **DropScreenFormsCache (\[<screen>\])**

_Аргументы:_  
      _<screen> (необязательный)_  
      Тип: **Объект Экран (Screen)**. Ссылка на экран, который должен быть удален из кэша.

_Возвращаемое значение:_  
      Удаляет из кэша данные об экранах. Возвращаемое значение отсутствует.

_Пример:_  
      `_DropScreenFormsCache (screen1);_`
