## CreateSubDocScreen

Если есть какой-либо большой глобальный документ (как правило - это общие настройки или персональные настройки), и требуется, чтобы он редактировался не в одном большом окне, а в небольших разделах, то открывается большой документ, но в окне показывается лишь некоторая его часть.  
Редко используемая функция.  
См. также ObtainSubDocScreen.

_Синтаксис:_  
      **CreateSubDocScreen (<docElem>, <xmsUrl>)**

_Аргументы:_  
      _<docElem> (обязательный)_  
      Тип: **Раздел документа (объект XmlElem)**.  
      _<xmsUrl> (обязательный)_  
      Тип: **Строка**. Url экранной формы, при помощи которой документ будет открыт.

_Возвращаемое значение:_  
      Тип: **Объект Экран (Screen)**. Ссылка на экран, демонстрирующий фрагмент документа. Результат действия функции.

_Пример:_  
      `_CreateSubDocScreen ( access_blocks.GetChildByKey( ListElem.id ), 'x-local://wtv/wtv_access_block.xms' );         // открывает раздел документа access_blocks.GetChildByKey( ListElem.id ) с помощью экранной формы 'x-local://wtv/wtv_access_block.xms'_`
