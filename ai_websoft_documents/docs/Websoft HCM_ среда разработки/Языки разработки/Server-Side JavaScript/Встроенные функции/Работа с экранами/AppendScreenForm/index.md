## AppendScreenForm

Производит объединение двух экранных форм. Используется для регистрации дополнительных (пользовательских) полей, открываемых дополнительной (пользовательской) экранной формой.  
Редко используемая функция.  
Смотри также MergeScreenForm.

_Синтаксис:_  
      **AppendScreenForm (<mainFormUrl>, <addFormUrl>)**

_Аргументы:_  
      _<mainFormUrl> (обязательный)_  
      Тип: **Строка**. Url основной формы.  
      _<addFormUrl> (обязательный)_  
      Тип: **Строка**. Url дополнительной формы.

_Возвращаемое значение:_  
      Тип: **Объект Экран (Screen)**. Ссылка на объединенный экран. Результат действия функции.

_Пример:_  
      `_screen = CreateDocScreen('base1_csd.xms', 'base2_csd.xms' );         // создает экран screen, объединяющий экранные формы 'base1_csd.xms' и 'base2_csd.xms'_`
