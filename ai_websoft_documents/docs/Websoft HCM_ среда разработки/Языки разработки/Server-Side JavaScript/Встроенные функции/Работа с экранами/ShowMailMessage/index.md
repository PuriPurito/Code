## ShowMailMessage

Отображает на экране почтовое сообщение, указанное в аргументе <msg>, с использованием выбранного способа отображения.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**ShowMailMessage (<msg>\[, <methodID>\])**

_Аргументы:_  
_<msg> (обязательный)_  
Тип: **Почтовое сообщение (объект MailMessage)**. Исходное почтовое сообщение.  
_<methodID> (необязательный)_  
Тип: **Строка**. Строковое выражение, содержащее способ отображения почтового сообщения.

_Возвращаемое значение:_  
Отображает на экране почтовое сообщение. Возвращаемое значение отсутствует.

ShowMailMessage ( message, local\_settings.mail\_method\_id ); // отображает на экране почтовое сообщение message с использованием способа отображения local\_settings.mail\_method\_id
