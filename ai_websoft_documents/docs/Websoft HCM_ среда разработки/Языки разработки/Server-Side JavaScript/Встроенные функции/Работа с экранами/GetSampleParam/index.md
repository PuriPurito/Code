## GetSampleParam

Возвращает заданный параметр для элементов, описанных в виде шаблона с установленным флагом SAMPLE и имеющих параметры.  
Флаг SAMPLE показывает, что данный элемент формы не используется при построении элемента экрана. Такой элемент может использоваться только как шаблон для другого элемента через конструкции ITEM и INHERIT.  
Если значение аргумента (наименование параметра) не задано, возвращает ошибку.

_Синтаксис:_  
      **GetSampleParam (<paramName>)**

_Аргументы:_  
      _<paramName> (обязательный)_  
      Тип: **Строка**. Строковое выражение, содержащее наименование параметра.  
Примеры значений параметра _<paramName>_:  
_'actual-date'  
'before-select-action'  
'foreign-array'  
'foreign-disp-name'  
'view-filter-expr'_

_Возвращаемое значение:_  
      Тип: **Строка, Число, Булево** и т.д. Значение параметра элемента, описанного в виде шаблона. Результат действия функции.

_Пример:_  
      `_if ( GetSampleParam( 'view-filter-expr' ) != '' )               defaultFilter = EvalSampleParam( 'view-filter-expr' );         // если отобран некоторый параметр, отличный от пустого строкового выражения, то строковой переменной defaultFilter присваивается соответствующее значение_`
