## EvalSampleParam

Вычисляет значение параметра элемента, описанного в виде шаблона с установленным флагом SAMPLE, если у этого параметра стоит атрибут EXPR.  
Флаг SAMPLE показывает, что данный элемент формы не используется при построении элемента экрана. Такой элемент может использоваться только как шаблон для другого элемента через конструкции ITEM и INHERIT.

_Синтаксис:_  
      **EvalSampleParam (<paramName>\[, <screenElem>\])**

_Аргументы:_  
      _<paramName> (обязательный)_  
      Тип: **Строка**. Строковое выражение, содержащее наименование параметра.  
Примеры значений параметра _<paramName>_:  
_'actual-date'  
'before-select-action'  
'foreign-array'  
'foreign-disp-name'  
'view-filter-expr'_  
      _<screenElem> (необязательный)_  
      Тип: **Объект ScreenItem (экранный элемент)**. Например, элемент-контейнер типа Selector.

_Возвращаемое значение:_  
      Тип: **Строка, Число, Булево** и т.д. Значение параметра элемента, описанного в виде шаблона. Результат действия функции.

_Пример:_  
      `_actualDate = EvalSampleParam( 'actual-date' );         // возвращает значение параметра         viewFilter = EvalSampleParam( 'view-filter-expr', _base_selector );_`
