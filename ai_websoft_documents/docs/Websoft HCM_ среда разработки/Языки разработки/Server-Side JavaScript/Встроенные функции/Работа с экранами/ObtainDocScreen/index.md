## ObtainDocScreen

Находит экран по url документа, открытого в этом экране.  
Функция проверяет, не открыт ли экран с заданным url. Если экран открыт, то функция поднимает его наверх (делает его активным). Если экран не открыт, то функция создает новый экран и открывает документ.  
Обычно эта функция вызывается, когда пользователь открывает какой-либо объект из списка двойным щелчком.

_Синтаксис:_  
      **ObtainDocScreen (<docUrl>)**

_Аргументы:_  
      _<docUrl> (обязательный)_  
      Тип: **Строка**. Url документа.

_Возвращаемое значение:_  
      Тип: **Объект Экран (Screen)**. Ссылка на экран заданного документа. Результат действия функции.

_Пример:_  
      `_if ( ( screen = FindOptScreenByDocUrl( docUrl ) ) != undefined )               ObtainDocScreen( docUrl );         // если экран найден, то он поднимается наверх и делается активным_`
