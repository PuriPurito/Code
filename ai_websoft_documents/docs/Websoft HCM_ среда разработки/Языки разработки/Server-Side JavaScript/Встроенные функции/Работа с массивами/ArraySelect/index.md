## ArraySelect

Выбирает элементы массива, удовлетворяющие заданному критерию.

_Синтаксис:_  
      **ArraySelect (<array>, <qualExpr>)**

_Аргументы:_  
      _<array> (обязательный)_  
      Тип: **Массив**. Исходный массив.  
      _<qualExpr> (обязательный)_  
      Тип: **Строка**. Выражение, определяющее соответствие элемента массива заданному критерию и вычисляемое относительно каждого элемента массива. При формировании данного выражения может быть использована переменная _This_.

_Возвращаемое значение:_  
      Тип: **Массив**. Массив, содержащий выбранные значения. Результат действия функции.

_Пример 1:_  
      _\_query\_str = "for $elem in collaborators where contains($elem/fullname, 'ин') return $elem";  
      personArray = XQuery(\_query\_str);  
      // personArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает всех сотрудников, в состав фамилии, имени или отчества которых входит подстрока 'ин'.  
      // Внимание - Для больших баз данных исполнение данного запроса может потребовать некоторого времени.  
      // О формировании запросов на языке XQuery - см. Статью 1 и Статью 2._

      _if (ArrayCount (personArray) == 0) alert ('Объект не найден!');_

      _Array1 = ArraySelect ( personArray, **'sex == "m" '** ); // функция возвращает массив сотрудников мужского пола, отобранный из массива personArray  
      j=1; // переменная-счетчик для ограничения количества элементов массива  
      for (arr in Array1)  
      {  
            alert (arr.fullname); // возвращает полные имена всех отобранных сотрудников  
             
            // ограничение количества элементов, которые выводятся на экран  
            if (j == 2) // если показано 2 элемента  
                  break; // остановить цикл  
            j=j+1;  
      }_

_Пример 2 (аналогичен примеру 1, но с использованием указателя This):_

_Пример 3 (в данном примере используется выражение, включающее в себя несколько полей элемента массива):_

 _Пример 4:_  
      _\_query = "for $elem in active\_test\_learnings return $elem";  
      arrActiveTestLearnings = XQuery( \_query ); // выбираются все назначенные тесты   
      alert ( 'Найдено назначенных тестов: ' + ArrayCount( arrActiveTestLearnings ) ); // выводится общее количество назначенных тестов   
      ArraySelect(arrActiveTestLearnings,_ **"state\_id==0 || state\_id==1"**_); // функция выбирает из массива тесты со статусами "Назначен" (state\_id=0) и "В процессе" (state\_id=1). В условиях отбора используется оператор **ИЛИ**_
