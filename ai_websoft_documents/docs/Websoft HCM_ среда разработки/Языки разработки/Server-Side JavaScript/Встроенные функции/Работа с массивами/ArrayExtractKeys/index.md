## ArrayExtractKeys

Выбирает значение определенного поля (атрибута) из каждого элемента массива. Возвращает новый массив той же длины, содержащий выбранные значения.  
Функция аналогична более универсальной функции ArrayExtract, но работает быстрее.

_Синтаксис:_  
      **ArrayExtractKeys (<array>, <field>)**

_Аргументы:_  
      _<array> (обязательный)_  
      Тип: **Массив**. Исходный массив.  
      _<field> (обязательный)_  
      Тип: **Строка**. Строка, содержащая имя поля, по которому производится отбор.  При формировании данного выражения может быть использован указатель _This_ (в который передается текущий элемент массива).

_Возвращаемое значение:_  
      Тип: **Массив**. Массив, содержащий выбранные значения. Результат действия функции.

_Пример:_  
      _try {  
            \_query\_str = "for $elem in collaborators where contains($elem/fullname, 'ин') return $elem";  
            personArray = XQuery(\_query\_str);  
            // personArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает всех сотрудников, в состав фамилии, имени или отчества которых входит подстрока 'ин'.  
            // Внимание - Для больших баз данных исполнение данного запроса может потребовать некоторого времени.  
            // О формировании запросов на языке XQuery - см. Статью 1 и Статью 2.  
            if (ArrayCount (personArray) == 0) alert ('Объект не найден!');  
  
            var Array1 = ArrayExtractKeys (personArray, 'fullname'); // функция выделяет значения атрибута, указанного во втором аргументе (т.е. полное имя (ФИО) отобранных сотрудников)  
            j=1; // переменная-счетчик для ограничения количества элементов массива  
            for (i in Array1)  
            {  
                  alert(i); // возвращает элементы массива - ФИО отобранных сотрудников  
             
                  // ограничение количества элементов, которые выводятся на экран  
                  if (j == 2) // если показано 2 элемента  
                        break; // остановить цикл  
                  j=j+1;  
            }  
      }  
      catch (err){  
           alert ('Объект не найден!');  
      };_
