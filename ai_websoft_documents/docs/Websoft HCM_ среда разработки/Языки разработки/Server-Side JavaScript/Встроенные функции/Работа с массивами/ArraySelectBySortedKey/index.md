## ArraySelectBySortedKey

Выбирает элементы массива, с определенным значением заданного поля. Массив должен быть предварительно отсортирован по возрастанию значения данного поля, что делает эту функцию существенно быстрее по сравнению с ArraySelectByKey.

_Синтаксис:_  
      **ArraySelectBySortedKey (<array>, <keyValue>\[, <keyName>\])**

_Аргументы:_  
      _<array> (обязательный)_  
      Тип: **Массив**. Исходный массив.  
      _<keyValue> (обязательный)_  
      Тип: **Строка**. Значение ключа.  
      _<keyName> (необязательный)_  
      Тип: **Строка**. Имя поля элемента массива, являющегося ключом. Если имя ключа не указано, используется первичный ключ.

_Возвращаемое значение:_  
      Тип: **Массив**. Массив, содержащий выбранные значения. Результат действия функции.

_Пример:_

_// Внимание - Для корректной работы данного примера в базе должен быть хотя бы один сотрудник, в ФИО которого содержится строка 'ин' (например, КалИНин, АнтонИНа)_

_**// 1) производится отбор сотрудников, в ФИО которых содержится строка 'ин'**  
\_query\_str = "for $elem in collaborators where contains($elem/fullname, 'ин') return $elem";  
arrPersonArray = XQuery(\_query\_str);  
// arrPersonArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает всех сотрудников, в состав фамилии, имени или отчества которых входит подстрока 'ин'.  
// Для больших баз данных исполнение данного запроса может потребовать некоторого времени.  
// О формировании запросов на языке XQuery - см. Статью 1 и Статью 2.  
iCnt1 = ArrayCount (arrPersonArray); // количество отобранных записей сотрудников, в ФИО которых содержится строка 'ин'  
alert( 'Найдено ' + iCnt1 + ' сотрудников');  
if (iCnt1 == 0) alert ('Не найдены сотрудники, в ФИО которых содержится строка ин!');_

  
_**// 2) производится отбор сотрудников мужского пола, в ФИО которых содержится строка 'ин'**  
try {  
            arrArray1 = ArraySort ( arrPersonArray, 'fullname', '+' ); // функция сортирует по возрастанию массив по критерию полных имен (ФИО) отобранных сотрудников  
            iCnt2 = ArrayCount ( arrArray1 );  
            alert( 'В отсортированном массиве найдено ' + iCnt2 + ' сотрудников' );_

            _arrArray2 = ArraySort ( arrArray1, 'sex', '+' ); // функция сортирует по возрастанию массив по критерию пола отобранных сотрудников  
            oA1 = ArraySelectBySortedKey ( arrArray2, 'm', 'sex' ); // функция ищет все элементы массива, удовлетворяющие заданному условию (сотрудник является мужчиной)_

  
            _**// 3) производится вывод на экран информации об отобранных объектах**  
            str = '';  
            for ( set in oA1 ) // вывод на экран наименований и значений параметров объекта  
            {  
             str = str + set.Name + ' - ' + set.fullname + '\\n';  
            }  
            alert (str); // пример результата вывода приведен на рисунке ниже_

      _}  
      catch (err){   
            alert ('Сотрудник мужского пола, в ФИО которого содержится строка ин, не найден!');  
      };_

  
_**// 4) производится отбор сотрудника, в ФИО которых содержится строка 'ин' и у которого ID=1 (такие сотрудники отсутствуют)**  
try {  
            arrArray2 = ArraySort ( arrArray1, 'id', '+' ); // функция сортирует по возрастанию массив по критерию ID  
            oA2 = ArraySelectBySortedKey ( arrArray2, 1, 'id' ); // функция ищет элемент массива, удовлетворяющий заданному условию  
        iCnt2 = ArrayCount (oA2); // количество отобранных записей сотрудников, в ФИО которых содержится строка 'ин'  
        if (iCnt2 == 0) alert ('Не найдены сотрудники, в ФИО которых содержится строка ин и с ID=1!');  
        else alert ('Найдено ' + iCnt2 + ' сотрудников');  
      }  
      catch (err){   
            alert ('Ошибка!');  
      };
