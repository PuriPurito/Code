## ArrayMax

Возвращает элемент заданного массива, соответствующий максимальному значению по определенному критерию.  
Если массив не содержит ни одного элемента, функция завершается с исключением.

_Синтаксис:_  
      **ArrayMax (<array>, <elemExpr>)**

_Аргументы:_  
      _<array> (обязательный)_  
      Тип: **Массив**. Исходный массив.  
      _<elemExpr> (обязательный)_  
      Тип: **Строка**. Строковое выражение, вычисляющее значение критерия для отбора элемента массива. При формировании данного выражения может быть использован указатель _This_ (в который передается текущий элемент массива). В простейшем случае в качестве данного аргумента может быть использовано имя поля элемента массива.

_Возвращаемое значение:_  
      Тип: **Элемент массива**. Отобранный элемент массива. Результат действия функции.

_Пример 1:_  
      _try {  
            \_query\_str = "for $elem in collaborators where contains($elem/fullname, 'ин') return $elem";  
            personArray = XQuery(\_query\_str);  
            // personArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает всех сотрудников, в состав фамилии, имени или отчества которых входит подстрока 'ин'.  
            // Внимание - Для больших баз данных исполнение данного запроса может потребовать некоторого времени.  
            // О формировании запросов на языке XQuery - см. Статью 1 и Статью 2.  
            if (ArrayCount (personArray) == 0) alert ('Объект не найден!');  
  
             A1 = ArrayMax ( personArray, 'fullname' ); // функция возвращает элемент массива сотрудников personArray с наибольшим значением указанного критерия  
            alert (A1.fullname); // на экран выводится полное имя отобранного сотрудника  
      }  
      catch (err){   
            alert (err);  
      };_
