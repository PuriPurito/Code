## ArrayRange

Возвращает фрагмент массива, начиная с определенной позиции (номера элемента массива).  
Данная функция как правило используется для реализации постраничного просмотра (paging) результатов запроса _XQuery_.

_Синтаксис:_  
      **ArrayRange (<array>, <pos>, <elemsNum>)**

_Аргументы:_  
      _<array> (обязательный)_  
      Тип: **Массив**. Исходный массив.  
      _<pos> (обязательный)_  
      Тип: **Целое число**. Начальная позиция отбираемого элемента массива. Нумерация позиции начинается с 0.  
      _<elemsNum> (обязательный)_  
      Тип: **Целое число**. Количество отбираемых элементов.

_Возвращаемое значение:_  
      Тип: **Массив**. Массив, содержащий выбранные значения. Результат действия функции.

_Пример:_  
      _var Array1 = \['one', 'two', 'three', 'four', 'five' \];  
      Array2 = ArrayRange (Array1, 1, 3); // создание копии исходного массива из 3-х элементов (elemsNum=3), начиная со 2-го элемента (pos=1)  
      for (arr in Array2)  
      {  
            alert (arr); // возвращает значения элементов результирующего массива ('two', 'three', 'four')  
      }_
