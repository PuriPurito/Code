## ArrayFind

Находит первый элемент массива, удовлетворяющий заданному условию.  
Если элемент, удовлетворяющий условию, не найден, функция завершается с исключением.

_Синтаксис:_  
      **ArrayFind (<array>, <qualExpr>)**

_Аргументы:_  
      _<array> (обязательный)_  
      Тип: **Массив**. Исходный массив.  
      _<qualExpr> (обязательный)_  
      Тип: **Булево**. Выражение, определяющее соответствие элемента массива заданному критерию и вычисляемое относительно каждого элемента массива. При формировании данного выражения может быть использован указатель _This_ (в который передается текущий элемент массива).

_Возвращаемое значение:_  
      Тип: **Элемент массива**. Отобранный элемент массива. Результат действия функции.

_Пример 1:_  
      _\_query\_str = "for $elem in collaborators where contains($elem/fullname, 'ин') return $elem";  
      personArray = XQuery(\_query\_str);  
      // personArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает всех сотрудников, в состав фамилии, имени или отчества которых входит подстрока 'ин'.  
      // Внимание - Для больших баз данных исполнение данного запроса может потребовать некоторого времени.  
      // О формировании запросов на языке XQuery - см. Статью 1 и Статью 2.  
       if (ArrayCount (personArray) == 0) alert ('Объект не найден!');  
  
      A1 = ArrayFind( personArray, 'sex == "m" ' ); // функция возвращает первого сотрудника мужского пола из массива сотрудников personArray  
      alert (A1.fullname); // на экран выводится полное имя отобранного сотрудника  
      A2 = ArrayFind( personArray, 'sex == "n" ' ); // такого значения критерия отбора нет; выводится сообщение об ошибке с прерыванием выполняемого кода  
      alert (A2.fullname);_  
  

_Пример 2 (аналогичен примеру 1, но с использованием указателя This):_      

      `__query_str = "for $elem in collaborators where contains($elem/fullname, 'ин') return $elem";         personArray = XQuery(_query_str);          if (ArrayCount (personArray) == 0) alert ('Объект не найден!');_`

      `_A1 = ArrayFind( personArray, ' This.sex == "m" ' ); // функция возвращает первого сотрудника мужского пола из массива сотрудников personArray, соответствующего указанному критерию         alert (A1.fullname); // на экран выводится полное имя отобранного сотрудника_`  

_Пример 3 (в данном примере используется выражение, включающее в себя несколько полей элемента массива):_      

      `__query_str = "for $elem in collaborators where contains($elem/fullname, 'ин') return $elem";         personArray = XQuery(_query_str);          if (ArrayCount (personArray) == 0) alert ('Объект не найден!');_`

      `_A1 = ArrayFind( personArray, ' This.sex == "m", This.fullname == "Калинин Михаил Михайлович" ' ); // функция возвращает первого сотрудника мужского пола из массива сотрудников personArray, соответствующего указанным критериям         alert (A1.fullname); // на экран выводится полное имя отобранного сотрудника_`
