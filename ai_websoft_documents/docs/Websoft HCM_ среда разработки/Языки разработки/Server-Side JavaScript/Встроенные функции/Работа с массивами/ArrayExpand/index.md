## ArrayExpand

Функция **ArrayExpand** получает на входе массив, содержащий в одном из полей подмассивы, и преобразует их в плоский массив.

_Синтаксис:_  
      **ArrayExpand( <array>, <elemCode> )**

_Аргументы:_  
      _<array> (обязательный)_  
      Тип: **Массив**. Исходный массив с подмассивом.  
      _<elemCode> (обязательный)_  
      Тип: **Строка**. Выражение, вычисляющее поле элемента исходного массива, содержащего подмассив.

_Возвращаемое значение:_  
      Тип: **Массив**. Преобразованный массив. Результат действия функции.

_Пример:_

     _var b1 = {a: 1, b: \[1,2,3\]}  
     var b2 = {a: 1, b: \[4,5,6\]}  
     var a = \[b1, b2\]_

     _c = ArrayExpand(a, "b"); // Результирующий массив \[1,2,3,4,5,6\], собранный из подмассивов, содержащихся в поле "b"  
     alert( tools.object\_to\_text(c, "json") );  // Выводит строку '\[1,2,3,4,5,6\]'_
