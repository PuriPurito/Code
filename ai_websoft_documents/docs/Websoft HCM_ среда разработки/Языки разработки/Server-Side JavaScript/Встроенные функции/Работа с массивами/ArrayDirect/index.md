## ArrayDirect

Преобразует заданный массив в массив прямого доступа (с прямым индексированием).  
Если заданный массив и так поддерживает прямое индексирование, функция возвращает сам исходный массив. В противном случае функция работает аналогично ArraySelectAll и возвращает массив, содержащий копию исходного массива.

_Синтаксис:_  
      **ArrayDirect (<array>)**

_Аргументы:_  
      _<array> (обязательный)_  
      Тип: **Массив**. Исходный массив.

_Возвращаемое значение:_  
      Тип: **Массив**. Массив прямого доступа. Результат действия функции.

_Пример:_  
      _try {  
           \_query\_str = "for $elem in collaborators where contains($elem/fullname, 'ин') return $elem";  
           personArray = XQuery(\_query\_str);  
           // personArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает всех сотрудников, в состав фамилии, имени или отчества которых входит подстрока 'ин'.  
           // Внимание - Для больших баз данных исполнение данного запроса может потребовать некоторого времени.  
           // О формировании запросов на языке XQuery - см. Статью 1 и Статью 2.  
           var Array1 = ArrayDirect (personArray); // функция преобразует заданный массив в массив прямого доступа  
           elemsNum = ArrayCount (Array1); // определение количества элементов результирующего массива прямого доступа  
           alert(Array1 \[elemsNum-1\].fullname); // возвращает ФИО последнего элемента массива отобранных сотрудников  
      }  
      catch (err){  
           alert ('Объект не найден!');  
      };_
