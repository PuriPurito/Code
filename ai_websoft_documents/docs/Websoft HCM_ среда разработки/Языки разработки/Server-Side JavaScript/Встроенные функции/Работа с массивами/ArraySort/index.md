## ArraySort

Сортирует массив по заданным полям. Возвращает новый массив отсортированных значений. Функция требует нечетного числа аргументов (не менее 3-х), для каждого нового уровня сортировки добавляется два новых аргумента.

_Синтаксис:_  
      **ArraySort (<array>, <elemExpr1>, <order1>\[, <elemExpr1>, <order2>…\] )**

_Аргументы:_  
      _<array> (обязательный)_  
      Тип: **Массив**. Исходный массив.  
      _<elemExprN> (обязательный)_  
      Тип: **Строка**. N-й параметр сортировки, строковое выражение N, определяющее значение, по которому производится сортировка элементов массива. При формировании данного выражения может быть использован указатель _This_. В простейшем случае в качестве данного аргумента может быть использовано имя поля элемента массива.  
      _<orderN> (обязательный)_  
      Тип: **Строка**. Направление сортировки по параметру <elemExprN> (если данный аргумент имеет значение '+', то сортировка производится по возрастанию; если аргумент имеет значение '-', то – по убыванию).

_Возвращаемое значение:_  
      Тип: **Массив**. Отсортированный массив. Результат действия функции.

_Пример 1:_

_arr1 = \[5, 0, 15, 10\];  
arrSort1 = ArraySort (arr1, "This", "+");  
alert( tools.object\_to\_text(arrSort1, "json") ); // выводится \[0,5,10,15\]_

_// В следующем примере элементы исходного массива обрабатываются как строки. Поэтому применяется сортировка по алфавиту  
arr2 = \["5", "0", "15", "10"\];  
arrSort2 = ArraySort (arr2, "This", "+");  
alert( tools.object\_to\_text(arrSort2, "json") ); // выводится \["0","10","15","5"\]_

      Array1 = ArraySort ( personArray, 'fullname', '-' ); // функция сортирует массив по критерию полных имен (ФИО) отобранных сотрудников (по убыванию)

            j=j+1;
