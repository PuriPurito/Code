## ArrayOptFindByKey

Ищет первый элемент массива с заданным значением определенного поля (ключа).  
Если элемент, удовлетворяющий условию, не найден, возвращается undefined.

_Синтаксис:_  
      **ArrayOptFindByKey (<array>, <keyValue>\[, <keyName>\])**

_Аргументы:_  
      _<array> (обязательный)_  
      Тип: **Массив**. Исходный массив.  
      _<keyValue> (обязательный)_  
      Тип: **Строка**. Значение ключа.  
      _<keyName> (необязательный)_  
      Тип: **Строка**. Имя поля элемента массива, являющегося ключом. Если имя ключа не указано, используется первичный ключ.

_Возвращаемое значение:_  
      Тип: **Элемент массива**. Отобранный элемент массива. Результат действия функции.

_Пример:_  
      _try {  
            \_query\_str = "for $elem in collaborators where contains($elem/fullname, 'ин') return $elem";  
            personArray = XQuery(\_query\_str);  
            // personArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает всех сотрудников, в состав фамилии, имени или отчества которых входит подстрока 'ин'.  
            // Внимание - Для больших баз данных исполнение данного запроса может потребовать некоторого времени.  
            // О формировании запросов на языке XQuery - см. Статью 1 и Статью 2._            _if (ArrayCount (personArray) == 0) alert ('Объект не найден!');_  
  
            _A1 = ArrayOptFindByKey ( personArray, 'm', 'sex' ); // функция ищет элемент массива, удовлетворяющий заданному условию  
            alert (A1.fullname); // возвращает ФИО первого сотрудника мужского пола из массива personArray  
            A2 = ArrayOptFindByKey ( personArray, 1, 'id' ); // функция ищет элемент массива, удовлетворяющий заданному условию  
            alert (A2); // возвращает значение undefined (в системе отсутствует сотрудник с идентификационным номером id, равным 1). В этом случае A2 не является элементом массива.  
      }  
      catch (err){   
            alert ('Объект не найден!');  
      };_
