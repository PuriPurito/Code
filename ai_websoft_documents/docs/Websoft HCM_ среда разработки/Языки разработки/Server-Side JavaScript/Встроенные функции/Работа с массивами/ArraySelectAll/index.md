## ArraySelectAll

Возвращает массив, содержащий все элементы исходного массива в виде массива с прямым доступом.  
Функция, как правило, используется в двух случаях:  
1\. Для сложной либо многократной обработки (особенно с прямым индексированием) "медленных" массивов, таких как результаты XQuery.  
2\. Когда в цикле, осуществляющем проход по массиву, происходит выборочное удаление его элементов.  
Примечание - В целях избежания переполнения памяти не рекомендуется использовать функцию ArraySelectAll для массивов с количеством элементов более 1000.

_Синтаксис:_  
      **ArraySelectAll (<array>)**

_Аргументы:_  
      _<array> (обязательный)_  
      Тип: **Массив**. Исходный массив.

_Возвращаемое значение:_  
      Тип: **Массив**. Результирующий массив. Результат действия функции.

_Пример:_  
      _\_query\_str = "for $elem in collaborators where contains($elem/fullname, 'ин') return $elem";  
      personArray = XQuery(\_query\_str);  
      // personArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает всех сотрудников, в состав фамилии, имени или отчества которых входит подстрока 'ин'.  
      // Внимание - Для больших баз данных исполнение данного запроса может потребовать некоторого времени.  
      // О формировании запросов на языке XQuery - см. Статью 1 и Статью 2.   
      if (ArrayCount (personArray) == 0) alert ('Объект не найден!');  
  
      Array1 = ArraySelectAll ( personArray ); // функция возвращает копию массива personArray (в формате массива с прямым доступом)  
      elemsNum = ArrayCount (Array1); // количество элементов результирующего массива  
      j=1; // переменная-счетчик для ограничения количества элементов массива  
      for ( i = 0; i < elemsNum; i++ )  
      {  
            elem = Array1 \[i\];  
            alert(elem.fullname); // возвращает полные имена всех отобранных сотрудников  
             
            // ограничение количества элементов, которые выводятся на экран  
            if (j == 2) // если показано 2 элемента  
                  break; // остановить цикл  
            j=j+1;  
      }_
