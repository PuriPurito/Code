## IsArray

Проверяет, является ли аргумент массивом.

_Синтаксис:_  
      **IsArray (<arg>)**

_Аргументы:_  
      _<arg> (обязательный)_  
      Тип: **Массив, строка, целое или вещественное число** и т.д. Исходный аргумент.

_Возвращаемое значение:_  
      Тип: **Булево**. Возвращает значение, показывающее, является ли аргумент массивом (true – аргумент является массивом, false – аргумент не является массивом). Результат действия функции.

_Пример:_  
      _var Array1 = \['one', 'two', 'three' \]; // массив  
      var A2 = 5; // A2 не является массивом  
      alert (IsArray (Array1)); // возвращает значение true  
      alert (IsArray (A2)); // возвращает значение false_
