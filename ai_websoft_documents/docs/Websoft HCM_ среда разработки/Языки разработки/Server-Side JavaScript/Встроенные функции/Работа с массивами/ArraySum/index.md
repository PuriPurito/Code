## ArraySum

 Возвращает сумму числовых значений определенного поля по всем элементам массива объектов.  
Если значение поля не является числовым, выдается сообщение об ошибке _"Element value is not numeric..."_ с прерыванием выполнения программного кода.

Внимание - Данная функция работает только с массивом объектов.

_Синтаксис:_  
      **ArraySum (<array>, <elemExpr>)**

_Аргументы:_  
      _<array> (обязательный)_  
      Тип: **Массив**. Исходный массив.  
      _<elemExpr> (обязательный)_  
      Тип: **Строка**. Строковое выражение, вычисляющее значение поля элемента массива, по которому производится суммирование. При формировании данного выражения может быть использован указатель _This_. В простейшем случае в качестве данного аргумента может быть использовано имя поля элемента массива (поле должно иметь числовое значение).

_Возвращаемое значение:_  
      Тип: **Целое или вещественное число**. Сумма значений определенного числового поля по всем элементам массива объектов. Результат действия функции.

_Пример 1:_  
      _arr1 = \[_  
            _{ id : '1', name : 'Иванов И.И.', num : 18 },  
            { id : '2', name : 'Жирова А.В.', num : 24 },  
           { id : '3', name : 'Калинин В.В.', num : 15 }  
      \]_  
  
      _A1 = ArraySum ( arr1, 'num' ); // функция возвращает сумму значений параметров num из массива arr1 (число 57)  
      alert ( A1 );_ 

_Пример 2 (аналогичен примеру 1, но с использованием указателя This):_

      `_arr1 = [               { id : '1', name : 'Иванов И.И.', num : 18 },               { id : '2', name : 'Жирова А.В.', num : 24 },              { id : '3', name : 'Калинин В.В.', num : 15 }         ]_`

      `_A1 = ArraySum ( arr1, 'This.num' ); // функция возвращает сумму значений параметров num из массива arr1 (число 57)         alert ( A1 );            var a = [{"v": 1}, {"v": 2}, {"v": 3}];         sum1 = ArraySum(a, "This.v"); // функция возвращает 6         alert (sum1);_`

_Пример 3 (в данном примере используется выражение, включающее в себя несколько полей элемента массива):_

      `_arr1 = [               { id : '1', name : 'Иванов И.И.', num : 18 },               { id : '2', name : 'Жирова А.В.', num : 24 },              { id : '3', name : 'Калинин В.В.', num : 15 }         ]_`

      `_A1 = ArraySum ( arr1, 'This.num+10*Int(This.id)' ); // функция возвращает сумму результатов заданных выражений для элементов массива arr1 (число 117)         alert ( A1 );_`

При работе с массивами чисел функция работает некорректно (аргументы, не являющиеся объектами пропускаются):

var a = \[1,2,3\];  
a1 = ArraySum(a, "This"); // функция возвращает 0
