## ArrayOptFindBySortedKey

Ищет первый элемент массива с заданным значением определенного поля (ключа).  
Если элемент, удовлетворяющий условию, не найден, возвращается _undefined_.  
Предполагается, что массив предварительно отсортирован по ключевому полю по возрастанию, что значительно повышает скорость поиска по сравнению с функцией ArrayOptFindByKey. Функцию имеет смысл использовать для частого поиска в каком-либо фиксированном справочнике большого размера, который необходимо заранее отсортировать.  
Если исходный массив не был отсортирован по ключу, то исполняемый код может прервать работу и выдать сообщение об ошибке.

_Синтаксис:_  
      **ArrayOptFindBySortedKey (<array>, <keyValue>\[, <keyName>\])**

_Аргументы:_  
      _<array> (обязательный)_  
      Тип: **Массив**. Исходный массив.  
      _<keyValue> (обязательный)_  
      Тип: **Строка**. Значение ключа.  
      _<keyName> (необязательный)_  
      Тип: **Строка**. Имя поля элемента массива, являющегося ключом. Если имя ключа не указано, используется первичный ключ.

_Возвращаемое значение:_  
      Тип: **XML объект (Элемент массива)**. Результат действия функции.

_Пример:_  
_// Внимание - Для корректной работы данного примера в базе должен быть хотя бы один сотрудник, в ФИО которого содержится строка 'ин' (например, КалИНин, АнтонИНа)_  
  
**_// 1) производится отбор сотрудников, в ФИО которых содержится строка 'ин'_**  
_\_query\_str = "for $elem in collaborators where contains($elem/fullname, 'ин') return $elem";  
arrPersonArray = XQuery(\_query\_str);  
// arrPersonArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает всех сотрудников, в состав фамилии, имени или отчества которых входит подстрока 'ин'.  
// Для больших баз данных исполнение данного запроса может потребовать некоторого времени._  
_// О формировании запросов на языке XQuery - см. Статью 1 и Статью 2._

_iCnt1 = ArrayCount (arrPersonArray); // количество отобранных записей сотрудников, в ФИО которых содержится строка 'ин'  
alert( 'Найдено ' + iCnt1 + ' сотрудников');  
if (iCnt1 == 0) alert ('Не найдены сотрудники, в ФИО которых содержится строка ин!');_

  
**_//_** _**2) производится отбор сотрудников мужского пола, в ФИО которых содержится строка 'ин'**_  
_try {  
            arrArray1 = ArraySort ( arrPersonArray, 'fullname', '+' ); // функция сортирует по возрастанию массив по критерию полных имен (ФИО) отобранных сотрудников  
            iCnt2 = ArrayCount ( arrArray1 );  
            alert( 'В отсортированном массиве найдено ' + iCnt2 + ' сотрудников' );  
  
            arrArray2 = ArraySort ( arrArray1, 'sex', '+' ); // функция сортирует по возрастанию массив по критерию пола отобранных сотрудников  
            oA1 = ArrayOptFindBySortedKey ( arrArray2, 'm', 'sex' ); // функция ищет данные первого элемента массива (XML объекта), удовлетворяющего заданному условию (сотрудник является мужчиной)_

  
         _**// 3) производится вывод на экран наименований и значений параметров** **отобранного объекта**_  
        _str = '';  
        for ( set in oA1 ) // вывод на экран наименований и значений параметров объекта  
        {  
             str = str + set.Name + ' = ' + set.Value + '\\n';  
        }  
        alert (str); // пример результата вывода параметров объекта приведен на рисунке ниже_

        _alert (oA1.fullname);  
      }  
      catch (err){   
            alert ('Сотрудник мужского пола, в ФИО которого содержится строка ин, не найден!');  
      };_

  
         _**// 4) производится отбор сотрудника, в ФИО которых содержится строка 'ин' и у которого ID=1**_  
_try {  
            arrArray2 = ArraySort ( arrArray1, 'id', '+' ); // функция сортирует по возрастанию массив по критерию ID  
            oA2 = ArrayOptFindBySortedKey ( arrArray2, 1, 'id' ); // функция ищет элемент массива, удовлетворяющий заданному условию  
            alert (oA2); // возвращает значение undefined (в системе отсутствует сотрудник с идентификационным номером id, равным 1). В этом случае oA2 не является элементом массива (XML объектом).  
      }  
      catch (err){   
            alert ('Ошибка!');  
      };_
