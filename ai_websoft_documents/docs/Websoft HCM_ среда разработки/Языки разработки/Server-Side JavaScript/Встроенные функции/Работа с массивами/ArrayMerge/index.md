## ArrayMerge

Возвращает строку, полученную путем соединения (склеивания) данных из элементов массива.

_Синтаксис:_  
      **ArrayMerge (<array>, <elemExpr>\[, <delim>\])**

_Аргументы:_  
      _<array> (обязательный)_  
      Тип: **Массив**. Исходный массив.  
      _<elemExpr> (обязательный)_  
      Тип: **Строка**. Выражение, вычисляющее значение, используемое для соединения данных, полученных на основании полей элементов массива. В простейшем случае в качестве данного аргумента может быть использовано имя поля элемента массива. При формировании данного выражения может быть использован указатель _This_ (в который передается текущий элемент массива).  
      _<delim> (необязательный)_  
      Тип: **Строка**. Строка-разделитель между соединяемыми данными.

_Возвращаемое значение:_  
      Тип: **Строка**. Строковое выражение, полученное путем соединения данных из элементов массива. Результат действия функции.

_Пример 1:_  
      _try {_  
            _\_query\_str = "for $elem in collaborators where contains($elem/fullname, 'ин') return $elem";  
            personArray = XQuery(\_query\_str);  
            // personArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает всех сотрудников, в состав фамилии, имени или отчества которых входит подстрока 'ин'.  
            // Внимание - Для больших баз данных исполнение данного запроса может потребовать некоторого времени.  
            // О формировании запросов на языке XQuery - см. Статью 1 и Статью 2.  
            if (ArrayCount (personArray) == 0) alert ('Объект не найден!');_

            _A1 = ArrayMerge (personArray, 'fullname', ' - '); // функция формирует строку из полных имен сотрудников, разделенных знаками «тире»  
            alert (A1); // возвращает сформированную строку   
      }  
      catch (err){   
            alert (err);  
      };_

_Пример 2 (аналогичен примеру 1, но с использованием указателя This):_      

      `_try {               _query_str = "for $elem in collaborators where contains($elem/fullname, 'ин') return $elem";               personArray = XQuery(_query_str);               if (ArrayCount (personArray) == 0) alert ('Объект не найден!');_`

            `_A1 = ArrayMerge (personArray, 'This.fullname', ' - '); // функция формирует строку из полных имен сотрудников, разделенных знаками «тире»               alert (A1); // возвращает сформированную строку         }         catch (err){                alert (err);         };_`

_Пример 3 (в данном примере используется выражение, включающее в себя несколько полей элемента массива):_  
      `_try {               _query_str = "for $elem in collaborators where contains($elem/fullname, 'ин') return $elem";               personArray = XQuery(_query_str);               if (ArrayCount (personArray) == 0) alert ('Объект не найден!');                              A1 = ArrayMerge (personArray, " This.fullname+' ('+(This.sex=='m'?'мужчина':'женщина')+')' ", " – " ); // функция формирует строку из данных, определенных выражением " This.fullname+' ('+(This.sex=='m'?'мужчина':'женщина')+')' " и разделенных знаками «тире»               alert (A1); // возвращает сформированную строку         }         catch (err){                alert (err);         };_`
