## OpenDoc

Открывает XML-документ и возвращает ссылку на объект типа XmlDoc.  
Если XML-документ, указанный в аргументе, не найден, программа выдает ошибку.  
См. также функцию tools.open\_doc и статью **Операция открытия документа (OpenDoc).**

_Синтаксис:_  
      **OpenDoc (<url>\[, <options>\])**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Url документа.  
      _<options> (необязательный)_  
      Тип: **Строка**. Опции открытия документа в виде "param1='value1';param2='value2';...". См. Опции открытия документа XML.

_Возвращаемое значение:_  
      Тип: **Объект XmlDoc**. Ссылка на документ. Результат действия функции.

_Пример 1:_  
      _OpenDoc (objectUrl);  
      OpenDoc (objectUrl, 'form=x-local://wtv/wtv\_form\_ui\_lng.xmd;ignore-top-elem-name=1');_

_Пример 2:_  
      _personArray =XQuery("for $elem in collaborators where contains($elem/fullname, 'ин') return $elem ");  
      // personArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает всех сотрудников, в состав фамилии, имени или отчества которых входит подстрока 'ин'.  
      // Внимание - Для больших баз данных исполнение данного запроса может потребовать некоторого времени.  
      // О формировании запросов на языке XQuery - см._ _Статью 1_ _и_ _Статью 2__.  
      j=1; // переменная для ограничения количества элементов массива  
      for(q in personArray)  
      {  
            m=OpenDoc(UrlFromDocID(Int(q.id))).TopElem;  
            // UrlFromDocID – определение URL по ID объекта (пример ID объекта: 6148914691236517121)  
            // OpenDoc – открытие XML-документа по URL (например, x-local://wt\_data/objects/4976E9DE7B2276/63.xml) и возвращение ссылки на объект  
            // TopElem – переход от документа к корневому объекту документа (для обращения к атрибутам открытого документа удобно использовать специальный атрибут TopElem)  
            alert(m.fullname);  
            // На экран выводятся полные имена отобранных сотрудников  
       
            // ограничение количества элементов, которые выводятся на экран  
            if (j == 2) // если показано 2 элемента  
                  break; // остановить цикл  
            j=j+1;  
      }_

 _Пример 3. Открытие файла в формате Excel:с использованием соответствующей_ опции открытия документа XML _(параметра format):_

_excelFileUrl = Screen.AskFileOpen( '', 'Выбери файл&#09;\*.\*' );_

_arrSourceList = OpenDoc( excelFileUrl, 'format=excel' );  
// Примечание - При открытии документа в формате Excel формируется трехмерный массив: \[номер листа в файле\]\[номер строки на листе\]\[номер столбца\].   
// Нумерация измерений массива начинается с 0._

_// Выбираем первый лист файла Excel с помощью функции ArrayFirstElem.   
arrLines = ArrayFirstElem( arrSourceList.TopElem );  
// Это двухмерный массив: \[номер строки на листе\]\[номер столбца\]._

_for (i = 0; i < ArrayCount(arrLines); i++)  
{  
     for (j = 0; j < ArrayCount(arrLines\[i\]); j++)  
     {  
          sData = arrLines\[i\]\[j\];  
          alert(sData); // выводит данные таблицы по строкам  
     }  
}_

_lineArray = OpenDoc(excelFileUrl, 'format=csv; delim=tab').TopElem;  
// lineArray = OpenDoc(excelFileUrl, 'format=csv; delim=sem').TopElem;  
// lineArray = OpenDoc(excelFileUrl, 'format=csv; delim=,').TopElem;_

_alert(ArrayCount(lineArray)); // выводит количество строк  
alert(ArrayCount(lineArray\[0\])); // выводит количество столбцов_

_for (i = 0; i < ArrayCount(lineArray); i++)  
{  
     for (j = 0; j < ArrayCount(lineArray\[i\]); j++)  
     {  
          alert(lineArray\[i\]\[j\]); // выводит данные таблицы по строкам  
     }  
}_
