## DeleteDoc

Удаляет документ с заданным url. Удаляемый документ попадает в корзину, откуда его можно будет при необходимости восстановить (например, с помощью функции MoveDoc).

Внимание! При использовании данной функции связанные с объектом бинарные данные, например, ресурсы базы (файлы/блобы), не удаляются и остаются на своем месте. Для их удаления используется команда ms\_tools.delete\_resource.  
  
См. также Правила удаления объектов.

_Синтаксис:_  
      **DeleteDoc (<url>\[, <StrictDelete>\])**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Url документа.  
      <StrictDelete> (необязательный)  
      Тип: **Булево**. Аргумент, определяющий, будет ли документ удален без помещения в Корзину (_true_ – документ удаляется без помещения в Корзину, _false_ – документ удаляется и помещается в Корзину). По умолчанию _false_. 

_Возвращаемое значение:_  
      Производится удаление документа. Возвращаемое значение отсутствует.

_Пример:_  
      _DeleteDoc (objectUrl);  
      DeleteDoc (UrlFromDocID (subs.id)); // удаляется документ с идентификационным номером subs.id  
      DeleteDoc( docUrl, true );_
