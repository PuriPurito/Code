## ObjectIDFromUrl

Выдает ID объектного документа по его url. См. также ObjectDocUrl.  
Примечание - Url, переданный в качестве аргумента, не обязательно должен существовать в файловой системе. Существование указанного url функцией не проверяется.

_Синтаксис:_  
      **ObjectIDFromUrl (<url>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Url объекта.

_Возвращаемое значение:_  
      Тип: **Целое число** или **Строка**. ID документа. Результат действия функции.

_Пример:_  
      _A1 = ObjectIDFromUrl ( 'x-db-obj://data/person/0x000000000012E5BD.xml' );  
      alert (A1); // возвращает число 1238461  
      A2 = ObjectIDFromUrl ( 'x-db-obj://data/event\_type/interview.xml' );  
      alert (A2); // возвращает строковое выражение 'interview'_
