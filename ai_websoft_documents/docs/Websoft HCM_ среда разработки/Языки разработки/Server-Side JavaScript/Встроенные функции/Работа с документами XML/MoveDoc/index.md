## MoveDoc

Перемещает XML-документ из одного url в другой url. В отличие от обычного перемещения файла, действие этой функции сопровождается выполнением стандартных свойств OnSave, OnBeforeSave и т.д. Документ сначала сохраняется по новому url, затем удаляется из предыдущего url. Редко используемая функция.

 Примечание - Данная функция может быть использована, в частности, для восстановления с помощью программного кода удаленных файлов (документов), находящихся в Корзине.

_Синтаксис:_  
      **MoveDoc (<url>, <newUrl>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Url существующего документа.  
      _<newUrl> (обязательный)_  
      Тип: **Строка**. Новый url документа.

_Возвращаемое значение:_  
      Производится перемещение документа. Возвращаемое значение отсутствует.

_Пример:_  
      _MoveDoc (oldUrl, newUrl);  
      MoveDoc (UrlFromDocID(id\_удаленного, 'trash'), UrlFromDocID(id\_удаленного, DefaultDb));  
      // возвращение удаленного документа из корзины (если в корзине данного документа нет, программа выдает ошибку)_
