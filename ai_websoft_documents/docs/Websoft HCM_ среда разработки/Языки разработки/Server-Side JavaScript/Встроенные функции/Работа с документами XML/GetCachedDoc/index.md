## GetCachedDoc

Возвращает документ с заданным url из кэша.  
Если документ с заданным url в кэше отсутствует, функция завершается с ошибкой.

_Синтаксис:_  
      **GetCachedDoc (<url>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Url документа.

_Возвращаемое значение:_  
      Тип: **Объект XmlDoc**. Ссылка на документ. Результат действия функции.

_Пример:_  
      _var docCachedView = GetCachedDoc(sCachedUrl);_
