## OpenDocFromStr

Открывает новый XML-документ, содержащий данные, указанные в строке, и возвращает ссылку на объект типа XmlDoc.

_Синтаксис:_  
      **OpenDocFromStr (<dataStr>\[, <options>\])**

_Аргументы:_  
      _**<dataStr>** (обязательный)_  
      Тип: **Строка**. Строка, содержащая данные открываемого документа.  
      _**<options>** (необязательный)_  
      Тип: **Строка**. Опции открытия документа в виде "param1='value1';param2='value2';...". См. Опции открытия документа XML.

_Возвращаемое значение:_  
      Тип: **Объект XmlDoc**. Ссылка на документ. Результат действия функции.

_Пример 1:_  
      `_sourceDoc = OpenDocFromStr ('<temp></temp>');         A1 = sourceDoc.TopElem.Xml; // возвращает содержимое открытого документа в формате XML (для обращения к атрибутам открытого документа удобно использовать специальный атрибут_ _TopElem__)         alert (A1); // возвращает строковое выражение 'temp/' (XML-преобразование выражения '<temp></temp>')_`  

_Пример 2:_  
      `_formDoc = OpenDocFromStr ( _xml, 'form=x-local://wtv/wtv_form_pwt_data.xmd' ).TopElem; // данные строки _xml используются для заполнения указанной формы_`
