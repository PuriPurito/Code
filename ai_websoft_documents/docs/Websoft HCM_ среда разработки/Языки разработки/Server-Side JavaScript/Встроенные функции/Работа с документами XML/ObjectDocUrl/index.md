## ObjectDocUrl

Возвращает url объектного документа по имени базы, типа объекта и ID документа.  
Примечание - Url, сформированный данной функцией, не обязательно должен существовать в файловой системе. Существование указанного url функцией не проверяется.

_Синтаксис:_  
      **ObjectDocUrl (<dbName>, <objectType>, <objectID>)**

_Аргументы:_  
      _<dbName> (обязательный)_  
      Тип: **Строка**. Наименование базы данных.  
      _<objectType> (обязательный)_  
      Тип: **Строка**. Наименование типа объекта.  
      _<objectID> (обязательный)_  
      Тип: **Целое число** или **Строка**. ID документа.

_Возвращаемое значение:_  
      Тип: **Строка**. Url документа. Результат действия функции.

_Пример:_  
      _A1 = ObjectDocUrl( 'data', 'person', 1238461 );  
      alert (A1); // возвращает строковое выражение 'x-db-obj://data/person/0x000000000012E5BD.xml'  
      A2 = ObjectDocUrl( 'data', 'event\_type', 'interview' );  
      alert (A2); // возвращает строковое выражение 'x-db-obj://data/event\_type/interview.xml'_
