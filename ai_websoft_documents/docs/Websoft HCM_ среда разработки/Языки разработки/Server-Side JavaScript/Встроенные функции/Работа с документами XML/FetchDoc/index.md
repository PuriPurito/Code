## FetchDoc

Открывает XML-документ и помещает его в кэш документов.  
Если документ с заданным url уже находится в кэше, возвращается ссылка на документ.

_Синтаксис:_  
      **FetchDoc (<url>\[, <options>\])**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Url документа.       
      _<options> (необязательный)_  
      Тип: **Строка**. Опции открытия документа в виде "param1='value1';param2='value2';...". См. Опции открытия документа XML

_Возвращаемое значение:_  
      Тип: **Объект XmlDoc**. Ссылка на документ. Результат действия функции.

_Пример:_  
      _storeDoc = FetchDoc ('x-local://data\_local/base1\_views\_stored\_data.xml');_
