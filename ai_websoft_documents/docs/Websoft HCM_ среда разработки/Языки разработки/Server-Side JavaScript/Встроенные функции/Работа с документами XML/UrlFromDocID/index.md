## UrlFromDocID

Возвращает url объектного документа с заданным идентификационным номером (id).

_Синтаксис:_  
      **UrlFromDocID(<docID>\[, <dbName>\])**

_Аргументы:_  
      _**<docID>** (обязательный)_  
      Тип: **Целое число**. Идентификационный номер (id) документа.  
      _**<dbName>** (необязательный)_  
      Тип: **Строка**. Имя информационной базы. Если имя базы не указано, то функция обращается к текущей информационной базе.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая url документа.

_Пример:_  
      _A1 = UrlFromDocID ( 123502899940580 );  
      alert (A1); // возвращает url документа с идентификационным номером 123502899940580, если такой документ существует (например, 'x-local://data/objects/00007053427ACC/E4.xml')  
  
      doc = OpenDoc( UrlFromDocID(id) ); // открывает документ с идентификационным номером id_
