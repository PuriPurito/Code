## RegisterSharedDoc

Загружает XML-документ в кэш документов и делает его корневой элемент видимым в списке глобальных имен.  
Примечание - Для корректного выполнения функции необходимо реальное наличие файла документа, указанного в аргументе _<docUrl>_.

_Синтаксис:_  
      **RegisterSharedDoc (<docUrl>)**

_Аргументы:_  
      _<docUrl> (обязательный)_  
      Тип: **Строка**. Url документа.

_Возвращаемое значение:_  
      Тип: **Объект XmlDoc**. Ссылка на документ. Результат действия функции.

_Пример:_  
      _RegisteredDoc = RegisterSharedDoc ("x-local://source/file1.xml");  
      A1 = RegisteredDoc.TopElem.Xml; // возвращает содержимое зарегистрированного документа в формате XML (для обращения к атрибутам документа удобно использовать специальный атрибут_ _TopElem__)  
      A2 = DecodeCharset (A1, 'windows-1251'); // преобразование содержимого зарегистрированного документа в кодировку windows-1251  
      alert (A2); // вывод на экран содержимого зарегистрированного документа_
