## Опции экспорта XML-документов

Опции экспорта XML-документа, используются в функциях SaveToUrl, SaveToStream и др.  
Опции имеют вид _"param1='value1'; param2='value2'; ..."_

      _Примерный список допустимых параметров:_  
      **<inline-ext-objects>**  
      Тип: **Булево**. Включение в экспорт объектов внешнего хранения (например, прикрепленных файлов). Позволяет экспортировать в один файл полное содержимое документа, включая объекты внешнего хранения.  
      **<tabs>**  
      Тип: **Булево**. Форматирование XML с использованием символов табуляции и перевода строк для удобства чтения текста человеком. Значение по умолчанию определяется глобальной настройкой в ini-файле приложения.

_Пример:_  
      _doc.SaveToUrl (tempUrl, 'inline-ext-objects=0;tabs=1;');_
