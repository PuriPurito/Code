## OpenNewDoc

Создает новый XML-документ по заданной форме.

_Синтаксис:_  
      **OpenNewDoc (<formUrl>)**

_Аргументы:_  
      _<formUrl> (обязательный)_  
      Тип: **Строка**. Url формы.

_Возвращаемое значение:_  
      Тип: **Объект XmlDoc**. Ссылка на документ. Результат действия функции.

_Пример:_  
      _var newDoc = OpenNewDoc ('x-local://wtv/wtv\_resource.xmd');_
