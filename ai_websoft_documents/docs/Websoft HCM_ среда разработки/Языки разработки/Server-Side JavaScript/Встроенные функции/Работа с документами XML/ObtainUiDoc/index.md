## ObtainUiDoc

Пытается найти открытую в пользовательском интерфейсе карточку XML-документа. Если таковая карточка найдена, функция возвращает ссылку на документ. В противном случае программа выдает ошибку.  
Чтобы сохранить измененный документ, необходимо использовать функцию UpdateUiDoc (а не вызвать метод Doc.Save, как при открытии документа при помощи OpenDoc).

_Синтаксис:_  
      **ObtainUiDoc (<docUrl>)**

_Аргументы:_  
      _<docUrl> (обязательный)_  
      Тип: **Строка**. Url документа.

_Возвращаемое значение:_  
      Тип: **Объект XmlDoc**. Ссылка на документ. Результат действия функции.

_Пример:_  
      _candidateDoc = ObtainUiDoc ('x-db-obj://data/candidate/0x5555555555555501.xml');_
