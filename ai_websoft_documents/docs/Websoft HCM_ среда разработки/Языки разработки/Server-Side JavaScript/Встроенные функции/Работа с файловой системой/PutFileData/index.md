## PutFileData

Сохраняет содержимое строки в файл. Содержимое строки интерпретируется как бинарные данные.

Если файл, указанный в аргументе _<path>_, не существует, то он создается заново. Если файл существует, то его содержимое удаляется без предупреждения, и он заполняется данными, указанными во втором аргументе функции.

Если в файловой системе отсутствует папка, указанная в аргументе <path>, то функция выдает сообщение об ошибке «Файл не найден» с прерыванием выполняемого кода.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**PutFileData (<path>, <str>)**

_Аргументы:_  
_<path> (обязательный)_  
Тип: **Строка**. Путь (или url) к файлу.  
_<str> (обязательный)_  
Тип: **Строка**. Данные для загрузки в файл.

_Возвращаемое значение:_  
Создается файл, содержащий данные из строки <str>. Возвращаемое значение отсутствует.

_Пример 1 (вывод информации в Блокнот):_  
strLog = 'Строка для вывода в Блокнот';  
path = 'C:\\\\\\WT\\\\';  
filePath = path + 'file.txt';  
ObtainDirectory(path, true); // встроенная функция: проверяет, существует ли указанная папка, если нет - создает ее  
PutFileData(filePath, strLog); // встроенная функция: сохраняет содержимое строки в файл  
ShellExecute('open', filePath); // встроенная функция: выполняет действие открытия файла в среде Windows Shell

_Пример 2:_  
A1 = EncodeCharset ('Программа WebTutor', 'windows-1251'); // преобразование загруженной строки в кодировку windows-1251  
PutFileData ('D:\\\\\\WebTutor\\\\file1.txt', A1); // загружает содержимое строки в текстовый файл (в файловой системе должна существовать папка D:\\\\WebTutor)
