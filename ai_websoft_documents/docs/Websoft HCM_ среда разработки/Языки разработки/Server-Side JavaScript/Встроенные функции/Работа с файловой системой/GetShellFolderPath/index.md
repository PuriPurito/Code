## GetShellFolderPath

Возвращает путь к одной из стандартных директорий _Shell_.  
Примечание - Функция используется только в _EStaff_ для регистрации _add-on_ к браузерам.

_Синтаксис:_  
      **GetShellFolderPath (<folderID>)**

_Аргументы:_  
      _<folderID> (обязательный)_  
      Тип: **Строка**. Идентификатор стандартной директории.  
      _Допустимые значения идентификатора:_  
      **AppData** - директория (папка) для хранения данных пользователя, например: "C:\\User\\PC\\AppData\\Roaming"  
      **LocalAppData** – локальная директория (папка) пользователя, например: "C:\\User\\PC\\AppData\\Roaming"

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая путь к стандартной директории Shell. Результат действия функции.

_Пример:_  
      _A1 = GetShellFolderPath ('AppData');  
      alert (A1); // возвращает директорию (папку) для хранения данных пользователя, например: "C:\\User\\PC\\AppData\\Roaming"  
      A2 = GetShellFolderPath ('LocalAppData');  
      alert (A2); // возвращает локальную директорию (папку) пользователя, например: "C:\\User\\PC\\AppData\\Local"_
