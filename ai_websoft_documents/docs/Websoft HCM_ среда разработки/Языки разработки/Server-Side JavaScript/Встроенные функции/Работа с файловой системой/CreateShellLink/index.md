## CreateShellLink

Создает ярлык на указанный файл.

Функция используется только в E-Staff при автоматической инсталляции клиента с серверного образа.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**CreateShellLink (<link\_path>, <dest\_app\_path>, '', <iconPath> )**

_Аргументы:_  
_<link\_path> (обязательный)_  
Тип: **Строка**. Путь (или url) к создаваемому ярлыку.  
_<dest\_app\_path> (обязательный)_  
Тип: **Строка**. Путь (или url) к файлу, на который будет указывать ярлык.  
_<iconPath> (обязательный)_  
Тип: **Строка**. Путь (или url) к значку (изображению) создаваемого ярлыка.

_Возвращаемое значение:_  
Создается ярлык на файл. Возвращаемое значение отсутствует.
