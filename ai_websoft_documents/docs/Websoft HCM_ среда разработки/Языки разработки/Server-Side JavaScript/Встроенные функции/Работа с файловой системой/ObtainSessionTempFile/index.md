## ObtainSessionTempFile

Возвращает путь (url) ко временному файлу, который создается при запуске сессии приложения (и будет автоматически удален при следующем запуске сессии приложения).

_Синтаксис:_  
      **ObtainSessionTempFile (\[<suffix>\])**

_Аргументы:_  
      _<suffix> (необязательный)_  
      Тип: **Строка**. Требуемый суффикс (расширение) имени искомого файла.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая путь (url) ко временному файлу. Результат действия функции.

_Пример:_  
      _A1 = ObtainSessionTempFile ();  
      alert (A1); // возвращает путь ко временному файлу, который создается при запуске сессии приложения_
