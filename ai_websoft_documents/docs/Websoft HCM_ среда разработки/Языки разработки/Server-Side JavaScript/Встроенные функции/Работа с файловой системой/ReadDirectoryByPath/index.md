## ReadDirectoryByPath

Возвращает массив, содержащий перечень файлов и вложенных директорий (папок) внутри указанной директории.

Каждый элемент массива будет содержать полный путь ко вложенному файлу или директории (папке).

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**ReadDirectoryByPath (<path>)**

_Аргументы:_  
_<path> (обязательный)_  
Тип: **Строка**. Путь (или url) к директории (папке).

_Возвращаемое значение:_  
Тип: **Массив**. Массив, содержащий строковые значения пути к файлам и вложенным директориям (папкам) внутри указанной директории. Результат действия функции.

      A1 = ReadDirectoryByPath ('D:\\\\\\WebTutor\\\\'); // возвращает массив, содержащий перечень файлов и вложенных директорий (папок)  
      elemsNum = ArrayCount (A1); // количество элементов результирующего массива  
      for ( i = 0; i < elemsNum; i++ )  
      {  
            elem = A1 \[i\];  
            alert(elem); // возвращает полные имена файлов и вложенных директорий (папок)  
      }
