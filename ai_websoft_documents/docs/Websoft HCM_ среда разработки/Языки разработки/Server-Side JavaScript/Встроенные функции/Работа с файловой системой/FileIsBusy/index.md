## FileIsBusy

Проверяет, открыт ли файл в другом приложении.

Если текстовый файл открыт в программе Блокнот, то функция выдает значение false.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**FileIsBusy (<path>)**

_Аргументы:_  
_<path> (обязательный)_  
Тип: **Строка**. Путь (или url) к файлу.

_Возвращаемое значение:_  
Тип: **Булево**. Возвращает значение, показывающее, открыт ли файл в другом приложении (true – файл открыт в другом приложении, false – файл не открыт). Результат действия функции.

  
A1 = FileIsBusy ('D:\\\\\\WebTutor\\\\file.docx'); // в файловой системе должны существовать папка D:\\\\WebTutor и в ней файл file.docx  
alert (A1); // возвращает результат проверки
