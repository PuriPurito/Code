## ObtainTempFile

Возвращает путь (url) ко временному файлу, который создается при запуске приложения.

_Синтаксис:_  
      **ObtainTempFile (\[<suffix>\])**

_Аргументы:_  
      _<suffix> (необязательный)_  
      Тип: **Строка**. Требуемый суффикс (расширение) имени искомого файла. Если аргумент отсутствует, то функция не обращает внимания на суффикс файла.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая путь (url) ко временному файлу. Результат действия функции.

_Пример:_  
      _A1 = ObtainTempFile ();  
      alert (A1); // возвращает путь ко временному файлу, который создается при запуске приложения_
