## UserDataDirectoryPath

Возвращает путь к директории (папке) для хранения данных пользователя. По умолчанию эта директория (папка) совпадает с установочной, если специальными настройками не установлено иное.

_Синтаксис:_  
      **UserDataDirectoryPath ()**

_Аргументы:_  
      _Функция вызывается без аргументов._

_Возвращаемое значение:_  
      Тип: **Строка**. Путь к директории (папке) для хранения данных пользователя. Результат действия функции.

_Пример:_  
      _A1 = UserDataDirectoryPath ();  
      alert (A1); // возвращает путь к директории (папке) для хранения данных пользователя (например, путь к папке WebTutorAdmin)_
