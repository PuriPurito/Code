## DeleteFile

Удаляет файл, путь (или url) к которому указан в качестве аргумента.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**DeleteFile (<path>)**

_Аргументы:_  
_<path> (обязательный)_  
Тип: **Строка**. Путь (или url) к удаляемому файлу.

_Возвращаемое значение:_  
Удаляется файл, указанный в качестве аргумента. Возвращаемое значение отсутствует.

DeleteFile ('D:\\\\\\WebTutor\\\\file.txt'); // в файловой системе должны существовать папка D:\\\\WebTutor и в ней файл file.txt  
// Файл D:\\\\WebTutor\\file.txt удален
