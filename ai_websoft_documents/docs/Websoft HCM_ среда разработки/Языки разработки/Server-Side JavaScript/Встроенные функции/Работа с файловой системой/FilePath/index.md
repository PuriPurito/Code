## FilePath

Формирует путь в файловой системе, добавляя фрагмент к базовому пути.

Существование объекта по указанному файловому пути не проверяется.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**FilePath (<filePath>, <fragm>)**

_Аргументы:_  
_<filePath> (обязательный)_  
Тип: **Строка**. Тип: Строка. Строковое выражение базового пути в файловой системе (часто в качестве базового пути используется путь к папке).  
_<fragm> (обязательный)_  
Тип: **Строка**. Строковое выражение добавляемого фрагмента (часто в качестве добавляемого фрагмента используется наименование файла).

_Возвращаемое значение:_  
Тип: **Строка**. Строка, содержащая результирующий путь в файловой системе. Результат действия функции.

  
A1 = 'C:\\\\Temp\\\\';  
A2 = FilePath ( A1, '1.htm');  
alert (A2); // возвращает строковое значение пути 'C:\\Temp\\1.htm'  
  
exePath = FilePath( GetSysEnvironmentVariable( 'windir' ), 'microsoft.net\\\\Framework\\\\v4.0.30319\\\\regasm.exe' ); // добавляет заданный фрагмент к пути "C:\\\\WINDOWS"  
alert ( exePath ); // возвращает строковое значение пути'C:\\WINDOWS\\microsoft.net\\Framework\\v4.0.30319\\regasm.exe'
