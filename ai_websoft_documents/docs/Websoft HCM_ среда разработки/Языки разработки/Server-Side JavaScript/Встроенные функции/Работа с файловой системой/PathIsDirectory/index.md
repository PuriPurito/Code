## PathIsDirectory

Проверяет, существует ли директория (папка) по указанному пути.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**PathIsDirectory (<path>)**

_Аргументы:_  
_<path> (обязательный)_  
Тип: **Строка**. Путь (или url) к директории (папке).

_Возвращаемое значение:_  
Тип: **Булево**. Возвращает значение, показывающее, существует ли директория (папка) по указанному пути (true – директория (папка) существует, false – директория (папка) не существует). Результат действия функции.

A1 = PathIsDirectory ('D:\\\\\\WebTutor\\\\1'); // в файловой системе существует папка D:\\\\WebTutor\\1  
alert (A1); // возвращает значение true  
  
A2 = PathIsDirectory ('D:\\\\\\WebTutor\\\\2'); // в файловой системе отсутствует папка D:\\\\WebTutor\\2  
alert (A2); // возвращает значение false
