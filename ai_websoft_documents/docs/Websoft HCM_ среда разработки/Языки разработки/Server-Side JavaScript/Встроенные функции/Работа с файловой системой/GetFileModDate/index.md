## GetFileModDate

Возвращает дату и время последнего изменения (модификации) файла.

Если файл отсутствует в файловой системе, функция выдает сообщение об ошибке _«Файл не найден»_ с прерыванием выполняемого кода.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**GetFileModDate (<path>)**

_Аргументы:_  
_<path> (обязательный)_  
Тип: **Строка**. Путь (или url) к файлу.

_Возвращаемое значение:_  
Тип: **Дата**. Возвращает дату и время последнего изменения файла. Результат действия функции.

A1 = GetFileModDate ('D:\\\\\\WebTutor\\\\file.docx');  
alert (A1); // возвращает дату и время последнего изменения файла
