## ObtainDirectory

Проверяет, существует ли указанная директория (папка), и если нет – создает ее.

Если аргумент <isRecursive> не указан или имеет значение false, то при отсутствии промежуточных папок, функция выдает сообщение об ошибке «Файл не найден» с прерыванием выполняемого кода.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**ObtainDirectory (<path>, <isRecursive>)**

_Аргументы:_  
_<path> (обязательный)_  
Тип: **Строка**. Путь (или url) к директории (папке).  
_<isRecursive> (необязательный)_  
Тип: **Булево**. Аргумент указывает, нужно ли создавать всю цепочку родительских директорий (папок), если они не существуют (_true_ – цепочка родительских директорий (папок) будет создана, _false_ – цепочка не создана (при отсутствии указанной цепочки выдается сообщение об ошибке)). Если данный аргумент не указан, то по умолчанию он считается равным _false_.

_Возвращаемое значение:_  
Создает указанную директорию (папку), если она отсутствовала в файловой системе. Возвращаемое значение отсутствует.

_Пример 1 (вывод информации в Блокнот):_  
strLog = 'Строка для вывода в Блокнот';  
path = 'C:\\\\\\WT\\\\';  
filePath = path + 'file.txt';  
ObtainDirectory(path, true); // встроенная функция: проверяет, существует ли указанная папка, если нет  создает ее  
PutFileData(filePath, strLog); // встроенная функция: сохраняет содержимое строки в файл  
ShellExecute('open', filePath); // встроенная функция: выполняет действие открытия файла в среде Windows Shell

_Пример 2:_  
ObtainDirectory ('D:\\\\\\WebTutor\\\\Папка 1\\\\Папка 2\\\\Папка 3', true);  
// создается цепочка директорий (папок), если они ранее отсутствовали в файловой системе
