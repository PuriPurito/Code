## ParentDirectory

Извлекает имя родительской директории (папки) из пути, переданного в качестве аргумента.  
Примечание – Фактическое существование директорий не проверяется.

_Синтаксис:_  
      **ParentDirectory (<path>)**

_Аргументы:_  
      _<path> (обязательный)_  
      Тип: **Строка**. Путь (или url) к исходной директории (папке).

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая имя родительской директории (папки). Результат действия функции.

_Пример:_  
      _A1 = ParentDirectory ('D:\\\\\\WebTutor\\\\1');  
      alert (A1); // возвращает строку 'D:\\WebTutor'  
      A2 = ParentDirectory ('D:\\\\\\WebTutor\\\\doc.docx');  
      alert (A2); // возвращает строку 'D:\\WebTutor'_
