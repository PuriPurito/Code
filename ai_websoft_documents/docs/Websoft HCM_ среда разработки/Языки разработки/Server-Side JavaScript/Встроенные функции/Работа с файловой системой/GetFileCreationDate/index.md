## GetFileCreationDate

Возвращает дату создания файла с заданным путем либо url в файловой системе.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**GetFileCreationDate( filePathOrUrl )**

_Аргументы:_  
filePathOrUrlstring   string  
  
Путь к файлу либо URL, отображаемый в файловую систему
