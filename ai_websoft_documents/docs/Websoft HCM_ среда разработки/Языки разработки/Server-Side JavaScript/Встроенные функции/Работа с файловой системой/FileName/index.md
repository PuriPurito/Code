## FileName

Извлекает имя файла или папки из пути, переданного в качестве аргумента.  
Примечание – Путь, переданный в качестве аргумента, не обязательно должен существовать в файловой системе. Существование указанных файла или папки данной функцией не проверяется.

_Синтаксис:_  
      **FileName (<path>)**

_Аргументы:_  
      _<path> (обязательный)_  
      Тип: **Строка**. Путь к файлу.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая имя файла или папки. Результат действия функции.

_Пример:_  
      _A1 = FileName ('D:\\\\\\WebTutor\\\\file.docx');  
      alert (A1); // возвращает значение 'file.docx'  
      A2 = FileName ('D:\\\\\\WebTutor\\\\');  
      alert (A2); // возвращает значение 'WebTutor'  
      A3 = FileName('work\\\\data\\\\doc.pdf');  
      alert (A3); // возвращает значение 'doc.pdf'  
      A4 = FileName('work\\\\data\\\\');  
      alert (A4); // возвращает значение 'data'_
