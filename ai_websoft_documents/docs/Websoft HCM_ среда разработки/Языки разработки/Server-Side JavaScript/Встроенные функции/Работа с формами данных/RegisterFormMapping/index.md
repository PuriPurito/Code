## RegisterFormMapping

Регистрирует отображение (перенаправление) (**mapping**) одной формы в другую.  
**Mapping** \- это таблица, в которой содержит соответствия между старыми и новыми формами документов. При попытке открыть документ по старой форме, будет автоматически вызвана новая форма, на которую указывает элемент таблицы.  
Функция используется в редких случаях, обычно при конвертации баз данных из предыдущих версий программы.

_Синтаксис:_  
      **RegisterFormMapping (<formUrl>, <newForm>)**

_Аргументы:_  
      _<formUrl> (обязательный)_  
      Тип: **Строка**. Url старой формы.  
      _<newForm> (обязательный)_  
      Тип: **Строка**. Url новой формы.

_Возвращаемое значение:_  
      Регистрирует отображение (перенаправление) (mapping) одной формы в другую. Возвращаемое значение отсутствует.
