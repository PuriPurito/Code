## GetOptCachedForm

Пытается найти по заданному url форму в кэше загруженных форм. Если такая форма была загружена в кэш, возвращает ссылку на форму, если нет - возвращает _undefined_.

_Синтаксис:_  
      **GetOptCachedForm (<formUrl>)**

_Аргументы:_  
      _<formUrl> (обязательный)_  
      Тип: **Строка**. Url формы.

_Возвращаемое значение:_  
      Тип: **Форма (объект XmlForm)**. Ссылка на форму. Результат действия функции.  
      Если искомая форма была загружена в кэш, функция возвращает ссылку на форму, если нет - возвращает значение undefined.

_Пример:_  
      _if (GetOptCachedForm (strForm) != undefined)  
      // определяет, была ли загружена в кэш форма с url, указанным в строковой переменной strForm  
      {  
            DropFormsCache('\*'+strForm+'\*');  
            // удаляет из кэша все формы, в составе названий которых содержится строковое выражение strForm  
      }_
