## DropFormsCache

С версии 2025.2.1265 функция объявлена устаревшей и не выполняется в коде.

Удаляет определенные формы из кэша. Функция используется в редких случаях при изменении структур данных на лету.

_Синтаксис:_  
      **DropFormsCache (<urlPattern>)**

_Аргументы:_  
      _<urlPattern> (обязательный)_  
      Тип: **Строка**. Url формы (XMD-файла) или маска url формы.

_Возвращаемое значение:_  
      Удаляет определенные из кэша в соответствии с заданным значением аргумента. Возвращаемое значение отсутствует.

_Пример 1:_  
      _DropFormsCache( '\*candidate\*' );  
      // удаляет из кэша все формы, в составе названий которых содержится строковое выражение 'candidate'_

_Пример 2:_  
      _for ( objectType in object\_types.items )  
      {  
            DropFormsCache (objectType.object\_form\_url);  
            // удаляет из кэша все формы, типы которых указаны в object\_types.items  
      }_
