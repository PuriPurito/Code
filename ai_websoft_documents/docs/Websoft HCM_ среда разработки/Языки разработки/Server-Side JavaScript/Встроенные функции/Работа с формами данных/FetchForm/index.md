## FetchForm

Загружает форму из XMD-файла и помещает ее в кэш форм.  
Если форма с данным url уже находится в кэше, возвращается уже загруженный вариант.

_Синтаксис:_  
      **FetchForm (<formUrl>)**

_Аргументы:_  
      _<formUrl> (обязательный)_  
      Тип: **Строка**. Url формы.

_Возвращаемое значение:_  
      Тип: **Форма (объект XmlForm)**. Ссылка на форму. Результат действия функции.

_Пример:_  
      _form = FetchForm ( 'x-local://wtv/wtv\_event.xmd' );  
      // загружает в кэш форму из XMD-файла с указанным url  
      alert (form.TopElem.Name);  
      // выводит сообщение 'event'_
