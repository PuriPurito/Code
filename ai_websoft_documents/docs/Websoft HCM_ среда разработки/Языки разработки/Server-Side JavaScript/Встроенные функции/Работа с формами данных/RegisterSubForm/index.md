## RegisterSubForm

Регистрирует субформу - фрагмент (элемент) существующей формы под новым url. Новый url состоит из url формы и полного наименования элемента формы, которое включает в себя путь внутри формы от корня до этого элемента.  
Редко используемая функция.

_Синтаксис:_  
      **RegisterSubForm (<formUrl>, <elemPath>)**

_Аргументы:_  
      _<formUrl> (обязательный)_  
      Тип: **Строка**. Url формы.  
      _<elemPath> (обязательный)_  
      Тип: **Строка**. Строковое выражение, которое содержит полный путь к элементу формы, включающий в себя путь внутри формы от корня до этого элемента.

_Возвращаемое значение:_  
      Тип: **Строка**. Url новой субформы. Результат действия функции.

_Пример:_  
      _RegisterSubForm ( 'x-local://wtv/wtv\_event.xmd', 'events.event' )_
