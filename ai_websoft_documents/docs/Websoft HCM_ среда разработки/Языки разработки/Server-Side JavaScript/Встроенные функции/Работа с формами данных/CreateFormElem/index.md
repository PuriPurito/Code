## CreateFormElem

Создает новый элемент формы. Созданный элемент формы не имеет родительского элемента.  
Функция используется в редких случаях, например, для динамической генерации форм данных.

_Синтаксис:_  
      **CreateFormElem (<name>, <type>)**

_Аргументы:_  
      _<name> (обязательный)_  
      Тип: **Строка**. Имя поля XMD-формы.  
      _<type> (обязательный)_  
      Тип: **Строка**. Тип данных XMD-формы.

_Возвращаемое значение:_  
      Тип: **Элемент формы (объект XmlFormElem)**. Ссылка на элемент формы. Результат действия функции.
