## UrlModDate

Возвращает дату и время последнего изменения файла, находящегося по заданному локальному url типа file: или x-local: .

_Синтаксис:_  
      **UrlModDate (<url>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Строковое выражение url файла. Исходное значение.

_Возвращаемое значение:_  
      Тип: **Дата**. Дата и время последнего изменения исходного файла. Результат действия функции.

_Пример:_  
      _A1 = UrlModDate ('file:///D://WebTutor//file1.txt'); // файл D:\\WebTutor\\file1.txt существует в файловой системе  
      alert (A1); // возвращает дату и время последнего изменения файла_
