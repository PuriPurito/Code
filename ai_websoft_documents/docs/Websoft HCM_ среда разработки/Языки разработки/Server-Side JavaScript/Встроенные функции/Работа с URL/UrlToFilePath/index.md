## UrlToFilePath

Преобразует локальный url (типа _file:_ или _x-local:_ ) в путь файловой системы.  
Примечание - Существование объекта по указанному url не проверяется.

_Синтаксис:_  
      **UrlToFilePath (<url>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Строковое выражение локального url (типа _file:_ или _x-local:_). Исходное значение.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая путь файловой системы. Результат действия функции.

_Пример:_  
      _A1 = UrlToFilePath( 'file:///d:/work/Temp.rar' );  
      alert (A1); // возвращает строковое выражение 'd:\\\\work\\\\Temp.rar'  
      A1 = UrlToFilePath( 'file:///d:/work/Temp.rar' );  
      alert (A1); // возвращает строковое выражение 'd:\\work\\Temp.rar'  
      A2 = UrlToFilePath( 'x-local:///wt/web/' );  
      alert (A2); // возвращает строковое выражение '..\\WebTutorAdmin\\wt\\web\\'_
