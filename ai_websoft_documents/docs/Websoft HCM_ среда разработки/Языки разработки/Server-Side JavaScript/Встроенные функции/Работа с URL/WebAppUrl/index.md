## WebAppUrl

Преобразует заданный url (схемы "_x-app_") в url, пригодный для использования во встроенном браузере (элемент HYPER).  
Для десктоп-версии осуществляется преобразование в url схемы "file", а для веб-версии - в специальный серверный запрос.

_Синтаксис:_  
      **WebAppUrl (<url>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Строковое выражение url (схемы "_x-app_"). Исходное значение.

_Возвращаемое значение:_  
      Тип: **Строка**. Строковое выражение url, преобразованное для использования во встроенном браузере. Результат действия функции.

_Пример:_  
      _A1 = WebAppUrl ( 'x-app://base1/base1\_view\_generic\_catalog.xms' );  
      alert (A1); // возвращает строковое выражение url в схеме, пригодной для использования во встроенном браузере_
