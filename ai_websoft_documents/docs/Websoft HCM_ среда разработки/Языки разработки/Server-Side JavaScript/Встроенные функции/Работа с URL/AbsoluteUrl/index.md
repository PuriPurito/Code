## AbsoluteUrl

Преобразует url, указанный в качестве первого аргумента, в абсолютный.  
Если заданный url является абсолютным, то он возвращается без изменения.  
Примечание - Если второй аргумент (базовый url) не указан, то в качестве базового url используется url папки, в которой находится файл, содержащий выполняемый код.

_Синтаксис:_  
      **AbsoluteUrl (<url>, <baseUrl>)**

_Аргументы:_  
      _**<url>** (обязательный)_  
      Тип: **Строка**. Строковое выражение относительного url. Исходное значение.  
      _**<baseUrl>** (необязательный)_  
      Тип: **Строка**. Строковое выражение базового абсолютного url, относительно которого формируется результирующий url. Если аргумент не указан, то в качестве базового url используется родительский url файла, содержащего выполняемый код.

_Возвращаемое значение:_  
      Тип: Строка. Строка, содержащая результирующий абсолютный url. Результат действия функции.

_Пример:_  
      _A1 = AbsoluteUrl( 'zz/1.htm', 'x-local://data/static/' );  
      alert (A1); // возвращает строку 'x-local://data/static/zz/1.htm'  
      A2 = AbsoluteUrl( 'zz/1.htm');  
      alert (A2); // возвращает url папки, в которой находится файл, содержащий выполняемый код_
