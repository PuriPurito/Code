## UrlPathSuffix

Возвращает суффикс (расширение) файла, указанного в строке url в качестве аргумента.  
Примечание - Существование объекта по указанному url не проверяется.

_Синтаксис:_  
      **UrlPathSuffix (<url>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Строковое выражение url исходного файла.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая суффикс (расширение) файла. Результат действия функции.

_Пример:_  
      _A1 = UrlPathSuffix( 'http://news.websoft.ru/db/kb/0939DD37D1C5F9B8C3257403003E8F4F/tree.html' );  
      alert (A1); // возвращает строковое выражение '.html'_
