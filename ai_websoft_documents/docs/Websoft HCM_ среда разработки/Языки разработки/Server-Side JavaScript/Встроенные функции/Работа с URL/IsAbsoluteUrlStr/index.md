## IsAbsoluteUrlStr

Проверяет, является ли строковое выражение абсолютным url (соответствует ли оно принципам формирования url).  
Примечание - Существование объекта под указанным url не проверяется.

_Синтаксис:_  
      **IsAbsoluteUrlStr (<url>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Строковое выражение для проверки. Исходное значение.

_Возвращаемое значение:_  
      Тип: **Булево**. Возвращает значение, показывающее, является ли заданное строковое выражение абсолютным url (true - строковое выражение является абсолютным url, false – строковое выражение не является абсолютным url). Результат действия функции.

_Пример:_  
      _A1 = IsAbsoluteUrlStr ( 'http://www.ya.ru/search.htm' ) ;  
      alert (A1); // возвращает значение true  
      A2 = IsAbsoluteUrlStr ('search.htm');  
      alert (A2); // возвращает значение false_
