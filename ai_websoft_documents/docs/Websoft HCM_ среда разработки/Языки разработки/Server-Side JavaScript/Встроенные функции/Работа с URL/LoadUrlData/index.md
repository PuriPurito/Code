## LoadUrlData

Загружает содержимое заданного url в результирующую строку, которая может содержать бинарные данные.

_Синтаксис:_  
      **LoadUrlData (<url>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Строковое выражение url загружаемого файла. Исходное значение.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, в которую загружается содержимое файла. Результат действия функции.

_Пример:_  
      _A1 = LoadUrlData ('file:///D://WebTutor//file1.txt'); // загружает содержимое текстового файла file1.txt в переменную A1 (текстовый файл D:\\WebTutor\\file1.txt существует в файловой системе)  
      A2 = DecodeCharset (A1, 'windows-1251'); // преобразование загруженной строки в кодировку windows-1251  
      alert (A2); // возвращает строку, содержащую текстовые данные из исходного файла_
