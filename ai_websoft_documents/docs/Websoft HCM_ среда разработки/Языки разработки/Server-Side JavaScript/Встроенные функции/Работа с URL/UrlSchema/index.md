## UrlSchema

Возвращает схему url (_file, http, mailto, ftp, x-local_).  
Примечание - Существование объекта по указанному url не проверяется.

_Синтаксис:_  
      **UrlSchema (<url>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Строковое выражение исходного url.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая схему url (например, _'file', 'http'_). Результат действия функции.

_Пример:_  
      _A1 = UrlSchema ( 'http://news.websoft.ru/db/kb/0939DD37D1C5F9B8C3257403003E8F4F/tree.html' );  
      alert (A1); // возвращает строковое выражение 'http'  
      A2 = UrlSchema ( 'file:///D://WebTutor//file1.txt' );  
      alert (A2); // возвращает строковое выражение 'file'  
      A3 = UrlSchema ( 'x-local://data/static/1/' );  
      alert (A3); // возвращает строковое выражение 'x-local'_
