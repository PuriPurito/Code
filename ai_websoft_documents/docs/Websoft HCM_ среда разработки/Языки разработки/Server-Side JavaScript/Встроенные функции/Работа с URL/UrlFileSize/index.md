## UrlFileSize

Определяет размер файла в байтах по локальному url, переданному в качестве аргумента.

_Синтаксис:_  
      **UrlFileSize (<url>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Строковое выражение локального url заданного файла (типа _file:_ или _x-local:_). Исходное значение.

_Возвращаемое значение:_  
      Тип: **Целое число**. Размер файла в байтах. Результат действия функции.

_Пример:_  
      _A1 = UrlFileSize ('file:///D://WebTutor//file1.txt'); // файл D:\\WebTutor\\file1.txt существует в файловой системе  
      alert (A1); // возвращает размер файла в байтах_
