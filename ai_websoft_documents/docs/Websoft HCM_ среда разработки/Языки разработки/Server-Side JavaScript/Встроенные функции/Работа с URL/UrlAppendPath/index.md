## UrlAppendPath

Добавляет фрагмент пути _<addPath>_ к заданному url.  
Примечание - Существование объекта по указанному url не проверяется.

_Синтаксис:_  
      **UrlAppendPath (<url>, <addPath>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Строковое выражение базового url.  
      _<addPath> (обязательный)_  
      Тип: **Строка**. Строковое выражение добавляемого пути.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая результирующий url. Результат действия функции.

_Пример:_  
      _A1 = UrlAppendPath( 'http://www.lin.ru/service', 'z/1.htm' ) ;  
      alert (A1); // возвращает строковое выражение 'http://www.lin.ru/service/z/1.htm'_
