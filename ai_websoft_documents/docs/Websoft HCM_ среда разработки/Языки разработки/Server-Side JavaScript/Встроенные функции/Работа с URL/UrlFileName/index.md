## UrlFileName

Извлекает имя файла из заданного url.  
Примечание - Существование объекта по указанному url не проверяется.

_Синтаксис:_  
      **UrlFileName (<url>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Строковое выражение url. Исходное значение.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая имя файла, извлеченное из исходного url. Результат действия функции.

_Пример:_  
      _A1 = UrlFileName ( 'http://news.websoft.ru/db/kb/0939DD37D1C5F9B8C3257403003E8F4F/tree.html?query=xxx' );  
      alert (A1); // возвращает строковое выражение 'tree.html'_
