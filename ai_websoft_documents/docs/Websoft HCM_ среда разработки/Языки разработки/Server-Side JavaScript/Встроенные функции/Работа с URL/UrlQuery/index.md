## UrlQuery

Извлекает из url, переданного в качестве аргумента, объект JavaScript, содержащий информацию о параметрах запроса с разбивкой их на пары _"имя - значение"_.  
Обращение к значениям данного объекта производится по именам параметра запроса: _<объект>.<имя параметра запроса>_.

_Синтаксис:_  
      **UrlQuery (<url>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: Строка. Строковое выражение исходного url.

_Возвращаемое значение:_  
      Тип: **Объект JavaScript**. Объект, содержащий данные о парах "имя - значение". Результат действия функции.

_Пример:_  
      _obj = UrlQuery( 'http://news.websoft.ru/en?x=1&y=2&z=3' );  
      alert( obj.x ); // возвращает значение '1' (имя параметра x, значение - '1')  
      alert( obj.y ); // возвращает значение '2' (имя параметра y, значение - '2')  
      alert( obj.z ); // возвращает значение '3' (имя параметра z, значение - '3')_
