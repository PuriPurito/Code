## UrlParent

Извлекает url родительской директории из заданного url.  
Примечание - Существование объекта по указанному url не проверяется.

_Синтаксис:_  
      **UrlParent (<url>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Строковое выражение исходного url.

_Возвращаемое значение:_  
      Тип: **Строка**. Строковое выражение url родительской директории. Результат действия функции.

_Пример:_  
      _A1 = UrlParent( 'http://news.websoft.ru/db/kb/0939DD37D1C5F9B8C3257403003E8F4F/tree.html?query=xxx' );  
      alert (A1); // возвращает строковое выражение 'http://news.websoft.ru/db/kb/0939DD37D1C5F9B8C3257403003E8F4F/'_
