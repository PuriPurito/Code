## CopyUrl

Копирует файл, указанный в аргументе <srcUrl>, в папку, указанную в аргументе _<destUrl>_.  
Примечание - В файловой системе должны существовать папки, указанные в аргументах _<destUrl>_ и _<srcUrl>_, и файл, указанный в аргументе _<srcUrl>_. Если данные папки и файл не существуют, то функция выдает ошибку с завершением выполнения кода.  
Если файл, указанный в аргументе _<destUrl>_, существовал до выполнения функции, то он будет удален, а новый файл будет записан на его место.

_Синтаксис:_  
      **CopyUrl (<destUrl>, <srcUrl>)**

_Аргументы:_  
      _<destUrl> (обязательный)_  
      Тип: **Строка**. Строковое выражение url объекта файловой системы (например, папки), в который производится копирование.  
      _<srcUrl> (обязательный)_  
      Тип: **Строка**. Строковое выражение url объекта файловой системы (например, файла), содержимое которого копируется.

_Возвращаемое значение:_  
      Копируется указанный файл. Возвращаемое значение отсутствует.

_Пример:_  
      _if (IsDirectory ('x-local://Dir1') == false)  
            CreateDirectory ('x-local://Dir1'); // создаем в папке WebTutorAdmin подпапку Dir1, если подпапка Dir1 не существует  
            // создается папка WebTutorAdmin\\Dir1\\  
      if (IsDirectory ('x-local://Dir2') == false)  
            CreateDirectory ('x-local://Dir2'); // создаем в папке WebTutorAdmin подпапку Dir2, если подпапка Dir2 не существует  
            // создается папка WebTutorAdmin\\Dir2\\  
      if (FilePathExists (UrlToFilePath('x-local://Dir1/file1.txt')) == false)  
            PutFileData(UrlToFilePath('x-local://Dir1/file1.txt'), '123'); // создаем в подпапке Dir1 файл file1.txt, если файл file1.txt в подпапке Dir1 не существует  
            // создается файл в папке Dir1  
       
      CopyUrl( 'x-local://Dir2/file1.txt', 'x-local://Dir1/file1.txt' ); // файл file1.txt копируется из подпапки Dir1 в подпапку Dir2_
