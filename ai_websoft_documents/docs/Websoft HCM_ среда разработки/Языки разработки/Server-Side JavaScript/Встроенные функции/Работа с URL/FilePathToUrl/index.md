## FilePathToUrl

Преобразует путь файловой системы в локальный url типа _file:..._ .  
Примечание - Существование объекта по указанному url не проверяется.

_Синтаксис:_  
      **FilePathToUrl (<filePath>)**

_Аргументы:_  
      _<filePath> (обязательный)_  
      Тип: **Строка**. Строковое выражение пути в файловой системе. Исходное значение.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая результирующий url. Результат действия функции.

_Пример:_  
      _A1 = FilePathToUrl ( 'C:\\\\Temp\\\\1.htm');  
      alert (A1); // возвращает строковое значение 'file:///C:/Temp/1.htm'  
      A2 = FilePathToUrl (AppDirectoryPath());  
      alert (A2); // возвращает строковое значение url папки WebTutorAdmin в схеме типа 'file:'_
