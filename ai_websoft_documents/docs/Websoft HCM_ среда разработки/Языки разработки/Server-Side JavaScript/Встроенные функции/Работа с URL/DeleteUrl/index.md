## DeleteUrl

Удаляет объект с заданным url.  
Примечание – Если указанный объект отсутствует в файловой системе, функция выдает сообщение об ошибке «Файл не найден» с прерыванием выполняемого кода.

_Синтаксис:_  
      **DeleteUrl (<url>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Строковое выражение url удаляемого объекта файловой системы (папки или файла). Исходное значение.

_Возвращаемое значение:_  
      Удаляется указанный файл. Возвращаемое значение отсутствует.

_Пример:_  
      _if (IsDirectory ('x-local://Dir2') == false)  
            CreateDirectory ('x-local://Dir2'); // создаем в папке WebTutorAdmin подпапку Dir2, если подпапка Dir2 не существует  
            // создается папка WebTutorAdmin\\Dir2\\  
      if (FilePathExists (UrlToFilePath('x-local://Dir2/file1.txt')) == false)  
            PutFileData(UrlToFilePath('x-local://Dir2/file1.txt'), '123'); // создаем в подпапке Dir2 файл file1.txt, если файл file1.txt в подпапке Dir2 не существует  
            // создается файл в папке Dir2  
       
      DeleteUrl ( 'x-local://Dir2/file1.txt' );  
      // файл file1.txt удаляется из подпапки Dir2_
