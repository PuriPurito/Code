## ReplaceUrlPathSuffix

Заменяет суффикс (расширение) имени файла в заданной строке url. Если суффикс _<suffix1>_ в исходной строке url отсутствует, то замена суффикса не производится.  
Примечание - Функция не осуществляет фактического обращения к файловой системе.

_Синтаксис:_  
      **ReplaceUrlPathSuffix (<url>, <suffix1>, <suffix2>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Строковое выражение url исходного файла.  
      _<suffix1> (обязательный)_  
      Тип: **Строка**. Строковое выражение суффикса (расширения), которое нужно заменить в url.  
      _<suffix2> (обязательный)_  
      Тип: **Строка**. Строковое выражение суффикса (расширения), на которое нужно заменить <suffix1> в url.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая результирующий url. Результат действия функции.

_Пример:_  
      _A1 = ReplaceUrlPathSuffix( 'http://news.websoft.ru/tree.html?query', 'html', 'asp' ) ;  
      alert (A1); // возвращает строковое выражение 'http://news.websoft.ru/tree.asp?query'  
      A2 = ReplaceUrlPathSuffix( 'http://news.websoft.ru/tree.html?query', 'htm', 'asp' ) ;  
      alert (A2); // возвращает строковое выражение 'http://news.websoft.ru/tree.html?query'_
