## StrCharCount

Возвращает количество символов в строке.

_Синтаксис:_  
      **StrCharCount (<str>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: Строка. Исходная строка.

_Возвращаемое значение:_  
      Тип: Целое число. Количество символов в строке. Результат действия функции.

_Пример:_  
      _A1 = StrCharCount ('Программа WebTutor'); // Определение количества символов в строке  
      alert (A1); // возвращает 18_
