## StrIsAlphaNum

Проверяет, состоит ли строка только из цифр или символов латинского алфавита.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**StrIsAlphaNum (<str>)**

_Аргументы:_  
_<str> (обязательный)_  
Тип: **Строка**. Строка, в которой проверяется состав символов. Исходное значение.

_Возвращаемое значение:_  
Тип: **Булево**. _true_ – строка состоит только из цифр или символов латинского алфавита, _false_ – в составе строки имеются символы, отличные от указанных. Результат действия функции.

A1 = StrIsAlphaNum ('ABCDE123'); // строка состоит из цифр и символов латинского алфавита  
alert (A1); // возвращает true  
  
A2 = StrIsAlphaNum ('ABCDEАБВ'); // в строке имеются символы кириллического алфавита  
alert (A2); // возвращает false  
  
A3 = StrIsAlphaNum ('ABCDE\_123'); // в строке имеется символ нижнего подчеркивания  
alert (A3); // возвращает false  
  
A4 = StrIsAlphaNum ('ABCDE 123'); // в строке имеется символ пробела  
alert (A4); // возвращает false
