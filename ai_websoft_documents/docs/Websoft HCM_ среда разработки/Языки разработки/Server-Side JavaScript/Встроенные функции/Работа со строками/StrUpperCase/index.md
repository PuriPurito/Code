## StrUpperCase

Переводит все символы строки в верхний регистр.

_Синтаксис:_  
      **StrUpperCase (<str>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Исходная строка.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, преобразованная к верхнему регистру. Результат действия функции.

_Пример:_  
      _A1 = StrUpperCase ('Программа WebTutor');  
      alert (A1); // возвращает строку 'ПРОГРАММА WEBTUTOR'_
