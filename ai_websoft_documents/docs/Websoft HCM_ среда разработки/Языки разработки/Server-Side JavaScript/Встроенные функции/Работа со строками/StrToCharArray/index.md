## StrToCharArray

Функция **StrToCharArray** преобразует строку в массив символов (по одному символу в каждом элементе массива). 

_Синтаксис:_  
      **StrToCharArray (<str>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Исходное значение.

_Возвращаемое значение:_  
      Тип: **Массив символов**. Результат действия функции.

_Пример:_

      _sData1 = 'Программа WebSoft HCM'; // исходное значение  
      aRes1 = StrToCharArray( sData1 ); // выполняется описываемая функция_

      _sStr = ''; // строка для вывода элементов массива  
      for (elem in aRes1) // выводит информацию об элементах массива  
      {  
           sStr = sStr + ' - ' + elem; // формирование строки для вывода элементов массива  
      }  
      alert ( sStr ); // вывод элементов массива_
