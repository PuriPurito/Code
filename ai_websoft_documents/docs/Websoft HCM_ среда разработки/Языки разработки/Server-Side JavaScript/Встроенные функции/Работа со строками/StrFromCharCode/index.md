## StrFromCharCode

Функция **StrFromCharCode** преобразует код символа (число) в строку, содержащую этот символ. 

_Синтаксис:_  
      **StrFromCharCode (<data>)**

_Аргументы:_  
      <data> (обязательный)  
      Тип: **Целое число**. Исходное значение.

_Возвращаемое значение:_  
      Тип: **Строка**. Результат действия функции.

_Пример:_  
      _sData1 = 65; // исходное значение  
      sRes1 = StrFromCharCode( sData1 ); // выполняется  описываемая функция  
      alert( sRes1 ); // возвращает результат действия функции (символ 'A')_
