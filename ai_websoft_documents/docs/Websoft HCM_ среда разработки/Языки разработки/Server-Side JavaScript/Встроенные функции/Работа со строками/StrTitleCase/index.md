## StrTitleCase

Преобразует первую букву строки в заглавную. Если строка уже приведена к описанному виду или если она не может быть приведена к такому виду, то строка возвращается без изменений.  
_Примечание_ – В ряде версий (например, 2019.2.3) функция StrTitleCase преобразует к нижнему регистру все строковые символы, кроме первого.

_Синтаксис:_  
      **StrTitleCase (<str>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Исходная строка.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, первый символ которой преобразован к верхнему регистру, а остальные символы – к нижнему регистру. Результат действия функции.

_Пример:_  
      _A1 = StrTitleCase ('программа работает');  
      alert (A1); // возвращает строку 'Программа работает'  
      A2 = StrTitleCase ('Программа работает');  
      alert (A2); // возвращает строку 'Программа работает'  
      A3 = StrTitleCase ('123');  
      alert (A3); // возвращает строку '123'_
