## Trim

Удаляет символы пробела, перевода строк и табуляции в начале и в конце исходной строки. Если указанные символы в начале и в конце исходной строки отсутствуют, то функция возвращает исходную строку без изменения.

_Синтаксис:_  
      **Trim (<str>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Исходная строка.

_Возвращаемое значение:_  
      Тип: **Строка**. Копия исходной строки, из которой удалены символы пробела, перевода строк и табуляции в начале и в конце. Результат действия функции.

_Пример:_  
      _A1 = Trim (' Программа WebTutor '); // строка содержит пробелы в начале и в конце  
      alert ('Это строка: ' + A1 + '.'); // возвращает строку 'Это строка: Программа WebTutor.' (пробелы в начале и в конце исходной строки удалены)_
