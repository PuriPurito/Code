## StrReplace

Заменяет все вхождения одной подстроки на другую в исходной строке, если такие вхождения имеются. Если указанные вхождения отсутствуют, то возвращается исходная строка.

_Синтаксис:_  
      **StrReplace (<str>, <subStr>, <newSubStr>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Исходная строка.  
      _<subStr> (обязательный)_  
      Тип: **Строка**. Подстрока для поиска. Если подстрока для поиска - пустая, то функция возвращает исходную строку.  
      _<newSubStr> (обязательный)_  
      Тип: **Строка**. Подстрока для замены. Если подстрока для замены - пустая, то функция удаляет все вхождения подстроки для поиска в исходной строке.

_Возвращаемое значение:_  
      Тип: **Строка**. Измененная строка. Результат действия функции.

_Пример:_  
      _A1 = StrReplace ('Программа WebTutor', 'а', 'б');  
      alert (A1); // возвращает строку 'Прогрбммб WebTutor'  
      A2 = StrReplace ('Программа WebTutor', 'я', 'б');  
      alert (A2); // возвращает строку 'Программа WebTutor' (вхождения подстроки для поиска в исходной строке отсутствуют)  
      A3 = StrReplace ('Программа WebTutor', 'а', '');  
      alert (A3); // возвращает строку 'Прогрмм WebTutor'_
