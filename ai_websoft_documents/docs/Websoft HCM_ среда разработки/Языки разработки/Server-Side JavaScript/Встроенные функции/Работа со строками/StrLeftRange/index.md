## StrLeftRange

Возвращает часть исходной строки str длиной length байтов, начиная с первого байта. Если второй аргумент больше длины исходной строки в байтах, то исходная строка возвращается полностью.  
_Примечание_ \- Длина строки в байтах может быть больше количества символов, если программа использует кодировку UTF-8. Например, символы латинского алфавита, цифры и пробелы могут занимать один байт, а символы латинского алфавита – 2 байта.  
Для определения части строки в символах необходимо использовать функцию StrLeftCharRange.

_Синтаксис:_  
      **StrLeftRange (<str>, <length>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Исходная строка.  
      _<length> (обязательный)_  
      Тип: **Целое число**. Количество возвращаемых байтов.

_Возвращаемое значение:_  
      Тип: **Строка**. Результат действия функции.

_Пример:_  
      _A1 = StrLeftRange ('Программа WebTutor', 6); // отделяет часть строки с 0-го по 6-й байты (кириллическую букву функция считает за 2 байта, а латинскую букву и цифру – за один)  
      alert (A1); // возвращает строку 'Про'  
      A2 = StrLeftRange ('ABCDE123', 5);  
      alert (A2); // возвращает 'ABCDE'  
      A3 = StrLeftRange ('ABCDE123', 10); // второй аргумент больше длины исходной строки  
      alert (A3); // возвращает исходную строку полностью 'ABCDE123'_
