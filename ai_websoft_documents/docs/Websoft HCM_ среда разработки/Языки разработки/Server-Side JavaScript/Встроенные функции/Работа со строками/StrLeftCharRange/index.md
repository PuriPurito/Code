## StrLeftCharRange

Возвращает часть строки, длиной length символов, начиная с первого символа. Если второй аргумент больше количества символов в строке, то исходная строка возвращается полностью.  
Для возвращения определенного количества байтов в строке необходимо использовать функцию StrLeftRange. Если аргумент не может быть преобразован к вещественному числу, функция выдает ошибку.

_Синтаксис:_  
      **StrLeftCharRange (<str>, <length>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Исходная строка.  
      _<length> (обязательный)_  
      Тип: **Целое число**. Количество возвращаемых байтов.

_Возвращаемое значение:_  
      Тип: **Строка**. Результат действия функции.

_Пример:_  
      _A1 = StrLeftCharRange ('Программа WebTutor', 6);  
      alert (A1); // возвращает строку 'Програ'  
      A2 = StrLeftCharRange ('ABCDE123', 5);  
      alert (A2); // возвращает 'ABCDE'  
      A3 = StrLeftCharRange ('ABCDE123', 10); // второй аргумент больше длины исходной строки  
      alert (A3); // возвращает исходную строку полностью 'ABCDE123'_
