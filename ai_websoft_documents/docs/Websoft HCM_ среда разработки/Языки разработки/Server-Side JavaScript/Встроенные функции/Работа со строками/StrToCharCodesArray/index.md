## StrToCharCodesArray

Функция **StrToCharCodesArray** преобразует строку в массив кодов символов (строка разбивается на символы, по каждому из которых определяется соответствующий код _CharCode_).  
См. также StrFromCharCodesArray.

_Синтаксис:_  
      **StrToCharCodesArray (<str>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Исходное значение.

_Возвращаемое значение:_  
      Тип: **Массив целых чисел**. Массив кодов символов, из которых состоит исходная строка. Результат действия функции.

_Пример:_

      _sData1 = ' Программа WebTutor '; // исходное значение  
      aRes1 = StrToCharCodesArray( sData1 ); // выполняется описываемая функция_

      _sStr = ''; // строка для вывода элементов массива  
      for (elem in aRes1) // выводит информацию об элементах массива  
      {  
           sStr = sStr + ' - ' + elem; // формирование строки для вывода элементов массива  
      }  
      alert ( sStr ); // вывод элементов массива_
