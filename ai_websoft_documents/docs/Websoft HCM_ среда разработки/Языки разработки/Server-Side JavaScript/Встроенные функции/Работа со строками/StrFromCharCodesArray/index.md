## StrFromCharCodesArray

Функция **StrFromCharCodesArray** выполняет действия, противоположные функции StrToCharCodesArray, - преобразует массив кодов в строку. Для каждого элемента массива чисел определяется соответствующий символ, и затем все символы объединяются в строку.

_Синтаксис:_  
      **StrFromCharCodesArray (<arrData>)**

_Аргументы:_  
      _<arrData> (обязательный)_  
      Тип: **Массив целых чисел**. Массив числовых кодов символов. Исходные данные.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, сформированная из символов, соответствующих числовым кодам исходного массива. Результат действия функции.

_Пример:_  
      _arrData1 = \[65, 66, 67\]; // исходный массив чисел  
      sRes1 = StrFromCharCodesArray( arrData1 ); // выполняется описываемая функция  
      alert( sRes1 ); // возвращает строку 'ABC'_
