## StrRangePos

Возвращает часть строки от начального до конечного байта.  
_Примечание_ \- Длина строки в байтах может быть больше количества символов, если программа использует кодировку UTF-8. Например, символы латинского алфавита, цифры и пробелы могут занимать один байт, а символы латинского алфавита – 2 байта.  
Для определения части строки в символах необходимо использовать функцию StrCharRangePos.

_Синтаксис:_  
      **StrRangePos (<str>, <pos1>, <pos2>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Исходная строка.  
      _<pos1> (обязательный)_  
      Тип: **Целое число**. Номер начального байта в исходной строке, уменьшенный на единицу (например, для указания первого байта необходимо ввести число 0).  
      _<pos2> (обязательный)_  
      Тип: **Целое число**. Номер конечного байта в исходной строке.

_Возвращаемое значение:_  
      Тип: **Строка**. Часть исходной строки от начального до конечного байта. Результат действия функции.

_Пример:_  
      _A1 = StrRangePos ('Программа WebTutor', 0, 8);  
      alert (A1); // возвращает строку 'Прог'  
      A2 = StrRangePos ('WebTutor 3.5', 0, 1);  
      alert (A2); // возвращает строку 'W'  
      A3 = StrRangePos ('WebTutor 3.5', 1, 2);  
      alert (A3); // возвращает строку 'e'  
      A4 = StrRangePos ('WebTutor 3.5', 7, 8);  
      alert (A4); // возвращает строку 'r'  
      A5 = StrRangePos ('WebTutor 3.5', 0, 3);  
      alert (A5); // возвращает строку 'Web'_
