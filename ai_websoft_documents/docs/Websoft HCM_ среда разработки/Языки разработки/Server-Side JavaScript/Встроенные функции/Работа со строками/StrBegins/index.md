## StrBegins

Производит проверку вхождения одной строки в начало другой строки (начинается ли строка 1 символами из строки 2).

_Синтаксис:_  
      **StrBegins (<str1>, <str2>, <ignoreCase>)**

_Аргументы:_  
      _<str1> (обязательный)_  
      Тип: **Строка**. Строка, в которой проверяется вхождение. Исходное значение.  
      _<str2> (обязательный)_  
      Тип: **Строка**. Искомая строка.  
      _<ignoreCase> (необязательный)_  
      Тип: **Булево**. Отсутствие учета регистра (true – регистр не учитывается, false – регистр учитывается). Если данный аргумент не указан, то поиск вхождения производится с учетом регистра.

_Возвращаемое значение:_  
      Тип: **Булево**. true – соответствие начала строки найдено, false – соответствие начала строки не найдено. Результат действия функции.

_Пример:_  
      _A1 = StrBegins ('ABCDE', 'abc', false); // Проверка вхождения одной строки в начало другой строки с учетом регистра  
      alert (A1); // возвращает false  
      A2 = StrBegins ('ABCDE', 'abc', true); // Проверка вхождения одной строки в начало другой строки без учета регистра  
      alert (A2); // возвращает true  
      A3 = StrBegins ('ABCDE', 'abc'); // Проверка вхождения одной строки в начало другой строки с учетом регистра (аргумент ignoreCase не указан)  
      alert (A3); // возвращает false  
      A4 = StrBegins ('ABCDE', 'pqrs', true); // Проверка вхождения одной строки в начало другой строки без учета регистра  
      alert (A4); // возвращает false_
