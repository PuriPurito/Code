## StrLen

Возвращает длину строки в байтах. Длина строки в байтах может быть больше количества символов, если программа использует кодировку UTF-8. Например, символы латинского алфавита, цифры и пробелы могут занимать один байт, а символы кириллического алфавита – 2 байта. В этом случае, например, строка 'Программа WebTutor' займет 27 байтов (9\*2+1+8).  
Для определения количества символов в строке необходимо использовать функцию StrCharCount.

_Синтаксис:_  
      **StrLen (<str>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Исходная строка.

_Возвращаемое значение:_  
      Тип: **Целое число**. Длина строки в байтах. Результат действия функции.

_Пример:_  
      _A1 = StrLen ('Программа WebTutor'); // определение длины строки в байтах  
      alert (A1); // возвращает количество байтов, занимаемых строкой._
