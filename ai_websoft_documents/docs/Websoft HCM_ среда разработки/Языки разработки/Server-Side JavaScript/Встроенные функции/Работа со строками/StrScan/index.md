## StrScan

Извлекает из исходной строки фрагменты в соответствии с заданным шаблоном. Шаблоны могут содержать элементы:  
**%s** \- вхождение подстроки (возвращаемое);  
**%\*s** - вхождение подстроки (невозвращаемое).  
Если какие-либо фрагменты, соответствующие шаблону, в исходной строке отсутствуют, функция возвращает ошибку с прерыванием выполняемого кода.

_Синтаксис:_  
      **StrScan (<str>, <template>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Исходная строка.  
      _<template> (обязательный)_  
      Тип: **Строка**. Шаблон, заданный в соответствии с правилами, приведенными в описании.

_Возвращаемое значение:_  
      Тип: **Массив строк**. Массив, элементами которого являются отобранные фрагменты исходной строки. Результат действия функции.

_Пример:_  
      _str1='http://news.websoft.ru/vacancy/6496024349381710036.htm';  
      A1 = StrScan( str1, '%\*s/vacancy/%s.htm');  
      vacancyID = A1\[0\];  
      alert (vacancyID); // возвращает строку '6496024349381710036'  
      str='Кто у нас лидер продаж? <p><strong>Лидер продаж:</strong></p>  
      <p><strong>Иванов И.И.</strong></p> Иванов И.И. получает премию.';  
      A2 = StrScan (str, '%\*s<p>%s</p>%\*s<p>%s</p>');  
      alert (A2\[0\]); // возвращает строку '<strong>Лидер продаж:</strong>'  
      alert (A2\[1\]); // возвращает строку '<strong>Иванов И.И.</strong>'_

_Разбор шаблонов:_  
      **_Разбор шаблона '%\*s/vacancy/%s.htm':_**  
           _1) пропуск невозвращаемого фрагмента до первого вхождения подстроки '/vacancy/';  
      2) первое вхождение подстроки '/vacancy/';  
      3) первый возвращаемый фрагмент – от первого вхождения подстроки '/vacancy/' до первого вхождения подстроки '.htm'; в данном примере: строка '6496024349381710036'. Фрагмент передается в результирующий массив (элемент 0);  
      4) первое вхождение подстроки '.htm';_

      **_Разбор шаблона '%\*s<p>%s</p>%\*s<p>%s</p>':_**  
           _1) пропуск невозвращаемого фрагмента до первого вхождения подстроки '<p>';  
      2) первое вхождение подстроки '<p>';  
      3) первый возвращаемый фрагмент – от первого вхождения подстроки '<p>' до первого вхождения подстроки '</p>'; в данном примере: строка '<strong>Лидер продаж:</strong>'. Фрагмент передается в результирующий массив (элемент 0);  
      4) первое вхождение подстроки '</p>';  
      5) пропуск невозвращаемого фрагмента от первого вхождения подстроки '</p>' до второго вхождения подстроки '<p>';  
      6) второе вхождение подстроки '<p>';  
      7) второй возвращаемый фрагмент – от второго вхождения подстроки '<p>' до второго вхождения подстроки '</p>'; в данном примере: строка '<strong>Иванов И.И.</strong>'. Фрагмент передается в результирующий массив (элемент 1);  
      8) второе вхождение подстроки '</p>'._
