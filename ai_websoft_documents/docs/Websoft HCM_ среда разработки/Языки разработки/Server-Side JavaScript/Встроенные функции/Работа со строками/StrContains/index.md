## StrContains

Проверяет, содержит ли строка другую строку в качестве подстроки.

_Синтаксис:_  
      **StrContains (<str1>, <str2>, <ignoreCase>)**

_Аргументы:_  
      _<str1> (обязательный)_  
      Тип: **Строка**. Строка, в которой проверяется вхождение. Исходное значение.  
      _<str2> (обязательный)_  
      Тип: **Строка**. Искомая строка.  
      _<ignoreCase> (необязательный)_  
      Тип: **Булево**. Отсутствие учета регистра (true – регистр не учитывается, false – регистр учитывается). Если данный аргумент не указан, то поиск вхождения производится с учетом регистра.

_Возвращаемое значение:_  
      Тип: **Булево**. _true_ – вхождение искомой строки найдено, _false_ – вхождение искомой строки не найдено. Результат действия функции.

_Пример:_  
      _A1 = StrContains ('ABCDE', 'bcd', false); // Проверка вхождения второй строки в первую с учетом регистра  
      alert (A1); // возвращает false  
      A2 = StrContains ('ABCDE', 'bcd', true); // Проверка вхождения второй строки в первую без учета регистра  
      alert (A2); // возвращает true  
      A3 = StrContains ('ABCDE', 'bcd'); // Проверка вхождения второй строки в первую с учетом регистра (аргумент ignoreCase не указан)  
      alert (A3); // возвращает false  
      A4 = StrContains ('ABCDE', 'pqrs', true); // Проверка вхождения второй строки в первую без учета регистра  
      alert (A4); // возвращает false_
