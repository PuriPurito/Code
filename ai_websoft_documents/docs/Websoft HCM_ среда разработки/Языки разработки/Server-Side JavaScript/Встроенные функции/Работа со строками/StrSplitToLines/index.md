## StrSplitToLines

Функция **StrSplitToLines** преобразует строку в массив абзацев, которые были разделены в первоначальной строке символами '\\n'.

_Синтаксис:_  
      **StrSplitToLines (<str>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Исходное значение.

_Возвращаемое значение:_  
      Тип: **Массив строк**. Массив абзацев. Результат действия функции.

_Пример:_  
      _sData1 = 'Программа WebTutor \\n - в настоящее время носит название WebSoft HCM'; // исходное значение  
      sRes1 = StrSplitToLines( sData1 ); // выполняется описываемая функция  
      alert (sRes1 \[0\]); // возвращает строку 'Программа WebTutor '   
      alert (sRes1 \[1\]); // возвращает строку ' - в настоящее время носит название WebSoft HCM'_
