## StrNonTitleCase

Преобразует первую букву строки к нижнему регистру. Если строка уже приведена к описанному виду или если она не может быть приведена к такому виду, то строка возвращается без изменений.

_Синтаксис:_  
      **StrNonTitleCase (<str>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Исходная строка.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, первый символ которой преобразован к нижнему регистру. Результат действия функции.

_Пример:_  
      _A1 = StrNonTitleCase ('Программа работает');  
      alert (A1); // возвращает строку 'программа работает'  
      A2 = StrNonTitleCase ('программа работает');  
      alert (A2); // возвращает строку 'программа работает'  
      A3 = StrNonTitleCase ('123');  
      alert (A3); // возвращает строку '123'_
