## StrMatchesMultiPattern

Функция аналогична StrMatchesPattern, но может выполнять поиск по нескольким маскам, включенным в шаблон. Маски перечисляются в шаблоне через запятую.  
Маска поиска использует символы '\*', заменяющие любое количество любых символов. Например, маске поиска 'aaa\*bbb' соответствуют следующие сочетания символов в составе исходной строки: 'aaacccbbb', 'aaa bbb', 'aaaabcdebbb' и т.д.

_Синтаксис:_  
      **StrMatchesMultiPattern (<str>, <pattern>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Исходная строка.  
      _<pattern> (обязательный)_  
      Тип: **Строка**. Шаблон, содержащий несколько масок поиска, использующих символ '\*' и перечисленных через запятую.

_Возвращаемое значение:_  
      Тип: **Булево**. Возвращаемое значение равно true, если исходная строка содержит в качестве подстроки любую из масок, перечисленных в шаблоне <pattern>. В противном случае функция возвращает значение false. Результат действия функции.

_Пример:_  
      _A1 = StrMatchesMultiPattern ('aaaabcdebbb', 'aaa\*bbb, ccc\*ddd\*eee');  
      alert (A1); // возвращает значение true  
      A2 = StrMatchesMultiPattern ('aabcdebbb', 'aaa\*bbb, ccc\*ddd\*eee');  
      alert (A2); // возвращает значение false_
