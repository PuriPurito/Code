## UnifySpaces

Заменяет повторяющиеся последовательности символов пробела, перевода строк и табуляции в строке на одиночные пробелы. Если указанные повторяющиеся последовательности символов в исходной строке отсутствуют, то функция возвращает исходную строку без изменения.

_Синтаксис:_  
      **UnifySpaces (<str>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Исходная строка.

_Возвращаемое значение:_  
      Тип: **Строка**. Копия исходной строки, в которой повторяющиеся последовательности символов пробела, перевода строк и табуляции заменены на одиночные пробелы. Результат действия функции.

_Пример:_  
      _A1 = UnifySpaces ('Программа        WebTutor'); // строка содержит повторяющуюся последовательность пробелов  
      alert (A1); // возвращает строку 'Программа WebTutor' (повторяющаяся последовательность пробелов заменена на одиночный пробел)_
