## StrCharRangePos

Возвращает часть строки от начального до конечного символа.  
Для определения части строки в байтах необходимо использовать функцию StrRangePos.

_Синтаксис:_  
      **StrCharRangePos (<str>, <pos1>, <pos2>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Исходная строка.  
      _<pos1> (обязательный)_  
      Тип: **Целое число**. Номер начального символа в исходной строке, уменьшенный на единицу (например, для указания первого символа необходимо ввести число 0).  
      _<pos2> (обязательный)_  
      Тип: **Целое число**. Номер конечного символа в исходной строке.

_Возвращаемое значение:_  
      Тип: **Строка**. Часть исходной строки от начального до конечного символа. Результат действия функции.

_Пример:_  
      _A1 = StrCharRangePos ('Программа WebTutor', 0, 8);  
      alert (A1); // возвращает строку 'Программ'  
      A2 = StrCharRangePos ('WebTutor 3.5', 0, 1);  
      alert (A2); // возвращает строку 'W'  
      A3 = StrCharRangePos ('WebTutor 3.5', 1, 2);  
      alert (A3); // возвращает строку 'e'  
      A4 = StrCharRangePos ('WebTutor 3.5', 7, 8);  
      alert (A4); // возвращает строку 'r'  
      A5 = StrCharRangePos ('WebTutor 3.5', 0, 3);  
      alert (A5); // возвращает строку 'Web'_
