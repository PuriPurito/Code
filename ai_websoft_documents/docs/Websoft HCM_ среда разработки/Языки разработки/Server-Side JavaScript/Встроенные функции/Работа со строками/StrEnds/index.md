## StrEnds

Производит проверку вхождения одной строки в конец другой строки (оканчивается ли строка 1 символами из строки 2).

_Синтаксис:_  
      **StrEnds (<str1>, <str2>, <ignoreCase>)**

_Аргументы:_  
      _<str1> (обязательный)_  
      Тип: **Строка**. Строка, в которой проверяется вхождение. Исходное значение.  
      _<str2> (обязательный)_  
      Тип: **Строка**. Искомая строка.  
      _<ignoreCase> (необязательный)_  
      Тип: **Булево**. Отсутствие учета регистра (_true_ – регистр не учитывается, _false_ – регистр учитывается). Если данный аргумент не указан, то поиск вхождения производится с учетом регистра.

_Возвращаемое значение:_  
      Тип: **Булево**. _true_ – соответствие конца строки найдено, _false_ – соответствие конца строки не найдено. Результат действия функции.

_Пример:_  
      _A1 = StrEnds ('ABCDE', 'cde', false); // Проверка вхождения одной строки в конец другой строки с учетом регистра  
      alert (A1); // возвращает false  
      A2 = StrEnds ('ABCDE', 'cde', true); // Проверка вхождения одной строки в конец другой строки без учета регистра  
      alert (A2); // возвращает true  
      A3 = StrEnds ('ABCDE', 'cde'); // Проверка вхождения одной строки в конец другой строки с учетом регистра (аргумент ignoreCase не указан)  
      alert (A3); // возвращает false  
      A4 = StrEnds ('ABCDE', 'pqrs', true); // Проверка вхождения одной строки в конец другой строки без учета регистра  
      alert (A4); // возвращает false_
