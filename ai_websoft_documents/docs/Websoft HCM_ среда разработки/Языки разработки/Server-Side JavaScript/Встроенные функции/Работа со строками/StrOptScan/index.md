## StrOptScan

Функция **StrOptScan** аналогична StrScan. Функция извлекает из исходной строки фрагменты в соответствии с заданным шаблоном. Если в исходной строке отсутствуют какие-либо фрагменты, соответствующие шаблону, функция возвращает значение undefined.

_Синтаксис:_  
      **StrOptScan (<str>, <template>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Исходное значение.  
      <template> (обязательный)  
      Тип: **Строка**. Шаблон, заданный в соответствии с правилами, приведенными в описании.

_Возвращаемое значение:_  
      Тип: **Массив строк**. Массив, элементами которого являются отобранные фрагменты исходной строки, или значение _undefined_. Результат действия функции.

_Пример:_

      _sStr1='http://news.websoft.ru/vacancy/6496024349381710036.htm';  
      **sRes1 = StrOptScan(sStr1, '%\*s/vacancy/%s.htm');** // выполняется описываемая функция  
      iVacancyID = sRes1\[0\];  
      alert (iVacancyID); // возвращает строку '6496024349381710036'_

      _sStr2='Кто у нас лидер продаж? <p><strong>Лидер продаж:</strong></p>  
      <p><strong>Иванов И.И.</strong></p> Иванов И.И. получает премию.';  
      **sRes2 = StrScan (sStr2, '%\*s<p>%s</p>%\*s<p>%s</p>');**  
      alert (sRes2\[0\]); // возвращает строку '<strong>Лидер продаж:</strong>'  
      alert (sRes2\[1\]); // возвращает строку '<strong>Иванов И.И.</strong>'_

      _**sRes3 = StrOptScan(sStr2, '%\*s/vacancy');** // ошибка в выполнении функции (невозможно извлечь фрагменты в соответствии с шаблоном)  
      if (IsArray (sRes3) == false) // проверка, является ли результат массивом   
           alert (sRes3); // возвращает значение undefined  
      else alert (sRes3\[0\]);_
