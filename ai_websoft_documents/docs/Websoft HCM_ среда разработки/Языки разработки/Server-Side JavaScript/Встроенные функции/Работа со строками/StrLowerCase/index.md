## StrLowerCase

Переводит все символы строки в нижний регистр.

_Синтаксис:_  
      **StrLowerCase (<str>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Исходная строка.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, преобразованная к нижнему регистру. Результат действия функции.

_Пример:_  
      _A1 = StrLowerCase ('Программа WebTutor');  
      alert (A1); // возвращает строку 'программа webtutor'_
