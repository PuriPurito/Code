## UnifyPhones

Приводит номера телефонов к стандартному виду. Экспериментальная функция.

_Синтаксис:_  
      **UnifyPhones (<str>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Строковое выражение с исходным номером телефона.

_Возвращаемое значение:_  
      Тип: **Строка**. Строковое выражение с номером телефона в стандартном формате. Результат действия функции.

_Пример:_  
      `_numStandard = UnifyPhones ( num );_`
