## DropXQueryCache

Очищает кэш от запроса XQuery. При отсутствии аргумента очищает кэш от всех запросов XQuery.   
Если функция вызывается с параметром (url документа), то из кеша будут удалены запросы, связанные с этим документом.   
Экспериментальная функция.

_Синтаксис:_  
      **DropXQueryCache (\[<arg1>\])**

_Аргументы:_  
      _<arg1> (необязательный)_  
      Тип: **Строка**. Url запроса XQuery.

_Возвращаемое значение:_  
      Производится очистка кэша. Возвращаемое значение отсутствует.

_Пример:_  
      `_DropXQueryCache ( event.ObjectUrl );         DropXQueryCache ();_`
