## DropDbPackage

Очищает кэш от загруженного зашифрованного модуля.

_Синтаксис:_  
      **DropDbPackage (<arg1>)**

_Аргументы:_  
      _<arg1> (обязательный)_  
      Тип: **Строка**. Url зашифрованного модуля (XFP-файла).

_Возвращаемое значение:_  
      Производится очистка кэша. Возвращаемое значение отсутствует.

_Пример:_  
      `_DropDbPackage ('x-local://wtl.xfp');_`
