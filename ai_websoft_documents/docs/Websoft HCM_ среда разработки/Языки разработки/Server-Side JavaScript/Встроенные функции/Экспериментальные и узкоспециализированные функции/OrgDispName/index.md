## OrgDispName

Возвращает обработанное условное наименование юридического лица, предназначенное для показа пользователю.

_Синтаксис:_  
      **OrgDispName (<orgName>\[, <orgShortName>\])**

_Аргументы:_  
      _<orgName> (обязательный)_  
      Тип: **Строка**. Полное наименование юридического лица.  
      _<orgShortName> (необязательный)_  
      Тип: **Строка**. Сокращенное наименование юридического лица.

_Возвращаемое значение:_  
      Тип: **Строка**. Обработанное условное наименование юридического лица. Результат действия функции.

_Пример:_  
      `_orgName1 = OrgDispName ( orgName, orgShortName );         name = OrgDispName ( full_name );_`
