## ReportToHtml

Формирование отчета в формате HTML.  
Экспериментальная функция.

_Синтаксис:_  
      **ReportToHtml (<str>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Строковое выражение, содержащее отчет.

_Возвращаемое значение:_  
      Тип: **Строка**. Строковое выражение, содержащее результирующий отчет в формате HTML. Результат действия функции.

_Пример:_  
      `_switch ( TopElem.export_type )         {               case '.rtf':                     sRep = ReportToRtf( sRep );                     break;                             default:                     sRep = ReportToHtml( sRep );                     break;         }_`
