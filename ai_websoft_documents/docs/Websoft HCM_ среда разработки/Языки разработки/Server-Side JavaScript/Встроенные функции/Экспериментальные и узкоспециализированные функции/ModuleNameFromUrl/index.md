## ModuleNameFromUrl

Выдает наименование модуля, в котором находится файл, по заданному url со схемой x-app.

_Синтаксис:_  
      **ModuleNameFromUrl (<url>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Url файла. Исходное значение.

_Возвращаемое значение:_  
      Тип: **Строка**. Наименование модуля, в котором находится заданный файл. Результат действия функции.

_Пример:_  
       `_moduleName1 = ModuleNameFromUrl( 'x-app://base1/base1_view_generic_catalog.xms'  );          alert ( moduleName1 ); // вернет 'base1'_`
