## SimulateCrash

Функция вызывает падение приложения.  
Используется для тестирования целостности данных к падению сервера.

_Синтаксис:_  
      **SimulateCrash()**

_Аргументы:_  
      Функция вызывается без аргументов.

_Возвращаемое значение:_  
      Производится завершение работы приложения. Возвращаемое значение отсутствует.

_Пример:_  
      `_SimulateCrash();_`
