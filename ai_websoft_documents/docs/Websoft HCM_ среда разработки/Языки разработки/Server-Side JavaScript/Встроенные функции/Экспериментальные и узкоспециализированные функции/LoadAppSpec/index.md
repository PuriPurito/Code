## LoadAppSpec

Загружает приложение по имени корневого модуля, не открывая его главную страницу.  
Функция используется в редких случаях - например, для выбора запускаемого приложения при старте.

_Синтаксис:_  
      **LoadAppSpec (<mainModuleName>)**

_Аргументы:_  
      _<mainModuleName> (обязательный)_  
      Тип: **Строка**. Имя корневого модуля.

_Возвращаемое значение:_  
      Производится загрузка приложения. Возвращаемое значение отсутствует.

_Пример:_  
      `_LoadAppSpec( 'rcr' );_`
