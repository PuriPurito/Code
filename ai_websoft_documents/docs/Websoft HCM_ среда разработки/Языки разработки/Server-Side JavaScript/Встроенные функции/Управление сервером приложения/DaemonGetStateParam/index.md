## DaemonGetStateParam

Возвращает значение параметра, обозначающее текущий статус задачи, выполняемой при запуске сервера (например, перестройка фалов каталога или конвертация данных из предыдущей версии программы).  
Серверная функция. Действует в конфигураторе сервера (в том случае, если конфигуратор запущен на сервере).

_Синтаксис:_  
      **DaemonGetStateParam (<serverID>, <param>)**

_Аргументы:_  
      _<serverID> (обязательный)_  
      Тип: **Строка**. Идентификатор сервера.  
      _<param> (обязательный)_  
      Тип: **Строка**. Значение параметра.  
      _Поддерживаемые значения:_  
      **'CurTask'** – вызов функции StartModalTask на сервере.  
      **'CurMsg'** – вызов функции ModalTaskMsg на сервере.

_Возвращаемое значение:_  
      Тип: **Строка** . Текущий статус задачи, выполняемой при запуске сервера. Результат действия функции.

_Пример:_  
      `_serverState = DaemonGetStateParam ( serverID, 'CurTask' );_`
