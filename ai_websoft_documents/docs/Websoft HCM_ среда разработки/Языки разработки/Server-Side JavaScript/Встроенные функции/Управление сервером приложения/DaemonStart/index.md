## DaemonStart

Включает сервер, указанный в качестве аргумента.  
Серверная функция. Действует в конфигураторе сервера (в том случае, если конфигуратор запущен на сервере).

_Синтаксис:_  
      **Real (<arg>)**

_Аргументы:_  
      _<serverID> (обязательный)_  
      Тип: **Строка**. Идентификатор сервера.

_Возвращаемое значение:_  
      Производится включение сервера. Возвращаемое значение отсутствует.

_Пример:_  
      `_if ( DaemonGetState ( serverID ) == 0 ) // если сервер с идентификационным номером serverID выключен         {               alert ( DaemonGetState ( serverID ) ); // выводится значение 0               DaemonStart ( serverID ); // сервер запускается         }         alert ( DaemonGetState ( serverID ) );_`
