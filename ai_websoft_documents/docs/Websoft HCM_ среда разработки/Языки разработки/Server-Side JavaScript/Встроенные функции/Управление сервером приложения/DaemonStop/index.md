## DaemonStop

Выключает сервер, указанный в качестве аргумента.  
Серверная функция. Действует в конфигураторе сервера (в том случае, если конфигуратор запущен на сервере).

_Синтаксис:_  
      **DaemonStop (<serverID>)**

_Аргументы:_  
      _<serverID> (обязательный)_  
      Тип: **Строка**. Идентификатор сервера.

_Возвращаемое значение:_  
      Производится выключение сервера. Возвращаемое значение отсутствует.

_Пример:_  
      `_if ( DaemonGetState ( serverID ) == 1 ) // если сервер с идентификационным номером serverID включен         {               alert ( DaemonGetState ( serverID ) ); // выводится значение 1               DaemonStop ( serverID ); // сервер выключается         }_`
