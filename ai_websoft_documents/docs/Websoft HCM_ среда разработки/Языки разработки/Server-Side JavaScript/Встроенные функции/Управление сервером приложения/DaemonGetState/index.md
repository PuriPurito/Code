## DaemonGetState

Определяет статус зарегистрированного сервера приложения (службы Windows).  
Серверная функция. Действует в конфигураторе сервера (в том случае, если конфигуратор запущен на сервере).

_Синтаксис:_  
      **DaemonGetState (<serverID>)**

_Аргументы:_  
      _<serverID> (обязательный)_  
      Тип: **Строка**. Идентификатор сервера.

_Возвращаемое значение:_  
      Тип: **Целое число** . Результат действия функции.  
      _Поддерживаемые значения статуса:_  
      **0** - сервер выключен;  
      **1** - сервер включен;  
      **2** - сервер начинает работу;  
      **3** - сервер завершает работу.

_Пример:_  
      `_serverState = DaemonGetState (serverID );                 if ( DaemonGetState ( serverID ) == 0 ) // если сервер с идентификационным номером serverID выключен         {               alert ( DaemonGetState ( serverID ) ); // выводится значение 0               DaemonStart ( serverID ); // сервер запускается         }         alert ( DaemonGetState ( serverID ) );_`
