## RValue

Возвращает скалярное значение аргумента, если в качестве аргумента передан объект. Если передано скалярное значение, то функция возвращает то же самое значение.   
Функция может быть использована для отмены наследования при создании новых объектов на основе базовых.

_Синтаксис:_  
     **RValue (<arg>)**

_Аргументы:_  
     _<arg> (обязательный)_  
     Тип: **Объект, строка, целое или действительное число** и др. Исходное значение.

_Возвращаемое значение:_  
     Тип: **Строка, целое или действительное число** и др. Скалярное значение аргумента. Результат действия функции.

_Пример:_  
     _doc = tools.open\_doc(3050438886317795229).TopElem; // создание переменной для работы с атрибутами базового объекта (сотрудник)  
     // 3050438886317795229 - id базового объекта (сотрудника) (здесь нужно будет вставить id своего тестового сотрудника)  
     alert (doc.fullname); // для проверки - возвращает ФИО сотрудника, с id = 3050438886317795229  
     doc.code = "15"; // присвоение базовому объекту значения кода "15"  
     obj1 = doc.code; // создание объекта 1 на основе базового объекта doc (объект 1 наследует базовому объекту)  
     obj2 = RValue (doc.code); // создание объекта 2 на основе базового объекта doc с помощью функции RValue (объект 2 НЕ наследует базовому объекту)   
     alert (obj1); // возвращает значение "15"  
     alert (obj2); // возвращает значение "15"  
     doc.code = "34"; // изменение значения кода базового объекта с "15" на "34"  
     alert (obj1); // значение кода объекта 1 изменилось вслед за кодом базового объекта   
     alert (obj2); // значение кода объекта 2, созданного с использованием функции RValue, не изменилось_
