## Особенности работы с числовыми данными с плавающей точкой (двойной точности)

**1\. Особенности хранения в системе числовых данных с плавающей точкой (двойной точности).**

Числовые данные с плавающей точкой (двойной точности) типа _real_ хранятся в системе в 8 байтах и поддерживают не более 15 знаков после десятичной точки. Поэтому не рекомендуется использовать в системе числовые значения, имеющие более 15 знаков после десятичной точки. 

  
**2\. Особенности преобразования числовых данных с плавающей точкой в строку.**

Преобразование данных типа real в строку зависит от значения параметра **REAL-PRECISION**, определяемого в файле xHttp.ini.  
Этот параметр указывает максимальное количество знаков после десятичной точки, отображаемое при преобразовании в строку (например, при использовании функций _StrReal( a )_ или _alert( a )_ ).  
Если значение параметра **REAL-PRECISION** не определено, то по умолчанию оно устанавливается равным 6.

Параметр **REAL-PRECISION** определяется отдельно для сервера и для клиента, и соответственно учитывается для преобразований на сервере и на клиенте.  
Например, если на сервере (в папке WebSoftServer) значение параметра **REAL-PRECISION** устанавливается равным 10, а на клиенте (в папке WebSoftAdmin) оно не определено, то преобразование данных типа real в строку на сервере выводит не более 10 знаков, а на клиенте - не более 6 знаков.

Подобный порядок преобразования действует также в случае неявного приведения данных.

  
Внимание! Если пользователь указал в программном коде большее количество знаков после десятичной точки N (_StrReal( a, N )_ ), чем это определено ограничениями хранения типа данных real и значением параметра **REAL-PRECISION**,  система будет работать следующим образом:  
а) Если N больше значения параметра **REAL-PRECISION**, но меньше или равно 15, то результат будет содержать N коррекных знаков после десятичной точки.  
б) Если N больше 15, то результат должен содержать 15 коррекных знаков после десятичной точки, а остальные знаки будут отображать случайное значение битовых ячеек.

  
**3\. Особенности арифметических действий с числовыми данными с плавающей точкой** 

При выполнении арифметических действий с числовыми данными с плавающей точкой результат определяется ограничениями хранения типа данных real (15 знаков после десятичной точки) и не будет зависеть от значения параметра **REAL-PRECISION**.
