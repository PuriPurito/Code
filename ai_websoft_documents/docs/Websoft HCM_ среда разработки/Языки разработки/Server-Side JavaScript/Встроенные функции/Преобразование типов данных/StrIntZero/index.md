## StrIntZero

Преобразует числовой аргумент в строку в целочисленном формате (аналогично функции StrInt), но при нулевом аргументе (с учетом округления) возвращает значение '-'. Округление исходного значения производится в меньшую сторону.  
Если аргумент не может быть преобразован к целому неотрицательному числу, функция выдает ошибку.

_Синтаксис:_  
      **StrIntZero (<arg>\[, <digitsNum>\[, <addGroupDelim>\]\])**

_Аргументы:_  
      _<arg> (обязательный)_  
      Тип: **Целое или вещественное неотрицательное число**. Исходное значение.  
      _<digitsNum> (необязательный)_  
      Тип: **Целое неотрицательное число**. Минимальное число символов в строке. Недостающие символы компенсируются нулями перед числом. Применяется, если аргумент <arg> больше или равен 1.  
      _<addGroupDelim> (необязательный)_  
      Тип: **Булево**. При указании значения true тысячные разряды в строке разделяются пробелами. Применяется, если аргумент <arg> больше или равен 1.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая целое неотрицательное число или значение '-' при аргументе, меньшем 1. Результат действия функции.

_Пример:_  
      _A1 = StrIntZero (11500);  
      alert (A1); // возвращает '11500'  
      A2 = StrIntZero (11500, 6);  
      alert (A2); // возвращает '011500'  
      A3 = StrIntZero (11500, 0, true);  
      alert (A3); // возвращает '11 500'  
      A4 = StrIntZero (11500.99);  
      alert (A4); // возвращает '11500'  
      A5 = StrIntZero (0);  
      alert (A5); // возвращает '-'  
      A6 = StrIntZero ('1000');  
      alert (A6); // недопустима обработка строковых значений (возвращает ошибку с прерыванием выполняемого кода)_
