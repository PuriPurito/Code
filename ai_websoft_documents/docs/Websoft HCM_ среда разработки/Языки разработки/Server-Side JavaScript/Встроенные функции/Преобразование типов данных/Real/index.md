## Real

Преобразует значение аргумента к действительному числу.  
Если аргумент не может быть преобразован к действительному числу, функция выдает ошибку.  
Рекомендуется вместо функции **Real** использовать функцию **OptReal**.  
См. также статью "Особенности работы с числовыми данными с плавающей точкой (двойной точности)".

_Синтаксис:_  
     **Real (<arg>)**

_Аргументы:_  
     _<arg> (обязательный)_  
     Тип: **Целое, действительное число или строка** (строка, содержащая число). Исходное значение.

_Возвращаемое значение:_  
     Тип: **Действительное число**. Результат действия функции.

_Пример:_  
     _A1 = Real (123);  
     alert (A1); // возвращает 123  
     A2 = Real (123.55);  
     alert (A2); // возвращает 123.55  
     A3 = Real (-123.55);  
     alert (A3); // возвращает -123.55  
     A4 = Real ('123.55');  
     alert (A4); // возвращает 123.55  
     A5 = Real ('.123Привет, мир!');  
     alert (A5); // возвращает 0.123  
     A6 = Real ('Привет, мир!'); // возвращает ошибку с прерыванием выполняемого кода  
     alert (A6);_
