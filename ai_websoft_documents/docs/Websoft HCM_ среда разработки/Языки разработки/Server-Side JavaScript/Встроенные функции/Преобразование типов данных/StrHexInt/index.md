## StrHexInt

Преобразует значение аргумента в строку, содержащую значение в 16-значном 16-ричном формате (64 бита). Округление исходного значения производится в меньшую сторону.  
Если аргумент выходит за пределы допустимых значений или имеет формат строки, функция выдает ошибку.

_Синтаксис:_  
     **StrHexInt (<arg>)**

_Аргументы:_  
      _<arg> (обязательный)_  
      Тип: **Целое или вещественное неотрицательное число**. Число в диапазоне от 0 до 18446744073709551615 (16^16-1). Исходное значение.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая целое шестнадцатизначное шестнадцатеричное неотрицательное число. Результат действия функции.

_Пример:_  
      _A1 = StrHexInt (123);  
      alert (A1); // возвращает '000000000000007B'  
      A2 = StrHexInt (123.55);  
      alert (A2); // возвращает '000000000000007B'  
      A3 = StrHexInt (18446744073709551614);  
      alert (A3); // возвращает 'FFFFFFFFFFFFFFFE'  
      A4 = StrHexInt (18446744073709551615);  
      alert (A4); // возвращает 'FFFFFFFFFFFFFFFF'  
      A5 = StrHexInt (18446744073709551616);  
      alert (A5); // некорректно обрабатывает числа, выходящие за пределы допустимых значений (возвращает ошибочное значение без прерывания выполняемого кода)  
      A6 = StrHexInt (-123);  
      alert (A6); // некорректно обрабатывает отрицательные числа (возвращает ошибочное значение без прерывания выполняемого кода)  
      A7 = StrHexInt ('123.55');  
      alert (A7); // недопустима обработка строковых значений (возвращает ошибку с прерыванием выполняемого кода)_
