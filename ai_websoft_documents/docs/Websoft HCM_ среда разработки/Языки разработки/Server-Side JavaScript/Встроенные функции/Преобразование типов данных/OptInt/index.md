## OptInt

Преобразует значение аргумента к целому неотрицательному числу (округление производится в меньшую сторону).  
Если основной аргумент не может быть преобразован к целому неотрицательному числу, функция возвращает второй аргумент (не обязательно числового типа) или значение _undefined_ без прерывания выполняемого кода (если второй аргумент отсутствует).   
Использование функции **OptInt** предпочтительнее функции Int.  
Для работы с целыми отрицательными числами рекомендуется использовать действительные числа (например, функцию **OptReal**).

_Синтаксис:_  
     **Opt****Int (<arg1>\[, <arg2>\])**

_Аргументы:_  
     _<arg1> (обязательный)_  
     Тип: **Целое, вещественное неотрицательное число или строка** (строка, содержащая целое неотрицательное число). Основной аргумент. Исходное значение.  
     _<arg2> (необязательный)_  
     Тип: **Строка, Число, Булево** или др. Второй аргумент. 

Использование булевой переменной в качестве первого аргумента возвращает значение _undefined_ без прерывания выполняемого кода.  

_Возвращаемое значение:_  
     Тип: **Целое неотрицательное число** или тип второго аргумента. Результат действия функции. 

_Пример 1:_  
     _A1 = OptInt (123);  
     alert (A1); // возвращает 123  
     A2 = OptInt (123.55);  
     alert (A2); // возвращает 123  
     A3 = OptInt (-123);  
     alert (A3); // некорректно обрабатывает отрицательные целые числа (возвращает ошибочное значение без прерывания выполняемого кода)  
     A4 = OptInt (-123.55);  
     alert (A4); // некорректно обрабатывает отрицательные вещественные числа (возвращает ошибочное значение без прерывания выполняемого кода)  
     A5 = OptInt ('123');  
     alert (A5); // возвращает 123  
     A6 = OptInt ('1.123');  
     alert (A6); // возвращает undefined, так как строка не содержит целое неотрицательное число_  
     _A7 = OptInt ('1.123Привет, мир!');  
     alert (A7); // возвращает undefined_  
     _A8 = OptInt ('Привет, мир!');   
     alert (A8); // возвращает undefined  
     A9 = OptInt ('sss', 123.55);   
     alert (A9); // возвращает 123  
     A10 = OptInt ('sss', 'sss1');  
     alert (A10); // возвращает 'sss1'_

_Пример 2 (преобразование строка с 16-ричным значением в 10-ричное целое число):_  
     _iData10 = OptInt('0xFF'); // строка с 16-ричным значением преобразуется в целое число 255  
     alert (iData10); // выводит 255_
