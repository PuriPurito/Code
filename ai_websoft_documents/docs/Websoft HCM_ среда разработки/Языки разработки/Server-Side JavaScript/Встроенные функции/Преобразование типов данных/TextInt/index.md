## TextInt

Преобразует числовое значение аргумента в словесное строковое представление (только для русскоязычной версии). Округление исходного значения производится в меньшую сторону.  
Если аргумент не может быть преобразован к целому неотрицательному числу, функция выдает ошибку.

_Синтаксис:_  
      **TextInt (<arg>\[, <gender>\])**

_Аргументы:_  
      _<arg> (обязательный)_  
      Тип: **Целое или вещественное неотрицательное число**. Исходное значение.  
      _<gender> (необязательный)_  
      Тип: **Целое число (0 или 1)**. Род словесного представления числа (0 – мужской род, 1 – женский род). При отсутствии аргумента <gender> словесное строковое представление отображается в мужском роде.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая словесное представление целого неотрицательного числа. Результат действия функции.

_Пример:_  
      _A1 = TextInt(121);  
      alert (A1); // возвращает 'сто двадцать один'  
      A2 = TextInt( 121, 1 );  
      alert (A2); // возвращает 'сто двадцать одна'  
      A3 = TextInt(121.99);  
      alert (A3); // возвращает 'сто двадцать один'  
      A4 = TextInt(0);  
      alert (A4); // возвращает 'ноль'  
      A5 = TextInt(0, 1);  
      alert (A5); // возвращает 'ноль'  
      A6 = TextInt(-121.99);  
      alert (A6); // некорректно обрабатывает отрицательные числа (возвращает ошибочное (пустое) значение без прерывания выполняемого кода)_
