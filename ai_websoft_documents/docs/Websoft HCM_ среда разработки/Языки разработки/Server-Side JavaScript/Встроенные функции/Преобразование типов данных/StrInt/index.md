## StrInt

Преобразует числовой аргумент в строку в целочисленном формате. Округление исходного значения производится в меньшую сторону.   
Данная функция также преобразует 16-ричное число в десятичное в строковом формате.  
Если аргумент не может быть преобразован к целому неотрицательному числу, функция выдает ошибку.

_Синтаксис:_  
      **StrInt (<arg>\[, <digitsNum>\[, <addGroupDelim>\]\])**

_Аргументы:_  
      _<arg> (обязательный)_  
      Тип: Целое или вещественное неотрицательное число. Исходное значение.  
      _<digitsNum> (необязательный)_  
      Тип: Целое неотрицательное число. Минимальное число символов в строке. Недостающие символы компенсируются нулями перед числом.  
      _<addGroupDelim> (необязательный)_  
      Тип: **Булево**. При указании значения true тысячные разряды в строке разделяются пробелами.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая целое неотрицательное число. Результат действия функции.

_Пример:_  
      _A1 = StrInt (11500);  
      alert (A1); // возвращает '11500'  
      A2 = StrInt (11500, 6);  
      alert (A2); // возвращает '011500'  
      A3 = StrInt (11500, 0, true);  
      alert (A3); // возвращает '11 500'  
      A4 = StrInt (11500.99);  
      alert (A4); // возвращает '11500'  
      A5 = StrInt (-11500);  
      alert (A5); // некорректно обрабатывает отрицательные числа (возвращает ошибочное значение без прерывания выполняемого кода)  
      A6 = StrInt ('1000');  
      alert (A6); // недопустима обработка строковых значений (возвращает ошибку с прерыванием выполняемого кода)_
