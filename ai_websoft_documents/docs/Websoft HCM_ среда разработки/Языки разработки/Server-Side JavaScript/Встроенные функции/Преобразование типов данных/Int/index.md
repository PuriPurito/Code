## Int

Преобразует значение аргумента к целому неотрицательному числу (округление производится в меньшую сторону).  
Если аргумент не может быть преобразован к целому неотрицательному числу, функция выдает ошибку.  
Рекомендуется вместо функции **Int** использовать функцию **OptInt**.  
Для работы с целыми отрицательными числами рекомендуется использовать действительные числа (например, функцию **OptReal**).

_Синтаксис:_  
     **Int (<arg>)**

_Аргументы:_  
     _<arg> (обязательный)_  
     Тип: **Целое, вещественное неотрицательное число или строка** (строка, содержащая целое неотрицательное число). Исходное значение.

Использование булевой переменной в качестве аргумента приводит к сообщению: "Неизвестная ошибка" и к остановке выполнения кода. 

_Возвращаемое значение:_  
     Тип: **Целое неотрицательное число**. Результат действия функции. 

_Пример 1:_  
     _A1 = Int (123);  
     alert (A1); // возвращает 123  
     A2 = Int (123.55);  
     alert (A2); // возвращает 123  
     A3 = Int (-123);  
     alert (A3); // некорректно обрабатывает отрицательные целые числа (возвращает ошибочное значение без прерывания выполняемого кода)  
     A4 = Int (-123.55);  
     alert (A4); // некорректно обрабатывает отрицательные вещественные числа (возвращает ошибочное значение без прерывания выполняемого кода)  
     A5 = Int ('123');  
     alert (A5); // возвращает 123  
     A6 = Int ('1.123Привет, мир!'); // возвращает ошибку с прерыванием выполняемого кода  
     alert (A6);   
     A7 = Int ('Привет, мир!'); // возвращает ошибку с прерыванием выполняемого кода  
     alert (A7);_ 

_Пример 2 (преобразование строки с 16-ричным значением в 10-ричное целое число):_  
     _iData10 = Int('0xFF'); // строка с 16-ричным значением преобразуется в целое число 255  
     alert (iData10); // выводит 255_
