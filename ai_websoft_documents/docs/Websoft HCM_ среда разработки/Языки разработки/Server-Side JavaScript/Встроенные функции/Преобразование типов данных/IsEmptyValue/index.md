## IsEmptyValue

Функция **IsEmptyValue** проверяет, имеет ли переменная значение _undefined, null_ или пустая строка.   
Позволяет писать универсальный код, не зная точный тип данных переданного аргумента.

Примечание - Функция действует, начиная с версии 507. 

Не рекомендуется использовать данную функцию с аргументами типа **Объект**. 

Функция **IsEmptyValue** воспринимает объект как пустое значение и в случае, если аргументом является объект, возвращает _true_. 

_Синтаксис:_  
     **IsEmptyValue (<arg>)**

_Аргументы:_  
     _<arg> (обязательный)_  
     Тип: **Различные типы переменных**. Исходное значение.

_Возвращаемое значение:_  
     Тип: **Булево**. Результат действия функции. Если аргумент имеет значение undefined, null или пустая строка, возвращается _true_. Если аргументом является объект, то также возвращается значение _true_.

_Пример:_  
     _A1 = 123;  
     alert (IsEmptyValue(A1)); // возвращает false  
     A2 = "123";  
     alert (IsEmptyValue(A2)); // возвращает false  
     A3 = " "; // значение - пробел  
     alert (IsEmptyValue(A3)); // возвращает false  
     A4 = undefined;  
     alert (IsEmptyValue(A4)); // возвращает true  
     A5 = null;  
     alert (IsEmptyValue(A5)); // возвращает true  
     A6 = '' ; // значение - пустая строка  
     alert (IsEmptyValue(A6)); // возвращает true_
