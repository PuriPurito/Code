## StrSignedInt

Преобразует числовой аргумент в строку, содержащую целое число со знаком. Округление исходного значения производится в меньшую сторону по модулю.  
Если первый аргумент не может быть преобразован к целому числу со знаком, функция выдает ошибку.  
 

Внимание! Если первый аргумент больше или равен 9223372036854775808, то использование функции приводит к некорректному результату. 

_Синтаксис:_  
      **StrSignedInt (<arg>\[, <digitsNum>\[, <addGroupDelim>\]\])**

_Аргументы:_  
      _<arg> (обязательный)_  
      Тип: **Целое или вещественное положительное или отрицательное число**. Исходное значение.  
      Данный аргумент должен быть меньше 9223372036854775808 (то есть 2^63 (2 в степени 63)).  
      _<digitsNum> (необязательный)_  
      Тип: **Целое неотрицательное число**. Минимальное число символов в строке. Недостающие символы компенсируются нулями перед числом.  
      _<addGroupDelim> (необязательный)_  
      Тип: **Булево**. При указании значения true тысячные разряды в строке разделяются пробелами.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая целое число со знаком. Результат действия функции.

_Пример:_  
      _A1 = StrSignedInt (-6);  
      alert (A1); // возвращает '-6'  
      A2 = StrSignedInt (-5.5);  
      alert (A2); // возвращает '-5'_  
      _A3 = StrSignedInt (11500, 6);  
      alert (A3); // возвращает '011500'  
      A4 = StrSignedInt (-5.5, 5, true);  
      alert (A4); // возвращает '-00 005'  
      A5 = StrSignedInt ('1000');  
      alert (A5); // обработка строковых значений недопустима (возвращает ошибку с прерыванием выполняемого кода)_
