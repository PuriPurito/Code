## Особенности арифметических действий с целыми и действительными числами

1\. Если производятся некоторые арифметические действия с целыми числами, то результат расчетов также получается целым числом:

alert ( (3+3+5) / 3 ); // возвращает 3 (целое число)

Для того, чтобы получить в результате расчетов действительное число, нужно, чтобы хотя бы одно число было действительным:

alert ( ( OptReal(3)+3+5)/3 ); // возвращает 3.666667 (действительное число)  
alert ( StrRealFixed ( (OptReal(3)+3+5)/3, 2 )); // возвращает '3.67' (строковое значение)

  
2\. Для получения корректного результата желательныно указывать последовательность арифметических действий скобками:

i = 24.0 / 4 / 3;  
alert( i ); // выводит 24 (результат некорректный)

i = (24.0 / 4) / 3;  
alert( i ); // выводит 2 (результат корректный)

  
3\. В качестве разделителя целой и дробной части действительного числа нужно использовать точку, а не запятую:

a = 1,3; // Некорректно: Оператор Comma (запятая) разделяет инструкции. Поэтому при использовании запятой в качестве разделителя 3 в данном случае не будет присвоено числу и игнорируется.   
alert( a );  // выводит 1

a = 1.3; // Корректно: В качестве разделителя целой и дробной части действительного числа используется точка:  
alert( a );  // выводит 1.3
