## StrHexColor

      Преобразует десятеричное обозначение цвета (RGB-код) в шестнадцатеричное обозначение (HEX-код), принятое в формате HTML.  
      Если аргумент не может быть преобразован к формату RGB-кода, функция выдает ошибку.

_Синтаксис:_  
      **StrHexColor (****<color>****)**

_Аргументы:_  
     _<color> (обязательный)_  
     Тип: **Строка**. Строка, содержащая десятеричное обозначение цвета (RGB-код) (три целых числа от 0 до 255, обозначающих количество соответствующего цвета (красный, зелёный, синий) в итоговом цвете). Исходное значение.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая шестнадцатеричное обозначение цвета (HEX-код). Результат действия функции.

_Пример:_  
      _A1 = StrHexColor ('128,128,128');  
      alert (A1); // возвращает '#808080'  
      A2 = StrHexColor ('123.55');  
      alert (A2); // возвращает ошибку с прерыванием выполняемого кода_
