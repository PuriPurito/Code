## Неявное приведение данных

Некоторые часто встречающиеся примеры неявного приведения данных:

_Строка + Число => Строка  
Число + Строка => Строка  
Булево + Число => Строка  
Число + Булево => Строка_  
Дата _\+ Число => Строка  
Число +_ Дата _\=> Строка_  
Булево _\+ Строка => Строка  
Строка +_ Булево _\=> Строка_  
Дата _\+ Строка => Строка  
Строка +_ Дата _\=> Строка_

Следует учитывать также, что при выполнении функции alert()  атрибут данной функции любого типа предварительно неявно преобразуется в строку.

Примечание. Во избежании ошибок использовать неявное приведение данных не рекомендуется. Лучше применять явное приведение данных с помощью функций  **OptInt, OptReal, StrInt, StrReal** и др.
