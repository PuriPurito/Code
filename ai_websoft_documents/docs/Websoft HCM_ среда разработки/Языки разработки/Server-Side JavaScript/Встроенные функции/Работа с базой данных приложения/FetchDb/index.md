## FetchDb

Открывает базу данных и помещает ее в список открытых баз. Если база уже открыта, возвращается ссылка на открытую базу из указанного списка.

_Синтаксис:_  
      **FetchDb (<dbName>)**

_Аргументы:_  
      _<dbName> (обязательный)_  
      Тип: **Строка**. Наименование базы данных.

_Возвращаемое значение:_  
      Тип: **Объект XmlDatabase**. Ссылка на объект базы данных. Результат действия функции.

_Пример:_  
      _FetchDb ( db\_name );_
