## FindOptCatalog

Ищет каталог по имени (наименованию) во всех используемых базах данных. Если функция не находит указанный каталог, то возвращается значение _undefined_.

_Синтаксис:_  
      **FindOptCatalog (<catalogName>)**

_Аргументы:_  
      _<catalogName> (обязательный)_  
      Тип: **Строка**. Наименование каталога базы данных.

_Возвращаемое значение:_  
      Тип: **Объект XmlCatalog**. Ссылка на найденный объект каталога. Результат действия функции.

_Пример:_  
      _catalog = FindOptCatalog ( 'events' );  
      alert (catalog.Name); // возвращает 'events'_
