## SetDbHostDir

Устанавливает директорию, которую программа будет считать местом расположения базы данных. По умолчанию директория называется так же, как и база, и располагается в программной директории. Функция используется, если нужно поместить базу в другую директорию.

_Синтаксис:_  
      **SetDbHostDir (<dbName>, <dirUrl>)**

_Аргументы:_  
      _<dbName> (обязательный)_  
      Тип: **Строка**. Наименование базы данных.  
      _<dirUrl> (обязательный)_  
      Тип: **Строка**. Url новой директории для базы данных.

_Возвращаемое значение:_  
      Производится установка новой директории для указанной базы данных. Возвращаемое значение отсутствует.

_Пример:_  
      _SetDbHostDir (dbName, dirUrl);_
