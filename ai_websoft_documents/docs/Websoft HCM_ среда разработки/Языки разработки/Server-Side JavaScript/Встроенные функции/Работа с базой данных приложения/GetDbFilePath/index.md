## GetDbFilePath

На основании наименования модуля зашифрованной базы данных выдает полный путь до XFP-файла.  
Функция не проверяет фактическое существование файла по указанному пути.

_Синтаксис:_  
      **GetDbFilePath (<moduleName>)**

_Аргументы:_  
      _<moduleName> (обязательный)_  
      Тип: **Строка**. Наименование модуля базы данных.

_Возвращаемое значение:_  
      Тип: **Строка**. Полный путь до XFP-файла соответствующей базы данных. Результат действия функции.

_Пример:_  
      _A1 = GetDbFilePath( 'app2' );  
      alert (A1); // возвращает 'С:\\Program files\\WebTutor\\WebTutorAdmin\\app2.xfp'_
