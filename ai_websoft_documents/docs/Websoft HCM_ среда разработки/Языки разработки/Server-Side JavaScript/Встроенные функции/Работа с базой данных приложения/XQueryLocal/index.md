## XQueryLocal

Выполняет заданный запрос на языке XQuery на клиентской машине. Используется для запроса данных из каталогов локальных баз данных.

_Синтаксис:_  
      **XQueryLocal (<query>)**

_Аргументы:_  
      _<query> (обязательный)_  
      Тип: **Строка**. Строчное выражение, содержащее запрос.

_Возвращаемое значение:_  
      Тип: **Массив**. Массив объектов, отобранных запросом. Результат действия функции.

_Пример 1:_  
      _try {_  
            _personArray = XQueryLocal("for $elem in collaborators where contains($elem/fullname, 'ин') return $elem");  
            // personArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает всех сотрудников, в состав фамилии, имени или отчества которых входит подстрока 'ин'.  
            // Внимание - Для больших баз данных исполнение данного запроса может потребовать некоторого времени.  
            // О формировании запросов на языке XQuery - см. Статью 1 и Статью 2._            _if (ArrayCount (personArray) == 0) alert ('Объект не найден!');_  
  
            _A1 = ArrayFirstElem ( personArray ); // функция возвращает первый элемент массива сотрудников personArray  
            alert (A1.fullname); // на экран выводится полное имя отобранного сотрудника  
      }  
      catch (err){   
            alert ('Объект не найден!');  
      };_

_Пример 2:_  
      _try {  
            personArray = XQueryLocal ("for $elem in collaborators where $elem/id = 6148914691236517121 return $elem");  
            // personArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает сотрудника с идентификационным номером (ID) 6148914691236517121, если такой сотрудник имеется в базе данных (в этом случае массив будет состоять из одного элемента).  
            // О том, как определить ID объекта - см.  статью.  
            // Внимание - Для больших баз данных исполнение данного запроса может потребовать некоторого времени.  
            if (ArrayCount (personArray) == 0) alert ('Объект не найден!');  
  
            A1 = ArrayFirstElem ( personArray ); // функция возвращает первый элемент массива сотрудников personArray  
            alert (A1.fullname); // на экран выводится полное имя отобранного сотрудника  
      }  
      catch (err){   
            alert ('Объект не найден!');  
      };_
