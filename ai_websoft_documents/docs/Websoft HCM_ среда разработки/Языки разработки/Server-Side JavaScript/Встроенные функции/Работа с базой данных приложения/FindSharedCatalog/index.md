## FindSharedCatalog

Ищет каталог по имени (наименованию) во всех используемых базах данных. Если функция не находит указанный каталог, то выдает ошибку.  
Примечание - Функция по историческим причинам названа не совсем корректно. Ее ближайший эквивалент - FindOptCatalog - имеет более правильное наименование.

_Синтаксис:_  
      **FindSharedCatalog (<catalogName>)**

_Аргументы:_  
      _<catalogName> (обязательный)_  
      Тип: **Строка**. Наименование каталога базы данных.

_Возвращаемое значение:_  
      Тип: **Объект XmlCatalog**. Ссылка на найденный объект каталога. Результат действия функции.

_Пример:_  
      _catalog = FindSharedCatalog ( 'events' );  
      alert (catalog.Name); // возвращает 'events'_
