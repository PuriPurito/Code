## StrSimpleEncrypt

Шифрует строку встроенным алгоритмом шифрования.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**StrSimpleEncrypt (<str>)**

_Аргументы:_  
_<str> (обязательный)_  
Тип: **Строка**. Строка, содержащая незашифрованный текст и подлежащая шифрованию. Исходное значение.

_Возвращаемое значение:_  
Тип: **Строка**. Строка в зашифрованном виде. Результат действия функции.

A1 = StrSimpleEncrypt ('Программа WebTutor');  
alert (A1); // возвращает строку в зашифрованном виде
