## MultipartFormEncode

Формирует тело http-запроса для последующей отправки методом POST в формате multipart/form-data на основе набора пар данных объекта «имя атрибута - значение».

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**MultipartFormEncode (<name1>, <value1>\[, <name2>, <value2>, ..., <nameN>, <valueN>\])**

_Аргументы:_  
_<name1> (обязательный), <name2>, ... <nameN> (необязательный)_   
Тип: Строка. Имя 1-го, 2-го или N-го атрибута объекта.  
_<value1> (обязательный), <value2>, ..., <valueN> (необязательный)_   
Тип: Строка, целое или вещественное число, дата и др. Значение 1-го, 2-го или N-го атрибута объекта.

Обязательным является наличие хотя бы одной пары аргументов <name> и <value>.

_Возвращаемое значение:_  
Тип: Строка. Строка http-запроса в формате multipart/form-data. Результат действия функции.

      oPostParams = MultipartFormEncode  
      (  
            "key", "2233",  
            "event\_id", Int(34566)  
      ); // формирует тело http-запроса в формате multipart/form-data на основе набора пар «имя атрибута - значение»  
      alert (oPostParams); // возвращает строку http-запроса  
      // resp = HttpRequest( URL , 'post', undefined, oPostParams ); // последующее отправление http-запроса
