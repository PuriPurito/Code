## EncodeCharset

Преобразует строку из кодировки, используемой в программе по умолчанию, в кодировку, указанную в аргументе charset.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**EncodeCharset (<str>, <charset>)**

_Аргументы:_  
_<str> (обязательный)_  
Тип: **Строка**. Строка в кодировке по умолчанию. Исходное значение.  
_<charset> (обязательный)_  
Тип: **Строка**. Содержит название кодировки, в которую нужно перевести исходную строку. Допустимые значения: 'windows-1251', 'utf-8', 'koi8-r', 'cp-866'.

_Возвращаемое значение:_  
Тип: **Строка**. Строка в кодировке, указанной в аргументе charset. Результат действия функции.

A1 = EncodeCharset ('Программа WebTutor', 'windows-1251');  
alert (A1); // возвращает строку в кодировке windows-1251  
  
A2 = EncodeCharset ('Программа WebTutor', 'utf-8');  
alert (A2); // возвращает строку в кодировке utf-8  
  
A3 = EncodeCharset ('Программа WebTutor', 'koi8-r');  
alert (A3); // возвращает строку в кодировке koi8-r  
  
A4 = EncodeCharset ('Программа WebTutor', 'cp-866');  
alert (A4); // возвращает строку в кодировке cp-866
