## ParseJson

ParseJson – парсинг строки формата JSON (анализ и разбор строки и построение объекта по тому описанию, которое приведено в строке).  
Действие функции обратно EncodeJson.

Внимание: Данная функция предназначена только для парсинга строк формата JSON. Применение функции к объектам иного типа может привести к прерыванию исполнения кода или к некорректным результатам.

_Синтаксис:_  
      **ParseJson (<arg1>)** 

_Аргументы:_  
      _<arg1> (обязательный)_  
      Тип: **Строка формата JSON**. Исходная строка формата JSON, представляющая собой набор данных типа «параметр - значение».

_Возвращаемое значение:_  
      Тип: **Объект JavaScript**. Результат выполнения функции. Результирующий объект включает в себя элементы в формате «параметр - значение». 

_Пример:_  
      `_sJson = '{a: "нотация", b: [1,2]}';         oParsedJson = ParseJson (sJson);          if (ObjectType (oParsedJson) == 'JsObject') // проверка соответствия результирующего объекта формату JavaScript         {                alert (oParsedJson.a); // обращение к параметру a результирующего объекта; возвращает значение "нотация"               alert (oParsedJson.b[0]); // обращение к параметру b результирующего объекта, к первому элементу соответствующего массива; возвращает значение 1         }_`
