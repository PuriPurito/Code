## SqlLiteral

Преобразует исходное значение в константу (литерал) языка запросов SQL. Функция используется для генерирования выражений на языке SQL из программы.  
См. также функции: CodeLiteral и XQueryLiteral.

_Синтаксис:_  
      **SqlLiteral (<arg>)**

_Аргументы:_  
      _<arg> (обязательный)_  
      Тип: **Строка, Целое число, Дата** и др. Исходное значение.

_Возвращаемое значение:_  
      Тип: **Строка**. Результат действия функции.  
      Значение типа **null** переводится в строку 'NULL'.  
      Значение типа **Строка** заключается в одинарные кавычки, при этом существующие одинарные кавычки внутри строки преобразуются в двойные кавычки в соответствии с правилами языка SQL.  
      Значение типа **Целое число** переводится в соответствующее строковое значение.  
      Значение типа **Вещественное число** не преобразуется.  
      Значение типа **Дата** переводится в строку, содержащую дату и время в формате SQL.

_Пример:_  
      _A1 = SqlLiteral (null);  
      alert (A1); // возвращает строку 'NULL'  
      A2 = SqlLiteral ('Программа \\'WebTutor\\'');  
      alert (A2); // возвращает строку 'Программа "WebTutor"'  
  
      A3 = SqlLiteral (123);  
      alert (A3); // возвращает строку '123'  
      A4 = SqlLiteral (Date());  
      alert (A4); // возвращает строку, содержащую текущие дату и время в формате SQL  
  
      A5 = SqlLiteral (123.45); // возвращает ошибку с прерыванием выполняемого кода  
      alert (A5);_   
  
      // Сопоставление результатов применения функций SqlLiteral, CodeLiteral, XQueryLiteral для данных типа Дата:  
      alert ("SqlLiteral = " + SqlLiteral(Date()) + "\\n" +"CodeLiteral = " + CodeLiteral(Date()) + "\\n" +"XQueryLiteral = " + XQueryLiteral(Date()) );
