## StrSimpleDecrypt

Дешифрует строку, зашифрованную встроенным алгоритмом.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**StrSimpleDecrypt (<str>)**

_Аргументы:_  
_<str> (обязательный)_  
Тип: **Строка**. Строка в зашифрованном виде. Исходное значение.

_Возвращаемое значение:_  
Тип: **Строка**. Строка в дешифрованном виде. Результат действия функции.

A1 = StrSimpleEncrypt ('Программа WebTutor');  
alert (A1); // подготовка строки в зашифрованном виде  
  
A2 = StrSimpleDecrypt (A1);  
alert (A2); // возвращает строку в дешифрованном виде
