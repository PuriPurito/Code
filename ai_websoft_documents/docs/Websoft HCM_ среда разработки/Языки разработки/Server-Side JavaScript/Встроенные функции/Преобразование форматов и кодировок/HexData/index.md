## HexData

Преобразует исходную строку в посимвольное шестнадцатеричное представление.

_Синтаксис:_  
      **HexData (<arg>)**

_Аргументы:_  
      _<arg> (обязательный)_  
      Тип: **Строка**. Исходное значение.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая шестнадцатеричное представление исходной строки. Результат действия функции.

_Пример:_  
      _A1 = HexData ('АБВабв');  
      alert (A1); // возвращает 'D090D090D092D0B0D0B1D0B2'_
