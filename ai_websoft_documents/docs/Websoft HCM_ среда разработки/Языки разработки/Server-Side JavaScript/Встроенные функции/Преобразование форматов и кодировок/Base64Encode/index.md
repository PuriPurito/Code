## Base64Encode

Преобразует (кодирует) строку в формат Base64.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**Base64Encode (<str>)**

_Аргументы:_  
_<str> (обязательный)_  
Тип: **Строка**. Исходное значение. Может содержать бинарные данные.

_Возвращаемое значение:_  
Тип: **Строка**. Строка в формате Base64. Результат действия функции.

`A1 = Base64Encode ('ABC');   alert (A1); // возвращает строку в формате Base64: 'QUJD'`
