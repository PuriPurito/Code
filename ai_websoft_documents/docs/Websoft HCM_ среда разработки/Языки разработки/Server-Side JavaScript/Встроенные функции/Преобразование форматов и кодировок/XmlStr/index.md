## XmlStr

Добавляет к исходной строке xml-теги.

_Синтаксис:_  
      **XmlStr (<tag>, <str>)**

_Аргументы:_  
      _<tag> (обязательный)_  
      Тип: **Строка**. Строка, содержащая xml-тег.  
      _<str> (обязательный)_  
      Тип: **Строка**. Строка, к которой добавляются теги. Исходное значение.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, с добавленными тегами. Результат действия функции.

_Пример:_  
      _A1 = XmlStr('text', 'Программа WebTutor');  
      alert (A1); // возвращает строку '<text>Программа WebTutor</text>'_
