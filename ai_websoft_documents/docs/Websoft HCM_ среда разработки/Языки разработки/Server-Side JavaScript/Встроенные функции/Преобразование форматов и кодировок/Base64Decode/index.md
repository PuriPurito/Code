## Base64Decode

Декодирует данные из формата Base64.

_Синтаксис:_  
      **Base64Decode (<str>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: Строка. Строка в формате Base64. Исходное значение.

_Возвращаемое значение:_  
      Тип: Строка. Результат действия функции. Может содержать бинарные данные.

_Пример:_  
      _A1 = Base64Encode ('ABC'); // подготовка строки в формате Base64  
      alert (A1); // возвращает строку в формате Base64: 'QUJD'  
      A2 = Base64Decode (A1);  
      alert (A2); // возвращает исходную строку: 'ABC'_
