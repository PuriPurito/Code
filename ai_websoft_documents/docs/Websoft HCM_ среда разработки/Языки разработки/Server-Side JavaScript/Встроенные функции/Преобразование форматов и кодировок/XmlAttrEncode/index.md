## XmlAttrEncode

Преобразует аргумент для вставки в xml в качестве значения атрибута. В результате действия функции выполняется замена ряда символов аргумента:  
\- символ перевода строки преобразуется в &#10;  
\- символ табуляции – в &#09;  
\- символ & - в &lt;  
\- символ < - в &amp;  
\- символ двойных кавычек - в &quot;

_Синтаксис:_  
      **XmlAttrEncode (<str>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Строка, подлежащая преобразованию для вставки в xml. Исходное значение.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, преобразованная для вставки в xml. Результат действия функции.

_Пример:_  
      _A1 = XmlAttrEncode ('Программа "WebTutor" + символы & и <');  
      alert (A1); // возвращает строку, преобразованную для вставки в xml_
