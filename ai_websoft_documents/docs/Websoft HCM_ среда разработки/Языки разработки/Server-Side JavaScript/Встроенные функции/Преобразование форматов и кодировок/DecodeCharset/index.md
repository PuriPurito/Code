## DecodeCharset

Преобразует строку из кодировки, указанной в аргументе charset, в кодировку, используемую в программе по умолчанию.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**DecodeCharset (<str>, <charset>)**

_Аргументы:_  
_<str> (обязательный)_  
Тип: **Строка**. Строка в кодировке, указанной в аргументе charset. Исходное значение.  
_<charset> (обязательный)_  
Тип: **Строка**. Содержит название кодировки, из которой нужно перевести исходную строку в кодировку по умолчанию. Допустимые значения: 'windows-1251', 'utf-8', 'koi8-r', 'cp-866'.

_Возвращаемое значение:_  
Тип: **Строка**. Строка в кодировке по умолчанию. Результат действия функции.

A1 = EncodeCharset ('Программа WebTutor', 'windows-1251'); // подготовка строки в кодировке windows-1251  
alert (A1); // возвращает строку в кодировке windows-1251  
  
A2 = DecodeCharset (A1, 'windows-1251');  
alert (A2); // возвращает исходную строку в кодировке по умолчанию  
  
A3 = EncodeCharset ('Программа WebTutor', 'utf-8'); // подготовка строки в кодировке utf-8  
alert (A3); // возвращает строку в кодировке utf-8  
  
A4 = DecodeCharset (A3, 'utf-8');  
alert (A4); // возвращает исходную строку в кодировке по умолчанию  
  
A5 = EncodeCharset ('Программа WebTutor', 'koi8-r'); // подготовка строки в кодировке koi8-r  
alert (A5); // возвращает строку в кодировке koi8-r  
  
A6 = DecodeCharset (A5, 'koi8-r');  
alert (A6); // возвращает исходную строку в кодировке по умолчанию  
  
A7 = EncodeCharset ('Программа WebTutor', 'cp-866'); // подготовка строки в кодировке cp-866  
alert (A7); // возвращает строку в кодировке cp-866  
  
A8 = DecodeCharset (A7, 'cp-866');  
alert (A8); // возвращает исходную строку в кодировке по умолчанию
