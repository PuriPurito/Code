## EncodeJson

EncodeJson – сериализация JavaScript-объекта (запись описания объекта в виде строки в формате JSON).   
Действие функции обратно ParseJson.

Внимание: Данная функция предназначена только для сериализации JavaScript-объектов. Применение функции к объектам иного типа может привести к некорректным результатам.

_Синтаксис:_  
      **EncodeJson (<arg1>)** 

_Аргументы:_  
      _<arg1> (обязательный)_  
      Тип: **Объект JavaScript**. Исходный объект, представляющий собой набор элементов типа «параметр - значение».

_Возвращаемое значение:_  
      Тип: **Строка формата JSON**. Результат выполнения функции. Объект включает в себя набор данных типа «параметр - значение».

_Пример:_  
     `_oJS = ({a: "нотация", b: [1,2]});        if (ObjectType (oJS) == 'JsObject') // проверка соответствия объекта формату JavaScript        {              sJson = EncodeJson (oJS);             alert ( sJson );        }_`

_Пример некорректного применения функции EncodeJson:_  
     `__query_str = " for $elem in collaborators  return $elem";         aPerson = XQuery(_query_str); // формируется массив объектов XQuery, а не объект JavaScript        alert (EncodeJson (aPerson)); // вместо строки формата JSON выводится некорректное сообщение о типе обрабатываемого объекта_`
