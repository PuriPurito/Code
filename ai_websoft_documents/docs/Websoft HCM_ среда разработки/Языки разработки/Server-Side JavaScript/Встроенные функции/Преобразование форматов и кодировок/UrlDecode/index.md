## UrlDecode

Преобразует строку по стандартным правилам декодирования url, т.е. заменяет знак "%код" на соответствующий текстовый символ кириллицы.

_Синтаксис:_  
      **UrlDecode (<str>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Строка в кодировке, принятой для использования в качестве параметра url. Исходное значение.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая обычный текст. Результат действия функции.

_Пример:_  
      _alert A1 = UrlDecode ('qwerty%2D%E0%EF%F0%EE%EB%2Ehtm');  
      A1 = DecodeCharset (A1, 'windows-1251') // преобразование строки из кодировки windows-1251 в кодировку, используемую в программе по умолчанию  
      alert (A1); // возвращает строку 'qwerty-апрол.htm'_
