## UrlEncodeQueryExt

Преобразует набор пар данных объекта «имя атрибута - значение» в строку вида 'name1=value1&name2=value2&...' в заданной кодировке для использования в качестве запроса в составе url.

_Синтаксис:_  
      **UrlEncodeQueryExt ({<name1>: <value1>\[, <name2>: <value2>, ..., <nameN>: <valueN>}, <charset>\])**

_Аргументы:_  
      _<name1> (обязательный), <name2>, ... <nameN> (необязательный)_   
      Тип: Строка. Имя 1-го, 2-го или N-го атрибута объекта.  
      _<value1> (обязательный), <value2>, ..., <valueN> (необязательный)_   
      Тип: Строка, целое или вещественное число, дата и др. Значение 1-го, 2-го или N-го атрибута объекта.  
      Примечание – Обязательным является наличие хотя бы одной пары аргументов <name> и <value>.  
      _<charset> (обязательный)_  
      Тип: **Строка**. Содержит название кодировки, в которую нужно перевести результирующую строку. Допустимые значения: 'windows-1251', 'utf-8', 'koi8-r', 'cp-866'.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка для использования в качестве запроса в составе url в указанной кодировке. Результат действия функции.

_Пример:_  
      _A1 = UrlEncodeQueryExt ({"key": "2233", "event\_id": Int(34566), "text": "Программа Webtutor"}, "koi8-r");  
      alert (A1); // возвращает строку для использования в составе url в указанной кодировке_
