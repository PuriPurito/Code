## UrlEncodeQuery

Преобразует набор пар данных объекта «имя атрибута - значение» в строку вида 'name1=value1&name2=value2&...' для использования в качестве запроса в составе url.

_Синтаксис:_  
      **UrlEncodeQuery ({ <name1>: <value1>\[, <name2>: <value2>, ..., <nameN>: <valueN> }\])**

_Аргументы:_  
      _<name1> (обязательный), <name2>, ... <nameN> (необязательный)_   
      Тип: **Строка**. Имя 1-го, 2-го или N-го атрибута объекта.  
      _<value1> (обязательный), <value2>, ..., <valueN> (необязательный)_   
      Тип: **Строка, целое или вещественное число, дата** и др. Значение 1-го, 2-го или N-го атрибута объекта.  
      Примечание – Обязательным является наличие хотя бы одной пары аргументов <name> и <value>.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка для использования в качестве запроса в составе url. Результат действия функции.

_Пример:_  
      _A1 = UrlEncodeQuery  
      ({  
            "key": "2233",  
            "event\_id": Int(34566),  
            "text": "Программа Webtutor"  
      });  
      alert (A1); // возвращает строку для использования в качестве запроса в составе url_
