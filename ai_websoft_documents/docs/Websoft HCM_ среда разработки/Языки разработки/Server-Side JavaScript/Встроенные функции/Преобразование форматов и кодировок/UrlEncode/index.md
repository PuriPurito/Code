## UrlEncode

Преобразует исходную текстовую строку по стандартным правилам кодирования для использования в качестве параметра url, т.е. заменяет текстовый символ кириллицы на соответствующий знак в формате "%код".

_Синтаксис:_  
      **UrlEncode (<str>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка**. Строка, содержащая обычный текст. Исходное значение.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка в кодировке, принятой для использования в качестве параметра url. Результат действия функции.

_Пример:_  
      _A1 = UrlEncode ('qwerty-апрол.htm');  
      alert (A1); // возвращает строку 'qwerty%2D%E0%EF%F0%EE%EB%2Ehtm'_
