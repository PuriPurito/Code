## HtmlEncodeDoc

Преобразует строку, содержащую обычный текст, в полный HTML-документ. Действие функции аналогично действию функции HtmlEncode, но, в отличие от последней, функция **HtmlEncodeDoc** формирует завершенный HTML-документ, содержащий теги <html>, <body> и др.

_Синтаксис:_  
      **HtmlEncodeDoc (<str>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: Строка. Исходное значение.

_Возвращаемое значение:_  
      Тип: Строка. Строка, содержащая HTML-документ. Результат действия функции.

_Пример:_  
      _A1 = HtmlEncodeDoc ('Это документ. Мы используем в тексте следующие символы: & и <');  
      alert (A1); // возвращает '<html> <meta http-equiv="content-type" content="text/html; charset=utf-8"> <body> Это документ. Мы используем в тексте следующие символы: &amp; и &lt;</body> </html>'_
