## GetCurTicks

Возвращает время в миллисекундах, прошедшее с момента запуска операционной системы.

_Синтаксис:_  
      **GetCurTicks ()**

_Аргументы:_  
      Функция вызывается без аргументов.

_Возвращаемое значение:_  
      Тип: **Целое число**. Время в миллисекундах от момента запуска операционной системы. Результат действия функции.

_Пример:_  
      _A1 = GetCurTicks ();  
      alert (A1); // возвращает время в миллисекундах, прошедшее с момента запуска операционной системы_
