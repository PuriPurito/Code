## StrMimeDate

Преобразует дату в формат MIME.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**StrMimeDate (<date>)**

_Аргументы:_  
_<date> (обязательный)_  
Тип: **Дата**. Исходная дата.

_Возвращаемое значение:_  
Тип: **Дата**. Исходная дата в формат MIME. Результат действия функции.

A1 = Date( '26.12.2011 10:45' );  
A2 = StrMimeDate (A1);  
alert (A2); // возвращает дату в формате MIME ('Mon, 26 Dec 2011 10:45:00 +0300')
