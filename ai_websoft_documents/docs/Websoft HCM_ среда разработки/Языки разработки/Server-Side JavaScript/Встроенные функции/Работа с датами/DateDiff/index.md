## DateDiff

Возвращает разность между первой и второй датами в секундах.

В некоторых версиях функция DateDiff может работать некорректно с датами ранее 1970 года.

_Синтаксис:_  
      **DateDiff (<date1>, <date2>)**

_Аргументы:_  
      _<date1> (обязательный)_  
      Тип: **Дата**. Исходная дата, из которой производится вычитание.  
      _<date2> (обязательный)_  
      Тип: **Дата**. Исходная дата, которую вычитают из date1.

_Возвращаемое значение:_  
      Тип: **Целое число**. Разность между первой и второй датами в секундах. Результат действия функции.

_Пример:_  
      _A1 = Date (); // Текущая дата  
      A2 = Date ('22.07.2019');  
      A3 = DateDiff (A1, A2);  
      alert (A3); // возвращает разность дат в секундах  
      A4 = Date ('22.07.2019 14:00:01');  
      A5 = Date ('22.07.2019 14:00:00');  
      A6 = DateDiff (A4, A5);  
      alert (A6); // возвращает 1_
