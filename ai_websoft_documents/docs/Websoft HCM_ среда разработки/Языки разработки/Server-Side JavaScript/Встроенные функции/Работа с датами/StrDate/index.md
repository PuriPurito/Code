## StrDate

Преобразует дату в строку в формате, используемом по умолчанию в операционной системе.  
Если в качестве аргумента передается null или пустая строка, функция возвращает пустую строку.

_Синтаксис:_  
      **StrDate (<date>\[,<showTime>\[,<showSeconds>\]\])**

_Аргументы:_  
      _<date> (обязательный)_  
      Тип: **Дата**. Исходная дата. Вместо объекта типа Дата аргументом может быть значение null или пустая строка.  
      _<showTime> (необязательный)_  
      Тип: **Булево**. Включение времени в строку (true – время включается, false – время не включается). По умолчанию данный аргумент принимает значение true.  
      _<showSeconds> (необязательный)_  
      Тип: **Булево**. Включение количества секунд в строку (true – количество секунд включается, false – количество секунд не включается). По умолчанию данный аргумент принимает значение true.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая исходную дату. Результат действия функции.

_Пример:_  
      _A1 = Date();  
      A2 = StrDate (A1);  
      alert (A2); // возвращает строку с текущей датой и временем  
  
  
      A3 = StrDate (A1, false);  
      alert (A3); // возвращает строку с текущей датой без указания временем  
  
  
      A4 = StrDate (A1, true, false);  
      alert (A4); // возвращает строку с текущей датой и временем (без указания секунд)  
  
  
      A5 = StrDate (null);  
      alert (A5); // возвращает пустую строку_
