## ParseMimeDate

Преобразует строку, содержащую дату в формате MIME, в дату.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**ParseMimeDate( str )**

_Аргументы:_  
strstring  
Строка с датой в формате MIME, например "Wed, 21 Oct 2015 07:28:00 GMT"
