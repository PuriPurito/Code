## DateToLocalDate

_Контент отсутствует или не загружен_

---

су, оставляя глобальное значение даты без изменений. Функция обычно используется в локальных вычислениях. При сохранении даты в базе данных или передачи ее по сети информация о хранимом часовом поясе внутри даты может потеряться.  
Данная функция эквивалентна следующему выражению: _DateToTimeZoneDate( date, GetLocalTimeZone() )._  
Смотри также функции DateNewTimeZone и DateToTimeZoneDate.

_Синтаксис:_  
      **DateToLocalDate (<date>)**

_Аргументы:_  
      _<date>_  
      Тип: **Дата**. Исходная дата.

_Возвращаемое значение:_  
      Тип: **Дата**. Дата, преобразованная к местному часовому поясу. Результат действия функции.

_Пример:_  
       _dDate1 = Date();  
      alert( dDate1 ); // возвращает текущую дату  
      alert( DateToLocalDate( dDate1 ));_
