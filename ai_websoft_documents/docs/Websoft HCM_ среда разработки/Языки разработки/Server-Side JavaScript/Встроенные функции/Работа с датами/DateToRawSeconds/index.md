## DateToRawSeconds

Возвращает количество секунд, прошедших с даты '01.01.1970 03:00:00', до заданной даты.

_Синтаксис:_  
      **DateToRawSeconds (<date>)**

_Аргументы:_  
      _<date> (обязательный)_  
      Тип: **Дата**. Заданная дата.

_Возвращаемое значение:_  
      Тип: **Целое число**. Количество секунд до заданной даты. Результат действия функции.

_Пример:_  
      _A1 = Date ('01.01.1970 03:00:10');  
      A2 = DateToRawSeconds (A1);  
      alert (A2); // возвращает число 10_
