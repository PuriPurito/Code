## Hour

Возвращает количество часов (от 0 до 23) в заданной дате. Если дата не содержит времени, то функция возвращает значение undefined.

_Синтаксис:_  
      **Hour (<date>)**

_Аргументы:_  
      _<date> (обязательный)_  
      Тип: **Дата**. Заданная дата.

_Возвращаемое значение:_  
      Тип: **Целое число**. Количество часов (от 0 до 23). Результат действия функции. Если дата не содержит времени, то функция возвращает значение undefined.

_Пример:_  
      _A1 = Date ('22.07.2019 14:10:15');  
      A2 = Hour (A1);  
      alert (A2); // возвращает число 14  
      A3 = Date ('22.07.2019');  
      A4 = Hour (A3);  
      alert (A4); // возвращает значение undefined_
