## GetLocalTimeZone

Возвращает местный часовой пояс в целочисленном формате.   
Смотри также функции DateNewTimeZone, DateToTimeZoneDate, DateToLocalDate.

_Синтаксис:_  
      **GetLocalTimeZone ()**

_Аргументы:_  
      Функция вызывается без аргументов.

_Возвращаемое значение:_  
      Тип: **Целое число**. Номер местного часового пояса. Результат действия функции.

_Пример:_  
       _alert ( GetLocalTimeZone () ); // возвращает номер местного часового пояса_
