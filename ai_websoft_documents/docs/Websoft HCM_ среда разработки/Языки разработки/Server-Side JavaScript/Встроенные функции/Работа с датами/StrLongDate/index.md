## StrLongDate

Преобразует дату в строку в «длинном» формате (со словесной формой отображения месяца (например, '1 января 2000 г.' )).  
Если в качестве аргумента передается null или пустая строка, функция возвращает пустую строку.  
Функция корректно работает только при запуске на клиенте. 

Внимание! При запуске функции на сервере выдается некорректный результат.   
При обработке веб-запросов или кода, вызываемого на сервере, можно использовать функцию **get\_str\_date\_from\_date** из библиотеки **libSchedule** - она вычисляет локаль текущего пользователя и возвращает строку даты в настройках этой локали.  
Для процессов, выполняемых на сервере автоматически (например, по расписанию), где текущего пользователя нет - возможность формировать дату в указанном формате отсутствует.  
Функция **get\_str\_date\_from\_date** работает только при внутренних вызовах JS и не будет работать в вызовах API и C#.

_Синтаксис:_  
      **StrLongDate (<date>)**

_Аргументы:_  
      _<date> (обязательный)_  
      Тип: **Дата**. Исходная дата. Вместо объекта типа Дата аргументом может быть значение null или пустая строка.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая исходную дату в «длинном» формате. Результат действия функции.

_Пример:_  
      _A1 = Date( '26.12.2011' );  
      A2 = StrLongDate (A1);  
      alert (A2); // возвращает строку с заданной датой в «длинном» формате ('26 декабря 2011 г.')  
      A3 = StrLongDate (null);  
      alert (A3); // возвращает пустую строку_
