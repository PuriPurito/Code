## Month

Возвращает номер месяца в году (от 1 до 12) для заданной даты.

_Синтаксис:_  
      **Month (<date>)**

_Аргументы:_  
      _<date> (обязательный)_  
      Тип: **Дата**. Заданная дата.

_Возвращаемое значение:_  
      Тип: **Целое число**. Номер дня (от 1 до 12). Результат действия функции.

_Пример:_  
      _A1 = Date ('22.07.2019 14:10:15');  
      A2 = Month (A1);  
      alert (A2); // возвращает число 7_
