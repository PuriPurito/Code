## Date

Преобразует строку, содержащую дату или дату и время, в объект типа **Дата** (это специальный объект (структура) даты).  
Если исходная строка содержит данные, отличные от указанных, то функция возвращает ошибку с прерыванием выполняемого кода.  
Если аргумент не указан, то функция возвращает текущую дату.  
Если аргумент содержит данное типа **Дата**, то функция возвращает его без изменений.

_Синтаксис:_  
      **Date (\[<str>\])**

_Аргументы:_  
      _<str> (необязательный)_  
      Тип: **Строка** или **Дата**. Строка должна содержать дату или дату и время. Исходная строка или исходная дата. Если аргумент не указан, то функция возвращает текущую дату.

_Возвращаемое значение:_  
      Тип: **Объект типа Дата**. Результат действия функции.

_Пример 1:_  
      _alert ( DataType (Date()) ); // возвращает строковое значение 'object' (тип данных - объект)  
      alert ( ObjectType(Date()) ); // возвращает строковое значение 'BmObject' (внутренний объект (структура данных) платформы SPXML)  
      alert ( DataType( ParseDate(Date()) ) ); // тип данных Дата; возвращает строковое значение 'date'_  
  
      _A1 = Date();  
      alert (A1); // возвращает текущую дату  
  
      A2 = Date('22.07.2019');  
      alert (A2); // возвращает дату, указанную в строке аргумента  
  
      A3 = Date('22.07.2019 14:00');  
      alert (A3); // возвращает дату и время, указанные в строке аргумента_

      _A4 = Date( 2019, 11, 5 ,21,25,15);  
      alert ( A4 ); // возвращает дату 05.11.2019 21:25:15, указанную в строке аргумента_      _A5 = Date();_

      _A6 = Date(A5);  
      alert (A6); // возвращает данное типа Дата без изменения  
  
      A7 = Date ('Программа WebTutor'); // строка не содержит дату или дату и время  
      alert (A7); // возвращает ошибку с прерыванием выполняемого кода_

_Пример 2:_  
      _String(ParseDate(Date())).split('.').join('');_
