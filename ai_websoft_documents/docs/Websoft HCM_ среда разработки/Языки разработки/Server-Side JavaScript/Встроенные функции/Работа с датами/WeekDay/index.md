## WeekDay

Возвращает номер дня недели (от 0 до 6) для заданной даты (0 - воскресенье, 1 - понедельник и т.д.).

_Синтаксис:_  
      **WeekDay (<date>)**

_Аргументы:_  
      _<date> (обязательный)_  
      Тип: **Дата**. Заданная дата.

_Возвращаемое значение:_  
      Тип: **Целое число**. Номер дня недели (от 0 до 6). Результат действия функции.

_Пример:_  
      _A1 = Date ('22.07.2019 14:10:15');  
      A2 = WeekDay (A1);  
      alert (A2); // возвращает число 1 (т.к. указанный день – понедельник)_
