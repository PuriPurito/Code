## StrTime

Выделяет время (количество часов и минут) из исходной даты в строковое выражение.  
Если в дате время не указывается или в качестве аргумента передается null или пустая строка, функция возвращает пустую строку.

_Синтаксис:_  
      **StrTime (<date>)**

_Аргументы:_  
      _<date> (обязательный)_  
      Тип: **Дата**. Исходная дата. Вместо объекта типа Дата аргументом может быть значение null или пустая строка.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая время, выделенное из исходной даты. Результат действия функции.

_Пример:_  
      _A1 = Date( '26.12.2011 21:45:15' );  
      A2 = StrTime (A1);  
      alert (A2); // возвращает строку, содержащую значение времени в составе заданной даты ('21:45')  
      A3 = Date( '26.12.2011' );  
      A4 = StrTime (A3);  
      alert (A4); // возвращает пустую строку  
      A5 = StrTime (null);  
      alert (A5); // возвращает пустую строку_
