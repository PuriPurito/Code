## Second

Возвращает количество секунд (от 0 до 59) для заданной даты. Если дата не содержит времени, то функция возвращает значение 0.

_Синтаксис:_  
      **Second (<date>)**

_Аргументы:_  
      _<date> (обязательный)_  
      Тип: **Дата**. Заданная дата.

_Возвращаемое значение:_  
      Тип: **Целое число**. Количество секунд (от 0 до 59). Результат действия функции. Если дата не содержит времени, то функция возвращает значение 0.

_Пример:_  
      _A1 = Date ('22.07.2019 14:10:15');  
      A2 = Second (A1);  
      alert (A2); // возвращает число 15  
      A3 = Date ('22.07.2019');  
      A4 = Second (A3);  
      alert (A4); // возвращает значение 0_
