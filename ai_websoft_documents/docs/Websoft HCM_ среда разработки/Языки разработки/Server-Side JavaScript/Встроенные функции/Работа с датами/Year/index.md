## Year

Возвращает номер года для заданной даты.

_Синтаксис:_  
      **Year (<date>)**

_Аргументы:_  
      _<date> (обязательный)_  
      Тип: **Дата**. Заданная дата.

_Возвращаемое значение:_  
      Тип: **Целое число**. Номер года. Результат действия функции.

_Пример:_  
      _A1 = Date ('22.07.2019 14:10:15');  
      A2 = Year (A1);  
      alert (A2); // возвращает номер года - 2019_
