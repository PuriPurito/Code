## StrXmlDate

Преобразует дату в строку в формате XML (данный формат не зависит от региональных настроек в системе).  
Если в качестве аргумента передается null или пустая строка, функция возвращает пустую строку.

_Синтаксис:_  
      **StrXmlDate (<date>)**

_Аргументы:_  
      _<date> (обязательный)_  
      Тип: **Дата**. Исходная дата. Вместо объекта типа Дата аргументом может быть значение null или пустая строка.  
      _<showTime> (необязательный)_  
      Тип: **Булево**. Включение времени в строку (_true_ – время включается, _false_ – время не включается). По умолчанию данный аргумент принимает значение _true_.  
      _<showSeconds> (необязательный)_  
      Тип: **Булево**. Включение количества секунд в строку (_true_ – количество секунд включается, _false_ – количество секунд не включается). По умолчанию данный аргумент принимает значение _true_.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая исходную дату в формате XML. Результат действия функции.

_Пример:_  
      _A1 = Date( '26.12.2011 10:45:15' );  
      A2 = StrXmlDate (A1);  
      alert (A2); // возвращает строку '2011-12-26T10:45:15+00:00'  
      A3 = StrXmlDate (A1, false);  
      alert (A3); // возвращает строку '2011-12-26'  
      A4 = Date( '26.12.2011' );  
      A5 = StrXmlDate (A4);  
      alert (A5); // возвращает строку '2011-12-26'  
      A6 = StrXmlDate (null);  
      alert (A6); // возвращает пустую строку_
