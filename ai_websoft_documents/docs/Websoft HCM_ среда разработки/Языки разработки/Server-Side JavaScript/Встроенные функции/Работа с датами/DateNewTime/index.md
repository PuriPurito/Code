## DateNewTime

Изменяет исходную дату с учетом заданного времени (часов, минут и секунд). Если указан только первый аргумент, функция возвращает дату без указания времени.

_Синтаксис:_  
      **DateNewTime (<date>\[, <hours>, <minutes>\[, <seconds>\]\])**

_Аргументы:_  
      _<date> (обязательный)_  
      Тип: **Дата**. Исходная дата, в которой производится изменение.  
      _<hours> (необязательный)_  
      Тип: **Целое число**. Количество часов в результирующей дате.  
      _<minutes> (необязательный)_  
      Тип: **Целое число**. Количество минут в результирующей дате.  
      _<seconds> (необязательный)_  
      Тип: **Целое число**. Количество секунд в результирующей дате.  
      Примечание – Допустимые сочетания аргументов:  
      **<date>** - функция возвращает исходную дату без указания времени;  
      **<date>, <hours>, <minutes>** - функция возвращает исходную дату со временем и количеством секунд, равным 0 (например, 11:34:00);  
      **<date>, <hours>, <minutes>, <seconds>** - функция возвращает исходную дату со временем и с указанием количества секунд (например, 11:34:15).

_Возвращаемое значение:_  
      Тип: **Дата**. Измененная дата. Результат действия функции.  
      При наличии аргументов «hours, minutes» или «hours, minutes, seconds» функция возвращает исходную дату с учетом заданного времени (часов, минут и секунд).

_Пример:_  
      _A1 = Date (); // Текущая дата  
      A2 = DateNewTime (A1, 11, 34, 15);  
      alert (A2); // возвращает текущую дату со временем 11:34:15  
      A3 = Date ('22.07.2019');  
      A4 = DateNewTime (A3);  
      alert (A4); // возвращает дату без указания времени_
