## RawSecondsToDate

Преобразует количество секунд, прошедших с даты '01.01.1970 03:00:00', в результирующую дату.

Преобразуемое количество секунд не должно быть отрицательным! В случае высокой вероятности получения отрицательных значений количества секунд рекомендуется использовать функцию **DateOffset**.  
 

_Синтаксис:_  
      **RawSecondsToDate (<seconds>)**

_Аргументы:_  
      _<seconds> (обязательный)_  
      Тип: **Целое положительное число или 0**. Количество секунд. Исходное число.

_Возвращаемое значение:_  
      Тип: **Дата**. Результирующая дата. Результат действия функции.

_Пример:_  
      _A1 = RawSecondsToDate (10);  
      alert (A1); // возвращает дату_
