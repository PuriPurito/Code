## DateOffset

Сдвигает дату на указанное число секунд. Если значение второго аргумента отрицательное, дата сдвигается назад.

 Примечание. Для информации - 1 сутки = 86400 секунд; 1 час = 3600 секунд; 1 минута = 60 секунд.

_Синтаксис:_  
      **DateOffset (<date>, <seconds>)**

_Аргументы:_  
      _<date> (обязательный)_  
      Тип: **Дата**. Исходная дата.  
      _<seconds> (обязательный)_  
      Тип: **Целое число**. Количество секунд, на которое выполняется сдвиг.

_Возвращаемое значение:_  
      Тип: **Дата**. Измененная дата. Результат действия функции.

_Пример 1:_  
      _A1 = Date ('22.07.2019 14:00:00');  
      A2 = DateOffset (A1, 10);  
      alert (A2); // возвращает дату 22.07.2019 14:00:10  
      A3 = DateOffset (A1, -10);  
      alert (A3); // возвращает дату 22.07.2019 13:59:50_

_Пример 2:_  
      _dCurrentDate = Date();   
      alert (dCurrentDate); // сегодняшнее число  
      dNewDate1 = DateOffset (dCurrentDate, 86400); // завтрашнее число  
      alert (dNewDate1);   
      dNewDate0 = DateOffset (dCurrentDate, -86400); // вчерашнее число  
      alert (dNewDate0);_
