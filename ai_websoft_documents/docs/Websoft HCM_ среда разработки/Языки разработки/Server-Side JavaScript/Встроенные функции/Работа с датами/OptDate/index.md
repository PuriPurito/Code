## OptDate

Преобразует строку, содержащую дату или дату и время, в объект типа Дата.  
Данная функция аналогична функции Date, но имеет перед функцией Date ряд преимуществ:  
1) В случае, если указаны недопустимые аргументы, функция возвращает значение undefined.  
2) Функция OptDate() проверяет корректность даты (например, 29 февраля).  
       
Допустимые варианты использования:  
_OptDate ( 2019, 04, 20 )  
OptDate ( 2019, 04, 20, 12, 30 )  
OptDate ( 2019, 04, 20, 12, 30, 0 )_  
       
Если аргумент не указан, то функция возвращает текущую дату.  
Если аргумент содержит данное типа Дата, то функция возвращает его без изменений.

_Синтаксис:_  
      **OptDate (\[<year>, <month>, <day>\[, <hours>, <minutes>\[, <seconds>\])\])**

_Аргументы:_  
      _<year>, <month>, <day>(необязательные)_  
      Тип: **Целые числа**. Значения года, месяца и числа, перечисленные через запятую в указанном порядке.  
      _<hours>, <minutes>, <seconds> (необязательные)_  
      Тип: **Целые числа**. Значения количества часов, минут и секунд в заданной дате, перечисленные через запятую в указанном порядке. Если количество секунд не указано, то оно считается равным 0.  
      Если аргумент функции отсутствует, то функция возвращает текущую дату.

_Возвращаемое значение:_  
      Тип: **Дата**. Результат действия функции.

_Пример:_  
      _A1 = OptDate ();  
      alert (A1); // возвращает текущую дату  
      A2 = OptDate ( 2019, 04, 20 );  
      alert (A2); // возвращает дату 20.04.2019  
      A3 = OptDate ( 2019, 04, 20, 12, 30 );  
      alert (A3); // возвращает дату 20.04.2019 12:30:00  
      A4 = OptDate ( 2019, 04, 20, 12, 30, 0 );  
      alert (A4); // возвращает дату 20.04.2019 12:30:00  
      A5 = OptDate ( 2019, 02, 29, 12, 30, 0 ); // такой даты не существует  
      alert (A5); // возвращает значение undefined без прерывания выполняемого кода  
      A6 = OptDate ('Программа WebTutor'); // строка не содержит дату или дату и время  
      alert (A6); // возвращает значение undefined без прерывания выполняемого кода_
