## DateNewTimeZone

Меняет значение часового пояса внутри даты, оставляя значение времени суток без изменений. Функция обычно используется в локальных вычислениях. При сохранении даты в базе данных или передачи ее по сети информация о хранимом часовом поясе внутри даты может потеряться.  
Смотри также функции DateToLocalDate и DateToTimeZoneDate.

_Синтаксис:_  
      **DateNewTimeZone( <date>, <timeZone> )**

_Аргументы:_  
      _<date>_   
      Тип: **Дата**. Исходная дата.  
      _<timeZone>_   
      Тип: **Целое число**. Часовой пояс.

_Возвращаемое значение:_  
      Тип: **Дата**. Результат действия функции.

_Пример:_  
      _dDate1 = Date();  
      alert( dDate1 ); // возвращает текущую дату  
      alert( DateNewTimeZone( dDate1, 3 ));_
