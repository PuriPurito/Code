## Day

Возвращает номер дня в месяце (от 1 до 31) для заданной даты.

_Синтаксис:_  
      **Day (<date>)**

_Аргументы:_  
      _<date> (обязательный)_  
      Тип: **Дата**. Заданная дата.

_Возвращаемое значение:_  
      Тип: **Целое число**. Номер дня (от 1 до 31). Результат действия функции.

_Пример:_  
      _A1 = Date ('22.07.2019 14:10:15');  
      A2 = Day (A1);  
      alert (A2); // возвращает число 22_
