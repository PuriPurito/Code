## StrShortDate

Преобразует дату в строку в «коротком» формате (с двухсимвольным отображением года).

_Синтаксис:_  
      **StrShortDate (<date>)**

_Аргументы:_  
      _<date> (обязательный)_  
      Тип: **Дата**. Исходная дата. Вместо объекта типа Дата аргументом может быть значение null или пустая строка.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, содержащая исходную дату с двухсимвольным отображением года. Результат действия функции.

_Пример:_  
      _A1 = Date( '26.12.2011' );  
      A2 = StrShortDate (A1);  
      alert (A2); // возвращает строку с заданной датой в «коротком» формате ('26.11.11')  
      A3 = StrShortDate (null);  
      alert (A3); // возвращает пустую строку_
