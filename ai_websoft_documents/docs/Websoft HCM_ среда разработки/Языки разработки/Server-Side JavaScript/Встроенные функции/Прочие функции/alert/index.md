## alert

Функция преобразует выражение (соответствующее значению аргумента) в текстовый формат и выводит текст в стандартный поток ввода-вывода.  
При выполнении кода на стороне сервера сообщение выводится на консоль сервера с копированием в основной журнал системы ('xhttp'), на стороне клиента - в виде всплывающего (pop-up) диалогового окна (типа **MsgBox**).  
В отличие от аналогичной стандартной функции JavaScript, данная функция возвращает переданное значение, что позволяет использовать ее внутри выражений, например:  
_LoadUrlData( alert( url ) );_  
О копировании информации из окна alert в текстовый редактор - см. здесь.

Примечание - В заголовке диалогового окна alert выводится строковое выражение «Ошибка».

Внимание! Функция **alert** может работать с целыми отрицательными числами некорректно. Поэтому для вывода результата функции Compare с помощью alert можно использовать дополнительно функции **StrSignedInt** или **OptReal** (см. ниже - _Пример 2_).  

Внимание! C середины 2022 г. в связи с развитием многопоточности выполнения кода, консоль сервера является стандартным потоком ввода-вывода не для каждого потока. Поэтому для вывода данных или отладочной информации в журнал сервера рекомендуется пользоваться функцией **LogEvent( "", message )**, которая выводит сообщение в основной журнал системы из любого потока выполнения кода (независимо от консоли сервера).

_Синтаксис:_  
      **alert (<val>)**

_Аргументы:_  
      _<val> (обязательный)_  
      Тип: **Строка, Число, Булево** или др. Информация, передаваемая в диалоговое окно

_Возвращаемое значение:_  
      Тип: **Строка, Число, Булево** или др. Информация, передаваемая в диалоговое окно. Результат действия функции.   
      Функция возвращает данные того типа, который ей был передан (например, если функции передана строка, то возвращается строка, если передано число, то возвращается число, и т.д.).

_Пример 1:_  
      `_A1 = 123;         alert (A1); // возвращает 123         A2 = alert (A1) *2; // = 246; в диалоговом окне выводится 123         alert (A2); // возвращает 246_`     

_Пример 2 (работа с целым отрицательным числом):_  
     `_i = (0-1); // результат - целое отрицательное число -1        alert(i); // получение некорректного результата         if (i < 0)         {              alert ( StrSignedInt ( i ) ); // использование функции StrSignedInt для вывода целого отрицательного значения с помощью alert; результат преобразуется в строку '-1'              alert ( OptReal ( i) ); // использование функции OptReal для вывода целого отрицательного значения с помощью alert; результат преобразуется в действительное число -1         }_`

**Основные непечатаемые символы, используемые при выводе информации с помощью функции alert**  
  
'\\n' – конец строки (новая строка);  
'\\t' – табуляция.
