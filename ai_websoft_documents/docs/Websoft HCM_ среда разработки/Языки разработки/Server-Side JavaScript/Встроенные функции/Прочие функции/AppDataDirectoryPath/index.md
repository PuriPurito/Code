## AppDataDirectoryPath

Возвращает путь к базовой директории хранения данных приложения (серверной или клиентской части). По умолчанию совпадает с установочной директорией, если иное не задано в app\_config.xml.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.
