## Md5Hex

Вычисляет контрольную сумму по алгоритму Md5 и возвращает результат в виде _HEX-строки_ (строки, содержащей контрольную сумму в шестнадцатеричной системе счисления).

_Синтаксис:_  
      **Md5Hex (<data>)**

_Аргументы:_  
      _<data> (обязательный)_  
      Тип: **Строка.** Исходная строка, содержащая массив байтов.

_Возвращаемое значение:_  
      Тип: **Строка.** Результирующая контрольная сумма. Результат действия функции.

_Пример:_  
      `_A1 = Md5Hex ( 'hello' );         alert ( A1 ); // возвращает контрольную сумму в виде HEX-строки_`
