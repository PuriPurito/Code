## ZipExtract

Распаковывает zip-архив.

_Синтаксис:_  
      **ZipExtract (<archivePath>, <destPath>)**

_Аргументы:_  
      _<archivePath> (обязательный)_  
      Тип: **Строка.** Путь до распаковываемого архива.  
      _<destPath> (обязательный)_  
      Тип: **Строка.** Путь до папки, в которую должен быть распакован архив.

_Возвращаемое значение:_  
      Производится распаковывание архива. Возвращаемое значение отсутствует.

_Пример:_  
      `_ZipExtract ( tempZipFilePath, tempUnzipDir );_`
