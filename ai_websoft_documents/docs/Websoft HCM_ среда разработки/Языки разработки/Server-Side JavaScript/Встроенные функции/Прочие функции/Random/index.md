## Random

Возвращает случайное целое число в заданном диапазоне.

_Синтаксис:_  
      **Random (<minVal>, <maxVal>)**

_Аргументы:_  
      _<minVal> (обязательный)_  
      Тип: **Целое число**. Нижняя граница диапазона.  
      _<maxVal> (обязательный)_  
     Тип: **Целое число**. Верхняя граница диапазона.  
     Примечание - Верхняя и нижняя границы могут быть указаны в любом порядке.

_Возвращаемое значение:_  
      Тип: **Целое число**. Формируется случайное целое число. Результат действия функции.

_Пример:_  
      `_A1 = Random (0, 10);         alert ( A1 ); // возвращает случайное целое число от 0 до 10_`
