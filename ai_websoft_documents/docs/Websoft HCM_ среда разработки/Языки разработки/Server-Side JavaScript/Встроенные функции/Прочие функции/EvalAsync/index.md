## EvalAsync

Выполняет заданный код в основном потоке при наступлении следующего системного события. Обычно, если код выполняется в отдельном потоке, из него нельзя обращаться к пользовательскому интерфейсу. Если же нужно сделать, например, обновление экрана, то этот код нужно вызывать через EvalAsync. Функция помещает этот код в очередь, и при следующем системном событии он выполняется.  
См. также EvalSync.

_Синтаксис:_  
      **EvalAsync (<arg1>\[, <arg2>, ...\] )**

_Аргументы:_  
      _<arg1> (обязательный)_  
      Тип: **Строка.** Код, который необходимо выполнить.  
      _<arg2> и др. (необязательные)_  
      Тип: **Строка, Число, Булево** или др. Параметры, передаваемые выполняемому коду.

_Возвращаемое значение:_  
      Производится выполнение заданного кода. Возвращаемое значение отсутствует.

_Пример:_  
      `_EvalAsync ( 'lib_reminder.ShowReminder( true )' );         EvalAsync ( 'lib_telephony.OnIncomingCallDetected( phoneCallRecord )', 'phoneCallRecord', phoneCallRecord );_`
