## Compare

**Compare** – сравнение двух значений.

Аргументы сравниваются в соответствии с типом данных. Аргументы типа _Число_ – сравниваются по правилам сравнения чисел, аргументы типа _Дата_ – по правилам сравнения дат, аргументы типа _Строка_ – по правилам сортировки по возрастанию (чем строка стоит выше в сортировке, тем она считается меньше).

Примечание: Если один из аргументов имеет тип _Строка_, то второй аргумент также автоматически приводится к типу _Строка_ и производится сравнение строк_._

Внимание! Функция _**alert**_ может работать с целыми отрицательными числами некорректно. Поэтому для вывода результата функции **Compare** с помощью alert можно использовать дополнительно функции **StrSignedInt** или **OptReal** (см. пример ниже).  

_Синтаксис:_  
      **Compare (<value1>,< value2>)** 

_Аргументы:_  
      _<value1> (обязательный)_  
      Тип: **Число, Дата или Строка**. Исходное значение первого аргумента для сравнения.  
      _<value2> (обязательный)_  
      Тип: **Число, Дата или Строка**. Исходное значение второго аргумента для сравнения.

_Возвращаемое значение:_  
      Тип: **Целое число со знаком**. Результат выполнения функции. Если _value1 = value2_ – возвращается _0_, если _value1 > value2_ – возвращается _1_, если _value1 < value2_ – возвращается _\-1_.   
      Если совместно с функцией **Compare** используется функция **StrSignedInt**, то результат преобразуется в строки _'0', '1', '-1'_.  
      Если совместно с функцией **Compare** используется функция **OptReal**, то результат преобразуется в действительные числа 0, 1, -1.

_Пример:_

     `_A1='abc';        A2='abc';        iRez = Compare (A1, A2); // результат равен 0        if (iRez < 0) alert ( "Первое значение меньше второго" );         else if (iRez == 0) alert ( "Первое значение равно второму" ); // выводит "Первое значение равно второму"              else alert ( "Первое значение больше второго" );_` 

     `_A1='abcde';        A2='abcdef';        iRez = Compare (A1, A2); // результат равен -1        if (iRez < 0) alert ( "Первое значение меньше второго" ); // выводит "Первое значение меньше второго"        else if (iRez == 0) alert ( "Первое значение равно второму" );              else alert ( "Первое значение больше второго" );         alert ( StrSignedInt (iRez) ); // использование функции StrSignedInt для вывода целого отрицательного значения с помощью alert; результат преобразуется в строку '-1'        alert ( OptReal (iRez) ); // использование функции OptReal для вывода целого отрицательного значения с помощью alert; результат преобразуется в действительное число -1           A1='abcde';        A2='abcdef';        iRez = Compare (A1, A2); // результат равен -1        if (iRez < 0) alert ( "Первое значение меньше второго" ); // выводит "Первое значение меньше второго"        else if (iRez == 0) alert ( "Первое значение равно второму" );              else alert ( "Первое значение больше второго" );         if (iRez < 0)         {             alert ( StrSignedInt (iRez) ); // использование функции StrSignedInt для вывода целого отрицательного значения с помощью alert; результат преобразуется в строку '-1'             alert ( OptReal (iRez) ); // использование функции OptReal для вывода целого отрицательного значения с помощью alert; результат преобразуется в действительное число -1        }        else alert ( iRez );_`  
 

     `_A1=2,1; // действительное число        A2=1; // целое число        iRez = Compare (A1, A2); // результат равен 1        if (iRez < 0) alert ( "Первое значение меньше второго" );         else if (iRez == 0) alert ( "Первое значение равно второму" );              else alert ( "Первое значение больше второго" ); // выводит "Первое значение больше второго"_`

     `_A1=2; // аргумент типа Число        A2='1abc'; // аргумент типа Строка        iRez = Compare (A1, A2); // первый аргумент автоматически приводится к типу Строка; результат равен 1        if (iRez < 0) alert ( "Первое значение меньше второго" );         else if (iRez == 0) alert ( "Первое значение равно второму" );              else alert ( "Первое значение больше второго" ); // выводит "Первое значение больше второго"_`
