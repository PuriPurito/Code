## IntModType

Возвращает тип склонения существительного в русском языке для заданного числа (например: _1 штука, 2 штуки, 5 штук_).

_Синтаксис:_  
      **IntModType (<num>)**

_Аргументы:_  
      _<num> (обязательный)_  
      Тип: **Целое число**. Исходное число.

_Возвращаемое значение:_  
      Тип: **Целое число**. Параметр, характеризующий тип склонения существительного в русском языке для заданного числа. Результат действия функции.  
      _Допустимые значения:_  
      **0** - "штук",  
      **1** - "штука",  
      **2** - "штуки".  
Например, для числа _1_ возвращается значение **1** («_1 штука_»), для чисел _2, 3 и 4_ – значение **2** (_«2 штуки», «3 штуки», «4 штуки»_), для чисел _0, 5, 6 и 7_ – **0** (_«0 штук», «5 штук» , «6 штук», «7 штук»_).

_Пример:_  
      `_A1 = IntModType ( 1 ); ;         alert ( A1 ); // возвращает 1         A2 = IntModType ( 3 ); ;         alert ( A2 ); // возвращает 2         A3 = IntModType ( 5 ); ;         alert ( A3 ); // возвращает 0_`
