## PamMd5

Вычисляет контрольную сумму по алгоритму PamMd5 (Md5 с использованием данных механизма аутентификации PAM (Pluggable Authentication Modules) (Подгружаемых модулей аутентификации)).

_Синтаксис:_  
      **PamMd5 (<data>)**

_Аргументы:_  
      _<data> (обязательный)_  
      Тип: **Строка.** Исходная строка, содержащая массив байтов.

_Возвращаемое значение:_  
      Тип: **Строка.** Результирующая контрольная сумма. Результат действия функции.

_Пример:_  
      `_A1 = PamMd5 ( 'hello' );         alert ( A1 ); // возвращает контрольную сумму_`
