## QuitApp

Вызывает завершение работы текущего приложения. Редко используемая функция. Используется в конвертерах, программах обновления.

_Синтаксис:_  
      **QuitApp ()**

_Аргументы:_  
      Функция вызывается без аргументов.

_Возвращаемое значение:_  
      Производится завершение работы текущего приложения. Возвращаемое значение отсутствует.

_Пример:_  
      `_QuitApp();_`
