## Cancel

Функция прерывает работу кода, в потоке которого данная функция находится, и вызывает исключение специального типа, соответствующее нажатию пользователями кнопки "Cancel".  
При запуске кода с сервера производит запись в журнале xhttp: "Action cancelled" без выдачи на экран сообщения об ошибке.  
При запуске кода с клиента открывает окно типа alert с сообщением: "Операция отменена пользователем".  
Управление может быть передано обработчику исключений, который производит обработку данного исключения.

_Синтаксис:_  
      **Cancel ()**

_Аргументы:_  
      Функция вызывается без аргументов.

_Возвращаемое значение:_  
      Производится вызов исключения типа "Cancel". Возвращаемое значение отсутствует.

_Пример 1:_  
      `_i = 0;         for (j = 0; j >= 0; j++)  // бесконечный цикл         {             if (i <= 3) {                alert ( 'i = ' +  i);                i++;              }             else {                     Cancel(); // прекращение работы программы при i>3             }             alert ( 'j = ' +  j);         }_`

_Пример 2:_  
      `_if ( Ps.runner.IsRunning )         {               Ps.runner.Stop ();               Cancel ();         }_`
