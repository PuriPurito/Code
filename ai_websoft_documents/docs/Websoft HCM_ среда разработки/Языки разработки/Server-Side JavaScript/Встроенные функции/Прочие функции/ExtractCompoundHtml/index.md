## ExtractCompoundHtml

Извлекает содержимое составного документа html (с вложенными файлами в формате ) в указанный файл, сохраняя все вложенные файлы относительно него.

_Синтаксис:_  
      **ExtractCompoundHtml (<html>, <fileUrl>)**

_Аргументы:_  
      _<html> (обязательный)_  
      Тип: **Строка.** Составной документ html.  
      _<fileUrl> (обязательный)_  
      Тип: **Строка.** Url файла, в который производится сохранение данных.

_Возвращаемое значение:_  
      Производится сохранение данных в файл. Возвращаемое значение отсутствует.

_Пример:_  
      `_file_url = UrlAppendPath ( tempDir, '1.htm' ); // фрагмент пути добавляется к заданному url         if ( attachment.text.HasValue ) // если объект attachment.text содержит значение               ExtractCompoundHtml ( attachment.text, file_url ); // из объекта attachment.text извлекается содержимое и сохраняется в файл file_url_`
