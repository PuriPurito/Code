## AppModuleUsed

Выдает значение _true_, если модуль, наименование которого указано в качестве аргумента, используется программой, и значение _false_, если указанный модуль программой не используется. Наименования стандартных модулей считываются из файла описания структуры приложения, наименование подключаемого модуля - из файла первичных настроек. Функция используется, например, в ядре программы, если необходимо использовать разные настройки для работы с различными подключаемыми модулями.

_Синтаксис:_  
      **AppModuleUsed (<moduleName>)**

_Аргументы:_  
      _<moduleName> (обязательный)_  
      Тип: **Строка.** Наименование модуля.

_Возвращаемое значение:_  
      Тип: **Булево.** Результат проверки использования модуля программой (_true_ – модуль используется программой, _false_ – модуль не используется программой). Результат действия функции.

_Пример:_  
      `_boolModuleIsUsed = AppModuleUsed ( 'module_datex' );                 if ( AppModuleUsed ( 'rcr' ) )               is_user_group = true;_`
