## MixColors

Смешивает два цвета в заданной пропорции.

_Синтаксис:_  
      **MixColors (<color1>, <color2>\[, <arg>\])**

_Аргументы:_  
      _<color1>, <color2> (обязательные)_  
      Тип: **Строка.** Смешиваемые цвета в формате _RGB-строки_, содержащие десятеричное обозначение цвета (_RGB-код_) (три целых числа от 0 до 255, обозначающих количество соответствующего цвета (красный, зелёный, синий) в итоговом цвете).  
      _<arg> (необязательный)_  
      Тип: **Действительное число**. Коэффициент, определяющий пропорцию значений цветов _<color1>_ и _<color2>_. В случае отсутствия этого коэффициента цвета будут смешаны в пропорции _1 к 1_.

_Возвращаемое значение:_  
      Тип: **Строка.** Строка, содержащая десятеричное обозначение результирующего цвета (_RGB-код_). Результат действия функции.

_Пример:_  
      `_A1 = MixColors ( '128,128,128', '64,64,64' );         alert ( A1 ); // возвращает строковое выражение '96,96,96' ( (128+64)/2=96 )                 A2 = MixColors ( '128,128,128', '64,64,64', 0.5 ); // значения цветов первого аргумента берутся с коэффициентом 0.5, значения цветов второго аргумента - с коэффициентом 1         alert ( A2 ); // возвращает строковое выражение '85,85,85' ( (128*0.5+64)/(0.5+1)=85,33 )_`
