## ClipboardFormatAvailable

Возвращает значение true, если пользователем в буфер (Clipboard) скопирована информация в заданном формате, и значение false, если буфер пуст или его содержимое не соответствует заданному формату.

_Синтаксис:_  
      **ClipboardFormatAvailable (<arg1>)**

_Аргументы:_  
      _<arg1> (обязательный)_  
      Тип: **Строка.** Наименование формата.  
      _Возможные примеры указания наименования формата:_  
      **_'text/plain'_**  
      _**'text/html'**_

_Возвращаемое значение:_  
      Тип: **Булево.** Возвращает значение, показывающее, скопирована ли пользователем информация в заданном формате в буфер (Clipboard) (_true_ – информация скопирована в буфер, _false_ – информация не скопирована в буфер). Результат действия функции.

_Пример:_  
      `_if ( ClipboardFormatAvailable( 'text/html' ) )         {               resumeText = GetClipboard( 'text/html' );         }_`
