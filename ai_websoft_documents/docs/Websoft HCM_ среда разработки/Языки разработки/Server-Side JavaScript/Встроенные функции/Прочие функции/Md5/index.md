## Md5

Вычисляет контрольную сумму по алгоритму Md5 и возвращает результат в бинарном формате (массив байтов).

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье

_Синтаксис:_  
**Md5 (<data>)**

_Аргументы:_  
_<data> (обязательный)_  
Тип: **Строка.** Исходная строка, содержащая массив байтов.

_Возвращаемое значение:_  
Тип: **Строка.** Результирующая контрольная сумма. Результат действия функции.

A1 = Md5 ( 'hello' );  
alert ( A1 ); // возвращает контрольную сумму в бинарном формате
