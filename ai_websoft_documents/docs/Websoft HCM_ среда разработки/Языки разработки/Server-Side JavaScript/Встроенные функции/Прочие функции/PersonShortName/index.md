## PersonShortName

Возвращает полное имя сотрудника в формате "Фамилия И.О."

_Синтаксис:_  
      **PersonShortName (<lastname>, <firstname>\[, <middlename>\])**

_Аргументы:_  
      _<lastname> (обязательный)_  
      Тип: **Строка.** Фамилия сотрудника.  
      _<firstname> (обязательный)_  
      Тип: **Строка.** Имя сотрудника.  
      _<middlename> (необязательный)_  
      Тип: **Строка.** Отчество сотрудника.

_Возвращаемое значение:_  
      Тип: **Строка.** Строковое значение полного имени сотрудника. Результат действия функции.

_Пример:_  
      `_lastname = 'Петров';         firstname = 'Иван';         middlename = 'Сергеевич';         FIO = PersonShortName ( lastname, firstname, middlename );         alert ( FIO ); // возвращает строковое значение 'Петров И.С.'_`
