## CheckPamMd5

Проверяет строку на соответствие контрольной сумме, вычисленной по алгоритму **PamMd5**.  
Алгоритм **PamMd5** вычисляет контрольную сумму Md5 с использованием данных механизма аутентификации PAM (Pluggable Authentication Modules) (Подгружаемых модулей аутентификации).

_Синтаксис:_  
      **CheckPamMd5 (<str>, <arg>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка.** Проверяемая строка.  
      _<arg> (обязательный)_  
      Тип: **Строка.** Контрольная сумма.

_Возвращаемое значение:_  
      Тип: **Булево.** Возвращает значение, показывающее соответствие строки контрольной сумме (true – строка соответствует контрольной сумме, false – строка не соответствует контрольной сумме). Результат действия функции.

_Пример:_  
      `_boolControl = CheckPamMd5 ( str, arg ); // Проверяет строку на соответствие контрольной сумме, вычисленной по алгоритму PamMd5_`
