## EnableLog

Включает/выключает заданный журнал, в который записывается информация (в строковом формате).  
С помощью данной функции может быть создан пользовательский журнал.  
См. также функцию **LogEvent**.

Включение/выключение журнала производится при выполнении агента на сервере.

Примечание - Запись обычно производится в папку _WebTutorAdmin\\Logs_.   
Название журнала формируется из аргумента  _<name>_ и текущей даты.   
Например, при выполнении функции **_EnableLog ( "log1", true )_** и текущей дате _8 февраля 2020 г._ название журнала будет следующим: _**log1-2020-02-08.log**_ .

_Синтаксис:_  
      **EnableLog (<name>\[, <enable>\])**

_Аргументы:_  
      _<name> (обязательный)_  
      Тип: **Строка.** Название журнала.  
      _<enable> (необязательный)_  
      Тип: **Булево.** Включить/выключить журнал (_true_ – включить журнал, _false_ – выключить журнал). Если аргумент не указан, по умолчанию принимается значение true.

_Возвращаемое значение:_  
      Производится включение/выключение заданного журнала. Возвращаемое значение отсутствует.

_Пример 1:_  
      _EnableLog ( "log1", true ); // пользовательский журнал с названием log1-<текущая дата>.log включен_

      `_try {               oResp = HttpRequest ( "https://ya.ru/423532452345", "get", null ); // такой страницы не существует         }         catch (err) {               LogEvent ( "log1", err ); // в пользовательский журнал записывается код ошибки: HTTP 404 Not Found          }_`

_Пример 2:_  
      `_EnableLog ( 'xquery', true ); // журнал 'xquery' включен         EnableLog ( 'xquery', false ); // журнал 'xquery' выключен         EnableLog ( 'xquery' ); // журнал 'xquery' включен                 EnableLog ( 'assessment_log', true ); // первый аргумент - название отдельного файла (журнала), в который будет записываться информация         LogEvent ( 'assessment_log', info ); // info – любая информация (в строковом формате), записываемая в журнал         EnableLog ( 'assessment_log', false ); // запись в журнал прекращена_`
