## SetHttpDefaultAuth

Выполняет авторизацию, используемую клиентом по умолчанию.

Данную функцию можно использовать только при работе с _spxml,_ т.к. в этом случае нет необходимости делать одновременные запросы по разным адресам.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**SetHttpDefaultAuth (<login>, <passw>)**

_Аргументы:_  
_<login> (обязательный)_  
Тип: **Строка.** Логин.  
_<passw> (обязательный)_  
Тип: **Строка.** Пароль.

_Возвращаемое значение:_  
Производится авторизация пользователя. Возвращаемое значение отсутствует.

SetHttpDefaultAuth ( log, pass );
