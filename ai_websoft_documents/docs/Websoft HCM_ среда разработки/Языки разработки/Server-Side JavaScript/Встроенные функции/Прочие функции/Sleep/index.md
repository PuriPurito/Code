## Sleep

Создает временную задержку, не загружая процессор.

_Синтаксис:_  
      **Sleep (<ticks>)**

_Аргументы:_  
      _<ticks> (обязательный)_  
      Тип: **Целое число**. Величина задержки в миллисекундах.

_Возвращаемое значение:_  
      Производится временная задержка при выполнении кода. Возвращаемое значение отсутствует.

_Пример:_  
      `_Sleep( 100 );                 var Array1 = ['one', 'two', 'three']; // массив Array1 включает в себя 3 элемента         for(q in Array1)         {               alert(q); // вывод на экран каждого элемента массива Array1               Sleep(1000); // временная задержка на 1000 миллисекунд         }_`
