## Max

Функция определяет максимальное значение из нескольких чисел, указанных в качестве аргументов.  
Если указан только один аргумент, то возвращается значение этого аргумента.  
См. также функцию Min.

_Синтаксис:_  
      **Max (<arg1>\[, <arg2>, <arg3>, ...\] )**

_Аргументы:_  
      _<arg1> (обязательный)_  
      Тип: **Действительное число**. Аргумент _1_ для сравнения.  
      _<arg2>, <arg3> и т.д. (необязательные)_  
      Тип: **Действительные числа**. Аргументы _2, 3_ и т.д. для сравнения.

_Возвращаемое значение:_  
      Тип: **Действительное число**. Результирующее максимальное значение. Результат действия функции.

_Пример:_  
      `_A1 = 123;         A2 = 5.5;         A3 = 12.3456;         A4 = Max (A1, A2, A3);         alert ( A4 ); // возвращает максимальное значение из указанных аргументов (123)_`
