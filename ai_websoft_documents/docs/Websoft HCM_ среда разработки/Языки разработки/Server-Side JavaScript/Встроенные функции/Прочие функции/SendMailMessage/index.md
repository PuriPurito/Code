## SendMailMessage

Вызывает отправку почтового сообщения тем способом, который был выбран в настройках (как правило, _Simple MAPI_). В качестве аргумента передается объект, созданный с помощью функции MailMessage.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**SendMailMessage (<arg1>)**

_Аргументы:_  
_<arg1> (обязательный)_  
Тип: **Объект XmlElem**. Ссылка на объект, созданный при помощи функции MailMessage.

_Возвращаемое значение:_  
Производится отправка почтового сообщения. Возвращаемое значение отсутствует.

message = MailMessageFromMimeStr( item.mime\_body ); // формирование электронного почтового сообщения  
SendMailMessage( message ); // отправление электронного почтового сообщения  
SendMailMessage( Doc.TopElem );
