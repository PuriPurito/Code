## ColorNewBrightness

Изменяет яркость цвета, переданного в качестве аргумента.

_Синтаксис:_  
      **ColorNewBrightness (<color>, <ratio>)**

_Аргументы:_  
      _<color> (обязательный)_  
      Тип: **Строка.** Цвет в формате _RGB_ - строка, содержащая десятеричное обозначение цвета (_RGB-код_) (три целых числа от 0 до 255, обозначающих количество соответствующего цвета (красный, зелёный, синий) в итоговом цвете). Исходное значение.  
      _<ratio> (обязательный)_  
      Тип: **Действительное число** . Коэффициент, определяющий, во сколько раз увеличивается/уменьшается яркость.

_Возвращаемое значение:_  
      Тип: **Строка.** Строка, содержащая десятеричное обозначение результирующего цвета (_RGB-код_). Результат действия функции.

_Пример:_  
      `_A1 = ColorNewBrightness ( '128,128,128', 0.5 );         alert ( A1 ); // возвращает строковое выражение '64,64,64'_`
