## ProcessExecute

Вызывает выполнение внешнего процесса, не связанного с системой.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

_Синтаксис:_  
**ProcessExecute (<path>\[, <cmdLine>, <options>\])**

_Аргументы:_  
_<path> (обязательный)_  
Тип: **Строка.** Путь к исполняемому файлу или имя исполняемого файла.  
_<cmdLine> (необязательный)_  
Тип: **Строка.** Аргументы командной строки.  
_<options> (необязательный)_  
Тип: **Строка.** Набор опций, записываемых через точку с запятой и имеющих вид "опция=значение; ...".  
  
Допустимый набор опций:

*   _**work-dir**_ – рабочая директория для процесса (строковая переменная).
*   **_sys_** – системный процесс. Если указана опция _sys=1_, то в качестве первого аргумента функции можно указывать не путь до исполняемого файла, а имя системного процесса.
*   _**wait**_ – дожидаться завершения процесса. Если указана опция _wait=1_, то функция вернет код завершения процесса (_0_ - успешное завершение, иначе - ошибка). В остальных случаях функция ничего не возвращает.
*   _**hidden**_ – запуск без пользовательского интерфейса. Если указана опция _hidden=1_, то производится запуск без пользовательского интерфейса (рекомендуется включать данную опцию, если функция вызывается с сервера).

_Возвращаемое значение:_  
Результат действия функции. Возвращаемое значение зависит от вида запускаемого процесса и условий запуска:

1.  Тип: **Целое число**. При задании опции _wait=1_ обычно возвращает _0_, если запуск процесса завершился успешно, или другое целое число – в других случаях.
2.  _Undefined_ – наличие ошибок неизвестно.
3.  Возвращаемое значение отсутствует – в случае, если не задана опция _wait=1_, или при запуске некоторых процессов Windows.

retVal = ProcessExecute ( appPath, execParam );  
retVal = ProcessExecute ( 'C:\\Temp\\pkzipc.exe', ' -add -rec -path=current xxx.zip 1.htm 2.htm', ' sys=1;wait=1;hidden=1;work-dir=C:\\Temp' );
