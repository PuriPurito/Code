## UserError

Выводит информацию с текстом ошибки при генерировании исключения, определяемого программистом, с помощью оператора _throw_. При этом выполнение кода будет остановлено (инструкции после оператора throw не будут выполнены).

_Синтаксис:_  
      **UserError (<str>)**

_Аргументы:_  
      _<str> (обязательный)_  
      Тип: **Строка.** Строковое выражение с текстом ошибки.

_Возвращаемое значение:_  
      Тип: **Строка.** Текст, передаваемый в сообщение об ошибке. Результат действия функции.

_Пример:_  
      `_throw UserError ('В этом месте допущена ошибка.\nОператор throw был установлен программистом Петровым И.С.\n');_`
