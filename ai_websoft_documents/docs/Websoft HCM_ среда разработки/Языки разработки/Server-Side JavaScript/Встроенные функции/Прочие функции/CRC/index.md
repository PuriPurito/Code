## CRC

Вычисляет контрольную сумму по алгоритму CRC.

_Синтаксис:_  
      **CRC (<data>)**

_Аргументы:_  
      _<data> (обязательный)_  
      Тип: **Строка.** Исходная строка, содержащая массив байтов.

_Возвращаемое значение:_  
      Тип: **Целое число**. Результирующая контрольная сумма. Результат действия функции.

_Пример:_  
      `_A1 = CRC ( 'hello' );         alert ( A1 ); // возвращает контрольную сумму_`
