## StatusMsg

Записывает текст в сроку состояния в главном окне программы. Обычно используется для показа количества найденных объектов в списке.

_Синтаксис:_  
      **StatusMsg (<msg>)**

_Аргументы:_  
      _<msg> (обязательный)_  
      Тип: **Строка.** Текст, который выводится в строке состояния.

_Возвращаемое значение:_  
      Производится вывод текст в сроку состояния. Возвращаемое значение отсутствует.

_Пример:_  
      `_var Array1 = ['one', 'two', 'three']; // массив Array1 включает в себя 3 элемента         StatusMsg ( 'Количество элементов в массиве: ' + ArrayCount (Array1) ); // записывает текст в сроку состояния_`
