## IsKeyPressed

Проверяет, нажата ли в данный момент клавиша, код которой указан в качестве аргумента. Обычно проверятся клавиши _Ctrl (код = 17)_ или _Shift (код = 16)_.

_Синтаксис:_  
      **IsKeyPressed (<arg1>)**

_Аргументы:_  
      _<arg1> (обязательный)_  
      Тип: **Целое число**. Код клавиши.  
      _Стандартные коды основных клавиш на клавиатуре_:  
  
      Коды клавиш в шестнадцатеричном формате – см. здесь.

_Возвращаемое значение:_  
      Тип: **Булево.** Результат проверки нажатия клавиши (_true_ – клавиша нажата, _false_ – клавиша не нажата). Результат действия функции.

_Пример:_  
      `_if ( IsKeyPressed ( 17 )) // проверяется нажатие клавиши Ctrl (код клавиши - 17)               newStatus = 'Клавиша нажата';         else               newStatus = 'Клавиша не нажата';         alert ( newStatus ); // если клавиша Ctrl нажата, выводится сообщение 'Клавиша нажата', если не нажата - сообщение 'Клавиша не нажата'_`
