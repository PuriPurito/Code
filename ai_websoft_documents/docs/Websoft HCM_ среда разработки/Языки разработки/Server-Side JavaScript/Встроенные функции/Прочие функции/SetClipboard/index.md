## SetClipboard

Вызывает копирование указанной информации в буфер (Clipboard).

_Синтаксис:_  
      **SetClipboard (<arg1>)**

_Аргументы:_  
      _<arg1> (обязательный)_  
      Тип: **Строка.** Информация, которую необходимо скопировать в буфер.

_Возвращаемое значение:_  
      Производится копирование информации в буфер. Возвращаемое значение отсутствует.

_Пример:_  
      `_A1 = 'Программа Webtutor';         SetClipboard ( A1 ); // копирует в буфер обмена строковое выражение 'Программа Webtutor'         resumeText = GetClipboard (); // возвращает данные из буфера обмена         alert (resumeText); // выводит на экран строковое выражение 'Программа Webtutor'_`
