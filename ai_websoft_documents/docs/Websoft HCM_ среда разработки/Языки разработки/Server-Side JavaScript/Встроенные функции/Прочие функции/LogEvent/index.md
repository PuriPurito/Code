## LogEvent

Делает запись в файл указанного журнала.  
Если наименование журнала не указано, то запись делается в основной журнал (лог) системы.  
См. также функции **alert** и **EnableLog**.

Запись в журнал производится при выполнении агента на сервере.

_Синтаксис:_  
      **LogEvent (<name>, <text>)**

_Аргументы:_  
      _<name> (необязательный)_  
      Тип: **Строка.** Наименование журнала. Если наименование журнала не указано, то запись делается в основной журнал системы.  
      _<text> (обязательный)_  
      Тип: **Строка.** Текст, записываемый в журнал.

_Возвращаемое значение:_  
      Выполняется запись в журнал. Возвращаемое значение отсутствует.

_Пример 1:_  
      `_EnableLog ( "log1", true ); // пользовательский журнал с названием log1-<текущая дата>.log включен         try {               oResp = HttpRequest ( "https://ya.ru/423532452345", "get", null ); // такой страницы не существует         }         catch (err) {               LogEvent ( "log1", err ); // в пользовательский журнал записывается код ошибки: HTTP 404 Not Found          }_`

_Пример 2:_  
      `_EnableLog ( 'assessment_log', true ); // первый аргумент - название отдельного файла (журнала), в который будет записываться информация         LogEvent ( 'assessment_log', info ); // info – любая информация (в строковом формате), записываемая в журнал         EnableLog ( 'assessment_log', false ); // запись в журнал прекращена                 if ( user == undefined )               LogEvent( "", 'WARNING: Security admin is not found: ' + login ); // запись производится в основной журнал (лог) системы_`
