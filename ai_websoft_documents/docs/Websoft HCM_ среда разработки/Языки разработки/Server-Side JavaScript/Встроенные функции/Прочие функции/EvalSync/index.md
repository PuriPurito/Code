## EvalSync

Выполняет заданный код в основном потоке при наступлении следующего системного события. Функция помещает этот код в очередь, и при следующем системном событии он выполняется. Эта функция блокирует поток и дожидается окончания выполнения вызванного кода.  
См. также EvalAsync.  
Если в результате выполнения кода определяется единственное значение, то функция возвращает это значение. Если же в результате выполнения кода определяется несколько значений, то функция возвращает _undefined_.

_Синтаксис:_  
      **EvalSync (<arg1>\[, <arg2>, ...\] )**

_Аргументы:_  
      _<arg1> (обязательный)_  
      Тип: **Строка.** Код, который необходимо выполнить.  
      _<arg2> и др. (необязательные)_  
      Тип: **Строка, Число, Булево** или др. Параметры, передаваемые выполняемому коду.

_Возвращаемое значение:_  
      Тип: **Строка, Число, Булево** или др. Результат выполнения заданного кода или значение undefined. Результат действия функции.

_Пример:_  
      `_EvalSync ( 'BuildEntriesStart()' );                 if ( EvalSync ( 'this.entriesBuildDate < DateOffset( CurDate, 0 - 30 * 60 )' ) )               BuildEntries();                 A1 = 3;         A2 = 5;         alert ( EvalSync ( 'A1 < A2' ) ); // в результате выполнения кода определяется единственное значение - true; функция возвращает true         if ( EvalSync ( 'A1 < A2' ) )               alert ( 'A1 меньше A2' ); // выводится сообщение 'A1 меньше A2'         else               alert ( 'A1 больше A2' ); // данное сообщение не выводится, так как при данных условиях функция возвращает true_`
