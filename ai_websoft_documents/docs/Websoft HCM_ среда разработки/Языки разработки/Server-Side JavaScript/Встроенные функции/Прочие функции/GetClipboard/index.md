## GetClipboard

Возвращает данные заданного формата из буфера (Clipboard).  
Если аргумент не указан, то производится выгрузка данных в любом формате.

_Синтаксис:_  
      **GetClipboard (\[<arg1>\])**

_Аргументы:_  
      _<arg1> (необязательный)_  
      Тип: **Строка.** Обозначение формата данных, которые должны быть выгружены.  
      _Возможные примеры указания наименования формата данных:_  
      _**'text/plain'  
      'text/html'**_

_Возвращаемое значение:_  
      Тип: **Строка.** Данные, выгружаемые из буфера. Результат действия функции.

_Пример:_  
      `_if ( ClipboardFormatAvailable( 'text/html' ) )         {               resumeText = GetClipboard( 'text/html' ); // выгрузка данных в формате 'text/html'         }                 resumeText = GetClipboard(); // выгрузка данных в любом формате_`
