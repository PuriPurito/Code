## EnableLogExt

Включает заданный журнал. В отличие от функции EnableLog позволяет задать дополнительные опции ведения журнала.

 Запуск функции должен производиться с сервера.

 Если вывод журнала  производится в папку, отличную от стандартной, то эта папка должна сущесттвовать и к ней должен иметься доступ на запись. В противном случае запись журнала производится в стандартную папку журналов системы: \\WebSoftServer\\Logs\\

_Синтаксис:_  
      **EnableLogExt (<name>\[, <options>\])**

_Аргументы:_  
      _<name> (обязательный)_  
      Тип: **Строка.** Название журнала.  
      _<options> (необязательный)_  
      Тип: **Строка.** Набор опций вида _'param1=value1;param2=value2;...'_.  
      _Возможные опции:_  
      _**life-time**_ \- период, на котрый заводится новый файла журнала (_'day', 'month', 'permanent'_). По умолчанию свой файл журнала заводится на каждую дату (_'day'_).  
      _**base-dir**_ \- директория, в которой будут заводиться журнал (строковая переменная). По умолчанию используется директория _Logs_ в установочной директории.  
      **_use-std-event-prefix_** \- Включать в начало каждой строки журнала стандартный префикс (дата, время, ID потока) (булева переменная). По умолчанию - _true_.  
      _**header-str**_ \- строка заголовка, добавляемая в начало каждого нового файла журнала (строковая переменная). По умолчанию строка заголовка не добавляется.

_Возвращаемое значение:_  
      Производится включение заданного журнала. Возвращаемое значение отсутствует.

_Пример 1 (запуск кода - с сервера):_  
      `_text = 'Hello!';           EnableLogExt ( 'wt_api', 'life-time=month' ); // открытие журнала 'wt_api' на месяц         LogEvent ( 'wt_api', text ); // запись значения текстовой переменной text в журнал 'wt_api'_`

_Пример 2 (запуск кода - с сервера):_  
     `_alert("Тестируем логи START");        try {             alert(UrlToFilePath("x-local:d://WebSoft/Files/Matrix/Logs")); // Выводит d:\WebSoft\Files\Matrix\Logs             EnableLogExt("matrix", "base-dir=" + UrlToFilePath("x-local:d://WebSoft/Files/Matrix/Logs"));             // Журнал записывается в папку d:\WebSoft\Files\Matrix\Logs, которая должна существовать и к которой у программы должен быть доступ_`  
          `_LogEvent("matrix", "Тестирование лога");        }         catch(error) {             alert(error);        }        alert("Тестируем логи FINISH");_`
