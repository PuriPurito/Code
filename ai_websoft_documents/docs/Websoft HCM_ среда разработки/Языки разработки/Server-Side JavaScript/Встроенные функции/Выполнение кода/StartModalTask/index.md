## StartModalTask

Обозначает запуск фрагмента кода с упрощенной индикацией пользователю.  
Прогресс выполнения будет обозначаться путем периодического вызова функции ModalTaskMsg.  
В часто вызываемом коробочном коде данную функцию использовать не рекомендуется, ввиду наличия более удобного для пользователя механизма с прогресс-индикаторами. Функцию хорошо использовать в одноразовом или редко используемом коде ввиду его простоты.  
Примечание - Модальные сообщения работают только в экранном (а не в фоновом) режиме.

_Синтаксис:_  
      **StartModalTask (<taskTitle>)**

_Аргументы:_  
      _<taskTitle> (обязательный)_  
      Тип: **Строка**. Название задачи с упрощенной индикацией.

_Возвращаемое значение:_  
      Производится запуск фрагмента кода с упрощенной индикацией. Возвращаемое значение отсутствует.

_Пример:_  
      `_StartModalTask ( 'Импорт данных' );         for (i = 0; i < 3; i++)         {               ModalTaskMsg ( 'Объект ' + i );               alert( 'Объект ' + i );         }         FinishModalTask ( 'Импорт данных' );_`
