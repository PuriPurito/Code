## EvalCodePageUrl

Интерпретирует содержимое страницы по правилам ASP из заданного файла.

_Синтаксис:_  
      **EvalCodePageUrl (<pageUrl>\[, <option>\])**

_Аргументы:_  
      _<pageUrl> (обязательный)_  
      Тип: **Строка**. Url, содержащий текст активной страницы.  
      _<option> (необязательный)_  
      Тип: **Строка**. Опция.  
      Поддерживается единственная опция:  
      **strict-errors=1** - завершать функцию с ошибкой, если таковая возникнет при обработке страницы. По умолчанию, в случае возникновения ошибки ее текст добавляется к результату, а функция завершается без ошибки.

_Возвращаемое значение:_  
      Тип: **Строка**. Результат действия функции.

_Пример:_  
      `_dest.chart_page_html_1 = EvalCodePageUrl ( 'x-app://base1/base1_stat_chart_fragment.htm', 'strict-errors=1' );         dest.chart_page_html_2 = EvalCodePageUrl ( 'x-app://base1/base1_stat_chart_fragment.htm' );_`
