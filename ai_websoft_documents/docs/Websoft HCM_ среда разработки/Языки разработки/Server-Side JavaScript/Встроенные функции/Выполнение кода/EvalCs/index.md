## EvalCs

Выполняет код _JavaScript_ аналогично функции eval, но внутри т.н. критической секции, что исключает одновременно выполнение кода из разных потоков.  
Функция как правило используется для доступа к данным типа _Non Thread Safe_, например, к глобальным XML-документам.  
Данной функцией следует пользоваться с осторожностью, поскольку глобальная секция является общей для всего приложения. Не следует выполнять внутри критической секции код, который может занять продолжительное время (обращения к диску, к сети и т.д.)

_Синтаксис:_  
      **EvalCs (<codeString>)**

_Аргументы:_  
      _<codeString> (обязательный)_  
      Тип: **Строка**. Строковое значение, содержащее код JavaScript.

_Возвращаемое значение:_  
      Тип: **Строка, Число, Булево** или др. Результат выполнения кода.

_Пример:_  
      `_EvalCs ( action.code ); // выполнение кода action.code         EvalCs ( 'global_agents.agent_completed = true' ); // выполнение кода global_agents.agent_completed = true         EvalCs ( 'running_agent_exists_core( agentID )' ); // выполнение пользовательской функции running_agent_exists_core с аргументом agentID                 EvalCs (' alert(Date()); A=1; alert(A); '); // выводит текущую дату и число 1_`
