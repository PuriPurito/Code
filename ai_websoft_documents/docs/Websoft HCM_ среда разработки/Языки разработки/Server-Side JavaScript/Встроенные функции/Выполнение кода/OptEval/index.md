## OptEval

Выполняет код JavaScript, который, возможно, завершится с ошибкой. В случае ошибки возвращается значение, указанное в аргументе <defaultVal>, или _undefined_.

_Синтаксис:_  
      **OptEval (<code>\[, <defaultVal>\])**

_Аргументы:_  
      _<code> (обязательный)_  
      Тип: **Строка**. Выполняемый код JavaScript.  
      _<defaultVal> (необязательный)_  
      Тип: **Строка** или др. Значение, возвращаемое в случае ошибки. Если аргумент не указан, а код завершается с ошибкой, то возвращается _undefined_.

_Возвращаемое значение:_  
      Тип: **Строка, Число, Булево** или др. Путь к директории (папке) для хранения данных пользователя. Результат действия функции.

_Пример:_  
      `_res1 = OptEval ( ' alert(Date()); A=1; alert(A); return 2; ' , null ); // выводит текущую дату и число 1         alert (res1); // возвращает 2         res2 = OptEval ( ' alert(1/0); return 2; ' , 'Ошибка'); // код содержит ошибку (деление на 0)         alert (res2); // возвращает 'Ошибка'         res3 = OptEval ( ' alert(1/0); return 2; ' ); // код содержит ошибку (деление на 0), второй аргумент отсутствует         alert (res3); // возвращает indefined_`
