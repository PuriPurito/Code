## IsCancelError

Проверяет, является ли заданный объект типа **Error** ошибкой отмены операции.

_Синтаксис:_  
      **IsCancelError (<e>)**

_Аргументы:_  
      _<e> (обязательный)_  
      Тип: **Объект Error**. Ошибка.

_Возвращаемое значение:_  
      Тип: **Булево**. Возвращает значение, показывающее, является ли заданный объект типа Error ошибкой отмены операции. Результат действия функции.

_Пример:_  
      `_try         {               A1 = 1/0; // деление на 0         }         catch ( e )         {               alert ( IsCancelError( e ) ); // возвращает false               if ( ! IsCancelError( e ) )                     alert( 'Невозможно выполнить программу: ' + ExtractUserError( e ) );         }_`
