## ExtractUserError

Извлекает из объекта типа **Error** сообщение об ошибке. 

_Синтаксис:_  
      **ExtractUserError (<e>)**

_Аргументы:_  
      _<e> (обязательный)_  
      Тип: **Объект Error**. Ошибка.

_Возвращаемое значение:_  
      Тип: **Строка**. Сообщение об ошибке. Результат действия функции.

_Пример:_  
      `_try         {               A1 = 1/0; // деление на 0         }         catch ( e )         {               alert( 'Невозможно выполнить программу: ' + ExtractUserError( e ) );         }_`
