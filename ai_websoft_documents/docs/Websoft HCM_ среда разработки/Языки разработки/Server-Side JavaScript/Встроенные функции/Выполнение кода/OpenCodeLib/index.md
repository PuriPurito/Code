## OpenCodeLib

Открывает документ (библиотеку) либо с расширением _XML_, содержащий набор методов, и возвращает его корневой элемент, либо с расширением _JS_, содержащий функции, возвращает псевдо-документ (псевдо-форму), содержащий те же функции. Далее могут быть выполнены указанные методы и функции.  
Действие похоже на действие функции EvalCodeUrl, но не тождественно ей. При выполнении сторонних функций при помощи EvalCodeUrl, переменные внешнего кода видны внутри сторонних функций, что может привести к появлению ошибок при совпадении имен переменных.  
_OpenCodeLib_ лишен этого недостатка, т.к. приводит к загрузке функций из внешнего источника как независимых методов, каждый из которых выполняется в собственном окружении. Но в этом случае, в отличие от EvalCodeUrl, загружаемый _JS_\-файл не может содержать глобальных переменных.

_Синтаксис:_  
      **OpenCodeLib (<url>)**

_Аргументы:_  
      _<url> (обязательный)_  
      Тип: **Строка**. Url загружаемого документа с расширением XML или JS.

_Возвращаемое значение:_  
      Тип: **Объект XmlDoc**. Ссылка на документ. Результат действия функции.

_Пример:_  
      `_lib = OpenCodeLib( 'x-app://gate/gate_lib_gate.js' );         config = lib.get_browser_plugin_config();            var test_lib = OpenCodeLib ("x-local://custom_folder//new_lib.js");                       OpenCodeLib ( 'lib_backup.js' ).RunBackup();_`
