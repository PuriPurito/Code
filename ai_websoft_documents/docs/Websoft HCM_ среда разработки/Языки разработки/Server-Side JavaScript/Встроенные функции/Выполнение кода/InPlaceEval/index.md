## InPlaceEval

Выполняет код _JavaScript_ в текущем окружении. В отличие от функции eval код выполняется на том же уровне (переменные, объявленные внутри кода, будут видны снаружи) и не позволяет возвращать значение.

_Синтаксис:_  
      **InPlaceEval (<code>)**

_Аргументы:_  
      _<code> (обязательный)_  
      Тип: **Строка**. Выполняемый код JavaScript.

_Возвращаемое значение:_  
      Производится выполнение кода JavaScript. Возвращаемое значение отсутствует.

_Пример 1:_  
      `_InPlaceEval ( action.code ); // выполнение кода action.code         InPlaceEval( tools_web.env_to_script( Env ) ); // выполнение функции tools_web.env_to_script с аргументом Env                 InPlaceEval (' alert(Date()); A=1; alert(A); '); // выводит текущую дату и число 1_`

_Пример 2:_  
      `_var x = 0;         InPlaceEval ('x=1');          alert ( x ); // выводится число 1_`  
  
      `_var y = 0;         s1 = 'y=1';         InPlaceEval ( s1 );          alert ( y ); // выводится число 1_`
