## FinishModalTask

Обозначает завершение фрагмента кода с упрощенной индикацией пользователю, начатого путем вызова функции StartModalTask.  
Примечание - Модальные сообщения работают только в экранном (а не в фоновом) режиме.

_Синтаксис:_  
      **FinishModalTask (\[<taskTitle>\])**

_Аргументы:_  
      _<taskTitle> (необязательный)_  
      Тип: **Строка**. Название задачи с упрощенной индикацией.

_Возвращаемое значение:_  
      Производится завершение фрагмента кода с упрощенной индикацией. Возвращаемое значение отсутствует.

_Пример:_  
      `_StartModalTask ( 'Импорт данных' );         for (i = 0; i < 3; i++)         {               ModalTaskMsg ( 'Объект ' + i );               alert( 'Объект ' + i );         }         FinishModalTask ( 'Импорт данных' );_`
