## eval

Выполняет код JavaScript в текущем окружении. Аналогична стандартной функции JavaScript с тем же именем, но, в отличие от нее, код выполняется на отдельном уровне (переменные, объявленные внутри кода, не будут видны снаружи).  
См. также InPlaceEval.

_Синтаксис:_  
      **eval (<code>)**

_Аргументы:_  
      _<code> (обязательный)_  
      Тип: **Строка**. Выполняемый код JavaScript.

_Возвращаемое значение:_  
      Тип: **Строка, Число, Булево** или др. Результат выполнения кода.

_Пример:_  
      `_eval ( action.code ); // выполнение кода action.code                 eval (' alert(Date()); A=1; alert(A); '); // выводит текущую дату и число 1_`
