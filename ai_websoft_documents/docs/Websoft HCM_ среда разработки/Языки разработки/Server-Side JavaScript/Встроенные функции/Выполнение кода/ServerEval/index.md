## ServerEval

Выполняет заданный код на сервере, и возвращает результат выполнения кода (только в виде строки) или значение _undefined_. Если эта функция вызывается на однопользовательской локальной версии программы, она полностью аналогична функции eval.

_Синтаксис:_  
      **ServerEval (<code>)**

_Аргументы:_  
      _<code> (обязательный)_  
      Тип: **Строка**. Код, который будет выполняться на сервере.

_Возвращаемое значение:_  
      Тип: **Строка**. Результат выполнения кода (может также принимать значение _undefined_).

_Пример:_  
      `_ServerEval ( action.code ); // выполнение кода action.code на сервере_`
