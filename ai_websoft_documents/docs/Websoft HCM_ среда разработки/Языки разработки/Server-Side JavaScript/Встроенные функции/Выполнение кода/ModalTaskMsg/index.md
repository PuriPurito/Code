## ModalTaskMsg

Обозначает текущий статус выполнения фрагмента кода с упрощенной индикацией пользователю, начатого путем вызова функции StartModalTask.  
Примечание - Модальные сообщения работают только в экранном (а не в фоновом) режиме.

_Синтаксис:_  
      **ModalTaskMsg (<msg>)**

_Аргументы:_  
      _<msg> (обязательный)_  
      Тип: **Строка**. Строка статуса.

_Возвращаемое значение:_  
      Производится вывод текущего статуса фрагмента кода с упрощенной индикацией. Возвращаемое значение отсутствует.

_Пример:_  
      `_StartModalTask ( 'Импорт данных' );         for (i = 0; i < 3; i++)         {               ModalTaskMsg ( 'Объект ' + i );               alert( 'Объект ' + i );         }         FinishModalTask ( 'Импорт данных' );_`
