## EvalCodePage

Интерпретирует содержимое страницы по правилам ASP из заданной строки.

_Синтаксис:_  
      **EvalCodePage (<pageData>\[, <raiseErrors>\])**

_Аргументы:_  
      _<pageData> (обязательный)_  
      Тип: **Строка**. Строка, содержащая текст страницы.  
      _<raiseErrors> (необязательный)_  
      Тип: **Булево**. Аргумент, указывающий на завершение функции с ошибкой, если таковая возникнет при обработке страницы (true). По умолчанию, в случае возникновения ошибки ее текст добавляется к результату, а функция завершается без ошибки.

_Возвращаемое значение:_  
      Тип: **Строка**. Результат действия функции.

_Пример:_  
      `_message_1.text = EvalCodePage( template.text, true );         message_2.text = EvalCodePage( template.text );_`
