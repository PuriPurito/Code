## Server-Side JavaScript

Бизнес-логика системы WebTutor реализована на собственной платформе SPXML, представляющей собой интерпретатор Server-Side JavaScript и объектную модель данных, к которой возможно обращение из этого скрипта.

Более подробный справочник по платформе здесь: http://docs.datex.ru/
