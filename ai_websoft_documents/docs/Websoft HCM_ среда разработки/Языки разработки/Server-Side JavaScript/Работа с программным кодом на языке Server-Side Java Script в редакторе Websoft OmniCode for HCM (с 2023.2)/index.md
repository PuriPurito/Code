## Работа с программным кодом на языке Server-Side Java Script в редакторе Websoft OmniCode for HCM (с 2023.2)

Редактор Websoft OmniCode for HCM позволяет создавать на языке Server-Side Java Script различные типы объектов, например, выборки, агенты сервера, удаленные действия и т.д. Программный код на языке Server-Side Java Script воспроизводится и обрабатывется в редакторе Websoft OmniCode for HCM без изменений (как в системе Websoft HCM).

Редактор Websoft OmniCode for HCM не позволяет выполнять отладку программного кода на языке Server-Side Java Script (отладка доступна только для кода на языке C#).
