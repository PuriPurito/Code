## ForeignElem()

Аналог атрибута ForeignElem для XQuery. Возвращает запись сопряженного каталога (целевой объект).  
Вызывается как обычный атрибут.  
См. также **описание атрибута ForeignElem**.

Ошибочное использование функции **ForeignElem()** (отсутствие в системе вызываемого каталога, некорректный синтаксис выражения и т.д.) завершается ошибкой сервера 500.

Функция **ForeignElem()** может быть использована в системе двумя способами:  
1) Как метод поля виртуального объекта запроса _$elem/parent\_id/ForeignElem()/name._ Данное выражение работает корректно только на XML-базе. В этом случае функция используется без параметров. Возвращается конкретное поле записи сопряженного каталога - скаляр.   
2) Как функция типа _ForeignElem( $elem/parent\_id )/name_ \- без указания объекта впереди, но с параметром - поля, для которого надо вернуть запись сопряженного каталога. Данное выражение работает корректно и на XML-базе, и в реляционной СУБД. Также возвращается конкретное поле записи сопряженного каталога - скаляр.   
  
На сайте Datex приведен пример использования функции ForeignElem():  
_for $elem in candidates order by $elem/state\_id/ForeignElem()/name return $elem_  
Данный пример работает в EStaff только на XML-базе .  
  
В последних версиях Websoft HCM используется реляционная система управления базами данных (в комплекте с мостом unibridge для обеспечения вариативности использования СУБД), поэтому часть вызовов функций может не работать или работать некорректно.  
В связи с этим на любой базе рекомендуется использовать выражение ForeignElem(), описываемое в настоящей статье:  
_for $elem in career\_reserves where ForeignElem($elem/person\_id)/org\_id = 6932369708268000789 return $elem_

При отсутствии в сопряженном каталоге записей, на которые в системе имеются ссылки  (например, в случае некорректного удаления записи, при наличии «битых» ссылок и т.д.), в XML-базе использование функции ForeignElem() вызовет ошибку и прекращение работы программы, а в реляционной СУБД - выдаст корректный результат. 

_Синтаксис:_  
      **ForeignElem ($elem/<field1>)/<field2>**

_Аргументы:_  
     _<field1> (обязательный)_  
      Тип: **Строка**. Название идентификатора поля, для которого нужно вернуть запись сопряженного каталога.  
     _<field2> (обязательный)_  
      Тип: **Строка**. Название идентификатора поля в сопряженном каталоге.

_Возвращаемое значение:_  
      Тип: **Скаляр**. Значение указанного поля записи сопряженного каталога.

 _Пример:_  
  
_squery = "for $elem in career\_reserves where ForeignElem($elem/person\_id)/org\_id = 6932369708268000789 return $elem"; // выполняется поиск записей, для которых значение поля org\_id сопряженного каталога равно 6932369708268000789_  
_squery = "for $elem in career\_reserves order by ForeignElem($elem/person\_id)/org\_id return $elem"; // выполняется сортировка по значению поля org\_id сопряженного каталога_
