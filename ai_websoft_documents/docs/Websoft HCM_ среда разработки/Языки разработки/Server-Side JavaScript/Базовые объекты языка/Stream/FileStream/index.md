## FileStream

Объект FileStream позволяет читать данные из файла на диске, либо записывать данные в файл. Наследует все свойства и методы объекта Stream.

По умолчанию файл открывается на чтение, если не заданы другие опции.

Данная функция не работает в тонком клиенте (в браузере). Для корректной работы функции рекомендуется переносить обработку данных на сервер. Подробнее в статье.

### Описание

Поддерживаются опции:

*   **Write** – открывать файл на запись (bool).
*   **CreateNew** – создавать файл в случае его отсутствия (bool). Обычно используется вместе с опцией OpenExisting.
*   **Truncate** – обнулять содержимое файла (bool).
*   **AppendMode** – режим записи данных в конец файла (bool).
*   **ReadCache** – режим кэширования данных при чтении (bool). Полезно при чтении небольшими фрагментами.
*   **WriteCache** – режим кэширования данных при записи (bool). Полезно при записи небольшими фрагментами.
