## indexOf

Поиск первого месторасположения подстроки в пределах объекта String. Если подстрока не найдена, возвращается -1.

Аргументы:  
     subString    - Подстрока для поиска (String).  
     startPos    - целое значение, указывающее индекс начала поиска (Integer). Необязательный аргумент.

Результат:  
     Integer  
 

Примеры:

     sTemp = "abc, def, ghi. ";  
     vTemp = sTemp.indexOf(",");   
     alert (vTemp); // возвращает 3 (четвертая позиция, начиная с 0)

     vTemp = sTemp.indexOf(",", 3); // поиск производится, начиная с элемента с индексом 3 (т.е. начиная с символа "запятая" включительно)   
     alert (vTemp); // возвращает 3 

     vTemp = sTemp.indexOf(",", 5); // поиск производится, начиная с элемента с индексом 5 (т.е. начиная с символа "d" включительно)   
     alert (vTemp); // возвращает 8 (девятая позиция, начиная с 0)
