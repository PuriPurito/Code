## sqrt

Метод объекта **Math**. Вычисляет квадратный корень из аргумента. 

_Синтаксис:_  
      **Math.sqrt (<Num>)**

_Аргументы:_  
     _<Num>  (обязательный)_  
      Тип: **Действительное или целое число**. Исходный аргумент.

 **Примечание** – Дробная часть числа отделяется от целой части точкой, а не запятой.

_Возвращаемое значение:_  
      Тип: **Действительное или целое число**. Результат вычисления.

_Пример:_

     `_rNum01 = 123.4;        rSQRT01 = Math.sqrt(rNum01);        alert (rSQRT01); // возвращает 11.108555_`

     `_rNum02 = 9;        rSQRT02 = Math.sqrt(rNum02);        alert (rSQRT02); // возвращает 3_`
