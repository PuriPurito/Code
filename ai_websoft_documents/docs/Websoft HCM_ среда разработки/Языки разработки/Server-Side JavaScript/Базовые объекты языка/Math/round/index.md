## round

Метод объекта **Math**. Округление значения числового выражения (по правилам округления).

_Синтаксис:_  
      **Math.round (<Num>)**

_Аргументы:_  
     _<Num>  (обязательный)_  
      Тип: **Число (Действительное число)**. Исходный аргумент.

 **Примечание** – Дробная часть числа отделяется от целой части точкой, а не запятой.

_Возвращаемое значение:_  
      Тип: **Целое число**. Результат округления.

_Пример:_

     `_rNum01 = 123.4;        iNum01 = Math.round(rNum01);        alert (iNum01); // возвращает 123_`

     `_rNum02 = 123.5;        iNum02 = Math.round(rNum02);        alert (iNum02); // возвращает 124_`

     `_rNum03 = 123.6;        iNum03 = Math.round(rNum03);        alert (iNum03); // возвращает 124_`
