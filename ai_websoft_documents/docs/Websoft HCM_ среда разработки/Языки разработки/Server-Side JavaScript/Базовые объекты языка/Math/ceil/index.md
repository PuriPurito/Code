## ceil

Метод объекта **Math**. Округление значения числового выражения до ближайшего большего целого числа (округление вверх). 

_Синтаксис:_  
      **Math.ceil (<Num>)**

_Аргументы:_  
     _<Num>  (обязательный)_  
      Тип: **Число (Действительное число)**. Исходный аргумент.

 **Примечание** – Дробная часть числа отделяется от целой части точкой, а не запятой.

_Возвращаемое значение:_  
      Тип: **Целое число**. Результат округления.

_Пример:_

     `_rNum01 = 123.4;        iNum01 = Math.ceil (rNum01);        alert (iNum01); // возвращает 124_`
