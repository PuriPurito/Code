## abs

Метод объекта **Math**. Определение абсолютной величины (модуля) числового значения. 

_Синтаксис:_  
      **Math.abs (<Num>)**

_Аргументы:_  
     _<Num>  (обязательный)_  
      Тип: **Число (Действительное число)**. Исходный аргумент.

 **Примечание** – Дробная часть числа отделяется от целой части точкой, а не запятой.

_Возвращаемое значение:_  
      Тип: **Действительное или целое число**. Результат преобразования - абсолютная величина (модуль) числа.

_Пример:_

     `_rNum01 = -123.4;        iNum01 = Math.abs (rNum01);        alert (iNum01); // возвращает 123.4_`

     `_rNum02 = -123.6;        iNum02 = Math.abs (rNum02);        alert (iNum02); // возвращает 123.6_`
