## push

Функция (метод) объекта Array. Добавляет элементы в конец массива и возвращает новую, увеличенную длину массива.  
    
Аргументы:  
     **arg1, arg2** и последующие аргументы - элементы, которые следует добавить в массив. Все агументы, корме первого - необязательные.  
   
Результат: integer   
   
Пример:

     var arrNew = \[ 1, 2, 3, 4, 5 \];  
     iRez = arrNew.push('fff','ggg','hhh');  
     alert( iRez ); // возвращает целое число 8  
     alert( arrNew.join(',') ); // возвращает строку '1,2,3,4,5,'fff','ggg','hhh''
