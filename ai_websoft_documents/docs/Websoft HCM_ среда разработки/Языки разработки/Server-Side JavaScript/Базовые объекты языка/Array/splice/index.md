## splice

Функция (метод) объекта Array. Удаляет указанную часть массива.  
   
Аргументы  
     **arg1** \- индекс в массив, с которого нужно начинать удаление (отсчет индексов начинается с 0).  
     **arg2** \- количество элементов, которое нужно удалить, начиная с индеса arg1.  
   
Пример:

     var arrNew = \[ 1, 2, 3, 4, 5 \];  
     arrNew.splice( 2, 1 ); // удаляет одно значение, начиная с 3-го элемента (0, 1, 2).  
     alert( arrNew.join(',') ); // возвращает строку '1,2,4,5'
