## length

Атрибут объекта Array. Возвращает количество элементов массива. 

Внимание! В формате UTF-8 многие символы могут состоять из нескольких байтов. Чтобы точно определить длину строки в символах, рекомендуется использовать функцию StrCharCount().

Результат: integer  
   
Пример: 

     var arrNew = \[ 1, 2, 3, 4, 5 \];  
     alert( arrNew.length ); // возвращает целое число 5
