## join

Функция выполняется только на сервере.

Функция (метод) объекта Array. Преобразует все элементы массива в строку (объект String) и соединяет их, используя разделитель, указанный в качестве аргумента.  
   
Аргументы:  
     **separator**    - разделитель между элементами (String). Не обязательный аргумент.  
   
Результат: String  
   
Пример:

     var arrNew = \[ 1, 2, 3, 4, 5 \];  
     alert( arrNew.join(',') ); // возвращает строку '1,2,3,4,5'
