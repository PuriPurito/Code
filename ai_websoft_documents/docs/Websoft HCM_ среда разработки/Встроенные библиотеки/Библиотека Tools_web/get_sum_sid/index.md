## get_sum_sid

_Контент отсутствует или не загружен_

---

ется использовать функцию tools\_web.get\_sum\_sid. Функция формирует уникальный идентификатор, определяющий текущую сессию и объект, для которого этот идентификатор получен.

_Синтаксис:_  
      **tools.get\_sum\_sid (<sIdParam>)**

_Аргументы:_  
     _<sIdParam> (обязательный)_  
      Тип: **Целое число**. ID объекта, для которого нужно получить уникальный идентификатор.

_Возвращаемое значение:_  
      Тип: **Целое число**. Уникальный идентификатор.

_Пример:_  
      `_iUID = tools.get_sum_sid ( iObj_ID );_`
