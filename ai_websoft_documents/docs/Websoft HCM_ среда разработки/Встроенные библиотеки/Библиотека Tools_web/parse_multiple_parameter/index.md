## parse_multiple_parameter

Формирование из строкового представления массива в разных форматах (подстроки, разделенные символами "запятая" и "точка с запятой", JSON и т.п.) JS-массива значений.

_Синтаксис:_  
      **tools\_web.parse\_multiple\_parameter (<sParam>)**

_Аргументы:_  
      _<sParam> (обязательный)_  
      _Тип: **Строка**. Преобразуемое строковое выражение._

_Возвращаемое значение:_  
      Тип: **Массив строк**. Массив, сформированный из исходного строкового выражения.

_Пример 1:_  
      `_var arrActivityTypes = tools_web.parse_multiple_parameter( sActivityTypes );_`
