## get_web_param

**Данная статья находится в стадии разработки.**  
 

Получение предустановленных значений параметров (переменных) с помощью кода.  
Переменная _curParams_ зарезервирована для получения предустановленных переменных и их значений.

Примечание - С помощью данной функции, в частности, удобно получать в коде настраиваемого web-шаблона значения параметров, заданных  в соответствующем элементе шаблона.

Пример 1 (получение значения параметра из элемента шаблона):  
  
     // _Переменная VAR1 и ее значение заданы в элементе шаблона._

     // _Код в настраиваемом web-шаблоне:_  
     <%=VAR1 %>  
     <br>  
     <%=tools\_web.get\_web\_param(curParams, 'VAR1', '', true) %>  
     <br>  

Пример 2:  
     sVar1 = tools\_web.get\_web\_param(curParams, 'VAR1', '', true);  
     sTabTitle = tools\_web.get\_web\_param( curParams, "tenancy\_panel\_body.tab\_list.tenancy\_tab", "", true ); // второй параметр - путь к переменной через шаблон (tenancy\_panel\_body - имя шаблона, tab\_list.tenancy\_tab - имя переменной в шаблоне); третий параметр - значение по умолчанию (в данном случае - пустая строка)
