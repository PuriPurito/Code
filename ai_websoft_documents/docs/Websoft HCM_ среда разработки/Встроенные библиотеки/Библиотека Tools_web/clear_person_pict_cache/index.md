## clear_person_pict_cache

Функция **tools\_web.clear\_person\_pict\_cache** предназначена для cброса кэша фотографии на портале.

_Синтаксис:_  
      **tools\_web.clear\_person\_pict\_cache ( <user\_id> )**

_Аргументы:_  
     **<user\_id>** (обязательный)  
      Тип: **Целое число**. ID пользователя.

  
     tools\_web.clear\_person\_pict\_cache( user\_id );
