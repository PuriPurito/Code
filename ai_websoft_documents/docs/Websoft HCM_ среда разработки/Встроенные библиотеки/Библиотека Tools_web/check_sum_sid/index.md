## check_sum_sid

_Контент отсутствует или не загружен_

---

ется использовать функцию _tools\_web.check\_sum\_sid_.   
Сравнивает уникальный идентификатор, переданный в нее с уникальным идентификатором, определяющим текущую сессию, и объект, для которого этот идентификатор получен.

_Синтаксис:_  
      **tools.check\_sum\_sid (<sIdParam>, <sSumParam>)**

_Аргументы:_  
     <sIdParam> (обязательный)  
     Тип: **Целое число**. ID объекта, для которого нужно осуществить проверку.  
     <sSumParam> (обязательный)  
     Тип: **Целое число**. Уникальный идентификатор, с которым производится сравнение.

_Возвращаемое значение:_  
      Тип: **Булево**. Возвращает значение, показывающее, соответствуют ли идентификаторы объекта и текущей сессии (_true_ – соответствует, _false_ – не соответствует).

_Пример:_  
      `_sCheckResult = tools.check_sum_sid ( curSid, Session.sid );_`
