## get_web_str

_Контент отсутствует или не загружен_

---

ся. Перенесена в библиотеку tools\_web.   
Вместо нее рекомендуется использовать функцию tools\_web.get\_web\_str.   
Возвращает текстовое значение константы для текущего языка (языка, используемого в интерфейсе).

_Синтаксис:_  
      **tools.get\_web\_str (<sNameParam>)**

_Аргументы:_  
     _<sNameParam> (обязательный)_  
      Тип: **Строка**. Строковое выражение ID-константы в XML-структуре текущего языка.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка со значением константы для текущего языка или строка вида _'UNDEFINED - ' + sNameParam_, если такой константы не найдено.

_Пример:_  
      `_tools.get_web_str ( 'vfb_anonymous_author' );_`
