## convert_xss

Функция преобразует управляющие символы _"_ (двойные кавычки), _<_ (меньше) и _&_ (амперсанд) соответственно в '&quot;' , '&lt;'  и '&amp;' и используется для защиты от XSS-атак и межсайтового скриптинга. 

_Синтаксис:_  
      **convert\_xss (<sData>)**

_Аргументы:_  
     _<sData>  (обязательный)_  
      Тип: **Строка**. Строка, подлежащая преобразованию.

_Возвращаемое значение:_  
      Тип: **Строка**. Результат выполнения функции.

_Пример:_  
      `_s = '"<@WT&>';         s1 = tools_web.convert_xss(s);         alert(s1); // формируется строка '&quot;&lt;@WT&amp;>'_`
