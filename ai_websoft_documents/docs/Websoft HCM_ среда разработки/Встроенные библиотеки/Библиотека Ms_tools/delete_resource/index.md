## delete_resource

Невозвратное удаление ресурса базы из системы («мимо Корзины») .   
  
См. также Правила удаления объектов.

_Синтаксис:_  
      **delete\_resource ( <oResourceParam> )**

_Аргументы:_  
     _<oResourceParam> (обязательный)_  
      Тип: **Строка, Целое число**. ID ресурса.

_Возвращаемое значение:_  
      Тип: **Булево**. Результат выполнения функции (true, если функция выполнена успешно).

_Пример:_  
      `_bRez = ms_tools.delete_resource ( iResourseID );_`
