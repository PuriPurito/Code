## knowledge_part_path_by_knowledge_part_id

Функция возвращает строку с полным путем из родительских элементов карты знаний (значений) без классификатора. Путь разделен указанным в параметрах функции разделителем.

Входные параметры:

\_knowledge\_partID (int)  необязательный, если передан\_knowledge\_partDoc. ID значения, для которого нужно найти пусть. 

\_knowledge\_partDoc  (TopElem) необязательный. TopElem значения, для которого нужно найти пусть. 

\_depth (int) необязательный  - глубина пути, число, показывающее длину цепочки в пути. Если 0, то показывается полная цепочка пути. По умолчанию 0.

\_top (int) необязательный  - параметр направления показа пути. Если 1, то путь  рассчитывается 'сверху', то есть от классификатора. Если 0, то путь рассчитывается 'снизу', то есть от текущего значения. По умолчанию 1.

\_separator (string) необязательный  - разделитель. Если указана пустая строка '', по умолчанию используется разделитель ' -> '.

Возвращаемый результат – строка (string) полным путем из родительских элементов карты знаний (значений) без классификатора.

Пример вызова:

**\_kp.full\_path = tools.knowledge\_part\_path\_by\_knowledge\_part\_id(\_value.key)**
