## get_tag_cloud

Функция возвращает массив уникальных строк, состоящий из ID тегов из карточки значений классификаторов знаний. В результате работы функции отбираются только те теги, которые привязаны хотя бы к одному значению.

_Синтаксис:_  
      **tools.get\_tag\_cloud ()**

_Аргументы:_  
      Функция вызывается без аргументов.

_Возвращаемое значение:_  
      Тип: **Массив**. Массив уникальных строк, состоящий из ID тегов из карточки значений классификаторов знаний.

_Пример:_  
      `_arrTags_ID = tools.get_tag_cloud ();_`
