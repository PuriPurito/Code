## AdjustDate

Сдвигает указанную дату на количество секунд, заданное параметрами функции. Можно передать дни, часы, минуты и секунды для сдвига даты. Дни, часы, минуты будут пересчитаны в секунды.

_Синтаксис:_  
      **tools.AdjustDate (\[<date\_val>\]\[, <days>\]\[, <hours>\]\[, <minutes>\]\[, <seconds>\])**

_Аргументы:_  
      _<date\_val> (необязательный)_  
      Тип: **Дата**. Исходная дата, подлежащая изменению. Если дата не указана, то по умолчанию принимается текущая дата.   
      _<days> (необязательный)_  
      Тип: **Целое число**. Количество дней, на которое нужно сдвинуть текущую дату. Если аргумент не указан, то по умолчанию принимается значение 0.  
      _<hours> (необязательный)_  
      Тип: **Целое число**. Количество часов, на которое нужно сдвинуть текущую дату. Если аргумент не указан, то по умолчанию принимается значение 0.  
      _<minutes> (необязательный)_  
      Тип: **Целое число**. Количество минут, на которое нужно сдвинуть текущую дату. Если аргумент не указан, то по умолчанию принимается значение 0.  
      _<seconds> (необязательный)_  
      Тип: **Целое число**. Количество секунд, на которое нужно сдвинуть текущую дату. Если аргумент не указан, то по умолчанию принимается значение 0.

_Возвращаемое значение:_  
      Тип: **Дата**. Измененная дата, полученная сдвигом исходной даты на указанное количество дней, часов, минут и секунд.

_Пример 1:_  
      `_newDate = tools.AdjustDate (null, 1); // сдвиг текущей даты на 1 сутки         alert (newDate);         newDate1 = tools.AdjustDate (null, -1); // сдвиг текущей даты на 1 сутки назад         alert (newDate1);_`

_Пример 2:_  
      `_docEducationPlan.TopElem.finish_date = tools.AdjustDate(Date(),_max_days);_`
