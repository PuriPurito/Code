## str_time_from_mseconds

Функция возвращает строку вида «часы : минуты : секунды . миллисекунды», полученную из параметра функции (миллисекунды). Миллисекунды после «.» в результирующей строке передаются, если их значение больше нуля.

Входные параметры:

\_mseconds (int)  количество миллисекунд. 

Возвращаемый результат – строку вида «часы : минуты : секунды . миллисекунды» (string).

Пример вызова:

**tools.str\_time\_from\_mseconds( Ps.time );**
