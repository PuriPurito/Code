## getDayYear

Функция **getDayYear** предназначена для определения номера дня в году.

_Синтаксис:_  
      **tools.getDayYear(<dData>)**

_Аргументы:_  
      _<dData> (обязательный)_  
      Тип: **Дата**. Дата, для которой определяется номер дня в году.

_Возвращаемое значение:_  
      Тип: **Целое число**. Номер дня в году. 

_Пример:_  
     `_dNumber = tools.getDayYear( Date() ); // номер сегодняшнего дня в году        alert( dNumber );_`
