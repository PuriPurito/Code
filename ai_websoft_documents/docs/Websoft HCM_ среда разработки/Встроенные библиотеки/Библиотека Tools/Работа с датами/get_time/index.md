## get_time

Устаревшая функция. Функция разработана для проверки данных времени в строке, полученной из внешнего источника. Возвращает строку со временем (часами и/или минутами и/или секундами) из строки времени, разделенной символами «:». Принимается строка вида '23:58:56'. Если строка будет некорректной – например, вида '33:58:56', функция возвращает значение null. Если в исходной строке передается неполное значение времени (без указания количества минут или секунд), то в зависимости от значения аргументов minite\_flag и second\_flag функция дополняет время значением ':00' или возвращает значение null.

_Синтаксис:_  
      **tools.get\_time (<str>\[, <minite\_flag>\]\[, <second\_flag>\])**

_Аргументы:_  
     <str> (обязательный)  
     Тип: **Строка**. Исходная строка для разбора.   
     <minite\_flag> (необязательный)  
     Тип: **Булево**. Указывает на необходимость проверки наличия минут в исходной строке. По умолчанию false. Например, если в исходной строке имеется значение '23', а minite\_flag = true, то функция выдаст значение null, а при minite\_flag = false – значение '23:00'.  
     <second\_flag> (необязательный)  
     Тип: **Булево**. Указывает на необходимость проверки наличия секунд в исходной строке. По умолчанию false.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка с откорректированным значением времени или значение null.

_Пример 1:_  
`_sTime = tools.get_time ( '23', true, true );   if (sTime == null)        alert ('null');_`  

_Пример 2:_  
      `__start_time = tools.get_time ( String(Trim(temp_doc.replication_time)).split('-') );_`
