## Работа с датами

В данный раздел включены все функции библиотеки Tools, связанные с **работой со датами**, кроме устаревших.

Внимание! Для изменения даты в Websoft HCM недопустимо использовать операторы сложения и вычитания.  
При использовании оператора сложения _<дата>+<число>_ дата и число преобразуются в строки и производится конкатенация этих строк.  
Например, из даты _<04.04.2023 09:23:50>_ и числа _5_ формируется строка _'04.04.2023 09:23:505'_.  
При использовании оператора вычитания _<дата>-<число>_ система выдает ошибку.  
Для изменения даты в Websoft HCM необходимо использовать встроенную функцию **DateOffset**.
