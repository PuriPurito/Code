## date_str

Преобразует дату в строку, разделенную символом \_ (нижнее подчеркивание). Например, дата 01.02.1999 12:34:15 будет преобразована в 1999\_02\_01\_12\_34.

_Синтаксис:_  
      **tools.date\_str (<cur\_date>)**

_Аргументы:_  
     <cur\_date> (необязательный)  
     Тип: **Дата**. Дата, подлежащая преобразованию. Если атрибут не указан, то будут преобразовываться текущие дата и время.

_Возвращаемое значение:_  
      Тип: **Строка**. Дата, преобразованная в строку. Результат дейсттвия функции.

_Пример 1:_  
      `_str = tools.date_str();         alert (str);_`

_Пример 2:_  
      `__pak_name = 'update_' + tools.date_str() + '_' + _cur_id + '.zip';_`
