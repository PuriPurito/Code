## get_period_from_iso

Возвращает продолжительность периода времени в миллисекундах, преобразованную из XML-тега period. Время в теге задано в формате _P5Y2M10DT15H30M45S_ по _ГОСТ ИСО 8601-2001_. Используется для разбора результатов курса.

_Синтаксис:_  
      **tools.get\_period\_from\_iso (<period>)**

_Аргументы:_  
     <period> (обязательный)  
     Тип: _Строка_. Строка с указанием продолжительности периода времени вида _'P5Y2M10DT15H30M45S'_.  
Примечание. _'P5Y2M10DT15H30M45S'_ – пример обозначения периода времени по _ГОСТ ИСО 8601-2001 СИБИД. Представление дат и времени. Общие требования_ (п. 4.3-4.4).   
Условные обозначения:  
P (period) – период времени;  
Y (years) – количество лет (5Y – 5 лет);  
M (months) – количество месяцев (2M – 2 месяца);  
D (days) – количество дней (10D – 10 дней);  
T (time) – время в пределах суток;  
H (hours) – количество часов (от 0 до 23) (15H – 15 часов);  
M (minutes) – количество минут (от 0 до 59) (30M – 30 минут);  
S (seconds) – количество секунд (от 0 до 59) (45S – 45 секунд).

_Возвращаемое значение:_  
      Тип: **Целое число**. Длительность в миллисекундах.

_Пример 1:_

`_sPeriod = 'PT02H30M45S'; // продолжительность времени в формате, принятом в ГОСТ ИСО 8601-2001 (2 часа 30 минут 45 секунд)   iPeriod = tools.get_period_from_iso ( sPeriod ); // продолжительность времени в миллисекундах   alert ( iPeriod );_` 

`_sPeriod1 = 'PT1S'; // продолжительность времени в формате, принятом в ГОСТ ИСО 8601-2001 (1 секунда)   iPeriod1 = tools.get_period_from_iso ( sPeriod1 ); // продолжительность времени в миллисекундах (1000 миллисекунд)   alert ( iPeriod1 );_`

_Пример 2:_  
      `_tools.get_period_from_iso ( _int.latency );_`
