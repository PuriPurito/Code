## get_time_from_seconds

Возвращаете время (часы, минуты и секунды) в виде «_часы H минуты M секунды S_», полученное из количества секунд. Используется для разбора результатов теста.

_Синтаксис:_  
      **tools.get\_time\_from\_seconds (<seconds>)**

_Аргументы:_  
     _<seconds> (обязательный)_  
      Тип: **Строка**. Количество секунд, которые нужно преобразовать в часы, минуты и секунды.

_Возвращаемое значение:_  
      Тип: **Строка**. Строковое значение, содержащее значение времени в формате «_часы H минуты M секунды S_» в строке, или пустая строка, если входной параметр (аргумент) не удалось преобразовать в число.

_Пример 1:_  
`_iSec = 86399;   sTime = tools.get_time_from_seconds ( iSec );   alert (sTime);   _`

_Пример 2:_  
      `_sTime = tools.get_time_from_seconds ( section.timer );_`
