## getWeekYear

Функция **getWeekYear** предназначена для определения номера недели в году. 

_Синтаксис:_  
      **tools.getWeekYear(<dData>)**

_Аргументы:_  
      _<dData> (обязательный)_  
      Тип: **Дата**. Дата, для которой определяется номер недели в году.

_Возвращаемое значение:_  
      Тип: **Целое число**. Номер недели в году. 

_Пример:_  
     `_dNumber = tools.getWeekYear( Date() ); // номер текущей недели в году        alert( dNumber );_`
