## get_seconds_from_duration

Возвращает продолжительность периода времени в секундах. Время задано в формате _P5Y2M10DT15H30M45S_ по ГОСТ ИСО 8601-2001. 

_Синтаксис:_  
      **tools.get\_seconds\_from\_duration (<duration>)**

_Аргументы:_  
     <duration> (обязательный)  
     Тип: **Строка**. Строка с указанием продолжительности времени вида _'P5Y2M10DT15H30M45S'_.  
Примечание. 'P5Y2M10DT15H30M45S' – пример обозначения периода времени по ГОСТ ИСО 8601-2001 СИБИД. Представление дат и времени. Общие требования (п. 4.3-4.4).   
Условные обозначения:  
P (period) – период времени;  
Y (years) – количество лет (5Y – 5 лет);  
M (months) – количество месяцев (2M – 2 месяца);  
D (days) – количество дней (10D – 10 дней);  
T (time) – время в пределах суток;  
H (hours) – количество часов (от 0 до 23) (15H – 15 часов);  
M (minutes) – количество минут (от 0 до 59) (30M – 30 минут);  
S (seconds) – количество секунд (от 0 до 59) (45S – 45 секунд).

_Возвращаемое значение:_  
      Тип: **Целое число**. Длительность в секундах.

_Пример 1:_

`_sDuration = 'P5Y2M10DT15H30M45S'; // продолжительность времени в формате, принятом в ГОСТ ИСО 8601-2001   iDuration = tools.get_seconds_from_duration (sDuration ); // продолжительность времени в секундах   alert (iDuration );_` 

`_sDuration = 'PT1S'; // продолжительность времени в формате, принятом в ГОСТ ИСО 8601-2001 (1 секунда)   iDuration = tools.get_seconds_from_duration (sDuration ); // продолжительность времени в секундах   alert (iDuration );_`  

_Пример 2:_  
      `__dur = tools.get_seconds_from_duration ( qtiDoc.duration );_`
