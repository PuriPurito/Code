## obtain_access_roles

Обновляет значения ролей в системе на основе списка, указанного в параметрах.

_Синтаксис:_  
      **tools.obtain\_access\_roles(\[<\_url>\], \[< \_source>\])**

  
**Входные параметры:**

     _\_url_ - путь до файла с структурой списка (list), из которого будут загружаться данные (строка). Параметр не обязателен, если передан \_source.  

     _\_source_ \- файл с структурой списка (list) для обновления (необязательный) (объект TopElem).

  
**Возвращаемый результат** – количество обновленных элементов списка (целое число).

**counter = tools.obtain\_access\_roles( null, fldFormRole );**
