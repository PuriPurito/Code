## encrypt_lib

Свойство. Возвращает ссылку на объект библиотеки, инициализированный функцией **tools.init\_encrypt\_lib**.

_Синтаксис:_  
      **tools.encrypt\_lib**

_Возвращаемое значение:_  
      Тип: **Строка**. Ссылка на объект библиотеки.

_Пример:_  
      `_obj = tools.encrypt_lib.Object;_`
