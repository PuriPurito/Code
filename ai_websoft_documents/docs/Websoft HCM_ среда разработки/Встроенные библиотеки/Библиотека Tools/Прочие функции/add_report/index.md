## add_report

Добавляет строку к событию базы, определяемому **report\_id** или документом **source\_doc**.

_Синтаксис:_  
      **tools.add\_report (<report\_id>, <str>\[, <source\_doc>\])**     или  
      **tools.add\_report (\[<report\_id>, \]<str>, <source\_doc>)**

_Аргументы:_  
      _<report\_id> (обязательный (необязательный, если задан аргумент source\_doc))_  
      Тип: **Целое число**. ID события базы, к которому нужно добавить строку.  
      _<str> (обязательный)_  
      Тип: **Строка**. Строка, которую нужно добавить к событию базы.  
      _<source\_doc> (обязательный (необязательный, если задан аргумент report\_id))_  
      Тип: **Объект XmlDoc**. Документ события базы, к которому нужно добавить строку.

_Возвращаемое значение:_  
      Тип: **Объект XmlDoc**. Сохраненный документ события базы с добавленной строкой.

_Пример:_  
      `_reportDoc = OpenNewDoc( 'x-local://wtv/wtv_action_report.xmd' );         _report_id = reportDoc.DocID;         tools.add_report( _report_id, 'Saving archive: OK.' );_`
