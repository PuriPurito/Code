## recovery_empty_lng_const

Восстанавливает значение для пустых констант в системе.

Входные параметры:

\_lng\_id (string) – ID языка, для которого нужно восстановить значения констант.

\_source (XML element) – элемент, в дочерних элементах которого происходит поиск язык по \_lng\_id  для восстановления значений.

Возвращаемый результат: (int) количество восстановленных элементов.

Пример вызова.

**iResCount = tools.recovery\_empty\_lng\_const( fldLngChild.PrimaryKey, fldLngChild );**
