## obtain_lists

Добавляет в системные lists новый список(списки) со значениям или обновляет старый.

Входные параметры:

\_url (sting) – путь до файла со Lists.

\_list\_name (sting) необязательный –названия списка, значения которого будут обновлены на основе данных из файла.

Возвращаемый результат – флаг да (bool) при любом (успешном или неуспешном) выполнение действия.

Пример вызова.

**tools.obtain\_lists( UrlAppendPath( 'x-local://custom/', temp\_doc.lists\_url ) );**
