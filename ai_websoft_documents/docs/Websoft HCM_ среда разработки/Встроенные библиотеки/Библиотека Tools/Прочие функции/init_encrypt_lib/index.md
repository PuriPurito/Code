## init_encrypt_lib

Инициализирует библиотеку для работы с лицензиями и объектами, зашифрованными с помощью этих лицензий.

_Синтаксис:_  
      **tools.init\_encrypt\_lib ()**

_Аргументы:_  
      Функция вызывается без аргументов.

_Возвращаемое значение:_  
      Инициализирует библиотеку для работы с лицензиями и объектами. Возвращаемое значение отсутствует.

_Пример:_  
      `_if ( tools.os_type != 'linux' )         {              tools.init_encrypt_lib();         }_`
