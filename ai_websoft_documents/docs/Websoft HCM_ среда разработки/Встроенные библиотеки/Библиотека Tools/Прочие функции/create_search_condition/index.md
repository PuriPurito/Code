## create_search_condition

Функция **create\_search\_condition** предназначена для формирования критерия поиска для отбора записей с целью упрощения работы со стандартным функционалом поиска. Функция доступна, начиная со 2-го релиза 2023 г.

_Синтаксис:_  
      **tools.create\_search\_condition (<sSearch>, <sTable>\[, <sFields>, <sFrnField>, <sType>\])**

_Аргументы:_  
     <sSearch> (обязательный)  
     Тип: **Строка**. Исходный критерий поиска.  
     <sTable> (обязательный)  
     Тип: **Строка**. Имя справочника (без _‘s’_), в котором осуществляется поиск (строка).   
     <sFields> (необязательный)  
     Тип: **Строка или массив строк**. Перечень полей каталога, в которых осуществляется индексированный (не полнотекстовый) поиск. В случае, если в качестве данного параметра представлена строка, названия полей должны быть разделены знаками «запятая» или «точка с запятой». Все поля списка должны быть проиндексированы (_INDEXED="1"_ в форме данных каталога). В неиндексированных полях поиск не производится. Если данный аргумент не указан или представлен в виде пустого массива, пустой строки, значений null или undefined, поиск будет выполняться по всем индексированным полям каталога.  
     <sFrnField> (необязательный)  
     Тип: **Строка**. Имя FOREIGN-поля каталога для поиска (строка) (необязательный параметр). По умолчанию — _'id'_.  
     <sType> (необязательный)  
     Тип: **Строка**. Тип поиска (индексированный или полнотекстовый) (строка) (необязательный параметр). Допустимые значения: _'global\_settings'_ (использование настроек типа поиска из **Общих настроек** (состав общих настроек приведен на рисунке ниже)), _'indexed'_ (индексированный поиск), _'fulltext'_ (полнотекстовый поиск). По умолчанию используется тип _'global\_settings'_.  
  

_Возвращаемое значение:_  
      Тип: **Строка**. Результирующий критерий поиска.

_Пример:_  
      `_sSearchCond = tools.create_search_condition(oFilter.value, "collaborator", arrSearchFieldNames);_`
