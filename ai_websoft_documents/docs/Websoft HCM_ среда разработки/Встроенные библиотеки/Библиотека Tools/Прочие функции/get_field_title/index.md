## get_field_title

Возвращает название поле из тега TITLE xmd или xml формы для указанного языка. Если в теге есть «const=», то производится поиск значения указанного после «=» среди констант языка. Если в константах значение не найдено, то возвращается, то, что указано после «const=». Если «const=» не указано, то возвращается значение тега TITLE.

Входные параметры:

\_field (XML element)  – объект, представляющий собой XML поле, для которого нужно взять название. 

curLngWeb (XML element) необязательный – текущий язык, если не указан, берется язык пользовательского интерфейса в администраторе. При вызове на портале параметр обязателен. 

Возвращаемый результат – название поле из тега TITLE xmd или xml формы для указанного языка (string).

Пример вызова

**tools.get\_field\_title( fldReqFieldElem, curLngWeb )**
