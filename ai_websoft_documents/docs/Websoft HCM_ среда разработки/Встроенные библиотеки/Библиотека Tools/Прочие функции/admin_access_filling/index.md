## admin_access_filling

Проверяет доступ к объекту на основе настроек в разделе **Отображение каталогов** (блок **Безопасность**) для текущего пользователя в Webtutor Administrator.

_Синтаксис:_  
      **tools.admin\_access\_filling (<teObjectParam>)**

_Аргументы:_  
      _<teObjectParam> (обязательный)_  
      Тип: **TopElem**. TopElem объекта, к которому проверяется доступ.

_Возвращаемое значение:_  
      Тип: **Булево**. Возвращает значение, показывающее наличие или отсутствие доступа (_true_ – доступ разрешен, _false_ – доступ запрещен).

_Пример:_  
      `_tools.admin_access_filling( TopElem );_`
