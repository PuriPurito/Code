## add_lng

Добавляет новый язык в список используемых в системе языков. Загрузка происходит из XML-файла с константами. Используется в администраторе в общих настройках, для установки новых языков или обновления существующих.

_Синтаксис:_  
      **tools.add\_lng (<sLngUrlParam>\[, <bDoObtainParam>\])**

_Аргументы:_  
      _<sLngUrlParam> (обязательный)_  
      Тип: **Строка**. Путь до XML-файла с константами.  
      _<bDoObtainParam> (необязательный)_  
      Тип: **Булево**. Используется при вызове функции на сервере. Если значение аргумента равно _true_, то существующие значения констант языка перезаписываются новыми из файла **sLngUrlParam**.

_Возвращаемое значение:_  
      Тип: **Целое число**. Количество обновленных констант.

_Пример:_  
      `_tools.add_lng( _url );         tools.add_lng( UrlAppendPath( 'x-local://custom/', temp_doc.lngs_url ), true );         _num = TopElem.add_lng_items( _doc, true );_`
