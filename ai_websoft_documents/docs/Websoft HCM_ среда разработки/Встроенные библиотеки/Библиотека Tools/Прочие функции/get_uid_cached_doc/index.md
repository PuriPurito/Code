## get_uid_cached_doc

Формирует строку с уникальным идентификатором на основе параметров функции. Формируется результирующая строка вида _$$uid\_первый параметр\_второй параметр_.

Примечание – Данная функция не производит проверку корректности аргументов (первого и второго параметров).

_Синтаксис:_  
      **tools.get\_uid\_cached\_doc (<sUIDParam>, <sUrlParam>)**

_Аргументы:_  
     <sUIDParam> (обязательный)  
     Тип: **Строка**. Строка формирования идентификатора (первый параметр).  
     <sUrlParam> (обязательный)  
     Тип: **Строка**. Строка формирования идентификатора (второй параметр).  
 

_Возвращаемое значение:_  
      Тип: **Строка**. Строка вида _$$uid\_первый параметр\_второй параметр_.

_Пример 1:_  
`_sId = '3050438886317795229';   sUrl = 'x-local://data/static/1/';   sUID = tools.get_uid_cached_doc ( sId, sUrl );   alert (sUID);_`   

_Пример 2:_  
      `_sUID = tools.get_uid_cached_doc( tools.uid, sUrlParam );_`
