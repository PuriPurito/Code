## get_param_error_text

Возвращает ошибку формы, переданной как параметр. 

_Синтаксис:_  
      **tools.get\_param\_error\_text (<param\_form>)**

_Аргументы:_  
     _<param\_form> (обязательный)_  
      Тип: **Объект XmlDoc**. Документ формы, содержащей ошибку.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка с описанием ошибки.

_Пример:_  
      `_errorText = tools.get_param_error_text ( paramForm );_`
