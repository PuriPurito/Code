## copy_manifest_resources

Копирует ресурсы из списка, указанного в файле manifest, в папку получателя.

_Синтаксис:_  
      **tools.copy\_manifest\_resources (<fileUrl>, <baseUrl>)**

_Аргументы:_  
     <fileUrl> (обязательный)  
     Тип: **Строка**. Путь или URL до файла manifest.  
     <baseUrl> (обязательный)  
     Тип: **Строка**. Путь или URL до папки получателя относительно папки _wt/web_.

_Возвращаемое значение:_  
      Тип: **Булево**. Возвращает значение _true_, если операция завершилась успешно (копирование выполнено), или _false_ \- в противном случае (копирование не выполнено).

_Пример:_  
      `_tools.copy_manifest_resources( TopElem.file_import, teCourse.base_url );_`
