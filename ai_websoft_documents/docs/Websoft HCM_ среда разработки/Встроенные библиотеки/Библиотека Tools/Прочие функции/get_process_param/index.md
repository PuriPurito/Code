## get_process_param

Функция **get\_process\_param** предназначена для получения значений параметров процесса.   
См. также: Общая точка входа для получения параметров (бизнес) процесса из библиотеки программного кода и приложений.

_Синтаксис:_  
      **tools.get\_process\_param(<Library>, <sNameAttr>)**

_Аргументы:_  
      _<Library> (обязательный)_  
      Тип: **Строка или целое число**. Код/ID библиотеки программного кода.  
      _<sNameAttr> (обязательный)_  
      Тип: **Строка**. Название требуемого параметра.

_Возвращаемое значение:_  
      Тип: **Целое число, строка, дата или др**. Значение параметра. Тип возвращаемого значения соответствует типу искомого параметра процесса.

_Пример:_  
     `_var bTeamRating = tools_web.is_true(tools.get_process_param("libGame", "rating"));        var bExistEfficiencyCollaborator = tools.get_process_param('libSuccession', 'efficiency_collaborator');_`
