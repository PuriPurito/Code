## get_ft_value

Возвращает строку для использования в запросах для поиска по full text индексу. Строка параметр функция преобразуется в строку в зависимости от настроек базы.

Входные параметры:

sValueParam (string) – строка для преобразования.

Возвращаемый результат – строка (string) для использования в запросах для поиска по full text индексу.

Пример вызова.

**tools.get\_ft\_value( value )**
