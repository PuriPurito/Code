## import_pwt_data_xml

Импортирует данные, полученные из **Personal WebTutor** (для дешифровки данных используется функция tools.decript\_pwt\_data\_str). Если в данных указан пользователь, который есть в системе, или ID пользователя передан в аргументах функции, то данные по обучению привязываются к этому пользователю.

_Синтаксис:_  
      **tools.import\_pwt\_data\_xml (<sXML>\[,<user\_id>\]\[, <report\_id>\]\[, <file\_url>\])**

_Аргументы:_  
     <sXML> (обязательный)  
     Тип: **Строка**. Строка с данными XML.  
     <user\_id> (необязательный)  
     Тип: **Целое число**. ID пользователя для привязки полученных данных.  
     <report\_id> (необязательный)  
     Тип: **Целое число**. ID объекта событий базы, в которой добавится отчет о загрузке (если ID объекта не указан, то будет создан новый отчет).  
     <file\_url> (необязательный)  
     Тип: **Строка**. Путь до файла с данными.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка _'ERROR=1'_, если произошла ошибка, или строка вида _'ERROR=0 \\nPROCESS\_NUM=Количество загруженных \\nFAILED\_NUM=количество не загруженных результатов'_, если функция выполнена успешно.

_Пример:_  
      `_alert (tools.import_pwt_data_xml ( LoadUrlData( _url ), null, null, _url ));_`
