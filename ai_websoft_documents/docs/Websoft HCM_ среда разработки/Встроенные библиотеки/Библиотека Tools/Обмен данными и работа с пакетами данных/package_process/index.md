## package_process

Обрабатывает пакет с данными и загружает содержимое в базу данных.

Входные параметры:

\_path (string) – путь до файла с пакетом.

\_type (string) – тип загрузки. Возможный значения:

objects и std\_objects – загружает объекты  в базу. std\_objects применяется для загрузки стандартных объектов из первоначальной установки.

code\_update – выгружает файлы из архива в папку wtv сервера WebTutor.

web – выгружает файлы из архива в папку wt/web сервера WebTutor.

\_source (Xml document) необязательный (если не указан, то берутся все типы объектов в системе) – источник данных о типах загружаемых объектов, и других параметров загрузки объектов.

\_report\_id (int) – ID документа событий базы, в который будут записываться отчет.

\_exchange\_server\_id (int) необязательный – ID сервера обмена данным, из которого берутся параметры для фильтрации данных из пакета.

iDownloadPackageIDParam (int) необязательный – ID пакета, из которого нужно загрузить данные.

Возвращаемый результат – успешная или не успешная загрузка данных (bool). В случае типа объектов objects и std\_objects. Возвращается форма открытого документа пакета.

Пример вызова

**common\_variables.len\_flag = ( tools.package\_process( \\'' + Ps.local\_file\_url + '\\', \\'' + Ps.type + '\\', \\'' + Ps.Doc.DocID + '\\' ) != null );**
