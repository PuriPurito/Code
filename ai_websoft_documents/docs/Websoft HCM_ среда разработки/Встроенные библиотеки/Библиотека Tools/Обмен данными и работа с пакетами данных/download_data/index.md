## download_data

Получение данных с сервера обмена данными.

_Синтаксис:_  
      **tools.download\_data (<server\_id>)**

_Аргументы:_  
     <server\_id> (обязательный)  
     Тип: **Целое число**. ID сервера обмена данными, с которого необходимо получить данные.

_Возвращаемое значение:_  
      Тип: **Объект Error**. Информация об успехе выполнения функции или об ошибке. Результирующий объект _oRes_ имеет три свойства: код _oRes.error_, URL файла данных _oRes.data\_file\_url_ и сведения об ошибке _oRes.error\_text_.  
      В случае успеха выполнения функции возвращаются значения _oRes.error = 0_ и пустая строка в поле _oRes.error\_text_.  
      В случае возникновения ошибки возвращаются значения _oRes.error = 500_ и сведения об ошибке в поле _oRes.error\_text_. 

_Пример:_  
      `_oRes = tools.download_data ( _exchange_server_id );            if ( oRes.error != 0 )               alert( oRes.error_text );_`
