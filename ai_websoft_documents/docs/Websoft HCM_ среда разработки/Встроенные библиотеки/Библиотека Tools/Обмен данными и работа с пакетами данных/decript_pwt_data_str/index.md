## decript_pwt_data_str

Используется в функции import\_pwt\_data\_xml. Дешифрует XML-файл с данными, полученными из Personal WebTutor.

_Синтаксис:_  
      **tools.decript\_pwt\_data\_str (<str>)**

_Аргументы:_  
     <str> (обязательный)  
     Тип: **Строка**. Строка для преобразования.

_Возвращаемое значение:_  
      Тип: **Строка**. Дешифрованная строка. Результат действия функции.

_Пример:_  
      `__xml = tools.decript_pwt_data_str( _xml );_`
