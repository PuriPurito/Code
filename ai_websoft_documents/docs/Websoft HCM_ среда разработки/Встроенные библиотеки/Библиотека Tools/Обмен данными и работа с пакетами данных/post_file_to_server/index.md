## post_file_to_server

Отправляет файл на указанный сервер обмена данными. Отправление идет Post по http протоколу.

Входные параметры:

\_send\_file (string) – строка с адресом до отправляемого файла.

\_server\_id (int) – ID сервера обмена данными, для которого формируется пакет.

\_report\_id (int) – ID документа событий базы, в который будут записываться отчет.

Возвращаемый результат – нет.

Пример вызова

            **tools.post\_file\_to\_server(\\'' + \_filename + '\\', ' + \_server\_id + ', ' + \_report\_id + ' );**
