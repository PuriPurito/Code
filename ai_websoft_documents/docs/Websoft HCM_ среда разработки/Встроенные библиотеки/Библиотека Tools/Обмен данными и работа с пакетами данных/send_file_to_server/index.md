## send_file_to_server

Отправляет файл на указанный сервер обмена данными. Отправление идет как письмо по протоколу Smtp. Поэтому возможно указать тему и тело сообщения.

Входные параметры:

\_subject (string) – строка с темой отправляемого сообщения.

\_body(string) – строка с телом отправляемого сообщения.

\_send\_file (string) – строка с адресом до отправляемого файла.

\_server\_id (int) – ID сервера обмена данными, для которого формируется пакет.

\_report\_id (int) – ID документа событий базы, в который будут записываться отчет.

Возвращаемый результат – строка с адресом до сформированного пакета(string).

Пример вызова

            **tools.send\_file\_to\_server(\\'data \[' + \_server\_doc.code + '\]' + ( \_type == 'full' ? ' - full' : '' ) + '\\', \\'ID: ' + \_package\_id + '\\', \\'' + \_filename + '\\', ' + \_server\_id + ', ' + \_report\_id + ');**
