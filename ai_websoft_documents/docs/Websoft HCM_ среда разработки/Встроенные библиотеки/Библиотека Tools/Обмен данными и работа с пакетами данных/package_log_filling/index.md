## package_log_filling

Заполняет пакет данными из пакета источника. Возвращает количество обработанных объектов в пакете.

Входные параметры:

fldPackageTarget (TopElem)  TopElem  пакета, в который нужно копировать данные. 

fldSourceParam (TopElem)  TopElem  пакета, из которого нужно копировать данные. 

Возвращаемый результат – количество скопированных элементов (int).

Пример вызова:

**tools.package\_log\_filling( fldPackageChild, teUpdate );**
