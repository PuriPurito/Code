## download_package_list

Загружает указанные пакеты с сервера обмена данными.

_Синтаксис:_  
      **tools.download\_package\_list (\[<server\_id>\]\[, <package\_id>\]\[, <temp\_url>\])**

_Аргументы:_  
     <server\_id> (необязательный)  
     Тип: **Целое число**. ID сервера обмена данными, с которого загружаются пакеты. Если ID сервера обмена данными не указан, считается, что сервер локальный.  
     <package\_id> (необязательный)  
     Тип: **Целое число**. ID пакета, который нужно загрузить.  
     <temp\_url> (необязательный)  
     Тип: **Строка**. Путь до файла с пакетом.

_Возвращаемое значение:_  
      Тип: **Объект Error**. Информация об успехе выполнения функции или об ошибке. Результирующий объект _oRes_ имеет несколько свойств: код _oRes.error_, URL файла данных _oRes.data\_file\_url_, ID отчета _oRes.report\_id_ и сведения об ошибке _oRes.error\_text_.  
      В случае успеха выполнения функции возвращаются значения _oRes.error = 0_ и пустая строка в поле _oRes.error\_text_.  
      В случае возникновения ошибки возвращаются значения _oRes.error = 500_ и сведения об ошибке в поле _oRes.error\_text_. 

_Пример:_  
      `_tools.download_package_list ( iExchangeServerID, reportDoc.DocID );         tools.download_package_list ( curExchangeServerID );_`
