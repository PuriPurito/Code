## download_data_package

Загружает пакет с данными с указанного сервера обмена. После загрузки пакет обрабатывается функцией tools.package\_process, и данные попадают в базу. Загрузка производится по протоколу _http_.

_Синтаксис:_  
      **tools.download\_data\_package (<server\_id>, <report\_id>)**

_Аргументы:_  
     <server\_id> (обязательный)  
     Тип: **Целое число**. ID сервера обмена данными, с которого скачивается пакет.  
     <report\_id> (обязательный)  
     Тип: **Целое число**. ID документа событий базы, в который будут записываться отчет.

_Возвращаемое значение:_  
      Тип: **Объект Error**. Информация об успехе выполнения функции или об ошибке. Результирующий объект _oRes_ имеет два свойства: код _oRes.error_ и сведения об ошибке _oRes.error\_text_.  
      В случае успеха выполнения функции возвращаются значения _oRes.error = 0_ и пустая строка в поле _oRes.error\_text_.  
      В случае возникновения ошибки возвращаются значения _oRes.error = 500_ и сведения об ошибке в поле _oRes.error\_text_. 

_Пример:_  
      `_ServerEval ( 'tools.download_data_package(' + _server_id + ', ' + _report_id + ')' );_`
