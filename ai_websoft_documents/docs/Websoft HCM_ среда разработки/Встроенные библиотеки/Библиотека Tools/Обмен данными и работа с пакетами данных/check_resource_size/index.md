## check_resource_size

На основе настроек профиля редактирования контента в карточке сотрудника проверяется возможность загрузки файла указанного размера. В частности, проверяется ограничение на размер загружаемого файла, на общий размер файлов, загруженных пользователем, и на максимальное количество загружаемых файлов. Применяется при загрузке файла в базу с портала.

_Синтаксис:_  
      **tools.check\_resource\_size (<iFileSizeParam>, <iPersonIDParam>)**

_Аргументы:_  
     <iFileSizeParam> (обязательный)  
     Тип: **Целое число**. Размер файла в байтах.  
     <iPersonIDParam> (обязательный)  
     Тип: **Целое число**. ID сотрудника.

_Возвращаемое значение:_  
      Тип: **Строка**. Возвращает выражение _'ok'_, если загрузка разрешена, или строку с сообщением о причине отказа в загрузке в противном случае. 

_Пример 1:_  
     

`_// Пусть в системе имеется сотрудник Васильева Людмила Петровна_` 

`_// Находим сотрудника Васильеву Л.П.   try {        _query_str = "for $elem in collaborators where $elem/fullname = 'Васильева Людмила Петровна' return $elem";        objArray = XQuery(_query_str);        // objArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает всех сотрудников, ФИО которых имеет значение 'Васильева Людмила Петровна'        A1 = ArrayFirstElem ( objArray ); // функция возвращает первый элемент массива сотрудников personArray (в данном случае массив состоит из одного элемента)        alert ('Найден сотрудник: ' + A1.fullname); // на экран выводится полное имя отобранного сотрудника   }    catch (err){        alert ('Сотрудник не найден!');   }_`

`_sCheckResult = tools.check_resource_size( 1000, A1.id);   alert ( sCheckResult ); // выводится строковое значение 'ok'_`

_Пример 2:_  
      `_sCheckResult = tools.check_resource_size(StrLen(oFileField), curUserID);_`
