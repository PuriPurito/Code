## get_current_user_operations

Возвращает массив каталожных записей операций, доступных типу руководителя с названием «Текущий пользователь» (code = current\_user в каталоге boss\_type («Тип руководителя»)).

_Синтаксис:_  
      **tools.get\_current\_user\_operations ()**

_Аргументы:_  
      Функция вызывается без аргументов.

_Возвращаемое значение:_  
      Тип: **Массив**. Массив каталожных записей операций, доступных типу руководителя «Текущий пользователь».

_Пример:_  
      `_xarrOperations = tools.get_current_user_operations();_`
