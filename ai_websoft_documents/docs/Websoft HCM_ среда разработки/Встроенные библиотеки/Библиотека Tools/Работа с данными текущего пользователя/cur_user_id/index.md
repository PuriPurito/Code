## cur_user_id

Свойство. ID текущего пользователя Webtutor Administrator.  
См. также cur\_user, get\_cur\_user.

_Синтаксис:_  
      **tools.cur\_user\_id**

_Возвращаемое значение:_  
      Тип: **Целое число**. ID текущего пользователя Webtutor Administrator.

_Пример 1:_  
      `_i_cui = tools.cur_user_id;          alert ( i_cui ); // возвращает ID текущего пользователя Webtutor Administrator_`

_Пример 2:_  
      `_docResource.TopElem.person_id = tools.cur_user_id;_`
