## update_cur_user_groups

Обновляет  список каталожных записей из групп текущего пользователя WebTutor администратор в свойстве cur\_user\_groups.

Входные параметры нет.

Возвращаемый результат – список каталожных записей из групп текущего пользователя или null если заполнение не удалось.

Пример вызова.

**tools.update\_cur\_user\_groups();**
