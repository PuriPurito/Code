## get_custom_document_form

Возвращает XMS-форму (экранную форму) для каталога (указанного в качестве аргумента), создаваемого из типа настраиваемого документа. Если для данного типа документа создан свой пользовательский интерфейс, то документ откроется с использованием этого интерфейса. В противном случае документ откроется с использованием формы по умолчанию.

_Синтаксис:_  
      **tools.get\_custom\_document\_form (<catalog\_name>)**

_Аргументы:_  
     _<catalog\_name> (обязательный)_  
      Тип: **Строка**. Название каталога, создаваемого из типа настраиваемого документа. 

_Возвращаемое значение:_  
      Тип: **Экранная форма**. XMS-форма в формате SPXML-SCREEN для каталога, создаваемого из типа настраиваемого документа.

_Пример:_  
      `_CreateDocScreen (docObject, tools.get_custom_document_form (TopElem.catalog_name ));         ObtainDocScreen ( UrlFromDocID ( ListElem.PrimaryKey ), tools.get_custom_document_form ( catalog.type ));_`
