## save_custom_ui_form

Создает xms форму пользовательского интерфейса.

Входные параметры:

TEMPLATE (variant) ID или TopElem объекта пользовательский интерфейс. 

Возвращаемый результат – флаг true – создание успешно завершено, false создание неуспешно (bool).

Пример вызова:

**tools.save\_custom\_ui\_form(TopElem)**
