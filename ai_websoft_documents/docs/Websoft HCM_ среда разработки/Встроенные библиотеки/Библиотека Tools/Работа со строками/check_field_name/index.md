## check_field_name

Проверяет, что переданная строка не пустая и не содержит русские буквы или недопустимые в названии теги XML-символы. Функция используется для проверки правильности названия полей, создаваемых пользователем в интерфейсе (настраиваемые поля, настраиваемые типы документов).

_Синтаксис:_  
      **tools.check\_field\_name (<field>\[, <is\_strict\_begin>\])**

_Аргументы:_  
     <field> (обязательный)  
     Тип: **Строка**. Строковое выражение с названием поля (то, что содержится в поле name, а не title).   
     <is\_strict\_begin> (необязательный)  
     Тип: **Булево**. Аргумент, определяющий выполнение проверки на наличие русских букв или недопустимых в названии тегов XML-символов (_true_ – указанная проверка производится, _false_ – указанная проверка не производится). По умолчанию _false_.

_Возвращаемое значение:_  
      Тип: **Булево**. Возвращает значение, показывающее, прошла ли строка указанную проверку (_true_ – проверка пройдена успешно, _false_ – проверка не пройдена). 

_Пример 1:_        
     `_str1 = ''; // пустая строка        str2 = 'Строка, содержащая русские буквы'; // строка, содержащая русские буквы        str3 = 'Correct'; // корректная строка        bRez1 = tools.check_field_name ( str1 );        alert ( bRez1 ); // выводит значение false        bRez2 = tools.check_field_name ( str2, true );        alert ( bRez2 ); // выводит значение false        bRez3 = tools.check_field_name ( str3, true );        alert ( bRez3 ); // выводит значение true_`

_Пример 2:_  
      `_tools.check_field_name ( NewValue, true );_`
