## activate_education_program_to_person

Назначение сотруднику курсов, которые указаны в учебных программах (с типом **"Электронный курс"**), перечисленных в наборе программ. Если в наборе учебных программ указаны учебные программы, содержащие дистанционное обучение (курсы), то эти курсы будут назначены сотруднику.

_Синтаксис:_  
      **tools.activate\_education\_program\_to\_person (<person\_id>, <education\_program\_id>\[, <person\_doc>\]\[, <education\_program\_doc>\])**

_Аргументы:_  
      _<person\_id> (обязательный)_  
      Тип: **Целое число**. ID сотрудника, которому назначается набор учебных программ.  
      _<education\_program\_id> (обязательный)_  
      Тип: **Целое число**. ID набора учебных программ.  
      _<person\_doc> (необязательный)_  
      Тип: **TopElem объекта XmlDoc**. TopElem карточки сотрудника, которому назначается тест.  
      _<education\_program\_doc> (необязательный)_  
      Тип: **TopElem объекта XmlDoc**. TopElem карточки набора учебных программ.

_Возвращаемое значение:_  
      Тип: **Целое число**. Количество назначенных курсов в составе набора учебных программ.

_Пример 1:_  
      `_// Пусть в системе имеется сотрудник Васильева Людмила Петровна         // и набор учебных программ «Наставничество и делегирование» (__модуль «Учебный центр»__)                 // Находим сотрудника Васильеву Л.П.         try {               _query_str = "for $elem in collaborators where contains($elem/fullname, 'Васильева') return $elem";               personArray = XQuery(_query_str);               // personArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает всех сотрудников, в состав ФИО которых входит подстрока 'Васильева'               A1 = ArrayFirstElem ( personArray ); // функция возвращает первый элемент массива сотрудников personArray               alert ('Найден сотрудник: ' + A1.fullname); // на экран выводится полное имя отобранного сотрудника         }         catch (err){               alert ('Сотрудник не найден!');         }                 // Находим набор учебных программ «Наставничество и делегирование»         try {               _query_str = "for $elem in education_programs where contains($elem/name, 'Наставничество и делегирование') return $elem";               edProgrArray = XQuery(_query_str);               // edProgrArray является массивом объектов Набор учебных программ, отобранных запросом. Запрос отбирает все наборы учебных программ, в состав названий которых входит подстрока 'Наставничество и делегирование'               A2 = ArrayFirstElem ( edProgrArray ); // функция возвращает первый элемент массива набора учебных программ edProgrArray               alert ('Найден набор учебных программ: ' + A2.name); // на экран выводится полное название отобранного набора учебных программ         }         catch (err){               alert ('Набор учебных программ не найден!');         }                 // Назначаем сотруднику набор учебных программ         try {               A3 = tools.activate_education_program_to_person ( A1.id, A2.id );               alert ('Количество курсов в назначенном наборе учебных программ: ' + A3 );         }         catch (err){               alert ('Набор учебных программ не назначен или допущена другая ошибка!');         }_`
