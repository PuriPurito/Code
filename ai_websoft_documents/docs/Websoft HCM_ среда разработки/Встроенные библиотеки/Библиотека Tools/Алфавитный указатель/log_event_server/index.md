## log_event_server

Функция **log\_event\_server** предназначена для записи информации в log-файл. 

_Синтаксис:_  
     **tools****.****log****\_****event****\_****server****( <****Protocol****\>, (<****sFile****\> + <****sText****\> ) )**

_Аргументы:_  
      <Protocol> (обязательный)  
      Тип: **Строка**. Название протокола передачи гипертекста. Обычно используется значение "xhttp" - расширенный протокол передачи гипертекста.  
      <sFile> (обязательный)  
      Тип: **Строка**. Название log-файла для записи информации.  
      <sText> (обязательный)  
      Тип: **Строка**. Записываемая информация.

_Пример:_  
     `_tools.log_event_server( "xhttp", ( 'chat_library.js ' + sText ) );_`
