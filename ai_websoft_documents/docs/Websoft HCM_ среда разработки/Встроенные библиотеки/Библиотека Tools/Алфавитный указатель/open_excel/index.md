## open_excel

Открывает документ файла Excel, размещенного по указанному адресу URL.  
Функция **tools.open\_excel ( excelFileUrl )** заменяет ранее использовавшийся вариант **OpenDoc(sFileUrlParam, 'format=excel').TopElem**, который требовал наличие компонента MSExcel.  
Функция **tools.open\_excel** не требует установки программы Excel и работает через .Net компонент Websoft.Office.Excel.  
Если файл, указанный в аргументе, не найден, функция выдает ошибки _«Элемент не найден»_ или _«Url host is not allowed»_ с прерыванием выполняемого кода.

Внимание! Функцию **tools.open\_excel** рекомендуется запускать с сервера. 

_Синтаксис:_  
      **tools.open\_doc (<excelFileUrl>)**

_Аргументы:_  
      _<excelFileUrl> (обязательный)_  
      Тип: **Строка**. Путь к файлу Excel.

Внимание! Папка с файлом Excel должна быть размещена в списке разрешенных.  
Для внесения папки в список разрешенных нужно добавить в конфигурационный файл **xhttp.ini** параметр   
**DATA-DB: путь\_к\_папке**   
с последующим перезапуском сервера Websoft HCM. 

Например, для внесения папки _WebTutorServer\\1_ в список разрешенных нужно добавить в файл **xhttp.ini** параметр:  
 **DATA-DB: 1**

_Возвращаемое значение:_  
      Тип: **Объект XmlElem**. Двумерный массив значений первого листа исходного файла Excel, содержащий свойство worksheet (также объект типа XmlElem). Результат действия функции.

_Пример:_  
     `_sExcelFileUrl = 'x-local://1/ttt.xls'; // папка WebTutorServer\1 должна быть добавлена в список разрешенных        arrXlsSourceList = tools.open_excel( sExcelFileUrl ).worksheet; // двумерный массив значений первого листа файла Excel ttt.xls_`
