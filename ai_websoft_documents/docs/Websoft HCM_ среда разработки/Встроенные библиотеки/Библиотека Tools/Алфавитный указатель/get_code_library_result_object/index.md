## get_code_library_result_object

Создание объекта, характеризующего результат выполнения метода (в особенности для библиотек программного кода).

Параметры создаваемого объекта:  
\- _error_ \= 0 (код ошибки (целое число)).  
\- _errorText_ \= '' (текст ошибки (строка)).  
\- _data_ \= ({}) (дополнительные данные (объект)).  
\- _paging_ \= ({}) (информация о пагинации (объект)).

Впоследствии данным параметрам присваиваются соответствующие значения.
