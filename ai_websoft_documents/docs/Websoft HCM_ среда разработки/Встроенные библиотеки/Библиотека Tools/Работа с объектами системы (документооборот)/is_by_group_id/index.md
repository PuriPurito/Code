## is_by_group_id

Используется для работы в документообороте по заявкам в процедуре оценки. Проверяет, входит ли текущий пользователь в указанную группу. Проверка производится относительно текущего пользователя (ID текущего авторизованного на портале пользователя равно curUserID), если этот пользователь определен в окружении, в котором вызывается функция.

_Синтаксис:_  
      **tools.is\_by\_group\_id (<is\_by\_group\_id>)**

_Аргументы:_  
     _<is\_by\_group\_id> (обязательный)_  
      Тип: **Целое число**. _ID_ должности для которой происходит проверка. 

_Возвращаемое значение:_  
      Тип: **Булево**. Возвращает значение _true_, если текущий пользователь входит в указанную группу, или _false_ - в противном случае.

_Пример 1:_      

`_// Пусть в системе имеется группа «Динамическая группа»   // Находим программно данную группу с помощью_ _функции tools.get_doc_by_key_   _oGroup = tools.get_doc_by_key ( 'group', 'name', 'Динамическая группа' ); // атрибуты групп хранятся в каталоге group; ищем группу по названию   alert ( 'Найдена группа ' + oGroup.TopElem.name + ' с идентификационным номером ' + oGroup.DocID ); // на экран выводится информация об отобранной группе_`

`_// Пусть в системе имеется сотрудник Калинин Михаил Михайлович, который входит в состав группы «Динамическая группа»   oCollab1 = tools.get_doc_by_key ( 'collaborator', 'fullname', 'Калинин Михаил Михайлович' );   alert ( 'Найден сотрудник ' + oCollab1.TopElem.fullname + ' с идентификационным номером ' + oCollab1.DocID ); // на экран выводится информация об отобранном сотруднике_`

`_curUserID = oCollab1.DocID; // указание текущего пользователя для корректного выполнения данного примера (на практике обычно текущий пользователь определен в_ _окружении_ _на портале)_`

`_// Проверяем, входит ли Калинин М.М. в состав указанной группы?   bRez = tools.is_by_group_id ( oGroup.DocID );   alert (bRez); // ответ - верно_` 

  
`_// Пусть в системе имеется сотрудник Васильева Людмила Петровна, которая не входит в состав группы «Динамическая группа»   oCollab2 = tools.get_doc_by_key ( 'collaborator', 'fullname', 'Васильева Людмила Петровна' );   alert ( 'Найден сотрудник ' + oCollab2.TopElem.fullname + ' с идентификационным номером ' + oCollab2.DocID ); // на экран выводится информация об отобранном сотруднике_`

`_curUserID = oCollab2.DocID; // указание текущего пользователя для корректного выполнения данного примера (на практике обычно текущий пользователь определен в_ _окружении_ _на портале)_`

`_// Проверяем, входит ли Васильева Л.П. в состав указанной группы?   bRez = tools.is_by_group_id ( oGroup.DocID );   alert (bRez); // ответ - неверно_`
