## is_self_cur_user

Используется для работы в документообороте по процедуре оценки и по заявкам. Проверяет, является ли указанный сотрудник тем, от чьего имени подана заявка или на кого создана форма оценки (где он оцениваемый). 

Входные параметры:

iUserIDParam (int) необязательный  – ID сотрудника, для которого нужно осуществить проверку. Если параметр не указан, то проверка происходит относительно текущего пользователя (curUserID), если он определен в окружении, в котором вызывается функция. 

Возвращаемый результат – флаг да или нет (bool).

Пример вызова

**tools.is\_self\_cur\_user()**
