## workflow_escalation_process

Вызов эскалации по документообороту.

Входные параметры:

\_source (Doc)  – документ (Doc) объекта, относительно которого вызывается действие.

\_escalation\_code (sting) – код эскалации документооборота.

\_workflow\_id (int) – ID документооборота.

\_workflow\_doc (TopElem) необязательный –TopElem документооборота.

\_alterCurObjectID (int) необязательный. Если эскалация документооборота, это печать печатной формы, то можно передать в этот параметр ID объекта, который будет передаваться в печатную форму как object\_id.

Возвращаемый результат – флаг (bool) всегда true
