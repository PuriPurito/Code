## is_person_func_manager

Используется для работы в документообороте по заявкам в процедуре оценки. Проверяет, является ли текущий пользователь  функциональным руководителем любого типа в карточке  сотрудника, подавшего заявку или сотрудника на которого создан анкета или план оценки.  Проверка происходит относительно текущего пользователя (curUserID), если он определен в окружении, в котором вызывается функция, и для текущего объекта curObject.person\_id, если он определен в окружении.

Входные параметры нет. 

Возвращаемый результат – флаг да или нет (bool).

Пример вызова

**tools.is\_person\_func\_manager()**
