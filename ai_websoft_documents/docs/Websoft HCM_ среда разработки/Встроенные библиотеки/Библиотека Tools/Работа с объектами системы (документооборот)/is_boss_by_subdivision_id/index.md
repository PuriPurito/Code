## is_boss_by_subdivision_id

Используется для работы в документообороте по заявкам в процедуре оценки. Проверяет, является ли текущий пользователь непосредственным руководителем указанного подразделения. Проверка производится относительно текущего пользователя (_ID_ текущего авторизованного на портале пользователя равно _curUserID_), если он определен в окружении, в котором вызывается функция. 

_Синтаксис:_  
      **tools.is\_boss\_by\_subdivision\_id (<sub\_id>)**

_Аргументы:_  
     _<sub\_id> (обязательный)_  
     Тип: **Целое число**. _ID_ подразделения, для которого производитсяпроверка. 

_Возвращаемое значение:_  
      Тип: **Булево**. Возвращает значение _true_, если функция выполнена успешно, или _false_ - в противном случае. 

_Пример 1:_      

`_// Пусть в системе имеется подразделение «IT отдел»   // Находим программно подразделение «IT отдел» с помощью_ _функции tools.get_doc_by_key_   _oSub = tools.get_doc_by_key ( 'subdivision', 'name', 'IT отдел' );    alert ( 'Найдено подразделение ' + oSub.TopElem.name + ' с идентификационным номером ' + oSub.DocID ); // на экран выводится информация об отобранном подразделении_`

`_// Пусть в системе имеется заведующая отделом Жирова Антонина Васильевна   oCollab1 = tools.get_doc_by_key ( 'collaborator', 'fullname', 'Жирова Антонина Васильевна' );   alert ( 'Найден сотрудник ' + oCollab1.TopElem.fullname + ' с идентификационным номером ' + oCollab1.DocID ); // на экран выводится информация об отобранном сотруднике_`

`_curUserID = oCollab1.DocID; // указание текущего пользователя для корректного выполнения данного примера (на практике обычно текущий пользователь определен в_ _окружении__)_`

`_// Проверяем, является ли Жирова А.В. начальником указанного подразделения?   bRez = tools.is_boss_by_subdivision_id ( oSub.DocID );   alert (bRez); // ответ - верно_`  
  
 

`_// Пусть в системе имеется сотрудник Васильева Людмила Петровна   oCollab2 = tools.get_doc_by_key ( 'collaborator', 'fullname', 'Васильева Людмила Петровна' );   alert ( 'Найден сотрудник ' + oCollab2.TopElem.fullname + ' с идентификационным номером ' + oCollab2.DocID ); // на экран выводится информация об отобранном сотруднике_`

`_curUserID = oCollab2.DocID; // указание текущего пользователя для корректного выполнения данного примера (на практике обычно текущий пользователь определен в_ _окружении__)_`

`_// Проверяем, является ли Васильева Л.П. начальником указанного подразделения?   bRez2 = tools.is_boss_by_subdivision_id ( oSub.DocID );   alert (bRez2); // ответ - неверно_`
