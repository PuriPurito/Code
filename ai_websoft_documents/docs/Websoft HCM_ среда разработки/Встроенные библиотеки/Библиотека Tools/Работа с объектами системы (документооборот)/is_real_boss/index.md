## is_real_boss

Используется для работы в документообороте по заявкам в процедуре оценки. Проверяет, является ли текущий пользователь  непосредственным руководителем для сотрудника, подавшего заявку или для сотрудника на которого создан анкета или план оценки.   Проверка происходит относительно текущего пользователя (curUserID), если он определен в окружении, в котором вызывается функция, и для текущего объекта curObject.person\_id, если он определен в окружении.

Входные параметры- нет.

Возвращаемый результат – флаг да или нет (bool).

Пример вызова

**tools.is\_real\_boss ()**
