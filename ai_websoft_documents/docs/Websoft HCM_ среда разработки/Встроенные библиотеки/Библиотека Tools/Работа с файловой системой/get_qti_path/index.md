## get_qti_path

Возвращает путь до файла со структурой теста/курса в формате qti.

_Синтаксис:_  
      **tools.get\_qti\_path (<oSource>\[, <fldPartParam>\])**

_Аргументы:_  
     <oSource> (обязательный)  
     Тип: **Целое число** или **TopElem**. ID карточки теста/курса, либо TopElem карточки теста/курса, либо TopElem карточки объекта, в котором имеется поле assessment\_id или course\_id для получения ID теста/курса.  
     <fldPartParam> (необязательный)  
     Тип: **Строка**. Код модуля электронного теста или курса, для которого нужно определить путь.

_Возвращаемое значение:_  
      Тип: **Строка**. Путь до файла со структурой теста/курса в формате qti.

_Пример 1:_

`_// Пусть в системе имеется тест с кодом 00001   // Находим программно тест с кодом 00001   try {        _query_str = "for $elem in assessments where $elem/code = '00001' return $elem";        objArray = XQuery(_query_str);        // objArray является массивом объектов Тест, отобранных запросом. Запрос отбирает тесты с кодом '00001'        A1 = ArrayOptFirstElem ( objArray ); // функция возвращает первый элемент массива objArray (в данном случае массив состоит из одного элемента)        alert ('Найден тест: ' + A1.title ); // на экран выводится название отобранного объекта   }   catch (err){        alert (err);   }_`

`_path = tools.get_qti_path ( A1.id ); // определяется путь до файла со структурой теста   alert (path); // указанный путь выводится на экран_`  

_Пример 2:_  
      `_path = tools.get_qti_path( courseDoc, _part );_`
