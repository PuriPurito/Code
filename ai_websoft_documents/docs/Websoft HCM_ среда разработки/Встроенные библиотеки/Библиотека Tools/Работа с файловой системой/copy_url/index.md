## copy_url

Копирует файл из адреса источника данных по адресу получателя данных. Все папки в адресе должны существовать до начала копирования, как в источнике, так и в получателе.

_Синтаксис:_  
      **tools.copy\_url (<sDestDirParam>, <sSourceDirParam>)**

_Аргументы:_  
     <sDestDirParam> (обязательный)  
     Тип: **Строка**. Путь или URL до файла получателя (включая название файла).  
     <sSourceDirParam> (обязательный)  
     Тип: **Строка**. Путь или URL до файла источника (включая название файла).

_Возвращаемое значение:_  
      Тип: **Булево**. Возвращает значение _true_, если операция завершилась успешно (копирование выполнено), или _false_ \- в противном случае (копирование не выполнено).

_Пример 1:_  
      _// В файловой системе должны существовать папки d:\\WebTutor\\Папка 1\\ и d:\\WebTutor\\Папка 2\\ и файл d:\\WebTutor\\Папка 1\\file.txt_

     `_sSource = 'file:///D:/WebTutor/Папка 1/file.txt';        sDest = 'file:///D:/WebTutor/Папка 2/file.txt';        bRez = tools.copy_url (sDest, sSource);        alert (bRez);_`

_Пример 2:_  
      `_tools.copy_url( 'x-local://' + DefaultDb + '/history.xml', 'x-local://wtv/history.xml' );_`
