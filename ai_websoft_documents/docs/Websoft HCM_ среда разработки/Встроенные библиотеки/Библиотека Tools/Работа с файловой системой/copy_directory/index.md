## copy_directory

Копирует папку с файлами, включая все подпапки из указанного источника в указанный приемник. Если приемник не существует, то он создается по указанному адресу.

_Синтаксис:_  
      **tools.copy\_directory (<sSourceDirParam>, <sDestDirParam>)**

_Аргументы:_  
     <sSourceDirParam> (обязательный)  
     Тип: **Строка**. Путь до папки источника.   
     <sDestDirParam> (обязательный)  
     Тип: **Строка**. Путь до папки приемника. 

_Возвращаемое значение:_  
      Тип: **Булево**. Возвращает значение _true_, если операция завершилась успешно (копирование выполнено), или _false_ \- в противном случае (копирование не выполнено).

_Пример 1:_  
     _// В файловой системе должна существовать папка d:\\WebTutor\\Папка 1\\_

     `_sSourceDir = 'file:///D:/WebTutor/Папка 1';        sDestDir = 'file:///D:/WebTutor/Папка 2';        bRez = tools.copy_directory(sSourceDir, sDestDir);        alert (bRez);_`

_Пример 2:_  
      `_tools.copy_directory(Source, Dest);_`
