## get_catalog_limits

Возвращает строку с XML-описанием каталогов, на которые наложено ограничение по количеству записей. 

_Синтаксис:_  
      **tools.get\_catalog\_limits ()**

_Аргументы:_  
      Функция вызывается без аргументов.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка с XML-описанием каталогов, на которые наложено ограничение по количеству записей.  
      Строка имеет следующую структуру:   
      <?xml version="1.0" encoding="utf-8"?><catalogs><catalog><name>cl\_course</name><max\_records\_num>3</max\_records\_num></catalog></catalogs>

_Пример:_

      `_str = tools.get_catalog_limits();         alert (str);_`
