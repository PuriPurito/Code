## create_object_version

Сохраняет версию объекта каталога, для которого проставлен флаг сохранения версий в администраторе. При этом создается объект в каталоге «Версии объектов» (**Системное администрирование – Версии объектов**).

_Синтаксис:_  
      **tools.create\_object\_version (<oDocParam>)**

_Аргументы:_  
     <oDocParam> (обязательный)  
     Тип: **Объект XmlDoc**. Документ объекта, версия которого сохраняется.

_Возвращаемое значение:_  
      Сохраняет версию объекта каталога. Возвращаемое значение отсутствует.

_Пример:_  
      `_tools.create_object_version( Doc );_`
