## get_sub_hierarchy

Возвращает массив каталожных записей всех дочерних объектов указанного объекта, включая его самого.

_Синтаксис:_  
      **tools.get\_sub\_hierarchy (<node\_id>,<node\_catalog>\[, <node\_parent\_field>\])**

_Аргументы:_  
     <node\_id> (обязательный)  
     Тип: **Целое число**. ID объекта, для которого происходит поиск дочерних объектов.   
     <node\_catalog> (обязательный)  
     Тип: **Строка**. Название каталога без ‘s’ на конце, в котором производится поиск.  
     <node\_parent\_field> (необязательный; обязательный, если название поля, в котором указывается ID родительского элемента, отличается от принятого по умолчанию)  
     Тип: **Строка**. Название поля, в котором указывается ID родительского элемента. По умолчанию parent\_object\_id. Если название данного поля отличается от принятого по умолчанию, это название обязательно нужно указать.

_Возвращаемое значение:_  
      Тип: **Массив**. Массив каталожных записей всех дочерних объектов указанного объекта, включая его самого.

_Пример 1 (поиск подчиненных организаций):_

`_// Пусть в системе имеется организация «Programming Development»   // Находим программно организацию «Programming Development» с помощью_ _функции tools.get_doc_by_key_   _oOrg = tools.get_doc_by_key ( 'org', 'disp_name', 'Programming Development' ); // ищем организацию по условному названию   alert ( 'Найдена организация ' + oOrg.TopElem.name + ' с идентификационным номером ' + oOrg.DocID ); // на экран выводится информация об отобранной организации_`

`_arrSub_hierarchy = tools.get_sub_hierarchy ( oOrg.DocID, 'org', 'app_instance_id' ); // поиск ведется в каталоге организаций org; в каталоге org отсутствует поле, отображающее ID родительских элементов, поэтому можно указать поле кода сервера app_instance_id   // функция находит только сам заданный объект (организацию), так как у данной организации нет дочерних организаций    alert ( ArrayCount (arrSub_hierarchy) ); // возвращает количество элементов массива    str = 'Подчиненные объекты для организации ' + oOrg.TopElem.name + ': \n';   for (elem in arrSub_hierarchy) // выводит информацию об элементах массива   {        str = str + ' - ' + elem.name + '\n';   }   alert ( str );_`  

_Пример 2 (поиск подчиненных организаций, подразделений и должностей):_

`_// Пусть в системе имеется организация «Programming Development»   // Находим программно организацию «Programming Development»    oOrg = tools.get_doc_by_key ( 'org', 'disp_name', 'Programming Development' ); // ищем организацию по условному названию   alert ( 'Найдена организация ' + oOrg.TopElem.name + ' с идентификационным номером ' + oOrg.DocID ); // на экран выводится информация об отобранной организации_`

`_arrSub_hierarchy = tools.get_sub_hierarchy ( oOrg.DocID, 'sub', 'parent_id' ); // поиск ведется в каталоге-связке sub, который включает в себя организации, подразделения и должности; поле, отображающее ID родительских элементов, в каталоге sub именуется parent_id (то есть отличается от названия, принятого по умолчанию - parent_object_id), поэтому название этого поля нужно указать   // функция находит сам заданный объект (организацию), подчиненное подразделение и все должности в организации    alert ( ArrayCount (arrSub_hierarchy) ); // возвращает количество элементов массива    str = 'Подчиненные объекты для организации ' + oOrg.TopElem.name + ': \n';   for (elem in arrSub_hierarchy) // выводит информацию об элементах массива   {        str = str + ' - ' + elem.name + '\n';   }   alert ( str );_`

_Пример 3 (поиск подчиненных подразделений):_

`_// Пусть в системе имеется подразделение «IT отдел»   // Находим программно подразделение «IT отдел» с помощью_ _функции tools.get_doc_by_key_   _oSub = tools.get_doc_by_key ( 'subdivision', 'name', 'IT отдел' );    alert ( 'Найдено подразделение ' + oSub.TopElem.name + ' с идентификационным номером ' + oSub.DocID ); // на экран выводится информация об отобранном подразделении_`

`_arrSub_hierarchy = tools.get_sub_hierarchy ( oSub.DocID, 'subdivision' ); // поиск ведется в каталоге подразделений subdivision; в каталоге subdivision поле, отображающее ID родительских подразделений, именуется parent_object_id (то есть так, как принято по умолчанию), поэтому название этого поля можно не указывать    // функция находит только сам заданный объект (подразделение), так как в системе у данного подразделения нет дочерних подразделений_`

`_alert ( ArrayCount (arrSub_hierarchy) ); // возвращает количество элементов массива    str = 'Подчиненные объекты для подразделения ' + oSub.TopElem.name + ': \n';   for (elem in arrSub_hierarchy) // выводит информацию об элементах массива   {        str = str + ' - ' + elem.name + '\n';   }   alert ( str );_`

_Пример 4 (поиск подчиненных разделов портала):_

`_// Пусть в системе имеется раздел портала «База знаний»   // Находим программно раздел портала «База знаний» с помощью_ _функции tools.get_doc_by_key_   _oPortal = tools.get_doc_by_key ( 'document', 'name', 'База знаний' ); // разделы портала хранятся в каталоге document   alert ( 'Найден раздел портала ' + oPortal.TopElem.name + ' с идентификационным номером ' + oPortal.DocID ); // на экран выводится информация об отобранном разделе портала_`

`_arrPortal_hierarchy = tools.get_sub_hierarchy ( oPortal.DocID, 'document', 'parent_document_id' ); // поиск ведется в каталоге разделов портала document; в каталоге document поле, отображающее ID родительских подразделений, именуется parent_document_id (то есть отличается от названия, принятого по умолчанию - parent_object_id), поэтому название этого поля нужно указать    // функция находит сам заданный объект (раздел портала) и дочерние подразделы_`

`_alert ( ArrayCount (arrPortal_hierarchy) ); // возвращает количество элементов массива    str = 'Подчиненные объекты для раздела портала ' + oPortal.TopElem.name + ': \n';   for (elem in arrPortal_hierarchy) // выводит информацию об элементах массива   {        str = str + ' - ' + elem.name + '\n';   }   alert ( str );_`
