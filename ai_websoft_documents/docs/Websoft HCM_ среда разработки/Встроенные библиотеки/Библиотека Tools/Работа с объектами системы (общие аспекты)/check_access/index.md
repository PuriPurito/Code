## check_access

Проверяет разрешение на доступ к указанному объекту для указанного пользователя. Проверка идет по уровню доступа, роли доступа, группам доступа и условиям доступа, если в карточке объекта есть соответствующие настройки.

_Синтаксис:_  
      **tools.check\_access (<source\_doc>, <user\_id>)**

_Аргументы:_  
     <source\_doc> (обязательный)  
     Тип: **TopElem**. TopElem объекта, доступ к которому нужно проверить.  
     <user\_id> (обязательный)  
     Тип: **Целое число**. ID сотрудника, для которого нужно проверить доступ.

_Возвращаемое значение:_  
      Тип: **Булево**. Возвращает значение, показывающее, разрешен ли сотруднику доступ к объекту (_true_ – доступ разрешен, _false_ – доступ запрещен).  

_Пример 1:_

`_// Пусть в системе имеется сотрудник Васильева Людмила Петровна    // и набор учебных программ «Наставничество и делегирование» (__модуль «Учебный центр»__)_`

`_// Находим сотрудника Васильеву Л.П.   try {        _query_str = "for $elem in collaborators where $elem/fullname = 'Васильева Людмила Петровна' return $elem";        objArray = XQuery(_query_str);        // objArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает всех сотрудников, ФИО которых имеет значение 'Васильева Людмила Петровна'        A1 = ArrayFirstElem ( objArray ); // функция возвращает первый элемент массива сотрудников objArray (в данном случае массив состоит из одного элемента)        alert ('Найден сотрудник: ' + A1.fullname); // на экран выводится полное имя отобранного сотрудника   }    catch (err){        alert ('Сотрудник не найден!');   }_`

`_// Находим набор учебных программ «Наставничество и делегирование»   try {        _query_str = "for $elem in education_programs where contains($elem/name, 'Наставничество и делегирование') return $elem";        objArray = XQuery(_query_str);        // objArray теперь является массивом объектов Набор учебных программ, отобранных запросом. Запрос отбирает все наборы учебных программ, названия которых имеют значение 'Наставничество и делегирование'        A2 = ArrayFirstElem ( objArray ); // функция возвращает первый элемент массива набора учебных программ objArray (в данном случае массив состоит из одного элемента)        alert ('Найден набор учебных программ: ' + A2.name); // на экран выводится полное название отобранного набора учебных программ   }    catch (err){        alert ('Набор учебных программ не найден!');   }_`

`_// Проверяем доступ сотрудника к объекту    bAccess = tools.check_access ( A2, A1.id );   alert ( bAccess );    if ( bAccess == true )        alert ( 'Сотрудник ' +  A1.fullname + ' имеет доступ к объекту ' + A2.name );   else         alert ( 'Сотрудник ' +  A1.fullname + ' не имеет доступа к объекту ' + A2.name );   _`

_Пример 2:_  
      `_bAccess = tools.check_access ( curCourse, curUserID );         if (tools.check_access(curCourseDoc.TopElem, curUserID) == false) throw "Нет доступа!";_`
