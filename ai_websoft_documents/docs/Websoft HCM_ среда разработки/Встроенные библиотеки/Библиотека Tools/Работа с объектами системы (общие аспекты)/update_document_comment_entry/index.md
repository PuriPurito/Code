## update_document_comment_entry

Обновляет данные о количестве дочерних элементов в родительском комментарии к разделу портала. Если задан iNewPortalDocIDParam, то дочерним записям,  проставляется новое значение документа портала, к которому они привязаны.

Входные параметры:

doc (Doc)  – Doc документ записи комментария к разделу портала, родителя которого нужно обновить;

iNewPortalDocIDParam (int) необязательный– ID раздела портала к которому нужно привязать дочерние комментарии.

Возвращаемый результат – целое число (int), количество дочерних элементов вниз по иерархии в определяемом doc.

Пример вызова

**tools.update\_document\_comment\_entry( TopElem.Doc, TopElem.portal\_doc\_id );**
