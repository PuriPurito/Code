## html_to_pdf

Преобразовывает html-файл, переданный в функцию, в файл в формате pdf и сохраняет его по указанному пути.

Примечание – Если указанный файл уже существует в файловой системе, то он перезаписывается без выдачи предупреждения.   
Если файл открыт в другой программе, то выдается ошибка с прерыванием выполняемого кода: _«Процесс не может получить доступ к файлу…, так как этот файл используется другим процессом.»_

_Синтаксис:_  
      **tools.html\_to\_pdf (<sHtmlText>, <sResourcesDirPath>, <sOutFilePath>)**

_Аргументы:_  
     <sHtmlText> (обязательный)  
     Тип: **Строка**. Строка с html для преобразования.  
     <sResourcesDirPath> (обязательный)  
     Тип: **Строка**. Путь до папки с ресурсами (изображения, стили и т.д.), которые используются в html. При отсутствии таких ресурсов указывается пустая строка ('').  
     <sOutFilePath> (обязательный)  
     Тип: **Строка**. Путь до файла, в который будет сохранен полученный файл pdf.

Примечание – Путь до файла может быть указан в следующем формате: _'D:/WebTutor/rezult.pdf'_.  
В данной функции формат URL не поддерживается.   
Указание расширения pdf обязательно.

_Возвращаемое значение:_  
      Тип: **Булево**. Возвращает значение _true_, если преобразование завершилось успешно, или _false_ - в противном случае.

_Пример 1:_  
`_// В системе должна существовать папка D:/WebTutor/   str = '<div class="wt-rte-note">***<br />***</div>';   bParam = tools.html_to_pdf (str, '', 'D:/WebTutor/rezult.pdf');   sRez = (bParam == true) ? 'Преобразование произведено корректно' : 'Ошибка';    // если выполняется условие, то переменная sRez принимает первое значение, если не выполняется - второе   alert (sRez);   _`

_Пример 2:_  
      `_tools.html_to_pdf (_str, '', UrlToFilePath(_filename));_`
