## desc_cleanup

Прообразовывает содержание строки для сохранения в теге _<desc> ... </desc>_. Предназначено для преобразования тегов и ссылок на файлы в описании.

_Синтаксис:_  
      **tools.desc\_cleanup (<desc>, \[<temp\_dir>\])**

_Аргументы:_  
     <desc> (обязательный)  
     Тип: **Строка**. Строка для преобразования.   
     <temp\_dir> (необязательный)  
     Тип: **Строка**. Строчное выражение пути до папки с файлами, указанными в теге.   
 

_Возвращаемое значение:_  
      Тип: **Строка**. Преобразованная строка. Результат действия функции.

_Пример:_  
      `_TopElem.desc = tools.desc_cleanup( TopElem.desc );_`
