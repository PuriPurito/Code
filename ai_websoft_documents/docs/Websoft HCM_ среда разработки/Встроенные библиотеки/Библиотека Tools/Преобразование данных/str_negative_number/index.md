## str_negative_number

Преобразует в строку числовой параметр функции. Если параметр отрицательный, то строка будет начинаться со знака «-».

Входные параметры:

iNumberParam (real) – число для преобразования в строку.

Возвращаемый результат – строка (string).

Пример вызова.

**tools.str\_negative\_number( TopElem.weight )**
