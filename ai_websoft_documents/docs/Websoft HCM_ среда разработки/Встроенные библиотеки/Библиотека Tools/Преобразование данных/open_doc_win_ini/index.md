## open_doc_win_ini

Возвращает сроку с тегами XML, полученную из файла путь до которого, передан в параметрах функции. Вызывает функцию tools.open\_str\_win\_ini для разбора файла.

Входные параметры:

sUrlParam (string) – строка с путем до файла.

Возвращаемый результат – срока (string) с тегами XML.
