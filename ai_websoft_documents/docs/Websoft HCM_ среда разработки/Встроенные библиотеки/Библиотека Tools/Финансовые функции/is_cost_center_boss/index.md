## is_cost_center_boss

Используется для работы в документообороте по заявкам в процедуре оценки. Проверяет, является ли текущий пользователь руководителем центра затрат для сотрудника, подавшего заявку, или для сотрудника, на которого созданы анкета или план оценки. Проверка производится относительно текущего пользователя (_ID_ текущего авторизованного на портале пользователя равно _curUserID_), если этот пользователь определен в окружении, в котором вызывается функция, и поля текущего объекта _curObject.person\_id_, если он определен в окружении.

_Синтаксис:_  
      **tools.is\_cost\_center\_boss ()**

_Аргументы:_  
      Функция вызывается без аргументов.

_Возвращаемое значение:_  
      Тип: **Булево**. Возвращает значение _true_, если текущий пользователь является руководителем центра затрат для сотрудника, подавшего заявку, или _false_ - в противном случае.

_Пример 1:_      

`_// Пусть в системе имеется сотрудник Иванов Иван Иванович, руководитель_ _центра затрат_ _«Центр затрат Управления» (текущий пользователь)   oCollab = tools.get_doc_by_key ( 'collaborator', 'fullname', 'Иванов Иван Иванович' );   alert ( 'Найден сотрудник ' + oCollab.TopElem.fullname + ' с идентификационным номером ' + oCollab.DocID ); // на экран выводится информация об отобранном сотруднике_`

`_// Пусть в системе имеется заявка с кодом '00008' (текущий объект)   oReq = tools.get_doc_by_key ( 'request', 'code', '00008' );   alert ( 'Найдена заявка ' + oReq.TopElem.code + ' с идентификационным номером ' + oReq.DocID ); // на экран выводится информация об отобранной заявке_`

`_curUserID = oCollab.DocID; // указание текущего пользователя для корректного выполнения данного примера (на практике обычно текущий пользователь определен в_ _окружении_ _на портале)   curObject = oReq.TopElem; // указание текущего объекта для корректного выполнения данного примера (на практике обычно текущий объект определен в_ _окружении_ _на портале)_`

`_// Проверяем, является ли текущий пользователь Иванов И.И. руководителем центра затрат для сотрудника, подавшего заявку   bRez = tools.is_cost_center_boss ( );   alert (bRez);_`

_Пример 2:_  
      `_bResult = tools.is_cost_center_boss();_`
