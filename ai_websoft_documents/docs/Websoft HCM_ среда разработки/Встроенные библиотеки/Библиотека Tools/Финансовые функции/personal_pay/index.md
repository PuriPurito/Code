## personal_pay

Создает документ об оплате (invoice) для курса из заявки.

Входные параметры:

\_org\_id (int) - ID организации.

\_request\_id (int) –ID заявки сотрудника на курс по которой происходит списание.

Возвращаемый результат – id оплаты (int).

Пример вызова

**\_invoce\_id = tools.personal\_pay( Int( \_org\_arr\[0\] ), Int( \_req ) );**
