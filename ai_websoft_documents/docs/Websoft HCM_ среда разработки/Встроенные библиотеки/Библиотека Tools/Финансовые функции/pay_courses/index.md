## pay_courses

Создает транзакцию по списанию указной суммы со счета указанной организации.

Входные параметры:

\_org\_id (int) - ID организации.

\_amount (real) – сумма списания.

\_comment (string) необязательный – комментарий к транзакции.

Возвращаемый результат – id транзакции  или null в случае неудачи (int).

Пример вызова

**tools.pay\_courses( personDoc.org\_id, courseDoc.price, '' );**
