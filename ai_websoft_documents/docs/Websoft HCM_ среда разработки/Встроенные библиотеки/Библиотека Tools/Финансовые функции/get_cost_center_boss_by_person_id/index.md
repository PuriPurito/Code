## get_cost_center_boss_by_person_id

Возвращает массив руководителей (руководителей по должности) центра затрат указанного сотрудника. Если указанные руководители не найдены, то возвращается пустой массив.

**Руководителем по должности** является сотрудник подразделения, у которого в карточке должности стоит флажок **Является руководителем подразделения**.

_Синтаксис:_  
      **tools.get\_cost\_center\_boss\_by\_person\_id (<person\_id>\[,<person\_doc>\])**      или  
      **tools.get\_cost\_center\_boss\_by\_person\_id (\[<person\_id>\],<person\_doc>)**

_Аргументы:_  
     <person\_id> (обязательный; необязательный, если передан параметр person\_doc)  
     Тип: **Целое число**. ID сотрудника, для которого производится поиск руководителей центра затрат.   
     <person\_doc> (необязательный)  
     Тип: **TopElem**. TopElem сотрудника, для которого производится поиск руководителей центра затрат.

_Возвращаемое значение:_  
      Тип: **Массив**. Массив каталожных записей сотрудников, являющихся руководителями центра затрат указанного сотрудника.

_Пример:_  
      `_cost_center_bossArray = tools.get_cost_center_boss_by_person_id ( curObject.person_id );_`
