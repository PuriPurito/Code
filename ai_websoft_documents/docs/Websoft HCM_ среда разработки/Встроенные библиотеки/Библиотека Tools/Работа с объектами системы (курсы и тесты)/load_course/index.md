## load_course

Загрузка курса из архива в базу. Курс создается если его нет или обновляется существующий.

Входные параметры:

*   fileUrl (string) – адрес до файла (архива) с курсом;
*   sFileCharsetParam (string) необязательный – кодировка (по умолчанию utf-8);
*   docCourseParam (Doc) необязательный – Doc документ курса.

Возвращаемый результат – документ загруженного курса. Если загрузка не удалась, вернет строку с описанием ошибки.

Пример вызова tools.load\_course( TopElem.file\_import, TopElem.file\_charset, docCourseParam );
