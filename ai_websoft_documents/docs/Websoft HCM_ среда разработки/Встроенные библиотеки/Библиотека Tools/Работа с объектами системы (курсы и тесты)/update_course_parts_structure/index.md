## update_course_parts_structure

Обновляет структуру разделов активных электронных курсов.

Входные параметры:

\_learning\_id (int) –– ID активного электронного курса структуру, которого нужно обновить.

\_course\_doc (TopElem) – TopElem электронного курса, структура которого обновляется.

\_doc\_learning (Doc) необязательный  – Doc активного электронного курса структуру, которого нужно обновить.

Возвращаемый результат – флаг (bool) да (true) в любом случае.

Пример вызова.

**tools.update\_course\_parts\_structure( \_learning.PrimaryKey, TopElem );**
