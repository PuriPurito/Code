## save_certificate

Формирует форму сертификата из стандартного шаблона templates/certificate\_template.html на основе завершенного курса.  Используется в карточке завершенного курса.

Входные параметры:

\_learning\_id (int) - ID завершенного курса, для которого формируется сертификат.

Возвращаемый результат –  сформированный Html сертификат (html).

Пример вызова

**\_text = tools.save\_certificate( \_id );**
