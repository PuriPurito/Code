## open_course_version

Отрывает указанную версию курса в интерфейсе администратора WebTutor.

Входные параметры:  
iCourseIdParam (int) – ID курса.  
sBaseUrlParam (string) –  путь до папок с предыдущий версией курса в файловой систем.

Возвращаемый результат  - Doc указанного курса.
