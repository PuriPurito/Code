## import_course

Импортирует курс в систему из указанного файла. Файл должен быть сформирован предварительно и соответствовать определенным стандартам (например, SCORM 2004).

Примечание - Предпочтительнее использовать стандартный способ импорта курса.

_Синтаксис:_  
      **tools.import\_course (<sFile>)**

_Аргументы:_  
     _<sFile> (обязательный)_  
      Тип: **Строка**. Путь до файла.

_Возвращаемое значение:_  
      Тип: Булево. Результат true в любом случае.

_Пример:_  
      `_tools.import_course (sPathToCourse);_`
