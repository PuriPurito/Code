## start_real_test

Назначает тест в рамках тестирования с ДУ для участников указанного мероприятия.

Входные параметры:

\_event\_id (int) –– ID мероприятия, участникам которого назначается тест.

\_doc\_event (Doc) необязательный  – Doc мероприятия.

Возвращаемый результат – измененный и сохраненный Doc мероприятия.

Пример вызова.

**ServerEval( 'tools.start\_real\_test(' + Ps.Doc.DocID + ')' );**
