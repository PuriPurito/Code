## obtain_custom_templates

Обновляет значения текущих настраиваемых полей в системе на основе списка, указанного в параметрах.

Входные параметры:

\_url (string) необязательный, если передан \_source.  Путь до файла с структурой списка (List) из которого будут загружаться данные.

\_source (TopElem) необязательный – list для обновления.

Возвращаемый результат – количество обновленных элементов списка.

Пример вызова.

**iCounter = tools.obtain\_custom\_templates( UrlAppendPath( 'x-local://custom/', temp\_doc.custom\_templates\_url ) );**
