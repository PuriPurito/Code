## disp_block_filling

Заполняет данные для отображения списка объектов в блоке в разделах администратора. Используется для отображения настраиваемых отчетов, настраиваемых типов документов, типов заявок и типов отзывов в нужных разделах администратора WebTutor с использованием функции disp\_block\_filling\_by\_source.

_Синтаксис:_  
      **tools.disp\_block\_filling (<source>, <disp\_block>)**

_Аргументы:_  
     <source> (обязательный)  
     Тип: **TopElem**. TopElem объекта, который нужно отобразить в блоке.  
     <disp\_block> (обязательный)  
     Тип: **Объект XmlElem**. XML-структура вида:  
     _<disp\_block>_          _<access\_block\_type TYPE="string"/> Код блока в который нужно добавить объект_  
          _<obj\_title TYPE="string"/> Название объекта, под которым он будет отображаться_          _<custom\_flag TYPE="bool"/> Стандартный или настраиваемый объект (нужно передавать true)_  
     _</disp\_block>_  
     Если в качестве атрибута _disp\_block_ передать пустую XML-структуру (_<disp\_block> </disp\_block>_), то список объектов будет удален из описания соответствующего раздела.

_Возвращаемое значение:_  
      Заполняет данные для отображения списка объектов. Возвращаемое значение отсутствует.

_Пример:_  
      tools.disp\_block\_filling( TopElem, TopElem.disp\_block );
