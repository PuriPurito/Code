## get_report_storage_field

Используется в настраиваемых отчетах для возврата названия тега, в котором хранится значение по типу данных этого значения. Значение затем может быть показано пользователю в ячейке отчета.

_Синтаксис:_  
      **tools.get\_report\_storage\_field (<sDatatype>)**

_Аргументы:_  
     <sDatatype> (обязательный)  
     Тип: **Строка**. Тип данных. Исходное значение.  
Предусмотрены следующие допустимые значения данного аргумента:  
\- _'integer'_ – целое число;  
\- _'real'_ – действительное число;  
\- _'date'_ – дата;  
\- _'bool'_ – булево.

_Возвращаемое значение:_  
Тип: **Строка**. Название тега, в котором хранится значение указанного типа.  
Предусмотрены следующие возвращаемые значения:  
\- _'vi'_ – для значения аргумента 'integer';  
\- _'vn'_ – для значения аргумента 'real';  
\- _'vd'_ – для значения аргумента 'date';  
\- _'vb'_ – для значения аргумента 'bool';  
\- _'vs'_ – для значений аргумента, отличных от допустимых.

_Пример 1:_  
      `_alert ( tools.get_report_storage_field ('integer') );_`

_Пример 2:_  
      `_ArrayExtract(Ps.columns, 'tools.get_report_storage_field(This.datatype.Value)'); || В данном случае, использован указатель This, в который передается текущий элемент массива._`
