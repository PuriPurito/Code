## disp_block_filling_by_source

Заполняет данные для отображения списка объектов в блоке в разделах администратора по указанным источникам. Используется для отображения настраиваемых отчетов, настраиваемых типов документов, типов заявок и типов отзывов в нужных разделах администратора WebTutor.

_Синтаксис:_  
      **tools.disp\_block\_filling\_by\_source (<source>, <disp\_block>, <disp\_object\_blocks>, <source\_id>)**

_Аргументы:_  
     <source> (обязательный)  
     Тип: **TopElem**. TopElem объекта, который нужно отобразить в блоке.  
     <disp\_block> (обязательный)  
     Тип: **Объект XmlElem**. XML-структура вида:  
     _<disp\_block>  
          <access\_block\_type TYPE="string"/> Код блока в который нужно добавить объект  
          <obj\_title TYPE="string"/> Название объекта, под которым он будет отображаться  
          <custom\_flag TYPE="bool"/> Стандартный или настраиваемый объект (нужно передавать true)  
     </disp\_block>_  
     Если в качестве атрибута _disp\_block_ передать пустую XML-структуру (_<disp\_block> </disp\_block>_), то список объектов будет удален из описания соответствующего раздела.  
     <disp\_object\_blocks> (обязательный)  
     Тип: **_Объект XmlElem_**. Существующие блоки (источники) для отображения.  
     <source\_id> (обязательный)  
     Тип: **_Целое число_**. ID объекта, который нужно отобразить в блоке.

_Возвращаемое значение:_  
      Заполняет данные для отображения списка объектов по источникам. Возвращаемое значение отсутствует.

_Пример:_  
      `_tools.disp_block_filling_by_source( _source, _disp_block, disp_object_blocks, _source.Doc.DocID );_`
