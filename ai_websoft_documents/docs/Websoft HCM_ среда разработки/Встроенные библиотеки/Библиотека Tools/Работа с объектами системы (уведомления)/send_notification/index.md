## send_notification

Отправляет созданное с помощью функции tools.create\_notification  неотправленное уведомление.

Входные параметры:

iActiveNotificationIDParam (int) - ID неотправленного уведомления, которое должно быть отправлено.

Возвращаемый результат – флаг успешной или не успешной отправки уведомления (bool).

Пример вызова

**tools.send\_notification( catActiveNotificationElem.id );**
