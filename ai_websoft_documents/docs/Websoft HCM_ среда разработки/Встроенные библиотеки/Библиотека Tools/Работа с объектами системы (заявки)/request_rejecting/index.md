## request_rejecting

Осуществляет отмену (отклонение) заявки. Выполняет действия по отклонению заявки по типу прикреплённого объекта (если в типе заявки не снят признак «Использовать стандартную обработку для данного типа объекта»). Выполняет код отмены заявки из типа заявки. Меняет статус у заявки на «отмена» и проставляет дату закрытия заявки. Если стандартная обработка включает отправку уведомлений, то будут отправлены уведомления.

Входные параметры:

iRequestID (int) – ID заявки для отмены.

docRequest (Doc) необязательный –Doc заявки для обработки.

iPersonID (int) необязательный – ID сотрудника. Если будет совпадать с id подавшего заявку, то руководителю будет отправлено уведомление, что подчиненный сотрудник отменил заявку.

Возвращаемый результат – Doc обработанной и сохраненной заявки.

Пример вызова.

**tools.request\_rejecting( \_source.DocID, \_source );**
