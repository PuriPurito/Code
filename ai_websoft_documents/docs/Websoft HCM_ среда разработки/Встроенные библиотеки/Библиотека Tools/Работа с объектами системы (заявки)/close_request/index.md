## close_request

Закрывает HTTP-запрос к странице. При закрытии запроса вызывается код, обрабатывающий ее закрытие. В самой функции статус запроса не меняется.

_Синтаксис:_  
      **tools.close\_request (<request\_id>)**

_Аргументы:_  
     <request\_id> (обязательный)  
     Тип: **Целое число**. ID HTTP-запроса, который необходимо закрыть.

_Возвращаемое значение:_  
      Тип: **Булево**. Возвращает значение _true_, если операция завершилась успешно, или _false_ - в противном случае.

_Пример:_  
      `_if ( tools.close_request ( iObjectID ) )               iCounterAct++;_`
