## DateFunc

С версии 2.2025.1278 функция объявлена устаревшей и не выполняется в коде.

Возвращает результат выполнения функции eval, определяемый формулой _evalstr_ и другими атрибутами вызова функции. 

_Синтаксис:_  
      **tools.DateFunc (\[<src1>\]\[, <src2>\], <evalstr>, \[<param1>\]\[, <param2>\]\[, <param3>\])**

_Аргументы:_  
     <src1> (необязательный)  
     Тип: **Дата**. Поле-источник для передачи даты в формулу evalstr. По умолчанию - текущая дата. Если в качестве данного аргумента будет передана пустая строка (''), то результатом будут текущие дата и время. Атрибут вызывается с помощью выражения #1.  
     <src2> (необязательный)  
     Тип: **Дата**. Второе поле-источник для передачи даты в формулу evalstr. По умолчанию - текущая дата. Если в качестве данного аргумента будет передана пустая строка (''), то результатом будут текущие дата и время. Атрибут вызывается с помощью выражения #2.  
     <evalstr> (обязательный)  
     Тип: **Строка**. Строковое выражение формулы, выполняемой в функции eval.  
     <param1> (необязательный)  
     Тип: **Строка**. Атрибут, в который можно записать промежуточное значение, а потом вызвать его в другом месте с помощью выражения @1. В составе данного атрибута можно также использовать источники src1 и src2 в форме выражений #1 и #2, соответственно.  
     <param2> (необязательный)  
     Тип: **Строка**. Атрибут, в который можно записать промежуточное значение, а потом вызвать его в другом месте с помощью выражения @2. В составе данного атрибута можно использовать источники src1 и src2 в форме выражений #1 и #2, соответственно.  
     <param3> (необязательный)  
     Тип: **Строка**. Атрибут, в который можно записать промежуточное значение, а потом вызвать его в другом месте с помощью выражения @3. В составе данного атрибута можно использовать источники src1 и src2 в форме выражений #1 и #2, соответственно.

_Возвращаемое значение:_  
      Тип: **Строка**. Результат выполнения формулы, заданной атрибутом _evalstr_.

_Пример:_  
      `_// В данном примере даты переводятся в секунды и определяется количество полных суток между второй и первой датами:         start_usage_date = Date('01.01.2020 00:00');         last_usage_date = Date('22.02.2020 14:00');         delta = tools.DateFunc ( start_usage_date, last_usage_date, "( (DateToRawSeconds(#2) -  DateToRawSeconds(#1) ) /  86400 )");         alert (delta);_`
