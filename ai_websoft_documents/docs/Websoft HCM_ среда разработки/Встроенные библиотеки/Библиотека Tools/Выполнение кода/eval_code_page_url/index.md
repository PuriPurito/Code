## eval_code_page_url

Выполняет функцию eval указанного в параметрах функции файла.

_Синтаксис:_  
      **tools.eval\_code\_page\_url (<url>\[, <doc\_id>\]\[, <rnd\_id>\])**

_Аргументы:_  
     <url> (обязательный)  
     Тип: **Строка**. Путь до файла.  
     <doc\_id> (необязательный)  
     Тип: **Целое число, объект XmlDoc** или **TopElem**. ID объекта. Если аргумент указан, то будет открыт объект по указанному ID (если данный объект еще не был открыт) и он будет доступен для исполняемого кода файла. В этом аргументе может быть также указан _объект XmlDoc_ или _TopElem_ открытого объекта.  
     <rnd\_id> (необязательный)  
     Тип: **Строка**. Строка с названием файла. Если аргумент указан, то результат выполнения функции eval будет сохранен в папку _trash/temp/_  с названием, указанным в данном аргументе.

_Возвращаемое значение:_  
      Тип: **Строка**. Строка, полученная после выполнения функции eval.

_Пример:_  
      `_ServerEval ( 'tools.eval_code_page_url(\'x-local://templates/poll_results_report.html\',' + TopElem.Doc.DocID + ',' + _rnd_id + ')' );_`
