## call_code_library_method

Вызов метода из библиотеки программного кода.  
После выполнения загрузки библиотека кэшируется.

Примечание - По существу, данная функция получает объект библиотеки по его имени и вызывает (при помощи функции _CallObjectMethod_) определенный метод из указанной библиотеки с заданными параметрами. 

Внимание! При выполнении функции **tools.call\_code\_library\_method** имеется возможность использования кода C#, записанного в карточке библиотеки.   
Для карточек, в которых записан код JavaScript, данная возможность заблокирована. В последнем случае имеется возможность использовать код, записанный в прикрепленном файле JavaScript.

_Синтаксис:_  
      **tools.call\_code\_library\_method (<oLibraryParam>, <sMethodNameParam>, <arrParams>)**

_Аргументы:_  
     _<oLibraryParam> (обязательный)_  
      Тип: **Объект**. Код библиотеки программного кода, в которой описан вызываемый метод.  
     _<sMethodNameParam> (обязательный)_  
      Тип: **Строка**. Название вызываемого метода.  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Строка в формате _json_, задающая значения массива параметров вызываемого метода. Параметры перечисляются через запятую, и весь набор параметров заключается в квадратные скобки.

_Возвращаемое значение:_  
      Тип: **Различные типы данных**. Результат выполнения метода _<sMethodNameParam>_, определяемый типом указанного метода. 

_Пример:_  
      `_var oRes = tools.call_code_library_method("libTalentPool", "GetCareerReserveHierStageTaskByID", [ OptInt( iCareerReserveID, curObjectID )])         // вызов метода получения иерархического списка этапов и задач программы развития карьеры GetCareerReserveHierStageTaskByID из библиотеки программного кода libTalentPool (Библиотека развития карьеры)_`
