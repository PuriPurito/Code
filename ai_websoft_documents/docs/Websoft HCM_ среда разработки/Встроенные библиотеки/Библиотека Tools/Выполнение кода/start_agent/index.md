## start_agent

Запускает системный агент на выполнение.

Входные параметры:

\_agent\_id (int) – ID агента для запуска.

\_element\_id (int) необязательный  – ID объекта, над которым запускается агента (например, в списке).

\_elems\_id\_str(string) необязательный  – ID объектов разделенных «;», над которым запускается агента (например, в списке).

dDateParam (data) необязательный  – дата запуска агента, по умолчанию текущая дата.

sTenancyNameParam(string) необязательный  – код экземпляра системы в multitenant системе, в котором нужно запустить агент.

Возвращаемый результат – флаг да/нет (bool) успех или неуспех выполнения агента.

Пример вызова.

**tools.start\_agent( \_agent\_id, \_element\_id, \_elems\_id\_str, dDate, sTenancyName );**
