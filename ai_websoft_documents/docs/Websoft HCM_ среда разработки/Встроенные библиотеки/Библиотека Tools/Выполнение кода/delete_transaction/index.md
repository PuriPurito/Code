## delete_transaction

Отменяет транзакцию. Используется в модуле геймификация.

_Синтаксис:_  
      **tools.delete\_transaction (<transaction\_id>)**

_Аргументы:_  
     <transaction\_id> (обязательный)  
     Тип: **Целое число**. ID транзакции, которую нужно отменить.

_Возвращаемое значение:_  
      Тип: **Целое число**. ID транзакции, отменяющей указанную транзакцию.

_Пример:_  
      `_tools.delete_transaction( Ps.Doc.DocID );_`
