## set_web_ban

Функция меняет статус указанного сотрудника у поля «Временно запрещен доступ на портал». Функция отправляет уведомления сотруднику об изменении доступа.

Входные параметры:

\_person\_id (int) – ID сотрудника для установки значения поля «Временно запрещен доступ на портал».

\_status (bool) – доступ запрещен (true), доступ разрешен (false).

\_source (Doc) необязательный –Doc документа, для которого поменять значение в поле.

\_check\_admin (bool) необязательный – если значение параметра (true) менять значение можно только у сотрудников не являющихся администраторами.

Возвращаемый результат – флаг да/нет (bool) успех или неуспех смены статуса доступа на портал.

Пример вызова.

**if ( tools.set\_web\_ban( eval( '\_env' + Ps.row\_list\_field + Ps.row\_key\_field ), false ) )**
