## generate_doc_type_xmds

Проверяется возможность создания настраиваемого документа указанного типа, после чего можно будет создать XMD-форму документа и XMD-форму каталога. При вызове функции из интерфейса администратора будут выводиться всплывающие сообщения об ошибках.

_Синтаксис:_  
      **tools.generate\_doc\_type\_xmds (<doc\_topelem>\[, <doc\_id>\])**  
      или  
      **tools.generate\_doc\_type\_xmds (\[<doc\_topelem>\], <doc\_id>)**

_Аргументы:_  
     <doc\_topelem> (необязательный)  
     Тип: **TopElem**. TopElem типа настраиваемого документа.   
     <doc\_id> (обязательный; необязательный, если передан doc\_topelem)  
     Тип: **Целое число**. ID типа настраиваемого документа. 

_Возвращаемое значение:_  
      Тип: **Булево**. Возвращает значение _true_, если можно создать настраиваемый документ указанного типа, или _false_ - в противном случае.

_Пример:_  
      `_if ( ! tools.generate_doc_type_xmds ( TopElem, TopElem.Doc.DocID ) )                Cancel();_`
