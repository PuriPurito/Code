## get_doc_by_key

Возвращает объект документа, соответствующего указанным условиям, или null, если документ не найден.

_Синтаксис:_  
      **tools.get\_doc\_by\_key (<sObjectNameParam>, <oKeyParam>, <oKeyValueParam>)**

_Аргументы:_  
     <sObjectNameParam> (обязательный)  
     Тип: **Строка**. Название каталога для поиска объекта (без s на конце).  
     <oKeyParam> (обязательный)  
     Тип: **Строка** или **Массив**. Критерии поиска. Если передается строка, то это название поля в каталоге, по которому происходит поиск значения, заданного oKeyValueParam. Если это массив свойств, то будет создано условие поиска, в котором название свойства - название поля в каталоге, по которому происходит поиск значения, а значение - значение указанного свойства.  
     <oKeyValueParam> (обязательный)  
     Тип: **Строка**. Значение поля в каталоге, по которому происходит поиск.

_Возвращаемое значение:_  
      Тип: **Объект XmlDoc**. Документ, удовлетворяющий указанным условиям, или значение null, если такой документ не найден.

_Пример 1:_  
`_// Пусть в системе имеется заведующая отделом Жирова Антонина Васильевна   // Находим программно сотрудника Жирову А.В.   Collab = tools.get_doc_by_key ( 'collaborator', 'fullname', 'Жирова Антонина Васильевна' );   alert ( Collab.TopElem.id ); // выводится ID объекта   alert ( tools.object_to_text (Collab, 'xml') );  // выводится XML-структура объекта, преобразованная в строку_`  

_Пример 2:_  
      `_docObject = tools.get_doc_by_key ( sObjectNameParam, oKeyParam, oKeyValueParam );         docUserData = tools.get_doc_by_key ( 'user_data', 'code', String( oConditionsParam ) );_`
