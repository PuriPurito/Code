## get_doc_type_xmds

На основе указанного типа настраиваемого документа создает объект, содержащий в своих полях строковое описание XMD-формы документа и XMD-формы каталога, а также поле, по которому строится иерархия данного документа.

_Синтаксис:_  
      **tools.get\_doc\_type\_xmds (<iDocTypeIDParam>\[, <teDocTypeParam>\])**      или  
      **tools.get\_doc\_type\_xmds (\[<iDocTypeIDParam>\], <teDocTypeParam>)**

_Аргументы:_  
     <iDocTypeIDParam> (обязательный; необязательный, если передан teDocTypeParam)  
     Тип: **Целое число**. ID типа настраиваемого документа.   
     <teDocTypeParam> (необязательный)  
     Тип: **TopElem**. TopElem типа настраиваемого документа. 

_Возвращаемое значение:_  
      Тип: **Объект**. Объект, содержащий в поле object\_form\_str строковое описание XMD-формы документа, в поле catalog\_form\_str описание XMD-формы каталога, а также поле hier\_field, по которому строится иерархия данного документа.

_Пример 1:_      

`_// Пусть в системе имеется тип документа 'Новый тип документа 1' (этот тип документа нужно предварительно создать)   _`

`_// Находим программно тип документа 'Новый тип документа 1'   try {        _query_str = "for $elem in doc_types where $elem/name = 'Новый тип документа 1' return $elem";        objArray = XQuery(_query_str);        // objArray является массивом объектов Тип документа, отобранных запросом. Запрос отбирает все типы документа, название которых имеет значение 'Новый тип документа 1'        A1 = ArrayOptFirstElem ( objArray ); // функция возвращает первый элемент массива типов документов objArray (в данном случае массив состоит из одного элемента)        alert ('Найден тип документа: ' + A1.name); // на экран выводится полное имя отобранного типа документа        alert ('ID найденного типа документа: ' + A1.id); // на экран выводится идентификационный номер отобранного типа документа   }    catch (err){        alert ('Тип документа не найден!');   }_`

`_oXmds = tools.get_doc_type_xmds ( A1.id ); // подставляем в функцию ID типа документа   alert ( tools.object_to_text (oXmds, 'xml') ); // выводятся данные сформированного объекта_`  

_Пример 2:_  
      `_oXmds = tools.get_doc_type_xmds ( DOC_ID, TopElem );_`
