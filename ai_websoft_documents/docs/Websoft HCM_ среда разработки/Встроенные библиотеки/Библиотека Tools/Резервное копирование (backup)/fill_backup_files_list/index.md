## fill_backup_files_list

Возвращает  строку с названием всех файлов с расширением zip из указной папки. Строка это разделенные символом | названия фалов. Название это разделённые символом ; дата, тип, размер и название файла. 

Входные параметры:

\_dir (string)  – адрес до папки.

Возвращаемый результат – строка (string).

Пример вызова

**ServerEval( 'tools.fill\_backup\_files\_list( \\'' + ( Ps.recovery\_dir == '' ? 'x-local://backup\_data/' : Ps.recovery\_dir ) + '\\' )' )**
