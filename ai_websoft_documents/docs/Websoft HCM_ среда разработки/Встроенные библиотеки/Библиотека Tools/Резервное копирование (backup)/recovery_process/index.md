## recovery_process

Разворачивает базу данных XML из backup файла.

Входные параметры:

\_backup\_file (string) – путь до файла с \_backup\_file относительно папки сервера WebTutor .

Возвращаемый результат – число с результатом выполнения (int). Если больше 0, значит возникла ошибка.

Пример вызова

**tools.recovery\_process( \\'' + StrReplace( \_filepath, '\\\\', '\\\\\\\\' ) + '\\' )**
