## backup_data

Выполняет резервное копирование и сохраняет базу данных XML в backup-файл. Обновляет дату последнего резервного копирования в настройках системы.  
Backup-файл создается автоматически.

_Синтаксис:_  
      **tools.backup\_data ()**

_Аргументы:_  
      Функция вызывается без аргументов.

_Возвращаемое значение:_  
      Тип: **Строка**. Url архивного файла с резервной копией.

_Пример:_  
      `__str = tools.backup_data ();_`
