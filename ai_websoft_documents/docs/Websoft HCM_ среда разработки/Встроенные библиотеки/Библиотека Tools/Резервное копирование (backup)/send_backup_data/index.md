## send_backup_data

Создает для базы данных XML backup файл и отправляет его на сервер.

Входные параметры:

\_server\_id (int) – ID сервера обмена данными, на который отправляется файл.

Возвращаемый результат – нет.

Пример вызова

            **\_str = tools.send\_backup\_data( curExchangeServerID );**
