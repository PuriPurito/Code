## backup_process

Выполняет резервное копирование и сохраняет базу данных XML в указанный backup-файл.

_Синтаксис:_  
      **tools.backup\_process (<\_backup\_file>)**

_Аргументы:_  
     <\_backup\_file> (обязательный)  
     Тип: **Строка**. Путь до архивного файла с резервной копией относительно папки сервера WebTutor.

_Возвращаемое значение:_  
      Тип: **Целое число**. Значение, характеризующее результат выполнения функции. Если возвращено значение 0, то резервное копирование выполнено корректно. Если результат больше 0, значит возникла ошибка.

_Пример:_  
      `__res = tools.backup_process ( '\' + _backup_file + '\' );_`
