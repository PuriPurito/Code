## report_decrypt

Устаревшая функция. Представляет результаты теста в XML формате.

Входные параметры:

\_core  (string)  –результаты для дешифровки.

\_qti\_path (string) необязательный – путь до файла со структурой теста в формате qti.

\_qti\_text (string) необязательный  – структура  теста в формате qti.

Возвращаемый результат –  XML документ, без отступов, но со стандартным XML заголовком на основе.

Пример вызова.

**tools.report\_decrypt( Ps )**
