## get_sub_boss_by_person_id

Устаревшая функция. Больше не используется. Возвращает непосредственных руководителей подразделения указанного сотрудника.  
См. функцию _tools.get\_sub\_boss\_by\_sub\_id_.

_Синтаксис:_  
      **tools.get\_sub\_boss\_by\_person\_id (<person\_id>\[, <person\_doc>\])**

_Аргументы:_  
     <person\_id> (обязательный)  
     Тип: **Целое число**. ID сотрудника для подразделения, которого производится поиск руководителей.  
     <person\_doc> (необязательный)  
     Тип: **TopElem**. TopElem карточки сотрудника.

_Возвращаемое значение:_  
      Тип: **Массив**. Массив ID сотрудников, являющихся руководителями подразделения указанного сотрудника.

_Пример:_  
      `_array = tools.get_sub_boss_by_person_id (collab.id);_`
