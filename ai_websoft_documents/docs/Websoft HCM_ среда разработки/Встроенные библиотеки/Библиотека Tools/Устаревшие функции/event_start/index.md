## event_start

Изменяет статус мероприятия на _«Проводится»_. Устаревшая функция. Больше не используется. Функционал перенесен в функцию _set\_status_ объекта Мероприятие (например: _Ps.set\_status('active');_ ). 

_Синтаксис:_  
      **tools.event\_start (<event\_id>\[, <event\_doc>\]\[, <oScreenParam>\])**

_Аргументы:_  
     <event\_id> (обязательный)  
     Тип: **Целое число**. ID мероприятия, статус которого нужно изменить.  
     <event\_doc> (необязательный)  
     Тип: **Объект XmlDoc**. Документ мероприятия.  
     <oScreenParam> (необязательный)  
     Тип: **Экран**. Экран, в который выводятся сообщения (работает только при вызове из администратора WebTutor).  
 

_Возвращаемое значение:_  
      Тип: **Объект XmlDoc**. Документ мероприятия.

_Пример:_  
      `_curObjectDoc = tools.event_start ( docEvent.TopElem.Doc.DocID, docEvent, Screen );_`
