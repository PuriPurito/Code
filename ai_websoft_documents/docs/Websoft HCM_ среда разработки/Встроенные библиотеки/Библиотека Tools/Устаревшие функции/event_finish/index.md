## event_finish

Меняет статус мероприятия на _«Завершено»_. Устаревшая функция. Больше не используется. Функционал перенесен в функцию _set\_status_ объекта Мероприятие (например: _Ps.set\_status('close');_ ).

_Синтаксис:_  
      **tools.event\_finish (<event\_id>\[, <event\_doc>\])**

_Аргументы:_  
     <event\_id> (обязательный)  
     Тип: **Целое число**. ID мероприятия, статус которого нужно изменить.  
     <event\_doc> (необязательный)  
     Тип: **Объект XmlDoc**. Документ мероприятия.  
 

_Возвращаемое значение:_  
      Тип: **Объект XmlDoc**. Документ мероприятия.

_Пример:_  
      `_curObjectDoc = tools.event_finish ( curObjectID, curObjectDoc );_`
