## get_default_notification_system_id

Устарешая функция. Заменена на функцию tools.get\_default\_object\_id.  
Возвращает ID системы отправки уведомлений по умолчанию.

_Синтаксис:_  
      **tools.get\_default\_notification\_system\_id ()**

_Аргументы:_  
      Функция вызывается без аргументов.

_Возвращаемое значение:_  
      Тип: **Целое число**. ID системы отправки уведомлений по умолчанию.

_Пример:_  
      `_notification_system_id = tools.get_default_notification_system_id();         alert (notification_system_id );_`
