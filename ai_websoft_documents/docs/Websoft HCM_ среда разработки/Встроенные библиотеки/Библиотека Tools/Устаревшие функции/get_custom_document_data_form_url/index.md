## get_custom_document_data_form_url

Устаревшая функция. Больше не используется. Возвращает путь до XMD-формы для указанного каталога или объекта, создаваемого из типа настраиваемого документа.

_Синтаксис:_  
      **tools.get\_custom\_document\_data\_form\_url (<sCatalogNameParam>)**

_Аргументы:_  
     _<sCatalogNameParam> (обязательный)_  
      Тип: **Строка**. Название каталога с ‘s’ на конце, создаваемого из типа настраиваемого документа, если нужен путь до формы каталога. Или название объекта без ‘s’ на конце, создаваемого из типа настраиваемого документа, если нужен путь до формы объекта. 

_Возвращаемое значение:_  
      Тип: **Строка**. Путь до формы. Результат действия функции.

_Пример:_  
      `_path = tools.get_custom_document_data_form_url ('collaborators');_`
