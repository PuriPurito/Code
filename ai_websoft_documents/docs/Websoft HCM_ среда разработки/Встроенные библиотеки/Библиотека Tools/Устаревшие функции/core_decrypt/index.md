## core_decrypt

Устаревшая функция. Представляет результаты теста в XML-формате.

_Синтаксис:_  
      **tools.core\_decrypt (<core>\]\[, <qti\_path>\]\[, <qti\_text>\]\[, <learning\_doc>\])**

_Аргументы:_  
     <core> (обязательный)  
     Тип: **Строка**. Исходная информация теста для дешифровки.  
     <qti\_path> (необязательный)  
     Тип: **Строка**. Путь или URL до файла со структурой теста в формате qti.  
     <qti\_text> (необязательный)  
     Тип: **Строка**. Структура теста в формате qti.  
     <learning\_doc> (необязательный)  
     Тип: **TopElem**. TopElem карточки завершенного теста для дешифровки.

_Возвращаемое значение:_  
      Тип: **Объект XmlElem**. Xml-структура, содержащая результаты в теге annals.

_Пример:_  
      `_sRez = tools.core_decrypt ( core_test_data );_`
