## get_default_webinar_system_id

Устарешая функция. Заменена на функцию tools.get\_default\_object\_id.  
Возвращает ID системы проведения вебинаров по умолчанию.

_Синтаксис:_  
      **tools.get\_default\_webinar\_system\_id ()**

_Аргументы:_  
      Функция вызывается без аргументов.

_Возвращаемое значение:_  
      Тип: **Целое число**. ID системы проведения вебинаров по умолчанию.

_Пример:_  
      `_idWeb = tools.get_default_webinar_system_id();         alert (idWeb );_`
