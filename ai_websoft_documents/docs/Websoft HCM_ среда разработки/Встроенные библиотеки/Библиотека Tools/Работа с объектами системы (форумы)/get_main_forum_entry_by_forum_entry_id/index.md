## get_main_forum_entry_by_forum_entry_id

Возвращает ID самой верхней в иерархии родительской статьи форума.

Входные параметры:

iForumEntryParam (int) необязательный, если передан teForumEntryParam. ID статьи форума. 

\_ teForumEntryParam (TopElem) необязательный. TopElem статьи форума. 

Возвращаемый результат – ID самой верхней в иерархии родительской статьи форума (int).
