## create_certificate_to_event

Создает сертификаты указанного типа для всех участников указанного мероприятия.

_Синтаксис:_  
      **tools.create\_certificate\_to\_event (<even\_id>, <type\_id>\[, <path>\])**      или  
      **tools.create\_certificate\_to\_event (\[<even\_id>,\] <type\_id>, <path>)**

_Аргументы:_  
     <even\_id> (обязательный; необязательный, если передан атрибут <doc\_event>)  
     Тип: **Целое число**. ID мероприятия.   
     <type\_id> (обязательный)  
     Тип: **Целое число**. ID типа сертификата.   
     <path> (необязательный; обязательный, если не передан атрибут <even\_id>)  
     Тип: **Объект XmlDoc**. Документ мероприятия. 

_Возвращаемое значение:_  
      Тип: **Целое число**. Количество созданных сертификатов.

_Пример 1:_

`_// Пусть в системе имеются мероприятие «Делегирование»    // и тип сертификата «Сертификат Корпоративного учебного центра»_`

`_// Находим мероприятие «Делегирование»   try {        _query_str = "for $elem in events where $elem/name='Делегирование' return $elem";        objArray = XQuery(_query_str);        // objArray является массивом объектов Мероприятие, отобранных запросом. Запрос отбирает мероприятия, которые имеют название 'Делегирование' (в данном случае массив состоит из одного элемента)        A1 = ArrayFirstElem (objArray ); // функция возвращает первый элемент массива мероприятий objArray (в данном случае массив состоит из одного элемента)        alert ('Найдено мероприятие: ' + A1.name); // на экран выводится название отобранного мероприятия   }    catch (err){        alert ('Мероприятие не найдено!');   }_`

`_// Находим тип сертификата «Сертификат Корпоративного учебного центра»   try {        _query_str = "for $elem in certificate_types where $elem/name = 'Сертификат Корпоративного учебного центра' return $elem";        objArray = XQuery(_query_str);        // objArray является массивом объектов Тип сертификата, отобранных запросом. Запрос отбирает объекты с названием 'Сертификат Корпоративного учебного центра' (в данном случае массив состоит из одного элемента)        A2 = ArrayFirstElem (objArray ); // функция возвращает первый элемент массива objArray (в данном случае массив состоит из одного элемента)        alert ('Найден тип сертификата: ' + A2.name); // на экран выводится полное название квалификации   }    catch (err){        alert ('Тип сертификата не найден!');   }_`

`_// Присваиваем сертификаты участникам мероприятия   iRez = tools.create_certificate_to_event (A1.id, A2.id);   alert ('Количество присвоенных сертификатов: ' + iRez );_`
