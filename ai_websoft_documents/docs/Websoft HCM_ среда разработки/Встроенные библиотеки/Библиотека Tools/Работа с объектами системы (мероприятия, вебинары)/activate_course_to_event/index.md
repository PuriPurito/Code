## activate_course_to_event

Назначение курса участникам указанного мероприятия.

_Синтаксис:_  
      **tools.activate\_course\_to\_event (<event\_id>, <course\_id>\[, <doc\_event>\]\[, <duration>\]\[, <start\_learning\_date>\]\[, <last\_learning\_date>\])**

_Аргументы:_  
      _<event\_id> (обязательный)_  
      Тип: **Целое число**. ID мероприятия, для участников которого назначается курс.  
      _<course\_id> (обязательный)_  
      Тип: **Целое число**. ID курса, который необходимо назначить.  
      _<doc\_event> (необязательный)_  
      Тип: **Объект XmlDoc**. Документ карточки мероприятия.  
      _<duration> (необязательный)_  
      Тип: **Целое число**. Длительность курса в днях. Определяет дату планируемого завершения.  
      _<start\_learning\_date> (необязательный)_  
      Тип: **Дата**. Дата начала обучения. Если данный аргумент задан, то обучение невозможно будет начать раньше указанной даты.  
      _<last\_learning\_date> (необязательный)_  
      Тип: **Дата**. Контрольная дата завершения предыдущего обучения. Если параметр задан, то при назначении курса, проверяется, существует ли в каталоге learnings курс, завершенный после указанной даты. Если такой курс существует, то соответствующая запись из каталога learnings возвращается как результат работы функции.

_Возвращаемое значение:_  
      Тип: **Целое число**. Количество назначенных курсов.

_Пример 1:_  
      `_// Пусть в системе имеется мероприятие «Делегирование» (__модуль «Учебный центр»__)         // и курс «Эффективные переговоры»                 // Находим мероприятие «Делегирование»         try {               _query_str = "for $elem in events where contains($elem/name, 'Делегирование') return $elem";               eventArray = XQuery(_query_str);               // eventArray является массивом объектов Мероприятие, отобранных запросом. Запрос отбирает все мероприятия, в состав названий которых входит подстрока 'Делегирование'               A1 = ArrayFirstElem ( eventArray ); // функция возвращает первый элемент массива мероприятий eventArray               alert ('Найдено мероприятие: ' + A1.name); // на экран выводится название отобранного мероприятия         }         catch (err){               alert ('Мероприятие не найдено!');         }                 // Находим курс «Эффективные переговоры»         try {               _query_str = "for $elem in courses where contains($elem/name, 'переговоры') return $elem";               courseArray = XQuery(_query_str);               // courseArray является массивом объектов Курс, отобранных запросом. Запрос отбирает все курсы, в состав названий которых входит подстрока 'переговоры'               A2 = ArrayFirstElem (courseArray ); // функция возвращает первый элемент массива курсов courseArray               alert ('Найден курс: ' + A2.name); // на экран выводится полное название отобранного курса         }         catch (err){               alert ('Курс не найден!');         }                 // Назначаем участникам мероприятия отобранный курс         try {               A3 = tools.activate_course_to_event ( A1.id, A2.id );               alert ('Количество назначенных курсов: ' + A3 );         }         catch (err){               alert ('Курс не назначен или допущена другая ошибка!');         }_`
