## put_collaborator_annals

Заполняет информацию о прохождении теста (annals) в карточке незавершённого теста, назначенного в рамках тестирования с ДУ для участников указанного мероприятия. Тест завершается. Действия производятся со всеми участниками мероприятия, которым был назначен данный тест.

Входные параметры:

\_text (Xml) – Xml  с данными о прохождении теста участниками.

\_assessment\_id (int) –– ID теста.

\_assessment\_doc (TopElem) необязательный  –TopElem теста.

Возвращаемый результат – количество (int) участников мероприятия, для которых была внесена информация по тесту.

Пример вызова.

**ServerEval( 'tools.put\_collaborator\_annals(\\'' + formDoc.Xml + '\\',' + TopElem.assessment\_id + ')' );**
