## assign_qualification_to_event

Создает объект присвоенной квалификации для всех участников указанного мероприятия.

Примечание – Присвоенная квалификация отображается на карточке сотрудника в интерфейсе Webtutor Administrator в разделе **Персонал – Присвоения квалификаций**.

_Синтаксис:_  
      **tools.assign\_qualification\_to\_event (<even\_id>\[, <doc\_event>\], <qualification\_id>, <date>)**      или  
      **tools.assign\_qualification\_to\_event (\[<even\_id>, \]<doc\_event>, <qualification\_id>, <date>)**

_Аргументы:_  
      <even\_id> (обязательный; необязательный, если передан аргумент <doc\_event>)  
      Тип: **Целое число**. ID мероприятия.  
      <doc\_event> (необязательный)  
      Тип: **TopElem**. Документ мероприятия.  
      <qualification\_id> (обязательный)  
      Тип: **Целое число**. ID квалификации.  
      <date> (обязательный)  
      Тип: **Дата**. Дата присвоения квалификации.

_Возвращаемое значение:_  
      Тип: **Целое число**. Количество созданных присвоенных квалификаций.

_Пример 1:_

`_// Пусть в системе мероприятие «Делегирование» (__модуль «Учебный центр»__)   // и квалификация «Эксперт» (__модуль «Персонал»__)_`

`_// Находим мероприятие «Делегирование»   try {        _query_str = "for $elem in events where $elem/name='Делегирование' return $elem";        eventArray = XQuery(_query_str);        // eventArray является массивом объектов Мероприятие, отобранных запросом. Запрос отбирает мероприятия, которые имеют название 'Делегирование' (в данном случае массив состоит из одного элемента)        A1 = ArrayFirstElem ( eventArray ); // функция возвращает первый элемент массива мероприятий eventArray (в данном случае массив состоит из одного элемента)        alert ('Найдено мероприятие: ' + A1.name); // на экран выводится название отобранного мероприятия   }    catch (err){        alert ('Мероприятие не найдено!');   }_`

`_// Находим квалификацию «Эксперт»   try {        _query_str = "for $elem in qualifications where $elem/name = 'Эксперт' return $elem";        qualArray = XQuery(_query_str);        // qualArray является массивом объектов Квалификация, отобранных запросом. Запрос отбирает квалификацию с названием 'Эксперт' (в данном случае массив состоит из одного элемента)        A2 = ArrayFirstElem ( qualArray ); // функция возвращает первый элемент массива qualArray (в данном случае массив состоит из одного элемента)        alert ('Найдена квалификация: ' + A2.name); // на экран выводится полное название квалификации   }    catch (err){        alert ('Квалификация не найдена!');   }_`

`_// Добавляем квалификацию всем участникам мероприятия    A3 = tools.assign_qualification_to_event ( Int(A1.id), null, Int(A2.id), Date() );   if (A3 != null)      alert ( A3 + ' участникам мероприятия ' + A1.name + ' присвоена квалификация ' + A2.name );   else          alert ('Присвоение квалификации не выполнено!');      _`
