## activate_test_to_event

Назначение теста участникам указанного мероприятия.

_Синтаксис:_  
      **tools.activate\_test\_to\_event (<event\_id>, <test\_id>\[, <doc\_event>\]\[, <duration>\]\[, <start\_learning\_date>\]\[, <last\_learning\_date>\]\[, <sActTypeParam>\])**

_Аргументы:_  
      _<event\_id> (обязательный)_  
      Тип: **Целое число**. ID мероприятия, участникам которого назначается тест.  
      _<test\_id> (обязательный)_  
      Тип: **Целое число**. ID теста, который необходимо назначить.  
      _<doc\_event> (необязательный)_  
      Тип: **Объект XmlDoc**. Документ карточки мероприятия.  
      _<duration> (необязательный)_  
      Тип: **Целое число**. Длительность теста в днях. Определяет дату планируемого завершения.  
      _<start\_learning\_date> (необязательный)_  
      Тип: **Дата**. Дата начала обучения. Если данный аргумент задан, то обучение невозможно будет начать раньше указанной даты.  
      _<last\_learning\_date> (необязательный)_  
      Тип: **Дата**. Контрольная дата завершения предыдущего обучения. Если параметр задан, то при назначении теста проверяется, существует ли в каталоге test\_learnings тест, завершенный после указанной даты. Если такой тест существует, то ID соответствующей записи из каталога test\_learnings возвращается как результат работы функции.  
      _<sActTypeParam> (необязательный)_  
      Тип: **Строка**. Строка, указывающая, кому назначать тесты.  
      Возможные значения:  
            _'all'_ - Тесты назначаются всем участникам мероприятия (значение по умолчанию).  
            _'post'_ - Тесты назначаются участникам мероприятия, у которых проставлен флаг «_Присутствовал на мероприятии_».

_Возвращаемое значение:_  
      Тип: **Целое число**. Количество назначенных тестов.

_Пример 1:_  
      `_// Пусть в системе имеется мероприятие «Делегирование» (__модуль «Учебный центр»__)         // и тест «Знаете ли Вы литературу»                 // Находим мероприятие «Делегирование»         try {               _query_str = "for $elem in events where contains($elem/name, 'Делегирование') return $elem";               eventArray = XQuery(_query_str);               // eventArray является массивом объектов Мероприятие, отобранных запросом. Запрос отбирает все мероприятия, в состав названий которых входит подстрока 'Делегирование'               A1 = ArrayFirstElem ( eventArray ); // функция возвращает первый элемент массива мероприятий eventArray               alert ('Найдено мероприятие: ' + A1.name); // на экран выводится название отобранного мероприятия         }         catch (err){               alert ('Мероприятие не найдено!');         }                 // Находим тест «Знаете ли Вы литературу»         try {               _query_str = "for $elem in assessments where contains($elem/title, 'Знаете ли Вы литературу') return $elem";               testArray = XQuery(_query_str);               // testArray является массивом объектов Тест, отобранных запросом. Запрос отбирает все тесты, в состав названий которых входит подстрока 'Знаете ли Вы литературу'               A2 = ArrayFirstElem ( testArray ); // функция возвращает первый элемент массива тестов testArray               alert ('Найден тест: ' + A2.title); // на экран выводится полное название отобранного теста         }         catch (err){               alert ('Тест не найден!');         }                 // Назначаем участникам мероприятия отобранный тест         try {               A3 = tools.activate_test_to_event ( A1.id, A2.id );               alert ('Количество назначенных тестов: ' + A3 );         }         catch (err){               alert ('Тест не назначен или допущена другая ошибка!');         }_`
