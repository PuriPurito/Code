## del_person_from_event

Удаляет участника (сотрудника) из мероприятия.

_Синтаксис:_  
      **tools.del\_person\_from\_event (<person\_id>, <event\_id>, \[<doc\_event>\]\[, <flag\_save>\])**

_Аргументы:_  
     <person\_id> (обязательный)  
     Тип: **Целое число**. ID сотрудника, удаляемого из мероприятия.  
     <event\_id> (обязательный)  
     Тип: **Целое число**. ID мероприятия, из которого удаляется сотрудник.  
     <doc\_event> (необязательный)  
     Тип: **Объект XmlDoc**. Документ мероприятия, из которого удаляется сотрудник.  
     <flag\_save> (необязательный)  
     Тип: **Булево**. Аргумент, определяющий необходимость сохранения карточки мероприятия после удаления сотрудника (_true_ – сохранять карточку мероприятия, _false_ – не сохранять). По умолчанию - _true_.

_Возвращаемое значение:_  
      Тип: **Объект XmlDoc**. Документ мероприятия, из которого удален сотрудник.

_Пример 1:_      

`_// Пусть в системе имеется сотрудник Васильева Людмила Петровна    // и мероприятие «Делегирование»   // Включите предварительно сотрудника Васильеву Л.П. в мероприятие «Делегирование»_`

`_// Находим программно сотрудника Васильеву Л.П.   try {        _query_str = "for $elem in collaborators where $elem/fullname = 'Васильева Людмила Петровна' return $elem";        objArray = XQuery(_query_str);        // objArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает всех сотрудников, ФИО которых имеет значение 'Васильева Людмила Петровна'        A1 = ArrayOptFirstElem ( objArray ); // функция возвращает первый элемент массива сотрудников objArray (в данном случае массив состоит из одного элемента)        alert ('Найден сотрудник: ' + A1.fullname); // на экран выводится полное имя отобранного сотрудника   }    catch (err){        alert ('Сотрудник не найден!');   }_`

`_// Находим мероприятие «Делегирование»   try {        _query_str = "for $elem in events where $elem/name='Делегирование' return $elem";        objArray = XQuery(_query_str);        // objArray является массивом объектов Мероприятие, отобранных запросом. Запрос отбирает объекты с названием 'Делегирование' (в данном случае массив состоит из одного элемента)        A2 = ArrayOptFirstElem (objArray ); // функция возвращает первый элемент массива мероприятий objArray (в данном случае массив состоит из одного элемента)        alert ('Найдено мероприятие: ' + A2.name); // на экран выводится название отобранного мероприятия   }    catch (err){        alert ('Мероприятие не найдено!');   }_`

`_doc = tools.del_person_from_event ( A1.id, A2.id );   alert ('Сотрудник ' + A1.fullname + ' удален из мероприятия ' + doc.TopElem.name); // на экран выводится сообщение об удалении сотрудника из мероприятия_`  

_Пример 2:_  
      `__doc = tools.del_person_from_event( _person.PrimaryKey, curObjectID, curObjectDoc, false );_`
