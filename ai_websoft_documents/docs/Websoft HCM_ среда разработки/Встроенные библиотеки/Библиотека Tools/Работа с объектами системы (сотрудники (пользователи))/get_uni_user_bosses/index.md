## get_uni_user_bosses

Возвращает массив ID или список каталожных записей сотрудников, являющихся непосредственными (фактическими) руководителями указанного объекта (организации, подразделения, сотрудника) по должности либо функциональными руководителями из карточки объекта или вышестоящего подразделения, организации (если они определены для данного типа объекта). Для сотрудника также учитываются функциональные руководители групп, в которые данный сотрудник включен.  
Искомые руководители выбираются из каталога **func\_managers** и имеют признак **is\_native=true**.

**Непосредственным руководителем** является сотрудник подразделения, указанный в каталоге **func\_managers** и имеющий признак **is\_native=true**. Указанный признак может устанавливаться через массив функциональных руководителейу или с помощью установки флажка **Является руководителем подразделения** в карточке должности .

_Синтаксис:_  
      **tools.get\_uni\_user\_bosses (<objectParam>)**  
      или  
      **tools.get\_uni\_user\_bosses (<object\_id>\[, {\[return\_object\_type: Value\[, return\_object\_value: Value\]\]}\])**

_Аргументы:_  
      _<objectParam> (обязательный)_  
      Тип: **Различные типы данных**. Либо ID объекта, либо Doc объекта, либо TopElem объекта, для которого идет поиск руководителей.  
  
      или  
  
      _<oParams> (обязательный)_  
      Тип: **Объект**. Объект, который может содержать следующие поля:  
            _<object\_id> (обязательный)_  
            Тип: **Целое число**. ID объекта, для которого идет поиск руководителей (ID карточки сотрудника (найти руководителя для сотрудника), ID карточки должности (найти руководителя для должности), ID карточки подразделения, ID карточки организации).  
            _<return\_object\_type> (необязательный)_  
            Тип: **Строка**. Строка, задающая тип возвращаемых данных (если параметр имеет значение _'collaborator'_, то возвращаются каталожные записи каталога _collaborator_, иначе – записи каталога _func\_managers_). По умолчанию имеет значение _'collaborator'_.  
             Если атрибут отсутствует или он равен _'collaborator'_ – ищутся руководители объекта с типом _«Непосредственный руководитель»_.  
             Если атрибут указан и он не равен _'collaborator'_ – ищутся все руководители сотрудника вверх по иерархии, без деления на непосредственных или функциональных (выборка каталога _func\_managers_). При этом атрибут _return\_object\_value_ игнорируется.  
            _<return\_object\_value> (необязательный)_  
            Тип: **Строка**. Строка, задающая тип возвращаемых данных. По умолчанию имеет значение _'id'_.  
            Если параметр _return\_object\_type_ имеет значение _'collaborator'_, а значение параметра _return\_object\_value_ равно _'id'_, то возвращаются ID записей из каталога _collaborators._  
            Если параметр _return\_object\_type_ имеет значение _'collaborator'_, а значение параметра _return\_object\_value_ не равно _'id'_, то возвращаются каталожные записи из каталога _collaborators._  
            Если параметр _return\_object\_type_ имеет значение, отличное от _'collaborator'_, то возвращаются каталожные записи из каталога _func\_managers_, а значение параметра _return\_object\_value_ не учитывается_._  
 

     Примеры реализации функции:  
     _arr1 = tools.get\_uni\_user\_bosses ( A1.id, { return\_object\_type: 'collaborator',  return\_object\_value: 'id' } ); // атрибут return\_object\_type равен 'collaborator', а  return\_object\_value - 'id'; функция возвращает ID записей руководителей_ с типом «Непосредственный руководитель».  
     _arr1 = tools.get\_uni\_user\_bosses ( A1.id, { return\_object\_type: 'collaborator',  return\_object\_value: null  } ); // атрибут return\_object\_type равен 'collaborator', а  return\_object\_value не равен 'id'; функция возвращает каталожные записи руководителей_ с типом «Непосредственный руководитель».  
     _arr1 = tools.get\_uni\_user\_bosses ( A1.id, { } ); // атрибут return\_object\_type не указан (по умолчанию он равен 'collaborator', а return\_object\_value_ по умолчанию равен _'id'); функция возвращает ID записей руководителей_ с типом «Непосредственный руководитель».  
     _arr1 = tools.get\_uni\_user\_bosses ( A1.id ); // атрибут return\_object\_type не указан (по умолчанию он равен 'collaborator', а return\_object\_value_ по умолчанию равен _'id'); функция возвращает ID записей руководителей_ с типом «Непосредственный руководитель».  
     _arr1 = tools.get\_uni\_user\_bosses ( A1.id, { return\_object\_type: 'no',  return\_object\_value: 'id' } ); // атрибут return\_object\_type не равен 'collaborator' (при этом значение return\_object\_value не учитывается); функция возвращает массив каталожных записей руководителей разного типа (из каталога func\_managers)_

_Возвращаемое значение:_  
      Тип: **Массив данных**. Массив ID или список каталожных записей руководителей указанного объекта.

_Пример 1:_  
      `_// Пусть в системе у сотрудника Васильевой Людмилы Петровны имеются один фактический руководитель (по должности) - Жирова А.В.         // и два функциональных руководителя, указанных в карточке Васильевой – Карамазов В.А. (тип руководителя: Непосредственный руководитель) и Пахомов В.И. (тип руководителя: Руководитель обучения)         _query_str = "for $elem in collaborators where contains($elem/fullname, 'Васильева') return $elem";         personArray = XQuery(_query_str);         // personArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает всех сотрудников, в состав ФИО которых входит подстрока 'Васильева'         A1 = ArrayFirstElem ( personArray ); // функция возвращает первый элемент массива сотрудников personArray         alert ('Найден сотрудник: ' + A1.fullname); // на экран выводится полное имя отобранного сотрудника                 arr1 = tools.get_uni_user_bosses ( A1.id, { return_object_type: 'collaborator', return_object_value: null } ); // выбрается массив руководителей только с типом «Непосредственный руководитель»         alert ( 'return_object_type: collaborator, return_object_value: null' );         alert ( 'Количество руководителей: ' + ArrayCount(arr1) );         for ( boss_Elem in arr1 )         {               alert ('Найден руководитель: ' + boss_Elem.fullname); // выбрается запись из массива руководителей // выбрается массив руководителей только с типом «Непосредственный руководитель»         }                 arr2 = tools.get_uni_user_bosses ( A1.id, { return_object_type: null, return_object_value: null} ); // возвращает массив каталожных записей руководителей разного типа (из каталога func_managers)         alert ( 'return_object_type: null, return_object_value: null' );         alert ( 'Количество руководителей: ' + ArrayCount(arr2) );         for ( boss_Elem in arr2 )         {               alert ('Найден руководитель: ' + boss_Elem.person_fullname );         }         arr3 = ArraySelect(arr2, 'This.is_native'); // отфильтрует только непосредственных руководителей (например, руководитель подразделения по должности А.В.Жирова и сотрудник, отмеченный в карточке объекта с указанием типа "непосредственный руководитель" В.А.Карамазов)         alert ( 'Фильтрация непосредственных руководителей' );         alert ( 'Количество непосредственных руководителей: ' + ArrayCount(arr3) );         for ( boss_Elem in arr3 )         {               alert ('Найден непосредственный руководитель: ' + boss_Elem.person_fullname );         }                 A2 = tools.get_uni_user_boss ( A1.id );         alert ('Найден один из руководителей: ' + A2.fullname); // выбрается первая запись из массива руководителей_`
