## create_certificate_to_person

Создает сертификаты указанного типа для указанного сотрудника. Если указано мероприятие, то сертификат привязывается к указанному мероприятию.

_Синтаксис:_  
      **tools.create\_certificate\_to\_person (<person\_id>, <type\_id>, <even\_id>\[, <person\_doc>\]\[, <type\_doc>\]\[, <event\_doc>\])**      или  
      **tools.create\_certificate\_to\_person (\[<person\_id>\]\[, <type\_id>\]\[, <even\_id>\], <person\_doc>, <type\_doc>, <event\_doc>)**

_Аргументы:_  
     <person\_id> (обязательный; необязательный, если передан атрибут <person\_doc>)  
     Тип: **Целое число**. ID сотрудника.   
     <type\_id> (обязательный; необязательный, если передан атрибут <type\_doc>)  
     Тип: **Целое число**. ID типа сертификата.   
     <even\_id> (обязательный; необязательный, если передан атрибут <event\_doc> или если в сертификате не указывается мероприятие)  
     Тип: **Целое число**. ID мероприятия.   
     <person\_doc> (необязательный; обязательный, если не передан атрибут <person\_id>)  
     Тип: **TopElem**. TopElem сотрудника.   
     <type\_doc> (необязательный; обязательный, если не передан атрибут <type\_id>)  
     Тип: **TopElem**. TopElem типа сертификата.   
     <event\_doc> (необязательный; обязательный, если не передан атрибут <even\_id>)  
     Тип: **TopElem**. TopElem мероприятия. 

_Возвращаемое значение:_  
      Тип: **Объект XmlDoc**. Документ созданного сертификата.

_Пример 1:_

`_// Пусть в системе имеется сотрудник Васильева Людмила Петровна   // и тип сертификата «Сертификат Корпоративного учебного центра»_`

`_// Находим сотрудника Васильеву Л.П.   try {        _query_str = "for $elem in collaborators where $elem/fullname = 'Васильева Людмила Петровна' return $elem";        objArray = XQuery(_query_str);        // objArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает всех сотрудников, ФИО которых имеет значение 'Васильева Людмила Петровна'        A1 = ArrayFirstElem ( objArray ); // функция возвращает первый элемент массива сотрудников objArray (в данном случае массив состоит из одного элемента)        alert ('Найден сотрудник: ' + A1.fullname); // на экран выводится полное имя отобранного сотрудника   }    catch (err){        alert ('Сотрудник не найден!');   }_`

`_// Находим тип сертификата «Сертификат Корпоративного учебного центра»   try {        _query_str = "for $elem in certificate_types where $elem/name = 'Сертификат Корпоративного учебного центра' return $elem";        objArray = XQuery(_query_str);        // objArray является массивом объектов Тип сертификата, отобранных запросом. Запрос отбирает объекты с названием 'Сертификат Корпоративного учебного центра' (в данном случае массив состоит из одного элемента)        A2 = ArrayFirstElem (objArray ); // функция возвращает первый элемент массива objArray (в данном случае массив состоит из одного элемента)        alert ('Найден тип сертификата: ' + A2.name); // на экран выводится полное название квалификации   }    catch (err){        alert ('Тип сертификата не найден!');   }_`

`_// Присваиваем сертификат сотруднику Васильевой Л.П.   docRez = tools.create_certificate_to_person (A1.id, A2.id);   alert ('Сертификат ' + docRez.TopElem.type_name +  ' номер ' +docRez.TopElem.number + ' присвоен сотруднику ' + A1.fullname );_`
