## get_main_boss_by_person_id

Возвращает непосредственных руководителей организации указанного сотрудника.

Входные параметры:

\_person\_id (int) –ID сотрудника для организации, которого производится поиск руководителей.

Возвращаемый результат –  массив с ID сотрудников, являющихся непосредственными руководителями организации указанного сотрудника (array).

Пример вызова

**for ( iBossIDElem in tools.get\_main\_boss\_by\_person\_id( cnf\_temp\_iPersonID ) )**
