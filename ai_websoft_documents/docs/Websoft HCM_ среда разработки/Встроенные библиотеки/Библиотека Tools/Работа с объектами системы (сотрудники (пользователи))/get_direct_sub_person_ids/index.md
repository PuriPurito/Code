## get_direct_sub_person_ids

Возвращает массив ID сотрудников, состоящий из непосредственных подчиненных указанного сотрудника.

_Синтаксис:_  
      **tools.get\_direct\_sub\_person\_ids (<iUserId>)**

_Аргументы:_  
     _<iUserId> (обязательный)_  
      Тип: **Целое число**. ID сотрудника, для которого идет поиск подчиненных.

_Возвращаемое значение:_  
      Тип: **Массив**. Массив каталожных записей сотрудников, состоящий из непосредственных подчиненных указанного сотрудника.

_Пример 1:_      

`_// Пусть в системе имеется заведующая отделом Жирова Антонина Васильевна_`

`_// Находим программно сотрудника Жирову А.В.   try {        _query_str = "for $elem in collaborators where $elem/fullname = 'Жирова Антонина Васильевна' return $elem";        objArray = XQuery(_query_str);        // objArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает всех сотрудников, ФИО которых имеет значение 'Жирова Антонина Васильевна'        A1 = ArrayOptFirstElem ( objArray ); // функция возвращает первый элемент массива сотрудников objArray (в данном случае массив состоит из одного элемента)        alert ('Найден сотрудник: ' + A1.fullname); // на экран выводится полное имя отобранного сотрудника   }    catch (err){        alert ('Сотрудник не найден!');   }_`

`_cnt = ArrayCount (tools.get_direct_sub_person_ids ( A1.id )); // подставляем в функцию ID отобранного объекта   alert ('Cотрудник ' + A1.fullname + ' имеет ' + cnt + ' продчиненных');_`
