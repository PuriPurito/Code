## get_uni_user_boss

Возвращает каталожную запись сотрудника, руководителем или заместителем руководителя. Учитываются непосредственные (фактические) руководители указанного объекта (организации, подразделения, сотрудника) по должности или функциональные руководители из карточки объекта или вышестоящего подразделения, организации (если они определены для данного типа объекта). Для сотрудника также учитывается функциональные руководители групп.  
По сути возвращается первый элемент массива, полученного из функции _tools.get\_uni\_user\_bosses_.  
  
Если из результатов поиска нужно исключить заместителей руководителей, то можно передать параметр **substitution\_tipe\_id = 0**.

**Руководителем по должности** является сотрудник подразделения, у которого в карточке должности стоит флажок **Является руководителем подразделения**.

_Синтаксис:_  
      **tools.get\_uni\_user\_boss (<objectParam>)**

_Аргументы:_  
      _<objectParam> (обязательный)_  
      Тип: **Различные типы данных**. Либо ID объекта, либо Doc объекта, либо _TopElem_ объекта, для которого идет поиск руководителей.

_Возвращаемое значение:_  
      Тип: **Объект XmlDoc**. Каталожная запись руководителя указанного объекта.

_Пример 1:_            `_try {               // Пусть в системе у сотрудника Васильевой Людмилы Петровны имеются один фактический руководитель (по должности) - Жирова А.В.               // и два функциональных руководителя, указанных в карточке Васильевой – Карамазов В.А. (тип руководителя: Непосредственный руководитель) и Пахомов В.И. (тип руководителя: Руководитель обучения)               _query_str = "for $elem in collaborators where contains($elem/fullname, 'Васильева') return $elem";               personArray = XQuery(_query_str);               // personArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает всех сотрудников, в состав ФИО которых входит подстрока 'Васильева'               A1 = ArrayFirstElem ( personArray ); // функция возвращает первый элемент массива сотрудников personArray               alert ('Найден сотрудник: ' + A1.fullname); // на экран выводится полное имя отобранного сотрудника                       arr1 = tools.get_uni_user_bosses ( A1.id );               alert ( 'Количество руководителей: ' + ArrayCount(arr1) );               for ( boss_Elem in arr1 )               {                     alert ('Найден руководитель: ' + boss_Elem.fullname);               }               A2 = tools.get_uni_user_boss ( A1.id );               alert ('Найден один из руководителей: ' + A2.fullname);         }         catch (err){               alert ('Объект не найден!');         }_`

_Пример 2:_  
      `__expert_person = tools.get_uni_user_boss(USER_PERSON_ID);_`
