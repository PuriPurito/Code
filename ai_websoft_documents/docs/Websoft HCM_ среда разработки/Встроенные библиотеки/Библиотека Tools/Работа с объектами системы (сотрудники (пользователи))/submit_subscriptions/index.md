## submit_subscriptions

Отправляет письмо об изменении в блоке, форуме, сообщении форума или документе портала, всем подписанным на изменения пользователям, или конкретному пользователю.

Входные параметры:

\_document\_id  (int) необязательный, если передается \_source – ID объекта, для рассылки изменений.

\_source (TopElem) – TopElem объекта.

iPersonIDParam (int) – ID сотрудника, которому нужно отправить сообщение.

Возвращаемый результат – массив каталожных записей с подписками, по которым произошла рассылка.

Пример вызова.

**tools.submit\_subscriptions( TopElem.blog\_id, \_cur\_blog );**
