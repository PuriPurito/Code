## assign_qualification_to_person

Создает объект присвоенной квалификации для указанного сотрудника.

Примечание – Присвоенная квалификация отображается на карточке сотрудника в интерфейсе Webtutor Administrator в разделе **Персонал** **– Присвоения квалификаций**.

_Синтаксис:_  
      **tools.assign\_qualification\_to\_person (<person\_id>\[, <even\_id>\], <qualification\_id>\[, <assignment\_date>\]\[, <expiration\_date>\]\[, <qualification\_test\_array>\]\[, <qualification\_course\_array>\]\[, <send\_mail>\]\[, <in\_process>\])**

_Аргументы:_  
      _<person\_id> (обязательный)_  
      Тип: **Целое число**. ID сотрудника.  
      _<even\_id> (необязательный)_  
      Тип: **Целое число**. ID мероприятия.  
      _<qualification\_id> (обязательный)_  
      Тип: **Целое число**. ID квалификации, которая присваивается.  
      _<assignment\_date> (необязательный)_  
      Тип: **Дата**. Дата присвоения квалификации.  
      _<expiration\_date> (необязательный)_  
      Тип: **Дата**. Дата истечения квалификации.  
      _<qualification\_test\_array> (необязательный)_  
      Тип: **Массив**. Массив ID тестов, на основе которых присваивается квалификация.  
      <qualification\_course\_array> (необязательный)  
      Тип: **Массив**. Массив ID курсов, на основе которых присваивается квалификация.  
      _<send\_mail> (необязательный)_  
      Тип: **Целое число**. Необходимость отправления уведомления о присвоении квалификации. Аргумент может принимать значения 1 (уведомление отправлять) или 0 (уведомление не отправлять). Уведомление отправляется только при изменении статуса (аргумент _<in\_process>_).  
      _<in\_process> (необязательный)_  
      Тип: **Целое число**. Проставление статуса присвоения квалификации. Аргумент может принимать значения 1 (статус «В процессе») или 0 (статус «Присвоена»). Значение данного аргумента по умолчанию равно 1.

_Возвращаемое значение:_  
      Тип: **Объект XmlDoc**. Документ созданной присвоенной квалификации.

_Пример 1:_

`_// Пусть в системе имеется сотрудник Васильева Людмила Петровна    // и квалификация «Эксперт» (__модуль «Персонал»__)_`

`_// Находим сотрудника Васильеву Л.П.   try {        _query_str = "for $elem in collaborators where $elem/fullname = 'Васильева Людмила Петровна' return $elem";        personArray = XQuery(_query_str);        // personArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает сотрудника, ФИО которых имеет значение 'Васильева' (в данном случае массив состоит из одного элемента)        A1 = ArrayFirstElem ( personArray ); // функция возвращает первый элемент массива сотрудников personArray        alert ('Найден сотрудник: ' + A1.fullname); // на экран выводится полное имя отобранного сотрудника   }    catch (err){        alert ('Сотрудник не найден!');   }_`

`_// Находим квалификацию «Эксперт»   try {        _query_str = "for $elem in qualifications where $elem/name = 'Эксперт' return $elem";        qualArray = XQuery(_query_str);        // qualArray является массивом объектов Квалификация, отобранных запросом. Запрос отбирает квалификацию с названием 'Эксперт'        A2 = ArrayFirstElem ( qualArray ); // функция возвращает первый элемент массива qualArray (в данном случае массив состоит из одного элемента)        alert ('Найдена квалификация: ' + A2.name); // на экран выводится полное название квалификации   }    catch (err){        alert ('Квалификация не найдена!');   }_`

`_// Добавляем сотруднику квалификацию     A3 = tools.assign_qualification_to_person ( Int(A1.id), null, Int(A2.id), Date(), null, [], [], 0, 1 );   if (A3 != null)      alert ( 'Сотруднику ' + A1.fullname + ' присвоена квалификация ' + A2.name );   else          alert ('Присвоение квалификации не выполнено!');      _`
