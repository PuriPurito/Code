## get_user_comp_profiles

Возвращает список каталожных записей из профилей компетенции указанного сотрудника. Данные собираются из кодов профилей, указанных в должности сотрудника, и из профиля компетенции, указанного в должности сотрудника. Если в должности сотрудника не найдены профили компетенции, то берется профиль из типовой должности, привязанной к должности сотрудника (если такая связь имеется).

_Синтаксис:_  
      **tools.get\_user\_comp\_profiles (<objectParam>)**

_Аргументы:_  
     _<objectParam> (обязательный)_  
      Тип: **Целое число, Объект** или **TopElem**. ID сотрудника, либо документ сотрудника, либо TopElem сотрудника. 

_Возвращаемое значение:_  
      Тип: **Массив**. Список каталожных записей из профилей компетенции, указанного сотрудника.

_Пример 1:_

`_// Пусть в системе имеется сотрудник Васильева Людмила Петровна, работающий в должности «Ведущий специалист». Эта должность должна быть связана в системе с профилем компетенций «Типовой профиль компетенций» (код профиля – '01')   // Находим программно сотрудника Васильеву Л.П. с помощью_ _функции tools.get_doc_by_key_   _oCollab = tools.get_doc_by_key ( 'collaborator', 'fullname', 'Васильева Людмила Петровна' );   alert ( 'Найден сотрудник ' + oCollab.TopElem.fullname + ' с идентификационным номером ' + oCollab.DocID + ' в должности ' + oCollab.TopElem.position_id.ForeignElem.name ); // на экран выводится информация об отобранном сотруднике_`

`_oPosition = tools.get_doc_by_key ( 'position', 'id', oCollab.TopElem.position_id ); // находим программно документ (объект) должности «Ведущий специалист»   alert ('Найдена должность: ' + oPosition.TopElem.name);_`

`_oProfile = ArrayOptFirstElem(XQuery("for $elem in competence_profiles where $elem/code='01' return $elem")); // Находим программно документ (объект) профиля компетенций с кодом '01' (такой профиль должен существовать в системе)   alert ('Найден профиль компетенций с кодом 01: ' + oProfile.name);   oPosition.TopElem.competence_profile_id = oProfile.id; // связываем программно документ должности с профилем компетенций   oPosition.Save(); // сохранение измененного документа должности_`

`_arrProfiles=tools.get_user_comp_profiles ( oCollab.DocID );   str = 'Количество элементов массива: ' + ArrayCount (arrProfiles) + '\n';   str = str + 'В массив входят следующие элементы: \n';   for (elem in arrProfiles) // выводит информацию об элементах массива   {        str = str + ' - ' + elem.name + ' с кодом '  + elem.code + '\n';   }   alert ( str );_`
