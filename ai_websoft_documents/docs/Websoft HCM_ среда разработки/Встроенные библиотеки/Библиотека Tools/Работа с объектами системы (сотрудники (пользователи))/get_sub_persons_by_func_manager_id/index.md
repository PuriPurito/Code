## get_sub_persons_by_func_manager_id

Возвращает массив каталожных записей подчинённых сотрудников (как непосредственных, так и подчинённых подчиненных) указанного сотрудника.

_Синтаксис:_  
      **tools.get\_sub\_persons\_by\_func\_manager\_id (<iManagerIDParam>\[, <sCatalogNamesParam>\]\[, <vBossType>\])**

_Аргументы:_  
     <iManagerIDParam> (обязательный)  
     Тип: **Целое число**. ID сотрудника, для которого производится поиск подчиненных.  
     <sCatalogNamesParam> (необязательный)  
     Тип: **Строка**.   
Допустимые значения:  
\- _native_ – поиск подчиненных только непосредственного руководителя по должности;   
\- _not\_native_ – поиск подчиненных руководителя любого типа: группы, сотрудника, подразделения, организации.   
Можно передать _любой набор из следующих каталогов_ (collaborator, group, org, position, subdivision), разделенных запятой. Тогда поиск будет происходить только среди объектов указанных каталогов.  
     <vBossType> (необязательный)  
     Тип: **Булево** или **Целое число**. Тип руководителя.  
Допустимые значения:  
\- _true_ – поиск только непосредственного руководителя;   
\- _false_ \- поиск только функционального руководителя без признака Непосредственный.   
\- _ID типа руководителя_. Если передать ID нужного типа руководителя, то будет осуществлен поиск подчинённых сотрудников только для руководителей указанного типа.

_Возвращаемое значение:_  
      Тип: **Массив**. Массив каталожных записей подчинённых сотрудников.

_Пример 1:_

`_// Пусть в системе имеется заведующая отделом Жирова Антонина Васильевна   // Находим программно сотрудника Жирову А.В. с помощью_ _функции tools.get_doc_by_key_   _oCollab1 = tools.get_doc_by_key ( 'collaborator', 'fullname', 'Жирова Антонина Васильевна' );   alert ( 'Найден сотрудник ' + oCollab1.TopElem.fullname + ' с идентификационным номером ' + oCollab1.TopElem.id ); // на экран выводится информация об отобранном сотруднике_`

`_arrPerson = tools.get_sub_persons_by_func_manager_id( oCollab1.TopElem.id );   alert ( ArrayCount (arrPerson) ); // возвращает количество элементов массива    str = 'Сотрудник ' + oCollab1.TopElem.fullname + ': \n';   str = str + 'Подчиненные сотрудника: \n';   for (elem in arrPerson) // выводит информацию об элементах массива   {        str = str + ' - ' + elem.fullname + '\n';   }   alert ( str );_`

_Пример 2:_  
      `__res = tools.get_sub_persons_by_func_manager_id ( initiator_person_id );         _res = tools.get_sub_persons_by_func_manager_id ( initiator_person_id, 'native' );         _res = tools.get_sub_persons_by_func_manager_id ( initiator_person_id, 'not_native' );_`
