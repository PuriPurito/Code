## get_all_subs_by_func_manager_id

Возвращает массив каталожных записей подчинённых подразделений (как непосредственных, так и дочерних) для указанного сотрудника. Сотрудник может быть руководителем любого типа.

_Синтаксис:_  
      **tools.get\_all\_subs\_by\_func\_manager\_id (<manager\_id>)**

_Аргументы:_  
     <manager\_id> (обязательный)  
     Тип: **Целое число**. ID сотрудника, для которого нужно найти подчиненные ему подразделения.

_Возвращаемое значение:_  
      Тип: **Массив**. Массив каталожных записей подчинённых подразделений. Результат действия функции.

_Пример 1:_

`_// Пусть в системе имеется заведующая отделом Жирова Антонина Васильевна_`

`_// Находим программно сотрудника Жирову А.В.   try {        _query_str = "for $elem in collaborators where $elem/fullname = 'Жирова Антонина Васильевна' return $elem";        objArray = XQuery(_query_str);        // objArray является массивом объектов Сотрудник, отобранных запросом. Запрос отбирает всех сотрудников, ФИО которых имеет значение 'Жирова Антонина Васильевна'        A1 = ArrayOptFirstElem ( objArray ); // функция возвращает первый элемент массива сотрудников objArray (в данном случае массив состоит из одного элемента)        alert ('Найден сотрудник: ' + A1.fullname); // на экран выводится полное имя отобранного сотрудника   }    catch (err){        alert ('Сотрудник не найден!');   }_`

`_arrDepSubs = tools.get_all_subs_by_func_manager_id (A1.id);   for (q in arrDepSubs) // выведет элементы массива   {        alert(q.name);   }_`

_Пример 2:_  
      `_arrDepSubs = tools.get_all_subs_by_func_manager_id ( iUserID );_`
