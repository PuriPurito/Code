## get_user_by_login

Возвращает каталожную запись сотрудника с соответствующим логином и типом авторизации, или undefined, если такой сотрудник не найден.

_Синтаксис:_  
      **tools.get\_user\_by\_login (<Login>, <AuthType>)**

_Аргументы:_  
     <Login> (обязательный)  
     Тип: **Строка**. Логин сотрудника.  
     <AuthType> (обязательный)  
     Тип: **Строка**. Тип авторизации (_'ntlm', 'basic'_).

_Возвращаемое значение:_  
      Тип: **Объект**. Каталожная запись сотрудника или undefined, если сотрудник не найден.

_Пример 1:_  
`_// Пусть сотрудник Васильева Л.П. использует логин 'v', тип авторизации – базовый.   // Тогда определим ID сотрудника по его логину и типу авторизации   user = tools.get_user_by_login ( 'v', 'basic' );   alert (user.id);   _`

_Пример 2:_  
      `__user = tools.get_user_by_login( _login, curHost.portal_auth_type );_`
