## get_relative_operations_by_boss_types

Возвращает массив каталожных записей операций, определяемых типами руководителей  (_boss\_types_), который передается в функцию. Возвращает объединение операций доступных отдельному типу руководителя. При этом возвращаются только операции, привязанные к определённому (заданному параметрами функции) типу объекта (каталога) или все операции, если тип не указан.

_Синтаксис:_  
      **tools.get\_relative\_operations\_by\_boss\_types (<arrBossTypesParam>\[, <sCatalogNameParam>\])**

_Аргументы:_  
     <arrBossTypesParam> (обязательный)  
     Тип: **Массив**. Массив каталожных записей типов руководителей (_boss\_types_).  
     <sCatalogNameParam> (необязательный)  
     Тип: **Строка**. Строка с названием типа объекта (каталога без ‘s’ на конце). Если передана пустая строка, то вернет все операция доступные указанным типам руководителей.

_Возвращаемое значение:_  
      Тип: **Массив**. Массив каталожных записей операций, доступных указанному пользователю относительно указанного объекта.

_Пример:_  
      `_arrOperations = tools.get_relative_operations_by_boss_types (xarrBossTypes);_`
