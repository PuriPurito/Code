## check_relative_operation

Проверяет, входит ли указанная операция в состав массива операций, определяемых типами руководителей из массива функциональных руководителей (_func\_managers_), который передается в функцию.

_Синтаксис:_  
      **tools.check\_relative\_operation (<oManagerParam>, <oOperationParam>)**

_Аргументы:_  
     <oManagerParam> (обязательный)  
     Тип: **Массив**. Массив каталожных записей функциональных руководителей (_func\_managers_).  
     <oOperationParam> (обязательный)  
     Тип: **Целое число** или **Строка**. ID операции или код действия (_action_), привязанного к операции.

_Возвращаемое значение:_  
      Тип: **Булево**. Возвращает значение, показывающее, входит ли указанная операция в массив операций (_true_ – операция входит в массив операций, _false_ – операция не входит в массив операций).

_Пример:_  
      `_bCheck = tools.check_relative_operation ( tools.get_relative_boss_types ( curUserID, catCollab.id ), 'block_access_person');_`
