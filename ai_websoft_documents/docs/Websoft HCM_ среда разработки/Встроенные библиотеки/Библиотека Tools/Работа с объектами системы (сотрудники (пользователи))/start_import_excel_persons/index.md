## start_import_excel_persons

Используется для проверки заполнения схемы импорта перед импортом сотрудников в интерфейсе администратора.

Входные параметры:

Ps– TopElem Xml документа с настройками для загрузки.

Возвращаемый результат –  строка с ошибкой или пустая строка в случае успеха (string).

Пример вызова

**sErr = tools.start\_import\_excel\_persons( TopElem );**
