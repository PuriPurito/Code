## get_relative_boss_types

Возвращает массив каталожных записей функциональных руководителей (_func\_managers_). Отбираются те функциональные руководители, где объект (например, сотрудник), переданный в качестве первого параметра, является руководителем объекта (сотрудника/сотрудников, подразделений, организаций, групп), переданного во втором параметре. Для объектов должность, группа, подразделение, организация, сотрудник руководитель может быть любого типа.

_Синтаксис:_  
      **tools.get\_relative\_boss\_types (<objectParam>, <oPersonParam>)**

_Аргументы:_  
     <objectParam> (обязательный)  
     Тип: **Целое число, Объект XmlDoc** или **TopElem**. ID объекта, либо Doc объекта, либо TopElem объекта, для которого идет поиск руководителей относительно объекта, переданного во втором параметре.  
     <oPersonParam> (обязательный)  
     Тип: **Целое число** или **Массив**. ID сотрудника, для которого ищется руководитель, либо массив элементов (сотрудников, подразделений, организаций, групп).  
 

_Возвращаемое значение:_  
      Тип: **Массив**. Массив каталожных записей функциональных руководителей (_func\_managers_).

_Пример 1:_

`_// Пусть в системе имеется сотрудник Васильева Людмила Петровна   // Находим программно сотрудника Васильеву Л.П. с помощью функции_ _tools.get_doc_by_key_   _oCollab = tools.get_doc_by_key ( 'collaborator', 'fullname', 'Васильева Людмила Петровна' );   alert ( 'Найден сотрудник: ' + oCollab.TopElem.fullname + ' с идентификационным номером ' + oCollab.TopElem.id ); // на экран выводится информация об отобранном сотруднике_`

`_// Пусть в системе имеется заведующая отделом Жирова Антонина Васильевна   // Находим программно сотрудника Жирову А.В. с помощью функции_ _tools.get_doc_by_key_   _oCollab1 = tools.get_doc_by_key ( 'collaborator', 'fullname', 'Жирова Антонина Васильевна' );   alert ( 'Найден сотрудник ' + oCollab1.TopElem.fullname + ' с идентификационным номером ' + oCollab1.TopElem.id ); // на экран выводится информация об отобранном сотруднике_`

`_arrBossTypes = tools.get_relative_boss_types ( oCollab1.TopElem.id, oCollab.TopElem.id );   alert ( ArrayCount (arrBossTypes) ); // возвращает количество элементов массива (1)   for (q in arrBossTypes) // выводит информацию об элементах массива   {        alert ( q.Xml );   }   _`
