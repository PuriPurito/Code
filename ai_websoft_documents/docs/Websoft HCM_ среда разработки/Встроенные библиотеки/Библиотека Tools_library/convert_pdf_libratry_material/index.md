## convert_pdf_libratry_material

Преобразует материал библиотеки, к которому приложен файл типа pdf, в формат, доступный для чтения на портале WebTutor.  
Функция перенесена из библиотеки **Tools** в библиотеку **Tools\_library**.   

Функция **convert\_pdf\_libratry\_material** выполняется только на сервере!

_Синтаксис:_  
      **tools\_library.Real (<iMaterialId>)**

_Аргументы:_  
     <iMaterialId> (обязательный)  
     Тип: **Целое число**. ID материала библиотеки.

_Возвращаемое значение:_  
      Тип: **Объект XmlDoc**. Документ материала библиотеки.

_Пример 1:_      

`_// Пусть в системе имеется материал библиотеки «Руководство системного администратора системы WT» (__модуль «Библиотека»__)_`

`_// Находим материал библиотеки «Руководство системного администратора системы WT»   try {        _query_str = "for $elem in library_materials where $elem/name = 'Руководство системного администратора системы WT' return $elem";        objArray = XQuery(_query_str);        // objArray является массивом объектов Материал библиотеки, отобранных запросом. Запрос отбирает все материалы библиотеки с указанным названием         A1 = ArrayFirstElem ( objArray ); // функция возвращает первый элемент массива objArray (в данном случае массив состоит из одного элемента)        alert ('Найден материал библиотеки: ' + A1.name); // в основной журнал сервера выводится название материала библиотеки   }    catch (err){        alert ('Материал библиотеки не найден!');   }_`

`_// Преобразуем материал библиотеки   docMat = tools_library.convert_pdf_libratry_material (A1.id );_`

_Пример 2:_  
      `_docMat = tools_library.convert_pdf_libratry_material ( matId );_`
