## Поиск по конкретной фразе в XQuery запросах

Начиная с релизной сборки 2023.2.976 в XQuery запросах можно использовать поиск по конкретной фразе наряду с обычными словами. Для этого в XQuery doc-contains необходимо указать запрос в \[\], по аналогии с custom полями, но без наименования поля.

`for $elem in collaborators where doc-contains($elem/id,'wt_data','[Websoft VClassTest29]') return $elem`

Также выполнить поиск (например, \[Websoft VClassTest29\]) можно в интерфейсе администратора.
