## Настройка и использование словоформ в XQuery запросах

Для возможности использования словоформ в XQuery запросах необходимо подготовить систему следующим образом.

1.  Установить на сервер последний патч для .Net Core.
2.  Скачать библиотеку словоформ и скопировать ее в папку ".../WebTutorServer".
3.  Перезапустить сервер WebTuor.

После этого в в XQuery запросах можно использовать поиск по словам с учетом его словоформ. Для указания таких слов в запросах используется символ \`, который ставится сразу после слова. 

Например:  for $elem in documents where doc-contains( $elem/id, 'wt\_data', **'****центра****\`'**, 'document' ) order by  $elem/position, $elem/name return $elem
