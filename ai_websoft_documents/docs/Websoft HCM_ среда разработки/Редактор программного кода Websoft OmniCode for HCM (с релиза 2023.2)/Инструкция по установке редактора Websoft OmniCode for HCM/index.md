## Инструкция по установке редактора Websoft OmniCode for HCM

Для корректной работы редактора Websoft OmniCode for HCM необходима актуальная версия Websoft HCM, которую можно скачать с официального клиентского Портала. Установку редактора Websoft OmniCode и работу с ним рекомендуется выполнять сотруднику с правами администратора или пользователя с полным доступом к агентам, показателям, удаленным действиям и к соответствующим каталогам Websoft HCM. В настоящее время редактор Websoft OmniCode for HCM рекомендуется для работы с сервером разработки (локальным или в монопольном пользовательском режиме).  

На текущий момент создание компонентов через Websoft OmniCode не поддерживается в режиме кластера.

Для установки редактора Websoft OmniCode for HCM выполните действия:

1.  Установите расширение **Websoft.OmniCode for HCM** из магазина Microsoft или в Visual Studio Code (далее – VS Code). Для этого в VS Code перейдите во вкладку **Расширения** (**Extensions** в английской версии), введите в поиске «omnicode» и нажмите кнопку **Установить** (**Install** в английской версии).
    
    После установки расширения во вкладке **Проводник** (**Explorer** в английской версии) появится раздел **WEBSOFT HCM LINK SERVERS**.
    
2.  Для отладки и запуска кода на C# дополнительно установите версию **Microsoft .Net SDK**, под которую откомпилирован Websoft HCM (.net 6.0). Ее можно скачать с официального источника. Также установите расширение VSCode **C# Dev Kit**. Для этого в VS Code перейдите во вкладку **Расширения** (**Extensions** в английской версии), введите в поиске «dev kit» и нажмите кнопку **Установить** (**Install** в английской версии).
    
3.  В файле ...\\WebSoft\\WebSoftServer\\xHttp.ini проверьте и, при необходимости, установите параметры:
    
    •
    
    DOTNETCORE-PATH: dotnetcore/core;
    
    •
    
    в параметре DOTNETLIBS-PATH в списке (через запятую) должен присутствовать каталог components.
    
4.  Скачайте компоненты **Websoft.DotNetBuild** и **Websoft.OmniCode** со страницы дистрибутивов (вкладка **Компоненты**) и установите их одним из способов:
    
    •
    
    распакуйте архивы и положите папки websoft\_dotnetbuild и websoft\_omnicode в папку ...\\WebSoft\\WebSoftServer\\components;
    
    •
    
    в среде x-shell выполните команду «wftget import <путь до zip файла>» (или «wftget install <путь до zip файла>»). Подробнее о PackageManager.
    
    `xsh> wftget import C:\Temp\components_websoft_omnicode_24102024_1.24.10.24.zip`
    
    Компонент **Websoft.DotNetBuild** (с установленным комплектом для разработки программного обеспечения SDK HCM) отвечает за компиляцию проектов .Net на языке C# на стороне сервера, а компонент **Websoft.OmniCode** – за работу редактора на стороне сервера.
    
    Комплект для разработки программного обеспечения SDK HCM может поставляться отдельно от системы WebSoft HCM (в этом случае он должен устанавливаться пользователем).
    
5.  Настройте переменные среды операционной системы:
    
    •
    
    WebTutorServerDir = <путь до сервера Websoft HCM> (например, C:\\Program Files\\WebSoft\\WebSoftServer);
    
    •
    
    DebugWebTutorServerDir = <путь до сервера Websoft HCM> (например, C:\\Program Files\\WebSoft\\WebSoftServer);
    
    •
    
    DefaultNetCoreTargetFramework = net6.0;
    
    •
    
    DefaultNetStandardTargetFramework = netstandard2.1;
    
    •
    
    WEBSOFT\_MSBUILD\_SDK\_PATH = <путь до каталога установки DOTNET SDK> (например, C:\\Program Files\\dotnet\\sdk).
    
6.  Перезапустите сервер.
7.  Во вкладке **Проводник** (**Explorer** в английской версии) редактора Websoft OmniCode for HCM в разделе **WEBSOFT HCM LINK SERVERS** нажмите кнопку **Link Server**. Затем в открывшемся окне выберите папку в вашей локальной директории, в которую будут выгружены объекты с сервера (агенты, выборки, показатели, удаленные действия и т.д.).
    
    Обратите внимание, файлы в выбранной локальной папке являются промежуточными. То есть, при изменении любого файла и его сохранении, если включена автоматическая синхронизация с сервером, соответствующий файл на сервере тоже изменится. Если автоматическая синхронизация с сервером выключена, изменения любого файла в вашей локальной папке не отразятся на сервере, синхронизировать эти файлы придется вручную.
    
8.  В специальное поле в верхней части экрана введите адрес сервера, например, «http://localhost/» и нажмите клавишу Enter. В дальнейшем с указанного сервера загрузятся объекты (агенты, выборки, показатели, удаленные действия и т.д.) в новую папку «localhost» (название папки по умолчанию соответствует названию сервера). Эта папка будет расположена в вашей локальной папке, указанной на предыдущем шаге.
    
9.  Во всплывающем окне нажмите кнопку **Разрешить** (**Allow** в английской версии), далее в браузере автоматически откроется страница авторизации на Портале. После успешной авторизации будет выдан токен, с помощью которого редактор Websoft OmniCode for HCM сможет синхронизироваться с сервером.
    
10.  В верхней части экрана появится список объектов, которые нужно синхронизировать. Выберите необходимые или все сразу и нажмите кнопку **OK**, после чего начнется синхронизация данных.
     
11.  После завершения синхронизации с сервером в папке «localhost» отобразятся выборки, показатели, удаленные действия, агенты и т.д (см. пункт 8). Также эта папка будет доступна в разделе **WEBSOFT HCM LINK SERVERS** редактора Websoft OmniCode for HCM.
