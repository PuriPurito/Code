## Интерфейс редактора Websoft OmniCode for HCM

Интерфейс редактора Websoft OmniCode for HCM после установки условно можно разделить на 3 части:

1.  Раздел **WEBSOFT HCM LINK SERVERS**.
2.  Область редактирования кода.
3.  Консоль **HCM CONSOLE**.

## Раздел WEBSOFT HCM LINK SERVERS

В разделе **WEBSOFT HCM LINK SERVERS** доступна локальная папка, одноименная с синхронизируемым сервером. В ней расположены все агенты, выборки, показатели, удаленные действия и т.д., загруженные с сервера. Изменение, создание, удаление любых файлов из этой папки без синхронизации с сервером отразятся только в вашей локальной директории.

В редакторе Websoft OmniCode for HCM возможно одновременно синхронизировать несколько серверов. В таком случае все папки, соответствующие каждому серверу, будут доступны в разделе **WEBSOFT HCM LINK SERVERS**.

Для работы с объектами локальной папки предусмотрены кнопки:

Режим отображения объектов

Code Veiw

Отображение объектов по коду

Name Veiw

Отображение объектов по наименованию

Режим отображения дерева объектов

Category Veiw

Отображение дерева объектов по категориям

File System Veiw

Отображение дерева объектов по файловой системе

Связь с сервером (для использования консоли для отладки в локальном режиме)

Connect Server

Установка связи с сервером

Disconnect Server

Разрыв связи с сервером

Режим синхронизации с сервером

Enable Auto Sync

Режим автоматической синхронизации с сервером (при каждом сохранении кода будет выполняться синхронизация с сервером)

Режим ручной синхронизации с сервером (для синхронизации с сервером необходимо ручное нажатие кнопки **Sync Server**)

Ручная синхронизация с сервером

Sync Server

Ручная синхронизация с сервером (в том числе и при работе в офлайн-режиме)

В контекстном меню локальной папки доступны действия:

*   Open Folder – открытие текущей папки во вкладке **ПРОВОДНИК** (**EXPLORER** в английской версии), если была открыта другая папка;
*   Refresh – обновление содержимого папки;
*   Remove Server – удаление папки из раздела **WEBSOFT HCM LINK SERVERS**;
*   ReSync Server – повторная полная синхронизация с объектами сервера.

В редакторе Websoft OmniCode for HCM можно создавать объекты типов:

*   агенты сервера (Agents);
*   библиотеки программного кода (CodeLibraries);
*   удаленные действия (RemoteActions);
*   выборки (RemoteCollections);
*   показатели (Statistics);
*   шаблоны документов (WebTemplates).

При наведении курсора на папку с объектами появляется кнопка **Create**, позволяющая создать новый объект соответствующего типа.

В редакторе Websoft OmniCode for HCM доступны действия с объектами:

*    (Copy) – скопировать объект;
*    (Delete) – удалить объект;
*    (Rename) – переименовать объект;
*    (Run) – запустить выполнение программного кода объекта (равносильно нажатию клавиш Alt+F5).

## Область редактирования кода

Для редактирования программного кода объекта в разделе **WEBSOFT HCM LINK SERVERS** выберите соответствующий файл. Код файла отобразится в области редактирования, после чего в него можно вносить изменения.

## Консоль HCM CONSOLE

Для запуска выполнения программного кода требуемого объекта нажмите кнопку  в соответствующей строке. Или откройте в области редактирования кода требуемый файл программного кода и нажмите сочетание клавиш Alt+F5. Результат выполнения отобразится в консоли **HCM CONSOLE**.
