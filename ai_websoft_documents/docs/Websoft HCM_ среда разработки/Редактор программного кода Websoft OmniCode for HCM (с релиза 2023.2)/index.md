## Редактор программного кода Websoft OmniCode for HCM (с релиза 2023.2)

Редактор программного кода Websoft OmniCode for HCM – это дополнительное расширение для Visual Studio Code (далее – VS Code), поэтому для работы с редактором необходимо установить VS Code с официального источника.

Редактор Websoft OmniCode for HCM предназначен для выполнения программного кода Websoft HCM, написанного на языках Server-Side Java Script и C#. При этом на языке C# доступна компиляция и отладка кода, а также формирование билда не отдельного файла или объекта, а проекта в целом.

Содержание:

*   Инструкция по установке
*   Интерфейс
*   Работа с объектами
*   Журналы (логи)
*   Работа с программным кодом на языке C#
*   Работа с программным кодом на языке Server-Side Java Script
