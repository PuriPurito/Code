## Работа с объектами в редакторе Websoft OmniCode for HCM

Редактор Websoft OmniCode for HCM позволяет работать с типами объектов:

*   агенты сервера (Agents);
*   библиотеки программного кода (CodeLibraries);
*   удаленные действия (RemoteActions);
*   выборки (RemoteCollections);
*   показатели (Statistics);
*   шаблоны документов (WebTemplates).

Для каждого типа объектов в редакторе Websoft OmniCode for HCM доступны действия:

*   создание объекта;
*   копирование объекта;
*   переименование объекта;
*   просмотр и редактирование программного кода объекта;
*   выполнение программного кода объекта;
*   удаление объекта.

При работе с объектами в редакторе Websoft OmniCode for HCM можно по умолчанию установить связь с сервером с помощью кнопки **Connect Server** () и включить автоматическую синхронизацию с помощью кнопки **Enable Auto Sync** (). В таком случае каждое сохранение любого файла автоматически отразится на соответствующем файле на сервере. В противном случае все изменения будут сохраняться только в вашей локальной папке, а синхронизацию с сервером нужно будет делать самостоятельно с помощью кнопки **Sync Server** ().

## Создание объекта

Для создания объекта в редакторе Websoft OmniCode for HCM выполните действия:

1.  В разделе **WEBSOFT HCM LINK SERVERS** наведите курсор на папку с типом, объект которого необходимо создать. Нажмите появившуюся кнопку **Create** ().
2.  Во всплывающем окне «Create entry» введите название объекта, например, test\_collection, и нажмите клавишу **Enter**.
    
3.  Выберите язык программирования, на котором будет написан создаваемый объект.
    
    Обратите внимание, несмотря на большое количество предлагаемых форматов объектов, в редакторе Websoft OmniCode for HCM доступно создание объектов только на языках C# (cs) и Server-Side Java Script (js).
    
4.  В окне «Create entry», при необходимости, измените название соответствующего файла программного кода или путь к нему и нажмите клавишу **Enter**.
    
5.  Папка с файлами созданного объекта отобразится в соответствующей локальной папке, а в области редактирования кода откроется файл программного кода созданного объекта.
    
    В редактор Websoft OmniCode for HCM по умолчанию встроены шаблоны программного кода создаваемых объектов в соответствии с типом объекта и языком программирования.
    
6.  Папка созданного объекта содержит файлы:
    
    •
    
    **.info.json** – данные соответствующей карточки объекта в Websoft HCM;
    
    •
    
    **test\_collection.cs** (или **test\_collection.js** в случае создания объекта на языке js) – файл с кодом;
    
    •
    
    **test\_collection.csproj** (отсутствует в случае создания объекта на языке js) – файл с проектом, который можно редактировать, добавлять в ссылки свои библиотеки и т.д.
    
7.  Синхронизируйте созданный объект с соответствующим объектом на сервере, нажав кнопку **Sync Server** (). Или просто сохраните файл (**Ctrl+S**), если у вас включена автоматическая синхронизация.

## Копирование объекта

Для копирования объекта в редакторе Websoft OmniCode for HCM выполните действия:

1.  В разделе **WEBSOFT HCM LINK SERVERS** наведите курсор на объект, который необходимо скопировать. Нажмите появившуюся кнопку **Copy** ().
2.  Во всплывающем окне «Copy entry» введите название нового объекта и нажмите клавишу **Enter**.
    
3.  Во всплывающем окне «Copy entry» введите название нового файла программного кода и нажмите клавишу **Enter**.
    
4.  Синхронизируйте скопированный объект с соответствующим объектом на сервере, нажав кнопку **Sync Server** (). Или просто сохраните файл (**Ctrl+S**), если у вас включена автоматическая синхронизация.

## Переименование объекта

Для переименования объекта в редакторе Websoft OmniCode for HCM выполните действия:

1.  В разделе **WEBSOFT HCM LINK SERVERS** наведите курсор на объект, который необходимо переименовать. Нажмите появившуюся кнопку **Rename** ().
2.  Во всплывающем окне «Rename entry» введите новое название объекта и нажмите клавишу **Enter**.
    
3.  Во всплывающем окне «Rename entry» введите новое название файла программного кода и нажмите клавишу **Enter**.
    
4.  Синхронизируйте переименованный объект с соответствующим объектом на сервере, нажав кнопку **Sync Server** (). Или просто сохраните файл (**Ctrl+S**), если у вас включена автоматическая синхронизация.

## Просмотр и редактирование программного кода объекта

Для просмотра и редактирования программного кода объекта в редакторе Websoft OmniCode for HCM выполните действия:

1.  В разделе **WEBSOFT HCM LINK SERVERS** выберите файл программного кода требуемого объекта, который нужно посмотреть или отредактировать.
2.  При необходимости внесите изменения в программный код файла, отображаемый в области редактирования кода.
3.  После внесения изменений сохраните файл (**Ctrl+S**).
4.  Если автоматическая синхронизация с сервером выключена, проведите ее вручную, нажав кнопку **Sync Server** ().

## Выполнение программного кода объекта

Для выполнения программного кода объекта в редакторе Websoft OmniCode for HCM выполните действия:

1.  В разделе **WEBSOFT HCM LINK SERVERS** наведите курсор на объект, который необходимо выполнить, и нажмите появившуюся кнопку **Run** (). Или откройте в области редактирования кода требуемый файл объекта и нажмите сочетания клавиш **ALT+F5**.
2.  После выполнения программного кода объекта результат отобразится в консоли **HCM CONSOLE**.
    
    Если при выполнении программного кода возникает ошибка 400: Run Id not found, значит объект не синхронизирован с сервером. Включите автоматическую синхронизацию с помощью кнопки **Enable Auto Sync** () или выполните ее вручную с помощью кнопки **Sync Server** ().
    

## Удаление объекта

Для удаления объекта в редакторе Websoft OmniCode for HCM выполните действия:

1.  В разделе **WEBSOFT HCM LINK SERVERS** наведите курсор на объект, который необходимо удалить, и нажмите появившуюся кнопку **Delete** ().
2.  В первом диалоговом окне подтвердите удаление объекта.
3.  Во втором диалоговом окне подтвердите удаление соответствующего объекта на сервере.
4.  В разделе **WEBSOFT HCM LINK SERVERS** останется пустая папка удаляемого объекта. Чтобы папка пропала из этого раздела, удалите ее из вашей файловой системы.
