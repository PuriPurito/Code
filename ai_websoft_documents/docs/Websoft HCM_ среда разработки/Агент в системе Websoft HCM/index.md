## Агент в системе Websoft HCM

Агенты сервера могут реализовывать различные процессы в системе и являются важным инструментом автоматизации процессов.

Агенты могут быть различных типов:   
_\- Исполняемый код;   
\- Выгрузка базы;   
\- Импорт сотрудников из Excel;   
\- Скачивание пакетов обновлений;   
\- Отправка данных;   
\- Прием данных;   
\- Назначения для пользователей._ 

Агенты могут запускаться в системе автоматически (по расписанию) или вручную. Ручной запуск может выполняться из карточки агента по кнопке “Запустить агент” или “Выполнить агент на стороне клиента”, а также над объектами системы Websoft HCM. 

В рамках работы агента, при необходимости, может выполняться журналирование событий и показателей. Запись может выполняться в следующие журналы:   
\- в журнал xhttp (...\\WebTutorServer\\Logs\\);   
\- в события базы (Системное администрирование -> События базы);   
\- в отдельный txt-лог (...\\WebTutorServer\\Logs\\) или в Excel-файл.

Чаще всего, преимущественно, речь идет об агентах типа **«Исполняемый код»**. Такой агент – это встроенный инструмент разработки, позволяющий разработчику (программисту) выполнять программный код.  
  
Агенты размещаются в интерфейсе Webtutor Administrator в разделе **Дизайнер – Агенты сервера**.  
    
  
Для создания нового агента нажмите на кнопку **Новая запись**.  
На карточке агента в интерфейсе Webtutor Administrator имеются две вкладки: **Общие сведения** и **Выполняемый код**.  
На вкладке **Общие сведения** указываются следующие параметры:  
\- _Код агента_;  
\- _Название агента_ (обязательный);  
\- _Тип агента_ (**Исполняемый код, Выгрузка базы, Импорт сотрудников из** **Excel, Скачивание пакетов обновлений, Отправка данных, Прием данных, Назначения для пользователей**) (обязательный; по умолчанию - **Исполняемый код**);  
\- _Ссылка на файл выполняемого кода_ (по умолчанию ссылка не указывается);  
\- _Расписание - Запускать_ (**Никогда, Периодично, Ежедневно, Еженедельно, Ежемесячно, Ежеквартально, Ежегодно**) (обязательный; по умолчанию - **Никогда**);  
\- _Прикрепить к блоку_ (**Персонал, Структура подразделений** и др.) (по умолчанию прикрепление к блоку отсутствует);  
\- Переменные (значения указанных здесь переменных будут доступны внутри исполняемого кода; по умолчанию переменные не указываются);  
\- Комментарий (комментарий виден только разработчику).  
  
  
На вкладке **Выполняемый код** можно ввести программный код, который необходимо выполнить.  
Программный код агента можно выполнять на сервере и на клиенте. Для выполнения кода на стороне сервера нажмите на кнопку **Запустить агент**. Для выполнения кода на стороне клиента нажмите на кнопку **Выполнить агент на стороне клиента**.
