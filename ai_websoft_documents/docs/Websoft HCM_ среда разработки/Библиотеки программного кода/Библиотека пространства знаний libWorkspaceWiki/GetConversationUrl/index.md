## GetConversationUrl

Метод **GetConversationUrl** предназначен для получения электронного адреса разговора по статье в пространстве знаний.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspaceWiki", "GetConversationUrl", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _iWikiArticleID_ \- ID статьи (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о разговоре по статье, а также ряд дополнительных атрибутов:  
     _conversation\_url_ – URL разговора (строка).  
     _conversation\_id_ – ID разговора (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspaceWiki", "GetConversationUrl", [iWikiArticleID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
