## CreateWikiArticle

Метод **CreateWikiArticle** предназначен для создания/изменения статьи в пространстве знаний.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspaceWiki", "CreateWikiArticle", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя пять параметров:  
     _iArticleID_ \- ID статьи для изменения (целое число).  
     _iPersonID_ \- ID текущего пользователя (целое число).  
     _iParentID_ \- ID родительской статьи или вики-базы (целое число).  
     _sStatus_ \- статус создаваемой статьи (строка).  
     _sType_ \- тип создаваемой статьи (строка) (необязательный). Значение по умолчанию - "longread".

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _result_ – ID объекта (целое число);  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspaceWiki", "CreateWikiArticle", [iArticleID, iPersonID, iParentID, sStatus, sType]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
