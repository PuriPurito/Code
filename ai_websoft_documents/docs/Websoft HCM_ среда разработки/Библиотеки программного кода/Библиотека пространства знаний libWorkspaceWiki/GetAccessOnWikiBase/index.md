## GetAccessOnWikiBase

Метод **GetAccessOnWikiBase** предназначен для проверки прав доступа к вики-базе в пространстве знаний.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspaceWiki", "GetAccessOnWikiBase", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID текущего пользователя (целое число).  
     _iWikiBaseID_ \- ID базы знаний (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о проверке прав доступа к вики-базе, а также ряд дополнительных атрибутов:  
\- _access_ \- данные о проверке прав доступа (объект с имеющимися правами доступа пользователя к базе знаний) (объект).  
     Атрибуты объекта:  
     _bCanRead_ \- имеется ли возможность чтения (булево).  
     _bCanEdit_ \- имеется ли возможность редактирования (булево).  
     _bCanDelete_ \- имеется ли возможность удаления (булево).  
     _bCanHistory_ \- имеется ли доступ к истории базы знаний (булево).  
     _bCanChangeAccess_ \- имеется ли возможность изменения прав (булево).  
     _bCanArticleCreate_ \- имеется ли возможность создания статьи в данной базе знаний (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspaceWiki", "GetAccessOnWikiBase", [iPersonID, iWikiBaseID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
