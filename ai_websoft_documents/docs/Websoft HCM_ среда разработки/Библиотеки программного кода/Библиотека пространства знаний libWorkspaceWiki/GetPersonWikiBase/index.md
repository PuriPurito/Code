## GetPersonWikiBase

Метод **GetPersonWikiBase** предназначен для получения списка пространств знаний (wiki-баз знаний) для указанного пользователя.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspaceWiki", "GetPersonWikiBase", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iPersonID_ \- ID пользователя (целое число). Устаревший параметр (с версии 2025.2.1369), в коде игнорируется, текущий пользователь определяется на основе сессии.  
     _sStatus_ \- статус вики-баз (строка).  
     _aTypes_ \- массив типов вики-баз (массив строк).  
     _sSearch_ \- дополнительный критерий полнотекстового поиска в формате XQuery для отбора (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень пространств знаний (wiki-баз знаний), а также ряд дополнительных атрибутов:  
\- _array_ \- массив пространств знаний (wiki-баз знаний) (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID wiki-базы (целое число);  
     _label_ – метка wiki-базы (строка);  
     _access_ \- характеристика доступа (объект). Объект может включать в себя следующие данные: bCanRead - доступно для чтения (булево); bCanEdit - доступно для редактирования (булево); bCanDelete - доступно для удаления (булево); bCanHistory - доступна история (булево); bCanChangeAccess - доступно изменение режима доступа (булево); bCanArticleCreate - доступно создание wiki-базы (булево).  
     _has\_child_ –имеются подчиненные (дочерние) wiki-базы (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _error\_string_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspaceWiki", "GetPersonWikiBase", [sStatus, aTypes, sSearch]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
