## GetSelectParentArticle

Метод **GetSelectParentArticle** предназначен для получения списка родительских статей для указанной статьи.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspaceWiki", "GetSelectParentArticle", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iPersonID_ \- ID пользователя (целое число).  
     _iArticleID_ \- ID статьи (целое число).  
     _sSearch_ \- дополнительный критерий полнотекстового поиска в формате XQuery для отбора (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень родительских статей, а также ряд дополнительных атрибутов:

\- _array_ \- массив родительских статей (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID статьи (целое число);   
     _name_ – название статьи (строка).   
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _error\_string_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspaceWiki", "GetSelectParentArticle", [iPersonID, iArticleID, sSearch]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
