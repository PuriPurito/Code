## BuildExpandedTree

Метод **BuildExpandedTree** предназначен для построения иерархического списка от выбранного элемента дерева до корневого.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspaceWiki", "BuildExpandedTree", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID пользователя (целое число).  
     _iWikiObjectID_ \- ID статьи/базы знаний (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит иерархический список от выбранного элемента дерева до корневого, а также ряд дополнительных атрибутов:

\- _array_ \- иерархический список элементов (массив объектов).  
     Атрибуты отдельного объекта:  
     _\_child_ – элемент вики-базы (объект) (в том числе \_child.id – ID элемента (целое число));  
\- _wiki\_base\_id_ – ID вики-базы (целое число);

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _error\_string_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspaceWiki", "BuildExpandedTree", [iPersonID, iWikiObjectID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
