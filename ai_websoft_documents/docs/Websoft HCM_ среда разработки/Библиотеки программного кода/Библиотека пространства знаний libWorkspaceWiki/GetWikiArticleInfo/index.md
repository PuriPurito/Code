## GetWikiArticleInfo

Метод **GetWikiArticleInfo** предназначен для получения информации о статье в пространстве знаний.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspaceWiki", "GetWikiArticleInfo", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _iArticleID_ \- ID статьи (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию о статье в пространстве знаний, а также ряд дополнительных атрибутов:  
\- _data_ \- информация о статье (объект). Атрибуты объекта:  
     _id_ – ID статьи (целое число);  
     _name_ – название статьи (строка);  
     _description_ – описание (строка);  
     _authors_ \- авторы (массив объектов). Объекты включают в себя следующие поля: id – ID автора (целое число); fullname – ФИО автора (строка); pict\_url – относительная ссылка на изображение (строка).  
     _message\_count_ \- количество сообщений, относящихся к статье (целое число).  
     _keywords_ \- ключевые слова (строка);  
     _tags_ \- тэги (массив объектов). Объекты включают в себя следующие поля: id – ID тэга (целое число); name - название тэга (строка).  
     _img\_link_ \- относительная ссылка на изображение (строка).  
     _access_ \- характеристика доступа (объект). Объект может включать в себя следующие данные: bCanRead - доступно для чтения (булево); bCanEdit - доступно для редактирования (булево); bCanDelete - доступно для удаления (булево); bCanHistory - доступна история (булево); bCanChangeAccess - доступно изменение режима доступа (булево); bCanArticleCreate - доступно создание статьи (булево).  
     _parent\_article\_id_ – ID статьи более высокого уровня (родительской статьи) (целое число);

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _error\_string_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspaceWiki", "GetWikiArticleInfo", [iArticleID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
