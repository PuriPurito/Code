## GetWikiBaseInfo

Метод **GetWikiBaseInfo** предназначен для получения информации о пространстве знаний.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspaceWiki", "GetWikiBaseInfo", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _iWikiBaseID_ \- ID пространства знаний (wiki-базы знаний) (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию о пространстве знаний, а также ряд дополнительных атрибутов:  
\- _data_ \- информация о пространстве знаний (объект).  
     Атрибуты объекта:  
     _id_ \- идентификационный номер (ID) (целое число).  
     _name_ \- название (строка).  
     _description_ \- описание (строка).  
     _img\_link_ \- относительная ссылка на изображение (строка).  
     _access_ \- характеристика доступа (объект). Объект может включать в себя следующие данные: bCanRead - доступно для чтения (булево); bCanEdit - доступно для редактирования (булево); bCanDelete - доступно для удаления (булево); bCanHistory - доступна история (булево); bCanChangeAccess - доступно изменение режима доступа (булево); bCanArticleCreate - доступно создание статьи (булево).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _error\_string_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspaceWiki", "GetWikiBaseInfo", [iWikiBaseID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
