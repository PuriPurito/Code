## GetFlatWikiList

Метод **GetFlatWikiList** предназначен для получения «плоского» списка статей пользователя. «Плоским» списком называется такой список, в котором в качестве элементов используются только примитивы (т.е. нет элементов, содержащих вложенные элементы).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspaceWiki", "GetFlatWikiList", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iPersonID_ \- ID пользователя (целое число).  
     _aArticleStatuses_ \- статусы статей (массив строк).  
     _sSearch_ \- дополнительный критерий полнотекстового поиска в формате XQuery для отбора (строка).

_Возвращаемое значение:_  
      Тип: **Объект**.

Содержит перечень статей пользователя, а также ряд дополнительных атрибутов:  
\- array - массив статей пользователя (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ –ID статьи (целое число);   
     _label_ – метка статьи (строка);  
     _access_ \- характеристика доступа (объект). Объект может включать в себя следующие данные: bCanRead - доступно для чтения (булево); bCanEdit - доступно для редактирования (булево); bCanDelete - доступно для удаления (булево); bCanHistory - доступна история (булево); bCanChangeAccess - доступно изменение режима доступа (булево); bCanArticleCreate - доступно создание статьи (булево).  
     _has\_child_ –имеются подчиненные (дочерние) статьи (булево).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _error\_string_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspaceWiki", "GetFlatWikiList", [iPersonID, aArticleStatuses, sSearch]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
