## GetArticleTree

Метод **GetArticleTree** предназначен для построения полного иерархического списка статей в пространстве знаний.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspaceWiki", "GetArticleTree", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iPersonID_ \- ID пользователя (целое число).  
     _iWikiBaseID_ \- ID wiki-базы в пространстве знаний (целое число).  
     _aStatuses_ \- массив статусов статей (массив строк).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит полный иерархический список статей в пространстве знаний, а также ряд дополнительных атрибутов:  
\- _array_ \- иерархический список статей (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID статьи (целое число);  
     _is\_root_ – является ли данная статья корневой (булево);  
     _label_ – метка (строка);  
     _img\_link_ – относительная ссылка на изображение (строка).  
     _access_ \- права доступа к статье (объект). Объект включает в себя следующие поля: bCanRead - имеется ли возможность чтения (булево); bCanEdit - имеется ли возможность редактирования (булево); bCanDelete - имеется ли возможность удаления (булево); bCanArticleCreate - имеется ли возможность создания статьи (булево); bCanChangeAccess - имеется ли возможность изменения прав (булево).  
     _children_ \- статьи нижележащего уровня (массив объектов).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspaceWiki", "GetArticleTree", [iPersonID, iWikiBaseID, aStatuses]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
