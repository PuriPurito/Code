## CreateWikiBase

Метод **CreateWikiBase** предназначен для создания вики-базы в пространстве знаний.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspaceWiki", "CreateWikiBase", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _iPersonID_ \- ID текущего пользователя (целое цисло).  
     _oParams_ \- параметры создания вики-базы в пространстве знаний (объект). В состав объекта могут входить следующие параметры: name - название вики-базы (строка); wiki\_base\_type - тип вики-базы (строка); func\_managers\_ids - идентификаторы функционалных руководителей (массив целых чисел); status - статус вики-базы (строка); comment - комментарий (строка); desc - описание (строка); file\_data - данные файла (ресурса) (строка).

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _result_ – ID объекта (созданной вики-базы) (целое число);  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspaceWiki", "CreateWikiBase", [iPersonID, oParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
