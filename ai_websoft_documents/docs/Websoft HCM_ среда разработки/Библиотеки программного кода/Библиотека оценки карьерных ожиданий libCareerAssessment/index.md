## Библиотека оценки карьерных ожиданий libCareerAssessment

В настоящем разделе описываются методы **библиотеки оценки карьерных ожиданий** из библиотеки программного кода **libCareerAssessment**. Указанные методы регистрируются в разделе **Дизайнер – Библиотеки программного кода – libCareerAssessment**.

Примечание - По состоянию на май 2024 г. библиотека предназначена исключительно для внутренних нужд системы и не содержит публичных методов.
