## GetFeed

Метод **GetFeed** предназначен для получения списка записей (сообщений) ленты провайдеров каналов RSS/Atom.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libFeedRSS", "GetFeed", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _sUrl_ \- URL ленты сообщений (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень записей (сообщений) ленты:  
\- arrFeed - массив записей (сообщений) ленты (массив объектов).  
     Атрибуты отдельного объекта:  
     id – ID записи ленты в строковом формате (строка);  
     name – наименование записи (строка);  
     desc – содержимое записи (строка);  
     src\_link – URL статьи в источнике (строка);  
     update – дата обновления записи (дата).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libFeedRSS", "GetFeed", [sUrl]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
