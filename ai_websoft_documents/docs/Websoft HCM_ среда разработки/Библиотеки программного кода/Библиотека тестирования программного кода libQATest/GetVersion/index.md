## GetVersion

Метод **GetVersion** предназначен для получения текущей версии сборки.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libQATest", "GetVersion", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Метод вызывается без аргументов. Для данного метода используется пустой массив аргументов.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о текущей версии сборки, а также ряд дополнительных атрибутов:  
\- _sVersion_ \- строка вида 'номер версии (дата модификации версии)' (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libQATest", "GetVersion", []);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
