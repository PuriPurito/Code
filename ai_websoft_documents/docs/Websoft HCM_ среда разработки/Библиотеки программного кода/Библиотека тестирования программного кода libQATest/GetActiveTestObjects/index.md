## GetActiveTestObjects

Метод **GetActiveTestObjects** предназначен для получения списка QA-тестов или наборов QA-тестов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libQATest", "GetActiveTestObjects", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _sType_ \- тип объектов (строка). Доступные значения: 'test' (QA-тест), 'test\_set' (набор QA-тестов), 'test\_paramset' (набор параметров QA-тестов).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень QA-тестов или наборов QA-тестов, а также ряд дополнительных атрибутов:  
\- array - массив данных о тестах или о наборах QA-тестов (массив объектов).  
     Атрибуты отдельного объекта:  
     id – идентификатор QA-теста или набора QA-тестов (целое число);  
     code - код QA-теста или набора QA-тестов (строка).  
     name – название QA-теста или набора QA-тестов (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libQATest", "GetActiveTestObjects", [sType]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
