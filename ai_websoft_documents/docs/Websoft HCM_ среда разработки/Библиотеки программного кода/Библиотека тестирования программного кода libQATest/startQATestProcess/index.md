## startQATestProcess

Метод **startQATestProcess** предназначен для запуска QA-теста или набора QA-тестов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libQATest", "startQATestProcess", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _iTestingIDParam_ \- ID запускаемого QA-теста/набора QA-тестов (целое число).  
     _iTestParamsetID_ \- ID сопровоздающего запуск набора параметров (целое число).

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:

_\- completed_ \- результат выполнения QA-теста или набора QA-тестов (булево) (true – тест выполнен корректно; false – ошибка).  
_\- duration_ \- продолжительность выполнения (целое число).  
_\- results_ \- массив результатов (массив объектов) (в том числе для кажддого объекта: result\_id - ID результата (целое число), completed - - результат выполнения (булево), duration - продолжительность выполнения (целое число))/

_\- oErr.error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
_\- oErr.errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libQATest", "startQATestProcess", [iTestingIDParam, iTestParamsetID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
