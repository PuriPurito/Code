## GetTestReports

Метод **GetTestReports** предназначен для получения списка результатов выполнения QA-тестов или наборов QA-тестов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libQATest", "GetTestReports", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _iTestIDParam_ \- ID теста или набора тестов в строковом выражении (строка).  
     _arrTestReportIDs_ \- коллекция (набор) ID результатов в строковом выражении (массив строк). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень результатов выполнения QA-тестов или наборов QA-тестов, а также ряд дополнительных атрибутов:  
\- array - массив результатов выполнения QA-тестов или наборов QA-тестов (массив объектов).  
     Атрибуты отдельного объекта:  
     id – ID результата QA-теста или набора QA-тестов (целое число);  
     test\_id – ID результата QA-теста (целое число);  
     test\_name – название результата QA-теста (строка);  
     test\_set\_id – ID результата набора QA-тестов (целое число);  
     test\_set\_name– название результата набора QA-тестов (строка);  
     status – код статуса результата QA-теста или набора QA-тестов (целое число);  
     status\_name – название статуса результата QA-теста или набора QA-тестов (целое число);  
     start\_date – начало выполнения QA-теста или набора QA-тестов (дата);  
     finish\_date – окончание выполнения QA-теста или набора QA-тестов (дата);  
     error – код ошибки выполнения QA-теста или набора QA-тестов (целое число);  
     duration – продолжительность результата QA-теста или набора QA-тестов (целое число);  
     log\_results – запись результата QA-теста или набора QA-тестов в журнале (логе) (массив объектов) (объект включает в себя следующие параметры: text - запись в логе (строка); is\_check - имеется запись проверки (булево); is\_failed - выполнена ли проверка не успешность (булево); result\_value - полученный результат для проверки (строка); template\_value - проверочное значение (строка));  
     log\_result\_text – текст записи результата QA-теста или набора QA-тестов в журнале (логе) (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libQATest", "GetTestReports", [iTestIDParam, arrTestReportIDs]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
