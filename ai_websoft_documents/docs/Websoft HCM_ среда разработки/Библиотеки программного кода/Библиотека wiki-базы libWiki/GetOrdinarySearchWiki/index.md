## GetOrdinarySearchWiki

Метод **GetOrdinarySearchWiki** предназначен для выполнения полнотекстового поиска в wiki-статьях или поиска по индексированным полям.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWiki", "GetOrdinarySearchWiki", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя четыре параметра:  
     _sSearchString_ \- строка поиска (строка).   
     _iWikiBaseIDs_ \- ID wiki-баз, в которых осуществляется поиск (массив целых чисел).  
     _iWikiBaseRoleIDs_ \- ID категорий с wiki-базами, в которых осуществляется поиск (массив целых чисел).  
     _oSearchParam_ \- дополнительные параметры отбора  (объект). В состав объекта могут входить следующие параметры: arrWikiArticlesStatuses – статусы wiki-статей (массив строк); arrWikiArticlesTypes – ID типов wiki-статей (массив целых чисел); bNotShowResultWithoutCond – не показывать результаты без переданных условий (булево).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит массив отобранных записей, а также ряд дополнительных атрибутов:  
\- _array_ \- массив отобранных записей (массив объектов).  
     Атрибуты отдельного объекта:  
     _ss\_score_ \- оценка результата поиска в текстовом формате (строка).  
     _ss\_field_ \- поле (строка).  
     _ss\_text_ \- текст (строка).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWiki", "GetOrdinarySearchWiki", [sSearchString, iWikiBaseIDs, iWikiBaseRoleIDs, oSearchParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
