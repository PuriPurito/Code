## WikiArticleDelete

Метод **WikiArticleDelete** предназначен для удаления вики-статей.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWiki", "WikiArticleDelete", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iCurUserID_ \- ID пользователя (целое число).  
     _sApplication_ \- код приложения (строка).  
     _arrWikiArticles_ \- массив ID вики-статей (массив целых чисел).

_Возвращаемые значения:_

      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _result_ – результат вызова метода (строка). Значения атрибута в случае успешного завершения метода – 'Статьи баз знаний удалены'; 'Статья базы знаний удалена'; 'Статью базы знаний удалить невозможно, так как она связана с другими'; 'Удалено статей баз знаний: … из … Остальные удалить невозможно, так как они связаны с другими'.

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWiki", "WikiArticleDelete", [iCurUserID, sApplication, arrWikiArticles]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
