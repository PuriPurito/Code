## GetWikiBaseContext

Метод **GetWikiBaseContext** предназначен для получения контекста wiki-базы по указанному сотруднику.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWiki", "GetWikiBaseContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _iWikiBaseID_ \- ID wiki-базы (целое число).  
     _iPersonID_ \- ID сотрудника (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о контексте wiki-базы, а также ряд дополнительных атрибутов:  
\- context - данные о контексте wiki-базы (объект).  
     Атрибуты объекта:  
     _bCanEditArticle_ – имеется ли у сотрудника право на редактирование статей wiki-базы (булево).  
     _bCanCreateArticle_ – имеется ли у сотрудника право на создание статей wiki-базы (булево).  
     _bModerator_ – является ли сотрудник модератором wiki-базы (булево).  
     _iActiveWikiArticlesNum_ – общее количество активных статей в wiki-базе (целое число).  
     _iNewWikiArticlesNum_ – количество новых статей в wiki-базе за последние 30 дней (целое число).  
     _iChangesNum_ – количество изменений в статьях в wiki-базе за последние 30 дней (целое число).  
     _iBaseWikiArticleTypeID_ – ID типа статей для построение базовой структуры wiki-базы (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWiki", "GetWikiBaseContext", [iWikiBaseID, iPersonID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
