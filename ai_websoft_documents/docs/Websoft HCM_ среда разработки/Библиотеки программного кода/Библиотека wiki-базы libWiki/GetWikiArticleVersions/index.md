## GetWikiArticleVersions

Метод GetWikiArticleVersions предназначен для получения списка версий wiki-статьи.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWiki", "GetWikiArticleVersions", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _iWikiArticleID_ \- ID wiki-статьи (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень версий wiki-статьи, а также ряд дополнительных атрибутов:  
\- array - массив версий wiki-статьи (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID версии wiki-статьи (целое число).  
     _name_ \- название wiki-статьи (строка).  
     _publicate\_date_ \- дата и время публикации wiki-статьи (дата).  
     _author\_name_ \- имя автора, который опубликовал данную версию wiki-статьи (строка).  
     _link_ \- ссылка на версию wiki-статьи (строка).  
     _desc_ \- описание версии wiki-статьи (строка).  
     _annotation_ \- аннотация версии wiki-статьи (строка).  
     _comment_ \- комментарий к версии wiki-статьи (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWiki", "GetWikiArticleVersions", [iWikiArticleID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
