## GetWikiBaseTree

Метод **GetWikiBaseTree** предназначен для получения деревьях вики-баз.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWiki", "GetWikiBaseTree", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя восемь параметров:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _iWikiBaseID_ \- ID вики-базы (целое число).  
     _iWikiArticleTypeID_ \- ID родительской вики-статьи (целое число).  
     _iHierNum_ \- число уровней вниз по иерархии (целое число).  
     _iWikiArticleID_ \- ID вики-статьи (целое число).  
     _bUseSortPosition_ \- сортировать статьи по позиции (булево) (необязательный). Значение по умолчанию – false.  
     _sBranchID_ \- ID элемента в дереве в текстовом формате (строка).   
     _iParentWikiArticleId_ \- ID родительской вики-статьи (целое число).   
 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию о деревьях вики-баз, а также ряд дополнительных атрибутов:  
\- _result_ – информация о деревьях вики-баз (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID вики-статьи (целое число).  
     _name_ \- название вики-статьи (строка).  
     _parent\_id_ \- ID родительской вики-статьи (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWiki", "GetWikiBaseTree", [ iPersonID, iWikiBaseID, iWikiArticleTypeID, iHierNum, iWikiArticleID, bUseSortPosition, sBranchID, iParentWikiArticleId ]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
