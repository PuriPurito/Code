## GetWikiArticleTypes

Метод **GetWikiArticleTypes** предназначен для получения списка типов статей вики-базы.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWiki", "GetWikiArticleTypes", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _sFilter_ \- строка для XQuery-фильтра (строка).  
     _sSearch_ \- строка для поиска (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень типов статей вики-бызы, а также ряд дополнительных атрибутов:  
\- _result_ - массив типов статей вики-бызы (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID типа статьи (целое число).  
     _name_ – название типа статьи (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWiki", "GetWikiArticleTypes", [sFilter, sSearch]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
