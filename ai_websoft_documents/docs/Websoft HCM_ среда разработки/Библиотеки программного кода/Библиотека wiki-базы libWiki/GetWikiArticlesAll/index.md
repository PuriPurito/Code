## GetWikiArticlesAll

Метод **GetWikiArticlesAll** предназначен для получения списка всех статей вики-базы.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWiki", "GetWikiArticlesAll", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.  
     Массив включает в себя восемь параметров:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _sAccessType_ \- роль доступа пользователя (строка).  
     _sApplication_ \- код приложения (строка).  
     _sStatus_ \- статус отбираемых статей (строка).  
     _sFilter_ \- строка для XQuery-фильтра (строка).  
     _sSearch_ \- строка для поиска (строка).  
     _oCollectionParams_ \- набор параметров (сортировка, пейджинг) (объект).   
     _arrFields_ \- названия отбираемых полей (массив строк).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень статей вики-базы, а также ряд дополнительных атрибутов:  
\- _result_ - массив статей вики-базы (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID статьи (целое число).  
     _name_ – название статьи (строка).  
     _wiki\_article\_type_ – тип статьи (строка).  
     _max\_mod\_date_ – дата последнего изменения статьи (дата).  
     _wiki\_base\_name_ – название статьи (строка).  
     _create\_date_ – дата создания статьи (дата).  
     _link_ – ссылка на статью (строка).  
     _image\_url_ – ссылка на изображение (строка).  
     _author\_name_ – ФИО автора (строка).  
     _tags_ – теги статьи, разделенные запятыми (строка).  
     _desc_ – описание статьи (строка).  
     _comment_ – комментарий к статье (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWiki", "GetWikiArticlesAll", [iCurUserID, sAccessType, sApplication, sStatus, sFilter, sSearch, oCollectionParams, arrFields]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
