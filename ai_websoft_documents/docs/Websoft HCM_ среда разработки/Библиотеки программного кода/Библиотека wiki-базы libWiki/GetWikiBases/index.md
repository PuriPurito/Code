## GetWikiBases

Метод **GetWikiBases** предназначен для получения списка вики-баз.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWiki", "GetWikiBases", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя десять параметров:  
     _iCurUserID_ \- ID текущего сотрудника (целое число).  
     _bCheckAccess_ проверять права доступа (булево).  
     oSort - информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).  
     _sAccessType_ \- тип доступа для приложения (строка).  
     _sApplication_ \- код приложения (строка).  
     _return\_data_ \- возвращаемые данные (строка).  
     _sFilter_ \- строка для XQuery-фильтра (строка).  
     _sFullText_ \- строка для поиска (строка).  
     _aTypes_ \- массив типов (массив строк).  
     _aStates_ \- массив статусов (массив строк).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень вики-баз, а также ряд дополнительных атрибутов:  
\- _array_ \- массив вики-баз (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID вики-базы (целое число).  
     _name_ – название вики-базы (строка).  
     _desc_ – описание вики-базы (строка).  
     _comment_ – комментарий к вики-базе (строка).  
     _link_ – ссылка на вики-базу (строка).  
     _image\_url_ – ссылка на изображение (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWiki", "GetWikiBases", [iCurUserID, bCheckAccess, oSort, sAccessType, sApplication, return_data, sFilter, sFullText, aTypes, aStates]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
