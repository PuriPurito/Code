## GetWikiArticleContext

Метод **GetWikiArticleContext** предназначен для получения контекста вики-статьи.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWiki", "GetWikiArticleContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iWikiArticleID_ \- ID анализируемой вики-статьи (целое число).  
     _iPersonID_ \- ID сотрудника (целое число).  
     _iWikiArticleTypeID_ \- ID базового типа статьи (целое число).  
     _iParentWikiArticleId_ \- ID родительской статьи (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию о контексте вики-статьи, а также ряд дополнительных атрибутов:  
_\- context_ \- контекст вики-статьи (объект). Атрибуты объекта:  
     _bHasParentWikiArticle_ – имеется родительская вики-статья (булево). Если параметр имеет значение true, то у анализируемой вики-статьи имеется родительская статья. В противном случае родительская вики-статья отсутствует и атрибут получает значение false.  
     _iParentWikiArticleId_ – если имеется родительская вики-статья, то атрибут получает значение ID родительской вики-статьи (целое число). В противном случае выводится пустая строка.  
     _sParentWikiArticleName_ – если имеется родительская вики-статья, то атрибут получает значение названия родительской вики-статьи (строка). В противном случае выводится пустая строка.  
     _sFirstParentWikiArticleName_ – название родительской вики-статьи (строка).  
     _iFirstParentWikiArticleId_ – ID родительской вики-статьи (целое число).  
     _sFirstParentWikiArticleTypeName_ – название типа верхнеуровневой родительской вики-статьи (строка).  
     _iFirstParentWikiArticleTypeId_ – ID типа верхнеуровневой родительской вики-статьи (целое число).  
     _bCanEdit_ – может ли пользователь редактировать статью (булево).  
     _bCanCreateChildArticle_ – пользователь может создавать дочерние статьи (булево).  
     _iFilesNum_ – количество файлов в статье (целое число).  
     _iCommChildWikiArticlesNum_ – количество дочерних связанных статей (целое число).  
     _iCommBaseWikiArticlesNum_ – количество родительских связанных статей (целое число).  
     _iObjectVersionNum_ – количество версий статьи (целое число).  
     _bHasObjectVersion_ – имеются ли различные версии статьи (булево).  
     _bConfirmAcquainting_ – установлена ли необходимость подтверждения ознакомления со статьёй (булево).  
     _sWikiArticleTreeID_ – ID вики-статьи в дереве (строка).  
     sStatusName – статус статьи (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWiki", "GetWikiArticleContext", [iWikiArticleID, iPersonID, iWikiArticleTypeID, iParentWikiArticleId]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
