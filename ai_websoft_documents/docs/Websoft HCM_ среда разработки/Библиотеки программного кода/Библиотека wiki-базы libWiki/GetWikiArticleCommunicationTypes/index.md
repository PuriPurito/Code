## GetWikiArticleCommunicationTypes

Метод **GetWikiArticleCommunicationTypes** предназначен для получения списка типов связей вики-статей.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWiki", "GetWikiArticleCommunicationTypes", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iWikiID_ \- ID вики-базы (целое число).  
     _sFilter_ \- строка для XQuery фильтра (строка).  
     _sSearch_ \- строка для поиска (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень типов связей вики-статей, а также ряд дополнительных атрибутов:  
\- _result_ - массив типов связей вики-статей (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID типа связи вики-статьи (целое число).  
     _code_ – код типа связи вики-статьи (строка).  
     _name_ – название типа связи вики-статьи (строка).  
     _wiki\_communication\_type_ – тип связи вики-статьи (строка).  
     _base\_wiki\_article\_type_ – тип базовой вики-статьи (строка).  
     _child\_wiki\_article\_type_ – тип дочерней вики-статьи (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWiki", "GetWikiArticleCommunicationTypes", [iWikiID, sFilter, sSearch]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
