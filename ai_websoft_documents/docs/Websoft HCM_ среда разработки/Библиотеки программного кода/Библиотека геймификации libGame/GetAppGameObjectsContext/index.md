## GetAppGameObjectsContext

Метод **GetAppGameObjectsContext** предназначен для расчета метрики объектов приложения (подразделения/организации/группы) в геймификации.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetAppGameObjectsContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _sTypeObject_ \- тип объекта subdivision/org/group (строка).  
     _iObjectIDParam_ \- ID объекта, для которого определяются метрики (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о метрике объектов приложения, а также ряд дополнительных атрибутов:  
\- _context_ \- метрика объектов приложения (объект).  
     Атрибуты объекта:  
     _person\_count_ – количество обсчитываемых сотрудников (целое число).  
     _active\_badges\_count_ – количество активных бейджей (целое число).  
     _badges\_count_ – количество бейджей (целое число).  
     _active\_rewards\_count_ – количество активных наград (целое число).  
     _rewards\_count_ – количество наград (целое число).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetAppGameObjectsContext", [sTypeObject, iObjectIDParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
