## CreateOrder

Метод **CreateOrder** предназначен для cоздания заказа из корзины (или изменения существующего заказа) в геймификации.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "CreateOrder", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя семь параметров:  
     _iPersonID_ \- ID заказчика (целое число).  
     _docBasket_ \- корзина (документ) (объект XmlDoc).  
     _arrGoods_ \- коллекция товаров из корзины, направленная в заказ (объект). В состав объекта могут входить следующие параметры: id – ID товара (целое число); name – наименование товара (строка); currency\_type\_id – валюта (целое число); quantity – количество (целое число); sum – сумма (действительное число); reserved\_date – дата резервирование (дата); request\_type\_id – ID типа заявки на товар (целое число); request\_has\_workflow – товар проводится по документообороту (булево); delivery\_type – тип поставки (строка)(необязательный) (допустимые значения - "all" (без ограничений), "instance" (по экземплярам), "cost" (по сумме). Значение по умолчанию - без ограничений); limit – ограничение по валюте (целое число).  
     _sComment_ \- комментарий к заказу (строка).  
     _sShopCurrencyTypeID_ \- ID текущей валюты магазина, в котором делается заказ.  (строка).  
     _bClearBasket_ \- очищать корзину при создании заказа (булево) (необязательный). Значение по умолчанию - true.  
     _iOrderID_ \- ID заказа, если предполагается изменение уже существующего заказа (целое число) (необязательный).

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
\- _result_ – результат (объект).  
  
_\- error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
_\- errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "CreateOrder", [iPersonID, docBasket, arrGoods, sComment, sShopCurrencyTypeID, bClearBasket, iOrderID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
