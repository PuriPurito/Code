## GetCurrencies

Метод **GetCurrencies** предназначен для формирования коллекции валют в геймификации.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetCurrencies", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _aStates_ \- статусы валют (массив строк).  
     _aTypes_ \- типы валют (массив строк).  
     _sSearch_ \- дополнительный критерий полнотекстового поиска в формате XQuery для отбора (строка) (необязательный).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень валют в геймификации, а также ряд дополнительных атрибутов:  
\- array - массив валют (массив объектов).  
     Атрибуты отдельного объекта:  
     code - код валюты (строка).  
     name - название валюты (строка).  
     short\_name - сокращенное название валюты (строка).  
     cent\_name - название дробной части валюты (строка).  
     status - статус валюты (строка).  
     is\_infinite - является ли количество валюты бесконечным (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetCurrencies", [aStates, aTypes, sSearch]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
