## CurrencyAddChange

Метод **CurrencyAddChange** предназначен для добавления/изменения валюты в геймификации.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "CurrencyAddChange", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _sCurrencyID_ \- ID валюты для изменения (строка).  
     _form\_fields_ \- поля формы (массив объектов). В состав отдельных объектов входят следующие параметры: name - название поля (строка), label – метка (строка), type – тип поля (строка), value – значение (строка), entries – входные параметры (массив объектов (name – имя объекта (строка), value – значение (строка))), validation – контрольное значение (строка), mandatory – является ли поле обязательным (булево), column – количество колонок (целое число).  
     _bIsNew_ \- признак создания новой валюты (булево).

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
_\- error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
_\- errorText_ – текст ошибки (строка).  
 

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "CurrencyAddChange", [sCurrencyID, form_fields, bIsNew]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
