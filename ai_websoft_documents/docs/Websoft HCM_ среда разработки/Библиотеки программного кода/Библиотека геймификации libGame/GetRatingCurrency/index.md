## GetRatingCurrency

Метод **GetRatingCurrency** предназначен для получения списка валют для рейтинга в геймификации.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetRatingCurrency", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
      _oAddParams_ \- параметры метода (объект). В состав объекта могут входить следующие параметры: bAddAllBadges – добавлять пункт «Все бейджи» (булево); bAddAllAwards – добавлять пункт Все награды» (булево); sAllBadges – название пункта «Все бейджи» (строка); sAllAwards – название пункта «Все награды» (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень валют для рейтинга в геймификации, а также ряд дополнительных атрибутов:  
\- _array_ \- массив валют для рейтинга (массив объектов).  
     Атрибуты отдельного объекта:  
     _i_d - ID валюты (строка).  
     _name_ \- название валюты (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetRatingCurrency", [oAddParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
