## GetGameLeadersAll

Метод **GetGameLeadersAll** предназначен для получения списка лидеров по заданной валюте/уровню.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetGameLeadersAll", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя следующие параметры:  
     _bAllLevel_ \- cтроить рейтинг по сотрудникам с любым уровнем (при значении данного параметра, равном _true_) или только по сотрудникам с заданным уровнем _iLevelID_, если _bCheckLevel = true_ (при значении данного параметра, равном _false_) (булево).  
     _bCheckLevel_ \- cтроить рейтинг с учетом последовательности уровней (булево), будет учитываться валюта заданного уровня _iLevelID_.  
     _iLevelID_ \- уровень, который будет учитываться при расчете рейтинга, если _bCheckLevel = true_ и _bAllLevel = false_ (целое число).  
     _bDispSub_ \- cтроить рейтинг только по сотрудникам заданного подразделения (булево) (необязательный). Значение по умолчанию - _false_.  
     _iSubdivID_ \- ID подразделения, по сотрудникам которого будет строиться рейтинг (целое число) (необязательный).  
     _iSubdivNum_ \- количество подразделений вверх по иерархии (целое число) (учитывается, если _bDispSub = true_).  
     _sCurrencyTypeID_ \- ID типа валюты, по которой строится рейтинг (строка) (обязательный, если _bCheckLevel = false_).  
     _iGrpColl_ \- ID группы (целое число) (необязательный). Если группа указана, то рейтинг формируется по сотрудникам указанной группы.   
     _oPaging_ \- объект пэйджинга для ограничения итераций цикла по массиву биллинговых счетов (объект) (используется, если _bCheckLevel = false_).  
     _bRange_ \- получить список сотрудников в рейтинге, ограниченный параметром _iAmntCollsRating_ (булево).  
     _iAmntCollsRating_ \- количество сотрудников в рейтинге (целое число).  
     _bSamePlace_ \- присваивать пользователям одно и тоже место в рейтинге при одинаковом количестве баллов (булево).  
     _bShowTopRating_ \- показывать три первых места рейтинга (булево) (используется, если _bRange = false_).   
     _iOrgID_ \- ID организации (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень сотрудников (лидеров по заданной валюте/уровню), а также ряд дополнительных атрибутов:  
\- _leaders_ \- массив сотрудников (лидеров) (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID рейтинга (целое число);  
     _modification\_date_ \- дата последнего составления рейтинга в строковом выражении (строка);  
     _person\_id_ \- ID сотрудника в строковом выражении (строка);  
     _fullname_ \- ФИО сотрудника (строка);  
     _level\_name_ \- название уровня (строка);  
     _level\_num_ \- номер уровня в строковом выражении (строка);  
     _currency\_types\_array_ \- типы валют в строковом выражении (массив объектов). В состав объекта входят следующие параметры: id – ID типа валюты (целое число); person\_score – количество баллов в указанной валюте (целое число).  
     _person\_score_ \- количество баллов, набранное сотрудником в строковом выражении (строка);  
     _icon\_url_ \- относительная ссылка на изображение (строка);  
     _num_ \- номер сотрудника в рейтинге (строка);

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetGameLeadersAll", [bAllLevel, bCheckLevel, iLevelID, bDispSub, iSubdivID, iSubdivNum, sCurrencyTypeID, iGrpColl, oPaging, bRange, iAmntCollsRating, bSamePlace, bShowTopRating, iOrgID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
