## ChangeCommentOrders

Метод **ChangeCommentOrders** предназначен для редактирования комментария к заказу.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "ChangeCommentOrders", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iOrderIDParam_ \- ID заказа (целое число).  
     _sComment_ \- текст комментария (строка).

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит атрибут:  
\- _action\_result_ \- текст сообщения (строка). Значение атрибута в случае успешного выполнения - "Изменения сохранены".

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "ChangeCommentOrders", [iOrderIDParam, sComment]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
