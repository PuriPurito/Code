## GetPersonAwards

Метод предназначен для получения списка наград (присвоенных квалификаций) сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetPersonAwards", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _sStatus_ \- статус присвоенной квалификации (строка).  
     _isTimeShow_ \- показывать время в датах (булево). 

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит перечень наград (присвоенных квалификаций) сотрудника, а также ряд дополнительных атрибутов:  
\- _array_ \- массив наград (присвоенных квалификаций) сотрудника (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID награды (целое число);  
     _qualification\_id_ – ID квалификации (целое число);  
     _qualification\_name_ \- название квалификации (строка);  
     _qualification\_url_ \- относительная ссылка на товар (строка).  
     _qualification\_img_ \- относительная ссылка на изображение (строка);  
     _qualification\_desc_ \- описание квалификации (строка);  
     _status_ \- статус квалификации (строка);  
     _assign\_date_ \- дата присвоения (строка).  
     _progress_ \- текущий прогресс (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetPersonAwards", [iPersonID, sStatus, isTimeShow]);_`   
 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
