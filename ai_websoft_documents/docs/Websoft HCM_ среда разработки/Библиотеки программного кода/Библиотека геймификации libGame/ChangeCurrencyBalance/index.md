## ChangeCurrencyBalance

Метод **ChangeCurrencyBalance** предназначен для добавления/списания валюты (сотрудникам/группам/подразделениям/организациям) в геймификации.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "ChangeCurrencyBalance", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя шесть параметров:  
     _sObjectType_ \- тип объекта: сотрудник/группа/подразделение/организация (строка).  
     _arrObjectsIDs_ \- массив ID сотрудников/групп/подразделений/организаций (массив целых чисел).  
     _arrFormFields_ \- коллекция с полями возврата из формы удаленного действия (массив объектов). В состав отдельных объектов входят следующие параметры: name - название поля (строка), label – метка (строка), type – тип поля (строка), value – значение (строка), entries – входные параметры (массив объектов (name – имя объекта (строка), value – значение (строка))), validation – контрольное значение (строка), mandatory – является ли поле обязательным (булево), column – количество колонок (целое число).  
     _bTeamRatingParam_ \- вести рейтинг команд (булево).  
     _arrTeamsList_ \- массив ID команд (массив целых чисел).  
     _SCOPE\_WVARS_ \- переменные удаленного действия (объект).

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
\- _count_ – количество измененных объектов (целое число).  
  
_\- error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
_\- errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "ChangeCurrencyBalance", [sObjectType, arrObjectsIDs, arrFormFields, bTeamRatingParam, arrTeamsList, SCOPE_WVARS]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
