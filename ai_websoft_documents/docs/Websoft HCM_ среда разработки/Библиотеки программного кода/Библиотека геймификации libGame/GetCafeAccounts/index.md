## GetCafeAccounts

Метод **GetCafeAccounts** предназначен для получения списка счетов сотрудников в геймификации.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetCafeAccounts", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя двенадцать параметров:  
     _arrCollIDs_ \- массив сотрудников, для которых необходимо вернуть счета (массив целых чисел).  
     _teApp_ \- TopElem приложения (объект XmlElem).  
     _sPersonState_ \- указание, счета каких сотрудников будут показаны (строка) (необязательный). Допустимые значения - "all" (все), "dismissed"(уволенные), "not\_dismissed" (неуволенные). Значение по умолчанию - "all".  
     _arrBudgetPeriodIDs_ \- массив ID бюджетных периодов (массив целых чисел).  
     _sBpSourse_ \- выбор поля источника бюджетного периода в приложении  (строка) (необязательный). Допустимые значения - "current" (текущий период), "old" (прошлые периоды); "all" (все периоды). Значение по умолчанию - "current";  
     _sCurrencyTypeIDs_ \- Коды валют счета, разделенные запятой  (строка).  
     _sReturnData_ \- указание, какие поля будет возвращать выборка (строка) (необязательный). Допустимые значения - "all" (все поля), "selected" (указанные поля). Значение по умолчанию - "all".  
     _arrFields_ \- массив возвращаемых полей (массив строк).  
     _sFilter_ \- строка содержащая условия из фильра (строка).  
     _sSearch_ \- дополнительный критерий полнотекстового поиска в формате XQuery для отбора (строка) (необязательный).  
     _oPaging_ \- информация из рантайма о пейджинге (объект). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные по счетам сотрудников, а также ряд дополнительных атрибутов:  
\- _accounts_ \- массив данных по счетам (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID счета (целое число).   
     _fullname_ \- ФИО владельца счета (строка).   
     _email_ \- e-mail владельца счета (строка).   
     _balance_ \- баланс счета (строка).   
     _summ\_spend_ \- потраченная сумма (строка).   
     _is\_dismiss_ \- уволен ли сотрудник (булево).   
     _code_ \- код счета (строка).   
     _budget\_period_ \- бюджетный период (целое число).   
     _currency_ \- валюта (строка).   
     _status_ \- статус (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetCafeAccounts", [arrCollIDs, teApp, sPersonState, arrBudgetPeriodIDs, sBpSourse, sCurrencyTypeIDs, sReturnData, arrFields, sFilter, sSearch, oPaging, oSort]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
