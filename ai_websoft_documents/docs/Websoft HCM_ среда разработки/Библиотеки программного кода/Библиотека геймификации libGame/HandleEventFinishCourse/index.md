## HandleEventFinishCourse

Метод **HandleEventFinishCourse** предназначен для начисления баллов за завершение электронного курса в валюте, указанной в разделе **"Бонусы"** карточки курса. Обработчик системного события **"Завершение электронного курса"**.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "HandleEventFinishCourse", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _courseDoc_ \- TopElem курса (объект XmlElem).  
     _learningDoc_ \- TopElem законченного электронного курса (объект XmlElem).

_Возвращаемое значение:_  
     Выполнение обработчика системного события. Возвращаемое значение отсутствует.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "HandleEventFinishCourse", [courseDoc, learningDoc]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
