## GetGameLeadersUserTeam

Метод **GetGameLeadersUserTeam** предназначен для получения списка команд-лидеров по наградам (по рейтингам команд) в геймификации.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetGameLeadersUserTeam", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя семь параметров:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _arrTeamsIDs_ \- массив ID команд (подразделений) (массив целых чисел).  
     _arrRatingBages_ \- массив ID бейджей (массив целых чисел).  
     _arrRatingAwards_ \- массив ID наград (массив целых чисел).  
     _sCurrencyTypeID_ \- код валюты (строка). Допустимые значения: "websoft\_all\_badges" (бейджи) "websoft\_all\_awards" (все награды).   
     _iAmntTops_ \- количество выводимых лидеров из ТОПа (целое число).  
     _oPaging_ - объект пейджинга (объект) ( oPaging.index - номер страницы (целое число); oPaging.size - размер страницы ((целое число)) ) .

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень команд-лидеров по наградам, а также ряд дополнительных атрибутов:  
\- _array_ \- массив команд-лидеров по наградам (массив объектов).  
     Атрибуты отдельного объекта:  
     _command\_id_ – ID команды (целое число).  
     _name_ \- название команды (строка).  
     _score_ – количество баллов (действительное число).  
     _num_ \- номер команды (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetGameLeadersUserTeam", [iPersonID, arrTeamsIDs, arrRatingBages, arrRatingAwards, sCurrencyTypeID, iAmntTops, oPaging]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
