## GetPersonShopContext

Метод **GetPersonShopContext** предназначен для получения контекста сотрудника в магазине призов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetPersonShopContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iPersonID_ \- ID сотрудника (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о контексте сотрудника в магазине призов, а также ряд дополнительных атрибутов:  
\- _context_ \- данные о контексте сотрудника в магазине призов (объект).  
     Атрибуты отдельного объекта:  
     _iBasketID_ \- ID корзины (целое число).  
     _iScore_ - сумма накопленных сотрудником баллов магазина призов в валюте (целое число).  
     _iBasketPrizesCount_ \- количество призов в корзине сотрудника (целое число).  
     _iBasketPrizesSum_ \- общая стоимость призов в корзине сотрудника (целое число).  
     _iActiveOrdersCount_ - количество актуальных заказов сотрудника (сформированных или согласованных) (целое число).  
     _iNonCancelledOrdersCount_ - количество неотмененных заказов сотрудника (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetPersonShopContext", [iPersonID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
