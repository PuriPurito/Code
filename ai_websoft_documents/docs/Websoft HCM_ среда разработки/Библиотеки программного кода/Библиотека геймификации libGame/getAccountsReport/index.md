## getAccountsReport

Метод **getAccountsReport** предназначен для получения отчета по счетам.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "getAccountsReport", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     Массив включает в себя три параметра:  
     _Ps_ \- объект, по которому формируется отчет (необязательный) (объект).  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _sApplicationID_ \- код приложения, по которому определяется доступ (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень счетов, а также ряд дополнительных атрибутов:  
\- _accounts_ – массив счетов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID счета (целое число).  
     _person\_fullname_ \- ФИО сотрудника (строка).  
     _person\_position\_name_ \- должность сотрудника (строка).  
     _person\_subdivision\_name_ \- подразделение, в котором работает сотрудник (строка).  
     _person\_org\_name_ \- организация, в которой работает сотрудник (строка).  
     _status_ \- статус счета (строка).  
     _balance_ \- баланс счета (целое число).  
     _currency_ \- валюта (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "getAccountsReport", [Ps, iCurUserID, sApplicationID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
