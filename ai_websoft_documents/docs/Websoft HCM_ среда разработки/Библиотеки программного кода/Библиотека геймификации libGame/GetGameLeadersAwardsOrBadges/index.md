## GetGameLeadersAwardsOrBadges

Метод **GetGameLeadersAwardsOrBadges** предназначен для получения списка лидеров по наградам (по рейтингам сотрудников) в геймификации.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetGameLeadersAwardsOrBadges", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя двенадцать параметров:  
     _tePerson_ \- TopElem сотрудника (объект XmlElem).  
     _bAllLevel_ \- cтроить ли рейтинг по сотрудникам с любым уровнем (при значении true), иначе только по сотрудникам с заданным уровнем iLevelID, если bCheckLevel = true (булево).  
     _bCheckLevel_ \- cтроить ли рейтинг с учетом последовательности уровней (при значении true), иначе будет учитываться валюта заданного уровня iLevelID (булево).  
     _iLevelID_ \- ID уровня, который будет учитываться при расчете рейтинга, если bCheckLevel = true и bAllLevel = false (целое число).  
     _iAmntCollsRating_ \- количество сотрудников, выводимое в рейтинге, начиная от первого (целое число).  
     _bDispSub_ \- строить ли рейтинг по сотрудникам подразделения (булево). Если да, то рейтинг формируется только по сотрудникам подразделения текущего пользователя.  
     _iSubdivID_ \- ID подразделения, по сотрудникам которого будет строиться рейтинг (целое число) (необязательный).  
     _iSubdivNum_ \- количество подразделений вверх по иерархии (если bDispSub = true) (целое число).  
     _sCurrencyTypeID_ \- ID валюты, по которой строится рейтинг (данный аргумент является обязательным, если bCheckLevel = false) (строка).  
     _iGrpColl_ \- ID группы сотрудников. Если задана, то рейтинг формируется по сотрудникам заданой группы (целое число).  
     _oPaging_ \- объект пейджинга (объект). В состав объекта могут входить следующие параметры: oPaging.index - номер страницы (целое число); oPaging.size - размер страницы (целое число).  
     _bRange_ \- получить список сотрудников в рейтинге, ограниченный параметром iAmntCollsRating (булево).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень лидеров по наградам, а также ряд дополнительных атрибутов:  
\- _leaders_ \- массив лидеров по наградам (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID лидера (целое число);  
     _modification\_date_ – дата модификации (строка).  
     _person\_id_ \- ID сотрудника (строка).  
     _fullname_ \- ФИО сотрудника (строка).  
     _level\_name_ \- название уровня (строка).  
     _level\_num_ \- номер уровня в текстовом формате (строка).  
     _currency\_types\_array_ \- перечисление ID типов валют (строка).  
     _person\_score_ \- количество баллов в текстовом формате (строка).  
     _count_ \- количество лидеров в текстовом формате (строка).  
     _num_ \- порядковый номер в текстовом формате (строка).  
     _icon\_url_ – адрес изображения лидера (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetGameLeadersAwardsOrBadges", [tePerson, bAllLevel, bCheckLevel, iLevelID, iAmntCollsRating,  bDispSub, iSubdivID, iSubdivNum, sCurrencyTypeID, iGrpColl, oPaging, bRange]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
