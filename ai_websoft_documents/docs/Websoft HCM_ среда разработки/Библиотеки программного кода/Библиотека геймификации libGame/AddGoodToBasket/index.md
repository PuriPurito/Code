## AddGoodToBasket

Метод **AddGoodToBasket** предназначен для добавления товара или приза в корзину.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "AddGoodToBasket", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iPersonUserID_ \- ID пользователя (целое число).  
     _iBasketID_ \- ID корзины (целое число).  
     _iGoodID_ \- ID товара/приза (целое число).

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
\- _action\_result_ \- сообщение о выполнении удаленного действия (объект).  
     Атрибуты объекта:  
     _command_ \- название окна сообщения (строка). Значение атрибута в случае успешного выполнения - _"alert"_.  
     _msg_ \- текст сообщения (строка). Значение атрибута в случае успешного выполнения - _"Товар добавлен в корзину"_.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "AddGoodToBasket", [iPersonUserID, iBasketID, iGoodID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
