## DeleteOrder

Метод **DeleteOrder** предназначен для удаления заказа.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "DeleteOrder", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.  
     Массив включает в себя один параметр:  
     _iOrderID_ \- ID заказа (целое число). 

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
\- _action\_result_ \- сообщение о выполнении удаленного действия (объект).  
     Атрибуты объекта:  
     _command_ \- название окна сообщения (строка). Значение атрибута в случае успешного выполнения - _"close\_form"_.  
     _msg_ \- текст сообщения (в т.ч. сообщения об ошибке) (строка). Значение атрибута в случае успешного выполнения - _"Заказ успешно удален"_.  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "DeleteOrder", [iOrderID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
