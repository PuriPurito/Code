## GetPersonThanks

Метод предназначен для получения списка благодарностей сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetPersonThanks", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _iPersonID_ – ID сотрудника, получившего или выразившего благодарность (целое число).  
     _iDirection_ – параметр направления благодарности (целое число) (_1_ – благодарность получена; _2_ – благодарность выражена (отправлена)) (необязательный). Значение по умолчанию – _1_.  
     _isTimeShow_ – показ времени в дате (булево) (необязательный). Значение по умолчанию – _false_.  
     _isShowComment_ – показ комментария к благодарности (булево).  
     _sImgSize_ \- размер картинки получателя/отправителя благодарности (строка) (необязательный). Значение по умолчанию - _"200"_. 

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит перечень благодарностей сотрудника, а также ряд дополнительных атрибутов:  
\- _array_ \- массив благодарностей сотрудника (массив объектов типа **Транзакция**).  
     Атрибуты отдельного объекта:  
     _id_ – ID благодарности (целое число);  
     _date_ \- дата получения благодарности (дата);  
     _amount_ – сумма материального поощрения (премии) (целое число);  
     _currency_ \- валюта материального поощрения (строка);  
     _comment_ \- комментарий к благодарности (строка);  
     _person\_id_ \- ID сотрудника, получившего/выразившего благодарность (строка);  
     _person\_fullname_ \- ФИО сотрудника, получившего/выразившего благодарность (строка);  
     _person\_img_ \- относительная ссылка на изображение сотрудника, получившего/выразившего благодарность (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен _0_) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetPersonThanks", [iPersonID, iDirection, isTimeShow, isShowComment, sImgSize]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
