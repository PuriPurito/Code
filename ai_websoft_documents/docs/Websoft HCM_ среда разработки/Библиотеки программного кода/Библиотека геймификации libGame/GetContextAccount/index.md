## GetContextAccount

Метод **GetContextAccount** предназначен для получения контекста счета в геймификации.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetContextAccount", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _iAccountID_ \- ID счета (целое число).  
     _teAccount_ \- Объект счета (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о контексте счета:  
\- context - контекст счета (объект).  
     Атрибуты объекта:  
     _icon_ – ссылка на изображение счета (строка).  
     _currency_ – наименование валюты счета (строка).  
     _currency\_code_ – код валюты счета (строка).  
     _amount_ – текущий баланс счета (целое число).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetContextAccount", [iPersonID, iAccountID, teAccount]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
