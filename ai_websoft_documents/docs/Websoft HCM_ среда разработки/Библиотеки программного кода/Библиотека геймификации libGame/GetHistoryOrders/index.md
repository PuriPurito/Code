## GetHistoryOrders

Метод **GetHistoryOrders** предназначен для получения списка заказов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetHistoryOrders", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID пользователя (целое число).  
     _oCollectionParams_ \- параметры выборки (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень заказов, а также ряд дополнительных атрибутов:  
\- _array_ - массив заказов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID записи (целое число).  
     _status_ \- статус заказа (строка).  
     _status\_name_ \- наименование статуса заказа (строка).  
     _formed\_date_ \- дата формирование (дата).  
     _currency\_type\_id_ \- ID валюты (строка).  
     _currency\_type\_name_ \- наименование валюты (строка).  
     _sum_ \- сумма заказа (действительное число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetHistoryOrders", [iPersonID, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
