## GetPersonAssignQualifications

Метод предназначен для получения списка квалификаций, присвоенных сотруднику (в модуле геймификации).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetPersonAssignQualifications", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _sStatus_ \- статус присвоенной квалификации сотрудника (строка). Доступные значения: _'active' (Действующая), 'archive' (Архив), 'plan' (Планируется)_. 

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит список квалификаций, присвоенных сотруднику, а также ряд дополнительных атрибутов:  
\- _array_ \- массив квалификаций (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID квалификации (целое число);  
     _name_ \- название квалификации (строка);  
     _assignment\_date_ \- дата присвоения (дата);  
     _expiration\_date_ \- дата окончания срока действия (дата);  
     _state_ \- состояние присвоения квалификации (строка) (доступные значения: _'assigned' (Присвоена), 'not\_assigned' (Не присвоена), 'in\_process' (В процессе), 'expired' (Истекла)_);  
     _link_ – относительная ссылка на квалификацию (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_`  
`_oRes = tools.call_code_library_method ("libGame", "GetPersonAssignQualifications", [ iPersonID, sStatus ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
