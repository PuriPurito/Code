## GetRequestsApp

Метод **GetRequestsApp** предназначен для получения списка заявок сотрудников.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetRequestsApp", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя пятнадцать параметров:  
     _aPersons_ \- Массив ID сотрудников (массив целых чисел) (необязательный). Значение по умолчанию – пустой массив.  
     _sObjects_ \- идентификаторы объектов заявки, разделенные запятой (строка) (необязательный). Значение по умолчанию – пустая строка.  
     _sStatusIDs_ \- идентификаторы статусов заявки, разделенные запятой (строка) (необязательный). Значение по умолчанию – пустая строка.  
     _aBudgetPeriods_ \- массив ID бюджетных периодов (массив целых чисел) (необязательный). Значение по умолчанию – пустой массив.  
     _aRequestTypes_ \- Массив ID типов заявки (массив целых чисел) (необязательный). Значение по умолчанию – пустой массив.  
     _aWorkflows_ \- Массив ID документооборотов (массив целых чисел) (необязательный). Значение по умолчанию – пустой массив.  
     _sWorkflowStates_ \- идентификаторы этапов документооборота, разделенные запятой (строка) (необязательный). Значение по умолчанию – пустая строка.  
     _sCustomFields_ \- список кодов настраиваемых полей, которые выводятся из заявки, разделенные запятой (строка) (необязательный). Значение по умолчанию – пустая строка.  
     _sWorkflowFields_ \- список кодов полей документооборота, которые выводятся из заявки, разделенные запятой (строка) (необязательный). Значение по умолчанию – пустая строка.  
     _sReturnData_ \- указание, какие поля будет возвращать выборка (строка) (необязательный). Допустимые значения: "all" (все поля), "selected" (указанные поля). Значение по умолчанию - "selected".  
     _aFields_ \- массив возвращаемых полей (массив строк).  
     _sFilter_ \- дополнительный фильтр XQuery для отбора (строка) (необязательный). Значение по умолчанию – пустая строка.  
     _sSearch_ \- дополнительный критерий полнотекстового поиска в формате XQuery для отбора (строка) (необязательный). Значение по умолчанию – пуста   
     _oPaging_ \- информация из рантайма о пейджинге (JSON объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень заявок, а также ряд дополнительных атрибутов:  
\- _array_ \- массив объектов с данными по заявкам (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID теста (целое число);  
     _person\_fullname_ – ФИО сотрудника, которому в рамках мероприятия был назначен тест (строка);  
     _name_ – название теста (строка);  
     _score_ – результат прохождения теста (целое число);  
     _start\_usage\_date_ – дата назначения теста (дата);  
     _status_ – статус прохождения теста (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEdu", "SendNotificationsEventBase", [iCompetenceID]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
