## GetPersonBasketGoods

Метод предназначен для получения списка корзин (с товарами) у сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetPersonBasketGoods", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _sBasketCurrency_ \- ID валюты (строка).  
     _isTimeShow_ \- показывать время в датах (булево).  
     _curDocID_ \- ID текущего документа (целое число) (необязательный). 

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит перечень корзин (с товарами) у сотрудника, а также ряд дополнительных атрибутов:  
\- _array_ \- массив корзин сотрудника (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID корзины (целое число);  
     _name_ \- название корзины (строка);  
     _sum_ \- сумма товаров в корзине (строка);  
     _num_ \- количество товаров в корзине (строка);  
     _currency_ \- название валюты корзины (строка);  
     _url_ \- относительная ссылка на корзину (строка);  
     _date_ \- дата формирования корзины (дата);  
     _img_ \- относительная ссылка на изображение (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetPersonBasketGoods", [iPersonID, sBasketCurrency, isTimeShow, curDocID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
