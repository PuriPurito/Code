## GetGoods

Метод предназначен для получения списка товаров.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetGoods", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _iGoodTypeID_ \- ID типа товара (целое число).  
     _iRoleID_ \- ID категории (роли) товара (целое число).  
     _sSearch_ – критерий поиска по наименованию товара (целое число).  
     _sTypeCurrency_ \- ID типа валюты товара (целое число).  
     _bShowInstances_ \- показывать наличие товара (булево). 

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит перечень товаров, а также ряд дополнительных атрибутов:  
\- _array_ \- массив товаров (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID товара (целое число);  
     _name_ \- название товара (строка);  
     _currency_ \- валюта, в которой оценивается товара (строка);  
     _sum_ \- стоимость товара (строка);  
     _instances_ \- информация о наличии товара (строка) (например: _Отсутствуют, Не ограничено_);  
     _img_ \- относительная ссылка на изображение (строка);  
     _url_ \- относительная ссылка на товар (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetGoods", [iGoodTypeID, iRoleID, sSearch, sTypeCurrency, bShowInstances]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
