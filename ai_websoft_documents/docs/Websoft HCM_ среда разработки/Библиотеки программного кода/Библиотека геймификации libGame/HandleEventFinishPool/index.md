## HandleEventFinishPool

Метод **HandleEventFinishPool** предназначен для начисления баллов за участие в опросе в валюте, указанной в разделе **"Бонусы"** карточки опроса. Обработчик системного события **"Создание результата опроса"**.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "HandleEventFinishPool", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _curSystemEventObject_ \- TopElem результата опроса (объект XmlElem).

_Возвращаемое значение:_  
     Выполнение обработчика системного события. Возвращаемое значение отсутствует.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "HandleEventFinishPool", [curSystemEventObject]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
