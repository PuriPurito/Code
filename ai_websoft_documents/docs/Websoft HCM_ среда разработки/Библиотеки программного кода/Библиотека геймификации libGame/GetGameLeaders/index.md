## GetGameLeaders

Метод предназначен для получения списка лидеров (на основании рейтинга сотрудников).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetGameLeaders", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя следующие параметры:  
     _tePerson_ \- TopElem сотрудника (объект);  
     _bCheckLevel_ \- строить рейтинг с учетом последовательности уровней (булево) (необязательный). Если параметр имеет значение _true_, то не будет учитываться валюта, заданная в параметре sCurrencyType. Значение по умолчанию - _true_.   
     _sCurrencyType_ \- тип валюты для построения рейтинга (строка). Обязательный параметр, если _bCheckLevel = false_.  
     _bAllLevel_ \- строить рейтинг по сотрудникам с любым уровнем (булево) (необязательный). Если параметр имеет значение _false_, то рейтинг строится по сотрудникам с тем же уровнем, что у текущего. Значение по умолчанию - _true_.  
     _bDispSub_ \- строить рейтинг по сотрудникам подразделения (булево). Если параметр имеет значение _true_, то рейтинг формируется только по сотрудникам подразделения текущего пользователя. Значение по умолчанию - _false_.  
     _iSubDepth_ \- количество подразделений вверх по иерархии (целое число). Применимо для _bDispSub = true_.  
     _iGrpColl_ \- ID группы сотрудников (целое число). Если задана, то рейтинг формируется по сотрудникам заданой группы.  
     _oPaging_ \- объект пейджинга (необязательный) ( _oPaging.index_ \- номер страницы; _oPaging.size_ \- размер страницы).  
     _iPersonID_ \- ID сотрудника (целое число).  
     _bRangeRating_ \- ограничить количество сотрудников (булево) (необязательный). Если параметр имеет значение _true_, то список сотрудников в рейтинге ограничивается параметром iAmntCollsRating. Значение по умолчанию - _false_.  
     _iRangeRatingPersons_ \- количество сотрудников в рейтинге до и после заданного сотрудника (целое число). Применимо при _bRangeRating = true_.   
     _bSamePlace_ \- присваивать пользователям одно и тоже место в рейтинге при одинаковом количестве баллов (булево) (необязательный). Значение по умолчанию - _false_.  
     _bShowTopRating_ \- показывать первые три места рейтинга (булево) (необязательный). Значение по умолчанию - false.  
     iOrgID - ID организации (целое число).

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит перечень лидеров (на основании рейтингов сотрудников), а также ряд дополнительных атрибутов:  
\- _array_ \- массив лидеров (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID рейтинга (целое число);  
     _modification\_date_ \- дата изменения рейтинга (дата);  
     _person\_id_ \- ID сотрудника, участвующего в рейтинге (строка);  
     _fullname_ \- ФИО сотрудника (строка);  
     _level\_name_ \- название уровня в рейтинге (строка);  
     _level\_num_ \- номер уровня в рейтинге (строка);  
     _currency\_types\_array_ \- перечень типов оценки (валюты) рейтинга (строка);  
     _person\_score_ \- значение персонального рейтинга (строка);  
     _icon\_url_ \- относительная ссылка на изображение (строка);  
     _num_ \- номер рейтинга (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetGameLeaders", [tePerson, bCheckLevel, sCurrencyType, bAllLevel, bDispSub, iSubDepth, iGrpColl, oPaging, iPersonID, bRangeRating, iRangeRatingPersons, bSamePlace, bShowTopRating, iOrgID]);_`   
  
`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
