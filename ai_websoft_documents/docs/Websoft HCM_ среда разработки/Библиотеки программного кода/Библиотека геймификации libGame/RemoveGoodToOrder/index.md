## RemoveGoodToOrder

Метод **RemoveGoodToOrder** предназначен для удаления товара или приза из корзины.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "RemoveGoodToOrder", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iBasketIDParam_ \- ID корзины (целое число).  
     _iGoodIDParam_ \- ID товара (целое число). 

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит атрибут:  
\- _result_ - текст сообщения (в т.ч. сообщения об ошибке) (строка). Значение атрибута в случае успешного выполнения - _"Товар успешно удален из корзины"_.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "RemoveGoodToOrder", [iBasketIDParam, iGoodIDParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
