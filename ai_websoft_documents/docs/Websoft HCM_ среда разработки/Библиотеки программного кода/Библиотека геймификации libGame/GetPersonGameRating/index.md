## GetPersonGameRating

Метод **GetPersonGameRating** предназначен для получения количества баллов сотрудника и его места в рейтинге.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetPersonGameRating", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя девять параметров:  
     _bCheckLevel_ \- строить рейтинг с учетом последовательности уровней (булево). Если да, то не будет учитываться валюта, заданная в параметре _sCurrencyType_.  
     _sCurrencyType_ \- валюта, по которой будет строиться рейтинг (строка). Обязательный параметр, если _bCheckLevel = false_.  
     _bAllLevel_ \- строить рейтинг по сотрудникам с любым уровнем (булево). Если значение равно _false_, то рейтинг строится по сотрудникам с тем же уровнем, что у текущего.  
     _bDispSub_ \- строить рейтинг по сотрудникам подразделения (булево). Если значение равно _true_, то рейтинг формируется только по сотрудникам подразделения текущего пользователя.  
     _iSubDepth_ \- количество подразделений вверх по иерархии (целое число). Применимо для _bDispSub = true_.  
     _iGrpColl_ – ID группы сотрудников (целое число) (необязательный). Если группа сотрудников задана, то рейтинг формируется по сотрудникам указанной группы.  
     _iPersonID_ \- ID сотрудника (целое число).  
     _bSamePlace_ \- одинаковые позиции в рейтинге (булево). Если значение равно _true_, то при одинаковом количестве баллов сотрудникам присваивается одно и то же место в рейтинге.  
     _bShowTopRating_ \- показывать первые три места рейтинга на каждой странице (булево). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о лидерах в соответствии с рейтингом, а также ряд дополнительных атрибутов:  
\- _iPoints_ \- количество баллов, полученное сотрудником (целое число);  
\- _iPlaceNumber_ – место сотрудника в рейтинге (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetPersonGameRating", [bCheckLevel, sCurrencyType, bAllLevel, bDispSub, iSubDepth, iGrpColl, iPersonID, bSamePlace, bShowTopRating]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
