## GetQualifications

Метод **GetQualifications** предназначен для формирования коллекции квалификаций в геймификации.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetQualifications", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя четыре параметра:  
     _aStates_ \- статусы квалификаций для отбора (массив строк).  
     _aTypes_ \- типы квалификаций для отбора (массив строк).  
     _sXQueryQual_ \- дополнительный фильтр XQuery для отбора (строка) (необязательный).  
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень присвоенных квалификаций, а также ряд дополнительных атрибутов:  
\- array - массив присвоенных квалификаций (массив объектов).  
     Атрибуты отдельного объекта:  
     id - ID присвоенной квалификации (целое число).  
     code - код квалификации (строка).  
     name - название квалификации (строка).  
     is\_reward - является ли присвоенная квалификация наградой (булево).  
     status\_name - название статуса (строка).  
     status - код статуса (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetQualifications", [aStates, aTypes, sXQueryQual, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
