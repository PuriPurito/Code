## CreateOrderFromBasket (устаревшая)

Метод **CreateOrderFromBasket** предназначен для cоздания заказа на товары или призы из корзины.

Примечание - Начиная с версии 2022.3, данная функция объявлена как **deprecated**.   
В функции реализована интерфейсная часть удаленных действий. Код перенесен в файл удаленных действий. 

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "CreateOrderFromBasket", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iBasketID_ \- ID корзины (целое число).  
     _sCommand_ \- текущий режим удаленного действия (строка).  
     _sFormFields_ \- JSON-строка с возвратом из формы удаленного действия (строка).   
     _sCurCurrencyTypeID_ \- ID текущей валюты в строковом выражении (строка). Данный аргумент учитывается, если формирование заказа производится не с портала, а из приложения.

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
\- _result_ \- сообщение о выполнении удаленного действия (объект).  
     Атрибуты объекта:  
     _command_ \- название окна сообщения (строка). Значение атрибута в случае успешного выполнения - _"close\_form"_.  
     _msg_ \- текст сообщения (в т.ч. сообщения об ошибке) (строка). Значение атрибута в случае успешного выполнения - _"Заказ успешно создан"_.  
_\- error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "CreateOrderFromBasket", [iBasketID, sCommand, sFormFields, sCurCurrencyTypeID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
