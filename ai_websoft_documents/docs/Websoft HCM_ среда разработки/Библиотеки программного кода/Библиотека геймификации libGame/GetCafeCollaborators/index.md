## GetCafeCollaborators

Метод **GetCafeCollaborators** предназначен для получения списка сотрудников с данными о доступе к приложению **«Кафетерий льгот»**.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetCafeCollaborators", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя восемь параметров:  
     _iCurUserID_ \- ID текущего сотрудника (целое число).  
     _iApplicationID_ \- ID / код приложения (строка).  
     _aBossTypes_ \- массив ID типов руководителей для отбора (массив целых чисел).  
     _bShowDissmiss_ \- нужно ли показывать уволенных сотрудников (булево).   
     _sFilter_ \- строка, содержащая условия выбора элемента фильтра для отбора (строка) (необязательный). Значение по умолчанию – пустая строка.  
     _sSearch_ \- дополнительный критерий полнотекстового поиска в формате XQuery для отбора (строка) (необязательный). Значение по умолчанию – пустая строка.  
     _oSort_ \- информация из рантайма о сортировке (JSON объект).   
     _oPaging_ \- информация из рантайма о пейджинге (JSON объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень сотрудников с данными о доступе к приложению «Кафетерий льгот», а также ряд дополнительных атрибутов:  
\- _collaborators_ \- массив сотрудников с данными о доступе к приложению «Кафетерий льгот» (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID сотрудника (целое число).  
     _fullname_ – ФИО сотрудника (строка).  
     _position\_name_ \- название должности сотрудника (строка).  
     _position\_parent\_name_ \- название подразделения (строка).  
     _has\_account_ \- наличие у сотрудника счета (строка) (допустимые значения: "Да", "Нет").

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetCafeCollaborators", [iCurUserID, iApplicationID, aBossTypes, bShowDissmiss, sFilter, sSearch, oSort, oPaging]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
