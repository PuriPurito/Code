## GetPrizes

Метод **GetPrizes** предназначен для получения списка всех призов или призов, находящихся в корзине сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetPrizes", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя шесть параметров:  
     _iBasketID_ \- ID корзины (целое число).  
     _sType_ \- тип возвращаемого результата (строка). Доступные значения: _all\_prizes_ (все призы); _basket\_prizes_ (призы в корзине сотрудника).  
     _arrDistinct_ \- перечень полей для формирования дополнительных списков для виджета фильтров (массив строк).  
     _arrFilters_ \- набор фильтров (массив объектов). Каждый объект массива включает в себя следующие данные: _id_ \- ID фильтра (строка), _type_ \- тип фильтра (строка), _value_ - критерий отбора (строка).  
     oSort - информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).  
     oPaging - информация из рантайма о пейджинге (объект). Объект включает в себя следующие данные:  INDEX - номер страницы (целое число);  SIZE - размер страницы (целое число); MANUAL - разделение на страницы вручную (булево); TOTAL - общее количество страниц (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень призов, а также ряд дополнительных атрибутов:  
\- _result_ - массив призов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID записи (целое число).  
     _name_ – наименование приза (строка).  
     _img\_url_ \- ссылка на изображения приза (строка).  
     _currency\_type\_id_ \- ID валюты (строка).  
     _currency\_type\_name_ \- наименование валюты (строка).  
     _cost_ \- стоимость (действительное число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetPrizes", [iBasketID, sType, arrDistinct, arrFilters, oSort, oPaging]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
