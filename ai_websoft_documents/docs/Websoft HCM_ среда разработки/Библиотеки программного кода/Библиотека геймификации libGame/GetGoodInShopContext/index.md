## GetGoodInShopContext

Метод **GetGoodInShopContext** предназначен для получения контекста сотрудника по указанному товару в магазине призов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetGoodInShopContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iGoodID_ \- ID товара (целое число).  
     _teGood_ \- TopElem товара (объект XmlElem).  
     _iPersonID_ \- ID сотрудника (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Объект. Содержит данные о контексте сотрудника указанному товару в магазине призов, а также ряд дополнительных атрибутов:  
\- context - контекст сотрудника по товару в магазине призов (массив объектов).  
     Атрибуты объекта:  
     bIsGoodInBasket - товар находится в корзине (булево).   
     iBasketID - ID корзины сотрудника в магазине призов (целое число).  
     rCost - цена товара в магазине призов (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetGoodInShopContext", [iGoodID, teGood, iPersonID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
