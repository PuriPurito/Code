## GetAccountsApp

Метод **GetAccountsApp** предназначен для получения списка счетов сотрудников.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetAccountsApp", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя двенадцать параметров:  
     _arrCollIDs_ \- массив ID сотрудников, для которых необходимо определить данные о счетах (массив целых чисел).  
     _teApp_ \- TopElem приложения (объект XmlElem).  
     _sPersonState_ \- указание, счета каких сотрудников будут показаны (строка) (необязательный). Допустимые значения: "all" (все), "dismissed" (уволенные), "not\_dismissed" (неуволенные). Значение по умолчанию - "all".  
     _arrBudgetPeriodIDs_ \- массив ID бюджетных периодов (массив целых чисел).   
     _sBpSourse_ \- выбор поля источника бюджетных периодов в приложении (строка) (необязательный). Допустимые значения: "current" (текущий), "all" (все). Значение по умолчанию - "current".  
     _sCurrencyTypeIDs_ \- идентификаторы типов валют счета, разделенные запятой (строка) (необязательный). Значение по умолчанию – пустая строка.  
     _sReturnData_ \- указание, какие поля будет возвращать выборка (строка) (необязательный). Допустимые значения: "all" (все поля), "selected" (указанные поля). Значение по умолчанию - "all".  
     _arrFields_ \- массив возвращаемых полей (массив строк) (необязательный). Значение по умолчанию - "fullname;email;balance;currency;status". Данный параметр используется, если **sReturnData="selected"**.  
     _sFilter_ \- строка, содержащая условия выбора элемента фильтра для отбора (строка) (необязательный). Значение по умолчанию – пустая строка.  
     _sSearch_ \- дополнительный критерий полнотекстового поиска в формате XQuery для отбора (строка) (необязательный). Значение по умолчанию – пуста   
     _oPaging_ \- информация из рантайма о пейджинге (JSON объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень счетов сотрудников, а также ряд дополнительных атрибутов:  
\- accounts - массив счетов сотрудников (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID счета (целое число).  
     _fullname_ \- ФИО сотрудника-владельца счета (строка).  
     _email_ \- электронная почта сотрудника-владельца счета (строка).  
     _balance_ \- баланс счета в строковом выражении (строка).  
     _summ\_spend_ \- расход средств со счета в строковом выражении (строка).  
     _is\_dismiss_ \- является ли сотрудник-владелец счета уволенным (булево).  
     _code_ – код счета (строка).  
     _budget\_period_ – название бюджетного периода (строка).  
     _currency_ \- валюта (строка).  
     _status_ \- название статуса счета (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetAccountsApp", [arrCollIDs, teApp, sPersonState, arrBudgetPeriodIDs, sBpSourse, sCurrencyTypeIDs, sReturnData, arrFields, sFilter, sSearch, oPaging, oSort]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
