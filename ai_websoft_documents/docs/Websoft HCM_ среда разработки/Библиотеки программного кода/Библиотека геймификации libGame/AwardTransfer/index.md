## AwardTransfer

Метод **AwardTransfer** предназначен для передачи награды в геймификации.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "AwardTransfer", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iSenderID_ \-  ID отправителя награды (целое число).  
     _iPersonID_ \-  ID получателя награды (целое число).  
     _oAssignmentParams_ \- параметры присвоения награды (объект).     oParam - параметры формирования этапа развития карьеры (объект). В состав объекта могут входить следующие параметры: qualification\_id - ID квалификации (целое число); currency\_type\_id - ID типа валюты в текстовом выражении (строка); bRatingTeam - вести рейтинг команд (булево); arrTeamsList - массив команд из параметров приложения (массив целых чисел); competence\_id - ID компетенции (целое число); comment - комментарий (основание) (строка); expired\_date - дата истечения награды (дата); bSentNotificationRecipient - отправка уведомления получателю награды (булево); iNotificationRecipient - ID типа уведомления получателя награды (целое число); bSentNotificationRecipientBoss - отправка уведомления руководителю получателя награды (булево); iNotificationRecipientBoss - ID типа уведомления руководителя получателя награды (целое число).

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
_\- error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
_\- errorText_ – текст ошибки (строка).  
 

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "AwardTransfer", [iSenderID, iPersonID, oAssignmentParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
