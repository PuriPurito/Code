## ChangeGoodCategory

Метод **ChangeGoodCategory** предназначен для изменения категории товара.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "ChangeGoodCategory", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iGoodID_ \- ID товара (целое число).  
     _arrGoodsIDs_ \- массив ID товаров (массив целых чисел).  
     _iNewRoleID_ \- ID новой категории товара (целое число).

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
\- _action\_result_ – сообщение о результате выполнения функции (объект). В состав объекта могут входить следующие параметры: command – название окна сообщения (строка) (значение "alert"), msg – текст сообщения, если выполнение было произведено с ошибкой (строка).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "ChangeGoodCategory", [iGoodID, arrGoodsIDs, iNewRoleID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
