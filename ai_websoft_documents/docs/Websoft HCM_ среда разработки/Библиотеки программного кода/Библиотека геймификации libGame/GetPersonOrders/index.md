## GetPersonOrders

Метод предназначен для получения списка заказов, оформленных сотрудником.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetPersonOrders", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _sStatus_ \- статус заказа (строка).  
     _isTimeShow_ \- показывать время в датах (булево). 

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит перечень заказов, оформленных сотрудником, а также ряд дополнительных атрибутов:  
\- _array_ \- массив заказов, оформленных сотрудником (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID заказа (целое число);  
     _code_ \- код заказа (строка);  
     _person\_fullname_ – ФИО сотрудника (строка);  
     _sum_ \- сумма заказа (целое число);  
     _status_ \- статус заказа (строка);  
     _currency_ \- валюта, в которой оплачен заказ (строка);  
     _formed\_date_ \- дата формирования заказа (строка);  
     _paid\_date_ \- дата оплаты заказа (дата).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetPersonOrders", [iPersonID, sStatus, isTimeShow]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
