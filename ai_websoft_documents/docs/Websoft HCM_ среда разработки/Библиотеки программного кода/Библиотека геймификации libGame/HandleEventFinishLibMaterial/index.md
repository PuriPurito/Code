## HandleEventFinishLibMaterial

Метод **HandleEventFinishLibMaterial** предназначен для начисления баллов за просмотр материала библиотеки в валюте, указанной в разделе **"Бонусы"** карточки материала библиотеки. Обработчик системного события **"Завершение просмотра материала библиотеки"**.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "HandleEventFinishLibMaterial", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPersonID_ - ID текущего пользователя (целое число).  
     _iLibraryMaterialID_ \- ID материала библиотеки (целое число).

_Возвращаемое значение:_  
     Выполнение обработчика системного события. Возвращаемое значение отсутствует.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "HandleEventFinishLibMaterial", [iPersonID, iLibraryMaterialID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
