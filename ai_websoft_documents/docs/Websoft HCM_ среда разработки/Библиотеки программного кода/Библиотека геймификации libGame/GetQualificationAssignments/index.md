## GetQualificationAssignments

Метод **GetQualificationAssignments** предназначен для формирования коллекции присвоений квалификаций в геймификации.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetQualificationAssignments", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя семь параметров:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _sAccessType_ \- тип доступа для отбора (строка) (необязательный). Допустимые значения: "admin" (администратор приложения); "manager" (администратор процесса); "hr" (менеджер по персоналу); "observer" (наблюдатель); "auto" (определяется автоматически в соответствии с правами доступа пользователя). Значение по умолчанию - "auto".  
     _sApplication_ \- код приложения для определения доступа (строка).  
     _aStates_ \- статусы присвоенных квалификаций (массив строк).  
     _aTypes_ \- типы присвоенных квалификаций (массив строк).  
     _sXQueryQual_ \- дополнительный фильтр XQuery для отбора (строка) (необязательный).  
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень присвоений квалификаций, а также ряд дополнительных атрибутов:  
\- array - массив присвоений квалификаций (массив объектов).  
     Атрибуты отдельного объекта:  
     person\_fullname - ФИО сотрудника, которому присвоена квалификация в процессе геймификации (строка).  
     sender\_fullname - ФИО сотрудника, который присвоил квалификацию в процессе геймификации (строка).  
     qualification\_name - название присвоенной квалификации в процессе геймификации (строка).  
     assignment\_date - дата присвоения квалификации (дата).  
     expiration\_date - дата истечения срока присвоения квалификации (дата).  
     competence\_name - компетенция, указанная в присвоенной квалификации (строка).  
     reason - основание присвоения квалификации (строка).  
     status - статус (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetQualificationAssignments", [iCurUserID, sAccessType, sApplication, aStates, aTypes, sXQueryQual, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
