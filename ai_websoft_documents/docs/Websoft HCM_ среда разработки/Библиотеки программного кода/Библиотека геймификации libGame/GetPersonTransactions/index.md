## GetPersonTransactions

Метод предназначен для получения списка транзакций сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetPersonTransactions", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя следующие параметры:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _sCurrency_ \- валюта счета, по которому проводились транзакции (строка) (необязательный). Значение по умолчанию - _"thanks"_.  
     _iDirection_ \- направление транзакции (целое число) (1 - приход; 2 - расход; 3 - приход и расход) (необязательный). Значение по умолчанию - _1_.  
     _isTimeShow_ \- показывать время в датах (булево) (необязательный). Значение по умолчанию - _false_.  
     _isShowComment_ \- показывать комментарий к транзакции (булево).  
     _sImgSize_ \- размер картинки получателя/отправителя в пикселях в текстовом выражении (строка) (необязательный). Значение по умолчанию - _"200"_.  
     _sObjects_ \- строка id объектов, связанных с транзакцией (строка).  
     _bReturnAll_ \- возвращать все транзакции по всем счетам/сотрудникам (с учетом значений sLinkType и sObjects) (булево) (необязательный). Значение по умолчанию - false.  
     _sLinkType_ \- выбор объекта для поиска (строка) (необязательный). Допустимые значения: "account" (счет); "collaborator" (сотрудник). Значение по умолчанию: "collaborator".  
     _aAccountIDs_ \- массив ID счетов (массив целых чисел).  
     _sReturnData_ \- указание, какие поля будет возвращать выборка (строка) (необязательный). Допустимые значения: "all" (все поля), "selected" (указанные поля). Значение по умолчанию - "all".  
     arrFields - массив возвращаемых полей (массив строк) (необязательный). Значение по умолчанию - "id;date;amount;currency;comment;person\_id;person\_fullname;person\_img". Данный параметр используется, если **sReturnData="selected"**.  
     _oFilters_ \- набор фильтров для формирования отчета (объект).  
     _sSearch_ \- дополнительный критерий полнотекстового поиска в формате XQuery для отбора (строка) (необязательный). Значение по умолчанию – пустая строка.  
     _oPaging_ \- информация из рантайма о пейджинге (JSON объект). 

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит перечень транзакций сотрудника, а также ряд дополнительных атрибутов:  
\- _array_ \- массив объектов с данными по транзакциям сотрудника (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID транзакции (целое число);  
     _date_ \- дата транзакции (дата);  
     _amount_ – сумма транзакции (целое число);  
     _currency_ \- валюта транзакции (строка);  
     _comment_ \- комментарий к транзакции (строка);  
     _person\_id_ \- ID сотрудника, выполнившего транзакцию (строка);  
     _person\_fullname_ \- ФИО сотрудника, выполнившего транзакцию (строка);  
     _person\_img_ \- относительная ссылка на изображение сотрудника (строка).  
     _account\_id_ \- ID счета в текстовом выражении (строка).  
     _account\_name_ \- название счета (строка).  
     _direction_ \- направление транзакции (строка) ("Списание"; "Начисление").  
     _code_ \- код транзакции (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetPersonTransactions", [iPersonID, sCurrency, iDirection, isTimeShow, isShowComment, sImgSize, sObjects, bReturnAll, sLinkType, aAccountIDs, sReturnData, arrFields, sFilter, sSearch, oPaging]);_`   
  
`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
