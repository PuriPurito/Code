## GetOrdersReport

Метод **GetOrdersReport** предназначен для формирования отчетов по заказам в геймификации.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetOrdersReport", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oFilters_ \- объект с фильтрами (параметрами) отчета (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные отчетов по заказам, а также ряд дополнительных атрибутов:  
\- orders - отчеты по заказам (массив объектов).  
     Атрибуты отдельного объекта:  
     id – ID заказа (целое число).  
     person\_fullname – ФИО сотрудника, сформировавшего заказ (целое число).  
     person\_position\_name – должность сотрудника (строка).  
     person\_subdivision\_name – подразделение, в котором работает сотрудник (строка).  
     person\_org\_name – организация, в которой работает сотрудник (строка).  
     name – название отчета (строка).  
     number – ID заказа в текстовом формате (строка).  
     formed\_date – дата формирования заказа (дата).  
     paid\_date – дата оплаты заказа (дата).  
     issue\_date – дата исполнения заказа (дата).  
     status – статус (строка).  
     goods – товары, включенные в заказ (строка).  
     immediate\_export – котовность отчета к экспорту (булево).  
     rows\_count – количество строк отчета (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetOrdersReport", [oFilters]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
