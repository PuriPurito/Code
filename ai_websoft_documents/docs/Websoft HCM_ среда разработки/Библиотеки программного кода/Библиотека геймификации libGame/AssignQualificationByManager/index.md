## AssignQualificationByManager

Метод **AssignQualificationByManager** предназначен для присвоения квалификации менеджером.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "AssignQualificationByManager", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _sCommand_ \- режим выполнения удаленного действия (строка). Допустимые значения: 'submit\_form' (показ формы); 'eval' (обработка формы).  
     _iManagerID_ \- ID руководителя (целое число).  
     _iPersonID_ \- ID подчиненного (целое число).  
     _SCOPE\_WVARS_ \- переменные удаленного действия (объект).

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
\- _result_ \- сообщение о выполнении удаленного действия (объект).  
     Атрибуты объекта:  
     _command_ \- название окна сообщения (строка). Значение атрибута в случае успешного выполнения - _"close\_form"_.  
     _msg_ \- текст сообщения (строка). Значение атрибута в случае успешного выполнения - _"Квалификация присвоена"_.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "AssignQualificationByManager", [sCommand, iManagerID, iPersonID, SCOPE_WVARS]);_`
