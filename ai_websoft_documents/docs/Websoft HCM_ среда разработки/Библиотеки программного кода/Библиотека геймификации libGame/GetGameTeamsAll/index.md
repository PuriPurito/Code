## GetGameTeamsAll

Метод **GetGameTeamsAll** предназначен для получения списка рейтингов всех команд в геймификации.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "GetGameTeamsAll", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _sCurrencyTypeID_ – ID типа валюта, по которой строится рейтинг websoft\_all\_awards (все награды) или websoft\_all\_badges (бэйджи) (строка).  
     _oPaging_ \- объект пейджинга для ограничения итераций цикла по массиву биллинговых счетов (применимо если bCheckLevel = false) (объект).  
     _bSamePlace_ \- присваивать пользователям одно и тоже место в рейтинге при одинаковом количестве баллов (булево).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень рейтингов всех команд, а также ряд дополнительных атрибутов:  
\- leaders - массив рейтингов всех команд (массив объектов).  
     Атрибуты отдельного объекта:  
     command\_id - ID команды (целое число).  
     name - название команды (строка).  
     score - количество баллов у команды (целое число).  
     num - номер команды (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "GetGameTeamsAll", [sCurrencyTypeID, oPaging, bSamePlace]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
