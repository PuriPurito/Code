## AwardCancelTransfer

Метод **AwardCancelTransfer** предназначен для отмены передачи награды в геймификации.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "AwardCancelTransfer", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _arrObjectIDs_ \- массив ID наград (массив целых чисел).  
     _oCancelParams_ \-  параметры отмены (объект). В состав объекта входят следующие параметры: comment - комментарий администратора (строка); bSentNotificationSender - отправка уведомления отправителю награды (булево); iNotificationSender - ID типа уведомления для отправителя награды (целое число); bSentNotificationRecipient - отправка уведомления получателю награды (булево); iNotificationRecipient - ID типа уведомления получателя награды (целое число).

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
_\- count – количество выполненных отмен (целое число)._  
  
_\- error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
_\- errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "AwardCancelTransfer", [arrObjectIDs, oCancelParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
