## SetOrderGoods

Метод **SetOrderGoods** предназначен для изменения списка товаров в заказе.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libGame", "SetOrderGoods", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _iOrderID_ \- ID заказа (целое число).  
     _arrGoods_ \- коллекция товаров в заказе (массив объектов).

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
\- _result_ – текст результата завершения функции (строка) (например: _"Заказ успешно изменен"; "Переданный id: …  не является id заказа"; "Не удалось изменить заказ: …"_).  
_\- error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
_\- errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libGame", "SetOrderGoods", [iOrderID, arrGoods]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
