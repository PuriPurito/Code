## GetFMSubsByBossTypes

Метод **GetFMSubsByBossTypes** предназначен для получения массива идентификаторов организаций/подразделений по типу руководителя.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAssessment", "GetFMSubsByBossTypes", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя четыре параметра:  
     _iUserID_ \- ID пользователя приложения (целое число).  
     _iLevelUser_ \- уровень доступа пользователя (целое число).  
     _teApp_ \- TopElem приложения (объект).  
     _bReturnOrgs_ \- параметр представления (true - связанные организации, false - связанные подразделения) (булево).

_Возвращаемое значение:_  
      Тип: **Массив целых чисел**. Содержит массив ID организаций/подразделений по типу руководителя.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAssessment", "GetFMSubsByBossTypes", [iUserID, iLevelUser, teApp, bReturnOrgs]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
