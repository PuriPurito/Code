## GetCompetenceInfoDevelopmentMethods

Метод предназначен для получения списка программ развития компетенции.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAssessment", "GetCompetenceInfoDevelopmentMethods", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iCompetenceID_ – ID компетенции (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит перечень программ развития компетенции, а также ряд дополнительных атрибутов:  
\- _array_ \- массив программ развития компетенции (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID программы развития компетенции (целое число);  
     _name_ – название программы (строка);  
     _code_ – код программы (строка);  
     _levels_ – уровни программы (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAssessment", "GetCompetenceInfoDevelopmentMethods", [iCompetenceID]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
