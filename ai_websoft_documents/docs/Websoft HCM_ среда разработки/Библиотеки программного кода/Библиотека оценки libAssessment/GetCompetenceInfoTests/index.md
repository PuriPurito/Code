## GetCompetenceInfoTests

Метод предназначен для получения списка тестов компетенции.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAssessment", "GetCompetenceInfoTests", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iCompetenceID_ – ID компетенции (целое число).   
     _iPersonID_ – ID сотрудника (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит перечень тестов компетенции, а также ряд дополнительных атрибутов:  
\- _array_ \- массив тестов компетенции (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID теста компетенции (целое число);  
     _name_ – название теста компетенции (строка);  
     _type_ – тип теста компетенции (строка);  
     _levels_ – уровни теста компетенции (строка);  
     _state_ – состояние теста компетенции (строка);  
     _score_ – количество баллов, полученное при сдаче теста компетенции (целое число);  
     _last\_date_ – дата окончания сдачи теста компетенции (строка).  
     _link_ – относительная ссылка на тест компетенции (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAssessment", "GetCompetenceInfoTests", [iCompetenceID, iPersonID]);= tools.call_code_library_method ("libAss", "GetAssessmentListToParticipate", [ iCurUserID, Status ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
