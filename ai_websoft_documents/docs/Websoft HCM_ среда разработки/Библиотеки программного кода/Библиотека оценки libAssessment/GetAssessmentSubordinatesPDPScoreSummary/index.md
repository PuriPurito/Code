## GetAssessmentSubordinatesPDPScoreSummary

Метод **GetAssessmentSubordinatesPDPScoreSummary** предназначен для получения списка данных по суммарному проценту оценки компетенции в индивидуальном плане развития (ИПР) сотрудников.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAssessment", "GetAssessmentSubordinatesPDPScoreSummary", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя шесть параметров:  
     _iPersonID_ \- ID пользователя (целое число).  
     _dStartDate_ \- начало процедуры оценки (дата).  
     _dEndDate_ \- окончание процедуры оценки (дата).   
     _iBudgetPeriodID_ \- ID бюджетного периода (целое число).  
     _sSex_ \- пол подчиненного (строка).  
     _aPositionCommons_ \- массив ID типовых должностей (массив целых чисел).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень данных по суммарному проценту оценки компетенции, а также ряд дополнительных атрибутов:  
\- _array_ \- массив данных суммарному проценту оценки компетенции (массив объектов).  
     Атрибуты отдельного объекта:  
     _person\_id_ \- ID сотрудника (целое число).  
     _fullname_ \- ФИО сотрудника (строка).  
     _value_ \- процент выполнения (действительное число).  
     _link_ \- ссылка на карточку пользователя (строка).  
     _assessment\_appraise\_link_ \- ссылка на процедуру оценки (строка).  
     _position\_name_ \- должность (строка).  
     _img\_url_ \- ссылка на изображение (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAssessment", "GetAssessmentSubordinatesPDPScoreSummary", [iPersonID, dStartDate, dEndDate, iBudgetPeriodID, sSex, aPositionCommons]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
