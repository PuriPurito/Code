## GetListPa

Метод **GetListPa** предназначен для получения выборки списка анкет.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAssessment", "GetListPa", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя десять параметров:  
     _oUser_ - ID пользователя (целое число).  
     _iAppID_ \- ID приложения (целое число).  
     _sFilter_ \- дополнительное условие XQuery (строка) (необязательный).  
     _oSort_ \- JSON-объект сортировки выборки (объект) (необязательный). Значение по умолчанию: сортировка по возрастанию по полю _"name"_.  
     _bInstanceOnly_ \- учитывать ли только процедуры, связанные с приложением (булево).  
     _arrApprStatus_ \- массив статусов процедуры, которые надо учитывать (массив) (необязательный).  
     _arrTypeAppraise_ \- массив типов оценки, которые надо учитывать (массив) (необязательный).  
     _teApp_ \- TopElem приложения (объект XmlElem) (необязательный).  
     _sSearch_ \- критерий поиска (строка) (необязательный).   
     _xquery\_qual_ \- дополнительный фильтр XQuery для отбора (строка) (необязательный).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит выборку списка анкет, а также ряд дополнительных атрибутов:  
\- _result_ – массив отобранных анкет (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID анкеты (целое число).  
     _pa\_code_ – код анкеты (строка).  
     _app\_name_ \- название анкеты (строка).  
     _app\_status_ \- статус анкеты (строка).  
     _app\_start\_date_ \- начало анкетирования в строковом выражении (строка).  
     _app\_end\_date_ \- завершение анкетирования в строковом выражении (строка).  
     _person\_fullname_ \- ФИО оцениваемого сотрудника (целое число).  
     _workflow\_state_ \- этап документооборота (строка).  
     _workflow\_state\_plan_ \- плановый этап документооборота (строка).  
     _expert\_person\_fullname_ – ФИО оценивающего сотрудника (целое число).  
     _expert\_role_ – роль оценивающего сотрудника (строка).  
     _overall_ \- итоговая оценка (действительное число).  
     _type\_asses_ – тип приложения, в котором производится анкетирование (оценка) (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAssessment", "GetListPa", [oUser, iAppID, sFilter, oSort, bInstanceOnly, arrApprStatus, arrTypeAppraise, teApp, sSearch, xquery_qual]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
