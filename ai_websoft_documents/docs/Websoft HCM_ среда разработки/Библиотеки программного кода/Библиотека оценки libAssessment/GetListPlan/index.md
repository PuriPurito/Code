## GetListPlan

Метод **GetListPlan** предназначен для получения выборки списка планов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAssessment", "GetListPlan", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя восемь параметров:  
     _oCurUser_ \- объект пользователя (объект).   
     _iAppID_ \- ID приложения (целое число).  
     _sFilter_ \- дополнительный фильтр полнотекстового поиска в формате XQuery для отбора (строка) (необязательный).  
     _oSort_ \- информация из рантайма о сортировке (JSON объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).  
     _bInstanceOnly_ \- параметр представления групп (булево) (true - учитываются только группы, связанные с приложением, false - все группы)  
     _arrStatus_ \- массив статусов процедуры, которые надо учитывать (массив строк).  
     _teApp_ \- TopElem приложения (объект XmlElem).   
     _sSearch_ \- критерий полнотекстового поиска для отбора (строка) (необязательный).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень планов, а также ряд дополнительных атрибутов:  
\- _array_ \- массив планов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID плана (целое число).  
     _code_ \- код плана (строка).  
     _name_ \- название плана (строка).  
     _person\_id_ \- ID сотрудника в строковом выражении (строка).  
     _sWorkflowState_ \- ID этапа документооборота в строковом выражении (строка).  
     _status_ \- статус плана (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAssessment", "GetListPlan", [oUser, iAppID, sFilter, oSort, bInstanceOnly, arrStatus, teApp, sSearch]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
