## GetAssessmentListToParticipate

Метод предназначен для получения списка оценочных процедур, в которых указанный сотрудник является оценщиком.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAssessment", "GetAssessmentListToParticipate", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _iCurUserID_ - ID пользователя (целое число).  
     _Status_ \- статус процедуры (строка). Допустимые значения: _'p' (Планируется), 'r' (Подготовлена), '0' (Выполняется), '1' (Архив), 'x' (Отменена)_. Значение по умолчанию - _'0' (Выполняется)_.  
     _bIncludeSelf_ \- учитывать собственные формы (булево) (необязательный). Значение по умолчанию - _false_.   
     _bIncludeAdmin_ \- учитывать процедуры, где пользователь является администратором (булево) (необязательный). Значение по умолчанию - false.   
     _bCheckVisible_ \- проверять условия видимости в карточке процедуры (булево) (необязательный). Значение по умолчанию - false. 

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит список оценочных процедур, в которых указанный сотрудник является оценщиком, а также ряд дополнительных атрибутов:  
\- _array_ \- массив оценочных процедур, осуществляемый сотрудником (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID оценочной процедуры (целое число);  
     _name_ \- название оценочной процедуры (строка).  
     _link_ \- относительная ссылка на оценочную процедуру (строка).  
     _start\_date_ \- дата начала процедуры оценки (дата).  
     _end\_date_ \- дата окончания процедуры оценки (дата).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAssessment", "GetAssessmentListToParticipate", [iCurUserID, Status, bIncludeSelf, bIncludeAdmin, bCheckVisible]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
