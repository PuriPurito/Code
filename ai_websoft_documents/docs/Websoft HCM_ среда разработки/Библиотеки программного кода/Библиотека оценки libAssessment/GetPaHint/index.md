## GetPaHint

Метод **GetPaHint** предназначен для получения подсказки для оценочной формы.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAssessment", "GetPaHint", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID участника оценочной формы (целое число).  
     _paDoc_ \- TopElem анкеты оценочной формы (объект XmlElem).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит текст подсказки для оценочной формы, а также ряд дополнительных атрибутов:  
\- _result_ \- текст подсказки для оценочной формы (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAssessment", "GetPaHint", [iPersonID, paDoc]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
