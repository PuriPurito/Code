## GetAssessmentAppraisesList

Метод **GetAssessmentAppraisesList** предназначен для получения коллекции оценочных процедур.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAssessment", "GetAssessmentAppraisesList", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя семь параметров:  
     _UserID_ \- ID текущего пользователя (целое число).  
     _iApplicationID_ \- ID текущего приложения (целое число) (необязательный).  
     _arrStatus_ \- массив статусов процедуры оценки (массив строк) (необязательный).  
     oSort - информация из рантайма о сортировке (объект) (необязательный). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).  
     _sFilter_ \- условия фильтра XQuery (строка) (необязательный).  
     _bInstanceOnly_ \- учитывать ли только процедуры, связанные с приложением (булево).  
     _sSearch_ \- текст поиска (строка) (необязательный).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит коллекцию кадровых комитетов:  
\- _array_ - массив оценочных процедур (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID процедуры оценки (целое число).  
     _name_ \- название оценочной процедуры (строка).  
     _start\_date_ \- начало процедуры (дата).  
     _end\_date_ \- окончание процедуры (дата).  
     _status\_name_ \- статус процедуры (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAssessment", "GetAssessmentAppraisesList", [iUserID, iApplicationID, arrStatus, oSort, sFilter, bInstanceOnly, sSearch]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
