## CheckScale

Метод **CheckScale** предназначен для проверки шкал оценки.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAssessment", "CheckScale", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iValue_ \- значение для проверки (действительное число).  
     _iScale_ \- ID шкалы (целое число).  
     _teScale_ \- TopElem шкалы (объект XmlElem).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит следующие атрибуты:  
\- _result_ – результат вызова метода (максимальный или минимальный уровень шкалы) (действительное число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAssessment", "CheckScale", [iValue, iScale, teScale]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
