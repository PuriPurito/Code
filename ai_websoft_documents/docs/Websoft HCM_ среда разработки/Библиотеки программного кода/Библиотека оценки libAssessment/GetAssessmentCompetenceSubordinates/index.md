## GetAssessmentCompetenceSubordinates

Метод **GetAssessmentCompetenceSubordinates** предназначен для получения списка данных по средней оценке компетенции в индивидуальном плане развития (ИПР) сотрудников.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAssessment", "GetAssessmentCompetenceSubordinates", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя восемь параметров:  
     _iPersonID_ \- ID пользователя (целое число).  
     _aBudgetPeriods_ \- массив ID бюджетных периодов (массив целых чисел).  
     _sex_ \- пол подчиненного (строка).  
     _aPositionCommons_ \- массив ID типовых должностей (массив целых чисел).  
     _aCompetenceProfiles_ \- массив ID профилей компетенции (массив целых чисел).  
     _iMaxCellCount_ \- ограничение по количеству записей (целое число).  
     _sProcedureStatus_ \- статус процедуры оценки (строка).  
     _cellDisplay_ \- вариант отображения (строка). Допустимые значения: "p"(фотография); "pn"(фотография и имя); "n"(имя).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень данных по оценке компетенции в индивидуальном плане развития, а также ряд дополнительных атрибутов:  
\- array - массив данных по оценке компетенции (массив объектов).  
     Атрибуты отдельного объекта:  
     id - ID оценки (целое число).  
     title – заголовок (строка).  
     profiles - ID профилей (строка).  
     link - ссылка на оценку компетенции (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAssessment", "GetAssessmentCompetenceSubordinates", [iPersonID, aBudgetPeriods, sex, aPositionCommons, aCompetenceProfiles, iMaxCellCount, sProcedureStatus, cellDisplay]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
