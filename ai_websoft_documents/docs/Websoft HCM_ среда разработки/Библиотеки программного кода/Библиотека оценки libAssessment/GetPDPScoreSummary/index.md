## GetPDPScoreSummary

Метод **GetPDPScoreSummary** предназначен для получения процента выполнения индивидуального плана развития (ИПР) сотрудником.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAssessment", "GetPDPScoreSummary", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _iPersonID_ \- ID пользователя (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о сотрудниках и проценте выполнения им ИПР, а также ряд дополнительных атрибутов:  
\- _array_ – данные о сотрудниках и проценте выполнения им ИПР (массив объектов).  
     Атрибуты отдельного объекта:  
     _person\_id_ \- ID сотрудника (целое число).  
     _fullname_ – ФИО сотрудника (строка).  
     _sex_ \- пол (строка).  
     _link_ \- ссылка на карточку пользователя (строка).  
     _position\_name_ – название должности (строка).  
     _img\_url_ \- URL изображения фотографии (строка).  
     _value_ \- процент выполнения (действительное число).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAssessment", "GetPDPScoreSummary", [iPersonID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
