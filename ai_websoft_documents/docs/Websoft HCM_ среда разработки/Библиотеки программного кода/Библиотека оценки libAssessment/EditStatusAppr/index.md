## EditStatusAppr

Метод  **EditStatusAppr** предназначен для изменения состояния процедуры.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAssessment", " EditStatusAppr", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _sStatus_ \- код статуса, который надо установить (строка).  
     _iApprID_ \- ID процедуры оценки (целое число).

_Возвращаемые значения:_  
      Тип:  **Булево**. Результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAssessment", " EditStatusAppr", [sStatus, iApprID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
