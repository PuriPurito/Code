## GetCompetenceInfoEducationMethods

Метод предназначен для получения списка учебных программ компетенции.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAssessment", "GetCompetenceInfoEducationMethods", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iCompetenceID_ – ID компетенции (целое число).   
     _iPersonID_ – ID сотрудника (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит перечень учебных программ компетенции, а также ряд дополнительных атрибутов:  
\- _array_ \- массив учебных программ компетенции (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID учебной программы компетенции (целое число);  
     _name_ – название программы (строка);  
     _type_ – тип программы (строка);  
     _levels_ – уровни программы (строка).  
     _recommended_ – программа рекомендована сотруднику (булево).  
     _learned_ – программа изучена сотрудником (булево).  
     _date_ – дата назначения программы (строка).  
     _link_ – относительная ссылка на программу (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAssessment", "GetCompetenceInfoEducationMethods", [iCompetenceID, iPersonID]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
