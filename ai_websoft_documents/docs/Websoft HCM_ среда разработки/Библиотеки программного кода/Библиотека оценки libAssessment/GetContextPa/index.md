## GetContextPa

Метод **GetContextPa** предназначен для получения данных контекста анкеты оценочной формы.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAssessment", "GetContextPa", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _iPaID_ \- ID анкеты оценочной формы (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные контекста анкеты оценочной формы, а также ряд дополнительных атрибутов:  
\- _context_ \- данные контекста анкеты оценочной формы (объект).  
     Атрибуты объекта:  
     _sWorkflowState_ – текущий этап документооборота (строка).  
     _bAllObjectivesHasMarks_ – все ли цели выполнены (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAssessment", "GetContextPa", [iPaID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
