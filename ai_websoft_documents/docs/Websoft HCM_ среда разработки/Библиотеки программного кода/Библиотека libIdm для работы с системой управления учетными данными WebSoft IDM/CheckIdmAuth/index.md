## CheckIdmAuth

Метод **CheckIdmAuth** предназначен для проверки того, авторизуется ли данный хост в IDM.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libIdm", "CheckIdmAuth", <arrParams>**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _sHostName_ \- название хоста (строка).

_Возвращаемые значения:_

      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _result_ – результат вызова метода (_true_ – если хост авторизуется в IDM, _false_ – в противном случае) (булево).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libIdm", "CheckIdmAuth", [sHostName]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
