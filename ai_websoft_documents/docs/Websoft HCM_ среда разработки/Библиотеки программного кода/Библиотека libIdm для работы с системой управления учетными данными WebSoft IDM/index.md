## Библиотека libIdm для работы с системой управления учетными данными WebSoft IDM

В настоящем разделе описываются методы **библиотеки для работы с системой управления учетными данными WebSoft IDM (Identity Management)** (библиотека программного кода **libIdm**). Указанная библиотека регистрируется в разделе **Дизайнер – Библиотеки программного кода – libIdm**.

Подробнее о системе управления учетными данными WebSoft IDM – см. здесь.  
  
Для вызова методов из библиотеки используется функция tools.call\_code\_library\_method.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libIdm", <sMethodNameParam>, <arrParams>)**

_Аргументы:_  
     _<sMethodNameParam> (обязательный)_  
      Тип: **Строка**. Название вызываемого метода.  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.
