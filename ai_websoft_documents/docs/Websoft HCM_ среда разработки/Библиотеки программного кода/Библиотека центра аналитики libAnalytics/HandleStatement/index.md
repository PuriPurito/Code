## HandleStatement

Метод **HandleStatement** (обработчик событий) предназначен для обработки записи xAPI (распределения данных из запроса в формате JSON по вспомогательным каталогам).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAnalytics", "HandleStatement", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _iStatementId_ \- ID карточки записи (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит следующие атрибуты:  
\- _arrCreatedDocIds_ \- ID созданных документов (массив целых чисел).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAnalytics", "HandleStatement", [iStatementId]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
