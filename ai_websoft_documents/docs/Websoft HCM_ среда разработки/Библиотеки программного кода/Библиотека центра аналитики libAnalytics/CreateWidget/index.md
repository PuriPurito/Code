## CreateWidget

Метод **CreateWidget** предназначен для формирования описания виджета.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAnalytics", "CreateWidget", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _data_ \- данные виджета (объект). Атрибуты объекта: default\_code - код виджета, на основе данных которого будет создаваться текущий (в строковом формате) (строка); dashboard\_id - ID дашборда в строковом формате (строка); code - код виджета (строка); type - тип виджета (строка); version - версия виджета (строка); order - позиция виджета в списке (целое число); name - название виджета (строка); subtitle - подзаголовок виджета (строка); description - описание виджета (строка); source\_id - ID источника (показателя или выборки) в строковом формате (строка); aggregate\_field\_name - поле агрегации (строка); group\_aggregate\_type - тип агрегирования внутри группы (строка); indicator\_title - заголовок индикатора (строка); gauge\_title - заголовок зоны (строка); gauge\_zone\_type - тип зоны датчика (строка); card\_background - фон индикатора (строка); table\_column\_name\_title - заголовок столбца таблицы (строка); line\_title - заголовок линии (строка); source\_widget\_id ID виджета источника данных (строка); source\_params - массив переменных источника (массив объектов) (в том числе: name - название переменной (строка); value - значение переменной (строка)); result - переменные результата (объект) (в том числе: name - значение переменной "Название" (строка); value - значение переменной "Значение" (строка)); filter - фильтр виджета (объект) (в том числе: start\_date - начало диапазона (дата); finish\_date - конец диапазона (дата); group - период группировки данных ('day', 'week', 'month', 'year', 'all') (строка); period - период (строка)); segmentation - данные сегментации (объект) (в том числе: object\_items - массив ID объектов в строковом формате (массив строк); structure\_items - массив данных о подразделениях и сотрудниках (id - ID объекта в строковом формате (строка); type - тип элемента (position, org, subdivision) (строка); include\_children - учитывать ли дочерние подразделения вниз по иерархии (булево))); prevent\_ordering - не производнить сортировку виджетов после добавления (булево). 

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- id - ID созданного виджета в строковом формате (строка).  
\- code - код виджета (строка).   
\- type - тип виджета (строка).  
\- version - версия виджета (строка).  
\- order - позиция в списке (целое число).  
\- name - название виджета (строка).  
\- subtitle - подзаголовок виджета (строка).  
\- description - описание виджета (строка).  
\- source\_id - ID источника (показателя или выборки) в текстовом формате (строка).  
\- aggregate\_field\_name - поле агрегации (строка).  
\- group\_aggregate\_type - тип агрегирования внутри группы (строка).  
\- indicator\_title - заголовок индикатора (строка).  
\- gauge\_title - заголовок индикатора (строка).  
\- gauge\_zone\_type - тип зон датчика (строка).  
\- card\_background - фон индикатора (строка).  
\- table\_column\_name\_title - заголовок столбца таблицы (строка).  
\- line\_title - заголовок линии (строка).  
\- source\_widget\_id - ID виджета источника данных в текстовом формате (строка).  
\- source\_params - переменные (массив объектов). Каждый объект массива может включать в себя следующие данные: name - название переменной (строка); value значение переменной в текстовом формате (строка).  
\- result - переменные результата (объект). В состав объекта могут входить следующие параметры: name - значение переменной "Название" (строка); value - значение переменной "Значение" в текстовом формате (строка).  
\- filter - данные фильтра (объект). В состав объекта могут входить следующие параметры: start\_date - начало диапазона (дата); finish\_date - конец диапазона (дата); group - период группировки данных ( day, week, month, year, all ) (строка); period - название периода диапазона (строка).  
\- segmentation - данные сегментации (объект). В состав объекта могут входить следующие параметры: object\_items - ID объектов в текстовом формате (массив строк); structure\_items - информация о подразделениях и сотрудниках (массив объектов) (в частности: id - ID объекта в текстовом формате (строка); type - тип элемента (position, org, subdivision) (строка); include\_children - учитывать ли дочерние подразделения вниз по иерархии (булево) и др.).  
\- component\_tag - тег компоненты виджета (строка).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAnalytics", "CreateWidget", [data]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
