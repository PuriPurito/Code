## CreateCategory

Метод **CreateCategory** предназначен для создания категории с учетом переданных данных.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAnalytics", "CreateCategory", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _data_ \- данные категории (объект). Атрибуты объекта: default\_code - код категории, на основе данных которой будет создаваться текущая категория (строка); order - порядковый номер (целое число); name - название категории (строка); subtitle - подзаголовок категории (строка); description - описание категории (строка); code - код категории (строка); image - URL изображения (строка); prevent\_ordering - не производнить сортировку категорий после добавления (булево).

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- id - ID созданной категории в строковом формате (строка).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAnalytics", "CreateCategory", [data]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
