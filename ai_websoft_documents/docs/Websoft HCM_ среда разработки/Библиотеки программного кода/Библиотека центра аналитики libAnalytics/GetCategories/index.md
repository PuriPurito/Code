## GetCategories

Метод **GetCategories** предназначен для получения списка категорий пользователя.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAnalytics", "GetCategories", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
      Функция (метод) вызывается без аргументов. 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень категорий пользователя, а также ряд дополнительных атрибутов:  
\- _items_ - массив категорий пользователя (массив объектов).  
     Атрибуты отдельного объекта:  
     _order_ \- номер категории (целое число);  
     _code_ \- код категории (строка).  
     _name_ \- название категории (строка).  
     _description_ \- описание категории (строка).  
     _image_ \- изображение (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAnalytics", "GetCategories", []);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
