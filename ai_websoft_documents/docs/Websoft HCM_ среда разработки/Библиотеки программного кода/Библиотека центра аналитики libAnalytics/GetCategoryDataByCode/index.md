## GetCategoryDataByCode

Метод **GetCategoryDataByCode** предназначен для получения данных категории пользователя.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAnalytics", "GetCategoryDataByCode", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _code_ \- код категории (строка). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные категории пользователя, а также ряд дополнительных атрибутов:  
     Атрибуты объекта:  
     _data_ \- данные категории (объект). В том числе: ID категории в строковом формате (строка); name - название категории (строка); subtitle - подзаголовок категории (строка); image - URL изображения (строка); description - описание категории (строка); code - код категории (строка); dashboards - информация о возвращаемых дашбордах (массив объектов) (id - ID дашборда в строковом формате (строка); name - название дашборда (строка)).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAnalytics", "GetCategoryDataByCode", [code]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
