## UpdateDashboard

Метод **UpdateDashboard** предназначен для обновления данных дашборда.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAnalytics", "UpdateDashboard", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _data_ \- обновляемые данные дашборда (объект). Атрибуты объекта: id - ID дашборда в строковом формате (строка); name - название дашборда (строка); code - код дашборда (строка); order - порядковый номер (целое число); view - количество отображаемых столбцов (в строковом выражении) (строка); filter - данные фильтра (объект) (в том числе: start\_date - начало диапазона (дата); finish\_date - конец диапазона (дата); group - период группировки данных (day, week, month, year, all) (строка)); segmentation - данные сегментации (объект) (в том числе: object\_items - массив ID объектов в строковом формате (массив строк); structure\_items - массив данных о подразделениях и сотрудниках (id - ID объекта в строковом формате (строка); type - тип элемента (position, org, subdivision) (строка); include\_children - учитывать ли дочерние подразделения вниз по иерархии (булево))); description - описание дашборда (строка).

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAnalytics", "UpdateDashboard", [data]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
