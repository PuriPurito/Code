## GetSegmentationObjectsMetaData

Метод **GetSegmentationObjectsMetaData** предназначен для получения данных объектов сегментации.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAnalytics", "GetSegmentationObjectsMetaData", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _object\_ids_ \- ID объектов (массив строк). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные объектов сегментации, а также ряд дополнительных атрибутов:  
_\- items_ \- данные объектов сегментации (массив объект).  
     Атрибуты объекта:  
     _id_ \- ID объекта в строковом формате (строка).  
     _name_ \- название объекта (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAnalytics", "GetSegmentationObjectsMetaData", [object_ids]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
