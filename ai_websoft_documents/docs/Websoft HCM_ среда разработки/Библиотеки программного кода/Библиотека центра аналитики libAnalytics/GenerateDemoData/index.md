## GenerateDemoData

Метод **GenerateDemoData** предназначен для генерирации демо-данных (стейтментов).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAnalytics", "GenerateDemoData", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя четыре параметра:  
     _object\_id_ \- ID учебной активности в строковом формате (строка).  
     _number_ \- количество стейтментов, которые надо сгенерировать (в строковом формате) (строка).  
     _start\_date_ \- начало диапазона (дата).  
     _finish\_date_ \- конец диапазона (дата).

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _data_ \- данные объекта (объект).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAnalytics", "GenerateDemoData", [object_id, number, start_date, finish_date]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
