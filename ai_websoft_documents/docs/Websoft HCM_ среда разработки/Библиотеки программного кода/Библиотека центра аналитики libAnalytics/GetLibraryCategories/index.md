## GetLibraryCategories

Метод **GetLibraryCategories** предназначен для получения данных диалогового окна "Библиотека категорий".

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAnalytics", "GetLibraryCategories", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя четыре параметра:  
     _search_ \- строка поиска (строка).  
     _page\_num_ \- номер страницы (целое число).  
     _page\_size_ \- размер страницы (целое число).  
     _category_ \- категория (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные диалогового окна "Библиотека категорий", а также ряд дополнительных атрибутов:  
     Атрибуты объекта:  
\- items - данные диалогового окна "Библиотека категорий" (объект).  
\- total - общее число элементов (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAnalytics", "GetLibraryCategories", [search, page_num, page_size, category]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
