## GetWidgetMeta

Метод **GetWidgetMeta** предназначен для возвращения метаданных виджета.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAnalytics", "GetWidgetMeta", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _id_ \- ID виджета в текстовом формате (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит метаданные виджета, а также ряд дополнительных атрибутов:  
\- data - метаданные виджета (объект).  
     Атрибуты отдельного объекта:  
     _id_ – ID виджета в текстовом формате (строка);  
     _name_ – название виджета (строка);  
     _component\_tag_ \- тег компоненты виджета в формате HTML (строка).   
     _description_ \- описание виджета (строка).  
     _order_ \- позиция виджета на дашборде (целое число).  
     _type_ \- тип отображения виджета (строка).  
     _version_ \- версия виджета (строка).  
     _subtitle_ \- подзаголовок виджета (строка).  
     _source\_id_ \- ID источника (показателя или выборки) в текстовом формате (строка).  
     _group\_aggregate\_type_ \- тип агрегирования внутри группы (строка).  
     _indicator\_title_ \- заголовок индикатора (строка).  
     _gauge\_title_ \- заголовок датчика (строка).  
     _gauge\_zone\_type_ \- тип зон датчика (строка).  
     _table\_column\_name\_title_ \- заголовок столбца таблицы (строка).  
     _line\_title_ \- заголовок линии (строка).  
     _source\_params_ \- переменные (массив объектов). Каждый объект массива может включать в себя следующие данные: name - название переменной (строка); value значение переменной в текстовом формате (строка).  
     _result_ \- переменные результата (объект). В состав объекта могут входить следующие параметры: name - значение переменной "Название" (строка); value - значение переменной "Значение" в текстовом формате (строка).  
     _filter_ \- данные фильтра (объект). В состав объекта могут входить следующие параметры: start\_date - начало диапазона (дата); finish\_date - конец диапазона (дата); group - период группировки данных ( day, week, month, year, all ) (строка); period - название периода диапазона (строка).  
     _segmentation_ \- данные сегментации (объект). В состав объекта могут входить следующие параметры: object\_items - ID объектов в текстовом формате (массив строк); structure\_items - информация о подразделениях и сотрудниках (массив объектов) (в частности: id - ID объекта в текстовом формате (строка); type - тип элемента (position, org, subdivision) (строка); include\_children - учитывать ли дочерние подразделения вниз по иерархии (булево) и др.).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAnalytics", "GetWidgetMeta", [id]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
