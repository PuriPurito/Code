## GetWidgetData

Метод **GetWidgetData** предназначен для получения данных для виджета.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAnalytics", "GetWidgetData", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя пять параметров:  
     _object\_id_ \- ID виджета (строка).  
     _start\_date_ \- начало диапазона (дата).   
     _finish\_date_ \- конец диапазона (дата).   
     _group_ \- период группировки данных ('day', 'week', 'month', 'year', 'all') (строка).  
     _segmentation_ \- данные сегментация (объект), в том числе: object\_items - ID объектов (массив строк); structure\_items - массив данных о подразделениях и сотрудниках (массив объектов). Атрибуты объектов: id - ID объекта в строковом выражении (строка); type - тип элемента ('position', 'org', 'subdivision') (строка); include\_children - учитывать дочерние подразделения вниз по иерархии (булево).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные для виджета, а также ряд дополнительных атрибутов:  
\- _data_ \- данные виджета (объект).  
\- _all\_statistic\_data_ \- все данные возвращаемые показателем (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAnalytics", "GetWidgetData", [object_id, start_date, finish_date, group, segmentation]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
