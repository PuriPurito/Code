## InitAnalyticsApp

Метод **InitAnalyticsApp** предназначен для получения данных, необходимых для инициализации приложения "Центр аналитики".

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAnalytics", "InitAnalyticsApp", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Метод вызывается без аргументов. 

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
     _auth_ \- данные авторизации (объект).  
     _styles_ \- данные стилей (объект).  
     _data_ \- данные приложения (объект).  
     _lang_ \- данные локализации (строка).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAnalytics", "InitAnalyticsApp", []);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
