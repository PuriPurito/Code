## UpdateWidget

Метод **UpdateWidget** предназначен для обновления данных виджета.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAnalytics", "UpdateWidget", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _data_ \- обновляемые данные виджета (объект). Атрибуты объекта: id - ID виджета в строковом формате (строка); name - название виджета (строка); code - код виджета (строка); type - тип виджета (строка); version - версия виджета (строка); order - порядковый номер (позиция) в дашборде (целое число); subtitle подзаголовок виджета (строка); description - описание виджета (строка); source\_id - ID источника (показателя или выборки) (строка); aggregate\_field\_name - поле агрегации (строка); group\_aggregate\_type - тип агрегирования внутри группы (строка); indicator\_title - заголовок индикатора (строка); gauge\_title - заголовок датчика (строка); gauge\_zone\_type - тип зон датчика (строка); card\_background - фон индикатора (строка); table\_column\_name\_title - заголовок столбца таблицы (строка); line\_title - заголовок линии (строка); source\_params - переменные источника (массив объектов). Атрибуты объектов: name - название переменной источника (строка); value - значение переменной источника (строка); result - переменные результата (объект) (в том числе: name - значение переменной "Название" (строка); value - значение переменной "Значение" (строка)); filter - данные фильтра (объект) (в том числе: start\_date - начало диапазона (дата); finish\_date - конец диапазона (дата); group - период группировки данных (day, week, month, year, all) (строка)); segmentation - данные сегментации (объект) (в том числе: object\_items - массив ID объектов в строковом формате (массив строк); structure\_items - массив данных о подразделениях и сотрудниках (id - ID объекта в строковом формате (строка); type - тип элемента (position, org, subdivision) (строка); include\_children - учитывать ли дочерние подразделения вниз по иерархии (булево))); source\_widget\_id - ID виджета источника данных в текстовом формате (строка)..

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAnalytics", "UpdateWidget", [data]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
