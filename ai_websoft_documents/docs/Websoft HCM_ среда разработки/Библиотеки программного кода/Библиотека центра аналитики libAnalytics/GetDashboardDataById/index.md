## GetDashboardDataById

Метод **GetDashboardDataById** предназначен для получения данных дашборда.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAnalytics", "GetDashboardDataById", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _id_ \- ID дашборда (строка). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные дашборда, а также ряд дополнительных атрибутов:  
\- data - данные дашборда (объект).  
     Атрибуты объекта:  
     _id_ \- ID дашборда (строка).  
     _name_ \- название дашборда (строка).  
     _code_ \- код дашборда (строка).  
     _order_ \- расположение дашборда в категории (целое число).  
     _filter_ \- фильтр дашборда (объект). Атрибуты объекта: start\_date - начало диапазона (дата); finish\_date - конец диапазона (дата); group - период группировки данных ('day', 'week', 'month', 'year', 'all') (строка); period - период (строка).  
     _widgets_ \- метаданные виджетов (массив объектов).  
     Атрибуты объектов:   
          id – ID виджета в текстовом формате (строка);  
          name – название виджета (строка);  
          component\_tag - тег компоненты виджета в формате HTML (строка).   
          description - описание виджета (строка).  
          order - позиция виджета на дашборде (целое число).  
          type - тип отображения виджета (строка).  
          version - версия виджета (строка).  
          subtitle - подзаголовок виджета (строка).  
          source\_id - ID источника (показателя или выборки) в текстовом формате (строка).  
          group\_aggregate\_type - тип агрегирования внутри группы (строка).  
          indicator\_title - заголовок индикатора (строка).  
          gauge\_title - заголовок датчика (строка).  
          gauge\_zone\_type - тип зон датчика (строка).  
          table\_column\_name\_title - заголовок столбца таблицы (строка).  
          line\_title - заголовок линии (строка).  
          source\_params - переменные (массив объектов). Каждый объект массива может включать в себя следующие данные: name - название переменной (строка); value значение переменной в текстовом формате (строка).  
          result - переменные результата (объект). В состав объекта могут входить следующие параметры: name - значение переменной "Название" (строка); value - значение переменной "Значение" в текстовом формате (строка).  
          filter - данные фильтра (объект). В состав объекта могут входить следующие параметры: start\_date - начало диапазона (дата); finish\_date - конец диапазона (дата); group - период группировки данных ( day, week, month, year, all ) (строка); period - название периода диапазона (строка).  
          segmentation - данные сегментации (объект). В состав объекта могут входить следующие параметры: object\_items - ID объектов в текстовом формате (массив строк); structure\_items - информация о подразделениях и сотрудниках (массив объектов) (в частности: id - ID объекта в текстовом формате (строка); type - тип элемента (position, org, subdivision) (строка); include\_children - учитывать ли дочерние подразделения вниз по иерархии (булево) и др.).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAnalytics", "GetDashboardDataById", [id]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
