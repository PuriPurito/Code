## GetCollaboratorsByStructureItems

Метод **GetCollaboratorsByStructureItems** предназначен для получения списка ID сотрудников и условий отбора по полученным элементам оргструктуры.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAnalytics", "GetCollaboratorsByStructureItems", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _structure\_items_ \- массив данных о подразделениях и сотрудниках (массив объектов). Атрибуты объектов: id - ID объекта в строковом выражении (строка); type - тип элемента ('position', 'org', 'subdivision') (строка); include\_children - учитывать дочерние подразделения вниз по иерархии (булево). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные объекта, а также ряд дополнительных атрибутов:  
\- _data_ \- данные объекта:  
     _collaborator\_ids_ \- перечень ID сотрудников (массив целых чисел).   
     _condition_ \- условие отбора (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAnalytics", "GetCollaboratorsByStructureItems", [structure_items]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
