## CreateDashboard

Метод **CreateDashboard** предназначен для создания дашборда с учетом переданных данных.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAnalytics", "CreateDashboard", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _data_ \- данные дашборда (объект). Атрибуты объекта: default\_code - код дашборда, на основе данных которого будет создаваться текущий дашборд (строка); order - порядковый номер (целое число); name - название дашборда (строка); description - описание дашборда (строка); code - код дашборда (строка); view - количество отображаемых столбцов (в строковом выражении) (строка); category\_id - ID категории (строка); object\_id ID объекта (строка); widgets - коды виджетов по умолчанию (массив строк); prevent\_ordering - не производнить сортировку дашбордов и виджетов после добавления (булево). 

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _id_ \- ID созданного дашборда в строковом формате (строка).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAnalytics", "CreateDashboard", [data]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
