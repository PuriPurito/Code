## GetPersonnelDocumentFiles

Метод **GetPersonnelDocumentFiles** предназначен для получения списка файлов кадрового документа.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPersonnelDocument", "GetPersonnelDocumentFiles", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iPersonnelDocumentID_ \- ID кадрового документа (целое число).  
     _bWithInsert_ – нужно ли сделать активной ссылку на файл с печатью (булево).  
     _bLinkToSave_ \- нужно ли сделать активной ссылку на скачивание файла (булево).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень файлов кадрового документа, а также ряд дополнительных атрибутов:  
\- _array_ - массив файлов кадрового документа (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID файла в строковом формате (строка).  
     _name_ – название файла (строка).  
     _file\_url_ – ссылка на файл (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPersonnelDocument", "GetPersonnelDocumentFiles", [iPersonnelDocumentID, bWithInsert, bLinkToSave]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
