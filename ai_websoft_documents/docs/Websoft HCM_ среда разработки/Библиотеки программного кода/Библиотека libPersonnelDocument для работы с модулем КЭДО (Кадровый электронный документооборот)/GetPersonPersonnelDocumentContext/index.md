## GetPersonPersonnelDocumentContext

Метод **GetPersonPersonnelDocumentContext** предназначен для получения контекста сотрудника по КЭДО.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPersonnelDocument", "GetPersonPersonnelDocumentContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _iApplicationID_ \- ID приложения (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит контекст сотрудника по КЭДО, а также ряд дополнительных атрибутов:  
\- _context_ \- контекст сотрудника по КЭДО (объект).  
     Атрибуты объекта:  
     _iActiveDocument_ – количество подписанных документов (целое число).  
     _iProcessDocument_ – количество документов на подписании (целое число).  
     _bEcp_ – имеется ли ЭЦП (булево).  
     _bUnepEcp_ – имеется ли усиленная неквалифицированная электронная подпись (УНЭП)  (булево).  
     _bUkepEcp_ – имеется ли усиленная квалифицированная электронная подпись (УКЭП)  (булево).  
     _bUkep_ \- используется ли усиленная квалифицированная электронная подпись (УКЭП) (булево).  
     _bAgreement_ \- имеется ли согласие на кадровый электронный документ (КЭДО) (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPersonnelDocument", "GetPersonPersonnelDocumentContext", [iPersonID, iApplicationID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
