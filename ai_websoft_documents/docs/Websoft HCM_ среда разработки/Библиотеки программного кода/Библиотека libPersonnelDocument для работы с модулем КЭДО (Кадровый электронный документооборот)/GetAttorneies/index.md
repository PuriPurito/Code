## GetAttorneies

Метод **GetAttorneies** предназначен для получения списка доверенностей.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPersonnelDocument", "GetAttorneies", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя восемь параметров:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _sAccessTypeId_ \- ID типа прав доступа для отбора (строка).  
     _sApplication_ \- код/ID приложения, по которому определяется доступ (строка).  
     _aStates_ \- перечень статусов для отбора (массив строк).  
     _sFilter_ \- строка, содержащая условия из фильра (строка).  
     _sSearch_ \- дополнительный критерий полнотекстового поиска в формате XQuery для отбора (строка).  
     _oPaging_ \- информация из рантайма о пейджинге (JSON объект).  
     _oSort_ \- информация из рантайма о сортировке (JSON объект). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень доверенностей, а также ряд дополнительных атрибутов:  
\- array - массив доверенностей (массив объектов).  
     Атрибуты отдельного объекта:  
     id – ID доверенности (целое число);  
     person\_id – ID сотрудника (целое число);  
     person\_fullname – ФИО сотрудника (строка);  
     org\_id – ID организации (целое число);  
     org\_name – название организации (строка);  
     essential\_id – ID юридического лица (строка);  
     essential\_name – название юридического лица (строка);  
     state\_id – ID состояния (строка);  
     state\_name – название состояния (строка);  
     start\_date – начало действия (дата);  
     end\_date – окончание действия (дата);  
     upload – загружена ли доверенность в текчтоыом выражении (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPersonnelDocument", "GetAttorneies", [iPersonID, sAccessTypeId, sApplication, aStates, sFilter, sSearch, oPaging, oSort]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
