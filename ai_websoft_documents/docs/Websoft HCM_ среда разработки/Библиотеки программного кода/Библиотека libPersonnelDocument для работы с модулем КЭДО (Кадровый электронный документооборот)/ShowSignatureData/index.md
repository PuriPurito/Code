## ShowSignatureData

Метод **ShowSignatureData** предназначен для получения данных подписи кадрового документа.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPersonnelDocument", "ShowSignatureData", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iUserID_ \- ID сотрудника (целое число).  
     _iPersonnelDocumentID_ \- ID кадрового документа (целое число).  
     _SCOPE\_WVARS_ \- JSON-объект с параметрами удаленного действия (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные подписи кадрового документа, а также ряд дополнительных атрибутов:  
\- _action\_result_ \- данные подписи кадрового документа (объект).  
     Атрибуты объекта:  
     _person\_code_ – код пользователя (сотрудника) (строка);  
     _person\_fullname_ – ФИО пользователя (сотрудника) (строка);  
     _person\_position\_name_ \- должность сотрудника на момент подписания (строка);  
     _person\_subdivision\_name_ – подразделение сотрудника на момент подписания (строка);  
     _date_ – дата подписи в строковом выражении (строка);  
     _subject_ – название сертификата (строка);  
     _issuer_ – орган, выдавший сертификат (строка);  
     _not_ – период действия сертификата в строковом выражении (строка);  
     _id_ – ID (серийный номер) сертификата в строковом выражении (строка);  
     _type_ – тип сертификата (строка);  
     _signature_ – электронная подпись (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPersonnelDocument", "ShowSignatureData", [iUserID, iPersonnelDocumentID, SCOPE_WVARS]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
