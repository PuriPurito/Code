## GetPersonByPersonnelDocumentContext

Метод **GetPersonByPersonnelDocumentContext** предназначен для получения контекста сотрудника по кадровому документу.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPersonnelDocument", "GetPersonByPersonnelDocumentContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _iPersonnelDocumentID_ \- ID кадрового документа (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит контекст сотрудника по кадровому документу, а также ряд дополнительных атрибутов:  
\- _context_ - контекст сотрудника (объект).  
     Атрибуты объекта:  
     _bCanSignature_ – может ли сотрудник подписать документ (булево).  
     _bMimeFile_ – имеется ли mime-файл (булево).  
     _bCanViewCard_ – имеется ли у сотрудника право на просмотр документа (булево).  
     _dPersonDate_ – дата подписания сотрудником (дата).  
     _dOrgDate_ – дата подписания организацией (дата).  
     _sPersonSignature_ –имеется ли подпись сотрудника (_"да"/"нет"_) (строка).  
     _sOrgSignature_ – собраны или нет все необходимые подписи от организации (_"да"/"нет"_) (строка).  
     _sPersonFullname_ – ФИО создателя документа (строка).  
     _iFilesCount_ – количество прикрепленных к документу файлов (целое число).  
     _sEssentialName_ – название юридического лица организации, к которому относится основная должность сотрудника (строка).  
     _sManagerFullname_ – ФИО непосредственного руководителя сотрудника (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPersonnelDocument", "GetPersonByPersonnelDocumentContext", [iPersonID, iPersonnelDocumentID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
