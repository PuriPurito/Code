## GetPersonPersonnelDocuments

Метод **GetPersonPersonnelDocuments** предназначен для получения списка кадровых документов сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPersonnelDocument", "GetPersonPersonnelDocuments", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя тринадцать параметров:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _arrStates_ \- массив статусов документа для отбора (массив строк) (необязательный).  
     _sType_ \- тип отбора (строка) (необязательный). Доступные значения - _"my"_ (кадровые документы сотрудника), _"on\_signature"_ (документы на подписи), _"not\_person\_signature"_ (неподписанные документы), _"all"_ (все документы). Значение по умолчанию - _"my"_.  
     _sAccessType_ \- роль доступа для отбора (строка) (необязательный).  
     _sFilter_ \- фильтр XQuery для отбора (строка) (необязательный).  
     _sSearch_ \- критерий полнотекстового поиска для отбора (строка) (необязательный).  
     _sApplicationID_ \- ID (код) приложения в текстовом формате для отбора (строка) (необязательный).  
     _tePerson_ \- TopElem сотрудника для отбора (объект XmlDoc).  
     _iCollaboratorID_ \- ID сотрудника для отбора (фильтрации) (целое число) (необязательный).  
     _bShowWithoutCompanySign_ \- показывать HR документы, не подписываемые организацией (булево) (необязательный). Значение по умолчанию – true.  
     _iStartIndex_ \- стартовая позиция в списке (целое число).  
     _iPageSize_ \- размер страницы (целое число).  
     _oSort_ \- информация из рантайма о сортировке (JSON объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень кадровых документов сотрудника, а также ряд дополнительных атрибутов:  
\- array - массив кадровых документов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID документа (целое число).  
     _name_ – название документа (строка).  
     _personnel\_document\_type\_name_ – название типа документа (строка).  
     _person\_fullname_ – ФИО сотрудника (строка).  
     _state\_name_ – название статуса (строка).  
     _state\_id_ – ID статуса в строковом формате (строка).  
     _create\_date_ – дата создания в строковом формате (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPersonnelDocument", "GetPersonPersonnelDocuments", [iPersonID, arrStates, sType, sAccessType, sFilter, sSearch, sApplicationID, tePerson, iCollaboratorID, bShowWithoutCompanySign, iStartIndex, iPageSize, oSort]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
