## GetPersonEcpKeys

Метод **GetPersonEcpKeys** предназначен для получения списка ключей ЭЦП сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPersonnelDocument", "GetPersonEcpKeys", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _tePerson_ \- TopElem сотрудника (объект XmlDoc).  
     _bOnlyValid_ \- только действующие сертификаты (булево). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит список ключей ЭЦП сотрудника, а также ряд дополнительных атрибутов:  
\- _array_ - массив ключей ЭЦП (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID подписи (серийный номер) (строка).  
     _name_ \- наименование подписи (строка).  
     _start\_date_ \- начало действия (дата).  
     _finish\_date_ \- завершение действия (дата).  
     _issuer_ \- орган, выдавший сертификат на подпись (строка).  
     _type\_name_ – название типа сертификата подписи (УКЭП/УНЭП).  
     _type\_id_ – ID типа сертификата подписи (УКЭП/УНЭП) в текстовом формате.   
     _private\_key_ – имеется ли закрытый ключ (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPersonnelDocument", "GetPersonEcpKeys", [iPersonID, tePerson, bOnlyValid]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
