## Библиотека API для системы тестирования (MainTest) libTestingSystemMainTestAPI

В настоящем разделе описываются методы **библиотеки API для системы тестирования (MainTest)** из библиотеки программного кода **libTestingSystemMainTestAPI**. Указанные методы регистрируются в разделе **Дизайнер – Библиотеки программного кода – libTestingSystemMainTestAPI**.

Подробнее о системе тестирования MainTest - см. здесь.

Для вызова метода из библиотеки используется функция tools.call\_code\_library\_method.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTestingSystemMainTestAPI", <sMethodNameParam>, <arrParams>)**

_Аргументы:_  
     _<sMethodNameParam> (обязательный)_  
      Тип: **Строка**. Название вызываемого метода.  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.
