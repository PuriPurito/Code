## GetBossEduLearnings

Метод **GetBossEduLearnings** предназначен для получения интегральной информации по учебным активностям сотрудников (подчиненных).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLearning", "GetBossEduLearnings", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _sActivityType_ \- тип активности (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит интегральную информацию по учебным активностям сотрудников (подчиненных), а также ряд дополнительных атрибутов:  
\- _array_ \- массив данных по обучению (массив объектов).  
     Атрибуты отдельного объекта:  
     _name_ – название объекта (строка);  
     _assign\_type_ – тип назначения (строка);  
     _is\_recomended_ – является ли обучение рекомендованным (булево);  
     _status_ – наименование статуса прохождения (строка);  
     _start\_date_ – дата начала (дата);  
     _finish\_date_ – дата окончания (дата);  
     _learn\_type\_filter_ – тип обучения (строка);  
     _assign\_type\_filter_ – фильтр для поиска (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLearning", "GetBossEduLearnings", [iPersonID, sActivityType]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
