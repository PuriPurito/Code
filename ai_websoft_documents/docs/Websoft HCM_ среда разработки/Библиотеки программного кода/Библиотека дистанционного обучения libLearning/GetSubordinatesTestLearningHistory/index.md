## GetSubordinatesTestLearningHistory

Метод **GetSubordinatesTestLearningHistory** предназначен для получения истории обучения подчиненных сотрудников по указанному тесту.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLearning", "GetSubordinatesTestLearningHistory", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iTestID_ \- ID теста (целое число).  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _bShowSubordinateEmployeesTests_ \- показывать историю прохождения тестов подчиненных сотрудников (булево). По умолчанию – _false_. 

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит выборку истории обучения подчиненных сотрудников по указанному тесту, а также ряд дополнительных атрибутов:  
\- _array_ \- массив прохождений тестов подчиненными сотрудниками (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID прохождения теста (целое число);  
     _fullname_ – ФИО сотрудника, проходившего тест (строка);  
     _last\_learning\_date_ – дата последнего прохождения (дата);  
     _status\_id_ \- ID статуса (целое число);  
     _status_ \- значение статуса (строка);  
     _state\_code_ \- код статуса (строка);  
     _score_ – количество набранных баллов (целое число);  
     _link_ – относительная ссылка на прохождение теста (строка).  
     _link\_report_ – относительная ссылка на отчет о прохождении теста (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLearning", "GetSubordinatesTestLearningHistory", [ iTestID, iCurUserID, bShowSubordinateEmployeesTests ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
