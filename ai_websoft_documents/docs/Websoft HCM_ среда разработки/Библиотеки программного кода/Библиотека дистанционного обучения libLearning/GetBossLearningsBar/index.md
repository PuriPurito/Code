## GetBossLearningsBar

Метод **GetBossLearningsBar** предназначен для получения информации для гистограммы динамики обучения по курсам/тестам.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLearning", "GetBossLearningsBar", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iPersonID_ - ID сотрудника (целое число).  
     _sActivityType_ \- тип активности (строка).  
     _iPeriodNum_ \- количество периодов (целое число).  
     _sPeriodType_ \- тип периода (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию для гистограммы динамики обучения по курсам/тестам, а также ряд дополнительных атрибутов:  
\- _array_ \- массив информации для гистограммы (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID объекта (курса, теста и т.д.) (целое число);  
     _label_ – заголовок (строка);  
     _bar\_bgcolor_ – цвет (строка);  
     _bar\_border\_color_ – цвет границы (строка);  
     _coordinates_ – JSON-координаты массива данных (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLearning", "GetBossLearningsBar", [iPersonID, sActivityType, iPeriodNum, sPeriodType]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
