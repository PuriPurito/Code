## GetCourseContext

Метод **GetCourseContext** предназначен для получения контекста по курсу.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLearning", "GetCourseContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iCourseID_ \- ID курса (целое число).   
     _bCalcHeavy_ \- признак вычисления нагруженных показателей (средний процент баллов и среднее время) (булево). Значение по умолчанию - _false_.  
     _iCurUserID_ \- ID пользователя для поддержки ролевой модели (целое число).   
     _sAppCode_ \- код приложения для поддержки ролевой модели (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные контекста по курсу, а также ряд дополнительных атрибутов:  
\- _context_ \- контекст по курсу (объект).  
     Атрибуты отдельного объекта:  
     _active\_learning\_count_ – количество активных сессий (целое число);  
     _assigned\_count_ – количество назначений (целое число);  
     _person\_count_ – количество сотрудников, которым было назначено обучение (целое число);  
     _person\_count\_learning_ – количество сотрудников, прошедших обучение (целое число);  
     _percent\_complete_ – процент завершенных курсов от числа назначений (целое число);  
     _complete\_success_ – количество успешно завершенных курсов (целое число);  
     _percent\_complete\_success_ – процент успешно завершенных курсов от всех завершенных (целое число);  
     _percent\_complete\_overdue_ – процент завершенного не в срок обучения (целое число);  
     _complete\_overdue_ – количество назначений (активных и пройденных), не уложившихся в срок обучения (целое число);  
     _active\_overdue_ – количество активных курсов, не завершенных в срок обучения (целое число);  
     _complete\_only\_overdue_ – количество завершенных курсов, оконченных не в срок обучения (целое число);  
     _percent\_active\_overdue_ – процент активных курсов, не завершенных в срок обучения (целое число);  
     _percent\_complete\_only\_overdue_ – процент завершенных курсов, оконченных не в срок обучения (целое число);  
     _percent\_average\_score_ – средний процент набранных баллов по завершенному обучению (целое число);  
     _response\_count_ – количество заполненных анкет обратной связи (целое число);  
     _percent\_response_ – процент заполнения анкет обратной связи (целое число);  
     _average\_response_ – средний балл оценки в анкетах обратной связи (целое число);  
     _time\_average_ – среднее время на прохождение курса (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_      _oRes = tools.call_code_library_method ("libLearning", "GetCourseContext", [iCourseID, bCalcHeavy, iCurUserID, sAppCode]);_`   
  
`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
