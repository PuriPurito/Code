## GetFinishCourseContext

Метод **GetFinishCourseContext** предназначен для получения контекста завершенной сессии обучения (законченного электронного курса).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLearning", "GetFinishCourseContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _iFinishedCourseID_ \- ID законченного электронного курса (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о контексте завершенной сессии обучения (законченного электронного курса), а также ряд дополнительных атрибутов:  
\- context - контекст завершенной сессии обучения (объект).  
     Атрибуты объекта:  
     _bIsSuccess_ – установлен ли статус законченного курса «Пройден» (булево).  
     _bHasResponseToDo_ – нет отзыва на пройденный курс (булево).  
     _bHasResponseRequiredToDo_ – нет обязательного отзыва на пройденный курс (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLearning", "GetFinishCourseContext", [iFinishedCourseID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
