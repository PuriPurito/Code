## GetBossLearningsCount

Метод **GetBossLearningsCount** предназначен для определения количества активностей указанного типа.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLearning", "GetBossLearningsCount", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _sActivityType_ \- тип активности (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о количестве активностей указанного типа, а также ряд дополнительных атрибутов:  
\- _array_ \- массив данных о количестве активностей указанного типа (массив целых чисел).  
     Атрибуты отдельного объекта:  
     _object\_id_ \- ID объекта (целое число);  
     _img_ – относительная ссылка на изображение объекта (строка);  
     _name_ – название объекта (строка);  
     _count_ – количество активностей указанного типа (целое число);

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLearning", "GetBossLearningsCount", [iPersonID, sActivityType]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
