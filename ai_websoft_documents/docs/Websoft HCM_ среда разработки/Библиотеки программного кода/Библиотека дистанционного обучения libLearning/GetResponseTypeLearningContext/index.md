## GetResponseTypeLearningContext

Метод **GetResponseTypeLearningContext** предназначен для получения контекста по типу отзыва.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLearning", "GetResponseTypeLearningContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iResponseTypeID_ \- ID типа отзыва (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит контекст по типу отзыва, а также ряд дополнительных атрибутов:   
\- _context_ \- информация по контексту (объект). Атрибуты объекта:  
     _response\_count_ – количество заполненных отзывов данного типа (целое число);  
     _person\_count_ – количество сотрудников (уникальных), заполнивших отзывы (целое число);  
     _course\_assigned\_count_ – количество курсов, по которым назначен данный тип отзыва (целое число);  
     _course\_count_ – количество курсов, по которым есть заполненные отзывы (целое число);  
     _percent\_response_ – процент заполнения анкет обратной связи (целое число) (только для курсов, у которых определен данный тип отзыва);  
     _create\_date\_last_ – дата последнего заполнения отзыва (дата).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLearning", "GetResponseTypeLearningContext", [iResponseTypeID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
