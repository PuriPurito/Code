## GetCourseLearningActions

Метод **GetCourseLearningActions** предназначен для получения списка действий курса.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLearning", "GetCourseLearningActions", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _iCourseID_ \- ID курса (целое число).  
     _sRequestTypeCode_ \- код типа заявки (строка). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень действий курса, а также ряд дополнительных атрибутов:  
\- _array_ \- массив действий курса (массив объектов).  
     Атрибуты отдельного объекта:  
     _id, action\_id_ \- идентификаторы действия (строка) (возможные значения: "start\_learning", "continue\_learning", "create\_request" и др.)  
     _title_ – название действия (строка) (возможные значения: "Начать", "Продолжить", "Создать заявку" и др.

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLearning", "GetCourseLearningActions", [ iPersonID, iCourseID, sRequestTypeCode ]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
