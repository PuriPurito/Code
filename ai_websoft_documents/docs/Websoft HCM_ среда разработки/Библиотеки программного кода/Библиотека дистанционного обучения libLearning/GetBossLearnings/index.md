## GetBossLearnings

Метод **GetBossLearnings** предназначен для получения информации с данными курсов/тестов без агрегации для табличного представления панели руководителя.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLearning", "GetBossLearnings", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _sActivityType_ \- тип активности (строка).  
     _oCollectionParams_ \- набор интерактивных параметров выборки (объект). В состав объекта могут входить следующие параметры: paging (пейджинг, настройка страниц) (объект) (возможные параметры настройки страниц: paging.INDEX - номер страницы (целое число);  paging.SIZE - размер страницы (целое число); paging.START\_INDEX - номер начального элемента текущей страницы (окна выборки); paging.MANUAL - разделение на страницы вручную (булево); paging.TOTAL - общее количество страниц (целое число)), sort (сортировка) (объект) (sort.FIELD - название поля, по которому производится сортировка (строка), sort.DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)), distincts (дополнительная входная информация) (массив строк), filters (фильтры) (массив объектов) (возможные параметры фильтрации: filter.type - тип фильтрации (строка) (например: 'search' (поиск), filter.value - критерий фильтрации (строка), filter.id - идентификатор (имя) фильтра (строка))), fulltext - критерий выборки (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию с данными курсов/тестов без агрегации для табличного представления панели руководителя, а также ряд дополнительных атрибутов:  
\- _array_ \- массив данных по обучению (массив объектов).  
     Атрибуты отдельного объекта:  
     _img_ – отностительная ссылка на изображение (аватар) сотрудника (строка);  
     _person\_name_ – ФИО сотрудника (строка);  
     _person\_position\_name_ \- наименование должности сотрудника (строка);  
     _person\_link_ – относительная ссылка на карточку сотрудника (строка);  
     _name_ – название объекта обучения (строка);  
     _link_ – относительная ссылка на карточку объекта обучения (строка);  
     _status\_id_ – ID статуса прохождения объекта обучения (целое число);  
     _status\_name_ – наименование статуса прохождения объекта обучения (строка);  
     _provider\_name_ – провайдер объекта обучения (строка);  
     _is\_passed_ – пройден ли объект обучения (булево);  
     _start\_learning\_date_ – дата начала обучения (дата);  
     _last\_usage\_date_ – дата последнего посещения (дата);  
     _time_ – длительность обучения в часах (целое число);  
     _role\_names_ – наименования категорий (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLearning", "GetBossLearnings", [iPersonID, sActivityType, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
