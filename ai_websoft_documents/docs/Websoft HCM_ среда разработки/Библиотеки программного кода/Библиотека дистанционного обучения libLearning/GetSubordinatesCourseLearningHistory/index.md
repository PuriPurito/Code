## GetSubordinatesCourseLearningHistory

Метод **GetSubordinatesCourseLearningHistory** предназначен для получения истории обучения подчиненных сотрудников по указанному курсу.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLearning", "GetSubordinatesCourseLearningHistory ", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iCourseID_ \- ID электронного курса (целое число).  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     oSort - информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).  
     oPaging - информация из рантайма о пейджинге (объект). Объект включает в себя следующие данные:  INDEX - номер страницы (целое число);  SIZE - размер страницы (целое число); MANUAL - разделение на страницы вручную (булево); TOTAL - общее количество страниц (целое число).

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит выборку истории обучения подчиненных сотрудников по указанному курсу, а также ряд дополнительных атрибутов:  
\- _array_ \- массив прохождений курсов подчиненными сотрудниками (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID прохождения курса (целое число);  
     _fullname_ – ФИО сотрудника, проходившего курс (строка);  
     _last\_learning\_date_ – дата последнего прохождения (дата);  
     _status_ - значение статуса (строка);  
     _state\_code_ - код статуса (строка);  
     _score_ – количество набранных баллов (целое число);  
     _link_ – относительная ссылка на прохождение курса (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).  
\- _paging_ \- информация о пагинации (объект). 

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLearning", "GetSubordinatesCourseLearningHistory ", [ iCourseID, iCurUserID, oSort, oPaging  ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
