## GetBossLearningsStat

Метод **GetBossLearningsStat** предназначен для получения информации об активностях по типу и способу назначения.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLearning", "GetBossLearningsStat", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _sActivityType_ \- тип активности (строка).  
     _sAssignMode_ \- способ назначения (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию об количестве активностей по типу и способу назначения, а также ряд дополнительных атрибутов:  
\- _array_ \- массив данных о количестве активностей (массив целых чисел).  
     Атрибуты отдельного объекта:  
     _person\_id_ \- ID сотрудника (целое число);  
     _img_ – относительная ссылка на изображение (строка);  
     _name_ – ФИО сотрудника (строка);  
     _count_ – количество активностей указанного типа и способа назначения (целое число);  
     _success_ – количество активностей, завершенных успешно (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLearning", "GetBossLearningsStat", [iPersonID, sActivityType, sAssignMode]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
