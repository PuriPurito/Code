## GetTestLearningLastAttemptsNum

Метод **GetTestLearningLastAttemptsNum** предназначен для получения количества неиспользованных попыток в тесте.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLearning", "GetTestLearningLastAttemptsNum", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iObjectID_ \- ID объекта (теста) (целое число).  
     _iPersonID_ \- ID сотрудника, сдававшего тест (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень тестов, которые были назначены участникам мероприятия, а также ряд дополнительных атрибутов:  
\- _result_ – количество неиспользованных попыток в тесте (целое число).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_`  
`_oRes = tools.call_code_library_method ("libLearning", "GetTestLearningLastAttemptsNum", [iObjectID, iPersonID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
