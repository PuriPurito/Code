## GetGroupLearnings

Метод **GetGroupLearnings** предназначен для получения списка завершенных (незавершенных) группой сотрудников курсов (тестов).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLearning", "GetGroupLearnings", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя девять параметров:  
     _iGroupID_ \- ID группы (целое число).  
     _sSearch_ \- строка для поиска (строка).  
     _sFilter_ \- строка для фильтра (строка).  
     _bShowPercentScore_ \- показывать ли соотношение набранных баллов к максимальному (булево).  
     _sType_ \- тип активности (строка). Допустимые значения: _learnings, learnings\_all_ \- законченные/незаконченные курсы; _test\_learnings, test\_learning\_all_ \- законченные/незаконченные тесты.  
     _sTypeLink_ \- тип ссылки (ссылка на карточку активного курса/теста или запуск плеера курса/теста) (строка) (необязательный).  
     _sCurrencyType_ \- тип валюты, по которой подсчитываются награды за прохождение курсов/тестов (строка). По умолчанию - _'experience'_.  
     oSort - информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).  
     oPaging - информация из рантайма о пейджинге (объект). Объект включает в себя следующие данные:  INDEX - номер страницы (целое число);  SIZE - размер страницы (целое число); MANUAL - разделение на страницы вручную (булево); TOTAL - общее количество страниц (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень завершенных (незавершенных) группой сотрудников курсов (тестов), а также ряд дополнительных атрибутов:  
\- _array_ - массив завершенных (незавершенных) курсов или тестов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID курса/теста (целое число).  
     _person\_fullname_ \- ФИО сотрудника (строка).  
     _name_ \- название курса/теста (строка).  
     _img\_url_ \- ссылка на изображение курса/теста (строка).  
     _start\_usage\_date_ \- дата активации назначения курса/теста (дата).  
     _start\_learning\_date_ \- начало обучения (дата).  
     _last\_usage\_date_ \- дата последнего посещения курса/теста (дата).  
     _score_ \- количество набранных баллов (целое число).  
     _percent\_score_ \- процент набранных баллов от максимального (строка).  
     _state_ \- состояние курса/теста (строка) (например, 'Назначен', 'В процессе', 'Завершен', 'Не пройден', 'Пройден', 'Просмотрен').  
     _link_ \- ссылка на карточку курса/теста (строка).  
     _status\_learning_ \- статус курса/теста (строка) (например, 'Изученные', 'Изучаемые', 'Завершенные', 'Текущие').  
     _type\_assign_ \- тип назначения курса/теста (строка) (например, 'По собственной инициативе', 'Обязательный').  
     _is\_recommended_ \- рекомендован ли сотруднику курс/тест (булево).  
     _combo\_type\_assign_ \- комплексная информация о типе назначения и рекомендации курса/теста (строка).  
     _sum\_points_ \- суммарное количество пунктов в указанной в аргументах валюте для определения награды (целое число).

\- _paging_ \- информация о пагинации (объект).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLearning", "GetGroupLearnings", [iGroupID, sSearch, sFilter, bShowPercentScore, sType, sTypeLink, sCurrencyType, oSort, oPaging]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
