## GetPersonActivityLearningTest

Метод **GetPersonActivityLearningTest** предназначен для выполнения расчета объектной метрики активности сотрудника по курсам/тестам.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLearning", "GetPersonActivityLearningTest", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _iObjectID_ \- ID объекта (курса или теста) (целое число).   
     _bReturnBestResult_ - нужно ли возвращать данные последней успешной попытки (булево).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию об активности по курсам/тестам:  
\- _array_ \- массив данных об активности (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID курса/теста (целое число).  
     _name_ \- наименование курса/теста (строка).  
     _state\_id_ \- ID статуса курса/теста (строка).  
     _state\_name_ \- статус курса/теста (строка).  
     _active\_type_ – тип активности (строка) (_none_ - тип активности не указан, _complete_ – законченный курс/тест, _active_ \- незаконченный курс/тест).  
     _start\_usage\_date_ – дата активации (дата).  
     _start\_learning\_date_ – дата начала обучения (дата).  
     _max\_end\_date_ – дата планируемого завершения (дата).  
     _last\_usage\_date_ – дата последнего посещения (дата).  
     _score_ – количество баллов (целое число).  
     _percent\_score_ – процентное соотношение набранных баллов к максимально возможному количеству баллов (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLearning", "GetPersonActivityLearningTest", [iPersonID, iObjectID, bReturnBestResult]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
