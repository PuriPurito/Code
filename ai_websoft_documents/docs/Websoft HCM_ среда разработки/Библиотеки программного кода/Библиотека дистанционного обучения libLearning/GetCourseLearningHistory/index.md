## GetCourseLearningHistory

Метод **GetCourseLearningHistory** предназначен для получения истории обучения по указанному курсу (истории прохождения курса).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLearning", "GetCourseLearningHistory", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.  
     Массив включает в себя девять параметров:  
     _iCourseID_ \- ID электронного курса (целое число).  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _bShowSubordinateEmployeesCourses_ \- показывать историю прохождения курсов подчиненных сотрудников (булево) (необязательно). По умолчанию – _false._  
     _bShowActive_ \- показывать ли только незаконченные курсы (булево) (необязательно). По умолчанию – _false._  
     _sAppCode_ \- код приложения для поддержки ролевой модели (строка).  
     _sAccessType_ \- тип доступа для выполнения операций (строка) (необязательный). Доступные значения: _'auto', 'observer', 'expert', 'manager', 'hr', 'admin'._ По умолчанию - _'auto'._  
     PAGING - информация из рантайма о пейджинге (объект). Объект включает в себя следующие данные:  INDEX - номер страницы (целое число);  SIZE - размер страницы (целое число); MANUAL - разделение на страницы вручную (булево); TOTAL - общее количество страниц (целое число).  
     _SORT_ - информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).  
     _sFilter_ \- строка для фильтра (строка).

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит выборку истории обучения по указанному курсу (истории прохождения курса), а также ряд дополнительных атрибутов:  
\- _array_ \- массив прохождений курсов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID прохождения курса (целое число);  
     _course\_id_ \- ID курса (целое число);  
     _name_ \- название курса (строка);  
     _fullname_ – ФИО сотрудника, проходившего курс (строка);  
     _activate\_date_ – дата начала прохождения (дата);  
     _finish\_date_ – дата завершения прохождения (дата);  
     _status_ – статус курса (строка);  
     _score_ – количество набранных баллов (целое число);  
     _link_ – относительная ссылка на прохождение курса (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLearning", "GetCourseLearningHistory", [iCourseID, iCurUserID, bShowSubordinateEmployeesCourses, bShowActive, sAppCode, sAccessType, PAGING, SORT, sFilter]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
