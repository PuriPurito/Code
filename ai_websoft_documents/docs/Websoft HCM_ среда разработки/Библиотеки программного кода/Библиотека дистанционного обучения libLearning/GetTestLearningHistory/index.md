## GetTestLearningHistory

Метод **GetTestLearningHistory** предназначен для получения истории обучения по указанному тесту (истории прохождения теста).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLearning", "GetTestLearningHistory", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя восемь параметров:  
     _iTestID_ \- ID теста (целое число).  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _bShowSubordinateEmployeesTests_ \- показывать историю прохождения тестов подчиненных сотрудников (булево) (необязательно). По умолчанию – _false_.  
     _bShowActive_ \- показывать ли только незаконченные курсы (булево) (необязательно). По умолчанию – _false_.  
     _sAppCode_ \- код приложения для поддержки ролевой модели (строка).  
     _sAccessType_ \- тип доступа для выполнения операций (строка) (необязательный). Доступные значения: _'auto', 'observer', 'expert', 'manager', 'hr', 'admin'_. По умолчанию - _'auto'_.  
     PAGING - информация из рантайма о пейджинге (объект). Объект включает в себя следующие данные:  INDEX - номер страницы (целое число);  SIZE - размер страницы (целое число); MANUAL - разделение на страницы вручную (булево); TOTAL - общее количество страниц (целое число).  
     SORT - информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит выборку истории обучения по указанному тесту, а также ряд дополнительных атрибутов:  
\- _array_ \- массив прохождений тестов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID прохождения теста (целое число);  
     _fullname_ – ФИО сотрудника, проходившего тест (строка);  
     _activate\_date_ – дата начала прохождения (дата);  
     _finish\_date_ – дата завершения прохождения (дата);  
     _status_ – статус теста (строка);  
     _score_ – количество набранных баллов (целое число);  
     _link_ – относительная ссылка на прохождение теста (строка).  
     _link\_report_ – относительная ссылка на отчет о прохождении теста (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLearning", "GetTestLearningHistory", [iTestID, iCurUserID, bShowSubordinateEmployeesTests, bShowActive, sAppCode, sAccessType, PAGING, SORT]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
