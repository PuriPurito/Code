## GetCourseResponseContext

Метод **GetCourseResponseContext** предназначен для получения контекста по курсу и по отзывам на курс.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLearning", "GetCourseResponseContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iCourseID_ – ID курса (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит контекст по курсу и по отзывам на курс, а также ряд дополнительных атрибутов:  
\- _context_ \- контекст по курсу (объект). В том числе:  
     _count\_learning_ – количество заверешенных сессий обучения (целое число);  
     _response\_count_ – количество заполненных анкет обратной связи (целое число);  
     _percent\_response_ – процент заполнения анкет обратной связи (целое число);  
     _average\_score_ – средняя оценка курса (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLearning", "GetCourseResponseContext", [iCourseID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
