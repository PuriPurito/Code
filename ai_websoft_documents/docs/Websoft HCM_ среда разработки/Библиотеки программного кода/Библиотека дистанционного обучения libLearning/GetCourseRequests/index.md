## GetCourseRequests

Метод **GetCourseRequests** предназначен для получения списка заявок на прохождение курса.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLearning", "GetCourseRequests", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iCourseID_ \- ID электронного курса (целое число).  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _bShowRequestsForApproval_ \- показывать руководителю список заявок, отправленных на согласование (булево). По умолчанию – _false_.  
     _oPaging_ \- информация из рантайма о пейджинге (объект) (в том числе: _oPaging.index_ \- номер страницы (целое число); _oPaging.size_ \- размер страницы (целое число)).

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит перечень заявок на прохождение курса, а также ряд дополнительных атрибутов:  
\- _array_ \- массив заявок на прохождение курса (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID заявки (целое число);  
     _date_ – дата формирования заявки (дата);  
     _code_ – код заявки (строка);  
     _fullname_ – ФИО сотрудника (строка);  
     _status_ – статус заявки (строка);  
     _link_ – относительная ссылка на заявку (строка).

\- _paging_ – информация о пейджинге (объект).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLearning", "GetCourseRequests", [ iCourseID, iCurUserID, bShowRequestsForApproval, oPaging ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
