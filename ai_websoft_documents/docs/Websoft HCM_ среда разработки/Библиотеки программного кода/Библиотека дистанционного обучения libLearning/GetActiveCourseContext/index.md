## GetActiveCourseContext

Метод **GetActiveCourseContext** предназначен для получения контекста сессии обучения (незаконченного электронного курса).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLearning", "GetActiveCourseContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _iActiveCourseID_ \- ID незаконченного электронного курса (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о контексте сессии обучения (незаконченного электронного курса), а также ряд дополнительных атрибутов:  
\- _context_ \- контекст сессии обучения (объект).  
     Атрибуты объекта:  
     _bIsDone_ – курс завершен (булево).  
     _bHasFiles_ – в электронном курсе имеются приложенные файлы (булево).  
     _bHasExpert_ – в электронном курсе указаны эксперты (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLearning", "GetActiveCourseContext", [iActiveCourseID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
