## GetGroupLearningContext

Метод **GetGroupLearningContext** предназначен для получения контекста по группе.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLearning", "GetGroupLearningContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iGroupID_ \- ID группы (целое число).  
     _oParam_ \- параметры контекста (объект) (необязательный).  
     _iCurUserID_ \- ID пользователя для поддержки ролевой модели (целое число).   
     _sAppCode_ \- код приложения для поддержки ролевой модели (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит контекст по группе, а также ряд дополнительных атрибутов:  
\- _context_ – информация о контексте обучения по группе (объект). Атрибуты объекта:  
     _collaborator\_count_ – количество сотрудников (целое число);  
     _active\_learning\_count_ – количество активных сессий обучения (целое число);  
     _learning\_all\_count_ – количество назначений (целое число);  
     _percent\_complete_ – процент завершенного обучения от числа назначений (целое число);  
     _percent\_complete\_success_ – процент успешно завершенного обучения от всех завершенных объектов (целое число);  
     _percent\_complete\_overdue_ – процент обучения, завершенного позднее установленного срока (целое число);  
     _percent\_average\_score_ – средний процент набранных баллов по завершенному обучению (целое число);  
     _response\_count_ – заполнено анкет обратной связи (целое число);  
     _percent\_response_ – процент заполнения анкет обратной связи (целое число);  
     _max\_last\_usage\_date_ – дата последней учебной активности (дата);  
     _max\_start\_usage\_date_ – дата последнего назначения обучения (дата);  
     _time\_average_ – среднее время, затрачиваемое на обучение в неделю (в секундах) (целое число)

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLearning", "GetGroupLearningContext", [iGroupID , oParam, iCurUserID, sAppCode]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
