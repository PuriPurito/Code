## GetTestRequests

Метод **GetTestRequests** предназначен для получения списка заявок на сдачу теста.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLearning", "GetTestRequests", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iTestID_ \- ID теста (целое число).  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _bShowRequestsForApproval_ \- показывать руководителю список заявок, отправленных на согласование (булево). По умолчанию – _false_.

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит перечень заявок на сдачу теста, а также ряд дополнительных атрибутов:  
\- _array_ \- массив заявок на прохождение теста (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID заявки (целое число);  
     _date_ – дата формирования заявки (дата);  
     _code_ – код заявки (строка);  
     _fullname_ – ФИО сотрудника (строка);  
     _status_ – статус заявки (строка);  
     _link_ – относительная ссылка на заявку (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLearning", "GetTestRequests", [ iTestID, iCurUserID, bShowRequestsForApproval ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
