## GetLibraryMaterials

Метод **GetLibraryMaterials** предназначен для получения списка материалов электронной библиотеки.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLibrary", "GetLibraryMaterials", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя тринадцать параметров:  
     _curUser_ \- ID пользователя (целое число).  
     _Mode_ \- тип результата (строка) (необязательный). Значение по умолчанию - "_library_".  
     _section\_id_ \- ID выбранного раздела (целое число) (необязательный).  
     _columns\_list_ \- коды необходимых столбцов, перечисленные через точку с запятой (;) (строка). Возможные значения кодов столбцов: _"name"_ (название), _"author"_ (автор), _"year"_ (год издания), _"has\_digital"_ (в электронном формате), _"has\_physical"_ (в физическом формате), _"status"_ (статус), _"cover"_ (обложка), _"view\_button"_ (кнопка просмотра), _"download\_button"_ (кнопка скачивания), _"link"_ (ссылка), _"download\_link"_ (ссылка для скачивания), _"view\_link"_ (ссылка для просмотра).  
     _filters_ – фильтры, перечисленные через точку с запятой (;) (строка) (необязательный). Возможные значения фильтров: _"search", "mattype", "viewtype"_.  
     _doc\_id_ \- ID документа портала (целое число).  
     _iRootID_ \- ID родительского раздела (целое число) (необязательный).  
     _iNDays_ \- количество дней (целое число).  
     _bCacheObjects_ – кеширование (булево) (необязательный). По умолчанию – _false_.  
     _bFlush_ \- сброс кеша (булево) (необязательный). По умолчанию – _false_.  
     _sort\_field_ \- поле сортировки (строка) (необязательный).  
     _bSortDesc_ \- сортировка в обратном порядке (булево) (необязательный). По умолчанию – _false_.  
     _sid_ \- ID сессии (целое число) (необязательный).  
     _paging_ \- информация из рантайма о пейджинге (JSON объект). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень материалов электронной библиотеки, а также ряд дополнительных атрибутов:  
\- _array_ \- массив результатов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID элемента (материала) (строка).  
     _name_ \- название материала (строка).  
     _author_ \- автор материала (строка).  
     _year_ \- год издания (строка).  
     _status_ \- статус (строка).  
     _cover_ \- обложка (строка).  
     _has\_digital_ \- материал имеется в цифровом формате (булево).  
     _has\_physical_ \- материал имеется в физическом формате (булево).

\- _columns_ \- массив столбцов (массив объектов).  
     Атрибуты отдельного объекта:  
     _data_ \- источник (строка).  
     _title_ \- заголовок столбца (строка).  
     _width_ \- ширина столбца (строка).  
     _type_ \- тип столбца (строка).  
     _sortable_ \- столбец сортируется (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLibrary", "GetLibraryMaterials", [curUser, Mode, section_id, columns_list, filters, doc_id, iRootID, iNDays, bCacheObjects, bFlush, sort_field, bSortDesc, sid, paging]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
