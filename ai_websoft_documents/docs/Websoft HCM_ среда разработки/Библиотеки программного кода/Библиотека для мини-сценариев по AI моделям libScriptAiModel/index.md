## Библиотека для мини-сценариев по AI моделям libScriptAiModel

В настоящем разделе представлена библиотека для мини-сценариев по AI моделям  (библиотека программного кода **libScriptAiModel**). Библиотека зарегистрирована в разделе **Дизайнер – Библиотеки программного кода – libScriptAiModel**.

Подробнее об использовании AI моделей – см. _здесь_.

Примечание - По состоянию на июнь 2024 г. библиотека предназначена исключительно для внутренних нужд системы и не содержит публичных методов.
