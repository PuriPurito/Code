## GetPersonContinuousFeedback

Метод **GetPersonContinuousFeedback** предназначен для получения списка результатов непрерывной обратной связи / отзывов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libContinuousFeedback", "GetPersonContinuousFeedback", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя семь параметров:  
     _iPersonID_ \- ID респондента (целое число).  
     _iInitiatorID_ \- ID инициатора (целое число).  
     _iObjectID_ \- ID оцениваемого (целое число).  
     _arrObjectTypes_ \- типы обьектов оцениваемого (массив строк).  
     _iApplicationID_ \- ID приложения, по которому определяется доступ (целое число).  
     _sApplicationAccessType_ \- роль, для которой отображается информация в приложении (строка).  
     _oCollectionParams_ \- набор интерактивных параметров выборки (объект). В состав объекта могут входить следующие параметры: paging (пейджинг) (объект), sort (сортировка) (объект), distincts (дополнительные поля) (массив объектов), filters (фильтры) (массив объектов), fulltext - критерий выборки (строка). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень результатов непрерывной обратной связи / отзывов, а также ряд дополнительных атрибутов:  
\- array - массив результатов непрерывной обратной связи / отзывов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID отзыва (целое число).  
     _code_ – код отзыва (строка).  
     _status_ – статус отзыва (строка).  
     _status\_id_ – код статуса отзыва в текстовом формате (строка).  
     _plan\_date_ – плановая дата заполнения отзыва (дата).  
     _done\_date_ – фактическая дата заполнения отзыва (дата).  
     _person\_fullname_ – ID респондента в текстовом формате (строка).  
     _person\_pict\_url_ – ссылка на фото респондента (строка).  
     _object\_fullname_ – ID оцениваемого в текстовом формате (строка).  
     _object\_pict\_url_ – ссылка на фото оцениваемого в текстовом формате (строка).  
     _owner\_person\_fullname_ – ID инициатора в текстовом формате (строка).  
     _owner\_person\_pict\_url_ – ссылка на фото инициатора в текстовом формате (строка).  
     _project\_name_ – название проекта (строка).  
     _text\_html_ – HTML для тайла (строка).  
     _basic\_score_ – оценка в текстовом формате (строка).  
     _basic\_desc_ – отзыв (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libContinuousFeedback", "GetPersonContinuousFeedback", [iPersonID, iInitiatorID, iObjectID, arrObjectTypes, iApplicationID, sApplicationAccessType, oCollectionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
