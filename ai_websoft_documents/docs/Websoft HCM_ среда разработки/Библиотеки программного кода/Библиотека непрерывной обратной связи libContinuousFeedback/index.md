## Библиотека непрерывной обратной связи libContinuousFeedback

В настоящем разделе описываются методы **библиотеки непрерывной обратной связи** из библиотеки программного кода **libContinuousFeedback**. Указанные методы регистрируются в разделе **Дизайнер – Библиотеки программного кода – libContinuousFeedback**.

Для вызова метода из библиотеки используется функция tools.call\_code\_library\_method.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libContinuousFeedback", <sMethodNameParam>, <arrParams>)**

_Аргументы:_  
     _<sMethodNameParam> (обязательный)_  
      Тип: **Строка**. Название вызываемого метода.  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.
