## GetProjectParticipantsApp

Метод **GetProjectParticipantsApp** предназначен для получения списка участников проектов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libContinuousFeedback", "GetProjectParticipantsApp", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя восемь параметров:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _sAccessType_ \- тип доступа для отбора (строка) (необязательный). Допустимые значения: "admin" (администратор приложения); "manager" (администратор процесса); "hr" (менеджер по персоналу); "observer" (наблюдатель); "auto" (определяется автоматически в соответствии с правами доступа пользователя). Значение по умолчанию - "auto".  
     _sApplication_ \- код приложения для определения доступа (строка).  
     _sXQueryQual_ \- дополнительный фильтр XQuery для отбора (строка) (необязательный).  
     _bShowDismiss_ \- показывать уволенных участников (булево).  
     _aStateParticipants_ \- статусы участников проекта для отбора (массив строк).  
     _aAdditionalFields_ \- дополнительные поля для отбора (массив строк).  
     _oCollectionParams_ \- набор интерактивных параметров выборки (объект). В состав объекта могут входить следующие параметры: paging (пейджинг) (объект), sort (сортировка) (объект), distincts (дополнительная входная информация) (массив объектов), filters (фильтры) (массив объектов), fulltext - критерий выборки (строка). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень участников проектов, а также ряд дополнительных атрибутов:  
\- array - массив участников проектов (массив объектов).  
     Атрибуты отдельного объекта:  
     id – ID участника проекта (целое число).  
     project\_id – ID проекта (целое число).  
     project\_name – название проекта (строка).  
     state – название статуса участника (строка).  
     fullname – ФИО участника проекта (строка).  
     position\_name – название основной должности (строка).  
     subdivision\_name – название подразделения основной должности (строка).  
     response\_received – количество полученных оценок обратной связи (целое число).  
     response\_requested – количество запрошенных оценок обратной связи (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libContinuousFeedback", "GetProjectParticipantsApp", [iCurUserID, sAccessType, sApplication, sXQueryQual, bShowDismiss, aStateParticipants, aAdditionalFields, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
