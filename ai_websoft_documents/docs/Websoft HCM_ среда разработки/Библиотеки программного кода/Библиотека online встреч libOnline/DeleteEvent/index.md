## DeleteEvent

Метод **DeleteEvent** предназначен для удаления мероприятия.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libOnline", "DeleteEvent", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iEventID_ – ID мероприятия (целое число).  
     _sExceptionCode_ \- код исключения для экземпляра объекта (строка).  
     _sScope_ \- тип редактирования (строка). Допустимые значения: "all", "current", "coming".

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _result_ \- результат выполнения (булево).  
\- _instance\_code_ \- код исключения для экземпляра объекта (строка).  
\- _status_ \- статус (строка).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libOnline", "DeleteEvent", [iEventID, sExceptionCode, sScope]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
