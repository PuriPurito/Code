## GetEvents

Метод **GetEvents** предназначен для получения списка встреч/вебинаров для текущего пользователя.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libOnline", "GetEvents", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя четыре параметра:  
     _sType_ \- режим представления (строка). Значение по умолчанию - 'week'.  
     _dStartDate_ \- начало запрашиваемого периода (дата).  
     _dFinishDate_ \- окончание запрашиваемого периода (дата).  
     _aEventIds_ \- массив ID событий (массив целых чисел).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень встреч/вебинаров для текущего пользователя, а также ряд дополнительных атрибутов:  
\- array - массив встреч/вебинаров (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- идентификатор мероприятия (целое число).   
     _name_ \- название мероприятия (строка).  
     _type_ \- тип мероприятия (строка).  
     _type\_name_ \- название типа мероприятия (строка).  
     _event\_url_ \- ссылка на событие (строка).  
     _instance\_code_ \- код исключения для экземпляра объекта (строка).  
     _parent\_id_ \- ID родительского объекта (целое число).  
     _start\_date_ \- начало мероприятия (дата).   
     _end\_date_ \- окончание мероприятия (дата).   
     _object\_id_ \- ID объекта (строка).  
     _object\_type_ \- тип объекта (строка).  
     _scheduler\_type\_id_ \- идентификатор типа расписания (строка). Допустимые значения: "none" (тип расписания отсутствует), "day" (на день), "week" (на неделю), "month" (на месяц), "year" (на год).  
     _week\_type\_id_ \- идентификатор типа недели (строка). Допустимые значения: "first" (первая), "second" (вторая), "third" (третья), "fourth" (четвертая), "last" (последняя).  
     _week\_days_ \- массив дней недели (массив строк). Допустимые значения: "monday", "tuesday", "wednesday", "thursday", "friday", "saturday", "sunday".  
     _participants_ \- массив участников (массив объектов). Каждый объект массива может включать в себя следующие данные: id - ID участника (целое число), fullname - ФИО участника (строка), participation - информация об участии (строка).  
     _tutors_ \- массив тьюторов (массив объектов). Каждый объект массива может включать в себя следующие данные: id - ID тьютора (целое число), fullname - ФИО тьютора (строка), participation - информация об участии (строка), icon\_url - URL ярлыка (иконки) (строка). 

\- _result_ \- результат выполнения (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libOnline", "GetEvents", [sType, dStartDate, dFinishDate, aEventIds]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
