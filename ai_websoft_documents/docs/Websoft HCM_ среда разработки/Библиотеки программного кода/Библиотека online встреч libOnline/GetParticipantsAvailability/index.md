## GetParticipantsAvailability

Метод **GetParticipantsAvailability** предназначен для получения списка доступности сотрудников для участия в мероприятии.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libOnline", "GetParticipantsAvailability", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя четыре параметра:  
     _iEventID_ – ID мероприятия (целое число).  
     _dStartDate_ \- начало запрашиваемого периода (дата).  
     _dFinishDate_ \- окончание запрашиваемого периода (дата).  
     _aParticipants_ \- массив ID потенциальных участников мероприятий (массив целых чисел).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию о доступности сотрудников для участия в мероприятии, а также ряд дополнительных атрибутов:  
\- _availability\_participants_ \- массив сотрудников с указанием их доступности для участия в мероприятии (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID сотрудника (целое число);  
     _availability_ – уровень доступности сотрудника (строка) ("available" или "busy").

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libOnline", "GetParticipantsAvailability", [iEventID, dStartDate, dFinishDate, aParticipants]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
