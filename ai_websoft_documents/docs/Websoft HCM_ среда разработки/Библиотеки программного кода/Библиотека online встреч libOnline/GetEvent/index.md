## GetEvent

Метод **GetEvent** предназначен для получения данных мероприятия.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libOnline", "GetEvent", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _iEventID_ – ID мероприятия (целое число).  
     _oParams_ – параметры (объект). В состав объекта могут быть включены: instance\_code - код исключения для экземпляра объекта (строка); sType - тип объекта (строка); dStartDate - дата начала для отбора (дата); dFinishDate - дата окончания для отбора (дата) и др.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию о мероприятии, а также ряд дополнительных атрибутов:  
\- _event\_data_ \- информация о мероприятии (объект).  
     Атрибуты объекта:  
     _id_ \- идентификатор мероприятия (целое число).   
     _name_ \- название мероприятия (строка).  
     _type_ \- тип мероприятия (строка).  
     _type\_name_ \- название типа мероприятия (строка).  
     _status\_id_ \- идентификатор статуса мероприятия (строка).  
     _status\_name_ \- название статуса мероприятия (строка).  
     _description_ \- описание мероприятия (строка).   
     instance\_code - код исключения для экземпляра объекта (строка).   
     object\_id - ID объекта (строка).  
     _object\_type_ \- тип объекта (строка).  
     _scheduler\_type\_id_ \- идентификатор типа расписания (строка). Допустимые значения: "none" (тип расписания отсутствует), "day" (на день), "week" (на неделю), "month" (на месяц), "year" (на год).  
     _week\_type\_id_ \- идентификатор типа недели (строка). Допустимые значения: "first" (первая), "second" (вторая), "third" (третья), "fourth" (четвертая), "last" (последняя).  
     _week\_days_ \- массив дней недели (массив строк). Допустимые значения: "monday", "tuesday", "wednesday", "thursday", "friday", "saturday", "sunday".  
     _start\_date_ \- начало мероприятия (дата).   
     _end\_date_ \- окончание мероприятия (дата).   
     series\_planned\_end\_date - дата планируемого завершения (дата).   
     event\_url - ссылка на событие (строка).  
     notification\_reminders - напоминать за указанное количество минут до начала (массив целых чисел).  
     participants - массив участников (массив объектов). Каждый объект массива может включать в себя следующие данные: id - ID участника (целое число), fullname - ФИО участника (строка), participation - информация об участии (строка), icon\_url - URL ярлыка (иконки) (строка), can\_use\_camera - имеется ли возможность использовать видеокамеру (булево), can\_use\_microphone - имеется ли возможность использовать микрофон (булево).  
     tutors - массив преподавателей (массив объектов). Каждый объект массива может включать в себя следующие данные: id - ID тьютора (целое число), fullname - ФИО тьютора (строка), participation - информация об участии (строка), icon\_url - URL ярлыка (иконки) (строка), can\_use\_camera - имеется ли возможность использовать видеокамеру (булево), can\_use\_microphone - имеется ли возможность использовать микрофон (булево).  
  
\- _result_ \- результат выполнения (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libOnline", "GetEvent", [iEventID, oParams]);_`   
  
`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
