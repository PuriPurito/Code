## GetReviewsDataRange

Метод **GetReviewsDataRange** предназначен для получения отзывов с учетом параметров (pagination).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libCoursePlayer", "GetReviewsDataRange", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _sCourseId_ \- ID курса (строка).  
     _iPage_ \- номер страницы в pagination (целое число).  
     _iItemsPerPage_ \- количество отзывов на странице (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень отзывов с учетом параметров (pagination), а также ряд дополнительных атрибутов:  
\- reviews - массив отзывов (массив объектов).

\- error - код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- errorText – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libCourse", "GetReviewsDataRange", [sCourseId, iPage, iItemsPerPage]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
