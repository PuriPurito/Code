## GetLearningHistoryData

Метод **GetLearningHistoryData** предназначен для получения данных законченного электронного курса.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libCoursePlayer", "GetLearningHistoryData", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _id_ \- ID законченнного электронного курса в текстовом формате (строка).  
     _sLaunchId_ \- ID запуска в текстовом формате (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные законченного электронного курса, а также ряд дополнительных атрибутов:  
\- _course\_name_ \- название курса (строка).  
\- _course\_code_ \- код курса в текстовом формате (строка).  
\- _time_ \- продолжительность прохождения (целое число).  
\- _start\_usage\_date_ \- дата активации (дата).  
\- _start\_learning\_date_ \- дата начала обучения (дата).  
\- _last\_usage\_date_ \- дата последнего посещения (дата).  
\- _max\_end\_date_ \- дата планируемого завершения (дата).  
\- _max\_score_ \- максимальный балл (целое число).  
\- _score_ \- количество набранных баллов (целое число).  
\- _state\_id_ \- ID состояния (целое число).  
\- _parts_ – данные о разделах курса (массив объектов).  
     _code_ \- код раздела в текстовом формате (строка).  
     _name_ \- название раздела (строка).  
     _type_ \- тип раздела (строка).  
     _object\_id_ \- ID объекта раздела (целое число).  
     _state\_id_ \- состоаяние раздела (целое число).  
     _score_ \- количество набранных баллов по разделу (целое число).  
     _learning\_part\_id_ \- ID раздела (целое число).  
     _scoring\_type_ \- формат передачи данных (строка).  
     _start\_usage\_date_ \- дата активации раздела (дата).  
     _last\_usage\_date_ \- дата последнего посещения (дата).  
     _attempts\_num_ \- количество попыток (целое число).  
     _cur\_attempt\_num_ \- текущая попытка (целое число).  
     _parent\_part\_code_ \- код родительского раздела в текстовом формате (строка).  
     _launch\_url_ \- URL для запуска раздела (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libCourse", "GetLearningHistoryData", [id, sLaunchId]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
