## GetLearningHistoryItems

Метод **GetLearningHistoryItems** предназначен для получения данных для таблицы "Моя история обучения".

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libCoursePlayer", "GetLearningHistoryItems", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _course\_id_ \- ID курса в текстовом формате (строка).   
     _page\_num_ \- номер страницы (целое число).  
     _page\_size_ \- размер страницы (целое число).  
     _sLaunchId_ \- ID запуска в текстовом формате (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные для таблицы "Моя история обучения", а также ряд дополнительных атрибутов:  
\- _items_ – законченные курсы (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID законченного электронного курса в текстовом формате (строка).  
     _start\_usage\_date_ \- дата активации в текстовом формате (строка).  
     _last\_usage\_date_ \- дата последнего посещения в текстовом формате (строка).  
     _score_ \- количество набранных баллов (целое число).  
     _state\_id_ – статус в текстовом формате (строка).

\- _total_ \- общее число объектов (целое число).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libCourse", "GetLearningHistoryItems", [course_id, page_num, page_size, sLaunchId]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
