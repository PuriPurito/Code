## GetReviewInitData

Метод **GetReviewInitData** предназначен для получения данных, необходимых для инициализации функционала отзывов в плеере курсов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libCoursePlayer", "GetReviewInitData", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _sCourseId_ \- ID курса (строка).  
     _iItemsPerPage_ \- количество отзывов на странице (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные, необходимые для инициализации функционала отзывов в плеере курсов, а также ряд дополнительных атрибутов.  
     Атрибуты объекта:  
     _averageRating_ \- средняя оценка (целое число).  
     _totalReviews_ \- количество всех отзывов (целое число).  
     _reviews_ \- массив отзывов (массив объектов).

     _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
     _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libCourse", "GetReviewInitData", [sCourseId, iItemsPerPage]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
