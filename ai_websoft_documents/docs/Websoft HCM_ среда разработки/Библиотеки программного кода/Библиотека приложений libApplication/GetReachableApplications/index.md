## GetReachableApplications

Метод **GetReachableApplications** предназначен для получения списка приложений, доступных сотруднику.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libApplication", "GetReachableApplications", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iWebModeIDParam_ \- ID типа страницы (целое число).  
     _iPersonIDParam_ \- ID сотрудника (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень приложений, доступных сотруднику, а также ряд дополнительных атрибутов:  
\- _array_ \- массив приложений (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID приложения (целое число);  
     _code_ \- код приложения (строка);  
     _name_ \- наименование приложения (строка);  
     _link_ \- ссылка на интерфейс приложения в Администраторе (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libApplication", "GetReachableApplications", [iWebModeIDParam, iPersonIDParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
