## GetPollActions

Метод предназначен для получениясписка действий по опросу.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "GetPollActions", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPollID_ \- ID опроса (целое число).  
     _iCurUserID_ \- ID сотрудника (целое число).

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит список действий по опросу, а также ряд дополнительных атрибутов:  
\- _array_ \- массив действий по опросу (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID действия по опросу (целое число);  
     _name_ – название действия по опросу (строка);  
     _action\_type_ – тип действия по опросу (строка);  
     _action\_id_ – строковый идентификатор действия по опросу (строка) (например: _"lp\_poll\_action"_);  
     _method_ – используемый метод действия по опросу (строка) (например: _"open\_url", "clear\_results"_);  
     _link_ – относительная ссылка на действие по опросу (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_`  
`_oRes = tools.call_code_library_method ("libPortal", "GetPollActions", [ iPollID, iCurUserID ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
