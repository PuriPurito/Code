## GetPollProcedures

Метод **GetPollProcedures** предназначен для получения списка процедур опроса.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "GetPollProcedures", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя восемь параметров:  
     _iPersonID_ \- ID текущего пользователя (целое число).  
     _sAccessType_ \- тип доступа (строка). Доступные значения: _"admin"/"manager"/"hr"/"expert"/"observer"/"reject"_.  
     _sApplication_ \- код приложения, по которому определяется доступ (строка).  
     _iCurApplicationID_ \- ID текущего приложения (целое число).  
     _arrState_ \- статусы процедур (массив строк или строка, содержащая статусы, разделенные запятыми или точками с запятой). Доступные значения статусов: _status\_active_ (в работе), _status\_completed_ (завершена).  
     _arrTemplate_ \- рабочие и/или эталонные процедуры (массив строк или строка, содержащая типы процедур, разделенные запятыми или точками с запятой). Доступные значения: _model\_true_ (эталонные), _model\_false_ (рабочие).  
     _sFilter_ \- строка для XQuery-фильтра (строка).  
     _sFullText_ \- строка для поиска (строка). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень процедур опроса, а также ряд дополнительных атрибутов:  
\- _array_ - массив процедур опроса (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID процедуры опроса (целое число).  
     _code_ \- код процедуры опроса (строка).  
     _name_ \- название процедуры опроса (строка).  
     _count\_polls\_groups_ \- количество групп опросов в процедуре опроса (целое число).  
     _count\_polls_ \- количество опросов в процедуре опроса (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPortal", "GetPollProcedures", [iPersonID, sAccessType, sApplication, iCurApplicationID, arrState, arrTemplate, sFilter, sFullText]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
