## DeleteRepositorium

Метод **DeleteRepositorium** предназначен для удаления репозитория (репозиториев).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "DeleteRepositorium", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _arrRepositoriumIDs_ \- Массив ID репозиториев, подлежащих удалению (массив целых чисел).

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _count_ \- количество удаленных объектов (целое число).  
  
\- error - код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- errorText – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPortal", "DeleteRepositorium", [arrRepositoriumIDs]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
