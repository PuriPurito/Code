## GetPollProcedureContext

Метод **GetPollProcedureContext** предназначен для получения контекста процедуры опроса.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "GetPollProcedureContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _iPollProcedureIDParam_ \- ID процедуры опроса (целое число).  
     _iPersonIDParam_ \- ID сотрудника (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию о контексте процедуры опроса, а также ряд дополнительных атрибутов:  
\- _context_ \- контекст (объектный показатель) процедуры опроса (объект).  
     Атрибуты объекта:  
     _bHasPollResult_ – у текущего пользователя имеется прохождение/прохождения текущей процедуры опроса (булево).  
     _bHasDonePollResult_ – у текущего пользователя имеется завершенное прохождение/прохождения текущей процедуры опроса (булево).  
     _bHasActivePollResult_ – у текущего пользователя имеется активное прохождение/прохождения текущей процедуры опроса (булево).  
     _iStatusID_ \- статус текущей процедуры опроса в числовом выражении (целое число).  
     _sStatusName_ \- статус текущей процедуры опроса в текстовом выражении (строка).   
     _bIsOpen_ \- текущая процедура опроса имеет признак "Открытая процедура" (булево).  
     _bCanPass_ \- текущая процедура опроса доступна для прохождения по дате (булево). 

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPortal", "GetPollProcedureContext", [iPollProcedureIDParam, iPersonIDParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
