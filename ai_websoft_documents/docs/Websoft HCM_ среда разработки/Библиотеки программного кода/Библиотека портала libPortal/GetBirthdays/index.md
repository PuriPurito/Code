## GetBirthdays

Метод **GetBirthdays** предназначен для получения списка дней рождения сотрудников.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "GetBirthdays", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя девять параметров:  
     _IntervalType_ – тип временного интервала (строка). Допустимые значения: _'all'_ \- без ограничений, _'days'_ \- за указанное число дней, _'prev'_ \- предыдущий месяц, _'curr'_ \- текущий месяц, _'next'_ \- следующий месяц, _'spec'_ - указанный месяц.  
     _nDays_ – дни рождения отбираются за предыдущий день и указанное число дней от текущего (целое число).  
     _iMonth_ – месяц, за который отбираются дни рождения (целое число).  
     _bWOYear_ – год рождения не указывается (булево).   
     _sLimitationType_ – тип ограничения (строка). Допустимые значения: _'org'_ - в одной организации, _'subdivision'_ - в одном подразделении.  
     _iPersonID_ – ID текущего сотрудника (целое число).  
     _sSearch_ – критерий поиска по ФИО (строка).  
     _oFilter_ – параметры для фильтрации списка сотрудников (объект). Параметры объекта: _view\_candidate_ (показывать кандидатов) (булево), _view\_dismiss_ (показывать уволенных) (булево).   
     _oPaging_ \- информация из рантайма о пейджинге (объект) (в том числе: _oPaging.index_ \- номер страницы (целое число); _oPaging.size_ \- размер страницы (целое число)).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень информации о сотрудниках (в том числе данных о днях рождения сотрудников), а также ряд дополнительных атрибутов:  
\- result - массив информации о сотрудниках (в том числе данных о днях рождения сотрудников) (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID сотрудника (целое число);  
     _name_ – ФИО сотрудника (строка);  
     _position\_id_ \- ID должности (целое число);  
     _position\_name_ \- название должности (строка);  
     _org\_id_ \- ID организации (целое число);  
     _org\_name_ \- название организации (строка);  
     _subdivision\_id_ \- ID подразделения (целое число);  
     _subdivision\_name_ \- название подразделения (строка);  
     _birth\_date_ \- дата рождения (дата);  
     _birth\_date\_name_ \- дата рождения в строчном формате (строка);  
     _birth\_date\_in\_cur\_year_ \- дата рождения в текущем году (дата);  
     _birth\_date\_rest\_days\_num_ \- число дней до дня рождения (целое число);  
     _email_ \- адрес электронной почты (строка);  
     _phone_ \- телефон (строка);  
     _message_ \- дополнительная (служебная) информация о сотруднике (строка);  
     _image\_url_ \- URL изображения сотрудника (строка);  
     _form\_url_ \- ссылка на карточку сотрудника (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPortal", "GetBirthdays", [ IntervalType, nDays, iMonth, bWOYear, sLimitationType, iPersonID, sSearch, oFilter, oPaging]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
