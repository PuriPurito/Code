## GetBanners

Метод **GetBanners** предназначен для получения списка баннеров.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "GetBanners", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _bCheckAccess_ \- проверка доступа пользователя (булево).   
     _bIgnoreRoles_ \- игнорировать категории (булево).  
     _arrBannersRoles_ \- массив ID категорий (массив целых чисел).  
     _bIsMobileRuntime_ \- вызван ли код из мобильного приложения (булево).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень баннеров, а также ряд дополнительных атрибутов:  
\- _array_ - массив баннеров (массив объектов).  
     Атрибуты отдельного объекта:  
     id \- ID баннера (строка).  
     _code_ \- код баннера (строка).  
     _name_ \- название баннера (строка).  
     _type_ \- тип баннера (строка).  
     _img\_url_ \- ссылка на изображение баннера (строка).  
     _url_ \- ссылка на баннер (строка).  
     _start\_date_ \- дата начала демонстрации баннера (дата).  
     _finish\_date_ \- дата окончания демонстрации баннера (дата).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPortal", "GetBanners", [iCurUserID, bCheckAccess, bIgnoreRoles, arrBannersRoles, bIsMobileRuntime]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
