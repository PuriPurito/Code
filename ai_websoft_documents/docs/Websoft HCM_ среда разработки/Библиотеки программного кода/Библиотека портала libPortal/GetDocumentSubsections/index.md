## GetDocumentSubsections

Метод предназначен для получениясписка подразделов раздела портала.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "GetDocumentSubsections", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя тринадцать параметров:  
     _iDocumentID_ \- ID раздела портала, список подразделов которого необходимо показать (целое число).  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _bCheckAccess_ \- проверять права доступа (булево). Значение по умолчанию - false.  
     _bShowExtendedData_ \- возвращать расширенные данные (булево). Значение по умолчанию - false.   
     _sSortType_ \- тип сортировки (строка) (необязательный).  
     _sSearchString_ \- критерий поиска (строка). Должен быть длиной в 3 и более символов; поиск полнотекстовый.  
     _sPeriod_ \- период, за который были созданы подразделы (строка).  
     _dDate_ \- дата, по которой будет определяться период выборки подразделов (дата).  
     _bUnauthorizedAccess_ \- разрешить доступ неавторизованным пользователям к подразделам (булево) (необязательный). Значение по умолчанию - _false_.  
     _arrDistinct_ \- перечень полей для формирования дополнительных списков для виджета фильтров (массив строк) (необязательный).  
     _arrFilters_ \- набор фильтров (массив объектов).  
     oSort - информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).  
     oPaging - информация из рантайма о пейджинге (объект). Объект включает в себя следующие данные:  INDEX - номер страницы (целое число);  SIZE - размер страницы (целое число); MANUAL - разделение на страницы вручную (булево); TOTAL - общее количество страниц (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит список подразделов раздела портала, а также ряд дополнительных атрибутов:  
\- _array_ \- массив подразделов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID подраздела (целое число);  
     _code_ – код подраздела (строка);  
     _name_ – название подраздела (строка);  
     _image_ – относительная ссылка на изображение (строка);  
     _comment_ – комментарий к подразделу (строка);  
     _tags_ – теги (метки) подраздела (строка);  
     _date_ – дата создания подраздела (дата);  
     _link_ – относительная ссылка на подраздел (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPortal", "GetDocumentSubsections", [ iDocumentID, iCurUserID, bCheckAccess, bShowExtendedData, sSortType, sSearchString, dDate, sPeriod, bUnauthorizedAccess, arrDistinct, arrFilters, oSort, oPaging]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
