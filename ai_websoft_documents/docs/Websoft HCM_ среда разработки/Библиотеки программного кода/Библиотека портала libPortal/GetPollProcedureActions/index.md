## GetPollProcedureActions

Метод **GetPollProcedureActions** предназначен для получения списка действий по процедуре опроса.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "GetPollProcedureActions", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPollProcedureID_ \- ID процедуры опроса (целое число).  
     _iCurUserID_ \- ID сотрудника (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень действий по процедуре опроса, а также ряд дополнительных атрибутов:  
\- _array_ \- массив действий (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID действия (целое число);  
     _name_ – название действия (строка);  
     _action\_type_ – тип действия (строка) (например, _"remote\_action"_);  
     _action\_id_ – ID типа действия (строка) (например, _"lp\_poll\_action"_);  
     _method_ – метод действия (строка) (например, _"open\_url", "clear\_results"_);  
     _url_ – относительная ссылка на действие (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPortal", "GetPollProcedureActions", [iPollProcedureID, iCurUserID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
