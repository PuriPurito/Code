## GetPollContext

Метод **GetPollContext** предназначен для получения контекста опроса.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "GetPollContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPollIDParam_ \- ID опроса (целое число).  
     _iPersonIDParam_ \- ID сотрудника (целое число).

_Возвращаемые значения:_

\- _bHasPollResult_ – показатель опроса, параметр, отображающий прохождение данным сотрудником указанного опроса (булево) (true – опрос пройден, false – опрос не пройден).   
\- _bHasDonePollResult_ \- есть ли у текущего пользователя завершенные прохождения текущего опроса (булево).  
\- _bHasActivePollResult_ \- есть ли у текущего пользователя активные прохождения текущего опроса (булево).  
\- _bIsOneTime_ \- можно ли голосовать только один раз (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPortal", "GetPollContext", [iPollIDParam, iPersonIDParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
