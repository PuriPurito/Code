## GetLastForumEntries

Метод **GetLastForumEntries** предназначен для получения списка последних сообщений форумов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "GetLastForumEntries", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _arrCodeFroums_ \- массив кодов форумов (массив строк).  
     _iCount_ \- количество возвращаемых сообщений (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень последних сообщений форумов, а также ряд дополнительных атрибутов:  
\- _array_ \- массив последних сообщений форумов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID статьи (целое число);  
     _name_ – название сообщения форума (строка);  
     _author\_info_ – ФИО автора (строка);  
     _create\_date_ \- дата и время создания сообщения форума (дата);  
     _modification\_date_ \- дата и время последнего изменения сообщения форума (дата);   
     _forum\_id_ \- ID форума, к которому относится сообщение форума (целое число);  
     _forum\_name_ \- название форума, к которому относится сообщение (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPortal", "GetLastForumEntries", [arrCodeFroums, iCount]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
