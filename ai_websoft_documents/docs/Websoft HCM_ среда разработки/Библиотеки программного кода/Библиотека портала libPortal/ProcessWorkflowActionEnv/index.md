## ProcessWorkflowActionEnv

Метод **ProcessWorkflowActionEnv** предназначен для выполнения действий по процессам на этапе согласования в соответствии с документооборотом.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "ProcessWorkflowActionEnv", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _iObjectID_ – ID объекта (целое число).  
     _sActionID_ – ID действия (строка).  
     _sCommand_ – название команды (строка).  
     _sFormFields_ \- список форм полей (строка).  
     _sSelectedObjectIDs_ – список ID выделенных объектов (строка). Отдельные ID объектов из данного списка выражаются целым числом и отделяются друг от друга символом «точка с запятой».   
     _SCOPE\_WVARS_ – JSON-объект с параметрами удаленного действия (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит следующие атрибуты:  
\- workflow\_action\_result - результат выполнения действия (true – если действие завершилась успешно, false – в противном случае) (булево).  
\- workflow\_action\_success\_action - результат выполнения действия в текстовом выражении (строка).  
\- workflow\_redirect\_url - результирующий URL переадресации документооборота (строка).  
\- error - код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- errorText – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPortal", "ProcessWorkflowActionEnv", [iObjectID, sActionID, sCommand, sFormFields, sSelectedObjectIDs, SCOPE_WVARS]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
