## GetRepositorium

Метод **GetRepositorium** предназначен для получения данных о репозитории.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "GetRepositorium", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPersonID_ – ID текущего сотрудника (целое число).  
     _iRepositoriumID_ – ID репозитория (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о репозитории, а также ряд дополнительных атрибутов:  
\- _data_ - массив данных о репозитории (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID репозитория (целое число).  
     _code_ – код репозитория (строка).  
     _name_ – название репозитория (строка).  
     _authors_ – авторы репозитория (строка).  
     _files_ – файлы, хранящиеся в репозитории (строка).  
     _date\_creation_ – дата создания репозитория (дата).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPortal", "GetRepositorium", [iPersonID, iRepositoriumID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
