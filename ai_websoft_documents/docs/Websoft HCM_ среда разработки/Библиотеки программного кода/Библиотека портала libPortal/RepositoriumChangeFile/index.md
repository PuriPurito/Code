## RepositoriumChangeFile

Метод **RepositoriumChangeFile** предназначен для перемещения файла (ресурса) из одного репозитория в другой.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "RepositoriumChangeFile", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _params_ \- параметры перемещения файла (ресурса) (объект). В состав объекта params, в частности, входят: _person\_id_ - ID владельца файла (целое число); _repo\_id\_current_ \- ID текущего репозитария (целое число); _repo\_id\_new_ \- ID нового репозитария (целое число); _file\_id_ \- ID файла (целое число). 

_Возвращаемые значения:_

      Тип:  Объект. Содержит следующие атрибуты:  
\- _result_ – результат успешного выполнения удаленного действия (_"Файл успешно перемещен в репозиторий <название\_репозитория>"_) (строка).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPortal", "RepositoriumChangeFile", [params]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
