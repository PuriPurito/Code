## GetDocumentObjects

Метод предназначен для получениясписка прикрепленных объектов раздела портала.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "GetDocumentObjects", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iDocumentID_ \- ID раздела портала, список прикрепленных объектов которого необходимо показать (целое число).  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _bCheckAccess_ \- проверять права доступа (булево). Значение по умолчанию - _false_.  
     _sSearchString_ \- критерий поиска (строка). Должен быть длиной в 3 и более символов; поиск полнотекстовый.

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит список объектов раздела портала, а также ряд дополнительных атрибутов:  
\- _array_ \- массив прикрепленных объектов раздела портала.  
     Атрибуты отдельного объекта:  
     _id_ – ID объекта (целое число);  
     _name_ – название объекта (строка);  
     _type_ – тип объекта (строка);  
     _link_ – относительная ссылка на объект (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPortal", "GetDocumentObjects", [ iDocumentID, iCurUserID, bCheckAccess, sSearchString ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
