## GetRepositoriumsFiles

Метод **GetRepositoriumsFiles** предназначен для получения списка файлов в репозитории.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "GetRepositoriumsFiles", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _bCheckAccess_ \- проверять права доступа (булево).   
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _iRepositoriumID_ \- ID репозитория (целое число).  
     _oCollectionParams_ \- объект, содержащий информацию о наборе фильтров, сортировке и пэйджинге (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень файлов в репозитории, а также ряд дополнительных атрибутов:  
\- _resources_ \- массив файлов в репозитории (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID файла (целое число).  
     _code_ \- код файла (строка).  
     _name_ \- название файла (строка).  
     _image_ \- ссылка на изображение (строка).  
     _comment_ \- комментарий (строка).  
     _tags_ \- теги файла (строка).  
     _date_ \- дата размещения файла в репозтории (дата).  
     _link_ \- ссылка на файл (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPortal", "GetRepositoriumsFiles", [bCheckAccess, iCurUserID, iRepositoriumID, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
