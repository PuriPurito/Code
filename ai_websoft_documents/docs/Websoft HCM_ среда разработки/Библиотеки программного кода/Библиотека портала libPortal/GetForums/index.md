## GetForums

Метод **GetForums** предназначен для получения получение списка форумов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "GetForums", \[\])**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iCurUserID_ \- ID текущего пользователя (сотрудника) (целое число).  
     _bCheckAccess_ \- проверять права доступа (булево) (необязательный).   
     oSort - информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).  
     oPaging - информация из рантайма о пейджинге (объект). Объект включает в себя следующие данные:  INDEX - номер страницы (целое число);  SIZE - размер страницы (целое число); MANUAL - разделение на страницы вручную (булево); TOTAL - общее количество страниц (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень данных о форумах, а также ряд дополнительных атрибутов:  
\- _array_ \- массив данных о форумах (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID форума (целое число);  
     _forum\_name_ – название форума (строка);  
     _forum\_url_ – относительная ссылка (URL) на форум (строка);  
     _forum\_articles_ – количество статей форума (строка);  
     _forum\_date\_update_ – дата последнего размещения статьи форума (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method( "libPortal", "GetForums", [iCurUserID, bCheckAccess, oSort, oPaging] );_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
