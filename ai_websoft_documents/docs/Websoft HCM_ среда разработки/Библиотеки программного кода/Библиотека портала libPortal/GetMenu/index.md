## GetMenu

Метод **GetMenu** предназначен для получения списка пунктов меню портала.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "GetMenu", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя восемь параметров:  
     _sMenuCode_ \- код меню (строка).  
     _iCurSiteIDParam_ \- ID текущего сайта (целое число).  
     _curSite_ \- текущий сайт (объект XmlElem).  
     _Env_ \- глобальное окружение (объект).  
     _bReturnMenyEntryWithBlankUrl_ \- возвращать пункты меню без ссылок (булево).  
     _bGetMenuCodeFromUrl_ \- брать код меню из параметров URL (булево).  
     _sUrlParamNameMenuCode_ \- наименование параметра URL с кодом меню (строка) (по умолчанию _"breadcrumbs"_). Параметр является обязательным, если _bGetMenuCodeFromUrl_ имеет значение _false_.   
     _arrActionRuleCodes_ \- коды категорий действий (массив строк) (необязательный).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит набор пунктов меню портала, а также ряд дополнительных атрибутов:  
\- _array_ \- массив пунктов меню (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID пункта меню (строка);  
     _name_ – наименование пункта меню (строка);  
     _link_ – ссылка пункта меню (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPortal", "GetMenu", [sMenuCode, iCurSiteIDParam, curSite, Env, bReturnMenyEntryWithBlankUrl, bGetMenuCodeFromUrl, sUrlParamNameMenuCode, arrActionRuleCodes]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
