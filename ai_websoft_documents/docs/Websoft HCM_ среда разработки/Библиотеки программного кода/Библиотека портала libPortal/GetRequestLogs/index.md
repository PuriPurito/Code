## GetRequestLogs

Метод **GetRequestLogs** предназначен для получения списка записей лога заявки.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "GetRequestLogs", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iRequestID_ \- ID заявки (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит списка записей лога заявки, а также ряд дополнительных атрибутов:  
\- _array_ \- массив записей лога заявки (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – информация об ID заявки (строка).  
     _date_ – информация о дате создания заявки (строка).  
     _person\_fullname_ – информация о сотруднике, на которого подается заявка (строка).  
     _action\_name_ – название действия (строка).  
     _begin\_state\_name_ – начальное состояние заявки (строка).  
     _end\_state\_name_ – конечное состояние заявки (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPortal", "GetRequestLogs", [iRequestID]);_`   
 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
