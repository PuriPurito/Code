## DeleteCurrentRepositorium

Метод **DeleteCurrentRepositorium** предназначен для удаления текущего репозитария.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "DeleteCurrentRepositorium", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iPersonID_ \- ID нового владельца (целое число).  
     _iRepositoriumID_ \- ID репозитария (целое число).  
     _sParams_ \- тип обработки файлов репозитария (строка). Доступные значения: _"repo"_ \- файлы "отвязываются" от репозитария, _"repo\_files"_ \- файлы удаляются. 

_Возвращаемые значения:_

      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _result_ – результат выполнения удаленного действия (_'Репозиторий успешно удален'_ или _'Репозиторий и связанные с ним файлы успешно удалены'_) (строка).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPortal", "DeleteCurrentRepositorium", [iPersonID, iRepositoriumID, sParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
