## GetResource

Метод **GetResource** предназначен для получения данных ресурса (файла).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "GetResource", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iResourceID_ – ID файла (ресурса) (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о ресурсе (файле), а также ряд дополнительных атрибутов:  
\- _resource_ \- данные о ресурсе (файле) (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID файла в текстовом формате (строка).  
     _name_ – название файла (строка).  
     _type_ – тип файла (строка).  
     _allow\_download_ \- разрешить ли скачивание файла (булево).   
     _allow\_unauthorized\_download_ \- разрешить ли скачивание неавторизованного файла (булево).  
     _allow\_search_ \- разрешить ли поиск файла (булево).  
     _size_ – размер файла в байтах (целое число).  
     _use\_count_ – количество использований файла (целое число).  
     _person\_id_ \- загружен пользователем (целое число).  
     _person\_fullname_ \- ФИО сотрудника (строка).  
     _links_ \- ссылка на файл (строка).  
     _comment_ \- комментарий (строка).  
     _date\_creation_ \- дата создания файла (дата).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPortal", "GetResource", [iResourceID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
