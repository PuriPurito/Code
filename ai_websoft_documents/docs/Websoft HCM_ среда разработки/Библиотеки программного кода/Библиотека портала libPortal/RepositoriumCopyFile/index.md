## RepositoriumCopyFile

Метод _RepositoriumCopyFile_ предназначен для копирования файла (ресурса) в указанный репозиторий.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "RepositoriumCopyFile", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _iFileID_ \- ID файла (целое число).  
     _iRepositoriumIDest_ \- ID репозитария назначения (целое число).  
     _strFileName_ \- имя файла назначения (строка).

_Возвращаемые значения:_

      Тип:  Объект. Содержит следующие атрибуты:  
\- _result_ – результат успешного выполнения удаленного действия (_"Файл успешно копирован"_) (строка).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPortal", "RepositoriumCopyFile", [iPersonID, iFileID, iRepositoriumID, strFileName]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
