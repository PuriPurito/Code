## GetPolls

Метод предназначен для получениясписка опросов портала.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "GetPolls", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя девять параметров:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _bCheckAccess_ \- проверять права доступа (булево). Значение по умолчанию - _false_.  
     _iMaxCount_ \- максимальное количество отбираемых записей (целое число).    
     _sSearch_ \- критерий отбора (строка).  
     _aPollRoles_ \- массив ID ролей (массив целых чисел).  
     _bMainPollOnly_ \- отбирать ли только основные опросы (булево) (необязательный). Значение по умолчанию - false.   
     _bCurrentByDate_ \- отбирать ли только активные опросы, актуальные на текущую дату (булево) (необязательный). Значение по умолчанию - _false_.   
     oSort - информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).  
     oPaging - информация из рантайма о пейджинге (объект). Объект включает в себя следующие данные:  INDEX - номер страницы (целое число);  SIZE - размер страницы (целое число); MANUAL - разделение на страницы вручную (булево); TOTAL - общее количество страниц (целое число).

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит список опросов портала, а также ряд дополнительных атрибутов:  
\- _array_ \- массив опросов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID опроса (целое число);  
     _name_ – название опроса (строка);  
     _image_ – относительная ссылка на изображение (строка);  
     _link_ – относительная ссылка на опрос (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_`  
`_oRes = tools.call_code_library_method ("libPortal", "GetPolls", [ iCurUserID, bCheckAccess, iMaxCount, sSearch, aPollRoles, bMainPollOnly, bCurrentByDate, oSort, oPaging ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
