## GetSearchObjects

Метод предназначен для получениясписка найденных объектов по критерию поиска.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPortal", "GetSearchObjects", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя следующие параметры:  
     _sSearchWord_ – критерий поиска (строка).  
     _oSearchParam_ \- дополнительные параметры поиска (объект). В состав объекта могут входить следующие параметры: bSearchCourse - включить поиск по курсам (булево); arrCourseRoleIDs - список ID категорий с курсами, по которым будет проведен поиск (массив целых чисел) (параметр действует при bSearchCourse=true); bSearchTest - включить поиск по тестам (булево); bSearchEvent - включить поиск по мероприятиям (булево); bSearchPerson - включить поиск по сотрудникам (булево); bSearchDocument - включить поиск по документам (булево); bSearchForum - включить поиск по форумам (булево); bSearchResource - включить поиск по ресурсам (булево); bSearchTag - включить поиск по тегам (булево); bSearchKnowledgePart - включить поиск по значениям карты знаний (булево); bSearchWikiArticle - включить поиск по статьям Wiki (булево); arrWikiRoleIDs - список ID категорий с wiki-базами, по которым будет проведен поиск (массив целых чисел) (параметр действует при bSearchWikiArticle=true); arrWikiBaseIDs - список ID wiki-баз, по которым будет проведен поиск (массив целых чисел) (параметр действует при bSearchWikiArticle=true); bUseSmartSearch - использовать режим "умного" поиска по wiki-статьям (булево); iSmartSearchWikiBaseID - Wiki-база, в которой будет проведен "умный" поиск (целое число) (параметр действует при bUseSmartSearch=true); bSearchLibraryMaterial - включить поиск по библиотеке материалов (булево); bSearchWebMode - включить поиск по типам страниц (булево).  
     _bCheckAccess_ \- нужно ли проверять права доступа (булево).

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит список найденных объектов по критерию поиска, а также ряд дополнительных атрибутов:  
\- _objects_ \- массив найденных объектов.  
     Атрибуты отдельного объекта:  
     _id_ – ID объекта (целое число);  
     _eobject\_name_ – название объекта (строка);  
     _eobject\_type_ – тип объекта (строка);  
     _eobject\_type\_name_ – название типа объекта (строка);  
     _eimage_ – относительная ссылка на изображение (строка);  
     _elink_ – относительная ссылка на объект (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_`  
_oRes = tools.call\_code\_library\_method ("libPortal", "GetSearchObjects", \[ sSearchWord, oSearchParam, bCheckAccess \]);_

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
