## Библиотека для мини-сценариев по отпускам libScriptVacation

В настоящем разделе описываются методы **библиотеки для мини-сценариев по отпускам** из библиотеки программного кода **libScriptVacation**. Указанные методы регистрируются в разделе **Дизайнер – Библиотеки программного кода – libScriptVacation**.

Примечание - По состоянию на май 2024 г. библиотека предназначена исключительно для внутренних нужд системы и не содержит публичных методов.
