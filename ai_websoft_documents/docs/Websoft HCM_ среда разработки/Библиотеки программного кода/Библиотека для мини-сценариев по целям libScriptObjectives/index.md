## Библиотека для мини-сценариев по целям libScriptObjectives

В настоящем разделе описываются методы **библиотеки для мини-сценариев по целям** из библиотеки программного кода **libScriptObjectives**. Указанные методы регистрируются в разделе **Дизайнер – Библиотеки программного кода – libScriptObjectives**.

Примечание - По состоянию на май 2024 г. библиотека предназначена исключительно для внутренних нужд системы и не содержит публичных методов.
