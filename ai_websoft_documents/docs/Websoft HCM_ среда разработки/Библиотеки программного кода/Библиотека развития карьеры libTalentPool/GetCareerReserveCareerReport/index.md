## GetCareerReserveCareerReport

Метод **GetCareerReserveCareerReport** предназначен для формирования отчета «По этапам развития карьеры».

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetCareerReserveCareerReport", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _iApplicationID_ \- ID приложения (целое число).  
     _oFilters_ \- объект с фильтрами (параметрами) отчета (объект). В состав объекта входят следующие параметры: plan\_types – типы плана для отбора (строка); status\_types - статусы типов для отбора (массив строк); org\_id - ID организации (целое число); hier\_sub\_select - нужно ли учитывать дочерние подразделения (булево); subdivision\_id - ID подразделения (целое число); date\_start - начало периода отбора (дата); date\_end - конец периода отбора (дата).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень объектов-этапов развития карьеры с фильтрами (параметрами) отчета, а также ряд дополнительных атрибутов:  
\- array - массив объектов с параметрами отчета (массив объектов).  
     Атрибуты отдельного объекта:  
     career\_reserve\_id - ID карьерного резерва (целое число).  
     person\_id - ID сотрудника (целое число).  
     person\_fullname - ФИО сотрудника (строка).  
     person\_position\_name - название должности (строка).  
     person\_subdivision - название подразделения (строка).  
     person\_org - название организации (строка).  
     status - статус (строка).  
     start\_date - начало этапа развития карьеры (дата).   
     plan\_readiness\_date – плановый срок достижения готовности (дата).  
     finish\_date - завершение этапа развития карьеры (дата).  
     is\_personnel\_reserve - имеется ли кадровый резерв (булево).   
     is\_successor - имеется ли преемник (булево).  
     is\_career\_plan - имеется ли карьерный план (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetCareerReserveCareerReport", [iCurUserID, iApplicationID, oFilters ]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
