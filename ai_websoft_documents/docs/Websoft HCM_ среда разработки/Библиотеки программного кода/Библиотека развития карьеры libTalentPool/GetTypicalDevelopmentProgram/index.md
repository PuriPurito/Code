## GetTypicalDevelopmentProgram

Метод предназначен для получения списка типовых программ развития. 

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetTypicalDevelopmentProgram", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя семь параметров:  
     _iCurUserID_ \- ID текущего пользователя, по которому осуществляется выборка этапов развития карьеры (целое число).  
     _sAccessType_ \- Тип доступа (строка) (необязательный). Доступные значения: _"admin", "manager", "hr", "expert", "tutor", "observer", "auto"_. Значение по умолчанию - _"auto"._  
     _sApplication_ \- код или идентифификатор (ID) приложения, по которому определяется доступ (строка).  
     _arrStates_ \- массив статусов типовых программ развития для вывода (массив строк). Доступные значения элементов массива: _"plan"_ (Планируется), _"active"_ (Действует), _"archive"_ (Архив).  
     _arrReturnData_ \- массив полей для вывода (массив строк). Доступные значения элементов массива: _"position\_common\_count"_ (Число типовых должностей), _"position\_family\_count"_ (Число семейств должностей), _"subdivision\_group\_count"_ (Число групп подразделений).  
     _oParam_ \- Параметры выборки (объект).  
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит перечень типовых программ развития, а также ряд дополнительных атрибутов:  
\- _result_ \- массив типовых программ развития (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID типовой программы развития (целое число);  
     _name_ – название типовой программы развития (строка).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetTypicalDevelopmentProgram", [iCurUserID, sAccessType, sApplication, arrStates, arrReturnData, oParam, oCollectionParams]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
