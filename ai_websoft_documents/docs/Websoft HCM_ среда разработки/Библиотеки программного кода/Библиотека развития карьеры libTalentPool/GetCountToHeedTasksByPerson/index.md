## GetCountToHeedTasksByPerson

Метод предназначен для получения информации о количестве актуальных или просроченных задач в активных этапах развития карьеры подчиненных или подопечных.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetCountToHeedTasksByPerson", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iPersonIDParam_ \- ID сотрудника, по которому осуществляется выборка этапов развития карьеры (целое число).  
     _sPersonType_ \- тип сотрудника для отбора (строка). Допустимые значения: _'tutor'_ – отбор этапов, в которых указанный сотрудник является наставником, _'boss'_ - отбор этапов, в которых указанный сотрудник является руководителем.   
     _sSelectType_ \- тип задач для отбора (строка). Допустимые значения: _'active'_ - актуальные, _'expire'_ - просроченные.  
     _bIsAdaptation_ \- выборка только из адаптаций (булево).

_Возвращаемое значение:_  
      Тип: **Целое число**. Количество актуальных или просроченных задач в этапах развития карьеры.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetCountToHeedTasksByPerson", [ iPersonIDParam, sPersonType, sSelectType, bIsAdaptation, bInActiveCareerResreve ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
