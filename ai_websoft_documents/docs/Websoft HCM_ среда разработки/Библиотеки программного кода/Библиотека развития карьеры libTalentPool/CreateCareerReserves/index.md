## CreateCareerReserves

Метод **CreateCareerReserves** предназначен для создания этапа развития карьеры (кроме адаптации) для сотрудников.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "CreateCareerReserves", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _arrObjectIDs_ \- ID объектов, по которым добавляются этапы развития (массив целых чисел).  
     _oParam_ \- параметры формирования этапа развития карьеры (объект). В состав объекта входят следующие параметры: _unite\_plan_ – действия в случае, если у сотрудника уже есть план карьерного этапа (строка) ("unite\_plan" (объединять планы), "not\_unite" (не объединять планы)); _goal_ - цели развития, доступные для выбора (строка); _position\_id_ - ID цели - должности (целое число); _position\_common\_id_ - ID цели - типовой должности (целое число); _staff\_position\_id_ \- ID цели - позиции штатного расписания (целое число); _position\_name_ - цель - наименования должности (строка); _state_ – статусы (массив строк); _start\_date\_mode_ - способ определения даты начала адаптации (строка) (today/tomorrow/optionally); start\_date - выбранная дата начала (дата); _program\_choise_ \- способ отбора типовых программ развития (массив строк) (subdivision\_group/position\_family/position\_common/optionally); _development\_program\_ids_ \- ID выбранных типовых программ развития (массив целых чисел); _merge\_type_ \- способ объединения типовых программ при назначении адаптации (строка) (serial/parallel/by\_application); _tutors\_mode_ \- способы отбора наставников (массив строк) (fact/func/optionally); _tutor\_person\_ids_ \- ID выбранных наставников (массив целых чисел); tutor\_boss\_type\_id - ID типа руководителя для отбора наставников по функциональным руководителям (целое число); _tutor\_source_ - наставники отбираются из списка наставников или из общего перечня сотрудников (строка) (tutor/person); _hierarchy\_level_ - количество уровней отбора вверх по иерархии (целое число); _send\_notification_ \- включение/выключение отправки уведомлений (булево); _send\_target_ - группы адресатов, которым будут отправляться уведомления (массив строк) (person/boss/tutor); _type\_create\_notification_ - способ формирования уведомлений (строка) (template/blank); _collaborator\_notification\_id_ - ID типа сотрудника для генерации уведомлений сотруднику (целое число); _boss\_notification\_id_ \- ID типа руководителя для генерации уведомлений наставнику и руководителю (целое число); _custom\_option_ \- добавляется ли текст в уведомления (строка) (wo\_add\_text (текст не добавляется) / with\_add\_text (текст добавляется)); _message\_subject_ \- тема сообщения без шаблона (строка); _message\_format_ \- формат сообщения без шаблона (строка) (plane (обычный текст) / html (текст в формате HTML)); _message\_body_ \- тело сообщения без шаблона (строка); add\_text - дополнительный текст в уведомлениях (строка) (учитывается, если custom\_option = 'with\_add\_text'); _APPLICATION_ \- ID приложения, если функция вызывается из приложения (целое число); _sAPPLICATION_ - код приложения, если функция вызывается из приложения (строка).

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- count – количество сформированных объектов (целое число).   
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "CreateCareerReserves", [arrObjectIDs, oParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
