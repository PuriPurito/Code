## ChangeCareerReserve

Метод **ChangeCareerReserve** предназначен для изменения этапа развития карьеры.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "ChangeCareerReserve", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя восемь параметров:  
     _iCareerReserveIDParam_ \- ID этапа развития карьеры (целое число).  
     _sCommand_ \- текущий режим удаленного действия (строка).  
     _sFormFields_ \- JSON-строка, сформированная на основании данных формы удаленного действия (строка).  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _sTutorChoice_ \- способ выбора наставников (строка) (необязательный). Доступные значения: 'tutor' (из списка наставников). По умолчанию - из общего списка сотрудников.  
     _bTutorHier_ \- учитывать ли иерархию подразделений при отборе (true) или делать выборку строго по указанным подразделениям (булево).  
     _iHierLevel_ \- количество учитываемых уровней иерархии вверх (целое число) (необязательный). По умолчанию - 0.  
     _sApplication_ \- код или идентифификатор (ID) приложения, по которому определяется доступ (строка).

_Возвращаемые значения:_

      Тип:  **Объект**. Содержит следующие атрибуты:  
**\- result** – результат вызова метода (объект). В случае успешного завершения выполнения метода в данный объект включается выражение "Этап развития карьеры успешно обновлен".  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "ChangeCareerReserve", [iCareerReserveIDParam, sCommand, sFormFields, iCurUserID, sTutorChoice, bTutorHier, iHierLevel, sApplication ]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
