## GetPersonnelCommitteeList

Метод **GetPersonnelCommitteeList** предназначен для получения списка участников кадровых комитетов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetPersonnelCommitteeList", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iPersonID_ \- идентификатор текущего пользователя (целое число).  
     _arrStates_ \- статусы кадровых комитетов (массив строк).  
     oSort - информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит список участников кадровых комитетов, а также ряд дополнительных атрибутов:  
\- _array_ \- массив участников кадровых комитетов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – идентификатор участника кадрового комитета (целое число).  
     _object\_id_ – идентификатор участника кадрового комитета (целое число).  
     _object\_name_ – наименование участника кадрового комитета (строка).  
     _catalog_ – тип объекта участника кадрового комитета (строка) (например, организация, подразделение, группа подразделений и т.д.)  
     _position\_name_ – название должности участника кадрового комитета (строка).  
     _position\_parent\_name_ – название подразделения, в котором работает участник кадрового комитета (строка).  
     _status_ – тип статуса участника кадрового комитета (строка) (например, подтвержден, не подтвержден, ожидает подтверждения и т.д.)  
     _status\_name_ – название статуса участника кадрового комитета (строка).  
     _f\_question_ – обсуждаемый вопрос (строка).  
     _link_ – ссылка на карточку участника кадрового комитета (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetPersonnelCommitteeList", [iPersonID, arrStates, oSort]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
