## SetPersonnelReserve

Метод **SetPersonnelReserve** предназначен для добавления резервиста и изменения его параметров в составе кадрового резерва.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "SetPersonnelReserve", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _PersonnelReserveParam_ \- текущий кадровый резерв (ID, или XmElem, или Doc) (целое число или объект).   
     _iCareerReserveTypeIDParam_ \- ID типа кадрового резерва (целое число).  
     _iPersonIDParam_ \- ID сотрудника (целое число).  
     _oFormField_ \- параметры из формы (объект) (в т.ч. _name_ \- название поля (строка), _label_ – метка (строка), _type_ – тип поля (строка), _value_ – значение (строка), _entries_ – входные параметры (массив объектов (_parent_ – ссылка на родительский объект (строка), _value_ – значение (строка))), _validation_ – контрольное значение (строка), _mandatory_ – является ли поле обязательным (булево), _css\_class_ – параметры CSS (строка), _error\_message_ – сообщение об ошибке (строка), _column_ – количество колонок (целое число), _visibility_ – видимость (булево)).  
     _Params_ \- дополнительные устанавливаемые атрибуты кадрового резерва (массив объектов) (в т.ч. _name_ \- название (строка) и _value_ \- значение (строка)).  
     _bCopyExams_ \- требуется ли копирование набора испытаний из типа кадрового резерва (булево).  
     _bStartExams_ \- нужно ли cразу начинать испытания при создании кадрового резерва (булево).   
     _bAllowExams_ \- требуется ли учитывать испытания при изменении статуса на Зачислен в резерв (булево).  
     _bCreateCareerReserve_ \- требуется ли создание/привязка этапа развития карьеры (булево).

_Возвращаемые значения:_

      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _message_ – сообщение о выполнении (строка).  
\- _reload_ – указание на перезагрузку страницы (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "SetPersonnelReserve", [PersonnelReserveParam, iCareerReserveTypeIDParam, iPersonIDParam, oFormField, Params, bCopyExams, bStartExams, bAllowExams, bCreateCareerReserve]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
