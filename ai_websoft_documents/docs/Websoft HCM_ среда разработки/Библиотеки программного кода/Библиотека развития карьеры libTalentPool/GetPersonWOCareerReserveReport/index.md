## GetPersonWOCareerReserveReport

Метод GetPersonWOCareerReserveReport предназначен для формирования отчета «Преемники, резервисты и маршруты без планов развития».

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetPersonWOCareerReserveReport", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _iApplicationID_ \- ID приложения (целое число).  
     _oFilters_ \- объект с фильтрами (параметрами) отчета (объект). В состав объекта входят следующие параметры: _status\_types_ – статусы типов для отбора (массив строк); _org\_id_ – ID организации для отбора (целое число); _subdivision\_id_ \- ID подразделения для отбора (целое число); _plan\_types_ – типы планов для отбора (массив строк); _status\_reserves_ – статусы резерва для отбора (массив строк); _status\_successors_ – статусы преемников для отбора (массив строк); _status\_routes_ \- статусы ключевой должности для отбора (массив строк).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень объектов с фильтрами (параметрами) отчета, а также ряд дополнительных атрибутов:  
\- _array_ \- массив объектов с параметрами отчета (массив объектов).  
     Атрибуты отдельного объекта:  
     _person\_id_ \- ID сотрудника (целое число).  
     _person\_fullname_ \- ФИО сотрудника (строка).  
     _person\_position\_name_ \- должность сотрудника (строка).  
     _person\_subdivision_ \- подразделение (строка).  
     _person\_org_ \- организация (строка).  
     _personnel\_reserve\_type\_name_ \- название типа резерва (строка).  
     _key\_position\_name_ \- название ключевой должности (строка).  
     _key\_position\_subdivision\_name_ \- название подразделения с ключевой должностью (строка).  
     _career\_plan\_name_ \- название карьерного плана (строка).  
     _career\_plan\_stage\_name_ \- название этапа карьерного плана (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetPersonWOCareerReserveReport", [iCurUserID, iApplicationID, oFilters ]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
