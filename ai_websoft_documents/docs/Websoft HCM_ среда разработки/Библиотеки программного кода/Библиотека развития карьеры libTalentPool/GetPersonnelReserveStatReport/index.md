## GetPersonnelReserveStatReport

Метод **GetPersonnelReserveStatReport** предназначен для формирования отчета «Cтатистика по кадровому резерву».

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetPersonnelReserveStatReport", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _iApplicationID_ \- ID приложения (целое число).  
     _oFilters_ \- объект с фильтрами (параметрами) отчета (объект). В состав объекта входят следующие параметры: _career\_reserve\_type\_id_ – ID типа карьерного резерва для отбора (целое число); _org\_id_ – ID организации для отбора (целое число); _subdivision\_id_ \- ID подразделения для отбора (целое число); _date\_start_ \- начало периода отбора (дата); _date\_end_ \- конец периода отбора (дата).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень объектов с фильтрами (параметрами) отчета, а также ряд дополнительных атрибутов:  
\- _result_ \- объект с параметрами отчета (объект).  
     Атрибуты объекта:  
     _candidate\_count_ – количество резервистов этого типа со статусом «Кандидат» (целое число).  
     _in\_reserve\_count_ – количество резервистов этого типа со статусом «Состоит в резерве» (целое число).  
     _left\_reserve\_count_ – количество резервистов этого типа со статусом «Исключен из резерва» (целое число).  
     _failed\_count_ – количество резервистов этого типа со статусом «Не прошел испытания» (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetPersonnelReserveStatReport", [iCurUserID, iApplicationID, oFilters ]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
