## GetTalentPoolNomination

Метод предназначен для получения списка способов выдвижения в кадровый резерв.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetTalentPoolNomination", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Для данного метода используется **пустой массив аргументов**. 

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит список способов выдвижения в кадровый резерв, а также ряд дополнительных атрибутов:  
\- _result_ \- массив способов выдвижения в кадровый резерв (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID способа выдвижения в кадровый резерв (целое число);  
     _name_ – название способа выдвижения в кадровый резерв (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetTalentPoolNomination", []);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
