## AssignTypicalPrograms

Метод **AssignTypicalPrograms** производит добавление задач типовой программы развития в адаптацию сотрудника.  
С 2022 г. этот метод рекомендуется использовать вместо устаревшей функции _**AssignTypicalProgram**_.

Функция добавляет все подходящие типовые программы из типовой должности сотрудника, группы подразделений и семейства должностей (в зависимости от параметров) и объединяет их последовательно или параллельно.   
При этом в плане деятельности формируются этапы, связанные с каждой из отобранных программ.   
Наставники, указанные в этих программах, могут добавляться в наставники этапа развития карьеры.  

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "AssignTypicalPrograms", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. 

     Массив включает в себя шесть параметров:  
     _iAdaptationCareerReserve_ - ID адаптации сотрудника (целое число).   
     _CareerReserveObject_ \- TopElem или документ адаптации сотрудника (объект XmlElem).  
     _arrTypicalProgramIDs_ \- массив ID типовых программ развития (в порядке добавления) (массив целых чисел).  
     _sMergeType_ \- тип добавления (строка). Допустимые значения: _'parallel' (объединение параллельно), 'serial' (объединение последовательно)_.  
     _sAdjustDayType_ \- тип учета дат (строка). Допустимые значения: _'calendar'_ (календарные дни), _'working'_ (рабочие дни).  
     _oModificators_ – набор дополнительных параметров выборки (объект). Данный объект включает в себя следующие параметры: _bClearAllTasks_ – нужна ли предварительная очистка всего плана деятельности существующего этапа развития карьеры (адаптации) (булево), _CanAddTasks_ - включает/выключает добавление новых задач из типовой программы в план развития (булево); _CanEditTasks_ \- включает/выключает обновление существующих задач (булево); _EditStates_ \- статусы задач, при которых задача может быть изменена (массив строк); _CanDeleteTasks_ \- включает/выключает удаление из плана деятельности тех задач, которые были удалены из типовой программы (булево), _DeleteStates_ – массив статусов задач, при которых задача может быть удалена (массив строк); _CancelInsteadDelete_ \- задачи вместо удаления переводятся в статус **Отменена** (булево).

_Возвращаемые значения:_

Выполняется добавление задач типовой программы развития в адаптацию сотрудника. Возвращаемое значение имеет тип **Объект**.   
Содержит следующие атрибуты:  
\- _result_ – результат вызова метода (объект).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "AssignTypicalPrograms", [iAdaptationCareerReserve, CareerReserveObject, arrTypicalProgramIDs, sMergeType, sAdjustDayType, oModificators]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
