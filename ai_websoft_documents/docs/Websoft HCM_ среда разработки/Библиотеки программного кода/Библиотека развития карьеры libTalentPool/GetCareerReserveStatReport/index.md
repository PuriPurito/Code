## GetCareerReserveStatReport

Метод **GetCareerReserveStatReport** предназначен для формирования отчета «Статистика по планам карьерных этапов».

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetCareerReserveStatReport", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _iApplicationID_ \- ID приложения (целое число).  
     _oFilters_ \- объект с фильтрами (параметрами) отчета (объект). В состав объекта входят следующие параметры: plan\_types – типы плана (строка); org\_id - ID организации (целое число); subdivision\_id - ID подразделения (целое число); date\_start - начало периода отбора (дата); date\_end - конец периода отбора (дата). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию о назначенных планах карьерных этапов, а также ряд дополнительных атрибутов:  
\- _array_ \- массив объектов с параметрами отчета (массив объектов).  
     Атрибуты отдельного объекта:  
     _name_ \- наименование параметра отчета (например, '#Назначено планов') (строка).   
     _code_ \- наименование параметра отчета (например, 'all') (строка).  
     _count_ \- количество назначенных планов (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetCareerReserveStatReport", [iCurUserID, iApplicationID, oFilters ]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
