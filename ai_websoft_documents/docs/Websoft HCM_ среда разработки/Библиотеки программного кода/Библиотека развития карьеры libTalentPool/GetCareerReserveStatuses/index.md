## GetCareerReserveStatuses

Метод предназначен для получения списка статусов этапов развития карьеры.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetCareerReserveStatuses", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
      Для данного метода используется **пустой массив аргументов**. 

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит перечень статусов этапов развития карьеры, а также ряд дополнительных атрибутов:  
\- _result_ \- массив статусов этапов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID статуса (строка);  
     _name_ – название статуса (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Данный агент должен быть выполнен на сервере_` 

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetCareerReserveStatuses", [ ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
