## GetExclusionReason

Метод предназначен для получения списка оснований для исключения, которые могут быть использованы в кадровом резерве.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetExclusionReason", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Для данного метода используется **пустой массив аргументов**.

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит список оснований для исключения, а также ряд дополнительных атрибутов:  
\- _result_ \- массив оснований для исключения (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID основания для исключения (целое число);  
     _name_ – название основания для исключения (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetExclusionReason", []);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
