## GetTalentPoolCuratorsByPerson

Метод предназначен для получения списка кураторов по сотруднику или по кадровому резерву.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetTalentPoolCuratorsByPerson", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iObjectIDParam_ \- ID сотрудника или карточки кадрового резерва, по которому осуществляется отбор кураторов (целое число).

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит список кураторов, а также ряд дополнительных атрибутов:  
\- _result_ \- массив кураторов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID куратора (целое число);  
     _name_ \- ФИО куратора (строка);  
     _position\_id_ \- ID должности куратора (целое число);  
     _position\_name_ – наименование должности куратора (строка);  
     _org\_id_ \- ID организации (целое число);  
     _org\_name_ \- наименование организации (строка);  
     _subdivision\_id_ \- ID подразделения (целое число);  
     _subdivision\_name_ \- наименование подразделения (строка);  
     _boss\_type\_id_ \- ID типа руководителя (целое число);  
     _boss\_type\_name_ \- наименование типа руководителя (строка);  
     _message_ \- дополнительная (служебная) информация о кураторе (строка);  
     _image\_url_ \- URL изображения куратора (строка);  
     _form\_url_ \- ссылка на карточку куратора (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetTalentPoolCuratorsByPerson", [ iObjectIDParam ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
