## GetAdaptation

Метод производит получение списка адаптаций подчиненных сотрудников указанного непосредственного руководителя.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetAdaptation", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя восемь параметров:  
     _iPersonIDParam_  – ID сотрудника, по которому осуществляется выборка этапов развития карьеры (целое число).   
     _sPersonType_ \- тип сотрудника для отбора (строка). Допустимые значения: _'all'_ – отбор всех этапов, _'person'_ – отбор этапов, которые проходит данный сотрудник, _'tutor'_ – отбор этапов, в которых указанный сотрудник является наставником, _'boss'_ \- отбор этапов сотрудников, для которых указанный сотрудник является руководителем.   
     _Statuses_ – массив статусов для отбора объектов (массив строк).  
     _sAccessType_ \- тип доступа (строка) (необязательный). Доступные значения: _"admin", "manager", "hr", "observer", "auto"_. По умолчанию - _"auto"_.  
     _sApplication_ \- код или идентифификатор (ID) приложения, по которому определяется доступ (строка).  
     _filter_ \- XQuery-фильтр (строка) (необязательный).  
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).  
     _oCalcProblemParams_ \- набор параметров для вычисления проблем (объект).

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит перечень адаптаций подчиненных сотрудников, а также ряд дополнительных атрибутов:  
\- _result_ \- массив адаптаций (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID адаптации (целое число);  
     _person\_id_ \- ID сотрудника (целое число);  
     _name_ \- ФИО сотрудника (строка);  
     _position_ \- должность сотрудника (строка);  
     _start\_date\_native_ \- дата начала адаптации (дата);  
     _start\_date_ \- дата начала адаптации в текстовом формате (строка);  
     _plan\_readiness\_date_ \- плановая дата окончания адаптации в текстовом формате (строка);  
     finish\_date\_native - дата окончания адаптации (дата);   
     plan\_readiness\_date\_native - дата планового окончания адаптации (дата);   
     plan\_readiness\_date - дата планового окончания адаптации в текстовом формате (строка);  
     finish\_date - дата окончания адаптации в текстовом формате (строка);  
     _readiness\_percent\_string_  \- процент завершенности в строковом выражении (строка).  
     _readiness\_percent_ \- процент завершенности в числовом выражении (действительное число);  
     _status_ \- статус адаптации (строка);  
     _subdivision_ \- подразделение (строка);  
     _boss\_type\_name_ \- наименование типа руководителя (строка);  
     _tutors\_number_ \- количество наставников (целое число);  
     _image\_url_ \- ссылка на изображение сотрудника (строка);  
     _link_ \- ссылка на карточку адаптации (строка);  
     _done\_percent\_native_ \- процент завершенности адаптации в строковом выражении (строка).  
     _done\_percent_ \- процент завершенности адаптации в числовом выражении (действительное число).   
     process\_progress - ход процесса (возможные значения 'Без проблем'/'Требует внимания'/'Есть проблемы/) (строка).  
     status\_id - ID статуса (строка).  
     text\_html - текст в формате HTML для описания процесса (строка).

Примечание. Атрибуты _done\_percent\_native_ и _done\_percent_ намечены на перспективу и временно могут не определяться.

  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetAdaptation", [iPersonIDParam, sPersonType, Statuses, sAccessType, sApplication, filter, oCollectionParams, oCalcProblemParams]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
