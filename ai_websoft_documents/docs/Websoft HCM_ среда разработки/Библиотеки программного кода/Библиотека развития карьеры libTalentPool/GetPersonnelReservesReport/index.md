## GetPersonnelReservesReport

Метод **GetPersonnelReservesReport** предназначен для формирования отчета по резервистам.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetPersonnelReservesReport", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _iApplicationID_ \- ID приложения (целое число).  
     _oFilters_ \- объект с фильтрами (параметрами) отчета (объект). В состав объекта входят следующие параметры: career\_reserve\_type\_id – ID типа карьерного резерва для отбора (целое число); org\_id – ID организации для отбора (целое число); subdivision\_id - ID подразделения для отбора (целое число); status\_types – статусы типов для отбора (массив строк); date\_start - начало периода отбора (дата); date\_end - конец периода отбора (дата); compare\_params – массив параметров для сравнения (массив строк).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень объектов с фильтрами (параметрами) отчета, а также ряд дополнительных атрибутов:  
\- array - массив объектов с параметрами отчета (массив объектов).  
     Атрибуты отдельного объекта:  
     career\_reserve\_type\_name – название типа карьерного резерва (строка).  
     person\_id - ID сотрудника (целое число).  
     person\_fullname - ФИО сотрудника (строка).  
     person\_position\_name - название должности сотрудника (строка).  
     person\_subdivision - название подразделения (строка).  
     person\_org - название организации (строка).  
     status - статус (строка).  
     start\_date - начало периода (дата).  
     include\_reserve\_date - дата включения в резерв (дата).  
     finish\_date - конец периода (дата).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetPersonnelReservesReport", [iCurUserID, iApplicationID, oFilters ]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
