## GetExclusionReasonContext

Метод **GetExclusionReasonContext** предназначен для вычисления контекста основания для исключения.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetExclusionReasonContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _iExclusionReasonIDParam_ \- ID основания для исключения (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию об основании для исключения, а также ряд дополнительных атрибутов:  
\- context - информация об основании для исключения (объект).  
     Атрибуты объекта:  
     personnel\_reserve\_count – общее число резервистов со всеми статусами, у которых указано это основание для исключения (целое число).  
     excluded\_count – число резервистов со статусом Исключен из резерва, у которых указано это основание для исключения (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetExclusionReasonContext", [iExclusionReasonIDParam ]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
