## GetAdaptationURLByPerson

Метод **GetAdaptationURLByPerson** предназначен для получения URL карточки адаптации указанного сотрудника..

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetAdaptationURLByPerson", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _Param_ – набор параметров этапа развития карьеры (объект). Набор включает в себя следующие элементы: _object\_id_ \- ID этапа развития карьеры (целое число), _person\_id_ - ID сотрудника, по которому ищется запись этапа развития карьеры (целое число), _url_ - исходная ссылка (строка). 

_Возвращаемое значение:_  
      Тип: **Строка**. Содержит URL карточки адаптации сотрудника.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetAdaptationURLByPerson", [Param]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
