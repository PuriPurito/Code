## AddAdaptation (устаревшая)

Метод производит добавление адаптации для сотрудника.

Если адаптация для указанного сотрудника уже была назначена ранее и осталась незавершенной, то выводится сообщение об ошибке. 

Примечание - Начиная с версии 2022.2, данная функция помечена как **deprecated**.   
Данную функцию использовать не рекомендуется. Вместо нее следует использовать функцию **CreateAdaptations** (libTalentPool/CreateAdaptations).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "AddAdaptation", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iPersonID_ – ID сотрудника, которому добавляется адаптация (целое число).    
     _dStartDate_ – дата начала (дата) (необязательный).   
     _dPlanReadinessDate_ – дата планируемой готовности (дата) (необязательный).   
     _arrTutorIDs_ – массив ID наставников (массив целых чисел) (необязательный). Элементы массива могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.

_Возвращаемое значение:_  
            Тип: **Целое число**. ID созданной адаптации.
