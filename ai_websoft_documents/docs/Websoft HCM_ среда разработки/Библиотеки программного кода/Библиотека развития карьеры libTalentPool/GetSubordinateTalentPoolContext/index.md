## GetSubordinateTalentPoolContext

Метод **GetSubordinateTalentPoolContext** предназначен для расчета объектной метрики (контекста) преемников и резервистов по подчиненным сотрудникам.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetSubordinateTalentPoolContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _PersonIDParam_ \- ID сотрудника, для которого определяются метрики (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные объектной метрики (контекста) преемников и резервистов по подчиненным сотрудникам, а также ряд дополнительных атрибутов:  
\- _context_ – данные метрики (контекста) преемника или резервиста (объект).  
     Атрибуты отдельного объекта:  
     _iKeyPositionNum_ – общее число ключевых должностей (целое число);  
     _iKeyPositionWOSuccessorNum_ – количество ключевых должностей без преемников, число ключевых должностей, для которых нет ни одного преемника со статусом _"Согласован"_ (целое число);  
     _iSuccessionActiveNum_ – количество несогласованных преемников, общее число преемников со статусом _"На согласовании"_ (целое число);  
     _iSuccessionApproveNum_ – количество согласованных преемников, общее число преемников со статусом _"Согласован"_ (целое число);  
     _iPersonnelReserveInReserveNum_ – количество резервистов – общее количество резервистов со статусом _"Состоит в кадровом резерве"_ (целое число);  
     _iPersonnelReserveCandidateNum_ – количество кандидатов в резерв, общее количество резервистов со статусом _"Кандидат"_ (целое число);  
     _iPersonnelReserveLeftNum_ – количество исключенных из резерва, общее количество резервистов со статусом _"Исключен из резерва"_ (целое число);  
     _bCreateKeyPosition_ – руководителю разрешено создание ключевых должностей (булево);   
     _bCreateSuccessor_ – руководителю разрешено создание преемников (булево);  
     _bRequestSuccessor_ \- возможность подачи заявок на преемников на портале (булево).  
     _iRequestTypeSuccessor_ \- ID типа заявок для подачи заявок на добавление преемников (целое число).  
     _bCreateReserve_ – руководителю разрешено создание резервистов (булево);  
     _bRequestAddSuccessor_ – руководителю разрешена подача заявок на добавление преемников (булево);  
     _bRequestSuccessorStatusChange_ – руководителю разрешена подача заявок на на смену статусов преемников (булево);  
     _bRequestAddPersonalReserve_ – руководителям разрешена подача заявок на включение в кадровый резерв подчиненного (булево);  
     _bRequestSelfPersonalReserve_ – сотрудникам разрешена подача заявок на включение себя в кадровый резерв  
     _bRequestPersonalReserveStatusChange_ – руководителю разрешена подача заявок на на смену статусов кадрового резерва (резервиста) (булево);  
     _bAddSuccessorWOPersonalReserve_ – можно выбирать преемников из подчиненных, не состоящих в кадровом резерве (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetSubordinateTalentPoolContext", [PersonIDParam]);_`
