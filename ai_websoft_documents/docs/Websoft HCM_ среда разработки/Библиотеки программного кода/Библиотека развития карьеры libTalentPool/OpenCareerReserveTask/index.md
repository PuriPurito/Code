## OpenCareerReserveTask

Метод **OpenCareerReserveTask** предназначен для создания отклика (результата) по работе с резервом.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "OpenCareerReserveTask", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя девять параметров:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _iCareerReserveActID_ \- ID этапа развития карьеры (целое число).  
     _sTaskID_ \- ID задачи плана деятельности (строка).  
     _bNewWindow_ \- включает/выключает открытие задачи в новом окне браузера (булево) (необязательный). Игнорируется для мобильных устройств.  
     _bCanChangeTask_ \- разрешает/запрещает назначение активностей и смену статусов задач (булево) (необязательный).  
     _bCanChangeBeforeDate_ \- разрешает/запрещает назначение активностей и смену статусов задач до наступления плановой даты (булево) (необязательный).  
     _sLink_ \- ссылка на объект, получаемая из результатов выборки (строка).  
     _sCommand_ \- режим выполнения удаленного действия (показ или обработка формы) (строка). Допустимые значения: "eval" (создание и показ формы); "submit\_form" (обработка формы).  
     _SCOPE\_WVARS_ – JSON-объект с параметрами удаленного действия (объект).     

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _action\_result_ – результат вызова метода (объект).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "OpenCareerReserveTask", [iCurUserID, iCareerReserveActID, sTaskID, bNewWindow, bCanChangeTask, bCanChangeBeforeDate, sLink, sCommand, SCOPE_WVARS ]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
