## AddTypicalDevelopmentProgramToObject

Метод **AddTypicalDevelopmentProgramToObject** предназначен для добавления типовых программ развития в объект.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "AddTypicalDevelopmentProgramToObject", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _arrObjectIDs_ \- массив идентификаторов типовых программ развития (массив целых чисел).  
     _arrResObjectIDs_ \- массив идентификатор типовых должностей, семейств должностей или группы подразделений (массив целых чисел).  
     _sTypeAdd_ \- способ назначения (строка). Доступные значения: any - любое, int - внутреннее, ext – внешнее.  
     _sComment_ – комментарий (строка).

_Возвращаемые значения:_

      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _count_ \- количество добавленных типовых программ (целое число).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "AddTypicalDevelopmentProgramToObject", [arrObjectIDs, arrResObjectIDs, sTypeAdd, sComment]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
