## CreateAdaptations

Метод **CreateAdaptations** предназначен для создания адаптаций для сотрудников.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "CreateAdaptations", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _arrPersonIDs_ – массив идентификаторов сотрудников, которым добавляются адаптации (массив целых чисел).  
     _oParam_ \- параметры добавления адаптации (объект).  
           Возможные свойства объекта (если отсутствует, берется значение по умолчанию):  
           - APPLICATION - код или ID приложения, для которого вызывается метод, по умолчанию - пусто (вне приложения);  
           - external\_depth - глубина поиска сотрудников (в днях) от даты приема, кому назначать адаптацию, по умолчанию 30 дней  
           - internal\_depth - глубина поиска сотрудников (в днях) от даты назначения на должность, кому назначать адаптацию, по умолчанию 30 дней  
           - state - статус назначенной адаптации, по умолчанию - plan (Планируется)  
           - merge\_type - тип объединения нескольких типовых програм, по умолчанию parallel (задачи встраиваются в соответствии с датами), возможные значения - serial (задачи дополнительных программ добавляются последовательно, без учета дат)  
           - program\_choise - массив критерием поиска типовых программ - subdivision\_group (по требованиям для группы подразделений)/ position\_family (по требованиям для семейства должностей)/ position\_common (по требованиями для типовой должности)/ optionally (указаный список)  
           - development\_program\_ids - массив ID типовых программ для назначения (если program\_choise включает optionally)  
           - tutors\_mode - массив вариантов поиска наставника - fact (фактический)/ func (функциональный)/ optionally (указанный) - в качестве наставников будут указаны все найденные по критериям  
           - tutor\_person\_ids - массив ID наставников (если tutors\_mode включает optionally)  
           - tutor\_boss\_type\_id - тип функционального руководителя (если tutors\_mode включает func)  
           - start\_date\_mode - тип даты старта программы - today (сегодня)/ tomorrow (с завтрашнего дня)/ optionally (указанная)  
           - start\_date - дата старта программы (если start\_date\_mode = optionally)  
           - send\_notification - флаг true|false - отправлять или нет уведомления  
           - send\_target - массив, кому отправлять - person (самому сотруднику)/ boss (непосредственному руководителю)/ tutor (наставникам)  
           - collaborator\_notification\_id - ID типа уведомления для сотрудника  
           - boss\_notification\_id - ID типа уведомления для руководителя и наставника  
           - custom\_option - дополнительные опции отправки - with\_add\_text (с доп. текстом)  
           - add\_text - текст, добавляемый к основному тексту уведомления (если custom\_option = with\_add\_text)  
           - type\_create\_notification - тип формирования уведомления - blank (без шаблона)  
           - message\_subject - текст для темы уведомления (если type\_create\_notification = blank)  
           - message\_body - текст уведомления (если type\_create\_notification = blank)  
           - message\_format - формат текста уведомления (если type\_create\_notification = blank) - plane (простой текст)/ html

_Возвращаемые значения:_

      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "CreateAdaptations", [arrPersonIDs, oParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
