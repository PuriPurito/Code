## GetCareerReserveTutorsByID

Метод предназначен для получения списка наставников в этапе развития карьеры. 

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetCareerReserveTutorsByID", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iCareerReserveIDParam_ – ID этапа развития карьеры (целое число).    
     _sTutorType_ \- тип наставника (строка) (необязательный). Допустимые значения: _"all", "tutor", "task\_tutor", "other\_tutor", "without"._ Значение по умолчанию - _"all"_.  
     _oAccessParam_ \- данные для определения доступа (объект).

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит перечень наставников в этапе развития карьеры, а также ряд дополнительных атрибутов:  
\- _result_ \- массив информации о наставниках (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID руководителя (целое число);  
     _name_ \- ФИО руководителя (строка);  
     _position\_id_ \- ID должности руководителя (целое число);  
     _position\_name_ – наименование должности руководителя (строка);  
     _org\_id_ \- ID организации (целое число);  
     _org\_name_ \- наименование организации (строка);  
     _subdivision\_id_ \- ID подразделения (целое число);  
     _subdivision\_name_ \- наименование подразделения (строка);  
     _boss\_type\_id_ \- ID типа руководителя (целое число);  
     _boss\_type\_name_ \- наименование типа руководителя (строка);  
     _message_ \- дополнительная (служебная) информация о руководителе (строка);  
     _image\_url_ \- URL изображения руководителя (строка);  
     _form\_url_ \- ссылка на карточку руководителя (строка).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример 1:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetCareerReserveTutorsByID", [ iCareerReserveIDParam, sTutorType, oAccessParam]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
