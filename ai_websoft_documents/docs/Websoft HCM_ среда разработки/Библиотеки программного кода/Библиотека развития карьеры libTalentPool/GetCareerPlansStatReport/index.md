## GetCareerPlansStatReport

Метод **GetCareerPlansStatReport** предназначен для получения статистики по карьерным маршрутам.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetCareerPlansStatReport", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _iApplicationID_ \- ID приложения (целое число).  
     _oFilters_ \- набор фильтров для формирования отчета (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит статистические данные по карьерным маршрутам, а также ряд дополнительных атрибутов:  
\- result - статистические данные по карьерным маршрутам (объект).  
     Атрибуты объекта:  
     routes\_count - количество карьерных маршрутов (целое число);  
     plan\_count - количество запланированных карьерных маршрутов (целое число);,  
     active\_count - количество активных карьерных маршрутов, со статусом В работе (целое число);  
     passed\_count - количество пройденных карьерных маршрутов, со статусом Пройдено успешно (целое число);  
     failed\_count - количество непройденных карьерных маршрутов, со статусом Пройдено неуспешно (целое число);  
     cancel\_count - количество прерванных карьерных маршрутов (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetCareerPlansStatReport", [iCurUserID, iApplicationID, oFilters]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
