## GetTalentPoolPersonWithSelectedTasks

Метод предназначен для получения списка сотрудников с задачами указанного типа.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetTalentPoolPersonWithSelectedTasks", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _iPersonIDParam_ \- ID сотрудника, по которому осуществляется выборка этапов развития карьеры (целое число).  
     _sPersonType_ \- тип сотрудника для отбора (строка). Допустимые значения: _'person'_ – отбор этапов, которые проходит данный сотрудник, _'tutor'_ – отбор этапов, в которых указанный сотрудник является наставником, _'curator'_ \- отбор этапов, в которых указанный сотрудник является куратором кадровых резервов, _'boss'_ \- отбор этапов, в которых указанный сотрудник является руководителем.   
     _sSelectType_ \- тип задач для отбора (строка). Допустимые значения: _'active'_ \- актуальные, _'expire'_ - просроченные.  
     _bIsAdaptation_ \- выборка только из адаптаций (булево).  
     _bShowPersonnelReserveTasks_ \- выборка также и испытаний, указанных в требованиях кадрового резерва (булево).

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит список сотрудников с задачами определенного типа, а также ряд дополнительных атрибутов:  
\- _result_ \- массив сотрудников (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID сотрудника (целое число);  
     _name_ \- ФИО сотрудника (строка);  
     _position\_id_ \- ID должности сотрудника (целое число);  
     _position\_name_ – наименование должности сотрудника (строка);  
     _org\_id_ \- ID организации (целое число);  
     _org\_name_ \- наименование организации (строка);  
     _subdivision\_id_ \- ID подразделения (целое число);  
     _subdivision\_name_ \- наименование подразделения (строка);  
     _boss\_type\_id_ \- ID типа руководителя (целое число);  
     _boss\_type\_name_ \- наименование типа руководителя (строка);  
     _message_ \- дополнительная (служебная) информация о сотруднике (строка);  
     _image\_url_ \- URL изображения сотрудника (строка);  
     _form\_url_ \- ссылка на карточку сотрудника (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetTalentPoolPersonWithSelectedTasks", [ iPersonIDParam, sPersonType, sSelectType, bIsAdaptation, bShowPersonnelReserveTasks ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
