## GetCareerReserveHierStageTaskByID

Метод предназначен для получения иерархического списка этапов программы развития (заданий программы развития типа «Этап») по этапу развития карьеры.

В качестве аргумента необходимо выбрать этап развития карьеры, для которого определены задания программы развития типа «Этап».  
Этапы программы развития в WebTutor Administrator определяются в карточке этапа развития карьеры (**Развитие карьеры – Этапы развития карьеры** – выбрать этап развития карьеры – вкладка **План деятельности** – добавить задание программы развития – тип задания: **Этап**). 

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetCareerReserveHierStageTaskByID", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iCareerReserveIDParam_ – ID этапа развития карьеры (целое число).    
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).  
     _oAccessParam_ \- данные для определения доступа (объект).

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит Содержит иерархический список заданий программы развития типа «Этап», а также ряд дополнительных атрибутов:  
\- _result_ \- массив заданий программы развития (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID записи (целое число);  
     _task\_id_ \- ID задачи (целое число);  
     _object\_id_ \- ID объекта справочника, в состав которого вxодит задача (целое число);  
     _object\_catalog_ \- имя справочника, в состав объекта которого вxодит задача (строка);  
     _object\_catalog\_title_ \- наименование справочника, в состав объекта которого вxодит задача (строка);  
     _person\_id_ \- ID сотрудника, которому назначена задача (целое число);  
     _person\_fullname_ \- ФИО сотрудника, которому назначена задача (строка);  
     _parent\_id_ \- ID родительской задачи (этапа программы развития) (целое число);  
     _has\_children_ \- возможность наличия дочерних элементов (булево);  
     _name_ \- наименование задачи (строка);  
     _type_ \- ID типа задачи (строка);  
     _type\_desc_ \- наименование типа задачи (строка);  
     _status_ \- ID статуса задачи (строка);  
     _status\_desc_ \- наименование статуса задачи (наименование) (строка);  
     _start\_date\_date_ \- плановая дата начала в формате даты (дата);  
     _start\_date_ \- плановая дата начала в строчном формате (строка);  
     _plan\_date\_date_ \- плановая дата выполнения в формате даты (дата);  
     _plan\_date_ \- плановая дата выполнения в строчном формате (строка);  
     _score_ \- оценка (целое число);  
     _tutor\_id_ \- ID наставника (целое число);  
     _tutor\_fullname_ \- ФИО наставника (строка);  
     _activity\_type_ \- тип (имя каталога) объекта по задаче (строка);  
     _desc_ \- описание задачи (строка);  
     _message_ \- дополнительная (служебная) информация по задаче (строка);  
     _activity\_id_ \- ID объекта по задаче (целое число);  
     _activity\_name_ \- наименование объекта по задаче (строка);  
     _activity\_link_ \- ссылка на карточку объекта (строка).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetCareerReserveHierStageTaskByID", [iCareerReserveIDParam, oCollectionParams, oAccessParam]);_      _// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
