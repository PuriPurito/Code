## GetPersonnelReserveType

Метод предназначен для получения списка типов кадрового резерва по указанному куратору или по всей системе в целом.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetPersonnelReserveType", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iPersonIDParam_ - ID куратора, по которому осуществляется выборка типов кадрового резерва (целое число) (необязательный). При отсутствии данного аргумента **указывается пустой массив**, и выборка производится по всей системе в целом. 

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит список типов кадрового резерва, а также ряд дополнительных атрибутов:  
\- _result_ \- массив типов кадрового резерва (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID типа кадрового резерва (целое число);  
     _name_ – название типа кадрового резерва (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetPersonnelReserveType", [ iPersonIDParam ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
