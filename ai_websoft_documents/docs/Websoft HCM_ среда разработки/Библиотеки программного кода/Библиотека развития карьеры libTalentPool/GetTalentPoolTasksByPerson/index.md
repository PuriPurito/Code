## GetTalentPoolTasksByPerson

Метод предназначен для получения списка задач для указанного сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetTalentPoolTasksByPerson", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _iPersonIDParam_ \- ID сотрудника, по которому осуществляется выборка этапов развития карьеры (целое число).  
     _sPersonType_ \- тип сотрудника для отбора (строка). Допустимые значения: _'person'_ – отбор этапов, которые проходит данный сотрудник, _'tutor'_ – отбор этапов, в которых указанный сотрудник является наставником, _'curator'_ \- отбор этапов, в которых указанный сотрудник является куратором кадровых резервов, _'boss'_ \- отбор этапов, в которых указанный сотрудник является руководителем.   
     _sSelectType_ \- тип задач для отбора (строка). Допустимые значения: _'all'_ – все типы задач, _'active'_ \- актуальные, _'tutor\_heed'_ \- требующие внимания наставника (например, оценки), _'expire'_ \- просроченные.  
     _bIsAdaptation_ \- выборка только из адаптаций (булево).  
     _bShowPersonnelReserveTasks_ \- выборка также и испытаний, указанных в требованиях кадрового резерва (булево).  
  
  
     Массив включает в себя один параметр:  
     _iObjectID_ – ID объекта, имеющего ссылки на значения карты знаний (целое число). Если метод вызывается из веб-шаблона и данный аргумент не задан, то данные могут быть взяты из текущего объекта (**curObject**).   
     _iLectorID_ – ID преподавателя (целое число). Если метод вызывается из веб-шаблона и данный аргумент не задан, то данные могут быть взяты из текущего объекта (**curObject**).      

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит список задач для указанного сотрудника, а также ряд дополнительных атрибутов:  
\- _result_ \- массив задач (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID записи (целое число);  
     _task\_id_ \- ID задачи (целое число);  
     _object\_id_ \- ID объекта справочника, в состав которого вxодит задача (целое число);  
     _object\_catalog_ \- имя справочника, в состав объекта которого вxодит задача (строка);  
     _object\_catalog\_title_ \- наименование справочника, в состав объекта которого вxодит задача (строка);  
     _person\_id_ \- ID сотрудника, которому назначена задача (целое число);  
     _person\_fullname_ \- ФИО сотрудника, которому назначена задача (строка);  
     _parent\_id_ \- ID родительской задачи (этапа программы развития) (целое число);  
     _has\_children_ \- возможность наличия дочерних элементов (булево);  
     _name_ \- наименование задачи (строка);  
     _type_ \- ID типа задачи (строка);  
     _type\_desc_ \- наименование типа задачи (строка);  
     _status_ \- ID статуса задачи (строка);  
     _status\_desc_ \- наименование статуса задачи (наименование) (строка);  
     _start\_date\_date_ \- плановая дата начала в формате даты (дата);  
     _start\_date_ \- плановая дата начала в строчном формате (строка);  
     _plan\_date\_date_ \- плановая дата выполнения в формате даты (дата);  
     _plan\_date_ \- плановая дата выполнения в строчном формате (строка);  
     _score_ \- оценка (целое число);  
     _tutor\_id_ \- ID наставника (целое число);  
     _tutor\_fullname_ \- ФИО наставника (строка);  
     _activity\_type_ \- тип (имя каталога) объекта по задаче (строка);  
     _desc_ \- описание задачи (строка);  
     _message_ \- дополнительная (служебная) информация по задаче (строка);  
     _activity\_id_ \- ID объекта по задаче (целое число);  
     _activity\_name_ \- наименование объекта по задаче (строка);  
     _activity\_link_ \- ссылка на карточку объекта (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetTalentPoolTasksByPerson", [ iPersonIDParam, sPersonType, sSelectType, bIsAdaptation, bShowPersonnelReserveTasks ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
