## GetCareerPlansReport

Метод **GetCareerPlansReport** предназначен для формирования отчета по карьерным маршрутам.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetCareerPlansReport", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _iApplicationID_ \- ID приложения (целое число).  
     _oFilters_ \- набор фильтров для формирования отчета (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные отчета по карьерным маршрутам, а также ряд дополнительных атрибутов:  
\- array - массив карьерных маршрутов (массив объектов).  
     Атрибуты отдельного объекта:  
     code – код карьерного маршрута (строка);  
     name – название карьерного маршрута (строка);  
     person\_id – ID сотрудника (целое число);  
     person\_fullname – ФИО сотрудника (строка);  
     target – цель карьерного маршрута (строка);  
     status – статус карьерного маршрута (строка);  
     start\_date – начало карьерного маршрута (дата).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetCareerPlansReport", [iCurUserID, iApplicationID, oFilters]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
