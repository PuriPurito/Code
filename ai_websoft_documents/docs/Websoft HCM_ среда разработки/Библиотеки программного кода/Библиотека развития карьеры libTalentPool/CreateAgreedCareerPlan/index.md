## CreateAgreedCareerPlan

Метод **CreateAgreedCareerPlan** предназначен для создания согласованного карьерного плана.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "CreateAgreedCareerPlan", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iCareerPlanIDParam_ \- идентификатор типового карьерного плана (для типовой должности, группы или семейства должностей) (целое число).  
     _iPersonIDParam_ \- идентификатор сотрудника, которому согласован план (целое число).  
     _sStatus_ \- статус карьерного плана (строка).

_Возвращаемые значения:_

      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _DocID_ – идентификатор нового согласованного карьерного плана (целое число).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "CreateAgreedCareerPlan", [iCareerPlanIDParam, iPersonIDParam, sStatus]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
