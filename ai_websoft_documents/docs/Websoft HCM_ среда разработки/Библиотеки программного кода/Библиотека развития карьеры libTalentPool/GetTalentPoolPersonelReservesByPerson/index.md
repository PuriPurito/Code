## GetTalentPoolPersonelReservesByPerson

Метод предназначен для получения списка кадровых резервов по сотруднику.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetTalentPoolPersonelReservesByPerson", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя восемь параметров:  
     _iPersonIDParam_ \- ID сотрудника, по которому осуществляется выборка этапов развития карьеры (целое число).  
     _sPersonType_ \- тип сотрудника для отбора (строка). Допустимые значения: _'person'_ – отбор этапов, которые проходит данный сотрудник, _'tutor'_ – отбор этапов, в которых указанный сотрудник является наставником, _'curator'_ \- отбор этапов, в которых указанный сотрудник является куратором кадровых резервов, _'boss'_ \- отбор этапов, в которых указанный сотрудник является руководителем.   
     _sTypeSubordinate_ \- типы подчинения (критерий отбора) (строка). Например, _"all\_subordinates"_ (непосредственные и функциональные подчиненные с иерархией).  
     _arrBossTypesID_ \- массив ID типов руководителей (массив целых чисел).  
     _arrDistinct_ \- перечень полей для формирования дополнительных списков для виджета фильтров (массив строк).  
     _arrFilters_ \- набор фильтров (массив объектов).  
     oSort - информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).  
     oPaging - информация из рантайма о пейджинге (объект). Объект включает в себя следующие данные:  INDEX - номер страницы (целое число);  SIZE - размер страницы (целое число); MANUAL - разделение на страницы вручную (булево); TOTAL - общее количество страниц (целое число).

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит список кадровых резервов по сотруднику, а также ряд дополнительных атрибутов:  
\- _result_ \- массив кадровых резервов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID кадрового резерва (целое число);  
     _name_ \- название кадрового резерва (строка);  
     _career\_reserve\_type\_id_ \- ID типа кадрового резерва (целое число);  
     _career\_reserve\_type\_name_ \- наименование типа кадрового резерва (строка);  
     _person\_id_ \- ID сотрудника (целое число);  
     _person\_fullname_ \- ФИО сотрудника (строка);  
     _start\_date_ \- дата получения статуса "Кандидат"  
     _include\_reserve\_date_ \- дата включения в резерв (строка);  
     _finish\_date_ \- дата закрытия (строка);  
     _status_ \- ID статуса кадрового резерва (строка);  
     _status\_desc_ \- наименование статуса кадрового резерва (строка);  
     _message_ \- дополнительная (служебная) информация по кадровому резерву (строка);  
     _nomination\_id_ \- ID способа выдвижения в резерв (целое число);  
     _nomination\_name_ \- наименование способа выдвижения в резерв (строка);  
     _exclusion\_reason\_id_ \- ID основания для исключения (целое число);  
     _exclusion\_reason\_name_ \- наименование основания для исключения (строка);  
     _development\_potential\_id_ \- ID потенциала развития (целое число);  
     _development\_potential\_name_ \- наименование потенциала развития (строка);  
     _efficiency\_estimation\_id_ \- ID оценки эффективности (целое число);  
     _efficiency\_estimation\_name_ \- наименование оценки эффективности (строка);  
     _career\_reserve\_id_ \- ID связанного этапа развития карьеры (целое число);  
     _career\_reserve\_readiness\_percent_ \- процент готовности (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetTalentPoolPersonelReservesByPerson", [iPersonIDParam, sPersonType, sTypeSubordinate, arrBossTypesID, arrDistinct, arrFilters, oSort, oPaging]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
