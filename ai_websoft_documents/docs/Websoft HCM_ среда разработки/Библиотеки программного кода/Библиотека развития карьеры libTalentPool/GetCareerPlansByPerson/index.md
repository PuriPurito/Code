## GetCareerPlansByPerson

Метод **GetCareerPlansByPerson** предназначен для получения списка карьерных планов по сотруднику.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetCareerPlansByPerson", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _PersonIDParam_ \- ID сотрудника, для которого отбираются карьерные планы (целое число);  
     _sCareerPlanTypes_ \- строка с массивом типов планов (типов связанных объектов) (строка);  
     _bGetCalculateField_ \- расчет дополнительных вычисляемых полей (булево).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень карьерных планов по сотруднику, а также ряд дополнительных атрибутов:  
\- _result_ \- массив карьерных планов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID карьерного плана (целое число);  
     _name_ \- название карьерного плана (строка);  
     _object\_type_ \- тип карьерного плана (строка);  
     _object\_type\_name_ \- название типа карьерного плана (строка);  
     _start\_date_ \- дата включения карьерного плана (дата);   
     _status_ \- код статуса карьерного плана (строка);  
     _status\_desc_ \- описание (наименование) статуса карьерного плана (строка);  
     _budget\_period\_id_ \- ID бюджетного периода (целое число);  
     _budget\_period\_name_ \- наименование бюджетного периода (строка);  
     _object\_id_ \- ID связанного объекта карьерного плана (целое число);  
     _object\_name_ \- наименование связанного объекта карьерного плана (строка);  
     _done\_percent_ \- процент заверщенности карьерного плана (строка);  
     _message_ \- дополнительная (служебная) информация по карьерному плану (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetCareerPlansByPerson", [PersonIDParam, sCareerPlanTypes, bGetCalculateField]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
