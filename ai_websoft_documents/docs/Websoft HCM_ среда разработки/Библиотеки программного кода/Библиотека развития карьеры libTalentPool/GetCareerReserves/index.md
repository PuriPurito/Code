## GetCareerReserves

Метод **GetCareerReserves** предназначен для получения списка этапов развития указанного типа цели по сотруднику.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetCareerReserves", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя четыре параметра:  
     _iPersonIDParam_ \- ID сотрудника, по которому осуществляется выборка этапов развития карьеры (целое число).  
     _oSelectionParams_ \- набор параметров для отбора записей каталога (объект). В состав объекта входят следующие параметры: _personID_ - ID сотрудника, по которому осуществляется выборка этапов развития карьеры (имеет приоритет перед отдельным аргументом функции) (целое число); _personType_ \- тип отбора по сотрудникам (строка) (all - любые, _person_ \- по сотруднику, чей этап, tutor - этапы, где указанный сотрудник является наставником, _boss_ – этапы, где указанный сотрудник является руководителем; _reserveID_ \- ID карьерного резерва, по которому отбираются этапы (целое число); _successorID_ \- ID преемника, по которому отбираются этапы (целое число); _planID_ \- ID карьерного плана, по которому отбираются этапы (целое число); _goals_ - набор целевых типов (массив строк) ('position' (целевая должность), 'position\_common' (целевая типовая должность), 'staff\_position' (целевая позиция штатного расписания), 'name' (название целевой должности), 'adaptation' (адаптация)); statuses - массив статусов для отбора объектов (массив строк); _objectInclude_ – связанные объекты, которые учитываются при отборе (массив строк). ('personnel\_reserve' (резервисты), 'successor' (преемники), 'career\_plan' (карьерные маршруты)); _applAccessType_ \- тип доступа для отбора (строка) ("admin"/"manager"/"hr"/"tutor"/"observer"/"auto"); applParam - код/ID приложения, по которому определяется доступ (строка); _sXqueryQual_ \- дополнительные условия отбора в синтакстсе XQuery (строка).  
     _oCollectionParams_ \- Набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).  
     _oCalcProblemParams_ \- Набор параметров для вычисления проблем (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень этапов развития указанного типа цели по сотруднику, а также ряд дополнительных атрибутов:  
\- result - массив этапов развития указанного типа цели по сотруднику (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID этапа развития (целое число).   
     _name_ \- ФИО сотрудника (строка).  
     _position_ \- должность сотрудника (строка).  
     _start\_date\_date_ \- дата начала адаптации (дата).   
     _start\_date_ \- дата начала адаптации в текстовом формате (строка).   
     _plan\_readiness\_date\_date_ \- плановая дата окончания адаптации (дата).   
     _plan\_readiness\_date_ \- плановая дата окончания адаптации в текстовом формате (строка).  
     _readiness\_percent\_string_  \- процент завершенности в текстовом формате (форматированная строка).  
     _readiness\_percent_ \- процент завершенности (действительное число).   
     _status_ \- статус адаптации (строка).  
     _boss\_type\_name_ \- наименование типа руководителя (строка).  
     _link_ \- ссылка на карточку адаптации (строка).  
     _done\_percent_ \- процент завершенности адаптации (действительное число)  
     _done\_percent\_native_ \- процент завершенности адаптации в текстовом формате (строка).  
     _process\_progress_ \- ход процесса (строка). Допустимые значения: Без проблем/Требует внимания/Есть проблемы)  
     _status\_id_ \- ID статуса в текстовом формате (строка).  
     _text\_html_ \- текст в формате HTML для плитки (тайла) (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetCareerReserves", [iPersonIDParam, oSelectionParams, oCollectionParams, oCalcProblemParams ]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
