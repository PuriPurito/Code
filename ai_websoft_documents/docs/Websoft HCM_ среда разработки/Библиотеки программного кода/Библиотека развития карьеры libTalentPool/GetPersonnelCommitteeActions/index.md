## GetPersonnelCommitteeActions

Метод **GetPersonnelCommitteeActions** предназначен для определения перечня действий кадрового комитета.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetPersonnelCommitteeActions", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iPersonnelCommitteeIDParam_ \- идентификатор кадрового комитета (целое число).  
     _iCurUserIDParam_ \- идентификатор сотрудника (целое число).  
     _sRemoteActionsParam_ – дополнительные данные для отбора (строка). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень действий кадрового комитета, а также ряд дополнительных атрибутов:  
\- _array_ \- массив действий кадрового комитета (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – идентификатор действия кадрового комитета (целое число).   
     _name_ \- название действия кадрового комитета (строка).  
     _operation_ \- код действия кадрового комитета (строка).  
     _ra\_id_ \- идентификатор удаленного действия (целое число).  
     _ra\_name_ \- название удаленного действия (строка).  
     _ra\_params_ \- параметры удаленного действия в формате JSON (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetPersonnelCommitteeActions", [iPersonnelCommitteeIDParam, iCurUserIDParam , sRemoteActionsParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
