## GetTutors

Метод **GetTutors** предназначен для получения списка наставников.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetTutors", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _iCurUserID_ \- идентификатор текущего пользователя (целое число).  
     _sAccessType_ \- тип доступа (строка). Доступные значения: _"admin", "manager", "hr", "observer", "auto"_.  
     _iApplicationID_ \- идентификатор приложения, по которому определяется доступ (целое число).  
     _sXQueryQual_ \- строка для XQuery-фильтра (строка).  
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию о наставниках, а также ряд дополнительных атрибутов:  
\- _array_ \- массив данных о наставниках (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – идентификатор наставника (целое число);  
     _code_ – код наставника (строка);  
     _disp\_name_ \- условное наименование наставника (строка);  
     _name_ \- официальное наименование наставника (строка);

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetTutors", [iCurUserID, sAccessType, iApplicationID, sXQueryQual, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
