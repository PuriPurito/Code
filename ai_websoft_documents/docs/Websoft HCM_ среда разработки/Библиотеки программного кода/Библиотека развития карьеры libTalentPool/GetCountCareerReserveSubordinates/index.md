## GetCountCareerReserveSubordinates

Метод предназначен для получения информации о количестве этапов развития карьеры подчиненных для указанного руководителя.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetCountCareerReserveSubordinates", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iPersonID_ \- ID руководителя (целое число).  
     _bIsAdaptation_ \- выборка только адаптаций (булево).  
     _bIsActiveOnly_ \- выборка только активных этапов развития карьеры (булево).  
     _bIsCountTrainees_ \- подсчет сотрудников (_true_ \- считать только для непосредственных подчиненных, _false_ \- считать для всех подчиненных) (булево). 

_Возвращаемое значение:_  
      Тип: **Целое число**. Количество этапов развития карьеры подчиненных.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetCountCareerReserveSubordinates", [ iPersonID, bIsAdaptation, bIsActiveOnly, bIsCountTrainees ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
