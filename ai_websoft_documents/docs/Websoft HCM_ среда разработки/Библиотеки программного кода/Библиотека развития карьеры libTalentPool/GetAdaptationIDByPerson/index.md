## GetAdaptationIDByPerson

Метод **GetAdaptationIDByPerson** предназначен для получения ID адаптации указанного сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetAdaptationIDByPerson", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iObjectIDParam_ \- ID этапа развития карьеры (целое число) (необязательный). Если значение отсутствует, оно определяется по параметру _iPersonID_.  
     _iPersonID_ \- ID сотрудника, по которому ищется запись этапа развития карьеры (целое число) (необязательный). Если значение отсутствует, оно определяется по параметру _iObjectIDParam_. 

_Возвращаемое значение:_  
      Тип: **Целое число**. ID адаптации указанного сотрудника.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetAdaptationIDByPerson", [iObjectIDParam, iPersonID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
