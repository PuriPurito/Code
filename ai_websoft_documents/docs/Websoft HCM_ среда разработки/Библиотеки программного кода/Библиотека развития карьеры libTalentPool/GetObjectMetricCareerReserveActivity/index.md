## GetObjectMetricCareerReserveActivity

Метод **GetObjectMetricCareerReserveActivity** предназначен для получения количества актуальных (текущих) активностей всех типов в текущем этапе или в полном плане деятельности этапа развития карьеры.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetObjectMetricCareerReserveActivity", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _iObjectIDParam_ \- ID текущего объекта (целое число).  
     _iPersonIDParam_ \- ID сотрудника, по которому ищется запись этапа развития карьеры (целое число).  
     _sActualizeMode_ \- способ актуализации активности (строка). Может принимать значения: _"date"_ \- по интервалу дат в задаче, _"status"_ - по статусу задачи и наличию назначенной активностию  
     _bCheckActualStageParam_ – поиск в пределах текущего этапа плана развития карьеры (булево) (необязательный). Если параметр имеет значение true, то поиск производится поиск в пределах текущего этапа развития карьеры; если false, то поиск производится в полном плане деятельности этапа развития карьеры. Значение по умолчанию - _false_.  
     _sCareerReserveType_ \- тип цели этапа развития карьеры (строка) (необязательный). Значение по умолчанию - _"adaptation"_.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные об активностях (активных курсах, тестах и др.) в этапе развития карьеры:  
\- _CountActiveCourse_ – количество активных курсов в этапе развития карьеры (целое число);  
\- _CountActiveDocumentLearning_ – количество активных ознакомлений с материалом в этапе развития карьеры (целое число);  
\- _CountActiveTest_ – количество активных тестов в этапе развития карьеры (целое число);  
\- _CountActiveEducationMethod_ – количество активных учебных программ в этапе развития карьеры (целое число);  
\- _CountActiveTasks_ – количество активных задач в этапе развития карьеры (целое число).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetObjectMetricCareerReserveActivity", [iObjectIDParam, iPersonIDParam, sActualizeMode, bCheckActualStageParam, sCareerReserveType]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
