## GetPersonnelReserveContext

Метод **GetPersonnelReserveContext** предназначен для вычисления контекста для кадрового резерва.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetPersonnelReserveContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _iPersonnelReserveIDParam_ \- ID кадрового резерва (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию о кадровом резерве, а также ряд дополнительных атрибутов:  
\- _context_ \- информация о кадровом резерве (объект).  
     Атрибуты объекта:  
     _all\_task\_count_ – общее количество испытаний в карточке со всеми статусами, кроме «Отменен» (целое число).  
     _success\_task\_count_ – количество испытаний в статусе «Пройдено успешно» (целое число).  
     _failed\_task\_count_ – количество испытаний в статусе «Пройдено неуспешно» (целое число).  
     _cr\_count_ – число этапов развития карьеры сотрудника, привязанных к данной карточке кадрового резерва (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetPersonnelReserveContext", [iPersonnelReserveIDParam ]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
