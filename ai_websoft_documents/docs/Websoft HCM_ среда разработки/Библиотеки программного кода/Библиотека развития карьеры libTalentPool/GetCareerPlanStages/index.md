## GetCareerPlanStages

Метод **GetCareerPlanStages** предназначен для получения списка этапов карьерного плана.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetCareerPlanStages", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iCareerPlanID_ \- ID карьерного плана (целое число).  
     _bIsForTree_ \- построение коллекции для представления в виде маршрута (булево).  
     _oAccessParam_ \- объект со сведениями для вычисления доступа (объект). Объект содержит, в частности, следующие поля: user\_id - ID сотрудника (целое число), access\_type - тип доступа (строка), cur\_lng - язык системы (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень этапов карьерного плана, а также ряд дополнительных атрибутов:  
\- _result_ \- массив этапов карьерного плана (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID этапа карьерного плана (целое число);  
     _name_ \- название этапа карьерного плана (строка);  
     _transition\_direction_ \- код направления этапа карьерного плана (строка);  
     _transition\_direction\_name_ \- наименование направления этапа карьерного плана (строка);  
     _position\_common\_id_ – ID типовой должности (целое число);  
     _position\_common\_name_ \- название типовой должности (строка);  
     _position\_id_ \- ID должности (целое число);  
     _position\_name_ \- название должности (строка);  
     _plan\_date_ \- плановая дата начала этапа (дата);   
     _fact\_date_ \- фактическая дата начала этапа (дата);   
     _status_ \- код статуса карьерного плана (строка);  
     _status\_desc_ \- описание (наименование) статуса карьерного плана (строка);  
     _budget\_period\_id_ \- ID бюджетного периода (целое число);  
     _budget\_period\_name_ \- название бюджетного периода (строка);  
     _stipulation_ \- дополнительное условие (строка);  
     _comment_ \- комментарий (строка);  
     _message_ \- дополнительная (служебная) информация по этапу карьерного плана (строка);  
     hier\_id - ID ветви в дереве (по иерархии) (строка);  
     title - название этапа карьерного плана (строка);  
     level - уровень записи (целое число);  
     parent - ID родительской ветви дерева в текстовом формате (строка);  
     text - текст (строка);  
     desc - описание (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetCareerPlanStages", [iCareerPlanID, bIsForTree, oAccessParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
