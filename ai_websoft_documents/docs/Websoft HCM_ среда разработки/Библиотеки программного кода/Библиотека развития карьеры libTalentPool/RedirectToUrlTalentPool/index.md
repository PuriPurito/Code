## RedirectToUrlTalentPool

Метод **RedirectToUrlTalentPool** предназначен для обработки ссылки в _Редакторе страниц_ (Landing Page Editor (LPE)).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "RedirectToUrlTalentPool", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _Param_ – набор параметров (объект). Включает в себя следующие элементы: _type_ – тип задачи (строка), _activity\_link_ – ссылка на активность (строка), _link\_msg_ – комментарий к ссылке (строка).

_Возвращаемые значения:_

     Тип: **Объект**. Содержит следующие атрибуты:  
\- result – объект, содержащий тип команды и ссылку (URL).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- errorText – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_`  
`_oRes = tools.call_code_library_method ("libTalentPool", "RedirectToUrlTalentPool", [Param]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
