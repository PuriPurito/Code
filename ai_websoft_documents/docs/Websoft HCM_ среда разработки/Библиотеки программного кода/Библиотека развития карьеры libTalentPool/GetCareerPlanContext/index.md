## GetCareerPlanContext

Метод **GetCareerPlanContext** предназначен для получения контекстных показателей для карьерного плана.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTalentPool", "GetCareerPlanContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _iCareerPlanID_ \- ID карьерного плана (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит контекстные показатели для карьерного плана, а также ряд дополнительных атрибутов:  
\- context - контекстные показатели для карьерного плана (объект).  
     Атрибуты объекта:  
     stages\_count – общее количество этапов в маршруте (целое число).  
     active\_stages\_count – число этапов в маршруте со статусом В работе (целое число).  
     expired\_stages\_count – число просроченных этапов (целое число).  
     passed\_stages\_count – число этапов в маршруте со статусом Пройдено успешно (целое число).  
     failed\_stages\_count – число этапов в маршруте со статусом Пройдено неуспешно (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTalentPool", "GetCareerPlanContext", [iCareerPlanID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
