## GetTasks

Метод **GetTasks** предназначен для получения списка задач.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProject", "GetTasks", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя одиннадцать параметров:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _sType_ \- тип выборки задач (строка). Могут быть испоьзованы следующие значения: _'my'_ (все задачи), _'preparation'_ (все задачи с добавлением подготовительных задач), '_my\_sub_' (все задачи с добавлением задач подчиненных сотрудников).  
     _dCreateDateStart_ \- начало интервала поиска по критерию даты создания задачи (дата) (необязательный). Если дата не указана, поиск производится по всему периоду.  
     _dCreateDateFinish_ \- конец интервала поиска по критерию даты создания задачи (дата) (необязательный). Если дата не указана, поиск производится по всему периоду.  
     _iAssignerID_ \- ID сотрудника, назначившего задачу (целое число) (необязательный). Если сотрудник не указан, поиск не зависит от лица, назначившего задачу.  
     _iTaskTypeID_ \- ID типа задачи (целое число) (необязательный).  
     _iProjectID_ \- ID проекта (целое число) (необязательный). Если ID проекта не указан, поиск производится по всем проектам.  
     _sStatus_ \- статус задачи (строка) (необязательный). Если статус не указан, поиск производится по всем статусам.  
     _sSearch_ \- строка поиска (строка) (необязательный). Если строка поиска не указана, используется пустая строка.  
     _sAccessRole_ \- роль пользователя (строка) (необязательный). Если роль пользователя не указана, поиск производится по всем ролям.  
     _aPersons_ \- массив ID сотрудников, участвующих в проекте (массив целых чисел) (необязательный).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень задач, а также ряд дополнительных атрибутов:  
\- _array_ \- массив задач (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID задачи (целое число);  
     _name_ – название задачи (строка);  
     _status_ \- статус задачи (строка);  
     _priority_\- приоритет задачи (строка) ("Низкий"; "Средний"; "Высокий");  
     _start\_date\_plan_ \- планируемая дата начала (дата);  
     _end\_date\_plan_ \- планируемая дата завершения (дата);  
     _date\_plan_ \- фактическая дата начала (дата);  
     _date\_end_ \- фактическая дата завершения (дата);  
     _mark_ \- оценка (действительное число);  
     _assigner\_id_ – ID сотрудника, назначившего задачу (целое число);  
     _assigner_ \- ФИО сотрудника, назначившего задачу (строка);  
     _executor\_id_ – ID сотрудника, исполняющего задачу (целое число);  
     _executor_ \- ФИО сотрудника, исполняющего задачу (строка);  
     _workflow\_state\_name_ \- название текущего этапа документооборота (строка);  
     _expired_ \- срок действия задачи истек (булево);  
     _link_ – относительная ссылка на задачу (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProject", "GetTasks", [iPersonID, sType, dCreateDateStart, dCreateDateFinish, iAssignerID, iTaskTypeID, iProjectID, sStatus, sSearch, sAccessRole, aPersons]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
