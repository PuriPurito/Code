## AddProjectParicipant

Метод **AddProjectParicipant** предназначен для начала планирования проекта.  
Данный метод предсттавляет собой удаленное действие, которое вызывает на клиенте диалоговую форму. В этой форме, в частности, можно выбрать проект, в который добавляется сотрудник. 

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProject", "AddProjectParicipant", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _sCommand_ \- режим выполнения удаленного действия (_"eval"_ (создание и показ формы); _"submit\_form"_ (обработка формы)) (строка).   
     _iBossID_ \- ID текущего пользователя (руководителя) (целое число).  
     _iPersonID_ \- ID пользователя (целое число).  
     _SCOPE\_WVARS_ \- входные параметры удаленного действия (объект) (в частности, _bSendNotificationAfterInclude_ – отправлять ли уведомление сотруднику о включении в проект (булево), _fields_ – cериализованное содержимое формы (строка)).  
    _aFieldEntries_ \- данные entries переменной fields удаленного действия (массив объектов). В состав объекта входят следующие параметры: name - название поля (строка); label - метка поля (строка); type - тип поля (строка); value - значение поля (строка); entries - входные параметры поля (массив объектов) (parent - родительский параметр (строка); value - значение (строка)); validation - контрольное значение (строка); mandatory - является ли поле обязательным (булево); css\_class - параметры CSS (строка); error\_message - сообщение об ошибке (строка); column - количество колонок (целое число); visibility - видимость (булево). 

_Возвращаемые значения:_

      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _result_ – результат вызова метода (объект). Состав объекта зависит от значения параметров _sCommand_ и _SCOPE\_WVARS.fields_.  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProject", "AddProjectParicipant", [sCommand, iBossID, iPersonID, SCOPE_WVARS, aFieldEntries]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
