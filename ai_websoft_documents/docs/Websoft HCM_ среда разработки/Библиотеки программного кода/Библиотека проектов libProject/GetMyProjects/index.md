## GetMyProjects

Метод **GetMyProjects** предназначен для получения списка проектов сотрудника в зависимости от заданных параметров.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProject", "GetMyProjects", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _sTypeProjects_ \- Тип возвращаемых проектов (мои (_'my'_) или доступные (_'open'_)) (строка) (необязательный). Значение по умолчанию - _'my'_.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень проектов сотрудника в зависимости от заданных параметров, а также ряд дополнительных атрибутов:  
\- _array_ \- массив проектов сотрудника (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID проекта (целое число).  
     _name_ – название проекта (строка).  
     _status_ – статус проекта (строка).  
     status\_id – ID статуса проекта (строка).  
     _date\_start_ – дата начала проекта (дата).  
     _date\_end_ – дата окончания проекта (дата).  
     _managers_ – руководители (менеджеры) проекта (массив объектов).  
     _has\_team_ – имеется проектная команда (булево).  
     _percent\_complete_ – процент выполнения проекта (строка).  
     _roles_ – роли сотрудника в проекте (строка).  
     _warning_ – сообщение о нарушении срока окончания проекта (строка).  
     _roles\_filter_ – фильтр ролей проекта (строка).  
     _link_ – относительная ссылка на проект (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProject", "GetMyProjects", [iPersonID, sTypeProjects]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
