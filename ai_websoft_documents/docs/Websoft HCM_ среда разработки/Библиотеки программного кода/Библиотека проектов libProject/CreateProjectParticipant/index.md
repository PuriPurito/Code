## CreateProjectParticipant

Метод _CreateProjectParticipant_ предназначен для создания/редактирования карточки участника проекта.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProject", "CreateProjectParticipant", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя семь параметров:  
     _sCommand_ \- режим выполнения удаленного действия (показ формы/обработка формы) (строка) (например: _'eval', 'submit\_form'_).  
     _iPersonID_ \- ID текущего пользователя (целое число).  
     _tePerson_ \- TopElem текущего пользователя (объект XmlElem).  
     _iProjectID_ \- ID проекта (целое число).  
     _iProjectParticipantID_ \- ID участника проекта (целое число). Если данный параметр не задан, то создается новый участник.  
     _SCOPE\_WVARS_ \- входные параметры удаленного действия (объект) (в том числе: _sChoiceParticipants_ – выбор участников из подчиненных (_'subordinates'_) или из всех сотрудников (_'all'_) (строка) (по умолчанию – _'all'_ (из всех сотрудников)), _bSendNotificationAfterInclude_ – отправлять/не отправлять уведомление сотруднику о включении в проект (булево), _bSendNotificationChangeRole_ – отправлять/не отправлять уведомление участнику о смене роли (булево), _bCommentRequired_ – поле комментарий обязательно/не обязательно к заполнению (булево), _bRolesRequired_ – поле роли обязательно/не обязательно к заполнению (булево), _bWithoutAgreement_ – включать сотрудника в проект без согласования (булево), _fields_ – cериализованное содержимое формы (строка)).  
    _aFieldEntries_ \- данные entries переменной fields удаленного действия (массив объектов). В состав объекта входят следующие параметры: name - название поля (строка); label - метка поля (строка); type - тип поля (строка); value - значение поля (строка); entries - входные параметры поля (массив объектов) (parent - родительский параметр (строка); value - значение (строка)); validation - контрольное значение (строка); mandatory - является ли поле обязательным (булево); css\_class - параметры CSS (строка); error\_message - сообщение об ошибке (строка); column - количество колонок (целое число); visibility - видимость (булево). 

_Возвращаемые значения:_

\- _result_ – поля карточки (объект).  
     Атрибуты объекта:  
     _name_ \- название (строка) (например: _'roles', 'start\_date', 'finish\_date'_).  
     _page_ \- страница (строка) (например: _'main'_).  
     _label_ \- надпись (строка).  
     _mandatory_ – обязательность заполнения (булево).   
     _type_ – тип поля (строка) (например: _'text'_ (текст), _'string'_ (строка), _'integer'_ (целое число), _'bool'_ (булево), _'date'_ (дата), _'select'_ (выбор значения из списка), _'foreign\_elem'_ (ссылка), _'file'_ (файл)).   
     _richtext_ – возможность форматирования (для типа _'text'_) (булево).   
     _catalog_ – название каталога (для ссылок) (строка) (например: _'project'_).   
     _value_ – значение (соответствует атрибуту _type_).   
     _disabled_ – поле заблокировано (булево).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProject", "CreateProjectParticipant", [sCommand, iPersonID, tePerson, iProjectID, iProjectParticipantID, SCOPE_WVARS, aFieldEntries]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
