## CreateProjectParticipantRole

Метод **CreateProjectParticipantRole** предназначен для создания и/или редактирования роли участника проекта.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProject", "CreateProjectParticipantRole", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _sCommand_ \- режим выполнения удаленного действия (_"eval"_ (создание и показ формы); _"submit\_form"_ (обработка формы)) (строка).   
     _iPersonID_ \- ID сотрудника (целое число).  
     _iProjectID_ \- ID проекта (целое число).  
     _iProjectParticipantRoleID_ \- ID роли участника проекта (целое число) (необязательный). Если ID роли не указан, создается новая роль.  
     _SCOPE\_WVARS_ \- входные параметры удаленного действия (объект) (в частности, _bSendNotificationAfterInclude_ – отправлять ли уведомление сотруднику о включении в проект (булево), _fields_ – cериализованное содержимое формы (строка)). 

_Возвращаемые значения:_

      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProject", "CreateProjectParticipantRole", [sCommand, iPersonID, iProjectID, iProjectParticipantRoleID, SCOPE_WVARS]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
