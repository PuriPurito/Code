## GetProjectRoles

Метод **GetProjectRoles** предназначен для получения списка ролей проекта.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProject", "GetProjectRoles", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iProjectID_ \- ID проекта (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень ролей проекта, а также ряд дополнительных атрибутов:  
\- _array_ \- массив ролей проекта (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID роли проекта (целое число).  
     _name_ \- название роли проекта (строка).  
     _skills_ – массив навыков (массив объектов). Параметры объекта: id - ID навыка (целое число); name - название навыка (строка); target\_level\_id - ID целевого уровня (строка).  
     _participants_ \- количество участников (целое число).  
     _comment_ \- комментарий (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProject", "GetProjectRoles", [iProjectID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
