## GetProjectsContext

Метод **GetProjectsContext** предназначен для получения контекста проекта по сотруднику.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProject", "GetProjectsContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID сотрудник (целое число).  
     _bBySubordinate_ \- учитывать ли проекты подчиненных, если сотрудник является руководителем (булево).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит контекст проекта по сотруднику, а также ряд дополнительных атрибутов:  
\- _context_ \- контекст проекта по сотруднику (объект).  
     Атрибуты объекта:  
     _projects\_num_ – общее количество проектов (целое число).  
     _active\_projects\_num_ – количество проектов в работе (целое число).  
     _expired\_projects\_num_ – количество просроченных проектов (целое число).  
     _unexpired\_projects\_num_ – количество проектов, выполненных вовремя (целое число).  
     _unexpired\_task\_percent_ – процент задач, выполненных в срок (целое число).  
     _project\_participant\_num_ – количество участников проектов (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProject", "GetProjectsContext", [iPersonID, bBySubordinate]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
