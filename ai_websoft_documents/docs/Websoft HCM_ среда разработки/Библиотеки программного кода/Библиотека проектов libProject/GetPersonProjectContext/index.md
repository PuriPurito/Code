## GetPersonProjectContext

Метод **GetPersonProjectContext** предназначен для получения контекста проекта по сотруднику.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProject", "GetPersonProjectContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iProjectID_ \- ID проекта (целое число).  
     _iPersonID_ \- ID сотрудника (целое число).  
     _iBossTypeID_ \- ID типа руководителя (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит контекст проекта по сотруднику, а также ряд дополнительных атрибутов:  
\- _context_ \- контекста проекта по сотруднику (объект).  
     Атрибуты объекта:  
     _bManager_ – является руководителем проекта (булево).  
     _bParticipant_ – является участником проекта (булево).  
     _bParticipantByBossType_ – является участников проекта c переданным типом руководителя (булево).  
     _bProjectParticipantRole_ – в проекте указаны роли участников (булево).  
     _bAllowAssessment_ – разрешена оценка участников после завершения проекта (булево).  
     _bTaskExecutor_ – является ответственным за исполнение задачи (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProject", "GetPersonProjectContext", [iProjectID, iPersonID, iBossTypeID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
