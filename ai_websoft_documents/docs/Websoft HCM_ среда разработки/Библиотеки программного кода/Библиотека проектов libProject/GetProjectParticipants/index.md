## GetProjectParticipants

Метод **GetProjectParticipants** предназначен для получения списка участников проекта.

Примечание. Выборка возвращает участников проекта с типом "Участник проекта". 

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProject", "GetProjectParticipants", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iProjectID_ \- ID проекта (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень участников проекта, а также ряд дополнительных атрибутов:  
\- _array_ \- массив участников проекта (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID участника проекта (целое число).  
     _photo_ – относительная ссылка на фотографию участника проекта (строка).  
     _fullname_ – ФИО участника проекта (строка).  
     _position_ – должность участника проекта (строка).  
     _subdivision_ – подразделение (строка).  
     _roles_ – роль участника проекта (строка).  
     _status_ – статус участника проекта (строка).  
     _percent_ – процент выполнения работ участником проекта (строка).  
     _data\_start_ – дата начала работы участника над проектом (дата).  
     _data\_end_ – дата окончания работы участника над проектом (дата).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProject", "GetProjectParticipants", [iProjectID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
