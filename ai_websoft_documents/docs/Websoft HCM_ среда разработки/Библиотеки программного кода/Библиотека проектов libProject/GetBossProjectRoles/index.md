## GetBossProjectRoles

Метод **GetBossProjectRoles** предназначен для получения списка ролей проектов сотрудника, в которых он является руководителем.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProject", "GetBossProjectRoles", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iPersonID_ \- ID сотрудника (руководителя проекта) (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень ролей проектов сотрудника, в которых он является руководителем, а также ряд дополнительных атрибутов:  
\- _array_ \- массив ролей проектов сотрудника (массив объектов).  
     Атрибуты отдельного объекта:  
     _project\_id_ \- ID проекта (целое число);  
     _project\_name_ \- название проекта (строка);  
     _project\_status_ \- статус проекта (строка);  
     _data\_start_ \- дата планового начала проекта (дата);  
     _data\_end_ \- дата планового окончания проекта (дата);  
     _role\_id_ \- ID роли проекта (целое число);  
     _role\_name_ \- название роли проекта (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProject", "GetBossProjectRoles", [iPersonID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
