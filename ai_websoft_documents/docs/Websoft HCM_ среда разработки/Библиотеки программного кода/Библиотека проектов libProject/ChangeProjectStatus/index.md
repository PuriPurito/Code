## ChangeProjectStatus

Метод **ChangeProjectStatus** предназначен для изменения статуса проекта.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProject", "ChangeProjectStatus", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _sCommand_ \- режим выполнения удаленного действия (показ формы/обработка формы) (строка) (например: _'eval'_).  
     _iPersonID_ \- ID текущего пользователя (целое число).  
     _iProjectID_ \- ID проекта (целое число).  
     _sStatus_ \- статус проекта (строка). Варианты статуса описаны в _common.project\_status\_types_ (например, _project_ (Проект), _plan_ (Планируется), _active_ (В работе), _close_ (Завершен), _cancel_ (Отменен)). 

_Возвращаемые значения:_

\- _result_ – результат вызова метода (объект со следующими параметрами: _command_ (название выполняемой команды (строка)), _msg_ (сообщение (строка)), _confirm\_result_ (действие (функция))).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProject", "ChangeProjectStatus", [sCommand, iPersonID, iProjectID, sStatus]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
