## GetProjectFiles

Метод **GetProjectFiles** предназначен для получения списка файлов проекта.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProject", "GetProjectFiles", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iProjectID_ \- ID проекта (целое число).  
     _bIncludeTaskFiles_ – учитываются ли файлы, прикрепленные к задачам, связанным с данным проектом (булево) (необязательный). Значение по умолчанию - _false_.  

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень файлов проекта, а также ряд дополнительных атрибутов:  
\- _array_ \- массив файлов проекта (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID файла (целое число).  
     _name_ – название файла (строка).  
     _link_ – относительная ссылка на файл (строка).  
     _fullname_ – ФИО сотрудника, разместившего файл (строка).  
     _position_ – должность сотрудника, разместившего файл (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProject", "GetProjectFiles", [iProjectID, bIncludeTaskFiles]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
