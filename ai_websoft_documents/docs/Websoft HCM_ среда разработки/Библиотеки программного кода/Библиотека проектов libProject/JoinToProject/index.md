## JoinToProject

Метод **JoinToProject** предназначен для добавления сотрудника в качестве участника проекта.

Примечание. В данном удаленном действии также производится проверка того, является ли сотрудник руководителем указанного проекта. 

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProject", "JoinToProject", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _sCommand_ \- Режим выполнения удаленного действия (показ формы/обработка формы) (строка) (например: _'eval', 'submit\_form'_).  
     _iPersonID_ \- ID текущего пользователя (целое число).  
     _iProjectID_ \- ID проекта (целое число).  
     _SCOPE\_WVARS_ \- входные параметры удаленного действия (объект) (в том числе: _bSendNtfPM_ – отправлять или не отправлять уведомление руководителям проекта (булево), _bCommentRequired_ – поле «Комментарий» обязательно к заполнению (булево), _bFilesRequired_ – поле «Файл» обязательно к заполнению (булево), _fields_ – cериализованное содержимое формы (строка)).  
    _aFieldEntries_ \- данные entries переменной fields удаленного действия (массив объектов). В состав объекта входят следующие параметры: name - название поля (строка); label - метка поля (строка); type - тип поля (строка); value - значение поля (строка); entries - входные параметры поля (массив объектов) (parent - родительский параметр (строка); value - значение (строка)); validation - контрольное значение (строка); mandatory - является ли поле обязательным (булево); css\_class - параметры CSS (строка); error\_message - сообщение об ошибке (строка); column - количество колонок (целое число); visibility - видимость (булево). 

_Возвращаемые значения:_  
      Тип: **Объект**. Содержит следующие атрибуты:  
\- _result_ – поля карточки (объект).  
     Атрибуты объекта:  
     _name_ \- название (строка) (например: 'roles', 'comment', 'file\_id').  
     _page_ \- страница (строка) (например: 'main').  
     _label_ \- надпись (строка).  
     _mandatory_ – обязательность заполнения (булево).   
    _type_ – тип поля (строка) (например: 'text' (текст), 'string' (строка), 'integer' (целое число), 'bool' (булево), 'date' (дата), 'select' (выбор значения из списка), 'foreign\_elem' (ссылка), 'file' (файл)).   
    _richtext_ – возможность форматирования (для типа _'text'_) (булево).   
    _catalog_ – название каталога (для ссылок) (строка) (например: _'project'_).   
    _value_ – значение (соответствует атрибуту _type_).   
    _disabled_ – поле заблокировано (булево).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProject", "JoinToProject", [sCommand, iPersonID, iProjectID, SCOPE_WVARS, aFieldEntries]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
