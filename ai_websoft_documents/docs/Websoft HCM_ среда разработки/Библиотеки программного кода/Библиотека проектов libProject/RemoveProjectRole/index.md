## RemoveProjectRole

Метод **RemoveProjectRole** предназначен для удаления роли проекта.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProject", "RemoveProjectRole", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _sCommand_ \- Режим выполнения удаленного действия (показ формы/обработка формы) (строка) (например: 'eval').  
     _iPersonID_ \- ID текущего пользователя (целое число).  
     _iRoleID_ \- ID роли (целое число).

_Возвращаемые значения:_

\- _result_ – результат вызова метода (объект со следующими параметрами: _command_ (название выполняемой команды (строка)), _msg_ (сообщение (строка)), _confirm\_result_ (действие (функция))).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProject", "RemoveProjectRole", [sCommand, iPersonID, iRoleID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
