## GetProjectManagers

Метод **GetProjectManagers** предназначен для получения списка руководителей проекта.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProject", "GetProjectManagers", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iProjectID_ \- ID проекта (целое число).  
     iBossTypeID - ID типа руководителя (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень руководителей проекта, а также ряд дополнительных атрибутов:  
\- _array_ \- массив руководителей проекта (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID руководителя проекта (целое число).  
     _name_ \- ФИО руководителя проекта (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProject", "GetProjectManagers", [iProjectID, iBossTypeID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
