## GetHierarchicalTasksPerson

Метод **GetHierarchicalTasksPerson** предназначен для получения списка этапов/задач сотрудника в проекте.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProject", "GetHierarchicalTasksPerson", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _iProjectID_ \- ID проекта (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень этапов/задач сотрудника в проекте, а также ряд дополнительных атрибутов:  
\- _array_ \- массив этапов/задач сотрудника (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID объекта (целое число).  
     _name_ \- название объекта (строка).  
     _fullname_ \- полное имя сотрудника (строка).  
     _position_ \- должность сотрудника (строка).  
     _date\_start_ \- начало работы над этапом/задачей (дата).  
     _date\_end_ \- окончание работы над этапом/задачей (дата).  
     _status_ \- статус этапа/задачи (строка). Варианты статуса описаны в _common.assessment\_appraise\_statuses_ (например, _'p' (Планируется), 'r' (Подготовлено), '0' (Выполняется), '1' (Архив), 'x' (Отменено)_)..

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProject", "GetHierarchicalTasksPerson", [iPersonID, iProjectID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
