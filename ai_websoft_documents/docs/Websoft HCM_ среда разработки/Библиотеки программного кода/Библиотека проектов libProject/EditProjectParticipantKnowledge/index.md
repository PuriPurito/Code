## EditProjectParticipantKnowledge

Метод **EditProjectParticipantKnowledge** предназначен для создания и/или редактирования подтверждения знаний для участника проекта.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProject", "EditProjectParticipantKnowledge", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     sCommand - режим выполнения удаленного действия ("eval" (создание и показ формы); "submit\_form" (обработка формы)) (строка).   
     _iPersonID_ \- ID сотрудника (целое число).  
     _iProjectParticipantID_ \- ID участника проекта (целое число).  
     _SCOPE\_WVARS_ \- входные параметры удаленного действия (объект) (в частности, _bSendNotificationAfterInclude_ – отправлять ли уведомление сотруднику о включении в проект (булево), _fields_ – cериализованное содержимое формы (строка)). 

_Возвращаемые значения:_

      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProject", "EditProjectParticipantKnowledge", [sCommand, iPersonID, iProjectParticipantID, SCOPE_WVARS]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
