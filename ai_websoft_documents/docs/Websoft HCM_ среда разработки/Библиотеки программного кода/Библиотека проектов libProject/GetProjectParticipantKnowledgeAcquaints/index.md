## GetProjectParticipantKnowledgeAcquaints

Метод **GetProjectParticipantKnowledgeAcquaints** предназначен для получения списка подтверждения знаний участника проекта.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProject", "GetProjectParticipantKnowledgeAcquaints", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     iProjectParticipantID - ID участника проекта (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень подтверждения знаний участника проекта, а также ряд дополнительных атрибутов:  
\- _array_ \- массив подтверждения знаний (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID подтверждения знаний (целое число);  
     _knowledge\_part\_name_ – название области знания (строка);  
     _current\_level\_name_ – название текущего уровня знания (строка);  
     _target\_level\_name_ – название целевого уровня знания (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProject", "GetProjectParticipantKnowledgeAcquaints", [iProjectParticipantID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
