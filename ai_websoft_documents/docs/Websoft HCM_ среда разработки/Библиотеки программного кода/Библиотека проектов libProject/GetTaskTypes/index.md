## GetTaskTypes

Метод **GetTaskTypes** предназначен для получения списка типов задач.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProject", "GetTaskTypes", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.     Массив включает в себя восемь параметров:  
     _iCurUserID_ \- ID сотрудника (целое число).  
     _aWorkSpace_ \- типы задач для отображения (массив строк).  
     _bVirtualTask_ \- нужно ли отображать виртуальные задачи (булево).  
     _aReturnData_ \- перечень атрибутов, которые будут вычисляться (массив строк).  
     _sAccessType_ \- тип доступа для отбора (строка) (необязательный). Допустимые значения: "admin" (администратор приложения); "manager" (администратор процесса); "admin\_workspace" (администратор рабочего пространства); "moderator" (модератор); "observer" (наблюдатель); "auto" (определяется автоматически в соответствии с правами доступа пользователя).   
     _sApplication_ \- код (или ID) приложения, по которому определяется доступ (строка).   
     _sXQueryQual_ \- дополнительный фильтр XQuery для отбора (строка) (необязательный).  
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень типов задач, а также ряд дополнительных атрибутов:  
\- _array_ \- массив типов задач (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID типа задачи (целое число).  
     _code_ \- код типа задачи (строка).  
     _name_ – название типа задачи (строка).  
     _task\_count_ \- количество задач данного типа (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProject", "GetTaskTypes", [iCurUserID, aWorkSpace, bVirtualTask, aReturnData, sAccessType, sApplication, sXQueryQual, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
