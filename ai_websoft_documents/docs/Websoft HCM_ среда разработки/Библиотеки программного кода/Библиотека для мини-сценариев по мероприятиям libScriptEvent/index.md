## Библиотека для мини-сценариев по мероприятиям libScriptEvent

В настоящем разделе описываются методы **библиотеки для мини-сценариев по мероприятиям** из библиотеки программного кода **libScriptEvent**. Указанные методы регистрируются в разделе **Дизайнер – Библиотеки программного кода – libScriptEvent**.

Примечание - По состоянию на май 2024 г. библиотека предназначена исключительно для внутренних нужд системы и не содержит публичных методов.
