## GetPollData

Метод **GetPollData** предназначен для получения данных опроса.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPollPlayer", "GetPollData", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.   
     Массив включает в себя три параметра:  
     _sPollId_ \- ID объекта (опроса) в строковом выражении (строка).  
     _sUserId_ \- ID пользователя в строковом выражении (строка) (необязательный). Если сотрудник не указан, используются данные текущего сотрудника.  
     _sLaunchId_ \- ID запуска в строковом выражении (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит набор данных опроса, а также ряд дополнительных атрибутов:  
\- _data_ \- набор данных опроса (объект).  
     Атрибуты объекта:  
     _id_ – ID опроса в строковом выражении (строка);  
     _type_ – тип объекта (строка). Указывается значение "poll";  
     _name_ – название опроса (строка);  
     _completed_ – завершен ли опрос (булево);  
     _start\_date_ – начало опроса (дата);  
     _end\_date_ – окончание опроса (дата);  
     _is\_anonymous_ – является ли опрос анонимным (булево);  
     _is\_one\_time_ – можно ли выполнить опрос только один раз (булево) (если указывается значение false, то опрос можно выполнять неоднократно);  
     _show\_comments\_in\_report_ – показываются ли комментарии к опросу (булево);  
     _show\_report_ – показываются ли отчет (булево);  
     _description_ – описание (строка);  
     _complete\_message_ – заполнено ли сообщение (булево);  
     _allow\_delete\_poll\_result_ – можно ли удалить результаты опроса (булево);  
     _date\_in\_poll\_period_ – заполнен ли опрос вовремя (булево);  
     _preview\_image\_url_ – относительная ссылка на предварительный просмотр изображения (строка);  
     _completed\_result\_exists_ – имеется ли полный результат опроса (булево);  
     _not\_completed\_result\_exists_ – имеется ли неполный результат опроса (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPollPlayer", "GetPollData", [sPollId, sUserId, sLaunchId]);_`   
  
`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
