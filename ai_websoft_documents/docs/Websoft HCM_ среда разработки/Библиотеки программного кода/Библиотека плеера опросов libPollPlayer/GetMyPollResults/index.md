## GetMyPollResults

Метод **GetMyPollResults** предназначен для получения результатов опросов пользователя.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPollPlayer", "GetMyPollResults", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.   
     Массив включает в себя четыре параметра:  
     _sPollId_ \- ID объекта (опроса) в строковом выражении (строка).  
     _sLaunchId_ \- ID запуска в строковом выражении (строка).  
     _sPageNum_ \- номер страницы в строковом выражении (строка).  
     _sPageSize_ \- количество элементов на странице в строковом выражении (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные результатов опросов пользователя, а также ряд дополнительных атрибутов:  
\- _data_ – данные о результатах опросов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID результата опроса в строковом выражении (строка);  
     _type_ – тип объекта (строка). Указывается значение "poll";  
     _person\_fullname_ – ФИО сотрудника (строка);  
     _avatar\_url_ – относительная ссылка на изображение (строка);  
     _date_ – дата формирования заявки в строковом выражении (строка);  
     _status_ – статус заявки (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPollPlayer", "GetMyPollResults", [sPollId, sLaunchId, sPageNum, sPageSize]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
