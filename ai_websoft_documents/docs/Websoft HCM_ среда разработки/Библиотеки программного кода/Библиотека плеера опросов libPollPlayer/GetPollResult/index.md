## GetPollResult

Метод **GetPollResult** предназначен для получения результата указанного опроса (в т.ч. набора вопросов и ответов).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libPollPlayer", "GetPollResult", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.   
     Массив включает в себя два параметра:  
     _sPollResultId_ \- ID результата опроса в строковом выражении (строка).  
     _sLaunchId_ \- ID запуска в строковом выражении (строка).

_Возвращаемое значение:_  
      Тип: **Объект**.Содержит результат указанного опроса, а также ряд дополнительных атрибутов:  
\- data - результат опроса (массив объектов).  
     Атрибуты отдельного объекта:  
    _person\_fullname_ – ФИО сотрудника, принявшего участие в опросе (строка);  
    _avatar\_url_ – относительная ссылка на изображение (строка);  
    _preview\_url_ – относительная ссылка на предварительный просмотр изображения (строка);  
    _name_ – название опроса (строка);  
    _status_ – статус опроса (строка);  
    _poll\_procedure\_name_ – название процедуры опроса (строка);  
    _date_ – дата формирования результата опроса в строковом выражении (строка);  
    items - коллекция вопросов и ответов опроса (массив объектов); в том числе:  
         _id_ – ID вопроса (целое число);  
         _title_ – заголовок (текст) вопроса (строка);  
         _type_ – тип вопроса (строка);  
         _value_ – значение ответа (строка);  
         _url_ – относительная ссылка на ресурс ответа (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libPollPlayer", "GetPollResult", [sPollResultId, sLaunchId]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
