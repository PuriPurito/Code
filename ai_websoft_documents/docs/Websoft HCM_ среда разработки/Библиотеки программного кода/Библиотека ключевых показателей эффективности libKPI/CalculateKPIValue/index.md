## CalculateKPIValue

Метод CalculateKPIValue предназначен для вычисления ключевого показателя эффективности сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKPI", "CalculateKPIValue", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iKPIIDParam_ \- ID ключевого показателя эффективности (целое число).  
     _iPersonIDParam_ \- ID сотрудника, для которого проверяются требования ключевого показателя эффективности (целое число).  
     _iPlanValue_ \- плановое значение показателя (целое число).  
     _dCurDate_ \- дата, на которою считается соответствие ключевого показателя эффективности (дата).

_Возвращаемое значение:_  
      Тип:  **Действительное число**. Ключевой показатель эффективности сотрудника.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKPI", "CalculateKPIValue", [iKPIIDParam, iPersonIDParam, iPlanValue, dCurDate]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
