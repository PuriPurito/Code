## GetPersonCertificates

Метод **GetPersonCertificates** предназначен для получения сертификатов пользователя.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetPersonCertificates", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iPersonID_ \- ID сотрудника (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень сертификатов пользователя, а также ряд дополнительных атрибутов:  
\- _array_ \- массив сертификатов (массив объектов).  
     Атрибуты отдельного объекта:  
     _img_ – относительная ссылка на унифицированное изображение сертификата (строка);  
     _name_ – название (типа) сертификата (строка);  
     _org\_name_ –  название организации, выдавшей сертификат (строка);  
     _delivery\_date_ – дата выдачи сертификата (дата)  
     _expire\_date_ – дата истечения срока действия сертификата (дата);  
     _valid_ – действителен ли сертификат (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetPersonCertificates", [iPersonID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
