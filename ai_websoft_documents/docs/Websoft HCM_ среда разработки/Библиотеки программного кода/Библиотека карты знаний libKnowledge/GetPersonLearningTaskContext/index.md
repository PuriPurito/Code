## GetPersonLearningTaskContext

Метод **GetPersonLearningTaskContext** предназначен для получения контекста выполнения заданий сотрудником.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetPersonLearningTaskContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _bGetExpertByResult_ \- пределять экспертов по заданию (по выполнению задания) (булево). Значение по умолчанию - _false_. 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит контекст выполнения заданий сотрудником, а также ряд дополнительных атрибутов:  
\- _context_ \- контекст выполнения заданий сотрудником (объект).  
     Атрибуты отдельного объекта:  
     _task\_num_ – всего заданий (целое число).  
     _done\_task\_num_ – количество выполненных заданий (целое число).  
     _passed\_task\_num_ – количество заданий, выполненных успешно (целое число).  
     _today\_task\_num_ – количество заданий, назначенных на сегодня (целое число).  
     _is\_expert_ – сотрудник является экспертом хотя бы в одном задании (выполнении задания) (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetPersonLearningTaskContext", [iPersonID, bGetExpertByResult]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
