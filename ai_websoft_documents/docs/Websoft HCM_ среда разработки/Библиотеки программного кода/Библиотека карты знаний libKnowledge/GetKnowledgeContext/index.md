## GetKnowledgeContext

Метод **GetKnowledgeContext** предназначен для получения контекста значения карты знаний.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetKnowledgeContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iKnowledgePartID_ \- ID значения карты знаний (целое число).  
     _iPersonID_ \- ID сотрудника (целое число).  
     _arrCostObjectTypes_ \- массив типов стоимости (массив строк).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о контексте значения карты знаний, а также ряд дополнительных атрибутов:  
\- _context_ \- данные о контексте значения карты знаний (объект):  
     _current\_level\_id_ – код текущего уровня (строка).  
     _current\_level\_name_ – наименование текущего уровня (строка).  
     _target\_level\_id_ – код целевого уровня (строка).  
     _target\_level\_name_ – наименование целевого уровня (строка).  
     _current\_cost_ – количество набранных баллов (целое число).  
     _target\_cost_ – целевое значение количества баллов (целое число).  
     _percent\_cost_ – процент достижения цели (действительное число).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetKnowledgeContext", [iKnowledgePartID, iPersonID, arrCostObjectTypes]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
