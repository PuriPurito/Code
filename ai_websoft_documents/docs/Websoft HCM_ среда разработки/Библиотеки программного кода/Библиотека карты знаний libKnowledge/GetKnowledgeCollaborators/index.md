## GetKnowledgeCollaborators

Метод **GetKnowledgeCollaborators** предназначен для получения информации об уровне знаний сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetKnowledgeCollaborators", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _sType_ \- тип знаний (строка).  
     _sTargetType_ \- тип отбора для требуемого уровня (строка).  
     _sReturnType_ \- тип возвращаемых данных (строка);   
     _iMaxLen_ \- максимальное количество возвращаемых записей (целое число).   
 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию об уровне знаний сотрудников, а также ряд дополнительных атрибутов:  
\- _array_ \- массив информации об уровне знаний сотрудников (массив объектов).  
     _id_ \- ID сотрудника (целое число).  
     _fullname_ – ФИО сотрудника (строка).  
     _person\_icon_ – URL изображения (фотографии) сотрудника (строка).  
     _level_ – уровень знаний (строка).  
     _level\_index_ – индекс уровня знаний (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetKnowledgeCollaborators", [iPersonID, sType, sTargetType, sReturnType, iMaxLen]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
