## GetExpertQuestionActions

Метод **GetExpertQuestionActions** предназначен для получения списка действий по вопросу, заданному эксперту.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetExpertQuestionActions", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iExpertQuestionID_ \- ID вопроса эксперту (целое число).  
     _iPersonID_ \- ID сотрудника, задавшего вопрос (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень действий по вопросу, заданному эксперту, а также ряд дополнительных атрибутов:  
\- _array_ \- массив действий (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID учебного действия (целое число);  
     _name_ \- название учебного действия (строка);  
     _action\_type_ \- тип учебного действия (строка);  
     _action\_id_ \- ID типа действия (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetExpertQuestionActions", [iExpertQuestionID, iPersonID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
