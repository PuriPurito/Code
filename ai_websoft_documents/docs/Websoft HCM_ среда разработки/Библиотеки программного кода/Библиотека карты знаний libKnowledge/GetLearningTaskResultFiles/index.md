## GetLearningTaskResultFiles

Метод **GetLearningTaskResultFiles** предназначен для получения списка файлов, прикрепленных к карточке выполнения задания.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetLearningTaskResultFiles", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iLearningTaskResultID_ \- ID выполнения задания (целое число).  
     _iPersonID_ \- ID сотрудника (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень файлов, прикрепленных к карточке выполнения задания, а также ряд дополнительных атрибутов:  
\- _array_ \- массив информации о файлах (массив объектов).  
     Атрибуты отдельного объекта:  
     _file\_id_ \- ID файла (целое число).  
     _is\_learning\_task\_result_ \- признак прикрепления к карточке выполнения задания (булево).  
     _source\_object\_id_ \- ID карточки, к которой прикреплен файл (целое число).  
     _creation\_date_ \- дата прикрепления к карточке (дата).  
     _file\_name_ \- название файла (строка).  
     _file\_download\_url_ \- ссылка для открытия/загрузки файла (строка).  
     _person\_fullname_ \- ФИО пользователя, который прикрепил файл к карточке (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetLearningTaskResultFiles", [iLearningTaskResultID, iPersonID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
