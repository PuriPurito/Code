## GetAcquaintContext

Метод **GetAcquaintContext** предназначен для получения контекста объекта (ознакомления).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetAcquaintContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iObjectID_ \- ID объекта (целое число).  
     _iUserID_ \- ID сотрудника (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит контекст объекта (ознакомления), а также ряд дополнительных атрибутов:  
_\- action\_result_ – данные о контексте ознакомления (объект):  
     _bHasActiveAcquaint_ – есть неподтвержденное назначенное ознакомление (булево).  
     _bHasAcquaint_ – есть назначенное ознакомление (булево).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetAcquaintContext", [iObjectID, iUserID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
