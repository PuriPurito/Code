## UpdateAcquaintAssign

Метод предназначен для обновление списка назначенных ознакомлений.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetCareerReserveHierStageTaskByID", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iAcquaintId_ – ID ознакомления (целое число).    
     _bDel_ – удалять назначенные уведомления, не попадающие в выборку (булево). По умолчанию - _false_ (необязательный).   
     _bDebug_ – выполнять дополнительное логирование (булево). По умолчанию - _false_ (необязательный). 

_Возвращаемое значение:_  
\- _iCounter_ \- количество назначений (целое число).

_Пример:_

`_// Пусть в системе имеется ознакомление с названием «Ознакомление 1»   // Находим программно ознакомление с названием «Ознакомление 1» с помощью функции_ _tools.get_doc_by_key_   _oAsquaint = tools.get_doc_by_key ('acquaint', 'name', 'Ознакомление 1' );   alert ( 'Найдено ознакомление ' + oAsquaint.TopElem.name + ' с идентификационным номером ' + oAsquaint.DocID ); // на экран выводится информация об отобранном ознакомлении_`

`_iAsquaintID = oAsquaint.DocID;_`

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _iCounter = tools.call_code_library_method ("libKnowledge", "UpdateAcquaintAssign", [ OptInt (iAsquaintID), false, false ]);_`

`_alert ("Количество назначений: " + iCounter);_`
