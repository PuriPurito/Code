## GetKnowledgeProfiles

Метод **GetKnowledgeProfiles** предназначен для получения списка профилей знаний.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetKnowledgeProfiles", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _arrReturnData_ \- массив полей для вывода (массив строк). Допустимые значения: _"knowledge\_part\_count"_ (число значений карты знаний), _"position\_count"_ (число должностей).  
     _sXQueryQual_ \- строка для XQuery-фильтра (строка).  
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень профилей знаний, а также ряд дополнительных атрибутов:  
\- _array_ \- массив профилей знаний (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID профиля знаний (целое число).  
     _code_ \- код профиля знаний (строка).  
     _name_ \- название профиля знаний (строка).  
     _knowledge\_part\_count_ \- число значений карты знаний в профиле знаний (целое число).  
     _position\_count_ \- число должностей в профиле знаний (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetKnowledgeProfiles", [arrReturnData, sXQueryQual, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
