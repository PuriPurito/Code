## GetKnowledgePartTypes

Метод **GetKnowledgePartTypes** предназначен для получения списка типов значений карты знаний.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetKnowledgePartTypes", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _sXQueryQual_ \- строка для XQuery-фильтра (строка).  
     _oCollectionParams_ \- Набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень типов значений карты знаний, а также ряд дополнительных атрибутов:  
\- _array_ \- массив типов значений карты знаний (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID типа значений карты знаний (целое число).  
     code - код типа значений карты знаний (строка).  
     name - название типа значений карты знаний (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetKnowledgePartTypes", [sXQueryQual, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
