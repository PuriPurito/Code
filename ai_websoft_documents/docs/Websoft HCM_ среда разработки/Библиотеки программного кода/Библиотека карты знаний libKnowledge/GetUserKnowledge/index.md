## GetUserKnowledge

Метод **GetUserKnowledge** предназначен для получения информации об уровне знаний пользователя.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetUserKnowledge", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _sKnowledgeTypeID_ \- тип знания (строка) (необязательный). Допустимые значения - _"all", "corporative", "project", "interest"_. Значение по умолчанию – _"all"_.  
     _bConfirmation_ \- показывать ли только подтвержденные значения (булево) (необязательный). Значение по умолчанию - _true_. 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию об уровне знаний пользователя, а также ряд дополнительных атрибутов:  
\- _array_ \- массив категорий знания пользователя (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID категории знания (целое число).  
     _knowledge\_part\_name_ \- название категории знания (строка).  
     _knowledge\_full\_path_ – полный путь к карточке знания (т.н. «хлебные крошки») (строка);  
     _level\_name_ \- текущий уровень знаний (строка).  
     _target\_level\_name_ \- требуемый уровень знаний (строка).  
     _is\_confirm_ – подтвержден ли уровень знания (булево).  
     _confirm\_name_ – информация о признаке подтверждения уровня знания  
     _color_ \- информация об оформлении признака подтверждения (цвет и стиль) (строка).  
     _is\_expert_ \- информация о признаке признания сотрудника официальным экспертом (строка).  
     _image\_url_ \- ссылка на изображение значения карты знаний (строка).  
     _link\_url_ \- ссылка на карту знаний (строка).  
     _target\_level\_cost_ \- стоимость целевого уровня (целое число).  
     _knowledge\_acquaint\_id_ – ID подтверждения значения карты знаний (целое число).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetUserKnowledge", [iPersonID, sKnowledgeTypeID, bConfirmation]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
