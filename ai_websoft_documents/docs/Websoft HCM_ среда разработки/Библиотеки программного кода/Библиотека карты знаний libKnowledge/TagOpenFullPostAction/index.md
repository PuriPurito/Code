## TagOpenFullPostAction

Метод **TagOpenFullPostAction** предназначен для проставления категорий у объекта, заданного параметром _iTagID_. Категории берутся из _teRemoteAction_. Эта функция - _post\_action_, вызываемая при сохранении карточки тега.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "TagOpenFullPostAction", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iTagID_ \- ID тега (целое число).  
     _bIsEdit_ \- состояние параметра is\_edit объекта-команды вызова карточки (_command: "open\_doc"..._) (булево).  
     _iAppID_ \- ID текущего приложения (целое число).  
     _teRemoteAction_ \- _TopElem_ текущего удаленного действия (объект). 

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "TagOpenFullPostAction", [iTagID, bIsEdit, iAppID, teRemoteAction]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
