## GetExperts

Метод предназначен для получение списка экспертов по значениям карты знаний.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetExperts", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _bCheckAccess_ \- проверять права доступа (булево).  
     _sSearch_ \- критерии поиска (строка).  
     _aKnowledgeParts_ \- массив значений карты знаний (массив целых чисел).  
     _bShowWithoutSearchParams_ \- показывать результаты без параметров поиска (булево) (необязательный). Значение по умолчанию - _true_.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень экспертов по значениям карты знаний, а также ряд дополнительных атрибутов:  
\- _array_ \- массив массив экспертов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID эксперта (целое число);  
     _fullname_ – ФИО сотрудника (эксперта) (строка);  
     _position\_name_ – название должности сотрудника (строка);  
     _knowledge_ – название карты знаний (строка);  
     _image_ – относительная ссылка на изображение (строка);  
     _link_ – относительная ссылка на карточку сотрудника (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetExperts", [iCurUserID, bCheckAccess, sSearch, aKnowledgeParts, bShowWithoutSearchParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
