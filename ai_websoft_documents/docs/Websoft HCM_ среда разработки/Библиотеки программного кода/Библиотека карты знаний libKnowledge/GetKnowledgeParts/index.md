## GetKnowledgeParts

Метод предназначен для получение списка значений карты знаний по классификатору, категории и родительскому значению.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetKnowledgeParts", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя десять параметров:  
     _iKnowledgeClassifierID_ \- ID классификатора карты знаний (целое число) (необязательный).  
     _iParentKnowledgePartID_ \- ID родительского значения карты знаний (целое число) (необязательный).  
     _iKnowledgePartLevelID_ \- ID категории карты знаний (целое число) (необязательный).  
     _iExpertID_ \- ID эксперта (целое число) (необязательный).  
     _iCurUserID_ \- ID текущего пользователя (целое число) (необязательный).  
     _sAccessType_ \- тип доступа (строка). Допустимые значения: _"admin"; "manager"; "hr"; "expert"; "observer"; "auto"._  
     _sApplication_ \- код приложения, по которому производится доступ (строка).  
     _arrReturnData_ \- массив полей для вывода (массив строк) (необязательный). Допустимые значения: _"objects\_count"_ (число объектов); _"experts\_count"_ (число экспертов); _"levels\_count"_ (число уровней).  
     _sXQueryQual_ \- строка для XQuery-фильтра (строка).  
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень значений карты знаний, а также ряд дополнительных атрибутов:  
\- _array_ \- массив значений карты знаний (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID значения карты знаний (целое число);  
     _name_ \- название значения карты знаний (строка);  
     _parent\_id_ \- ID родительского значения карты знаний (целое число);  
     _classifier\_id_ \- ID классификатора значения карты знаний (целое число);  
     _classifier\_name_ \- название классификатора значения карты знаний (строка);  
     image - ссылка на изображение (строка).  
     objects\_count - количество объектов (в зависимости от значения параметра arrReturnData) (целое число).   
     experts\_count - количество экспертов (в зависимости от значения параметра arrReturnData) (целое число).   
     levels\_count - количество уровней (в зависимости от значения параметра arrReturnData) (целое число). 

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetKnowledgeParts", [iKnowledgeClassifierID, iParentKnowledgePartID, iKnowledgePartLevelID, iExpertID, iCurUserID, sAccessType, sApplication, arrReturnData, sXQueryQual, oCollectionParams]);_`   
  
`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
