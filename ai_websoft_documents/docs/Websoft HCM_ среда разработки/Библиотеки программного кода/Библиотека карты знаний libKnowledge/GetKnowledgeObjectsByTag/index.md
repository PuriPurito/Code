## GetKnowledgeObjectsByTag

Метод **GetKnowledgeObjectsByTag** предназначен для получения списка объектов по тегу.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetKnowledgeObjectsByTag", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iTagIDParam_ \- ID тега (целое число).  
     _bCheckAccess_ \- проверять права доступа (булево).  
     _iCurUserID_ \- ID текущего пользователя (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень объектов по тегу, а также ряд дополнительных атрибутов:  
\- _array_ \- массив объектов по тегу.  
     Атрибуты отдельного объекта:  
     _id_ \- ID тега (целое число).  
     _name_ \- название тега (строка).  
     _catalog_ \- тип объекта (каталога) (строка).  
     _catalog\_name_ \- название объекта (каталога) (строка).  
     _create\_date_ \- дата создания тега (дата).  
     _require\_acknowledgement_ – требуется ли подтверждение эксперта (булево).  
     _image_ \- относительная ссылка на изображение тега (строка).  
     _link_ \- относительная ссылка на тег (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetKnowledgeObjectsByTag", [iTagIDParam, bCheckAccess, iCurUserID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
