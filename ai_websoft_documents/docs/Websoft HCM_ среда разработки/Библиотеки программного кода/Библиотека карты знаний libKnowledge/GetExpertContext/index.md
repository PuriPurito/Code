## GetExpertContext

Метод **GetExpertContext** предназначен для получения контекста эксперта.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetExpertContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iUserID_ \- ID сотрудника (целое число).  
     _bHier_ \- учитывать иерархию значений (булево).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит контекст эксперта, а также ряд дополнительных атрибутов:  
_\- oContext_ – данные о контексте эксперта (объект):  
     _bExpert_ – является экспертом (булево).  
     _iQuestion_ – количество вопросов (целое число).  
     _iUnanswerQuestion_ – количество неотвеченных вопросов (целое число).  
     _iKnowledgePartNum_ – число значений карты знаний, по которым пользователь является экспертом (целое число).  
     _iKnowledgeAcquaintNum_ – число подтверждений знаний, относящихся к области экспертизы пользователя, со статусом "В процессе" (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetExpertContext", [iUserID, bHier]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
