## ActivateLearningTask

Метод предназначен для назначения задания сотруднику.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "ActivateLearningTask", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя одиннадцать параметров:  
     _iPersonID_ – ID сотрудника, которому назначается задание (целое число).    
     _iLearningTaskID_ \- ID задания (целое число).  
     _iEducationPlanID_ \- ID плана обучения (целое число).   
     _aFiles_ \- массив ID файлов (массив целых чисел).  
     _sDesc_ – описание (строка).  
     _iActiveLearningID_ \- ID незаконченного курса (целое число).  
     _iExpertID_ \- ID эксперта (целое число).  
     _dStartDate_ \- дата начала обучения (дата).  
     _dPlanStartDate_ \- плановая дата начала обучения (дата).  
     _dPlanEndDate_ \- плановая дата завершения обучения (дата).  
     _bStartTask_ \- начинать задачу (булево).

_Возвращаемые значения:_

Тип: **Объект**. Содержит ряд атрибутов:  
\- _doc\_learning\_task\_result_ \- документ назначенного задания (объект XmlDoc).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_ – текст ошибки (строка).
