## GetKnowledgeObjects

Метод предназначен для получение списка объектов в карте знаний.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetKnowledgeObjects", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя девять параметров:  
     _aObjectType_ \- массив типов объектов (массив строк).  
     _sSearch_ \- критерии поиска (строка).  
     _aKnowledgeParts_ \- массив значений карты знаний (массив целых чисел).  
     _bShowWithoutSearchParams_ \- показывать результаты без параметров поиска (булево) (необязательный). Значение по умолчанию - _true_.   
     oSort - информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).  
     oPaging - информация из рантайма о пейджинге (объект). Объект включает в себя следующие данные:  INDEX - номер страницы (целое число);  SIZE - размер страницы (целое число); MANUAL - разделение на страницы вручную (булево); TOTAL - общее количество страниц (целое число).  
     _iUserID_ \- идентификатор текущего сотрудника (целое число).  
     _bUseLevel_ \- учитывать ли уровни (булево) (необязательный). Значение по умолчанию - _false_.  
     _bUseActivity_ \- учитывать ли активности (булево) (необязательный). Значение по умолчанию - _false_.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень объектов в карте знаний, а также ряд дополнительных атрибутов:  
\- _array_ \- массив объектов в карте знаний (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID объекта в карте знаний (целое число);  
     _object\_name_ – название объекта (строка);  
     _catalog_ – название каталога объекта (строка);  
     _knowledge_ – название карты знаний объекта (строка);  
     _image_ – относительная ссылка на изображение объекта (строка);  
     _link_ – относительная ссылка на объект (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetKnowledgeObjects", [aObjectType, sSearch, aKnowledgeParts, bShowWithoutSearchParams, oSort, oPaging, iUserID, bUseLevel, bUseActivity]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
