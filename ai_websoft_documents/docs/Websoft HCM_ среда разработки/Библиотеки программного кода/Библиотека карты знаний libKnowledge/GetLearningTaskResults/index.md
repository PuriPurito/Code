## GetLearningTaskResults

Метод **GetLearningTaskResults** предназначен для получения списка результатов выполнения задания.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetLearningTaskResults", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя шесть параметров:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _sType_ \- тип отбора заданий (строка). Доступные значения: _"all"_ (все типы сотрудников), _"expert"_ (эксперт), _"executor"_ (исполнитель). Значение по умолчанию - _"all"_.  
     _arrStatuses_ \- массив статусов для отбора заданий (массив строк). Возможные значения статусов: _"assign"_ (назначено), _"process"_ (в работе), _"viewed"_ (просмотрено), _"success"_ (пройдено), _"evaluation"_ (оценивается), _"cancel"_ (отменено), _"failed"_ (не пройдено).  
     _sSearch_ – критерий поиска (строка).  
     _bGetExpertByResult_ \- определять экспертов по заданию (по выполнению задания) (булево). Значение по умолчанию - _false_.   
     _arrFilters_ \- набор фильтров (массив объектов). Каждый объект массива включает в себя следующие данные: _id_ \- ID фильтра (строка), _type_ \- тип фильтра (строка), _value_ - критерий отбора (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень результатов выполнения задания, а также ряд дополнительных атрибутов:  
\- _array_ \- массив данных о результатах выполнения задания (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID выполнения задания (целое число).  
     _delayed_ – задание просрочено (булево).  
     _plan\_date_ \- плановая дата выполнения задания (дата).  
     _title_ \- название задания (строка).  
     _img\_url_ – относительная ссылка на изображение (строка).  
     _status\_id_ – ID статуса задания (строка).  
     _status\_name_ \- наименование статуса задания (строка).  
     _score_ – полученная оценка (целое число).  
     _executor_ – исполнитель задания (строка).  
     _link_ – относительная ссылка на результат выполнения задания (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetLearningTaskResults", [ iPersonID, sType, arrStatuses, sSearch, bGetExpertByResult, arrFilters]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
