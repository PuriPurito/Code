## GetPersonKnowledgeAccessContext

Метод **GetPersonKnowledgeAccessContext** предназначен для получения прав на редактирование знаний для сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetPersonKnowledgeAccessContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя шесть параметров:  
     _iUserID_ \- ID текущего сотрудника (целое число).  
     _iPersonID_ \- ID проверяемого сотрудника (если пусто берется ID текущего сотрудника) (целое число).  
     _bAccessMainBoss_ \- разрешить ли доступ к корпоративным знаниям для непосредственных руководителей (булево) (необязательный). Значение по умолчанию – _true_.  
     _bAccessFuncBoss_ \- разрешить ли доступ к корпоративным знаниям для функциональных руководителей (булево) (необязательный). Значение по умолчанию - _false_.  
     _aFuncManagers_ \- массив функциональных руководителей (массив целых чисел) (необязательный).  
     _bAccessInterest_ \- разрешить доступ к знаниям по интересам (булево) (необязательный). Значение по умолчанию - _true_. 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит контекст доступа сотрудника к корпоративным знаниям, а также ряд дополнительных атрибутов:  
\- _context_ \- контекст доступа сотрудника к корпоративным знаниям (объект).  
     Атрибуты объекта:  
     _bAccessCorpKnowledge_ – имеется ли доступ к корпоративным знаниям (булево).  
     _bAccessInterestKnowledge_ – имеется ли доступ к знаниям по интересам (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetPersonKnowledgeAccessContext", [iUserID, iPersonID, bAccessMainBoss, bAccessFuncBoss, aFuncManagers, bAccessInterest]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
