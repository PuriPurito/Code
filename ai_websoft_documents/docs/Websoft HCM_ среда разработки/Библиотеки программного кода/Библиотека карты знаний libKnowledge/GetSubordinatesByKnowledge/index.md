## GetSubordinatesByKnowledge

Метод **GetSubordinatesByKnowledge** предназначен для получения списка подчиненных с указанными значениями карты знаний.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetSubordinatesByKnowledge", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iUserID_ \- ID текущего пользователя (целое число).  
     _iKnowledgePartID_ \- ID значения карты знаний (целое число).  
     oSort - информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).  
     oPaging - информация из рантайма о пейджинге (объект). Объект включает в себя следующие данные:  INDEX - номер страницы (целое число);  SIZE - размер страницы (целое число); MANUAL - разделение на страницы вручную (булево); TOTAL - общее количество страниц (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень подчиненных с указанными значениями карты знаний, а также ряд дополнительных атрибутов:  
\- _array_ \- массив подчиненных с указанными значениями карты знаний (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- идентификатор сотрудника (целое число).  
     _image_ \- ссылка на фотографию сотрудника (строка).  
     _link_ \- ссылка на карточку сотрудника (строка).  
     _fullname_ \- ФИО сотрудника (строка).  
     _position\_name_ \- название основной должности сотрудника (строка).  
     _subdivision\_name_ \- название подразделения, к которому относится основная должность сотрудника (строка).  
     _current\_level\_name_ \- название подтверждаемого уровня (строка).  
     _target\_level\_name_ \- название требуемого уровня (строка).  
     _knowledge\_type_ \- тип знания (строка). Допустимые значения: корпоративное (из профиля знаний и из подтверждений с типом «_Корпоративное_»), проектное (подтверждение с типом «_По результатам проекта_»), область интересов (подтверждение с типом «_По интересам_»). Знание, которое относится одновременно к нескольким типам, отображается одной строкой (типы знания перечисляются через запятую).  
     _completed_ \- подтвержденный уровень больше или равен требуемому (булево).   
     _completed\_title_ \- признак подтверждения уровня (строка). Допустимые значения: _"Подтверждено"; "Не подтверждено"_.

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetSubordinatesByKnowledge", [iUserID, iKnowledgePartID, oSort, oPaging]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
