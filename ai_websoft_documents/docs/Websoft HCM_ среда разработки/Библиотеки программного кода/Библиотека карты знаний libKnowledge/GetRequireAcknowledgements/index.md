## GetRequireAcknowledgements

Метод **GetRequireAcknowledgements** предназначен для получения списка объектов на согласовании для указанного сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetRequireAcknowledgements", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _sTypeID_ \- ID типа объекта (строка). Допустимые значения: 'knowledge\_part' (значение карты знаний), 'tag' (тег).  
     _iPersonID_ \- ID сотрудника (целое число).  
     _sSearch_ \- критерии поиска (строка) (необязательный).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень объектов на согласовании, а также ряд дополнительных атрибутов:  
\- _array_ \- массив объектов.  
     Атрибуты отдельного объекта:  
     _object\_id_ \- ID объекта (целое число);  
     _object\_name_ \- название объекта (строка);  
     _type\_object\_id_ \- ID типа объекта (целое число);  
     _type\_object\_name_ \- название типа объекта (строка);  
     _catalog_ \- тип каталога (строка);  
     _image_ \- относительная ссылка на изображение объекта (строка);  
     _link_ – относительная ссылка на объект (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetRequireAcknowledgements", [sTypeID, iPersonID, sSearch]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
