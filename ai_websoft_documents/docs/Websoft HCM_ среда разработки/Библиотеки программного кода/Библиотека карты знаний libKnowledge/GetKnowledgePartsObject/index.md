## GetKnowledgePartsObject

Метод предназначен для получения списка значений карты знаний объекта.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetKnowledgePartsObject", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iObjectID_ \- ID объекта (целое число).  
     _iKnowledgeClassifierID_ \- ID классификатора карты знаний (целое число).  
     _iKnowledgePartLevelID_ \- ID категории карты знаний (целое число).  
     _bShowOnlyAcknowledgement_ \- показывать только подтвержденные значения (булево) (необязательный). Значение по умолчанию - _true_.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень значений карты знаний объекта, а также ряд дополнительных атрибутов:  
\- _array_ \- массив значений карты знаний объекта (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID значения карты знаний объекта (целое число);  
     _name_ \- название значения карты знаний объекта (строка);  
     _desc_ \- описание значения карты знаний объекта (строка);  
     _require\_acknowledgement_ \- требуется ли подтверждение эксперта (булево);  
     _img_ \- относительная ссылка на изображение (строка).  
 

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetKnowledgePartsObject", [ iObjectID, iKnowledgeClassifierID, iKnowledgePartLevelID, bShowOnlyAcknowledgement]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
