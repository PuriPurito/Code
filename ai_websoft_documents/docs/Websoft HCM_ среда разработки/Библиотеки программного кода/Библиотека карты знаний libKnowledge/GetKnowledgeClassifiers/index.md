## GetKnowledgeClassifiers

Метод **GetKnowledgeClassifiers** предназначен для получения списка классификаторов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetKnowledgeClassifiers", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя шесть параметров:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _sAccessType_ \- тип доступа (строка). Допустимые значения: _"admin"; "manager"; "hr"; "expert"; "observer"; "auto"._  
     _sApplication_ \- код приложения, по которому производится доступ (строка).  
     _arrReturnData_ \- массив полей для вывода (массив строк). Допустимое значение: _"knowledge\_part\_count"_ (общее количество значений карты знаний, относящихся к данному классификатору).  
     _sXQueryQual_ \- строка для XQuery-фильтра (строка).  
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень классификаторов, а также ряд дополнительных атрибутов:  
\- _array_ \- массив классификаторов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID классификатора (целое число).  
     _code_ \- код классификатора (строка).  
     _name_ \- название классификатора (строка).  
     _knowledge\_part\_count_ \- число значений карты знаний, относящихся к данному классификатору (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetKnowledgeClassifiers", [iCurUserID, sAccessType, sApplication, arrReturnData, sXQueryQual, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
