## GetKnowledgeAcquaints

Метод **GetKnowledgeAcquaints** предназначен для получения объектов подтверждения знаний указанного сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetKnowledgeAcquaints", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iUserID_ \- ID текущего пользователя (целое число).  
     _sType_ \- тип отбора подтверждения (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень объектов подтверждения знаний указанного сотрудника, а также ряд дополнительных атрибутов:  
\- _array_ \- массив объектов подтверждения знаний указанного сотрудника (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- идентификатор подтверждения знания (целое число).  
     _person\_id_ \- идентификатор сотрудника (целое число).  
     _person\_image_ \- ссылка на фотографию сотрудника (строка).  
     _person\_fullname_ \- ФИО сотрудника (строка).  
     _person\_position\_name_ \- название основной должности сотрудника (строка).  
     _person\_subdivision\_name_ \- название подразделения, к которому относится основная должность сотрудника (строка).  
     _level\_name_ \- название подтверждаемого уровня (строка).  
     _knowledge\_part\_name_ \- название значения карты знаний из подтверждения (строка).  
     _knowledge\_part\_id_ \- идентификатор значения карты знаний из подтверждения (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetKnowledgeAcquaints", [iUserID, sType]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
