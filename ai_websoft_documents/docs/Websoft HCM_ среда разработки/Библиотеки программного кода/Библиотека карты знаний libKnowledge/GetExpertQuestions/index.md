## GetExpertQuestions

Метод **GetExpertQuestions** предназначен для получения списка вопросов эксперту.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetExpertQuestions", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _sTypeID_ \- тип вопроса (строка). Допустимые значения: _'my'_ (вопрос сотрудника), _'to\_me'_ (вопрос эксперта), _'faq'_ (часто задаваемый вопрос), _'open'_ (открытый вопрос, отображаемый в общем списке).  
     _iPersonID_ \- ID сотрудника, чьи вопросы необходимо вернуть (целое число) (обязательный для _sTypeID='my'_).  
     _iExpertID_ \- ID эксперта, чьи вопросы необходимо вернуть (целое число) (обязательный для _sTypeID='to\_me'_).  
     _sSearch_ \- критерии поиска (строка) (необязательный).  
     _sStatus_ \- статус вопроса (строка) (необязательный).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень тестов, которые были назначены участникам мероприятия, а также ряд дополнительных атрибутов:  
\- _array_ \- массив вопросов эксперту, а также ряд дополнительных атрибутов:  
     Атрибуты отдельного объекта:  
     _id_ – ID вопроса (целое число).  
     _question_ – содержание вопроса (строка).  
     _expert\_fullname_ \- ФИО эксперта (строка).  
     _person\_fullname_ \- ФИО сотрудника (строка).  
     _status_ – статус вопроса (строка).  
     _status\_name_ – название статуса вопроса (строка).  
     _date_ – дата, когда был задан вопрос (дата).  
     _link_ \- относительная ссылка на вопрос (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _action\_result_ – информация о результате вызова метода (объект) (в том числе: _command_ – команда вывода информации о результате (строка) (например, _"alert", "display\_form", "close\_form"_); другие параметры зависят от значения параметра _command_).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetExpertQuestions", [sTypeID, iPersonID, iExpertID, sSearch, sStatus]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
