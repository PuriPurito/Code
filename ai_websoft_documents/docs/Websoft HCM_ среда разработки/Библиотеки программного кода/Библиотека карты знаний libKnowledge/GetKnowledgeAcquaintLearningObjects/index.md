## GetKnowledgeAcquaintLearningObjects

Метод **GetKnowledgeAcquaintLearningObjects** предназначен для получения объектов подтверждения знаний.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetKnowledgeAcquaintLearningObjects", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.  
     Массив включает в себя два параметра:  
     _iKnowledgeAcquaintID_ \- ID подтверждения знания (целое число).  
     _bShowCompleted_ \- показывать пройденные (булево) (необязательный). Значение по умолчанию - _true_.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень объектов подтверждения знаний, а также ряд дополнительных атрибутов:  
\- _array_ \- массив объектов подтверждения знаний (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- идентификатор объекта (целое число).  
     _catalog_ \- каталог объекта (строка).  
     _catalog\_name_ \- название каталога объекта (строка).  
     _name_ \- название объекта (строка).  
     _object\_link_ \- ссылка на карточку объекта (строка).  
     _object\_image_ \- ссылка на изображение (строка).  
     _status_ \- статус завершенности (завершен/не завершен) (булево).  
     _status\_name_ \- название статуса (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetKnowledgeAcquaintLearningObjects", [iKnowledgeAcquaintID, bShowCompleted]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
