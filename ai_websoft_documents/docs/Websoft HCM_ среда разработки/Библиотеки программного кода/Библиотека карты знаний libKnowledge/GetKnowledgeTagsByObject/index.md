## GetKnowledgeTagsByObject

Метод **GetKnowledgeTagsByObject** предназначен для получения списка тегов по объекту.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetKnowledgeTagsByObject", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iObjectIDParam_ \- ID объекта (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень тегов по объекту, а также ряд дополнительных атрибутов:  
\- _array_ \- массив тегов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID тега (целое число);  
     _name_ \- название тега (строка);  
     _image_ \- относительная ссылка на изображение тега (строка);  
     _link_ \- относительная ссылка на тег (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetKnowledgeTagsByObject", [iObjectIDParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
