## RunKnowledgeAcquaintAction

Метод **RunKnowledgeAcquaintAction** предназначен для выполнения действий над карточкой знаний сотрудника.

Примечание - Начиная с версии 2023.2, данная функция помечена как deprecated.   
Данную функцию использовать не рекомендуется.   
В функции реализована интерфейсная часть удаленного действия. Код перенесен в файл удаленного действия.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "RunKnowledgeAcquaintAction", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя двенадцать параметров:  
     _iUserID_ \- ID текущего пользователя (целое число).  
     _iPersonID_ \- ID сотрудника, над карточкой знаний которого выполняются действия (целое число).  
     _iKnowledgePartID_ \- ID значения карты знаний (целое число).  
     _iKnowledgeClassifierID_ \- ID классификатора знаний (целое число).  
     _sActionType_ \- тип действия (строка).  
     _bInterestSendNotification_ – включить (_true_) или отключить (_false_) отправку уведомлений руководителям при изменении области интересов (булево).  
     _bCorpSendNotification_ \- включить (_true_) или отключить (_false_) отправку уведомлений сотрудникам при изменении корпоративных знаний (булево).  
     _bBossChangeCorpKnowledge_ – разрешить (_true_) или запретить (_false_) непосредственным руководителям изменять требования к корпоративным знаниям для подчиненных (булево).  
     _bFuncManagerChangeCorpKnowledge_ \- разрешить (_true_) или запретить (_false_) функциональным руководителям изменять требования к корпоративным знаниям для подчиненных (булево).  
     _arrBossTypeIDs_ \- ID типов функциональных руководителей, которым разрешено изменять требования к знаниям у подчиненным (массив целых чисел).  
     _bPersonChangeInterestKnowledge_ \- разрешить (_true_) или запретить (_false_) сотрудникам изменять области своих интересов (булево).  
     _SCOPE\_WVARS_ \- JSON-объект с параметрами удаленного действия (объект). 

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
\- action\_result – информация о результате вызова метода (объект) (в том числе: _command_ – команда вывода информации о результате (строка) (например, _"alert", "display\_form", "close\_form"_); другие параметры зависят от значения параметра _command_).   
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "RunKnowledgeAcquaintAction", [iUserID, iPersonID, iKnowledgePartID, iKnowledgeClassifierID, sActionType, bInterestSendNotification, bCorpSendNotification, bBossChangeCorpKnowledge, bFuncManagerChangeCorpKnowledge, arrBossTypeIDs, bPersonChangeInterestKnowledge, SCOPE_WVARS]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
