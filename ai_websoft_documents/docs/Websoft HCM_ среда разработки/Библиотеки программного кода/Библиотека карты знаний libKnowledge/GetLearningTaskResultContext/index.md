## GetLearningTaskResultContext

Метод **GetLearningTaskResultContext** предназначен для получения контекста выполнения задания сотрудником.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libKnowledge", "GetLearningTaskResultContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iLearningTaskResultID_ \- ID результата выполнения задания (целое число).  
     _iUserID_ \- ID сотрудника (целое число).  
     _bGetExpertByResult_ \- определять экспертов по заданию (по выполнению задания) (булево). Значение по умолчанию - _false_. 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень мероприятий, которые проводит указанный преподаватель, а также ряд дополнительных атрибутов:  
\- _array_ \- массив тестов, которые были назначены участникам в рамках мероприятия (массив объектов).  
     Атрибуты отдельного объекта:  
\- _context_ \- массив мероприятий, проводимых преподавателем (массив объектов).  
     Атрибуты отдельного объекта:  
     _is\_executor_ – сотрудник является исполнителем задания (true – текущий пользователь является исполнителем данного задания).  
     _is\_expert_ – сотрудник является экспертом по данногому заданию (true - текущий пользователь является экспертом по выполнению данного задания или связанного задания) (если значение параметра _bGetExpertByResult_ равно _true_).  
     _person\_id_ – ID сотрудника, высполняющего задание (целое число).  
     _learning\_task\_result\_id_ – ID выполнения задания (целое число).  
     _person\_name_ – ФИО сотрудника, выполняющего задание (строка).  
     _person\_position\_name_ – наименование должности сотрудника, выполняющего задание (строка).  
     _person\_subdivision\_name_ – наименование подразделения сотрудника, выполняющего задание (строка).  
     _person\_img_ – изображение (или аватар) сотрудника, выполняющего задание (строка).  
     _status\_id_ – ID текущего статуса выполнения задания (строка).  
     _status\_name_ – наименование статуса выполнения задания (строка).  
     _time\_left_ – время, остающееся на выполнение задания (целое число).  
     _time\_left\_str_ – время, остающееся на выполнение задания в строковом формате (строка).  
     _work\_time\_str_ – продолжительность выполнения задания в строковом формате (строка).  
     _learning\_task\_desc_ \- текст описания задания (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libKnowledge", "GetLearningTaskResultContext", [iLearningTaskResultID, iUserID, bGetExpertByResult]);_`   
 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
