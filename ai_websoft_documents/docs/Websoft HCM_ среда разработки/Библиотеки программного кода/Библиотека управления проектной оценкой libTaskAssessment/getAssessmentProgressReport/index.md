## getAssessmentProgressReport

Метод **getAssessmentProgressReport** предназначен для получения данных для отчета "Ход оценки".

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTaskAssessment", "getAssessmentProgressReport", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _oReportAssessmentProgress_ \- объект отчета (объект).   
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _sApplicationID_ \- ID приложения (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные для отчета "Ход оценки", а также ряд дополнительных атрибутов:  
\- oResult - данные для отчета "Ход оценки" (объект).  
     Атрибуты объекта:  
     _id_ \- ID сотрудника (целое число).  
     _person\_fullname_ \- ФИО сотрудника (строка).  
     _person\_position\_name_ \- наименование должности сотрудника (строка).  
     _person\_subdivision\_name_ \- наименование подразделения, к которому относится должность (строка).  
     _person\_org\_name_ \- наименование организации, к которой относится подразделение (строка).  
     _eval\_task\_count_ \- общее число оцененных задач (целое число).  
     _current\_mark_ \- текущая оценка, подсчитанная по оцененным задачам (действительное число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTaskAssessment", "getAssessmentProgressReport", [oReportAssessmentProgress, curUserID, sApplicationID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
