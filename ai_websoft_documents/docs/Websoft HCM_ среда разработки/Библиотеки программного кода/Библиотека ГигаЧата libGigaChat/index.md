## Библиотека ГигаЧата libGigaChat

В настоящем разделе описываются методы **библиотеки ГигаЧата** из библиотеки программного кода **LibGigaChat**. Указанные методы регистрируются в разделе **Дизайнер – Библиотеки программного кода – LibGigaChat**.

Примечание - По состоянию на май 2024 г. библиотека предназначена исключительно для внутренних нужд системы и не содержит публичных методов.
