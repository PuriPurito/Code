## GetSimilarVacancies

Метод **GetSimilarVacancies** предназначен для получения списка похожих вакансий.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetSimilarVacancies", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя семь параметров:  
     _iVacancyID_ – ID ваансии (целое число).  
     _bShowOnlyCurrentSiteVacancies_ \- показывать только те вакансии, которые относятся к текущему сайту (булево) (необязательный). Значение по умолчанию - _false_.  
     _iRecruitmentSystemID_ \- ID системы подбора персонала (целое число) (необязательный).  
     _arrDistincts_ \- перечень полей для формирования дополнительных списков для виджета фильтров (массив строк).  
     _arrFilters_ \- набор фильтров (массив объектов).  
     oSort - информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).  
     oPaging - информация из рантайма о пейджинге (объект). Объект включает в себя следующие данные:  INDEX - номер страницы (целое число);  SIZE - размер страницы (целое число); MANUAL - разделение на страницы вручную (булево); TOTAL - общее количество страниц (целое число).

_Возвращаемое значение:_  
      Тип: Объект. Содержит перечень похожих вакансий, а также ряд дополнительных атрибутов:  
\- array - массив похожих вакансий (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID вакансии (целое число).  
     _name_ – название вакансии (строка).  
     _professional\_area\_id_ – ID профессиональной области (целое число).  
     _professional\_area\_name_ – название профессиональной области (строка).  
     _region\_id_ – ID региона (целое число).  
     _region\_name_ – название региона (строка).  
     _min\_wage_ – минимальная зарплата (целое число).  
     _max\_wage_ – максимальная зарплата (целое число).  
     _full\_wage_ \- полный размер зарплаты в строковом формате 'от <минимальная зарплата> до <максимальная зарплата>' (строка).  
     _employment_ \- занятость (строка).  
     _publication\_date_ \- дата публикации вакансии (дата).  
     _image\_url_ \- ссылка на избражение (строка).  
     _comment_ \- комментарий (строка).  
     _description_ \- описание (строка).  
     _link_ – ссылка на карточку вакансии (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_`  
`_oRes = tools.call_code_library_method ("libStaff", "GetSimilarVacancies", [iVacancyID, bShowOnlyCurrentSiteVacancies, iRecruitmentSystemID, arrDistincts, arrFilters, oSort, oPaging]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
