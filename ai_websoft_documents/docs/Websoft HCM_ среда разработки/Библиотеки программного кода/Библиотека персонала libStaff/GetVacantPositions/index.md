## GetVacantPositions

Метод **GetVacantPositions** предназначен для получения списка вакантных должностей.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetVacantPositions", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _bOnlyOwnSubdivision_ \- только собственное подразделение (булево).  
     _bHierarchy_ \- учитывать иерархию (булево).   
     _bNotShowClosed_ \- если параметр имеет значение true, в результаты не попадают закрытые вакансии (булево).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень вакантных должностей, а также ряд дополнительных атрибутов:  
\- _array_ \- массив вакантных должностей (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID вакантной должности (целое число).  
     _name_ – название вакантной должности (строка).  
     _org\_id_ – ID организации (целое число).  
     _org\_name_ – название организации (строка).  
     _subdivision\_id_ – ID подразделения (целое число).  
     _subdivision\_name_ – название подразделения (строка).  
     _position\_common\_id_ – ID типовой должности (целое число).  
     _position\_common\_name_ – название типовой должности (строка).  
     _is\_boss_ – является руководителем (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetVacantPositions", [iPersonID, bOnlyOwnSubdivision, bHierarchy, bNotShowClosed]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
