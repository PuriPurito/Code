## GetPersonBlogs

Метод **GetPersonBlogs** предназначен для получения списка блогов сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetPersonBlogs", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _bShowAmntEntries_ \- показывать количество сообщений блога (булево) (необязательный). Значение по умолчанию - _false_.  
     _iCurUserID_ \- ID текущего сотрудника (целое число).  
     _bCheckAccess_ \- выполнить проверку прав доступа (булево). 

_Возвращаемое значение:_  
      Тип: **Объект**. Объект. Содержит перечень блогов сотрудника, а также ряд дополнительных атрибутов:  
\- _array_ \- массив блогов сотрудника (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID блога (целое число).  
     _blog\_name_ \- название блога (строка).  
     _blog\_url_ \- относительная ссылка на карточку блога (строка).  
     _blog\_autor\_fullname_ \- ФИО автора блога (строка).  
     _blog\_autor\_url_ \- относительная ссылка на карточку автора блога (строка).  
     _blog\_autor\_img_ \- относительная ссылка на изображение автора блога (строка).  
     _blog\_entries_ \- количество сообщений блога (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetPersonBlogs", [iPersonID, bShowAmntEntries, iCurUserID, bCheckAccess]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
