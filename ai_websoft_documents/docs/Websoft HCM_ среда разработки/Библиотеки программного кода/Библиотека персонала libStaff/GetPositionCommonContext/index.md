## GetPositionCommonContext

Метод **GetPositionCommonContext** предназначен для расчета объектной метрики (контекста) типовой должности.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetPositionCommonContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iPositionCommonIDParam_ \- ID типовой должности, для которого определяются метрики (целое число).  
     _iCurUserID_ \- ID текущего сотрудника (целое число).  
     _iApplicationID_ \- ID приложения, для которого вычисляется контекст (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит расчета объектную метрику (контекст) типовой должности, а также ряд дополнительных атрибутов:  
\- _context_ – данные объектной метрики (контекста) типовой должности (объект).  
     Атрибуты объекта:  
     _code_ – код типовой должности (строка).  
     _name_ – название типовой должности (строка).  
     _position\_count_ – число должностей, отнесенных к данной типовой должности (целое число).  
     _typical\_development\_program\_count_ \- общее количество типовых программ (целое число).  
     _typical\_development\_program\_any\_count_ \- общее число типовых программ в требованиях с типом назначения Любое перемещение (целое число).  
     _typical\_development\_program\_ext\_count_ \- общее число типовых программ в требованиях с типом назначения Внешнее перемещение (целое число).  
     _typical\_development\_program\_int\_count_ \- общее число типовых программ в требованиях с типом назначения Внутреннее перемещение (целое число).  
     _position\_familys\_count_ \- количество семейств, в которые входит типовая должность (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetPositionCommonContext", [iPositionCommonIDParam, iCurUserID, iApplicationID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
