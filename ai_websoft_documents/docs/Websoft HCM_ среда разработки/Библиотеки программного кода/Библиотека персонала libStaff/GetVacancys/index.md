## GetVacancys

Метод **GetVacancys** предназначен для получения списка вакансий по профессиональным областям.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetVacancys", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя семь параметров:  
     _iProfessionalAreaID_ \- ID профессиональной области (целое число) (необязательный). Если параметр не указан, то поиск производится по всем профессиональным областям.  
     _iRegionID_ \- ID региона (целое число) (необязательный). Если параметр не указан, то поиск производится по всем регионам.  
     _sSearch_ – критерий полнотекстового поиска по каталогу вакансий (строка) (необязательный). Если параметр не указан, то поиск производится без учета критерия.  
     _bShowOnlyCurrentSiteVacancies_ \- показывать только те вакансии, которые относятся к текущему сайту (булево) (необязательный). Значение по умолчанию - _false_.  
     _iRecruitmentSystemID_ \- ID системы подбора персонала (целое число) (необязательный). Если параметр не указан, то значение берется из системы Websoft HCM.  
     bNotShowClosed - не показывать закрытые вакансии (булево).  
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень вакансий, а также ряд дополнительных атрибутов:  
\- _array_ \- массив вакансий (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID вакансии (целое число).  
     _name_ \- название вакансии (строка).  
     _professional\_area\_id_ \- ID профессиональной области (целое число).  
     _professional\_area\_name_ \- название профессиональной области (строка).  
     _region\_id_ \- ID региона (целое число).  
     _region\_name_ \- название региона (строка).  
     _min\_wage_ – минимальная зарплата (целое число).  
     _max\_wage_ – максимальная зарплата (целое число).  
     _full\_wage_ \- полный размер зарплаты в строковом формате 'от <минимальная зарплата> до <максимальная зарплата>' (строка).  
     _employment_ \- занятость (строка).  
     _publication\_date_ \- дата публикации (дата).  
     _image\_url_ – относительная ссылка на изображение (строка).  
     _comment_ \- комментарий к вакансии (строка).  
     _link_ – относительная ссылка на карточку вакансии (строка).  
     _description_ \- описание вакансии (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetVacancys", [iProfessionalAreaID, iRegionID, sSearch, bShowOnlyCurrentSiteVacancies, iRecruitmentSystemID, bNotShowClosed, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
