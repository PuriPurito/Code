## ShowRecruitmentEventInfo

Метод **ShowRecruitmentEventInfo** предназначен для показа информации из карточки события.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "ShowRecruitmentEventInfo", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _iRecruitmentEventID_ \- ID события (целое число).  
     _sCommand_ \- режим выполнения удаленного действия (показ или обработка формы) (строка). Допустимые значения: "eval" (создание и показ формы); "submit\_form" (обработка формы). 

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _result_ – открытая форма или сообщение об ошибке (объект).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "ShowRecruitmentEventInfo", [iRecruitmentEventID, sCommand]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
