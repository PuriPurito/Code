## GetEducationResume

Метод **GetEducationResume** предназначен для получения данных об образовании из резюме.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetEducationResume", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iResumeID_ \- ID резюме, для которого определяются метрики (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные об образовании, а также ряд дополнительных атрибутов:  
\- _array_ - массив данных об образовании (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID резюме (целое число).  
     _name_ \- название резюме (строка).  
     _education\_type\_id_ \- ID типа образования (целое число).  
     _education\_type\_name_ \- наименование типа образования (строка).  
     _form_ \- форма обучения (строка).  
     _mode_ \- способ получения образования (строка).  
     _date_ \- год окончания (строка).  
     _professional\_area\_id_ \- специальность по диплому (строка).  
     _specialisation_ \- обучающая организация, факультет  
     _result_ \- результат обучения (диплом/степень) (строка).  
     _site_ \- URL сайта обучающей организации (строка).  
     _comment_ \- комментарий (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetEducationResume", [iResumeID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
