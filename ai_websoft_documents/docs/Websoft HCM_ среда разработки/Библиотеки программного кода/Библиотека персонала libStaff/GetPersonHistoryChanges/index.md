## GetPersonHistoryChanges

Метод **GetPersonHistoryChanges** предназначен для получения списка изменений из истории изменений карточки сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetPersonHistoryChanges", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _dStartPeriod_ \- дата начала периода определения изменений (дата).  
     _dEndPeriod_ \- дата окончания периода определения изменений (дата).  
     _sSortDirection_ \- направление сортировки (строка) (необязательный). (Допустимые значения: минус (_'-')_ (по убыванию), плюс (_'+'_) (по возрастанию)). Значение по умолчанию - минус (_'-')_.   
     _bGetDatesFromPositions_ \- брать даты начала/конца действия должности: true - по должностям, false - по истории изменений в карточке сотрудника (булево).  
     Примечание - До апреля 2025 г. параметр _bGetDatesFromPositions_ характеризовал учет даты начала изменений.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень изменений карточки сотрудника, а также ряд дополнительных атрибутов:  
\- _array_ \- массив изменений карточки сотрудника (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID изменения (целое число).  
     _date_ – дата изменения (дата).  
     _position\_id_ – ID должности (целое число).  
     _position\_name_ – название должности (строка).  
     _position\_parent\_id_ – ID подразделения (целое число).  
     _position\_parent\_name_ – название подразделения (строка).  
     _org\_id_ – ID организации (целое число).  
     _org\_name_ – название организации (строка).  
     _comment_ – комментарий к изменению (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetPersonHistoryChanges", [iPersonID, dStartPeriod, dEndPeriod, sSortDirection, bGetDatesFromPositions]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
