## GetCollaboratorContext

Метод **GetCollaboratorContext** предназначен для расчета объектной метрики (контекста) сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetCollaboratorContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _PersonIDParam_ \- ID сотрудника, для которого определяются метрики (целое число).  
     _arrCaclulateParam_ \- перечень атрибутов, которые будут вычисляться (массив строк). Доступные значения показателя (см. _Возвращаемые значения_): _inherent_ (собственные параметры сотрудника), _birthday_ (наступление дня рождения), _tutor_ (параметры наставничества и адаптации), _successor_ (является ли сотрудник преемником), _grade_ (грейд), _working\_condition_ (условия работы), _resume_ (резюме), _adaptation_ (адаптации).   
     _iApplicationID_ \- ID приложения (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект**.    
\- _context_ \- контекст сотрудника (объект).  
     Возможные атрибуты отдельного объекта:

     sSex – пол сотрудника (строка).   
     sAge – возраст сотрудника (строка).   
     isBitrhday – в указанной окрестности текущей даты находится день рожденья сотрудника (булево).   
     iTutorTotalAdaptationNum – количество адаптаций, где сотрудник является наставником (целое число).   
     iTutorPlanAdaptationNum – количество адаптаций в статусе "Планируется", где сотрудник является наставником (целое число).   
     iTutorActiveAdaptationNum – количество адаптаций в статусе "В работе", где сотрудник является наставником (целое число).   
     iTutorPassedAdaptationNum – количество адаптаций в статусе "Завершено успешно", где сотрудник является наставником (целое число).   
     iTutorFailedAdaptationNum – количество адаптаций в статусе "Завершено неуспешно", где сотрудник является наставником (целое число).   
     isSuccessor – сотрудник является актуальным преемником (булево).   
     sGrageName – наименование грейда сотрудника (строка).   
     iGrageLevel – уровень грейда сотрудника (целое число).   
     sGrageLevelDesc – описание уровня грейда сотрудника (строка).   
     iWorkingConditionID – ID условий труда (целое число).   
     iResumeID – ID Резюме (целое число).   
     isAdapatationTutor – сотрудник является наставником в адаптациях (булево).   
     isCareerReserveTutor – сотрудник является наставником в прочих этапах развития карьеры (булево).   
     name - название категории сотрудника (строка).   
     min\_wage - минимальная зарплата (строка).   
     max\_wage - минимальная зарплата (строка).   
     currency\_type\_id - ID типа валюты (строка).   
     employment\_type\_id - ID типа работника (строка).   
     schedule\_work\_id - ID типа выполняемой работы (строка).   
     education\_type\_id - ID типа образования (строка).   
     profession\_id - ID профессии (строка).   
     exp\_years - количество лет работы (строка).   
     academic\_degree - научное звание (строка).   
     academic\_heading - научный руководитель (строка).   
     main\_lng - основной язык (строка).   
     phone - телефон (строка).   
     work\_phone - рабочий телефон (строка).   
     mobile\_phone - мобильный телефон (строка).   
     email - электронная почта (строка).   
     location\_id - ID местоположения (строка).   
     address - адрес (строка).   
     exist\_adaptation - проходит ли сотрудник адаптацию в настоящее время (строка).   
     complete\_adaptation\_count - число адаптаций со статусами "Завершено успешно" и "Завершено неуспешно" (целое число).   
     typical\_developmend\_program\_count - общее количество типовых программ развития, которые соответствуют сотруднику (целое число).   
     active\_career\_reserve\_count - количество этапов развития карьеры (не адаптаций) в работе (целое число).   
     plan\_career\_reserve\_count - количество планирующихся этапов развития карьеры (не адаптаций) (целое число).   
     passed\_career\_reserve\_count - количество успешно завершенных этапов развития карьеры (не адаптаций) (целое число).   
     failed\_career\_reserve\_count - количество неуспешно завершенных этапов развития карьеры (не адаптаций) (целое число).   
     agreed\_career\_plan – имеется ли согласованный карьерный план (булево).   
     finish\_career\_plan – имеется ли завершенный карьерный план (булево).   
     active\_badges\_count – количество активных бейджей (целое число).   
     badges\_count – количество бейджей (целое число).   
     active\_rewards\_count – количество активных наград (целое число).   
     rewards\_count – количество наград (целое число).   
 

      Атрибуты контекста зависят от установленных значений aCaclulateParam.  
      При задании значения _inherent_ выводится информация о поле и возрасте сотрудника.   
      При задании значения _birthday_ выводится информация о наступлении дня рождения сотрудника в указанной окрестности текущей даты (за 1 день до текущей даты и до 5 дней после текущей даты).   
      При задании значения _tutor_ выводятся сведения о прохождении сотрудником адаптаций.   
      При задании значения _successor_ выводится информация о том, является ли сотрудник преемником.  
      При задании значения _grade_ выводятся данные о грейде (уровне типовой должности) сотрудника.  
      При задании значения _working\_condition_ выводится информация об ID условий работы сотрудника.   
      При задании значения _resume_ выводятся сведения о резюме сотрудника.

Дополнительные атрибуты:  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetCollaboratorContext", [PersonIDParam, arrCaclulateParam, iApplicationID]);_`
