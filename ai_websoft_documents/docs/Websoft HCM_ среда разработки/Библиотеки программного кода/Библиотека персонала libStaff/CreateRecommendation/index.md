## CreateRecommendation

Метод **CreateRecommendation** предназначен для создания рекомендаций на вакансию.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "CreateRecommendation", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя шесть параметров:  
     _iVacancyID_ \- ID вакансии (целое число).  
     _sCommand_ – тип команды (строка). Принимаемые значения: "eval" (заполнение формы), "submit\_form" (отправка формы).  
     _iPersonID_ \- ID сотрудника (целое число) (необязательный; обязателен, если не указан параметр _tePerson)_.  
     _tePerson_ – TopElem сотрудника (объект) (необязательный; обязателен, если не указан параметр _iPersonID_).  
     _SCOPE\_WVARS_ – объект данных возврата из страницы Landing Page, генерируемой редактором лендингов (объект).  
     _curLngWeb_ – код текущего языка (объект типа XML element) (необязательный). Если параметр не указан, то берется язык пользовательского интерфейса в администраторе. При вызове на портале параметр обязателен. 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит массив рекомендаций на вакансию:  
\- _docRecommendation_ \- массив тестов, которые были назначены участникам в рамках мероприятия (массив объектов).  
     Атрибуты отдельного объекта:  
     _vacancy\_id_ \- ID вакансии (целое число);  
     _vacancy\_name_ – название вакансии (строка);  
     _src\_person\_id_ \- ID сотрудника (целое число);  
     _src\_person\_fullname_ – ФИО сотрудника (строка);  
     _lastname_ – фамилия сотрудника (строка);  
     _firstname_ – имя сотрудника (строка);  
     _middlename_ – отчество сотрудника (строка);  
     _phone_ – телефон (строка);  
     _work\_phone_ – рабочий телефон (строка);  
     _mobile\_phone_ – мобильный телефон (строка);  
     _email_ – электронный адрес (строка);  
     _letter\_text_ – текст сообщения (строка);  
     _desc_ – описание рекомендации (строка);  
     _files_ \- ссылки на прилагаемые файлы (массив строк);  
  
а также дополнительный атрибут:  
\- _result_ – результат вызова метода (объект с несколькими параметрами: в частности, _command_ – тип результата (строка) (в случае ошибки обычно имеет значение _"alert"_ (сообщение)), _msg_ – текст сообщения (строка)). Если функция завершилась успешно, то параметр _command_ получает значение _"close\_form"_, а параметр _msg - "Рекомендация успешно создана"_.

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "CreateRecommendation", [iVacancyID, sCommand, iPersonID, tePerson, SCOPE_WVARS, curLngWeb]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
