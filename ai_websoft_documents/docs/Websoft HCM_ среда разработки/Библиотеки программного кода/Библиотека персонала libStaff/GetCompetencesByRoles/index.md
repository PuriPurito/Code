## GetCompetencesByRoles

Метод **GetCompetencesByRoles** предназначен для получения списка компетенций по категориям.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetCompetencesByRoles", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _aRoleIds_ \- ID категорий компетенций, для которых не будет учтена иерархия (массив строк).  
     _aHierRoleIds_ \- ID категорий компетенций, для которых будет учтена иерархия (массив целых строк).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень компетенций по категориям, а также ряд дополнительных атрибутов:  
\- _result_ \- массив компетенций (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID компетенции (целое число).  
     _name_ \- название компетенции (строка).  
     _desc_ \- описание компетенции (строка).  
     _comment_ \- комментарий к компетенции (строка).  
     _link_ \- относительная ссылка на компетенцию (строка).  
     _image\_url_ \- относительная ссылка на изображение (строка).  
     _roles\_names_ - наименования категорий компетенций (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetCompetencesByRoles", [aRoleIds, aHierRoleIds]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
