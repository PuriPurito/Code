## GetProfessionalAreas

Метод **GetProfessionalAreas** предназначен для получения списка профессиональных областей.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetProfessionalAreas", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _bCheckAcess_ \- проверять права доступа (булево) (необязательный). Значение по умолчанию - _false_.  
     _iPersonID_ \- ID сотрудника, для которого определяется список профессиональных областей (целое число) (необязательный). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень профессиональных областей, а также ряд дополнительных атрибутов:  
\- _array_ \- массив профессиональных областей (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID профессиональной области (целое число).  
     _name_ – название профессиональной области (строка).  
     _parent\_id_ \- ID родительского элемента (целое число).  
     _image\_url_ – относительная ссылка на изображение (строка).  
     _comment_ – комментарий (строка).  
     _link_ – относительная ссылка на карточку профессиональной области (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример 1:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetProfessionalAreas", [bCheckAcess, iPersonID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
