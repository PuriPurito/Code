## GetEmployeePersonalData

Метод **GetEmployeePersonalData** предназначен для получения списка личных данных сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetEmployeePersonalData", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iCurUserID_ \- ID пользователя (целое число).  
     _sDisplayFields_ \- отображаемые поля (строка) (необязательный).  
     _bEmailAsLink_ \- тип формата вывода электронной почты (булево). Если параметр имеет значение true, то возвращать e-mail в формате <a href="mailto:...

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень личных данных сотрудника, а также ряд дополнительных атрибутов:  
\- _array_ \- массив личных данных сотрудника (массив объектов).  
     Атрибуты отдельного объекта:  
     id - ID сотрудника (целое число).  
     name - название параметра объекта Сотрудник (строка). Например: 'email', 'phone' и т.д.  
     title - название константы, соответствующее параметру объекта (строка).   
     _value_ \- значение параметра объекта (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetEmployeePersonalData", [iCurUserID, sDisplayFields, bEmailAsLink]);_`
