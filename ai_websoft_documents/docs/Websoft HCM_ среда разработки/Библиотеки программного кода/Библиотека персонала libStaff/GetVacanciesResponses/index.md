## GetVacanciesResponses

Метод **GetVacanciesResponses** предназначен для получения списка откликов текущего пользователя на вакансии.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetVacanciesResponses", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _iPersonID_ \- ID сотрудника/кандидата (целое число).  
     _arrDistincts_ \- перечень полей для формирования дополнительных списков для виджета фильтров (массив строк).  
     _arrFilters_ \- набор фильтров (массив объектов).)  
     oSort - информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).  
     oPaging - информация из рантайма о пейджинге (объект). Объект включает в себя следующие данные:  INDEX - номер страницы (целое число);  SIZE - размер страницы (целое число); MANUAL - разделение на страницы вручную (булево); TOTAL - общее количество страниц (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень откликов текущего пользователя на вакансии, а также ряд дополнительных атрибутов:  
\- _array_ - массив откликов на вакансии (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID отклика (целое число).  
     _name_ – название отклика (строка).  
     _status_ – статус отклика (строка).  
     _status\_name_ – название статуса отклика (строка).  
     _response\_date_ – дата ответа (дата).  
     _invitation\_date_ – дата приглашения (дата).  
     _link_ – ссылка на карточку отклика (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetVacanciesResponses", [iPersonID, arrDistincts, arrFilters, oSort, oPaging]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
