## GetMyVacancies

Метод **GetMyVacancies** предназначен для получения списка вакансий по заявке сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetMyVacancies", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _bNotShowClosed_ \- если параметр имеет значение _true_, в результаты не попадают закрытые вакансии (булево).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень вакансий по заявке сотрудника, а также ряд дополнительных атрибутов:  
\- _array_ \- массив вакансий (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID вакансии (целое число);  
     _name_ – название вакансии (строка);  
     _creation\_date_ \- дата создания вакансии в строковом выражении (строка);  
     _modification\_date_ \- дата модификации вакансии в строковом выражении (строка);  
     _professional\_area\_id_ \- ID профессиональной области (строка) (например, _it, finances, marketing_);  
     _professional\_area\_name_ \- название профессиональной области (строка) (например, _Информационные технологии/Интернет/Телеком, Бухгалтерия/Управленческий учет/Финансы предприятия, Маркетинг/Реклама/PR_);  
     _education\_type\_id_ \- ID типа образования (строка) (например, _secondary, higher, bachelor, master_);  
     _education\_type\_name_ \- название типа образования (строка) (например, _среднее, высшее, высшее Бакалавр, высшее Магистр_);  
     _link_ – относительная ссылка на карточку вакансии (строка);  
     _image\_url_ – относительная ссылка на изображение (строка);  
     _comment_ – комментарий к вакансии (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetMyVacancies", [iCurUserID, bNotShowClosed]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
