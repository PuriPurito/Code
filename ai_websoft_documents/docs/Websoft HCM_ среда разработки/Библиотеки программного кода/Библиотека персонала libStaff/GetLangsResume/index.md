## GetLangsResume

Метод **GetLangsResume** предназначен для получения данных о знании иностранных языков из резюме.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetLangsResume", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iResumeID_ \- ID резюме, для которого определяются метрики (целое число).

_Возвращаемое значение:_

      Тип: **Объект**. Содержит данные о знании иностранных языков, а также ряд дополнительных атрибутов:  
\- _array_ - массив данных о знании иностранных языков (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID языка (целое число).  
     _name_ \- наименование языка (строка).  
     _level_ \- ID уровня владения  
     _level\_name_ \- наименование уровня владения (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetLangsResume", [iResumeID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
