## GetMyResumes

Метод **GetMyResumes** предназначен для получения списка резюме сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetMyResumes", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _sResumeStatus_ – статус резюме в поисковом запросе (строка) (необязательный). Доступные значения: 'active' (поиск в активных резюме), 'archive' (поиск в архивных резюме). Если параметр не указан, то производится отбор всех резюме без учета их статуса.  
     _sSortType_ \- тип сортировки (строка) (необязательный). Если параметр не указан, то производится сортировка по убыванию даты модификации резюме.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень резюме сотрудника, а также ряд дополнительных атрибутов:  
\- _array_ \- массив резюме (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID резюме (целое число);  
     _fullname_ – ФИО сотрудника, на которого составлено резюме (строка);  
     _creation\_date_ \- дата создания резюме в строковом выражении (строка);  
     _modification\_date_ \- дата модификации резюме в строковом выражении (строка);  
     _position_ \- название должности (строка);  
     _professional\_area\_id_ \- ID профессиональной области (строка) (например, _it, finances, marketing_);  
     _professional\_area\_name_ \- название профессиональной области (строка) (например, _Информационные технологии/Интернет/Телеком, Бухгалтерия/Управленческий учет/Финансы предприятия, Маркетинг/Реклама/PR_);  
     _education\_type\_id_ \- ID типа образования (строка) (например, _secondary, higher, bachelor, master_);  
     _education\_type\_name_ \- название типа образования (строка) (например, _среднее, высшее, высшее Бакалавр, высшее Магистр_);  
     _status_ – статус резюме (строка) (_'Архивное'_ или _'Действующее'_);  
     _link_ – относительная ссылка на карточку резюме (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetMyResumes", [iCurUserID, sResumeStatus, sSortType]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
