## GetPersonWorkflowRequestsEnv

Метод предназначен для получениясписка заявок сотрудника на обучение, которые находятся на этапе согласования (в соответствии с документооборотом).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetPersonWorkflowRequestsEnv", <arrParams>)**

_Аргументы:_  
     _<arrParams>_   
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iRequestTypeID_ \- ID типа заявки (целое число).  
     _sStatus_ \- статус заявки (строка).  
     _oCollectionParams_ \- параметры выборки (объект) (параметры объекта: _filters, distincts, paging_).

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит данные о заявках сотрудника на обучение, находящихся на этапе согласования, а также ряд дополнительных атрибутов:  
\- _array_ \- массив заявок сотрудника на обучение, которые находятся на этапе согласования (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID заявки (целое число);  
     _create\_date_ – дата формирования заявки (дата);  
     _code_ – код заявки (строка);  
     _request\_type\_id_ – ID типа заявки (целое число);  
     _request\_type\_name_ – название типа заявки (строка);  
     _type_ – каталог типа заявки (строка);  
     _object\_name_ – название объекта, с которым связана заявка (строка);  
     _status\_name_ – название статуса заявки (строка) (например, _'Активная', 'Закрыта', 'Отклонена', 'Оплачена'_);  
     _status\_id_ – ID статуса заявки (строка) (например, _'active', 'close', 'ignore', 'pay'_);  
     _link_ – относительная ссылка на заявку (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetPersonWorkflowRequestsEnv", [  iRequestTypeID, sStatus, oCollectionParams ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
