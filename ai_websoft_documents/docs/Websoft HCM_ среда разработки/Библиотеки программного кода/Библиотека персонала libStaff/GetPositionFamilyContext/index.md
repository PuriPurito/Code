## GetPositionFamilyContext

Метод **GetPositionFamilyContext** предназначен для расчета объектной метрики (контекста) семейства должностей.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetPositionFamilyContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iPositionFamilyIDParam_ \- ID семейства должностей, для которого определяются метрики (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные объектной метрики (контекста) семейства должностей, а также ряд дополнительных атрибутов:  
\- _context_ – данные объектной метрики (контекста) семейства должностей (объект).  
     Атрибуты объекта:  
     _code_ – код семейства должностей (строка).  
     _name_ – название семейства должностей (строка).  
     _position\_common\_count_ – число типовых должностей в требованиях к семейству (целое число).  
     _typical\_development\_program\_count_ \- общее количество типовых программ (целое число).  
     _typical\_development\_program\_any\_count_ \- общее число типовых программ в требованиях с типом назначения _Любое перемещение_ (целое число).  
     _typical\_development\_program\_ext\_count_ \- общее число типовых программ в требованиях с типом назначения _Внешнее перемещение_ (целое число).  
     _typical\_development\_program\_int\_count_ \- общее число типовых программ в требованиях с типом назначения _Внутреннее перемещение_ (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_`  
`_oRes = tools.call_code_library_method ("libStaff", "GetPositionFamilyContext", [iPositionFamilyIDParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
