## GetTypicalDevelopmentProgramContext

Метод **GetTypicalDevelopmentProgramContext** предназначен для расчета объектной метрики (контекста) типовой программы развития.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetTypicalDevelopmentProgramContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iTypicalDevelopmentProgram_ \- ID типовой программы развития (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные объектной метрики (контекста) типовой программы развития, а также ряд дополнительных атрибутов:  
\- _context_ – данные объектной метрики (контекста) типовой программы развития (объект).  
     Атрибуты объекта:  
     _name_ – название типовой программы развития (строка).  
     _count_ \- общее число объектов, в которых используется данная типовая программа (сумма значений _position\_common\_count, position\_family\_count_ и _position\_group\_subdivision\_count_) (целое число).  
     _position\_common\_count_ – число типовых должностей, в требованиях которых прописана данная типовая программа (целое число).  
     _position\_family\_count_ – число семейств должностей, в требованиях которых прописана данная типовая программа (целое число).  
     _position\_group\_subdivision\_count_ – число групп подразделений, в требованиях которых прописана данная типовая программа (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetTypicalDevelopmentProgramContext", [iTypicalDevelopmentProgram]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
