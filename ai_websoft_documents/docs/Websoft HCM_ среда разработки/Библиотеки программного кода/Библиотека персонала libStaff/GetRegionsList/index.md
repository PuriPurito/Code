## GetRegionsList

Метод **GetRegionsList** предназначен для получения списка регионов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetRegionsList", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя шесть параметров:  
     _iCurUserID_ \- ID пользователя (целое число).  
     _bAnonymousAccess_ \- показывать список регионов для неавторизованных пользователей (булево) (необязательный).  
     _arrDistincts_ \- перечень полей для формирования дополнительных списков для виджета фильтров (массив строк).  
     _arrFilters_ \- набор фильтров для отбора (массив объектов).  
     _oSort_ \- информация из рантайма о сортировке (объект).  
     _oPaging_ \- информация из рантайма о пейджинге (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень регионов, а также ряд дополнительных атрибутов:  
\- _array_ \- массив регионов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID региона (целое число);  
     _code_ – код региона (строка);  
     _name_ – название региона (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetRegionsList", [iCurUserID, bAnonymousAccess, arrDistincts, arrFilters, oSort, oPaging]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
