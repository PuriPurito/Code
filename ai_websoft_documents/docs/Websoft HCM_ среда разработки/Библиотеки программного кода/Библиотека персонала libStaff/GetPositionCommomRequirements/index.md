## GetPositionCommomRequirements

Метод **GetPositionCommomRequirements** предназначен для получения списка требований для типовой должности.  
Устаревшая функция. С 3-го квартала 2023 г. данная функция заменена на **GetPositionCommonRequirements**.  

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetPositionCommomRequirements", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя четыре параметра:  
     _iPositionCommonIDParam_ \- ID типовой должности (целое число).  
     _tePositionCommon_ \- TopElem типовой должности (объект XmlElem).  
     _iPersonIDParam_ \- ID сотрудника, для котоого проверяются требования (целое число).  
     _bStrongObligatory_ \- проверять только обязательные параметры (булево).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень требований для типовой должности, а также ряд дополнительных атрибутов:

\- _requirements_ \- массив требований для типовой должности (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID требования (целое число);  
     _type_ – код типа требования (строка);  
     _type\_name_ – наименование типа требования (строка);  
     _name_ – наименование требования (строка);  
     _checked_ – соответствие требованию (целое число) (допустимые значения: 1 - соответствует, 0 - не соответствует);   
     _check\_comment_ – сообщение о соответствии требованию (строка);  
     _activity\_name_ – наименование активности (строка);  
     _activity\_url_ – ссылка на прохождение активности (строка).

\- _done\_checked_ – все проверки пройдены (булево).

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetPositionCommomRequirements", [iPositionCommonIDParam, tePositionCommon, iPersonIDParam, bStrongObligatory]);_`
