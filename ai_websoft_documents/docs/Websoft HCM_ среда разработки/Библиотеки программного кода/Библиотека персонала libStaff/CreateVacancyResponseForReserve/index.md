## CreateVacancyResponseForReserve

Метод **CreateVacancyResponseForReserve предназначен** для создания отклика в резерв.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "CreateVacancyResponseForReserve", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _sAlertText_ \- текст сообщения, которое будет показано пользователю, если он не подтвердит согласие на обработку данных (строка).  
     _sUserAgreementLink_ \- ссылка на пользовательское соглашение (строка).  
     _sCommand_ \- режим выполнения удаленного действия (строка). Допустимые значения: _"eval"_ (создание и показ формы); _"submit\_form"_ (обработка формы).   
     _SCOPE\_WVARS_ \- входные параметры удаленного действия (объект).  
     _curLngWeb_ \- переменная, определяющая язык выражения (строка).  

_Возвращаемые значения:_

      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _result_ – результат вызова метода (содержит значения полей формы form\_fields ("lastname", "firstname", "middlename", "email", "phone", "city", "profession\_id", "resume\_file\_id", "portfolio\_file\_id", "is\_confirm" (наличие согласия на обработку персональных данных)) (объект).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "CreateVacancyResponseForReserve", [sAlertText, sUserAgreementLink, sCommand, SCOPE_WVARS, curLngWeb]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
