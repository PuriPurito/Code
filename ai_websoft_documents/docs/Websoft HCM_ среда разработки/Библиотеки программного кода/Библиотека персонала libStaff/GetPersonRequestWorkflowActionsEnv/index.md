## GetPersonRequestWorkflowActionsEnv

Метод **GetPersonRequestWorkflowActionsEnv** предназначен для получения списка действий заявки, которые доступны для пользователя на этапе согласования в соответствии с документооборотом.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetPersonRequestWorkflowActionsEnv", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iRequestID_ \- ID заявки (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень действий заявки, которые доступны для пользователя на этапе согласования в соответствии с документооборотом, а также ряд дополнительных атрибутов:  
\- _array_ \- массив действий заявки (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID действия (целое число).  
     _title_ – название действия (строка).  
     action\_id – ID действия (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetPersonRequestWorkflowActionsEnv", [iRequestID]);_`   
  
`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
