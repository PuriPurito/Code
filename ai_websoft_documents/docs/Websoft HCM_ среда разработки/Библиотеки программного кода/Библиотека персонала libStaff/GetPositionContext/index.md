## GetPositionContext

Метод **GetPositionContext** предназначен для расчета объектной метрики (контекста) должности.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetPositionContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iPositionIDParam_ \- ID должности, для которого определяются метрики (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит объектную метрику (контекст) должности, а также ряд дополнительных атрибутов:  
\- _context_ – данные объектной метрики (контекста) должности (объект).  
     Атрибуты объекта:  
     _code_ – код должности (строка).  
     _name_ – название должности (строка).  
     _position\_family\_count_ – число семейств должностей, в которые входит типовая должность, к которой относится данная должность (целое число).  
     _group\_subdivision\_count_ \- число групп подразделений, в которые входит подразделение, к которому относится данная должность (целое число).  
     _typical\_development\_program\_count_ \- общее количество типовых программ развития (целое число).  
     _typical\_development\_program\_any\_count_ \- общее число типовых программ развития со способом назначения _Любое перемещение_ (целое число). Считается как сумма программ развития с этим способом назначения, указанных в требованиях к типовой должности (к которой относится должность), к семействам должностей (к которым относится типовая должность) и к группам подразделений (к которым относится подразделение должности)   
     _typical\_development\_program\_ext\_count_ \- общее число типовых программ с типом назначения _Внешнее перемещение_ (целое число).  
     _typical\_development\_program\_int\_count_ \- общее число типовых программ с типом назначения _Внутреннее перемещение_ (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetPositionContext", [iPositionIDParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
