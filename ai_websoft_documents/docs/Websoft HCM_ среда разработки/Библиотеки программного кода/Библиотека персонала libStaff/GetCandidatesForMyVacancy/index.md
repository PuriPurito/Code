## GetCandidatesForMyVacancy

Метод **GetCandidatesForMyVacancy** предназначен для получения списка кандидатов для вакансии, опубликованной сотрудником.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetCandidatesForMyVacancy", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iVacancyID_ \- ID вакансии (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень кандидатов для вакансии, а также ряд дополнительных атрибутов:  
\- _array_ \- массив кандидатов для вакансии (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID кандидата (целое число);  
     _fullname_ – ФИО кандидата (строка);  
     _status_ – статус кандидата (строка);  
     _date_ – дата формирования карточки кандидата в строковом выражении (строка);  
     _link_ – относительная ссылка на карточку кандидата (строка).  
 

\- _action\_result_ – результат вызова метода (объект с несколькими параметрами: command – тип результата (строка) (в случае ошибки обычно имеет значение "alert" (сообщение)) и др.)  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetCandidatesForMyVacancy", [iVacancyID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
