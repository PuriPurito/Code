## GetPositionCommonRequirements

Метод **GetPositionCommonRequirements** предназначен для получения коллекции требований в типовой должности.

Внимание! До  3-го квартала 2023 г. данная функция именовалась **GetPositionCommomRequirements.**

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetPositionCommonRequirements", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iPositionCommonID_ \- ID типовой должности (целое число).  
     _tePositionCommon_ \- TopElem типовой должности (объект XmElem).  
     _iPersonID_ \- ID сотрудника, для котоого проверяются требования (целое число).  
     _bStrongObligatory_ \- проверять только обязательные параметры (булево). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень требований для типовой должности, а также ряд дополнительных данных:  
  
\- _requirements_ \- массив требований для типовой должности (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID требования (целое число);  
     _type_ – код типа требования (строка);  
     _type\_name_ – наименование типа требования (строка);  
     _name_ – наименование требования (строка);  
     _checked_ – соответствие требованию (целое число) (допустимые значения: 1 - соответствует, 0 - не соответствует);   
     _check\_comment_ – сообщение о соответствии требованию (строка);  
     _activity\_name_ – наименование активности (строка);  
     _activity\_url_ – ссылка на прохождение активности (строка).  
  
\- _add\_requirements_ – массив дополнительных требований (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID требования (целое число).  
     _name_ – наименование требования (строка).  
     _comment_ – комментарий требования (строка).  
  
\- _done\_checked_ – все проверки пройдены (булево).
