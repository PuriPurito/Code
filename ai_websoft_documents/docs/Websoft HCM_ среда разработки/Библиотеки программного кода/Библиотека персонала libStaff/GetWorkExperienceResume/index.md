## GetWorkExperienceResume

Метод **GetWorkExperienceResume** предназначен для получения перечня данных об опыте работы из резюме.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetWorkExperienceResume", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iResumeID_ \- ID резюме, для которого определяются метрики (целое число).

_Возвращаемое значение:_

      Тип: **Объект**. Содержит перечень данных об опыте работы из резюме, а также ряд дополнительных атрибутов:  
\- _array_ - массив данных об опыте работы (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID опыта работы (целое число).  
     _start\_date_ \- дата начала работы в строчном формате (строка).  
     _finish\_date_ \- дата окончания работы в строчном формате (строка).  
     _org\_name_ \- название организации (строка).  
     _profession\_id_ \- ID профессиональной области (целое число).  
     _profession\_name_ \- наименование профессиональной области (строка).  
     _region\_id_ \- ID региона (целое число).  
     _region\_name_ \- наименование региона (строка).  
     _org\_phone_ \- рабочий телефон организации (строка).  
     _org\_fax_ \- факс организации (строка).  
     _org\_email_ \- e-mail организации (строка).  
     _org\_address_ \- адрес организации (строка).  
     _org\_site_ \- URL сайта организации (строка).  
     _position\_name_ \- занимаемая должность (строка).  
     _desc_ – описание (строка).  
     _comment_ \- комментарий (строка).  
  
\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetWorkExperienceResume", [iResumeID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
