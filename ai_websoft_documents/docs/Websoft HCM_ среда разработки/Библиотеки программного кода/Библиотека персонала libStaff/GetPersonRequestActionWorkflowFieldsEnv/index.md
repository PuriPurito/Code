## GetPersonRequestActionWorkflowFieldsEnv

Метод **GetPersonRequestActionWorkflowFieldsEnv** предназначен для получения списка полей действий заявки, которые доступны пользователю для чтения на этапе согласования в соответствии с документооборотом.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetPersonRequestActionWorkflowFieldsEnv", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iRequestID_ \- ID заявки (целое число).  
     sAction - ID действия (необязательный) (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень полей действий заявки, а также ряд дополнительных атрибутов:  
\- _array_ \- массив полей (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID поля (целое число).  
     _title_ \- название поля (строка).  
     _value_ \- значениеполя (строка).  
     _type_ \- тип поля (строка).  
     _catalog_ \- название каталога (строка).  
     _tooltip_ \- всплывающая подсказка (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetPersonRequestActionWorkflowFieldsEnv", [iRequestID, sAction]);_`
