## GetRequestContext

Метод **GetRequestContext** предназначен для получения контекста заявки.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetRequestContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _iRequestID_ \- ID заявки (целое число).  
     _iPersonID_ \- ID сотрудника (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о контексте заявки, а также ряд дополнительных атрибутов:  
\- _context_ \- контекст заявки (объект).  
     Атрибуты объекта:  
     _bAccess_ – имеется ли доступ к заявке (булево);  
     _sPersonRole_ – роль сотрудника (текущего пользователя) по отношению к заявке (строка) (допустимые значения: 'person', 'tutor', 'none').  
     _bCanCancel_ – может ли сотрудник отменить заявку (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetRequestContext", [iRequestID, iPersonID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
