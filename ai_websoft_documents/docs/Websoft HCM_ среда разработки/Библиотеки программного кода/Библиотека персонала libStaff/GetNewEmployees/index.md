## GetNewEmployees

Метод **GetNewEmployees** предназначен для получения списка новых сотрудников за период.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetNewEmployees", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iPeriod_ \- количество дней, в течение которых сотрудник считается новым (целое число).  
     _iOrgID_ \- ID организации (целое число).  
     oSort - информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).  
     oPaging - информация из рантайма о пейджинге (объект). Объект включает в себя следующие данные:  INDEX - номер страницы (целое число);  SIZE - размер страницы (целое число); MANUAL - разделение на страницы вручную (булево); TOTAL - общее количество страниц (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень новых сотрудников за период, а также ряд дополнительных атрибутов:  
\- _array_ \- массив новых сотрудников (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID сотрудника (целое число).  
     _fullname_ – ФИО сотрудника (строка).  
     _hire\_date_ \- дата приема сотрудника на работу (дата).  
     _hire\_date\_str_ \- дата приема сотрудника на работу в строковом выражении (строка).  
     _image_ – относительная ссылка на изображение (строка).  
     _desc_ – описание (строка).  
     _link_ – относительная ссылка на карточку сотрудника (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetNewEmployees", [ iPeriod, iOrgID, oSort, oPaging ]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
