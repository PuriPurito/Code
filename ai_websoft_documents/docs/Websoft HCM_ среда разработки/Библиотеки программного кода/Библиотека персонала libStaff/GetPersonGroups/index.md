## GetPersonGroups

Метод предназначен для получения списка групп, в которые входит сотрудник.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libStaff", "GetPersonGroups", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _bShowMyOwnGrp_ \- показывать только те группы, владельцем которых является сотрудник (булево).  
     _bShowHideGrp_ \- показывать скрытые группы (булево)  
     _iCurUserID_ \- ID текущего сотрудника (целое число).  
     _bCheckAccess_ \- выполнить проверку прав доступа (булево). 

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит данные о группе, в которую входит сотрудник, а также ряд дополнительных атрибутов:  
\- _array_ \- массив данных о группах (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID группы (целое число);  
     _name_ – название группы (строка);  
     _link_ – относительная ссылка на группу (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libStaff", "GetPersonGroups", [iPersonID, bShowMyOwnGrp, bShowHideGrp, iCurUserID, bCheckAccess]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
