## SaveEvent

Метод **SaveEvent** предназначен для сохранения карточки мероприятия.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "SaveEvent", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра (данные будут уточнены):  
     _docEvent_ – документ карточки мероприятия (объект XmlDoc).  
     _bNeedSave_ – сохранять ли карточку мероприятия (булево) (необязательный). Значение по умолчанию - _true_. 

_Возвращаемое значение:_  
      Тип:  **Объект** . Содержит ряд атрибутов:  
\- _doc\_event_ – документ карточки мероприятия (объект XmlDoc).  
  
_\- error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
_\- errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "SaveEvent", [docEvent, bNeedSave]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
