## GetTrainerCollaborators

Метод **GetTrainerCollaborators** предназначен для получения выборки сотрудников для Кабинета тренера.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetTrainerCollaborators", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четырнадцать параметров (данные будут уточнены):  
     _iPersonID_ \- ID сотрудника (целое число).  
     _tePerson_ \- TopElem сотрудника (объект XmlElem).  
     _sSearch_ – критерий поиска (строка);   
     _sFilterID_ – ID фильтра (строка);  
     _sQueryQual_ – текст запроса (строка);  
     _sAccessTypeID_ – тип доступа пользователя (строка);  
     _arrRestrictions_ – набор ограничений (массив);   
     _arrBossTypesID_ \- массив ID типов руководителей для поиска для типов func\_subordinates и all\_subordinates (массив целых чисел);  
     _arrStatuses_ – массив статусов (массив строк);  
     _arrEventTypesID_ – массив ID типов мероприятий (массив целых чисел);  
     _arrRolesID_ – массив ID типов ролей (массив целых чисел);  
     oSort - информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).  
     oPaging - информация из рантайма о пейджинге (объект). Объект включает в себя следующие данные:  INDEX - номер страницы (целое число);  SIZE - размер страницы (целое число); MANUAL - разделение на страницы вручную (булево); TOTAL - общее количество страниц (целое число).  
     _arrAddColumns_ – добавленные колонки (массив).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит выборку сотрудников для Кабинета тренера, а также ряд дополнительных атрибутов:  
\- _array_ \- массив сотрудников для Кабинета тренера (массив объектов).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "GetTrainerCollaborators", [iPersonID, tePerson, sSearch, sFilterID, sQueryQual, sAccessTypeID, arrRestrictions, arrBossTypesID, arrStatuses, arrEventTypesID, arrRolesID, oSort, oPaging, arrAddColumns]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
