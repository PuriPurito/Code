## GetPersonEventResults

Метод **GetPersonEventResults** предназначен для получения списка результатов мероприятий по сотруднику.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetPersonEventResults", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя девять параметров:  
     _iPersonID_ \- ID пользователя (целое число).  
     _sType_ \- тип отбора сотрудников (строка) (необязательный). Значение по умолчанию - _"all\_subordinates"_.  
     _aStates_ \- массив статусов (массив строк) (необязательный).  
     _bOnlyPast_ \- показывать ли только данные по прошедшим мероприятиям (булево) (необязательный). Значение по умолчанию - _false_.  
     _bShowDismiss_ \- показывать ли уволенных сотрудников (булево) (необязательный). Значение по умолчанию - _false_.  
     _sSearch_ \- критерий поиска (строка) (необязательный).  
     _bAllHier_ \- выполнять ли поиск всех руководителей вверх по иерархии (булево) (необязательный). Значение по умолчанию - _false_.  
     _arrBossTypesID_ \- массив ID типов руководителя (массив целых чисел) (необязательный).  
     _iNum_ \- количество возвращаемых записей (целое число) (необязательный). По умолчанию количество возвращаемых записей неограничено. 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень результатов мероприятий по сотруднику, а также ряд дополнительных атрибутов:  
\- _array_ \- массив результатов мероприятий (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID результата мероприятия (целое число);  
     _event\_name_ \- название результата мероприятия (строка);  
     _person\_fullname_ \- ФИО сотрудника (строка);  
     _status\_id_ \- статус результата мероприятия (строка). Примеры статусов мероприятий: _'scheduled', 'start', 'active', 'succeeded', 'failed', 'cancelled'_.  
     _status\_name_ \- название статуса результата мероприятия на русском языке (строка). Примеры названий статусов на русском языке: _'запланировано', 'начато', 'в процессе', 'пройдено', 'не пройдено', 'отменено'_.  
     _person\_icon_ – относительная ссылка на изображение сотрудника (строка);  
     _person\_link_ – относительная ссылка на карточку сотрудника (строка);  
     _person\_position\_name_ \- название должности сотрудника (строка);  
     _event\_link_ – относительная ссылка на карточку мероприятия (строка);  
     _event\_type\_name_ \- название типа мероприятия (строка);  
     _is\_assist_ \- признак присутствия сотрудника на мероприятии (булево);  
     _score_ \- результат участия сотрудника в мероприятии (целое число);  
     _start\_date_ \- дата начала мероприятия (дата);  
     _finish\_date_ \- дата окончания мероприятия (дата);  
     _education\_org\_name_ \- название обучающей организации (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "GetPersonEventResults", [iPersonID, sType, aStates, bOnlyPast, bShowDismiss, sSearch, bAllHier, arrBossTypesID, iNum]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
