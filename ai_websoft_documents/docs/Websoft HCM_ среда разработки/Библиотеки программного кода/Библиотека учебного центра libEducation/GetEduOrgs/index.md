## GetEduOrgs

Метод **GetEduOrgs** предназначен для получения списка обучающих организаций.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetEduOrgs", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя семь параметров:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _sAccessType_ \- тип доступа для отбора (строка) (необязательный). Допустимые значения: "admin" (администратор приложения); "manager" (администратор процесса); "hr" (менеджер по персоналу); "expert" (эксперт по тематике); "observer" (наблюдатель); "auto" (определяется автоматически в соответствии с правами доступа пользователя). Значение по умолчанию - "auto".  
     _sApplication_ \- код (или ID) приложения, по которому определяется доступ (строка) (необязательный).   
     _arrTypesOrgs_ \- типы возвращаемых обучающих организаций (массив строк) (необязательный). Допустимые значения: "is\_provider\_courses" (провайдеры, являющиеся поставщиками курсов), "is\_not\_provider\_courses" (провайдеры, не являющиеся поставщиками курсов).  
     _arrReturnData_ \- массив полей для вывода (массив строк) (необязательный). Допустимые значения: "lectors\_count" (количество преподавателей), "education\_method\_count"( количество программ), "event\_count"( количество мероприятий).  
     _sXQueryQual_ \- фильтр XQuery для отбора (строка) (необязательный).  
     _oCollectionParams_ \- набор интерактивных параметров выборки (объект). Параметры объекта: filters (отбор), sort (сортировка), paging (пейджинг). 

_Возвращаемое значение:_  
      Тип: **Объект**.

Содержит перечень обучающих организаций, а также ряд дополнительных атрибутов:  
\- _array_ \- массив обучающих организаций (массив объектов).  
     Атрибуты отдельного элемента массива:  
     _id_ \- ID обучающей организации (целое число).  
     _disp\_name_ \- условное название обучающей организации, отображаемое в системе в разделах Персонал - Структура подразделений и Персонал - Структура подразделений - Организации (строка).  
     _name_ \- официальное название обучающей организации (строка).  
     _provider\_courses_ \- поставщик электронных курсов (строка). Допустимые значения: "Да"; "Нет".  
     _lectors\_count_ \- количество преподавателей, указанных в данной обучающей организации (целое число). Параметр отображается в зависимости от значения массива arrReturnData.  
     _education\_method\_count_ \- количество учебных программ, в которых указана данная обучающая организация (целое число). Параметр отображается в зависимости от значения массива arrReturnData.  
     _event\_count_ \- количество мероприятий, в которых указана данная обучающая организация (целое число). Параметр отображается в зависимости от значения массива arrReturnData.  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "GetEduOrgs", [iCurUserID, sAccessType, sApplication, arrTypesOrgs, arrReturnData, sXQueryQual, oCollectionParams]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
