## GetCompoundProgramFiles

Метод **GetCompoundProgramFiles** предназначен для получения списка материалов (файлов) по модульной программе.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetCompoundProgramFiles", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iCompoundProgramID_ \- ID модульной программы (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень материалов (файлов) по модульной программе, а также ряд дополнительных атрибутов:  
\- _array_ \- массив материалов (файлов) по модульной программе (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID файла (целое число);  
     _name_ – название файла, прикрепленного к мероприятию, с расширением;  
     _type_ – тип прикрепленного элемента (строка, имеющая значение "file");  
     _link_ – относительная ссылка на файл (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "GetCompoundProgramFiles", [iCompoundProgramID]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
