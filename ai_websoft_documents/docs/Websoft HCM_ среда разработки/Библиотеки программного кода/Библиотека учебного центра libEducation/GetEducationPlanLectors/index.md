## GetEducationPlanLectors

Метод **GetEducationPlanLectors** предназначен для получения списка преподавателей по учебному плану/программе.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetEducationPlanLectors", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iObjectIDParam_ \- ID учебного плана/программы (целое число).  
     _bShowDismiss_ \- показывать уволенных сотрудников (булево) (необязательный). Если параметр получает значение _true_, то будут показаны уволенные сотрудники. Если параметр получает значение _false_, то уволенные сотрудники показаны не будут. Значение по умолчанию - _false_.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень преподавателей по учебному плану/программе, а также ряд дополнительных атрибутов:  
\- _array_ \- массив преподавателей по учебному плану/программе (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID преподавателя (целое число);  
     _name_ – ФИО преподавателя (строка);  
     _image\_url_ – относительная ссылка на фотографию или аватар преподавателя (строка);  
     _link_ – относительная ссылка на карточку преподавателя (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "GetEducationPlanLectors", [iObjectIDParam, bShowDismiss]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
