## GetEducationPrograms

Метод **GetEducationPrograms** предназначен для получения списка наборов программ.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetEducationPrograms", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя шесть параметров:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _sAccessType_ \- тип доступа для отбора (строка) (необязательный). Допустимые значения: "admin" (администратор приложения); "manager" (администратор процесса); "hr" (менеджер по персоналу); "expert" (эксперт по тематике); "observer" (наблюдатель); "auto" (определяется автоматически в соответствии с правами доступа пользователя). Значение по умолчанию - "auto".  
     _sApplication_ \- код (или ID) приложения, по которому определяется доступ (строка) (необязательный).   
     _arrReturnData_ \- массив полей для вывода (массив строк) (необязательный). Допустимые значения: "methods\_count" (количество программ, входящих в набор),"event\_count" (количество мероприятий для данного набора программ).  
     _sXQueryQual_ \- фильтр XQuery для отбора (строка) (необязательный).  
     _oCollectionParams_ \- набор интерактивных параметров выборки (объект). Параметры объекта: filters (отбор), sort (сортировка), paging (пейджинг). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень наборов программ, а также ряд дополнительных атрибутов:  
\- _array_ \- массив наборов программ (массив объектов).  
     Атрибуты отдельного элемента массива:  
     _id_ \- ID набора программ (целое число).  
     _name_ \- название набора программ (строка).   
     _methods\_count_ \- количество программ, входящих в набор (целое число). Параметр отображается в зависимости от значения массива arrReturnData.  
     _event\_count_ \- количество мероприятий для данного набора программ (целое число). Параметр отображается в зависимости от значения массива arrReturnData.

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "GetEducationPrograms", [iCurUserID, sAccessType, sApplication, arrReturnData, sXQueryQual, oCollectionParams]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
