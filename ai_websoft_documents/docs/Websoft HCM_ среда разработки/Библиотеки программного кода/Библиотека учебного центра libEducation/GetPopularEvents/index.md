## GetPopularEvents

Метод **GetPopularEvents** предназначен для получения списка наиболее популярных мероприятий.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetPopularEvents", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя десять параметров:  
     _iPersonID_ \- ID пользователя (целое число).  
     _sType_ \- тип отбора сотрудников (строка) (необязательный). Значение по умолчанию - _"all\_subordinates"_.  
     _aStates_ \- массив статусов (массив строк) (необязательный).  
     _bOnlyPast_ \- показывать ли только данные по прошедшим мероприятиям (булево) (необязательный). Значение по умолчанию - _false_.  
     _bShowDismiss_ \- показывать ли уволенных сотрудников (булево) (необязательный). Значение по умолчанию - _false_.  
     _sSearch_ \- критерий поиска (строка) (необязательный).  
     _bAllHier_ \- выполнять ли поиск всех руководителей вверх по иерархии (булево) (необязательный). Значение по умолчанию - _false_.  
     _arrBossTypesID_ \- массив ID типов руководителя (массив целых чисел) (необязательный).  
     _iNum_ \- количество возвращаемых записей (целое число) (необязательный). По умолчанию количество возвращаемых записей неограничено.  
     _sSortType_ \- тип сортировки (строка) (необязательный). По умолчанию сортировка производится по убыванию количества участников, присутствовавших на мероприятии. Если _sSortType = "name"_, то сортировка производится по возрастанию названия мероприятия. 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень наиболее популярных мероприятий, а также ряд дополнительных атрибутов:  
\- _array_ \- массив наиболее популярных мероприятий (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID мероприятия (целое число);  
     _name_ \- название мероприятия (строка);  
     _image_ – относительная ссылка на изображение (строка);  
     _count_ \- количество участников, присутствовавших на мероприятии (целое число);  
     _success\_percent_ \- процент количества участников, присутствовавших на мероприятии, от общего количества зарегистрированных участников (целое число);  
     _total\_hours_ \- фактическая продолжительность мероприятия в часах (целое число);  
     _is\_coming_ \- признак незавершенности мероприятия (при значении true мероприятие считается незавершенным) (булево);  
     _total\_num_ \- общее количество зарегистрированных участников (целое число).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "GetPopularEvents", [iPersonID, sType, aStates, bOnlyPast, bShowDismiss, sSearch, bAllHier, arrBossTypesID, iNum, sSortType]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
