## GetSimilarEducationMethods

Метод предназначен для получения списка учебных программ, похожих на текущую.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetSimilarEducationMethods", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iEducationMethodID_ – ID учебной программы, из которой извлекаются данные (целое число).   
     _sTypeSimilar_ – способ отбора похожих программ (строка).   
Допустимые значения параметра _sTypeSimilar_:   
\- _tags_ \- по тегам (отбираются программы с такими же тегами),   
\- _education\_program_ \- по наборам программ (отбираются программы из того же набора),   
\- _role_ \- по категориям (отбираются программы из той же категории)   
\- _education\_method_ – по учебным программам (выбираются программы, указанные в карточке текущей).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень учебных программ, похожих на текущую, а также ряд дополнительных атрибутов:  
\- _array_ \- массив учебных программ, похожих на текущую (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID учебной программы, похожей на текущую (целое число);  
     _name_ – название учебной программы (строка);  
     _link_ – относительная ссылка на карточку учебной программы (строка);  
     _type_ – тип учебной программы (строка);  
     _object\_name_ – название объекта (строка);  
     _person\_num_ – количество участников (целое число);  
     _cost_ – стоимость (целое число);  
     _image\_url_ – относительная ссылка на изображение (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример 1:_

`_// Пусть в системе имеется учебная программа «Английский язык»   // Находим указанную учебную программу с помощью функции_ _tools.get_doc_by_key_   _oEdMeth = tools.get_doc_by_key ( 'education_method', 'name', 'Английский язык' );   alert ( 'Найдена учебная программа ' + oEdMeth.TopElem.name + ' с идентификационным номером ' + oEdMeth.TopElem.id ); // на экран выводится информация об отобранной учебной программе_`

`_iEduMethodID = oEdMeth.TopElem.id;_`

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "GetSimilarEducationMethods", [OptInt (iEduMethodID), 'education_method']);_`

`_// В данном примере используется способ отбора "education_method". `_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
