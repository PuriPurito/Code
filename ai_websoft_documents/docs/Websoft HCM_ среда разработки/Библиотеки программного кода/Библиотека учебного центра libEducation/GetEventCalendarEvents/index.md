## GetEventCalendarEvents

Метод предназначен для получения списка мероприятий сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetEventCalendarEvents", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя семнадцать параметров:  
     _iUserID_ \- ID пользователя (сотрудника) (целое число) (обязательный).  
     _sSearchWord_ \- критерий поиска (строка) (необязательный).  
     _sType_ \- принадлежность мероприятия (строка) (допустимые значения: _'all', 'my', 'mysub'_) (необязательный). Значение по умолчанию - _'all'_.  
     _sStatus_ \- ID статуса мероприятия (строка) (необязательный) (допустимые значения: _'all' (Все статусы), 'undefined' (Не определен), 'project' (Проект), 'plan' (Планируется), 'active' (Проводится), 'close' (Завершено), 'cancel' (Отменено)_). Значение по умолчанию - _'all'_.  
     _iPlace_ \- ID места проведения мероприятия (целое число) (необязательный).  
     _iEducationOrg_ \- ID обучающей организации (целое число) (необязательный).  
     _sOrgForm_ \- организационная форма (строка) (необязательный) (допустимые значения: 'all' (Все организационные формы), 'individual' (индивидуальная), 'corporative' (корпоративная)). Значение по умолчанию - 'all'.  
     _sEventForm_ \- форма проведения (строка) (необязательный) (допустимые значения: _'all' (Все формы проведения), 'seminar' (семинар), 'training' (тренинг), 'conference' (конференция), 'examination' (экзамен), 'courses' (курсы), 'questioning' (анкетирование), 'corporate\_seminar' (корпоративный семинар), 'improvement\_professional\_skill' (повышение квалификации), 'consulting\_seminar' (консультационный семинар), 'service\_participants' (обслуживание участников), 'information\_consulting\_services' (информационно-консультационные услуги), 'education' (обучение)_). Значение по умолчанию - _'all'_.  
     _iLector_ – ID преподавателя, принимающего участие в мероприятии (целое число) (необязательный).  
     _iEducationProgram_ – ID набора программ (целое число) (необязательный).  
     _bShowOnlySamePlace_ \- отображать только мероприятия из расположения сотрудника (булево) (необязательный). Значение по умолчанию - _false_.  
     _bCheckHirePlace_ \- учитывать расположения вниз по иерархии (булево) (необязательный).  
     _sUserType_ \- тип участия в мероприятии (строка) (Допустимые значения: _'participant', 'lector', 'tutor'_). В данной строке можно указать несколько значений, разделенных символом «точка с запятой» («;»). Значение по умолчанию - _'participant;lector;tutor'_.  
     _dStartDate_ \- начало периода поиска (дата) (необязательный).   
     _dEndDate_ \- конец периода поиска (дата) (необязательный).  
     _bShowOnlyOpen_ \- показывать только открытие мероприятия (булево) (необязательный). Значение по умолчанию - _false_.  
     _bShowOnlyPublic_ \- показывать только публичные мероприятия (булево) (необязательный). Значение по умолчанию - _false_.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит список мероприятий сотрудника, а также ряд дополнительных атрибутов:  
\- _array_ \- массив мероприятия сотрудника (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID мероприятия (целое число);  
     _name_ – название мероприятия (строка);  
     _desc_ – описание (строка);  
     _type_ – тип мероприятия (строка);  
     _status\_id_ – ID статуса мероприятия (строка) (допустимые значения: _'undefined' (Не определен), 'project' (Проект), 'plan' (Планируется), 'active' (Проводится), 'close' (Завершено), 'cancel' (Отменено)_);  
     _start\_date_ – начало мероприятия (дата);  
     _finish\_date_ – конец мероприятия (дата);  
     _category_ – категория мероприятия (строка);  
     _class_ – класс мероприятия (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "GetEventCalendarEvents", [ iUserID, sSearchWord, sType, sStatus, iPlace, iEducationOrg, sOrgForm, sEventForm, iLector, iEducationProgram, bShowOnlySamePlace, bCheckHirePlace, sUserType, dStartDate, dEndDate, bShowOnlyOpen, bShowOnlyPublic ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
