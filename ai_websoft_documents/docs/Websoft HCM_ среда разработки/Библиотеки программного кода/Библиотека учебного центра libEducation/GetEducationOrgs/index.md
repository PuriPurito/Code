## GetEducationOrgs

Метод **GetEducationOrgs** предназначен для получения списка обучающих организаций.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetEducationOrgs", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя следующие параметры:     iCurUserID - ID сотрудника (целое число).  
     _bCheckAccess_ \- нужно ли проверять права доступа (булево).   
     _aRolesID_ \- массив ID категорий (массив целых чисел).  
     _bWithComment_ \- возвращать комментарий (булево).  
     _bRetByHier_ \- возвращать также данные из дочерних категорий (булево).  
     _bIgnoreRoles_ \- не учитывать категории в отборе (булево).  
     _arrDistinct_ \- перечень полей для формирования дополнительных списков для виджета фильтров (массив строк).  
     _arrFilters_ \- набор фильтров (массив объектов) (параметры объекта: id - ID фильтра (строка или массив строк), type - тип фильтра (строка), value - значение (строка)).  
     _oSort_ \- информация из рантайма о сортировке (JSON объект).   
     _oPaging_ \- информация из рантайма о пейджинге (JSON объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень обучающих организаций, а также ряд дополнительных атрибутов:  
\- _array_ \- массив обучающих организаций (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID обучающей организации (целое число);  
     _name_ \- название обучающей организации (строка);  
     _desc_ \- описание (строка);  
     _image_ – относительная ссылка на изображение (строка);  
     _link_ – относительная ссылка на обучающую организацию (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "GetEducationOrgs", [iCurUserID, bCheckAccess, aRolesID, bWithComment, bRetByHier, bIgnoreRoles, arrDistinct, arrFilters, oSort, oPaging]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
