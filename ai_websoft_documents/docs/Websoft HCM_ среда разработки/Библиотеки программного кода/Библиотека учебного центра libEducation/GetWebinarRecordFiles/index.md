## GetWebinarRecordFiles

Метод предназначен для получения файлов видеозаписи вебинара.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetWebinarRecordFiles", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два элемента:  
     _iEventID_ – ID мероприятия (целое число).   
     _iPersonID_ – ID сотрудника (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит массив файлов видеозаписи вебинара, а также ряд дополнительных атрибутов:  
\- _array_ \- массив файлов видеозаписи вебинара (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID файла (целое число);  
     _name_ – название файла, прикрепленного к мероприятию, с расширением;  
     _type_ – тип прикрепленного элемента (строка, имеющая значение _"file"_);  
     _link_ – относительная ссылка на файл (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

     `_RESULT = tools.call_code_library_method ("libEducation", "GetWebinarRecordFiles", [iEventID, iPersonID]).array;_`
