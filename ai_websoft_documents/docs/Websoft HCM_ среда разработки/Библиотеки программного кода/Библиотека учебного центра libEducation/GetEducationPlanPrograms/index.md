## GetEducationPlanPrograms

Метод предназначен для получения списка этапов учебного плана.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEdu", "GetEducationPlanPrograms", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один элемент:  
     _iEducationPlanID_ \- ID учебного плана (целое число).

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит перечень этапов учебного плана, а также ряд дополнительных атрибутов:  
\- _array_ \- массив мероприятий по учебной программе (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID этапа учебного плана (целое число);  
     _name_ – название этапа (строка);  
     _parent\_id_ – ID родительского объекта (строка);  
     _status\_name_ – статус этапа (строка) (допустимые значения: 'Не определен', 'Проект', 'Планируется', 'Проводится', 'Завершено', 'Отменено').  
     _type\_name_ – название типа этапа (строка);  
     _link_ – относительная ссылка на этап учебного плана (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

     `_RESULT = tools.call_code_library_method ("libEdu", "GetEducationPlanPrograms", [iEducationPlanID]).array;_`
