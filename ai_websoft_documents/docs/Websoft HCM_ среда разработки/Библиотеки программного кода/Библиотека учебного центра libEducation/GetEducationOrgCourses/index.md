## GetEducationOrgCourses

Метод **GetEducationOrgCourses** предназначен для получения списка курсов по учебной организации.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetEducationOrgCourses", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iEducationOrgID_ \- ID учебной организации (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень курсов по учебной организации, а также ряд дополнительных атрибутов:  
\- _array_ \- массив курсов (массив объектов).  
     Атрибуты отдельного элемента массива:  
     _id_ \- ID курса (целое число).  
     _code_ \- код курса (строка).  
     _name_ \- название курса (строка).  
     _status_ \- статус курса (строка).  
     _education\_org\_id_ \- ID обучающей организации (целое число).  
     _mastery\_score_ \- проходной балл (целое число).  
     _max\_score_ \- максимальный балл (целое число).  
     _duration_ \- продолжительность курса в днях (целое число).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "GetEducationOrgCourses", [iEducationOrgID]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
