## GetEducationMethodContext

Метод **GetEducationMethodContext** предназначен для получения статистики по учебной программе.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetEducationMethodContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iEducationMethodID_ \- ID учебной программы (целое число).  
     _iPersonID_ \- ID текущего пользователя (целое число).  
     _sAppCode_ \- код приложения (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о статистике по учебной программе, а также ряд дополнительных атрибутов:  
\- _context_ \- данные о статистике по учебной программе (объект).  
     Атрибуты контекста:  
     _event\_count_ – сумма всех мероприятий по этой программе с любыми статусами, кроме _Отменено и Проект_ (целое число).  
     _collaborators\_trained\_count_ \- число всех участников мероприятий со статусами _Проводится и Завершено_, у которых отмечен признак присутствия (целое число).  
     _next\_event_ \- ближайшее по дате и времени проведение мероприятие по данной учебной программе со статусом _Планируется_ или _Проводится_ (целое число).  
     _planned\_event_ \- сумма всех мероприятий по этой программе со статусом _Планируется_ (целое число).  
     _planned\_education_ \- число всех участников мероприятий со статусом _Планируется_ (целое число).  
     _response\_count_ \- количество анкет (отзывов) (целое число).  
     _percent\_response_ \- процент заполнения отзывов (целое число).  
     _average\_response_ \- средняя оценка по отзывам (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "GetEducationMethodContext", [iEducationMethodID, iPersonID, sAppCode]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
