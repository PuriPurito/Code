## GetEduMethodKnowledgeParts

Метод предназначен для получения списка значений карты знаний учебной программы.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEdu", "GetEduMethodKnowledgeParts", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iEduMethodID_ – ID учебной программы (целое число).    
     _iCurUserID_ \- ID пользователя (сотрудника), относительно которого извлекаются данные (целое число).   
     _bShowOnlyAcknowledgement_ \- отображение только подтвержденных значений (булево). Если параметр равен _true_, то выборка возвращает только подтвержденные значения, если _false_, то - все значения. По умолчанию – _true_.

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит значения карты знаний учебной программы, а также ряд дополнительных атрибутов:  
\- _array_ \- массив значений карты знаний (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID значения карты знаний (целое число);  
     _name_ – название значения карты знаний (строка);  
     _desc_ – описание (строка);  
     _class_ – значение классификатора (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

`_// Пусть в системе имеется сотрудник Васильева Людмила Петровна, которая принимает участие в мероприятии   // Находим программно сотрудника Васильеву Л.П. с помощью функции tools.get_doc_by_key   oCollab = tools.get_doc_by_key ( 'collaborator', 'fullname', 'Васильева Людмила Петровна' );   alert ( 'Найден сотрудник ' + oCollab.TopElem.fullname + ' с идентификационным номером ' + oCollab.DocID ); // на экран выводится информация об отобранном сотруднике_`  
  
`_iEduMethodID = oEdMeth.TopElem.id;   iCurUserID = oCollab.DocID;_`

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEdu", "GetEduMethodKnowledgeParts", [OptInt (iEduMethodID), OptInt (iCurUserID), false]);_`

`_// Проверьте наличие значений карты знаний, связанных с учебной программой: Учебный центр - Карточка учебной программы - Значения карты знаний   // Если значения карты знаний, связанные с учебной программой, отсутствуют, добавьте значение, нажав на соответствующую кнопку.   // Добавьте в данную учебную программу сотрудника Васильеву Людмилу Петровну, относительно которого производится определение результата._`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`  
  
`_Результат выполнения метода, записанный в лог и преобразованный в формат JSON:_`

{

}
