## GetCompoundProgramPrograms

Метод **_GetCompoundProgramPrograms_** предназначен для получения списка этапов модульной программы.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetCompoundProgramPrograms", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iCompoundProgramID_ \- ID модульной программы (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень этапов модульной программы, а также ряд дополнительных атрибутов:  
\- _array_ \- массив этапов модульной программы (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID модульной программы (строка);  
     _name_ – название модульной программы (строка);  
     _parent\_id_ – ID родительского элемента модульной программы (строка);  
     _duration_ – продолжительность модульной программы в днях (строка);  
     _required_ – обязательность выполнения модульной программы (строка);  
     _comment_ – комментарии (строка);  
     _cost_ – стоимость модульной программы (целое число);  
     _person\_num_ – количество обучающихся (целое число);  
     _type\_name_ – название типа модульной программы (строка);  
     _link_ – относительная ссылка на модульную программу (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "GetCompoundProgramPrograms", [iCompoundProgramID]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
