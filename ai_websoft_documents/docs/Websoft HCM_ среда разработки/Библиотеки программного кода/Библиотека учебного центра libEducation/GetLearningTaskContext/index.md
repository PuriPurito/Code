## GetLearningTaskContext

Метод **GetLearningTaskContext** предназначен для получения статистики по заданию.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetLearningTaskContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iLearningTaskID_ \- ID задания (целое число).  
     _iPersonID_ \- ID текущего пользователя (целое число).  
     _sAppCode_ \- код приложения (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о статистике по заданию, а также ряд дополнительных атрибутов:  
\- _context_ \- данные о статистике по заданию (объект).  
     Атрибуты контекста:  
     _assigned\_task\_count_ – количество всех назначений заданий с любым статусом, кроме _Отменено_, по этому заданию (целое число).  
     _complete\_task\_count_ \- сумма всех назначений заданий по данному заданию со статусами _Пройден, Не пройден_ (целое число).  
     _percent\_complete\_task_ \- процент назначений заданий по данному заданию со статусами _Пройден, Не пройден_ от назначенных (целое число).  
     _avg\_mark_ \- средняя оценка по всем выполнениям заданий по данному заданию со статусами _Пройден, Не пройден_ (целое число). Если в выполнении задания нет оценки, то указанное здание в среднем значении не учитывается   
     _success\_task\_count_ \- сумма всех назначений заданий по данному заданию со статусом _Пройден_ (целое число).  
     _percent\_success\_task_ \- процент назначений заданий по данному заданию со статусами _Пройден_ от показателя Завершено (целое число).  
     _avg\_duration_ \- средняя продолжительность выполнения по всем выполнениям задания со статусами _Пройден, Не пройден_ (целое число).  
     _last\_start\_date_ \- наибольшая дата создания назначения задания с любым статусом по этому заданию (целое число).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "GetLearningTaskContext", [iLearningTaskID, iPersonID, sAppCode ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
