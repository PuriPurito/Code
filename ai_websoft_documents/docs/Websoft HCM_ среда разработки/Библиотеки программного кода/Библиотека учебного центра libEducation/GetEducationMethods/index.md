## GetEducationMethods

Метод GetEducationMethods предназначен для получения списка учебных программ.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetEducationMethods", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя семь параметров:  
     _aRolesID_ \- массив ID категорий (массив целых чисел).  
     _bGetDesc_ \- возвращать описание (булево).  
     _bWithArchive_ \- учитывать ли архивные (неактивные) категории (булево) (необязательный). Если _bWithArchive=false_, то учитываются только категории со статусом _'active'_. Значение по умолчанию – false.  
     _arrDistinct_ \- перечень полей для формирования дополнительных списков для виджета фильтров (массив строк).  
     _arrFilters_ \- набор фильтров (массив объектов). В состав объекта могут входить следующие параметры: id - идентификатор в текстовом формате (строка); type - тип (строка); value - значение (строка).  
     oSort - информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).  
     oPaging - информация из рантайма о пейджинге (объект). Объект включает в себя следующие данные:  INDEX - номер страницы (целое число);  SIZE - размер страницы (целое число); MANUAL - разделение на страницы вручную (булево); TOTAL - общее количество страниц (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень учебных программ, а также ряд дополнительных атрибутов:  
\- _array_ \- массив учебных программ (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID учебной программы (целое число);  
     _name_ \- название учебной программы (строка);  
     _desc_ \- описание (строка);  
     _comment_ \- комментарии (строка);  
     _image_ – относительная ссылка на изображение (строка);  
     _roles\_names_ \- названия категорий (строка);  
     _link_ – относительная ссылка на учебную программу (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "GetEducationMethods", [aRolesID, bGetDesc, arrDistinct, bWithArchive, arrFilters, oSort, oPaging]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
