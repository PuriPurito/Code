## GetPersonEducationPlans

Метод предназначен для получения списка планов обучения сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetPersonEducationPlans", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID пользователя (сотрудника) (целое число).  
     _sStateID_ \- статус плана обучения (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит список планов обучения сотрудника, а также ряд дополнительных атрибутов:  
\- _array_ \- массив мероприятий по учебной программе (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID плана обучения (целое число);  
     _name_ – название плана (строка);  
     _status\_name_ – статус плана (строка) (допустимые значения: 'Не определен', 'Проект', 'Планируется', 'Проводится', 'Завершено', 'Отменено').  
     _create\_date_ – дата создания карточки плана (дата);  
     _link_ – относительная ссылка на план обучения (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "GetPersonEducationPlans", [ iPersonID, sStateID ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
