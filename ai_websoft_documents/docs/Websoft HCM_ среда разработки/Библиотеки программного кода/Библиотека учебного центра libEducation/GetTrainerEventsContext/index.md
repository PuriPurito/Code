## GetTrainerEventsContext

Метод **GetTrainerEventsContext** предназначен для получения статистики по мероприятиям.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetTrainerEventsContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _iPersonID_ \- ID текущего пользователя (целое число).  
     _sAppCode_ \- код приложения (строка).  
     _sAccessTypeID_ \- тип доступа (строка).  
     _dStartDate_ \- дата начала периода (дата).   
     _dEndDate_ \- дата окончания периода (дата).  

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит статистику по мероприятиям, а также ряд дополнительных атрибутов:  
\- _context_ \- статистика по мероприятиям (объект).  
     Атрибуты объекта:  
     _id_ – ID заявки (целое число);  
     _person\_fullname_ – ФИО сотрудника (строка);  
     _create\_date_ – дата формирования заявки (дата);  
     _status_ – статус заявки (строка);  
     _link_ – относительная ссылка на заявку (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "GetTrainerEventsContext", [iPersonID, sAppCode, sAccessTypeID, dStartDate, dEndDate]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
