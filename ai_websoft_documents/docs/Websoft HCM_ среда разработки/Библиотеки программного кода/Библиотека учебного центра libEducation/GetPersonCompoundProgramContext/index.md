## GetPersonCompoundProgramContext

Метод GetPersonCompoundProgramContext предназначен для получения контекста мероприятия.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetPersonCompoundProgramContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _iCompoundProgramID_ \- ID модульной программы (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит контекст мероприятия, а также ряд дополнительных атрибутов:  
\- _context_ \- контекст мероприятия (объект).  
     Атрибуты объекта:  
     _bActiveEducationPlan_ – наличие у текущего пользователя активного плана обучения, связанного с модульной программой (булево);  
     _bLector_ – является ли текущий пользователь преподавателем, указанным в карточке модульной программы (булево);  
     _iEducationPlanID_ – ID учебного плана (целое число);  
     _sEducationPlanState_ – статус учебного плана (строка);  
     _sEducationPlanStateName_ – наименование статуса учебного плана (строка);  
     _iCompoundProgramID_ – ID модульной программы (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "GetPersonCompoundProgramContext", [iPersonID, iCompoundProgramID]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
