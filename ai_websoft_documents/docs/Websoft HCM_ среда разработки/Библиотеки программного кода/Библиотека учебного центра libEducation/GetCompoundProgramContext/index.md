## GetCompoundProgramContext

Метод  **GetCompoundProgramContext** предназначен для получения статистики по модульной программе.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", " GetCompoundProgramContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iCompoundProgramID_ \- ID модульной программы (целое число).  
     _iPersonID_ \- ID текущего пользователя (целое число).  
     _sAppCode_ \- код приложения (строка). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о статистике по модульной программе, которые проводит указанный преподаватель, а также ряд дополнительных атрибутов:  
\- _context_ \- данные о статистике по модульной программе (объект).  
     Атрибуты контекста:  
     _folder\_count_ – количество разделов модульной программы с типом _Этап_ (целое число);  
     _activity\_count_ \- количество разделов модульной программы с любым типом, кроме _Этап_ (целое число);  
     _collaborators\_trained\_count_ \- число планов обучения с типом _Сотрудник_, привязанных к данной программе и имеющих статус _Пройден_ (целое число);  
     _groups\_trained\_count_ \- число планов обучения с типом _Группа_, привязанных к данной программе и имеющих статус _Пройден_ (целое число);

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", " GetCompoundProgramContext", [iCompoundProgramID, iPersonID, sAppCode]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
