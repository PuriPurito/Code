## GetTrainerLearningTaskResults

Метод _GetTrainerLearningTaskResults_ предназначен для получения выборки выполнения заданий по мероприятиям для Кабинета тренера.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetTrainerLearningTaskResults", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя шестнадцать параметров (данные будут уточнены):  
     _iPersonID_ \- ID сотрудника (целое число).  
     _tePerson_ \- TopElem сотрудника (объект XmlElem).  
     _sSearch_ – критерий поиска (строка);   
     _sFilterID_ – ID фильтра (строка);  
     _sAccessTypeID_ – тип доступа пользователя (строка);  
     _arrLearningTaskResultStates_ \- массив статусов результатов выполнения заданий (массив строк);   
     _arrBossTypesID_ \- массив ID типов руководителей для поиска для типов func\_subordinates и all\_subordinates (массив целых чисел);  
     _arrStatuses_ – массив статусов (массив строк);  
     _arrEventsID_ – ID мероприятий (массив целых чисел);  
     _arrEventTypesID_ – массив ID типов мероприятий (массив целых чисел);  
     _arrRolesID_ – массив ID типов ролей (массив целых чисел);  
     _sReturnData_ – возврат данных (строка);  
     _arrFields_ – набор полей (массив);  
     _oSort_ \- информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: _FIELD_ \- название поля, по которому производится сортировка (строка), _DIRECTION_ \- направление сортировки (строка);  
     _oPaging_ \- информация из рантайма о пейджинге (объект) (в том числе: _oPaging.index_ \- номер страницы (целое число);  _oPaging.size_ \- размер страницы (целое число));  
     _sQueryQual_ – текст запроса (строка). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит выборку выполнения заданий по мероприятиям для Кабинета тренера, а также ряд дополнительных атрибутов:  
\- _array_ \- массив заданий по мероприятиям для Кабинета тренера (массив объектов).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "GetTrainerLearningTaskResults", [iPersonID, tePerson, sSearch, sFilterID, sAccessTypeID, arrLearningTaskResultStates, arrBossTypesID, arrStatuses, arrEventsID, arrEventTypesID, arrRolesID, sReturnData, arrFields, oSort, oPaging, sQueryQual]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
