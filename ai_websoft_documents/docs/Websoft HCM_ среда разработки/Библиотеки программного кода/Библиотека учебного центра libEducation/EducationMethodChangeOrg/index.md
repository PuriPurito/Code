## EducationMethodChangeOrg

Метод **EducationMethodChangeOrg** предназначен для изменения обучающей организации в учебных программах.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "EducationMethodChangeOrg", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
      Массив включает в себя три параметра:  
     _iEduOrgID_ \- ID обучающей организации (целое число).  
     _arrEduMethodIDs_ \- массив ID учебных программ (массив целых чисел).  
     _sCanRewrite_ \- действие с учебной программой, если обучающая организация в ней уже заполнена (строка). Допустимые значения: "skip" (пропускать), "overwrite" (перезаписывать). 

_Возвращаемое значение:_  
      Тип:  **Объект** . Содержит ряд атрибутов:  
\- _EduMethodCount_ – количество измененных учебных программ (целое число).  
  
_\- error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
_\- errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "EducationMethodChangeOrg", [iEduOrgID, arrEduMethodIDs, sCanRewrite]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
