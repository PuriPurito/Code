## GetTrainerEventContext

Метод **GetTrainerEventContext** предназначен для получения статистики мероприятия.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetTrainerEventContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iEventID_ \- ID мероприятия.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит статистику мероприятия, а также ряд дополнительных атрибутов:  
_\- context_ \- статистика мероприятия (объект).  
     Атрибуты объекта:  
     _iPersonsCount_ – количество участников (целое число);  
     _iPersonsConfirm_ – количество сотрудников, подтвердивших участие (целое число);  
     _iPersonsNotPrt_ – количество сотрудников, не подтвердивших от участия (целое число);  
     _iPersonsAssist_ – количество сотрудников, присутствовавших на мероприятии (целое число);  
     _iRequestsActive_ – количество незакрытых заявок (целое число);  
     _iTasksActive_ – количество незавершенных заданий (целое число);  
     _iTestsFailed_ – количество несданных тестов (целое число);  
     _iCoursesActive_ – количество незаконченных курсов (целое число);  
     _iResponsesCount_ – количество заполненных отзывов (целое число);  
     _sScoreAvg_ – средний балл (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "GetTrainerEventContext", [iEventID]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
