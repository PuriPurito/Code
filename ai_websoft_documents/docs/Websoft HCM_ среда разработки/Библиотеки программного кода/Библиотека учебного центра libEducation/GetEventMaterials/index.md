## GetEventMaterials

Метод **GetEventMaterials** предназначен для получения списка материалов по мероприятию.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "GetEventMaterials", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iEventID_ \- ID мероприятия (целое число).  
     _iCurUserID_ \- ID сотрудника (целое число).  
     _sTypeMaterial_ \- тип материала (строка) (Возможные значения: _"all"_ (все материалы), _"files"_ (файлы), _"catalogs"_ (каталоги)).  
     _bShowEventResultFiles_ \- отображать ли файлы результатов мероприятия (булево) (необязательный). Значение по умолчанию - _false_.  

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень материалов по мероприятию, а также ряд дополнительных атрибутов:  
\- _array_ \- массив материалов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID материала (целое число);  
     _name_ – название материала (строка);  
     _type_ – тип материала (строка);  
     _link_ – относительная ссылка на материал (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "GetEventMaterials", [iEventID, iCurUserID, sTypeMaterial, bShowEventResultFiles]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
