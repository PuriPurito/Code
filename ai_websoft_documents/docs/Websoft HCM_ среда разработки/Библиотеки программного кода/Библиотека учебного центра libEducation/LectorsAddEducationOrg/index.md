## LectorsAddEducationOrg

Метод **LectorsAddEducationOrg** предназначен для формирования отношения преподавателей к обучающей организации.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libEducation", "LectorsAddEducationOrg", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iEduOrgID_ \- ID обучающей организации (целое число).  
     _arrLectorIDs_ \- массив ID преподавателей, добавляемых в состав организации (массив целых чисел).  
     _sCanRemove_ \- действие, если преподаватель уже отнесен к какой либо обучающей организации (строка). Допустимые значения: "skip" (пропускать); "move" (переносить); "copy" (копировать).

_Возвращаемое значение:_  
      Тип:  **Объект** . Содержит ряд атрибутов:  
\- _LectorCount_ – количество удаленных учебных программ (целое число).  
  
_\- error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
_\- errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEducation", "LectorsAddEducationOrg", [iEduOrgID, arrLectorIDs, sCanRemove]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
