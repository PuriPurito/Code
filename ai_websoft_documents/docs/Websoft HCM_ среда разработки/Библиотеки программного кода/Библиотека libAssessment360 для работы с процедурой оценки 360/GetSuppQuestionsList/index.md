## GetSuppQuestionsList

Метод **GetSuppQuestionsList** предназначен для получения списка дополнительных вопросов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAssessment360", "GetSuppQuestionsList", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя пять параметров:  
     _oSort_ \- информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).  
     _bTotalVisibility_ \- видимость объектов (булево). Если параметр имеет значение true, то видимыми являются все объекты, в противном случае – только объекты из приложения.   
     _iAppID_ \- ID приложения (целое число).  
     _sFormFilter_ \- фильтры представления приложения для отбора (строка).   
     _sSearch_ \- критерий полнотекстового поиска для отбора (строка). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень дополнительных вопросов оценки 360, а также ряд дополнительных атрибутов:  
\- array - массив дополнительных вопросов оценки 360 (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID дополнительного вопроса оценки 360 (целое число);  
     _code_ \- код дополнительного вопроса оценки 360 (строка);  
     _name_ \- название дополнительного вопроса оценки 360 (строка);  
и др. параметры дополнительного вопроса оценки 360.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAssessment360", "GetSuppQuestionsList", [oSort, bTotalVisibility, iAppID, sFormFilter, sSearch]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
