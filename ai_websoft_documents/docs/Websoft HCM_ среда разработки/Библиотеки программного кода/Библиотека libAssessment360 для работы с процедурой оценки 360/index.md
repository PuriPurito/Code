## Библиотека libAssessment360 для работы с процедурой оценки 360

В настоящем разделе описывается **библиотека для работы с процедурой оценки 360** (библиотека программного кода **libAssessment360**). Указанная библиотека регистрируется в разделе **Дизайнер – Библиотеки программного кода – libAssessment360**.  
  
Подробнее о процедуре оценки 360 – см. здесь.

Примечание - Библиотека программного кода **libAssessment360** на данный момент не предназначена для публикации через внешний интерфейс API (за исключением нескольких методов, представленных ниже).

Для вызова доступных пользователям методов из библиотеки используется функция tools.call\_code\_library\_method.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAssessment360", <sMethodNameParam>, <arrParams>)**

_Аргументы:_  
     _<sMethodNameParam> (обязательный)_  
      Тип: **Строка**. Название вызываемого метода.  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.
