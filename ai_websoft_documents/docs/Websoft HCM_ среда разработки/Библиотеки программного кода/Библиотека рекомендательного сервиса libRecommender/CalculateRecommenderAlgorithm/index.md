## CalculateRecommenderAlgorithm

Метод **CalculateRecommenderAlgorithm** предназначен для выполнения вычислений по рекомендательному алгоритму.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libRecommender", "CalculateRecommenderAlgorithm", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
      _iRecommenderAlgorithmID_ \- ID рекомендательного алгоритма (целое число).  
      _iObjectID_ \- ID объекта (целое число).  
      _bUseCache_ \- использовать кэш (булево) (необязательный). Значение по умолчанию - true.  
      _iContextObjectID_ \- ID контекстного объекта (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит набор результатов вычислений по рекомендательному алгоритму, а также ряд дополнительных атрибутов:  
\- _array_ \- массив результатов вычислений по рекомендательному алгоритму (массив объектов).  
     Атрибуты отдельного объекта:  
     _object\_type_ \- тип объекта (строка);  
     _object\_name_ \- название объекта (строка);  
     _comment_ \- комментарий (строка);  
     _object\_id_ \- ID объекта (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libRecommender", "CalculateRecommenderAlgorithm", [iRecommenderAlgorithmID, iObjectID, bUseCache, iContextObjectID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
