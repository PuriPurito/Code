## GetUserRecommendations

Метод **GetUserRecommendations** предназначен для получения рекомендации пользователю.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libRecommender", "GetUserRecommendations", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
      _iObjectID_ \- ID объекта (целое число).  
      _iRecommenderAlgorithmID_ \- ID рекомендательного алгоритма (целое число).  
      _bUseCache_ \- использовать кэш (булево) (необязательный). Значение по умолчанию - _true_.  
      _iContextObjectID_ \- ID контекстного объекта (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит набор рекомендаций пользователю, а также ряд дополнительных атрибутов:  
\- _array_ \- массив рекомендаций пользователю (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID рекомендации (целое число);  
     _name_ \- название рекомендации (строка);  
     _type_ \- код типа рекомендации (строка);  
     _type\_name_ \- название типа рекомендации (строка);  
     _comment_ \- комментарий к рекомендации (строка);  
     _pict\_url_ \- относительная ссылка на изображение рекомендации (строка);  
     _link_ \- относительная ссылка на рекомендацию (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libRecommender", "GetUserRecommendations", [iObjectID, iRecommenderAlgorithmID, bUseCache, iContextObjectID]);_`   
 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
