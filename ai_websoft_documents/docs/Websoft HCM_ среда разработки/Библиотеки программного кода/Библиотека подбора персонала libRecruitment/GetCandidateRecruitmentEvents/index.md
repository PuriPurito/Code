## GetCandidateRecruitmentEvents

Метод **GetCandidateRecruitmentEvents** предназначен для получения списка событий кандидата.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libRecruitment", "GetCandidateRecruitmentEvents", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iCurUserID_ – ID текущего пользователя (кандидата) (целое число).   
     _bShowOnlyCurrentSiteVacancies_ \- показывать ли только те вакансии, которые относятся к текущему сайту (булево).  
     _iRecruitmentSystemID_ \- ID системы подбора персонала (целое число).   
     _sMethodNameParam_ - название метода, вызываемого внутри связанного с системой подбора файла функций (необязательный) (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень событий кандидата, а также ряд дополнительных атрибутов:  
\- _array_ \- массив событий (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID события (целое число).  
     _name_ – название события (строка).  
     _start\_date_ – дата начала события (дата).  
     _finish\_date_ – дата окончания события (дата).  
     _vacancy\_id_ – ID вакансии (целое число).  
     _vacancy\_name_ – название вакансии (строка).  
     _candidate\_id_ – ID кандидата (целое число).  
     _candidate\_name_ – название кандидата (строка).  
     _status_ – статус события (строка).  
     _comment_ – комментарий (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libRecruitment", "GetCandidateRecruitmentEvents", [iCurUserID, bShowOnlyCurrentSiteVacancies, iRecruitmentSystemID, sMethodNameParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
