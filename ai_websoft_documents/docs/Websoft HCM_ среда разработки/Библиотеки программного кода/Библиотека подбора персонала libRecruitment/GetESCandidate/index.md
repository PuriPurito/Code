## GetESCandidate

Метод **GetESCandidate** предназначен для получения информации по кандидату из E-Staff.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libRecruitment", "GetESCandidate", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iPersonID_ \- ID кандидата (целое число).  
     _bESPersonID_ \- соответствует ли ID кандидата в WebSoft HCM и в E-Staff (булево) (необязательный). Значение по умолчанию - _false_.  
     _iRecruitmentSystemID_ \- ID системы подбора персонала (целое число).  
     _bUseGlobalRecruitmentSystem_ \- использовать ли систему подбора персонала, указанную в глобальных настройках, если система подбора персонала не указана (булево). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о кандидате из E-Staff, а также ряд дополнительных атрибутов:  
\- _array_ – массив данных о кандидате (массив объектов).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libRecruitment", "GetESCandidate", [iPersonID, bESPersonID, iRecruitmentSystemID, bUseGlobalRecruitmentSystem]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
