## Библиотека плана преемственности libSuccession

В настоящем разделе описываются методы **библиотеки плана преемственности** (библиотека программного кода **libSuccession**). Указанная библиотека регистрируется в разделе **Дизайнер – Библиотеки программного кода – libSuccession**.

Для вызова методов из библиотеки используется функция tools.call\_code\_library\_method.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSuccession", <sMethodNameParam>, <arrParams>)**

_Аргументы:_  
     _<sMethodNameParam> (обязательный)_  
      Тип: **Строка**. Название вызываемого метода.  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки. 

В библиотеке **libSuccession** настраиваются следующие глобальные параметры:

**bAddSuccessorWOPersonalReserve** определяет возможность выбора преемников из подчиненных, не состоящих в кадровом резерве. 

**BossRequestRights** (структура глобальных параметров) определяет набор прав руководителя на создание заявок.

**BossRights** (структура глобальных параметров) определяет набор прав руководителя на создание объектов.

**bRequestSelfPersonalReserve** определяет, разрешена ли сотрудникам подача заявок на включение себя в кадровый резерв.

**iHRBossTypeID** определяет тип руководителя, согласующего решения по HR.
