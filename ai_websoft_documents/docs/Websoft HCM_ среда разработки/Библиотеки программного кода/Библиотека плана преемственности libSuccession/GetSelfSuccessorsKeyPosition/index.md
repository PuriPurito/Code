## GetSelfSuccessorsKeyPosition

Метод **GetSelfSuccessorsKeyPosition** предназначен для получения списка преемников по ключевым должностям.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSuccession", "GetSelfSuccessorsKeyPosition", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _sStatus_ - ограничение отбора по статусам (строка). Допустимые значения: _"all"_ (отбор без ограничений) или любое строковое значение (добавляется ограничение отбора по статусам _'approved'_ (Согласован) и _'inposition'_ (Принят на должность)).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень преемников по ключевым должностям, а также ряд дополнительных атрибутов:  
\- _oRes_ - массив преемников (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID преемника (целое число);  
     _key\_position\_id_ – ID ключевой должности (целое число);  
     _person\_id_ – ID сотрудника (целое число);  
     _position\_id_ – ID должности сотрудника (целое число);  
     _person\_fullname_ \- ФИО преемника (строка).  
     _person\_position\_name_ \- название должности преемника (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSuccession", "GetSelfSuccessorsKeyPosition", [iPersonID, sStatus]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
