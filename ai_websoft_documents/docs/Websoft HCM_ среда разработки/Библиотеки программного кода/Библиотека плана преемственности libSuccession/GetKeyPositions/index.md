## GetKeyPositions

Метод **GetKeyPositions** предназначен для получения списка ключевых должностей по подчиненным сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSuccession", "GetKeyPositions", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя девять параметров:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _sTypeCollaborator_ \- критерий отбора, по которому производится выборка (строка). Доступные значения: _'subordinates', 'main\_subordinates', 'func\_subordinates', 'all\_subordinates'_.  
     _arrBossTypesID_ \- массив ID типов руководителя (массив целых чисел).  
     _bReturnByBoss_ \- отбирать ключевые должности, для которых сотрудник является руководителем (булево).  
     _bReturnByHR_ \- отбирать ключевые должности, для которых сотрудник является специалистом кадровой службы (HR) (булево).  
     _iAppLevel_ \- уровень доступа сотрудника в приложении (целое число).  
     _sState_ \- статус ключевой должности (строка).  
     _sFilter_ \- дополнительные условия для xquery-запроса по каталогу ключевых должностей (строка).  
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень ключевых должностей по подчиненным сотрудника, а также ряд дополнительных атрибутов:  
\- _array_ \- массив ключевых должностей (TopElem ключевых должностей) (массив объектов).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSuccession", "GetKeyPositions", [iPersonID, sTypeCollaborator, arrBossTypesID, bReturnByBoss, bReturnByHR, iAppLevel, sState, sFilter, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
