## GetKeyPositionThreat

Метод **GetKeyPositionThreat** предназначен для получения списка угроз ключевым должностям.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSuccession", "GetKeyPositionThreat", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _sXQueryQual_ \- дополнительный фильтр XQuery для отбора (строка) (необязательный).  
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).

_Возвращаемое значение:_  
      Тип: **Объект**.

Содержит перечень угроз ключевым должностям, а также ряд дополнительных атрибутов:  
\- _array_ \- массив угроз ключевым должностям (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID угрозы (целое число).  
     _code_ \- код угрозы (строка).   
     _name_ \- название угрозы (строка).  
     _color_ \- код цвета (строка).  
     _color\_name_ \- название цвета (строка).

\- _paging_ \- пейджинг (объект).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSuccession", "GetKeyPositionThreat", [sXQueryQual, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
