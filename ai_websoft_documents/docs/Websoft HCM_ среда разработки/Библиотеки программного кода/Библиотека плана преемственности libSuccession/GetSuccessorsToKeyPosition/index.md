## GetSuccessorsToKeyPosition

Метод **GetSuccessorsToKeyPosition** предназначен для получения списка преемников на ключевую должность.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSuccession", "GetSuccessorsToKeyPosition", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iKeyPositionID_ \- ID ключевой должности (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень преемников на ключевую должность, а также ряд дополнительных атрибутов:  
\- result \- массив преемников на ключевую должность (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID преемника (целое число);  
     _key\_position\_id_ – ID ключевой должности (целое число);  
     _key\_position\_name_ \- название ключевой должности (строка).  
     _person\_id_ – ID сотрудника (целое число);  
     _position\_id_ – ID должности сотрудника (целое число);  
     _person\_fullname_ \- ФИО преемника (строка).  
     _person\_position\_name_ \- название должности преемника (строка).  
     _person\_subdivision\_name_ \- название подразделения преемника (строка).  
     _person\_org\_name_ \- название организации преемника (строка);  
     _status_ \- статус преемника (строка). Например: _"active"_ (В работе), _"approved"_ (Принят), _"rejected"_ (Отклонен), _"archive"_ (Архив).  
     _description_ \- описание в карточке преемника (строка).  
     _link_ – относительная ссылка на карточку преемника (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSuccession", "GetSuccessorsToKeyPosition", [iKeyPositionID]);_`   
 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
