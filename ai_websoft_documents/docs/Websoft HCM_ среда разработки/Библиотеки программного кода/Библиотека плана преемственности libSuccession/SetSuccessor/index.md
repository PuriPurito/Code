## SetSuccessor

Метод **SetSuccessor** предназначен для добавления/изменения преемника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSuccession", "SetSuccessor", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     iSuccessorIDParam - ID изменяемого преемника (целое число) (необязательный).  
     oFormField - данные полей возврата из формы удаленного действия (объект) (в т.ч. name - название поля (строка), label – метка (строка), type – тип поля (строка), value – значение (строка), entries – входные параметры (массив объектов (parent – ссылка на родительский объект (строка), value – значение (строка))), validation – контрольное значение (строка), mandatory – является ли поле обязательным (булево), css\_class – параметры CSS (строка), error\_message – сообщение об ошибке (строка), column – количество колонок (целое число), visibility – видимость (булево)).  
     oAddParam - параметры выполнения (объект). В состав объекта входят следующие параметры: cur\_user\_id – ID текущего пользователя (целое число); send\_on\_create – посылать ли уведомление при создании (булево); person\_notification\_id – ID типа уведомления преемника (целое число); send\_on\_change – посылать ли уведомление при изменении (булево); hr\_notification\_id – ID типа уведомления HR (целое число); send\_owner – посылать уведомление сотруднику на ключевой должности (булево); owner\_notification\_id\_on\_create – ID типа уведомления сотруднику на ключевой должности при создании (целое число); owner\_notification\_id\_on\_change – ID типа уведомления сотруднику на ключевой должности при изменении (целое число); efficiency\_collaborator – брать оценку эффективности из карточки сотрудника (булево); potential\_collaborator – брать потенцивл развития из карточки сотрудника (булево).

_Возвращаемые значения:_  
      Тип:  **_Объект_**. Содержит следующие атрибуты:  
_\- result_ – результат вызова метода (объект). В состав объекта входят следующие параметры: command - команда (строка); название формы (строка); message – сообщение (строка); css\_class - данные класса CSS формы (строка); form\_fields - поля формы (массив объектов); buttons - кнопки (массив объектов); no\_buttons - отсутствуют ли кнопки на форме (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSuccession", "SetSuccessor", [iSuccessorIDParam, oFormField, oAddParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
