## GetGradePotentialEfficiency

Метод **GetGradePotentialEfficiency** предназначен для получения списка записей оценок эффективности / оценок потенциала.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSuccession", "GetGradePotentialEfficiency", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iPersonID_ \- ID сотрудника, для которого должны быть получены записи оценок эффективности (целое число).  
     _sResultType_ \- выбор типа результата, возвращаемого выборкой (строка). : "GradeEfficiency"/"GradePotential" (Список записей оценок эффективности/Список записей оценок потенциала)  
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень записей оценок эффективности / оценок потенциала, а также ряд дополнительных атрибутов:  
\- array - массив записей оценок эффективности/потенциала (массив объектов).  
     Атрибуты отдельного объекта:  
     grade - потенциал/оценка эффективности (строка).  
     assessment\_source - источник оценки (строка).  
     person\_fullname – ФИО сотрудника (строка).  
     assessment\_date - дата оценки (дата).  
     assessment\_type - тип оценки (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSuccession", "GetGradePotentialEfficiency", [iPersonID, sResultType, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
