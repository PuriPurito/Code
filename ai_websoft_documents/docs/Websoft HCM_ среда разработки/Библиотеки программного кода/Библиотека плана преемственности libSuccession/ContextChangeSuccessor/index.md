## ContextChangeSuccessor

Метод **ContextChangeSuccessor** предназначен для изменения контекста карточки преемника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSuccession", "ContextChangeSuccessor", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя четыре параметра:  
     _docSuccessor_ \- документ преемника (объект XmlDoc).  
     _arrFormFields_ \- массив полей формы из удаленного действия (массив объектов). В состав объекта входят следующие параметры: name - название поля (строка), label – метка (строка), type – тип поля (строка), value – значение (строка), entries – входные параметры (массив объектов (parent – ссылка на родительский объект (строка), value – значение (строка))), validation – контрольное значение (строка), mandatory – является ли поле обязательным (булево), css\_class – параметры CSS (строка), error\_message – сообщение об ошибке (строка), column – количество колонок (целое число), visibility – видимость (булево).  
     _bSendOwnerNotificationOnChangeCreate_ \- нужно ли отправлять уведомление сотруднику на ключевой должности при изменении преемника (булево).   
     _iOwnerNotificationOnChangeCreate_ \- тип уведомления сотруднику на ключевой должности (целое число).

_Возвращаемые значения:_  
      Тип:  **_Объект_**. Содержит следующие атрибуты:  
\- result – результат вызова метода (объект). В состав объекта входят следующие параметры: command - команда (строка); название формы (строка); message – сообщение (строка); css\_class - данные класса CSS формы (строка); form\_fields - поля формы (массив объектов); buttons - кнопки (массив объектов); no\_buttons - отсутствуют ли кнопки на форме (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSuccession", "ContextChangeSuccessor", [docSuccessor, arrFormFields, bSendOwnerNotificationOnChangeCreate, iOwnerNotificationOnChangeCreate]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
