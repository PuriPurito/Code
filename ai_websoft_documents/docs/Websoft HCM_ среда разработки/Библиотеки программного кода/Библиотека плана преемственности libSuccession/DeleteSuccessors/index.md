## DeleteSuccessors

Метод **DeleteSuccessors** предназначен для удаления преемника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSuccession", "DeleteSuccessors", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _arrSuccessorIDs_ \- массив ID преемников, подлежащих удалению (массив целых чисел).

_Возвращаемые значения:_  
      Тип:  Объект. Содержит следующие атрибуты:  
\- count – количество удаленных записей (целое число).

\- error - код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- errorText – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSuccession", "DeleteSuccessors", [arrSuccessorIDs]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
