## GetKeyPositionContext

Метод **GetKeyPositionContext** предназначен для получения контекста ключевой должности.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSuccession", "GetKeyPositionContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iKeyPositionIDParam_ \- ID ключевой должности (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию о контексте ключевой должности, а также ряд дополнительных атрибутов:  
\- _context_ \- контекст ключевой должности (объект).  
     Атрибуты отдельного объекта:  
     _id_ – ID ключевой должности (целое число).  
     _name_ \- название ключевой должности (строка).  
     _position\_id_ – ID должности сотрудника (целое число).  
     _position\_name_ – название должности сотрудника (строка).  
     _person\_id_ – ID сотрудника (целое число).  
     _person\_fullname_ – ФИО сотрудника (строка).  
     _person\_code_ – код сотрудника (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSuccession", "GetKeyPositionContext", [iKeyPositionIDParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
