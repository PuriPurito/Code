## GetEmployeesSubdivisionKeyPositions

Метод **GetEmployeesSubdivisionKeyPositions** предназначен для получения списка ключевых должностей в подразделении сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSuccession", "GetEmployeesSubdivisionKeyPositions", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iPersonID_ \- ID сотрудника, в подразделении которого ищутся ключевые должности (целое число).  
     _bOnlyDirectSubdivisions_ \- искать только подразделения верхнего уровня, в которых сотрудник является руководителем, без учёта подчинённых подразделений (булево) (необязательный). Значение по умолчанию - _false_.  
     _bIncludeOrgsWhereUserIsBoss_ \- учитывать организации, где сотрудник является руководителем (булево) (необязательный). Значение по умолчанию - _false_. 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень ключевых должностей в подразделении сотрудника, а также ряд дополнительных атрибутов:  
\- _result_ \- массив ключевых должностей (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID ключевой должности (целое число).  
     _name_ \- название ключевой должности (строка).  
     _person\_id_ \- ID сотрудника (целое число).  
     _position\_id_ \- ID должности сотрудника (целое число).  
     _person\_fullname_ \- ФИО сотрудника (строка).  
     _person\_position\_name_ \- название должности сотрудника (строка).  
     _person\_subdivision\_name_ \- название подразделения сотрудника (строка).  
     _person\_org\_name_ \- название организации сотрудника (строка).  
     _status_ \- статус ключевой должности (строка). Например: _"plan"_ (Планируется), _"active"_ (В работе), _"agreement"_ (На согласовании), _"approved"_ (Принята), _"archive"_ (Архив).  
     _description_ \- описание ключевой должности (строка).  
     _link_ \- относительная ссылка на карточку ключевой должности (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSuccession", "GetEmployeesSubdivisionKeyPositions", [iPersonID, bOnlyDirectSubdivisions, bIncludeOrgsWhereUserIsBoss]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
