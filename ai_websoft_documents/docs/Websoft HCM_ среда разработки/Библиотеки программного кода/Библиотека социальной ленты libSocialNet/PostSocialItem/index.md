## PostSocialItem

Метод **PostSocialItem** предназначен для возвращения массива созданных сообщений.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSocialNet", "PostSocialItem", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров.   
     Для реализации данного метода аргументы не предусмотрены. Используется пустой массив аргументов.

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит массив созданных сообщений, а также ряд дополнительных атрибутов:  
\- _array_ - массив созданных сообщений (массив объектов).  
     В т.ч. атрибуты элемента массива:  
    _id_ \- ID сообщения (целое число).  
    _type_ \- тип элемента (сообщения) (строка).  
    _name_ \- название сообщения (строка).  
    _link_ \- ссылка на сообщение (строка).  
    _text_ \- текст сообщения (строка).  
    _date\_create_ \- дата создания сообщения (дата).  
    _blocked_ \- блокирование сообщения (булево).  
    _date\_modified_ \- дата последнего изменения сообщения (дата).  
    _likes_ \- количество лайков (целое число).  
    _dislikes_ \- количество дизлайков (целое число).  
    _has\_my\_like_ \- поставлен ли лайк текущим пользователем (булево).  
    _has\_my\_dislike_ \- поставлен ли дизлайк текущим пользователем (булево).  
    _has\_subscription_ \- оформлена подписка на сообщения (булево).  
    _can\_delete_ \- сообщение может быть удалено (булево).  
    _access_ \- доступ к сообщению (строка).  
    _person_ \- сотрудник, написавший сообщение (объект).  
    _owner_ \- владелец элемента (сообщения) (строка).  
    _attachments_ \- ссылки на вложения в сообщение (массив строк).  
    _tags_ \- теги (массив строк).  
    _comments_ \- комментарии (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSocialNet", "PostSocialItem", []);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
