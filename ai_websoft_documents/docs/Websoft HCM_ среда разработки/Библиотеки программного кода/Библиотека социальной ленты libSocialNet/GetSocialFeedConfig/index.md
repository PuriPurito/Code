## GetSocialFeedConfig

Метод **GetSocialFeedConfig** предназначен для получения параметров шаблона _'Социальная лента / Параметры' (vsocial\_net\_params)_.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSocialNet", "GetSocialFeedConfig", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _code_ – код шаблона (строка) (необязательный). Значение по умолчанию - _'vsocial\_net\_params'_.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит параметры шаблона 'Социальная лента / Параметры' (vsocial\_net\_params), а также ряд дополнительных атрибутов:

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSocialNet", "GetSocialFeedConfig", [code]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
