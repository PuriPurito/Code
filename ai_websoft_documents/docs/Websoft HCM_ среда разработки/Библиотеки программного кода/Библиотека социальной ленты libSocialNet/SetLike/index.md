## SetLike

Метод **SetLike** предназначен для создания лайка или дизлайка для заданного объекта.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSocialNet", "SetLike", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _sObjectId_ \- ID объекта, к которому относится оценка (сообщение блога, комментарий) в строковом выражении (строка).  
     _sOwnerId_ \- ID владельца оцениваемого объекта (блога, группы) в строковом выражении (строка).  
     _sCommand_ \- тип оценки объекта (строка). Доступные значения: _'like' (лайк); 'dislike' (дизлайк)._  
     _bCanRevoke_ \- возможно ли изменение оценки (булево). 

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
\- _id_ \- ID созданного лайка или диззлайка (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSocialNet", "SetLike", [sObjectId, sOwnerId, sCommand, bCanRevoke]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
