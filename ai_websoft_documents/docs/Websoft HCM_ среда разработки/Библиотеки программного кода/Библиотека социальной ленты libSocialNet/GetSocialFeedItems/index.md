## GetSocialFeedItems

Метод **GetSocialFeedItems** предназначен для получения данных выборки, формирующей список элементов (items) социальной ленты.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSocialNet", "GetSocialFeedItems", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.      Массив включает в себя семь параметров:  
     _iPageNum_ \- номер страницы (целое число).  
     _iPageSize_ \- размер страницы (целое число).  
     _directions_ \- строка, состоящая из ID направлений, перечисленных через запятую (строка) (необязательный).  
     _search_ \- критерий отбора (строка) (необязательный).  
     _dateFrom_ \- начало диапазона дат в строковом выражении (строка) (необязательный).  
     _dateTo_ \- конец диапазона дат в строковом выражении (строка) (необязательный).  
     _sCollectionTargetId_ \- ID коллекции, возвращающей список направлений в строковом выражении (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные выборки, формирующей список элементов (items) социальной ленты, а также ряд дополнительных атрибутов:  
\- _array_ \- список элементов для социальной ленты (массив объектов).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSocialNet", "GetSocialFeedItems", [iPageNum, iPageSize, directions, search, dateFrom, dateTo, sCollectionTargetId]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
