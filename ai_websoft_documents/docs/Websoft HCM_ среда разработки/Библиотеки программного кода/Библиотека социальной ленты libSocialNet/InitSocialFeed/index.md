## InitSocialFeed

Метод **InitSocialFeed** предназначен для формирования данных, необходимых для инициализации социальной ленты (массив данных со значениями параметров шаблона _'Социальная лента / Параметры'_).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSocialNet", "InitSocialFeed", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
Для реализации данного метода аргументы не предусмотрены. Используется пустой массив аргументов.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные, необходимые для инициализации социальной ленты, а также ряд дополнительных атрибутов:  
\- oConfig - параметры социальной ленты (объект).  
\- aTargetsAll - массив всех направлений (для фильтрации) (массив объектов).  
\- aTargetsForPost - массив направлений (для постинга) (массив объектов).  
\- aTags - массив тегов (массив объектов). Каждый объект типа Тег содержит параметры id и name.  
  
  
     _oCollectionResult_ \- данные выборки направлений для постинга (объект).  
     _oTags_ \- теги (объект).  
     _oGroups_ \- группы (объект).  
     _oConfig_ \- параметры социальной ленты (объект).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSocialNet", "InitSocialFeed", []);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
