## PostComment

Метод **PostComment** предназначен для возвращения массива комментариев.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSocialNet", "PostComment", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров.   
     Для реализации данного метода аргументы не предусмотрены. Используется пустой массив аргументов.

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит массив комментариев, а также ряд дополнительных атрибутов:  
\- _array_ \- массив комментариев (массив объектов).  
     Атрибуты отдельного элемента массива:  
    _id_ – ID комментария (целое число).  
    _type_ – тип элемента типа Комментарий (строка) (значение равно _'comment'_).  
    _parent\_id_ – ID родительского элемента комментария (целое число).  
    _owner\_id_ – ID автора комментария (целое число).  
    _text_ \- текст комментария (строка).  
    _link_ \- ссылка на комментарий (строка).  
    _date_ \- дата написания комментария (дата).  
    _likes_ \- количество лайков (целое число).  
    _dislikes_ \- количество дислайков (целое число).  
    _has\_my\_like_ \- поставлен ли лайк текущим пользователем (булево).  
    _has\_my\_dislike_ \- поставлен ли дизлайк текущим пользователем (булево).  
    _person_ – автор комментария (объект).  
    _attachments_ \- массив вложений в комментарий (массив строка).  
    _access\_groups_ \- массив групп доступа к комментарию (массив объектов).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSocialNet", "PostComment", []);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
