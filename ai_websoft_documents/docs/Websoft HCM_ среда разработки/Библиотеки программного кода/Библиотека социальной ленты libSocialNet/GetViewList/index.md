## GetViewList

Метод **GetViewList** предназначен для формирования массива объектов, включающих в себя ID лайка/дизлайка, ФИО, ID сотрудника, поставившего лайк/дизлайк.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSocialNet", "GetViewList", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _sObjectId_ \- ID оцениваемого объекта (сообщение, комментарий) в строковом выражении (строка).  
     _sLikeType_ \- тип оценки объекта (строка). Доступные значения: _'like' (лайк); 'dislike' (дизлайк)._ 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит массив данных, связанных с лайком или дизлайком, а также ряд дополнительных атрибутов:  
\- _aLikePersons_ \- массив данных, связанных с лайком или дизлайком (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID лайка/дизлайка (целое число).  
     _type_ – тип лайка/дизлайка (строка) _('like' или 'dislike')_.  
     _person\_id_ – ID автора лайка/дизлайка (целое число).  
     _person\_fullname_ – ФИО автора лайка/дизлайка (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSocialNet", "GetViewList", [sObjectId, sLikeType]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
