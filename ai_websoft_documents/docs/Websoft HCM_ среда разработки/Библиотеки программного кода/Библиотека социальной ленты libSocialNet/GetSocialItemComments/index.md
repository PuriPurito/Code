## GetSocialItemComments

Метод **GetSocialItemComments** предназначен для формирования массива комментариев, вложенных и связанных с элементом социальной ленты.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSocialNet", "GetSocialItemComments", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _sItemID_ \- ID сообщения в строковом выражении (строка).  
     _sItemType_ \- тип сообщения (строка) (например, _'blog\_entry'_ \- сообщение блога).  
     _sItemComments_ \- набор ID комментариев сообщения в строковом выражении, перечисленных через запятую (строка). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит массив комментариев, вложенных и связанных с элементом социальной ленты, а также ряд дополнительных атрибутов:  
\- _array_ \- массив комментариев (элементов социальной ленты) (массив объектов).  
     В т.ч. атрибуты отдельного объекта:  
    _id_ \- ID элемента для социальной ленты (целое число).  
    _type_ \- тип элемента (строка).  
    _name_ \- название элемента (строка).  
    _link_ \- ссылка на карточку элемента (строка).  
    _text_ \- текст элемента (строка).  
    _date\_create_ \- дата создания элемента (дата).  
    _blocked_ \- блокирование элемента (булево).  
    _date\_modified_ \- дата последнего изменения элемента (дата).  
    _likes_ \- количество лайков (целое число).  
    _dislikes_ \- количество дизлайков (целое число).  
    _has\_my\_like_ \- поставлен ли лайк текущим пользователем (булево).  
    _has\_my\_dislike_ \- поставлен ли дизлайк текущим пользователем (булево).  
    _has\_subscription_ \- оформлена подписка на объект (булево).  
    _can\_delete_ \- объект может быть удален (булево).  
    _access_ \- доступ (строка).  
    _person_ \- сотрудник (объект).  
    _owner_ \- владелец элемента (строка).  
    _attachments_ \- ссылки на вложения (массив строк).  
    _tags_ \- теги (массив строк).  
    _comments_ \- комментарии к комментарию (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSocialNet", "GetSocialItemComments", [sItemID, sItemType, sItemComments]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
