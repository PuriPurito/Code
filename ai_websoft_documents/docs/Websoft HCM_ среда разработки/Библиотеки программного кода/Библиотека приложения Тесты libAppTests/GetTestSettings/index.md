## GetTestSettings

Метод **GetTestSettings** предназначен для получения списка настроек теста.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAppTests", "GetTestSettings", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _assessment\_id_ \- ID теста в текстовом формате (строка).  
     _te\_assessment_ \- TopElem теста (объект XmlElem).  
     _te\_active\_test\_learning_ \- TopElem незаконченного теста (объект XmlElem).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень настроек теста, а также ряд дополнительных атрибутов:  
\- oRes - данные о настройках теста (объект).  
     Атрибуты объекта:  
     _id_ \- ID теста в текстовом формате (строка).  
     _code_ \- код теста (строка).  
     _title_ \- заголовок теста (строка).  
     _rubric\_candidate_ \- описание (теста из карточки) (строка).  
     _objectives\_candidate_ \- инструкция к тесту (строка).  
     _desc_ \- описание теста (из раздела «Описание») (строка).  
     _is\_open_ \- доступен ли тест для самоназначения (булево).  
     _image_ \- ссылка на изображение теста (строка).  
     _publish\_path_ \- директория публикации теста (строка).  
     _attempts\_num_ \- количество попыток (целое число).  
     _feedback\_wrong_ \- общее для теста сообщение при ошибочном ответе (строка).  
     _feedback\_correct_ \- общее для теста сообщение при правильном ответе (строка).  
     _feedback\_passed_ \- сообщение при удачном завершении теста (строка).  
     _feedback\_failed_ \- сообщение при неудачном завершении теста (строка).  
     _connection\_break_ \- при потере соединения останавливать тест (булево).  
     _navigate\_progress_ \- разрешить переходы по элементам прогресс-индикатора (булево).  
     _display\_res\_score_ \- показывать информацию о баллах в результатах теста (булево).  
     _display\_type_ \- тип показа вопросов (строка). Доступные значения: item (По одному вопросу); sec (Списком по разделам); ass (Списком весь тест).   
     _rubric\_display\_type_ \- тип показа описаний и контрольного блока в плейере (строка). Допустимые значения: none (Не показывать); ass (Только теста); sec (Только разделов); item (Только описания вопросов); ass\_sec (Теста и разделов); ass\_item (Описания теста и вопросов); sec\_item (Описания разделов и вопросов); ass\_sec\_item (Описания теста, разделов и вопросов).  
     _send\_type_ \- тип пересылки данных в плейере (строка).  
     _accept\_next_ \- совместить прием ответа и переход к следующему вопросу в плейере (булево).  
     _not\_disp\_last\_attempt_ \- не показывать сообщение об исчерпании попыток ответа (булево).  
     _not\_display\_feedback_ \- не показывать в данном тесте сообщения обратной связи (булево).  
     _strict\_navigation_ \- строгий порядок навигации внутри теста в плейере (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAppTests", "GetTestSettings", [assessment_id, te_assessment, te_active_test_learning]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
