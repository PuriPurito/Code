## GetTestPageData

Метод **GetTestPageData** предназначен для получения списка данных теста.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAppTests", "GetTestPageData", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _assessment\_id_ \- ID теста в текстовом формате (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень данных теста, а также ряд дополнительных атрибутов:  
     _access_ \- разрешен ли текущему пользователю доступ к тесту (булево).  
     _settings_ \- настройки теста (объект) (см. выходные параметры функции **GetTestSettings**).  
     _meta_ - метаданные теста в XML-формате (строка).   
     _data -_ данные прохождения теста в XML-формате (строка). 

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAppTests", "GetTestPageData", [assessment_id]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
