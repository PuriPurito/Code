## GetTests

Метод **GetTests** предназначен для получения списка данных для главной страницы приложения "Тесты".

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAppTests", "GetTests", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _search_ \- критерий поиска для отбора (строка).  
     _page\_num_ \- номер страницы (целое число).  
     _page\_size_ \- размер страницы (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень данных для главной страницы приложения "Тесты", а также ряд дополнительных атрибутов:  
\- items - массив данных для главной страницы приложения  (массив объектов oData).  
     Атрибуты отдельного объекта:  
     _id_ \- ID прохождения теста (завершенного или незавершенного теста) в текстовом выражении (строка).  
     _test\_id_ \- ID теста в текстовом выражении (строка).  
     _code_ \- код теста (строка).  
     _name_ \- название теста (строка).  
     _image_ \- ссылка на изображение теста (строка).  
     _assignment\_type_ \- тип теста (строка). Допустимое значение: "Обязательный".  
     _status_ \- статус прохождения теста (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAppTests", "GetTests", [search, page_num, page_size]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
