## Библиотека приложения Тесты libAppTests

В настоящем разделе описываются методы **библиотеки приложения Тесты** (библиотека программного кода **libAppTests)**. Указанная библиотека регистрируется в разделе **Дизайнер – Библиотеки программного кода – libAppTests**.  
Это библиотека API для работы плеера тестов.

Для вызова методов из библиотеки используется функция tools.call\_code\_library\_method.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAppTests", <sMethodNameParam>, <arrParams>)**

_Аргументы:_  
     _<sMethodNameParam> (обязательный)_  
      Тип: **Строка**. Название вызываемого метода.  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.
