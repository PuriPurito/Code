## GetTestingInitData

Метод **GetTestingInitData** предназначен для получения списка данных инициализации проходимого теста.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libAppTests", "GetTestingInitData", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _active\_test\_learning\_id_ \- ID незаконченного теста в текстовом формате (строка).  
     _session\_id_ \- ID сессии в текстовом формате (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень данных инициализации проходимого теста, а также ряд дополнительных атрибутов:  
\- _oRes_ \- данные инициализации теста (объект).  
     Атрибуты объекта:  
     _meta -_ метаданные теста в XML-формате (строка).  
     _data_ \- данные прохождения теста в XML-формате (строка).  
     _settings_ \- настройки теста (объект) (см. выходные параметры функции **GetTestSettings**).  
     _additional_ \- дополнительные/вспомогательные данные (объект) (см. выходные параметры функции **GetTestSettings**). 

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libAppTests", "GetTestingInitData", [active_test_learning_id, session_id]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
