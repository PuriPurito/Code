## GetCoursesStatistic

Метод GetCoursesStatistic предназначен для получения контекста (показателя) по электронным курсам.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libCourse", "GetCoursesStatistic", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя десять параметров:  
     _iUserID_ \- ID сотрудника (целое число).  
     _sAppCode_ \- код/ID приложения (строка).  
     _sAccessType_ \- тип доступа (строка).  
     _arrCategory_ \- ID категорий электронных курсов, для которых будет учтена иерархия (строка). ID перечисляются через запятую.  
     _sResultType_ \- тип отбора (строка).  
     _dDateStart_ \- дата начала периода отбора (строка).  
     _dDateEnd_ \- дата окончания периода отбора (строка).  
     _arrCourseIDs_ \- ID электронных курсов (строка). ID перечисляются через запятую.  
     _bExtendInfo_ \- производится ли расчет дополнительных показателей (булево).  
     _bContextMode_ \- используется ли контекстный режим показателя (булево). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит контекст (показатель) по электронным курсам, а также ряд дополнительных атрибутов:  
\- _context_ \- контекст (показатель) по электронным курсам (объект). Атрибуты объекта:  
     _course\_count_ – общее количество курсов (целое число).  
     _active\_course_ – количество курсов, находящихся в процессе обучения (целое число).  
     _learning\_course_ – количество законченных курсов (целое число).  
     _percent\_success\_course_ – процент успешно завершенных курсов (целое число).  
     _assigned_ \- количество назначенных курсов (целое число).  
     _avg\_resp\_score_ \- средняя оценка по отзывам (целое число).  
     _avg\_time_ \- средняя продолжительность прохождения курса в секундах (целое число).  
     _avg\_time\_module_ \- средняя продолжительность прохождения модуля в секундах (целое число).  
     _avg\_score_ \- средний набранный балл (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libCourse", "GetCoursesStatistic", [iUserID, sAppCode, sAccessType, arrCategory, sResultType, dDateStart, dDateEnd, arrCourseIDs, bExtendInfo, bContextMode]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
