## GetCoursesByRoles

Метод **GetCoursesByRoles** предназначен для получения списка электронных курсов по категориям.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libCourse", "GetCoursesByRoles", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя двенадцать параметров:  
     _arrCoursesRoles_ – массив ID категорий электронных курсов в троковом формате, для которых не будет учтена иерархия (массив строк).   
     _arrCoursesHierRoles_ \- массив ID категорий электронных курсов в троковом формате, для которых будет учтена иерархия (массив строк).   
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _bCheckAccess_ \- проверять права доступа (булево) (необязательный). Значение по умолчанию - _false_.   
     _bExcludeArchiveCources_ \- нужно ли исключить из выборки архивные курсы (булево) (необязательный). Значение по умолчанию - _false_.   
     _bExcludeSecretCources_ \- нужно ли исключить из выборки скрытые курсы (булево) (необязательный). Значение по умолчанию - _false_.   
     _bExcludeProjectCourses_ \- нужно ли исключить из выборки проектируемые курсы (булево) (необязательный). Значение по умолчанию - false.   
     _bCalculatePersonnelParam -_ нужно ли вычислять параметры прохождения курса для текущего сотрудника (булево) (необязательный). Значение по умолчанию - _false_.   
     _sCurrencyType_ \- тип валюты для построения рейтинга (строка).  
     _arrDistinct_ \- перечень полей для формирования дополнительных списков для виджета фильтров (массив строк).  
     _arrFilters_ \- набор фильтров (массив объектов). Каждый объект массива включает в себя следующие данные: _id_ \- ID фильтра (строка), _type_ \- тип фильтра (строка), _value_ \- критерий отбора (строка).  
     _oSort_ \- информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: _FIELD_ - название поля, по которому производится сортировка (строка), _DIRECTION_ - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).  
     _oPaging_ \- информация из рантайма о пейджинге (объект) (в том числе: _oPaging.index_ \- номер страницы (целое число); _oPaging.size_ \- размер страницы (целое число)).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень электронных курсов по категориям, а также ряд дополнительных атрибутов:  
\- _array_ \- массив электронных курсов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID электронного курса (целое число).  
     _name_ \- название электронного курса (строка).  
     _image_ \- относительная ссылка на изображение (строка).  
     _desc_ \- описание курса (строка).  
     _comment_ \- комментарии (строка).  
     _roles\_names_ \- названия категорий (строка).   
     _link_ \- относительная ссылка на электронный курс (строка).  
     _status_ \- статус курса (строка). Варианты статуса описаны в common.course\_test\_states (например, publish (Открытый), project (Проект), secret (Скрытый), archive (Архивный)).  
     _status\_learning_ \- статус стадии обучения (строка) (например, 'Изучаемые', 'Изученные').  
     _status\_color_ – статус цвета в формате RGB (строка).  
     _type\_assign_ \- тип назначения курса (например, "По собственной инициативе", "Обязательный").  
     _sum\_points_ \- информация о количестве баллов, получаемых за прохождение курсов в процессе геймификации (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libCourse", "GetCoursesByRoles", [arrCoursesRoles, arrCoursesHierRoles, iCurUserID, bCheckAccess, bExcludeArchiveCources, bExcludeSecretCources, bExcludeProjectCourses, bCalculatePersonnelParam, sCurrencyType, arrDistinct, arrFilters, oSort, oPaging ]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
