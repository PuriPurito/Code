## GetCourseModules

Метод **GetCourseModules** предназначен для получения списка учебных модулей.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libCourse", "GetCourseModules", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя шесть параметров:  
     _iCurUserID_ \- ID сотрудника (целое число).  
     _sAccessType_ \- тип доступа для отбора (строка) (необязательный). Допустимые значения: "admin" (администратор приложения); "manager" (администратор процесса); "expert" (эксперт по тематике); "observer" (наблюдатель); "auto" (определяется автоматически в соответствии с правами доступа пользователя). Значение по умолчанию - "auto".  
     _sApplication_ \- код (или ID) приложения, по которому определяется доступ (строка) (необязательный). Значение по умолчанию - пустая строка.  
     _arrCategories_ \- массив ID категорий (массив целых чисел) (необязательный).  
     _arrModules_ \- массив ID учебных модулей (массив целых чисел) (необязательный).  
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень учебных модулей, а также ряд дополнительных атрибутов:  
\- result - массив учебных модулей (массив объектов).  
\- paging - информация о пагинации (объект).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libCourse", "GetCourseModules", [iCurUserID, sAccessType, sApplication, arrCategories, arrModules, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
