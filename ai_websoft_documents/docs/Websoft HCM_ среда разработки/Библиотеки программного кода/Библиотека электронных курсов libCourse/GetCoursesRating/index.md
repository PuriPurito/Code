## GetCoursesRating

Метод **GetCoursesRating** предназначен для определения рейтингов курсов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libCourse", "GetCoursesRating", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя одиннадцать параметров:  
     _iUserID_ – ID сотрудника (целое число).   
     _sAppCode_ \- код приложения, по которому определяется доступ (строка).  
     _sAccessType_ \- тип доступа для отбора (строка) (необязательный). Допустимые значения: "admin" (администратор приложения); "manager" (администратор процесса); "expert" (эксперт по тематике); "observer" (наблюдатель); "auto" (определяется автоматически в соответствии с правами доступа пользователя). Значение по умолчанию - "auto".  
     _arrCategory_ – массив ID категорий электронных курсов, для которых будет учтена иерархия (массив целых чисел) (необязательный).   
     _arrCourseIDs_ – массив ID электронных курсов (массив целых чисел) (необязательный).  
     _sResultType_ \- тип отбора (строка) (необязательный). Значение по умолчанию – пустая строка.  
     _bLastUsageDate_ \- учитывается ли дата последнего использования (булево) (обязательный, если sResultType = 'date').  
     _dDateStart_ \- начало периода отбора (дата).  
     _dDateEnd_ \- окончание периода отбора (дата).  
     _arrStatistics_ – параметры, характеризующие отображение показателей (массив строк) (необязательный). Допустимые значения массива: "all\_count" (Всего назначено); "active\_learning\_count" (Не завершено); "learning\_count" (Завершено); "active\_learning\_overdue\_count" (Просрочено); "max\_last\_usage\_date" (Последняя сессия); "max\_start\_usage\_date" (Последнее назначение); "popular" (Популярность), "avg\_score" (Средняя оценка); "success" (Успешность).  
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень рейтингов курсов, а также ряд дополнительных атрибутов:  
\- _array_ - массив рейтингов курсов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID электронного курса (целое число).  
     _name_ \- название электронного курса (строка).  
     _name\_second_ \- тип электронного курса (строка) ("Открытый"; "Проект"; "Скрытый"; "Архивный").  
     _resource\_id_ \- ID ресурса (целое число).  
     _image\_url_ \- относительная ссылка на изображение (строка).  
     _all\_count_ \- общее количество назначенных курсов (целое число) (если один из элементов входного массива параметров arrStatistics имеет значение "all\_count").  
     _active\_learning\_count_ \- количество назначенных курсов (целое число) (если один из элементов входного массива параметров arrStatistics имеет значение "active\_learning\_count").  
     _learning\_count_ \- количество законченных (завершенных) курсов (целое число) (если один из элементов входного массива параметров arrStatistics имеет значение "learning\_count").  
     _active\_learning\_overdue\_count_ \- количество незаконченных (незавершенных) курсов (целое число) (если один из элементов входного массива параметров arrStatistics имеет значение "active\_learning\_overdue\_count").  
     _max\_last\_usage\_date_ \- время последнего обучения в строковом формате (строка) (если один из элементов входного массива параметров arrStatistics имеет значение "max\_last\_usage\_date").  
     _max\_start\_usage\_date_ \- начало использования курса в строковом формате (строка) (если один из элементов входного массива параметров arrStatistics имеет значение "max\_start\_usage\_date").  
     _popular_ \- популярность курса (отношение количества оцениваемых незавершенных курсов к общему количеству незавершенных курсов) (действительное число) (если один из элементов входного массива параметров arrStatistics имеет значение "popular").  
     _avg\_score_ \- средняя оценка (действительное число) (если один из элементов входного массива параметров arrStatistics имеет значение "avg\_score").  
     _success_ \- успешность обучения (отношение количества курсов со статусом "Пройден" к количеству завершенных курсов) (действительное число) (если один из элементов входного массива параметров arrStatistics имеет значение "success").  
  
\- _paging_ \- информация о пагинации (объект).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libCourse", "GetCoursesRating", [iUserID, sAppCode, sAccessType, arrCategory, arrCourseIDs, sResultType, bLastUsageDate, dDateStart, dDateEnd, arrStatistics, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
