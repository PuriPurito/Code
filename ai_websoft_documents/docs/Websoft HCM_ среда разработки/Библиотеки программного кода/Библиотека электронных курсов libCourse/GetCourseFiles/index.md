## GetCourseFiles

Метод предназначен для получения списка файлов электронного курса.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libCourse", "GetCourseFiles", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iCourseID_ \- ID электронного курса (целое число).  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _bCheckAccess_\- выполнить проверку прав доступа (булево). По умолчанию – _false_.  
     _sSearch_ – критерий отбора (строка) (необязательный).

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит список файлов электронного курса, а также ряд дополнительных атрибутов:  
\- _File_ \- файлы электронного курса (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID файла (целое число);  
     _name_ – название файла (строка);  
     _type_ – тип файла (строка);  
     _size_ – размер файла (целое число);  
     _comment_ – комментарий (строка);  
     _link_ – относительная ссылка на файл (строка).

\- _result_ – результат выполнения метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – сообщение об ошибке (строка).

_Пример:_

`_// Вызов метода_ _с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libCourse", "GetProctoringObjectId", [iCourseID, iCurUserID, bCheckAccess, sSearch]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
