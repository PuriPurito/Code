## GetCourseResponses

Метод **GetCourseResponses** предназначен для получения списка отзывов на электронный курс. 

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libCourse", "GetCourseResponses", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя одиннадцать параметров:  
     _iCourseID_ \- ID электронного курса (целое число).  
     _arrResponsesTypesIDs_ \- массив ID типов отзывов на электронный курс (массив целых чисел).  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _bCheckAccess_ \- проверять права доступа (булево). Значение по умолчанию - _false_.  
     _bShowOnlyPublicResponses_ \- показывать только публичные отзывы (булево). Значение по умолчанию - _false_.   
     _iUserID_ \- ID сотрудника (целое число).  
     _sAppCode_ \- код приложения, по которому определяется доступ (строка) (необязательный).  
     _sAccessType_ \- тип доступа (строка) (необязательный). Допустимые значения: _"admin"; "manager"; "hr"; "expert"; "observer"; "auto"_. Значение по умолчанию - _"auto"_.  
     PAGING - информация из рантайма о пейджинге (объект). Объект включает в себя следующие данные:  INDEX - номер страницы (целое число);  SIZE - размер страницы (целое число); MANUAL - разделение на страницы вручную (булево); TOTAL - общее количество страниц (целое число).  
     SORT - информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).  
     _sSearch_ – критерий отбора (строка) (необязательный).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень отзывов на электронный курс, а также ряд дополнительных атрибутов:  
\- _array_ \- массив отзывов на электронный курс (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID отзыва (целое число).  
     _response\_type\_id_ \- ID типа отзыва (целое число).  
     _response\_type\_name_ \- название типа отзыва (строка).  
     _person\_id_ \- ID сотрудника, написавшего отзыв (целое число).  
     _person\_fullname_ \- ФИО сотрудника, написавшего отзыв (строка).  
     _person\_position\_name_ \- должность сотрудника, написавшего отзыв (строка).  
     _person\_subdivision\_name_ \- подразделение сотрудника, написавшего отзыв (строка).  
     _person\_org\_name_ \- название организации сотрудника, написавшего отзыв (строка).  
     _course\_id_ \- ID курса (целое число)  
     _course\_name_ \- название курса (строка).  
     _comment_ \- комментарий к отзыву (строка).  
     _link_ \- относительная ссылка на отзыв (строка).  
     _create\_date_ \- дата создания отзыва (дата).  
     _basic\_desc_ \- базовое описание (строка);  
     _basic\_score_ \- базовая оценка (действительное число).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libCourse", "GetCourseResponses", [iCourseID, arrResponsesTypesIDs, iCurUserID, bCheckAccess, bShowOnlyPublicResponses, iUserID, sAppCode, sAccessType, PAGING, SORT, sSearch]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
