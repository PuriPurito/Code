## DeleteObjects

Метод **DeleteObjects** предназначен для удаления объектов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "DeleteObjects", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
\- _sCatalogName_ \- название каталога объектов (строка).  
\- _SCOPE\_WVARS_ \- JSON-объект с переменными удаленного действия (объект).  
\- _PARAMETERS_ \- JSON-объект с параметрами удаленного действия (объект).  
\- _iUserID_ \- ID сотрудника (целое число).  
\- _teUser_ \- TopElem сотрудника (объект XmlDoc).

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
\- _result_ – информация о результате вызова метода (объект) (в том числе: command – команда вывода информации о результате (строка) (например, "alert", "display\_form", "close\_form"); другие параметры зависят от значения параметра command).  
  
_\- error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
_\- errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "DeleteObjects", [sCatalogName, SCOPE_WVARS, PARAMETERS, iUserID, teUser]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
