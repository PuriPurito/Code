## GetNumSuffix

Метод **GetNumSuffix** предназначен для определения форм выражения периодов времени (год, года, лет; месяц, месяцев; день, дня) для строкового представления дат в зависимости от числового значения.  
Например: _5 лет 10 месяцев 1 день_.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetNumSuffix", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iNum_ \- число, для которого определяются формы выражения периодов времени (целое число).  
     _sType_ \- тип периода времени (_"year"_ - годы, _"month"_ - месяцы, _"day"_ - дни) (строка).  
     _curLngWeb_ \- переменная, определяющая язык выражения (строка) (необязательный). Если параметр не указан, то используется язык, заданный по умолчанию в Websoft HCM. 

_Возвращаемое значение:_  
      Тип: **Строка**. Содержит выражение периода времени для строкового представления даты в зависимости от числового значения и типа временного периода. 

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetNumSuffix", [iNum, sType, curLngWeb]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
