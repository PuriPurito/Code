## GetSubPersonList (устаревшая)

Метод предназначен для получения информации о прохождении подчиненными сотрудниками курса, теста или учебной программы.   
Функция, в частности, может быть использована для выборок в карточках курсов, тестов и учебных программ.

В данную выборку также включаются данные о самом функциональном руководителе, если он проходит или проходил указанный курс, тест или учебную программу.   

Примечание - Начиная с версии 2023.2, данная функция объявлена как deprecated.   
Данную функцию использовать не рекомендуется. Вместо нее следует использовать libLearning/GetBossLearnings. 

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetSubPersonList", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.    
     Массив включает в себя пять параметров:  
     _iObjectID_ – ID объекта (курса, теста или учебной программы) (целое число).    
     _iUserID_ – ID функционального руководителя (целое число).   
     _sSearchFullname_ – критерий поиска по ФИО (строка). Для выборки всех подчиненных сотрудников, проходящих курс, тест или учебную программу, необходимо ввести значение _null_.   
     _oPagingParam_ - информация из рантайма о пейджинге (объект) (необязательный). Объект включает в себя следующие данные:  INDEX - номер страницы (целое число);  SIZE - размер страницы (целое число); MANUAL - разделение на страницы вручную (булево); TOTAL - общее количество страниц (целое число).  
     _oSortParam_ \- информация из рантайма о сортировке (объект) (необязательный). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит информацию о прохождении подчиненными сотрудниками курса, теста или учебной программы, а также ряд дополнительных атрибутов:  
\- _array_ \- массив данных о подчиненных сотрудниках, проходящих или проходивших курс, тест или учебную программу  (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID подчиненного сотрудника (целое число);  
     _fullname_ – ФИО сотрудника (строка);  
     _position_ – должность сотрудника (строка);  
     _sub_ – подразделение (строка);  
     _status_ – статус обучения (строка);  
     _url\_status_ – URL статуса сотрудника (строка);  
     _last\_date_ – последняя дата работы с объектом (дата);  
     _max\_score_ – максимальное количество баллов, набранное сотрудником (целое число);  
     _rec_ – перечень наименований объектов обязательного обучения (строка);  
     _url_ – относительная ссылка на страницу сотрудника (строка);  
     _status\_class_ – значение классификатора статуса (строка).  
  
\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).
