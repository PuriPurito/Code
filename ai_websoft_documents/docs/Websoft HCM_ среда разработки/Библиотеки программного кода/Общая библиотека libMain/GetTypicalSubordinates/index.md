## GetTypicalSubordinates

Метод **GetTypicalSubordinates** предназначен для получения типичных наборов подчиненных с использованием параметров из библиотеки процесса

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetTypicalSubordinates", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя шесть параметров:  
     _iPersonID_ \- ID руководителя (целое число).  
     _sTypeSubordinate_ \- тип подчиненных (строка). Допустимые значения - _"main\_subordinates"_ (только основные фактические подчиненные (по должности или если указан тип «Непосредственный руководитель»)), _"subordinates"_ (добавляются фактические (по должности или если указан тип «Непосредственный руководитель») подчиненные по организациям), _"func\_subordinates"_ (добавляются только функциональные подчиненные - по организациям, персональные подчиненные и подчиненные по всему дочернему поддереву подразделений), _"all\_subordinates"_ (добавляются все подчиненные по организациям, персональные подчиненные и подчиненные по всему дочернему поддереву подразделений).  
     _arrBossTypesID_ \- массив ID типов руководителей для отбора по функциональным руководителям (массив целых чисел). Данный массив используется, если параметр _sTypeSubordinate_ имеет значение _"func\_subordinates"_ или _"all\_subordinates"_.  
     _bReturnIDs_ \- возвращать массив ID (_true_) (иначе - каталожные записи (_false_)) (булево).  
     _sXQueryCond_ \- дополнительное условие отбора в XQuery (строка) (необязательный).   
     _arrResultFieldNames_ \- массив возвращаемых полей (необязательный) (массив строк).

_Возвращаемое значение:_  
      Тип: **Массив**. Массив ID подчиненных (массив целых чисел) или их каталожных карточек (массив объектов) в зависимости от значения _bReturnCalalogRecordset_.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetTypicalSubordinates", [iPersonID, sTypeSubordinate, arrBossTypesID, bReturnIDs, sXQueryCond, arrResultFieldNames]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
