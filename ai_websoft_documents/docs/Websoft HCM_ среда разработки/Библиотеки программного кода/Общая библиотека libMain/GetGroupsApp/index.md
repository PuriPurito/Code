## GetGroupsApp

Метод **GetGroupsApp** предназначен для получения списка групп.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetGroupsApp", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя семь параметров:  
\- _iApplLevel_ – - тип доступа (строка). Допустимые значения: "admin"; "manager"; "hr"; "expert"; "observer"; "reject".  
\- _arrBossTypesID_ \- массив типов руководителей (массив целых чисел) (необязательный).  
\- _sApplicationID_ – код приложения, по которому определяется доступ (строка).  
\- _iCurApplicationID_ \- ID текущего приложения (целое число).  
\- _sGroupType_ \- типы групп (строка) (необязательный). Допустимые значения: "all" (Все); "static" (Статические); "dynamic" (Динамические); "educ" (Учебные). Значение по умолчанию – "all".  
\- _sXQueryQual_ \- строка для XQuery-фильтра (строка) (необязательный).  
\- _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).  

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень групп, а также ряд дополнительных атрибутов:  
\- _array_ - массив групп (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID группы (целое число).  
     _code_ \- код группы (строка).  
     _name_ \- название группы (строка).  
     _dynamic_ \- признак динамической группы (булево).   
     _educ_ \- признак учебной группы (булево).  
     _count_ \- количество сотрудников (целое число).  
     _type_ \- тип группы (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetGroupsApp", [iApplLevel, arrBossTypesID, sApplicationID, iCurApplicationID, sGroupType, sXQueryQual, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
