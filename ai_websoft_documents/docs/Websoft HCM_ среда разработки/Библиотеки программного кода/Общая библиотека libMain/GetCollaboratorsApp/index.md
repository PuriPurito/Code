## GetCollaboratorsApp

Метод **GetCollaboratorsApp** предназначен для получения списка сотрудников.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetCollaboratorsApp", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя десять параметров:  
\- _iCurUserID -_ ID текущего пользователя (целое число).  
\- _sAccessType_ \- тип доступа (строка). Допустимые значения: _"admin"; "manager"; "hr"; "observer"; "auto"._  
\- _arrBossTypesID_ \- массив ID типов руководителей (массив целых чисел) (необязательный).  
\- _sApplication_ \- код приложения, по которому определяется доступ (строка).  
\- _iCurApplicationID_ \- ID текущего приложения (целое число).  
\- _sReturnData_ \- тип сотрудников, по которым производится отбор (строка) (необязательный). Допустимые значения: _"all" (Все); "dismissed" (Уволенные); "not\_dismissed" (Неуволенные). Значение по умолчанию – "all"._  
\- _sXQueryQual_ \- строка для XQuery-фильтра (строка).  
\- _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).  
\- _aAdditionalFields_ \- дополнительные поля (массив строк).   
\- _request\_type_ - тип запроса (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень сотрудников, а также ряд дополнительных атрибутов:  
\- _array_ \- массив сотрудников (массив объектов).  
     Атрибуты отдельного объекта:  
     _basic\_info_ \- основная информация о сотруднике (ФИО и должность) (строка).  
     _id_ – ID сотрудника (целое число).  
     _code_ – код сотрудника (строка).  
     _fullname_ – ФИО сотрудника (строка).  
     _sex_ – пол сотрудника ('m' или 'w') (строка).  
     _birth\_date_ – дата рождения (дата).  
     _login_ \- логин (строка).  
     _email_ \- электронный адрес (строка).  
     _primary\_position_ \- название основной должности (строка).  
     _main\_subdivision_ \- название основного подразделения, в котором работает сотрудник (строка).  
     _main\_org_ \- название основной оргганизации, в которой работает сотрудник (строка).  
     _person\_current\_state_ \- текущее состояние сотрудника (строка).  
     _hire\_date_ \- дата приема на работу (дата).  
     _dismiss\_date_ \- дата увольнения (дата).  
     _phone_ \- телефон (строка).  
     _access\_role_ \- роль доступа (строка).  
     _typical\_development\_program\_count_ \- количество типовых программ развития (целое число).  
     _adaptation\_count_ \- количество адаптаций (целое число).  
     _end\_adaptation\_count_ \- количество завершенных адаптаций (целое число).  
     _active\_adaptation\_count_ \- количество активных адаптаций (целое число).  
     _plan\_adaptation\_count_ \- количество запланированных адаптаций (целое число).  
     _consent\_kedo_ \- согласие на использование кадрового электронного документооборота (КЭДО) (булево).  
     _active\_badges\_count_ \- количество активных бэджей (в геймификации) (целое число).  
     _badges\_count_ \- общее количество бэджей (в геймификации) (целое число).   
     _active\_rewards\_count_ \- количество активных наград (в геймификации) (целое число).  
     _rewards\_count_ \- общее количество наград (в геймификации) (целое число).  
     _response\_given\_to\_collaborator\_count_ \- количество завершенных отзывов (обратных связей) по сотруднику (целое число).  
     _requested\_response\_count_ \- общее количество запрошенных отзывов (целое число).  
     _added\_response\_count_ \- общее количество отзывов, подготовленных сотрудником (целое число).  
     _need\_add\_response\_count_ \- общее количество отзывов, запрошенных у сотрудника (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetCollaboratorsApp", [iCurUserID, sAccessType, arrBossTypesID, sApplication, iCurApplicationID, sReturnData, sXQueryQual, oCollectionParams, aAdditionalFields, request_type]);_`   
  
`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
