## GetSubdivisionGroups

Метод **GetSubdivisionGroups** предназначен для получения списка групп подразделений.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetSubdivisionGroups", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя восемь параметров:  
\- _sFilter_ \- строка для XQuery-фильтра (строка).  
\- _sFulltext_ \- строка для полнотекстового поиска (строка).  
\- _iTypicalDevelopmentProgram_ \- ID типовой программы развития (целое число).  
\- _sAccessType_ \- тип доступа (строка). Допустимые значения: _"admin"; "manager"; "hr"; "observer"; "auto"_.  
\- _arrBossTypesID_ \- массив типов руководителей (массив целых чисел).  
\- _ApplicationParam_ \- код или ID приложения, по которому определяется доступ, в текстовом выражении (строка).  
\- _arrReturnData_ \- набор вычисляемых атрибутов выборки (массив строк).  
\- _iCurUserIDParam_ \- ID текущего пользователя (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень групп подразделений, а также ряд дополнительных атрибутов:  
\- _array_ \- массив групп подразделений (массив объектов).  
     Атрибуты отдельного объекта:  
     _code_ \- код группы подразделений (строка).  
     _name_ \- название группы подразделений (строка).  
     _subdivisions\_count_ \- количество подразделений (целое число).  
     _typical\_development\_programs\_count_ \- количество типовых программ развития (целое число).  
     _is\_dynamic_ \- признак динамической группы (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetSubdivisionGroups", [sFilter, sFulltext, iTypicalDevelopmentProgram, sAccessType, arrBossTypesID, ApplicationParam, arrReturnData, iCurUserIDParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
