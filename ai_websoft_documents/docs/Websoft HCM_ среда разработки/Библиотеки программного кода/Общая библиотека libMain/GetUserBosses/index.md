## GetUserBosses

Метод **GetUserBosses** предназначен для получения списка руководителей сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetUserBosses", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
\- _iUserID_ \- ID пользователя (целое число).  
\- _bCheckMain_ \- проверять ли руководителей по должности (булево) (необязательный). Значение по умолчанию - _true_.  
\- _arrBossTypes_ \- массив ID типов руководителей (массив целых чисел) (необязательный).  
\- _oParams_ \- параметры возвращаемых данных (объект) (необязательный).   
\- _bAllHier_ \- возвращать ли всех руководителей по иерархии (булево) (необязательный). Значение по умолчанию - _true_. 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень руководителей сотрудника, а также ряд дополнительных атрибутов:  
\- _array_ \- массив руководителей сотрудника (массив объектов).  
     Атрибуты отдельного объекта:  
     _person\_id_ \- ID функционального руководителя (целое число).  
     _person\_fullname_ \- ФИО функционального руководителя (строка).  
     _person\_position\_id_ \- ID должности функционального руководителя (целое число).  
     _person\_position\_name_ \- наименование должности функционального руководителя (строка).  
     _person\_org\_id_\- ID организации, где работает функциональный руководитель (целое число).  
     _person\_org\_name_ \- наименование организации, где работает функциональный руководитель (строка).  
     _person\_org\_code_ \- код организации, где работает функциональный руководитель (строка).  
     _person\_subdivision\_id_ \- ID подразделения, где работает функциональный руководитель (целое число).  
     _person\_subdivision\_name_\- наименование подразделения, где работает функциональный руководитель (строка).  
     _boss\_type\_id_ \- тип функционального руководителя (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetUserBosses", [iUserID, bCheckMain, arrBossTypes, oParams, bAllHier]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
