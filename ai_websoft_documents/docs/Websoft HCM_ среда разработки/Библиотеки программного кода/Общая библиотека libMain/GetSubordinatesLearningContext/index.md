## GetSubordinatesLearningContext

Метод **GetSubordinatesLearningContext** предназначен для получения контекста по обучению подчиненных сотрудников.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetSubordinatesLearningContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
\- _iCurUserID_ \- ID пользователя для поддержки ролевой модели (целое число).  
\- _sAppCode_ \- код приложения для поддержки ролевой модели (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит контекст по обучению подчиненных сотрудников, а также ряд дополнительных атрибутов:  
\- _context_ \- контекст сотрудников по обучению (объект).  
     Атрибуты контекста:  
     _percent\_mandatory\_course_ \- процент обязательного обучения для курсов (целое число).  
     _percent\_mandatory\_test_ \- процент обязательного обучения для тестов (целое число).  
     _overdue\_learning\_course_ \- количество просроченных курсов (целое число).  
     _overdue\_learning\_test_ \- количество просроченных тестов (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetSubordinatesLearningContext", [iCurUserID, sAppCode]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
