## Общая библиотека libMain

В настоящем разделе описываются методы **общей библиотеки (библиотеки общих методов работы с системой)** (библиотека программного кода **libMain**). Указанная библиотека регистрируется в разделе **Дизайнер – Библиотеки программного кода – libMain**.

Для вызова методрв из библиотеки используется функция tools.call\_code\_library\_method.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", <sMethodNameParam>, <arrParams>)**

_Аргументы:_  
     _<sMethodNameParam> (обязательный)_  
      Тип: **Строка**. Название вызываемого метода.  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки. 

В библиотеке **libMain** настраиваются следующие глобальные параметры:

**DefaultColleagueType** определяет способ отбора коллег для пользователя.

**DefaultHighEffectivenessLevel** указывает уровень, выше которого сотрудник считается высокоэффективным.

**DefaultHighEffectivenessSuccessorMinNum** указывает минимально необходимое количество высокоэффективных преемников для закрытия ключевой должности.

**DefaultSubordinateType** определяет способ отбора подчиненных для пользователя;

**sDefaultAssessmentAppraiseTypes** указывает тип форм оценки, который используется в данном экземпляре системы для получения данных по целям сотрудника (подразделения, организации).
