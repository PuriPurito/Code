## GetPersonLearningContext

Метод **GetPersonLearningContext** предназначен для получения контекста сотрудника по результатам прохождения обучения.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetPersonLearningContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iUserID_ \- ID сотрудника (целое число).  
     _iCurUserID_ \- ID пользователя для поддержки ролевой модели (целое число).  
     _sAppCode_ \- код приложения для поддержки ролевой модели (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные контекста сотрудника по результатам прохождения обучения, а также ряд дополнительных атрибутов:  
\- _context_ \- данные контекста сотрудника по результатам прохождения обучения  (объект).  
     Атрибуты объекта:  
     _percent\_mandatory\_course_ – процент прохождения обязательного обучения (изучение курсов) (целое число).  
     _percent\_success\_course_ – процент успешности прохождения курсов (целое число).  
     _percent\_mandatory\_test_ – процент прохождения обязательного обучения (сдача тестов) (целое число).  
     _percent\_success\_test_ – процент успешности сдачи тестов (целое число).  
     _learning\_course_ – всего изучено/закончено курсов (целое число).  
     _learning\_test_ – всего сдано тестов (целое число).  
     _youself\_course_ – количество законченных курсов, изучаемых по собственной инициативе (целое число).  
     _youself\_test_ – количество тестов, сданных по собственной инициативе (целое число).  
     _active\_course_ – количество курсов в процессе обучения (целое число).  
     _active\_test_ – количество тестов в процессе обучения (целое число).  
     _mandatory\_active\_course_ – количество незаконченных обязательных курсов (целое число).  
     _mandatory\_active\_test_ – количество незаконченных обязательных тестов (целое число).  
     _percent\_not\_learning\_recommender\_course_ – процент не изученных рекомендованных курсов (целое число).  
     _finish\_event_ – количество пройденных мероприятий (целое число).  
     _percent\_assist\_event_ – процент посещения мероприятий (целое число).  
     _visiting\_hours_ – количество часов посещения мероприятий (целое число).  
     _future\_event_ – количество текущих и будущих мероприятий (целое число).  
     _overdue\_learning\_course_ \- количество просроченных курсов (целое число).  
     _overdue\_learning\_test_ \- количество просроченных тестов (целое число).  
     _overdue\_learning_ – количество просроченных элементов обучения (курсов и тестов) (целое число).  
     _percent\_overdue\_learning\_course_ – процент просроченных курсов в составе завершенных курсов (целое число).  
     _percent\_overdue\_learning\_test_ – Процент просроченных тестов в составе завершенных тестов (целое число).  
     _percent\_overdue\_learning_ – процент просроченных элементов обучения в составе завершенных курсов и тестов (целое число).  
     _percent\_average\_score\_course_ \- средний процент набранных баллов по завершенным курсам (целое число).  
     _percent\_average\_score\_test_ \- средний процент набранных баллов по завершенным тестам (целое число).  
     _percent\_average\_score_ – средний процент набранных баллов по завершенным элементам обучения (курсам и тестам) (целое число).  
     _percent\_complete\_mandatory\_course_ \- процент завершения обязательных курсов (целое число).  
     _percent\_complete\_mandatory\_test_ \- процент завершения обязательных тестов (целое число).  
     _percent\_complete\_mandatory_ – процент завершения обязательных элементов обучения (целое число).  
     _percent\_success\_complete\_mandatory\_course_ \- процент успешно завершенных обязательных курсов (целое число).  
     _percent\_success\_complete\_mandatory\_test_ \- процент успешно завершенных обязательных тестов (целое число).  
     _percent\_success\_complete\_mandatory_ – процент успешно завершенных обязательных элементов обучения (целое число).  
     _percent\_average\_score\_mandatory\_course_ \- средний процент набранных баллов по обязательным курсам (целое число).  
     _percent\_average\_score\_mandatory\_test_ \- средний процент набранных баллов по обязательным тестам (целое число).  
     _percent\_average\_score\_mandatory_ – средний процент набранных баллов по обязательным элементам обучения (целое число).  
     _overdue\_learning\_mandatory\_course_ \- количество просроченных сессий обязательных курсов (целое число).  
     _overdue\_learning\_mandatory\_test_ \- количество просроченных сессий обязательных тестов (целое число).  
     _overdue\_learning\_mandatory_ – количество просроченных сессий обязательного обучения (целое число).  
     _max\_last\_usage\_date\_course_ \- дата последнего прохождения курса (максимальное значение поля last\_usage\_date для активного и завершенного обучения) (дата).  
     _max\_last\_usage\_date\_test_ \- дата последнего прохождения теста (максимальное значение поля last\_usage\_date для активного и завершенного обучения) (дата).  
     _max\_last\_usage\_date_ \- дата последней учебной активности (дата).  
     _max\_start\_usage\_date\_course_ \- дата последнего назначения курса (максимальное значение поля start\_usage\_date для активного и завершенного обучения) (дата).  
     _max\_start\_usage\_date\_test_ \- дата последнего назначения теста (максимальное значение поля start\_usage\_date для активного и завершенного обучения) (дата).  
     _max\_start\_usage\_date_ – дата последнего назначения обучения (дата).  
     _time\_average\_course_ \- среднее время, затрачиваемое на прохождение курсов в неделю (в часах) (целое число).  
     _time\_average\_test_ \- среднее время, затрачиваемое на прохождение тестов в неделю (в часах) (целое число).  
     _time\_average_ – среднее время, затрачиваемое на обучение (в часах) (целое число).  
     _response\_count\_course_ \- количество заполненных анкет обратной связи курсов (целое число).  
     _response\_count\_test_ \- количество заполненных анкет обратной связи для тестов (целое число).  
     _response\_count_ – количество заполненных анкет обратной связи (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetPersonLearningContext", [iUserID, iCurUserID, sAppCode]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
