## GetLectors

Метод GetLectors предназначен для получения справочника преподавателей.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetLectors", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
      Массив включает в себя одиннадцать параметров:  
 - _sLectorType_ \- тип преподавателя (строка) (необязательный) (Допустимые значения: _'all'_ (все типы преподавателей); _'invitee'_ (приглашенные преподаватели); _'collaborator'_ (преподаватели, которые являются сотрудниками организации)). Значение по умолчанию - _'all'_.  
\- _aRolesID_ \- массив ID категорий (массив целых чисел) (необязательный).  
\- _bGetRoleHier_ \- брать все категории вниз по иерархии  (булево) (необязательный). Значение по умолчанию - _false_.  
\- _bShowDismiss_ \- показывать уволенных сотрудников (булево) (необязательный). Значение по умолчанию - _false_.   
\- iCurUserID - ID текущего пользователя (целое число).  
\- sAccessType - Тип доступа (строка). Допустимые значения: "admin", "manager", "hr", "expert", "observer", "auto".  
\- sApplication код (или id) приложения, по которому определяется доступ (строка).  
\- _arrReturnData_ \- массив полей для вывода (массив строк) (необязательный). Допустимые значения: "education\_method\_count"(число учебных программ, в которых указан преподаватель),"event\_count"(число мероприятий, в которых указан преподаватель).  
\- _bShowActive_ \- показывать неуволенных сотрудников (булево). Значение по умолчанию - false.  
\- _sXQueryQual_ \- фильтр XQuery для отбора (строка) (необязательный).  
\- _oCollectionParams_ \- набор интерактивных параметров выборки (отбор, сортировка, пейджинг) (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень преподавателей, а также ряд дополнительных атрибутов:  
\- array - массив преподавателей (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID преподавателя (целое число).  
     _name_ – ФИО преподавателя (строка).  
     _phone_ – номер телефона преподавателя (строка).  
     _email_ – электронный адрес преподавателя (строка).  
     _mobile\_phone_ – номер мобильного телефона преподавателя (строка).  
     _system\_email_ \- внутренний электронный адрес преподавателя (строка).  
     _comment_ – комментарий (строка).  
     _desc_ – описание (строка).  
     _image\_url_ \- относительная ссылка на изображение (строка).  
     _link_ \- относительная ссылка на карточку преподавателя (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetLectors", [sLectorType, aRolesID, bGetRoleHier, bShowDismiss, iCurUserID, sAccessType, sApplication, arrReturnData, bShowActive, sXQueryQual, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
