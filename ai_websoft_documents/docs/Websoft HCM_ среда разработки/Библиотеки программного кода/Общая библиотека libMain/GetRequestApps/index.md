## GetRequestApps

Метод **GetRequestApps** предназначен для получения списка заявок.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetRequestApps", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя девять параметров:  
     _sAccessType_ \- тип доступа (строка). Допустимые значения: "admin"; "hr"; "expert"; "observer"; "auto".  
     _sApplication_ \- код приложения, по которому определяется доступ (строка).  
     _iCurApplicationID_ \- ID текущего приложения (целое число).  
     _iReqTypeID_ \- тип возвращаемых заявок (строка).  
     _sStates_ \- статус заявок (строка). Доступные статусы заявок: _active (Активная); close (Закрыта); ignore (Отклонена); pay (Оплачена)_.  
     _sReturnData_ \- возвращаемые данные (строка).  
     _sXQueryQual_ \- фильтр XQuery для отбора (строка) (необязательный).  
     _oCollectionParams_ \- набор интерактивных параметров выборки (объект). Параметры объекта: _filters (отбор), distincts (сортировка), paging (пейджинг)_. 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень заявок, а также ряд дополнительных атрибутов:  
\- _array_ \- коллекция заявок (массив объектов).  
     Атрибуты отдельного элемента массива:  
      _url\_photo_ \- ссылка на изображение (строка).  
      _person\_fullname_ \- ФИО сотрудника (строка).  
      _position\_name_ \- должность сотрудника (строка).  
      _subdivision\_name_ \- подразделение сотрудника (строка).  
      _org\_name_ \- организация, в которой работает сотрудник (строка).  
      _create\_date_ \- дата создания заявки (дата).  
      _close\_date_ \- дата закрытия заявки (дата).  
      _status_ \- статус заявки (строка).  
      _workflow\_state\_name_ \- название текущего этапа документооборота (строка).  
      _request\_type_ \- тип заявки (строка).  
      _object\_type_ \- тип объекта (строка).  
      _object\_name_ \- название объекта (строка).  
      _object\_id_ \- ID объекта (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetRequestApps", [iCurUserID, sAccessType, sApplication, iCurApplicationID, iReqTypeID, sStates, sReturnData, sXQueryQual, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
