## GetObjectLectors

Метод предназначен для получения списка преподавателей по объекту.

В качестве аргумента необходимо выбрать объект, имеющий ссылки на преподавателей.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetObjectLectors", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iObjectID_ – ID объекта, имеющего ссылки на преподавателей (целое число).    
     _bShowDismiss_ – показывать уволенных сотрудников (булево). По умолчанию – _false_.

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит перечень преподавателей по объекту, а также ряд дополнительных атрибутов:  
\- _array_ \- массив преподавателей (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID преподавателя (целое число);  
     _name_ – ФИО преподавателя (строка);  
     _image\_url_ – относительная ссылка на фотографию преподавателя (строка);  
     _link_ – относительная ссылка на карточку преподавателя (строка).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).
