## StrDateInterval

Метод **StrDateInterval** для формирования строкового представления временного интервала в формате "X лет \[Y месяцев \[Z дней\]\]".

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "StrDateInterval", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _dStartDate_ \- начало интервала (дата и время).  
     _dEndDate_ \- начало интервала (дата и время).  
     _bShowMonth_ \- отображать ли месяцы в результате преобразования (булево) (необязательное). По умолчанию - _true_.  
     _bShowDays_ \- отображать ли дни в результате преобразования (булево) (необязательное). По умолчанию - _true_.

_Возвращаемое значение:_  
      Тип: **Строка**. Строковое представление временного интервала (в формате "X лет \[Y месяцев \[Z дней\]\]").

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "StrDateInterval", [dStartDate, dEndDate, bShowMonth, bShowDays]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
