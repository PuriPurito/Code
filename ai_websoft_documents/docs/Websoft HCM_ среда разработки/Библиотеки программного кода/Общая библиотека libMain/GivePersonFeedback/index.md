## GivePersonFeedback

Метод **GivePersonFeedback** предназначен для того, чтобы дать обратную связь сотруднику.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GivePersonFeedback", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя шесть параметров:  
     _iPersonID_ \- ID сотрудника, получающего обратную связь (целое число).  
     _iPoints_ \- размер благодарности (целое число).  
     _iCompetence_ \- компетенция сотрудника, по которой дается обратная связь (целое число).  
     _sComment_ \- комментарий к благодарности (строка).  
     _sCurrency_ \- валюта, в которой выражается благодарность (строка). Значение по умолчанию - "thanks".  
     _bScoresWithoutDebiting_ \- только начислять баллы, без списания (булево). Для валюты типа "thanks" (Спасибо) данный параметр не учитывается. 

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
_\- paragraph_ – текст сообщения (строка). Возможные сообщения: "alert", "close\_form".  
  
_\- error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
_\- errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GivePersonFeedback", [iPersonID, iPoints, iCompetence, sComment, sCurrency, bScoresWithoutDebiting ]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
