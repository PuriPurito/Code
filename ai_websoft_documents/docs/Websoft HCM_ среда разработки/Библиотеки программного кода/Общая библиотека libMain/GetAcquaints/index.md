## GetAcquaints

Метод **GetAcquaints** предназначен для получения списка ознакомлений.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetAcquaints", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя восемь параметров:  
\- _iCurUserID_ \- ID текущего пользователя (целое число).  
\- _sAccessType_ \- тип доступа (строка). Допустимые значения: _"admin"; "manager"; "hr"; "expert"; "observer"; "auto"._  
\- _sApplication_ \- код приложения, по которому определяется доступ (строка).  
\- _arrState_ \- массив состояний (массив строк) (необязательный). Допустимые значения: _"active" (Активное), "archive" (Архив)._  
\- _arrReturnData_ \- массив полей для вывода (массив строк) (необязательный). Допустимые значения: _"all\_count" (Общее число назначений), "familiar\_count" (Число назначений со статусом 'Ознакомлен'), "assign\_count" (Число назначений со статусом 'Назначен'), "active\_count" (Число назначений со статусом 'В процессе'), "last\_assign\_date" (Дата последнего назначения)._  
\- _sFilter_ \- строка для XQuery-фильтра (строка).  
\- _sFulltext_ \- строка для полнотекстового поиска (строка).   
\- _oCollectionParams_ \- набор интерактивных параметров выборки (отбор, сортировка, пейджинг) (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень ознакомлений, а также ряд дополнительных атрибутов:  
\- _array_ \- массив ознакомлений (массив объектов).  
     Атрибуты отдельного объекта:  
     _code_ \- код ознакомления (строка).  
     _name_ \- название ознакомления (строка).  
     _object\_type\_name_ \- код ознакомления (строка).  
     _object\_name_ \- название типа объекта (строка).  
     _acquaint\_assign\_all\_count_ \- общее количество назначенных ознакомлений (целое число).  
     _acquaint\_assign\_familiar\_count_ \- количество назначений ознакомлений со статусом Ознакомлен (целое число).  
     _acquaint\_assign\_assign\_count_ \- количество назначений ознакомлений со статусом Назначен (целое число).  
     _acquaint\_assign\_active\_count_ количество назначений ознакомлений со статусом В процессе (целое число).  
     _last\_assign\_date_ \- дата последнего назначения ознакомления (дата).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetAcquaints", [iCurUserID, sAccessType, sApplication, arrState, arrReturnData, sFilter, sFulltext, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
