## GetSubdivisionsApp

Метод **GetSubdivisionsApp** предназначен для получения списка подразделений.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetSubdivisionsApp", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя восемь параметров:  
\- _iCurUserID_ \- ID текущего пользователя (целое число).  
\- _iApplLevel_ \- уровень доступа сотрудника в приложении (целое число).  
\- _arrBossTypesID_ \- Массив типов руководителей (массив целых чисел) (необязательный).  
\- _sApplicationID_ \- код приложения, по которому определяется доступ (целое число).  
\- _iCurApplicationID_ \- ID текущего приложения (целое число).  
\- _sXQueryQual_ \- строка для XQuery-фильтра (строка).  
\- _oCollectionParams_ \- набор интерактивных параметров (ID текущего пользователя, отбор, сортировка, пейджинг) (объект).  
\- _sSubdivisionGroupID_ \- ID группы подразделений в строковом выражении (строка). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень подразделений, а также ряд дополнительных атрибутов:  
\- subdivisions – массив подразделений (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID подразделения (целое число).  
     _code_ – код подразделения (строка).  
     _name_ – название подразделения (строка).  
     _company_ \- название организации (строка).  
     _place_ \- расположение подразделения (строка).  
     _parent\_subdiv\_name_ \- название вышестоящего подразделения (строка).  
     boss\_fullname - ФИО непосредственного руководителя (строка).

\- paging - пейджинг (объект).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetSubdivisionsApp", [iCurUserID, iApplLevel, arrBossTypesID, sApplicationID, iCurApplicationID, sXQueryQual, oCollectionParams, sSubdivisionGroupID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
