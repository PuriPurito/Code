## GetToDo

Метод предназначен для получения списка текущих задач пользователя.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetToDo", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя шестнадцать параметров:  
     _iPersonID_ – ID сотрудника (целое число);  
     _sStatus_ \- статус задач (_все 'indefinite', просроченные 'exceeded', срочные 'critical', предстоящие 'future'_) (строка);   
     _iDaysToShow_ \- количество дней, в течение которых задача попадает в список (целое число). Например, если будет указано значение _iDaysToShow=30_, то отбираются задачи на 30 дней вперед (а также просроченные);  
     _iCriticalDays_ \- количество дней, которое остается до отнесения задачи к категории срочных (целое число);  
     _bShowCourse_ \- показывать назначенные курсы (булево);  
     _bShowTest_ \- показывать назначенные тесты (булево);  
     _bShowEventConfirmation_ \- показывать напоминания о подтверждении участия в мероприятии (булево);  
     _bShowResponseLeaving_ \- показывать напоминания оставить отзыв (булево);  
     _bShowPolls_ \- показывать опросы (булево);  
     _bShowRequests_ \- показывать заявки на согласование (булево);  
     _bShowAssessmentApraises_ \- показывать оценочные процедуры (булево);  
     _bShowLibraryMaterials_ \- показывать материалы библиотеки, с которыми необходимо ознакомиться (булево);  
     _bShowChatInvites_ \- показывать новые сообщения в чате (булево);  
     _bShowTasks_ \- показывать задачи (булево);  
     _bShowAcquaints_ \- показывать ознакомления (булево);  
     _bShowLearningTasks_ \- показывать выполнения заданий (булево). 

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит список текущих задач пользователя, а также ряд дополнительных атрибутов:  
\- _array_ \- массив задач пользователя (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID задачи (целое число);  
     _name_ – название задачи (строка);  
     _type_ – тип задачи (строка);  
     _state\_id_ \- ID статуса задачи (строка);  
     _state_ \- статус задачи (строка);  
     _action_ \- действие (строка);  
     _actionLabel_ \- ярлык действия (строка);  
     _image_ – относительная ссылка на изображение (строка);  
     _value_ \- значение задачи (строка);  
     _date_ \- дата создания задачи (дата);  
     _strDate_ \- дата создания задачи в строковом выражении (строка);  
     _exceeded_ \- задача относится к типу просроченных (булево);  
     _indefinite_ \- тип задачи не определен (булево);  
     _critical_ \- задача относится к типу срочных (булево);  
     _future_ \- задача относится к типу предстоящих (булево).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetToDo", [ iPersonID, sStatus, iDaysToShow, iCriticalDays, bShowCourse, bShowTest, bShowEventConfirmation, bShowResponseLeaving, bShowPolls, bShowRequests, bShowAssessmentApraises, bShowLibraryMaterials, bShowChatInvites, bShowTasks, bShowAcquaints, bShowLearningTasks ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
