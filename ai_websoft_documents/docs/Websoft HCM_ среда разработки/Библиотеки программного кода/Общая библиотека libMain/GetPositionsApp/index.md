## GetPositionsApp

Метод **GetPositionsApp** предназначен для получения списка должностей.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetPositionsApp", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя девять параметров:  
\- _iCurUserID_ \- ID текущего пользователя (целое число).  
\- _sAccessType_ \- тип доступа (строка). Допустимые значения: _"admin"; "manager"; "hr"; "observer"; "auto"._  
\- _arrBossTypesID_ \- массив типов руководителей (массив целых чисел) (необязательный).  
\- _sApplication_ \- код приложения, по которому определяется доступ (строка).   
\- _iCurApplicationID_ \- ID текущего приложения (целое число).  
\- _sXQueryQual_ \- строка для XQuery-фильтра (строка).  
\- _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).  
\- _iTypicalPositions_ \- ID типовой программы (целое число).  
\- _arrReturnData_ \- дополнительные возвращаемые поля (массив строк).      

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень должностей, а также ряд дополнительных атрибутов:  
\- _array_ \- массив должностей (массив объектов).  
     Атрибуты отдельного объекта:  
     _code_ \- код должности (строка).  
     _name_ \- название должности (строка).  
     _org\_name_ \- название организации (строка).  
     _subdivision\_name_ \- название подразделения (строка).  
     _collaborator\_fullname_ \- ФИО сотрудника (строка).  
     _position\_date_ \- дата вступления в должность (дата).  
     _position\_common\_name_ \- название типовой должности (строка).  
     _kpi\_profile\_name_ \- название профиля KPI (строка).  
     _bonus\_profile\_name_ \- название профиля премирования (строка).  
     _knowledge\_profile\_name_ \- название профиля знаний (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetPositionsApp", [iCurUserID, sAccessType, arrBossTypesID, sApplication, iCurApplicationID, sXQueryQual, oCollectionParams, iTypicalPositions, arrReturnData]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
