## GetPersonCollaborators

Метод предназначен для получения списка сотрудников (коллег, руководителей или подчиненных).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetPersonCollaborators", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя восемь параметров:  
     _iPersonID_ \- ID сотрудника (опорный сотрудник) (целое число).  
     _sTypeCollaborator_ \- тип сотрудников, по которому осуществляется выборка (строка). Допустимые значения параметра: _"colleаgues"_ (коллеги по подразделению. Сотрудники того же подразделения что и опорный сотрудник); _"colleagues\_hier"_ (Коллеги по подразделению с иерархией (сотрудники того же и дочерних ему подразделений); _"colleagues\_org"_ (коллеги по организации, сотрудники той же организации); _"colleagues\_boss"_ (коллеги по руководителю, сотрудники, имеющие того же непосредственного рководителя); "bosses" (непосредственные руководители); _"main\_subordinates"_ (непосредственные подчиненные); _"subordinates"_ (непосредственные подчиненные с учетом иерархии (сотрудники, для которых опорный сотрудник является непосредственным руководителем, а также их подчиненные)); _"func\_subordinates"_ (функциональные подчиненные с иерархией, сотрудники, для которых опорный сотрудник является функциональным руководителем, а также их подчиненные); _"all\_subordinates"_ (функциональные и непосредственные подчиненные с иерархией (сотрудники, для которых опорный сотрудник является непосредственным  или функциональным руководителем, а также их подчиненные).  
     _iMaxCnt_ \- максимальное количество выводимых сотрудников в блоке (целое число).  
     _bShowDismiss_ \- показывать уволенных сотрудников (булево) (необязательное). Значение по умолчанию – _false_.  
     _sSearch_ \- критерий поиска (строка) (необязательное).  
     _bAllHier_ \- искать всех руководителей вверх по иерархии (булево) (необязательное). Значение по умолчанию – _false_.  
     _arrBossTypesID_ \- массив ID типов руководителей для поиска для типов func\_subordinates и all\_subordinates (массив целых чисел).  
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект). 

Иерархия в значениях параметра **sTypeCollaborator** учитывается только в структуре подразделений и не поддерживается в личной подчиненности.  
Например, Сотрудник 1 является персонально функциональным руководителем (в личной карточке) Подчиненного 1, а Подчиненный 1 указан персонально функциональным руководителем Подчиненного 2. В этом случае для Сотрудника при показе подчиненных отобразятся только лично его подчиненные (то есть Подчиненный 1), а далее вниз по иерархии персональные подчиненные подчиненных (то есть Подчиненный 2) не отобразятся.

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит список сотрудников (коллег, руководителей или подчиненных), а также ряд дополнительных атрибутов:  
\- _array_ \- массив данных о сотрудниках (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID сотрудника (целое число);  
     _fullname_ – ФИО сотрудника (строка);  
     _position\_name_ – название должности сотрудника (строка);  
     _link_ – относительная ссылка на сотрудника (строка);  
     _image\_url_ – относительная ссылка на изображение сотрудника (строка).  
     _email_ \- электронный адрес сотрудника (строка).  
     _phone_ \- номер телефона сотрудника (строка).  
     _org\_name_ \- название организации (строка).  
     _position\_parent\_name_ \- название подразделения (строка).  
     _birth\_date_ \- дата рождения сотрудника (строка).  
     _age_ \- возраст сотрудника (целое число).  
     _hire\_date_ \- дата приема на работу (дата).  
     _expirience_ \- стаж в компании в месяцах (целое число).  
     _expirience\_level_ \- уровень стажа в компании (строка).  
     _sex_ \- пол сотрудника (строка).  
     _status_ \- статус сотрудника (строка) (например, "Работает", "Уволен").  
     _status\_class_ – цветовое обозначение статуса (строка) (например, "green\_color" (для статуса "Работает"), "red\_color" (для статуса "Уволен")).  
     _tags_ \- строка тэгов (строка).  
     _effectiveness_ \- эффективность сотрудника (строка).  
     _efficiency\_estimation\_id_ \- ID оценки эффективности (целое число).  
     _efficiency\_estimation_ \- оценка эффективности (строка).  
     _development\_potential\_id_ \- ID оценки потенциала (целое число).  
     _development\_potential_ \- оценка потенциала (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetPersonCollaborators", [ iPersonID, sTypeCollaborator, iMaxCnt, bShowDismiss, sSearch, bAllHier, arrBossTypesID, oCollectionParams]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
