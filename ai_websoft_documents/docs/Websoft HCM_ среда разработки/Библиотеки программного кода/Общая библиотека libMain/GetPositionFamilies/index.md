## GetPositionFamilies

Метод **GetPositionFamilies** предназначен для получения списка семейства должностей.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetPositionFamilies", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.  
     Массив включает в себя десять параметров:  
\- _iCurUserID -_ ID текущего пользователя (целое число).  
\- _sAccessType_ \- тип доступа (строка). Допустимые значения: "admin"; "manager"; "hr"; "expert"; "observer"; "reject".  
\- _sApplication_ \- код приложения, по которому определяется доступ (строка).  
\- _iCurApplicationID_ - ID текущего приложения (целое число).  
\- _arrReturnData_ \- дополнительные поля для вывода  (массив строк) (необязательный).  Допустимое значение: _"_positions\_count\_active" (число должностей).  
\- _sFilter_ \- строка для XQuery-фильтра (строка).  
\- _sFulltext_ \- строка для полнотекстового поиска (строка).  
\- _sPositionCommon_ \- единичный выбор из каталога Типовая должность (ID типовой должности в строковом выражении) (строка) (необязательный).  
\- _sTypicalDevelopmentProgram_ \- единичный выбор из каталога Типовая программа развития (ID типовой программы развития в строковом выражении) (строка) (необязательный).  
\- _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень семейства должностей, а также ряд дополнительных атрибутов:  
\- _array_ \- массив семейства должностей (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID семейства должностей (целое число).  
     _code_ \- код семейства должностей (строка).  
     _name_ \- название семейства должностей (строка).  
     _positions\_count_ \- количество типовых должностей в семействе (целое число).  
     _typical\_development\_programs\_count_ \- количество типовых программ развития в семействе (целое число).  
     _job\_transfer\_type\_id_ \- идентификатор направления перевода (строка).  
     _is\_dynamic_ \- признак динамической группы (булево)  
     _modification\_date_ \- дата последнего изменения (дата).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetPositionFamilies", [iPersonID, sAccessType, sApplication, iCurApplicationID, arrReturnData, sFilter, sFullText, sPositionCommon, sTypicalDevelopmentProgram, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
