## AddResponse

Метод **AddResponse** предназначен для добавления отзыва на объект.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "AddResponse", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя четыре параметра:  
     iResponseTypeIDParam - ID типа отзыва (целое число).  
     iPersonID - ID сотрудника, оставляющего отзыв (целое число).  
     arrFormFields - коллекция с полями возврата из формы удаленного действия (массив объектов).  
     oAddParam - параметры выполнения (объект). Параметры объекта: _cur\_user\_id_ - ID текущего пользователя (целое число), _cur\_user_ \- TopElem текущего пользователя (объект XmlElem), _show\_comment_ – нужно ли сохранять комментарий (булево).

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
\- _paragraph_ – текст сообщения о выполнении (строка).   
  
_\- error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
_\- errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "AddResponse", [iResponseTypeIDParam, iPersonID, arrFormFields, oAddParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
