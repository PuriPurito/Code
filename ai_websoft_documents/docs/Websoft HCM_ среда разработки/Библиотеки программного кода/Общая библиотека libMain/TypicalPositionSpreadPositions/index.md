## TypicalPositionSpreadPositions

Метод **TypicalPositionSpreadPositions** предназначен для проставления должностям типовой должности (должностей).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "TypicalPositionSpreadPositions", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
\- _iCurUserID_ \- ID текущего пользователя (целое число).  
\- _arrPosCommonIDs_ \- массив ID типовых должностей (массив целых чисел).  
\- _sCanChange_ \- вид действия при наличии у должности типовой должности (строка). Допустимые значения: _"replace" (Заменять); "skip" (Пропускать)._  
\- _sApplicationCode_ - код приложения (строка).

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
_\- error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
_\- errorText_ – текст ошибки (строка).  
 

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "TypicalPositionSpreadPositions", [iCurUserID, arrPosCommonIDs, sCanChange, sApplicationCode]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
