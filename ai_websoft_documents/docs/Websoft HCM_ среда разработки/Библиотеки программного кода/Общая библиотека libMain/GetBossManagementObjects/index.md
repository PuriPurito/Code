## GetBossManagementObjects

Метод **GetBossManagementObjects** предназначен для получения списка объектов управления руководителя.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetBossManagementObjects", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя шесть параметров:  
\- _iPersonID_ \- ID пользователя (целое число).  
\- _bHierSubdivisions_ – учитывать ли для руководителей подразделения все подразделения вниз по иерархии (булево).  
\- arrObjectTypes - перечень возвращаемых типов объектов (массив объектов).  
\- bAddManagementObjectClearCommand - добавить команду на очистку объекта управления (булево).  
\- _iMaxCnt_ \- максимальное количество записей (целое число).  
\- _bCheckDisbandedSub_ \- нужно ли учитывать расформированные подразделения (необязательный) (булево). Значение по умолчанию - false.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит список объектов управления руководителя, а также ряд дополнительных атрибутов:  
\- _array_ \- массив объектов управления (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID объекта управления (целое число).  
     _name_ – название объекта управления (строка).  
     _type_ – тип объекта управления (строка).  
     _type\_name_ – название типа объекта управления (строка).  
     _parent\_id_ – ID родительского объекта для объекта управления (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetBossManagementObjects", [iPersonID, bHierSubdivisions, arrObjectTypes, bAddManagementObjectClearCommand, iMaxCnt, bCheckDisbandedSub]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
