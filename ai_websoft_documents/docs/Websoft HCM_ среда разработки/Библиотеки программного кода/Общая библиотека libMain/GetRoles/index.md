## GetRoles

Метод **GetRoles** предназначен для получения связанного списка (дерева) категорий по объекту или имени каталога и корневой категории. 

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetRoles", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _sSourceParam_ \- имя каталога или ID объекта каталога (строка).  
     _iRoleIDParam_ \- ID корневой категории, от которой строится набор (root id) (целое число).  
     _bIncludeSelf_ \- добавлять в набор также и корневую категорию (булево) (необязательный). По умолчанию – _false_. 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит связанный список категорий, а также ряд дополнительных атрибутов:  
\- result \- связанный список категорий (массив объектов).  
     Атрибуты отдельного объекта:  
     id – ID категории (целое число).  
     parent\_id – родительская категория (целое число).  
     name – наименование (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetRoles", [sSourceParam, iRoleIDParam, bIncludeSelf]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
