## SetCollaboratorCategory

Метод **SetCollaboratorCategory** предназначен для отнесения сотрудника к категории.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "SetCollaboratorCategory", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iCollId_ \- ID сотрудника (целое число).  
     _sId_ \- ID категории в текстовом формате (строка).  
     _sSetRole_ \- режим отнесения (строка). Допустимые значения: "replace" (только одна категория (добавить в заданную категорию и удалить из остальных)); "add" (может быть указано несколько категорий (только добавить в заданную категорию)).

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
_\- error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
_\- errorText_ – текст ошибки (строка).  
 

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "SetCollaboratorCategory", [iCollId, sId, sSetRole]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
