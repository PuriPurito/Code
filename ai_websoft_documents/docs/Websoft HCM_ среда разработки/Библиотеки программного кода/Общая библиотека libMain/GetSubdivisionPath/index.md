## GetSubdivisionPath

Метод **GetSubdivisionPath** предназначен для получения списка подразделений для руководителя от текущего до корня дерева подразделений (вверх по иерархии).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetSubdivisionPath", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID руководителя (целое число).  
     _bSortFromRoot_ \- направление сортировки списка подразделений (булево) (_true_ \- сортировка списка от корня до текущего подразделения (сверху вниз); _false_ - сортировка списка от текущего подразделения к корню (снизу вверх)). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень подразделений до корня дерева подразделений, а также ряд дополнительных атрибутов:  
\- _array_ \- массив подразделений (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID подразделения (целое число).  
     _name_ \- наименование подразделения (строка).  
     _link_ \- ссылка на карточку подразделения (строка).  
     _parent\_id_ \- ID родительского подразделения (строка).  
     _is\_disbanded_ \- признак расформированности подразделения (булево).  
     _position_ – порядковый номер подразделения в списке (целое число).  
     _root\_id_ \- ID корневого подразделения (целое число).  
     _root\_name_ \- наименование корневого подразделения (строка).  
     _root\_position_ – порядковый номер поддерева (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetSubdivisionPath", [iPersonID, bSortFromRoot]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
