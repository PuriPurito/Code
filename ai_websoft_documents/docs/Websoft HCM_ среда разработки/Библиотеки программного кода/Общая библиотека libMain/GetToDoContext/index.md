## GetToDoContext

Метод предназначен для получения контекста текущих дел (задач).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetToDoContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя 16 параметров:  
      _iPersonID_ \- ID сотрудника (целое число);  
      _iDaysToShow_ \- количество календарных дней, в течение которых задача попадает в список текущих дел **ToDo** (целое число). Например, если будет указано значение _iDaysToShow=30_, то отбираются задачи на 30 дней вперед (а также просроченные);  
      _iCriticalDays_ \- количество дней до отнесения задачи к категории срочных (целое число);  
      _bShowCourse_ \- показывать назначенные курсы (булево);  
      _bShowTest_ \- показывать назначенные тесты (булево);  
      _bShowEventConfirmation_ \- показывать напоминания о подтверждении участия в мероприятии (булево);  
      _bShowResponseLeaving_ \- показывать напоминания оставить отзыв (булево);  
      _bShowPolls_ \- показывать опросы (булево);  
      _bShowRequests_ \- показывать заявки на согласование (булево);  
      _bShowAssessmentApraises_ \- показывать оценочные процедуры (булево);  
      _bShowLibraryMaterials_ \- показывать материалы библиотеки, с которыми необходимо ознакомиться (булево);  
      _bShowChatInvites_ \- показывать новые сообщения в чате (булево);  
      _bShowTasks_ \- показывать задачи (булево);  
      _bShowAcquaints_ \- показывать ознакомления (булево);  
      _bShowLearningTasks_ \- показывать выполнение заданий (булево);  
      _sSearch_ \- строка для поиска (критерий поиска) (строка).

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит контекст текущих дел, а также ряд дополнительных атрибутов:  
\- _context_ \- контекст задач (объект **ToDoContext**).  
     Атрибуты объекта:  
     _exceeded_ – количество просроченных задач (целое число);  
     _critical_ – количество срочных задач (целое число);  
     _future_ – количество будущих задач (целое число);  
     _count_ – общее количество задач (целое число);  
     _courses_ – количество задач типа Курс (целое число);  
     _tests_ – количество задач типа Тест (целое число);  
     _events_ – количество задач типа Мероприятие (целое число);  
     _acquaints_ – количество задач типа Ознакомление (целое число);  
     _requests_ – количество задач типа Заявка (целое число).     

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_  
      `_RESULT = tools.call_code_library_method ("libMain", "GetToDoContext", [iPersonID, iDaysToShow, iCriticalDays, bShowCourse, bShowTest, bShowEventConfirmation, bShowResponseLeaving, bShowPolls, bShowRequests, bShowAssessmentApraises, bShowLibraryMaterials, bShowChatInvites, bShowTasks, bShowAcquaints, bShowLearningTasks, sSearch]).context;_`
