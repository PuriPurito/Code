## GetRequestTypesByRoles

Метод **GetRequestTypesByRoles** предназначен для получения списка типов заявок по категориям.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetRequestTypesByRoles", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _aRolesID_ \- ID категорий (массив целых чисел) (необязательный). Если список пуст, то будут отобраны все типы заявок без учета категорий.   
     _bChilds_ \- учитывать ли дочерние категории (булево) (необязательный). При указании значения _Да_ будет отобран список всех типов заявок по указанным категориям и по категориям, являющимся их дочерними. По умолчанию принимается значение _Нет_.  
     _bIgnoreRoles_ \- возвращать все заявки (без учета категорий) (булево) (необязательный). При выборе значения _Да_ будут возвращаться все типы заявок без учета категорий. По умолчанию принимается значение _Нет_.  
     _bQuasyReqToEnd_ \- добавляются ли квази-заявки в конец списка (булево) (необязательный). По умолчанию принимается значение _Нет_.  
     _QuasyReqs_ \- набор дополнительных квази-заявок (массив объектов). Объекты, входящие в массив, имеют следующие параметры: _name_ – наименование заявки (строка); _img\_url_ – URL изображения (аватара) заявки (строка); _ra\_id_ – ID удаленного действия-обработчика (целое число); _ra\_param_ – параметры удаленного действия в формате JSON (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень типов заявок, а также ряд дополнительных атрибутов:  
\- _array_ \- массив типов заявок (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID типа заявки (целое число).  
     _name_ \- название типа заявки (строка).  
     _img\_url_ \- относительная ссылка на изображение (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetRequestTypesByRoles", [aRolesID, bChilds, bIgnoreRoles, bQuasyReqToEnd, QuasyReqs]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
