## GetObjectsInSameRole

Метод **GetObjectsInSameRole** предназначен для получения списка объектов из той же категории, что и указанный.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetObjectsInSameRole", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя четыре параметра:  
     _iObjectIDParam_ \- ID текущего объекта (целое число).  
     _bAndSelf_ \- добавить ли в результат текущий объект (булево).   
     _iMaxQuantity_ \- максимальное общее количество получаемых записей (целое число).  
     _oCollectionParams_ \- набор интерактивных параметров выборки (объект). Параметры объекта: filters (фильтры), distincts (дополнительная входная информация), paging (пейджинг).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень объектов из той же категории, что и указанный, а также ряд дополнительных атрибутов:  
\- _array_ \- коллекция объектов в категории (массив объектов).  
     Атрибуты отдельного элемента массива:  
     _id_ – ID объекта (целое число).  
     _name_ – наименование объекта (строка).  
     _image\_url_ – ссылка на изображение объекта (строка).  
     _link_ – ссылка на карточку объекта (строка).  
     _comment_ – комментарий к объекту (строка).  
     desc – описание объекта (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetObjectsInSameRole", [iObjectIDParam, bAndSelf, iMaxQuantity, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
