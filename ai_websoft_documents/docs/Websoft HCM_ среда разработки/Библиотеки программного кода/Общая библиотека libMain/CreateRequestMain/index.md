## CreateRequestMain

Метод **CreateRequestMain** предназначен для создания заявки.

Примечание. Данный метод используется, начиная с версии 2022.3 вместо метода **CreateRequest**. С появлением метода **CreateRequestMain** метод **CreateRequest** считается устаревшим и не рекомендуется к использованию. 

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "CreateRequestMain", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя шесть параметров:  
     _iRequestTypeID_ \- ID типа заявки (целое число).  
     _teRequestType_ \- TopElem карточки типа заявки (объект XmlDoc) (необязательный).  
     _oSourceParam_ \- JSON объект с набором полей (объект JSON) (необязательный). Объект _oSourceParam_ содержит настраиваемые поля и следующие атрибуты: _is\_group_ \- является ли заявка групповой (булево); _SelectedPersons_ - идентификаторы сотрудников, входящих в группу (через точку с запятой) (строка); _selected\_object\_id_ - ID объекта заявки (целое число); _portal\_comment_ - комментарий заявки (строка).  
     _iPersonID_ – ID сотрудника (целое число).  
     _tePerson_ \- TopElem карточки сотрудника (объект XmlDoc) (необязательный).  
     _docNewRequest_ \- Doc новой карточки заявки (документ) (необязательный). Если данный параметр отсутствует, то создается новый документ.  

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
\- _doc\_request_ \- документ заявки.  
_\- error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
_\- errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "CreateRequestMain", [iRequestTypeID, teRequestType, oSourceParam, iPersonID, tePerson, docNewRequest]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
