## GetLearningTasks

Метод **GetLearningTasks** предназначен для получения списка заданий.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetLearningTasks", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя девять параметров:  
\- _iPersonID_ \- ID текущего пользователя (целое число).  
\- _bCheckAccess_ \- проверять ли права доступа (булево) (необязательный). Значение по умолчанию - false.  
\- _sAccessType_ \- тип доступа (строка). Допустимые значения: "admin"; "manager"; "hr"; "expert"; "observer"; "reject".  
\- _sApplication_ \- код приложения, по которому определяется доступ (строка).  
\- _iCurApplicationID -_ ID текущего приложения (целое число).  
\- _arrReturnData_ \- код показателя, который будет рассчитываться в результатах (целое число). Доступные значения: 10 - Общее количество назначений задания, 20 - Количество активных назначений задания, 30 - Количество завершенных назначений задания, 40 - Количество просроченных назначений заданий, 50 - Дата последнего назначения задания.  
\- _sFilter_ \- строка для XQuery-фильтра (строка).  
\- _sFullText_ \- строка для полнотекстового поиска (строка).  
\- _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень заданий, а также ряд дополнительных атрибутов:  
\- _array_ \- массив заданий (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID задания (целое число).  
     _code_ \- код задания (строка).  
     _name_ \- название задания (строка).  
     _desc_ \- описание задания (строка).  
     _comment_ \- комментарий к заданию (строка).  
     _counts\_all\_learning\_task_ \- общее количество назначений задания (количество назначений данного задания с любым статусом, кроме _Отменен_) (целое число).  
     _counts\_active\_learning\_task_ \- количество активных назначений задания (количество назначений данного задания со статусами _Назначен, В работе, Просмотрен, Оценивается_) (целое число).  
     _counts\_success\_learning\_task_ \- количество завершенных назначений задания (количество назначений данного задания со статусами _Пройден, Не пройден_) (целое число).  
     _counts\_expired\_learning\_task_ \- количество просроченных назначений заданий (количество назначений данного задания, выполнение которых было просрочено) (целое число). Для статусов _Назначен, В работе, Просмотрен, Оценивается_ назначенное задание просрочено, если поле _Планируемая дата завершения_ заполнено и значение в нем меньше текущей даты. Для статусов _Пройден, Не пройден_ назначенное задание просрочено, если включен флажок _Просрочено_.   
     _date\_assignment_ \- дата последнего назначения задания (дата).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetLearningTasks", [iPersonID, bCheckAccess, sAccessType, sApplication, iCurApplicationID, arrReturnData, sFilter, sFullText, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
