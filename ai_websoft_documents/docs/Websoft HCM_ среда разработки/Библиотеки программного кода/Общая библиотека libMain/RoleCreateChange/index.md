## RoleCreateChange

Метод **RoleCreateChange** предназначен для создания/изменения категории.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "RoleCreateChange", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя девять параметров:  
     _iRoleID_ \- ID категории для изменения (целое число).  
     _iParentRoleID_ \- ID родительской категории (целое число).  
     _sTargetCatalog_ \- название целевого каталога категории (строка).  
     _sName_ \- название категории (строка).  
     _sCode_ \- код категории (строка).  
     _iResourceId_ \- ID ресурса изображения (целое число).  
     _arrExpertIDs_ \- массив ID экспертов (массив целых чисел).  
     _sComment_ \- текст комментария (строка).  
     _sDesc_ \- текст описания (строка). 

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
\- _role\_id_ – ID сформированной категории (целое число).  
  
_\- error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
_\- errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "RoleCreateChange", [iRoleID, iParentRoleID, sTargetCatalog, sName, sCode, iResourceId, arrExpertIDs, sComment, sDesc ]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
