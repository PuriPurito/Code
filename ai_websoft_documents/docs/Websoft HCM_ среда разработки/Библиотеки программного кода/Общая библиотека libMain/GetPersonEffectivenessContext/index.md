## GetPersonEffectivenessContext

Метод **GetPersonEffectivenessContext** предназначен для определения контекста эффективности сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetPersonEffectivenessContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _arrAssessmentAppraiseTypes_ \- массив типов оценки (массив строк). По умолчанию – _'activity\_appraisal'_. 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит контекст эффективности сотрудника, а также ряд дополнительных атрибутов:  
\- _context_ \- контекст эффективности сотрудника (объект).  
     Атрибуты объекта:  
     _is\_high\_effectiveness_ – является ли сотрудник высокоэффективным (булево).  
     _effectiveness\_level_ – уровень эффективности сотрудника (целое число). Если оценок у сотрудника нет, то данное поле не заполняется.

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetPersonEffectivenessContext", [iPersonID, arrAssessmentAppraiseTypes]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
