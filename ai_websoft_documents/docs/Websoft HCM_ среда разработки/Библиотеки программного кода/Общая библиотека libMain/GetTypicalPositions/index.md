## GetTypicalPositions

Метод **GetTypicalPositions** предназначен для получения списка типовых должностей.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetTypicalPositions", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя одиннадцать параметров:  
\- _iPersonID -_ ID текущего пользователя (целое число).  
\- _sAccessType_ \- тип доступа (строка). Допустимые значения: _"admin"; "manager"; "hr"; "expert"; "observer"; "reject"._  
\- _sApplication_ \- код приложения, по которому определяется доступ (строка).  
\- _sApplicationID_ \- ID текущего приложения (целое число).  
\- _sState_ \- статус (строка). Допустимые значения: _"active" (Действующая), "plan" (Планируется), "archive" (Архив)._  
\- _arrReturnData_ \- число должностей (целое число).  
\- _sFilter_ \- строка для XQuery-фильтра (строка).   
\- _sFullText_ \- строка для полнотекстового поиска (строка).   
\- _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).  
\- _sPositionFamilys_ \- единичный выбор из каталога Семейство должностей (ID семейства должностей в строковом выражении) (строка) (необязательный).  
\- _sTypicalDevelopmentProgram_ \- единичный выбор из каталога Типовая программа развития (ID типовой программы развития в строковом выражении) (строка) (необязательный).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень типовых должностей, а также ряд дополнительных атрибутов:  
\- _typical\_positions_ \- массив типовых должностей (массив объектов).  
     Атрибуты отдельного элемента массива:  
     _id_ – ID типовой должности (целое число).  
     _code_ – код типовой должности (строка).  
     _name_– название типовой должности (строка).  
     _typical\_development\_programs\_count_ \- количество типовых программ развития у типовой должности (целое число).  
     _positions\_count_ \- количество должностей, связанных с типовой должностью (целое число).  
     _job\_transfer\_type\_id_ \- идентификатор направления перевода (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetTypicalPositions", [iPersonID, sAccessType, sApplication, iCurApplicationID, sState, arrReturnData, sFilter, sFullText, oCollectionParams, sPositionFamilys, sTypicalDevelopmentProgram]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
