## IsBossCurUser

Метод **IsBossCurUser** предназначен для определения, является ли текущий сотрудник руководителем текущего объекта или руководителем вообще.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "IsBossCurUser", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iCurUserIDParam_ \- ID текущего пользователя, проверяемого на руководителя (целое число).  
     _iObjectIDParam_ \- ID объекта, для которого текущий пользователь проверяется на руководство (необязательный) (целое число).  
     _arrBossTypesID_ \- коллекция ID типов руководителя (необязательный) (массив целых чисел).

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
\- _flag_ – возвращаемый признак (булево). Возможные значения – true (сотрудник является руководителем) и false (сотрудник не является руководителем). По умолчанию устанавливается значение этого параметра - false.  
  
_\- error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
_\- errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "IsBossCurUser", [iCurUserIDParam, iObjectIDParam, arrBossTypesID ]);_`
