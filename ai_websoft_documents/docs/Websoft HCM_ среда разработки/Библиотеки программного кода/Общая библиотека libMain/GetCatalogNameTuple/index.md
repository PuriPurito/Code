## GetCatalogNameTuple

Метод **GetCatalogNameTuple** предназначен для формирования строки вида "name 1, name 2, и еще N" .

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetCatalogNameTuple", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _arrIDs_ \- Массив ID записей справочника-источника (массив целых чисел).  
     _iNum_ \- количество выводимых в кортеж имен (целое число). По умолчанию – 2.  
     _sFieldName_ \- имя поля каталога, выводимого в кортеж (строка). По умолчанию - помеченное как "disp\_name" для данного каталога.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит результирующую строку, а также ряд дополнительных атрибутов:  
      Атрибуты объекта:  
\- paragraph - результирующее выражение вида "name 1, name 2, и еще N" (строка).  
  
\- _result_ – результат использования метода (целое число).  
\- _name_ – наименование справочника-источника (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetCatalogNameTuple", [arrIDs, iNum, sFieldName]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
