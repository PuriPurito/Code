## SubdivisionGroupUpdate

Метод **SubdivisionGroupUpdate** предназначен для обновления указанных групп подразделений.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "SubdivisionGroupUpdate", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
\- _arrSubdivGroupIDs_ \- массив ID организаций (массив целых чисел).  
\- _sAddType_ \- тип обновления подразделений в группе (строка). Допустимые значения: _"replace" (Заменить); "add" (Добавить)._ 

_Возвращаемое значение:_  
      Тип:  **Объект**. Содержит ряд атрибутов:  
\- _action\_result_ – информация о результате вызова метода (объект) (в том числе: command – команда вывода информации о результате (строка) (например, "alert", "display\_form", "close\_form"); другие параметры зависят от значения параметра command).  
  
_\- error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
_\- errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "SubdivisionGroupUpdate", [arrSubdivGroupIDs, sAddType]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
