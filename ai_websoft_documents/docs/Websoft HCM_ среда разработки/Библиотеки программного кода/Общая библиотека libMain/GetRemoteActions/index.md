## GetRemoteActions

Метод **GetRemoteActions** предназначен для получения коллекции операций/удаленных действий для сотрудника по объекту.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libMain", "GetRemoteActions", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iPersonIDParam_ \- ID сотрудника (целое число).  
     _iObjectIDParam_ \- ID объекта (целое число).  
     _bRemoteActionOnly_ \- возвращать только удаленные действия (булево) (необязательный). По умолчанию – _true_.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит коллекцию операций/удаленных действий, а также ряд дополнительных атрибутов:  
\- _result_ \- коллекция операций и (или) удаленных действий (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID операции (целое число).  
     _operation_ – код операции (строка).  
     _name_ – наименование операции (строка).  
     _ra\_id_ – ID удаленного действия (целое число).  
     _ra\_name_ – наименование удаленного действия (строка).  
     _ra\_params_ – JSON-строка с набором значений параметров удаленного действия (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libMain", "GetRemoteActions", [iPersonIDParam, iObjectIDParam, bRemoteActionOnly]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
