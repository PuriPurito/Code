## Общая точка входа для получения параметров (бизнес) процесса из библиотеки программного кода и приложений

Реализован механизм сопоставления параметров процесса, находящихся в библиотеке программного кода, с параметрами приложений, аналогичными по смыслу и по использованию.

Точка входа остается прежней — библиотека программного кода. Для получения значения параметра следует использовать функцию _tools.get\_process\_param()_. Функция принимает два аргумента: _код/ID библиотеки программного кода_ и _имя требуемого параметра_.

 В библиотеку программного кода добавлены настройки, позволяющие получать из указанного в этих настройках приложения значения соответствующих параметров:

В верхнем списке перечислены приложения, в которых могут быть параметры соответствующей тематики процесса. 

В нижнем соответствия имен параметров из библиотеки и приложений перечисляются поименно.

Алгоритм получения значения параметра следующий:

1.  Параметр прежде всего ищется по имени в библиотеке.
2.  Если в библиотеке такого параметра нет, он ищется во всех перечисленных в настройке приложениях.
    1.  При этом, если имя переданного в функцию _tools.get\_process\_param()_ параметра разделено через точку, то первая часть считается кодом приложения и поиск параметра с указанным именем идет только в приложении с этим кодом
    2.  Если среди связанных приложений нет приложения с этим кодом, то параметр ищется во всех приложениях
3.  Если в библиотеке такой параметр указан, смотрится не упомянут ли он в маппинге (соответствии) параметров.
    1.  Если упомянут, берется значение параметра с именем, указанным в найденном соответствии из приложения, указанного в найденном соответствии.
    2.  Если соответствие не найдено или в целевом приложении не найден/не задан указанный в соответствии параметр — возвращается значение параметра библиотеки
