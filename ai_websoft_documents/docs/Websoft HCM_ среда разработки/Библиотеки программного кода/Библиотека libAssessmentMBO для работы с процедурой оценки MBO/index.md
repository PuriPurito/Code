## Библиотека libAssessmentMBO для работы с процедурой оценки MBO

В настоящем разделе описывается **библиотека для работы с процедурой оценки MBO** (библиотека программного кода **libAssessmentMBO)**. Указанная библиотека регистрируется в разделе **Дизайнер – Библиотеки программного кода – libAssessmentMBO**.  
  
MBO расшифровывается как управление по целям (англ. ****Management**** By ****Objectives****). Подробнее о процедуре оценки MBO – см. здесь.

Примечание - Библиотека программного кода **libAssessmentMBO** на данный момент не предназначена для публикации через внешний интерфейс API.
