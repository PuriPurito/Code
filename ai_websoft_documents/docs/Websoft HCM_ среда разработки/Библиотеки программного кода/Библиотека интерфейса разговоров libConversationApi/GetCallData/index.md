## GetCallData

Метод **GetCallData** предназначен для получения расширенных данных о звонке.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "GetCallData", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект). В состав объекта входят следующие параметры: call\_id – ID звонка (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит расширенные данные о звонке, а также ряд дополнительных атрибутов:

\- _call\_id_ – ID звонка (целое число).  
\- _conversation\_id_ – ID разговора (целое число).  
\- _name_ – название звонка (строка).  
\- _start\_date_ – дата начала звонка (дата).  
\- _end\_date_ – дата завершения звонка (дата).  
\- _plan\_start\_date_ – планируемая дата начала звонка (дата).  
\- _plan\_end\_date_ – планируемая дата завершения звонка (дата).  
\- _duration_ – продолжительность в миллисекундах (целое число).  
\- _state\_id_ – ID статуса звонка (строка).  
\- _participants_ – сотрудники, принимающие участие в звонке (массив объектов).   
     Атрибуты объекта:  
     _id_ – ID участника (целое число).   
     _fullname_ – ФИО участника (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "GetCallData", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
