## HideConversationMessages

Метод **HideConversationMessages** предназначен для сокрытия сообщений разговора.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "HideConversationMessages", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект). В состав объекта входят следующие параметры: conversation\_id – ID разговора (целое число); block\_message\_id – ID блока сообщений (целое число); message\_id – ID сообщения (целое число); delete\_only\_for\_yourself – удалять ли отображение сообщения только у себя (булево); messages\_id - массив данных о сообщениях (если их несколько) (массив объектов) (состав отдельного объекта: id – ID сообщения (целое число); block\_message\_id – ID блока сообщений (целое число)). 

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _conversation\_id_ – ID разговора (целое число).  
\- _name_ – название разговора (строка).  
\- _state\_id_ – ID статуса разговора (строка).  
\- _icon\_url_ – ссылка на изображение ярлыка (иконки) (строка).  
\- _participants_ – массив ID участников разговора (массив целых чисел).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "HideConversationMessages", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
