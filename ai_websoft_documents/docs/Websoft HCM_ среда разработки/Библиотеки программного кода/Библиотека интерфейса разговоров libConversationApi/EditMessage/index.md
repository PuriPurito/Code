## EditMessage

Метод **EditMessage** предназначен для редактирования сообщения.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "EditMessage", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _oActionParam_ \- входные параметры функции (объект). В состав объекта входят следующие параметры: conversation\_id – ID разговора (целое число); message\_text – текст сообщения (строка); message\_id – ID сообщения в текстовом формате (строка); block\_message\_id – ID блока сообщения (целое число); files – массив ID файлов (массив целых чисел); button\_code – код кнопки (строка); message\_recipients – массив ID адресатов (массив целых чисел); disp\_roles – массив ролей (массив строк); forward – массив пересылаемых сообщений (массив объектов); conversation\_ids – массив ID разговоров (массив целых чисел); reply – ответ на сообщение (объект).  
     _sWebsocketID_ – ID сокета в текстовом формате (строка).

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- message\_id – ID сообщения в текстовом формате (строка).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "EditMessage", [oActionParam, sWebsocketID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
