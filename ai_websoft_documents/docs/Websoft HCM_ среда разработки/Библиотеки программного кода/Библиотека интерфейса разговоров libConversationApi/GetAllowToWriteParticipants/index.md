## GetAllowToWriteParticipants

Метод **GetAllowToWriteParticipants** предназначен для получения списка участников разговора, которым разрешена запись в чат.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "GetAllowToWriteParticipants", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект). В состав объекта входят следующие параметры: action - действие (строка); conversation\_id – ID разговора (целое число); page\_num – номер страницы (целое число); page\_size – размер страницы (целое число); search\_fullname – критерий полнотекстового поиска по ФИО сотрудников в формате XQuery для отбора (строка); user\_ids - массив ID пользователей (массив целых чисел). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень участников разговора, которым разрешена запись в чат, а также ряд дополнительных атрибутов:  
\- _collaborators_ \- массив сотрудников (массив объектов).  
     Атрибуты объекта:  
     _is\_filtered_ – результат отфильтрован (булево).  
     _total_ – общее количество (целое число).  
     _collaborators_ – участники разговора, которым выдается разрешение записи в чат (массив объектов) (состав отдельного объекта: id – ID сотрудника (целое число); fullname – ФИО сотрудника (строка); position\_id – ID должности (целое число); position\_name – название должности (строка); org\_id – ID организации (целое число); org\_name – название организации (строка); email – электронная почта (строка); phone – телефон (строка); birth\_date – дата рождения (дата); icon\_url – ссылка на изображение ярлыка (иконки) (строка); selectable – доступна ли учетная запись для выбора (булево); last\_activity\_date – дата последней активности (дата); online – находится ли в настоящее время пользователь онлайн (булево); active\_call – участвует ли в настоящее время пользователь в звонке (булево); comment – комментарий (строка); operations – доступные действия (массив строк)).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "GetAllowToWriteParticipants", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
