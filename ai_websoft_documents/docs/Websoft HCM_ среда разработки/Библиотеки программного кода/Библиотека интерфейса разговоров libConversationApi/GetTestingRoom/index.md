## GetTestingRoom

Метод **GetTestingRoom** предназначен для получения данных для тестовой комнаты в mediasoup..

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "GetTestingRoom", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект).  

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит контекст данных для тестовой комнаты в mediasoup, а также ряд дополнительных атрибутов:  
\- room\_id – ID комнаты (строка).   
\- ticket\_id – ID тикета (строка).  
\- ws\_media\_service\_url – ссылка на медиасервер (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "GetTestingRoom", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
