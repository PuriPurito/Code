## SetPersonState

Метод **SetPersonState** предназначен для обновления настроек пользователя в интерфейсе разговоров.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "SetPersonState", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект). В состав объекта входит следующий параметр: settings – настройки пользователя (объект) (подробнее см.: **GetPersonState**).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит контекст обновленных настроек пользователя в интерфейсе разговоров, а также ряд дополнительных атрибутов:  
\- settings – настройки пользователя (объект).  Состав объекта setting соответствует указанному в статье, посвященной функции **GetPersonState**.

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "SetPersonState", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
