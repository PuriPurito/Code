## GetActivityParticipants

Метод **GetActivityParticipants** предназначен для получения данных по участию сотрудников в разговоре (данных по активности).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "GetActivityParticipants", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект). В состав объекта входят следующие параметры: conversation\_id – ID разговора (целое число); participants – массив ID участников (массив целых чисел). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень данных по участию сотрудников в разговоре, а также ряд дополнительных атрибутов:  
\- collaborators - массив сотрудников-участников разговора (массив объектов).  
     Атрибуты отдельного объекта:  
     id – ID сотрудника (целое число).  
     last\_activity\_date – дата последней активности (дата).  
     online – находится ли в настоящее время пользователь онлайн (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "GetActivityParticipants", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
