## CreateConversation

Метод **CreateConversation** предназначен для создания разговора.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "CreateConversation", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект). В состав объекта входят следующие параметры: action\_type - тип действия (целое число); title - заголовок (строка); conversation\_id – ID разговора (целое число); params - параметры разговора (объект).

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _middle\_action_ \- промежуточные действия (строка).  
\- _action\_result_ \- результат действия (объект). В состав объекта входят следующие параметры: type - тип действия (целое число); message - сообщение (строка); buttons - информация о кнопках (массив объектов).  
\- _conversation\_data_ – данные разговора (объект). В состав объекта входят следующие параметры: id – ID разговора (целое число); name – название разговора (строка); state\_id – статус разговора (строка); active\_call – имеется ли активный звонок (булево); conversation\_state – статус в разговоре (строка); open\_additional\_info – открыта ли панель дополнительной информации (булево); position\_priority – приоритет позиции (целое число); list\_css – стиль CSS (строка); icon\_url – ссылка на изображение разговора (строка); format\_id – ID формата разговора (строка); is\_public – является ли разговор публичным (булево); object\_id – ID объекта, по которому создан разговор (строка); object\_name – название объекта, по которому создан разговор (строка); object\_type – тип объекта, по которому создан разговор (строка); last\_unread\_message – последнее сообщение в разговоре (строка); last\_unread\_message\_id – ID последнего сообщения в разговоре (строка); last\_unread\_message\_is\_file – имеется ли файл в последнем сообщении (булево); last\_unread\_message\_date – дата последнего сообщения в разговоре (дата); new\_reaction – имеется ли непросмотренная реакция на сообщение пользователя (булево); disp\_roles – роли в разговоре (объект); unread\_message\_count – количество непрочитанных сообщений в разговоре (целое число); timestamp - временная метка актуальности непрочитанных/последних сообщений (целое число).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "CreateConversation", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
