## GetReactionDetails

Метод **GetReactionDetails** предназначен для получения детализации реакций на сообщение.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "GetReactionDetails", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект). В состав объекта входят следующие параметры: conversation\_id – ID разговора (целое число); block\_message\_id – ID блока сообщений (целое число); message\_id – ID сообщения в текстовом формате (строка); reaction\_id – ID реакции пользователя в текстовом формате (строка); page\_num – номер страницы (целое число); page\_size – размер страницы (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит детализацию реакций на сообщение, а также ряд дополнительных атрибутов:  
\- _conversation\_id_ – ID разговора (целое число).  
\- _message\_id_ – ID сообщения в текстовом формате (строка).  
\- _reaction\_id_ – ID реакции в текстовом формате (строка).  
\- _has\_more_ – есть еще записи (булево).  
\- _persons_ – сотрудники, отреагировавшие на сообщения разговора (массив объектов).  
     Атрибуты отдельного объекта:  
     _person\_fullname_ – ФИО сотрудника, добавившего реакцию (строка).  
     _person\_icon\_url_ – ссылка на значок (иконку) ярлыка сотрудника (строка).  
     _person\_id_ – ID сотрудника (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "GetReactionDetails", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
