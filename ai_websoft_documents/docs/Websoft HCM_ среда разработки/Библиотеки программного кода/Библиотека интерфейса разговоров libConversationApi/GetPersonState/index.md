## GetPersonState

Метод **GetPersonState** предназначен для получения настроек пользователя в интерфейсе разговоров.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "GetPersonState", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Метод вызывается без аргументов. Для данного метода используется пустой массив аргументов.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит контекст настроек пользователя в интерфейсе разговоров, а также ряд дополнительных атрибутов:  
\- settings – настройки пользователя (объект).   
     Атрибуты объекта:  
     _ui_ \- данные пользовательского интерфейса (объект). В состав объекта могут входить следующий параметр: theme - тема интерфейса (строка).  
     _autostatus_ \- показ автостатуса (булево).  
     _state\_id_ \- ID статуса (строка).   
     _conversation_ \- настройки разговора (объект). В состав объекта могут входить следующие параметры:  confirm\_deletion (булево), open\_aux (булево), reverse\_panels (булево), scroll\_to\_new (булево), page\_size (целое число), page\_size\_calls (целое число), page\_size\_cnv (целое число), page\_size\_files (целое число),  page\_size\_links (целое число), page\_size\_media (целое число), page\_size\_peers (булево).   
     _media_ \- настройки медиа (объект). В состав объекта могут входить следующий параметр: ring (строка). 

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "GetPersonState", []);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
