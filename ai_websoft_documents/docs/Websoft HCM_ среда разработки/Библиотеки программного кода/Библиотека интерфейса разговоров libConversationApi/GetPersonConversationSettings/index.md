## GetPersonConversationSettings

Метод **GetPersonConversationSettings** предназначен для получения настроек пользователя в интерфейсе разговоров.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "GetPersonConversationSettings", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Метод вызывается без аргументов. Для данного метода используется пустой массив аргументов.  
 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит настройки пользователя в интерфейсе разговоров, а также ряд дополнительных атрибутов:  
\- _settings_ – настройки разговора (объект). 

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "GetPersonConversationSettings", []);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
