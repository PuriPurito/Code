## GetStates

Метод **GetStates** предназначен для получения списка статусов разговора.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "GetStates", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект). 

Примечание - Состав входных параметров находится в стадии разработки. 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень статусов разговора, а также ряд дополнительных атрибутов:  
\- _states_ \- массив статусов разговора (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID статуса разговора в текстовом формате (строка).  
     _name_ \- название статуса разговора (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "GetStates", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
