## GetUnreadMessageCount

Метод **GetUnreadMessageCount** предназначен для получения данных по непрочитанным сообщениям.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "GetUnreadMessageCount", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект). В состав объекта входят следующие параметры: conversation\_id – id разговора (целое число); object\_type - список типов объектов (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень данных по непрочитанным сообщениям, а также ряд дополнительных атрибутов:  
\- _unread\_message\_count_ – количество непрочитанных сообщений (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "GetUnreadMessageCount", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
