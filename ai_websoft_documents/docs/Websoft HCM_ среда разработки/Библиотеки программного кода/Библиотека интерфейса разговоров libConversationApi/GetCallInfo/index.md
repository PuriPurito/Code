## GetCallInfo

Метод **GetCallInfo** предназначен для получения информации о звонке.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "GetCallInfo", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект). В состав объекта входят следующие параметры: call\_id – ID звонка (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию о звонке, а также ряд дополнительных атрибутов:  
\- _call\_id_ – ID звонка (целое число).  
\- _call\_info_ – данные по звонку (объект).  
     Атрибуты объекта:  
     _participants_ – сотрудники, принимающие участие в звонке (массив объектов) (состав отдельного объекта: id – ID участника (целое число); fullname – ФИО участника (строка); online – участвует ли в настоящее время пользователь в звонке онлайн (булево); entered – входил ли пользователь в состав участников звонка (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "GetCallInfo", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
