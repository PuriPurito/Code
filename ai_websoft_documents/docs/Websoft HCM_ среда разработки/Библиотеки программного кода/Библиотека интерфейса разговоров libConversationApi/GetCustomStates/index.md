## GetCustomStates

Метод **GetCustomStates** предназначен для получения списка пользовательских статусов типа разговора.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "GetCustomStates", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект). В состав объекта входят следующие параметры: conversation\_type\_id – ID типа разговора (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень пользовательских статусов типа разговора, а также ряд дополнительных атрибутов:  
\- _custom\_states_ \- пользовательские статусы типа разговора (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID пользовательского статуса типа разговора в текстовом формате (строка).  
     _name_ \- название пользовательского статуса типа разговора (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "GetCustomStates", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
