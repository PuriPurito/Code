## GetConversationFiles

Метод **GetConversationFiles** предназначен для получения списка файлов разговора.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "GetConversationFiles", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект). В состав объекта входят следующие параметры: conversation\_id – ID разговора (целое число); page\_num – номер страницы (целое число); page\_size – размер страницы (целое число); file\_type – тип файлов (строка). Допустимые значения - "media" (медийные ресурсы), "non\_media" (немедийные ресурсы), "all" (все ресурсы). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень файлов разговора, а также ряд дополнительных атрибутов:  
\- _more_ – является ли данная страница не последней (булево).  
\- _files_ – файлы в сообщениях разговора (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID файла (целое число).  
     _name_ – название файла (строка).  
     _url_ – ссылка на файл (строка).  
     _type_ – тип файла (строка).  
     _type\_name_ – название типа файла (строка).  
     _message\_date_ – дата сообщения (дата).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "GetConversationFiles", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
