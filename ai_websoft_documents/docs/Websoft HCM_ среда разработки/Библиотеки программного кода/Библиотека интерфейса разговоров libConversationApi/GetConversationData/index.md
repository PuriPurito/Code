## GetConversationData

Метод **GetConversationData** предназначен для получения расширенных данных о разговоре.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "GetConversationData", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект). В состав объекта входят следующие параметры: conversation\_id – ID разговора (целое число); files\_page\_size – количество элементов в списке файлов (целое число); links\_page\_size – количество элементов в списке ссылок (целое число); calls\_page\_size – количество элементов в списке звонков (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит расширенные данные о разговоре, а также ряд дополнительных атрибутов:  
\- _conversation\_data_ \- расширенные данные о разговоре (объект).  
     Атрибуты объекта:  
     _id_ – ID разговора (целое число).  
     _name_ – название разговора (строка).  
     _state\_id_ – ID статус разговора в текстовом формате (строка).  
     _format\_id_ – ID формат разговора в текстовом формате (строка).  
     _creator\_id_ – ID инициатора разговора (целое число).  
     _icon\_url_ – ссылка на значок (иконку) разговора (строка).  
     _participants_ – список ID участников разговора (массив целых чисел).  
     _operations_ – список разрешенных операций в разговоре (массив объектов) (состав отдельного объекта: id – ID действия/права в текстовом формате (строка); name – название действия/права (строка); action – является ли объект действием или правом (булево); middle\_action - промежуточные действия (строка).  
     _desc_ – описание разговора (строка).  
     _files_ – файлы в сообщениях разговора (массив объектов) (состав отдельного объекта: id – ID файла (целое число); name – название файла (строка); url – ссылка на файл (строка); type – тип файла (строка); type\_name – название типа файла (строка); message\_date – дата сообщения (дата).  
     _files\_more_ – в разговоре имеются другие файлы (булево).  
     _links_ – ссылки в сообщениях разговора (массив объектов) (состав отдельного объекта: id – ID ссылки в текстовом формате (строка); link – URL ссылки (строка); message\_text – текст сообщения (строка); block\_message\_id – ID блока сообщения (целое число); message\_id – ID сообщения в текстовом формате (строка); message\_date – дата сообщения (дата).  
     _links\_more_ – в разговоре имеются другие ссылки (булево).  
     _calls_ – звонки в звонке (массив объектов) (состав отдельного объекта: id – ID звонка (целое число); creator\_id – ID автора звонка (целое число); conversation\_id – ID разговора (целое число); start\_date – дата начала звонка (дата); end\_date – дата окончания звонка (дата); duration - продолжительность звонка в миллисекундах (целое число); duration\_str – продолжительность звонка в миллисекундах в текстовом формате (строка); state\_id – ID статуса в текстовом формате (строка); entered entered – входил ли пользователь в состав участников звонка (булево); is\_group\_call – является ли звонок групповым (булево); type – тип звонка (строка).  
     _calls\_more_ – в разговоре имеются другие звонки (булево).  
     _unread\_message\_count_ – количество непрочитанных  
     _timestamp_ \- временная метка актуальности непрочитанных/последних сообщений (целое число).  
     _disp\_roles_ – роли в разговоре (массив объектов) (состав отдельного объекта: id – ID роли в текстовом формате (строка); name – название роли (строка)).  
     _last\_unread\_message_ – последнее непрочитанное сообщение (строка).  
     _last\_unread\_message\_date_ – дата последнего непрочитанного сообщения (дата).  
     _last\_unread\_message\_is\_file_ – в последнем непрочитанном сообщении имеются файлы (булево).  
     _keyboards_ – панели разговора (массив объектов) (состав отдельного объекта: id – ID кнопки в текстовом формате (строка); text – текст кнопки (строка); next\_row – производится ли в разговоре переход на следующую строку (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "GetConversationData", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
