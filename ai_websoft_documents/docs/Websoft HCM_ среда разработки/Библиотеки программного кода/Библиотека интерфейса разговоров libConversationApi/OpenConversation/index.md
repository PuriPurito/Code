## OpenConversation

Метод **OpenConversation** предназначен для открытия (начала) разговора. Метод вызывается при открытии в разговора на портале.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "OpenConversation", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект). В состав объекта входит следующий параметр: conversation\_id – ID разговора (целое число). 

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _conversation\_id_ – ID разговора (целое число);  
\- _name_ – название разговора (строка).  
\- _state\_id_ – ID статуса разговора (строка).  
\- _icon\_url_ – ссылка на изображение ярлыка (иконки) (строка).  
\- _participants_ – список ID участников (массив целых чисел).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "OpenConversation", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
