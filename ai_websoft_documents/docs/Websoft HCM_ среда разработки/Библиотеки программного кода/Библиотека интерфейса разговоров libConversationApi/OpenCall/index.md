## OpenCall

Метод OpenCall предназначен для начала сотрудником звонка.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "OpenCall", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект). В состав объекта входит следующий параметр: call\_id – ID звонка (целое число). 

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _call\_id_ – ID звонка (целое число).  
\- _start\_date_ – дата начала (дата).  
\- _current\_duration_ – текущая продолжительность в миллисекундах (целое число).  
\- _participants_ – массив участников (массив объектов). . В состав каждого объекта входят следующие параметры: participant\_id – ID участника (целое число); hash\_id – хеш ID тикета звонка (строка); state\_id – ID статуса участника (строка); has\_entered – присоединился ли участник разговора к звонку (булево); participant\_state – статус участника в звонке (строка).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "OpenCall", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
