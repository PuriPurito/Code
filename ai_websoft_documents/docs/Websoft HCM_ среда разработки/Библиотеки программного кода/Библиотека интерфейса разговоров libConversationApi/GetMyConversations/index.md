## GetMyConversations

Метод **GetMyConversations** предназначен для получения списка разговоров текущего пользователя.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "GetOperations", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект). В состав объекта входят следующие параметры: state\_id - статус разговора (строка); query\_qual - условие xquery выборки (строка); show\_public - показывать ли только публичные разговоры (булево); update\_state - обновлять ли статус в разговорах (булево); object\_type - список типов объектов (строка); last\_conversation\_id – ID последнего полученного разговора (целое число); iPageSize – размер страницы (целое число); sort – настройки сортировки (объект) (в состав объекта входят следующие параметры: field – поле (строка); direction – направление сортировки (строка)); search\_param – параметры поиска (массив объектов) (в состав объекта входят следующие параметры: recipients – список участников (массив целых чисел); start\_active\_date – дата начала последней активности (дата); finish\_active\_date – дата завершения последней активности (дата); search\_text – критерий поиска по тексту (строка); org\_name – критерий поиска по организации автора разговора (строка); subdivision\_name – критерий поиска по подразделению автора разговора (строка); custom\_state\_id – кастомный статус (строка); conversation\_type – тип разговора (целое число); search\_type – тип поиска (строка)).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень разговоров текущего пользователя, а также ряд дополнительных атрибутов:  
\- _lite\_data_ – используется упрощенный список разговоров (булево).   
\- _more_ – данная страница не является последней (булево).  
\- _conversations_ – список разговоров (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID разговора (целое число).  
     _name_ – название разговора (строка).  
     _state\_id_ – ID статуса разговора в текстовом формате (строка).  
     _active\_call_ – имеется ли активный звонок в разговоре (булево).  
     _conversation\_state_ – статус в разговоре (строка).  
     _open\_additional\_info_ – панель дополнительной информации по умолчанию открыта (булево).  
     _position\_priority_ – позиция (целое число).  
     _list\_css_ – стиль CSS (строка).  
     _icon\_url_ – ссылка на изображение ярлыка (иконки) разговора (строка).  
     _format\_id_ – ID формата разговора в текстовом выражении (строка).  
     _is\_public_ – является ли звонок публичным (булево).  
     _object\_id_ – ID объекта, по которому создан разговор в текстовом формате (строка).    
     _object\_name_ – название объекта, по которому создан разговор (строка).   
     _object\_type_ – тип объекта, по которому создан разговор (строка).   
     _last\_unread\_message_ – последнее сообщение в разговоре (строка).   
     _last\_unread\_message\_id_ – ID последнего сообщения в разговоре в текстовом формате (строка).  
     _last\_unread\_message\_is\_file_ – в последнем сообщении имеется файл (булево).  
     _last\_unread\_message\_date_ – дата последнего сообщения в разговоре (дата).  
     _new\_reaction_ – имеется непросмотренная реакция на мое сообщение (булево).  
     _disp\_roles_ – роли в разговоре (массив объектов) (состав отдельного объекта: id – ID роли в текстовом формате (строка); name – название роли (строка)).  
     _unread\_message\_count_ – количество непрочитанных сообщений в разговоре (целое число).  
     _unread\_message_ – общее количество непрочитанных сообщений (целое число).  
     _timestamp_ \- временная метка актуальности непрочитанных/последних сообщений (целое число).  
     _person\_data_ – данные собеседника (объект). В состав объекта входят следующие параметры: id – ID сотрудника (целое число); fullname – ФИО (строка); position\_id – должность (целое число); position\_name – название должности (строка); org\_id – организация (целое число); org\_name – название организации (строка); email – email (строка); phone – телефон (строка); birth\_date – дата рождения (дата); icon\_url – иконка (строка); selectable – доступно для выбора (булево); last\_activity\_date – дата последней активности (дата); online – сейчас онлайн (булево); active\_call – сейчас в звонке (булево); comment – комментарий (строка); state\_id – ID статуса (целое число); operations – доступные действия (массив строк).  
     _is\_pinned_ – закреплен ли разговор (булево). О закреплении/откреплении разговора см. также функцию **PinConversation**.

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "GetMyConversations", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
