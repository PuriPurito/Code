## ViewMessageReaction

Метод **ViewMessageReaction** предназначен для пометки просмотренными реакций на свои сообщения.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "ViewMessageReaction", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект). В состав объекта входят следующие параметры: conversation\_id – ID разговора (целое число); block\_message\_id – ID блока сообщений (целое число); message\_id – ID сообщения в текстовом формате (строка); messages – список сообщений (массив объектов) (состав отдельного объекта: message\_id – ID сообщения в текстовом формате (строка); block\_message\_id – ID блока сообщений (целое число)). 

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "ViewMessageReaction", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
