## GetUserList

Метод **GetUserList** предназначен для получения списка сотрудников, участвовавших в разговоре.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "GetUserList", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект). В состав объекта входят следующие параметры: action – действие (строка); conversation\_id – ID разговора (целое число); page\_num – номер страницы (целое число); page\_size – размер страницы (целое число); search\_fullname - критерий полнотекстового поиска по ФИО сотрудников в формате XQuery для отбора (строка); user\_ids - массив ID пользователей (массив целых чисел).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень сотрудников, участвовавших в разговоре, а также ряд дополнительных атрибутов:  
\- _is\_filtered_ – результат отфильтрован (булево).  
\- _total_ – общее количество (целое число).  
\- _collaborators_ – сотрудники, принимающие участие в разговоре (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID сотрудника (целое число).  
     _fullname_ – ФИО сотрудника (строка).  
     _position\_id_ – ID должности (целое число).  
     _position\_name_ – название должности (строка).  
     _org\_id_ – ID организации (целое число).  
     _org\_name_ – название организации (строка).  
     _email_ – электронная почта (строка).  
     _phone_ – телефон (строка).  
     _birth\_date_ – дата рождения (дата).   
     _icon\_url_ – ссылка на изображение ярлыка (иконки) (строка).  
     _selectable_ – доступна ли учетная запись для выбора (булево).  
     _last\_activity\_date_ – дата последней активности (дата).  
     _online_ – участвует ли в настоящее время пользователь в звонке онлайн (булево).  
     _active\_call_ – участвует ли в настоящее время пользователь в звонке (булево).  
     _comment_ – комментарий (строка).  
     _state\_id_ – ID статуса (целое число).  
     _operations_ – доступные действия (массив строк).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "GetUserList", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
