## GetConversationLinks

Метод **GetConversationLinks** предназначен для получения списка ссылок разговора.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "GetConversationLinks", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект). В состав объекта входят следующие параметры: conversation\_id – ID разговора (целое число); page\_num – номер страницы (целое число); page\_size – размер страницы (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень ссылок разговора, а также ряд дополнительных атрибутов:  
\- _more_ – является ли данная страница не последней (булево).  
\- _links_ – ссылки в сообщениях разговора (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID ссылки в текстовом формате (строка).  
     _link_ – URL ссылки (строка).  
     _message\_text_ – текст сообщения (строка).  
     _block\_message\_id_ – ID блока сообщения (целое число).  
     _message\_id_ – ID сообщения в текстовом формате (строка).  
     _message\_date_ – дата сообщения (дата).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "GetConversationLinks", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
