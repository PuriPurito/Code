## GetConversationObjectTypes

Метод **GetConversationObjectTypes** предназначен для получения списка возможных типов документов в разговоре.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "GetConversationObjectTypes", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект).  

Примечание - Состав входных параметров находится в стадии разработки. 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень возможных типов документов в разговоре, а также ряд дополнительных атрибутов:  
\- conversation\_object\_types - типы документов в сообщениях разговора (массив объектов).  
     Атрибуты отдельного объекта:  
     id - ID типа документа в текстовом формате (строка).  
     _name_ \- название типа документа (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "GetConversationObjectTypes", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
