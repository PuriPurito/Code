## SearchByCatalog

Метод **SearchByCatalog** предназначен для поиска объектов каталога.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "SearchByCatalog", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ - входные параметры функции (объект). В состав объекта входят следующие параметры: search\_text – критерий полнотекстового поиска в формате XQuery для отбора (строка); catalog – каталог для поиска (строка).

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит перечень звонков в разговоре, а также ряд дополнительных атрибутов:  
\- _array_ \- массив звонков (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID отобранного звонка в текстовом формате (строка).  
     _name_ \- название отобранного звонка (строка).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "SearchByCatalog", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
