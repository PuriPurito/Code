## GetOperations

Метод **GetOperations** предназначен для получения списка разрешенных операций (действий, прав) в разговоре.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libConversationApi", "GetOperations", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _oActionParam_ \- входные параметры функции (объект). В состав объекта входят следующие параметры: conversation\_id – ID разговора (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень операций (действий, прав) в разговоре, а также ряд дополнительных атрибутов:  
\- _operations_ – операции в разговоре (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID действия/права в текстовом формате (строка).  
     _name_ – название действия/права (строка).  
     _action_ – является ли объект действием или правом (булево).  
     _middle\_action_ \- промежуточные действия (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_– текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libConversationApi", "GetOperations", [oActionParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
