## bHierSubdivisions

Глобальный параметр bHierSubdivisions определяет необходимость учета всех дочерних подразделений вниз по иерархии для руководителей подразделений.  
Параметр связан с библиотекой программного кода персонала  **libStaff**.  
  
Не является служебным параметром (т.е. может использоваться для настройки объектов, а также может передаваться и принимать новые значения при вызове из внешнего окружения (API, конструктор интерфейсов и т.п.)).

_Синтаксис:_  
      **var libParam = tools.get\_params\_code\_library('libStaff');  
      var iDaysAfter = libParam.GetOptProperty("bHierSubdivisions", \[<arg1>\]);**

_Аргументы параметра GetOptProperty:_  
     _<arg1>_ \- количество дней после дня рождения сотрудника для поздравления по умолчанию (целое число) (Если аргумент _<arg1>_ не задан, то значение по умолчанию равно **1** (**true**)).

_Возвращаемое значение:_  
      Тип: **Булево (bool)**. Глобальный параметр, указывающий необходимость учета всех дочерних подразделений вниз по иерархии для руководителей подразделений. 

_Примеры (типовой код применения):_

   `_var libParam = tools.get_params_code_library('libStaff');      var iDaysBefore = libParam.GetOptProperty("bHierSubdivisions", 1);_`
