## expert_type

Глобальный параметр **expert\_type** определяет тип согласующего эксперта. Значение по умолчанию – _standart_.  
Параметр связан с библиотекой программного кода карты знаний  **libKnowledge**.  
  
Не является служебным параметром (т.е. может использоваться для настройки объектов, а также может передаваться и принимать новые значения при вызове из внешнего окружения (API, конструктор интерфейсов и т.п.)).

_Синтаксис:_  
      **var libParam = tools.get\_params\_code\_library('libKnowledge');  
            var expert\_type1 = libParam.GetOptProperty("expert\_type", \[\]);**

_Аргументы параметра GetOptProperty:_  
      Для реализации данного метода аргументы не предусмотрены. Используется пустой массив аргументов.

_Возвращаемое значение:_  
      Тип: **Комбинированный список (combo)**, позволяющий ввести значение вручную или выбрать из раскрывающегося списка. Глобальный параметр, указывающий тип (способ определения) согласующего эксперта.   
      Доступные значения:  
      - _standart_ – официальные эксперты (выбор по умолчанию и значение, указываемое в однострочном текстовом поле комбинированного списка);  
      - _with\_knowledge_ – любой эксперт, обладающий соответствующими знаниями;  
      - _with\_expert\_level_ \- любой сотрудник, имеющий уровень эксперта.

_Примеры (типовой код применения):_

   `_var libParam = tools.get_params_code_library('libKnowledge');      var arrExpertTypes = tools_web.parse_multiple_parameter( libParam.GetOptProperty("expert_type", "[]"));_`
