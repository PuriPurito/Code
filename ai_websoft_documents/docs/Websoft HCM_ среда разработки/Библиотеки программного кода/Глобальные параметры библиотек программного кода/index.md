## Глобальные параметры библиотек программного кода

**Глобальные параметры библиотек программного кода** предназначены для настройки портала и шаблонов. Для того, чтобы разные элементы системы (виджеты, коллекции, показатели) на страницах портала и в шаблонах работали одинаково и предсказуемо, они должны использовать один и тот же вариант настроек.

Глобальные параметры  определяются в одном месте (в документе библиотеки), могут быть использованы различными объектами системы и будут одинаковы в любом контексте использования.

Область видимости указанных параметров является глобальной - методы библиотек можно использовать везде, где доступен объект библиотек **tools** и **tools\_web**.

Для вызова глобального параметра используется функция  **tools\_web.parse\_multiple\_parameter**. 

_Синтаксис (вызов из JS-кода):_  
      **tools\_web.parse\_multiple\_parameter(<libParam>.GetOptProperty(<sNameParam>, <arrParams>))**

_Аргументы:_  
     _<libParam> (обязательный)_  
      Тип: **Объект**. Библиотека программного кода, к которой относится вызываемый глобальный параметр. Объект определяется с помощью кода следующего вида:  
      _var libParam = tools.get\_params\_code\_library(<sNameLib>);_  
      где _<sNameLib>_ \- строка, содержащая название библиотеки программного кода (например, _'libMain'_).  
      Таким образом, для общей библиотеки программного кода libMain аргумент <libParam> будет определяться следующим образом:  
      _var libParam = tools.get\_params\_code\_library('libMain');_  
  
     _<sNameParam> (обязательный)_  
      Тип: **Строка**. Название вызываемого глобального параметра.  
     _<arrParams> (обязательный)_  
      Тип: **Строка**. Строка в формате _json_, задающая значения массива вспомогательных параметров, необходимых для вызова глобального параметра. Параметры перечисляются через запятую, и весь набор вспомогательных параметров заключается в квадратные скобки. Если вспомогательные параметры отсутствуют, то указывается пустая строка (_**"\[\]"**_).

Глобальные параметры библиотек программного кода можно вызывать в кодах агентов, шаблонов, выборок, удаленных действий, системных событий, действий документооборота и др.

**Примечание** - Глобальные параметры библиотек программного кода по умолчанию описываются в библиотеке **inst\_pack\_code\_library**, которая хранится в файле **WebSoftServer\\custom\\inst\_pack\_code\_library.xml**.
