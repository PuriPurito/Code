## Overlay

Метод **Overlay** предназначен для наложения на видеофайл изображений и других видеофайлов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libVideoCourse", "Overlay", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _sOutputPath_ \- путь для сохранения выходного файла (строка).  
     _sInputVideo_ \- путь до видеофайла, на который нужно наложить файл (строка).  
     _aFiles_ \- массив объектов файлов, преобразованных в JSON-строку (строка). Аргумент включает в себя следующие параметры: Path – путь до файла (строка); C – параметр отвечает за то, как будет залиты пробелы (строка); Scale – размер файла в формате 100:200 (строка); X – позиция файла по оси Х (целое число); Y – позиция файла по оси Y (целое число); Z\_index – z-индекс (целое число); Rotate – угол поворота файла (целое число); Fade\_in – время начала показа файла (двойное целое число); Fade\_out – время окончания показа файла (двойное целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит следующие атрибуты:  
\- _output\_path_ \- путь выходного видеофайла (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
_\- error\_string_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libVideoCourse", "Overlay", [sOutputPath, sInputVideo, aFiles]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
