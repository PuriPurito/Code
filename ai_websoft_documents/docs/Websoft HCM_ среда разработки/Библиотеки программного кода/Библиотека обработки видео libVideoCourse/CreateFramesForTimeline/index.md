## CreateFramesForTimeline

Метод **CreateFramesForTimeline** предназначен для создания кадров (фреймов) для таймлайна.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libVideoCourse", "CreateFramesForTimeline", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _sOutputPath_ \- путь до папки для сохранения изображений (строка) (\\\\image\\\\image%05d.jpeg - сохранение файлов с нумераций по порядку).  
     _sInputVideo_ \- путь до видеофайла (строка).  
     _interval_ \- количество получаемых файлов из видео в строковом выражении (строка). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит следующие атрибуты:  
\- _result_ \- набор URL кадров (фреймов) (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _error\_string_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libVideoCourse", "CreateFramesForTimeline", [sOutputPath, sInputVideo, interval]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
