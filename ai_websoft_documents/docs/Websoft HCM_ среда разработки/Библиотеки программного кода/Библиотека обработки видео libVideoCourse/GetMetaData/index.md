## GetMetaData

Метод **GetMetaData** предназначен для получения метаданных видеозаписи.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libVideoCourse", "GetMetaData", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _sFilePath_ \- Путь до файла, из которого нужно получить метаданные (строка).

_Возвращаемое значение:_  
     _result_ \- строка JSON с метаданными (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libVideoCourse", "GetMetaData", [sFilePath]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
