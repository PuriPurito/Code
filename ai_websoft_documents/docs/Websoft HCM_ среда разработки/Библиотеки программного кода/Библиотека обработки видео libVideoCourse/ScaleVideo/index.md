## ScaleVideo

Метод **ScaleVideo** предназначен для масштабирования видео.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libVideoCourse", "ScaleVideo", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя пять параметров:  
     _sOutputPath_ \- путь для сохранения выходного файла (строка).  
     _sInputVideo_ \- путь до видеофайла, который нужно обработать (строка).  
     _width_ \- ширина в строковом выражении (строка).  
     _hight_ \- высотав строковом выражении (строка).  
     _sSetsar_ \- соотношение сторон в строковом выражении (строка) (необязательный параметр).

_Возвращаемое значение:_  
      Тип: **Объект**.

Содержит следующие атрибуты:  
\- _sOutputPath_ \- путь выходного видеофайла (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _error\_string_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libVideoCourse", "ScaleVideo", [sOutputPath, sInputVideo, width, hight, sSetsar]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
