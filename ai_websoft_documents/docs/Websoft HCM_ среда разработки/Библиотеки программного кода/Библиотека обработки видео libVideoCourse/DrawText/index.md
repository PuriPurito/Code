## DrawText

Метод **DrawText** предназначен для наложения текста на видеофайл.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libVideoCourse", "DrawText", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _sOutputPath_ \- путь для сохранения выходного файла (строка).  
     _sInputVideo_ \- путь до видеофайла, на который нужно наложить текстовый файл (строка).  
     _aTexts_ \- Массив объектов файлов, преобразованных в JSON-строку (строка). Аргумент включает в себя следующие параметры: Label – текст, который нужно наложить на видео (строка); Font – ссылка к файлу шрифтов (строка); Font\_color – цвет текста (строка); Font\_size – размер текста (целое число); X – позиция файла по оси Х (целое число); Y – позиция файла по оси Y (целое число); Z\_index – z-индекс (целое число); Fade\_in – время начала показа изображения (двойное целое число); Fade\_out – время окончания показа изображения (двойное целое число).

_Возвращаемое значение:_  
     _sOutputPath_ \- путь выходного видеофайла (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libVideoCourse", "DrawText", [sOutputPath, sInputVideo, aTexts]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
