## MixAudio

Метод **MixAudio** предназначен для наложения аудиофайла на видео.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libVideoCourse", "MixAudio", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _sOutputPath_ \- путь для сохранения выходного файла (строка).  
     _sInputVideo_ \- путь до видеофайла, на который нужно наложить аудиофайл (строка).  
     _sInputAudio_ \- путь до аудиофайла (строка).

_Возвращаемое значение:_  
     sOutputPath - путь выходного видеофайла (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libVideoCourse", "MixAudio", [sOutputPath, sInputVideo, sInputAudio]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
