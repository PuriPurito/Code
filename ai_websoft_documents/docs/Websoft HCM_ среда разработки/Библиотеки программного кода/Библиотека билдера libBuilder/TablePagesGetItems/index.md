## TablePagesGetItems

Метод **TablePagesGetItems** предназначен для получения списка страниц.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libBuilder", "TablePagesGetItems", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _search_ \- критерий полнотекстового поиска в формате XQuery для отбора (строка).  
     _page\_num_ \- номер страницы (целое число).  
     _page\_size_ \- размер страницы (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о страницах, а также ряд дополнительных атрибутов:  
\- _items_ \- совокупность страниц (массив объектов).   
\- _total_ \- общее число страниц (целое число). 

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libBuilder", "TablePagesGetItems", [search, page_num, page_size]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
