## GetComponentLibraryItems

Метод **GetComponentLibraryItems** предназначен для получения списка иконок для компоненты выбора иконок.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libBuilder", "GetComponentLibraryItems", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя шесть параметров:  
     _search_ \- критерий поиска (строка).  
     _page\_num_ \- номер страницы (целое число).  
     _page\_size_ \- размер страницы (целое число).  
     _sort_ – сортировка (объект).  
     _order_ – порядок (объект).  
     _types_ \- тип компоненты (объект).

_Возвращаемое значение:_  
      Тип: **Объект**.

Содержит перечень иконок для компоненты выбора иконок, а также ряд дополнительных атрибутов:  
\- items - массив иконок (массив объектов).  
     Атрибуты отдельного объекта:  
      _id_ \- ID объекта (целое число);  
      _name_ \- название объекта (строка).  
      _image\_url_ \- URL объекта (строка).  
      _owner\_id_ \- ID объекта более высокого уровня (целое число).  
      _owner\_display\_name_ \- название объекта более высокого уровня (строка).  
      _owner\_avatar\_url_ \- URL объекта более высокого уровня (строка).  
      _type_ \- тип объекта (строка).  
      _public_ \- является ли объект публичным (булево).

\- _total_ \- общее число элементов массива (целое число).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libBuilder", "GetComponentLibraryItems", [search, page_num, page_size, sort, order, types]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
