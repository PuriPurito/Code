## CreateSection

Метод **CreateSection** предназначен для создания секции.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libBuilder", "CreateSection", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _pageId_ \- ID страницы в текстовом формате (строка).  
     _sectionLayoutTypeId_ \- ID типа макета секции в текстовом формате (строка).  
     _aboveComponentId_ \- ID компоненты расположенной выше в текстовом формате (строка). 

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _id_ \- ID созданной секции в текстовом формате (строка).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libBuilder", "CreateSection", [pageId, sectionLayoutTypeId, aboveComponentId]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
