## GetIcons

Метод **GetIcons** предназначен для получения списка иконок для компоненты выбора иконок.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libBuilder", "GetIcons", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.

     Массив включает в себя шесть параметров:  
     _search_ \- критерий поиска для отбора (строка).  
     _page\_num_ \- номер страницы (целое число).   
     _page\_size_ \- размер страницы (целое число).   
     _families_ \- семейства (объект).   
     _styles_ \- стили (объект).  
     _categories_ \- категории (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень иконок для компоненты выбора иконок, а также ряд дополнительных атрибутов:  
\- _total_ \- общее количество элементов (цедое число)  
\- _items_ \- массив иконок (массив объектов).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libBuilder", "GetIcons", [search, page_num, page_size, families, styles, categories]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
