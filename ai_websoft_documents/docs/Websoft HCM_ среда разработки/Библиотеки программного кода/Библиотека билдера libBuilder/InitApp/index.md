## InitApp

Метод **InitApp** предназначен для возвращения данных, необходимых для инициализации приложения Builder.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libBuilder", "InitApp", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
      Метод вызывается без аргументов. Для данного метода используется пустой массив аргументов.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит следующие атрибуты:  
\- _app_ \- данные приложения (объект). В состав объекта могут входить следующие параметры: badge - бейдж логотипа приложения (строка); copyright - строка копирайта (строка); logoUrl - URL логотипа приложения (строка); name - название приложения (строка).  
\- _user_ \- данные пользователя (объект). В состав объекта могут входить следующие параметры: avatarUrl - URL аватара пользователя (строка); displayName - имя пользователя (строка); email - e-mail пользователя (строка); hasAccess - наличие доступа к приложению (булево); initials - инициалы имени пользователя (строка); signedIn - статус авторизации (булево).  
\- _componentsTypes_ \- типы компонентов (массив объектов). Каждый объект массива может включать в себя следующие данные: category - категория (строка); code - код (строка); html\_tag - HTML тега (строка); id - ID типа компоненты (строка); image - URL изображения (строка); layout - расположение (строка); tooltip\_image - URL изображения подсказки (строка); type - тип (строка).  
\- _i18n_ \- данные локализации (объект). В состав объекта могут входить следующие параметры: languages - доступные языки (массив объектов) (состав отдельного объекта: code - код языка (строка); direction - направление (строка); image - URL изображения (строка); name - название (строка)); locale - текущий код языка (строка).   
\- _propertiesTypes_ \- типы свойств (массив объектов). Каждый объект массива может включать в себя следующие данные: category - категория (строка); component\_type\_id - ID компоненты (строка); html\_tag - HTML тега (строка); id - ID типа свойства в текстовом формате (строка); name - название свойства (строка); value - значение (строка); value\_type - тип значения (целое число).  
\- _tableComponentsTypes_ - типы компонентов таблиц (массив объектов). Каждый объект массива может включать в себя следующие данные: category - категория (строка); component\_type\_id - ID компоненты (строка); html\_tag - HTML тега (строка); id - ID типа свойства в текстовом формате (строка); name - название свойства (строка); value - значение (строка); value\_type - тип значения (целое число).  
\- _tablePropertiesTypes_ \- типы свойств компонентов таблиц (массив объектов). Каждый объект массива может включать в себя следующие данные: category - категория (строка); component\_type\_id - ID компоненты (строка); html\_tag - HTML тега (строка); id - ID типа свойства в текстовом формате (строка); name - название свойства (строка); value - значение (строка); value\_type - тип значения (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libBuilder", "InitApp", []);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
