## Библиотека для мини-сценариев по электронным курсам libScriptCourse

В настоящем разделе описываются методы **библиотеки для мини-сценариев по электронным курсам** из библиотеки программного кода **libScriptCourse**. Указанные методы регистрируются в разделе **Дизайнер – Библиотеки программного кода – libScriptCourse**.

Примечание - По состоянию на май 2024 г. библиотека предназначена исключительно для внутренних нужд системы и не содержит публичных методов.
