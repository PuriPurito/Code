## TimeEntryList

Метод **TimeEntryList** предназначен для получения перечня завершенных записей времени пользователя.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTimeTracker", "TimeEntryList", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя семь параметров:  
     _iUserID_ \- ID пользователя (сотрудника) (целое число).  
     _sTargetDate_ \- дата в строковом формате, начиная с которой отбираются записи времени пользователя за период 7 дней (строка). Если данный аргумент не задан, то берется текущая дата.   
     sEndTargetDate - дата завершения периода в строковом формате (строка) (необязательный).  
     _iProjectId_ \- ID проекта (целое число) (необязательный).  
     _sSearchText_ \- дополнительный критерий полнотекстового поиска в формате XQuery для отбора (строка) (необязательный).  
     aTaskSortFields – массив полей для сортировки задач (массив объектов). Каждый объект массива может включать в себя следующие данные: field - название поля для сортировки (строка); direction - направление сортировки ("ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)) (строка).  
     aTimeEntrySortFields – массив полей для сортировки учета времени (массив объектов). Каждый объект массива может включать в себя следующие данные: field - название поля для сортировки (строка); direction - направление сортировки ("ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)) (строка).  
     _oPaging_ – данные для пейджинга (необязательный) (объект). Каждый объект массива может включать в себя следующие параметры: pagenum - номер страницы (строка); pagesize – размер страницы (строка).  
     _iTaskID_ \- ID задачи (необязательный) (целое число).  
     _iSelectedLastDays_ \- ID задачи (необязательный) (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень завершенных записей времени пользователя, а также ряд дополнительных атрибутов:  
\- data – результат функции (объект). Объект включает в себя следующие поля:   
     _start\_date_ – дата начала записи учета времени (дата);   
     _end\_date_ – дата окончания записи учета времени (дата);   
     _total\_entries_ – количество записей учета времени time\_entries (целое число).  
     _org\_id_ – ID организации (целое число);   
     _org\_name_ – наименование организации (строка).  
     _tasks_ – список задач, "нарезанных" посуточно (для удобства отображения в UI) (массив объектов) (в том числе: task\_id – ID задачи (целое число); task\_date – дата задачи (дата); task\_name – наименование задачи (строка); project\_id – ID проекта (целое число); task\_type\_id – ID типа задачи (целое число); project\_name – наименование проекта (строка); description – описание задачи (строка); time\_entries – массив записей времени по задаче за сутки (массив объектов, _включающий в себя следующие поля: id – ID записи времени (целое число); start\_date – дата начала записи времени (дата); end\_date – дата окончания записи времени (дата); duration – длительность записи времени в минутах (целое число); description – описание записи времени, заданное пользователем (строка); person\_id – ID сотрудника (целое число); person\_fullname – ФИО сотрудника (строка))_.     

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message -_ текст ошибки (строка). При отсутствии ошибки выводится пустая строка.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libEdu", "SendNotificationsEventBase", [iUserID, sTargetDate, sEndTargetDate, iProjectId, sSearchText;  aTaskSortFields, aTimeEntrySortFields]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
