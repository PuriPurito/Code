## TaskList

Метод **TaskList** предназначен для получения списка активных задач проекта (второго уровня вложенности), доступных пользователю.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTimeTracker", "TaskList", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iUserID_ \- ID пользователя (сотрудника) (целое число).  
     _iProjectId_ \- ID проекта (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень активных задач проекта (второго уровня вложенности), доступных пользователю, а также ряд дополнительных атрибутов:  
\- _data_ – результат функции (объект). Объект включает в себя поле tasks - массив задач проекта (массив объектов).  
В том числе:   
_\- tasks_ \- массив задач проекта (массив объектов).  
     Атрибуты отдельного объекта data.tasks:  
     _id_ – ID задачи (целое число).  
     _name_ – наименование задачи (строка).  
     _phase\_id_ – ID этапа проекта (родительской задачи) (целое число).  
     _phase\_name_ – наименование этапа проекта (строка).  
     _parent\_id_ – ID родительской задачи (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0, при наличии – код равен 1) (целое число).  
\- _message_ – текст ошибки (строка). При отсутствии ошибки выводится пустая строка.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTimeTracker", "TaskList", [iUserID, iProjectId]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
