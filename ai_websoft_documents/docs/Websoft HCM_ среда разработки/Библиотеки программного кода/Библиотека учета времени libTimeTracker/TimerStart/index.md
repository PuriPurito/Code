## TimerStart

Метод **TimerStart** предназначен для запуска таймера задачи. Если таймер данной задачи уже был запущен, то запущенный ранее таймер будет остановлен.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTimeTracker", "TimerStart", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iUserID_ \- ID пользователя (сотрудника) (целое число).  
     _iTaskID_ \- ID задачи, по которой необходимо запустить таймер (целое число).  
     _sDescription_ \- описание выполняемой задачи, заданное пользователем (строка) (необязательный). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит следующие атрибуты:  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_ \- текст ошибки (строка). При отсутствии ошибки выводится пустая строка.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTimeTracker", "TimerStart", [iUserID, iTaskID, sDescription]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
