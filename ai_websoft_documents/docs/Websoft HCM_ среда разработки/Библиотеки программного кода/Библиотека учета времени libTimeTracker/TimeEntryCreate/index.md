## TimeEntryCreate

Метод **TimeEntryCreate** предназначен для создания или изменения записи времени.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTimeTracker", "TimeEntryCreate", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _iUserID_ \- ID пользователя (сотрудника) (целое число).  
     _iTaskID_ \- ID задачи, по которой необходимо запустить таймер (целое число).  
     _oTimeEntryData_ \- объект со значениями полей, которые необходимо сохранить в записи времени (объект). Объект содержит следующие поля: start\_date – дата начала записи времени (дата); end\_date – дата окончания записи времени (дата); description – описание записи времени, заданное пользователем (строка).  
     _iTimeEntryId_ – ID записи времени, в которую будут внесены изменения (необязательный) (целое число). Если аргумент не задан, то будет создана новая запись времени.  
     _bSendToSocket_ – нужно ли отправлять данные в сокет (необязательный) (булево).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит следующие атрибуты:  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0, при наличии – код равен 1) (целое число).  
\- _message_ – текст ошибки (строка). При отсутствии ошибки выводится пустая строка.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTimeTracker", "TimeEntryCreate", [iUserID, iTaskID, oTimeEntryData, iTimeEntryId, bSendToSocket]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
