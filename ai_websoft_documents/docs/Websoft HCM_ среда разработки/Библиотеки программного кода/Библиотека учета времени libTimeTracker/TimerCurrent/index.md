## TimerCurrent

Метод **TimerCurrent** предназначен для получения информации о запущенном пользователем в данный момент таймере.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTimeTracker", "TimerCurrent", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iUserID_ \- ID пользователя (сотрудника) (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит следующие атрибуты:  
\- _data_ – информация об активном таймере (если он найден) (объект). Объект включает в себя следующие поля:   
     _id_ \- ID запущенного таймера (целое число).  
     _org\_id_ \- ID организации, по проекту которой запущен таймер (целое число).  
     _org\_name_ \- наименование организации, по проекту которой запущен таймер (строка).  
     _task\_id_ \- ID задачи, по которой запущен таймер (целое число).  
     _task\_name_ \- наименование задачи, по которой запущен таймер (строка).  
     _project\_id_ \- ID проекта, по которому запущен таймер (целое число).  
     _project\_name_ \- наименование проекта, по которому запущен таймер (строка).  
     _start\_date_ \- дата и время начала отсчета таймера (дата).  
     _description_ \- описание выполняемой задачи, заданное пользователем (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_ – текст ошибки (строка). При отсутствии ошибки выводится пустая строка.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTimeTracker", "TimerCurrent", [iUserID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
