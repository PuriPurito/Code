## ProjectList

Метод **ProjectList** предназначен для получения списка активных проектов, в которых участвует пользователь.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTimeTracker", "ProjectList", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iUserID_ \- ID пользователя (сотрудника) (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень активных проектов, в которых участвует пользователь, а также ряд дополнительных атрибутов:  
\- _data.projects_ \- массив активных проектов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID проекта (целое число).  
     _name_ – наименование проекта (строка).  
     _org\_id_ – ID организации, для которой создан проект (целое число).  
     _org\_name_ – наименование организации, для которой создан проект (строка).

\- error - код ошибки (при отсутствии ошибок код равен 0, при наличии – код равен 1) (целое число).  
\- message – текст ошибки (строка). При отсутствии ошибки выводится пустая строка.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTimeTracker", "ProjectList", [iUserID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
