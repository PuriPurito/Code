## GetRecipients

Метод предназначен для получения списка адресатов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libChat", "GetRecipients", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iObjectID_ – ID объекта (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит перечень адресатов, а также ряд дополнительных атрибутов:  
\- _recipients_ \- массив ID адресатов (массив целых чисел).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_ – сообщение об ошибке (строка).

_Пример:_

`_// Данный агент должен быть выполнен на сервере_` 

`_// Пусть в системе имеется разговор с названием «Разговор 1»   // Находим программно ознакомление с названием «Разговор 1» с помощью функции_ _tools.get_doc_by_key_   _oConv = tools.get_doc_by_key ('conversation', 'name', 'Разговор 1' );   alert ( 'Найдено ознакомление ' + oConv.TopElem.name + ' с идентификационным номером ' + oConv.DocID ); // на экран выводится информация об отобранном разговоре_`

`_iConvID = oConv.DocID;_`

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libChat", "GetRecipients", [OptInt (iConvID)]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`  
  
`_Результат выполнения метода, записанный в лог и преобразованный в формат JSON:_`

{  
    "error": 0,  
    "message": "",  
    "recipients": \[3050438886317795229, 5293675553778464355, 1105387902724063523\]  
}
