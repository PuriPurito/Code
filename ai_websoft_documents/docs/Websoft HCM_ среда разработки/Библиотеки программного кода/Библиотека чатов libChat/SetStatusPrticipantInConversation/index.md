## SetStatusPrticipantInConversation

Метод предназначен для изменения статуса участников разговора. 

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libChat", "SetStatusPrticipantInConversation", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iConversationID_ \- ID разговора (целое число).  
     _aParticipantStates_ \- массив участников разговора с их статусами (массив объектов). Объект включает в себя ID участника разговора и его статус. Статус _'delete'_ – участник исключен из разговора. 

_Возвращаемое значение:_  
     Тип: **Объект**. Результат выполнения действия, включающий в себя следующие параметры:  
     _error_ – код ошибки (целое число).  
     _message_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libChat", "SetStatusPrticipantInConversation", [ iConversationID, aParticipantStates ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
