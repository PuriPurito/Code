## GetChates

Метод **GetChates** предназначен для получения списка чатов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libChat", "GetChates", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _arrDistinct_ \- перечень полей для формирования дополнительных списков для виджета фильтров (массив строк) (необязательный).  
     _arrFilters_ \- набор фильтров для формирования отчета (массив объектов).   
     _oSort_ \- информация из рантайма о сортировке (JSON объект).   
     _oPaging_ \- информация из рантайма о пейджинге (JSON объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень чатов, а также ряд дополнительных атрибутов:  
\- array - массив чатов (массив объектов).  
     Атрибуты отдельного объекта:  
     id – ID чата (целое число);  
     name – название чата (строка).

\- _result_ \- результат выполнения функции (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ - текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libChat", "GetChates", [iCurUserID, arrDistinct, arrFilters, oSort, oPaging]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
