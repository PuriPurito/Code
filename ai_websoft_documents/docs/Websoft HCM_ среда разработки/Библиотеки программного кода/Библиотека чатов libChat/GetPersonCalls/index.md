## GetPersonCalls

Метод **GetPersonCalls** предназначен для получения списка звонков.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libChat", "GetPersonCalls", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пять параметров:  
     _iPersonID_ \- ID пользователя (целое число).  
     _arrStates_ \- массив статусов для поиска (массив строк).  
     _iPageNum_ \- номер страницы с сообщениями (целое число) (необязательный)  
     _iPageSize_ \- количество сообщений на странице (целое число) (необязательный).  
     _iConversationID_ \- ID разговора (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень звонков, а также ряд дополнительных атрибутов:  
\- array - массив звонков (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID звонка (целое число).  
     _creator\_id_ \- инициатор звонка (целое число).  
     _conversation\_id_ \- ID разговора (целое число).  
     _start\_date_ \- начало звонка (дата и время).  
     _end\_date_ \- конец звонка (дата и время).  
     _duration_ \- продолжительность звонка в секундах (целое число).  
     _duration\_str_ \- продолжительность звонка в секундах в строковом формате (строка).  
     _state\_id_ \- ID статуса звонка (строка). Например: undefined (не определен), project (проект), plan (планируется), active (проводится), close (завершено), cancel (отменено).  
     _entered_ \- является ли звонок входящим (булево).  
     _is\_group\_call_ \- является ли звонок групповым (булево).  
     _type_ \- тип звонка (строка).  
  
\- _total_ – количество записей (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libChat", "GetPersonCalls", [iPersonID, arrStates, iPageNum, iPageSize, iConversationID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
