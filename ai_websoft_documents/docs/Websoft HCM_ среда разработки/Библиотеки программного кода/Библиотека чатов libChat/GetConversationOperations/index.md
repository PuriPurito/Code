## GetConversationOperations

Метод предназначен для получения списка действий (операций) сотрудника по разговорам.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libChat", "GetConversationOperations", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPersonID_ – ID пользователя (целое число).   
     _iConversationID_ – ID разговора (целое число).  

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит перечень разрешенных действий (операций) сотрудника по разговорам, а также ряд дополнительных атрибутов:  
\- _operations_ \- массив разрешенных действий (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID действия (целое число);  
     _name_ – название действия (строка).  
  
\- _is\_boss_ – сотрудник является руководителем (булево).  
\- _type_ – тип сотрудника (строка).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_ – сообщение об ошибке (строка).

_Пример:_

`_// Данный агент должен быть выполнен на сервере_` 

`_// Пусть в системе имеется сотрудник Васильева Людмила Петровна, которая принимает участие в мероприятии   // Находим программно сотрудника Васильеву Л.П. с помощью функции_ _tools.get_doc_by_key_   _oCollab = tools.get_doc_by_key ( 'collaborator', 'fullname', 'Васильева Людмила Петровна' );   alert ( 'Найден сотрудник ' + oCollab.TopElem.fullname + ' с идентификационным номером ' + oCollab.DocID ); // на экран выводится информация об отобранном сотруднике_`

`_// Пусть в системе имеется разговор с названием «Разговор 1»   // Находим программно ознакомление с названием «Разговор 1» с помощью функции tools.get_doc_by_key   oConv = tools.get_doc_by_key ('conversation', 'name', 'Разговор 1' );   alert ( 'Найдено ознакомление ' + oConv.TopElem.name + ' с идентификационным номером ' + oConv.DocID ); // на экран выводится информация об отобранном разговоре_`

`_iCollabID = oCollab.DocID;   iConvID = oConv.DocID;_`

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libChat", "GetConversationOperations", [OptInt (iCollabID), OptInt (iConvID)]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
