## DelChatbotFromConversation

Метод предназначен для отключения чат-бота от разговора. 

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libChat", "DelChatbotFromConversation", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iConversationID_ \- ID разговора (целое число).  
     _iChatbotID_ \- ID чатбота (целое число).   
     _bClearOldChatbotChat_ \- закрывать все сценарии (булево) (необязательный). Значение по умолчанию - _false._ 

_Возвращаемое значение:_  
      Тип: **Объект**. Результат выполнения действия, включающий в себя следующие параметры:  
      _error_ – код ошибки (целое число).  
      _message_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libChat", "DelChatbotFromConversation", [ iConversationID, iChatbotID, bClearOldChatbotChat ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_``_;_`
