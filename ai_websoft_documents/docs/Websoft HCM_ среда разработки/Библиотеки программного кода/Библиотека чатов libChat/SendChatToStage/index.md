## SendChatToStage

Метод предназначен для перевода чата чат-бота на указанный этап. 

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libChat", "SendChatToStage", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя шесть параметров:  
     _iChatID_ \- ID чата чат-бота (целое число).  
     _iStageID_ \- ID этапа, на который переводится чат (целое число).  
     _sChatBotCode_ – код бота (строка) (необязательный).  
     _iPrevStageID_ \- ID предыдущего этапа (целое число) (необязательный).  
     _bReWriteLastMessage_ \- перезаписывать последнее сообщение в чате (булево) (необязательный). По умолчанию – _false_.  
     _iConversationID_ \- ID разговора (целое число) (необязательный). 

_Возвращаемое значение:_  
      Тип: **Объект**. Результат выполнения действия, включающий в себя следующие параметры:  
      _error_ – код ошибки (целое число).  
      _message_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libChat", "SendChatToStage", [ iChatID, iStageID, sChatBotCode, iPrevStageID, bReWriteLastMessage, iConversationID ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
