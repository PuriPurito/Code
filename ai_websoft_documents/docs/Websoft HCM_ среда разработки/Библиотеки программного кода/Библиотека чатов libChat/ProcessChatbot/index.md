## ProcessChatbot

Метод предназначен для обработки чат-ботом запроса, полученного от мессенджера. 

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libChat", "ProcessChatbot", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _sBotID_ - ID бота (строка).  
     _oMessage_ – сообщение (объект). Объект включает в себя ID сообщения, тип сообщения, ID чата и текст сообщения.  
     _iSenderID_ \- ID отправителя (целое число).  
     _iConversationID_ \- ID разговора (целое число) (необязательный).

_Возвращаемое значение:_  
      Тип: **Объект**. Результат выполнения действия, включающий в себя следующие параметры:  
      _error_ – код ошибки (целое число).  
      _message_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libChat", "ProcessChatbot", [ sBotID, oMessage, iSenderID, iConversationID ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
