## GetPolicyFiles

Метод **GetPolicyFiles** предназначен для получения списка файлов полиса.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libBenefit", "GetPolicyFiles", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _iPolicyID_ \- ID полиса (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень файлов полиса, а также ряд дополнительных атрибутов:  
\- _array_ \- массив файлов полиса (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID файла полиса (целое число).   
     _name_ – название файла (строка).  
     _type_ –тип файла (строка).  
     _link_ – ссылка на карточку файла полиса (строка).  
     _size_ – размер файла полиса (целое число). 

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libBenefit", "GetPolicyFiles", [iPolicyID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
