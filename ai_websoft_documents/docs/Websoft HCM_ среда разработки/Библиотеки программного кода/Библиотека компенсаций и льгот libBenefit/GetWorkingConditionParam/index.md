## GetWorkingConditionParam

Метод **GetWorkingConditionParam** предназначен для получения содержимого карточки условий работы.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libBenefit", "GetWorkingConditionParam", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iWorkingConditionIDParam_ \- ID условий работы (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию о содержимом карточки условий работы, а также ряд дополнительных атрибутов:  
\- _array_ \- массив карточек условий работы (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID карточки условий работы (целое число);  
     _name_ – наименование карточки условий работы (строка).  
     _value_ – значение условий работы (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libBenefit", "GetWorkingConditionParam", [iWorkingConditionIDParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
