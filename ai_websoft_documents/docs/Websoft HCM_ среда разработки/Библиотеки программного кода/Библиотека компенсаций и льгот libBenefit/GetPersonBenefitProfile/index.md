## GetPersonBenefitProfile

Метод **GetPersonBenefitProfile** предназначен для получения списка профилей льгот сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libBenefit", "GetPersonBenefitProfile", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _iPersonID_ \- ID сотрудника (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень профилей льгот сотрудника, а также ряд дополнительных атрибутов:  
\- _array_ \- массив профилей льгот (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID профиля льгот (целое число).  
     _code_ – код профиля льгот (строка).  
     _name_ – наименование профиля льгот (строка).  
     _status_ – статус профиля льгот (строка).  
     _benefit\_ids_ – ID типов привилегий (массив целых чисел).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libBenefit", "GetPersonBenefitProfile", [iPersonID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
