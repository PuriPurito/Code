## GetCollaboratorPolicyContext

Метод **GetCollaboratorPolicyContext** предназначен для получения контекста полиса сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libBenefit", "GetCollaboratorPolicyContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _oParam_ \- набор параметров для выбора полиса (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные контекста полиса сотрудника, а также ряд дополнительных атрибутов:  
\- _context_ \- контекст полиса сотрудника (объект).  
     Атрибуты отдельного объекта:  
     _id_ – ID полиса (целое число);  
     _type\_id_ – ID типа полиса (целое число);  
     _type\_name_ – наименование типа полиса (строка);  
     _start\_date_ – дата начала (строка);  
     _finish\_date_ – дата завершения (строка);  
     _number_ – номер полиса (строка);  
     _link_ – относительная ссылка на карточку типа полиса (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libBenefit", "GetCollaboratorPolicyContext", [iPersonID, oParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
