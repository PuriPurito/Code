## HandleEventLikeChannelEntry

Метод **HandleEventLikeChannelEntry** предназначен для обработки системных событий, связанных с лайками сообщений каналов.

  Примечание. Канал - это блог, имеющий тип **"Канал"**. Сообщение - это единица пользовательского контента.  

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLXP", "HandleEventLikeChannelEntry", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя шесть параметров:  
     _sTypeEvent_ \- тип обработки (создание/отмена лайка) (строка).  
     _teChannelEntry_ \- TopElem сообшения канала (объект).  
     _iUserID_ \- ID текущего пользователя (то есть того, который ставит лайк) (целое число).  
     _sCurrencyType_ \- тип валюты для построения рейтинга, в которой будут начислены баллы за лайк (строка) (См. **Общие настройки - Администрирование**). Основные доступные значения параметра - _'experts'_ (экспертные баллы), _'experience'_ (опыт), _'bonus'_ (бонусы), _'thanks'_ (благодарности), _'ball'_ (баллы). Значение по умолчанию - _'experts'_.  
     _iPoints_ \- количество начисляемых баллов в указанной валюте (целое число).  
     _sComment_ \- комментарий к транзакции (строка).

_Возвращаемые значения:_

Производит обработку системных событий, связанных с лайками сообщений каналов. Возвращаемое значение отсутствует.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLXP", "HandleEventLikeChannelEntry", [sTypeEvent, teChannelEntry, iUserID, sCurrencyType, iPoints, sComment]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
