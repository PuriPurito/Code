## GetChannelAuthors

Метод **GetChannelAuthors** предназначен для получения коллекции авторов канала.

  Примечание. Канал - это блог, имеющий тип **"Канал"**.  

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLXP", "GetChannelAuthors", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iChannelID_ \- ID канала (целое число).  
     _bExcludeOwner_ \- исключать из перечня авторов владельца канала (булево).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень авторов канала, а также ряд дополнительных атрибутов:  
\- _result_ \- массив авторов канала (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID канала в текстовом выражении (строка).  
     _name_ – ФИО автора канала (строка).  
     _img_ – URL изображения автора канала (строка).  
     _link_ – URL карточки автора канала (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLXP", "GetChannelAuthors", [iChannelID, bExcludeOwner]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
