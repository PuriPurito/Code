## GetPersonChannelsItems

Метод **GetPersonChannelsItems** предназначен для получения списка сообщений каналов.

Примечание. Канал - это блог, имеющий тип **"Канал"**. Сообщение - это единица пользовательского контента.  
Список каналов определяется коллекцией, заданной в параметре шаблона социальной ленты - _soc\_wall.sTargetCollectionId_.  

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLXP", "GetPersonChannelsItems", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _aListItems_ \- массив сообщений (массив объектов).  
     _aFilters_ \- набор фильтров (массив объектов) (параметры объекта: _id_ - ID фильтра (строка или массив строк), _type_ - тип фильтра (строка), _value_ - значение (строка)).   
     _iCollectionId_ \- ID коллекции (целое число).  
     _curObjectID_ \- ID текущего объекта (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень сообщений каналов, а также ряд дополнительных атрибутов:  
\- _channelsMessages_ \- массив сообщений каналов (массив объектов).  
     Атрибуты отдельного объекта:  
     _action_ \- действие (транзакция) (строка).  
     _error_ \- ошибка (строка).  
     _eof_ \- учитывать ли конец файла (булево).  
     _item_ \- массив сообщений (массив строк).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLXP", "GetPersonChannelsItems", [aListItems, aFilters, iCollectionId, curObjectID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
