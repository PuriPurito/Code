## SetChannelSubscribe

Метод **SetChannelSubscribe** предназначен для подписки пользователя на канал или отписки пользователя от канала.

  Примечание. Канал - это блог, имеющий тип **"Канал"**.  

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLXP", "SetChannelSubscribe", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _sCommand_ \- режим выполнения удаленного действия (строка). Допустимые значения: "eval" (создание и показ формы); "submit\_form" (обработка формы).  
     _iPersonID_ \- ID сотрудника (целое число).  
     _sChannelID_ \- ID канала в текстовом формате (строка).  
     _curObject_ \- TopElem текущего объекта (объект). 

_Возвращаемые значения:_

      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _result_ – результат вызова метода (объект).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLXP", "SetChannelSubscribe", [sCommand, iPersonID, sChannelID, curObject]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
