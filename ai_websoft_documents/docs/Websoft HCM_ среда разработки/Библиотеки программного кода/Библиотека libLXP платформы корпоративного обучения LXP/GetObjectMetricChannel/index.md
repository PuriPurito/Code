## GetObjectMetricChannel

Метод **GetObjectMetricChannel** предназначен для расчета объектной метрики канала.

  Примечание. Канал - это блог, имеющий тип **"Канал"**.  

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLXP", "GetObjectMetricChannel", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _ChannelIDParam_ \- ID текущего канала (целое число).  
     _PersonIDParam_ \- ID текущего или указанного сотрудника, для которого определяются метрики канала (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные об объектной метрики канала, а также ряд дополнительных атрибутов:  
\- _oMetric_ – метрика канала (объект).  
     Атрибуты объекта:  
     _isOwner_ – сотрудник является владельцем, создателем канала (булево).  
     _isAuthor_ – сотрудник является автором канала (булево).  
     _isAdministrator_ – сотрудник является автором-администратором канала (булево).  
     _isSubscriber_ – сотрудник является подписчиком канала (булево).  
     _PermitSubscribe_ – на канал возможна подписка (булево).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLXP", "GetObjectMetricChannel", [ChannelIDParam, PersonIDParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
