## HandleEventSubscribeChannel

Метод **HandleEventSubscribeChannel** предназначен для обработки системных событий, связанных с подписками на каналы.

  Примечание. Канал - это блог, имеющий тип **"Канал"**.  

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLXP", "HandleEventSubscribeChannel", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя семь параметров:  
     _sType_ \- тип обработки (подписка на канал или отмена подписки) (строка).  
     _iChannelID_ \- ID канала (на который подписывается пользователь) (целое число).  
     _teChannel_ \- TopElem канала, на который подписывается пользователь (объект) (необязательный).  
     _iPersonID_ \- ID пользователя (на кого оформлена подписка) (целое число).  
     _sCurrencyType_ \- тип валюты для построения рейтинга, в которой будут начислены баллы за подписку (строка) (См. **Общие настройки - Администрирование**). Основные доступные значения параметра - _'experts'_ (экспертные баллы), _'experience'_ (опыт), _'bonus'_ (бонусы), _'thanks'_ (благодарности), _'ball'_ (баллы). Значение по умолчанию - _'experts'._  
     _iPoints_ \- количество начисляемых баллов в указанной валюте (целое число).  
     _sComment_ \- комментарий к транзакции (строка).

_Возвращаемые значения:_

Производит обработку системных событий, связанных с подписками на каналы. Возвращаемое значение отсутствует.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLXP", "HandleEventSubscribeChannel", [sType, iChannelID, teChannel, iPersonID, sCurrencyType, iPoints, sComment]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
