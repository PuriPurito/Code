## ImportFeedInChannel

Метод **ImportFeedInChannel** предназначен для добавления элементов внешней ленты в канал.

  Примечание. Канал - это блог, имеющий тип **"Канал"**.  

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLXP", "ImportFeedInChannel", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iChannelID_ \- ID канала (целое число).  
     _arrFeedMessages_ \- коллекция сообщений внешней ленты (массив объектов). Состав параметров объекта: _id_ – ID записи ленты в текстовом формате (строка); _name_ – наименование записи (строка); _desc_ – содержание записи (строка); _update_ – дата обновления записи (дата). 

_Возвращаемые значения:_

Производит добавление элементов внешней ленты в канал. Возвращаемое значение отсутствует.

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLXP", "ImportFeedInChannel", [iChannelIDParam, arrFeedMessages]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
