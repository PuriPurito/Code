## ChangeChannel

Метод **ChangeChannel** предназначен для изменения канала.

  Примечание. Канал - это блог, имеющий тип **"Канал"**.  

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLXP", "ChangeChannel", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _sCommand_ \- режим выполнения удаленного действия (показ или обработка формы) (строка). Допустимые значения: _"eval"_ (создание и показ формы); _"submit\_form"_ (обработка формы).  
     _curObjectID_ \- ID текущего канала (целое число).  
     _curUserID_ \- ID текущего пользователя (целое число).  
     _oArgs_ \- аргументы (объект). Состав параметра: _sPersonID_ – ID сотрудника в текстовом формате (для подстановок) (строка); _iParentKnowlPart_ – корневое значение карты знаний (для отбора) (целое число); _sTagsRoleCode_ – код категории тегов (для отбора) (строка); _form\_fields_ – сериализованное содержимое формы (строка).

_Возвращаемые значения:_

      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _result_ – результат вызова метода (объект).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLXP", "ChangeChannel", [sCommand, curObjectID, curUserID, oArgs]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
