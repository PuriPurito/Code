## GetChannelsByAuthor

Метод **GetChannelsByAuthor** предназначен для получения списка каналов, в которых указанный сотрудник является автором.

  Примечание. Канал - это блог, имеющий тип **"Канал"**.  

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLXP", "GetChannelsByAuthor", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iAuthorIDParam_ \- ID сотрудника (автора) (целое число).  
     oPaging - информация из рантайма о пейджинге (объект). Объект включает в себя следующие данные:  INDEX - номер страницы (целое число);  SIZE - размер страницы (целое число); MANUAL - разделение на страницы вручную (булево); TOTAL - общее количество страниц (целое число).  
     oSort - информация из рантайма о сортировке (объект). Объект включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень каналов, в которых указанный сотрудник является автором, а также ряд дополнительных атрибутов:  
\- _channels_ \- массив каналов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID канала в текстовом выражении (строка).  
     _type_ – тип канала (строка).  
     _name_ – наименование канала (строка).

\- _result_ – результат вызова метода (объект).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLXP", "GetChannelsByAuthor", [iAuthorIDParam, oSort, oPaging]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
