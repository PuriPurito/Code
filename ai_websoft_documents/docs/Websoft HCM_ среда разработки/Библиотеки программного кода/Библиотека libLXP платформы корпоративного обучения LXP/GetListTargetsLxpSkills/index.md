## GetListTargetsLxpSkills

Метод **GetListTargetsLxpSkills** предназначен для получения списка каналов по уровню опыта пользователей.

  Примечание. Канал - это блог, имеющий тип **"Канал"**.  

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libLXP", "GetListTargetsLxpSkills", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя шесть параметров:  
     iPersonID - ID сотрудника (целое число).  
     Request - объект запроса (целое число).  
     isForPostEntrys - показывать только свои каналы (булево).  
     isIncludeAutorsChannels - включать в состав свои каналы (булево).  
     knowledgeTypeId - тип знания пользователя (строка). Значение по умолчанию - _all_.  
     bHierarchy - учитывать иерархию знаний (булево). Значение по умолчанию - _false_.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень каналов по уровню опыта пользователей, а также ряд дополнительных атрибутов:  
\- _array_ \- массив каналов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID канала в текстовом выражении (строка).  
     _type_ – тип канала (строка).  
     _name_ – наименование канала (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libLXP", "GetListTargetsLxpSkills", [iPersonID, Request, isForPostEntrys, isIncludeAutorsChannels, knowledgeTypeId, bHierarchy]);_`
