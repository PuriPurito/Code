## GetWorkspaceChildTasks

Метод **GetWorkspaceChildTasks** предназначен для получения списка списка дочерних задач.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "GetWorkspaceChildTasks", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _iTaskID_ \- ID задачи, для которой определяются дочерние задачи (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень дочерних задач, а также ряд дополнительных атрибутов:  
\- _array_ \- массив дочерних задач (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID задачи (целое число).  
     _name_ \- название задачи (строка).  
     _status_ \- статус задачи (строка).  
     _executor\_url_ \- ссылка на исполнителя задачи (строка).  
     _executor\_id_ \- ID исполнителя задачи (целое число).  
     _executor\_name_ \- ФИО исполнителя задачи (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "GetWorkspaceChildTasks", [iTaskID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
