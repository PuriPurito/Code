## GetCalendarEventsStatReport

Метод **GetCalendarEventsStatReport** предназначен для получения cтатистики по событиям календаря для отчета.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "GetCalendarEventsStatReport", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _oFilters_ \- объект с фильтрами для формирования отчета (объект). В состав объекта входят следующие параметры: object\_type - тип объекта (строка); state\_id - ID состояния(строка); date\_start - дата начала (дата); date\_end - дата окончания (дата).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию о событиях календаря для отчета, а также ряд дополнительных атрибутов:  
\- _result_ \- cтатистика по событиям календаря (объект).  
     Атрибуты объекта:  
     _event\_count_ \- количество событий(целое число).  
     _part\_count_ \- количество участников (целое число).  
     _avg\_part\_count_ \- среднее количество участников (целое число).  
     _duration\_plan_ \- плановая продолжительность в текстовом выражении (строка).  
     _avg\_duration\_plan_ \- средняя плановая продолжительность в текстовом выражении (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "GetCalendarEventsStatReport", [iCurUserID, oFilters]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
