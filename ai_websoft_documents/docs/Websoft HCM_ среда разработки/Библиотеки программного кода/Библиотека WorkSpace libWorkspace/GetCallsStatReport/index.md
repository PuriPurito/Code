## GetCallsStatReport

Метод **GetCallsStatReport** предназначен для получения cтатистики по звонкам для отчета.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "GetCallsStatReport", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _oFilters_ \- объект с фильтрами для формирования отчета (объект). В состав объекта входят следующие параметры: state\_id - ID состояния(строка); date\_start - дата начала (дата); date\_end - дата окончания (дата).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию о звонках для отчета, а также ряд дополнительных атрибутов:  
\- _result_ \- cтатистика по звонкам (объект).  
     Атрибуты объекта:  
     _call\_count_ \- количество звонков (целое число).  
     _part\_count_ \- количество участников (целое число).  
     _avg\_part\_count_ \- среднее количество участников (целое число).  
     _duration_ \- продолжительность в текстовом выражении (строка).  
     _avg\_duration_ – средняя длительность одного звонка (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "GetCallsStatReport", [iCurUserID, oFilters]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
