## GetConversationMessages

Метод **GetConversationMessages** предназначен для получения списка сообщений из последнего блока сообщений разговора.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "GetConversationMessages", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _iConversationIDParam_ \- ID разговора (целое число).  
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень сообщений из последнего блока сообщений разговора, а также ряд дополнительных атрибутов:  
\- _array_ \- массив сообщений из последнего блока сообщений разговора (массив объектов).  
     Атрибуты отдельного объекта:  
     _block\_message\_id_ – ID блока сообщений (целое число).  
     _text_ – текст сообщения (строка).  
     _author_ – автор сообщения (строка).  
     _date_ – дата сообщения (дата).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "GetConversationMessages", [iConversationIDParam, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
