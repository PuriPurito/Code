## GetTaskWorkflowActions

Метод **GetTaskWorkflowActions** предназначен для получения списка действий документооборота.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "GetTaskWorkflowActions", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _iTaskID_ \- ID задачи в текстовом формате (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень действий документооборота, а также ряд дополнительных атрибутов:  
\- actions - массив действий документооборота (массив объектов).  
     Атрибуты отдельного объекта:  
     id – ID действия документооборота (целое число);  
     name – действия документооборота (строка).

\- result – результат вызова метода (true – если операция завершилась успешно, false – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "GetTaskWorkflowActions", [iTaskID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
