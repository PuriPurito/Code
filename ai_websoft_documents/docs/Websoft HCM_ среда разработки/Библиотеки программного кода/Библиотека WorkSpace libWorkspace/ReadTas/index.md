## ReadTas

Метод **ReadTask** предназначен для пометки задач прочитанными.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "ReadTask", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _aTaskIds_ \- массив ID задач, помечаемых прочитанными, в текстовом формате(массив строк).

_Возвращаемое значение:_  
      Тип: **Объект**.

Содержит информацию о задачах, помеченных прочитанными, а также ряд дополнительных атрибутов:  
\- _tasks_ - массив ID задач, помеченных прочитанными, в текстовом формате (массив строк).

\- _result_ – результат вызова метода (true – если операция завершилась успешно, false – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _error\_string_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "ReadTask", [aTaskIds]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
