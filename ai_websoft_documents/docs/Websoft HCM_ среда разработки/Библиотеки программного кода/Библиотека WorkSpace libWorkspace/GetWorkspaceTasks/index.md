## GetWorkspaceTasks

Метод **GetWorkspaceTasks** предназначен для получения списка задач функционала WorkSpace.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "GetWorkspaceTasks", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя следующие параметры:  
     _iPersonID_ \- ID пользователя (целое число).  
     _tePerson_ \- TopElem сотрудника (разговора) (объект XmlDoc) (необязательный).  
     _iTaskTypeID_ \- ID типа задачи функционала WorkSpace (целое число).  
     _sPeriodType_ – период отбора (строка) (необязательный). Допустимые значения: week; month; quarter; year.  
     _sSearchText_ \- критерий поиска для отбора (строка) (необязательный).  
     _sTaskType_ \- тип задачи для отбора (строка) (необязательный). Допустимые значения: my (задачи пользователя); subordinates (задачи подчиненных пользователя); all (все задачи).  
     _sStateID_ \- ID статуса задачи (строка) (необязательный).  
     _sCustomStateID_ \- ID кастомного статуса задачи (строка) (необязательный).  
     _iSourceObjectID_ \- ID объекта-источника (целое число) (необязательный).  
     _bUsePageByCustomState_ \- учитывать ли пейджинг по настраиваемым статусам (булево) (необязательный).  
     _iPageNum_ \- номер страницы (целое число) (необязательный).  
     _iPageSize_ \- размер страницы (целое число) (необязательный).  
     _sSortField_ \- поле для сортировки (строка) (необязательный).   
     _sSortDirection_ \- направление для сортировки (строка) (необязательный). Допустимые значения: asc (по возрастанию); desc (по убыванию). Значение по умолчанию: asc.  
     _sExpireType_ \- тип просроченной задачи (строка) (необязательный). Допустимые значения: all (все задачи); without\_date (задачи без даты завершения); expired (истекшие); expire\_day (истекшие в течение одних суток и менее); expire\_week (истекшие в течение одной недели и менее); expire\_month (истекшие в течение одного месяца и менее); period (указанный период)).  
     _bList_ \- производить ли отбор задач по списку (булево) (необязательный). Значение по умолчанию – false.  
     _iExecutorID_ \- ID ответственного (целое число) (необязательный).  
     _sTaskNameSearch_ \- критерий поиска по названию (строка) (необязательный). Значение по умолчанию – пустая строка.  
     _dStartExpireDate_ \- дата начала срока истечения (дата).  
     _dFinishExpireDate_ \- дата окончания срока истечения (дата).  
     _arrFilters_ \- набор фильтров (массив объектов). Каждый объект массива включает в себя следующие данные: id - ID фильтра (строка), type - тип фильтра (строка), value - критерий отбора (строка).  
     _arrDistincts_ \- перечень полей для формирования дополнительных списков для виджета фильтров (массив строк) (необязательный).  
     _aSortArray_ \- массив полей сортировки (объект). В состав объекта могут входить следующие параметры: field - поле сортировки (строка); direction - направление сортировки (строка) ("asc" или "desc").

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень задач функционала WorkSpace, а также ряд дополнительных атрибутов:  
\- _total_ – общее количество задач (целое число).  
\- _state\_total_ – общее кол-во записей по статусам (массив объектов). Каждый объект массива может включать в себя следующие данные: id - ID записи в текстовом формате (строка); total - количество (целое число); current - номер текущей записи (целое число); full - рассмотрены ли все задачи (булево).  
\- _data_ \- результирующие данные (объект).  
\- _array_ \- массив задач функционала WorkSpace (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID задачи (целое число);  
     _name_ \- название задачи (строка);  
     _executor\_url_ \- ссылка на карточку ответственного исполнителя (строка);  
     _executor\_id_ \- ID ответственного исполнителя (целое число);  
     _executor\_name_ \- ФИО ответственного исполнителя (строка);  
     _status_ \- статус задачи (строка);   
     _finished_ \- завершена ли задача (булево);  
     _custom\_state\_id_ \- ID кастомного статуса задачи (строка);  
     _priority_ \- приоритет (строка);  
     _start\_date_ \- начало задачи (дата);   
     _end\_date_ \- завершение задачи (дата);  
     _parent\_task\_id_ \- ID родительской задачи (целое число);  
     _parent\_task\_name_ \- название родительской задачи (строка);  
     _time\_entry\_duration_ \- продолжительность просмотра задачи в секундах (целое число).  
     _project\_id_ \- ID проекта (целое число);  
     _project\_name_ \- название проекта (строка);  
     _conversation\_url_ - ссылка на карточку разговора (строка);  
     _activity\_url_ \- ссылка на карточку действия (строка).  
     _has\_files_ \- имеются ли вложенные файлы (булево).  
     _is\_read_ \- прочитана ли задача (булево).  
     _custom\_elems_ \- дополнительные элементы (массив объектов). В состав объекта могут входить  следующие параметры: name - название (строка); title - заголовок на портале (строка); type - тип (строка); value - значение (строка); display\_value - отображаемон значение (строка); is\_required - обязателен ли объект (булево); catalog - каталог (строка); xquery\_qual - текст поиска, который используется в конструкции where (строка); entries - входные значения (массив объектов). 

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "GetWorkspaceTasks", [iPersonID, tePerson, iTaskTypeID, sPeriodType, sSearchText, sTaskType, sStateID, sCustomStateID, iSourceObjectID, bUsePageByCustomState, iPageNum, iPageSize, sSortField, sSortDirection, sExpireType, bList, iExecutorID, sTaskNameSearch, dStartExpireDate, dFinishExpireDate, arrFilters, arrDistincts]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
