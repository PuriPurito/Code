## GetWorkspaceTaskTypes

Метод **GetWorkspaceTaskTypes** предназначен для получения списка типов задач функционала WorkSpace.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "GetWorkspaceTaskTypes", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID пользователя (целое число).  
     _tePerson_ \- TopElem сотрудника (разговора) (объект XmlDoc) (необязательный).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень типов задач функционала WorkSpace, а также ряд дополнительных атрибутов:  
\- array - массив типов задач функционала Workspace (массив объектов).  
     Атрибуты отдельного объекта:  
    _id_ – ID типа задачи (строка);  
    _name_ – название задачи (строка);  
    _virtual_ – является ли задача виртуальной (булево);  
    _view\_task\_type\_id_ \- ID типа видимости задачи (строка);  
    _can\_view\_subordinate_ – могут ли видеть задачу подчиненные (булево);  
    _related\_to\_projects_ – связана ли задача с проектами (булево);  
    _can\_change\_status_ – разрешено ли изменение статуса задачи (булево);  
    _can\_change\_task_ – разрешено ли изменение задачи (булево);  
    _create\_task\_type\_id_ \- ID типа формирования задачи (строка);  
    _edit\_task\_type\_id_ \- ID типа редактирования задачи (строка);  
    _related\_object\_type_ \- тип связанного объекта (строка);  
    _virtual\_remote\_action\_id_ \- виртуальный идентификатор удаленного действия (целое число).  
    workflow\_remote\_action\_id - идентификатор удаленного действия документооборота (целое число).  
    _can\_delete\_task_ – разрешено ли удаление задачи (булево);  
    _consider\_time_ \- учитывать ли время выполнения задачи (в интерфейсе WorkSpace) (булево);  
    _mandatory\_project_ \- является ли обязательной связь задачи с проектом (булево);  
    _mandatory\_parent\_task_ \- является ли обязательным наличие родительской задачи (булево);  
    _states_ – статусы задачи (массив объектов). Параметры объекта: id - ID статуса в текстовом формате (строка); name - название статуса (строка).  
    _custom\_states_ – кастомные (пользовательские) статусы задачи (массив объектов). Параметры объекта: id - код пользовательского статуса в текстовом формате (строка); name - название пользовательского статуса (строка); workflow\_state - статус документооборота (строка); state\_id - ID статуса в текстовом формате (строка).  
    _disp\_fields_ \- отображаемые поля (массив строк);  
    _is\_workflow_ \- связана ли задача с документооборотом (булево).  
    _can\_change\_view_ \- можно ли разрешать переключение способ отображения (булево).  
    _default\_display\_mode_ \- способ отображения по умолчанию (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "GetWorkspaceTaskTypes", [iPersonID, tePerson]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
