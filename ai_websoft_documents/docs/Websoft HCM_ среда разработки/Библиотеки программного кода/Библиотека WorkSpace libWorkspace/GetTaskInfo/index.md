## GetTaskInfo

Метод **GetTaskInfo** предназначен для получения данных о задаче функционала WorkSpace.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "GetTaskInfo", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя три параметра:  
     _iPersonID_ \- ID пользователя (целое число).  
     _iTaskID_ \- ID задачи функционала WorkSpace (целое число).  
     _tePerson_ \- TopElem сотрудника (разговора) (объект XmlDoc) (необязательный).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о задаче функционала WorkSpace, а также ряд дополнительных атрибутов:  
\- task\_info - данные о задаче функционала WorkSpace (объект).  
     Атрибуты объекта:  
     _id_ \- ID задачи (целое число);  
     _code_ \- код задачи (строка);  
     _name_ \- название задачи (строка);  
     _executor\_id_ \- ID ответственного исполнителя (целое число);  
     _executor\_name_ \- ФИО ответственного исполнителя (строка);  
     _assigner\_id_ \- ID сотрудника, назначившего задачу (целое число);  
     _assigner\_name_ \- ФИО сотрудника, назначившего задачу (строка);  
     _parent\_task\_id_ \- ID родительской задачи (целое число);  
     _parent\_task\_name_ \- название родительской задачи (строка);  
     _status_ \- статус задачи (строка);   
     _custom\_state\_id_ \- ID кастомного статуса задачи (строка);  
     _source\_object\_type_ \- тип источника задачи (строка);  
     _source\_object\_id_ \- ID источника задачи (целое число);  
     _source\_object\_name_ \- название источника задачи (строка);  
     _priority_ \- приоритет (строка);  
     _start\_date_ \- начало задачи (дата);   
     _end\_date_ \- завершение задачи (дата);  
     _files_ \- сведения о файлах (массив объектов) (ID (целое число), тип (строка), название файла (строка), URL файла (строка));  
     _custom\_elems_ – массив пользовательских элементов (полей) (массив объектов). Параметры объекта: name - название поля в системе (строка); title - название поля на портале (строка); type - тип поля (строка); value - значение в текстовом формате (строка); display\_value - отображаемое значение в текстовом формате (строка); is\_required - является ли поле обязательным для заполнения (булево);  catalog - каталог, связанный с данным полем (строка); xquery\_qual - дополнительный фильтр XQuery для отбора (строка); entries - допустимые значения поля для ввода информации пользователем (массив объектов) (параметр объекта: value - значение (строка)).  
     _workflow\_fields_ \- поля документооборота (массив объектов);  
     _can\_edit_ \- можно ли редактировать задачу (булево);  
     _can\_delete_ \- можно ли удалить задачу (булево);  
     _can\_edit\_status_ \- можно ли редактировать статус задачи (булево).  
     _is\_read_ \- прочитана ли задача (булево).  
     _message\_count_ \- количество сообщений (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "GetTaskInfo", [iPersonID, iTaskID, tePerson]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
