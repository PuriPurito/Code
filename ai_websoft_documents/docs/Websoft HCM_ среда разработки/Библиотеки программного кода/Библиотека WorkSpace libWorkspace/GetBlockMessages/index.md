## GetBlockMessages

Метод **GetBlockMessages** предназначен для получения списка блоков сообщений.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "GetBlockMessages", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя четыре параметра:  
     _iConversationIDParam_ \- ID разговора (целое число).  
     _bArchive_ \- выводить ли все блоки сообщений, помимо самого последнего (булево).  
     _sXQueryQual_ \- дополнительный фильтр XQuery для отбора (строка) (необязательный).  
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень блоков сообщений, а также ряд дополнительных атрибутов:  
\- _array_ \- массив блоков сообщений (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID блока сообщения (целое число).  
     _last\_message\_date_ \- дата последнего сообщения (дата).   
     _create\_date_ \- дата создания блока (дата).  
     _count\_message_ \- количество сообщений в блоке (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "GetBlockMessages", [iConversationIDParam, bArchive, sXQueryQual, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
