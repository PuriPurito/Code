## TaskTypeAddChange

Метод **TaskTypeAddChange** предназначен для добавления/изменения типа задачи.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "TaskTypeAddChange", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _sTaskTypeID_ \- ID типа задачи для изменения в текстовом формате (строка).  
     _oParams_ \- параметры удаленного действия (объект). В состав объекта могут входить следующие параметры: code - код задачи (строка); name - название задачи (строка); can\_change\_task - разрешено ли изменение задачи (булево); can\_change\_status - разрешено ли изменение статуса (булево); can\_delete\_task - разрешено ли удаление задачи (булево); consider\_time\_in\_workspace - учитывать ли время выполнения (булево); view\_task\_type\_id - тип сотрудника, который может просматривать задачи (строка); create\_task\_type\_id - тип сотрудника, который может создавать задачи (строка); edit\_task\_type\_id - тип сотрудника, который может изменять задачи (строка); custom\_states - настраиваемые статусы (объект) (name - название объекта (строка); parent\_task\_type\_id - ID типа родительской задачи (целое число); parent\_task\_states - статусы родительской задачи (массив строк); mandatory\_parent\_task - обязательна ли родительская задача (булево); related\_to\_projects - связаны ли задачи с проектами (булево); mandatory\_project - обязателен ли выбор проекта (булево); show\_in\_workspace - показывается ли создаваемый тип задачи в Workspace (булево). 

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "TaskTypeAddChange", [sTaskTypeID, oParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
