## GetSubordinateUsers

Метод **GetSubordinateUsers** предназначен для получения списка подчиненных сотрудников в функционале WorkSpace.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "GetSubordinateUsers", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя десять параметров:  
     _sSearch_ \- критерий поиска для отбора (строка) (необязательный).  
     _sSearchFullname_ \-  критерий поиска для отбора по ФИО (строка) (необязательный).  
     _iPageNum_ \- номер страницы (целое число) (необязательный).  
     _iPageSize_ \- размер страницы (целое число) (необязательный).  
     _sSortField_ \- поле для сортировки (строка) (необязательный).  
     _sSortDirection_ \- направление для сортировки (asc/desc) (строка) (необязательный).  
     _iTaskTypeID_ \- ID типа задачи (целое число) (необязательный).  
     _iProjectID_ \- ID проекта в текстовом формате (необязательный) (строка).  
     _teTaskType_ \- TopElem типа задачи (необязательный) (объект XmlElem).  
     _iTaskID_ \- ID задачи в текстовом формате (необязательный) (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень подчиненных сотрудников в функционале WorkSpace, а также ряд дополнительных атрибутов:  
\- _users_ - массив подчиненных сотрудников (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID сотрудника (целое число);  
     _fullname_ – ФИО сотрудника (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "GetSubordinateUsers", [sSearch, sSearchFullname, iPageNum, iPageSize, sSortField, sSortDirection, iTaskTypeID, iProjectID, teTaskType, iTaskID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
