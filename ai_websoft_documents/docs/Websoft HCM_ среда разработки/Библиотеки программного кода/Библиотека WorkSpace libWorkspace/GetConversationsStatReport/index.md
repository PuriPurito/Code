## GetConversationsStatReport

Метод **GetConversationsStatReport** предназначен для получения cтатистики по чатам для отчета.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "GetConversationsStatReport", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _oFilters_ \- объект с фильтрами для формирования отчета (объект). В состав объекта входят следующие параметры: conversation\_type\_id - ID типа разговора (целое число); state\_id - ID состояния (строка); format\_id - ID формата (строка); date\_start - дата начала (дата); date\_end - дата окончания (дата).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию о чатах для отчета, а также ряд дополнительных атрибутов:  
\- _result_ \- cтатистика по чатам (объект).  
     Атрибуты объекта:  
     _chat\_count_ \- количество чатов (целое число).  
     _message\_count_ \- количество сообщений (целое число).  
     _file\_count_ \- количество файлов (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "GetConversationsStatReport", [iCurUserID, oFilters]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
