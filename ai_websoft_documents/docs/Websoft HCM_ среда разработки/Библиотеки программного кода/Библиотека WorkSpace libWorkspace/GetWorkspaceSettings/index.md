## GetWorkspaceSettings

Метод **GetWorkspaceSettings** предназначен для получения настроек функционала WorkSpace.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "GetWorkspaceSettings", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Данный метод вызывается без аргументов. Для данного метода используется пустой массив аргументов.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о настройках функционала WorkSpace, а также ряд дополнительных атрибутов:  
\- settings – данные о настройках функционала WorkSpace (объект).  
     Атрибуты объекта:  
     _cur\_user\_id_ – ID текущего пользователя функционала WorkSpace (целое число);  
     _cur\_user\_fullname_ – ФИО текущего пользователя (строка);  
     _cur\_user\_position\_name_ – название должности текущего пользователя (строка);  
     _access_ – разрешен ли текущему пользователю доступ к функционалу WorkSpace (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "GetWorkspaceSettings", []);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
