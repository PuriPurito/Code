## GetConversations

Метод **GetConversations** предназначен для получения списка разговоров.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "GetConversations", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя восемь параметров:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _sAccessType_ \- тип доступа для отбора (строка) (необязательный). Допустимые значения: "admin" (администратор приложения); "manager" (администратор процесса); "admin\_workspace" (администратор рабочего пространства); "moderator" (модератор); "observer" (наблюдатель); "auto" (определяется автоматически в соответствии с правами доступа пользователя). Значение по умолчанию - "auto".  
     _sApplication_ \- код приложения для определения доступа (строка).  
     _aTypes_ \- массив ID типов разговоров для отбора (массив целых чисел) (необязательный).  
     _aStates_ \- массив статусов разговоров для отбора (массив строк) (необязательный).  
     _aFormats_ \- форматы разговоров для отбора (массив строк) (необязательный).  
     _sXQueryQual_ \- дополнительный фильтр XQuery для отбора (строка) (необязательный).  
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень разговоров, а также ряд дополнительных атрибутов:  
\- _array_ \- массив разговоров (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID разговора (целое число).  
     _name_ \- название разговора (строка).  
     _create\_date_ \- дата создания разговора (дата).  
     _message\_count_ \- количество сообщений (целое число).  
     _type_ \- тип разговора (строка).  
     _state_ \- статус разговора (строка).  
     _format_ – формат разговора (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "GetConversations", [iCurUserID, sAccessType, sApplication, aTypes, aStates, aFormats, sXQueryQual, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
