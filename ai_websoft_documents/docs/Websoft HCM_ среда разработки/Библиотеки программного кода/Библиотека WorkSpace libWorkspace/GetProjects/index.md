## GetProjects

Метод **GetProjects** предназначен для получения списка проектов.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "GetProjects", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя четыре параметра:  
     _sSearch_ \- дополнительный критерий полнотекстового поиска в формате XQuery для отбора (строка) (необязательный).  
     _iPageNum_ \- номер страницы (целое число) (необязательный).  
     _iPageSize_ \- размер страницы (целое число) (необязательный).  
     _iExecutorID_ \- ID ответственного в текстовом формате (строка) (необязательный).

_Возвращаемое значение:_  
      Тип: **Объект**.

Содержит перечень проектов, а также ряд дополнительных атрибутов:  
\- projects - массив проектов (массив объектов).  
     Атрибуты отдельного объекта:  
     id – ID проекта (целое число);  
     name – название проекта (строка).

\- result – результат вызова метода (true – если операция завершилась успешно, false – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "GetProjects", [sSearch, iPageNum, iPageSize, iExecutorID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
