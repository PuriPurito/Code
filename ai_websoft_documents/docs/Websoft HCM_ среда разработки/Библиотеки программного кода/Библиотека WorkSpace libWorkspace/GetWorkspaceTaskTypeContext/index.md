## GetWorkspaceTaskTypeContext

Метод **GetWorkspaceTaskTypeContext** предназначен для получения контекста для типа задачи.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "GetWorkspaceTaskTypeContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _iWorkspaceTaskTypeIDParam_ \- ID типа задачи (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию о типе задачи, а также ряд дополнительных атрибутов:  
\- _context_ \- контекст для типа задачи (массив объектов).  
     Атрибуты отдельного объекта:  
     _task\_count_ – общее количество задач (целое число).  
     _success\_task\_count_ – количество выполненных задач (целое число).  
     _active\_task\_count_ – количество задач, находящихся в процессе выполнения (целое число).  
     _plan\_task\_count_ – количество запланированных задач (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "GetWorkspaceTaskTypeContext", [iWorkspaceTaskTypeIDParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
