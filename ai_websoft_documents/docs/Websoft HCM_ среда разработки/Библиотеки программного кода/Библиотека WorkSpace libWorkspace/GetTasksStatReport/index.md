## GetTasksStatReport

Метод **GetTasksStatReport** предназначен для получения cтатистики по задачам для отчета.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "GetTasksStatReport", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _oFilters_ \- объект с фильтрами для формирования отчета (объект). В состав объекта входят следующие параметры: task\_type\_id - ID типа задачи (целое число); status – статус (строка); date\_start - дата начала (дата); date\_end - дата окончания (дата).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию о задачах для отчета, а также ряд дополнительных атрибутов:  
\- _result_ \- cтатистика по задачам (объект).  
     Атрибуты объекта:  
     _task\_count_ \- общее количество задач (целое число).  
     _plan\_task\_count_ \- количество запланированных задач (целое число).  
     _ready\_task\_count_ \- количество оконченных задач (целое число).  
     _process\_task\_count_ \- количество задач, находящихся в процессе выполнения (целое число).  
     _complete\_task\_count_ \- количество выполненных задач (целое число).  
     _cancel\_task\_count_ \- количество завершенных задач (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "GetTasksStatReport", [iCurUserID, oFilters]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
