## GetConversationContext

Метод **GetConversationContext** предназначен для получения контекста для разговора.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "GetConversationContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _iConversationIDParam_ \- ID разговора (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит информацию о разговоре, а также ряд дополнительных атрибутов:  
\- _context_ \- контекст для разговора (объект).  
     Атрибуты объекта:  
     _participants\_count_ – количество участников (целое число).  
     _messages\_count_ – количество сообщений (целое число).  
     _chat\_calls\_count_ – количество звонков из чата (целое число).  
     _calendar\_calls\_count_ – количество звонков из календаря (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "GetConversationContext", [iConversationIDParam]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
