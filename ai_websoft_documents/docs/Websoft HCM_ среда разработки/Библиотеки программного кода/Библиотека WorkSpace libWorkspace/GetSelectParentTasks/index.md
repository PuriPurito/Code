## GetSelectParentTasks

Метод **GetSelectParentTasks** предназначен для получения списка задач (для выбора родительской задачи).

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "GetSelectParentTasks", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя пять параметров:  
     _iTaskTypeID_ \- ID типа задачи в текстовом формате (строка) (необязательный).  
     _sSearch_ \- дополнительный критерий полнотекстового поиска в формате XQuery для отбора (строка) (необязательный).  
     _iPageNum_ \- номер страницы (целое число) (необязательный).  
     _iPageSize_ \- размер страницы (целое число) (необязательный).  
     _iTaskID_ \- ID задачи (целое число) (необязательный).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень задач, а также ряд дополнительных атрибутов:  
\- _tasks_ \- массив задач (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID задачи (целое число);  
     _name_ – задачи проекта (строка).

\- _result_ – результат вызова метода (true – если операция завершилась успешно, false – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "GetSelectParentTasks", [iTaskTypeID, sSearch, iPageNum, iPageSize, iTaskID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
