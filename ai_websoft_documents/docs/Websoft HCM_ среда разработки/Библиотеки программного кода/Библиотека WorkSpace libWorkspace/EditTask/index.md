## EditTask

Метод **EditTask** предназначен для получения данных о задаче функционала WorkSpace.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "EditTask", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя пять параметров:  
     _iPersonID_ \- ID пользователя (целое число).  
     _iTaskID_ \- ID задачи функционала WorkSpace (целое число).  
     _iTaskTypeID_ \- ID типа задачи функционала WorkSpace (целое число).  
     _oTaskInfo_ \- данные по задаче функционала WorkSpace (объект). В объект входят следующие параметры: id (ID задачи (целое число)); code (код задачи (строка)); name (код задачи (строка)); executor\_id (ID ответственного исполнителя задачи (целое число)); executor\_name (имя ответственного исполнителя задачи (строка)); parent\_task\_id (ID родительской задачи (целое число)); parent\_task\_name (название родительской задачи (строка)); status (статус задачи (строка)); custom\_state\_id (ID кастомного статуса задачи (строка)); priority (приоритет задачи (строка)); start\_date (начало задачи (дата)); end\_date (конец задачи (дата)); files (информация о файлах (массив объектов)).  
     sWorkflowActionID - ID действия документооборота в текстовом формате (строка) (необязательный). 

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _task\_id_ – ID задачи (целое число).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "EditTask", [iPersonID, iTaskID, iTaskTypeID, oTaskInfo, sWorkflowActionID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
