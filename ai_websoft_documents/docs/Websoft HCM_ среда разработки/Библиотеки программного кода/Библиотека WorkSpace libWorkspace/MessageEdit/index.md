## MessageEdit

Метод **MessageEdit** предназначен для изменения сообщения в блоке сообщений.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "MessageEdit", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя четыре параметра:  
     _iBlockMessageID_ \- ID блока сообщений (целое число).  
     _sMessageID_ \- ID сообщения в текстовом формате (строка).  
     _sText_ \- текст сообщения (строка).  
     _aFiles_ \- массив файлов (массив объектов). Каждый объект массива включает в себя следующие данные: name - название файла (строка); value - значение (целое число).

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "MessageEdit", [iBlockMessageID, sMessageID, sText, aFiles]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
