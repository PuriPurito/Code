## GetCalendarEvent

Метод **GetCalendarEvent** предназначен для получения списка событий календаря.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "GetCalendarEvent", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя восемь параметров:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _sAccessType_ \- тип доступа для отбора (строка) (необязательный). Допустимые значения: "admin" (администратор приложения); "manager" (администратор процесса); "admin\_workspace" (администратор рабочего пространства); "moderator" (модератор); "observer" (наблюдатель); "auto" (определяется автоматически в соответствии с правами доступа пользователя). Значение по умолчанию - "auto".  
     _sApplication_ \- код приложения для определения доступа (строка).  
     _sObjectType_ \- тип объектов, для которого отбираются события (строка) (необязательный). Значение по умолчанию - "event".  
     _aCalendarType_ \- массив типов повторения для отбора (массив строк) (необязательный).  
     _aStates_ \- массив статусов событий для отбора (массив строк) (необязательный).  
     _sXQueryQual_ \- дополнительный фильтр XQuery для отбора (строка) (необязательный).  
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень событий календаря, а также ряд дополнительных атрибутов:  
\- _array_ \- массив событий календаря (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID события (целое число).  
     _name_ \- название события (строка).  
     _plan\_start\_date_ \- дата планового начала события (дата).  
     _start\_time_ \- время планового начала события (строка).  
     _end\_time_ \- время планового завершения события (строка).  
     _plan\_start\_date\_time_ \- планируемая дата и время начала (дата).  
     _start\_date_ \- дата начала (дата).  
     _end\_date_ \- дата завершения (дата).  
     _state_ \- статус (строка).  
     _person\_id_ \- ID создателя события (целое число).  
     _person\_fullname_ \- создатель события (строка).  
     _participants\_count_ \- количество участников в событии (целое число).  
     _tutors\_count_ \- количество ответственных в событии (целое число).  
     _duration_ \- длительность события в формате «чч:мм:сс» (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "GetCalendarEvent", [iCurUserID, sAccessType, sApplication, sObjectType, aCalendarType, aStates, sXQueryQual, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
