## GetWorkspaceTaskChanges

Метод **GetWorkspaceTaskChanges** предназначен для получения списка изменений по задаче.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "GetWorkspaceTaskChanges", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _iTaskID_ \- ID задачи (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень изменений по задаче, а также ряд дополнительных атрибутов:  
\- array - массив изменений по задаче (массив объектов).  
     Атрибуты отдельного объекта:  
     id - ID задачи (целое число).  
     name - название задачи (строка).  
     person\_url - ссылка на исполнителя задачи (строка).  
     person\_id - ID исполнителя задачи (целое число).  
     person\_fullname - ФИО исполнителя задачи (строка).  
     create\_date - дата изменения задачи (дата).  
     desc - описание (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "GetWorkspaceTaskChanges", [iTaskID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
