## GetCalls

Метод **GetCalls** предназначен для получения списка звонков.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libWorkspace", "GetCalls", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя шесть параметров:  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _sAccessType_ \- тип доступа для отбора (строка) (необязательный). Допустимые значения: "admin" (администратор приложения); "manager" (администратор процесса); "admin\_workspace" (администратор рабочего пространства); "moderator" (модератор); "observer" (наблюдатель); "auto" (определяется автоматически в соответствии с правами доступа пользователя). Значение по умолчанию - "auto".  
     _sApplication_ \- код приложения для определения доступа (строка).  
     _aStates_ \- массив статусов звонков для отбора (массив строк) (необязательный).  
     _sXQueryQual_ \- дополнительный фильтр XQuery для отбора (строка) (необязательный).  
     _oCollectionParams_ \- набор интерактивных параметров (отбор, сортировка, пейджинг) (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень звонков, а также ряд дополнительных атрибутов:  
\- _array_ \- массив звонков (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID звонка (целое число).  
     _name_ \- название звонка (строка).  
     _conversation_ – разговор (строка).  
     _start\_date_ \- начало звонка (дата).   
     _end\_date_ \- завершение звонка (дата).  
     _plan\_start\_date_ \- плановое начало звонка (дата).  
     _plan\_end\_date_ \- плановое завершение звонка (дата).  
     _state_ \- статус (строка).  
     _person\_fullname_ \- ФИО автора (инициатора) (строка).  
     _participants\_count_ \- количество участников (целое число).  
     _duration_ \- продолжительность в текстовом выражении (строка).  
     _plan\_duration_ \- плановая продолжительность в текстовом выражении (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libWorkspace", "GetCalls", [iCurUserID, sAccessType, sApplication, aStates, sXQueryQual, oCollectionParams]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
