## Библиотека для мини-сценариев по групповому обучению libScriptEducation

В настоящем разделе представлена библиотека для мини-сценариев по групповому обучению (библиотека программного кода **libScriptEducation**). Библиотека зарегистрирована в разделе **Дизайнер – Библиотеки программного кода – libScriptEducation**.

Подробнее об использовании группового обучения – см. _здесь_.

Примечание - По состоянию на июнь 2024 г. библиотека предназначена исключительно для внутренних нужд системы и не содержит публичных методов.
