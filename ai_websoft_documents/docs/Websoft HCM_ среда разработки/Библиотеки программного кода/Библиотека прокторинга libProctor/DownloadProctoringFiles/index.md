## DownloadProctoringFiles

Метод предназначен для загрузки файлов _прокторинга_ в WebTutor.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProctor", "DownloadProctoringFiles", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iLearningRecordID_ \- ID записи прокторинга (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект**. Результат выполнения действия, включающий в себя следующие параметры:  
\- error - код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- message – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProctor", "DownloadProctoringFiles", [ iLearningRecordID ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
