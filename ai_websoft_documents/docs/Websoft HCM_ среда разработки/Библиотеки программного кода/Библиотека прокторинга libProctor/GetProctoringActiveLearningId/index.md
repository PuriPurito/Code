## GetProctoringActiveLearningId

Метод предназначен для получения ID назначенного обучения для _прокторинга_.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProctor", "GetProctoringActiveLearningId", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iLearningRecordID_ \- ID записи прокторинга (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит ID назначенного обучения, а также ряд дополнительных атрибутов:  
\- _object\_id_ \- ID назначенного обучения (целое число или строка).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_ – сообщение об ошибке (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProctor", "GetProctoringActiveLearningId", [ iLearningRecordID ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
