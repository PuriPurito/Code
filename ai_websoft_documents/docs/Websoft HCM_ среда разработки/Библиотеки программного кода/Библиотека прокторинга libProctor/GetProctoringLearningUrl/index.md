## GetProctoringLearningUrl

Метод предназначен для получения ссылки для запуска _прокторинга_.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libProctor", "GetProctoringLearningUrl", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iLearningObjectId_ \- ID назначенного обучения (целое число).  
     _sCurHostPath_ \- адрес хоста (строка).  
     _sLaunchUrl_ \- URL для запуска обучения (строка).  
     _sUrlParams_ \- параметры URL для запуска обучения (строка).

_Возвращаемое значение:_  
      Тип: **Объект Выборка**. Содержит строковое выражение ссылки для запуска прокторинга, а также ряд дополнительных атрибутов:  
\- _proctoring\_object\_url_ \- ссылка для запуска прокторинга (строка).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _message_ – сообщение об ошибке (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libProctor", "GetProctoringLearningUrl", [ iLearningObjectId, sCurHostPath, sLaunchUrl, sUrlParams ]);_`

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
