## Библиотека прокси libProxyApi

В настоящем разделе описываются методы **библиотеки прокси** из библиотеки программного кода **libProxyApi**. Указанные методы регистрируются в разделе **Дизайнер – Библиотеки программного кода – libProxyApi**.

Примечание - По состоянию на май 2024 г. библиотека предназначена исключительно для внутренних нужд системы и не содержит публичных методов.
