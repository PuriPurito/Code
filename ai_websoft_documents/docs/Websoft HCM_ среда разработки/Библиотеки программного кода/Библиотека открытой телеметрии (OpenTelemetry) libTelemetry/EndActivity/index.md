## EndActivity

Метод **EndActivity** предназначен для завершения активности, запущенной функцией **StartActivity**.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTelemetry", "EndActivity", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя пять параметров:  
     _oActivityResult_ \- объект, результат функции StartActivity (может быть null) (объект).  
     _bIsUseCurrent_ \- флаг, устанавливающий использование статического поля Activity.Current (в случае отсутствия первого параметра) (булево).  
     _iErrorCode_ \- код ошибки; если активность завершена успешно – 0 (целое число).  
     _sErrorMessage_ \- описание ошибки; если активность завершена успешно, то значение равно null (строка).  
     _arrMeters_ \- массив названий метрик, из которых будет вычтена 1 (массив строк).

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _oResult_ \- объект, характеризующий результат выполнения метода.  
В том числе:   
     _tag_ \- массив тэгов (массив объектов). Каждый объект массива может включать в себя следующие данные: name - название объекта (строка), value - значение в текстовом формате (строка).  
     _data_ \- дополнительные данные (объект).  
     _paging_ \- информация о пагинации (объект).  
     _error_ \- код ошибки (целое число).  
     _errorText_ \- текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTelemetry", "EndActivity", [oActivityResult, bIsUseCurrent, iErrorCode, sErrorMessage, arrMeters]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
