## Библиотека открытой телеметрии (OpenTelemetry) libTelemetry

В настоящем разделе описываются методы **библиотеки открытой телеметрии (OpenTelemetry)** из библиотеки программного кода **libTelemetry**. Указанные методы регистрируются в разделе **Дизайнер – Библиотеки программного кода – libTelemetry**.

Подробнее о телеметрии – см. здесь.

Для вызова метода из библиотеки используется функция tools.call\_code\_library\_method.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTelemetry", <sMethodNameParam>, <arrParams>)**

_Аргументы:_  
     _<sMethodNameParam> (обязательный)_  
      Тип: **Строка**. Название вызываемого метода.  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.
