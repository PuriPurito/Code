## RecordMeter

Метод **RecordMeter** предназначен для записи значения в счетчик метрики.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTelemetry", "RecordMeter", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _sMeterName_ \- название счетчика метрики (строка).  
     _iMeterValue_ \- значение метрики (целое число).

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _oResult_ \- объект, характеризующий результат выполнения метода.  
В том числе:   
     _meter_ \- метрика (объект).   
     _data_ \- дополнительные данные (объект).  
     _paging_ \- информация о пагинации (объект).  
     _error_ \- код ошибки (целое число).  
     _errorText_ \- текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTelemetry", "RecordMeter", [sMeterName, iMeterValue]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
