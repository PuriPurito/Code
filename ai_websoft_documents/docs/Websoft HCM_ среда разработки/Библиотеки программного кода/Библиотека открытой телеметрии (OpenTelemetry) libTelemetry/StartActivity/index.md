## StartActivity

Метод **StartActivity** предназначен для создания и запуска активности для телеметрии.   
По окончании активности обязательно должен быть вызван метод **EndActivity(ActivityResult)**, где **ActivityResult** - возвращаемый объект.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTelemetry", "StartActivity", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя пять параметров:  
     _iTraceID_ \- ID потока (целое число).  
     _sName_ \- название активности (строка).  
     _sDescription_ \- описание активности (строка).  
     _tag_ \- массив тэгов (массив объектов). Каждый объект массива может включать в себя следующие данные: name - название объекта (строка), value - значение в текстовом формате (строка).  
     _arrMeters_ \- массив названий метрик, к которым будет добавлена 1 (массив строк).

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _oResult_ \- объект, характеризующий результат выполнения метода.  
В том числе:   
     _tag_ \- массив тэгов (массив объектов). Каждый объект массива может включать в себя следующие данные: name - название объекта (строка), value - значение в текстовом формате (строка).  
     _data_ \- дополнительные данные (объект).  
     _paging_ \- информация о пагинации (объект).  
     _error_ \- код ошибки (целое число).  
     _errorText_ \- текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTelemetry", "StartActivity", [iTraceID, sName, sDescription, arrTags, arrMeters]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
