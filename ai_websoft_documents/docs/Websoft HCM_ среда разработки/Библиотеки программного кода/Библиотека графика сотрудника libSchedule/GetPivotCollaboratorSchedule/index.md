## GetPivotCollaboratorSchedule

Метод **GetPivotCollaboratorSchedule** предназначен для получения сводной таблицы графика сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSchedule", "GetPivotCollaboratorSchedule", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя семь параметров:  
     _iCurPersonID_ \- ID сотрудника (целое число).  
     _dStartDate_ \- дата начала периода (дата).  
     _dFinishDate_ \- дата завершения периода (дата).  
     _sCollaboratorType_ \- тип сотрудников для отбора (строка). Допустимые значения: _'my', 'all', 'org', 'colleagues', 'subordinates'_.  
     _aPersonID_ \- массив ID сотрудников (массив целых чисел).  
     _aPresenceState_ \- массив ID типов присутствия/отсутствия (массив целых чисел).  
     _aStates_ \- массив статусов для поиска (массив строк).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные сводной таблицы графика сотрудника, а также ряд дополнительных атрибутов:

_\- array_ \- массив данных сводной таблицы графика сотрудника (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID сотрудника (целое число).  
     _state_ \- статус графика сотрудника (строка) (например, 'Согласовано')  
     а также ряд др. данных.

_\- columns_ \- массив данных столбцов сводной таблицы графика сотрудника (массив объектов).  
     Атрибуты отдельного объекта:  
     _data_ \- название данных колонки (строка) (например, _'state'_).  
     _title_ \- заголовок колонки (строка) (например, _'Согласовано'_).  
     _type_ \- тип данных колонки (строка) (например, _'string'_).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSchedule", "GetPivotCollaboratorSchedule", [iCurPersonID, dStartDate, dFinishDate, sCollaboratorType, aPersonID, aPresenceState, aStates]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
