## GetMyVacationContext

Метод GetMyVacationContext предназначен для получения контекста отпусков сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSchedule", "GetMyVacationContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _arrPresenceStates_ \- массив ID типов присутствия/отсутствия (массив целых чисел).  
     _bCheckWorkflowIntervalSchedule_ \- проверять ли наличие интервалов графиков на согласовании (булево) (необязательный). Значение по умолчанию - _false_.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные контекста отпусков сотрудника, а также ряд дополнительных атрибутов:  
\- _context_ \- данные контекста отпусков сотрудника (объект).  
     Атрибуты объекта:  
     _iRemainingDaysVacation_ \- количество оставшихся дней отпуска (целое число).  
     _iRemainingDaysThisVacation_ \- количество оставшихся дней текущего отпуска (целое число).  
     _dFinishDateNextVacation_ – дата окончания ближайшего следующего отпуска (дата).  
     _dStartDateCurrentVacation_ – дата начала текущего отпуска (дата).  
     _dFinishDateCurrentVacation_ – дата окончания текущего отпуска (дата).  
     _bHasCurrentVacation_ – сотрудник в начстоящее время находится в отпуске (булево).  
     _bWorkflowIntervalSchedule_ \- наличие видимых интервалов графиков (булево).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSchedule", "GetMyVacationContext", [iPersonID, arrPresenceStates, bCheckWorkflowIntervalSchedule]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
