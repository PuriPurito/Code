## GetVacationContext

Метод **GetVacationContext** предназначен для получения контекста отпусков с учетом указанного интервала графика.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSchedule", "GetVacationContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя один параметр:  
     _iIntervalScheduleID_ \- ID интервала графика (целое число). 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные контекста отпусков с учетом указанного интервала графика, а также ряд дополнительных атрибутов:  
\- _context_ \- данные контекста отпусков (объект):  
     _iRemainingDaysVacation_ \- количество оставшихся дней годового отпуска (целое число).  
     _iDays_ \- количество календарных дней в отпуске (целое число).  
     _iWorkingDays_ \- количество рабочих дней в отпуске (целое число).  
     _iUntilDays_ \- количество дней до окончания отпуска (целое число).  
     _dStartDateLastVacation_ \- дата начала ближайшего предыдущего отпуска (дата).  
     _dFinishDateLastVacation_ \- дата окончания ближайшего предыдущего отпуска (дата).  
     _iAgoMonths_ \- количество месяцев, прошедших после ближайшего предыдущего отпуска (целое число).

\- _result_ – результат вызова метода (_true_ – если операция завершилась успешно, _false_ – в противном случае) (булево).  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSchedule", "GetVacationContext", [iIntervalScheduleID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
