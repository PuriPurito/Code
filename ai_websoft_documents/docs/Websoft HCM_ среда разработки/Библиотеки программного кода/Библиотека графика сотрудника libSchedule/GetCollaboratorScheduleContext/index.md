## GetCollaboratorScheduleContext

Метод **GetCollaboratorScheduleContext** предназначен для получения контекста текущих дел по графику сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSchedule", "GetCollaboratorScheduleContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.  
     Массив включает в себя два параметра:  
     _iPersonID_ – ID сотрудника (целое число).   
     _oParam_ – набор параметров (объект).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит контекст текущих дел, а также ряд дополнительных атрибутов:  
\- _CollaboratorScheduleContext_ – набор данных о контексте (объект).  
     Атрибуты объекта:  
     _vacation\_days_ – количество запланированных дней (целое число);  
     _scheduled\_vacation\_days_ – оставшееся количество запланированных дней (целое число);  
     _unscheduled\_vacation\_days_ – оставшееся количество незапланированных дней (целое число);  
     _free\_vacation\_days_ – непрошедшее число дней (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSchedule", "GetCollaboratorScheduleContext", [iPersonID, oParam]);_`   
  
`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
