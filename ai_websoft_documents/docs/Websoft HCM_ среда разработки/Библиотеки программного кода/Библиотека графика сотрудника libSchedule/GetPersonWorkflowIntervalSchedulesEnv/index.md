## GetPersonWorkflowIntervalSchedulesEnv

Метод **GetPersonWorkflowIntervalSchedulesEnv** предназначен для получения списка интервалов графиков по документообороту.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSchedule", "GetPersonWorkflowIntervalSchedulesEnv", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.  
     Массив включает в себя два параметра:  
     _aPresenceState_ \- массив ID типов присутствия/отсутствия (массив целых чисел) (необязательный). Если параметр не указан, то отбор производится по всем типам присутствия/отсутствия.  
     _aStatusID_ \- массив статусов интервала (массив строк) (необязательный). Если параметр не указан, то отбор производится без учета статусов интервала.  
 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень интервалов графиков по документообороту, а также ряд дополнительных атрибутов:  
\- _array_ \- массив интервалов графиков (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID интервала графика (целое число);  
     _code_ – код интервала графика (строка);  
     _create\_date_ – создание интервала графика (дата);  
     _start\_date_ – начало интервала графика (дата);  
     _finish\_date_ – конец интервала графика (дата);  
     _change\_start\_date_ – измененная дата начала интервала графика (дата);  
     _change\_finish\_date_ – измененная дата конца интервала графика (дата);  
     change\_days\_num - измененное количество календарных дней (целое число);  
     change\_working\_days\_num - измененное количество рабочих дней (целое число);  
     _str\_create\_date_ – создание интервала графика в строковом выражении (строка);  
     _str\_start\_date_ – начало интервала графика в строковом выражении (строка);  
     _str\_finish\_date_ – конец интервала графика в строковом выражении (строка);  
     _presence\_state\_id_ – ID типа присутствия/отсутствия (целое число);  
     _presence\_state\_name_ – название типа присутствия/отсутствия (строка);  
     _workflow\_state_ – код этапа документооборота (строка);  
     _workflow\_state\_name_ – название этапа документооборота (строка);  
     _workflow\_type_ – тип документооборота (строка);  
     _days\_num_ – количество календарных дней (целое число);  
     _working\_days\_num_ – количество рабочих дней (целое число);  
     _person\_id_ – ID сотрудника (целое число);  
     _person\_fullname_ – ФИО сотрудника (строка);  
     _position\_name_ – название должности (строка);  
     _person\_icon_ – относительная ссылка на фотографию или иное изображение сотрудника (строка);  
     _status\_id_ – ID статуса интервала графика (строка);  
     _status\_name_ – название статуса интервала графика (строка);  
     _link_ – относительная ссылка на интервал графика (строка);

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_`  
`_oRes = tools.call_code_library_method ("libSchedule", "GetPersonWorkflowIntervalSchedulesEnv", [aPresenceState, aStatusID ]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
