## GetCollaboratorSchedule

Метод **GetCollaboratorSchedule** предназначен для получения списка графиков сотрудника.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSchedule", "GetCollaboratorSchedule", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
      Массив включает в себя одиннадцать параметров:  
      _iCurPersonID_ \- ID сотрудника (целое число).  
      _sCollaboratorType_ \- тип сотрудника для отбора (строка). Допустимые значения: _"my"_ (текущий сотрудник), _"all"_ (все сотрудники), _"org"_ (сотрудники данной организации), _"colleagues"_ (коллеги), _"subordinates"_ (подчиненные).  
      _sPeriodType_ \- тип периода для отбора (строка). Допустимые значения: _"budget\_period"_ (бюджетный период), _"fix\_date"_ (фиксированная дата), _"year"_ (год, начиная с текущей даты), _"year\_year"_ (два года – начиная от года до текущей даты и кончая годом после текущей даты), _"halfyear\_halfyear"_ (два полугодия – начиная от полугодия до текущей даты и кончая полугодием после текущей даты).  
      _aPersonID_ \- массив ID сотрудников для отбора (массив целых чисел).  
      _aStatus_ \- массив статусов для отбора (массив строк).  
      _aPresenceState_ \- массив ID типов состояний присутствия/отсутствия сотрудников для отбора (массив строк).  
      _iBudgetPeriodID_ \- ID бюджетного периода для отбора (целое число).  
      _dStartDate_ \- дата начала периода (дата).  
      _dFinishDate_ \- дата завершения периода (дата).  
      _bShowEntryTime_ – возвращать данные по фактически отработанному времени (булево).  
      _bShowPeriod_ – возвращать периоды (булево).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень графиков сотрудника, а также ряд дополнительных атрибутов:  
\- _array_ \- массив графиков сотрудника (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID графика сотрудника (целое число);  
     _fact\_value_ \- фактическая отработка в секундах (целое число).  
     _plan\_value_ \- плановая отработка в секундах (целое число).  
     _start\_date_ \- дата начала графика (дата).  
     _finish\_date_ \- дата окончания графика (дата).  
     _schedule\_collaborator\_id_ \- ID графика сотрудника (целое число).  
     _date_ – дата (составления) графика сотрудника (дата).  
     _person\_id_ \- ID сотрудника (целое число).  
     _person\_fullname_ \- ФИО сотрудника (целое число).  
     _presence\_state\_id_ \- ID статуса присутствия/отсутствия (целое число).  
     _presence\_state\_name_ \- название статуса присутствия/отсутствия (целое число).  
     _state\_id_ \- ID статуса графика сотрудника (целое число).  
     _link_ – относительная ссылка на график (строка).  
     _state_ \- название статуса графика сотрудника (целое число).  
     _periods_ \- массив периодов, входящих в состав графика сотрудника (массив объектов типа _oPeriod_).  
     _str\_plan\_value_ \- плановая отработка в секундах в строковом выражении (строка).  
     _str\_fact\_value_ \- фактическая отработка в секундах в строковом выражении (строка).  
     _week\_day\_name_ \- название дня недели (строка) (например: _'Понедельник', 'Вторник', ..._).  
     _week\_day\_short\_name_ \- краткое название дня недели (строка) (например: _'пн', 'вт', ..._).  
     _start\_time_ – время начала рабочего дня (строка).  
     _finish\_time_ – время окончания рабочего дня (строка).  
     _reason\_comment_ \- Комментарий причины согласования/отмены (строка).

\- fact\_value - фактическая продолжительность (целое число).  
\- plan\_value - плановая продолжительность (целое число).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSchedule", "GetCollaboratorSchedule", [iCurPersonID, sCollaboratorType, sPeriodType, aPersonID, aStatus, aPresenceState, iBudgetPeriodID, dStartDate, dFinishDate, bShowEntryTime, bShowPeriod]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
