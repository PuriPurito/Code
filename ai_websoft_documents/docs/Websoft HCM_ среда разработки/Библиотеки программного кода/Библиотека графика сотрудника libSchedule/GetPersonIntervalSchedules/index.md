## GetPersonIntervalSchedules

Метод **GetPersonIntervalSchedules** предназначен для получения списка интервалов графиков.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSchedule", "GetPersonIntervalSchedules", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя тринадцать параметров:  
     _iPersonID_ – ID сотрудника (целое число).   
     _aPresenceState_ \- массив ID типов присутствия/отсутствия (массив целых чисел) (необязательный). Если параметр не указан, то отбор производится по всем типам присутствия/отсутствия.  
     _aStatusID_ \- массив статусов интервала (массив строк) (необязательный). Если параметр не указан, то отбор производится без учета статуса интервала.  
     _sSearch_ \- критерий поиска (в режиме полнотекстового поиска) (строка) (необязательный). Если параметр не указан, то отбор производится без учета критерия полнотекстового поиска.  
     _sCollaboratorType_ \- тип сотрудников для отбора (строка) (необязательный) (допустимые значения: _my/all/org/colleagues/subordinates/this\_org/this\_sub_). Если параметр не указан, то отбор производится без учета типа сотрудника.  
     _sPeriodType_ \- тип периода для отбора (строка) (необязательный) (допустимые значения: _budget\_period/fix\_date/year/year\_year/halfyear\_halfyear_). Если параметр не указан, то отбор производится без учета типа периода.  
     _aPersonID_ \- массив ID сотрудников (массив целых чисел) (необязательный). Если параметр не указан, то отбор производится без учета массива сотрудников.  
     _iSelectedObjectID_ \- ID объекта для отбора сотрудников (целое число) (необязательный). Если параметр не указан, то отбор производится без учета объекта для отбора сотрудников.  
     _iBudgetPeriodID_ \- ID бюджетного периода (целое число) (необязательный). Если параметр не указан, то отбор производится без учета бюджетного периода.  
     _dStartDate_ \- дата начала периода (дата) (необязательный). Если параметр не указан, то отбор производится без учета даты начала периода.  
     _dFinishDate_ \- дата окончания периода (дата) (необязательный). Если параметр не указан, то отбор производится без учета даты окончания периода.  
     _sSelectDateType_ \- тип отбора (строка) (необязательный) (допустимые значения: _start\_vacation/period\_vacation_). Если параметр не указан, то отбор производится без учета типа отбора.  
     _bOnAgreement_ \- возвращать только интервалы на согласовании (булево) (необязательный). Если параметр не указан, то отбор производится без учета статуса интервала.

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень интервалов графиков, а также ряд дополнительных атрибутов:  
\- _array_ \- массив интервалов графиков (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID интервала графика (целое число);  
     _code_ – код интервала графика (строка);  
     _create\_date_ – создание интервала графика (дата);  
     _start\_date\_native_ – исходное начало интервала графика (дата);  
     _finish\_date\_native_ – исходный конец интервала графика (дата);  
     _start\_date_ – начало интервала графика (дата);  
     _finish\_date_ – конец интервала графика (дата);  
     _change\_start\_date_ – измененная дата начала интервала графика (дата);  
     _change\_finish\_date_ – измененная дата конца интервала графика (дата);  
     _str\_create\_date_ – создание интервала графика в строковом выражении (строка);  
     _str\_start\_date_ – начало интервала графика в строковом выражении (строка);  
     _str\_finish\_date_ – конец интервала графика в строковом выражении (строка);  
     _presence\_state\_id_ \- идентификатор состояния присутствия (целое число);  
     _presence\_state\_name_ \- название состояния присутствия (строка);  
     _status\_id_ – ID статуса интервала графика (строка);  
     _status\_name_ – название статуса интервала графика (строка);  
     _days\_num_ – количество календарных дней (целое число);  
     _working\_days\_num_ – количество рабочих дней (целое число);  
     _workflow\_type_ – тип документооборота (строка);  
     _workflow\_state_ – код этапа документооборота (строка);  
     _workflow\_state\_name_ – название этапа документооборота (строка);  
     _link_ – относительная ссылка на интервал графика (строка);  
     _pic\_url_ \- относительная ссылка на изображение (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_`  
`_oRes = tools.call_code_library_method ("libSchedule", "GetPersonIntervalSchedules", [iPersonID, aPresenceState, aStatusID, sSearch, sCollaboratorType, sPeriodType, aPersonID, iSelectedObjectID, iBudgetPeriodID, dStartDate, dFinishDate, sSelectDateType, bOnAgreement]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
