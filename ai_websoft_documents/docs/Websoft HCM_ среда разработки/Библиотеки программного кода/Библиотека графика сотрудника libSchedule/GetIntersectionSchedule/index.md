## GetIntersectionSchedule

Метод GetIntersectionSchedule предназначен для получения списка пересечений отпусков сотрудников.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSchedule", "GetIntersectionSchedule", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iUserID_ \- ID текущего сотрудника (целое число).  
     _iIntersectionUserID_ \- ID сотрудника для пересечения (целое число).  
     _iPresenceStateID_ \- ID типов присутствия/отсутствия (целое число).  

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень пересечений отпусков сотрудников, а также ряд дополнительных атрибутов:  
\- _context_ \- массив пересечений отпусков сотрудников (массив объектов).  
     Атрибуты отдельного объекта:  
     _dUserDate_ – дата ближайшего согласованного расписания текущего сотрудника (**curUser**) (дата).  
     _sUserDay_ \- название дня недели ближайшего расписания текущего сотрудника (строка). Допустимые значения: _"Понедельник", "Вторник", "Среда", "Четверг", "Пятница", "Суббота", "Воскресенье"_.  
     _dIntersectionUserDate_ \- дата ближайшего расписания сравниваемого сотрудника (дата) (дата).  
     _sIntersectionUserDay_ \- название дня недели недели ближайшего расписания сравниваемого сотрудника (строка). Допустимые значения: _"Понедельник", "Вторник", "Среда", "Четверг", "Пятница", "Суббота", "Воскресенье"_.  
     _dIntersectionDate_ – дата ближайшего пересечения текущего и сравниваемого сотрудника (дата).  
     _sIntersectionDay_ \- название дня недели ближайшего пересечения текущего и сравниваемого сотрудника (строка). Допустимые значения: _"Понедельник", "Вторник", "Среда", "Четверг", "Пятница", "Суббота", "Воскресенье"_.

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSchedule", "GetIntersectionSchedule", [iUserID, iIntersectionUserID, iPresenceStateID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
