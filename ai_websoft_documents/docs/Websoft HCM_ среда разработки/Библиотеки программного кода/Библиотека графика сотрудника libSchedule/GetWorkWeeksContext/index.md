## GetWorkWeeksContext

Метод **GetWorkWeeksContext** предназначен для получения контекста с параметрами текущего периода учета для рабочего графика.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libSchedule", "GetWorkWeeksContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
    _iWeekDay_ \- индекс дня недели начала периода (целое число) (необязательный). Допустимые значения: _1_ (понедельник), _2_ (вторник), _3_ (среда), _4_ (четверг), _5_ (пятница), _6_ (суббота), _7_ (воскресенье). Значение по умолчанию - _1_.  
    _iPeriodSize_ \- количество дней периода (целое число) (необязательный параметр). Значение по умолчанию - _7_. 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные контекста с параметрами текущего периода учета для рабочего графика, а также ряд дополнительных атрибутов:  
_\- context_ \- данные контекста (объект).  
     Атрибуты контекста:  
     _iStartPeriodDay_ \- день недели начала периода (целое число). Допустимые значения: _1_ (понедельник), _2_ (вторник), _3_ (среда), _4_ (четверг), _5_ (пятница), _6_ (суббота), _7_ (воскресенье).  
     _sStartPeriodDay_ \- название дня недели начала периода (строка). Допустимые значения: _"Понедельник", "Вторник", "Среда", "Четверг", "Пятница", "Суббота", "Воскресенье"._  
     _iFinishPeriodDay_ \- день недели конца периода (целое число). Допустимые значения: _1_ (понедельник), _2_ (вторник), _3_ (среда), _4_ (четверг), _5_ (пятница), _6_ (суббота), _7_ (воскресенье).  
     _sFinishPeriodDay_ \- название дня недели конца периода (строка). Допустимые значения: _"Понедельник", "Вторник", "Среда", "Четверг", "Пятница", "Суббота", "Воскресенье"._  
     _dStartPeriodDate_ \- дата начала периода (дата).  
     _dFinishPeriodDate_ \- дата конца периода (дата).  
     _iPeriodSize_ \- продолжительность периода в днях (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libSchedule", "GetWorkWeeksContext", [iWeekDay, iPeriodSize]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
