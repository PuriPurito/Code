## AddItemsToAssessment

Метод **AddItemsToAssessment** предназначен для добавления вопросов в тест.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTest", "AddItemsToAssessment", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _SCOPE\_WVARS_ \- объект JSON с параметрами удаленного действия (объект).  
     _PARAMETERS_ \- объект JSON с параметрами удаленного действия (объект).

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующий атрибут:  
\- _action\_result_ – результат вызова метода (объект). Может содержать следующие параметры: command (название выполненной команды) (строка), msg (сообщение) (строка), confirm\_result (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTest", "AddItemsToAssessment", [SCOPE_WVARS, PARAMETERS ]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
