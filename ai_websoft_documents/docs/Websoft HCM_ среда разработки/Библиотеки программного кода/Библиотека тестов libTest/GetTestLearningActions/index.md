## GetTestLearningActions

Метод **GetTestLearningActions** предназначен для получения списка действий сотрудника по тесту.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTest", "GetTestLearningActions", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID сотрудника (целое число).  
     _iTestID_ \- ID теста (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень действий сотрудника по тесту, а также ряд дополнительных атрибутов:  
\- _actions_ \- массив действий (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ – ID действия (строка) (возможные значения: _"create\_request", "start\_learning", "continue\_learning"_);  
     _title_ – наименование действия (строка) (соответственные значения: _"Создать заявку", "Начать", "Продолжить"_);  
     _action\_id_ – ID действия (строка). Аналогичен указанному выше атрибуту id (возможные значения: _"create\_request"_, _"start\_learning"_, _"continue\_learning"_).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTest", "GetTestLearningActions", [iPersonID, iTestID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
