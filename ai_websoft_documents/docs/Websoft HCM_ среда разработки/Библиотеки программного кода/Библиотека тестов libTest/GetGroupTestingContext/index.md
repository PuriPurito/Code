## GetGroupTestingContext

Метод **GetGroupTestingContext** предназначен для получения контекста по тестированию группы.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTest", "GetGroupTestingContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iGroupID_ \- ID группы (целое число).  
     _oParam_ \- параметры контекста (объект).  
     _iCurUserID_ \- ID пользователя для поддержки ролевой модели (целое число).  
     _sAppCode_ \- код приложения для поддержки ролевой модели (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о контексте по тестированию группы, а также ряд дополнительных атрибутов:  
\- _context_ \- контекст по тестированию группы (объект).  
     Атрибуты данного объекта:  
     _collaborator\_count_ – количество сотрудников в группе (целое число).  
     _testing\_all\_count_ – количество всех незавершенных и завершенных тестов для всех членов группы (целое число).  
     _complete\_testing\_count_ \- количество завершенных тестов для всех членов группы (целое число).  
     _percent\_complete_ \- процент завершенных курсов от числа назначений (целое число).  
     _complete\_success_ \- количество успешно завершенных тестов (целое число).  
     _percent\_complete\_success_ \- процент успешно завершенных тестов от всех завершенных (целое число).  
     _all\_testing\_expired_ \- количество просроченных незавершенных и завершенных тестов (целое число).  
     _percent\_all\_testing\_expired_ \- процент просроченных незавершенных и завершенных тестов от назначенных (целое число).  
     _percent\_average\_score_ \- средний процент набранных баллов по завершенному тестированию (целое число).  
     _max\_start\_usage\_date_ \- дата последнего назначения любого теста любому члену группы (дата).  
     _max\_last\_usage\_date_ \- дата последнего открытия плеера с любым тестом любым членом группы (дата).  
     _active\_testing\_count_ – количество незавершенных тестов по всем тестам всех членов группы (целое число).  
     _active\_testing\_expired_ – количество просроченных незавершенных тестов по всем тестам всех членов группы (целое число).  
     _percent\_active\_testing\_expired_ \- процент просроченных незавершенных тестов от общего числа незавершенных тестов (целое число).  
     _complete\_testing\_expired_ \- количество просроченных завершенных тестов по всем тестам для всех членов группы (целое число).  
     _percent\_complete\_testing\_expired_ \- процент просроченных завершенных тестов от всех завершенных (целое число).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTest", "GetGroupTestingContext", [iGroupID , oParam, iCurUserID, sAppCode]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
