## GetStartTestLearningUrl

Метод **GetStartTestLearningUrl** предназначен для получения истории обучения по тесту для подчиненных сотрудников.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTest", "GetStartTestLearningUrl", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя четыре параметра:  
     _iPersonID -_ ID сотрудника (целое число).  
     _iAssessmentID_ \- ID теста (целое число).  
     _dStartLaunch_ - запускать тест (булево) (необязательный). По умолчанию - false.  
     _iClLocalizationID_ \- ID локализации (целое число) (необязательный). По умолчанию рассматривается текущая локализация. 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит историю обучения по тесту для подчиненных сотрудников, а также ряд дополнительных атрибутов:  
\- _redirect\_url_ \- URL истории обучения подчиненных сотрудников по указанному тесту (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTest", "GetStartTestLearningUrl", [iPersonID, iAssessmentID, dStartLaunch, iClLocalizationID]);_`   
 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
