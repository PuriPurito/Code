## GetTestsByRoles

Метод **GetTestsByRoles** предназначен для получения списка тестов по категориям.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTest", "GetTestsByRoles", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого будут переданы методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя пятнадцать параметров:  
     _arrTestsRoles_ \- массив ID категорий тестов, для которых не будет учтена иерархия (массив строк).  
     _arrTestsHierRoles_ \- массив ID категорий тестов, для которых будет учтена иерархия (массив строк).  
     _iCurUserID_ \- ID текущего пользователя (целое число).  
     _bCheckAccess_ \- проверять ли права доступа (булево) (необязательный). Значение по умолчанию - _false_.   
     _bExcludeArchiveTests_ \- исключить ли из выборки архивные тесты (булево) (необязательный). Значение по умолчанию - _false_.  
     _bExcludeSecretTests_ \- исключить ли из выборки скрытые тесты (булево) (необязательный). Значение по умолчанию - _false_.  
     _bExcludeProjectTests_ \- исключить ли из выборки проектные тесты (булево) (необязательный). Значение по умолчанию - _false_.  
     _bCalculateTestLearningParams_ \- вычислять ли параметры прохождения теста для текущего сотрудника (булево) (необязательный). Значение по умолчанию - _false_.  
     _sCurrencyType_ \- тип валюты для построения рейтинга (строка).  
     _sAccessType_ \- тип доступа (строка) (необязательный). Доступные значения: _"admin", "manager", "hr", "expert", "observer", "auto"_. Значение по умолчанию - _"auto"_.  
     _sApplication_ \- код приложения, по которому определяется доступ (строка) (необязательный).  
     _iCurApplicationID_ \- ID текущего приложения (целое число).  
     _arrReturnData_ \- массив полей для вывода (массив строк) (необязательный). Доступные значения: _"all\_test\_session\_count"(общее количество сессий тестирования), "active\_test\_session\_count"(количество активных сессий тестирования), "finished\_test\_session\_count"(количество завершенных сессий тестирования), "all\_test\_session\_expired\_count"(количество просроченных сессий), "max\_last\_usage\_date"(дата последней активности), "max\_start\_usage\_date"(дата последнего назначения теста)_.  
     _sXQueryQual_ \- дополнительные данные для отбора (для XQuery-фильтра) (строка) (необязательный).  
     _oCollectionParams_ \- набор интерактивных параметров (объект). Включает в себя поля:  
          _personID_ \- ID сотрудника (целое число) (необязательный);   
          _paging_ (информация о пейджинге) (объект) (включает в себя следующие данные:  INDEX - номер страницы (целое число);  SIZE - размер страницы (целое число); MANUAL - разделение на страницы вручную (булево); TOTAL - общее количество страниц (целое число));   
          _sort_ (информация о сортировке) (объект) (включает в себя следующие данные: FIELD - название поля, по которому производится сортировка (строка), DIRECTION - направление сортировки (строка) (допустимые значения:  "ASC" (сортировка по возрастанию), "DESC" (сортировка по убыванию)),  
          _distincts_ \- массив названий полей для отбора (массив строк) (необязательный);   
          _filters_ \- фильтры (массив объектов) (необязательный) (включает в себя следующие данные: id - идентификатор объекта, используемого для фильтрации, в текстовом формате (строка или массив строк); name - название объекта (строка); type - тип объекта (строка); value - значение (строка, целое число или объект) (необязательный); value\_from - начало периода отбора (целое число или дата) (необязательный); value\_to - конец периода отбора (целое число или дата) (необязательный));  
         _fulltext_ \- дополнительный фильтр XQuery для отбора (строка) (необязательный).  
         _management\_object\_ids_ \- ID управляемых объектов (массив целых чисел) (необязательный), 

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень тестов по категориям, а также ряд дополнительных атрибутов:  
\- _array_ \- массив тестов (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID теста (целое число);  
     _name_ \- название теста (строка);  
     _image_ \- относительная ссылка на изображение (строка);  
     _desc_ \- описание теста (строка);  
     _roles\_names_ \- названия категорий (строка);  
     _link_ – относительная ссылка на тест (строка).  
     _all\_test\_session\_count_ \- общее количество сессий тестирования (целое число). Данный атрибут выводится, если входной аргумент arrReturnData содержит соответствующее значение.  
     _active\_test\_session\_count_ \- количество активных сессий тестирования (целое число). Данный атрибут выводится, если входной аргумент arrReturnData содержит соответствующее значение.  
     _finished\_test\_session\_count_ \- количество завершенных сессий тестирования (целое число). Данный атрибут выводится, если входной аргумент arrReturnData содержит соответствующее значение.  
     _all\_test\_session\_expired\_count_ \- количество просроченных сессий (целое число). Данный атрибут выводится, если входной аргумент arrReturnData содержит соответствующее значение.  
     _max\_last\_usage\_date_ \- дата последней активности (дата). Данный атрибут выводится, если входной аргумент arrReturnData содержит соответствующее значение.  
     _max\_start\_usage\_date_ \- дата последнего назначения теста (дата). Данный атрибут выводится, если входной аргумент arrReturnData содержит соответствующее значение.  
     _status_ \- статус теста (строка). Например: открытый, скрытый, проект, архивный.

\- _data_ \- дополнительные данные (объект).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_      _oRes = tools.call_code_library_method ("libTest", "GetTestsByRoles", [arrTestsRoles, arrTestsHierRoles, iCurUserID, bCheckAccess, bExcludeArchiveTests, bExcludeSecretTests, bExcludeProjectTests, bCalculateTestLearningParams, sCurrencyType, sAccessType, sApplication, iCurApplicationID, arrReturnData, sXQueryQual, oCollectionParams]);_`   
  
`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
