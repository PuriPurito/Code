## GetTestContext

Метод **GetTestContext** предназначен для получения контекста по тесту.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libTest", "GetTestContext", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода. Параметры могут быть перечислены через запятую, а весь массив - заключен в квадратные скобки.   
     Массив включает в себя три параметра:  
     _iTestID_ \- ID теста (целое число).  
     _iCurUserID_ \- ID пользователя для поддержки ролевой модели (целое число).  
     _sAppCode_ \- код приложения для поддержки ролевой модели (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит данные о контексте по тесту, а также ряд дополнительных атрибутов:  
\- _context_ \- контекст по тесту (массив объектов).  
     Атрибуты данного объекта:  
     _assigned\_count_ \- количество назначений (целое число).  
     _active\_test\_learning\_count_ \- количество активных сессий (целое число).  
     _percent\_active\_test\_learning_ \- процент активных сессий от назначенных (целое число).  
     _complete\_test\_learning\_count_ \- количество успешно завершенных сессий со статусом «Пройден» (целое число).  
     _percent\_complete\_test\_learning_ \- процент успешно завершенных сессий от всех завершенных (целое число).  
     _expired\_count_ \- количество просроченных незавершенных и завершенных сессий по данному тесту (целое число).  
     _percent\_expired\_count_ \- процент просроченных сессий от числа назначенных (целое число).  
     _active\_expired\_count_ \- количество просроченных незавершенных сессий по данному тесту (целое число).  
     _percent\_active\_expired\_count_ \- процент просроченных незавершенных сессий от общего числа незавершенных сессий (целое число).  
     _test\_learning\_count_ \- сумма всех завершенных сессий по данному тесту (целое число).  
     _percent\_test\_learning_ \- процент завершенных сессий от общего числа назначенных (целое число).  
     _expired\_test\_count_ \- количество просроченных завершенных сессий по данному тесту (целое число).  
     _percent\_expired\_test\_count_ \- процент просроченных завершенных сессий от общего числа завершенных сессий (целое число).  
     _percent\_average\_score_ \- средний процент набранных баллов по завершенному тестированию (целое число).  
     _avg\_time_ \- средняя продолжительность прохождения теста в строковом выражении (строка).  
     _avg\_time\_module_ \- средняя длительность прохождения модуля теста в строковом выражении (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libTest", "GetTestContext", [iTestID, iCurUserID, sAppCode]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
