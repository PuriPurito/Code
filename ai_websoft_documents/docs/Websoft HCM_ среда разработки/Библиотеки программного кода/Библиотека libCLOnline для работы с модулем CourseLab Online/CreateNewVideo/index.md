## CreateNewVideo

Метод **CreateNewVideo** предназначен для формирования кнопки создания нового видеопроекта.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libCLOnline ", "CreateNewVideo", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя четыре параметра:  
     _iPersonID_ \- ID пользователя (целое число).  
     _sNameVideo_ \- заголовок видео (строка).  
     _sComment_ – комментарий (строка).  
     _oImage_ \- изображение (объект). 

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _msg_ – сообщение (строка) (в том числе сообщение об ошибке.  
\- _doc\_id_ \- ID документа созданного видеопроекта (целое число). 

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libCLOnline ", "CreateNewVideo", [iPersonID, sNameVideo, sComment, oImage]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
