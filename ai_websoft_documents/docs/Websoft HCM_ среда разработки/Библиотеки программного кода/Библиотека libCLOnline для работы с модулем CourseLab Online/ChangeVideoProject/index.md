## ChangeVideoProject

Метод **ChangeVideoProject** предназначен для редактирования видеопроекта.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libCLOnline ", "ChangeVideoProject", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя четыре параметра:  
     _iProjectID_ \- ID видеопроекта (целое число).  
     _sNameVideo_ \- заголовок видео (строка).  
     _sComment_ \- комментарий (строка).  
     _oImage_ \- изображение (объект). 

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _msg_ – сообщение (строка) (в том числе сообщение об ошибке.  
\- _doc\_id_ \- ID документа редакируемого видеопроекта (целое число).   
 

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libCLOnline ", "ChangeVideoProject", [iProjectID, sNameVideo, sComment, oImage]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
