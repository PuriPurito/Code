## GetParamForVideoByAuthor

Метод **GetParamForVideoByAuthor** предназначен для получения параметров видеопроектов, автором которых является пользователь.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libCLOnline ", "GetParamForVideoByAuthor", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _iPersonID_ \- ID пользователя (целое число).  
     _iDefaultImgVd_ \- ID изображения из ресурса базы, принятого по умолчанию (целое число).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень параметров видеопроектов, автором которых является пользователь, а также ряд дополнительных атрибутов:  
\- result - массив параметров видеопроектов (массив объектов).  
     Атрибуты отдельного объекта:  
     command - исполняемое действие (строка).  
     title - название формы (строка).  
     message - сообщение (строка).  
     css\_class - классы CSS (строка).  
     form\_fields – поля формы (массив объектов).  
     buttons – кнопки формы (массив объектов).  
     no\_buttons – не нужно ли использовать кнопки (булево). При значении true кнопки использовать не нужно.

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libCLOnline ", "GetParamForVideoByAuthor", [iPersonID, iDefaultImgVd]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
