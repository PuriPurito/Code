## GetCourseLab

Метод **GetCourseLab** предназначен для получения списка модулей курса CourseLab.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libCLOnline ", "GetCourseLab", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя один параметр:  
     _iPersonUserID_ \- ID текущего пользователя в строковом выражении (строка).

_Возвращаемое значение:_  
      Тип: **Объект**. Содержит перечень модулей курса CourseLab, а также ряд дополнительных атрибутов:  
\- _array_ \- массив модулей курса CourseLab (массив объектов).  
     Атрибуты отдельного объекта:  
     _id_ \- ID модуля курса в строковом выражении (строка).  
     _name_ \- название модуля (строка).  
     _cl\_course\_id_ \- ID курса CLOnline в строковом выражении (строка).  
     _state\_id_ \- ID статуса (целое число).  
     _state\_name_ \- наименование статуса (строка).  
     _img\_url_ \- ссылка на изображение (строка).

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).  
\- _errorText_ – текст ошибки (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libCLOnline ", "GetCourseLab", [iPersonUserID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
