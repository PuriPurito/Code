## DeleteModule

Метод **DeleteModule** предназначен для удаления указанного модуля курса CourseLab.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libCLOnline ", "DeleteModule", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _iIdCLModule_ \- ID модуля (целое число).  
     _sCommand_ \- текущий режим удаленного действия (строка).

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _action\_result_ – результат вызова метода (объект). Возможные атрибуты объекта:   
     _command_ – исполняемое действие (строка) (например: "display\_form").  
     _title_ – название (строка) (например, "Удалить модуль").  
     _form\_fields_ – поля формы (массив объектов).  
     _buttons_ – кнопки формы (массив объектов).  
     _message_ – сообщение (строка) (например, "Вы действительно хотите удалить текущий модуль?").

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libCLOnline ", "DeleteModule", [iIdCLModule, sCommand]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
