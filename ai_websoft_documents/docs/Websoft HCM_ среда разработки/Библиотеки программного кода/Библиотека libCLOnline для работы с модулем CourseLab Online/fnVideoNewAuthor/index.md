## fnVideoNewAuthor

Метод **FnVideoNewAuthor** предназначен для добавления автора в видеопроект.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libCLOnline ", "FnVideoNewAuthor", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя два параметра:  
     _oArgs_ \- объект со свойством oDoc и значением, соответствующем открытому документу видеопроекта (объект).   
     _iPersonID_ \- ID пользователя (целое число).

_Возвращаемые значения:_  
      Тип:  **Булево**. Результат вызова метода (_true_ – если операция завершилась успешно).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libCLOnline ", "FnVideoNewAuthor", [oArgs, iPersonID]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
