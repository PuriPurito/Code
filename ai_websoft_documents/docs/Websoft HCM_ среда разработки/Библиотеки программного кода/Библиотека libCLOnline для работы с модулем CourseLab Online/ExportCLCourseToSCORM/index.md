## ExportCLCourseToSCORM

Метод **ExportCLCourseToSCORM** предназначен для экспорта модуля курса CourseLab.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libCLOnline ", "ExportCLCourseToSCORM", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя пять параметров:  
     _iCLModuleID_ \- ID изменяемого модуля (целое число).  
     _sCurUserID_ \- ID текущего пользователя в строковом выражении (строка).  
     _sCommand_ \- текущий режим удаленного действия (строка).  
     _sFormFields_ \- JSON-строка с возвратом из формы удаленного действия (строка).  
     _sZipUrl_ \- название сохраняемого файла (строка). Значение по умолчанию – null.

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:  
\- _action\_result_ – результат вызова метода (объект). Возможные атрибуты объекта:   
     _command_ – исполняемое действие (строка) (например: "display\_form").  
     _msg_ – сообщение (строка) (в том числе сообщение об ошибке).  
  
\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libCLOnline ", "ExportCLCourseToSCORM", [iCLModuleID, sCurUserID, sCommand, sFormFields , sZipUrl]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
