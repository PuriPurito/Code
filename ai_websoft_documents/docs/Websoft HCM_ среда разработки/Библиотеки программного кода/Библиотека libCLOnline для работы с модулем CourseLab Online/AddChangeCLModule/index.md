## AddChangeCLModule

Метод **AddChangeCLModule** предназначен для создания / редактирования модуля курса CourseLab.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libCLOnline ", "AddChangeCLModule", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя четыре параметра:  
     _iCLModuleID_ \- ID изменяемого модуля (целое число).  
     _iRoleID_ \- ID корневой категории (целое число).  
     _sCommand_ \- текущий режим удаленного действия (строка).  
     _sFormFields_ \- JSON-строка с возвратом из формы удаленного действия (строка).

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:

\- _action\_result_ – результат вызова метода (объект). Возможные атрибуты объекта:   
     _command_ – исполняемое действие (строка) (например: "display\_form").  
     _title_ – название (строка) (например, "Создать модуль CourseLab", "Изменить модуль CourseLab").  
     _header_ – заголовок (строка) (например, "Заполните поля").  
     _form\_fields_ – поля формы (массив объектов).  
     _msg_ – сообщение (строка) (например, "Модуль курса успешно создан", "Модуль курса успешно изменен").

\- _error_ \- код ошибки (при отсутствии ошибок код равен 0) (целое число).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libCLOnline ", "AddChangeCLModule", [iCLModuleID, iRoleID, sCommand, sFormFields]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
