## ViewEditCLModule

Метод **ViewEditCLModule** предназначен для просмотра/редактирования указанного модуля курса CourseLab.

_Синтаксис (вызов из JS-кода):_  
      **tools.call\_code\_library\_method ("libCLOnline ", "ViewEditCLModule", <arrParams>)**

_Аргументы:_  
     _<arrParams> (обязательный)_  
      Тип: **Массив**. Массив, элементы которого передаются методу в качестве параметров. Порядок следования элементов в массиве должен соответствовать порядку параметров метода.  
     Массив включает в себя четыре параметра:  
     _iPersonID_ \- ID пользователя (целое число).  
     _iIdCLModule_ \- ID модуля (целое число).  
     _sHost_ \- хост модуля (строка).  
     _sMode_ \- просмотр или редактирование модуля (строка). Допустимые значения - 'edit', 'view'. 

_Возвращаемые значения:_  
      Тип:  **Объект**. Содержит следующие атрибуты:- action\_result – результат вызова метода (объект). Возможные атрибуты объекта:   
     _command_ – исполняемое действие (строка) (например: "new\_window", "alert").  
     _msg_ – сообщение (строка) (в том числе сообщение об ошибке).  
     _redirect\_url_ – адрес перенаправления (строка).

_Пример:_

`_// Вызов метода с помощью функции_ _tools.call_code_library_method_   _oRes = tools.call_code_library_method ("libCLOnline ", "ViewEditCLModule", [iPersonID, iIdCLModule, sHost, sMode]);_` 

`_// Запись результата в основной журнал (лог) системы xhttp-<текущая_дата>.log   LogEvent('', EncodeJson(oRes));_`
