## Особенности программирования обработчиков системных событий

Начиная с версии 2023.2 для программирования обработчиков системных событий используется специальный **объект HANDLER\_WVARS**. 

Внимание! _В более ранних версиях системы_ использование **объекта HANDLER\_WVARS** вызывает ошибку: «_HANDLER\_WVARS not defined_». В этом случае рекомендуется использовать конструкцию типа:  
_teSystemEventHandler.wvars.ObtainChildByKey( "переменная" ).value_  
Изменение связано с оптимизацией (очередей и кеширования) и унификацией (для взаимосвязи с C#) выполнения кода обработчиков.  
В версии 2023.2 и более поздних версиях teSystemEventHandler не является объектом формата XML TopElem, а представляет из себя стандартный JS-объект.  
В свою очередь, в указанных версиях для работы с переменными обработчиков системных событий был введен **глобальный объект HANDLER\_WVARS**.

При работе с объектом HANDLER\_WVARS для создания универсального кода рекомендуется использовать **конструкцию try... catch** для проверки на существование **объекта HANDLER\_WVARS**.

 Ниже приведен пример работы с **объектом HANDLER\_WVARS** и с использованием **конструкции try... catch**.

_Пример:_

`_docEventHandler = tools.open_doc( teSystemEventHandler.id ); // формируется документ обработчика системного события docEventHandler; одновременно создается объект HANDLER_WVARS для работы с переменными обработчика системного события   if ( docEventHandler != undefined ) // проверка документа на существование   {       try // начало действия конструкции try... catch       {           var iChatbotID = OptInt( HANDLER_WVARS.GetOptProperty( "chatbot_id", "" ) ); // определяется значение переменной обработчика системного события       }       catch( ex ) // рассматривается случай, когда объект HANDLER_WVARS по каким-либо причинам не был сформирован корректно       {           var iChatbotID = undefined; // указывается значение переменной обработчика системного события undefined для случая, если объект HANDLER_WVARS не был сформирован        } // конец действия конструкции try... catch_`

    `_if ( iChatbotID != undefined ) // рассматривается случай, когда значение переменной обработчика системного события равно undefined       {           CallServerMethod( "tools", "call_code_library_method", [ "libChat", "create_chatbot_script", [ learningDoc.person_id.Value, learningDoc.id, iChatbotID ] ] );       }   }_`
