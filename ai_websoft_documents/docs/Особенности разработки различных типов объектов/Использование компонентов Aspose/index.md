## Использование компонентов Aspose

WebSoft HCM поставляется с набором компонентов, доступных в виде объектов ActiveX.

Для работы компонентов необходимо наличие установленного пакета .Net Framework версии не ниже 4.0.

Справочник по работе с компонентами доступен по ссылке: /doc/net/html/163e2842-0455-47f5-93fb-821d12784123.htm.

Особенности использования и ограничения компонента Aspose:  
1\. Если в файле html в коде используется стиль _display: flex_, при конвертации такого файла в формат pdf будет добавлен пустой лист. Чтобы избежать этой проблемы, необходимо отказаться от этого стиля в исходном файле html.  
2. При использовании ОС Linux просмотр файлов формата ppt и pptx на Портале недоступен, подробнее в статье.
