## Особенности использования программного кода в веб-шаблонах

Код шаблонов портала представляет собой HTML текст в котором расположены вставки кода.

Существует 2 варианта вставки кода:

**1\. Код расположен на нескольких строках**

_html_  
<%  
_код JavaScript_  
%>  
_продолжение html_

**2\. Код расположен на одной строке**

_html_<%=_код JavaScript_%>_html_
