## 1.4.4 Дополнительные/вспомогательные интерфейсные окна

Открываются по нажатию на дополнительные/настраиваемые кнопки левой панели. Могут быть как контекстно-зависимыми (отчет по текущему пользователю и т.п.), так и контекстно-независимыми (материалы по текущей процедуре и т.п.).

_Количество настраиваемых кнопок не ограничено. Технологически интерфейс представляет из себя окно IFRAME, в котором отображается шаблон, указанный в настройках кнопки. Формат верстки шаблона – предпочтительно XAML, возможен и обычный HTML. Есть API для передачи команд из дополнительного интерфейса в основное окно плеера._
