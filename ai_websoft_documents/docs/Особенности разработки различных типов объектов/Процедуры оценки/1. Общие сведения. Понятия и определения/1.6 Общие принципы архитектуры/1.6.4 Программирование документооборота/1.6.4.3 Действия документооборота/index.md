## 1.6.4.3 Действия документооборота

_В действиях ДО необходимо использовать только глобальные переменные типа curObject, curPА и curPersonID. Использование других глобальных переменных (PHASE. IS\_DONE. COLLABORATOR\_USER\_ID и т.д.) не гарантируется, это связано с изменениями в реализации функционала._

_\- в коде действий ДО доступны к изменению переменные BRUTE\_MESSAGE, WORKFLOW\_ACTION\_BREAK, WORKFLOW\_CREATE\_BREAK – для формирования сообщения об ошибке/успешном выполнении, прерывания обработки действия и т.д._

\- в коде действия ДО, при успешном выполнении, ОБЯЗАТЕЛЬНО должна быть сформирована команда плееру на обработку. Формирование команды задается выставлением флага в одной из трех переменных:

_RELOAD\_ALL \= true  \- перерисовать дерево иерархии (оценки), перезагрузив содержание плеера._

_RELOAD\_PA = true – перерисовать (обновить) только текущую закладку (форму)_

_REDIRECT\_TO\_PA = ID нужной PA – открыть в окне плеера другую форму (как другую закладку для текущего пользователя, так и форму другого пользователя)._

Команда выполняется только одна, в соответствии с порядком/приоритетом, указанным выше. Т.е., если будет выставлено несколько флагов, выполнится команда, встретившаяся первой по списку.

_При переходе на другую PA она должна присутствовать в списке видимости текущего пользователя на момент перед нажатием кнопки (т.е. быть загружена в дерево плеера)._
