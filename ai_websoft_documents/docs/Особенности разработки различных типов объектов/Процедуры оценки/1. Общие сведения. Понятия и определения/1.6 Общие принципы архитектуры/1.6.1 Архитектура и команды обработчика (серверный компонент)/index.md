## 1.6.1 Архитектура и команды обработчика (серверный компонент)

Серверный обработчик представляет из себя веб-шаблон, построенный по тем же правилам, что и остальные портальные шаблоны системы.

Обмен данными с плеером оценки (клиентской частью) происходит в формате JSON.

Структура входных данных:

{

“mode”: “вызываемый метод”,

“assessment\_appraise\_id”: “ID _процедуры оценки_”,

“options”: {Объект с описанием параметров выполнения команды}

“pas”: \[Массив идентификаторов запрашиваемых анкет для методов put или reuest\]

}

Возможные методы обработчика:

·         get – получить список идентификаторов доступных анкет для пользователя

_·_         params _– получить набор настроечных параметров для работы плеера_

·         list – получить общую информацию по доступным анкетам пользователя (идентификатор, тип оценки, статус анкеты, оцениваемый, оценивающий, дополнительные эксперты, этап документооборота) для построения дерева оценки

·         request – получение подробной информации по анкете/анкетам для формирования закладок с оценочными формами

·         put – сохранить данные, внесенные пользователем

·         action – выполнить действие документооборота

·         subordinates – получить список подчиненных для руководителя

·         tasktree – получить данные для построения дерева целей (структура целей с учетом трансляций от руководителей к подчиненным)

·         workflowlogs – получить данные журнала действий документооборота

·         dataset – получение обновления по задаче или набору данных

·         task – получить дополнительную информацию по цели (история изменений или список комментариев), также используется для сохранения комментария по цели

·         block – работа с признаком редактирования - позволяет обеспечить работу нескольких пользователей с одной формой оценки

Структура выходных данных (типовой набор, для отдельных методов некоторые элементы могут отсутствовать):

{

                “sId”: “Идентификатор оценочной процедуры”,

                “assessment\_user”: {“id”:””, “name”:””}, //пользователь, с учетом делегирования (ФИО, ID)

                “pas”: \[Массив данных анкет(форм оценки)\],

                “config”: {Объект конфигурации/настроек для плеера},

                “dataset”: {Данные справочников},

                “error”: {“code”:”Код ошибки (0 – без ошибок)”, “message”:”Текст ошибки или информационное сообщение”},

                “subordinates”: \[Массив подчиненных сотрудников – для метода subordinates\],

                “tasks”: \[Массив целей/задач – для метода tasktree\],

                “workflow\_log\_entrys”: \[Массив записей журнала действий – для метода workflowlogs\],

                “assessment\_start\_date”: “Дата начала процедуры”,

                “assessment\_end\_date”: “Дата окончания процедуры”,

                “assessment\_status”: “Статус процедуры оценки”,

                “assessment\_title”: “Название процедуры”

}
