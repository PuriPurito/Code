## 1.6.1.2. Режим "task" - получение доп. информации по цели

Режим обработчика "task" используется для получения дополнительной информации по цели - получение массива истории изменений или массива комментариев по конкретной задаче. Также режим используется для сохранения комментария по конкретной задаче (не по анкете целиком), если это предусмотрено разработчиком.

Вызов инициируется при переходе на закладку истории или комментариев в открытом диалоге редактирования/просмотра конкретной цели.

Входные параметры:

\- collection - код коллекции, формирующей массив данных (если пусто - будет вызвана стандартная функция получения данных)

\- task\_id - ID цели (объект Задача - task системы)

\- assessment\_appraise\_id - ID процедуры оценки

\- pa\_id - ID текущей анкеты

\- action - запрашиваемое действие ( commentlist - получить массив комментариев, commentsave - сохранить текущий комментарий и вернуть обновленный список, loglist - вернуть массив истории изменений)

\- comment - текст текущего комментария, введенный пользователем

\- state - фаза - ключ, по которой будет создан или запрошен текущий комментарий)

\- options - объект дополнительных данных

      - impersonate\_id - ID пользователя, если действие выполняется в режиме делегирования

Возвращаемое значение - объект:

   - data - массив данных (список комментариев или записи истории изменений)

   - comment - текущий комментарий (только для списка комментариев или сохранения комментария)
