## 1.6.1.3 Режим "block" - работа с блокировками

Режим "block" предназначен для установки/удаления/обновления признака блокировки анкеты, для того, чтобы обеспечить нескольким пользователям попеременно работать с одной и той же формой, без риска потери данных при параллельном сохранении одного и того же объекта данных.

Входные данные - объект:

\- action - тип действия, возможные значения:

         - set - установить признак блокировки

         - get - получить данные о блокировке

         - update - обновить данные блокировки

        - clear - очистить признак блокировки

\- pa\_id - ID анкеты, блокировку на которой надо обработать

\- interval - интервал, на который будет установлен признак блокировки (в минутах), по умолчанию - 20 минут

Выходные данные - объект:

\- state - статус текущей блокировки, возможные значения:

        - free - на данную анкету признак блокировки не установлен

        - my - для данной анкеты установлен признак блокировки текущим пользователем

        - block = для данной анкеты установлен признак блокировки другим пользователем

\- ttl - время (в минутах), оставшееся до истечения времени текущей блокировки

\- user\_id - ID пользователя, установившего блокировку

\- fio - ФИО пользователя, установившего блокировку

Режим блокировки необходим, когда несколько пользователей, в соответствии с правилами документооборота, имеют право на внесение изменений в анкету. Если не предпринять специальных действий, то изменения, внесенные одним пользователем, могут "затереть" изменения другого. Для предотвращения этого для анкеты необходимо прислать параметр конфигурации bHasBlocked.

Получив данный параметр плеер не открывает режим редактирования до тех пор, пока на сервере для данной анкеты и данного пользователя не будет установлен признак блокировки. Если форма уже блокирована другим пользователем, то приступить к редактированию нельзя, пока признак не будет сброшен, командой или по истечению времени.

Если времени на редактирование не хватает, пользователь может запросить продление режима блокировки.

Если он закончил процесс или его попросили - то есть возможность сбросить режим блокировки.
