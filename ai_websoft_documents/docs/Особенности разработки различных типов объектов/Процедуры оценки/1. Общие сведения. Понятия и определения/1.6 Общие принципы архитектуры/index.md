## 1.6 Общие принципы архитектуры

_Плеер оценки запускается файлом appr\_player.html. В качестве параметра в командной строке передается ID текущей оценочной процедуры в виде appr\_player.html?assessment\_appraise\_id\=…_

_Обработка данных на сервере осуществляется обработчиком assessment\_appraise\_data.xml._

Дополнительно в адресе вызова плеера могут быть переданы параметры:  
\- pa\_id - идентификатор оценочной формы, если такая форма есть в списке видимости текущего пользователя - она будет открыта сразу, минуя выбор из дерева оценки  
\- impersonate\_id - идентификатор замещаемого сотрудника - будет осуществлен вход в оценку с делегированием, минуя выбор сотрудника из селектора
