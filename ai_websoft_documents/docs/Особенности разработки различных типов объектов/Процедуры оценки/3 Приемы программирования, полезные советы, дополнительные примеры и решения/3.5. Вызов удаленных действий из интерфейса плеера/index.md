## 3.5. Вызов удаленных действий из интерфейса плеера

Начиная с релиза 2023.2 в плеере реализована возможность запускать интерпретатор удаленных действий, например, при нажатии на кнопку форму или кнопку ДО.

Например, для вызова удаленного действия по кнопке докуметооборота, в коде действия ДО можно прописать:

BRUTE\_MESSAGE = EncodeJson({type:"action", action:{type:"api",command:"remote\_action",remote\_action\_id:"0x65D3131F7B547713", wvars:{param1:"yes",param2:true}}})

при обработке нажатия такой кнопки ДО, на портале, в интерфейсе плеера, будет запущено удаленное действие с ID=0x65D3131F7B547713 c набором переменных param1 и param2

При необходимости, после выполнения УД, управление может быть возвращено в плеер или выполнена некая команда API. Для этого удаленное действие должнол вернуть в интерпретатор директиву call, например, такую (g\_oAppr и API - фиксированные значения для вызова API плеера оценки):

oResAction = {  
            command: "call",  
            fn\_name: "g\_oAppr",  
            fn\_method: "API",  
            args\_array:\[{command:"reload\_pa"}\]  
        }

RESULT = oResAction;
