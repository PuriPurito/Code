## 3.2. Программирование коллекции для нестандартной выборки анкет для дерева оценки

При вызове исполняемого кода коллекции для построения дерева оценки устанавливаются следующие переменые:

\- sMode - режим вызова коллекции - для построения дерева "list" (может быть использован в случае универсальной коллекции, вызывамой в нескольких местах)

\- curUserID - id объекта текущего пользователя  
\- curPersonID - id объекта текущего участника оценки (с учетом замещения)  
\- curAssessmentAppraiseID - id объекта текущей оценочной процедуры  
\- curWorkflowID - id объекта текущего документооборота  
\- bIdOnly - флаг - возвращать только id анкеты, без дополнительных атрибутов  
\- bExpertInfo - флаг - возвращать данные руководителя (дополнительно к оценивающему) - дерево будет построено по нему  
\- bPersonIco - флаг - возвращать URL аватара/фото сотрудника  
\- bRootUserID - id объекта сотрудника - верхний уровень иерархии при инкрементальной загрузке  
\- bIncremental - флаг частичной загрузки - означает, что вернуть надо один уровень иерархии дерева, а нижние будут подгружаться  
\- iLevelExpand - число, сколько уровней иерархии вниз будет раскрыто в дереве по умолчанию  
\- bExcludeSelf - не возвращать анкеты верхнего уровня (bRootUserID), а только анкеты следующего уровня  
\- iTargetPAID - id анкеты верхнего уровня - для инкрементальной загрузки по иерарахии анкет

При выполнении код выборки может возвращать данные в двух вариантах  
            - массив RESULT, содержащий список объектов-описаний анкет

           - объект DATA, который может содержать элементы

                        - массив data cо списком анкет

                       - объект config с параметрами отображения дерева и работы плеера

                       - объект dataset - набор массивов различных блоков данных - значений для выбора в полях, отображения списков и т.д.

Т.е., если коллекция возвращает непустой массив RESULT - то список анкет будет взят из него.

Если массив RESULT пустой - то все данные будут взяты из объекта DATA - DATA.data, DATA.config, DATA.dataset.

Каждый элемент массива анкет представляет из себя объект со свойствами:

\- id - идентификатор объекта анкеты

\- person - объект описания оцениваемого с атрибутами

          - id - идентификатор объекта сотрудника

          - fullname - ФИО сотрудника

          - position - название должности

          - icon\_url - путь к фото сотрудника, возвращается, если установлен флаг bPersonIco

\- expert - объект описания оценивающего с атрибутами

          - id - идентификатор объекта сотрудника

          - fullname - ФИО сотрудника

          - position - название должности

          - icon\_url - путь к фото сотрудника, возвращается, если установлен флаг bPersonIco

\- boss - объект описания руководителя с атрибутами, возвращается, если установлен флаг bExpertInfo

          - id - идентификатор объекта сотрудника

          - fullname - ФИО сотрудника

          - position - название должности

\- custom\_experts -  массив объектов описания экспертов с атрибутами, возвращается, если установлен флаг bExpertInfo

          - id - идентификатор объекта сотрудника

          - fullname - ФИО сотрудника

          - position - название должности

\- status - статус анкеты (self/manager/expert и т.д.)  
\- type - тип анкеты (competence\_appraisal/staffrating и т.д.)  
\- is\_done - флаг - признак заполненности анкеты  
\- is\_processed - флаг - признак того, что анкета начала заполнятся  
\- workflow\_state - код этапа документооборота  
\- index - число - индекс формы

\- has\_children - флаг, признак наличия анкет следующего уровня иерархии
