## 2.3 Настройка интерфейса иерархии целей

Интерфейс иерархии целей доступен только для форм оценки целей.

Включение/выключение данного интерфейса – при помощи атрибута config.btn\_objectives.

Внешний вид интерфейса:

Заголовок интерфейса, наличие и текст дополнительной информации (как в дереве иерархии) настраивается в объекте config.

Содержание текста каждой строки в списке настраивается в конкретной форме, в объекте wfparameters.task\_tree.

При построении дерева процесс начинается в задач верхнего уровня текущей формы (этим задачам присваивается уровень 0). Далее вверх или вниз построение идет по алгоритму:

\- если к данной задаче есть подчиненные/родительские задачи (по полю parent\_task\_id) – то они добавляются в список с уровнем, увеличенным или уменьшенным на единицу;

\- если подчиненных/родительских задач нет, идет поиск транслированных/каскадированных задач (по полю translated\_task\_id) и, если они есть, то включаются в список с уровнем, увеличенным или уменьшенным на единицу;

\- для каждой задачи извлекается стандартный набор полей (указан в описании объекта task\_tree).

\- в соответствии с описанием уровня из массива task\_tree, задача текущего уровня может быть исключена из списка или может быть изменен список ее атрибутов (класс, набор полей с настройками их показа).

Интерфейс позволяет визуально показать для сложных методик оценки, с каскадированием и декомпозицией целей, весь путь, от цели вышестоящего руководителя до цели конечного исполнителя, с формулировками и значениям показателей.
