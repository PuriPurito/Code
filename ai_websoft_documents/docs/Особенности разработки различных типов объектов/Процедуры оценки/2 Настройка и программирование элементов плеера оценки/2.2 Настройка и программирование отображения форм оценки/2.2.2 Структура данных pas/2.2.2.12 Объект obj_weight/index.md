## 2.2.2.12 Объект obj_weight

Объект содержит настройки интерфейса редактирования весов целей. Интерфейс открывается по кнопке «Редактировать веса» (action\=weight), расположенной вне списка целей, и позволяет редактировать веса сразу нескольких целей в одном окне, сохраняя все значения разом (что удобно при балансировке – приведения суммы весов к нужному значению).

По умолчанию, если объект пуст или отсутствует, в окно редактирования весов попадают все значения полей «weight» целей верхнего уровня, а в качестве описания используется название цели из поля «name».

Структура объекта:

{

obj\_id: \[ // Массив объектов, описывающих цели, веса которых будут редактироваться в окне, если массив отсутствует – в окно будут выведены все цели верхнего уровня

                {id: “”, // Идентификатор цели, которую надо включить в перечень редактирования весов

                readonly: false, // Признак блокировки, если true – вес этой цели нельзя редактировать (в списке значение видно, но его нельзя менять)

                class: “”} // Класс, будет добавлен в список стилей строки с полями цели

\],

mode:  // режим отбора задач для показа в форме, используется, если не задан obj\_id, если не задан, то будут показаны только цели первого уровня, также может принимать значения:

               "all" - в форме будут показаны все цели анкеты

               "blocks\_and\_first" - будут показаны все цели первого уровня каждого блока + строка итогов для каждого блока + общий итог

               "blocks\_and\_all" - будут показаны все цели анкеты + строка итогов для каждого блока + общий итог

sum\_mode: "all" // режим суммирования - если не задан или "all", то все цели суммируются "сплошным" потоком и итоговая сумма - сумма весов всех целей

               "levels" - цели суммируются иерархически, т.е. сумма внутри уровня/блока, а уровнем выше - суммируются веса этого блока

obj\_label: “”, // Заголовок колонки с описанием цели, по умолчанию «Название»

add\_label: “”, // Заголовок колонки в доп. описанием – по умолчанию только одна колонка

weight\_label: “”, // Заголовок колонки с полями для редактирование веса – по умолчанию «Вес»

obj\_field: “”, // Поле объекта цели, значение которого будет в первой колонке (name)

add\_field: “”, // Поле объекта цели, значение которого будет выведено в доп. колонку

weight\_field: “” // Поле, значение которого будет выведено в качестве веса (weight)

min: 0 // минимально возможное значение для веса отдельной цели

max: 100 // максимально возможное значение

_scale: \[ //  Шкала задания классов для различных значений итоговой суммы весов_

                { min: 0,   // нижняя граница интервала задания класса

                   max: 100,   // верхняя граница интервала задания класса

                  class: "",  // класс, который будет присвоен строке итогов при попадании суммы весов в интервал

                  title: "" // заголовок строки итогов при попадании в данный интервал

                }

\],

}

Настройка объекта позволяет:

\- выводить в список редактирования не все цели, например, исключать отмененные или виртуальные (если их вес не учитывается в общем весе целей формы)

\- выводить в диалоговое окне не только название цели, но и некоторую дополнительную информацию

\- запрещать редактирование весов некоторых целей, например, обязательных или ранее утвержденных

\- устанавливать ограничения на вводимые значения весов целей

\- раскрашивать сроки с целями различным цветом, например, выделяя приоритетные

\- динамически менять цвет и внешний вид строки итогов (суммы весов) при изменении значений веосв целей. Алгоритм проверки следуюущий - последовательно обрабатываются все элементы массива scale - если задана минимальная граница, то текущая вычисленная сумма провераяется относительно нее по "больше или равна", если задана максимальная - то для нее по "меньше или равно". если условия выполнены - строке итогов присваивается нужный класс и название строки. Пример для случая: 100% - класс good и строка "ОК", для менее 100% - класс low и строка "Мало", больше 100% - класс upp и строка "Многовато":

_\[{min:100, max:100, class: "good", title: "ОК"}, {__max:100, class: "low", title: "Мало"__}, {__min:100, class: "upp", title: "Многовато__}\]_
