## 2.2.2.1 Объект person

Описывает структуру данных об участнике оценки. Плеер использует эти данные для показа информации в заголовке формы - об оцениваемом, руководителе или эксперте.

Структура одинакова для объектов person, expert, boss и элементов массива custom\_experts.

{

Id: “”, // идентификатор личной карточки участника оценки

fullname: “”, // ФИО

position: “”, // Должность

sub: “”, // Подразделение

org: “”, // Организация

icon\_url: “”, // Путь к файлу фотографии

header: “”, // Текст заголовка при показе информации об участнике в режиме развернутого заголовка формы, заменяет стандартный заголовок (Сотрудник, Руководитель, Эксперт и т.п.)

title: “”, // Наименование участника, заменяет стандартный текст (Оцениваемый, Оценивающий руководитель, Функциональный руководитель, Согласующий руководитель и т.п.)

**title\_add: null, //** доп. текст для наименования (будет показан по умолчанию белым на синем фоне справа от наименования)

position\_title: “”, // Заголовок данных по должности, заменяет стандартный заголовок «Должность» в колонке развернутого заголовка

sub\_title: “” // Заголовок данных по подразделению, заменяет стандартный заголовок «Подразделение» в колонке развернутого заголовка

}

Все структуры данного типа доступны разработчику для изменения в коде дополнительного шаблона. Т.е. можно кастомизировать данные, например сокращать информацию ФИО только до фамилии и имени, выводить контекстно наименование участника, в зависимости от его функционала в оценке, например.

Начиная с релиза 2023.2 в объект person дополнительно добавлены параметры:  
_custom\_experts\_layout (vertical)_ \- вертикальное расположение плашек с фото и ФИО руководителей).  
_custom\_experts\_expand (true)_ \- раскрывать блок плашек ФИО при вертикальном расположении (видно только 1).
