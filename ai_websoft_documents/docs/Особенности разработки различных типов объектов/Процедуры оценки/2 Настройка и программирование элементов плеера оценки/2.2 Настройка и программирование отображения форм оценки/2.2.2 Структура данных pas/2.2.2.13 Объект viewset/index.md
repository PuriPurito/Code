## 2.2.2.13 Объект viewset

Объект содержит описания настроек дополнительных виджетов, которые необходимо отобразить на форме. В настоящий момент в плеере поддерживается один дополнительный виджет – scaleblock, представляющий из себя информер с названием и значением оценки:

Структура объекта (для приведенного рисунка):

{

items\_in\_row: 2, // Количество виджетов в строке

scaleblock: \[ // Массив объектов, содержащих описание каждого выводимого виджета

                { // Настройки виджета 1

                text: “Интегральная оценка по целям”, // Название показателя

                value: “”, // Значение показателя

                desc: “Описание оценки”, // Заголовок описания показателя

                comment: “Комментарии к целям”, // Описание показателя

                class: “classname” // Класс блока

                },

                { // Настройки виджета 2

                text: “Интегральная оценка по компетенциям”, // Название показателя

                value: “”, // Значение показателя

                desc: “Описание компетенций”, // Заголовок описания показателя

                comment: “Комментарии к компетенциям”, // Описание показателя

                class: “classname” // Класс блока

                }             

\]

}
