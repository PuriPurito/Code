## 2.2.2.8.4 Массив competences.indicators

Содержит массив объектов, описывающих настройки отображения каждого индикатора из набора в форме, относящихся к данной компетенции. Структура объекта, описывающего индикатор, следующая:

{

id: “”, // Идентификатор индикатора

name: “”, // Название индикатора

description: “”, // Описание индикатора

editable: true, // Признак возможности изменить значение

mark: {}, // Оценка по индикатору, текст (только оценка) или объект (оценки и параметры отображения/редактирования)

value: ””, // Числовое значение оценки

comment: “”, // Комментарий к оценке индикатора

has\_comment: false, // Признак возможности ввода/показа комментария

comment\_after\_control: false, // Показывать поле комментария после элемента ввода оценок, по умолчанию (false) поле ввода комментария выводится ниже названия индикатора

class: ””, // Класс, будет добавлен в таблицу стилей контейнера отображающего индикатор

scale: \[\], // Шкала оценки индикатора

tip\_text: "", // всплывающий, при наведении мыши на название индикатора, текст подсказки

tip\_text\_class: "", // класс, будет добавлен к всплывающему тексту

check\_require\_on\_select: false // - предупреждать об обязательности комментария сразу после выбора значения оценки, имеет приоритет над одноименным параметром в компетенции

}

Структура и принципы формирования объектов mark и scale, входящих в состав настроек индикатора, совпадают с таковыми для настройки компетенции, и описаны в разделе описания структуры объекта настроек компетенции.
