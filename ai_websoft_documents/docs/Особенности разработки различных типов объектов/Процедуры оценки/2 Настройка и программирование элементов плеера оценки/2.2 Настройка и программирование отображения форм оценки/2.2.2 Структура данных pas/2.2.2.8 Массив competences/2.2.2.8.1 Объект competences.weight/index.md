## 2.2.2.8.1 Объект competences.weight

Содержит значение и параметры отображения/редактирования веса компетенции.

Обработчик формирует простой вариант данного объекта в виде строки со значением веса.

Если вес компетенции не нужно показывать, разработчик может установить атрибут weight\_view\=”none”.

Если вес необходимо редактировать, необходимо сформировать объект следующей структуры:

{

control\_type: “”, // тип элемента управления для ввода значения, поддерживается number и spinner

value: “”, // текущее значение веса

min: “”, // минимально возможное значение для ввода

max: “”, // максимально возможное значение для ввода

step: “”, // шаг изменения значения, для типа spinner

visible: true, // видимость элемента ввода

editable: true // признак возможности редактирования

}
