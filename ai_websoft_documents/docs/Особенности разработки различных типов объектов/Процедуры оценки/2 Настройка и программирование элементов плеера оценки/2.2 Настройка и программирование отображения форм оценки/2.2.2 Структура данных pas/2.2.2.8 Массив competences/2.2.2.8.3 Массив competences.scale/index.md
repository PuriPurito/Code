## 2.2.2.8.3 Массив competences.scale

Содержит массив значений шкалы оценки компетенций, формируется обработчиком.

{

id: “”, // сохраняемое значение

name: “”, // показываемый текст для значения

desc: “”, // описание, показывается при наведении мыши на значение

comment\_require: false // признак необходимости ввода комментария, если выбрано данное значение

check\_require\_on\_select: false // - предупреждать об обязательности комментария сразу после выбора значения, имеет приоритет над одноименным параметром в компетенции/индикаторе/конфиге

}

Значения данного массива используются, если объект mark не настроен и используются настройки по умолчанию.
