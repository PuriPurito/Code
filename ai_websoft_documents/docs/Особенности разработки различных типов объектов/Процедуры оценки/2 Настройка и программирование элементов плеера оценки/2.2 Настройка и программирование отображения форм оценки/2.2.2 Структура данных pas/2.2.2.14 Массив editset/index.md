## 2.2.2.14 Массив editset

Массив содержит набор объектов, описывающих настройки блоков полей:

\- для формы общей оценки - основной элемент(ы) формы;

\- для формы целе/компетенций - дополнительный элемент, размещаемый ниже основых (блока целей или компетенций), например - для показа доп. вопросов.

Структура описания каждого блока:

{

label: “”, // Заголовок блока

visible: true, // Признак видимости блока

editable: true, // Признак возможности редактирования полей блока

required: false, // Признак обязательности заполнения полей блока

class: “”, // Класс, будет добавлен к списку стилей контейнера блока полей

btn\_view\_show: false, // Флаг, показывать или нет кнопку просмотра блока. По умолчанию, блок открывается в отдельном поле только для редактирования, когда форма в режиме просмотра – видны поля только в форме, кнопки просмотра блока в отдельном окне нет.

btn\_view\_title: “”, // Текст кнопки просмотра. Если атрибута нет, по умолчанию - «Открыть»

btn\_edit\_title: “”, // Текст кнопки редактирования. По умолчанию – «Изменить»

<field\_name\>: {}, // Объекты, содержащие описание настроек полей,

<field\_name\>: {}, // входящих в состав блока.

<field\_name\>: {}, // Название объекта – код поля (name, period и т.п.)

……..

}

В форме общей оценки есть возможность сгруппировать редактируемые и показываемые поля по блокам. Каждый блок выделяется на форме оформлением. Редактирование полей блока осуществляется в отдельном окне, открываемом по кнопке в заголовке блока, сохранение и обновление формы – по закрытию этого окна.

Обработчик не формирует массива editset – это должен обеспечить разработчик в коде шаблона подготовки данных.

При сохранении данных формы общей оценки обработчик извлекает поля (входящие в состав видимых полей документооборота) из объектов массива editset и сохраняет их в массиве custom\_fields документа плана оценки (assessment\_plan).
