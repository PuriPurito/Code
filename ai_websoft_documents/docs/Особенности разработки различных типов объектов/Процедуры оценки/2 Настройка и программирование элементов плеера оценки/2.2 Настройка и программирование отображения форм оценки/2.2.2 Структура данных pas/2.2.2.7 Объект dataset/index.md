## 2.2.2.7 Объект dataset

Содержит массивы данных справочников, общих для всех элементов данной формы. Это могут быть, например списки выбора для различных полей формы, например справочник бюджетных периодов, доступный, путем выставления атрибута data\_src для поля, для всех полей типа «плановый период достижения цели» или «фактический период выполнения», или массив KPI, доступных для выбора в формулировке цели.

Структура объекта dataset, например, содержащего справочники периодов и KPI, может быть такой:

{

periods: \[{},{},…\],

kpis: \[{},{},…\],

…..

}

Каждый массив справочника состоит из элементов следующего вида:

{

                id: “”, // сохраняемое значение

                name: “”, // показываемый текст для значения

                desc: “”, // описание, показывается при наведении мыши на значение

                class: “”, // класс, который будет добавлен в таблицу стилей контейнера для данного значения (возможность, например, раскрашивать значения в списке выбора)

                disabled: false // признак неактивности, если true – значение будет показано в списка, но его нельзя будет выбрать

}

В отличии от объекта dataset, загружаемого с деревом оценки, обработчик не формирует такой объект для каждой формы, поэтому, при необходимости, разработчик должен сформировать этот объект самостоятельно, в коде шаблона подготовки данных. При этом, при желании, он может в справочнике для конкретной формы, переопределить общий объект, загруженный вместе с деревом оценки. Логика работы плеера при работе со справочниками следующая - при наличии в настройках поля ссылки на справочник сначала проверяется его наличие в объекте dataset текущей формы, и только, если тут справочник с нужным кодом отсутствует, он ищется в общем объекте dataset, загруженным вместе с деревом оценки.

В частности, в данном объекте можно передавать объект workflow - список этапов ДО, специфический для данной формы (т.е. для каждой формы может быть показана индивидуально настроенная линейка этапов ДО). При этом в элементах описания этапов могут быть установлены дополнительные атрибуты - title (всплывающее описание этапа), start\_date (дата начала этапа), end\_date (дата окончания этапа), которые будут показаны в линейке.
