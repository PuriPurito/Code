## 2.2.2.11 Массив objective_blocks

Массив содержит описания блоков целей, если они заданы для формы. Если массив не пуст, цели верхнего уровня при показе будут сгруппированы по блокам, связь цели с блоком – через атрибут objective\_block\_id  в объекте описания цели

{

id: “”, // Идентификатор блока

name: “”, // Заголовок блока

weight: “”, // Вес блока (опционально), если пусто – не показывается

mark: “”, // Оценка по блоку (опционально), если пусто – не показывается

class: “”, // Класс, если задан – будет добавлен к списку стилей контейнера блока

expandable: false, // Признак возможности свернуть/развернуть блок, если false или не задан – кнопка сворачивания блока не показывается

collapsed: false // Показывать свернутым при открытии формы (по умолчанию все блоки развернуты)

}

Обработчик не формирует данный массив. Он, при необходимости, должен быть сформирован разработчиком самостоятельно.
