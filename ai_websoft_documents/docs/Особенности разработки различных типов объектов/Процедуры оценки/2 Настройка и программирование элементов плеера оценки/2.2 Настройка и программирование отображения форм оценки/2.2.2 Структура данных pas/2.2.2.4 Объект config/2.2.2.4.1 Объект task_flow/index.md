## 2.2.2.4.1 Объект task_flow

Объект task\_flow - это объект настроек, позволяющий показать и настроить параметры отображения для линейки задач в верхней части формы

Линейка задач - это область в верней части формы целей (между блоком инструкции и фильтром), в котором, по желанию разработчика, может быть размещен:

\- прогресс-индикатор, отображающий ход выполнения задач формы

\- список задач, полный или выборочный, в виде текстовых плашек или пиктограмм, с возможностью раскраски по статусу выполнения, и быстрого перехода к нужной задаче

Если данный объект отстуствует, блок линейки задач не показывается.

Структура объекта настройки панели задач следующая:

task\_flow : {

     pos: "top"|"bottom"|"all" // положение линейки задач на форме (выше блока задач, ниже блока задач, и выше и ниже)

    show\_tasks: true|false // формировать масскив задач для показа в линейке автоматически. Если false - то в наборах данных формы (oData.data.dataset) должен быть задан массив taskflow, содержащий список элементов для линейки задач

    task\_all: true|false // включать в линейки все задачи формы (на всех уровнях)

    task\_level: число // уровень целей, которые будут включены в линейку задач. 0  - блоки целей, 1 - цели первого уровня, 2 - второго и т.д.

   task\_name: name // название поля задачи, из которого будет взят текст для показа в линейке (случай плашек)

    task\_title: desc // название поля, из которого будет взято описание задачи (всплывает в окошке при наведении мыши на задачу в линейке)

    task\_ico: icon // название поля, из которого будет взята ссылка на пикторграмму задачи в линейке

   task\_class: class // название поля, из которого будет взято название класса для плашки/пикторграммы задачи в линейке

   task\_state: "" // название поля, из которого будет взято состояние задачи, определяет предустановленное отображение/предзаданный класс, возможные стандартные значения - n (задача не активна), i - задача в процессе выполнения, c - задача выполнена. Если поле пустое, плеер попытается вычислить статус на основе оценки цели в процентах (0 - n, 100 - c)

  view\_type: taskflow|progressbar // тип отображения линеки задач - цепочка плашек или линейка прогресса (цветовой пронресс-индикатор)

  fill\_tasks\_line: true // заполнить блок линейки (только для режима task\_flow), если false - то плашки с текстом задач будут фиксированной ширины, елси true - ширина плашек подбирается, чтобы заполнить всю ширину формы

   show\_tasks\_content: false|text|icon // тип отображения плашки - без текста (пустой блок), текст в блоке, картинка

   title: "" // заголовок перед линейкой задач (если параметр отстуствует  - значение по умолчанию "Прогресс выполнения", если параметр ест, но пуст - то без заголовка

   color\_null: "" // только для прогресс-индикатора - цвет правой части индикатора (не начатые задачи)

   color\_full: "" // только для прогресс-индикатора - цвет левой части индикатора (завершенные задачи)

   action: "" expand|expandfirstonelevel|expandfirst|focus|open // для линейки задач - действие, выполняемое по нажатию на плашку (expand - развернуть нужный блок задачи, expandfirstonelevel - развернуть нужный блок (только верхний уровень) и свернуть все остальные, expandfirst - развернуть нужный блок (включая нижестоящие уровни) и свернуть все остальные, focus - развернуть нужный блок и установить на нем фокус/проскролить окно браузера), open - открыть диалог просмотра/изменения задачи

}

Процент выполненения задач для програсс-индикатора берется из атрибута overall\_percent объекта pa (oData.data.overall\_percent). Если такого атрибута нет - процент рассчитывается, как среднее от списка задач в линейке, по формуле - статус n = 0%, i = 50%, c = 100%
