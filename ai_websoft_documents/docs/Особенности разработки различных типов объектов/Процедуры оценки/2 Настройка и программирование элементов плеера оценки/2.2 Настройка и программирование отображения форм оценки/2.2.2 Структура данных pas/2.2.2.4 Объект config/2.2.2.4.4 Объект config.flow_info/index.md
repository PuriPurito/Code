## 2.2.2.4.4 Объект config.flow_info

Для того, чтобы ускорить показ основной части формы, предусмотрена возможность загружать данные для отдельных служебных блоков отдельными асинхронными запросами к серверу. В частности такая возможность присутствует для линейки ДО, где расположена информация об этапах и сроках документооборота.

Для настройки правил динамической подгрузки этой части формы служит объект flow\_info. Он может содержать следующие свойства:

\- collection - код выборки, которая вернет данные для показа, или,  
\- library - код библиотеки программного кода, и,  
\- method - название функции этой библиотеки, которая будет выполнена, а ее результат вернется в плеер, как данные для отображения, или,  
\- application - код или ID универсального приложения, из библиотеки которого будетт вызвана функция для получения данных.  
\- external\_data - строка или объект с дополнительными данными, который будет передан в коллекцию или функцию, в том же самом виде

Приоритет следующий - если указан код коллекции, то будет выполнена она, если код и метод библиотеки - то они, если данные приложения - то метод из библиотеки приложения.

Данные передаются в код коллекции через установку переменных, в функцию библиотеки - в виде свойств единственного параметра-объекта. Передается следующее:

\- sAction: признак выполняемого действия - сейчас всегда custom\_data  
\- sMode: режим вызова, для данных по линейке этапов - flow\_info  
\- assessment\_appraise\_id: ID текущей процедуры оценки  
\- pa\_id: ID текущей анкеты  
\- curUserID: ID карточки текущего пользователя  
\- curPersonID: ID текущего участника оценки, с учетом делегирования  
\- impersonate\_id: ID, по которому затребовано делегирование (если делегирование не подтверждено, может отличатся от curPersonID)  
\- sUserRole: роль пользователя в текущей форме (user|boss|expert|custom\_expert)  
\- sWFState: текущий этап ДО  
\- bIsDone: признак завершенности формы  
\- sExtData: дополнительные данные, переданные в объекте настроек

Результат выполнения кода коллекции - стандартный объект DATA, функция должна вернуть стандартный объект вида {data:{}, error: 0, errorText:""}

Возвращаемый объект может содержать следующие свойства:  
\- workflow\_state - строка с кодом текущего этапа ДО  
\- dataset: { workflow: { states: \[ {id: , name: , title, start\_date, end\_date, value} \] } } - стандартный массив данных для этапов ДО, аналогичен таковому в dataset  
\- assessment\_start\_date - строка с датой начала процедуры  
\- assessment\_end\_date - строка с датой окончания процедуры  
Если коллекция/функция вернула один из объектов данных - он замещает текущий (даже если прислан null), если объекта нет в возвращаемых данных - он остается, таким, как был прислан в pa.
