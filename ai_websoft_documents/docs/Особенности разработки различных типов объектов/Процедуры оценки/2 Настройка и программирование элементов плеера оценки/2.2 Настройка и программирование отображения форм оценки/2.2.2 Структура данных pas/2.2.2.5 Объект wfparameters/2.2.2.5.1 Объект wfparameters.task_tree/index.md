## 2.2.2.5.1 Объект wfparameters.task_tree

Объект содержит параметры формирования и отображения дерева целей – интерфейса, показываемого при нажатии соответствующей кнопки в левой панели плеера. Объект формируется программистом в программном коде шаблона (в данных, создаваемых обработчиком, данного объекта нет) и передается плеером, как параметры обработчику при запросе данных на прорисовку дерева целей. Если объект настроек отсутствует, дерево целей не строится и кнопка в левой панели неактивна.

{ level: \[ { // массив объектов – настроек показа уровней целей (относительно текущей формы)

                id : 0, // уровень цели (0-текущая цель, 1…n – цели уровня ниже, \_n…\_1 – цели уровня выше (с символом подчеркивания)

                <field\_name\> : { // объект описания поля цели, <field\_name\> - название цели, есть зарезервированные значения, можно использовать дополнительные (см. описание ниже)

                                block: “”, // блок (область) элемента дерева, где будет помещено значение поля, возможные варианты: performer (левый блок, испольнитель) | title (центральный блок, название задачи) | score (центральный блок, оценка) | period\-plan (1 строка правого блока, плановый период) | date\-plan (2 строка правого блока, плановая дата) | period\-fact (3 строка правого блока, фактический период) | date\-fact (4 строка правого блока, фактическая дата), для зарезервированных значений может отсутствовать

label : “”, // Название поля, показывается слева от значения, если пусто или отсутствует – поле без названия, только значение

                                link: “”, // URL ссылки, если пусто или отсутствует – без ссылки, если непусто – формируется ссылка с добавлением параметров (pa\_id, person\_id, task\_id), позволяет, например, открывать печатную форму при клике на текст задачи или ФИО исполнителя

                                data\_src: “”, // название справочника из списка массивов объекта dataset – позволяет показывать наименования элементов справочника по их идентификаторам, получаемым с сервера

                                class: “”, // класс из таблицы стилей, будет добавлен к блоку показа поля

Если формула непустая и возвращает true – цель будет показана в дереве, если false – не будет показана

                                }

},

….

\]}

Зарезервированные названия полей:

\- name (название цели)

\- executor\_name (ФИО исполнителя)

\- executor\_icon (ссылка на фото исполнителя)

\- assigner\_name (ФИО назначившего задачу)

\- assigner\_icon (ссылка на фото назначившего)

\- period\_plan (плановый период достижения цели)

\- date\_plan (плановая дата)

\- period\_fact (фактический период)

\- date\_fact (фактическая дата)

\- score (оценка цели)

Дополнительные названия полей, если указаны в объекте, сначала ищутся в списке стандартных полей документа задачи, если такого поля нет – поле ищется (по ключу name) в структуре custom\_fields документа задачи.
