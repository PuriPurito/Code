## 2.2.2.5.5 Объект wfparameters.objective

Объект, описывающий настройки отображения целей (для формы оценки целей).

{

can\_delete: false, // Признак возможности удалять задачи второго уровня

can\_add\_child: true, // Признак возможности добавлять задачи второго уровня

can\_translate: false, // Признак возможности транслирования задач второго уровня

“buttons”: \[\], // Массив настроек показа кнопок в плашках целей

“dialog\_buttons”:\[\], // Массив настроек показа кнопок в окне диалога редактирования/показа цели

“window\_title”: “”, // Заголовок окна диалога добавления новой цели

_"__scroll\_position__": "", // Величина прокрутки (в пикселях) формы диалога после открытия по кнопке_

“<field\_name\>”: {}, // Набор объектов, описывающих поля цели – настройки отображения

“objective”: \[{}\] // Массив объектов, описывающих настройки отображения целей следующего уровня разных типов. При использовании одного типа - можеть быть просто объектом

}

Атрибуты объекта wfparameters.objective частично совпадают с атрибутами корневого объекта wfparameters, но описывают настройки только для того уровня целей, на котором они находятся в структуре объекта. Т.е., если предусматривается два уровня целей, то в корневом объекте параметр can\_add\_child должен быть выставлен в true, в objective – тоже true, а во вложеном (wfparameters.objective.objective) – в false.

Массив dialog\_buttons – совпадает по структуре и функциональности с соответствующем на верхнем уровне.

Объекты типа “<field\_name\>” описывают все используемые поля цели. Наименование объекта совпадает с наименованием формы, т.е. для поля «Название» (name) объект, содержащий настройки для него, будет name: {….}, для поля «План» - plan: {….} и т.д.

Вложенный объект objective – идентичен по структуре, но описывает настройки целей следующего уровня.
