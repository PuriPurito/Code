## 2.2.2.5.3 Объект wfparameters.sum_weight

При задании на верхем уровне (oData.data.wfparameters), объект содержит настройки отображения значения суммы весов целей (атрибут “sum\_weight” из объекта “pa”).

{

“position”: “”, // расположение виджета – top | bottom | both

“class”: “”, // класс, будет добавлен к верхнему объекту виджета

“title”: “” // заголовок, если пусто – заголовок по умолчанию "Суммарный вес всех целей,%"

}

Если объект задан на втором или более нижнем уровне (oData.data.wfparameters.objective.wfparameters или oData.data.objectives\[i\].wfparameters), объект задает параметры строки с суммой весов подцелей, структура объекта при этом:

{

“show”: “”, // управление показом сроки итогов, "none" - не показывать

“class”: “”, // класс, будет добавлен к верхнему объекту строки

“title”: “” // заголовок, если пусто – заголовок по умолчанию "Суммарный вес задач даннной цели,%"

}
