## 2.2.2.5 Объект wfparameters

Объект содержит информацию о параметрах отображения формы

{

task\_tree: {}, // Объект, содержащий настройки показа дерева целей (показывается по кнопке в левой панели) для данной формы оценки целей

buttons: \[\], // Массив, содержащий описание настроек кнопок формы

sum\_weight: {}, // Объект, содержащий настройки отображения блока редактирования

btn\_column\_title: “”, // Строка, содержащая текст заголовка колонки с кнопками (Редактировать/Просмотреть/Удалить) при табличном варианте отображения формы целей (view\_type\=”table”)

dialog\_buttons: \[\], // Массив, содержащий настройки показа кнопок диалога формы редактирования/отображения цели (кнопки Сохранить/Черновик/Закрыть)

objective: \[{}\] // Массив объектов, описывающих параметры отображения целей верхнего уровня разных типов, если используется один тип целей - может быть просто объектом

view_\__type_: “”, // Режим отображения_ _–_ tree _|_ table

view_\__type_\__level_: “”, // только для формы целей в режиме_ table _– уровень цели (начиная с 0), с которого включается режим таблицы - т.е. все дочерние цели ниже этого уровня будут отображаться в виде таблицы_

_onAdd: {}, // Объект, описывающий поведение плеера при добавлении задачи/цели_

_onEdit: {}, // Объект, описывающий поведение плеера при открытии окна задачи/цели на редактирование_

_onView: {}, // Объект, описывающий поведение плеера при открытии окна задачи/цели на просмотр_

}
