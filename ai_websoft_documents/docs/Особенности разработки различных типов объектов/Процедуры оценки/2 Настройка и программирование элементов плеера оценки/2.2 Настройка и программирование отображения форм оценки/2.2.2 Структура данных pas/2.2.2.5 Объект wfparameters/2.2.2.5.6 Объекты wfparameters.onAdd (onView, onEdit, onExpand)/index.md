## 2.2.2.5.6 Объекты wfparameters.onAdd (onView, onEdit, onExpand)

wfparameters.onAdd {

     depend\_datasets: \[ 

              { name: <имя набора данных>, collection: <код коллекции для получения набора данных> },

              ...........

              { name: <имя набора данных>, collection: <код коллекции для получения набора данных> }

          \],

     update\_data: {

             collection: <Код коллекции для получения данных и параметров задачи>

          }

          no\_task: false,

          no\_params: false,

          no\_parent: false,

}

Объект служит для задания режима работы плеера при получении команды на добавление цели/задачи (нажатие кнопки "Добавить")

Объект содержит два элемента и два флага:

\- depend\_datasets - массив объектов, описывающий, какие наборы данных (dataset) надо обновить перед открытием окна цели. используется, если форма содержит много индивидуальных (отдельных для каждой цели) наборов для выбора значения полей. Позволяет не формировать большой массив данных при первом открытии формы (из которых, возможно, будут востребованы не все), а подгружать эти данные с сервера по мере их затребованности

\- update\_data - объект, содержащий один обязательный элемент - код коллекции, которая вернет параметры показа полей цели (param) и, возможно, значения полей (task). Если этот атрибут заполнен, то перед открытием окна цели указанная коллекция будет вызвана с сервера. Полученные данные будут использованы для модификации параметров, полученных при первоначальном открытии формы.

\- no\_task - не передавать данные (содержание полей) текущей задачи (если надо уменьшить объем передаваемых данных), по умолчанию - данные передаются

\- no\_params - не передавать настройки (wfparameters.objective) текущей задачи, по умолчанию - параметры передаются

\- no\_parent - не передавать данные (содержание полей) родительской задачи- по умолчанию передается

Также могут присутствовать объекты onEdit и onView, которые задают режим работы плеера при открытии окна цели на редактирование или на просмотр, соответственно.

Еще можно задать объект onExpand - он будет учтен при разворачивании плашки цели, используется для уменьшения времени открытия формы и минимазации объема пересылаемых данных, когда цель присылается с признаком collapse = true и минимальным набором полей/параметров (только заголовок), а при открытии цели ее содержание и параметры показа подгружаются динамически с сервера вызовом специальной коллекции.

Использование этих настроек позволяет не загружать все данные, нужные для показа целей (поля и параметры) в момент первоначальной загрузки формы, а подгружать эти данные с сервера, по мере необходимости/действий пользователя.

Принципы программирования коллекций при использовании этих настроек см. статьи 2.2.5.4.1, 2.2.5.4.2 и 2.2.5.4.3 настоящей документации.
