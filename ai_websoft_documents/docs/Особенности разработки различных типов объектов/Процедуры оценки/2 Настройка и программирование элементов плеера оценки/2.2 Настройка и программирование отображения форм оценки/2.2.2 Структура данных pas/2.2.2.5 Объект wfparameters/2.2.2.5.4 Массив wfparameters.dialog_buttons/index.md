## 2.2.2.5.4 Массив wfparameters.dialog_buttons

Массив содержит элементы, описывающие настройки отображения кнопок диалогового окна, открывающегося по кнопке редактирования или просмотра цели.

По умолчанию окно в режиме редактирования содержит три кнопки: «Сохранить», «Сохранить как черновик», «Отмена», в режиме просмотра – одну кнопку «Отмена».

Структура элемента массива:

{

“action”: “”, // Тип кнопки (save | draft | cancel)

“title”: “”, // Текст кнопки

“class”: “”, // Класс, который будет добавлен в список стилей верхнего элемента кнопки

“save”: false, // Для кнопки «Отмена» - сохранять форму при нажатии кнопки (для кнопок «Сохранить» и «Сохранить как черновик» сохранение происходит всегда)

“softcheck”: false, // Для кнопки «Сохранить» - тип проверки обязательных полей, если атрибут = false или отсутствует, при попытке сохранить форму без заполнения обязательных полей выдается стандартное сообщение «Вы не заполнили обязательные поля» и кнопка «Отмена», возвращающая в окно ввода данных. Если атрибут установлен в true – кнопка «Сохранить» проверяет заполненность обязательных полей и, если что-то не заполнено, выдает окно сообщения с двумя кнопками «ОК» (сохранение данных) и «Отмена» (возврат в окно ввода).

“softcheck\_oktitle”: “”, // Текст кнопки «ОК» в окне подтверждения (при сохранении недозаполненной формы)

“softcheck\_canceltitle”: “”, // Текст кнопки «Отмена» в окне подтверждения

“softcheck\_message”: “” // Текст сообщения в окне подтверждения

}

Если массив пуст или отсутствует – показываются кнопки диалога по умолчанию. При наличии массива в параметрах – показываются только кнопки, описанные в массиве.
