## 2.2.2.5.5.2 Объект описания поля цели objective.<field_name>

В структуре objective должны быть перечислены параметры отображения всех видимых полей цели, т.е. поля, присутствующие в цели, но не описанные в структуре, не будут отображаться на форме – плеер их просто проигнорирует.

Название объекта соответствует названию поля.

Есть 4 зарезервированных названия для показа элементов формы, не связанных со значением полей задач:

\- header – текст, размещаемый в верхней части формы, сразу под заголовком окна

\- divider – разделитель (сплошная линия)

\- instruction – текст, размещаемый в качестве инструкции по заполнению полей формы

\- richtext – текст, размещаемый в произвольном месте формы

Элементы header|instruction|richtext – по сути, один и тот же элемент (произвольный текстовый блок, с поддержкой HTML\-развертки) и отличаются друг от друга только стандартным стилем, применяемым к блоку по умолчанию, условно говоря: header – полужирный, instruction – красный, richtext – без эффектов.

Если на форме необходимо использовать несколько стандартных элемекнтов оформления, то можно использовать суффиксные названия - к зарезервированному слову добавляется суффикс с номером по порядку (divider\_0, divider\_1, header\_1, richtext\_1 и т.п.)

Также есть список стандартных полей, которые формируются обработчиком особым образом и всегда присутствуют в наборе данных. Список стандартных полей:

\- name – название цели (поле name из объекта task)

\- plan – плановое значение цели (поле plan из объекта task)

\- fact – фактическое значение (поле fact из объекта task)

\- period\_plan – _плановый период_ (_поле_ plan\_budget\_period\_id _из объекта_ task)

\- date\_plan – дата планирования (поле date\_plan из объекта task)

\- period\_fact – фактический период (поле fact\_budget\_period\_id из объекта task)

\- date\_fact – фактическая дата (поле date\_fact из объекта task)

\- mark – оценка по цели (поле value из объекта task)

\- weight – вес цели (поле weight из структуры tasks объекта pa – оценочной формы)

_\-_ position _– порядковый номер цели (поле_ position _из структуры_ tasks _объекта_ pa _– оценочной формы) (2019.2.3.83)_

Помимо стандартных и зарезервированных полей, обработчик автоматически включает в данные поля документооборота, видимые согласно условиям, описанным в объекте ДО.

Структура описания поля следующая:

{

control\_type: ””, // Тип поля, возможные значения:

//            group – специальный тип – группа полей, объединенная в контейнере с возможностью свернуть (оставив только название) или развернуть содержимое контейнера

//            text – поле для ввода и показа текста

//            number – числовой ввод, показ – как текст

//            date – ввод даты, показ – как текст

//            textarea – ввод нескольких строк текста, показ – как текст

//            select – выбор значения из выпадающего списка, показ – как текст

//            list – выбор нескольких значений в окне выбора слева, с переносом выбранного в окно справа, показ – как список в несколько строк текста

//            checkbox – установка «галки» в квадрате, показ - аналогично

//            slider – выбор значения путем перемещения указателя по линейке, показ – выбранное значение

//            spinner – поле числового ввода с возможностью изменения значения мышью в полосе прокрутки

//            file – выбор файла, при показе – возможность скачать/просмотреть содержимое

//            url – ввод текста ссылки, при показе – возможность перейти по клику на ссылке

_//           foreign\_elem - выбор объекта(ов) из каталога_

label: “”, // заголовок (текстовое название) поля

design\_block: "fact", // только для полей типа date или number - область плашки, куда будет размещено поле (plan | fact | common)

class: “”, // класс, который будет добавлен в список стилей контейнера поля

cell\_class: “”, // Класс, который будет добавлен к ячейкам поля в табличном представлении

_primary: false, // Признак фокуса, если параметр установлен в true - то при открытии диалога формы экран будет прокручен до этого поля_

width: “”, // Ширинка колонки (для табличного представления), где будут размещены значения

_desc\_form: "", // Текст всплывающего сообщения (tooltip/title), будет показан при наведении мыши на заголовок поля в окне редактирования_

_desc\_from\_class: "", // дополнительный класс для сообщения_

_desc\_view: "",_ _// Текст всплывающего сообщения (tooltip/title), будет показан при наведении мыши на заголовок поля в списке/таблице_

_desc\_view\_class: "",_ _// дополнительный класс для сообщения_

_desc\_value: "",_ _// Текст всплывающего сообщения (tooltip/title), будет показан при наведении мыши на элемент ввода в окне редактирования_

_desc\_value\_class: "",_ _// дополнительный класс для сообщения_

editable: true, // признак возможности изменить значение поля

required: false, // признак обязательности - необходимости заполнить/выбрать значение

visible: true, // признак видимости – возможность создания скрытых полей

visible\_in: “”, // область видимости, строка значений, разделенных точкой с запятой. Значения:

//            title – значение поля показывается в заголовке окна редактирования/просмотра цели

//            view – значение поля показывается в основной форме (плашка или ячейка таблицы)

//            form – поле показывается для просмотра/редактирования в диалоговом окне показа/редактирования цели

group: “”, // Группа, в составе которой будет показано поле (должно совпадать с именем одного из объектов с типом group, причем этот объект должен быть описан до появления поля, ссылающегося на него)

expand\_in: “”, // для полей типа group – развернутое состояние группы в указанных областях (анлогично visible\_in – одно из двух или оба значения view;form). По умолчанию группа свернута во всех областях. Например expand\_in: “form” – группа будет свернута в основной форме (на плашке цели), но развернута при открытии окна диалога редактирования

layout: “”, // для полей типа checkbox или radio – ориентация элементов контрола (радиокнопок или чекбоксов) – col (размещение в колонках по горизонтали – одна строка, несколько элементов) | row (размещение в строках по вертикали – несколько строк, по одному элементу в каждой)

spot\_position: “”, // Положение радио/чекбокса относительно текста выбираемого значения:

// left – элемент слева, текст справа

// right – элемент справа, текст слева

// top – элемент выше, текст под элементом

// bottom – элемент ниже, текст над элементом

spot\_type: “”, // тип элемента выбора – plain (круглые элементы) | square (квадратные элементы)

value\_position: “”, // для поля типа slider – положение области, где показывается текущее установленное значение left|right|top|bottom

data\_src: “”, // для элементов со списками (list/select/checkbox/slider/spinner) – если используется общий массив данных (из объекта dataset) - название справочника, хранящего данные для выбора

scale: { // задание массива данных для выбора (если не задан data\_src)

                value: \[ // массив значений для выбора

                                {

                                id: “”, // сохраняемое значение

                                name: “”, // показываемый текст для значения

                                desc: “”, // описание, показывается при наведении мыши на значение

                                class: “”, // класс, который будет добавлен в таблицу стилей контейнера для данного значения (возможность, например, раскрашивать значения в списке выбора)

                                disabled: false // признак неактивности, если true – значение будет показано в списка, но его нельзя будет выбрать

                                }

                                \]

                },

_depend\_datasets: \[ // массив, задающий связанные наборы данных (которые надо обновить при смене значения в данном поле) и выборки для их обновления_

                {

                                name: имя\_набора\_данных,

                                collection: код\_объекта\_выборки},

                \],

clear\_fields: "name1;name2", // строка с названиями полей (через точку с запятой), которые будут очищены (выставлены значения по умолчанию) при изменении значения в данном поле

update\_data: {collection: col\_name, params: false}, // объект, определяющий действия плеера при смене значения в данном поле, с параметрами: collection - код коллекции, которая будет вызвана на сервере, params - флаг, показывающий, будут ли обновлятся только данные или параметры цели тоже. Логика функционала - при смене значения в поле на сервере будет вызвана коллекция, в которую будут переданы текущие значения формы и (если установлен флаг params) обхект параметров формы (wfparameters.objective). Выборка может модифицировать эти объекты и вернуть их плеере, который перерисует форму с учетом изменений. Подробнее - в отдельной статье.

placeholder: “”, // «заглушка» - текст, который будет показан в поле, если не выбрано значение

default: “”, // значение по умолчанию, устанавливается при создании цели

_default\_name: "" // для поля типа foregn\_elem - название объектов, которые должны быть выбраны по умолчанию, через точку с запятой_

key\_value: "", // ключевое значение - данный набор параметров будет использоваться для отображения объекта, если значние поля в объекте совпадает с ключом

step: “”, // для поля типа spinner – шаг смены значения при клике на полосе прокрутки

min: 0, // для полей типа number и spinner – минимально возможное значение ввода, для полей типа date - минимально возможная дата выбора из календаря (в формате ISO 8601 или dd.mm.yy), для полей типа file - минимально возможный размер загружаемого файла (в байтах)

max: 100 // для полей типа number и spinner \- максимально возможное значение ввода, для полей типа date - максимально возможная дата выбора из календаря_(в формате ISO 8601 или dd.mm.yy)_, для полей типа file - максимально возможный размер загружаемого файла (в байтах)

_catalog\_name: "" // для поля типа foregn\_elem - название катлога_

_xquery\_qual: "" // для поля типа foregn\_elem - дополнительное условие XQuery, относительно $elem_

_multi\_select: true|false // для поля типа foregn\_elem - признак множественного выбора_

_show\_all: true|false // для поля типа foregn\_elem - учитывать условия огранияения (по текущему пользователю) на объекты типа collaborator, subdivision. org_

_typein: false // флаг, определяющий, будет ли сразу показан список объектов, или пустой список с полем поиска - для очень больших списков_

_view\_type: "" // название каталога, который будет использоваться, как шаблон для показ списка, вместо текущего каталога_

_can\_be\_empty: false // флаг, означающий, можно ли выйти из диалога без выбора объекта_

display\_filter: false // флаг, означающий, показывать ли поле выбора фильтра для списка выбора

css\_template\_id: "" // ID шаблона документа, содержащего дополнительную таблицу стилей, которая будет добавлена к стилям диалога выбора

extensions: null // для полей типа file - разрешенные к загрузке расширения файлов (через запятую), если пусто - то допустима загрузка с любым расширением

mimetypes: null // для полей типа file - разрешенные к загрузке типы файлов (mime\\type, через запятую), если пусто - любой тип, без ограничения

_page\_url: "" // для поля типа foregn\_elem - адрес кастомной страницы диалога, в которой будет осуществлятся выбор объекта_

disp\_hier\_view _// для поля типа foregn\_elem -_ показывать каталог в иерархическом виде (false - только в виде плоского списка, true - использовать иерархический вид, если каталог поддерживает иерархию)

disp\_tree\_selector _// для поля типа foregn\_elem -_ флаг, показывать чекбокс "В виде структуры" (true - показывать, если каталог поддерживает иерархию, false - не показывать в любом случае, если параметр disp\_hier\_view = false, то чекбокс не показывается никогда, параметр не учитывается)

page\_param _// для поля типа foregn\_elem -_ строка параметров, будет передана в кастомный диалог выбора (через URL)

flds\_dlg _// для поля типа foregn\_elem -_ строка названий полей, через точку с запятой, значения которых будут переданы в кастомный диалог (через URL), можно передать значение "none", чтобы не передавать значения полей в диалог, если пусто или параметр отсутствует - то будут переданы полностью все поля формы

}

Если для описания поля определен атрибут visible\_in = "form", поле невидимо (visible = true), но для поля определен непустой атрибут default - то поле на форме отобаражаться не будет, но для вновь создаваемых целей его значение будет заполнено дефолтным текстом.

digit\_nums - для типа number - количество знаков дробной части, до которого будут округлено значение при показе (при редактировании - без округления)  
no\_locale - не приводить значение при показе к локальным настройкам (разделитель тысяч и знак дробной части)

При показе (без редактирования) числовых значений, они будут сконвертированы в соответствии с настройками формы или плеера (по умолчанию округлены до второго знака и приведены к локальному формату ОС). Если нужно отключить конвертацию, можно задать digit\_nums = -1 и no\_locale = true.
