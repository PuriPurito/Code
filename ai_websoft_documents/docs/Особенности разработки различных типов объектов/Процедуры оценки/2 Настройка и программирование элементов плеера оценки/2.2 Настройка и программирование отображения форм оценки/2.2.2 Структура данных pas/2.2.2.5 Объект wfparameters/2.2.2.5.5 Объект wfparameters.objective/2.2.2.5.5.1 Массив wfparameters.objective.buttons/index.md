## 2.2.2.5.5.1 Массив wfparameters.objective.buttons

Массив содержит элементы, описывающие параметры отображения кнопок плашки цели:

\- кнопка добавления цели следующего уровня (action: “add”)

\- кнопка удаления цели (action: “delete”)

\- кнопка редактирования цели (action: “edit”)

\- кнопка просмотра цели (action: “view”)

Структура объекта описания:

{

“action”: “”, // тип кнопки – add | delete | edit | view

“title”: “”, // текст кнопки

“class”: “”, // класс, присваиваемый контейнеру кнопки

_"position" : "" //  bottom | top | header | footer | all - только для кнопки типа add - позиция кнопки, если top - то в заголовке цели, вместе с иконками/кнопками остальных действий, если иное (по умолчанию) - то внутри плашки цели в правом отдельном блоке_

zone: "top-left" // строка, определяющая положение кнопки на форме - сверху/снизу, справа/слева - top-right, bottom-left и т.п.

}

Условия показа или скрытия кнопок цели определяются настройками цели:

\- can\_add\_child -> показ кнопки добавления цели следующего уровня

\- editable -> показ кнопки редактирования или просмотра

\- can\_delete -> показ кнопки удаления цели

По умолчанию, кнопка добавления цели показывается в виде кнопки с текстом, остальные кнопки – в виде пиктограммы. Если в массиве есть объект описания настроек кнопки и в объекте установлен атрибут “title” – вместо пиктограммы отображается заданный текст кнопки.
