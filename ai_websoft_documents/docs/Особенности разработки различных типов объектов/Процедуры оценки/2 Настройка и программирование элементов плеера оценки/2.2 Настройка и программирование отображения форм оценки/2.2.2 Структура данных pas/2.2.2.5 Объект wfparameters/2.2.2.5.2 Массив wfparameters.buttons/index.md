## 2.2.2.5.2 Массив wfparameters.buttons

Массив содержит элементы, описывающие параметры отображения кнопок формы, как стандартных, так и дополнительных.

Стандартные кнопки:

\- кнопка добавление цели (для формы оценки целей) (action: “add”)

\- кнопка редактирования весов целей в отдельном диалоге (action: “weight”)

\- кнопка добавления комментария (action: “comment”)

Для стандартных кнопок структура объекта описания:

{

“action”: “”, // _тип кнопки_ – add | weight | comment

“title”: “”, // текст кнопки

“class”: “”, // класс, присваиваемый контейнеру кнопки

“desc”: “”, // текст описания (всплывающий текст при наведении мыши)

“position”: “” // позиция кнопки на форме

          – top - верхняя линейка кнопок в теле формы

          - bottom - нижняя линецка кнопок в теле формы

          - both - дублирование кнопки в нижней и верхней линейке

         - header - встравивание кнопки формы в верхниюю линейку кнопок ДО

         - footer - встравивание кнопки формы в нижнюю линейку кнопок ДО

        - all - дублирование кнопки формы в обоих линейках кнопок ДО

posindex: "" // для вариантов header/footer/all - задает порядок следованеия кнопок в линейке (чем больше индекс, тем левее)

is\_private: false // флаг, обозначающий, что данную кнопку необходимо показывать только в режиме редактирования (при параллельном редактировании/блокировках)

zone: "top-left" // строка, определяющая положение кнопки на форме - сверху/снизу, справа/слева - top-right, bottom-left и т.п.

}

Дополнительные кнопки (action: “iframe”) – кнопки открытия дополнительных шаблонов/интерфейсов. Структура настроек аналогична той, что используется для кнопок левой панели, но есть дополнительные атрибуту (position, desc)

{

"action": "", // тип кнопки

"id": "", // Идентификатор кнопки – должен быть уникален в рамках всего набора дополнительных кнопок плеера

"title": "Материалы", // Текст на кнопке

"class": "assessment\_docs", // стиль из таблицы CSS, который будет применен к кнопке

"visible": "1", // Видимость кнопки

"dialog\_title": "Материалы по ежегодной оценке", // Заголовок окна iframe

"url": "%2Fcustom\_web\_template%2Ehtml%3Fobject\_code%3Dass\_materials", // адрес страницы, которая будет загружена в окне iframe

“target”: “iframe”, // Цель ссылки – если указан iframe или параметр отсутствует, ссылка открывается в окне iframe, если указана другая цель (\_blank, \_top и т.п.) – ссылка открывается по той цели, которая указана (новое окно, окно с определенным идентификатором) – по правилам HTML

“pa\_id”: “6466355517103872284”, // Идентификатор целевой анкеты – необходим при отработке отдельных команд по закрытии окна

"title\_close\_action": "none", // Команда, которая будет выполнена при нажатии на «крест» в правом верхнем углу окна iframe.

"dialog\_buttons": \[ // массив настроек кнопок закрытия диалога в правом нижнем окне iframe. Если массив пуст – кнопки в правом нижнем углу скрыты (закрытие окна только по кресту в левом верхнем углу)

                {

“action”: “reload\_all”, // команда, выполняемая по нажатию кнопки

“title”: “Обновить данные” // Текст кнопки

                }

\],

"iframe\_width": "80", // ширина окна iframe в процентах от общего окна плеера

"iframe\_height": "80", // высота окна iframe в процентах от общего окна плеера

“position”: “”, //положение кнопки на форме

            – top - верхняя линейка кнопок в теле формы

          - bottom - нижняя линецка кнопок в теле формы

          - both - дублирование кнопки в нижней и верхней линейке

         - header - встравивание кнопки формы в верхниюю линейку кнопок ДО

         - footer - встравивание кнопки формы в нижнюю линейку кнопок ДО

        - all - дублирование кнопки формы в обоих линейках кнопок ДО

“desc”: “” // Описание кнопки – всплывающий текст при наведении мыши на кнопку

posindex: "" // для вариантов header/footer/all - задает порядок следованеия кнопок в линейке (чем больше индекс, тем левее)

is\_private: false // флаг, обозначающий, что данную кнопку необходимо показывать только в режиме редактирования (при параллельном редактировании/блокировках)

}
