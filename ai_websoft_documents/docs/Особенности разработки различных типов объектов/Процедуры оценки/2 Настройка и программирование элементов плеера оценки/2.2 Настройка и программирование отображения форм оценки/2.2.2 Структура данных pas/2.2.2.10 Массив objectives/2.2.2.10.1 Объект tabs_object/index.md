## 2.2.2.10.1 Объект tabs_object

Объект tabs\_object служит для описания дополнительных закладок карточки цели (комментарии и история изменения), если таковые используются. Может содержат свойства:

\- data - объект, описывающий закладку данных (набор полей формы) - стандартный вид диалога

    - title - строка-заголовок закладки, если свойство отсутствует, будет выведено стандартное значение "Данные"

   - visible - true/false - по умолчанию true - видимост закладки

\- comment - объект, описывающий закладку со списком комментариев

  - visible - флаг видимости закладки

  - title - заоголовок закладки (по умолчанию - Комментарии)

  - collection - код выборки, которая вернет массив данных по комментариям, если пусто - будет использована стандартная функция

  - can\_add - флаг, может ли текущий пользователь оставить новый комментарий

  - state - строка текущей фазы, если пусто - в качестве текущей фазы буде указан текущий этап ДО (как в случае общих комментриев к анкете)

  - show\_button - флаг, показывающий, будет ли на плашке цели отображаться кнопка, позволяющая открыть цель сразу на закладке комментариев

\- log - объект, описывающий закладку с историей изменений

    - visible - флаг видимости закладки

   - title - строка, заголовок закладки, по умолчанию - История

  - collection - код выборки, которая вернет массив записей истории изменений, если пусто - будет использована стандартная функция

  - columns - массив объектов, описывающий колонки, отображаемые в таблице истории, если отстуствует - будут использованы стандартные колонки, аналогично журналу действий ДО (дата и время, ФИО, начальный статус, действие, конечный статус), каждая колонка описывается, как объект, содержащий свойства

      - name - имя поля из массива истории

      - label - заголовок колонки

  - show\_button - флаг, показывающий, будет ли на плашке цели отображаться кнопка, позволяющая открыть цель сразу на закладке истории

В обычном режиме диалог редактирования/показа формы цели содержит заголовок цели и область с полями для показа и/или заполнения. Если задан объект tabs\_object, то под заголовком цели появляется набор закладок (данные, комментарии, история) при нажатии на которые отображается дополнителная информация по цели. При открытии такой цели она всегда открывается на первой закладке (данные - список полей), если только не снят флаг visible для объекта data.

На закладке комментарии отображается список комментариев по конкретной цели, аналогично общему списку комментариев для анкеты. Список комментариев цели хранится в таком же массиве custom\_comments, как и для анкеты (pa), но хранящемся в объекте task системы. Если указан код collection, то будет вызван на исполнение программный скрипт выборки с указанным кодом. В перенных выборки будут установлены значения, переданные при вызове серверного обработчика в режиме "task" (см.1.2.6.2 настоящей документации). Выборка должна вернуть массив данных - объектов со свойствами - person\_id (ID пользователя написавшего комментарий), workflow\_state (фаза, за которой закреплен комментарий), comment (текст комментария), comment\_date (дата и время комментария). Если передана команда commentsave, выборка должна сначала сохранить текущий комментарий пользователя, а потом сформировать новый список комментарией в учетом добавленного.

Стандартный функционал отображает список комментариев из массива custom\_comments объекта task, но, теоретически, при использовании явной коллекции, массив комментриев может хранится в любой другой системой сущности. 

Переданный параметр state служит для извлечения текущего комментария пользователя - если в массиве есть уже комментарий с указанным ID пользователя и указанной фазой - то его текст будет извлечен из массива, как текущий, и, если пользователю разрешено оставлять комментарии (флаг can\_add) - предложен пользователю для изменения (если такого комментария в списке нет - то будет показано пустое поле ввода).

На закладке "История" отображается история изменений/действий ДО для данной цели. Аналогично комментариям, в стандартной функции для хранения используется массив workflow\_log\_entrys в объекте цели, стандартная функция возвращает поля create\_date (дата и время действия), action\_id (код действия или его название), person\_id (ID пользователя), person\_fullname (ФИО пользователя), begin\_state (код или название этапа ДО до вызова действи), finish\_state (код или название этапа ДО после вызова действия).

В отличии от функционала комментариев к цели, какого-то стандартного функционала занесения данных в журнал истории в системе не предусмотрено - это должен сделать программист (в коде шаблона сохранения данных или в коде действия ДО).

Также, в отличии от списка комментариев, список полей массива записей истории и названия колонок не определяется жестко, программист вправе сформировать произвольный массив объектов, главное - задать параметр columns с описанием названий колонок и какие поля массива результатов им будут соответствовать

Пример задания объекта : \_o2.tabs\_object = { data: { visible: true, title: "Форма" }, comment: { visible: true, title: "Замечания", can\_add: true, state: tools.random\_string(5) }, log: { visible: true, title: "Журнал", collection: "getHistory", columns: \[{name:"date", label:"Дата"},{name:"action", label:"Запись"}\] } }; - задает видтмость всех трех закладок, используется стандартная функци получения списка комментариев, с возможностью добавить свой и редакьтированием в течении периода открытия текущей анкеты (если анкета будет закрыта и открыта вновь - старый комментарий становится недоступен, но можно ввести новый). Журнал истории формируется отдельной выборкой с кодом getHistory, которая возвращает массив объектов с двумя свойствами - датой и текстом изменения.

Начиная с релиза 2023.2 предоставлена возможность добавления дополнительных кнопок на форму, рядом с текущими кнопками редактирования/просмотра/удаления - **Показать историю** и **Комментировать**. Кнопка открывает окно цели с переключением на нужную вкладку. Комментарий может быть добавлен и в случае закрытой задачи на редактирование.  
В структуру _tabs\_object_ добавлен параметр _show\_button_. Если этот параметр имеет значение _true_, то показывается кнопка, по которой форма открывается на нужной вкладке в режиме комментария или журнала.  
Если _tabs\_object.comment.can\_add = true_, то кнопка Сохранить на закладке комментариев показывается всегда, даже если цель не в режиме редактирования.  
На закладке **История** кнопка **Сохранить** скрывается всегда, даже если цель в режиме редактирования.  
На закладке **Данные** кнопка **Сохранить** показывается только в режиме редактирования.   
  
Для кнопки **"add"** (массив wfparameters.objective.buttons) добавлен параметр "position". Если этот параметр имеет значение "top", то кнопка показывается в шапке цели, рядом с иконками просмотра/редактирования/удаления.
