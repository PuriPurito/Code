## 2.2.2.9 Массив competence_blocks

Массив содержит описания блоков компетенций, если они заданы для формы. Если массив не пуст, компетенции при показе будут сгруппированы по блокам, связь компетенции с блоком – через атрибут competence\_block\_id  в объекте описания компетенции

{

id: “”, // Идентификатор блока

name: “”, // Заголовок блока

weight: “”, // Вес блока (опционально), если пусто – не показывается

mark: “”, // Оценка по блоку (опционально), если пусто – не показывается

class: “” // Класс, если задан – будет добавлен к списку стилей контейнера блока

}

Обработчик не формирует данный массив. Он, при необходимости, должен быть сформирован разработчиком самостоятельно.
