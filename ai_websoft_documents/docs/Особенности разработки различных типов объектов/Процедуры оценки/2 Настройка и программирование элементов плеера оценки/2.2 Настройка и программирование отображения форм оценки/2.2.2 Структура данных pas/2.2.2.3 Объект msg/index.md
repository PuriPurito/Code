## 2.2.2.3 Объект msg

Содержит данные для отображения информационного сообщения, которое будет показано (при наличии данного объекта) после отрисовки основного интерфейса формы и действия, которое при этом будет выполнено.

В комплексом варианте объект имеет следующую структуру:

{

type: “”, // тип сообщения – alert | confirm | action – простое окно сообщения с кнопкой «ОК» или окно с вопросом и выбором/отменой (кнопки «ОК» и «отмена») или выполнение действия без показа окна сообщения

title: “”, // заголовок окна сообщения

text: “”, // текст сообщения

text\_ok:””, // текст кнопки «ОК» - подтверждение и закрытие окна сообщения

text\_cancel: “”, // Текст кнопки «отмена» - отмена действия и закрытие окна сообщения – только для сообщения типа “confirm”

class:””, // Класс, который будет добавлен в набор стиле верхнего элемента окна сообщения

action: { // объект, описывающий действие, выполняемое (по кнопке «ОК» или сразу, см. выше варианты type)

                type: “”, //тип действия – api (вызов команды API плеера) | select (переход в другую форму/закладку из текущего набора форм) | workflow (вызов действия/нажатие кнопки документооборота) | print (открытие печатной формы/нажатие кнопки «Печать») | comment (открытие окна ввода комментария) | objective (открытие диалога просмотра/редактирования указанной цели – только для формы оценки целей) | iframe (открытие окна дополнительного интерфейса, описанного в настройках кнопки типа iframe)

                id: “”, // идентификатор объекта, для которого будет исполнено действие, тип объекта зависит от типа действия (для api или select – идентификатор оценочной формы, workflow или iframe – код кнопки ДО или дополнительной кнопки, objective – идентификатор задачи

                command: “” // _команда_ api (reload\_pa | reload\_all | redirect\_to\_pa || reload\_to\_pa)

}

cancel\_action_: { // объект, описывающий действие, выполняемое по кнопке «Отмена»_

                type_: “”, //тип действия – api (вызов команды_ API _плеера) |_ select _(переход в другую форму/закладку из текущего набора форм) |_ workflow _(вызов действия/нажатие кнопки документооборота) |_ print _(открытие печатной формы/нажатие кнопки «Печать») |_ comment _(открытие окна ввода комментария) |_ objective _(открытие диалога просмотра/редактирования указанной цели – только для формы оценки целей) |_ iframe _(открытие окна дополнительного интерфейса, описанного в настройках кнопки типа_ iframe_)_

                id_: “”, // идентификатор объекта, для которого будет исполнено действие, тип объекта зависит от типа действия (для_ api _или_ select _– идентификатор оценочной формы,_ workflow _или_ iframe _– код кнопки ДО или дополнительной кнопки,_ objective _– идентификатор задачи_

                command: “” // __команда__ api (reload\_pa | reload\_all | redirect\_to\_pa)

}

}
