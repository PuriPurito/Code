## 2.2.4.3 Вариант «Таблица»

view\_type: “table”

Каждая компетенция отображается отдельной табличкой в общей форме, внутри таблицы – список индикаторов и поля для ввода оценок и комментариев.

В режиме по умолчанию сохранение оценок происходит «мгновенно» - в момент переноса фокуса из поля ввода. На практике такой режим требует высокого быстродействия от сервера системы и клиентского рабочего места, потому что после сохранения обработчик должен пересчитать итоговые значения по форме, а плеер оценки – перерисовать форму оценки. Поэтому для вариантов с размещением элементов управления непосредственно на форме (Таблица, Аккордеон, Сплошная таблица) рекомендуется использовать режим массового сохранения, путем установки параметра config.full\_save – при котором сохранение данных происходит только по нажатию специальной кнопки «Сохранить».
