## 2.2.3.1 Заголовок формы

Свернутый вид:

Развернутый вид:

По умолчанию заголовок открывается в свернутом виде. Для переключения между свернутым и развернутым видом используется кнопка «8».

В развернутом виде по умолчанию полностью раскрыта колонка «Сотрудник», колонки руководителей свернуты до ФИО, но могут быть развернуты (при этом сворачиваются до ФИО остальные колонки) при помощи кнопок «23».

Третья колонка, со списком дополнительных/согласующих/экспертов показывается, только если массив custom\_experts в структуре «pa» поступает в плеер.

Элементы формы:

1.       Строка-приглашение. По умолчанию – «Зравствуйте, <ФИО сотрудника>!». Может быть изменено параметром config.welcome\_string

2.       Название процедуры. Может быть задано в параметре config.assessment\_title

3.       Надпись, информирующая о делегировании. Показывается, только если у текущего пользователя есть активные делегирования.

4.       Дата начала процедуры. Может быть задана индивидуально для конкретной анкеты или скрыта параметрами в объекте config.

5.       Подпись под датой начала. Задается в параметре config.assessment\_rest\_left. По умолчанию не показывается.

6.       Дата окончания процедуры. Может быть задана индивидуально для конкретной анкеты или скрыта параметрами в объекте config.

7.       Подпись под датой окончания. Задается в параметре config.assessment\_rest\_right. По умолчанию не показывается.

8.       Панель этапов документооборота. Формируется на основе данных массива dataset.workflow.states. Отрисовка текущего положения формы на линейке ДО определяется таблицей стилей:

_\- текущий этап ДО – селектор \[_wta-spot-state='active'\]

_\- пройденные этапы (слева от текущего) - селектор \[_wta-spot-state='completed'\]

_\- предстоящие этапы (справа от текущего) - селектор \[_wta-spot-state='incomplete'\]

9.       Кнопка сворачивания/разворачивания заголовка формы и Заголовок для ФИО сотрудника. Может быть задан в параметре person.title. По умолчанию – «Оцениваемый сотрудник».

10.   ФИО оцениваемого сотрудника. Считывается из параметра person.fullname.

11.   Заголовок для ФИО руководителя. Может быть задан в параметре boss.title. По умолчанию – «Оценивающий руководитель».

12.   ФИО оценивающего руководителя. Считывается из параметра boss.fullname.

13.   Заголовок для ФИО эксперта. Может быть задан в параметре custom\_expert.title. По умолчанию – «Эксперт». Может быть задан индивидуально для каждого экперта.

14.   ФИО эксперта. Считывается из параметра custom\_expert.fullname.

15.   Заголовок столбца с данными сотрудника. Может быть задан в параметре person.header. По умолчанию «Сотрудник».

16.   Заголовок столбца с данными руководителя. Может быть задан в параметре expert.header. По умолчанию «Руководитель».

17.   Заголовок для ФИО эксперта. Может быть задан в параметре custom\_expert.header первого в списке элемента custom\_experts. По умолчанию – «Эксперт».

18.   Заголовок столбца с ФИО сотрудника в развернутом представлении заголовка. Совпадает с элементом «9» в свернутом виде. Может быть изменено параметром person.title. По умолчанию – «Оцениваемый сотрудник».

19.   Заголовок столбца с данными должности в развернутом представлении заголовка. Для данных сотрудника может быть изменено параметром person.position\_title (для столбца руководителя – boss.position\_title, для столбца эксперта – custom\_expert.position\_title, причем для каждого эксперта может быть установлено индивидуально). Значение по умолчанию – «Должность».

20.   Заголовок столбца с данными подразделения в развернутом представлении заголовка. Для данных сотрудника может быть изменено параметром person.sub\_title (для столбца руководителя – boss.sub\_title, для столбца эксперта – custom\_expert.sub\_title, причем для каждого эксперта может быть установлено индивидуально). Значение по умолчанию – «Подразделение».

21.   Заголовок столбца с ФИО руководителя в развернутом представлении заголовка. Совпадает с элементом «11» в свернутом виде. Может быть изменено параметром boss.title. По умолчанию – «Оценивающий руководитель».

22.   Заголовок столбца с ФИО эксперта в развернутом представлении заголовка. Совпадает с элементом «13» в свернутом виде. Может быть изменено параметром custom\_expert.title. По умолчанию – «Эксперт». Для каждого эксперта может быть установлено индивидуально.

23.   Кнопка «Развернуть/Свернуть» текущий столбец заголовка. При этом все остальные столбцы сворачиваются до столбца с ФИО участника, а для текущего типа разворачиваются столбцы с названиями должности и подразделения.

Если оба значения - boss.fullname и expert.fullname - пустые, то блок "Оценивающий" скрывается целиком.

Если в заголовке отображаются несколько экспертов, то записи по ним могут отображаться вертикально (как на рисунке выше в режиме свернутого заголовка), так и горизонтально, как отображено на рисунке ниже:
