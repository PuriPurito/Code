## 2.2.3.6 Блок итоговых оценок – настраиваемый вариант

Настраиваемый блок итоговых показателей может быть показан на форме любого вида (компетенции, цели, общая оценка).

Для настройки показа блока используется объект viewset, создаваемый программистом в коде шаблона подготовки данных.

Особенности показа блока для различных типов форм оценки:

\- для формы общей оценки блок показывается только в верхней части формы, других условий, кроме наличия объекта viewset – нет;

\- для формы оценки целей и компетенций блок показывается только при наличии атрибута overall, положение блока на форме определяется атрибутом overall\_view. Т.е. для форм оценки целей и компетенций, если присутствует overall не пуст и overall\_view не равен “none” – при наличии объекта viewset показывается настраиваемый блок итоговых оценок, при отсутствии объекта viewset – стандартный блок, если overall отсутствует или overall\_vew:”none” – блоки итоговых оценок не показываются.

Пример настройки:

oData.data.viewset = {

                                "scaleblock": \[

                                                {

                                                                "text": "Самооценка",

                                                                "value": 3,

                                                                "control\_type": "circle-comment"

                                                },

                                                {

                                                                "text": "_Оценка коллег_",

                                                                "value": 3,

                                                                "control\_type": "circle-comment"

                                                },

                                                {

                                                                "text": "Оценка непосредственного руководителя",

                                                                "value": 4,

                                                                "control\_type": "circle-comment"

                                                },

                                                {

                                                                "text": "_Текущая оценка_",

                                                                "value": 2,

                                                                "control\_type": "circle-comment"

                                                }

                                \],

                                "items\_in\_row": 4

                }
