## 2.2.3.2 Ярлыки форм

Линейка ярлыков форм располагается ниже заголовка формы.

Количество ярлыков соответствует количеству форм, видимых в паре Сотрудник – Оценивающий.

При клике на ярлык отображается соответствующая форма, а другие формы – скрываются.

Области на рисунке:

1.       Активный ярлык – стиль определяется селектором .wt-appr-tab\[wta-tab-state='selected'\]

2.       Неактивный ярлык – селектор .wt-appr-tab\[wta-tab-state='idle'\]

3.       Пиктограмма формы

В качестве базового набора пиктограмм форм используется 3 svg-inline изображения, скрываемые/показываемые с использованием стилей:

 - круг  отображение по селектору \[wta-fill-state='n'\] (is\_processed: false – заполнение формы не начато), стиль .wt-tab-icon-svg-circle

 - галка зеленая  отображение по селектору \[wta-fill-state='c'\] (is\_done: true – заполнение формы завершено), .wt-tab-icon-svg-checkmark path { fill: #0a0; }

 - галка красная  отображение по селектору \[wta-fill-state='i'\] (is\_processed: true, is\_done: false – заполнение формы начато, но не завершено), .wt-tab-icon-svg-checkmark path { fill: #c00; }

Дополнительно в базовый комплект входят две пиктограммы (svg-inline), не показываемые стандартными стилями, но разработчик может настроить их показ (и покраску) вместо базовых

 - _стрелка_  .wt-tab-icon-svg-arrow

 - _восклицательный знак_  .wt-tab-icon-svg-exclamation

Примеры смены дизана пиктограмм::

Покраска фона пиктограммы стрелка path:first-child {fill: #c00;} 

Красная стрелка на белом фоне path:first-child {fill: #fff;} path:last-child {fill: #c00;}
