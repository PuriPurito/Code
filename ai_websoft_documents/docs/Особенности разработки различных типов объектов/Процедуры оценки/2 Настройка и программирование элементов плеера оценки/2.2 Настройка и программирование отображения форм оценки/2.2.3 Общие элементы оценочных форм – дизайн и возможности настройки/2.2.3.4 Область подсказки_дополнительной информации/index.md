## 2.2.3.4 Область подсказки/дополнительной информации

Область содержит информацию, размещенную в атрибуте wfcomment. Если атрибут отсутствует – блок не показывается. Информационный текст может содержать HTML\-разметку.

Заголовок блока можно изменить атрибутом wfcomment\_title. Если атрибута нет – выводится текст «Полезная информация».

Блок в процессе заполнения формы можно скрыть/раскрыть при клике на кнопку со стрелкой в заголовке. Базовое состояние блока при открытии формы – развернут. Базовое состояние может быть изменено атрибутом wfcomment\_state (expanded|collapsed).

_Общее стилевое оформление блока можно изменить с использованием дополнительной таблицы стилей (.wt-appr-hint, .wt-appr-hint-_header_, .wt-appr-hint-_text) или индивидуально для конкретной формы, установив атрибут класса wfcomment\_class.
