## 2.2.3.7 Блок комментариев

Блок комментариев формы показывается на основе массива custom\_comments.

Если массив отсутствует  \- блок комментариев на форме скрыт.

Обработчик подготавливает массив комментариев на основе текущей анкеты, разработчику он доступен в коде подготовки данных, как переменная oData.data.custom\_comments.

Комментарий из данного массива, заполненный текущим пользователем на текущем этапе ДО заносится также в переменную oData.data.comment.

Кнопка добавления комментария описывается в массиве wfparameters.buttons.

Возможности разработчика:

\- скрыть полностью комментарии к форме oData.data.custom\_comments = null;

\- изменить порядок сортировки комментариев, отфильтровать их;

\- сохранять комментарии со всех форм в одном массиве (в плане оценки) и показывать на всех формах один набор комментариев;

\- сменить алгоритм сохранения комментариев, меняя уникальный ключ (код этапа ДО) – чтобы каждый новый комментарий на том же этапе не изменял предыдущий, а записывался в новый элемент (создать непрерывную ленту комментариев).

Пример кода для реализации последнего пункта (в шаблоне постобработки сохранения формы):

\_cur\_comment = ArrayOptFind(docPA.TopElem.custom\_comments,”This.person\_id==”+curPersonID+” && This. workflow\_state==”+CodeLiteral(oData.data.workflow\_state));

if (\_cur\_comment!=undefined) {\_cur\_comment.workflow\_state += tools.random\_string(8);}
