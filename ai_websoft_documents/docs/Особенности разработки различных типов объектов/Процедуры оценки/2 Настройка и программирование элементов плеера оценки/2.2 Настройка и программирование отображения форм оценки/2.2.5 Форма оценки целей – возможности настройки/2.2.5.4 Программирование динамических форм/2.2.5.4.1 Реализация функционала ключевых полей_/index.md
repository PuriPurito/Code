## 2.2.5.4.1 Реализация функционала ключевых полей.

На плеер присылается не один комплект параметров описания формы, а несколько, каждый комплект описывает свой вариант набора полей, со своими условиями видимости/редактирования/типа используемого элемента ввода. Программно это реализуется тем, что объект objective (на любом уровне - wfparameters.objective или wfparameters.objective.objective или ниже) представляет из себя массив объектов, каждый из которых содержит описание своего варианта.  
В нужных полях формы задается параметр key\_value, определяющий значение поля, для которого данное описание будет актуально.  
При отрисовке формы код плеера последовательно перебирает все варианты описаний, проверяя все обнаруженные значения key\_value на соответствие значению соответствующего поля в отображаемом объекте (если это вновь создаваемый объект - берется значение по умолчанию, заданное в параметре default).  
Если описание формы, в котором значения всех ключевых полей совпадают с текущим объектом, найдено - этот элемент массива описаний используется для отрисовки. Если такого набора не найдено - форма отображается по первному элементу массива описаний.  
Если ключевых полей несколько и для разных значений в них надо отобразить разные варианты формы, то, в общем случае длинна массива описаний должна быть результатом перемножения количества возможных вариантов значений полей. Можно сократить длинну массива, указывая в атрибуте key\_value несколько ключевых значений, через точку с запятой (например, в поле может быть три значения - 1, 2 и 3, но внешни вид для случая "3" должен отличатся, а для "1" и "2" совпадать. В таком случае можно создать массив из двух элементов описаний, в одно указать key\_value="1;2", а во втором key\_value="3").

При добавленни цели необходимо показать форму из двух полей: тип цели и название цели. При этом тип цели может быть одним из двух вариантов: задача или КПЭ. Для типа "задача" поле названия - обычное текстовое, для типа "КПЭ" - выбор значения из справочника. Получается следующее описание (после нажатия кнопки "Добавить задачу" показывается окно с радокнопкой "Тип цели" и полем ввода "Название задачи", после переключения радиокнопки на "КПЭ" вид второго поля меняется на выбор из списка, а название - на "Название КПЭ"):  
wfparameters.objective = \[  
    {  
        goal\_type: {   
            label: "Тип цели",  
            control\_type: "radio",   
            editable: true,  
            visible: true,  
            key\_value: "goal",  
            "default": "goal",  
            scale: {  
                value: \[  
                    { id: "goal", name: "Задача" },  
                    { id: "kpi", name: "КПЭ" }  
                \]  
            }  
        },  
        name: {  
            label: "Название задачи",  
            control\_type: "text",   
            editable: true,  
            visible: true  
        }  
    },  
    {  
        goal\_type: {   
            label: "Тип цели",  
            control\_type: "radio",   
            editable: true,  
            visible: true,  
            key\_value: "kpi",  
            "default": "goal",  
            scale: {  
                value: \[  
                    { id: "goal", name: "Задача" },  
                    { id: "kpi", name: "КПЭ" }  
                \]  
            }  
        },  
        name: {  
            label: "Название КПЭ",  
            control\_type: "select",   
            editable: true,  
            visible: true,  
            scale: {  
                value: \[  
                    { id: "1", name: "КПЭ1" },  
                    { id: "2", name: "КПЭ2" }  
                \]  
            }  
        }  
    }  
\]
