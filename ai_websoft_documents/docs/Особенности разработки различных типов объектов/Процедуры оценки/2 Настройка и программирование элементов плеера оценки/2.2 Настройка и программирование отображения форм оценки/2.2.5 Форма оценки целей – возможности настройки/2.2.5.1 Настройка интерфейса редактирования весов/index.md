## 2.2.5.1 Настройка интерфейса редактирования весов

Интерфейс предназначен для показа в общем отдельном окне всех целей, веса которых можно редактировать на нужном уровне, обычно – достигая 100 процентов по всему набору. Возможность отображения интерфейса настраивается показом кнопки «Редактировать веса (action: “weight” в массиве wfparameters.buttons).

В базовом варианте в окне редактирования попадают все цели верхнего уровня. Для тонкой настройки используется объект obj\_weight.

Пример настройки: Цели атрибутированы двумя полями:

\- prohibit – признак защиты поля – вес должен учитываться, но не может быть изменен

\- not\_actual – признак неактуальности (цель отменена) – вес цели не учитывается

Следующим кодом:

oData.data.obj\_weight = {"obj\_id": \[\]};

for (\_o in oData.data.objectives)

{

                if (\_o.not\_actual.value == "")

                {

                                if (\_o.prohibit.value != "")

                                {

                                                oData.data.obj\_weight.obj\_id.push({"id":\_o.id+'', "readonly": true});

                                }

                                else

                                {

                                                oData.data.obj\_weight.obj\_id.push({"id":\_o.id+'', "readonly": false});

                                }

                }

}

Можно получить вот такой результат:

                           

Цели 4 и 5 неактуальны и не попали в список редактирования.

Цель 1 защищена от изменения, попала в список, но без возможности редактирования
