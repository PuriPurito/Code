## 2.2.5 Форма оценки целей – возможности настройки

Форма оценки целей может быть представлена в двух видах, определяемых параметром view\_type – в виде дерева/плашек (view\_type пуст или отсутствует) и таблицы (view\_type: “table”).

Переход с режима «плашки/дерево» в режим «таблица» может быть осуществлен на любом уровне иерархии целей и определяется атрибутом view\_type\_level. Например, если в форме есть три уровня иерархии целей и view\_type\_level=2, то первые два уровня будут отображены в виде плашек в дереве, а третий уровень – в виде таблицы. Если после уровня, определенного как таблица, будут цели следующего уровня – они будут проигнорированы (не будут показаны).

Ввод или детальный просмотр данных в обоих вариантах осуществляется в дополнительном диалоговом окне, открывающемся при нажатии кнопки «редактировать/просмотреть» (пиктограмма со значком карандаша или глаза) в заголовке цели или в строке таблицы:

Цели могут быть объединены в группы путем создания массива objective\_blocks и установке в данных цели параметра objective\_block\_id. Назначение блоков может быть различным – разделение целей по назначившим задачу, по типу цели и т.д.

В верхней части формы расположен блок фильтра – элемент управления, позволяющий свернуть цели формы нужного уровня (при сворачивании цели видимым остается только заголовок). Управление показом блока фильтра, количеством радиокнопок  и названиями над кнопками осуществляется при помощи объекта config.obj\_filter.

При переходе в режим кнопка исчезает, а на экране отображается диалоговое окно с кнопками "Сохранить" и "Отмена":

При работе в режиме перетаскивания пользователь может переместить, при помощи указателя мыши, цель внутри своего уровня, и сохранить новый порядок следования.

При нажатии кнопки "Сохранить" внесенные изменения (в порядок следования целей) сохраняются на сервере и форма обновляется.

При нажатии кнопки "Отменить" происходит выход из режима перетаскивания, вновь появляется кнопка перехода в режим, возможность перетаскивания целей отключается.

Тексты кнопок, подсказок и инструкции могут быть изменены при помощи задания параметров.

Количество полей каждой цели и тип их отображения определяются в параметрах, указанных в объекте wfparameters. Для отображения на плашке или в таблице это будут поля, для которых атрибут “visible\_in” содержит значение “view”. В диалоговом окне редактирования/просмотра цели отображаются поля, для которых атрибут “visible\_in” содержит значение “form”. В заголовке цели отображается значение поля, для которого в атрибуте “visible\_in” указано значение “title”. Если ни для одного поля значение “title” не установлено – в заголовке будет указано значение поля “name”. Если значение “title” установлено для нескольких полей – в заголовке будут указаны значения всех этих полей, разделенные запятой.

При настройке списка полей соблюдается следующий алгоритм:

\- если в данных цели найден объект wfparameters – настройки показа полей цели будут взяты из  него (объект wfparameters.objective);

\- если в данных цели объект wfparameters отсутствует, он ищется в цели уровнем выше, но настройки берутся из параметра wfparameters.objective.objective, и так далее, поднимаясь выше (и опускаясь ниже на objective внутри найденных параметров), вплоть до объекта wfparameters самой формы;

\- для определения количества и названий столбцов таблицы объект параметров ищется в той цели, которая содержит таблицу (в объекте wfparameters.objective.objective);

\- для создания новой цели параметры также берутся из объекта wfparameters.objective.objective той цели, к которой будет добавлена вновь создаваемая цель, для новой цели верхнего уровня – из объекта wfparameters.objective формы.

Таким образом, создается возможность для каждой цели задать индивидуальный набор полей и параметров их показа, в зависимости от типа цели или значения каких-то других ее параметров.

Порядок расположения полей в диалоговом окне редактирования/показа формы определяется порядком их следования в объекте параметров.

Порядок показа полей цели в табличном представлении также определяется порядком их следования в объекте параметров.

Порядок показа полей в плашке цели на форме зависит от типа цели и принадлежности ее к стандартному набору:

\- в третью колонку попадают поля “fact”, “period\_fact”, “mark”;

\- во вторую колонку попадают поля “weight”, “period\_plan”, “subordinates”, а также все нестандартные поля, содержащие даты и числа (control\_type: “number” или “date”);

\- все остальные поля показываются в первой колонке плашки.
