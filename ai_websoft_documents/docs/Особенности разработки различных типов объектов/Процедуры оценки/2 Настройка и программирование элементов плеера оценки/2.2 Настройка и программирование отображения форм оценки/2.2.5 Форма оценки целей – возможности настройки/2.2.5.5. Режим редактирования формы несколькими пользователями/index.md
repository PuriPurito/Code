## 2.2.5.5. Режим редактирования формы несколькими пользователями

В процессе оценки иногда бывает необходимо обеспечить возможность внесения изменений несколькими пользователями в одну и ту же форму.

При этом необходимо предусмотреть, чтобы изменения одного пользователя не затерли изменения, внесенные другим.

Для этого предусмотрен режим блокировки:

\- один из пользователей запрашивает эксклюзивный режим редактирования и получает его на определенный промежуток времени

\- все это время, пока он вносит изменения и сохраняет их, другие пользователи не могут редактировать форму - ждут, пока она освободится

\- редактор, если он закончил редактирование, может "освободить" форму или, наоборот, продлить период редактирования, если ему не хватило времени

\- когда форма освободится - любой из ожидающих может запросить редактирования и получить его... потом освободит и т.д.

Для включения данного режима необходимо:

\- чтобы форма была доступна для редактирования ( oData.data.editable = true )

\- в объекте конфигурации был выставлен флаг ( oData.data.config.bHasBlocked = true )
