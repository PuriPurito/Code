## 2.1.1 Структура данных

Структура данных, формируемая обработчиком, имеет следующий состав (данные в атрибутах приведены для примера):

{

                "assessment\_status": "0",

                "assessment\_title": "_Оценка целей и компетенций_",

                "assessment\_start\_date": "2018-04-29",

                "assessment\_end\_date": "2019-10-31",

                "dataset": {

                                "workflow": {

                                                "states": \[

                                                                {

                                                                                "id": "1",

                                                                                "name": "САМООЦЕНКА"

                                                                },

                                                                .........

                                                                {

                                                                                "id": "10",

                                                                                "name": "_ОЦЕНКА ЗАВЕРШЕНА_"

                                                                }

                                                \]

                                },

                                "impersonation": {

                                                "persons": \[

                                                                {

                                                                                "person\_id": "1105387902724063523",

                                                                                "name": "Лезова Надежда Семеновна"

                                                                },

                                                                ..........

                                                                {

                                                                                "person\_id": "1105387902724063527",

                                                                                "name": "Максимова Светлана Викторовна"

                                                                }

                                                \]

                                }

                },

                "pas": \[ \],

                "config": { },

                "error": {

                                "code": 0,

                                "message": "OK"

                },

                "assessment\_user": {

                                "id": "1105387902724063510",

                                "name": "_Анисимов Геннадий Федорович_"

                },

                "sid": "8174878616190976"

}

assessment\_user – текущий пользователь оценочной процедуры с учетом делегирования. Т.е. в начальный момент – это текущий авторизованный пользователь портала. Но, если было выбрано делегирование (работа от имени другого пользователя) – то это будут данные выбранного сотрудника.
