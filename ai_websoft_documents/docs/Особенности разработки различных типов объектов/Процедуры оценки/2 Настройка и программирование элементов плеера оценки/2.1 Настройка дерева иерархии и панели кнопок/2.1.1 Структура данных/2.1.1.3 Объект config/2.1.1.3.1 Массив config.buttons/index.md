## 2.1.1.3.1 Массив config.buttons

Массив содержит набор объектов-описаний дополнительных кнопок, размещаемых на левой панели плеера.

При нажатии на кнопку может быть открыт какой-либо дополнительный интерфейс – веб-страница, шаблон портала и т.д. Интерфейс может открываться в новом окне браузера или в том же окне, что и плеер оценки, в iframe\-окне.

Структура объекта описания кнопки следующая:

{

"action": "iframe", // тип кнопки, пока только iframe – открыть добавочный интерфейс в окне

"id": "assessment\_docs", // Идентификатор кнопки – должен быть уникален в рамках всего набора дополнительных кнопок плеера

  Предусмотрены специальные иконки для кнопок показа отчетов (id = "report"), помощи (id="help") и подачи заявок (id="call\_request")

"title": "Материалы", // Текст подписи под кнопкой

"class": "assessment\_docs", // стиль из таблицы CSS, который будет применен к кнопке

"visible": "1", // Видимость кнопки

"dialog\_title": "Материалы по ежегодной оценке", // Заголовок окна iframe

"url": "%2Fcustom\_web\_template%2Ehtml%3Fobject\_code%3Dass\_materials", // адрес страницы, которая будет загружена в окне iframe

"no\_wfbuttons": false, // добавлять в ли в url данные по кнопкам документооборота. По умолчанию к заданному url добавляются параметры - pa\_id (идентификатор текущей анкеты, если она открыта), person\_id (идентификатор текущего пользователя, с учетом делегирования) и wf\_buttons (json-строка с массивом данных по доступным кнопкам документооборота),  если параметр выставлен в true - то данные по массиву кнопок в адрес не включаются

“target”: “iframe”, // Цель ссылки – если указан iframe или параметр отсутствует, ссылка открывается в окне iframe, если указана другая цель (\_blank, \_top и т.п.) – ссылка открывается по той цели, которая указана (новое окно, окно с определенным идентификатором) – по правилам HTML

“pa\_id”: “6466355517103872284”, // Идентификатор целевой анкеты – необходим при отработке отдельных команд по закрытии окна

"title\_close\_action": "none", // Команда, которая будет выполнена при нажатии на «крест» в правом верхнем углу окна iframe. Подробнее о командах – ниже в данном разделе.

_api\_args: {} - объект параметров, который будет передан в вызов API плеере (если задана команда api для title\_close\_action)_

"dialog\_buttons": \[ // массив настроек кнопок закрытия диалога в правом нижнем окне iframe. Если массив пуст – кнопки в правом нижнем углу скрыты (закрытие окна только по кресту в левом верхнем углу)

                {

“action”: “reload\_all”, // команда, выполняемая по нажатию кнопки

“title”: “Обновить данные” // Текст кнопки

_api\_args: {} - объект параметров, который будет передан в вызов API плеере (если задана команда "api")_

                }

\],

"iframe\_width": "80", // ширина окна iframe в процентах от общего окна плеера

"iframe\_height": "80" // высота окна iframe в процентах от общего окна плеера

_"block": "menu" // зона, в котиорой будет показан кнопка, возможны два значения - menu (значение по умолчанию, кнопка будет показана в левой панели) и filter (кнопка будет показана в верхней части над деревом оценки)_

}

Команды, выполняемые по закрытию окна iframe (при нажатии кнопок окна), могут быть следующими:

\- none – никаких действий, только закрытие окна iframe

\- reload\_all – закрыть окно iframe и перезагрузить весь интерфейс плеера

\- reload\_pa – закрыть окно iframe и перезагрузить текущую оценочную форму

\- redirect\_to\_pa – закрыть окно iframe, закрыть текущую форму и открыть другую форму (по идентификатору, указанному в атрибуте pa\_id).

\- api - вызов команды API плеера, см. тут

Также данные команды могут быть вызваны по нажатию кнопок внутри окна iframe, в кастом-шаблоне. Подробнее об этом ниже, в разделе «Описание функционала».

_При вызвое команды api для выполнения удаленного действия (command = "remote\_action") объект начтроек должен/может содержать следующие элементы:_

   _- remote\_action\_id - ID вызываемого действия (обязательный параметр)_

   _- wvars - объект значений переменных, которые будут переданы в действие, соответствует флрмату объекта SCOPE\_WVARS (или PARAMETERS) - код переменной (свойство объекта): значение переменной (значение свойства)_
