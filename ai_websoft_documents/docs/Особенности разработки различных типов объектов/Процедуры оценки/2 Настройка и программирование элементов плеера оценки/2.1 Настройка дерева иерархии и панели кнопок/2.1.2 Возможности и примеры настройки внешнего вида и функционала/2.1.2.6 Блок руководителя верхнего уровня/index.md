## 2.1.2.6 Блок руководителя верхнего уровня

Показывается для руководителя верхнего уровня в текущей иерархии для текущего пользователя. Обычно – оценивающий для текущего пользователя, формы которого недоступны для просмотра, но его ФИО фигурирует в списке оценивающих. В блоке показывается только ФИО и фотография руководителя.

Параметризация данного элемента не предусмотрена.

Возможно задания специальных стилей путем использования селектора wta-leaf-no-sheets, например:

.wt-appr-tree .wt-tree-leaf-user-name\[wta-leaf-no-sheets='1'\] { background-color: #7094b6;}
