## 2.1.2.5 Блок подсказки/описания

Функционал предназначен для оперативного информирования пользователя о шагах, которые ему надо предпринять, или/и дать ему подсказку/оперативную помощь по использованию текущего интерфейса.

По умолчанию блок не показывается. Для его активации необходимо установить в коде атрибут wfcomment\_users. Текст может содержать HTML-форматирование.

По умолчанию заголовок блока – «Полезная информация». Его можно изменить, передав атрибут wfcomment\_title\_users.

Если нужно показать блок изначально свернутым (открыт только заголовок) – надо установить атрибут wfcomment\_state\_users. Текст может содержать HTML-форматирование.

Если нужно изменить стиль блока комментариев, в дополнительно таблице стилей надо пере- или доопределить классы wt-appr-hint, wt-appr-hint-header, wt-appr-hint-text.

Можно задать индивидуальный стиль блока (для конкретной процедуры, пользователя или по некоему условию) – надо установить атрибут wfcomment\_class\_users

_Пример:_

oData.config.wfcomment\_users = "Текст <u>помощи</u> при работе с интерфейсом";

oData.config.wfcomment\_title\_users = "Помощь/<b>Описание</b>";

oData.config.wfcomment\_state\_users = "collapsed";
