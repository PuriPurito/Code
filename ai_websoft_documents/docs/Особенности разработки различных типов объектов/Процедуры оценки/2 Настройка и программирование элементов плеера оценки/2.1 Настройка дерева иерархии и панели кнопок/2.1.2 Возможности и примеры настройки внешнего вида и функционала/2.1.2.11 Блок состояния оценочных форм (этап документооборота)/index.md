## 2.1.2.11 Блок состояния оценочных форм (этап документооборота)

В блоке выводится название этапа документооборота. Причем изначально ищется название в глобальном справочнике этапов workflow, соответствующее коду, пришедшему в атрибуте wokflow\_state элемента структуры pa. Если такого кода в справочнике нет – выводится само значение атрибута wokflow\_state.

С точки зрения кастомизации это означает, что в коде шаблона дерева потенциально можно задавать произвольный текст для показа в данном поле. Допустимы элементы HTML\-форматирования.

Пример: Для руководителя пометить все формы, которые он должен заполнить (на этапе Оценка руководителя – 2) текстом «Нужно заполнить».

for (\_pa in oData.data)

{

                if (\_pa.workflow\_state=="2" && String(\_pa.expert.id) == String(curPersonID) )

                {

                                \_pa.workflow\_state = " Нужно заполнить";

                }

}
