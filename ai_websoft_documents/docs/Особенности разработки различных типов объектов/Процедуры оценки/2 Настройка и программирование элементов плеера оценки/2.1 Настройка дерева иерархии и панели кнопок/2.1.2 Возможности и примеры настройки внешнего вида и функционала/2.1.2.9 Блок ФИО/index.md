## 2.1.2.9 Блок ФИО

В блоке по умолчанию показывается ФИО оцениваемого сотрудника, одновременно являющееся ссылкой на блок доступных оценочных форм.

При желании, к ФИО достаточно несложно добавить дополнительную информацию, например должность, которая возвращается обработчиком в структуре person, но, по умолчанию, не показывается. Вот такой пример кода выводит должности в дерево оценки:

for (\_pa in oData.data)

{

                \_pa.person.fullname += “ (“ + \_pa.person.position + “)”;

}

Возможны более продвинутые варианты добавления дополнительной информации в дерево оценки. Но при этом надо помнить, что, хотя код построения дерева выполняется реже, чем код показа форм, например, тем не менее, при выполнении действий ДО часто необходимо вызывать перерисовку дерева (изменение видимости форм, смена этапов ДО и пр.). Поэтому «утежелять» без необходимости код настройки дерева не следует. Это порою приводит к критическим проблемам в быстродействии, причем, зачастую, у критически важных пользователей – руководителей высокого уровня, для которых количество видимых оценочных форм (и сотрудников) достаточно велико.
