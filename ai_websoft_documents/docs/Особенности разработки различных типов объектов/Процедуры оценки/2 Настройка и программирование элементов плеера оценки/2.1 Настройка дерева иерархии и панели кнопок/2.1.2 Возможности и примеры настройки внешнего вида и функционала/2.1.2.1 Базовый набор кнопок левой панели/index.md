## 2.1.2.1 Базовый набор кнопок левой панели

Включает в себя:

\- Кнопка показа иерархии сотрудников

                Выводит на экран интерфейс дерева сотрудников (как на рисунке выше). Может быть скрыта глобально (для всех интерфейсов плеера), если, например, методика проведения оценки не предполагает возможности для пользователя произвольно перемещаться между оцениваемыми сотрудниками/оценочными формами для просмотра/редактирования. Для глобального скрытия кнопки в программном коде шаблона дерева надо установить переменную

oData.config.btn\_users = false;

\- Кнопка показа иерархии целей сотрудника

                Выводит на экран интерфейс дерева целей сотрудника. Кнопка видна и доступна для нажатия только, если в интерфейсе была выбрана (и открыта) форма оценки целей. Описание функционала и возможных настроек дерева целей смотрите в разделе «Форма планирования и оценки деятельности/целей». Возможно глобальное скрытие кнопки, если методика оценки не предполагает формирования иерархии целей (нет транслирования и/или декомпозиции целей). Для глобального скрытия кнопки в программном коде шаблона дерева надо установить переменную

oData.config.btn\_objectives = false;

\- Кнопка показа журнала вызова действий документооборота

                Выводит на экран интерфейс журнала действий пользователей по документообороту. Кнопка видна и доступна для нажатия только, если в интерфейсе была выбрана и открыта какая-либо оценочная форма. Внешний вид интерфейса см. в разделе 1.4.3. В журнале фиксируется каждое нажатие кнопки документооборота – дата/время вызова действия, ФИО инициатора, название действия, этап ДО до нажатия кнопки и этап ДО после нажатия кнопки. Возможно глобальное скрытие кнопки, для этого в программном коде шаблона дерева надо установить переменную

oData.config.btn\_logs = false;
