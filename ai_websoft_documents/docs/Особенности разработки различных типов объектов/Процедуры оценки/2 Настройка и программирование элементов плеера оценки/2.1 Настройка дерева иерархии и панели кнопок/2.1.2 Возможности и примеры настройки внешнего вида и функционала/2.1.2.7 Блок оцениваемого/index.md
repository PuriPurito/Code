## 2.1.2.7 Блок оцениваемого

Показывается для всех сотрудников, являющихся участниками оценки, формы которых доступны текущему пользователю на просмотр или редактирование.

Если сотрудник сам является оценивающим в текущей процедуре и формы его оцениваемых доступны текущему пользователю, блок отображается как узел дерева оценки с элементом управления (кнопкой) в правом углу, с возможностью свернуть/развернуть дерево ниже данного узла.

Блок содержит сотруднике и его участии в оценке: фото, ФИО, признак завершенности оценочных форм и текущий этап документооборота. Элементы, входящие в блок и возможности их кастомизации описаны ниже.

Блоку целиком можно задать необходимы класс из таблицы стилей, поменяв размер или цвет шрифта, цвет подложки и т.д. Для этого в коде шаблона необходимо задать атрибут class у соответствующего элемента массива pas. Например, раскрасить по-особому формы на этапе ДО с кодом «2».

for (\_pa in oData.data)

{

                if (\_pa.workflow\_state=="2")

                {

                                \_pa.class = "tree\_hold";

                }

}
