## Пример 2

**_Пример 2_**. JavaScript код для передачи команды плееру изнутри дополнительного шаблона.

function goAPI(action, pa\_id)

{

                var p\_args = {sAction :  action, "sPAId": pa\_id};

                parent.g\_oAppr.API(p\_args);

}

// g\_oAppr – глобальный JS-объект плеера

// API – класс объекта плеера, реализующий выполнение команд

Возможны набор команд:

\- reload\_all (перегрузить окно плеера целиком)

\- reload\_pa (перезагрузить текущую форму с сервера)

\- redirect\_to\_pa (открыть другую форму в плеере, необходимо передать pa\_id/sPAId)

\- reload\_to\_pa (перегрузить данные плеера, включая дерево анкет и список анкет текущего пользователя, и открыть конкретную указанную анкету - pa\_id/sPAId)

\- workflow (инициировать действие документооборота/нажатие кнопки ДО, код кнопки - атрибут sWFCode)

\- message (показать сообщение, параметры сообщения - атрибут oMsg, описание параметров - см. описание структуры msg)

\- iframe (отобразить другое дополнительное окно/нажать кнопку показа окна, идентификатор кнопки - атрибут sWFCode)

\- show\_tree (показать дерево оценки)

\- show\_log (показать журнал действий ДО)

\- show\_obj\_tree (показать дерево целей)

\- remote\_action - выполнить удаленное действие (в стандарте LPE)

\- none (заглушка, не предпринимать никаких действий)
