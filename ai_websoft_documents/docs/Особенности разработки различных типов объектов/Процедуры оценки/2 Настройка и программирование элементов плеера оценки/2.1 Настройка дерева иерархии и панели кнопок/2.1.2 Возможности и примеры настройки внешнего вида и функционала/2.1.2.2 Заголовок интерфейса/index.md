## 2.1.2.2 Заголовок интерфейса

Текст по умолчанию – «Иерархия подчиненности».

При необходимости текст может быть изменен в зависимости от вида процедуры, документооборота, текущего пользователя и т.д. Для изменения установите значение переменной, при этом возможно использовать HTML\-форматирование

oData.config.tree\_header\_label = “Дерево <b\>годовой</b\> оценки”;
