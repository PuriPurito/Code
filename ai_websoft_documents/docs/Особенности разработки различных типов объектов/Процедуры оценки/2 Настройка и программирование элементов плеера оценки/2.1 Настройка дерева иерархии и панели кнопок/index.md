## 2.1 Настройка дерева иерархии и панели кнопок

_Выдача данных для интерфейса дерева оценки осуществляется по команде «list», подаваемой на обработчика при первой загрузке плеера или при получении команды RELOAD\_ALL от действия ДО._

По команде, в соответствии с условиями видимости ДО, обработчик формирует список форм для текущего пользователя (с учетом делегирования), данные из которого передаются шаблону кастом-обработки (если указан в карточке процедуры – закладка «Дополнительно», поле «Настраиваемый шаблон, заменяющий стандартное дерево»).

Код шаблона может изменить данные нужным образом, после чего они возвращаются в обработчик для передачи на плеер клиента. Плеер, в соответствии с полученными данными и настройками, формирует интерфейс дерева оценки и левой панели с кнопками.

Плеер получает информацию по всем оценочным формам, доступным в текущий момент текущему пользователю. Для построения дерева формы группируются по паре идентификаторов «Оцениваемый – Руководитель», после чего строится дерево подчиненности оценочных форм от руководителя к оцениваемому. Для каждого блока оценочных форм по оцениваемому выводится информация: ФИО оцениваемого, Название этапа ДО, Фото оцениваемого.

ФИО оцениваемого является ссылкой, при клике на которую дерево оценки скрывается, и открывается интерфейс с закладками форм – в соответствии с набором и порядком идентификаторов форм в блоке для данного оцениваемого.

_Если форм для пары "Оцениваемый - Руководитель" несколько, то если одна из форм отмечена признаком is\_main (если такой нет - то первая форма) - то:_

_\- все признаки этапа ДО и состояния формы для блока будет браться для этой формы_

_\- при открытии интерфеса закладок эта форма будет активна/показана, а остальные скрыты_

_\- если для "главной" формы определен свой набор линейки ДО (workflow\_set) - от в дереве будет показан именно он_

Параметры вызова метода «list» - объект options:

{

"impersonate\_info":true, //возвращать список делегирования

"workflow":true, //возвращать справочник этапов документооборота

"person\_icon":true, //возвращать адреса фотографий для показа в дереве

"expert\_info":true //возвращать информацию о руководителе и экспертах

}
