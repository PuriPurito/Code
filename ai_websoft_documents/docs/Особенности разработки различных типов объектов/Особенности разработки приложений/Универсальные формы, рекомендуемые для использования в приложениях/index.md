## Универсальные формы, рекомендуемые для использования в приложениях

Архитекторы и разработчики приложений могут создавать самостоятельно различные формы для использования в приложениях (подробнее см. раздел **Рекомендации по проектированию форм отображения объектов**).  
Однако компания WebSoft рекомендует для этих целей ряд универсальных форм, которые будут рассмотрены в данном разделе.
