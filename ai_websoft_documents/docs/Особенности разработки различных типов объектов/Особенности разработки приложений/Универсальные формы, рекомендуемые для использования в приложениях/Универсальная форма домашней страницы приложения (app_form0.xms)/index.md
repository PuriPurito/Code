## Универсальная форма домашней страницы приложения (app_form0.xms)

Функционал формы – автоматическое создание домашней страницы приложения на основе файла настроек.

Форма домашней страницы приложения должна быть определена в настройках приложения в поле _«Форма страницы по умолчанию»_:

Форма размещается в той же директории, что и само приложение. Она считывает данные из файла настроек _menu__\_structure__.xml_. Основные атрибуты формы следующие:

\- _home\_image_ – название файла картинки (изображения на домашней странице приложения). Файл картинки лежит в директории приложения.

\- _api\_url_ – адрес размещения вики-базы по данному приложению.

\- _wiki\_id_ – ID вики-базы по данному приложению.

На домашней странице отображается список статей документации из вики-базы, относящихся к данному приложению.

Текст заглавной статьи описания приложения формируется из вики-базы. Код заглавной статьи должен совпадать с кодом приложения.
