## Универсальная форма отображения настроек приложения (app_form_settings.xms)

Форма размещается в той же директории, что и само приложение (по умолчанию - в директории _.../WebTutorServer/applications/<код приложения>_). Она может быть вызвана с параметром _mode,_ определяющим режим отображения.

Форма считывает данные из файла настроек отображения _setting\_structure.xml_. Файл настроек отображения должен быть расположен в директории приложения и иметь следующую примерную структуру:

<?xml version="1.0" encoding="utf-8"?>  
<app>  
    <code>websoft360</code>  
    <entrys>  
        <entry>  
            <name>request\_type</name>  
            <mode>process</mode>  
            <target>instance</target>  
            <title>Подача заявок на получение обратной связи 360</title>  
            <control\_type>combo</control\_type>  
            <catalog></catalog>  
            <items>  
                <item>  
                    <name> </name>  
                    <value>none</value>  
                    <title>Не предусмотрена</title>  
                </item>  
                <item>  
                    <value>manager</value>  
                    <title>Только руководители</title>  
                    <access\_level></access\_level>  
                </item>  
                <item>  
                    <value>user</value>  
                    <title>Все сотрудники</title>  
                </item>  
            </items>  
            <access\_level></access\_level>  
            <view\_condition></view\_condition>  
            <edit\_condition></edit\_condition>  
        </entry>  
        <entry>  
            <name>request\_type\_id</name>  
            <mode>process</mode>  
            <target>instance</target>  
            <title>Тип заявки</title>  
            <control\_type>selector</control\_type>  
            <catalog>request\_type</catalog>  
            <items></items>  
            <view\_condition>\[\[request\_type\]\]!='none' && \[\[request\_type\]\]!=''</view\_condition>  
            <edit\_condition></edit\_condition>  
        </entry>  
    </entrys>  
</app>

Корневой элемент файла – _<app> ... </app>_.

Внутри данной пары тегов, как правило, размещаются следующие элементы:

\- _code_ – код приложения, обязательный элемент

\- _entrys_ – массив элементов, описывающих расположение на форме элементов отображения настроек.

Атрибуты элемента массива _entrys_ могут быть следующими:

      - _name_ – уникальный код элемента, который должен совпадать с соответствующим элементом массива wvars.

      - _mode_ – код режима. Форма при показе будет отображать только те элементы, код режима которых совпадает с кодом режима, переданным при вводе формы.

      - _target_ – целевой объект.  
      Может принимать одно из двух значений:  
               - _app_ – настройка приложения (значение элемента будет выбираться (и сохраняться) в массив _wvars_ приложения);  
               - _instance_ – настройка процесса приложения (значение элемента будет выбираться (и сохраняться) в массив _instance.wvars_ процесса приложения).

      - _title_ – название элемента настройки, которое будет отображено на форме.

      - _control\_type_ – тип отображаемого элемента управления.  
      Допустимые значения:  
                - _selector_ – выбор объекта системы в стандартном диалоге выбора;  
                - _combo_ – выпадающий список выбора;  
                - _bool_ – флаг с установкой значения _true|false_;  
                - _checkbox_ – один или несколько чекбоксов с единым заголовком.

      - catalog (для элемента управления типа _selector_) – название типа объекта, по которому будет производиться выбор.

      - items – массив значений элементов выбора для элементов управления типа _combo_ или _checkbox_.  
      Параметры элемента этого массива следующие:  
                - _name_ (для элемента типа checkbox) - название элемента. Если указывается значение данного атрибута, то значение каждого элемента _checkbox_ будет сохранятся в элемент массива wvars с указанным именем, если атрибут отсутствует или не заполнен, значения всех чекбоксов будут сохранены в один элемент wvars в виде строки (разделитель – точка с запятой);  
                - _value_ – сохраняемое значение элемента при выборе данного значения;  
                - _title_ – выводимое название значения.

      - _access\_level_ – уровень доступа, необходимый для показа этого элемента.

      - _view\_condition_ – условие отображения данного элемента в списке выбора или в группе чекбоксов.

      - _edit\_condition_ – условие, определяющее возможность редактирования элемента.

      Условия показа и редактирования задаются с помощью формул, которые, в общем случае, должны возвращать значения _true_ или _false_. Формулы, определяющие условия показа и редактирования, используют следующие основные объекты и переменные окружения:  
      - _TopElem_ – документ приложения;  
      - \_sMode – текущий режим отображения формы;  
      - sAppCode – текущий код приложения;  
      - iCurUserAppLevel – текущий уровень доступа пользователя в приложении.

Кроме этого для облегчения записи условий может использоваться мнемоническая форма записи – название элемента, обрамленное специальными символами:  
\- двойными квадратными скобками – в этом случае в форму будет подставлено значение элемента массива instance.wvars с указанным названием (например, _\[\[select\_type\_manager\]\]_ соответствует выражению _TopElem.instance.wvars.ObtainChildByKey(‘select\_type\_manager’).value_);  
\- комбинация фигурной и квадратной скобки – в этом случае в форму будет подставлено значение элемента массива wvars с указанным названием (например, _{\[select\_type\_func\_manager\]}_ соответствует выражению _TopElem.wvars.ObtainChildByKey(‘select\_type\_func\_manager').value_).

Пример формулы:

tools\_web.is\_true(\[\[select\_type\_manager\]\]) || tools\_web.is\_true({\[select\_type\_func\_manager\]})

Приведенная выше формула соответствует следующей:

tools\_web.is\_true(TopElem.instance.wvars.ObtainChildByKey(‘select\_type\_manager’).value) || tools\_web.is\_true(TopElem.wvars.ObtainChildByKey(‘select\_type\_func\_manager').value)
