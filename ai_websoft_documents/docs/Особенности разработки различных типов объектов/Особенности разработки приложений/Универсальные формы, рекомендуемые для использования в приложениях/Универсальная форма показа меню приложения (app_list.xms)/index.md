## Универсальная форма показа меню приложения (app_list.xms)

Функционал универсальной формы **app\_list.xms** – автоматическое создание меню приложения на основе файла настроек.

Если вы хотите использовать эту форму для показ меню, в поле _«Форма списка»_ карточки приложения необходимо задать текст «_x-local://applications/<код приложения>/app\_list.xml_».

Форма размещается в той же директории, что и само приложение (по умолчанию - в директории _.../WebTutorServer/applications/<код приложения>_).

Форма считывает данные из файла настроек меню приложения _menu\_structure.xml_, который должен быть размещен в той же директории.  
Примерная структура файла настроек меню приложения следующая:

<?xml version="1.0" encoding="utf-8"?>  
<app>  
                <code>websoft360</code>  
                <home\_image>FB360.jpg</home\_image>  
                <api\_url>https://help.websoft.ru/wiki\_api.html</api\_url>  
                <wiki\_id>6756528059998932980</wiki\_id>  
                <menu\_entrys>  
                               <menu\_entry>  
                                               <name>app</name>  
                                               <title>Приложение</title>  
                                               <form\_url>app\_form0.xml?mode=app</form\_url>  
                                               <type>app</type>  
                                               <menu\_entrys>  
                                                               <menu\_entry>  
                                                                              <name>reports</name>  
                                                                              <title>Отчеты</title>  
                                                                              <form\_url></form\_url>  
                                                                              <type></type>  
                                                                              <menu\_entrys>  
                                                                                              <menu\_entry>  
                                                                                                              <name>competence\_profile\_report</name>  
                                                                                                              <title>Отчет по профилям  
                                                                                                                     компетенций</title>  
                                                                                                              <form\_url>wtv\_view\_competence\_profile\_  
                                                                                                                     report.xml</form\_url>  
                                                                                                              <type>wtv</type>  
                                                                                                              <access\_level></access\_level>  
                                                                                              </menu\_entry>  
                                                                                              <menu\_entry>  
                                                                                                              <name>websoft360\_individual\_report</name>  
                                                                                                              <title>Индивидуальный отчет</title>  
                                                                                                              <form\_url>custom\_web\_template.html?  
                                                                                                                    custom\_web\_template\_id=  
                                                                                                                   5475919579372595587</form\_url>  
                                                                                                              <type>http</type>  
                                                                                              </menu\_entry>  
                                                                              </menu\_entrys>  
                                                               </menu\_entry>  
                                               </menu\_entrys>  
                               </menu\_entry>  
                </menu\_entrys>      
</app>

Корневой элемент файла – _<app> ... </app>_.

Внутри данной пары тегов обычно размещаются следующие элементы:

\- _<code>_ – код приложения, обязательный элемент.

\- _<home\_image>_ – файл заглавной картинки, опционально (если путь к файлу не задан, то по умолчанию принимается файл «код\_приложения+.jpg» в директории приложения.

\- _<api\_url>_ – адрес API сервера документации (если адрес не задан, то по умолчанию принимается адрес https://help.websoft.ru/wiki\_api.html .

\- _<wiki\_id>_ – ID вики-базы с документацией приложения (если ID не задан, то по умолчанию принимается _ID = 6756528059998932980_ (идентификатор базы, где будет размещаться документация по всем приложениям, корневой документ документации по конкретному приложению должен иметь код, совпадающий с кодом приложения).

\- _<menu\_entrys>_ – массив элементов, описывающих структуру меню приложения (может содержать несколько вложенных массивов <menu\_entry>, описывающие элементы меню нижних уровней). Каждый элемент меню определяется атрибутами:

                - <name> – уникальный (в пределах всего меню, независимо от вложенности) код элемента.

                - _<title>_ – отображаемое название пункта меню.

                - _<form\_url>_ – адрес документа (формы), который будет открыт при выборе данного пункта меню.

                - _<type>_ – тип документа (формы).  
                               Допустимые варианты данного атрибута:  
                               - _app_ – документ приложения из собственной директории;  
                               - _wtv_ – системная форма, которая будет открыта из директории _wtv_;  
                               - _http_ – веб-страница, которая будет открыта с портала сервера.

                - _<access\_level>_ – уровень доступа пользователя, выше которого ему становится доступен данный пункт меню.

По стандарту верхний уровень содержит один пункт меню _«Приложение»_, для которого определена базовая универсальная форма _app\_form0.xml_ – домашняя страница приложения, содержащая заглавную картинку и раздел помощи. Эта же форма должна быть определена в настройках приложения в поле _«Форма страницы по умолчанию»_.

Второй уровень, в зависимости от сложности приложения, может быть функциональным или группировочным.

Для сложных приложений с большим количеством настроек и связанных объектов, разнесенных по разным формам, целесообразно на втором уровне использовать группирующие элементы без привязки к форме. Иначе говоря, при выборе элемента меню второго уровня раскрывается третий, функциональный уровень. На втором уровне могут быть разделы типа _«Настройки», «Справочники», «Процессы»_ и т.д. В таком случае функциональные уровни (блоки настроек, списки объектов) размещаются на следующем, третьем уровне.

Если приложение не очень сложное и имеет немного настроек (которые умещаются на одной странице), немного типов связанных объектов и т.д., то второй уровень можно сделать функциональным, а третьего вообще не создавать.

На фунцкиональном уровне могут быть использованы две универсальных (стандартных) формы:  
\- форма отображения настроек (_app\_form\_settings.xml_)  
\- форма отображения списков объектов (_app\_form\_objects.xml_)

Каждой из универсальных форм можно задавать свой параметр отображения _mode_ (_app\_form\_settings.xml?mode=set1_) и использовать ее многократно в различных пунктах меню для показа отдельных блоков настроек или списков объектов.
