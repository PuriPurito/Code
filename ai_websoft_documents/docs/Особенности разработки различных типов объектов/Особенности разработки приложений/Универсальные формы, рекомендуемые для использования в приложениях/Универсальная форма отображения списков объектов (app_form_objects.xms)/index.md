## Универсальная форма отображения списков объектов (app_form_objects.xms)

Принцип функционала формы аналогичен форме отображения настроек.

Настройки отображения списков объектов считываются из файла _objects\_structure.xml_.   
Примерная структура файла настроек отображения списков объектов имеет следующий вид:

<?xml version="1.0" encoding="utf-8"?>  
<app>  
    <code>websoft360</code>  
    <entrys>  
        <entry>  
            <name>assessment\_appraises</name>  
            <mode>assessment\_appraise</mode>  
            <target>instance</target>  
            <title></title>  
            <create\_title></create\_title>  
            <catalog>assessment\_appraise</catalog>  
            <form\_url>app\_assessment\_appraise.xms</form\_url>  
            <create\_instance />  
            <access\_level />  
            <view\_condition />  
            <create\_condition />  
            <edit\_condition />  
            <delete\_condition />  
            <xquery\_condition />  
        </entry>  
    </entrys>  
</app>

Корневой элемент файла – _<app> ... </app>_.

Внутри данной пары тегов, как правило, размещаются следующие элементы:

\- _code_ – код приложения, обязательный элемент.

\- _entrys_ – массив элементов, описывающих расположение на форме элементов показа объектов.

Атрибуты элемента массива _entrys_ могут быть следующими:

     - _name_ – уникальный код элемента внутри файла настроек.

     - _mode_ – код режима. Форма при показе будет отображать только те элементы, код режима которых совпадает с кодом режима, переданным при вводе формы.

     - _target_ – целевой объект привязки создаваемых объектов.  
      Может принимать одно из двух значений:  
              - _app_ – настройка приложения (созданный в интерфейсе объект будет привязан к приложению в целом (актуально для справочников и объектов типа уведомлений), а также выбираться (и сохраняться) в массив _wvars_ приложения);  
              - _instance_ – настройка процесса приложения (созданный объект будет привязан к объекту «Процесс приложения», а также выбираться (и сохраняться) в массив _instance.wvars_ процесса приложения).

     - _title_ – заголовок элемента со списком объектов (если значение отсутствует, то будет выведено стандартное название из системного справочника (например, «Компетенции»)).

     - _create\_title_ – название кнопки создания нового объекта (если значение отсутствует, то кнопка не будет показана).

     - _catalog_ – название типа объекта.

     - _form\_url_ – название формы, по которой объект будет показан при открытии карточки в приложении. Если атрибут пуст, то будет использована стандартная системная карточка объекта. Использование стандартных карточек в приложениях должно быть минимизировано. В приложении должны быть видны только те поля и элементы управления, которые приложение использует (подробнее см. раздел **Рекомендации по проектированию форм отображения объектов**).

     - _create\_instance_ – флаг, определяющий, будет ли при создании нового объекта создаваться новый процесс приложения (этот параметр может принимать значения true|false ). Например, если приложение используется для автоматизации процесса опросов, то наличие такого флага означает, что для каждого нового опроса будет автоматически создаваться отдельный процесс приложения со своими настройками. Если данный флаг получает значение false, то все опросы будут проводиться в рамках одного процесса с общими настройками.

     - _access\_level_ – требуемый уровень доступа текущего пользователя в рамках приложения для показа этого элемента.

     - _view\_condition_ – формула условия показа элемента (данный параметр может использоваться дополнительно к уровню доступа _access\_level_).

     - _create\_condition_ – формула условия для возможности создания нового объекта (показа кнопки **Создать**).

     - _edit\_condition_ – формула условия для возможности редактирования объекта данного типа.

     - _delete\_condition_ – формула условия для возможности удаления объекта.

     - _xquery\_condition_ – формула, возвращающая строку дополнительного условия для отбора элементов списка объектов.

Правила обработки формул аналогичны описанным в разделе **Универсальная форма отображения настроек приложения (app\_form\_settings.xms)**.

По умолчанию, в список отбираются только объекты, связанные с документом приложения или с любым из процессов данного приложения (по полю _app\_instance\_id_).

Наложить дополнительные ограничения на выборку объектов можно с помощью:  
\- добавления параметра _xqual_ в строку вызова формы (дополнительно к параметру mode);  
\- формирования атрибута _xquery\_condition_ в описание элемента.
