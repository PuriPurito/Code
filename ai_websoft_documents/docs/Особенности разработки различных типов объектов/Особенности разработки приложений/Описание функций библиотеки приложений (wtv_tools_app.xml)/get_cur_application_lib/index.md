## get_cur_application_lib

Возвращается ссылка на объект собственной библиотеки приложения.  
На первом шаге функция получает объект приложения (путем вызова функции _get\_cur\_application_ с передачей ей всех параметров).  
Из объекта приложения извлекается путь к файлу собственной библиотеки. Если путь не указан – по умолчанию внутри директории приложения ищется файл с расширением js или xfp, название которого совпадает с кодом приложения.

_Синтаксис:_  
      **tools\_app.get\_cur\_application\_lib (\[<iApplicationIDParam>\], \[<iApplicationInstanceIDParam>\], \[<iObjectIDParam>\], \[<teObjectParam>\])**

_Аргументы:_  
     <iApplicationIDParam> (необязательный (см. примечания))  
     Тип: **Целое число** или **Строка**. ID объекта (или код) приложения  
     <iApplicationInstanceIDParam> (необязательный (см. примечания))  
     Тип: **Целое число**. ID объекта процесса приложения  
     <iObjectIDParam> (необязательный (см. примечания))  
     Тип: **Целое число**. ID объекта, связанного с приложением или процессом  
     <teObjectParam> (необязательный (см. примечания))  
     Тип: **TopElem**. _TopElem_ объекта, указанного в аргументе _iObjectIDParam_, если он уже открыт в системе (чтобы не открывать объект повторно).

Если файл собственной библиотеки приложения существует, то он расшифровывается, загружается в память, и, как результат выполнения функции, возвращается ссылка на объект загруженной библиотеки. Вызов функций библиотеки после получения ссылки осуществляется штатным образом. Например, вызов некоторой условной функции с названием _getInitPage_ из собственной библиотеки приложения в коде шаблона текущего объекта на портале имеет следующий вид:  
_result = tools\_app.get\_cur\_application\_lib (null, null, curObjectID, curObject ).getInitPage();_

Примечание - Если данная функция выполняется из агента, то должны быть указаны все аргументы (параметры).

_Возвращаемое значение:_  
      Тип: **Объект**. Ссылка на объект собственной библиотеки приложения.

_Пример:_  
      `_result = tools_app.get_cur_application_lib (null, null, curObjectID, curObject ).getInitPage();_`
