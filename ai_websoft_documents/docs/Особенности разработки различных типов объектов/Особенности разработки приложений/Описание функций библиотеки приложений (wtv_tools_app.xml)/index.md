## Описание функций библиотеки приложений (wtv_tools_app.xml)

Общие функции приложения обычно хранятся в файле системной библиотеки в директории приложения: ..._/WebTutorServer/wtv/wtv\_tools\_app.xml_.  
Вызов любой общей функции приложения производится следующим образом:  
**tools\_app.<функция>(<параметры>)**

Примечание - Если данные функции выполняются из агента, то должны быть указаны все аргументы (параметры).
