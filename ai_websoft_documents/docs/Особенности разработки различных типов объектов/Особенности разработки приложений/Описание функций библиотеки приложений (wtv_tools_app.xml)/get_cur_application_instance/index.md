## get_cur_application_instance

Получение объекта процесса приложения.

_Синтаксис:_  
      **tools\_app.get\_cur\_application\_instance (\[<iApplicationIDParam>\], \[<iApplicationInstanceIDParam>\], \[<iObjectIDParam>\], \[<teObjectParam>\])**

_Аргументы:_  
     <iApplicationIDParam> (необязательный (см. примечания))  
     Тип: **Целое число** или **Строка**. ID объекта (или код) приложения.  
     <iApplicationInstanceIDParam> (необязательный (см. примечания))  
     Тип: **Целое число**. ID объекта процесса приложения.  
     <iObjectIDParam> (необязательный (см. примечания))  
     Тип: **Целое число**. ID объекта, связанного с приложением или процессом.  
     <teObjectParam> (необязательный (см. примечания))  
     Тип: **TopElem**. TopElem объекта, указанного в аргументе _iObjectIDParam_, если он уже открыт в системе (чтобы не открывать объект повторно).

Примечание - При вызове функции без параметров возвращает _TopElem_ текущего объекта процесса текущего приложения. Вариант возможен для использования только в коде форм/действий программы **WebTutor Administrator**.

Приоритет параметров: Если передан идентификатор процесса приложения (_iApplicationInstanceIDParam_), возвращается TopElem объекта процесса, если он существует, если объект процесса не существует – возвращается _null_. Если передан идентификатор (ID) объекта, связанного с процессом приложения (_iObjectIDParam_), то по этому идентификатору определяется связанный процесс (если последний аргумент имеет значение null, то документ объекта процесса приложения будет открыт внутри библиотеки). Если передан только идентификатор приложения _iApplicationIDParam_ или объекта _iObjectIDParam_, связанного с приложением (а не процессом), то возвращается последний (по дате модификации) активный процесс приложения. Если в приложении нет процессов, то создается новый активный процесс

Примечание - Если данная функция выполняется из агента, то должны быть указаны все аргументы (параметры).

_Возвращаемое значение:_  
      Тип: **TopElem**. TopElem объекта процесса приложения.

_Пример:_  
      `__instance = tools_app.get_cur_application_instance ();_`
