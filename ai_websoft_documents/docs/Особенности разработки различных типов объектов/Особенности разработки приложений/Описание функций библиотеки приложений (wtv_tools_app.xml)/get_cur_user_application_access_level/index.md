## get_cur_user_application_access_level

Возвращает уровень доступа текущего пользователя в текущем приложении. Функция используется только в интерфейсе администратора.

_Синтаксис:_  
      **tools\_app.get\_cur\_user\_application\_access\_level ()**

_Аргументы:_  
      Функция вызывается без аргументов.

_Возвращаемое значение:_  
      Тип: **Целое число**. Уровень доступа текущего пользователя в текущем приложении.

_Пример:_  
      `_access_level = tools_app.get_cur_user_application_access_level ();_`
