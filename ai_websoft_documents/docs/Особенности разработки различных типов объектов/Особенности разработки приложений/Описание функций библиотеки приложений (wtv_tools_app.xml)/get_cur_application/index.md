## get_cur_application

Получение объекта приложения.

_Синтаксис:_  
      **tools\_app.get\_cur\_application (\[<iApplicationIDParam>\], \[<iApplicationInstanceIDParam>\], \[<iObjectIDParam>\], \[<teObjectParam>\])**

_Аргументы:_  
     <iApplicationIDParam> (необязательный (см. примечания))  
     Тип: **Целое число** или **Строка**. ID объекта (или код) приложения  
     <iApplicationInstanceIDParam> (необязательный (см. примечания))  
     Тип: **Целое число**. ID объекта процесса приложения.  
     <iObjectIDParam> (необязательный (см. примечания))  
     Тип: **Целое число**. ID объекта, связанного с приложением или процессом.  
     <teObjectParam> (необязательный (см. примечания))  
     Тип: **TopElem**. TopElem объекта, указанного в аргументе _iObjectIDParam_, если он уже открыт в системе (чтобы не открывать объект повторно).

Примечание - При вызове функции без параметров возвращает TopElem текущего объекта приложения. Вариант возможен для использования только в коде форм / действий программы **WebTutor Administrator**.

Приоритет параметров: Если передан идентификатор приложения, то поиск ведется по этому идентификатору; Если передан первый параметр со значением _null_, но есть идентификатор процесса, то поиск ведется по приложению, связанному с указанным процессом; Если первые два параметра переданы со значением null, но передан идентификатор объекта, то определяется приложение, связанное с этим объектом (напрямую или через процесс), и поиск ведется по указанному приложению; Если передан последний параметр со значением _null_, то документ будет открыт внутри библиотеки.

Примечание - Если данная функция выполняется из агента, то должны быть указаны все аргументы (параметры).

_Возвращаемое значение:_  
      Тип: **TopElem**. TopElem объекта приложения.

_Пример:_  
      `__target = tools_app.get_cur_application ( null, null, _doc.DocID, _doc.TopElem );         teApplication = tools_app.get_cur_application ();_`
