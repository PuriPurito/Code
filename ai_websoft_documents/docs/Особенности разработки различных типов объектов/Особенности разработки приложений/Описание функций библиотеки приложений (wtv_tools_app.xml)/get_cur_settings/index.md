## get_cur_settings

Возвращает значение заданного параметра или объект настроек для приложения или конкретного процесса приложения.  
Сначала функция находит нужный источник блока настроек, затем ищет в указанном источнике значение заданного параметра или объект настроек.

_Синтаксис:_  
      **tools\_app.get\_cur\_settings (<sNameParam>, \[<sTargetParam>\], \[<sFormatParam>\], <iApplicationIDParam>, <iApplicationInstanceIDParam>, <iObjectIDParam>, \[<teObjectParam>\])**      или  
      **tools\_app.get\_cur\_settings (\[<sNameParam>\], \[<sTargetParam>\], <sFormatParam>, <iApplicationIDParam>, <iApplicationInstanceIDParam>, <iObjectIDParam>, \[<teObjectParam>\])**

_Аргументы:_  
     <sNameParam> (необязательный (см. примечания))  
     Тип: **Строка**. Название параметра.  
     <sTargetParam> (необязательный (см. примечания))  
     Тип: **Строка**. Строковое выражение целевого объекта.   
Допустимые значения:  
\- _'app'_ – извлекать настройки для объекта приложения;  
\- _'instance'_ – извлекать настройки для объекта процесса приложения.  
     <sFormatParam> (необязательный; обязательный, если не задан аргумент sNameParam)  
     Тип: **Строка**. Строковое выражение формата возвращаемых данных.   
Допустимые значения:  
\- _'wvars'_ – возвращается объект настроек wvars в формате _XmlElem_ (см. примечание).  
\- _'xml'_ – возвращается _объект XML_ с корневым элементом _DATA_ (см. примечание).  
\- _'json'_ – возвращается _объект JSON_ с настройками (см. примечание).  
     <iApplicationIDParam> (обязательный)  
     Тип: **Целое число** или **Строка**. ID (или код) объекта приложения.  
     <iApplicationInstanceIDParam> (обязательный)  
     Тип: **Целое число**. ID процесса приложения.  
     <iObjectIDParam> (обязательный)  
     Тип: **Целое число**. ID объекта, связанного с приложением.  
     <teObjectParam> (необязательный)  
     Тип: **TopElem**. _TopElem_ объекта, указанного в аргументе _iObjectIDParam_, если он уже открыт в системе (чтобы не открывать объект повторно). 

На первом шаге функция находит, в соответствии с переданными аргументами (объект, процесс или приложение), нужный источник блока настроек. Тип источника (собственно приложение или процесс) определяется, исходя из переданного типа целевого объекта _sTargetParam_.  
Если передано название искомого параметра _sNameParam_, то из найденного блока настроек (массива wvars) извлекается значение элемента с заданным значением и возвращается, как результат функции. Если название искомого параметра _sNameParam_ не передано, то возвращается весь блок настроек. В этом случае формат возвращаемых данных зависит от переданного параметра _sFormatParam_.  
  
Если формат возвращаемых данных _sFormatParam == 'wvars'_, из полученного источника извлекается массив wvars и в неизменном виде возвращается, как результат выполнения функции.  
При других вариантах вначале производится анализ массива _wvars_ на предмет иерархической структуры (пары _name - parent\_wvar\_name_). Если структура прослеживается – она создается и в результат функции возвращается уже иерархический объект. Если названия параметров уже содержат иерархические признаки (знак точки в названии) – они соответствующим образом «обрезается» (остается только последняя часть названия без точки).  
 

Например, имеется структура _user.has\_fio.has\_firstname_. Она может быть реализована в 3-х вариантах.

**Вариант 1.** Есть три переменные, имеющие иерархическую структуру:  
**\- user**: родительская переменная = _nul_l  
**\- has\_fio**: родительская переменная = _user_  
**\- has\_firstname**: родительская переменная = _has\_fio_

**Вариант 2.** Есть три переменные, не имеющие иерархической структуры, но названия которых содержат путь через точку. В этом случае структура будет создана путем анализа названий переменных (выявления точек в названии).  
 **- user  
\- user.has\_fio  
\- user.has\_fio.has\_firstname**

**Вариант 3.** Разработчики используют одновременно оба варианта – и иерархическую структуру, и названия переменных, содержащие путь через точку. Это может быть сделано из-за того, что метод хранения переменных wvars требует уникальности имен переменных и приходится переменные с одинаковым функциональным назначением (например _request\_id_) для разных веток функционала называть длинными именами, чтобы обеспечить уникальность.   
**\- user**: родительская переменная = _null_  
**\- user.has\_fio**: родительская переменная = _user_  
**\- user.has\_fio.has\_firstname**: родительская переменная = _has\_fio_

Во втором и в третьем случаях код функции будет «обрезать» часть названия переменных перед последней точкой, и результирующие названия переменных во всех трех случаях будут одинаковыми и приводятся к виду:  
**\- user  
\- has\_fio  
\- has\_firstname**

Полученный объект возвращается в указанном формате (xml или json).  
В _формате XML_ значения возвращаются, как и обычно, в виде объекта с парой значений _Name – Value._  
В _формате JSON_ для каждого элемента создается свойство value, содержащее значение настройки (это позволяет передавать значения не только конечных, но и промежуточных узлов).  
Получение полного объекта настроек в форматах xml или json удобно в таких процессах, когда настроек много (можно один раз получить полный объект, а потом извлекать из него значения в удобном формате).

Примечание - Если данная функция выполняется из агента, то должны быть указаны все аргументы (параметры).

_Возвращаемое значение:_  
      Тип: **Объект XmlElem, XML или JSON**. Значение заданного параметра или объект настроек для приложения. Результат действия функции (см. примечание к разделу Аргументы).

_Примеры:_      

`_В настройках имеется параметр request (флаг наличия заявок вообще) (булево) и параметр request.request_type_id (идентификатор типа заявки) (целое число)_`  
 

_Пример 1. Получение одиночной настройки с названием "request.request\_type\_id" из приложения:_  
`__val = tools_app.get_cur_settings ( "request.request_type_id", "app", null, null, null, curObjectID, curObject );_`  
 

_Пример 2. Получение полного объекта настроек процесса и извлечение из него настройки "request.request\_type\_id" (в формате XML):_  
`__set = tools_app.get_cur_settings ( "", "instance", "xml", null, null, curObjectID, curObject );   _val = null;   If (tools_web.is_true (_set.request))   {         _val = _set.request.request_type_id.Value;   }_`  
 

_Пример 3. Получение полного объекта настроек процесса и извлечение из него настройки "request.request\_type\_id" (в формате JSON):_  
`__set = tools_app.get_cur_settings ( "", "instance", "json", null, null, curObjectID, curObject );   _val = null;   If (tools_web.is_true (_set.request.value))   {         _val = _set.request.request_type_id.value;   }_`
