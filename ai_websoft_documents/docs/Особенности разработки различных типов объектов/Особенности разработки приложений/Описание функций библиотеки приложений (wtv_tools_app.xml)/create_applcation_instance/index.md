## create_applcation_instance

Создание нового процесса приложения.  
После создания объекта процесса, функция делает его активным и возвращает _TopElem_ созданного объекта.

_Синтаксис:_  
      **tools\_app.create\_applcation\_instance (\[<iApplicationIDParam>\])**

_Аргументы:_  
     _<iApplicationIDParam> (необязательный (см. примечание))_  
      Тип: **Целое число** или **Строка**. Идентификатор (ID) или код приложения. В интерфейсе администратора возможен вызов без параметра – будет создан процесс текущего приложения.

Примечание - Если данная функция выполняется из агента, то должны быть указаны все аргументы (параметры).

_Возвращаемое значение:_  
      Тип: **Объект XmlDoc**. Документ объекта созданного процесса. 

_Пример:_  
      `_teResult = tools_app.create_applcation_instance ( iApplicationIDParam ).TopElem;_`
