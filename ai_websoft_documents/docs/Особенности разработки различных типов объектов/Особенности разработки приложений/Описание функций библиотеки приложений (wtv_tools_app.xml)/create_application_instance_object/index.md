## create_application_instance_object

Создание нового объекта, связанного с приложением. Функция создает в базе новый документ по форме, определенной для переданного типа объекта.

_Синтаксис:_  
      **tools\_app.create\_application\_instance\_object (<sObjectNameParam>, \[<oObjectFieldsParam>\], <iApplicationInstanceIDParam>, \[<bSaveParam>\])**

_Аргументы:_  
     <sObjectNameParam> (обязательный)  
     Тип: **Строка**. Название типа объекта, который надо создать (например, 'competence', 'event' или др.)  
     <oObjectFieldsParam> (необязательный (см. примечания))  
     Тип: **Строка**. Объект, содержащий значения полей создаваемого документа (строковое выражение в формате JSON).  
     <iApplicationInstanceIDParam> (обязательный)  
     Тип: **Целое число**. Идентификатор процесса или приложения.  
     <bSaveParam> (необязательный)  
     Тип: **Булево**. Признак сохранения. Если параметр _bSaveParam_ равен _true_, то документ будет сохранен внутри кода функции. В противном случае документ создается, привязывается к базе, наполняется значениями полей, привязывается к процессу или приложению, но не сохраняется. По умолчанию – _false_.

Если в параметрах передан объект со значениями полей (_oObjectFieldsParam_), то значения полей документа заполняются в соответствии со значениями полей переданного объекта. Если передан идентификатор объекта процесса (_iApplicationInstanceIDParam_), созданный документ привязывается к этому процессу (заполняется поле _app\_instance\_id_), если передан идентификатор приложения – объект привязывается непосредственно к приложению.

Примечание - Если данная функция выполняется из агента, то должны быть указаны все аргументы (параметры).

_Возвращаемое значение:_  
      Тип: **Объект XmlDoc**. Документ нового объекта, связанного с приложением. 

_Пример:_  
      `_oDoc = tools_app.create_application_instance_object ('event', null, curInstance, null);          oDoc1 = tools_app.create_application_instance_object ('competence', jsFields, iApp, true);_`
