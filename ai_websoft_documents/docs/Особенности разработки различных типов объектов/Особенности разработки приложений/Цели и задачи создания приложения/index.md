## Цели и задачи создания приложения

**Основные цели и задачи создания приложений:**

1.  формирование единого интерфейса (и объекта) для хранения/изменения/отображения/получения настроек различных элементов бизнес-процесса, которые сейчас разбросаны по различным объектам (шаблоны/агенты/коллекции/документообороты);
2.  формирование единого интерфейса для администраторов конкретного бизнес-процесса – списки объектов только по данному процессу (в том числе из разных модулей), упрощенные формы ввода данных, специфические операции;
3.  формирование интерфейса управления доступа пользователей к бизнес-процессу, с возможностью задания определенного уровня доступа;
4.  формирование механизма защиты разработок от несанкционированного распространения (лицензирование и шифрование).

Далее мы будем рассматривать основные вопросы разработки и программирования приложений на примере приложения **Exit-интервью**.
