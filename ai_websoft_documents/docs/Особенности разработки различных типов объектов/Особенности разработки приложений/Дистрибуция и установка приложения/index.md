## Дистрибуция и установка приложения

**Алгоритм создания пакета** (материал подготовлен _Тарасом Теницким_)**:**

Заполняем обязательные поля приложения в разделе **“Общие сведения”**:

*   **Код**
*   **Название**
*   **Изображение** \- иконка, которая будет отображаться в выпадающем меню для перехода по разделам программы Администратор WT. Должен быть указан файл в формате _.svg_
*   **Вендор** (по умолчанию websoft)
*   **Дата релиза**
*   **Версия приложения**
*   **Версия сервера**

 В разделе **“Объекты”** добавляем в список объектов приложения все компоненты, которые должны быть переданы с приложением.  
В разделе **“Общие сведения”** нажимаем кнопку **“Собрать пакет приложения”**.  
 

**Примечания:**

*   При распаковке приложения в системе создается карточка приложения, идентификатор, которой не переносится из системы, в которой было создано приложение.
*   Объекты, указанные в разделе **”Объекты”** после распаковки привязываются к приложению по новому идентификатору.
*   В связи с тем, что в архиве с приложением хранятся файлы с расширением _.js_, почтовые серверы не пропускают письма с вложенным архивом. Для передачи пакета пользуйтесь облачными хранилищами.
