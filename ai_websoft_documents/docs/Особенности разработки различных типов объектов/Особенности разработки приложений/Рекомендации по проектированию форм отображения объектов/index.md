## Рекомендации по проектированию форм отображения объектов

Предпосылки для проектирования собственных форм отображения объектов в приложении следующие:

*   Карточка объекта в приложении должна содержать только те поля и элементы управления, которые связаны с функционалом именно данного приложения. Стандартные системные карточки могут содержать универсальный набор полей и элементов управления для всего функционала системы, большая часть которого в функционале приложения не используется. Например, карточка сотрудника для приложения по рассылкам может содержать только _ФИО, Должность, Подразделение, Пол, Дату рождения, Адрес электронной почты_ и копки «_Поставить/Снять признак запрета на рассылки_», что является незначительным подмножеством элементов стандартной карточки сотрудника в системе.
*   Карточка объекта в системе (стандартные системные карточки) имеет сложную структуру с закладками, элементами перехода в связанные объекты других модулей и пр. Карточка объекта в приложении, в идеале, должна иметь простую структуру, все элементы которой должны быть расположены в пределах одного окна (переходов в другие объекты быть не должно).
*   Карточка объекта в приложении, для упрощения интерфейса, должна открываться в окне модального диалога (а не на полном экране, как в стандартном интерфейсе), поэтому исключается многоэкранность (открыто только одно окно объекта). Чтобы открыть окно другой объект, надо закрыть окно предыдущего.  В частности, это предполагает другие требования к стандартным элементам управления (например, кнопки сохранения и отмены должны располагаться в нижней правой части формы, а не в верхней левой части, как в стандартных системных карточках).

Типовой набор действий по трансформации стандартной системной карточки в карточку приложения:

1.  Копируем файл _xms_ из директориии _wtv_ в директорию приложения, меняя префикс имени файла с _wtv_ на _app_ (например, название _wtv\_general.xms_ меняется на _app\_general.xms)._
2.  Удаляем строки:
    
    <ITEM TYPE="std\_doc\_menu"/>  
    <ITEM TYPE="std\_doc\_toolbar"/>
    
3.  В заголовке формы, в строке <SPXML-SCREEN> меняем параметр SOURCE на "TopElem.object.Object" (этот параметр необходим для обработки формы в режиме модального диалога).
4.  Проверяем формулы в атрибутах заголовка (BEFORE-INIT-ACTION, BEFORE-SAVE-ACTION и пр.). При необходимости – модифицируем или удаляем их.
5.  Удаляем элементы типа:
    
    <INHERIT TYPE="page\_tree\_base"/>  
      
    <SELECTOR NAME="main\_selector">  
    <PAGE TITLE-EXPR="ms\_tools.get\_const('cavr3d3iwk')" IMAGE-URL="ico/common.ico" VERT-SCROLL="1">  
    </PAGE>
    
6.  Удаляем все поля и элементы управления (_button, command,_ списки объектов и пр.), не имеющие отношения к функционалу текущего приложения.
7.  Остающиеся на форме элементы, при необходимости, модифицируем:  
    \- ставим признак _READ-ONLY_ для элементов, которые не будут изменяться в рамках функционала данного приложения;  
    \- удаляем возможность перехода на другие объекты и открытия карточек других объектов;  
    \- меняем код кнопок и действий в соответствии с функционалом текущего приложения;  
    \- добавляем дополнительные элементы, если они необходимы для реализации функционала текущего приложения.
    
8.  Добавляем в нижнюю часть формы (для большинства стандартных форм – выше последних строк _</PANEL></LINE></SPXML-SCREEN>_) следующий блок, формирующий стандартные кнопки button для сохранения и закрытия окна:
    
    <SPLIT FIXED="1" BK-COLOR-EXPR="AppUi.themeColors.separator"/>  
                    <PANEL NAME="PanelDlgBottom" STD-MARGINS="0" PADDING="24vpx 24vpx 24vpx 24vpx">  
                                   <LINE WIDTH="100%" HORIZ-SPACING="16vpx">  
                                                   <BUTTON TITLE="##ms\_tools.get\_const('c\_cancel')##" WIDTH="100vpx" HEIGHT="32px" ALIGN="right" CMD="2"/>  
                                                   <BUTTON TITLE="##ms\_tools.get\_const('c\_save')##" WIDTH="100vpx" HEIGHT="32px" ALIGN="right" CMD="1"/>  
                                   </LINE>  
                    </PANEL>
