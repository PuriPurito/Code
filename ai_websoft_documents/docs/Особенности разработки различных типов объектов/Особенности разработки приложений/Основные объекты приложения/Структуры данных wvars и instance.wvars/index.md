## Структуры данных wvars и instance.wvars

В объекте приложения используются две структуры данных для хранения настроек - **wvars** и **instance.wvars**.

В принципе, _wvars_ в системе WebTutor - это стандартная структура, которая используется во многих объектах – агентах, шаблонах, элементах шаблонов, удаленных действиях, выборках и т.д. В упомянутых объектах используется стандартный объект для редактирования настроек в этой структуре. 

В экранной системной форме объекта приложения такой элемент редактирования тоже имеется, но он служит только для административных целей – при необходимости прямого изменения данных.

Как было отмечено выше, в объекте приложения имеются две структуры для хранения настроек:

\- _wvars_ – содержит общие настройки приложения. Данные настройки также передаются запускаемым процессам. Если в интерфейсе приложения данные настроек в структуре _wvars_ будут изменены, то все вновь запускаемые процессы получат из этой структуры новые значения параметров. На запущенные ранее процессы эти изменения не повлияют.

\- _instance.wvars_ – содержит настройки по умолчанию для нового запущенного процесса. Когда в приложении запускается новый процесс с индивидуальными настройками (если это предусмотрено функционалом приложения) – то этот блок копируется в создаваемый объект «процесс приложения», и, с этого момента, запущенный процесс будет использовать указанные значения настроек.

Какие именно настройки будут хранится непосредственно в объекте приложения, а какие – в объекте процесса приложения, должны решать архитекторы и разработчики приложений. 

В приложениях общие настройки _wvars_ по умолчанию обычно хранятся в файле **app\_objects.xml**. Например, в файле **app\_objects.xml** приложения **Exit-интервью** общие настройки по умолчанию имеют следующую структуру:

<wvars>  
                <wvar>  
                               <name>is\_for\_manager</name>  
                               <value>true</value>  
                               <type>string</type>  
                               <position>0</position>  
                </wvar>  
                <wvar>  
                               <name>days\_to\_remind</name>  
                               <value>1</value>  
                               <type>string</type>  
                               <position>0</position>  
                </wvar>  
</wvars>

Однако, в некоторых приложениях настройки по умолчанию не предусмотрены. В этом случае все настройки могут быть сформированы заказчиком после установки приложения на свой сервер. После установки настроек заказчиком (после первого сохранения) в объекте такого приложения структура _wvars_ появится.
