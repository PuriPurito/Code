## Особенности работы с каталогом person_hierarchys

**Каталог person\_hierarchys** предназначен для быстрого получения иерархии подразделений для сотрудника.  
Каталог **person\_hierarchys** заполняется автоматически и регулярно обновляется.   
Более подробное описание каталога person\_hierarchys и его полей см. здесь.

Перед началом работы с каталогом **person\_hierarchys** можно произвести его актуализацию.  
В принципе, данный каталог генерируется автоматически при апгрейде сервера с помощью специального скрипта, имеющегося в конвертационных файлах.  
В то же время, для актуализации каталога можно запустить на сервере агент из одной строки:   
_tools.person\_hierarchy\_build\_all();_  
 

Работа с каталогом **person\_hierarchys** аналогична работе с другими каталогами системы.  
Например, можно вывести на экран содержимое полей каталога с помощью панели запросов:  

Состав полей каталога перечислен в данном разделе.

Примечание - Кроме приведенных на скриншоте полей каталог **person\_hierarchy** содержит также поле subdivision\_id типа массив XML. Данное поле не отображается в панели запросов из-за своего типа. 

  
Ниже приведен пример простого программного кода для работы с каталогом **person\_hierarchy**:

`_// tools.person_hierarchy_build_all(); // Генерация каталога person_hierarchy   arrRes0 = XQuery( "for $hier in person_hierarchys return $hier" );   arrRes = ArrayFirstElem( arrRes0 );_`

`_str = 'В состав элемента массива входят следующие поля: \n';   for (elem in arrRes) // выводит информацию о первом элементе массива   {       str = str  + elem.Name + ' - ' + elem.Value + '  ' + '\n';   }   alert ( str );_`
