## Особенности использования программного кода в печатных формах

При создании печатных форм оперелены следующие системные переменные:

**1\. Для печатной формы создаваемой в интерфейсе администратора:**

TopElem - TopElem текущего документа, относительно которого создается печатная форма

**2\. Для печатной формы создаваемой на портале:**

curObject - TopElem документа на портале, идентификатор которого указан в параметры URL &object\_id=...

curObjectID - значение из URL выражения &object\_id=...
