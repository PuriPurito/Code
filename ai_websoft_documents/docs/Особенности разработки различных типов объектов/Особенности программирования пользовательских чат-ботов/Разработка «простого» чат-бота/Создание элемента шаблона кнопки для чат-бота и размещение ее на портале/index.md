## Создание элемента шаблона кнопки для чат-бота и размещение ее на портале

Элемент шаблона кнопки для чат-бота может быть загружен из открытых компонентов софта. После этого он становится доступным в программе _WebTutor_ _Administrator_ в разделе **Дизайнер – Шаблоны – Шаблоны документов – Элементы шаблонов**.

Название элемента шаблона, в данном случае, - «Кнопка перехода в чат».

Карточка элемента шаблона кнопки для чат-бота обычно состоит из двух вкладок:

*   **"Общие сведения";**
*   **"Доступ".**

Основные параметры, связанные с настройкой элемента шаблона кнопки для чат-бота находятся в разделе "**Общие сведения**" карточки элемента шаблона:

*   **Код элемента шаблона** (необязателен)**;**
*   флажок **«Включен»** (для отображения кнопки данный флажок должен быть установлен)**;**
*   **Mode** **(**страница, на которой будет выводиться кнопка (в данном случае, _mode = home_ (кнопка отображается на главной (домашней) странице портала))**;**
*   **Зона** (в данном случае, _Зона = main_)**;**
*   **Позиция в списке** (в данном случае, номер позиции = 1)**;**
*   **Дизайн портала** (наименование дизайна, в котором будет выводиться кнопка (в данном случае, в указанном поле поставлен символ «звездочка» (\*), то есть кнопка отображается во всех дизайнах));
*   **Сайт** (наименование сайта, на котором будет выводиться кнопка (в данном случае, также поставлена звездочка, то есть кнопка отображается на всех сайтах));
*   **Шаблон** (шаблон документа, связанный с данным элементом шаблона (в данном случае, это шаблон с названием «_Кнопка перехода в разговор с ботом_» (об этом шаблоне будет более подробно сказано далее)).

В карточке шаблона кнопки для чат-бота отображаются следующие переменные:

*   **chatbot\_id** – идентификационный номер (ID) чат-бота, который будет активирован данной кнопкой (в данном случае должен быть выбран чат-бот с названием _«Чат-бот поддержки»_);
*   **btn** – данные, характеризующие кнопку:
    *   **show\_icon** – флажок, определяющий видимость кнопки на портале;
    *   **text** – надпись на кнопке;
    *   **title** – надпись, которая отображается при наведении курсора на кнопку на портале.

Примечание – Если значения аналогичных переменных в карточках элемента шаблона и шаблона документа различаются, то приоритет имеют значения переменных элемента шаблона.
