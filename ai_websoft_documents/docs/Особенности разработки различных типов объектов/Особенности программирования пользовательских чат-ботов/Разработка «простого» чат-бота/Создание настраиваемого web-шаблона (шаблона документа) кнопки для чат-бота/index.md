## Создание настраиваемого web-шаблона (шаблона документа) кнопки для чат-бота

**Шаблон документа кнопки для чат-бота** – это специальный настраиваемый web-шаблон, разработанный программистами компании WebSoft для вызова чата и чат-бота.

Шаблон доступен в программе _WebTutor_ _Administrator_ в разделе **Дизайнер – Шаблоны – Шаблоны документов**.

Название шаблона документа, в данном случае, - «**Кнопка перехода в разговор с ботом**».

Карточка шаблона кнопки для чат-бота обычно состоит из пяти вкладок:

*   **"Общие сведения";**
*   **"Зоны разметки";**
*   **"Код";**
*   **"Описание";**
*   **"Доступ".**

Основные параметры, связанные с настройкой шаблона кнопки для чат-бота находятся в разделах "**Общие сведения**" и "**Код**" карточки шаблона.

В частности, в разделе "**Общие сведения**" указываются следующие основные параметры.

*   **Код;**
*   **Название;**
*   **Переменные**, используемые для дополнительной настройки шаблона.

В карточке шаблона кнопки для чат-бота отображаются следующие переменные:

*   **chatbot\_id** – идентификационный номер (ID) чат-бота, который будет активирован данной кнопкой (в данном случае должен быть выбран чат-бот с названием _«Чат-бот поддержки»_);
*   **btn** – данные, характеризующие кнопку:
    *   **show\_icon** – флажок, определяющий видимость кнопки на портале;
    *   **text** – надпись на кнопке;
    *   **title** – надпись, которая отображается при наведении курсора на кнопку на портале.

Примечание – Если значения аналогичных переменных в карточках шаблона и элемента шаблона различаются, то приоритет имеют значения переменных элемента шаблона.

В разделе **Код** на карточке настраиваемого web-шаблона кнопки для чат-бота приведен программный код, определяющий работу кнопки.

Разработчикам пользовательских чат-ботов рекомендуется изучить открытый код настраиваемого web-шаблона, который при необходимости можно откорректировать.

Данный программный код состоит из трех частей:  
\- настройка стилей <style> ... </style> с использованием языка CSS;  
\- настройка кнопки <button> ... </button>;  
\- скрипт активации чат-бота <script> ... </script> с использованием языка JavaScript, библиотеки jQuery и системы технологий AJAX.

Примечание – Обратите внимание на фрагмент программного кода:  
_window.location.href = '/chat/default.html?conversation\_id=' + oData.data.conversation\_id;_  
Здесь _oData__.__data__.__conversation__\___id_ – это выражение, позволяющее определить значение ID разговора чат-бота.  
При необходимости данное выражение разработчик может использовать в своем программном коде.
