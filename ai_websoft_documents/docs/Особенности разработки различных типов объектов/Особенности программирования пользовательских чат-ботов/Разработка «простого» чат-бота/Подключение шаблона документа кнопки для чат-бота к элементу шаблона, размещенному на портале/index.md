## Подключение шаблона документа кнопки для чат-бота к элементу шаблона, размещенному на портале

Для подключения настраиваемого web-шаблона (шаблона документа) кнопки для чат-бота к элементу шаблона выполните следующие действия:

1.  Откройте в программе _WebTutor_ _Administrator_ карточку элемента шаблона кнопки для чат-бота (карточка находится в разделе **Дизайнер – Шаблоны – Шаблоны документов – Элементы шаблонов**).
2.  Нажмите на кнопку  справа от поля **Шаблон**:
    
3.  В открывшемся окне **Выбор объекта** выберите нужный шаблон кнопки для чат-бота:
    
    .
    
4.  Нажмите на кнопку **Применить**.
5.  Сохраните карточку элемента шаблона кнопки для чат-бота в программе _WebTutor_ _Administrator_.
