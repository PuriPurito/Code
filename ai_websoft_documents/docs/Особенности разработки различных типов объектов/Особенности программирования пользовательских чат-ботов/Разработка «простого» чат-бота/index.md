## Разработка «простого» чат-бота

Разработку чат-бота удобно производить «сверху вниз» - от элементов более высокого уровня к элементам более низкого уровня. Установление связи между элементами также производится «сверху вниз». Поэтому, создав элемент более низкого уровня, разработчик возвращается к элементу более высокого уровня для формирования связи между этими элементами.

Для создания и настройки простого чат-бота используются следующие элементы и составные части:

1.  Элементы шаблона (для старых версий WebSoft HCM).
2.  Шаблоны документа (настраиваемые шаблоны, Web-шаблоны). 
3.  Собственно чат-бот.
4.  Этапы чат-бота. 
5.  Язык разметки для искусственного интеллекта AIML (Artificial Intelligence Markup Language).

Примерный порядок создания чат-бота (от элементов более высокого уровня к элементам более низкого уровня) следующий:

1.  Формируется и настраивается карточка чат-бота.
2.  Формируется начальный этап чат-бота, который необходимо подключить к чат-боту. За начальным этапом чат-бота, при необходимости, могут следовать и другие этапы. Они формируюются аналогично начальному.
3.  Для каждого этапа формируется настраиваемый шаблон, который необходимо указать в карточке этапа.
4.  Для настраиваемого шаблона каждого этапа чат-бота (в том числе и для начального этапа) заполняется вкладка «Код». На вкладке «Код» может быть записана программа реализации этапа. Для записи программы обычно используется относительно несложный язык разметки для искусственного интеллекта AIML (Artificial Intelligence Markup Language). 

В качестве примера реализации простого чат-бота и кода на языке AIML можно взять "Чат-бот AIML".

После создания чат-бота в актуальных версиях нового интерфейса WebSoft HCM он может быть привязан к разговору.

Для старых версий системы для размещения чат-бота используется следующий алгоритм.

1.  Создайте и настройте кнопку для чат-бота и разместите ее на портале. Для этого формируются элемент шаблона кнопки и шаблон документа кнопки кнопки. К элементу шаблона кнопки подключается шаблон документа кнопки.
2.  Подключите шаблон документа кнопки для чат-бота к элементу шаблона кнопки.
3.  Затем к шаблону документа кнопки подключите собственно чат-бот. Подробнее **подключение чат-бота к элементу шаблона кнопки**.

Если у вас в системе WebTutor отсутствует программный модуль «Чат-бот», установите демо-версию модуля (пакеты с примером чат-бота технической поддержки, включающий в себя демо-версию модуля «Чат-бот» можно скачать в разделе Открытые компоненты софта). Данный пакет устанавливается в системе стандартным способом.
