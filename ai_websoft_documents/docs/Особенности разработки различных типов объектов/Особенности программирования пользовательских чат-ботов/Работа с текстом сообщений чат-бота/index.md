## Работа с текстом сообщений чат-бота

Для администраторов чат-ботов особый интерес представляет работа с текстом сообщений. Тексты сообщений могут быть впоследствии использованы для различных целей (загрузка информации в корпоративную CRM, передача данных менеджерам по работе с клиентами, исследование аналитики и т.д.).

Тексты сообщений чат-бота доступны в программе _Websoft HCM Administrator_ в разделе **Чат-боты – Чаты – Блок сообщений**.

Для просмотра текста сообщений конкретного чат-бота выполните следующие действия:

1.  Откройте в программе _Websoft HCM Administrator_ указанный выше раздел **Блок сообщений**. 
2.  Найдите блоки сообщений нужного чат-бота.
    
    В указанном разделе каждому чат-боту соответствуют две строки – со статусом **Открыт** и со статусом **Закрыт**.
    
    Текст переписки пользователя с чат-ботом можно увидеть на карточке соответствующего блока сообщений со статусом **Открыт**.
    
3.  Откройте карточку блока сообщений со статусом **Открыт**.
    
    Тексты сообщений данного чат-бота приводятся на вкладке **Сообщения**:
    
    Тексты сообщений данного чат-ботов можно получить также программным способом. Они хранятся в системе на карточках документа **Блок сообщений**.
    
    Получить доступ к карточке документа **Блок сообщений** можно с помощью запроса к каталогу _block\_message_.
    

Приведем пример программного кода агента, позволяющего получить информацию о текстах сообщений, связанных с конкретным пользователем:

// Введем полное имя пользователя, использовавшего чат-бот (допустим его зовут Иванов Иван Иванович,  
// и его учетная запись имеется в системе и уникальна по полному имени (fullname), то есть в системе нет другой учетной записи с полным именем Иванов Иван Иванович)  
sFullname = 'Иванов Иван Иванович';

// Находим все блоки сообщений со статусом 'active' («Открыт»)  
objArray = XQuery("for $elem in block\_messages where $elem/state\_id = 'active' return $elem");

for(q in objArray)  
{  
     oDoc = OpenDoc(UrlFromDocID(Int(q.id))).TopElem;  
     // UrlFromDocID – определение URL по ID объекта (пример ID объекта: 6148914691236517121)  
     // OpenDoc – открытие XML-документа по URL (например, x-local://wt\_data/objects/4976E9DE7B2276/63.xml) и возвращение ссылки на объект  
     // TopElem – переход от документа к корневому объекту документа.

     // Определяем программно идентификационный номер сотрудника, использовавшего чат-бот.  
     sID = ArrayOptFirstElem ( oDoc.recipient\_id );  
     // Находим объект Сотрудник с идентификационным номером sID с помощью функции tools.get\_doc\_by\_key  
     oCollab = tools.get\_doc\_by\_key ( 'collaborator', 'id', sID );  
     // Полное имя найденного сотрудника может быть определено так: oCollab.TopElem.fullname

     if ( oCollab.TopElem.fullname == sFullname) // вывод на экран всех сообщений разговоров сотрудника Иванова И.И. с чат-ботом "Чат-бот поддержки"  
     {  
          arrMessages = oDoc.messages;  
          // массив сообщений чат-бота

           sRes = 'Сообщения чат-бота ' + oDoc.object\_name + ' от ' + oDoc.last\_message\_date + ' (сотрудник - ' +  oCollab.TopElem.fullname +'): \\n\\n\\n';  
           for(m in arrMessages)  
           {  
                 sRes = sRes + m.text + '\\n\\n';  
           }

           alert(sRes);  
     }  
}
