## Нюансы и прочие соглашения

Изменение темы разговора возможно с помощью указания в <set> имени topic, значение <set> будет выбрано в качестве темы разговора.  
Например:

_<template>  
    <set name="topic">movies</set>  
</template>_

В результате тема разговора переключается на паттерн _movies_.

Изменение этапа чат бота возможно с помощью указания в <set> имени stage, значение <set> будет выбрано в качестве этапа чат-бота.  
Например:

_<template>  
    <set name="stage">greeting</set>  
</template>_

В результате чат-бота переключается на этап _greeting_.

Переменные чат-бота должны быть записаны в карточке Чат-бота, тогда их можно будет использовать внутри AIML,  
Например:

_<template>  
    Меня зовут <bot name="botname"/>.  
</template>_

Теперь, если, например, на вкладке **Настройки** карточки чат-бота была задана переменная _botname_ со значением 'Ботяня':

то указанный шаблон будет выдавать ответ:

_Меня зовут Ботяня._

Важно: Менять значения переменных бота средствами кода AIML нельзя.

Для реализации кода AIML особое значение имеют файлы _parser.js_ и _interpreter.js._ Эти файлы находятся в папке _/wtv/aiml_. В частности, в них используется переменная _bDebugMode_, которая включает запись логов (false – логирование выключено, true – логирование включено). Значение переменной _bDebugMode_ задается в файлах _parser.js_ и _interpreter.js._

Предупреждение - Не рекомендуется постоянно устанавливать для переменной _bDebugMode_ значением true (особенно в файле _interpreter.js_), так как логирование происходит очень долго. Такое логирование используется по необходимости в процессе разработки или при малом количестве перезагрузок шаблонов AIML.
