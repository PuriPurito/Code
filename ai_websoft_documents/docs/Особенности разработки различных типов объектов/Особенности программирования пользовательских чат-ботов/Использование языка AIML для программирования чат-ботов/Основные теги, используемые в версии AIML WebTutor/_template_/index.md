## <template>

Тег _<template>_ определяет ответ бота на действие пользователя, соответствующее образцу _<pattern>_.

Алгоритм выполнения блока информации является следующим:

1) Пользователь производит некоторое действие (вводит текст, нажимает на кнопку и т.д.).

2) Программа сравнивает указанное действие с условиями шаблона _<pattern>_.  
Если действие пользователя соответствует паттерну блока информации, то блок информации выполняется (чат-бот выполняет код, помещенный в теге _<template>_).  
В противном случае программа переходит к рассмотрению следующего блока информации.

Например, имеется следующий блок информации:

<category>  
    <pattern>Какое ваше имя</pattern>  
    <template>Моё имя - Олег</template>  
</category>

Если пользователь ввел выражение «_Какое ваше имя_», то выполняется данный блок, паттерн которого соответствует запросу пользователя, и в окне чат-бота печатается фраза, содержащаяся в теге _<template>_: «_Моё имя - Олег_»:

**Примечание** -  Внутри тега _<template>_ могут применяться теги HTML.
