## <request>

Тег _<request>_ повторяет одно из предыдущих действий пользователя (запросов, данных, введенных пользователем).

Например, имеется следующий блок информации:

<category>  
     <pattern>ПОВТОРИ МОЙ ЗАПРОС</pattern>  
     <template><request index="1" /></template>  
</category>

_Запрос: Привет  
Ответ: Привет, Иван!_

_Input: Повтори мой запрос  
Output: Привет_
