## <set>

Тег _<set>_ используется для установки значения локальной переменной, которое можно впоследствии получить с помощью тега <get>.

Например, имеются следующие два блока информации:

<category>  
     <pattern>Мне \* лет</pattern>  
     <template>  
          Я понял, Вам <set name="age"><star /></set> лет.  
     </template>  
</category>  
  
<category>  
     <pattern>Сколько мне лет</pattern>  
     <template>Вам <get name="age" /> лет.</template>  
</category>

Если пользователь введет выражение «_Мне 30 лет_», то в локальную переменную _age_ с помощью тега _<set>_ записывается значение, соответствующее символу «звездочка» (30).

Во втором блоке программа находит соответствующее значение переменной _ag__e_ и выводит в окне чат-бота фразу, указанную в шаблоне _<template>_: «_Вам 30 лет_»:
