## <bot>

Тег _<bot>_ используется для вызова пользовательских свойств бота.

Например: 

<category>  
    <pattern> КАК ТЕБЯ ЗОВУТ? </pattern>  
    <template>Меня зовут <bot name="botname"/>.</template>  
</category>

Пользовательские свойства (значения переменных) бота могут быть указаны на вкладке **Настройки** карточки чат-бота:
