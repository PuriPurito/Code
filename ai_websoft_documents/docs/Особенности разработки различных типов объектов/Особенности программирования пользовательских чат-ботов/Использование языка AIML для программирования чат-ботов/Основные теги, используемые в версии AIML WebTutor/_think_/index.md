## <think>

Тег _<think>_ устанавливает значение переменной без отображения пользователю содержимого тега _<set>_.

Например, имеется следующий блок информации:

<category>  
     <pattern>Меня зовут \*</pattern>  
     <template>  
            <think><set name="name"></set></think>  
            Я запомнил Ваше имя.  
     </template>  
</category>

В этом примере программа запоминает имя, введенное пользователем, но не выводит его в окно чат-бота.

Если же используется только тег _<star>_, то в ответе чат-бота имя пользователя будет выведено имя:

<category>  
     <pattern>Меня зовут \*</pattern>  
     <template>  
          Привет, <set name="name"><star /></set>!  
     </template>  
</category>
