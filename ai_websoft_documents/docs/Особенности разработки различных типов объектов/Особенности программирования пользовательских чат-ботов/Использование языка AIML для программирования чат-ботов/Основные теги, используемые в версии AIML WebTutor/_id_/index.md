## <id>

Тег _<id>_ выводит ID чат-бота.

Например, имеется следующий блок информации:

<category>  
    <pattern>Сообщи ID</pattern>  
    <template>  
          <id/>  
    </template>  
</category>

Если пользователь введет выражение «_Сообщи ID_», то программа напечатает в окне чат-бота его ID:
