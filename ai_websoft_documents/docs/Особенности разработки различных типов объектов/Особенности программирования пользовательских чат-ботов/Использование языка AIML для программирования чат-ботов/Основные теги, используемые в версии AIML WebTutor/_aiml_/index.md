## <aiml>

_<aiml>_ является верхнеуровневым тегом, определяющим начало и конец кода AIML.

Пример использования тега _<aiml>_ в языке AIML 2.0:

<?xml version="1.0" encoding="UTF-8"?>  
<aiml version="2.0">  
     <!-- Здесь вводится код AIML -->  
</aiml>

Внимание! В системе WebTutor на вкладке **Код** карточки настраиваемого шаблона чат-бота вводится код AIML в формате xml без верхнеуровнего тега <aiml>.
