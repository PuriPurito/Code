## <li>

Тег _<li>_ задает элемент списка.

Например, имеется следующий блок информации:

<category>  
    <pattern> КАК ДЕЛА </pattern>  
    <template>  
        <random>  
            <li>Всё хорошо!</li>  
            <li>Вроде нормально.</li>  
            <li>Всё плохо...</li>  
        </random>  
    </template>  
</category>

В данном случае программа отвечает на запрос пользователя «Как дела», выбирая случайным образом с помощью тега _<random>_ значения из списка, элементы которого заданы тегом _<li>_.
