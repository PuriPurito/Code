## <star>

Тег _<star>_ используется для выделения из запроса пользователя значений, которые были определены подстановочным знаком «звездочка» (\*).

Если в теге _<pattern>_ указывается несколько символов \*, то выделяемые значения можно идентифицировать с помощью параметра _index_.

Первое значение может идентифицироваться выражением _<star />_ или _<star index="1" />_, второе значение - _<star index="2" />_ и т.д.

Например, имеется следующий блок информации:

<category>  
     <pattern>Мое имя - \*, фамилия - \*</pattern>  
     <template>Вас зовут <star index="2" /> <star /> </template>  
</category>

В следующем примере пользователь вводит выражение: "_Мое имя - Иван, фамилия - Иванов_". Первое значение, выделенное из запроса – «_Иван_», второе значение – «_Иванов_». В ответе чат-бота эти значения меняются местами:
