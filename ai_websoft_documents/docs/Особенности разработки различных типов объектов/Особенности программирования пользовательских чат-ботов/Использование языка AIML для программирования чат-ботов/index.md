## Использование языка AIML для программирования чат-ботов

Для разработки «простых» чат-ботов в системе используется специализированная версия _языка разметки для искусственного интеллекта AIML (Artificial Intelligence Markup Language)_, адаптированная программистами компании WebSoft.

В работе чат-ботов в системе используется следующая принципиальный технологический процесс:

1.  Пользователь активирует чат-бот.
2.  Чат-бот открывается и при необходимости может вывести первоначальное сообщение. Это сообщение может содержать форматированный текст, кнопки и т.д.
3.  Пользователь выполняет в области чат-бота некоторые действия ( _`Input`_ ) (вводит текст, нажимает на кнопку и т.д.).
4.  Чат-бот автоматически формирует ответ на действия пользователя ( _`Output`_ ).
5.  Пользователь может выполнить новые действия в области чат-бота.
6.  Чат-бот формирует новый ответ на действия пользователя и т.д.
7.  При определенных условиях пользователь или чат-бот могут вызвать завершение работы чат-бота.

Указанный процесс может быть реализован в чат-ботах с помощью программного кода AIML.
