## Настройка в Websoft HCM Administrator

В разделе **Этапы чат-ботов** (**Чат-боты - Чат-бот - Этапы чат-ботов**) создается новый этап. В поле **Тип обработки** необходимо выбрать пункт **AIML**, а в поле **Настраиваемый шаблон** указывается настраиваемый шаблон, в котором будет находиться соответствующий код AIML. Подробнее – см. статью «Формирование начального этапа чат-бота».

Затем в разделе **Настраиваемый шаблон для чат-ботов** (**Чат-боты - Чат-бот - Настраиваемый шаблон для чат-ботов**) можно создать новый настраиваемый шаблон. В поле **Тип результата** необходимо указать пункт **AIML**, а на вкладке **Код** ввести соответствующий код AIML в формате xml без верхнеуровнего тега <aiml>. 

Если в составе _<pattern>_ используется тег _<set>_, необходимо в разделе **Настраиваемый шаблон для чат-ботов** (**Чат-боты - Чат-бот - Настраиваемый шаблон для чат-ботов**) создать настраиваемый шаблон для чат-ботов с типом SET и кодом, соответствующим значению _<set>_ в _<pattern>_.

Например, для корректной работы следующего паттерна:

_<__pattern>  
    Как тебе <__set__\>__cities__</__set>?  
</pattern>_

в разделе **Настраиваемый шаблон для чат-ботов** должен быть создан настраиваемый шаблон с типом результата **SET** и кодом **cities**.

Код шаблона должен содержать возможные значения, разделённые переводом строки, например:

_Москва  
Санкт-Петербург  
Тула_

Для того, чтобы бот работал, необходимо подключить шаблон к этапу с типом результата AIML.
