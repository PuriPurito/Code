## Особенности реализации и поддержки языка AIML в системе

Для программирования чат-ботов в системе реализована поддержка AIML версий AIML 1.0 и частично AIML 2.0. Логика работы тегов в целом соответствует требованиям версии AIML 2.0, но также добавлена возможность вложения тегов друг в друга.

Поддерживаются следующие теги языка AIML (теги перечислены по алфавиту):

*   _<__aiml__\>_ - определяет начало и конец кода AIML.
*   _<__bot__\>_ - используется для вызова пользовательских свойств бота.
*   _<__button__\>_ - содержимое тега конвертируется в кнопку.
*   _<__category__\>_ - формирует категорию, блок информации.
*   _<__condition__\>_ - производит ветвление процесса исполнения кода (соответствует оператору _switch_ в языках программирования).
*   _<__explode__\>_ - разделяет слово по буквам.
*   _<__formal__\>_ - приводит первые буквы слов к верхнему регистру, остальные к нижнему.
*   _<__get__\>_ - используется для получения значения из переменной.
*   _<__id__\>_ - выводит ID чат-бота.
*   _<__input__\>_ - повторяет действие пользователя.
*   _<__item__\>_ - формирует элемент маркированного или нумерованного списка (соответствует тегу <li>).
*   _<__javascript__\>_ - вложенный код на языке JavaScript.
*   _<__li__\>_ - задает элемент списка в нумерованных или маркированных списках.
*   _<__link__\>_ - содержимое тега конвертируется в кнопку.
*   _<__list__\>_ - формирует маркированный список (соответствует тегу _<__ul__\>_).
*   _<__lowercase__\>_ - приводит буквы к нижнему регистру.
*   _<__olist__\>_ - формирует нумерованный список (соответствует тегу _<__ol__\>_).
*   _<__pattern__\>_ - определяет паттерн - образец для сравнения с действием, выполненным пользователем (с данными, введенными пользователем).
*   <postback> - код, который будет отправлен на сервер для поиска ответа по нажатию кнопки, если ответ отсутствует, то отправляет значение _<__text__\>_ (используется внутри тегов _<link>, <button>, <reply>_).
*   _<__program__\>_ - выводит версию интерпретатора.
*   _<__random__\>_ - производит случайный выбор из списка.
*   _<__reply__\>_ - содержимое тега конвертируется в кнопку.
*   _<__request__\>_ - повторяет одно из предыдущих действий пользователя (данных, введенных пользователем).
*   _<__response__\>_ - повторяет один из предыдущих ответов бота.
*   _<__sentence__\>_ - приводит первую букву первого слова к верхнему регистру.
*   _<__set__\>_ - используется для установки значения в переменной.
*   _<__size__\>_ - выводит количество блоков информации _<__category__\>_, хранящихся в памяти.
*   _<__sr__\>_ - сокращенная версия тега _<srai><star /></srai>_.
*   _<split>_ - разделяет ответ чат-бота на несколько отдельных сообщений.
*   _<__srai__\>_ - перенаправляет исполнение кода AIML на блок информации с <pattern>, определенный текстовым значением внутри тегов _<__srai__\>_.
*   _<__star__\>_ - используется для обработки действий пользователя (данных, введенных пользователем), которые были определены подстановочным знаком «звездочка» (\*).
*   _<__template__\>_ - определяет ответ бота на действие пользователя, соответствующее образцу _<pattern>_.
*   _<__text__\>_ - текст кнопки (используется внутри тегов _<link>, <button>, <reply>_).
*   _<__that__\>_ - используется для уточнения контекста паттерна _<__pattern__\>_ (например, уточняет, на какой вопрос пользователь ответил «Да» или «Нет»).
*   _<__thatstar__\>_ - используется для обработки действий пользователя (данных, введенных пользователем), которые были определены подстановочным знаком «звездочка» (\*) внутри тега _<that>_.
*   _<__think__\>_ - устанавливает значение переменной без отображения пользователю содержимого тега <set>.
*   _<__topic__\>_ - используется для уточнения контекста блока информации _<category>_ (например, уточняет условие, при котором бот задействует тот или иной блок информации в зависимости от предыдущих действий пользователя (данных, введенных пользователем)).
*   _<__uppercase__\>_ - приводит буквы к верхнему регистру.
*   _<__url__\>_ - URL для перехода по нажатию кнопки (используется внутри тегов <link>, <button>, <reply>).

Примечание - Внутри тегов _<template>_ поддерживаются стандартные теги языка HTML: _<i>, <u>, <b>, <br>, <a>, <img>_.

Далее будут рассмотрены на примерах основные теги версии AIML, используемой в системе для программирования чат-ботов.
