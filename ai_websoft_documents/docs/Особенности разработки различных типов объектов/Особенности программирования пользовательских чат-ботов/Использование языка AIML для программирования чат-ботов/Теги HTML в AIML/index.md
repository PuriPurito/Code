## Теги HTML в AIML

Для использования в AIML стандартных тегов языка HTML (<i>, <u>, <b>, <br>, <a>, <img>) используется тег <template>.

Например:

<category>  
    <pattern>HTML</pattern>  
    <template>  
          Поддерживаются стандартные теги языка HTML: <br/>  
          <i>курсив</i> <br/>  
          <u>подчеркнутый шрифт</u> <br/>  
          <b>полужирный шрифт</b> <br/>  
          новая строка: ,<br/>  
          <a href="/view\_doc.html?mode=requests\_hd">ссылка</a> ,<br/>  
          изображение:  
          <img src="/Learn\_AIML.png"></img>   
          <img src="https://upload.wikimedia.org/wikipedia/commons/thumb/6/61/HTML5\_logo\_and\_wordmark.svg/220px-HTML5\_logo\_and\_wordmark.svg.png"></img>  
     </template>  
</category>

  
Примечание - Для размещения изображения (картинки) в чат-боте необходимо указывать либо абсолютные ссылки, либо ссылки на файлы относительно хоста.  
Если изображение размещается в системе, то его нужно скопировать в папку _WebTutorServer/wt/web/_.  
В этом случае для вывода изображения в чат-бот нужно использовать относительный путь _/<название\_файла>_.  
Например, если файл с карртинкой называется _Learn\_AIML.png_, то в коде AIML нужно записать следующее выражение:  
_<img src="/Learn\_AIML.png"></img>_ 

**Внимание!** Ошибка в использовании тегов (например, отсутствие закрывающего тега) внутри шаблона _<template>_ может вызвать отказ функционирования чат-бота (в частности, отказ перезагрузки AIML-шаблона с помощью команды RELOAD\_AIML).

В разделе **Файлы** размещен текстовый файл тегов AIML для демонстрационной версии чат-бота (от 04.2022) из **Открытых компонентов софта**.
