## Особенности работы с тегом <javascript>

Внутри тега допустимо использовать любой код _JavaScript (BorisScript)_.

На данный момент изнутри тега доступны все функции и переменные из файла interpreter.js, однако рекомендуется использовать только следующие переменные:  
**AIML\_USER\_INPUT, AIML\_CUR\_CHAT\_ID, AIML\_WILD\_CARDS, AIML\_THAT\_WILD\_CARDS, AIML\_INPUTS, AIML\_REQUESTS, AIML\_RESPONSES, AIML\_DATA, AIML\_VARIABLES, AIML\_BOT, AIML\_PREVIOUS\_ANSWER, AIML\_TOPIC, AIML\_CUR\_USER\_ID**.

Итоговый текст ответа необходимо записывать в переменную **_RESULT\_TEXT_**. Ответы бота передаются в чат в том формате, в котором они формируются, они могут содержать полноценный HTML-код.

Предупреждение - Внутри тега _<javascript>_, в данный момент, не поддерживаются строчные комментарии (//), блочные комментарии (/\* \*/) поддерживаются.

Внимание! Все полученные от пользователя вопросы необходимо самостоятельно проверять в коде на предмет попыток взлома.

Пример использования тега _<javascript>_ будет рассмотрен в статье «Особенности создания «сложного» чат-бота».
