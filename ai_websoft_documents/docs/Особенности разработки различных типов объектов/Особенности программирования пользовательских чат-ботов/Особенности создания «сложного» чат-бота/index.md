## Особенности создания «сложного» чат-бота

_«Сложным» чат-ботом_ мы называем такой чат-бот, работа которого не может быть описана средствами языка AIML и требует использования программирования на языке _JavaScript_ и др. программных средств. В настоящее время для разработки сложных чат-ботов рекомендуется использовать язык программирования _JavaScript_.

Для использования программного кода JavaScript в чат-ботах применяется тег _<javascript>_.  
Приведем пример:

<category>  
    <pattern> ПРИВЕТ </pattern>  
    <template>  
        <javascript>  
            docUser = tools.open\_doc(curUserID);  
            teUser = docUser.TopElem;  
            fnSetStoredVariable('has\_username', true);  
            fnSetStoredVariable('username', teUser.firstname);  
            RESULT\_TEXT = 'Привет, ' + teUser.firstname + '!';  
        </javascript>  
    </template>  
</category>

Данный информационный блок работает следующим образом (обратите внимание, что имя текущего пользователя, от учетной записи которого выполняется запрос, - _Иван_; этого пользователя зовут _Иванов Иван Иванович_):

Рассмотрим подробнее код, содержащийся в теге <javascript> в приведенном выше примере (код JavaScript выделен жирным шрифтом):

**docUser = tools.open\_doc(curUserID);**  
// открывается документ текущего пользователя по ID пользователя; curUserID - идентификатор объекта текущего пользователя  
  
**teUser = docUser.TopElem;**  
// получение корневого элемента в документе  
  
**fnSetStoredVariable('has\_username', true);**  
// использование встроенной функции присвоения значения переменной _has\_username_ (данная переменная используется в других информационных блоках)  
  
**fnSetStoredVariable('username', teUser.firstname);**  
// присвоение значения имени текущего пользователя переменной _username_ (данная переменная используется в других информационных блоках)  
  
**RESULT\_TEXT = 'Привет, ' + teUser.firstname + '!';**  
// итоговый текст ответа записывается в переменную RESULT\_TEXT (подробнее см. здесь); из этой переменной текст выводится в окно чат-бота

Примечание - Программный код размещается в настраиваемых шаблонах чат-бота, в которых применимы глобальные переменные веб-шаблонов).
