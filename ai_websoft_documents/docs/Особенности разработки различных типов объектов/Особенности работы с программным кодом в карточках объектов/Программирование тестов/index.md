## Программирование тестов

Система позволяет задать произвольный программный код, который будет выполняться перед завершением теста. Сделать это можно в карточке теста.

Программный код, который вводится в этой карточке, выполняется на сервере. Он может быть использован для статистической или аналитической обработки текущего полученного результата.

Вместо данного кода можно использовать инструмент "**Системные события**" ("**Дизайнер** **\->** **Бизнес-логика –> Системные события**"), объект "**Завершение теста**". Системное событие (в отличие от программного кода, выполняемого при завершении теста) выполняется после завершения теста, когда завершение теста уже произошло.

Код выполняется в специальном окружении, в нем доступны только следующие объекты:

*   _docLearning_ - Doc документа текущего завершенного теста,
*   _assessmentDoc_ - TopElem документа текущего теста.
*   _activeLearningDoc_ – TopElem документа текущего незавершенного теста

В случае ввода в указанное поле некорректного кода, завершающегося ошибкой с прерыванием выполнения операции, система WebTutor выдает сообщение об ошибке, и завершения теста не производится.

Пример программного кода, выполняемого при завершении теста:

alert ("Завершен тест с ID = " + docLearning.DocID);
