## Программирование типов задач

Система позволяет указать код формирования URL для перехода в задачу для различных типов задач проекта. Сделать это можно в карточке типа задачи на вкладке «**Настройки**».  
Код типа задачи формирует адрес перехода к карточке задачи.

Код выполняется в специальном окружении и доступны только следующие объекты:  
**catElem** – элемент XQuery для задачи.

Пример кода формирования URL для перехода в задачу:

"view\_doc.html?mode=task&object\_id="+catElem.id

Подробнее особенности формирования кода типа задачи будут описаны позднее.
