## Программирование процедур опроса

Система позволяет указать программный код для различных процедур опроса. Сделать это можно в карточке процедуры опроса   на вкладке «**Дополнительно**».

В частности, могут быть заданы три типа программного кода: 

*   агент, запускаемый из панели инструментов процедуры, 
*   дополнительная обработка при создании опросного листа, 
*   условие показа анкет в процедуре оценки.

Подробнее особенности формирования кода процедуры опроса будут описаны позднее.
