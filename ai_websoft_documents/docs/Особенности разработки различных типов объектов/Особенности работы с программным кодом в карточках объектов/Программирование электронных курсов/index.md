## Программирование электронных курсов

Система позволяет задать правила обработки данных для адаптивной и динамической структур курса. Сделать это можно в карточке курса.

  
Адаптивная структура курса означает, что список разделов курса не задан жестко, а формируется программным кодом по некоторому алгоритму в момент назначения курса.  
Динамическая структура курса аналогична адаптивной структуре, но список разделов курса для конкретного сотрудника пересчитывается по мере прохождения курса (иначе говоря, алгоритм срабатывает при первом запросе на прохождение курса и каждый раз при переходе к следующему разделу).  
  
Программный код, который задается в этой карточке, выполняется на сервере.   
  
Программный код алгоритмов формирования адаптивной и динамической структур курса задается в файле библиотеки функций, адрес которого указывается в поле «**Ссылка на файл библиотеки функций**».  
Файл библиотеки функций рекомендуется размещать в директории сервера, в папке курса.   
Пример указания адреса файла библиотеки в поле «**Ссылка на файл библиотеки функций**»:  
_x-local://wt/web/webtutor/sm207/course\_lib.js_

Библиотека функций представляет собой обычный текстовый файл со стандартным расширением _js_, содержащий код функций.

Для создания алгоритма адаптивной структуры курса в файле библиотеке должна присутствовать функция «_GetCourseParts_» с параметром-объектом «_oParams_», имеющим свойства «_teCourse_» (документ курса) и «_teActiveLearning_» (документ текущего назначаемого обучения).

Функция «_GetCourseParts_» должна вернуть объект со свойством «_parts_», представляющим собой массив XML-элементов списка модулей незаконченного курса.

Пример – в курсе имеется 3 модуля, один общий (третий, с индексом 2), а два других (первый и второй, соответственно с индексами 0 и 1) – разные для сотрудников головного офиса и филиалов. Задача – сделать так, чтобы каждый сотрудник прошел два модуля (специфический и общий). Принадлежность к филиалу определяется кодом организации сотрудника («_filial_»).  
Файл может содержать следующий программный код:

function GetCourseParts( oParams )  
{  
      teCourse = oParams.teCourse;  
      teActiveLearning = oParams.teActiveLearning;  
      \_res = { };  
      \_res.parts = teCourse.parts  
      \_person\_org\_code = teActiveLearning.person\_id.ForeignElem.org\_id.ForeignElem.code; // определяем код организации сотрудника  
      If ( \_person\_org\_code == "filial" )  
      {  
            \_res.parts = ArraySelect( teCourse.parts, "This.ChildIndex\==0 || This.ChildIndex==2" ); // для филиала оставляет первый и третий модуль  
      }  
      else  
      {  
            \_res.parts = ArraySelect( teCourse.parts, "This.ChildIndex==1 || This.ChildIndex==2" ); // для головного офиса – второй и третий  
      }  
      return \_res;  
}

  
Для создания алгоритма динамической структуры курса в файле библиотеке должна присутствовать функция «_GetLearningStructure_» с параметром-объектом «_oParams_», имеющим свойства «_sAction_» (код вызывающей операции), «_teCourse_» (документ курса), «_teActiveLearning_» (документ текущего назначаемого обучения).   
Код вызывающей операции «sAction» может принимать следующие значения: 

*   «_wt\_get\_structure_» – операция вызывается при получении структуры курса (при открытии плеера курсов); 
*   «_wt\_skip_» – операция вызывается при запросе следующего модуля (по кнопкам «**Начать обучение**» или «**Далее**» в плеере курсов).

Функция «_GetLearningStructure_» должна вернуть объект со свойствами «_structure_» (структура курса для плеера курсов) и «_parts_» (массив модулей для карточки незаконченного обучения).

Результирующая структура «structure» должна соответствовать форме описания данных _wtv\_form\_course\_structure.xmd_ (то есть карточке электронного курса с набором дополнительных параметров – команд и атрибутов для плеера курсов).

Пример – первым модулем курса с динамической структурой является тест, по результатам которого определяется, к какому модулю далее переходит сотрудник. Если сотрудник набрал от 10 до 19 баллов, то он изучает только второй модуль, а если более 20 баллов – то второй и третий. Если же сотрудник набрал менее 10 баллов по первому тесту, то ему снова предъявляется тот же тест.  
Итак, данный курс включает в себя 3 модуля – тест (индекс модуля равен 0), второй модуль (индекс модуля равен 1) и третий модуль (индекс модуля равен 2).

Файл может содержать следующий программный код:

function GetLearningStructure( oParams )  
{  
      sAction = oParams.sAction;  
      teCourse = oParams.teCourse;  
      teActiveLearning = oParams.teActiveLearning;  
      \_res = { };  
      \_res.parts = teActiveLearning.parts; // по условиям примера – структуру модулей мы не меняем  
      \_res.structure = OpenNewDoc( 'x-local://wtv/wtv\_form\_course\_structure.xmd' ).TopElem; // создаем базовую структуру (заготовку)  
      \_res.structure.AssignElem( teCourse ); // наполняем структуру данными курса  
      \_res.structure.AssignElem( teActiveLearning ); // дополняем/изменяем структуру данными текущего обучения (пользователь, статус пройденных элементов)  
      \_max\_module = 0; // начальное значение – номер модуля, который разрешаем открывать/запускать  
      for ( \_part in \_res.sctucture.parts ) // цикл по всем модулям незаконченного курса  
      {  
            if ( \_part.ChildIndex == 0 ) // первый модуль – тест  
            {  
                  \_score = OptReal( \_part.score , 0); // результат теста, если есть, или 0, если тест не сдавался  
                  if ( \_score > 20 )  
                  {  
                        \_max\_module = 2; // если тест сдан на 20 и более баллов – можно запускать модули 1 и 2  
                  }  
                  else if ( \_score > 10 )  
                  {  
                        \_max\_module = 1; // если сдан на 10 и больше (но не больше 20) – то только модуль 1  
                  }  
                  else  
                  {  
                        \_max\_module = 0; // если меньше 10 – то только нулевой (тест)  
                  }  
            }  
            \_part.launchable = ( \_max\_module >= \_part.ChildIndex ) ; // признак – можно запускать или нет  
      }  
      return \_res;  
}

Файл библиотеки функций может содержать обе указанные выше функции или одну из них. Если в файле библиотеки имеются обе функции, то его можно использовать в курсах с разными настройками (и в адаптивном, и в динамическом).
