## Программирование результатов опросов

Система позволяет задать произвольный программный код, который будет выполняться перед завершением опроса. Сделать это можно в карточке опроса.

Внимание! Код выполняется до момента сохранения документа "Результат опроса" на сервере. Поэтому он не может отменить сохранение документа. Имеется только возможность изменить поля сохраняемого документа.

Программный код, который вводится в этой карточке, выполняется на сервере. Код, записываемый в данной карточке, предназначен для статистической или аналитической обработки текущего полученного результата (например, выведение средних показателей, вычисление категорий и прочих показателей, для быстрого построения отчетов в будущем).

В случае, если настроен показ вопросов одним списком, то результат опроса может еще не быть отображен в базе (при показе по одному вопросу результат сохранится после первого ответа).

Вместо данного кода можно использовать следующие объекты инструмента **Системные события** (**Дизайнер** – группа **Бизнес-логика – Системные события**):   
\- **Создание результата опроса** \- срабатывает при начале заполнения опроса (при входе в опрос с портала создаётся карточка результата опроса и срабатывает данное системное событие).  
\- **Заполнение результата опроса** \- срабатывает при завершении заполнения опроса.

Код выполняется в специальном окружении и доступны только следующие объекты:

*   _docPollResult_ - документ создаваемого результата опроса,
*   _tePoll_ - TopElem карточки опроса.

В случае ввода в указанное поле некорректного кода, завершающегося ошибкой с прерыванием выполнения операции, система WebTutor выдает сообщение об ошибке, и завершения опроса не производится.

Пример программного кода обработки результатов опроса: вычисление среднего значения по всем ответам с числовым типом данных и запись полученного результата в настраиваемое поле _overall_ документа результата:

\_overall = 0.0;  
\_count = 0;

for (qst in docPollResult.TopElem.questions)  
{  
     \_pq = ArrayOptFind (tePoll.questions, "This.id==" + CodeLiteral (qst.id));  
     if (\_pq!=undefined)  
     {  
          If (\_pq.type == "number" && OptReal(qst.value)!=undefined)  
          {  
               \_overall += OptReal(qst.value);  
               \_count++;  
          }  
          else If (\_pq.type == "choice" || \_pq.type == "combo")  
          {  
               \_ent = ArrayOptFind (\_pq.entries, "This.id==" + CodeLiteral (qst.value));  
               If (\_ent! = undefined && OptReal (\_ent.value)!=undefined)  
               {  
                    \_overall += OptReal(\_ent.value);  
                    \_count++;  
               }  
          }  
     }  
}

If (\_count > 0)  
{  
     docPollResult.TopElem.custom\_elems.ObtainChildByKey ("overall").value = \_overall / Real(\_count);  
}

Другой возможный пример – подсчет количества отвеченных/неотвеченных вопросов и также запись их в некоторое дополнительное (настраиваемое) поле.
