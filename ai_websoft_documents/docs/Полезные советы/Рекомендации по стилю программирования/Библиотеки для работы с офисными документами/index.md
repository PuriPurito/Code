## Библиотеки для работы с офисными документами

• Используются компоненты _Aspose_   
• Документация доступна на news.websoft.ru 

Для работы с офисными документами используются следующие библиотеки:  
_• Websoft.Office.Word.dll  
• Websoft.Office.Excel.dll  
• Websoft.Office.Powerpoint.dll  
• Websoft.Office.Pdf.dll_

Использование библиотек:  
_var oPdf = tools.get\_object\_assembly(‘Pdf’); // Используется функция get\_object\_assembly
