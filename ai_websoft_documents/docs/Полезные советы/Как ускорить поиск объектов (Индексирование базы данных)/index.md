## Как ускорить поиск объектов (Индексирование базы данных)

Пользователи, наверное, замечали, что сразу после ввода данных, например, о сотруднике, часто они не могут сразу найти его в поиске в разделе **Сотрудники**.    
  
Лишь по истечению некоторого времени этот объект становится доступным в поиске.  
  
Для того, чтобы можно было выполнить поиск объекта должно быть произведено индексирование базы данных, которое выполняется агентом с кодом WT\_FT\_UPDATE.

Как видно из скриншота, в коробочном варианте данный агент по умолчанию запускается один раз в час. Но при необходимости администратор системы Websoft HCM может запустить внеочередное выполнение этого агента вручную.  
Запуск агента производится на стороне сервера (с помощью кнопки **Запустить агент**).  
За индексирование базы данных отвечает специальная функция **FTIndexDatabase** с аргументом **1**:

`ftIndexResult = tools.spxml_unibridge.Object.provider.FTIndexDatabase(1);`

После успешного выполнения данного агента администратор системы Websoft HCM может производить поиск недавно введенных в систему объектов.
