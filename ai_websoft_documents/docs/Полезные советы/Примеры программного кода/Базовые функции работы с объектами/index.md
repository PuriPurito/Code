## Базовые функции работы с объектами

1.  **OpenDoc - открыть объект по его URL.**
    
    Результат функции - структурированный объект со всеми данными объекта
    
    Пример:  
    _doc = OpenDoc(UrlFromDocID(4520064238755258808));_
    
    Функция UrlFromDocID строит URL объекта по его идентификатору
    
2.  **DeleteDoc (url) - удалить объект.**
    
    Пример:  
    _DeleteDoc(UrlFromDocID(4520064238755258808));_
    
3.  **OpenNewDoc(urlXMD) - создать новый объект.**
    
    y = OpenNewDoc('x-local://wtv/wtv\_collaborator.xmd');  
    y.BindToDb();
    
    Метод объекта BindToDb присваивает новому объекту идентификатор
    
    \*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*
    
    Атрибуты объекта:  
    \- _TopElem_ \- XML структура объекта  
    \- _Url_ \- URL объекта  
    \- _FormUrl_ \- URL типа (XMD) объекта  
    \- _DocID_ \- идентификатор объекта  
     
    
    Пример:  
    _doc = OpenDoc(UrlFromDocID(4520064238755258808));  
    // значение атрибута name объекта_  
    _n = doc.TopElem.name;  
    // идентификатор объекта  
    id = doc.DocID;  
    // изменяем атрибут объекта name  
    doc.TopElem.name = 'какое-то имя'  
    // удалим атрибут с именем desc  
    doc.TopElem.desc.Clear();  
    // сохраняем документ  
    doc.Save();_
    
    \*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*\*
    
    Если атрибут объекта является массивом, то добавить в него запись можно с помощью метода AddChild:
    
    Пример:  
    _// добавим функционального руководителя в карточку сотрудника  
    emp = OpenDoc(UrlFromDocID(4520064238755258808));  
    manager = emp.TopElem.func\_managers.AddChild();  
    manager.person\_id = '11111111111';  
    manager.person\_fullname = 'Boss name';  
    emp.Save();_
    
    Удалить элемент массива (атрибута):
    
    _emp.TopElem.func\_managers\[0\].Delete();_
