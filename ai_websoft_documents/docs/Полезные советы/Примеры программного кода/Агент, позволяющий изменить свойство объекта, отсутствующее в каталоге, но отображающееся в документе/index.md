## Агент, позволяющий изменить свойство объекта, отсутствующее в каталоге, но отображающееся в документе

Некоторые свойства объекта не отображаются в каталоге, но, тем не менее, их значения хранятся в документе.  
Например, у объекта _«Материал библиотеки»_ имеется свойство use\_old\_format (булево; _true – Flash_ (просмотр материала библиотеки в системе), _false – HTML_ (возможность скачивания материала библиотеки)).  
Данное свойство отсутствует в каталоге, но его значение можно видеть в XML-структуре документа «Материал библиотеки»:

<use\_old\_format>0</use\_old\_format>

Обратите внимание – в библиотеке должен быть хотя бы один материал!

Если мы найдем каталожную запись материала библиотеки в каталоге и попробуем обратиться непосредственно к свойству _use\_old\_format_ в каталожной записи:

cat\_elem = ArrayOptFirstElem ( XQuery("for $elem in library\_materials return $elem") );  
cat\_elem.use\_old\_format = true;  
alert (cat\_elem.use\_old\_format);

то выполнение данного кода выдаст ошибку: _«Unknown object property: use\_old\_format»_:  

Для изменения описанных выше свойств нужно открыть найденный документ и изменить свойство с использованием атрибута TopElem.  
В данном примере мы выполняем следующие действия:

1.  Отбираем каталожные записи объектов, свойство которых требуется изменить.
2.  Открываем документы, соответствующие отобранным каталожным записям, с помощью ID объектов.
3.  Изменяем свойство в документе, используя атрибут TopElem.
4.  Сохраняем измененный документ в базу.

В результате выполнения данного агента для всех материалов библиотеки, хранящихся в системе, устанавливается формат _HTML_:

// Пусть в системе имеются один или несколько материалов библиотеки  
arr\_cat\_elem = XQuery("for $elem in library\_materials return $elem") ; // отбор всех материалов библиотеки  
alert ( 'Количество материалов библиотеки в системе: ' + ArrayCount (arr\_cat\_elem));  
  
for (cat\_elem in arr\_cat\_elem) // перебор всех материалов библиотеки (агент может выполняться долго)  
{  
      cat\_elem\_id = cat\_elem.id;   
      doc = OpenDoc(UrlFromDocID(cat\_elem\_id)); // открытие документа (материала библиотеки) по ID  
      if ( doc.TopElem.use\_old\_format == true ) {  
            doc.TopElem.use\_old\_format = false; // изменение свойства документа use\_old\_format (преобразование формата в HTML)  
            doc.Save(); // сохранение измененного документа в базу  
      }  
}

Для преобразования всех материалов библиотеки в формат _Flash_ выполните следующий код:

// Пусть в системе имеются один или несколько материалов библиотеки  
arr\_cat\_elem = XQuery("for $elem in library\_materials return $elem") ; // отбор всех материалов библиотеки  
alert ( 'Количество материалов библиотеки в системе: ' + ArrayCount (arr\_cat\_elem));  
  
for (cat\_elem in arr\_cat\_elem) // перебор всех материалов библиотеки (агент может выполняться долго)  
{  
      cat\_elem\_id = cat\_elem.id;   
      doc = OpenDoc(UrlFromDocID(cat\_elem\_id)); // открытие документа (материала библиотеки) по ID  
      if ( doc.TopElem.use\_old\_format == false ) {  
            doc.TopElem.use\_old\_format = true; // изменение свойства документа use\_old\_format (преобразование формата в Flash)  
            doc.Save(); // сохранение измененного документа в базу  
      }  
}
