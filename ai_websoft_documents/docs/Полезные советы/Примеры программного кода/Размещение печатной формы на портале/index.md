## Размещение печатной формы на портале

Ранее нами был рассмотрен механизм создания печатной формы сертификата по результатам тестирования. Эта печатная форма открывалась из интерфейса администратора из карточки завершенного теста.

Иногда бывает необходимо открывать печатную форму с портала. Например, чтобы сотрудник мог сам распечатать себе сертификат. Рассмотрим этот вариант:

1.  Сначала создадим печатную форму как это было описано ранее.  
     
2.  Загрузим в систему дополнительный настраиваемый шаблон **"Универсальная печатная форма"**, который предназначен для открытия печатной формы с портала (обработайте пакет **print\_template.zip**, который размещен на вкладке **Файлы**).
3.  В коде шаблона установите переменную code равную коду печатной формы. Проставьте поле код в печатной форме. В нашем примере этот код равен 4365
    
4.  Откройте на портале страницу на которую вы хотите встроить вызов печатной формы. Посмотрите на конструкцию mode=<что-то> в URL страницы. Запомните это <что-то>.
    
5.  Создайте элемент шаблона в котором укажите, что на странице с mode равным <что-то> (в нашем примере test\_learning\_stat) по центру (зона = main) будет использоваться наш шаблон вызова печатной формы. Чтобы сместить кнопку **"Печать"** вниз страницы укажите позицию к примеру как "30".
    
6.  В нашу ранее сделанную печатную форму .htm в самом начале текста вставляем конструкцию:  
     
    
    <%  
    oid = Int(Request.QueryString.GetProperty("object\_id"));  
    TopElem = OpenDoc(UrlFromDocID(oid)).TopElem;  
    %>
    
    И обновляем файл формы в WT. Правая кнопка мышки по значку папки **"Очистиль поле"**, и тут же нажимает левой кнопкой на значок папки и указываем модифицированную форму. Сохраняем.
    
7.  Заходим на портал в раздел с **mode=test\_learning\_stat** и видим внизу страницы нашу рабочую кнопку **"Печать"**:
