## Агент "Продление обучения по электронным курсам"

Если вы назначаете обучение большим группам обучаемых на определенный срок, то иногда необходимо продлевать срок такого обучения. Можно это сделать вручную, войдя в каждую карточку незавершенного курса и изменив значение поля "**Дата планируемого завершения**". Создадим агент, который можно будет применить к группе выделенных незавершенных курсов, используя команду "**Выполнить агент**". Этот агент изменит дату завершения обучения не указанное в настройках количество дней.  
  

Пакет с агентом можно скачать в полезных компонентах.

Обратите внимание на то, что для того, чтобы агент показывался в списке агентов модуля (например, **Дистанционное обучение**), в параметрах агента необходимо указать этот модуль в поле "**Прикрепить к блоку**".

  
Разберем программный код агента.  
Комментарии выделены красным шрифтом (текст комментария относится к блоку кода, расположенного выше него), код шаблона - синим.

days = 5;  
// Агент, который вызывается из интерфейса Webtutor Administrator и, будучи примененным к нескольким незавершенным электронным курсам, продлевает срок обучения на количество дней, указанное в переменной _days_  
// Измените это значение для того, чтобы продлить (или уменьшить - в этом случае напишите отрицательное число) обучение на другое количество дней  
  
arr = OBJECTS\_ID\_STR.split(";");  
// В переменной OBJECTS\_ID\_STR хранится список кодов выделенных объектов, разделенных ";". Эта переменная имеет тип строка (String)  
// К любой переменной типа String, можно применить метод split, указав в качестве параметра разделитель (в нашем случае, символ "точка с запятой"). Результатом выполнения метода будет массив идентификаторов, который мы присваиваем переменной _arr_  
  
for (sid in arr)  
{  
     // Проходим в цикле по массиву идентификаторов  
     id = Int(sid);  
     // _arr_ - массив строк. Нам нужно перевести значения в число (Int), чтобы передать параметр в функцию UrlFromDocID и затем в OpenDoc  
  
     doc = OpenDoc( UrlFromDocID(id) );  
     // Открываем документ. Переменной doc присваиваем информационную структуру документа, аналогичную XML-структуре объекта. Чтобы просмотреть XML-структуру объекта - нажмите _**Ctrl+Shift+C**_ на объекте и вставьте скопированные данные в программу **Notepad** с помощью комбинации клавиш **_Ctrl+V_**.  
  
     if (doc.TopElem.Name!="active\_learning")  
     {  
     // Проверяем значение поля **Name** - это поле есть в любом документе и его значение равно типу документа. Для электронного курса поле **Name** должно быть равно **active\_learning (Незавершенный курс)**. Если это не так - выдаем сообщение об ошибке и переходим к следующему шагу цикла  
     _// (в системе WebTutor_ _учитывается регистр букв –_ **_Name_** _и_ **_name_** _представляют собой различные идентификаторы)_  
     // Атрибут TopElem встроенного объекта XmlDoc возвращает корневой элемент документа и используется, в частности, для обращения к атрибутам документа и для их изменения.   
  
          alert("Документ с идентификатором "+id+" не является незавершенным электронным курсом");  
          // Выдадим сообщение с помощью функции alert \- если агент, выполняется на сервере, то результаты записываются в файл xhttp<...>.log на сервере. Если агент выполняется на клиенте, то открывается соответствующее информационное окно.  
  
          continue;  
     }  
  
     if (doc.TopElem.max\_end\_date!=null)     // Производим проверку указания нормативной даты завершения курса, хранящейся в поле _max\_end\_date_. Если поля нет или оно пустое - значит, нормативный срок для этого курса не установлен. В этом случае мы не продлеваем обучение.    
     {          alert("Модификация параметров документа "+id);  
          doc.TopElem.max\_end\_date = DateOffset(doc.TopElem.max\_end\_date,days\*86400);  
          // Если значение не пустое - присваиваем значение, равное дате увеличенной на значение переменной _days_. Для того, чтобы модифицировать даты воспользуемся функцией DateOffset, в которую передаем исходную дату + величину сдвига в секундах (в одном дне 86400 секунд).  
     }  
     else  
     {          alert("Для документа "+id+" нормативная дата завершения не установлена");  
     }  
  
     doc.Save();  
     // сохраняем документ с помощью метода Save  
}

**Как воспроизвести данный агент**

1.  Создайте новый агент на вкладке **Дизайнер – Агенты сервера**.  
     
2.  На вкладке **Общие сведения** введите название агента: **Продление обучения по электронным курсам.**  
     
3.  Прикрепите созданный агент к блоку **Дистанционное обучение.**  
      
     
4.  Скопируйте приведенный выше код агента в поле на вкладке **Выполняемый код**.  
      
     
5.  Сохраните учетную карточку созданного агента.  
     
6.  Перейдите в интерфейс Webtutor Administrator, выделите курсы, по которым будет разрешено самоназначение, и выполните для этих курсов агент в пользовательском интерфейсе:  
      
    Выделите созданный агент и нажмите на кнопку **ОК**:  
      
     
7.  Проверьте, что для всех выделенных курсов был установлен режим самоназначения.
