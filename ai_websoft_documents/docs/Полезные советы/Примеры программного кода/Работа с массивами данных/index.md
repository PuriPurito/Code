## Работа с массивами данных

Результатом XQuery\-запроса является массив указателей на объекты каталога:

arr = XQuery('for $i in education\_methods return $i')

Обработка результатов:

for (i in arr)  
{  
   alert(i.name);  
}

**! Будьте осторожны с запросами на сортировку или поиск по неиндексированным полям каталогов (таблиц) - их выполнение может приводить к загрузке сервера СУБД и выделению большого объема оперативной памяти**

Если поле является ссылкой на другой объект, то можно воспользоваться конструкцией **ForeignElem**:

i.education\_org\_id.ForeignElem.disp\_name  
// поле **education\_org\_id** объекта **i** является ссылкой на объект из каталога учебных программ; выражение вернет название обучающей организации

В системе есть несколько типов массивов:  
\- результат XQuery;  
\- массивы JavaScript;  
\- XML-массивы внутри объектов (поля типа список).

Для работы с массивами данных есть набор функций. В тех случаях, когда результатом этих функций является массив, то это массив JavaScript.  
Массив JavaScript всегда хранится в памяти. Поэтому желательно стараться избегать создание JavaScript-массивов с десятками тысяч записей.  
JavaScript-  и XML-массивы можно адресовать по индексу _x\[i\]_ (нумерация массивов начинается от 0).

В следующем примере показано формирование нового JavaScript-массива:

_x = new Array;_ _// формируется новый массив с именем x_  
_x = \[1,2,3,4,5\];_ _// первым пяти элементам массива (с номерами от 0 до 4) соответственно присваиваются числовые значения 1-5._  
_x\[x.length\] = 'new array element';_ _//  элементу массива с номером 5 (x.length равно 5) присваивается текстовое значение 'new array element'_
