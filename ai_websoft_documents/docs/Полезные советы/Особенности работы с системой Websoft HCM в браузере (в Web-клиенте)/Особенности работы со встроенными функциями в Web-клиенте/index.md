## Особенности работы со встроенными функциями в Web-клиенте

Внимание! В системе Websoft HCM в браузере (в Web-клиенте) некоторые встроенные функции заблокированы. В основном это связано с требованиями безопасности системы.

  
При попытке использования таких встроенных функций открывается предупреждение «_Not supported in Web client_» с указанием названия встроенной функции. Затем выполнение программного кода прерывается аварийно.
