## Как вывести данные из системы в браузере (в Web-клиенте) с помощью агента

Если нужно скопировать текст из системы в браузерной версии (в Web-клиенте), лучше использовать не alert, а функцию **LogEvent**.  
Информация выводится в консоль браузера.  
Например, в браузерах Google Chrome и Mozilla консоль браузера открывается с помощью клавиши **F12** или комбинации клавиш **Ctrl + Shift + I**.

Для сохранения текстовой информации в файл можно использовать встроенную функцию **PutUrlText** (предпочтительно для текстовых данных) или **PutUrlData**.  
В приведенном ниже примере файл должен быть сохранен в папку _..\\WebSoftServer\\share\\temp\\_ (если пользователь имеет право сохранения файла в указанную папку).

  
Вот пример вывода списка зарегистрированных библиотек программного кода:

  
\_query = "for $elem in code\_librarys order by $elem/code ascending return $elem";  
  
arrElems = ArraySelectAll( XQuery( \_query ) ); // использование функции ArraySelectAll позволяет вывести не только первую страницу отбора, а весь отобранный массив  
str = 'В данной версии зарегистрированы следующие библиотеки программного кода (' + ArrayCount( arrElems ) + '): \\n'; // строка для вывода элементов массива  
for (oObj in arrElems) // формируется информация об элементах массива для вывода  
{  
     str1= oObj.code + ' ' + oObj.name ;  
     str = str + str1 + '\\n';  
}  
LogEvent( '', str ); // вывод информации в консоль браузера  
  
filePath = ObtainSessionTempFile('.txt'); // файл должен быть сохранен в папку ..\\WebSoftServer\\share\\temp\\  
PutUrlText(filePath, str); // встроенная функция: сохраняет содержимое строки в файл
