## Как вывести данные из системы в браузере (в Web-клиенте) с помощью настраиваемого отчета

Вывод данных из системы в браузере (в Web-клиенте) с помощью настраиваемого отчета имеет следующие особенности:

1) Настраиваемый отчет формируется стандартным способом.

2) Результат выполнения настраиваемого отчета можно экспортировать с помощью кнопки «**Экспорт...**»:

Примечание – При выборе опций «**в** **html**» и «**в текстовый файл**» результат выполнения настраиваемого отчета открывается в новой вкладке браузера, откуда его можно скопировать стандартным способом. При выборе опций «**в excel**», «**в word**» и «**в pdf**» результат сохраняется в папку, в которую настроено сохранение файлов в браузере (по умолчанию сохранение производится в папку **Downloads**).
