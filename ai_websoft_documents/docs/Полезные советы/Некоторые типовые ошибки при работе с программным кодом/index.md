## Некоторые типовые ошибки при работе с программным кодом

**\- В ходе выполнения кода произошла ошибка:** **JavaScript** **syntax** **error**

Синтаксическая ошибка.  
Часто встречающиеся синтаксические ошибки:  
\- отсутствие открывающей или закрывающей скобки,  
\- отсутствие открывающей или закрывающей кавычки,  
\- несоответствие открывающей и закрывающей скобки или кавычки (например, открывающая скобка - фигурная, а закрывающая - круглая),  
\- преобразованные кавычки (например, кавычки-лапки ‘ или ’ вместо прямых одинарных кавычек ', двойные кавычки-елочки « или » вместо прямых двойных кавычек "),  
\- двойные кавычки вместо двух одинарных кавычек (и наоборот),  
\- использование русских букв в названии переменной и др.

В данной ошибке часто упоминается, что некорректно выполняется функция **EvalCode()**, связанная с выполнением  потока из заданного кода. 

**\- Ошибка регистрации компонента**

Ошибка может проявляться при попытке регистрации компонента, относящегося к несоответствующей версии системы.

**\- Файл не найден либо не указан. Unable to convert Excel to XML**  
(при импорте данных из файла Excel)

**\- ОШИБКА: файл не найден либо не указан. Unable to convert Excel to XML**

Приложению Microsoft Excel не удается получить доступ к файлу ...   
Это может быть вызвано одной из следующих причин:   
• Указан несуществующий файл или путь.   
• Файл используется другой программой.   
• Имя книги, которую вы пытаетесь открыть, совпадает с именем другой книги, открытой в данный момент.   
• Файл используется другой программой.   
• Отсутствует право запуска Excel на сервере (/view\_doc.html?mode=expert\_answer&object\_id=5900188448272230592).

Также подобная ошибка может быть связана с тем, что на сервере не установлен Excel.  
В этом случае предлагаются два решения:  
1) Установить Excel на сервере.  
2) Переписать агент под открытие csv файла  
3) Запускать агент со своего рабочего компьютера, на котором установлен Excel.

Подробнее см. : /\_wt/forum\_entry/6712292973817844116

**\- Элемент не найден** **ArrayFirstElem ()**

Массив, к которому применена функция **ArrayFirstElem**, является пустым.

Для обработки массивов, которые потенциально могут быть пустыми рекомендуется использовать функцию **ArrayOptFirstElem**.

**\- 'continue' outside a loop**

Использование оператора continue вне цикла.

**\- Cs timeout expired**

Ошибка может воспроизводиться при отправке запроса на сервер (Cs - CallServer).  
Предположительно, данная ошибка связана с истечением времени ожидания ответа от сервера.  
Рекомендуется попробовать увеличить значение параметра **TCP-CONN-TIMEOUT** в файле _xHttp.ini_.

**\- Empty url schema**

Возможная причина: Ошибка при работе с документом XML (например, параметр URL, определяющий документ, указан некорректно).

**\- Foreign array not defined**

Ошибка при использовании атрибута ForeignElem: внешний (связанный) массив не определен.

Возможная причина: Производится обращение к данным каталога, который не связан с атрибутом исходного объекта.

**\- HTTP 500 Internal Server Error**

Ошибка сервера.

Например, некорректное выражение **XQuary()**, отсутствует требуемый каталог и др.

Важно обратить внимание на сообщение, которое указывается в нижней части текста (в данном случае, это - XQuery() ). Иногда это сообщение может подсказать причину ошибки.

Ошибка воспроизводится в новых версиях.

**CallServerMethod()** \- возможна ошибка при открытии документа.

Ошибка связана с выполнением функции **ObtainDocScreen**.  
Возможно, что для открытия документа на экране отсутствуют корректные данные.  
  
  
  
Причиной ошибки 500 (в браузере) может быть также предоставление пользователю недостаточных прав на пользование приложением. В этом случае необходимо предоставить пользователю соответствующие права и очистить кэш.

Внимание! В релизе **Websoft HCM 2023.1** для очистки кэша размещен специальный агент **websoft\_clear\_claim\_access\_cache (Очищение кэша)**, который необходимо запускать на сервере. 

**\- Index is out of range**   
(при импорте данных из файла Excel)

**\- Error of extract primary key from ... Index is out of range**

Данная ошибка, вероятно, связана с попыткой обратиться к несуществующему листу файла Excel или к несуществующей ячейке.

Подробнее см. : /\_wt/forum\_entry/6712292973817844116

**\- Invalid array index: …**

После двоеточия указывается размерность массива.

В приведенном примере размерность массива равна 2 (отсчет индекса начинается от 0).

Возможная причина: Переменная-счетчик (индекс элемента массива) выходит за пределы размерности массива.

**\-** **Invalid** **format**

Некорректное значение переменной по типу (в данном случае значение переменной дожно быть целым числом).

В сообщении иногда указывается необходимый тип значения переменной.

Пример:

Некорректный формат в функции Data():

alert (Date('2023.01.11'));

Корректный формат:

alert (Date('11.01.2023'));

**\- Invalid HTTP method**

При работе через IIS причина ошибки может заключаться в том, что не был включен WebSocket Protocol (https://learn.microsoft.com/en-us/iis/configuration/system.webserver/websocket).

  
 

**\- License error: Index was outside the bounds of the array.**

Ошибка в файле лицензии:  
или файл лицензии сформирован некорректно (его размер в байтах не кратен 16)  
или файл передавали клиенту для скачивания с нашего сайта и при скачивании он обрезан и его размер изменился и не кратен 16

Рекомендуется скачать файл повторно и проверить его размер на кратность 16 (Например, размер файла лицензии – 2943 байта, а должен быть хотя бы 2944 байта).  
Если повторное скачивание не принесло результата - попросить сгенерировать новый файл лицензии.

Подробнее см. : /\_wt/wiki\_base/7020782751575525736

  
 

**\-** **Method** **XQuery()** **failed**

Ошибка в функции поиска объектов – в запросе XQuery() или в аналогичной функции (например, tools.get\_doc\_by\_key ()).

Ошибка воспроизводится в старых версиях.

Например, неправильно указан параметр (критерий) поиска.

**\- ...** **not** **defined**

Объект или переменная не определены.

В сообщении приводится имя первой переменной с неопределенным значением, встречающейся в программном коде (в данном примере – **xxxxx**).

Также может быть указано некорректное название встроенной функции.

**\- Not supported in Web client**

Данная ошибка может встречаться при выполнении некоторых встроенных функций в браузере (в Web-клиенте). В системе Websoft HCM в браузере (в Web-клиенте) такие функции могут быть заблокированы. В основном это связано с требованиями безопасности системы.

Рекомендуется заменить их на аналогичные функции, допустимые в Web-клиенте. 

**\- Object required before '.'**

Не сформирован объект, с которым производится работа.

Например:

oObj = tools.get\_doc\_by\_key ( 'org', 'disp\_name', 'data' ); // такого значения параметра disp\_name ('data') в каталоге org нет  
alert (oObj.id);

В частности, данная ошибка может воспроиводиться, если: 

\- неправильно указано название каталога;

\- неправильно указан параметр (критерий) поиска;

\- неправильно указано значение параметра (критерия) поиска.

Причиной расхождения значений параметра (названия объекта) может быть переименование объекта.

Проверка того, что объект сформирован:

if (oObj != null) {  
                alert ("Объект сформирован");  
                alert(tools.object\_to\_text(oObj, "json"));  
}  
else {  
                alert ("Объект не сформирован");  
                alert ('объект = null');  
}

или:

FoundArray = XQuery(\_query\_str);  
\_elem = ArrayOptFirstElem(FoundArray);  
if (\_elem == undefined)  
{  
                alert("Ошибка: объект не найден.");  
                // Завершение итерации цикла:  
                continue;  
}

или:

if (ArrayCount(FoundArray))>0)  
{  
                // Объект найден.  
}  
else  
{  
                // Объект не найден.  
}

**\- 'return' outside a function**

Использование оператора return вне функции.

**\- Unable to assign value to an integer element**

Невозможно присвоить значение элементу целого типа.

Элементу объекта, который имеет тип целого числа, присваивается значение иного типа.

  
 

**\- Unable to build screen**

Данная ошибка может встречаться при выполнении пользовательских объектов API (выборок, показателей и удаленных действий).  
Возможная причина: Не указан или некорректно указан выходной параметр объекта (например, вместо _RESULT_ в программном коде объекта написано _result_).

  
 

**\- Unknown method: \*\*\*\*\*()**

Обращение к неизвестному, некорректному или недоступному методу.

Возможно, недоступен файл библиотеки, в которой находится данный метод.

**\- Unknown object property: \*\*\*\*\***

Указан некорректный параметр объекта через точку (например, **oObj.id1**).

В сообщении приводится название первого некорректного параметра, встречающегося в программном коде (в данном примере – **id1**).

В этом сообщении указана функция, в которой использован неизвестный (некорректный) параметр объекта.

Возможные причины возникновения ошибки:  
\- Неверно указан объект (например, объект, у которого нет указанного параметра). Проверьте название вызванного объекта, наличие указанного параметра у объекта указанного типа (например, с помощью панели запросов (Ctrl+Shift+F8) или в актуальном Справочнике каталогов (/view\_doc.html?mode=catalogs)).  
\- Возможно. не была использована функция TopElem для обращения к параметру объекта.

  
**\- Url host is not allowed: \*\*\*\*\***

Папка \*\*\*\*\* по указанному адресу недоступна.

Необходимо проверить наличие папки по указанному адресу. Если указан адрес "_x-local://custom\_folder_", то имеется в виду ../_WebSoftAdmin/custom\_folder/_ (или ранее -  ../_WebTutorAdmin/custom\_folder/_).  
Начиная с 2023 г. папки с произвольным именем не разрешены для размещения файлов с программным кодом.   
Для разрешения доступа к данной папке внесите корректировки в файл xhttp.ini на сервере (параметры DESIGN-DB - это перечень директорий, в которых разрешено хранение программного кода).   
После добавления туда пользовательской папки перезагрузите сервер.  
  
Можно также попробовать указать полный адрес папки или файла: _'file:///C:/custom\_folder/1.htm'_.  
 

**\- Value is not an object**

Значение не является объектом (т.е. должен быть сформирован объект, а вместо него формируется значение другого типа).  
Причинами могут быть: запрещение формирования объекта политикой безопасности, антивирусом, недостатком прав пользователя, отсутствие необходимых компонентов или что-то иное.  
 

**\-** **Zero** **divide**

Деление на 0.

  
**\- Неизвестная ошибка**

Ошибка, тип которой не определен системой.

В сообщении иногда указывается название функции, которая не смогла выполниться (в данном случае – **Date()**).  
 

См. также "Типовые ошибки в логе spxml\_unibridge\_xxxxxxxx.log".
