## Выбор элемента массива

Если результаты выборки запроса XQuery или элементы XML структуры выбираются для модификации, то необходимо передавать массив по значению, а не по ссылку. Для это используется функция ArraySelectAll (http://docs.datex.ru/article.htm?id=5620250451197911706). Например, если необходимо удалить уволенных сотрудников, то нужно выполнить следующий код.

arrUsers = ArraySelectAll(XQuery( 'for $elem in collaborators where $elem/is\_dismiss=true() return $elem' ))

for (catUser in arrUsers)

{

            DeleteDoc( UrlFromDocID( catUser.id ) );

}

Однако, нужно помнить, что данная функция забирает весь результат запроса в память, что при больших объемах, может привести к переполнению. Поэтому не рекомендуется использовать функцию ArraySelectAll для массивов с количеством элементов больше 1000.
