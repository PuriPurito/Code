## Как определить идентификационный номер (ID) объекта

В ряде случаев администратору учебного портала нужно определить идентификационный номер (ID) конкретного объекта системы.

ID объекта присваивается системой при создании объекта и уникален для данной системы.

Существует несколько способов определения ID объекта. В настоящей статье будет рассказано о наиболее часто используемом способе.

Рассмотрим данный способ на примере объекта **Сотрудник**.

1\. Откройте каталог **Сотрудник** (**Персонал - Сотрудники**).

2\. Выберите строку объекта **Сотрудник**, для которого необходимо определить идентификационный номер.

3\. Выполните двойной щелчок мышью по выбранной строке.

Откроется карточка объекта:

4\. Перейдите в меню карточки объекта и выберите команду **Сервис - Копировать** **ID документа**:

Идентификационный номер данного объекта копируется в буфер обмена, после чего его можно вставить стандартным способом в любой текстовый файл, в область записи кода и т.д. (Для вставки скопированного текста обычно используется комбинация клавиш **Ctrl+****V**).
