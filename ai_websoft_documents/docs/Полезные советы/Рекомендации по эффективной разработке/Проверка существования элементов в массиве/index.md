## Проверка существования элементов в массиве

Для проверки есть ли в массиве элементы предпочтительно использовать ArrayOptFirstElem, а не ArrayCount, потому что ArrayOptFirstElem работает быстрее. То есть вместо

if (ArrayCount(arrElems)!=0) нужно использовать if (ArrayOptFirstElem(arrElems)!= undefined).

Использование ArrayOptFirstElem обеспечит многократный рост производительности, особенно на больших данных и на типах базы отличных от XML.
