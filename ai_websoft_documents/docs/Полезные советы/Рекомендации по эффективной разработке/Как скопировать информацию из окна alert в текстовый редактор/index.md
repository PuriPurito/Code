## Как скопировать информацию из окна alert в текстовый редактор

Для копирования информации из окна alert в текстовый редактор выполните следующие действия:

1.  Выделите окно alert, сделав его активным.
2.  Нажмите комбинацию клавиш _Ctrl+C_.
3.  Перейдите в текстовый редактор и нажмите комбинацию клавиш Ctrl+V.
