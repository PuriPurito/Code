## Переменные окружения

При разработке шаблонов необходимо помнить, что зачастую код шаблона выполняется в некотором окружении. Важно, чтобы названия переменных, объявленных локально, не совпадали с названиями окружения. Например, код настраиваемого типа уведомления выполняется в функции create\_notification. Переменные в теле шаблона уведомления. См. описание функций из tools. Функция create\_notification.

Есть зарезервированные переменные, которые доступны в администраторе, на портале или в шаблонах.

Портальные переменные.

**curDocID** - ID текущего раздела портала, может быть не определён, если не  передан doc\_id в адресе.  
**curDoc** - TopElem текущего раздела портала, может быть не определён, если не  передан doc\_id в адресе.  
**curObjectID** - ID текущего объекта, может быть не определён, если не  передан object\_id в адресе.  
**curObject** - TopElem текущего объекта, может быть не определён, если не  передан object\_id в адресе.  
**curUserID** - ID текущего авторизованного пользователя, не определен на не авторизуемых страницах.  
**curUser** - TopElem текущего авторизованного пользователя, не определен на не авторизуемых страницах.

Переменные в администраторе **LdsIsServer**, если переменная имеет значение true, то программа работает в режиме сервера.
