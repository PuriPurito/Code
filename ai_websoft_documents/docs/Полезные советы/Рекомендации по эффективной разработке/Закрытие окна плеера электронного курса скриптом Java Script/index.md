## Закрытие окна плеера электронного курса скриптом Java Script

При разработке курсов в CourseLab или других редакторах часто бывает необходимо на последнем слайде разместить кнопку **Завершить курс** или **Закрыть курс**. Однако эта кнопка не работает в плеере электронных курсов Версии 1 и Версии 2021 (из-за фрейма). В таком случае можно указать скрипт Java Script прямо на кнопку и напрямую вызвать действие плеера курсов на закрытие окна прямо с курса. Примеры скриптов, вызывающих действия:

*   Закрыть курс
    
    `var playerApp = window.parent.document.querySelector('#app');   if (playerApp !== null) playerApp.__vue__.$store.dispatch('app/close');`
    
*   Сделать редирект
    
    `var playerApp = window.parent.document.querySelector('#app');   if (playerApp !== null) playerApp.__vue__.$store.dispatch('app/redirect', "https://websoft.ru");`
    

Данные скрипты будут работать только для плеера электронных курсов Версии 2021.

Таким образом, при разработке электронного курса нужно учитывать СДО, где будет запускаться курс, и «вешать» указанные скрипты на кнопку **Завершить курс** или **Закрыть курс**.
