## Логирование в системе WebTutor

В системе WebTutor предусмотрено логирование результатов работы.  
Журналы (файлы с расширением _log_) записываются в папке _WebTutorServer\\Logs\\_.  
  
Обычно записываются следующие четыре файла (файлы формируются по датам работы системы):  
\- **agent-гггг-мм-дд.****log** (например, _agent-2020-01-04.__log_) – журнал действий системных агентов (данные о запуске агентов);  
\- **cfg\_ддммгггг.****log** (например, _cfg\_04012020.__log_) - журнал запросов (сообщения о web-запросах к серверу при открытии страниц портала);  
\- **email-гггг-мм-дд.****log** (например, _email-2020-01-04.__log_) – журнал отправки почтовых сообщений (информация об использовании сервера SMTP и о почтовых отправлениях);  
\- **xhttp-гггг-мм-дд.****log** (например, _xhttp-2020-01-04.__log_) – основной журнал сообщений сервера системы (информация об ошибках в процессе работы сервера системы и вывод результатов использования функции alert при запуске агентов с сервера).  
  
При необходимости могут быть подключены и другие журналы логирования (подробнее см. документ «**Руководство системного администратора WebTutor»**, раздел **«Системные журналы WebTutor»**).

В интерфейсе Webtutor Administrator журналы логирования отображаются в разделе **Системное администрирование – Журналы сервера**.  

C конца 2022 г. в **«Общие настройки»** системы (**Настройка системы – Общие настройки – Администрирование - Журналы**) добавлены элементы _Tracing_ и _Tracing timeout_ для получения дополнительных возможностей отслеживания информации в журнале:

  
Для того, чтобы включить трейсинг необходимо:   
а) в Общих настройках включить параметр на скриншоте   
б) в адресную строку добавить параметр ?tracing=statistic|collection|normal|verbose  
Доступные варианты трейсинга:  
**statistic** \- отслеживание только по показателям,   
**collection** \- отслеживание только по коллекциям,   
**normal** \- отслеживание с учетом ограничения по времени (_Tracing timeout_),   
**verbose** \- получение расширенной информации.

После установки флажка _Tracing_ информация будет записываться в журнал _tracing_ в папке _logs_.

В поле _Tracing timeout_ записывается ограничение по времени (в миллисекундах) для записи в журнал _Tracing_.
