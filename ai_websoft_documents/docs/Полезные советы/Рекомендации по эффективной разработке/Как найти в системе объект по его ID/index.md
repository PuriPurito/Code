## Как найти в системе объект по его ID

Для поиска в системе объекта по его ID выполните следующие действия:

1.  Нажмите на значок с изображением шестеренки (**«Настройки»**) в левой нижней части окна программы WebTutor Administrator.
2.  В выпадающем списке меню выберите позицию **«Поиск»**.
3.  В открывшемся подменю выберите команду **«По ID...»**.  
    
4.  Открывается окно **«ID-объекта»**. Введите в поле **«ID-объекта»** идентификационный номер того объекта, который нужно найти.
5.  Нажмите на кнопку **«Применить»**.

  
  
Если объекта с указанным идентификационным номером в системе не существует, то на экран будет выведено сообщение "_Файл не найден..._"
