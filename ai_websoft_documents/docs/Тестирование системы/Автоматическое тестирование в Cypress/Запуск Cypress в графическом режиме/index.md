## Запуск Cypress в графическом режиме

Для запуска Cypress в графическом режиме выполним действия:

1.  Откроем IDE (например, Visual Studio Code).
2.  В терминале перейдем в корневую папку проекта, где находится файл _cypress.config.js_, и введем команду **`npx cypress open`** .
3.  В открывшемся окне приложения выберем **E2E Testing**.
    
4.  Выберем браузер, например, Chrome и нажмем кнопку **Start E2E Testing in Chrome**, после чего откроется браузер со всеми имеющимися в проекте сценариями.
