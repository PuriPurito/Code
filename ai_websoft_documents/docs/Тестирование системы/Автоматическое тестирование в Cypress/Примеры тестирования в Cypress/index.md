## Примеры тестирования в Cypress

Для более наглядного представления, как мы тестируем нашу систему с использованием фреймворка Cypress, рассмотрим примеры тестирования страниц Портала и используемой бизнес-логики.

## **Тестирование страницы Портала «Адресная книга»**

### Подготовка сценария тестирования

Рассмотрим сценарий тестирования страницы Портала «Адресная книга» от лица руководителя отдела обучения и развития Анисимова Геннадия. Для просмотра страницы перейдем в раздел **Сервисы → Адресная книга**. Этот сценарий будет проверять наличие информации, представленной на странице:

Код сценария _Portal\_check\_addressbook\_page\_elements.cy.js_ содержит три блока:

1.  Необходимые импорты.
2.  Создание необходимых констант и экземпляров классов, используемых для проверки соответствующих данных на странице Портала «Адресная книга».
3.  Команды для проверки наличия требуемой информации на странице Портала «Адресная книга».

Вы можете скачать архив с кодом сценария _Portal\_check\_addressbook\_page\_elements.cy.js_ , приложенный в конце статьи (архив «1 пример»). Однако, воспроизвести его выполнение не получится, так как сценарий содержит множество импортируемых из других файлов элементов.

Методы, используемые в сценарии, включают в себя команды Cypress:

*   **createSession(login, password)** – авторизация на Портале с указанием логина и пароля:
    
    `createSession(login, password) {           cy.session([login, password], () => {               cy.loginuser(login, password)           },           {               cacheAcrossSpecs: true           })           cy.viewport(1500, 900)`  
      
            `return this;       }`
    
*   **pageVisit(path)** – посещение страницы с указанным адресом:
    
    `pageVisit(path) {      cy         .visit(path)      cy         .url().should('include', path)      return this;   }`
    
*   **checkWindowText(window, text)** – проверка наличия и видимости передаваемого текста в требуемом месте страницы:
    
    `checkWindowText(window, text) {      cy         .get(window)         .should('contain', text).and('be.visible')       return this;`  
    `}`
    
*   **clickButtonClass(buttonclass, buttontext, click='left')** – нажатие какой-либо кнопки мыши:
    
    `clickButtonClass(buttonclass, buttontext, click='left') {      if (click=='right'){         cy            .get(buttonclass)            .rightclick()      }      else if (click=='double') {         cy            .get(buttonclass)            .dblclick()      }      else {         cy            .get(buttonclass)            .contains(buttontext)            .click()      }      return this;   }`

Чтобы выполнить сценарий с использованием графического режима Cypress, выполним действия:

1.  Запустим Cypress в графическом режиме.
2.  Выберем необходимый сценарий (в нашем примере – _Portal\_check\_addressbook\_page\_elements.cy.js_) из списка всех доступных сценариев и кликнем по его названию левой кнопкой мыши.
    
3.  Запустится автоматический процесс прохождения сценария, в котором будут выполнены действия (в скобках указаны номера строк из кода):
    
    •
    
    вход на Портал под логином и паролем Анисимова Геннадия (строка 16);
    
    •
    
    посещение страницы «Адресная книга» (строка 17);
    
    •
    
    проверка «хлебных крошек» (строки 19-21);
    
    •
    
    проверка заголовка страницы «Адресная книга» (строка 23);
    
    •
    
    проверка заголовка таблицы адресной книги (строки 25-27);
    
    •
    
    проверка содержимого первой записи в таблице адресной книги (строки 28-32);
    
    •
    
    проверка пагинатора: активности указателя первой страницы (строка 34);
    
    •
    
    нажатие кнопки **Далее** и переход к следующей странице (строка 36);
    
    •
    
    проверка пагинатора: активности указателя второй страницы (строка 38).
    
4.  По завершении тестирования получим результаты на экране Cypress, который состоит из двух фреймов: в одном фрейме открыта страница Портала «Адресная книга», в другом фрейме отображена служебная информация о происходящих во время тестирования процессах и количество успешно пройденных тестов (в данном случае – 1).

### Пример неудачного выполнения сценария

Чтобы сценарий завершился неуспешно, фактическое содержимое любого элемента должно отличается от ожидаемого. Для визуализации такой ошибки заменим в коде сценария _Portal\_check\_addressbook\_page\_elements.cy.js_ строку 23 – явно укажем заголовок страницы неправильно:

``mainCommands.checkWindowText(`#${Services["Addressbook"].id}`, 'Адресная книжка')``

В таком случае вызовется ошибка **AssertionError**, и сценарий завершится неуспешно, о чем будет выдано сообщение в левом фрейме.

## **Тестирование бизнес-логики**

### Подготовка сценария тестирования

С помощью Cypress можно тестировать бизнес-логику, создавать разнообразные заявки, отзывы, карточки и т.д. и управлять ими. Рассмотрим еще один пример, в котором создадим обратную связь от руководителя Анисимова Геннадия на подчиненную Вилкову Ольгу на странице Портала «Непрерывная обратная связь». Для просмотра страницы перейдем в раздел **Сервисы → Обратная связь**.

Код сценария _Portal\_continuous\_feedback\_collaborator.cy.js_ содержит блоки:

1.  Необходимые импорты и создание экземпляров классов, используемых для проверки соответствующих данных на странице «Непрерывная обратная связь».
2.  Блок «Удаление объектов», необходимый для приведения системы в исходное состояние посредством удаления созданных ранее в процессе тестирования объектов.
3.  Блок тестов «Непрерывная обратная связь (по сотруднику)».
4.  Проверка на заполнение обязательных полей при создании обратной связи.
5.  Создание обратной связи от имени Анисимова Геннадия на подчиненную Вилкову Ольгу.
6.  Проверка обратной связи от лица Вилковой Ольги.

Вы можете скачать архив с кодом сценария _Portal\_continuous\_feedback\_collaborator.cy.js_, приложенный в конце статьи (архив «2 пример»). Однако, воспроизвести его выполнение не получится, так как сценарий содержит множество импортируемых из других файлов элементов.

Методы, используемые в сценарии, включают в себя команды Cypress:

*   **createSession(login, password)** – вход на Портал под указанным логином и паролем:
    
    `createSession(login, password) {           cy.session([login, password], () => {               cy.loginuser(login, password)           },           {               cacheAcrossSpecs: true           })           cy.viewport(1500, 900)`  
      
            `return this;       }`
    
*   **deleteAutotestsObjects()** – удаление объектов, созданных при предыдущем тестировании:
    
    `deleteAutotestsObjects() {           cy               .visit('/test/settings.html?action=delete_autotest_objects')              return this;`  
       }
    
*   **pageVisit(path)** – посещение страницы с указанным адресом:
    
    `pageVisit(path) {      cy         .visit(path)      cy         .url().should('include', path)      return this;   }`
    
*   **clickPageObject(objectID, item, click='left')** – нажатие указанной кнопки и выполнение соответствующего действия:
    
    `clickPageObject(objectID, item, click='left') {           switch (click) {               case 'right':                   cy                       .get('[id^=' + objectID + ']')                       .rightclick()               break               case 'double':                   cy                       .get('[id^=' + objectID + ']')                       .dblclick()               break               default:                   cy                       .get('[id^=' + objectID + ']')                       .contains(item)                       .wait(1000)                       .click({ force: true })               break           }              return this;       }`
    
*   **clickButtonClass(buttonclass, buttontext, click='left')** – нажатие какой-либо кнопки мыши:
    
    `clickButtonClass(buttonclass, buttontext, click='left') {      if (click=='right'){         cy            .get(buttonclass)            .rightclick()      }      else if (click=='double') {         cy            .get(buttonclass)            .dblclick()      }      else {         cy            .get(buttonclass)            .contains(buttontext)            .click()      }      return this;   }`
    
*   **checkWindowText(window, text)** – проверка наличия и видимости передаваемого текста в требуемом месте страницы:
    
    `checkWindowText(window, text) {      cy         .get(window)         .should('contain', text).and('be.visible')       return this;`  
    `}`
    
*   **selectItemFromListInFrame(iframelocator, item)** – выбор элемента из списка:
    
    `selectItemFromListInFrame(iframelocator, item) {           cy           .enter(iframelocator).then(getBody => {               getBody().contains(item).click()               getBody().contains('Выбрать').click()             })              return this;       }`
    
*   **typeText(flieldlocator, text, position=0)** – ввод текста:
    
    `typeText(flieldlocator, text, position=0) {           cy               .get(flieldlocator)               .eq(position)               .clear()               .type(text).should('have.value', text)                    return this;       }`
