## Основные понятия

Программа Websoft HCM представляет собой объектно-ориентированную систему, использующую инструментарий и методологии, поддерживающие технологию объектно-ориентированного программирования.  
Данные, хранящиеся в системе, представляют собой на логическом уровне набор информационных объектов. Объекты могут быть связаны между собой.

В системе хранятся объекты различных типов.  
Примеры типов объектов:  
_\- Электронный курс;  
\- Тест;  
\- Сотрудник;  
\- Должность._

  
Каждый объект представляет набор атрибутов (полей) различных типов.  
В состав объекта могут входить как атрибуты базовых типов (строка, дата, число, текст и т.п.), так и составные атрибуты, например, массивы.

Описание структуры полей типа объекта обычно хранятся в соответствующем файле с расширением XMD, который в базе данных типа XML хранится по следующему адресу:  
_WebTutorServer/wtv/wtv\_<имя объекта>.xmd_

Данные хранятся в объектах, но прямой поиск по объектам является медленной операцией, поэтому, для быстрой выборки списков объектов и данных созданы _специальные структуры (таблицы) – каталоги_, куда выведены наиболее часто используемые поля _объектов (документов)_.

Каталоги могут быть _простыми_ – созданные по объектам одного типа (например, **collaborators**, в таких каталогах каждая строка представляет собой один объект), _комплексными_ (например, **subs**, здесь в одном каталоге могут быть сведены данные по нескольким типам объектов) и _каталогами-связками_ (например, **func\_managers**, где в одной строке выведена информация по нескольким связанным типам объектов).

_Каталоги-связки_ позволяют связать отдельные каталоги и облегчить отбор объектов.  
Вот несколько примеров каталогов-связок:  
_\- Мероприятие – Группа (event\_group);  
\- Модульная программа – Учебная программа (compound\_program\_education\_method);  
\- Объект – Эксперт (object\_expert);  
\- Персональный чат (personal\_chat)._

Перечень каталогов-связок можно увидеть, например, на карточке настраиваемого отчета при выборе опции **«Каталог-связка»**:

Поля _каталога_ могут как дублировать информацию из полей _документа (объекта)_, так и быть результатом выполнения некоторого программного кода (например, в каталоге **collaborators** имеется поле _fullname,_ которое представляет собой соединение значений полей _lastname, firstname_ и _middlename_ из _документа (объекта)_.

_Каталог_, в общем случае, не содержит всех полей _документа (объекта)_, а только их часть. Например, в каталоге **collaborators** _(Сотрудники)_ отсутствует информация о пароле сотрудника, а в документе объекта эта информация имеется.

Каталог – не самостоятельный источник данных, а лишь отображение тех данных, которые хранятся в полях объекта. При изменении данных в объекте синхронно меняются данные в каталоге.

Более подробно работа с документами и каталогами описывается далее в разделе "Работа с объектами системы WebSoft HСM".  
  
 

Компания WebSoft в открытом доступе предоставляет пользователям информацию о каталогах системы (_/view\_doc.html?mode=catalogs_) WebTutor и о полях, отображающихся в каталогах.  
Актуальные данные о структуре каталогов, размещаемые по адресу /view\_doc.html?mode=catalogs, регулярно (автоматически) обновляются.
