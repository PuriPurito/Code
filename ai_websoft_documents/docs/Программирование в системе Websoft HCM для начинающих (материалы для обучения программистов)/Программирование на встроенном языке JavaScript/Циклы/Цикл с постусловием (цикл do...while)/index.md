## Цикл с постусловием (цикл do...while)

**Цикл с постусловием** — это цикл, в котором условие проверяется после выполнения тела цикла. Поэтому данный цикл всегда выполняется хотя бы один раз.   
Цикл с постусловием часто также называется **циклом do...while**.  
Данный цикл используется реже, чем цикл while, так как требование выполнения цикла хотя бы один раз встречается редко.

Общий формат цикла с постусловием в системе WebTutor имеет следующий вид:

do  
{  
     <тело цикла>   
}  
while ( <условие> ) 

Тело цикла заключается в фигурные скобки, а условие выполнения цикла – в круглые.

Например, следующий набор команд выводит на экран квадраты чисел от 1 до 5 с помощью цикла с постусловием:

var i = 1;  
do   
{  
     alert ( i \* i ); // на экран выводятся значения 1, 4, 9, 16, 25  
     i++; // при выходе из цикла значение переменной i равно 6  
} while (i <= 5); // когда значение переменной i становится больше 5, цикл завершается
