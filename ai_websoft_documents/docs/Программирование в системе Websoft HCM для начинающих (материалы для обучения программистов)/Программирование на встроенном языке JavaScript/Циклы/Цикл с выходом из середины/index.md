## Цикл с выходом из середины

**Цикл с выходом из середины** – это цикл, в котором условие выхода проверяется внутри тела цикла.

Это тоже нечасто встречающийся тип цикл.

Вот пример цикла такого типа. Цикл выводит два первых элемента массива:

var Array = \['one', 'two', 'three', 'four', 'five'\]; // исходный массив  
i=1;  
for(q in Array)  
{  
     alert(q); //   
  
     // ограничение количества элементов, которые выводятся на экран  
    if (i == 2)  // если показано 2 элемента  
          break; // остановить цикл  
      i=i+1;  
}
