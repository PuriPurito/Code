## Цикл с предусловием (цикл while)

**Цикл с предусловием** — это цикл, который выполняется, пока истинно некоторое условие, указанное перед его началом. Это условие проверяется до выполнения тела цикла, поэтому тело может быть не выполнено ни разу (если условие с самого начала ложно). 

Цикл с предусловием часто называется также **циклом while**, так как при реализации этого цикла для проверки условия используется оператор while.

Общий формат цикла с предусловием в системе WebTutor имеет следующий вид:

while ( <условие> )   
{  
     <тело цикла>   
}

Условие выполнения цикла заключается в круглые скобки, а тело цикла – в фигурные.

Например, следующий набор команд выводит на экран квадраты чисел от 1 до 5 с помощью цикла с предусловием: 

var i = 1;  
while (i <= 5) // когда значение переменной i становится больше 5, цикл завершается  
{  
     alert ( i \* i ); // на экран выводятся значения 1, 4, 9, 16, 25  
     i++; // при выходе из цикла значение переменной i равно 6  
}
