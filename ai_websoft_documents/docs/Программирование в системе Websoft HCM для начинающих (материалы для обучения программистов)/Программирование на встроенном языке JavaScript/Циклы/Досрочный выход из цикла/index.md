## Досрочный выход из цикла

Для досрочного выхода из цикла используется оператор **break.**

Пример:

_for (__i = 0; i < 3; i++) // выведет 0, затем 1, затем 2  
{_  
                _alert(__i + ' Оператор до break – выводится на экран');_  
                _break; // выход из цикла (на экран выводится только одно сообщение)_  
                _alert(i + ' Оператор после break – не выводится на экран');  
}_
