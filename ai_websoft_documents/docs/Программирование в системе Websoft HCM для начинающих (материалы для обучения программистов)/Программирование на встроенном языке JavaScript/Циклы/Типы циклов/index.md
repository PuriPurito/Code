В программировании используются следующие основные типы циклов:

1.  Безусловные циклы
  
3.  Цикл с выходом из середины
  
5.  Цикл с предусловием
  
7.  Цикл с постусловием
  
9.  Цикл со счетчиком
  
11.  Цикл с перебором элементов
