## Цикл со счетчиком (цикл for)

**Цикл со счетчиком** — это цикл, в котором некоторая переменная изменяет свое значение от заданного начального значения до конечного значения с некоторым шагом, и для каждого значения этой переменной тело цикла выполняется один раз.   
Цикл со счетчиком часто называется также **циклом for**.

Общий формат цикла со счетчиком в системе WebTutor имеет следующий вид:

for ( <имя\_счетчика> = <начальное\_значение>; <условие\_завершение>; <прирост\_счетчика> )  
{  
     <тело цикла>   
}

  
Параметры счетчика заключаются в круглые скобки, а тело цикла – в фигурные.

Например, следующий набор команд выводит на экран квадраты чисел от 1 до 5 с помощью цикла со счетчиком:

for (i = 1; i <= 5; i++) // когда значение переменной i становится больше 5, цикл завершается; при выходе из цикла значение переменной i равно 6  
{  
     alert ( i \* i ); // на экран выводятся значения 1, 4, 9, 16, 25  
}

Цикл со счетчиком удобно также использовать для работы с массивами: 

var Array1 = \['one', 'two', 'three'\]; // исходный массив  
n = ArrayCount (Array1); // определяем количество элементов массива (в данном случае оно равно 3)  
for (i = 0; i < n; i++) {  
     alert (Array1\[i\] ); // на экран выводятся по очереди все элементы массива  
}
