## Цикл с перебором элементов

**Цикл с перебором элементов** — это цикл, который перебирает по одному все элементы, которые входят в состав указанного объекта.   
Цикл с перебором элементов иногда называется также циклом с перебором коллекции.  
Для цикла с перебором элементов не нужно определять количество элементов в объекте – система делает это автоматически.

Общий формат цикла с перебором элементов объекта в системе WebTutor имеет следующий вид:

for (<элемент\_объекта> in <имя\_объекта>)   
{  
     <тело цикла>   
}

Параметры перебора элементов заключаются в круглые скобки, а тело цикла – в фигурные.

Например, следующий набор команд выводит на экран по одному все элементы массива с помощью цикла с перебором элементов:

var Array1 = \['one', 'two', 'three'\];  
for ( q in Array1 )   
{  
     alert(q);  
}
