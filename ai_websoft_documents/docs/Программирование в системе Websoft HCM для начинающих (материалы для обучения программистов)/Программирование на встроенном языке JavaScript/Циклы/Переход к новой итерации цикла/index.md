## Переход к новой итерации цикла

Для перехода к новой итерации цикла используется оператор **continue**.

Пример:

for (i = 0; i < 3; i++) // выведет 0, затем 1, затем 2  
{  
                alert(i + ' Оператор до continue – выводится на экран');  
                continue; // Переход к новой итерации цикла  
                alert(i + ' Оператор после continue – не выводится на экран');  
}
