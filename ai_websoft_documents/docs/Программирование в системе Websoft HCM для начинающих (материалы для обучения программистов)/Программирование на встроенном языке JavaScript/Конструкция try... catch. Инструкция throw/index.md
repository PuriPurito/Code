## Конструкция try... catch. Инструкция throw

**"try... catch"** - это общая конструкция для обработки ошибок, используемая в том числе и в языке JavaScript.

Конструкция состоит из двух основных блоков **try** и **catch**:

try {  
    // код...  
}   
catch (err) {  
    // обработка ошибки  
}

Работает она следующим образом:  
1\. Сначала выполняется код внутри блока **try {...}**.  
Если в нём нет ошибок, то блок **catch(err)** игнорируется: выполнение доходит до конца блока **try**, а блока **catch** пропускается.  
Далее выполняется код, который следует после данной конструкции.

2\. Если в коде имеется ошибка, то выполнение блока try прерывается, и управление передается в начало блока **catch(err)**.   
Переменная **err** (вместо err можно использовать и любое другое имя) содержит объект ошибки с подробной информацией о ней.

Таким образом, при ошибке в блоке **try {…}** программа не прерывается, и мы получаем возможность обработать ошибку внутри блока catch.

Пример кода с ошибкой в блоке **try** (деление на 0):

try {  
    alert('Начало блока try');  // Оператор выполняется   
    iNum1 = 3; // Оператор выполняется   
    iNum2 = 0; // Оператор выполняется   
    iDiv = iNum1/iNum2; // Ошибка - деление на 0  
    alert('Конец блока try (никогда не выполнится)');  // Оператор никогда не выполняется   
}   
catch(err) {  
    alert('Возникла ошибка!'); // Будет выведено сообщение: "Возникла ошибка!"  
     // err - это особый объект типа BmErrorInfo с полями message (description) и number  
    alert(err); // Будет выведено содержание ошибки   
    alert(err.message); // Будет выведено название ошибки (в данном случае - "Zero divide")  
    alert(err.description); // Аналогично err.message. Будет выведено название ошибки (в данном случае - "Zero divide")  
    alert(err.number); // Будет выведен номер ошибки (в данном случае - 1008)  
}

**Инструкция throw** 

Инструкция **throw** используется для генерирования исключения. При этом в данной инструкции нужно задать значение исключения, которое передается в параметр **e.message**. 

throw "Error2"; // генерирует исключение, значением которого является строка  
throw 42; // генерирует исключение, значением которого является число 42  
throw true; // генерирует исключение, значением которого является логическое значение true

  
После выполнения инструкции **throw** управление передается в блок **catch**. Операторы, идущие после **throw** в блоке **try**, не выполняются.  
  
Пример:

try {  
     throw "err"; // генерируется исключение со значением ошибки "err". Управление передается в блок catch.  
     // Дальнейшие операторы не выполняются.  
} catch (e) {  
     alert( e.message ); // выводится строковое значение err  
}
