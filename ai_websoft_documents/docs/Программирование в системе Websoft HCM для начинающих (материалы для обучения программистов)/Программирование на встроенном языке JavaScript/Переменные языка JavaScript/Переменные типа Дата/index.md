## Переменные типа Дата

Переменные типа **Дата** в системе WebTutor часто отображают значения полей, связанных с календарем.  
Ниже приводится пример поля, связанного с календарем, на карточке сотрудника:  

Как определить соответствие переменной типа **Дата** и поля, связанного с календарем, – об этом будет говориться далее.

Необходимо различать данные в формате **Дата** и даты, записанные в текстовом формате,  
Даты, записанные в текстовом формате, имеют следующий вид:

'22.07.2020'  
'22.07.2020 14:00'

Для преобразования вышеуказанного текстового (строкового) значения в дату используется встроенная функция **Date**. 

Введите в поле программного кода агента следующие выражения:

d1 = Date ('26.11.2020'); // возвращает значение типа Дата  
alert (d1);   
d2 = Date ('26.11.2020 14:00'); // также возвращает значение типа Дата  
alert (d2); 

**Примечание** – В приведенных выше выражениях строковое значение, указанное в скобках (например, _'26.11.2019'_), называется **параметром функции**.

Выполните программный код.

**Примечание** – Для определения текущей даты используется функция **Date** без параметра:

d3 = Date(); // возвращает значение текущей даты типа Дата  
alert (d3);
