## Переменные языка JavaScript

Переменные языка JavaScript могут содержать значения следующих основных типов:  
•    **Строки** \- последовательность символов;  
•    **Числовые значения** \- целые и действительные числа;  
•    **Булевы значения** \- только два значения _true_ или _false_;  
•    **Даты** \- значения даты и времени;  
•    **Массивы** \- множества однотипных переменных.

Могут быть использованы и переменные других типов, но к этому вопросу можно вернуться позднее.

**Примечание** – Для **преобразования типов переменных** в системе WebTutor удобно использовать встроенные функции системы или специальные функции встроенной библиотеки tools. Примеры преобразования данных будут рассмотрены далее.

Для обозначения переменных в системе Websoft HCM в соответствии с рекомендациями по стилю программмирования и соглашением о названиях переменных используется Венгерская нотация:  
• Название начинается с маленькой (строчной) буквы  
• <префикс><Название>\[Суффикс\]  
• camelCase

**Префиксы простых типов переменных**  

Объявление переменных в системе Websoft HCM, в принципе, не обязательно, но в ряде случаев возможно объявление переменных с помощью ключевого слова _var_:

var iObjectID, teObject;  
var curUserID = null;

Такое объявление делается только один раз либо в общем коде (например, коде агента), либо в коде функции, описанной в библиотеке или внутри общего кода.

Преимущества объявления:  
\- исключена ситуация, когда код падает на проверке значения переменной, а эта переменная еще не создана и не имеет значения по умолчанию, например, потому что ранее была обойдена ветка кода, где значение этой переменной присваивалось  
\- исключена ситуация, когда название локальной переменной совпадает с названием какой-то глобальной переменной (системной или пользовательской). Будет получено сообщение об ошибке, свидетельствующее о том, что такая переменная уже имеется в системе.
