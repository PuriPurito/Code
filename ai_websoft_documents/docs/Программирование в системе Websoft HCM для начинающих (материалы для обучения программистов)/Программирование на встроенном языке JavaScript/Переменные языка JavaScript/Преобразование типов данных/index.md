## Преобразование типов данных

Для преобразования типов данных в системе WebTutor удобно использовать встроенные функции.  
Описание и примеры использования основных встроенных функций преобразования типов данных приведено здесь.

Рассмотрим пример.  
Требуется преобразовать числовую переменную в строковую.

Исходное значение переменной:  
i = 12345;

Откройте страницу «Преобразование типов данных» и выберите нужную функцию.   
Это функция **StrInt**. Применим эту функцию к переменной _i_ и проверим тип полученного результата с помощью функции **DataType**.

i = 12345;  
s = StrInt (i); // преобразование числовой переменной в строковую  
alert (DataType(s)); // проверка типа полученного результата

   
Результат получился корректным - числовая переменная преобразована в строковую.
