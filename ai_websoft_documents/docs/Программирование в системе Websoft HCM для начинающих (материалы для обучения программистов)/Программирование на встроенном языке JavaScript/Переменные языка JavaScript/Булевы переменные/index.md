## Булевы переменные

Булевы переменные могут иметь только два значения: _true_ (истина) или _false_ (ложь).  
  
Булевы переменные в системе WebTutor часто отображают значения флажков.

Как определить соответствие булевой переменной и состояния флажка – об этом будет говориться далее.

1.  Присвойте переменной _b_ булево значение (например, _true_) и выведите значение переменной на экран.
2.  Создайте две булевы переменные и сложите их с помощью оператора +. Выведите результат на экран. Какой тип имеет результат?
