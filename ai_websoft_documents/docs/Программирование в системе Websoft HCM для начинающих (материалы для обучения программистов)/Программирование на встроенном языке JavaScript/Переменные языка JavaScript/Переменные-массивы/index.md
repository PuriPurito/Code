## Переменные-массивы

Переменная может также отображать массив.  
Для этого необходимо определить переменную в качестве массива.  
  
Сделать это можно различными способами. Вот некоторые из них:

1.  Перечисление элементов массива:
    
    var arr = \['one', 'two', 'three'\];
    
    или
    
    arr = \['one', 'two', 'three'\];
    
    **Примечание** – Обратите внимание, что элементы массивов в JavaScript нумеруются с 0.
    
  
3.  Объявление массива с помощью конструктора **Array()**:
    
    arr = new Array(); // формируется новый массив с именем x  
    arr\[0\] = 'one';  
    alert (arr\[0\]); // возвращает значение 'one'
    
  
5.  Присвоение значения новому элементу массива:
    
    arr = new Array();  
    arr = \[1,2,3,4,5\]; // первым пяти элементам массива (с номерами от 0 до 4) соответственно присваиваются числовые значения 1-5.  
    arr\[arr.length\] = 'new array element'; //  элементу массива с номером 5 (свойство массива arr.length равно 5) присваивается текстовое значение 'new array element'
    
  
7.  Присвоение новому массиву значений уже существующего в системе массива:
    
    arr = new Array();  
    arr\[0\] = 'one';  
    arr\[2\] = 'three';  
    alert (arr\[0\]); // возвращает значение 'one'  
    arr1 = arr; // Присвоение новому массиву arr1 значений массива arr  
    alert (arr1\[2\]); // возвращает значение 'three'
    

  
  
Элементы массивов **могут иметь различный тип**:

var Array = \['one', 'two', 3, true\]; // это объявление массива корректно

  
О способах работы с массивами объектов будет рассказано далее.

1.  Выполните следующий код:
    
    var Array = \['one', 'two', 'three'\];  
    alert (Array\[2\]); 
    
    Какое значение будет выведено на экран? Почему? Какому элементу массива оно будет соответствовать?   
     
    
2.  Выполните следующий код:
    
    arr = new Array();  
    arr\[0\] = 'one';  
    arr\[2\] = 'three';  
    alert (arr\[1\]); 
    
    Каков будет результат выполнения кода? Почему?
