## Работа с тернарным оператором (оператором ?)

Тернарный (трехчастный) **оператор «вопросительный знак» (?)** выполняет ту же функцию, что и оператор IF, но является более упрощенным.

Общий формат ветвления с помощью условного оператора «вопросительный знак» в системе WebTutor имеет следующий вид:

( <условие> ) ? < выражение 1> : < выражение 2>

В случае выполнения условия исполняется выражение 1, а в противном случае – выражение 2.

Условие ветвления заключается в круглые скобки, выражение, выполняемое в случае исполнения условия, – после знака вопроса (?), а выражение, выполняемое в случае неисполнения условия, – после знака двоеточия (:). В этом случае фигурные скобки не используются.

  
Приведем пример использования оператора «вопросительный знак»:

age = 18;  
(age > 18) ? accessAllowed = true : accessAllowed = false;   
// если выполняется условие, то переменная accessAllowed принимает первое значение, если не выполняется - второе  
alert (accessAllowed);

  
Приведенный выше пример можно преобразовать следующим образом:

age = 18;  
accessAllowed = (age > 18) ? true : false;   
alert (accessAllowed);

2.  2) Измените пример так, чтобы выполнялось условие оператора. Проверьте работу измененного примера.
