## Работа с оператором IF

**Оператор IF** состоит из:

1.  служебного слова _if (если)_,
  
3.  _условия_, которое записывается в скобках после служебного слова _if_, и
  
5.  _действия_ (одного или некоторых выражений, которые выполняются при соблюдении условия).   
      
      
    Оператор IF может также включать в себя (но это не обязательно):
6.  служебное слово _else (иначе)_ и
7.  _действия_, выполняемого при несоблюдении указанного условия (1).

Общий формат ветвления с помощью условного оператора IF в системе WebTutor имеет следующий вид:

if ( <условие> )   
{  
     <блок команд 1>  
}  
else   
{  
     <блок команд 2>  
}

Условие ветвления заключается в круглые скобки, а блоки команд – в фигурные.

  
Например:

year = 2015  
if (year == 2015) // условие «равно»  
{  
     alert( 'Да вы знаток!' );  
}   
else   
{  
     alert( 'А вот и неправильно!' ); // любое значение, кроме 2015  
}

  
Условие может содержать следующие основные операторы сравнения:  
\== (два знака «равно») – проверка равенства  
\> – больше   
< – меньше  
\>= – больше или равно  
<= – меньше или равно  
! – отрицание условия (например, !== означает «не равно»)

Внимание! Один знак равенства в выражении условия имеет другой смысл. Не допустите ошибку!

  
Действия записываются в фигурных скобках (если действие состоит из одного выражения, то ставить фигурные скобки не обязательно).

Условие со значением _null_ соответствует _false_. Такое условие может быть использовано для работы с необязательными аргументами функций булевого типа со значением по умолчанию _false_.
