## Проверка значений undefined, null и пустого строкового значения

**Значения undefined, null и пустое строковое значение** в некоторых аспектах похожи, но имеют существенные отличия.

Значение **undefined** возвращается, если переменная была объявлена, но значение переменной не было установлено.

var A1; // значение переменной A1 не определено  
if (A1 == undefined )  
      alert( 'undefined' ) ; // возвращает 'undefined'

  
Значение **null** – это несуществующее значение, оно может рассматриваться как преднамеренное отсутствие значения какого-либо объекта. Значение null должно быть явно назначено программистом.

A2 = null; // переменной A2 присвоено значение null  
if (A2 == null )  
      alert( 'null' ) ; // возвращает 'null'

  
В отличие от undefined и null **пустое строковое значение** является строкой, не содержащей ни одного символа.

A3 = ''; // переменной A2 присвоено пустое строковое значение  
if (A3 == '' )  
      alert( 'пустое строковое значение' ) ; // возвращает 'пустое строковое значение'
