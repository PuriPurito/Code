## Конструкция <% ... %>

_Конструкция **<% ... %>**_ используется для исполнения кода, заключенного между тегами **<%** и **%>**, на стороне сервера.

Все, что находится вне указанной конструкции, отображается без изменений.   
Подобная конструкция часто используется для создания файлов типа _.html, .css, .xml_ и т.п. Например, текст вне конструкции **<% ... %>** рассматривается как код HTML, а внутри конструкции – как код программы на языке Java Script.  
Конструкция **<% ... %>** нередко встречается, например, в программном коде шаблонов документов, в текстах уведомлений, печатных форм и т.д.

Встречается также конструкция **<%= ... %>**, которая может использоваться для вывода строки или результата расчета.

В следующем примере описываются _ячейки таблицы_ (_тег <TD>_):

<TD WIDTH="<%=\_width\*2%>" BGCOLOR="<%=\_color%>"> <%=(\_title == undefined ? '' : \_title)%></TD>

Ширина ячеек (_WIDTH_) определяется значением переменной _\_width_, умноженным на 2, цвет фона (_BGCOLOR_) определяется значением переменной _\_color_, а в ячейках записывается пустое значение или значение переменной _\_title_.
