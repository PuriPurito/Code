## Определение количества элементов массива

Ранее мы уже говорили о встроенных функциях для работы с массивами.  
Рассмотрим здесь одну, часто используемую встроенную функцию **ArrayCount**.

  
Функция ArrayCount возвращает количество элементов массива.  
Например:

\_query\_str = "for $elem in test\_learnings return $elem ";   
TestArray = XQuery(\_query\_str);  
alert (ArrayCount (TestArray));
