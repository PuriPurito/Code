## Преобразование массива в строку

Имеется возможность преобразовать массивы произвольного формата и их элементы в строку. Для этого удобно использовать функцию **array\_to\_text** из встроенной библиотеки **tools**.  
Далее приводятся примеры преобразования массива в строки форматов **XML** и **JSON**.
