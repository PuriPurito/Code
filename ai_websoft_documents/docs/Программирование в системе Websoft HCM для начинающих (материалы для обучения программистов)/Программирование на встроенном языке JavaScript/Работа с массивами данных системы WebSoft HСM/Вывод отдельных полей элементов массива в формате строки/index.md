## Вывод отдельных полей элементов массива в формате строки

Это форма вывода данных, удобная для отладки и проверки результатов работы программы.  
Для такой формы вывода формируем строковое значение, соединяющее некоторый текст, значения полей и символы _'\\n'_, означающие перенос строки.

Рассмотрите следующий пример:

\_query\_str = "for $elem in test\_learnings return $elem ";   
TestArray = XQuery(\_query\_str);  
  
str = 'Были отобраны следующие данные: \\n'; // здесь формируется заголовок выводимых данных; символ '\\n' означает переход на следующую строку  
i=1;  
for(q in TestArray) // выполняется перебор элементов массива  
{  
     elem = q.person\_fullname + ' закончил сдачу теста ' + q.assessment\_name;  
     str = str + ' - ' + elem + '\\n'; // в выводимое строковое значение добавляется информация об очередном элементе массива   
  
     if (i == 3) // перебираются первые три элемента массива  
          break;   
     i=i+1;  
}  
alert ( str ); // вывод сформированного строкового значения
