## Перебор элементов массива

Здесь имеется в виду получение программистом доступа к каждому из элементов массива. Обычно для этих целей используются циклы.   
Перебор элементов состоит в том, что мы в цикле просматриваем все элементы массива и, если нужно, выполняем с этими элементами некоторые действия.

  
В следующем примере производится перебор элементов полученного массива (законченных тестов) и вывод на экран ФИО отобранных сотрудников (красным шрифтом выделен новый код в разделе «Работа с массивами данных системы WebTutor»). Используется цикл с перебором элементов:

\_query\_str = "for $elem in test\_learnings return $elem ";   
TestArray = XQuery(\_query\_str);  
for (coll in TestArray)  
{  
    alert (coll.fullname);  
}

Внимание! В данном примере может быть выведено на экран много элементов (все законченные тесты). Для сокращения работы с этой программой можно использовать следующий программный код:

\_query\_str = "for $elem in test\_learnings return $elem ";   
TestArray = XQuery(\_query\_str);  
  
i=1;  
for(coll in TestArray)  
{  
     alert(coll.person\_fullname + ' закончил сдачу теста ' + coll.assessment\_name);  
     // ограничение количества элементов, которые выводятся на экран  
     if (i == 3)  // если показано 3 элемента  
          break; // остановить цикл  
     i=i+1;  
}
