## Функции для работы с массивами

Для работы с массивами разработаны специальные встроенные функции.  
Рассмотрим для примера несколько основных функций.

**ArrayExtract** – выбор значения определенного поля (атрибута) из каждого элемента массива и возвращение нового массива той же длины, содержащего выбранные значения.  
В данную функцию передаются два аргумента – название массива, из которого производится выбор, и название поля, значения которого необходимо выбрать.   
При формировании второго аргумента может быть использована переменная **This**, обозначающая текущий объект.  
Например:

arrRez1 = ArrayExtract( arrPerson, 'fullname' ); // функция выделяет значения атрибута, указанного во втором аргументе (т.е. полное именование (ФИО) отобранных сотрудников) из исходного массива arrPerson

или иначе:

arrRez1 = ArrayExtract( arrPerson, 'This.fullname' );

**ArrayOptFind** – поиск первого элемента массива, удовлетворяющего заданному условию.  
В данную функцию передаются два аргумента – название массива, в котором производится поиск, и то выражение, которое необходимо найти в массиве.   
Выражение может вычисляться относительно каждого элемента массива. При формировании данного выражения может быть использована переменная This, обозначающая текущий элемент массива.  
При формировании второго аргумента может быть использована переменная **This**, обозначающая текущий объект.  
Например:

arrRez1 = ArrayOptFind ( arrPerson, 'sex == ' + " 'm' " ); // функция ищет первый элемент массива arrPerson, удовлетворяющий заданному условию sex == m (т.е. первого мужчину из массива arrPerson)

или иначе:

arrRez1 = ArrayOptFind ( arrPerson, 'This.sex == ' + " 'm' " );

**ArraySelect** – выбор элементов массива, удовлетворяющих заданному критерию.  
В данную функцию передаются два аргумента – название массива, в котором производится поиск, и то выражение, которое необходимо найти в массиве.   
Выражение может вычисляться относительно каждого элемента массива. При формировании данного выражения может быть использована переменная **This**, обозначающая текущий элемент массива.  
Например:

arrRez1 = ArraySelect( arrPerson, ' This.sex == "m" && This.fullname == "Калинин Михаил Михайлович" ' ); // функция возвращает массив сотрудников мужского пола с указанным именем, отобранный из массива arrPerson

**ArraySelectByKey** – выбор элементов массива с определенным значением заданного поля (ключа).  
Функция аналогична более универсальной функции **ArraySelect**, но работает быстрее.  
В данную функцию передаются три аргумента – название массива, в котором производится поиск, выражение (значение ключа), которое необходимо найти в массиве, и название поля ключа, по которому производится поиск.   
Например:

arrRez1 = ArraySelectByKey( arrPerson, 'm', 'sex' ); // функция возвращает массив сотрудников мужского пола, отобранный из массива arrPerson

Выражение может вычисляться относительно каждого элемента массива. При формировании данного выражения и названия поля ключа может быть использована переменная **This**, обозначающая текущий элемент массива.
