## Особенности работы с массивом объектов типа «поле - значение»

Подведем итоги.

Программистам WebTutor часто приходится работать с массивами объектов со многими полями.  
В данном разделе мы рассмотрим несколько примеров работы с массивами таких объектов.  
Для работы с такими объектами удобно представлять их в виде совокупности пар данных «поле - значение». 

Для начала рассмотрим массив объектов с одним полем _id_ и покажем, как обращаться к значениям такого массива: 

var arr = \[{id:1}, {id:2}, {id:4}, {id:8}\];  
alert (arr\[0\].id); // выдает значение 1  
alert (arr\[1\].id); // выдает значение 2  
alert (arr\[2\].id); // выдает значение 4  
alert (arr\[3\].id); // выдает значение 8

  
А вот массив объектов с тремя полями:

arr1 = \[  
     {   
          id : '1',   
          name : 'Иванов И.И.',   
          num : 18  
     },  
     {   
          id : '2',   
          name : 'Жирова А.В.',   
          num : 24   
     },  
     {   
          id : '3',   
          name : 'Калинин В.В.',   
          num : 15   
     }  
\]

  
1) Выведите на экран имя из второго элемента массива _arr1_.  
2) Выведите на экран числовое значение поля num из третьего элемента массива _arr1_.

Обращение к отдельным значениям полей производится через точку – <название\_массива>.<название\_поля>.

В следующем примере на экран выводятся все значения полей элементов массива:

arr1 = \[  
     { id : '1', name : 'Иванов И.И.', num : 18 },  
     { id : '2', name : 'Жирова А.В.', num : 24 },  
     { id : '3', name : 'Калинин В.В.', num : 15 }  
\]  
  
str = 'Массив объектов: \\n'; // здесь формируется заголовок выводимых данных; символ '\\n' означает переход на следующую строку  
for(q in arr1) // выполняется перебор элементов массива  
{  
     elem = q.id + " " + q.name + " " + q.num;  
     str = str + ' - ' + elem + '\\n'; // в выводимое строковое значение добавляется информация об очередном элементе массива   
}  
alert ( str ); // вывод сформированного строкового значения 

  
В системе WebTutor имеется специальная функция **ArraySum** для суммирования числовых значений полей массива однородных объектов.

arr1 = \[  
     { id : '1', name : 'Иванов И.И.', num : 18 },  
     { id : '2', name : 'Жирова А.В.', num : 24 },  
     { id : '3', name : 'Калинин В.В.', num : 15 }  
\]  
  
      A1 = ArraySum ( arr1, 'num' ); // функция возвращает сумму значений параметров num из массива arr1 (число 57)  
      alert ( A1 );

В функцию _ArraySum_ можно сразу подставить результат отбора из информационной базы системы по запросу:

      A1 = ArraySum ( XQuery('for $elem in test\_learnings return $elem'), 'score' ); // функция возвращает сумму баллов (score), набранных сотрудниками в законченных тестах (отбор производится из каталога test\_learnings)  
      alert ( A1 );
