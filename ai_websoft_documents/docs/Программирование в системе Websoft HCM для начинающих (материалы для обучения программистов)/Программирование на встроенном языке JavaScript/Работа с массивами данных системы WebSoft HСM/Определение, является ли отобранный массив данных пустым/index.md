## Определение, является ли отобранный массив данных пустым

При выполнении запроса может получиться так, что отобранный массив будет пустым. Соответственно у такого массива не будет ни одного элемента, и с этими элементами нельзя будет произвести никакие действия.   
Как же определить, является ли отобранный массив данных пустым?

  
Это можно сделать, например, с помощью функции **ArrayCount**, о которой говорилось в предыдущем разделе, с помощью функции **ArrayOptFirstElem** или и с помощью атрибута массива **length**.

  
Рассмотрим следующие примеры.

  
Пример 1:

\_query\_str = "for $elem in collaborators where contains($elem/org\_name, 'Молодежный центр') return $elem ";   
// отбираются все записи сотрудников, у которых в качестве места работы указана организация,   
// в названии которой содержится выражение «Молодежный центр»  
personArray = XQuery(\_query\_str);  
elemsNum = ArrayCount (personArray); // определение количества элементов результирующего массива   
if (elemsNum > 0) alert ('Количество объектов: ' + elemsNum); // для непустого массива на экран выводится количество элементов  
if (elemsNum == 0) alert ('Массив personArray является пустым - объекты не найдены'); // если массив является пустым, выводится соответствующее сообщение

  
Пример 2 (с помощью функции ArrayOptFirstElem):

if ( ArrayOptFirstElem(Array) == undefined )  
     alert ('Массив пустой');

Пример 3 (с помощью второго параметра функции ArrayOptFirstElem):

varA1 = ArrayOptFirstElem (arrA1, 'Массив пустой'); // Если массив пустой, то в переменную varA1 передается второй параметр.  
if ( varA1 ==  'Массив пустой')   
      alert (varA1); // выводится сообщение 'Массив пустой'

Пример 4 (с помощью атрибута массива length):

if ( Array.length == 0 )  
     alert ('Массив пустой');
