## Работа с массивами данных системы WebSoft HСM

В работе с массивами данных системы WebSoft HСM используются некоторые подходы, характерные для простых массивов данных. При изучении этого раздела нам придется также вспомнить описание запросов и циклов.  
См. также статью А. Королькова «Работа с массивами данных».

Для работы с массивами используются специализированные встроенные функции. Некоторые из этих функций будут рассмотрены далее.

Рассмотрим следующий пример:

\_query\_str = "for $elem in test\_learnings return $elem ";   
// сформирована строка запроса, отбирающего все законченные тесты  
TestArray = XQuery(\_query\_str);  
// для выполнения запроса используется встроенная функция XQuery  
// отбираются все записи законченных тестов 

  
Каждый элемент массива _TestArray_ является отдельным объектом системы WebSoft HСM (в данном случае, объектом типа **Законченный тест**). 

Вот некоторые основные операции, которые мы можем выполнить с подобным массивом:  
 

1.  Перебор элементов массива объектов.
2.  Определение количества элементов массива объектов.
3.  Определение, является ли массив пустым.
4.  Сортировка массива.
5.  Выборка первого элемента массива. 
6.  Выборка нескольких элементов массива.
7.  Работа с массивом объектов типа «параметр - значение».
8.  Вывод элементов массива.
9.  Преобразование массива в строку. 

  
Подробнее о работе с массивами объектов будет рассказано далее.
