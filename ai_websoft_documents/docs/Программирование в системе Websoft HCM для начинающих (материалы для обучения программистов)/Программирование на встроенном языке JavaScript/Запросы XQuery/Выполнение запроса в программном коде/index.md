## Выполнение запроса в программном коде

Для выполнения запроса в программном коде используется встроенная функция **XQuery**.

Вот пример применения запроса:

\_query\_str = " for $elem in collaborators where contains($elem/fullname, 'ин') return $elem";   
// сформирована строка запроса, отбирающего все записи сотрудников, фамилия, имя или отчество которых содержит (contains) выражение «ин»  
personArray = XQuery(\_query\_str);  
// для выполнения запроса используется встроенная функция **XQuery**  
// отбираются все записи сотрудников, фамилия, имя и отчество которых содержит выражение «ин»   
// personArray является массивом объектов **Сотрудник**, отобранных запросом.   
  
// Далее следует перебор элементов полученного массива и вывод на экран ФИО отобранных сотрудников:  
for (coll in personArray)  
{  
    alert (coll.fullname);  
}

Результат выполнения программного кода:  

В тексте запроса XQuery можно использовать переменные или константы.  
В этом случае удобно использовать встроенную функцию XQueryLiteral. Функция сама определит тип данных для XQuery-запроса.  
Тогда текст запроса приобретает следующий вид:

cFullName = 'Жирова Антонина Васильевна'; // ФИО сотрудника  
// найти все незавершенные тесты для сотрудника  
\_query\_str = "for $elem in active\_test\_learnings where $elem/person\_fullname =" + XQueryLiteral( cFullName ) +" return $elem";  
arrActiveTest = XQuery(\_query\_str);

Подробнее о работе с массивами объектов будет рассказано далее.
