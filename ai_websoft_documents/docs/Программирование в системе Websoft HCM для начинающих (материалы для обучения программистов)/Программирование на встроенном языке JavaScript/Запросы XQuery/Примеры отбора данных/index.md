## Примеры отбора данных

Приведем некоторые примеры отбора данных из каталога collaborators на языке **XQuery**.   
В результате отбора формируется массив объектов. О работе с массивами объектов будет подробнее говориться в специальной статье.

1.  Отбор сотрудников по названию организации:
    
    for $elem in collaborators where contains($elem/org\_name, 'Молодежный центр') return $elem  
    // отбираются все записи сотрудников, у которых в качестве места работы указана организация, в названии которой содержится (contains) выражение «Молодежный центр» 
    
  
3.  Отбор сотрудников по названию должности:
    
    for $elem in collaborators where contains($elem/position\_name, 'инженер') return $elem  
    // отбираются все записи сотрудников, название должности которых содержит выражение «инженер» 
    
  
5.  Отбор сотрудников по ФИО:
    
    for $elem in collaborators where contains($elem/fullname, 'Иванов') return $elem  
    // отбираются все записи сотрудников, фамилия, имя или отчество которых содержит выражение «Иванов» 
    
  
7.  Отбор законченных тестов для определенного сотрудника:
    
    for $elem in test\_learnings where contains($elem/person\_fullname, 'Иванов Иван Иванович') return $elem
    
  
9.  Отбор незаконченных тестов для определенного сотрудника:
    
    for $elem in active\_test\_learnings where contains($elem/person\_fullname, 'Иванов Иван Иванович') return $elem
    
  
11.  Отбор пройденных тестов (state\_id=4) среди законченных по данному сотруднику:
     
     for $elem in collaborators where contains($elem/fullname, 'Иванов') and $elem/state\_id=4 return $elem
     
12.  
13.  Разберите подробнее элементы запроса _в примерах 4-7_.
14.  Что означает _$elem_ в указанных примерах? Может ли этот параметр называться иначе? Что получится, если переименовать данный параметр? Проверьте с помощью кода в агенте.
15.  Проверьте работу приведенных примеров (можно взять за образец код из раздела «**Выполнение запроса в программном коде**»). Если приведенный запрос не отбирает ни одного элемента, измените его так, чтобы выборка не была пустой.
