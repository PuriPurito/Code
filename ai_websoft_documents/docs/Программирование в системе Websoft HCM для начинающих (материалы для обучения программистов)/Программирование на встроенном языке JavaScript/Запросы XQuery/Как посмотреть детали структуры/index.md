## Как посмотреть детали структуры

Для того, чтобы увидеть состав и значения полей конкретного объекта в каталоге, выполните следующие действия:  
1) Откройте программу WebTutor Administrator.  
2) Нажмите комбинацию клавиш **Ctrl+Shift+F8**.  
Откроется панель запросов **XQuery**:  

3) Введите в поле Объект название каталога из списка со страницы _/view\_doc.html?mode=catalogs_ (без буквы _s_ на конце), а в поле **Поиск** – фамилию сотрудника _Васильева_. Далее нажмите на кнопку **Запрос**.  
   
В нижней части панели запросов отображаются все данные об объекте, указанные в каталоге. Названия полей можно увидеть также во второй строке **Поля**, а сформированный текст запроса – в поле **XQuery**.  
Если те или иные данные в системе (и в каталоге) не указаны, то в нижней части панели запросов эти данные также будут отсутствовать (например, на приведенном выше скриншоте отсутствует значение _code_). 

Подробнее о панели запросов – см. здесь.

Для того, чтобы увидеть состав и значения полей документа объекта, выполните следующие действия:  
1) Откройте программу WebTutor Administrator.  
2) Перейдите в блок **Дизайнер** и откройте объект **Агент** (можно создать новый объект **Агент**).  
3) Введите на вкладке **Программный код** следующий код:

_\_query\_str = "for $elem in collaborators where $elem/fullname ='Васильева Людмила Петровна' return $elem";  
personArray = XQuery(\_query\_str); // выполнение запроса по поиску сотрудника  
personArray1 = ArrayFirstElem (personArray); // на всякий случай, выбирается первый элемент массива  
alert (personArray1.fullname);  
alert (personArray1.id);  
doc = OpenDoc (UrlFromDocID (personArray1.id)); // открытие документа объекта  
alert ( tools.object\_to\_text (doc.TopElem, 'xml') ); // вывод на экран данных документа объекта в формате XML_

4) Выполните программный код, нажав на кнопку **Выполнить агент на стороне клиента**.
