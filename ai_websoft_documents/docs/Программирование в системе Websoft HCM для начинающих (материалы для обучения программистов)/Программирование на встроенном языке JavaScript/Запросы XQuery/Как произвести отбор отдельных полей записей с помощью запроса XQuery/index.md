## Как произвести отбор отдельных полей записей с помощью запроса XQuery

Для того, чтобы отобрать не все, а только отдельные поля записей, можно использовать в конце выражения критерия запроса XQuery оператор   
**... return $elem/Fields('<наименование поля 1>'\[, '<наименование поля 2>'\[, ... '<наименование поля n>' \]\])**

Например:

XQuery("for $elem in collaborators return $elem/Fields('id', 'login')");

При этом рекомендуется использовать функцию _XQuery_, а не _tools.xquery_.

Можно также отобрать записи полностью, со всеми полями, а затем выбрать из них те поля, которые необходимы пользователю.
