## Работа с записью объекта в каталоге

Объекты в системе WebTutor организованы в каталоги объектов, в которых хранится некоторая информация об этих объектах.  
Каталоги объектов удобны для поиска объектов. Для этого используются запросы.

Допустим, нам нужно найти определенного сотрудника и изменить у него номер телефона.

Рассмотрим следующий пример, в котором мы выводим на экран номер телефона сотрудника Г.Ф. Анисимова или сообщение о том, что номер его телефона не указан. 

Внимание! В информационной базе Вашей системы WebTutor должен иметься сотрудник «_Анисимов Геннадий Федорович_». Если такого сотрудника в информационной базе нет, то его учетную запись нужно предварительно создать.

\_query\_str = " for $elem in collaborators where $elem/fullname = 'Анисимов Геннадий Федорович' return $elem";   
personArray = XQuery(\_query\_str);  
personArray1 = ArrayFirstElem (personArray); // на всякий случай выбираем первый элемент массива, если таких сотрудников будет несколько  
if (personArray1.phone == '')   
     alert (personArray1.fullname + ' - номер телефона не указан');  
else  
     alert (personArray1.fullname + ' - номер телефона ' + personArray1.phone);

Как мы можем узнать, что поле с номером телефона сотрудника называется _phone_?  
 

Ранее говорилось, что на сайте _news.websoft.ru_ имеется справочник каталогов объектов системы и полей этих каталогов.  
Откроем данный справочник каталогов и найдем в нем ссылку _collaborator (Сотрудник)_. Перейдем по данной ссылке. 

Находим в таблице название поля _«Телефон» - phone_.

Попробуем добавить к приведенному выше коду оператор для изменения значения поля phone.

\_query\_str = " for $elem in collaborators where $elem/fullname = 'Анисимов Геннадий Федорович' return $elem";   
personArray = XQuery(\_query\_str);  
personArray1 = ArrayFirstElem (personArray); // выбирается первый элемент массива  
if (personArray1.phone == '')    
     alert (personArray1.fullname + ' - номер телефона не указан');  
else  
     alert (personArray1.fullname + ' - номер телефона ' + personArray1.phone);  
personArray1.phone = '(901) 111-1111';

Кажется, все работает корректно – после второго запуска кода номер телефона оказывается записанным в поле phone объекта в каталоге _collaborator_.  

Но стоит нам только перезагрузить программу WebTutor Administrator, как введенный номер телефона пропадает. Измененное значение поля не сохраняется.  
Номер телефона также отсутствует в карточке сотрудника на вкладке **Анкетные данные**.

Для сохранения измененного значения поля в карточке сотрудника используется документ объекта.
