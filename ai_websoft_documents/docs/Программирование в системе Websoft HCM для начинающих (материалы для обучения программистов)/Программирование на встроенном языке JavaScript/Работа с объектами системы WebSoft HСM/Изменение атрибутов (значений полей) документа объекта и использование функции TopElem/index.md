## Изменение атрибутов (значений полей) документа объекта и использование функции TopElem

Для изменения атрибутов (значений полей) документа объекта необходимо использовать встроенную функцию **TopElem**. Данная функция применяется для перехода к корневому объекту документа, что является необходимым для обращения к атрибутам документа объекта и для изменения значения этих атрибутов.

Выполните следующий код:

\_query\_str = " for $elem in collaborators where $elem/fullname = 'Анисимов Геннадий Федорович' return $elem";   
personArray = XQuery(\_query\_str);  
personArray1 = ArrayFirstElem (personArray); // выбирается первый элемент массива  
if (personArray1.phone == '')    
     alert (personArray1.fullname + ' - номер телефона не указан');  
else  
     alert (personArray1.fullname + ' - номер телефона ' + personArray1.phone);  
doc = OpenDoc (UrlFromDocID (Int(personArray1.id)));  
te = doc.TopElem;  
te.phone = '(901) 111-1111';

Теперь для завершения операции изменения атрибута необходимо сохранить документ.  
 

Примечание – При обращении к атрибуту объекта непосредственно из документа (без использования функции _TopElem_) программный код выдает ошибку «_Unknown object property..._»:
