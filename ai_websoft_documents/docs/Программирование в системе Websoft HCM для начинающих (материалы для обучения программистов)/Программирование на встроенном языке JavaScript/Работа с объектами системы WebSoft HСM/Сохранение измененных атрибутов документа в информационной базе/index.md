## Сохранение измененных атрибутов документа в информационной базе

После изменения атрибута документа сохраним измененный документ с помощью встроенной функции **Save**.   
 

Выполните следующий код:

\_query\_str = " for $elem in collaborators where $elem/fullname = 'Анисимов Геннадий Федорович' return $elem";   
personArray = XQuery(\_query\_str);  
personArray1 = ArrayFirstElem (personArray); // выбирается первый элемент массива  
if (personArray1.phone == '')    
     alert (personArray1.fullname + ' - номер телефона не указан');  
else  
     alert (personArray1.fullname + ' - номер телефона ' + personArray1.phone);  
doc = OpenDoc (UrlFromDocID (Int(personArray1.id)));  
te = doc.TopElem;  
te.phone = '(901) 111-1111';  
doc.Save();

Проверьте карточку сотрудника и убедитесь, что введенный номер телефона теперь записан на вкладке **Анкетные данные**.
