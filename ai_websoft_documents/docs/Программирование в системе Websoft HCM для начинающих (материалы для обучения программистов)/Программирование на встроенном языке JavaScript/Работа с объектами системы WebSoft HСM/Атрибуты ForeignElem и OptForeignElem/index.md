## Атрибуты ForeignElem и OptForeignElem

Рассмотрим еще одну часто используемые возможности при работе с объектами - атрибуты **ForeignElem** и **OptForeignElem**.

Оба указанных атрибута позволяют перейти к элементу целевого массива или связанного каталога. Основное отличие между ними заключается в том, что что если элемент не найден, то при использовании **ForeignElem** возвращается ошибка и выполнение кода завершается, а при использовании **OptForeignElem** возвращается значение _undefined_ и выполнение кода продолжается дальше. Во втором случае рекомендуется делать проверку на значение _undefined_.

Необходимо обратить внимание на то, что оба указанных атрибута возвращают не документ, а каталожную запись. Если необходимо работать именно с документом, то его нужно открывать отдельно.

Рассмотрим пример.  
Допустим, нам нужно узнать название и код (в системе) организации, в которой работает сотрудник Г.Ф. Анисимов. Выведем на экран ФИО сотрудника, название и код организации.  
Если название организации может быть получено из карточки сотрудника (атрибут _org\_name_ из карточки сотрудника), то для получения кода организации приходится обращаться к атрибуту code в связанном каталоге **org (Организация)**.  
 

\_query\_str = " for $elem in collaborators where $elem/fullname = 'Анисимов Геннадий Федорович' return $elem";   
personArray = XQuery(\_query\_str);  
personArray1 = ArrayFirstElem (personArray); // выбирается первый элемент массива  
alert ( 'Найден сотрудник ' + personArray1.fullname + ' с идентификационным номером ' + personArray1.id ); // на экран выводится информация об отобранном сотруднике  
alert ( 'Сотрудник работает в организации ' + personArray1.org\_name ); // на экран выводится название организации, в которой работает сотрудник (название организации может быть взято из карточки сотрудника)  
alert ( 'Код организации ' + personArray1.org\_id.ForeignElem.code ); // производится переход к записи в каталоге организации, откуда считывается код организации (используется функция ForeignElem)

  
  
Для того, чтобы определить, как перейти из каталога **Сотрудник** в каталог **Организация**, можно обратиться к справочнику каталога **Сотрудник**.

  
В четвертом столбце данного справочника указано, что переход к смежному каталогу org производится через атрибут _org\_id_ каталога **Сотрудник**.   
Таким образом, переход к атрибутам каталога **Организация** из каталога **Сотрудник** может быть выполнен с помощью следующей строки кода:

personArray1.org\_id.ForeignElem.code

  
где:   
_personArray1_ – элемент каталога **Сотрудник**;  
_org\_id_ – атрибут каталога **Сотрудник**, связанный со смежным каталогом;   
_ForeignElem_ – функция перехода к смежному каталогу;  
_code_ – атрибут смежного каталога **Организация**.
