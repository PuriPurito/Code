## Как открыть документ объекта (переход от элемента каталога к документу)

Для открытия документа объекта по найденной записи объекта в каталоге воспользуемся встроенной функцией **OpenDoc** и **UrlFromDocID**.

В настоящее время для перехода от элемента каталога к документу рекомендуется использовать функцию **tools.open\_doc()**. Однако в текущем коде системы и в примерах можно увидеть использование выражения **OpenDoc(UrlFromDocID())**. Оба эти методы легитимны, но предпочтительно (в том числе, для будущей совместимости кода) использовать функцию **tools.open\_doc()**.

Подробнее см. описание встроенных функций **OpenDoc**, **tools.open\_doc** и **UrlFromDocID**, а также статью А. Королькова «Операция открытия документа (OpenDoc)».

  
Выполните следующий код:

\_query\_str = " for $elem in collaborators where $elem/fullname = 'Анисимов Геннадий Федорович' return $elem";   
personArray = XQuery(\_query\_str);  
cat = ArrayFirstElem (personArray); // выбирается первый элемент массива (элемент каталога)  
if (cat.phone == '')    
     alert (cat.fullname + ' - номер телефона не указан');  
else  
     alert (cat.fullname + ' - номер телефона ' + cat.phone);  
doc = OpenDoc (UrlFromDocID (cat.id)); // документ объекта  
// UrlFromDocID – определение URL объекта по его идентификатору в системе   
// OpenDoc – функция открытия XML-документа по URL и возвращения ссылки на объект  
 

  
В результате выполнения данного кода в переменную _doc_ записывается документ объекта **Сотрудник**.  
Документ объекта открыт.
