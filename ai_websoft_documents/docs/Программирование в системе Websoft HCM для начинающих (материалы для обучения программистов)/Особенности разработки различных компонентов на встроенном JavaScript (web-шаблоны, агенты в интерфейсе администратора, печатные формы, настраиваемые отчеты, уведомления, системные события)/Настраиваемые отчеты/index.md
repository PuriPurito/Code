## Настраиваемые отчеты

При формировании настраиваемых отчетов программный код может быть использован в нескольких местах: в частности, при настройке столбцов в режиме функции (**f(x)**) и в поле **Исполняемый код**.  
Рассмотрим более подробно оба этих варианта.

Подробнее см. статьи **«Основные правила получения отчетов»**, **_«Программирование настраиваемых отчётов»_** и сообщение блога **«Программисты»** о программировании настраиваемых отчетов.
