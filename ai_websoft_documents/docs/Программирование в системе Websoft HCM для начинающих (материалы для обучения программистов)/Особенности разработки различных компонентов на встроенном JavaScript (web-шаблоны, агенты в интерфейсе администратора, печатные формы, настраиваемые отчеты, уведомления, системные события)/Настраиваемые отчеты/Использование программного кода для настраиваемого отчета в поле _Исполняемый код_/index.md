## Использование программного кода для настраиваемого отчета в поле "Исполняемый код"

Для использования программного кода в настраиваемых отчетах необходимо открыть вкладку **Настройка отчета** и установить переключатель в положение **Исполняемый код**: 

В открывшееся поле необходимо ввести программный код для отбора объектов в настраиваемом отчете.  
Исполняемый код должен возвращать массив записей.  
Для возврата отобранного массива используется ключевое слово **return**. 

Общий вид исполняемого кода для настраиваемого отчета:

arrResp = XQuery("<текст запроса>"); // первичный отбор данных   
// изменение отобранного массива   
// запись результата в результирующего массив arrRes  
return arrRes; // вывод результирующего массива в настраиваемый отчет

Часто требуется преобразовывать отдельные записи первичного отобранного массива. В таком случае исполняемый код может иметь следующий вид:

arrResp = XQuery("<текст запроса>"); // первичный отбор данных  
arrRes = \[\]; // или new Array();// определение результирующего массива   
for( catResp in arrResp ) // перебор записей отобранного массива  
{  
    oR = {}; // или new Object(); определение результирующего объекта  
    // Требуемые манипуляции с данными и присвоение результирующих значений параметрам объекта oR  
    arrRes.push( oR ); // запись данных объекта oR в результирующий массив  
}  
return arrRes; // вывод результирующего массива в настраиваемый отчет

Обратите внимание на использование конструкции _<результирующий массив>.push(<объект или запись>)_ для формирования результирующего (измененного) массива.

Несколько массивов с идентичной структурой можно объединить с помощью функции ArrayUnion:   
_arrAllTests = ArrayUnion( arrTestLearnings, arrActiveTestLearnings );_

В исполняемом коде можно использовать данные заданных условий отчета.   
  
  
Для этого можно использовать выражения следующего типа:  
_{PARAM1}, {PARAM2},... {PARAM<N>}_

  
Рассмотрим несколько примеров использования исполняемого кода в настраиваемых отчетах.

Исполняемый код настраиваемого отчета может состоять всего из одной строки:  
_return XQuery('learnings', 'test\_learnings');_

Данный код возвращает объекты из каталогов **learnings** (законченные электронные курсы) и **test\_learnings** (законченные тесты).  
В случае, если в поле **Каталог документов** указан каталог **Законченный электронный курс \[learning\]**, приведенный код отбирает законченные курсы, а, если в качестве каталога документов указан каталог **Законченный тест \[test\_learning\]**, отбираются законченные тесты.

Для вывода на экран результатов отчета перейдите на вкладку **Отчет** и нажмите на кнопку **Создать отчет**:  

Рассмотрим еще один, более сложный пример.

Данный исполняемый код отбирает законченные и незаконченные тесты данного сотрудника, объединяет массивы отобранных законченных и незаконченных тестов и возвращает объединенный массив:

arrTestLearnings = XQuery ("for $elem in test\_learnings where $elem/person\_id = {PARAM1} return $elem");  
arrActiveTestLearnings = XQuery ("for $elem in active\_test\_learnings where $elem/person\_id = {PARAM1} return $elem");  
arrAllTests = ArrayUnion( arrTestLearnings, arrActiveTestLearnings );  
return arrAllTests;

В случае использования исполняемого кода в настраиваемых отчетах несущественно, какой именно каталог объектов выбирается в отчете, так как отбор производится непосредственно исполняемым кодом. Однако такой способ отбора приводит к замедлению работы отчета (особенно в случае использования значительной по объему базы данных).

В данном примере _{PARAM1}_ – это значение параметра условия отбора в отчете (такой параметр в этом отчете только один – ФИО сотрудника). Если бы таких параметров было несколько, то в исполняемом коде можно было бы использовать значения _{PARAM2}, {PARAM3}_ и т.д.

Обратите внимание на флажок **Вынести как параметр отчета** на вкладке **Настройка отчета** (_см. выше_). Если данный флажок установлен, то на вкладке **Отчет** (и на портале) появится возможность выбора значения этого параметра перед созданием отчета (_см. следующий скриншот_).
