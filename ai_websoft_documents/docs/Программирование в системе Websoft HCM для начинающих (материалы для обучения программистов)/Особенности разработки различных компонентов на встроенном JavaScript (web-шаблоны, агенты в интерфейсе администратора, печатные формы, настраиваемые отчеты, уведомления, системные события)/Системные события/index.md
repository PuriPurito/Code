## Системные события

Механизм **системных событий** позволяет настраивать поведение системы таким образом, чтобы при наступлении определенных событий в системе автоматически выполнялись определенные действия. Например, с помощью механизма системных событий может быть автоматически отправлено уведомление, выполнен программный код, добавлена запись в журнал сервера или выполнена операция.

Системные события и выполняемые при их наступлении действия описываются в карточках системных событий, список которых содержится в разделе **Системные события** блока **Дизайнер**.

Программный код для системного события вводится в поле **Выполняемый программный код** на вкладке **Общие сведения** карточки **Системное событие** в Администраторе. Также необходимо указать тип действия **Выполнить программный код**. В этом случае при наступлении отмеченного события будет выполнен соответствующий программный код.  
 

Например, для события Назначение электронного курса (и для условия назначения курса Л.П. Васильевой) мы введем следующий код:

// Находим программно сотрудника Л.П. Васильеву с помощью функции tools.get\_doc\_by\_key  
oCollab = tools.get\_doc\_by\_key ( 'collaborator', 'fullname', 'Васильева Людмила Петровна' );  
alert ( 'Найден сотрудник ' + oCollab.TopElem.fullname + ' с идентификационным номером ' + oCollab.DocID ); // выводится информация об отобранном сотруднике  
// Формируем уведомление для сотрудника с помощью функции tools.create\_notification; для примера формируем сообщение с кодом типа уведомления '9' - Уведомление сотрудника о логине и пароле  
tools.create\_notification( '9', Int(oCollab.DocID), '' );  
// О нумерации кодов типов стандартных уведомлений и наименованиях переменных для таких уведомлений - см. также статью «Использование в тексте шаблона уведомлений операторов и выражений».

Таким образом, в случае назначения сотруднику Л.П. Васильевой электронного курса ей будут высланы для напоминания ее логин и пароль в системе.
