## Использование диалоговых окон для остановки запущенного агента

При запуске агента из Администратора (из клиента) иногда возникает необходимость вывести на экран основные исходные данные, просмотреть их и далее принять решение о том, продолжать ли работу агента или нет.

В системе Websoft HCM это удобно сделать с помощью диалоговых окон **Screen.MsgBox** и **Screen.ModalDlg**.  
  
**Использование диалогового окна Screen.MsgBox для остановки агента**

Для остановки запущенного агента с помощью диалогового окна **Screen.MsgBox** можно использовать следующий код:

if ( ! Screen.MsgBox( 'Агент будет запущен со следующими исходными данными         \\nПоле1: Значение 1\\nПоле2: Значение 2\\nПоле3: Значение 3\\n\\nДанные корректны, начать выполнение агента?', ' Проверка исходных данных', 'question', 'yes,no' ) )  
{  
      Cancel(); // завершение работы агента  
}  
  
// продолжение выполнения агента  
alert ("Работа программного агента продолжается");

  
После нажатия на кнопку **Да** работа программного агента продолжается, а после нажатия на кнопку **Нет** или в случае принудительного закрытия окна – работа агента завершается.

**Использование диалогового окна Screen.ModalDlg** **для остановки агента**  
  
Для остановки запущенного агента с помощью диалогового окна **Screen.ModalDlg** можно использовать следующий код:  
 

var docDlg = OpenDoc( 'x-local://wtv/wtv\_dlg\_edit\_list\_item.xml' );  
                                docDlg.TopElem.title = 'Проверка исходных данных';  
                                docDlg.TopElem.message = ' Агент будет запущен со следующими исходными данными         \\nПоле1: Значение 1\\nПоле2: Значение 2\\nПоле3: Значение 3\\n\\nДанные корректны, начать выполнение агента?';  
                                docDlg.TopElem.height = 50;  
                                docDlg.TopElem.width = 20;  
   
Screen.ModalDlg( docDlg );  
  
// продолжение выполнения агента  
alert ("Работа программного агента продолжается");

   
После нажатия на кнопку **Применить** работа программного агента продолжается, а после нажатия на кнопку **Отмена** или в случае принудительного закрытия окна – работа агента завершается.
