## Агент "Удаление подписок уволенных сотрудников"

Рассмотрим еще один **агент, удаляющий подписки уволенных сотрудников**.

Пакет с указанным агентом можно скачать в разделе "**Полезные компоненты**" или в данной статье на вкладке **Файлы**.

Скачайте пакет и установите его в системе.

Установленный агент можно найти в разделе **Агенты сервера** (в модуле **Дизайнер**). Данный шаблон имеет название **Удаление подписок уволенных пользователей**.  

Разберем программный код агента. Комментарии выделены красным шрифтом (текст комментария относится к блоку кода, расположенного выше него), код шаблона - синим.

// Агент, который вызывается на сервере (обычно периодически) для удаления подписок уволенных пользователей  
  
dismissed = XQuery( 'for $elem in collaborators where $elem/is dismiss\=true() return $elem' );  
// Найдем уволенных пользователей  
  
for (employee in dismissed)  
{  
// Проходим в цикле по уволенным  
   
     subscribtions = XQuery( 'for $elem in subscriptions where $elem/person\_id\='+employee.id+' return $elem' );  
     // Найдем подписки для данного пользователя  
  
     arr = ArraySelectAll( subscribtions );  
     // Т.к. мы будем удалять документы, то воспользуемся функцией ArraySelectAll - она написана так, что по массиву, полученному в результате ее выполнения, можно проходить циклом и удалять документы (просто по результатам выполнения функции XQuery этого делать нельзя)  
  
     if( ArrayCount( arr )>0 )  
     {  
     // Если для пользователя есть подписки. Посчитаем количество элементов массива с помощью функции ArrayCount  
  
          alert( "Есть подписки для пользователя: " + employee.fullname );  
          // Выдадим сообщение с помощью функции alert - если агент, выполняется на сервере, то результаты записываются в файл xhttp<...>.log на сервере. Если агент выполняется на клиенте, то открывается соответствующее информационное окно.  
  
          for ( subs in arr )  
          {  
          // Пройдем по подпискам  
  
               alert( "Удаляю подписку с идентификатором " + subs.document\_id );               DeleteDoc( UrlFromDocID( subs.id ) );  
               // Удалим документы подписок с помощью функции DeleteDoc - они попадут в корзину, откуда их можно будет восстановить  
          }  
     }  
}
