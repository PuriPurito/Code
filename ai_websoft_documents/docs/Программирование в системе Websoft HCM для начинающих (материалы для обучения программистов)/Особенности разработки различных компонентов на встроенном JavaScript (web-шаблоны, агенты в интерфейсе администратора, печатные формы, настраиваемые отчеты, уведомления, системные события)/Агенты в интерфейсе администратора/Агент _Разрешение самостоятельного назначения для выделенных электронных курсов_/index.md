## Агент "Разрешение самостоятельного назначения для выделенных электронных курсов"

Рассмотрим агент - **"Изменение параметров электронного курса"**. Данный агент применяется в интерфейсе Администратора к выделенному списку электронных курсов и выставляет выделенным электронным курсам указанное значение параметра "**Разрешить самостоятельное назначение курса**" ("да" или "нет").

Пакет с данным агентом можно скачать в разделе "**Полезные компоненты**" или в данной статье на вкладке **Файлы**.

Скачайте пакет и установите его в системе.

Установленный агент можно также найти в разделе **Агенты сервера** (в модуле **Дизайнер**). 

Так как агент изменяет параметры электронных курсов, он прикрепляется к блоку **Дистанционное обучение**.

Разберем программный код этого агента. Комментарии выделены красным шрифтом (текст комментария относится к блоку кода, расположенного выше него), код шаблона - синим.

// Агент вызывается из интерфейса Webtutor Administrator и, будучи примененным к нескольким электронным курсам, меняет один из их атрибутов. В данном примере устанавливается разрешение на самоназначение выделенных курсов  
  
arr = OBJECTS\_ID\_STR.split( ; );  
// В переменной OBJECTS\_ID\_STR хранится список кодов выделенных объектов, разделенных символом ";". Эта переменная имеет тип строка (String)  
// К любой переменной типа String, можно применить метод split, указав в качестве параметра разделитель (в нашем случае разделителем является символ "_точка с запятой_"). Результатом выполнения метода будет массив идентификаторов, который мы присваиваем переменной arr  
  
for ( sid in arr )  
{  
     // Проходим в цикле по массиву идентификаторов  
     // arr - массив строк. Нам нужно перевести значения в число (Int), чтобы передать параметр в функции UrlFromDocID и затем в OpenDoc  
     id = Int( sid );  
  
     // Открываем документ. Переменной doc присваиваем информационную структуру документа, аналогичную XML-структуре объекта. Чтобы посмотреть - нажмите Ctrl+Shift+C на объекте и вставьте (Ctrl+V) - в Notepad.  
     doc = OpenDoc( UrlFromDocID( id ) );  
  
     // Проверяем значение поля **Name** - это поле есть в любом документе и его значение равно типу документа (для электронного курса - оно должно иметь значение **course**). Если это не так - выдаем сообщение об ошибке и переходим к следующему шагу цикла (continue)  
     _// (в системе WebTutor_ _учитывается регистр букв –_ **_Name_** _и_ **_name_** _представляют собой различные идентификаторы)_  
     // Атрибут TopElem встроенного объекта XmlDoc возвращает корневой элемент документа и используется, в частности, для обращения к атрибутам документа и для их изменения.   
     if( doc.TopElem.Name!="course" )  
     {  
          alert( "Документ с идентификатором "+id+" не являектся электронным курсом" );          continue;  
     }  
  
     // Выдадим сообщение с помощью функции alert - если агент, выполняется на сервере, то результаты записываются в файл xhttp<...>.log на сервере. Если агент выполняется на клиенте, то открывается соответствующее информационное окно.  
     alert( "Модификация параметров документа " + id );  
  
     // В поле **yourself\_start** (разрешить самостоятельное назначение курсов) нашего документа записываем значение true (если самоназначение разрешено) или false (если оно запрещено). В данном примере самоназначение курса разрешено   
     doc.TopElem.yourself\_start = true;  
  
     // сохраняем документ с помощью метода Save  
     doc.Save();  
}
