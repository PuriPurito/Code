## Web-шаблоны

Рассмотрим в качестве примера шаблон портала, выводящий список электронных учебных курсов. Принципиальный вид отображения шаблона на портале приведен на картинке:  
   
Пакет с шаблоном можно скачать в разделе "**Полезные компоненты**" или в данной статье на вкладке **Файлы**.

Скачайте пакет и установите его в системе.

Установленный web-шаблон можно найти в разделе **Шаблоны документов** (в модуле **Дизайнер**). Данный шаблон имеет название **Каталог электронных курсов** и код **news\_websoft\_catalog**.  

Откройте электронную карточку шаблона и перейдите на вкладку **Программный код**:  

Разберем программный код шаблона.  
Комментарии выделены красным шрифтом (текст комментария относится к блоку кода, расположенного выше него), код шаблона - синим.  
Обратите внимание на программный код типа _<%=ВЫРАЖЕНИЯ%>_. Данная конструкция указывает на исполняемый код _JavaScript_. Код вне указанных символов представляет собой программу на языке _HTML_. Иначе говоря, конструкции _<%=ВЫРАЖЕНИЯ%>_ являются вставками _JavaScript_ в код _HTML_.

// Начало кода шаблона на языке HTML.   
<table>  
     <tr>  
          <td class="tableRowEven"><b>Название</b></td>  
          <td class="tableRowEven"><b>Инфо</b></td>  
          <td class="tableRowEven"><b>Количество модулей</b></td>  
          <td class="tableRowEven"><b>Максимальный балл</b></td>  
          <td class="tableRowEven"><b>Проходной балл</b></td>  
          <td class="tableRowEven"><b>Можно завершать без проходного балла</b></td>  
          <td class="tableRowEven"><b>Разрешено самоназначение курса</b></td>  
          <td class="tableRowEven"><b>Продолжительность (дней)</b></td>  
          <td class="tableRowEven"><b>Код курса</b></td>  
     </tr>  
     // Это обычный HTML-блок - рисуем заголовок таблицы. Никакое программирование здесь не используется  
  
     <%  
     // Такая конструкция говорит о том, что в шаблоне начинается исполняемый код - т.е. далее идет не HTML, а JavaScript. Предполагается что синтаксис JavaScript вам знаком   
  
          arr=XQuery ("for $elem in courses order by $elem/name return $elem");  
          // Переменной arr присваиваем результат выполнения функции XQuery - т.е. массив объектов, выбранных из базы данных. В данном XQuery-запросе мы делаем выборку из каталога (таблицы) **courses**. Запрос возвращает все курсы, отсортированные  (по умолчанию по возрастанию) по полю name (название курса). Чтобы узнать, как называется интересующая вас таблица, ознакомьтесь с объектной моделью системы (Справочником каталогов).  
  
          for (i in arr)  
          {  
               // Проходим циклом for по массиву arr, значение текущего элемента массива сохраняется в переменной i. Значение элемента данного массива - это структура данных, содержащая набор полей, соответствующих структуре каталога. Например, выражение i.name возвращает значение поля name текущего элемента каталога  
  
               course = OpenDoc(UrlFromDocID( Int( i.id ))).TopElem;  
               // Переменной _course_ мы присваиваем значение функции OpenDoc. Результатом работы функции является структура данных, содержащая данные объекта (в нашем случае электронного курса) с определенным идентификационным номером. Идентификационный номер объекта (курса) хранится в поле id каталога Courses. Мы открываем документ, т.к. нам понадобятся некоторые поля карточки курса (например, описание), которых нет в каталоге.  
  
     %>  
     // Такая конструкция говорит о том, что в шаблоне заканчивается исполняемый код JavaScript. Далее снова идет HTML  
  
     // Для каждого курса создаем новую строку  
     <tr>  
          <td class="tableRowOdd" width=30%><a href="/view\_doc.html?mode=course\_info&object\_id=<%\=i.id%>"><%\=i.name%></a></td>  
          // Это обычный HTML код, но в нем есть конструкция типа <%=ВЫРАЖЕНИЕ%> - такая конструкция является фрагментом на JavaScript. В данной строке мы вставляем имя курса (i.name) и формируем ссылку на карточку курса с использованием его идентификационного номера (i.id)  
  
          <td class="tableRowOdd">  
               <a href=#onclick= "document.getElementById('<%\=i.id%>').style.display = document.getElementById('<%\=i.id%>').style.display == 'none' ? 'inline' : 'none'; document.getElementById('pic\_<%\=i.code%>').src = document.getElementById('<%\=i.id%>').style.display == 'none' ? '/pics/plus.jpg' : '/pics/minus.jpg';   
return false;"> <img id="pic\_<%\=i.code%>" src=<%\=(course.desc\=='') ? ('/pics/1blank.gif') : ('/pics/plus.jpg')%> border=0></a>  
          </td>  
          // В колонке "Инфо" мы показываем картинку с +/- в случае, если у курса есть описание, или пустую картинку (1blank.gif), если описания нет. Чтобы проверить, есть ли описание, мы используем конструкцию <%\=(course.desc\=='')?('/pics/1blank.gif') : ('/pics/plus.jpg')%>. Чтобы узнать структуру объекта (например, для того, чтобы определить, что поле описания в карточке курса называется **_desc_**) в интерфейсе администратора установите курсор на интересующий вас объект и нажмите комбинацию клавиш **Ctrl+Shift+C**. Затем перейдите в программу **Notepad** и нажмите **Ctrl+V**. Вы увидите XML-структуру объекта с полями. При нажатии на картинку (код **onclick**) мы прячем или показываем строку с описанием  
  
          <td class="tableRowOdd"><%\=ArrayCount(course._parts_)%></td>  
          // Секция _parts_ в карточке курса - не поле, а массив полей (список модулей курса). Применив к ней функцию ArrayCount мы получим количество модулей курса  
  
          <td class="tableRowOdd"><%\=course.max\_score%></td>  
          <td class="tableRowOdd"><%\=course.mastery\_score%></td>  
          <td class="tableRowOdd"><img src=/pics/<%\=course.finish\_without\_mastery\_score?'vwicn082.gif':'no.gif'%>\></td>  
          <td class="tableRowOdd"><img src=/pics/<%\=course.yourself\_start?'vwicn082.gif':'no.gif'%>\></td>  
          <td class="tableRowOdd"><%\=course.duration%></td>  
          <td class="tableRowOdd"><%\=course.code%></td>  
          // Вставляем колонки с другими полями  
  
     </tr>  
     // Строка с параметрами курса закончилась  
  
     <tr id=<%\=i.id%> style="display:none">  
          <td class="tableRowEven" colspan=10><%\=course.desc%></td>  
     </tr>  
     // Для описания у нас будет отдельная строка (_%=course.desc%>_) ниже строки с параметрами курса, но она будет изначально скрыта  
  
     <%  
     }  
     %>  
     // Снова конструкция на JavaScript - закрываем фигурную скобку, открытую в цикле for - конец кода, исполняемого в цикле  
  
</table>  
// Конец шаблона - закрываем таблицу

Вы можете создавать и собственные шаблоны - в разделе **Дизайнер - Шаблоны документов**.

  
**Как воспроизвести данный шаблон**

Для того, чтобы опубликовать на портале импортированный или созданный пользователем шаблон, необходимо перейти в раздел "**Портал**", создать раздел портала и на закладке "**Атрибуты**" выбрать шаблон из списка настраиваемых web-шаблонов.  
  
 

_Внимание! Для воспроизведения примера указанным ниже способом рекомендуется использовать только тестовый экземпляр системы_ _**Websoft HCM**._

1.  Создаем новый шаблон документа (**Дизайнер – Шаблоны документов**). Название шаблона: **Шаблон "Каталог электронных курсов"**  
    Код: **test****\_****example02**  
    На вкладке **Код** вводим приведенный выше пример программного кода шаблона. Для простоты уберем все комментарии или окружим их тегами, используемыми в языке HTML: <!-- и --> (_<!-- любой текст -->_) (в пределах тегов выполнения кода JavaScript <% код JavaScript %>) комментарии нужно выделять двойной косой чертой (//), как это делается в приведенном выше примере).  
      
      
     
2.  Создаем новый элемент шаблона (**Дизайнер – Элементы шаблонов**).Код: **test****\_****el****\_****example02**  
    К элементу шаблона добавляем созданный ранее шаблон под названием **Шаблон "Каталог электронных курсов"** с кодом **test****\_****example****02**.  
    Mode: **test** (это будет специальный раздел для тестирования шаблонов)  
    Зона: **main**  
    Позиция в списке: **2** (номер примера кода, чтобы элементы шаблонов примеров кода выводились на странице по порядку)  
      
     
3.  Вводим URL портала WebTutor с параметром _mode=__test_ (например, _http://localhost/view\_doc.html?mode=__test_).
    
    _Примечание: Если шаблон будет сформирован некорректно, то на странице может появиться сообщение об ошибке._
