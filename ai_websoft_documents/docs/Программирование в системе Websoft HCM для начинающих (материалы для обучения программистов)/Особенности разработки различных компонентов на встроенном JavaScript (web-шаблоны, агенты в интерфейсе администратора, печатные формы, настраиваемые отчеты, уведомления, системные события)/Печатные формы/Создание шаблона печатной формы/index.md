## Создание шаблона печатной формы

Для создания веб-шаблона печатной формы выполните следующие действия:

1.  Отформатируйте в программе Microsoft Word необходимый документ и внесите в него условные данные.  
      
     
2.  Создайте шаблон сертификата в Microsoft Word - см. пример прикрепленного исходного документа. В подготовленном ранее документе замените условные данные на условные обозначения полей в квадратных скобках (например, "Иванов Иван Иванович" замените на _\[ФИО\]_, "Эффективное управление" - на _\[Тест\]_ и т.д.). Позднее эти условные обозначения будут заменены на программный код.
    
      
     
    
3.  Определите объект, к которому будет прикреплена создаваемая печатная форма. В нашем случае это будет **"Завершенный тест"**. Указывать его будем на этапе создания печатной формы в программе Administrator.  
     
4.  Сохраните исходный документ Word как веб-страницу с расширением _htm._  
      
     
    
5.  Откройте полученный документ к примеру в Notepad++ и преобразуйте его кодировку в UTF-8. Это необходимо для корректного отображения текста печатной формы. 
    
    Вместо пунктов 3 и 4 можно использовать в MS Word следующий макрос:
    
      
    _Sub Conv1()  
    '  
    ' Макрос для Word - Сохранение файла в веб-формате с расширением htm и преобразование сохраненного файла в кодировку UTF-8  
    '  
        Name1 = ActiveDocument.FullName ' полное имя активного файла  
        x = InStrRev(Name1, ".") ' номер знака последнего вхождения точки в строку  
        String1 = Left(Name1, x - 1)  ' отсекает расширение  
        FileName$ = String1 + ".htm" ' имя активного файла с расширением htm  
          
        ActiveDocument.SaveAs2 FileName:=FileName$, FileFormat:=wdFormatHTML  
        ' сохранение файла в веб-формате с расширение htm  
        ActiveWindow.View.Type = wdPrintView  
        ' установка режима просмотра Разметка страницы вместо Веб-документ  
        ActiveDocument.Close  
        ' закрытие активного файла  
          
        ' изменение кодировки  
        SourceCharset$ = "Windows-1251" ' исходная кодировка  
        DestCharset$ = "UTF-8" ' новая кодировка  
        With CreateObject("ADODB.Stream")  
            .Type = 2  
            If Len(SourceCharset$) Then .Charset = SourceCharset$     ' указываем исходную кодировку  
            .Open  
            .LoadFromFile FileName$    ' переоткрытие файла в веб-формате (с расширением htm)  
            FileContent$ = .ReadText   ' считываем текст файла в переменную FileContent$  
            .Close  
            .Charset = DestCharset$     ' назначаем новую кодировку  
            .Open  
            .WriteText FileContent$  
            .SaveToFile FileName$, 2   ' сохраняем файл в новой кодировке  
            .Close  
        End With  
    End Sub_  
     
    
6.  Далее в любом текстовом редакторе замените названия полей, заключенные в квадратные скобки, на программный код.
    
    В нашем случае:  
    _<%=TopElem.person\_fullname%>_ - будет подставлено ФИО тестируемого  
    _<%=TopElem.assessment\_name%>_ - будет подставлено название теста  
    _<%=TopElem.score%>_ - будет подставлен набранный балл за тест  
    _<%=StrDate(Date(),false)%>_ - будет подставлена преобразованная в строку сегодняшняя дата
