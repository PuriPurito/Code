## Печатные формы

**Печатные формы** используются для автоматизированной подготовки различных служебных документов (сертификатов, протоколов, справок и т.д.).

Рассмотрим простейший вариант печатной формы - сертификат, который выдается по итогам тестирования.

Примеры шаблонов печатной формы в doc-формате и в htm-формате в кодировке _utf-8_ вместе с пакетом для Websoft HCM приложены на вкладке **Файлы**.

Для более подробного изучения программирования печатных форм можно порекомендовать _вебинар А. Королькова «Создание печатных форм в системе WebTutor»_ (см. файл **Печатные формы - Видео.zip** на вкладке **Файлы**).   
Для просмотра видеозаписи нужно разархивировать указанный архив в отдельную папку и запустить файл _vcplayer.hta_.
