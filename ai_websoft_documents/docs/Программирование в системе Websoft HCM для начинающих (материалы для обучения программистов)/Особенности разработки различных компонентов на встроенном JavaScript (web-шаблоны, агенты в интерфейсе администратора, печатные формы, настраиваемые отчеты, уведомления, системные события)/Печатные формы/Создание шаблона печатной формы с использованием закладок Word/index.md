## Создание шаблона печатной формы с использованием закладок Word

1) Выполните предварительную настройку демонстрации закладок в программе MS Word: установить флажок **Показывать закладки** (**Файл – Параметры** – вкладка **Дополнительно** – группа **Показывать содержимое документа**).   

В этом режиме границы закладок будут отображаться серыми квадратными скобками:  

2) Определите, по какому объекту системы необходима печатная форма (например, пусть это будет карточка законченного курса).  
3) Подготовьте в MS Word макет документа, как это делалось в разделе **Создание шаблона печатной формы**. Макет документа должен быть отформатирован в соответствии с потребностями пользователя. Все необходимые данные, которые будут введены в шаблон с помощью программного кода, пока что мы выделяем квадратными скобками.  

4) Готовим выражения для программного кода.  
Правила для составления таких выражений для шаблонов печатных форм с использованием закладок в Word следующие:  
\- для отображения в виде текста выполненного программного кода Websoft HCM перед выражением ставится двойной знак равенства (например, _\==TopElem.assessment\_name_);   
\- для отображения в виде текста выполненного кода HTML перед выражением ставится один знак равенства (например, _\='<img src="'+UrlAppendPath( global\_settings.settings.portal\_base\_url, '/design/default/images/logo.png')+'">'_).

Примечание – В последнем случае приведен пример вставки в печатную форму логотипа системы.

В процессе ввода вычисляемого кода могут возникнуть «нарушения» разметки, «ползти» строки или появиться избыточные переносы. На это не нужно обращать внимания – весь текст кода будет заменен на результат вычисления, и исходная разметка восстановится.  
Если нужно вставить большое количество вычисляемого кода, он может идти в несколько строк, можно применять функции библиотек, а в конце должно присутствовать выражение _return sResultString;_ (название возвращаемой переменной неважно, но это должна быть строка).

В данном случае можно будет использовать следующие выражения:  
_\[ФИО\] - ==TopElem.person\_fullname  
\[Тест\] - ==TopElem.assessment\_name  
\[Балл\] - ==TopElem.score  
\[Дата\] - ==StrDate( TopElem.last\_usage\_date, true, true, false )_ 

Программный код для полей закладок рекомендуется сначала написать в отдельном файле, а потом вставлять его в закладки.

  
Вспомните, почему в данном случае мы используем атрибут TopElem и с какой целью для вывода даты в печатную форму применяется функция StrDate?

5) Замените условные обозначения полей на программный код в закладках Word. Для этого выполните следующие действия:  
а) Выделите условное обозначение поля вместе с квадратными скобками и создайте закладку (пока закладке можно задать условное название). 

Закладки в программе MS Word формируются следующим образом: выделение фрагмента текста для закладки – **Вставка – Закладка**.

  
   
В заданном режиме закладки будут обозначаться квадратными скобками серого цвета.  
б) Вместо текста закладок введите разработанные ранее выражения вместе со знаками равенства.

Находившийся ранее в закладках условный текст должен быть полностью удален. 

Текст в MS Word приобретает следующий вид:  
   
в) сохраните полученный текстовый шаблон.

6) Далее выполните действия, описанные в разделе **Создание новой печатной формы**.   
а) Создайте в блоке **Дизайнер** новую печатную форму, укажите название формы, код, выберите нужный тип объекта и вставьте подготовленный файл Word.

б) Выберите тип формы **MS Word Document**, если нужно получить файл в формате MS Word, или **PDF (from MS Word Document)**, если нужно получить документ в формате PDF.

в) Откройте законченный тест, нажмите на кнопку  (**Печать**) и выберите в открывшемся списке соответствующую печатную форму.  

Если на компьютере открыт другой файл в программе, открывающей по умолчанию файлы в формате PDF, то может появиться сообщение об ошибке: _«Произошла ошибка при открытии данного документа. Отказ в доступе»_. Для устранения этой ошибки завершите работу программы для просмотра файлов PDF и повторите действия, описанные в пункте (в).
