## Особенности разработки показателей

**Показателями** в системе называются произвольные статистические характеристики, которые могут рассчитываться автоматически по заранее заданному алгоритму. Показатели используются в системе для решения следующих задач:  
\- автоматическое вычисление всевозможных характеристик обучения сотрудников;  
\- мониторинг производительности системы и сервера, на котором она работает;  
\- мониторинг активности сотрудников. 

Показатели, с точки зрения программирования, во многом аналогичны Коллекциям (выборкам), но отличаются тем, что они обычно возвращают не массив, а один элемент с одним свойством.

Электронные карточки показателей представлены в Администраторе в разделе **Дизайнер - Бизнес-логика - Показатели**.   

  
Впоследствии определенное значение показателя может быть передано в специальный виджет и представлено на портале.

В общем случае виджет размещается в нужном месте на портале, а в параметрах виджета должен быть указан соответствующий объект типа **Показатель**.

Стандартные объекты типа **Показатель** обычно исполняют код, содержащийся в соответствующем файле шаблона программного кода.  
Файлы шаблонов программного кода показателя обычно размещаются в папке _WebTutorServer/wtv/statistics/_ , в их названии чаще всего содержится слово _statistic_ и расширения _bs_ или _js_.  
Соответствующий файл шаблона программного кода указывается в Администраторе на вкладке **Общие сведения** карточки показателя в поле **Ссылка на файл**. Ссылка имеет следующий вид:   
_x-local://wtv/statistics/<название файла>_  

Программный код может также указываться на вкладке **Выполняемый код** карточки показателя:  

Как в файле шаблона программного кода показателя, так и на вкладке **Выполняемый код** могут использоваться следующие общие переменные:  
\- _curStatistic_ – объект показателя;  
\- _curStatisticData_ – объект текущего вычисления значения показателя;  
\- _curSaveFlag_ – флаг необходимости сохранения;  
\- _dBegin_ – дата начала периода;   
\- _dEnd_ – дата окончания периода;  
\- _curObject_ – запись каталога текущего объекта.

Результат расчета значения показателя передается в переменную-объект _curStatisticData_. У данного объекта имеются следующие основные параметры:  
\- _value (curStatisticData.value)_ – реальное значение того типа, который рассчитанный показатель имеет в системе (число, дата, строка, булево и т.д.).  
\- _value\_str (curStatisticData.value\_str)_ – то же самое значение рассчитанного показателя, преобразованное в строковый тип данных.

Рассмотрим для примера показатель «**Количество участников**» (код _event\_results_). Данный объект содержит ссылку на шаблон программного кода _wtv\_statistic\_event\_results.js_.

curStatisticData.value = ArrayCount( tools.xquery( "for $elem in event\_results where $elem/event\_id = " + curObject.id+ " return $elem/id" ) );  
curStatisticData.value\_str = StrReal( curStatisticData.value, 1 );

В данном примере выполняются следующие действия:  
1) Производится отбор количества участников мероприятия с ID, равным _curObject.id_, с помощью функции **tools.xquery**.  
2) Определяется количество отобранных элементов с помощью функции **ArrayCount**.  
3) Результат расчета преобразуется в строковый тип данных с помощью функции **StrReal**.

Начиная с _версии 2020.4_ в системе доступна отладка программного кода показателя.
