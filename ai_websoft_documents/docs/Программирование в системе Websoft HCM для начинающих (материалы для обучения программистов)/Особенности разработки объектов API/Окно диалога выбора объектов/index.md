## Окно диалога выбора объектов

Начиная с релиза 2023.2 в окно выбора параметров добавлена возможность выведения дополнительных полей, помимо каталожных.  
К окну выбора в приложениях можно добавить произвольную коллекцию.  
При этом с целью обеспечения безопасности запрещено выполнение любых XQuery запросов из программы Администратор, если у пользователя нет прав доступа к режиму "Данные". Все запросы производятся только через обращение к коллекциям, доступ к которым регламентируется клеймами.

Начиная с релиза 2023.2 добавлены параметры диалога:  
typein: false // флаг, определяющий, будет ли сразу показан список объектов, или пустой список с полем поиска - для очень больших списков  
view\_type: "" // название каталога, который будет использоваться, как шаблон для показ списка, вместо текущего каталога  
can\_be\_empty: false // флаг, означающий, можно ли выйти из диалога без выбора объекта  
display\_filter: false // флаг, означающий, показывать ли поле выбора фильтра для списка выбора  
css\_template\_id: "" // ID шаблона документа, содержащего дополнительную таблицу стилей, которая будет добавлена к стилям диалога выбора
