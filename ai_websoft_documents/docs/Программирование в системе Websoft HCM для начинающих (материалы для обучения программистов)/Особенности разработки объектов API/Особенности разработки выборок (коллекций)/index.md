## Особенности разработки выборок (коллекций)

**Коллекции (выборки)** - это операции, связанные с выборкой объектов из базы системы для отображения на портале. Они используются в различных шаблонах.

В комплект поставки системы входит большой набор готовых выборок для всех стандартных шаблонов. При необходимости можно переопределить существующие выборки или создать новые для использования в своих шаблонах.

Выборки представлены в системе в виде карточек, список которых размещен в разделе **Бизнес-логика - Выборки** блока **Дизайнер**.

Ранее в системе Websoft HCM использовалось название «выборки». В настоящее время специалисты Websoft HCM все чаще переходят на использование термина «коллекция объектов».

Выполняемый программный код коллекции объектов (выборки) может содержаться в поле на вкладке **Программный код** или в специальном файле шаблона программного кода (в этом случае название файла вносится в поле **Ссылка на шаблон** на вкладке **Общие сведения**).   
   
Стандартные коллекции объектов (выборки) обычно исполняют код, содержащийся в соответствующем файле шаблона программного кода.  
Файлы шаблонов программного кода обычно размещаются в папке _WebTutorServer/wt/web/_ , в их названии чаще всего содержится слово _collection_ и расширение _bs_.  
Программный код из указанного файла автоматически записывается в поле на вкладке **Программный код** (при этом введенное вручную содержание поля на вкладке **Программный код** удаляется безвозвратно).  

Рассмотрим для примера коллекцию «**Список резюме**» (код _MyResumeCollection_). Коллекция содержит ссылку на шаблон программного кода _view\_resumes\_collection.bs_:

xarrResumes = XQuery( "for $elem in resumes where $elem/person\_id = " + curUserID + " return $elem" );  
  
RESULT = Array();  
  
for ( catResume in xarrResumes )  
{  
    oResume                   = new Object();  
    oResume.id                = catResume.id.Value;  
    oResume.name              = catResume.name.Value;  
    oResume.profession\_area   = catResume.profession\_area.Value;  
    oResume.create\_date       = StrDate( catResume.creation\_date.Value,true,true );  
    oResume.modification\_date = StrDate( catResume.modification\_date.Value,true,true );  
    oResume.url               = tools\_web.get\_mode\_clean\_url( 'resume', null, { resume\_id : catResume.id.Value, doc\_id : Env.GetOptProperty( 'curDocID', '' ) } );  
  
    RESULT.push( oResume );  
}  
  
if ( SORT.FIELD == null )  
    RESULT = ArraySort( RESULT, "name", "+" );  
else  
    RESULT = ArraySort( RESULT, SORT.FIELD, ( SORT.DIRECTION == "ASC" ? "+" : "-" ) );

  
В этом примере можно наблюдать общую принципиальную структуру шаблонов программного кода коллекции:  
1) Выполнение первоначального отбора объектов (например, в данном случае с помощью функции **XQuery**) и создание массива отобранных объектов.  
2) Преобразование отобранного массива в соответствии с требованиями формирования коллекции.  
3) Результат формирования коллекции (массив) передается в переменную _RESULT_.

Начиная _с версии 2020.4_ в системе доступна отладка программного кода коллекции (выборки).
