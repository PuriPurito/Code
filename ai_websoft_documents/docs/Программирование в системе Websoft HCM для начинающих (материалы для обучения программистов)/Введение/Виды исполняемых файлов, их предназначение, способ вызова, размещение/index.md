## Виды исполняемых файлов, их предназначение, способ вызова, размещение

В системе WebTutor имеется целый ряд исполняемых файлов (агенты, библиотеки программного кода, шаблоны, отчеты, приложения, уведомления, системные события, выборки и др.)  
Как правило, данные файлы содержат нужные настройки или программный код в открытом виде.

Данные файлы предназначены для активации (исполнения) в процессе работы системы.

В программе WebTutor Administrator большинство исполняемых файлов находятся в блоке **Дизайнер**, однако некоторые из исполняемых файлов (например, отчеты) могут находиться и в других разделах (блоках) системы.  
При использовании базы данных типа **XML** (внутреннее хранилище), мы можем достаточно легко найти в компьютере собственно файлы, содержащие данные о тех или иных исполняемых файлах.

Для того, чтобы определить файл, описывающий структуру данного типа объекта (в данном случае, объектом является _исполняемый файл – агент_), выполните следующие действия:

1\. Откройте электронную карточку объекта в программе WebTutor Administrator.

2\. Нажмите на кнопку **Сервис**   на панели инструментов карточку объекта.   
3\. В открывшемся меню выберите команду **Показать в виде XML...**

Откроется окно объекта.  
В данном окне, в частности, можно увидеть наименование файла, описывающего структуру данного типа объекта (_x-local://wtv/wtv\_server\_agent.xmd_ (иначе говоря: _WebTutorServer/wtv/wtv\_server\_agent.xmd_ или _WebTutorAdmin/wtv/wtv\_server\_agent.xmd_)):  

Вообще, XMD файлы, описывающие структуру типов объектов, хранятся в папке сервера системы по адресу: _/wtv/wtv\_<тип объекта>.xmd_

При использовании базы данных типа **XML** каждый объект размещается в своем XML файле в папке _wt\_data/objects_ в папке сервера, а каталог – в бинарных индексных файлах в папке _wt\_data/catalogs_ в папке сервера.  
Например, файл агента с ID _0x5EA9B433697B3B6E_ размещается в файле:  
_WebTutorServer/wt\_data/objects/5EA9B433697B3B/6E.xml_

Особенности физической структуры данных для некоторых других типов СУБД указаны здесь.

Любой процесс в системе (в том числе способ вызова исполняемого файла) может быть инициирован либо пользователем, либо другим объектом, связанным с ним, либо сервером по расписанию.  
И практически в любом процессе в системе может быть предусмотрен этап выполнения программного кода на JS или на C#.  
Так что основные различия в способе вызова различных исполняемых файлов могут различаться в некоторых деталях и во внешнем проявлении.

Например, объект типа **Агент** представляет собой процесс, который состоит, по сути, из выполнения кода. Данный файл может быть запущен пользователем вручную или по специальному расписанию.

Для **настраиваемого отчета** процесс, условно говоря, состоит из трех этапов – инициализация начальных параметров, выполнение программного кода, визуализация полученных данных.  
И на среднем этапе может быть выполнен или автоматически сгенерированный код (если отчет делается только настройками) или кастомный код, написанный пользователем.

Для **шаблона** это: запрос на формирование страницы веб-сервера, формирование разметки страницы, выдача результата пользователю.  
Причем вторая часть (формирование разметки) может включать в себя выполнение кода (если это задано в шаблоне в формате ASP-вставок).

**Уведомления** в целом аналогичны шаблонам, но в этом случае производится запрос не на формирование веб-страницы, а на формирование письма (сообщения).

Наконец, **системное событие** – это тоже чистый код, который запускается он в определенном месте конкретного системного процесса.

Внимание! Никогда не изменяйте программный код и значения параметров настройки исполняемых файлов без крайней необходимости! Делайте это исключительно в том случае, если вы точно уверены в необходимости таких изменений.
