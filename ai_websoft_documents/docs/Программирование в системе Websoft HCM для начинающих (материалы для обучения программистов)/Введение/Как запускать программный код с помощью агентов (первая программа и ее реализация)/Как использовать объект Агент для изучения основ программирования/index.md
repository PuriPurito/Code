## Как использовать объект Агент для изучения основ программирования

Создадим новый объект **Агент**. Для этого выполните следующие действия:

1\. Откройте раздел **Дизайнер – Агенты сервера**.  
2\. Нажмите на кнопку **Новая запись** на панели инструментов раздела **Агенты сервера**.  

3\. В открывшемся окне **Агент сервера** введите название создаваемого объекта и его код:  
 

**Примечание** – Название агента можно вводить кириллицей, для указания кода используйте латинские буквы и цифры (возможно также применять некоторые символы – тире, подчеркивание и т.д.). Кириллицу для указания кода использовать не рекомендуется.

4\. Сохраните карточку объекта.
