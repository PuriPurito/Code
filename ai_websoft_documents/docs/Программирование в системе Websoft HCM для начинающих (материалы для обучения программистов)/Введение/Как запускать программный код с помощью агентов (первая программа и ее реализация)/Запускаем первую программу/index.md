## Запускаем первую программу

Напишем нашу первую программу и запустим ее.   
Для этого выполните следующие действия:

1\. Откройте карточку созданного ранее агента **«Изучение основ программирования»**.  
2\. Перейдите на вкладку **Программный код**.  
Проверьте тип выполняемого кода. Переключатель типа выполняемого кода должен быть установлен в положение **JS**.

**Примечание** \- По умолчанию переключатель типа выполняемого кода устанавливается в положение JS.

3\. В поле программного кода введите выражение: 

alert ('Привет, мир!'); 

4\. Сохраните карточку агента.  
5\. Нажмите на кнопку _Выполнить агент на стороне клиента_ на панели инструментов карточки агента.  
6\. Если все было выполнено корректно, то открывается окно с надписью: _«Привет, мир!»_.

**Примечание** – Не обращайте внимания на название окна _«Ошибка»_. Никакой ошибки здесь нет – это стандартное название окна _alert_, с помощью которого мы будем выводить на экран результаты обучения.

7\. Нажмите на кнопку **OK** в окне **alert** и затем с помощью кнопки **OK** обязательно закройте окно **Information**, сообщающее нам о завершении работы агента:  
 

При необходимости вы можете добавить комментарии к программному коду.
