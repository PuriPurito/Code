## Общая архитектура Websoft HCM

Общая архитектура Websoft HCM (WebTutor) приведена на следующем рисунке.

Основные компоненты решения:

*   Интерпретатор языка JavaScript
*   Unibridge - компонент для работы с различными типами СУБД
*   Системный программный код системы (шаблоны, агенты, серверные процедуры) - ядро системы. Разработан на Server-Side JavaScript

Программный код заказчика  
 

Система WebTutor поддерживает работу со следующими типами баз данных:

*   **Microsoft SQL Server** (начиная с 2008, оптимально 2012)
*   **Oracle** (11+)
*   **PostgreSQL**
*   **XML** (внутреннее хранилище)
*   **Microsoft Azure** (при облачном размещении)

В настоящем курсе мы будем, преимущественно, изучать, каким образом пользователи могут писать собственный программный код в системе WebTutor и применять его для оптимизации своей работы.  
Для простоты мы будем далее рассматривать тип базы данных **XML** (внутреннее хранилище).
