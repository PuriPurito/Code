## Использование библиотек в коде

Рассмотрим более подробно использование функций библиотеки **Tools** в программном коде.

Обращение к функции библиотеки производится следующим образом:  
_<название\_библиотеки>.<название\_функции>_  
Например:  
tools.activate\_course\_to\_person  
tools.create\_notification  
tools.get\_exchange\_date

При вызове функций в большинстве случаев нужно задать требуемые аргументы.   
Например:   
_courses\_act = tools.activate\_course\_to\_event ( event.id, course.id );  
bAccess = tools.check\_access ( curCourse, curUserID );  
tools.create\_notification( '23', \_collaborator.PrimaryKey, docEvent.TopElem.name, docEvent.TopElem.Doc.DocID, null, docEvent.TopElem );_  
  
Аргументы функций бывают двух видов – _обязательные и необязательные_.   
Аргументы функции указываются в скобках в определенном порядке, который можно уточнить на странице технического описания функции.  
Если при вызове функции какие-либо необязательные аргументы отсутствуют, их рекомендуется заменить значениями null. Если отсутствуют один или несколько аргументов в конце списка, приведенного в описании функции, то их можно опустить.

  
Приведем несколько примеров использования функций библиотеки **Tools**.

**Пример 1. Программно найти объект документа**

Для поиска объекта документа можно использовать функцию **tools.get\_doc\_by\_key**.

Перейдите по ссылке и прочитайте описание функции.  
В описании, в частности, говорится, что функция «возвращает объект документа, соответствующего указанным условиям, или null, если документ не найден».

Предварительно проверьте, что в системе, которую вы используете, имеется сотрудник Васильева Людмила Петровна.   
Если такого сотрудника нет, временно введите его (а после окончания обучения не забудьте удалить!)

Для программного поиска сотрудника Васильевой Л.П. с помощью функции tools.get\_doc\_by\_key требуется только одна строка кода (вторая строка кода добавлена для вывода результата и для проверки корректности работы системы):

_oCollab = tools.get\_doc\_by\_key( 'collaborator', 'fullname', 'Васильева Людмила Петровна' );  
alert ( 'Найден сотрудник ' + oCollab.TopElem.fullname + ' с идентификационным номером ' + oCollab.DocID ); // на экран выводится информация об отобранном сотруднике_

Введите указанный код в используемый тестовый агент и выполните его на стороне клиента.

Результат выполнения кода:  

Без использования функции библиотеки выполнить указанные действия было бы гораздо сложнее:

_sQquery = "for $elem in collaborators where $elem/fullname = 'Васильева Людмила Петровна' return $elem";  
arrObjects = XQuery( sQquery );

oCollab = ArrayOptFirstElem (arrObjects ); // функция возвращает первый элемент массива сотрудников arrObjects (в данном случае массив состоит из одного элемента)  
alert ( 'Найден сотрудник ' + oCollab.fullname + ' с идентификационным номером ' + oCollab.id ); // на экран выводится информация об отобранном сотруднике_

  
**Пример 2. Программное определение перечня ID руководителей по идентификационному номеру подразделения**

Для определения перечня ID руководителей по идентификационному номеру подразделения можно использовать функцию **tools.get\_sub\_boss\_by\_sub\_id**.

Перейдите по ссылке и прочитайте описание функции.  
В описании, в частности, говорится, что функция «возвращает массив ID руководителей (руководителей по должности) по идентификационному номеру подразделения. Если руководители не найдены, то возвращается пустой массив».

Предварительно определите ID отдела, руководителей которого мы будем определять. 

В используемой нами системе идентификационный номер отдела (отдела IT) равен 5293675553778464388.  
Найдем ID руководителей этого отдела.

Категорически не рекомендуется указывать в коде идентификационный номер объекта. Этот номер в некоторых случаях может измениться, что приведет к некорректной работе программного кода. Идентификационный номер объекта лучше определять запросом по уникальным параметрам объекта.   
В данном случае идентификационный номер объекта был использован для упрощения приведенного примера кода.

  
Откройте тестовый агент и введите следующий код: 

_arrBosses\_id = tools.get\_sub\_boss\_by\_sub\_id (5293675553778464388);  
for (boss\_id in arrBosses\_id) {  
     alert (boss\_id)  
}_

**Пример 3. Программное назначение курса сотруднику**

Для назначения курса сотруднику можно использовать функцию tools.activate\_course\_to\_person.

Перейдите по ссылке и прочитайте описание функции.  
В описании, в частности, говорится, что функция производит «назначение курса сотруднику».  
В данном случае важно, каковы будут выходные данные используемой нами функции.   
Выходные данные могут быть двух типов: **Объект XMLDoc** или **Целое число**. Если курс назначен при выполнении функции, то возвращается ссылка на вновь созданный документ обучения. Если курс был назначен ранее, но не завершен, или завершен, но не прошло еще время, указанное в атрибуте _dtLastLearningDateParam_, то возвращается ID карточки ранее назначенного курса (из каталога **active\_learning**).  
  
Предварительно проверьте, что в системе, которую вы используете, имеются сотрудник _Васильева Людмила Петровна_ и электронный курс _«Эффективные переговоры»_.  
Если такого сотрудника и такого курса нет, временно введите их (а после окончания обучения не забудьте их удалить!)

Откройте тестовый агент и введите следующий код: 

_// Находим сотрудника Васильеву Л.П. (см. Пример 1)  
oCollab = tools.get\_doc\_by\_key( 'collaborator', 'fullname', 'Васильева Людмила Петровна' );  
alert ( 'Найден сотрудник ' + oCollab.TopElem.fullname + ' с идентификационным номером ' + oCollab.DocID ); // на экран выводится информация об отобранном сотруднике_

_// Находим электронный курс «Эффективные переговоры» (аналогично Примеру 1)  
oCourse = tools.get\_doc\_by\_key( 'course', 'name', 'Эффективные переговоры' );  
alert ( 'Найден курс ' + oCourse.TopElem.name + ' с идентификационным номером ' + oCourse.DocID ); // на экран выводится информация об отобранном курсе_

_// Назначаем сотруднику отобранный курс  
Result = tools.activate\_course\_to\_person( oCollab.DocID, oCourse.DocID );   
// Если данный курс не был ранее назначен, то возвращается ссылка на вновь созданный документ обучения.  
// Если данный курс был уже назначен ранее, то возвращается ID незаконченного курса.  
if ( OptInt (Result, 0) == 0) // Проверка, является ли переменная Result объектом или числом.   
// Если эта переменная – объект, то выражение OptInt (Result, 0) равно 0 (второму аргументу)  
// Если эта переменная – целое число, то выражение OptInt (Result, 0) больше 0  
{  
     alert ('Сотруднику ' + oCollab.TopElem.fullname + ' назначен курс ' + Result.TopElem.course\_name + '. Id незаконченного курса: ' + Result.DocID);   
}  
else   
{  
     alert ('Курс был назначен ранее! Id незаконченного курса: ' + Result );  
}_
