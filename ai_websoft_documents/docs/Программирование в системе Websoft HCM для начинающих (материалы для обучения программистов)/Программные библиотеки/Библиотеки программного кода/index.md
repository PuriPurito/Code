## Библиотеки программного кода

В настоящем разделе описываются методы, входящие в состав Библиотек программного кода. Библиотеки программного кода начали работать в системе с третьего квартала 2020 г.

Файлы Библиотек программного кода находятся в папке _WebTutorServer\\wtv\\libs\\_ , а файлы обращений к Библиотекам программного кода – в папке _WebTutorServer\\wt\\web\\library\\_.

Для вызова методов из Библиотек программного кода используется функция _tools.__call\___code\___library\___method_.

Синтаксис вызова метода из кода JavaScript:

      _tools.call\_code\_library\_method (<oLibraryParam>, <sMethodNameParam>, <arrParams>)_

В качестве аргументов для вызова методов из указанных библиотек используются: _<oLibraryParam>_ - код (условное название) библиотеки, в которой описан вызываемый метод, _<sMethodNameParam>_ - название вызываемого метода, _<arrParams>_ - набор параметров метода, перечисленных через запятую и заключенных в квадратные скобки.

Например:

_oRes = tools.call\_code\_library\_method( "libEducation", "ActivateCourseToEventBase", \[OptInt (iEventID), OptInt (iCourseID), 30, Date(), null\] );_

Здесь _"libEducation" -_ код (условное название) библиотеки (в данном случае используется Библиотека учебного центра _libEducation_)_, "ActivateCourseToEventBase" -_ название вызываемого метода (в данном случае используется метод назначения курса участникам мероприятия (метод удаленного действия)), _\[OptInt (iEventID), OptInt (iCourseID), 30, Date(), null\] -_ набор параметров метода <arrParams>, заключенных в квадратные скобки.
