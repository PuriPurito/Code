## Создание собственных библиотек

Пользователи могут создавать собственные кастомные библиотеки.  
Приведем простой пример создания подобной библиотеки.  
Для создания библиотеки выполните следующие действия:

1) Для удобства создайте на сервере системы отдельные папки для пользовательских библиотек и других кастомных файлов в разделах WebTutorAdmin и WebTutorServer (например, _WebTutorAdmin/custom\_folder/ и WebTutorServer/custom\_folder/_).

2) Создайте пустой текстовый файл с расширением _JS_ или _XML_ (например, _new\_lib.js_) и сохраните его в папки _WebTutorAdmin/custom\_folder/_ и _WebTutorServer/custom\_folder/_.

3) Введите в файл new\_lib.js пользовательскую функцию – например, такую: 

_function custom\_allert (alert\_text) {  
     alert ('The function of a custom library says: ' + alert\_text);  
}_

Сохраните файл.

4) Откройте тестовый агент и введите следующий код: 

_var lib = OpenCodeLib ("x-local://custom\_folder//new\_lib.js"); // подключение кастомной библиотеки (переменная, в которую сохраняется кастомная библиотека)  
lib.custom\_allert ('Привет, мир!'); // вызов функции из кастомной библиотеки_

5) Запустите агент, нажав на кнопку **Выполнить агент на стороне клиента**.

В результате на экран должно быть выведено сообщение _«Привет, мир!»_.

Примечание – При запуске на стороне клиента (например, с помощью кнопки **Выполнить агент на стороне клиента**) система ищет кастомную библиотеку в подпапке папки _WebTutorAdmin_, а при запуске на стороне сервера (например, с помощью кнопки **Запустить агент**) - в подпапке папки _WebTutorServer_.

После выполнения функций кастомной библиотеки она кэшируется в оперативной памяти сервера. После изменения кода библиотеки нужно очистить кэш. Это можно сделать путем перезагрузки сервера или с помощью специальной команды сброса кэша:  
_DropFormsCache ('\*new\_lib.js\*');_

Для устранения проблем с кодировкой кириллических выражений в файле библиотеки, подключаемой с помощью функции **OpenCodeLib**, этот файл необходимо сохранять в кодировке **UTF-8 with BOM**.
